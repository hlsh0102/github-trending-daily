## 项目概述

DeerFlow（全称 **D**eep **E**xploration and **E**fficient **R**esearch **Flow，深度探索与高效研究流）是由字节跳动开源的一款**超长任务超级代理框架**。它能够自主进行研究、编写代码并创造内容，通过整合沙箱、记忆系统、工具、技能、子代理和消息网关等组件，处理从几分钟到数小时不等的复杂任务。项目面向需要构建复杂 AI 代理系统的开发者、研究人员以及希望将高级 AI 自动化能力集成到自身应用中的团队。DeerFlow 2.0 是一次从零开始的重写，与 v1 版本代码完全不兼容，但保留了原版深度研究框架的核心思想并进行了全面升级。

## 核心功能

- **多层级任务编排**：支持从简单对话到需要数小时完成的多步骤复杂任务，自动将长周期目标分解为可执行的子任务序列。
- **子代理协同机制**：内置子代理调度系统，可以创建和管理多个专业化子代理，让它们协同工作以完成大规模任务。
- **沙箱化安全执行**：提供隔离的代码执行环境，让 AI 生成的代码在安全沙箱中运行，避免对主机系统造成影响。
- **持久化记忆系统**：具备长期记忆能力，能够在不同会话和任务间保持上下文，持续学习和积累知识。
- **可扩展技能库**：支持通过插件和自定义技能扩展代理能力，开发者可以轻松添加新的工具和功能模块。
- **消息网关**：统一的消息路由系统，管理子代理之间、代理与工具之间的通信，确保信息高效流转。

## 技术架构

DeerFlow 基于 Python 构建，采用模块化微服务架构设计。核心引擎负责任务调度与状态管理，每个子代理运行在独立的执行上下文中。沙箱系统基于容器化技术实现，确保代码执行的隔离性和安全性。记忆系统采用向量数据库存储语义记忆，结合结构化数据存储实现短期和长期记忆的协同工作。技能系统通过插件架构扩展，每个技能作为一个独立模块注册到代理框架中。消息网关基于事件驱动架构，支持异步消息传递和任务状态广播。整个系统在设计上强调可观测性，通过日志和事件追踪机制让开发者能够监控代理的决策过程和执行状态。

## 安装与使用

**安装步骤**：

1. 确保已安装 Python 3.10 或更高版本，以及 Docker（用于沙箱功能）。
2. 克隆仓库并进入项目目录：
   ```bash
   git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
   ```
3. 安装依赖并启动后端服务：
   ```bash
   cd backend
   pip install -e .
   # 或者使用 Makefile 一键启动
   make up
   ```
4. 配置环境变量，设置 LLM API 密钥（推荐使用豆包 Seed-2.0-Code、DeepSeek v3.2 或 Kimi 2.5）。

**最小可用示例**：

```python
from deer_flow import Agent, Skill

# 创建一个简单的代理
agent = Agent(
    model="deepseek-v3",
    skills=[Skill("web_search"), Skill("code_interpreter")]
)

# 执行一个研究任务
result = agent.run("研究最新的 Python 异步框架并写一个示例")
print(result)
```

更完整的示例和预配置场景请参考项目文档和 [官方网站](https://deerflow.tech) 上的 Demo。

## 适用场景

- **自动化深度研究**：让代理自主搜索、分析、整理信息，生成结构化的研究报告，适用于市场调研、技术预研、学术文献综述等场景。
- **代码生成与调试**：代理可以根据需求描述生成完整项目代码，并在沙箱中测试运行，自动修复错误，适合快速原型开发和自动化编程。
- **复杂工作流自动化**：将多个步骤的重复性工作（如数据采集、处理、分析和可视化）交给代理自动完成，解放人力。
- **智能对话系统增强**：为现有对话系统添加长期记忆、工具调用和子代理能力，实现更深度、更持久的智能交互体验。

## 项目亮点

- **长任务处理能力**：与其他代理框架相比，DeerFlow 专为数分钟到数小时的超长周期任务设计，能够有效管理长时间执行中的状态、上下文和资源。
- **企业级开源方案**：背靠字节跳动，拥有完善的技术文档和社区支持，同时保持开源精神和活跃的社区贡献。项目发布 2.0 版本后即登上 GitHub Trending 榜首。
- **完全模块化设计**：沙箱、记忆、技能、子代理等组件均可独立替换和扩展，开发者可以根据需求自由组合，不绑定特定实现。
- **多模型兼容**：推荐使用豆包、DeepSeek 和 Kimi 等顶尖模型，但框架设计上支持便捷地接入其他 LLM 提供商。
