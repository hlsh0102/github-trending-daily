## 项目概述

Harness 是一款专为 Claude Code 设计的团队架构工厂插件，它本质上是一种元技能（meta-skill）。该项目解决的核心问题是：如何让 AI 编程助手（如 Claude Code）能够根据不同的项目领域和需求，自动组建专业化的智能体团队，并为这些智能体生成所需的技能。用户只需要对 Harness 说一句话——“为这个项目创建一个 harness”，它就会自动分析项目领域，设计对应的智能体团队架构，定义专业化的智能体角色，并生成这些智能体运行所需的技能文件。

目标用户主要是使用 Claude Code 进行软件开发的工程师、技术团队负责人，以及希望将 AI 编程能力结构化和专业化的开发者群体。

## 核心功能

- **一键团队架构生成**：通过自然语言指令（支持英文、韩文、日文），Harness 可以自动分析项目领域，并生成完整的智能体团队架构配置。
- **领域智能体定义**：根据项目类型和需求，自动定义不同专业方向的智能体角色（如代码审查专家、架构师、测试工程师等）。
- **技能自动生成**：为每个定义的智能体生成其执行任务所需的技能文件（skills），确保智能体具备完成任务的能力。
- **六种架构模式支持**：内置 6 种不同的智能体团队架构模式，可根据项目需求选择最合适的协作方式。
- **多语言交互**：支持英语、韩语、日语三种语言的自然语言指令输入，方便全球开发者使用。
- **Claude Code 原生集成**：作为 Claude Code 的插件运行，无缝融入现有开发工作流。

## 技术架构

Harness 采用分层架构设计，位于 L3 Meta-Factory 层（元工厂层）和 Team-Architecture Factory 子层。这意味着它不仅是一个工具，更是一个能够创建工具的“元工具”。

从技术实现角度看，Harness 的核心基于 HTML 和 JavaScript，前端使用现代化布局和组件化设计。项目遵循以下关键设计原则：

1. **元编程范式**：Harness 不直接执行具体开发任务，而是生成用于完成任务的智能体团队及其技能，体现了“元”能力。
2. **模式驱动**：内置 6 种预定义的团队架构模式，这些模式覆盖了从单智能体到多智能体协作的各种场景。
3. **领域感知**：通过分析用户提供的项目上下文（如代码库结构、技术栈、项目目标），智能选择最合适的团队架构。
4. **可扩展架构**：用户可以根据需要自定义新的智能体类型或调整现有架构，系统支持灵活的扩展。

## 安装与使用

### 安装步骤

1. 确保已安装 Claude Code 并配置好环境。
2. 从 GitHub 仓库（revfactory/harness）克隆或下载项目文件。
3. 将 Harness 插件文件放置在 Claude Code 的插件目录中（具体路径请参考 Claude Code 文档）。
4. 重新启动 Claude Code 以使插件生效。

### 最小可用示例

安装完成后，在 Claude Code 中执行以下操作：

```
# 英文指令
Build a harness for this project

# 韩文指令
하네스 구성해줘

# 日文指令
ハーネスを構成して
```

Harness 会自动分析当前项目，并提供团队架构配置选项。用户可以选择预设的 6 种架构模式之一，或让 Harness 根据项目特点自动推荐。

## 适用场景

- **大型项目团队协作**：当面对复杂的大型软件项目时，Harness 可以快速搭建由不同专业智能体组成的高效协作团队，节省人工配置时间。
- **多项目并行开发**：对于需要同时管理多个不同领域项目的团队，Harness 可以快速为每个项目生成最适合的智能体团队架构。
- **快速原型验证**：在项目早期阶段，使用 Harness 快速建立智能体团队，加速技术选型和架构验证过程。
- **教育和培训场景**：新成员加入团队时，可以通过 Harness 生成的标准智能体团队配置快速了解和适应团队工作流程。

## 项目亮点

与同类项目相比，Harness 有以下显著差异化优势：

1. **元技能设计**：不同于直接提供功能工具的插件，Harness 是一种元技能——它不直接完成任务，而是创造完成任务的“工作者”和“工具”，这种设计理念在 AI 辅助开发领域较为超前。
2. **领域自适应能力**：能够根据项目上下文自动调整团队配置，无需用户手动配置复杂的参数。
3. **多语言支持**：原生支持三种语言，降低了非英语用户的使用门槛。
4. **丰富的架构模式库**：内置 6 种经过验证的团队架构模式，覆盖从简单到复杂的各种协作场景。
5. **与 Claude Code 深度整合**：作为官方插件运行，操作流畅，学习成本低。
