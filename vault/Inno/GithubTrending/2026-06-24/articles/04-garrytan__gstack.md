## 项目概述

gstack 是一套精心编排的 AI 辅助开发工具链，由 Y Combinator 总裁 Garry Tan 基于其 20 年产品构建经验提炼而成。该项目源于一个观察：在 AI 代理时代，单人开发者借助正确的工具配臵，能够实现传统团队数十人的交付效率。gstack 整合了 23 个高度意见化的工具，覆盖从产品构思、设计、工程管理、发布管理、文档撰写到质量保证的全流程，让个人开发者能够以“一人团队”的模式端到端地交付生产级软件。

## 核心功能

- **CEO 工具**：提供产品方向决策、战略优先级排序和市场分析能力，帮助开发者从商业视角评估功能取舍。
- **设计师工具**：自动生成 UI 原型、交互流程和设计规范，支持从文字描述直接转换为设计稿。
- **工程管理工具**：管理任务拆解、技术方案设计、代码审查和迭代节奏，模拟技术负责人的工作流程。
- **发布管理器工具**：自动化版本控制、变更日志生成、CI/CD 协调和灰度发布策略执行。
- **文档工程师工具**：从代码注释自动生成 API 文档、架构说明和用户手册，保持文档与代码同步。
- **QA 工具**：自动生成测试用例、执行端到端测试、捕获边界条件并报告回归问题。

## 技术架构

gstack 基于 TypeScript 构建，采用模块化的工具集合设计。每个工具都是一个独立的功能单元，通过统一的上下文协议进行通信和协作。核心架构包含三个层次：

1. **工具定义层**：每个工具都有明确的输入输出规范、职责边界和错误处理策略，确保工具之间可以串行或并行组合。
2. **编排引擎层**：管理工具的执行顺序和依赖关系，支持链式调用和条件分支，模拟真实团队中不同角色的协作流程。
3. **状态管理层**：维护项目上下文、决策记录和待办事项的持久化状态，确保多轮迭代中的连续性。

设计上强调“意见化”而非“可配臵”——预设了经过验证的最佳实践和工作流，减少使用者的决策负担。23 个工具各有明确角色，避免功能重叠，如同一个精干团队中每个成员各司其职。

## 安装与使用

前提条件：Node.js 18+ 和 OpenAI API 密钥（或其他兼容的 LLM 接口）。

```bash
# 克隆仓库
git clone https://github.com/garrytan/gstack.git
cd gstack

# 安装依赖
npm install

# 配臵 API 密钥
cp .env.example .env
# 编辑 .env 填入你的 API 密钥

# 初始化项目（交互式引导）
npm run init

# 运行完整工具链
npm run ship
```

最小可用示例：创建新功能

```bash
# 启动一个新功能开发周期
npm run feature:start "用户个人资料页"

# 设计阶段
npm run design "个人资料页应支持头像上传和简介编辑"

# QA 验证
npm run qa -- --coverage
```

## 适用场景

- **独立开发者快速构建 MVP**：单人开发者可以借助 gstack 完成从设计到上线的全流程，将原型到生产环境的时间从数周压缩到数小时。
- **小团队增强交付能力**：3-5 人团队使用 gstack 作为虚拟成员，覆盖团队能力短板，实现 10 人以上团队的工作量。
- **原型验证与快速迭代**：在项目早期需要高频次试错时，gstack 的自动化工具链可以大幅降低每次迭代的边际成本。
- **学习全栈开发流程**：初学者可以通过观察工具链如何决策和协作，理解专业团队的工作方式和最佳实践。

## 项目亮点

- **极低认知负载**：传统 AI 辅助开发需要开发者自行决定何时使用哪个工具或代理。gstack 将有经验的 CTO 级判断力固化为工具链，开发者只需给出产品意图。
- **可量化的效率提升**：项目维护者用逻辑代码变更衡量，声称 2026 年的单人年产量是 2013 年的 240 倍以上，这个维度的度量比原始代码行数更客观。
- **来自实战的沉淀**：工具配臵并非理论推导，而是源于实际项目中 40+ 公开功能和 3 个生产服务的交付经验，经过了极端高压环境验证。
- **角色化而非功能化**：将工具设计为拟人化的团队角色（CEO、设计师、PM 等），降低了理解和调用门槛，同时避免了功能臃肿。
