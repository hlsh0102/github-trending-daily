## 项目概述

**i-have-adhd** 是一个专为编码助手设计的技能插件，旨在让 AI 助手的输出更符合 ADHD（注意力缺陷多动障碍）友好型阅读习惯。它解决了开发者与 AI 编码助手交互时常见的痛点——AI 倾向于在回答的开头添加冗长的客套话、背景解释和“思考过程”，而将关键答案“埋没”在大量文本中。该插件的核心理念是：**行动优先，步骤编号，杜绝“希望这有帮助！”这类无效废话**。目标用户是使用 Claude Code、Codex 等编码代理的开发者，尤其是那些注意力容易分散、希望快速获取直接答案的用户——但正如项目所说，“不需要 ADHD 诊断即可使用”。

## 核心功能

- **答案前置输出**：AI 将直接给出解决方案或代码修改，而非先进行大量背景说明。用户第一眼看到的就是可操作的内容。
- **步骤编号与结构化**：所有输出内容以清晰的编号列表呈现，使信息层次分明，便于快速扫描和理解。
- **去除冗余客套话**：消除“希望这有帮助”、“如还有其他问题请随时提出”等无意义结尾，以及冗长的思考过程展示。
- **显式/隐式调用模式**：用户在 Claude Code 中可通过 `/i-have-adhd` 命令显式调用，在 Codex 中可通过 `$i-have-adhd` 触发；同时，编码代理会在识别到适合该风格的任务时自动隐式应用。
- **跨平台兼容**：支持 Claude Code、Codex 等主流编码代理，且安装过程统一通过插件市场管理，无需手动克隆仓库。
- **持久化启用选项**：用户可通过创建 `~/.claude/.i-have-adhd-always` 文件，使该技能在每个 Claude Code 会话中自动启用。

## 技术架构

本项目本质上是一个编码代理的“技能插件”，其技术实现基于编码代理（如 Claude Code、Codex）的插件/技能扩展机制。仓库以 Python 编写，但核心逻辑并非复杂的算法，而是一套精心设计的**提示词模板和行为规则**，用于修改 AI 的默认输出风格。安装时，编码代理的插件市场会从 GitHub 拉取仓库内容，并将其作为运行时技能应用。项目采用 MIT 开源许可，生命周期完全由插件市场管理，确保用户始终使用最新版本。其设计思路体现了“少即是多”的哲学——通过强制性的输出格式约束，提升信息传递效率。

## 安装与使用

安装过程非常简洁，用户无需手动克隆仓库。

**在 Claude Code 中安装：**
```bash
claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
```
安装后，在会话中键入 `/i-have-adhd` 即可应用该输出风格。若希望每次会话都自动启用，可执行 `touch ~/.claude/.i-have-adhd-always`。

**在 Codex 中安装：**
```bash
codex plugin marketplace add ayghri/i-have-adhd --ref main
codex plugin add i-have-adhd@i-have-adhd
```
使用 `$i-have-adhd` 显式调用，或让编码代理在合适场景下自动触发。

其他编码代理的安装方式请参考仓库中的 [INSTALL.md](./INSTALL.md) 文件。

## 适用场景

- **快速故障排查**：当需要 AI 立即给出代码错误修复方案时，无需阅读 AI 对问题的分析过程，直接定位到行动步骤。
- **日常代码审查与重构**：在审查代码并提出修改建议时，AI 输出更简练，专注于需要修改的具体行和改动内容。
- **学习与探索**：快速获取代码实现示例或架构建议，省去阅读冗长背景介绍的时间。
- **多任务切换频繁的开发环境**：开发者在不同任务间来回跳转时，AI 的直接输出能显著减少上下文切换的认知负担。

## 项目亮点

相比其他编码助手提示词优化方案，i-have-adhd 的差异化优势体现在：
- **极致简洁**：不是泛泛的“让回答更短”，而是定义了精确的格式约束（行动优先、步骤编号），可操作性极强。
- **零配置快速安装**：完全通过插件市场管理，安装仅需两条命令，无需手动编写提示词或修改配置文件。
- **无诊断门槛**：项目名称虽包含“ADHD”，但其设计对所有追求效率的开发者都有益，适用范围远超出特定人群。
- **高度可复用**：作为一个通用技能，只需一次安装即可在所有支持的编码代理间生效，且可通过持久化文件实现全局启用。
- **社区热度验证**：项目在 GitHub 上获得了 7184 颗星（单日新增 1866 颗），说明其准确切中大量开发者的真实需求。
