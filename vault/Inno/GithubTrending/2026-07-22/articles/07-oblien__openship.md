## 项目概述

Openship 是一个开源、可自行托管的部署平台，内置 CI/CD 能力。它允许开发者在推送代码后自动将应用容器化并部署到目标服务器，同时提供桌面应用、Web 仪表盘和命令行工具三种交互界面，满足不同使用习惯。项目主要面向需要轻量级部署方案的个人开发者、小型团队以及希望完全掌控基础设施的中小型企业，帮助其摆脱对云平台专有服务的依赖，降低部署成本与复杂度。

## 核心功能

- **自动化 CI/CD 流水线**：从代码推送开始，自动完成构建、测试、容器化与部署，减少手动操作步骤。
- **多界面支持**：提供桌面应用、Web 仪表盘和 CLI 三种操作方式，用户可根据场景灵活选择。
- **容器化部署**：基于容器技术（如 Docker）构建，确保应用环境一致性，简化跨环境迁移。
- **基础设施管理**：支持通过统一界面管理部署目标服务器的配置、资源与状态。
- **自托管部署**：平台自身可部署在用户自己的服务器上，保证数据与流程的完全可控。
- **开源社区驱动**：基于 Apache-2.0 协议开放源码，允许自由扩展与定制。

## 技术架构

Openship 采用 TypeScript 作为主要开发语言，前端使用现代化框架构建响应式界面，后端基于 Node.js 运行环境。其架构设计遵循模块化原则，核心组件包括：

- **编排引擎**：负责解析用户配置、调度构建任务、管理容器生命周期，与 Docker 或类似容器运行时交互。
- **事件驱动机制**：通过事件总线响应代码仓库（如 GitHub、GitLab）的 Webhook 触发，实现推流式 CI/CD。
- **多端适配层**：桌面应用基于 Electron 构建，Web 仪表盘采用前后端分离模式，CLI 通过 RESTful API 与后端通信，三者共享同一核心逻辑。
- **安全性设计**：支持 TLS 加密、令牌认证与角色权限控制，确保平台自身及所管理基础设施的安全。

整个系统设计为轻量化，不依赖 Kubernetes 等重型编排工具，适合在单机或小规模集群上运行，部署资源需求较低。

## 安装与使用

安装 Openship 主要有两种方式：

**方式一：一键安装（推荐）**
```bash
# 通过 npm 全局安装
npm install -g openship

# 启动 Openship 服务
openship start
```

**方式二：Docker 部署**
```bash
# 拉取最新镜像
docker pull oblien/openship:latest

# 运行容器，将配置文件挂载到宿主机
docker run -d -p 3000:3000 -v /path/to/config:/config oblien/openship:latest
```

**最小可用示例**：完成安装后，打开桌面应用或访问 `http://localhost:3000` 进入 Web 仪表盘。以下三步可完成首次部署：

1. 添加一个服务器节点（输入 SSH 连接信息）。
2. 连接一个 Git 仓库（如 GitHub），选择目标分支。
3. 配置简单部署触发规则（如推送至 main 分支自动部署）。

此后每次推送代码，Openship 将自动拉取变更、构建镜像并部署至指定服务器。

## 适用场景

* **个人项目快速部署**：个人开发者无需管理复杂 CI/CD 工具链，一个命令即可完成从代码到在线服务的完整流程。
* **小型团队内部工具**：团队可自建部署平台，将内部服务、微服务或管理面板的部署流程标准化与自动化。
* **边缘或私有化部署**：对数据合规性要求高的场景，如企业内部系统或边缘计算节点，可在自有服务器上运行 Openship，不依赖第三方云服务。
* **教育与实验环境**：学习容器化与 CI/CD 概念时，Openship 提供了一个低门槛的实践平台，便于理解自动化部署的全过程。

## 项目亮点

相比同类工具，Openship 的差异化优势在于：

- **全接口覆盖**：同时提供桌面应用、Web 端和命令行界面，是少有的“三端合一”的部署工具，满足不同用户偏好。
- **极低上手门槛**：安装仅需一条命令，无需预先配置 Kubernetes、Jenkins 等重量级工具，适合快速启动。
- **真正自托管**：平台本身完全可自托管，数据不经过第三方，用户掌握全部控制权，且不产生额外费用。
- **活跃社区响应**：项目 GitHub 上获得超过 6400 星，且近期增长迅速（单日新增 1500+ 星），表明社区活跃度高，用户反馈及时。
