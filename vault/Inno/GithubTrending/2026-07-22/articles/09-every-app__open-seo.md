## 项目概述

OpenSEO 是一款开源的 SEO（搜索引擎优化）工具，旨在成为 Semrush 和 Ahrefs 等商业工具的替代方案。它解决了传统 SEO 工具价格昂贵、功能臃肿、数据不透明等问题，面向个人站长、创业者、自由职业者以及希望自主控制 SEO 数据的技术团队。用户可以通过自带 API 密钥的方式按需付费，而非订阅昂贵的全功能套件，同时支持与 AI 智能体（如 Claude Code、OpenClaw）集成，实现自动化 SEO 工作流。

## 核心功能

- **关键词研究**：发现高潜力关键词，分析搜索量、竞争难度和趋势。
- **排名追踪**：监控网站在目标关键词上的每日排名变化，支持多维度对比。
- **竞争对手洞察**：分析竞争对手的关键词策略、流量来源和内容表现。
- **反向链接分析**：跟踪网站的反向链接概览，识别高质量外链机会。
- **站点审计**：全面扫描网站的技术 SEO 问题，如加载速度、爬虫友好度和页面结构。
- **AI 可见性分析**：评估网站内容在 AI 摘要、生成式搜索中的展现情况。

## 技术架构

OpenSEO 采用现代 Web 技术栈构建，核心基于 TypeScript，确保了代码的类型安全性和可维护性。项目设计为前后端分离架构，前端使用简洁现代的 UI 框架，提供专注型工作流而非复杂套件。后端集成 DataForSEO API，用户可自带密钥，实现按调用量计费。特别地，OpenSEO 内置了 MCP（Model Context Protocol）服务器，使 AI 智能体能够直接通过标准化接口获取和操作 SEO 数据。Agent Skills 则是预定义的可复用工作流，引导 AI 智能体自动完成关键词聚类、排名分析等任务。项目支持 Docker 化部署，便于用户在自有服务器上运行，并支持 fork 后自定义修改。

## 安装与使用

OpenSEO 提供托管版本和自托管两种方式。

**托管版本**：免费注册后即可使用，付费订阅 $10/月。

**自托管部署**（基于 Docker）：
1. 克隆仓库：`git clone https://github.com/every-app/open-seo.git`
2. 进入项目目录：`cd open-seo`
3. 复制环境配置：`cp .env.example .env`，并编辑填入 DataForSEO API 密钥。
4. 启动服务：`docker compose up -d`
5. 访问 `http://localhost:3000` 进入控制台。

**最小可用示例**：登录后，直接进入“关键词研究”模块，输入目标关键词，系统自动返回搜索量、竞争度和相关建议。若连接 AI 智能体，可发送“分析我的排名下降原因”等自然语言指令，AI 通过 MCP 调用日志数据进行解读。

## 适用场景

- **个人网站或博客优化**：站长可用低成本关键词研究和站点审计功能，提升内容搜索引擎友好度。
- **小型电商 SEO**：监控产品页和品类页的排名变化，同时分析竞品的反向链接策略，优化外链建设。
- **自由 SEO 顾问**：为多个客户管理项目，利用批量排名追踪和站点审计功能生成报告。
- **AI 驱动 SEO 自动化**：开发者将 OpenSEO 与自有 AI 系统集成，实现关键词批量筛选、内容策略生成等自动化任务。

## 项目亮点

- **按需付费**：无需订阅昂贵的全功能套件，自带 DataForSEO 密钥，仅支付实际使用的 API 调用费用。
- **AI 原生集成**：内置 MCP 服务器与 Agent Skills，让 AI 智能体直接操作 SEO 数据，开箱即用的自动化工作流。
- **简洁聚焦的 UI**：摒弃传统 SEO 工具的繁多功能，提供专注型工作流，降低学习成本。
- **完全可控**：开源代码可 fork 后定制，支持 Docker 自托管，数据不出服务器。
- **社区活跃**：MIT 许可，近期获得大量星标增长，社区贡献频繁。
