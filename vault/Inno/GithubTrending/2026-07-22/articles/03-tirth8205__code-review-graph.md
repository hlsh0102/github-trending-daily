## 项目概述

code-review-graph 是一个本地优先的代码智能图谱工具，专为 MCP（Model Context Protocol）和 CLI 场景设计。它通过构建代码库的持久化语义地图，让 AI 编码工具在代码审查和大型仓库工作流中只读取真正相关的代码片段，从而显著降低 token 消耗。根据项目基准测试，该工具在代码审查和大型仓库工作流中实现了可验证的上下文缩减效果，帮助开发者节省成本同时提升 AI 交互效率。目标用户包括使用 AI 辅助编码的开发者、需要频繁进行代码审查的团队管理员，以及希望优化 LLM 调用成本的高效工程团队。

## 核心功能

- **智能代码图谱构建**：自动解析代码库中的文件、类、函数、变量及其依赖关系，生成结构化的持久化语义关系图，供 AI 工具按需查询。
- **MCP 原生支持**：作为 MCP 服务器运行，与支持 MCP 协议的 AI 编码工具（如 Claude Desktop、VS Code 扩展等）无缝集成，提供按需的上下文检索能力。
- **CLI 工具集**：提供命令行接口用于手动或自动触发代码分析、图谱构建、上下文提取和 token 消耗报告，便于集成到 CI/CD 流程。
- **按需上下文提取**：针对给定任务（如“review this PR”），仅提取与变更文件和逻辑依赖相关的代码上下文，而非加载整个仓库，减少 token 使用量达 50%-90% 以上。
- **持久化存储与增量更新**：将构建的代码图谱持久化到本地文件系统，支持增量扫描以捕捉代码变更，避免每次分析时重建全部索引。
- **基准测试与报告**：内置基准测试套件，可量化上下文缩减效果，生成 token 节省和性能报告，帮助团队评估 ROI。

## 技术架构

code-review-graph 采用 Python 开发，核心架构围绕“代码解析器-图谱构建器-查询引擎”三层设计。解析层使用静态分析技术（如 AST 解析）提取代码结构，支持主流编程语言（包括 Python、JavaScript、TypeScript、Go 等），并保留了插件化扩展能力以覆盖更多语言。图谱构建层将解析结果组织为带权重的有向图，其中节点表示代码实体（文件、类、函数等），边表示依赖关系（调用、继承、导入等），并缓存关键元数据。查询引擎层根据用户输入（如文件变更列表或自然语言描述）计算最小上下文子图，优先返回关键依赖链而非完整文件，从而在保持语义完整性的前提下大幅减少传递给 LLM 的数据量。设计上强调本地优先，所有数据处理在用户机器上完成，不发送代码到外部服务，保障代码隐私和安全。存储层采用 SQLite 或自定义序列化格式，支持快速读写和增量更新。

## 安装与使用

安装方式简单，通过 pip 即可完成：

```bash
pip install code-review-graph
```

安装后，可使用以下命令初始化代码库分析：

```bash
crg init --path /path/to/your/project
```

该命令会扫描当前项目目录，构建代码智能图谱并保存到本地缓存目录。之后，可以启动 MCP 服务器：

```bash
crg serve --mcp
```

这将启动一个符合 MCP 协议的服务器，AI 工具（如 Claude Desktop 配置 MCP 服务器指向它的地址）即可自动使用图谱功能。你也可以通过 CLI 直接基于变更文件列表提取上下文：

```bash
crg context --files src/module_a.py:1-50,src/module_b.py --output json
```

输出结果包含最小必要上下文及其 token 量统计。

## 适用场景

- **代码审查工作流**：在 Pull Request 审查时，使用 code-review-graph 仅提取变更函数及其直接依赖的上下文，避免 AI 审查工具阅读整个仓库，将单次审查的 token 消耗降低 60%-80%。
- **大型仓库 AI 辅助编程**：在拥有数万文件的 monorepo 中，AI 编码助手通常因上下文过长导致响应变慢或成本过高。使用本工具的 MCP 集成，助手能快速定位相关代码，提升响应速度并节省费用。
- **CI/CD 自动化审查**：将工具集成到 CI 流水线中，在每次提交后自动计算变更的代码上下文，生成 token 使用报告和审查建议，帮助团队在预算内实现持续代码质量保障。
- **长期项目维护中的知识沉淀**：随着项目演进，code-review-graph 持续更新图谱，形成可查询的代码关系数据库，辅助新成员快速理解项目结构和逻辑依赖。

## 项目亮点

- **本地优先，数据隐私**：与依赖云端解析的竞品不同，所有代码分析在本地完成，无需上传代码到第三方服务器，适用于对代码安全有严格要求的组织。
- **显著且可衡量的上下文缩减**：项目公开提供了基准测试结果，真实场景下 token 节省可验证，非营销性宣称。用户可运行内置基准测试复现结果。
- **开放的 MCP 标准**：作为 MCP 的实现者，能与所有兼容 MCP 的 AI 工具协作，而不是绑定特定平台或厂商，降低了供应商锁定风险。
- **极低的集成成本**：pip 安装即可用，不需要复杂的配置或基础设施部署。支持主流语言和框架，对已有项目侵入性小。
