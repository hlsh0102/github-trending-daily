## 项目概述

jcode 是一个面向代码开发场景的下一代智能体框架，旨在为开发者提供能驾驭多会话工作流、具备无限可定制性且性能卓越的编码助手。该项目由 Rust 语言构建，核心目标是突破传统单次对话式编码助手的局限，将技能天花板提升至新的高度。无论是个人开发者、团队协作还是自动化流水线，jcode 都能作为高效的智能体核心，管理复杂的编码任务，实现从简单代码补全到大规模多步骤重构的全面覆盖。

## 核心功能

- **多会话工作流支持**：jcode 原生支持跨会话的上下文管理和任务编排，让智能体能够无缝衔接长时间、多步骤的编码任务，避免因会话中断导致的上下文丢失。
- **无限可定制性**：提供灵活的插件和配置系统，允许用户根据项目需求定制行为、提示词模板、工具调用逻辑，甚至接入外部 API 或数据库。
- **资源高效与性能优化**：基于 Rust 实现，占用内存和 CPU 极低，能轻松支撑同时运行的数十个会话，确保在复杂工作流中仍保持毫秒级响应。
- **智能上下文管理**：自动跟踪代码变更、依赖关系和项目结构，在长时运行时主动压缩或归档不必要的历史信息，保持上下文窗口高效利用。
- **多模态与工具集成**：支持与 Git、文件系统、代码解释器、测试框架等常见开发者工具无缝集成，通过统一接口调用外部资源。
- **开箱即用的安装与配置**：通过一行命令即可在 macOS、Linux 和 Windows 上完成安装，并内置智能体引导的初始化流程，降低上手门槛。

## 技术架构

jcode 采用 Rust 作为核心语言，充分利用其零成本抽象、内存安全和高并发能力。整体架构分为三层：

- **核心引擎层**：负责任务调度、会话管理、上下文压缩与恢复，采用事件驱动架构，支持异步 I/O 以处理多会话并发。
- **智能体层**：基于模块化设计，每个智能体实例可以运行独立的策略（如链式推理、反思、工具调用循环），并通过标准协议与核心引擎交互。
- **扩展层**：提供 Rust 和语言无关的绑定（如通过 JSON-RPC 或 WebSocket），允许用户用 Python、JavaScript 等语言编写自定义工具或动作。

设计上强调 **“最小默认配置，最大扩展能力”**，核心引擎仅保留最必要的功能，所有高级行为通过插件或配置文件注入。此外，内存管理采用引用计数和区域分配策略，大幅减少 GC（垃圾回收）带来的停顿。

## 安装与使用

### 安装

**macOS / Linux**：在终端执行一下命令即可安装最新版本：
```bash
curl -fsSL https://jcode.sh/install | bash
```

**Windows 11 (PowerShell 5.1+)**：
```powershell
irm https://jcode.sh/install.ps1 | iex
```

若需定制安装（如使用 Homebrew、源码编译、企业代理配置等），请参考官方文档中的“详细安装”章节。

### 最小可用示例

1. 启动 jcode 交互模式：
   ```bash
   jcode
   ```

2. 输入一个简单的编码任务，例如：
   ```
   /tool read myproject/src/main.rs
   Return the function sorted by line length in this file.
   ```

3. jcode 会自动读取文件内容，分析函数列表，并按排序结果输出。

4. 若需多会话支持，可用 `--session` 参数：
   ```bash
   jcode --session myproject-refactor
   ```

## 适用场景

- **大型代码库重构**：需要跨多个文件、多个会话逐步完成的重构任务，jcode 的持久化上下文和状态管理能避免重复加载和分析。
- **自动化代码审查与修复**：集成到 CI/CD 流水线中，自动对 Pull Request 进行深度审查、生成修复建议，甚至自动创建提交补丁。
- **交互式代码教学与探索**：学生或新手开发者可通过 jcode 与代码库进行自然对话，获得深度解释、示例生成和渐进式引导。
- **多模型协同工作流**：例如使用一个模型负责代码生成，另一个模型负责安全审查，jcode 可编排两者的协作流程。

## 项目亮点

- **性能优先**：相较于基于 Python 或 Node.js 的同类工具，jcode 在 Rust 的加持下，启动速度和内存占用低一个数量级，能轻松支撑 50+ 并发的会话实例。
- **会话持久化与无状态切换**：支持将会话状态序列化到磁盘，即使重启进程也能恢复，这对于长时间运行的重构任务至关重要。
- **极简主义与模块化**：核心二进制仅 5MB，但通过插件系统可扩展至任意复杂度，用户可选择性加载功能，避免臃肿。
- **开发者优先的体验**：文档齐全，提供 Web UI 和纯终端两种模式，并内置错误诊断和性能监控命令，方便调优。
