## 项目概述

CAD Skills 是一个专为 CAD（计算机辅助设计）、机器人学和硬件设计而构建的智能体技能库。该项目旨在弥合自然语言与物理设计之间的鸿沟，让用户能够通过文本指令直接生成、检查、切片和处理 CAD 模型及机器人描述文件。其目标用户包括硬件工程师、机器人开发者、创客、设计师，以及任何希望在本地项目中利用 AI 辅助完成几何建模与制造准备工作的技术人员。通过将复杂的 CAD 操作封装为可被智能体调用的技能模块，该项目大幅降低了传统 3D 建模软件的学习门槛，使设计迭代更加高效。

## 核心功能

- **文本到 CAD 生成**：支持通过自然语言描述直接生成三维几何模型，用户只需输入如“创建一个直径为 50mm、高 30mm 的圆柱”即可获得对应 CAD 实体。
- **模型检查与预览**：提供对生成的 CAD 几何体进行本地预览和检查的能力，确保设计符合预期后再进入下一步流程。
- **文件格式处理**：支持多种计算机辅助设计与机器人描述文件的导入、导出与转换，包括 URDF、SDF、SRDF 等机器人行业标准格式。
- **3D 切片准备**：包含针对 3D 打印的切片技能，可将 CAD 模型直接转换为 G-code 或其它可制造格式，简化从设计到制造的流程。
- **本地项目管理**：所有生成的 CAD 工件和机器人描述文件均以本地项目文件形式组织，便于版本管理和团队协作。
- **技能模块化设计**：每个 CAD 操作（如生成立方体、创建装配体、添加约束）都被设计为独立技能，用户可自由组合调用，构建自定义工作流。

## 技术架构

CAD Skills 采用基于 JavaScript 的模块化架构，核心设计围绕“技能”（Skill）这一抽象概念展开。每个技能文件通常包含 SKILL.md 文档、代码实现（支持多种语言）、依赖项说明（如 requirements.txt）和测试用例。技能之间通过标准化的输入输出接口进行通信，使得系统具有良好的可扩展性。项目深度利用了现代 Web 技术进行 3D 可视化，在前端侧集成了 Three.js 或类似引擎以提供实时的几何预览功能。在逻辑层，项目接入了大语言模型（LLM）作为智能体的大脑，负责理解用户文本意图并调度相应的技能执行。后端则负责处理文件系统操作、格式转换和与本地 CAD 引擎（如 OpenCASCADE 的 WebAssembly 版本）的交互。值得一提的是，项目对机器人描述文件（URDF、SDF、SRDF）提供了原生支持，这为机器人运动学建模与仿真提供了便利。

## 安装与使用

由于项目的定位是一个技能库，其安装需要基于特定的智能体框架。基本安装步骤如下：

1. **克隆仓库**：
   ```bash
   git clone https://github.com/earthtojake/text-to-cad.git
   cd text-to-cad
   ```

2. **安装依赖**：根据你的智能体框架（如 LangChain、AutoGPT 或其他兼容框架），安装所需的 Python 或 Node.js 依赖。核心技能文件在 `skills/cad/` 目录下，其依赖项列于 `requirements.txt` 中：
   ```bash
   pip install -r skills/cad/requirements.txt
   ```

3. **配置智能体**：在你的智能体配置文件中注册 CAD Skills 库，通常需指定技能目录路径和调用权限。

4. **使用示例**：启动智能体后，输入以下文本指令即可触发 CAD 生成技能：
   ```
   创建一个边长为 10mm 的立方体，并将模型保存为 STL 格式到当前目录。
   ```
   如果智能体响应成功，你可在指定目录找到生成的立方体文件，并通过内置预览功能查看。

## 适用场景

- **快速原型设计**：硬件初创团队或创客在概念验证阶段，可利用文本快速生成多种几何方案，加速设计迭代。
- **机器人系统集成**：机器人工程师需要为机械臂或机器人平台生成 URDF/SDF 描述文件时，可借助技能库将 CAD 模型自动转换为仿真格式，减少手动编写 XML 的工作量。
- **3D 打印工作流**：从设计到制造的整个链条中，用户可通过单一智能体完成模型生成、检查、修复和切片，无需在不同软件之间切换。
- **教育培训**：在 CAD 教学或机器人学课程中，学生可通过自然语言与系统交互，直观理解几何建模与运动学描述的关系。

## 项目亮点

与传统的 CAD 软件或单独的 AI 建模工具相比，CAD Skills 的核心差异化优势在于其**模块化技能体系**和**开放集成能力**。它不是一款封闭的应用程序，而是一个可与任何主流 AI 智能体框架组合使用的技能库。这种设计使得用户不必抛弃现有工作流，就能获得 AI 辅助的建模能力。此外，项目对机器人描述格式（URDF、SDF、SRDF）的一等公民支持，使其在机器人社区中具有独特价值。开发者可以轻松扩展现有技能，或基于项目提供的模板创建全新的 CAD 操作，这使得项目的成长潜力远超过传统的固定功能软件。
