📡 今日 GitHub 趋势 TOP10 速览 | 开源日报

1️⃣ World Monitor 🌍  
一个实时全球情报仪表盘，用 AI 聚合新闻、监控地缘政治、追踪基础设施。适合分析师、记者、决策者。支持通用/科技/金融/大宗商品等多视图。

2️⃣ 《深入理解 AI Agent》📘  
开源书籍，覆盖 AI Agent 完整设计 = LLM + 上下文 + 工具。含 88 个实验，支持中英文等多语言 PDF 下载。工程师和研究人员的入门到进阶必备。

3️⃣ code-review-graph 🗺️  
本地优先的代码智能图谱工具，为 MCP 和 CLI 设计。构建代码依赖图让 AI 只读相关代码，经测试可大幅减少 token 消耗，适合大型仓库开发。

4️⃣ i-have-adhd 🧠  
编程助手技能插件，让 AI 输出更符合 ADHD 用户习惯：行动优先、步骤编号、去掉废话。无诊断也可用，提升信息获取效率。

5️⃣ text-to-cad 🔧  
智能体技能库，支持文本指令直接生成、检查、切片 CAD 模型和机器人描述文件。降低硬件设计和 3D 建模学习门槛。

6️⃣ jcode 🦀  
Rust 编写的智能代理框架，面向多会话工作流。可定制结构、低资源占用、毫秒级响应。适合需要强大编码助手的专业开发者。

7️⃣ Openship 🚢  
开源自托管部署平台，内置 CI/CD。支持桌面、Web、CLI 三种方式部署容器化应用。适合需控制基础设施的团队或个人。

8️⃣ AstrBot 🤖  
AI 智能体助手与开发框架，整合 QQ、Telegram、微信等 IM 平台和多种 LLM，插件生态丰富。可替代 OpenClaw，轻松搭建聊天机器人。

9️⃣ OpenSEO 🔍  
开源 SEO 工具，替代 Semrush/Ahrefs。按需付费、自带 API 密钥，支持关键词研究、排名追踪、竞争分析、站点审计。可与 AI Agent 集成。

🔟 TradingView MCP Bridge 📊  
连接 Claude Code 与本地 TradingView Desktop，实现 AI 辅助图表分析、Pine Script 开发、流程自动化。本地处理，数据安全。
