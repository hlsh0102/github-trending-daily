# multica-ai/andrej-karpathy-skills

这是一个基于 Andrej Karpathy 对 LLM 编码陷阱观察的 CLAUDE.md 文件，旨在改善 Claude Code 的行为。它通过列出“先思考再编码”、“简洁优先”、“精准改动”和“目标驱动”四个原则，帮助开发者避免常见的 AI 编码错误，例如过度复杂化、不必要修改以及缺乏假设验证。该项目适用于所有希望更高效、更可靠地使用 Claude Code 的开发者。
