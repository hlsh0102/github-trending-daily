# abus-aikorea/voice-pro

> Voice-Pro 是一个基于 Gradio 的 Web 界面，面向创作者和开发者，提供语音识别、翻译和多语言配音功能。它集成了 Edge-TTS、Kokoro 等文本转语音引擎，以及 E2、F5-TTS、CosyVoice 等零样本语音克隆工具，并支持 Whisper 音频处理、YouTube 下载、Demucs 人声分离和多语言翻译。该项目适合需要批量处理音频、生成多语言配音或进行语音克隆的用户。
