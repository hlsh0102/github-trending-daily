# argoproj/argo-cd

> Argo CD 是一个基于 GitOps 原则的 Kubernetes 声明式持续交付工具。它将应用程序定义、配置和环境以声明式方式存储在 Git 仓库中，实现自动化部署和生命周期管理。适用于需要版本控制和审计追踪的 Kubernetes 集群运维团队。
