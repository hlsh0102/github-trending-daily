# facebook/astryx

> Astryx 是 Meta 内部使用八年的开源设计系统，为超过 13,000 个应用提供 150 多个可访问组件、品牌主题、暗色模式和 CLI 工具。它基于 React 和 StyleX 构建，无需额外构建插件或样式库即可直接使用，并支持通过 className 直接用 Tailwind、CSS Modules 等方式覆盖样式。该项目面向需要高度可定制、无样式锁定且支持人与 AI 助手协同构建的工程师和设计师。
