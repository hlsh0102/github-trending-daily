# superlinked/sie

> SIE 是一个开源的推理引擎，旨在通过单一的 OpenAI 兼容 API，为代理任务提供搜索、检索、文档转换、结构化输出及内容安全等各类模型服务。它解决了为每个任务分别部署独立模型服务器所带来的复杂性和资源浪费问题，将 100 多个模型整合到一个系统中，并按需加载。该项目适合需要自托管模型推理服务、希望简化代理基础设施的开发者或团队。
