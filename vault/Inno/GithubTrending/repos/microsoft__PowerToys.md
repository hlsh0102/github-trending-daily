# microsoft/PowerToys

> Microsoft PowerToys 是一套面向 Windows 系统的开源工具集合，旨在帮助用户自定义操作系统并提升日常操作效率。该项目提供了超过 30 种实用工具，例如高级粘贴、窗口置顶、颜色选取和批量文件重命名等，适合希望增强 Windows 功能、优化工作流程的普通用户和高级用户。
