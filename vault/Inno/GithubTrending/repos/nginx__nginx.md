# nginx/nginx

> NGINX 是世界上最流行的开源 Web 服务器、高性能负载均衡器、反向代理、API 网关和内容缓存软件。它采用简化的 2-clause BSD 许可证发布，提供企业级发行版和商业支持。该项目适合需要构建高并发、高可用 Web 基础设施的开发者和运维人员。
