# averygan/reclip

> ReClip 是一个自托管的开源视频和音频下载工具，提供简洁的 Web 界面。它基于 yt-dlp 支持从 YouTube、TikTok、Instagram 等 1000 多个网站下载内容，并可将视频保存为 MP4 或提取为 MP3。适合需要批量下载媒体文件且希望完全掌控自己数据的个人用户或开发者，后端仅为约 150 行的单一 Python 文件，无需复杂构建步骤，也可通过 Docker 快速部署。
