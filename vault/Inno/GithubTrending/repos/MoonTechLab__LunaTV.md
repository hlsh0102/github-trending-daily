# MoonTechLab/LunaTV

> MoonTV 是一个基于 Next.js 14、Tailwind CSS 和 TypeScript 构建的开源跨平台影视聚合播放器。它支持多资源聚合搜索、在线播放、收藏同步、播放记录和云端存储，并可作为 PWA 安装到桌面或移动端。项目本身不包含任何内置播放源，需要用户自行配置，适合希望自建影视聚合服务的技术用户。
