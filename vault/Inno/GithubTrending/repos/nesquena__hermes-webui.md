# nesquena/hermes-webui

> Hermes WebUI 是为 Hermes Agent 设计的轻量级 Web 界面，使用 Python 和原生 JavaScript 构建，无需构建步骤或框架。它通过三面板布局提供与终端体验完全一致的功能，包括会话管理、聊天、工作区文件浏览、模型和配置文件控制，用户可通过浏览器或手机直接操作。该项目面向希望以更便捷的图形化方式使用 Hermes Agent 自治代理的用户，尤其适合需要远程或移动端访问服务器代理的场景。
