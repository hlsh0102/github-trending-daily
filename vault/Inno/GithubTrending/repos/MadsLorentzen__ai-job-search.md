# MadsLorentzen/ai-job-search

> AI Job Search 是一个基于 Claude Code 的开源求职框架。用户只需填写个人资料，即可让 Claude 自动评估职位匹配度、定制简历、撰写求职信并准备面试。该项目针对丹麦求职市场优化了岗位搜索功能，但其核心工作流可适配其他地区的招聘网站。
