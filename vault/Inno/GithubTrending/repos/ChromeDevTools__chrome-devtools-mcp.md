# ChromeDevTools/chrome-devtools-mcp

> chrome-devtools-mcp 是一个开源项目，它通过模型上下文协议（MCP）为 AI 编码助手（如 Claude、Cursor 等）提供操控和检查 Chrome 浏览器的能力。该项目利用 Chrome DevTools 和 Puppeteer，使 AI 代理能够进行可靠的自动化操作、深度调试以及性能分析。它特别适合需要将 AI 编码工具与真实浏览器环境进行集成，以实现自动化测试、故障排查和性能优化的开发者和团队。
