# LMCache/LMCache

> LMCache 是一个用于大语言模型（LLM）推理的键值（KV）缓存管理层，旨在通过高效的缓存机制显著提升 LLM 的响应速度。它解决了长序列推理和多轮对话中重复计算 KV 缓存导致的延迟问题，适用于需要低延迟、高吞吐量的 LLM 部署场景，如聊天机器人、智能体工作负载等。该项目提供开箱即用的性能优化，支持主流 GPU 和 CPU 内存层级，并兼容 PyTorch 等框架。
