# nautechsystems/nautilus_trader

> Nautilus Trader 是一个基于 Rust 构建的生产级交易引擎，采用确定性事件驱动架构，专为高频和算法交易设计。它解决了在复杂市场环境中对低延迟、高可靠性和精确时序控制的需求，适用于专业交易员、量化研究员和机构开发者。该项目提供 Python 绑定，允许用户以 Python 编写策略逻辑，同时享受 Rust 带来的性能优势。
