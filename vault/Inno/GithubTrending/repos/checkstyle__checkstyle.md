# checkstyle/checkstyle

> Checkstyle 是一个 Java 代码质量检查工具，用于帮助开发者遵循特定的编码标准或最佳实践。它默认支持 Google Java Style Guide 和 Sun Code Conventions，并允许高度自定义规则。该工具可以通过命令行或 ANT 任务调用，适合希望在开发流程中自动执行代码风格检查的 Java 项目团队。
