# puppeteer/puppeteer

> Puppeteer 是一个 JavaScript 库，提供高级 API 来控制 Chrome 或 Firefox 浏览器。它通过 DevTools 协议或 WebDriver BiDi 与浏览器交互，默认在无界面（headless）模式下运行。该项目适用于需要自动化浏览器操作（如生成页面截图、抓取网页内容或测试 Web 应用）的开发者。
