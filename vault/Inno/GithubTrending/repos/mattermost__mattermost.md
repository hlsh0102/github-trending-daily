# mattermost/mattermost

> Mattermost 是一个开源的自托管协作平台，专为软件开发生命周期中的安全团队协作而设计。它提供聊天、工作流自动化、语音通话、屏幕共享及 AI 集成功能，核心代码采用 Go 和 React 编写，以单一 Linux 二进制文件运行并依赖 PostgreSQL 数据库。该项目适合需要完全控制数据、注重隐私和合规性的企业与开发团队。
