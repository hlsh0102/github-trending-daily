# RocketChat/Rocket.Chat

> Rocket.Chat 是一个开源、安全的团队通讯平台，使用 TypeScript 开发，专为对数据保护有高要求的组织设计。它支持实时消息、文件共享和可定制的部署选项，帮助团队、企业与客户之间进行私密且合规的沟通。该平台已被全球超过150个国家、数千万用户采用，包括德国铁路和美国海军等机构。
