# simplex-chat/simplex-chat

> SimpleX 是一个去中心化的即时通讯网络，其核心特点是完全摒弃用户标识符（如手机号、用户名），仅通过临时链接建立加密会话，实现最大程度的隐私保护。该项目专注于解决传统通讯服务中元数据泄露和身份追踪问题，适合注重隐私安全的个人用户、记者或任何需要匿名通信的场景。
