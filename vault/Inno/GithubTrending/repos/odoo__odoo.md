# odoo/odoo

> Odoo 是一套基于 Web 的开源商业应用程序套件，旨在帮助企业整合并管理客户关系、电子商务、库存、会计、人力资源等核心业务。它由多个独立可用的应用模块组成，模块间也能无缝集成，形成完整的企业资源计划系统。适用于各类中小企业，希望通过一个平台统一管理运营流程、降低软件采购成本。
