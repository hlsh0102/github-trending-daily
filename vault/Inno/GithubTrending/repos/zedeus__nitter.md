# zedeus/nitter

> Nitter 是一个免费开源的 Twitter 替代前端，专注于保护用户隐私和提升访问性能。它通过后端服务器转发所有请求，使客户端不直接与 Twitter 交互，从而防止 Twitter 追踪用户的 IP 地址或 JavaScript 指纹，同时无需开发者账号即可使用其非官方 API。该项目适合希望在不被跟踪的情况下浏览 Twitter 内容的用户，并支持 RSS 订阅和移动端访问，采用 AGPLv3 许可证。
