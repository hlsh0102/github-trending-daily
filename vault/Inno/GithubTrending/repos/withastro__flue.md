# withastro/flue

> Flue 是一个用 TypeScript 构建的智能体框架，旨在帮助开发者创建自主运行的 AI 智能体和复杂工作流。它提供了一个可编程的“沙箱”环境，让智能体能够安全地执行任务，例如处理 GitHub issue 的自动分类、复现和修复。该项目适合需要构建可靠、可扩展 AI 工作流的工程师，避免了从头搭建底层基础设施的繁琐工作。
