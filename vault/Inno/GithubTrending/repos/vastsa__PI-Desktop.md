# vastsa/PI-Desktop

> PI-Desktop 是一个本地优先的 AI 编程代理桌面应用，基于 Electron 构建界面，结合 Rust 编写的主机核心与 pi Agent Harness，支持用户自行安装插件扩展功能。它让开发者在本地打开任意项目，接入自己配置的模型服务，由代理执行编程任务，同时保持对过程的控制。该项目适合希望避免账号绑定、强制中转和编辑器锁定的开发者，支持 macOS、Windows 和 Linux。
