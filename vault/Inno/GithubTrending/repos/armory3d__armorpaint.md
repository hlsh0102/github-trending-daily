# armory3d/armorpaint

> ArmorPaint 是一款用于 3D PBR 纹理绘制的软件，基于 Armory 引擎开发，采用 C 语言编写。该仓库面向开发者，提供源代码以便自行编译和参与开发，但官方分发的二进制版本为付费软件，以支持项目持续发展。它适合需要为 3D 模型直接绘制 PBR 纹理的艺术家和技术用户。
