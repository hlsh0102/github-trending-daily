# andrewyng/aisuite

> aisuite 是一个轻量级的 Python 库，为多个生成式 AI 提供商（如 OpenAI、Anthropic 和 Google）提供统一的聊天补全接口，并在此基础上构建了支持工具和工具包的代理 API。它旨在简化开发者对不同大语言模型的调用与集成，同时支持本地运行（如 Ollama）以保护数据隐私。该项目适合需要跨模型开发 AI 应用或构建桌面代理的开发者，例如 OpenCoworker 便基于此库实现。
