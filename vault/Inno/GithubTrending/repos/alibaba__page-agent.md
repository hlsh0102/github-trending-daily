# alibaba/page-agent

> Page Agent 是一个基于 TypeScript 开发的 JavaScript 内页 GUI 代理库，允许用户通过自然语言直接控制网页界面。它无需浏览器扩展、Python 环境或无头浏览器，仅通过注入页面的 JavaScript 脚本即可实现基于文本的 DOM 操作，适用于需要自动化网页交互或构建智能助手的开发者。该项目由阿里巴巴开源，支持接入多种大语言模型，并提供可选的 Chrome 扩展以处理跨页面任务。
