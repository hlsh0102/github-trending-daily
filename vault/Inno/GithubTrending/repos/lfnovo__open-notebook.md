# lfnovo/open-notebook

> Open Notebook 是一个开源的、注重隐私的 Notebook LM 替代方案，旨在提供比原版更灵活和丰富的功能。该项目使用 TypeScript 开发，允许用户自行部署，从而完全控制自己的数据。适用于需要个性化笔记管理、知识整理和内容生成的开发者和团队。
