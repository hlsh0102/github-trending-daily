# abi/screenshot-to-code

> Screenshot-to-Code 是一个利用 AI 将截图、设计稿、Figma 设计甚至屏幕录制自动转换为干净代码的开源工具，支持 HTML、React、Vue 等多种技术栈。它主要面向希望将视觉设计快速转化为可运行代码的开发者或设计师，可通过本地部署或官方托管服务使用。
