# tt-a1i/archify

> Archify 是一个面向 AI 编码代理（如 Cursor、Claude Code、Codex CLI 和 OpenCode）的 Node.js 渲染与验证系统。它将代码库或系统描述转换为可视化的架构、流程、时序、数据流和生命周期图表，并生成自包含的 HTML 文件，支持动效和多种格式导出。该项目还提供架构变更对比功能，帮助开发者在合并前审查修改，适合需要清晰展示系统结构和验证变更的团队。
