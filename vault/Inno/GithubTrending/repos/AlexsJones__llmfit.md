# AlexsJones/llmfit

> llmfit 是一个用 Rust 编写的命令行工具，帮助用户从数百个模型和提供商中，快速找到适合自己硬件配置的大语言模型。通过一个命令，它能够评估并列出哪些模型可以在用户的设备上运行，避免用户手动比对模型参数与硬件规格。该工具适合需要在本地或自有硬件上部署大模型，但又担心性能不达标的开发者和技术用户。项目还提供了基准测试功能，用户可以测量并分享真实运行性能，以改进估算准确性。
