# MemPalace/mempalace

> MemPalace 是一个本地优先的 AI 记忆系统，以原文形式存储对话历史，并通过语义搜索进行检索。它不使用摘要、提取或释义来压缩记忆，而是以结构化的索引（如人物、项目、主题）来组织内容，支持范围限定搜索。该项目在 LongMemEval 基准测试中达到 96.6% 的 R@5 原始准确率，且完全不依赖外部 API 调用，适合需要高保真记忆管理的 AI 应用场景。
