# masterking32/MasterDnsVPN

> MasterDnsVPN 是一个基于 DNS 查询和响应的 TCP 流量隧道项目，旨在绕过网络审查。与 DNSTT 或 SlipStream 类似，但采用了不同的协议结构，自定义 ARQ 协议使传输头开销降低约 71%–88%。该项目针对高丢包、高延迟的恶劣网络环境进行了优化，适用于需要在受限网络下保持稳定连接的用户。
