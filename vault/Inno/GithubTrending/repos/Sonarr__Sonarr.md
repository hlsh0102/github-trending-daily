# Sonarr/Sonarr

> Sonarr 是一个面向 Usenet 和 BitTorrent 用户的 PVR（个人视频录像机）工具，可监控多个 RSS 源以自动获取、整理和重命名所关注剧集的新剧集。它还能扫描现有媒体库补全缺失剧集，并在出现更高画质版本时自动升级已下载文件。该项目适合希望自动化管理电视剧下载与媒体库整理的用户，支持 Windows、Linux、macOS、树莓派等主要平台。
