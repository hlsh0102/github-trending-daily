# dotnet/aspnetcore

> ASP.NET Core 是一个由 .NET 基金会维护的开源、跨平台框架，用于构建现代化的云端互联网应用程序，包括 Web 应用、物联网应用和移动后端。它基于 .NET 运行时，采用模块化组件设计，在保持灵活性的同时降低了开销。该框架适合需要在 Windows、macOS 或 Linux 上开发并部署到云端或本地的开发者。
