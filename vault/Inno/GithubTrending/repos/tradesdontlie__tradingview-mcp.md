# tradesdontlie/tradingview-mcp

> TradingView MCP Bridge 是一个开源工具，通过 Chrome DevTools 协议将 Claude Code 与本地运行的 TradingView Desktop 应用连接起来，实现 AI 辅助的图表分析、Pine Script 开发和流程自动化。它完全在本地处理数据，不传输或存储任何 TradingView 数据到外部，适用于已拥有有效 TradingView 订阅并希望借助 AI 提升个人图表分析效率的用户。
