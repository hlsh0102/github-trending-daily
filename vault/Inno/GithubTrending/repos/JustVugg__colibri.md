# JustVugg/colibri

> Colibrì 是一个用纯 C 实现的 MoE 大模型推理引擎，无外部依赖，通过将磁盘、内存和显存视为统一的分层推理架构，使消费级和异构硬件也能运行参数量达 744B 至 2.8T 的前沿 MoE 模型。它目前支持 GLM、Kimi、DeepSeek、Qwen 和 OLMoE 等多个模型家族，并提供统一的 chat、serve 和 web 命令行前端。该项目面向希望在自有硬件上本地部署超大规模 MoE 模型的开发者与研究者。
