# nodejs/node

> Node.js 是一个开源的、跨平台的 JavaScript 运行时环境，旨在让开发者使用 JavaScript 编写服务器端和网络应用程序。它基于 Chrome V8 引擎，采用事件驱动、非阻塞 I/O 模型，适用于构建高性能、可扩展的网络服务。该项目适合前端和后端开发者，以及任何希望在服务器端运行 JavaScript 的人。
