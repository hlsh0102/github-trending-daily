# zeux/meshoptimizer

> meshoptimizer 是一个 C++ 网格优化库，旨在减小三角形网格的存储体积并提升 GPU 渲染效率。它提供多种算法，例如顶点缓存优化、索引缓存优化以及网格简化，帮助图形应用程序在保持几何质量的同时降低带宽和计算开销。该库适用于游戏开发、实时渲染以及任何处理三角网格的性能敏感型场景。
