# nvm-sh/nvm

> nvm（Node Version Manager）是一个用于管理多个 Node.js 版本的工具，它通过一个 POSIX 兼容的 bash 脚本实现。该工具解决了开发者在不同项目间切换 Node.js 版本时遇到的版本冲突问题，允许用户轻松安装、切换和卸载特定版本的 Node.js。nvm 主要面向使用 Linux、macOS 或其他类 Unix 系统的 Node.js 开发者，尤其适合需要在多个项目中使用不同 Node.js 版本的用户。
