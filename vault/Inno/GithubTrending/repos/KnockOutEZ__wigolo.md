# KnockOutEZ/wigolo

> Wigolo 是一个为 AI 编码代理提供本地优先网络智能的工具，支持搜索、抓取、爬取和研究等功能。它无需 API 密钥，不依赖云端服务，且查询完全免费，所有数据仅存储在本地 `~/.wigolo/` 目录中。该项目适合需要在无网络计费或隐私敏感环境中运行 AI 代理的开发者，可通过 MCP 服务器、REST 端点或 SDK 集成到 Claude Code、Cursor、LangChain 等多种工作流中。
