# apple/container

> `container` 是苹果公司开发的工具，用于在 Mac 上通过轻量级虚拟机创建和运行 Linux 容器。它使用 Swift 编写，针对 Apple Silicon 进行了优化，并支持 OCI 镜像规范，因此用户可以从标准容器仓库拉取和推送镜像。该工具适合需要在 macOS 环境下使用 Linux 容器的开发者和系统管理员。
