# magnitudedev/magnitude

> Magnitude 是一个开源的推理服务器，旨在根据你的硬件配置运行最适合的本地模型，并与你现有的智能体工具无缝集成。它解决了依赖云端大模型带来的隐私、成本和网络限制问题，支持 Pi、OpenCode、Codex、Claude Code 等多种编程代理，使用户能够免费、私有且离线地运行本地模型。该项目主要面向希望在不牺牲数据隐私的前提下，利用本地算力驱动 AI 代理的开发者。其采用 Apache-2.0 许可证，并主要使用 TypeScript 编写。
