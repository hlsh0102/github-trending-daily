# chenyme/grok2api

> grok2api 是一个基于 Go 语言开发的多账户 API 网关，用于统一管理 Grok Build、Grok Web 和 Grok Console 的接口调用。它解决了在使用 Grok 服务时需要管理多个账户和端点的问题，通过集成多个账户并提供统一的 API 接口，简化了开发者的接入流程。该项目适合需要将 Grok 能力集成到自建应用或服务中的开发者，提供了基于 Web 的前端管理界面和 Docker 部署支持，便于快速搭建和使用。
