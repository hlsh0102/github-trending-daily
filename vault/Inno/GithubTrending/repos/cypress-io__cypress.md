# cypress-io/cypress

> Cypress 是一个基于 JavaScript 的前端端到端测试框架，专为现代 Web 应用设计。它直接在浏览器中运行测试，提供实时重载、自动等待和调试工具，以简化和加速测试流程。该项目适用于需要快速、可靠地验证浏览器中应用行为的前端开发者和测试工程师。
