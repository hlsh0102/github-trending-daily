# jdx/mise

> mise 是一个用 Rust 编写的命令行工具，旨在将开发工具版本管理、环境变量配置和任务执行整合到单一接口中。它解决了开发者在不同项目间切换时，需要分别使用多种工具来管理运行环境、依赖版本和构建脚本的问题。该项目适用于希望简化开发工作流、统一项目环境配置的开发者。
