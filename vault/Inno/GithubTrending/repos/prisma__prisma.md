# prisma/prisma

> Prisma 是一款面向 Node.js 和 TypeScript 的下一代 ORM（对象关系映射）工具，支持 PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、MongoDB 和 CockroachDB 等多种数据库。它通过声明式的 Prisma Schema 定义数据模型，自动生成类型安全的查询客户端，旨在解决传统 ORM 中手写 SQL 易出错、类型不安全以及数据库迁移繁琐的问题。Prisma 适合需要高效、安全地与数据库交互的全栈开发者和团队，尤其适用于 TypeScript 项目中对类型安全有高要求的场景。
