# swc-project/swc

> SWC（Speedy Web Compiler）是一个基于 Rust 语言编写的高性能 JavaScript/TypeScript 编译器。它旨在替代 Babel 等传统工具，通过利用 Rust 的速度优势，显著提升代码转换、压缩和打包的效率。该项目主要面向需要快速构建和优化现代 Web 应用的开发者，能够大幅缩短开发与构建过程中的等待时间。
