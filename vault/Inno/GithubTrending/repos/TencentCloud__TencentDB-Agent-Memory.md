# TencentCloud/TencentDB-Agent-Memory

> TencentDB Agent Memory 是一个为 AI Agent 提供本地长期记忆的开源项目。它通过四层渐进式管道将对话历史转化为结构化的人物角色和场景，无需依赖任何外部 API。该项目适用于需要高效记忆管理以降低计算成本并提升任务成功率的 AI 应用开发者和研究者。
