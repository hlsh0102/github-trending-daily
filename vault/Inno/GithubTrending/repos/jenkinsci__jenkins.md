# jenkinsci/jenkins

> Jenkins 是一个用 Java 编写的开源自动化服务器，通过超过 2000 个插件支持构建、测试、静态代码分析和部署等开发工作流的自动化。它帮助开发团队将重复性任务交给机器处理，从而专注于更有价值的工作。该项目适合任何需要持续集成和持续交付的软件开发团队。
