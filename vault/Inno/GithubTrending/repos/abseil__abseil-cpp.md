# abseil/abseil-cpp

> Abseil 是 Google 内部 C++ 代码库中经过生产环境广泛测试的公共组件集合，以开源形式发布。该项目旨在补充 C++ 标准库的功能，提供标准中缺失的实用工具或针对特定需求的高性能替代实现，适用于追求代码质量和可维护性的 C++ 开发者。它严格遵循 C++17 标准，不是对标准库的竞争，而是其增强层。
