# pascalorg/editor

> Pascal Editor 是一个基于 React Three Fiber 和 WebGPU 的 3D 建筑编辑器，帮助用户创建和分享建筑项目。它通过模块化的包结构（包括核心、渲染器、编辑器和节点定义）提供灵活的编辑和查看能力，适合建筑师、设计师和开发者快速构建和展示三维建筑场景。
