# Stirling-Tools/Stirling-PDF

> Stirling PDF 是一个开源的 PDF 编辑平台，支持在桌面应用、浏览器或自托管服务器上运行。它提供了超过 50 种 PDF 处理工具，包括合并、拆分、签名、OCR 和转换等功能，并且所有操作都在本地完成，无需将文档发送到外部服务。该软件适合需要安全、高效且可自定义 PDF 工作流的个人用户和企业开发者。
