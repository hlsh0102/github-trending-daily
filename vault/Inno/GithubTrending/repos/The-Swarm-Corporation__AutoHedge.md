# The-Swarm-Corporation/AutoHedge

> AutoHedge 是一个基于 Python 的企业级自主代理对冲基金系统，利用群体智能和专业化 AI 代理实现市场分析、风险管理与交易执行的自动化。该项目当前支持 Solana 链上的全自主交易，并计划扩展到 Coinbase 等更多交易所。其目标用户是需要高效、自动化交易解决方案的机构或开发者，系统采用多代理架构和风险优先的设计原则，以减少人工干预。
