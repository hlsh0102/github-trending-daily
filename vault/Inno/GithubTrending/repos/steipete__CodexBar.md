# steipete/CodexBar

> CodexBar 是一款适用于 macOS 14 及更高版本的菜单栏应用，用于实时显示 OpenAI Codex、Claude Code 等 AI 编码服务的使用限额与重置倒计时。它无需登录即可查看各提供商的配额、积分余额和费用信息，帮助用户规划长时间任务，避免因额度耗尽而中断工作。该项目适合频繁使用 AI 编码工具的开发者。
