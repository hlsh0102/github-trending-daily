# llvm/llvm-project

> LLVM 项目是一个包含模块化且可复用的编译器与工具链技术的开源集合，其核心提供了处理中间表示并将其转换为目标文件所需的工具、库和头文件。它解决了构建高效编译器、优化器和运行时环境的复杂问题，支持 C、C++、Objective-C 等语言，并附带 Clang 前端、libc++ 标准库和 LLD 链接器等组件。该项目面向编译器开发者、编程语言实现者以及需要构建高性能工具链的系统级程序员。
