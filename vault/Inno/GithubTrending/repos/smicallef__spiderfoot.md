# smicallef/spiderfoot

> SpiderFoot 是一个开源的 OSINT（开源情报）自动化工具，用于威胁情报分析和攻击面测绘。它集成了超过 200 个数据源模块，能够自动收集、分析并关联公开信息，帮助安全研究人员和渗透测试人员识别目标资产可能存在的风险。该工具提供 Web 界面和命令行两种使用方式，支持数据导出与自定义关联规则，适用于安全评估、漏洞管理和红队侦察等场景。
