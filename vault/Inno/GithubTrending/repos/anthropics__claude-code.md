# anthropics/claude-code

> Claude Code 是一个终端内的代理式编程工具，能够理解整个代码库，通过自然语言命令执行常规任务、解释复杂代码并处理 Git 工作流。它旨在帮助开发者提高编码效率，适用于在终端、IDE 或 GitHub 上使用。该项目由 Anthropic 开发，主要面向需要快速理解和操作代码库的软件工程师。
