# cloudflare/computer

> Cloudflare Computer 是一个虚拟文件系统，它运行在 Durable Object 中，并使用 SQLite 作为权威存储。该项目通过统一的 workspace.runtime.exec 接口，提供了容器、隔离 Shell 和隔离 JavaScript 三种可插拔的执行后端，使开发者能够在 Cloudflare 平台上运行真实的 Linux 二进制文件、Shell 命令或 ECMAScript 模块。它适用于需要在边缘环境中构建或执行代码的开发者，目前作为预览版本提供，API 设计仍在演进中。
