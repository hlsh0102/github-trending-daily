# cupy/cupy

> CuPy 是一个与 NumPy 和 SciPy 兼容的数组库，专为在 GPU 上进行加速计算而设计。它允许用户直接在 NVIDIA CUDA 或 AMD ROCm 平台上运行现有的 NumPy/SciPy 代码，无需修改即可获得显著的性能提升。该项目适合需要在 Python 中高效处理大规模数值计算的数据科学家和研究人员。
