# Kong/insomnia

> Insomnia 是一个开源的跨平台 API 客户端，支持 GraphQL、REST、WebSockets、SSE 和 gRPC 等多种协议。它提供了本地存储、Git 同步和云端同步三种数据管理方式，适合需要调试、设计、测试或模拟 API 的开发者和团队。通过内置的 OpenAPI 编辑器、测试套件和 CLI 工具，用户可以完成从开发到 CI/CD 集成的全流程工作。
