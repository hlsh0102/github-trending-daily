# Robbyant/lingbot-map

> LingBot-Map 是一个前馈式三维基础模型，专门用于从流式数据中重建场景。它通过几何上下文变换器架构，统一了坐标定位、密集几何线索和长程漂移校正，能够在高分辨率下以约每秒20帧的速度稳定处理超过一万帧的长序列。该项目适用于需要实时或大规模三维重建的机器人、自动驾驶和增强现实等领域。
