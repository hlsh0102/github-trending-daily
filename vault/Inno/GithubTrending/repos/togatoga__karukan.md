# togatoga/karukan

> Karukan 是一个基于神经网络的日语输入法系统，支持 Linux 和 macOS 平台。它利用 GPT-2 模型通过 llama.cpp 进行推理，实现高质量的假名-汉字转换，并提供实时转换、上下文感知和用户选择学习等特性。该项目适合需要高效、智能日语输入体验的用户。
