# tursodatabase/turso

> Turso 是一个进程内 SQL 数据库，兼容 SQLite。它旨在提供嵌入式数据库的简单性和性能，同时支持分布式部署和边缘计算场景。Turso 适合需要轻量级、低延迟数据库的应用程序开发者，特别是那些运行在边缘或受限环境中的应用。
