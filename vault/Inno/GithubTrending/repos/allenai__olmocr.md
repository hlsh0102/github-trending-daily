# allenai/olmocr

> olmocr 是一个开源的 PDF 转纯文本工具包，专为生成高质量的大语言模型训练数据集而设计。它能够将 PDF、PNG 和 JPEG 文档转换为结构清晰的 Markdown 文本，同时保留公式、表格和手写内容，并自动去除页眉页脚。该项目主要面向需要从 PDF 中提取干净、可读文本的 AI 研究人员和开发者。
