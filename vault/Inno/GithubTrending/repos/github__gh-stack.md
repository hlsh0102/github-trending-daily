# github/gh-stack

> gh-stack 是一个 GitHub CLI 扩展，用于管理堆叠式分支和拉取请求。它通过将大型变更拆分为一系列相互依赖的小型 PR，并自动处理分支创建、重基、PR 基础分支设置等繁琐步骤，解决了堆叠式开发流程中手动操作复杂易错的问题。该工具适合使用 GitHub 进行代码审查的开发者，特别是需要将大型功能拆分成多个可独立审查的小型 PR 的团队。
