# jellyfin/jellyfin

> Jellyfin 是一个自由开源的媒体系统服务器后端和 API，旨在管理和流式传输个人媒体库（如电影、电视节目、音乐和照片）。它解决了商业媒体服务器（如 Plex 或 Emby）的专有性和付费限制问题，适合希望完全控制个人媒体数据并避免订阅费用的用户。该项目采用 C# 开发，支持跨平台部署，并提供灵活的客户端应用程序生态。
