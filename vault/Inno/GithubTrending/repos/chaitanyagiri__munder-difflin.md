# chaitanyagiri/munder-difflin

> Munder Difflin 是一个开源的本地多智能体协调框架，旨在将你日常使用的终端编码 CLI（如 Claude Code、Gemini、OpenAI Codex 等）扩展为能够持续工作的“克隆体”，并在你自己的机器上协调多个智能体协同完成任务。它支持自带 API 密钥或本地 LLM，适用于希望自动化或并行处理编程任务的开发者。该项目目前处于工作原型阶段，基于 Electron、React 和 TypeScript 构建。
