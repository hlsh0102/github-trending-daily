# holaboss-ai/holaOS

> holaOS 是一个开源的、以本地优先为设计理念的 AI 智能体工作空间。它允许用户在一个统一的界面中运行 Claude Code、Codex 或 holaOS 等任何 AI 智能体，并通过 100 多种集成和 MCP 协议连接外部工具、应用、浏览器和本地文件，同时提供共享记忆功能。该项目面向需要高效管理和协调多个 AI 工作流的开发者和团队，支持使用内置的先进模型或自带 API 密钥（BYOK）。
