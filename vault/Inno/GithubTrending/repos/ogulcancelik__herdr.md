# ogulcancelik/herdr

> herdr 是一个运行在终端中的智能体多路复用器，专为需要同时管理多个编码智能体的开发者设计。它基于 Rust 语言构建，为每个智能体提供独立的真实终端环境，支持分屏、拖拽和标签页操作，并能清晰显示每个智能体的状态（阻塞、工作中或完成）。即使关闭笔记本电脑，所有智能体也能继续运行，你可以通过 SSH 从另一台终端或手机重新连接，无需图形界面或注册账户。
