# ColeMurray/background-agents

> Background Agents (Open-Inspect) 是一个开源的背景编程代理系统，允许开发者在处理其他任务的同时，让代理在后台自动完成编码工作。它支持完整的开发环境（Node.js、Python、git、浏览器自动化、VS Code），并可通过网页界面、Slack、GitHub PR、Linear 或 webhook 进行连接。该项目适合需要自动化代码任务、多人协作或定时调度工作的团队，但仅设计用于单租户部署，要求所有用户来自同一组织并信任彼此。
