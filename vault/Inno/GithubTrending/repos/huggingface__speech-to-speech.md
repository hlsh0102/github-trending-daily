# huggingface/speech-to-speech

> Speech-to-Speech 是一个低延迟、完全模块化的语音智能体管道，由 Hugging Face 开源。它将语音活动检测、语音识别、大语言模型推理和语音合成串联起来，并对外提供与 OpenAI Realtime API 兼容的 WebSocket 接口。项目允许用户自由替换每个组件，并支持将大语言模型指向云服务或本地部署的开源模型，适合需要构建本地、端到端语音对话系统的开发者和研究人员。
