# abhigyanpatwari/GitNexus

> GitNexus 是一个完全运行在浏览器中的客户端代码智能引擎，能够将 GitHub、GitLab、Azure 或本地的 Git 仓库或 ZIP 文件转化为交互式知识图谱，并内置基于图谱的 RAG 智能问答代理。它旨在帮助开发者快速理解复杂代码库的结构与关系，适用于代码探索、项目分析和知识管理场景。该工具无需服务器端部署，所有处理均在用户本地浏览器中完成，且项目明确声明不涉及任何加密货币或代币。
