# github/spec-kit

> Spec Kit 是一个开源工具包，用于帮助开发者从零开始实施基于规范的驱动开发（Spec-Driven Development）。它提供 CLI 工具、预设模板和与 AI 编码代理的集成，让团队能够专注于产品场景和可预测的结果，而非从头编写每段代码。该项目适合希望提高软件质量和开发效率的 Python 开发者及团队。
