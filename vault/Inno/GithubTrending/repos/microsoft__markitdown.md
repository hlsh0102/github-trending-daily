# microsoft/markitdown

> MarkItDown 是一个轻量级的 Python 工具，用于将 PDF、Word、Excel、PPT 等多种格式的文档和文件转换为 Markdown 格式。它专注于保留文档中的标题、列表、表格、链接等结构信息，以便于大型语言模型和文本分析管线消费。该项目适合需要批量转换办公文档为结构化文本的开发者或数据分析师。
