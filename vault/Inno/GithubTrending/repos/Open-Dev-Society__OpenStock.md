# Open-Dev-Society/OpenStock

> OpenStock 是一个开源的市场数据追踪平台，旨在作为昂贵商业行情服务的免费替代方案。它支持查看实时价格、设置个性化提醒，并浏览详细的公司信息。该项目面向希望以零成本获取股票行情与基本面数据的个人投资者和开发者，采用 TypeScript 编写并遵循 AGPL-3.0 许可证。
