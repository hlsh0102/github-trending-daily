# OtterMind/Chat2DB

> Chat2DB 是一款开源的、跨平台的数据库客户端和 SQL 工作台，支持 Windows、macOS 和 Linux。它集成了 AI 助手，允许用户使用自有模型通过自然语言生成、解释和优化 SQL，同时提供完整的 SQL 编辑、执行与格式化功能。该项目面向开发人员、数据库管理员、数据分析师和数据团队，旨在提升数据库操作与查询效率。
