# santifer/career-ops

> Career-Ops 是一个基于 AI 的求职系统，利用 Claude Code 的智能代理能力，帮助求职者自动化搜索、分析和申请工作。该项目提供 14 种技能模式、Go 语言编写的仪表盘、PDF 简历生成以及批量处理功能，旨在让求职者像企业筛选候选人一样高效地选择合适的工作。适合希望提升求职效率、利用 AI 技术优化求职流程的开发者或求职者。
