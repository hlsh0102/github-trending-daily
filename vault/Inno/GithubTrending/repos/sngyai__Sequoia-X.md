# sngyai/Sequoia-X

> Sequoia-X 是一个面向 A 股市场的自动量化选股系统，使用 Python 编写。它基于多种技术形态（如海龟突破、均线放量等）在每日收盘后自动扫描全市场股票，并通过飞书推送选股结果。该项目适合个人投资者或量化爱好者，用于自动化跟踪市场技术信号，节省每日人工复盘的时间。
