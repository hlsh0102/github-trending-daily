# HKUDS/Vibe-Trading

> Vibe-Trading 是一个基于 Python 的个人交易代理项目，旨在通过一条命令为用户提供全面的交易功能。它结合了 FastAPI 后端和 React 前端，支持用户自定义策略并自动执行交易操作。该项目适用于希望快速搭建自动化交易系统的个人投资者和开发者。
