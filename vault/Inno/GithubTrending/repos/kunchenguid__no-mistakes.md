# kunchenguid/no-mistakes

> no-mistakes 是一个基于 Go 语言开发的本地 Git 代理工具。它在本地与远程仓库之间建立一个验证层，当开发者执行 `git push no-mistakes` 时，工具会自动创建临时工作区，运行基于 AI 的代码校验流程，确保推送的代码符合预设的质量标准。该工具适用于希望减少人工审查工作量、提高代码合并请求（PR）质量的开发团队和个人。
