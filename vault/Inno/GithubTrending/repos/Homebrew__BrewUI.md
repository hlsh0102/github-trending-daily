# Homebrew/BrewUI

> BrewUI 是 Homebrew 官方推出的 macOS 图形界面，基于 SwiftUI 构建，面向不熟悉命令行的用户，使其能够以图形方式发现、安装、更新和管理 Homebrew 软件包。该工具在简化操作的同时保持对底层 Homebrew 操作的完全透明，要求 macOS Tahoe 26 及以上版本，并提供 brew cask 安装方式。
