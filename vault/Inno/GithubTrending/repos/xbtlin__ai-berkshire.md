# xbtlin/ai-berkshire

> AI Berkshire 是一个基于 Claude Code 的价值投资研究框架，将巴菲特、芒格、段永平、李录四位投资大师的方法论系统化，并通过多 Agent 并行分析实现专业级投资研究。该项目旨在解决直接向 AI 提问时获得的分析往往流于表面、无法用于实际决策的问题，通过强制输出明确结论（通过/不通过/灰色地带）和具体价格区间，提升分析质量和决策纪律。该框架适合希望借助 AI 工具进行深度、结构化价值投资研究的个人投资者。
