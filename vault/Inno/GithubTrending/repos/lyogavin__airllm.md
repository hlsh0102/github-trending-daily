# lyogavin/airllm

> AirLLM 是一个开源项目，通过优化推理内存使用，使得如70B参数规模的大型语言模型能够在单张4GB显存的GPU上运行，而无需使用量化、蒸馏或剪枝等压缩技术。该项目支持包括Llama 3.1 405B、DeepSeek-V3 671B在内的多种最新模型，适用于显存有限的个人开发者和小型团队进行大模型推理。
