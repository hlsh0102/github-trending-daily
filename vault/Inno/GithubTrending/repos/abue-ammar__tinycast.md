# abue-ammar/tinycast

> Tinycast 是一个用 Swift 编写的原生 macOS 启动器，提供快捷键唤起、应用搜索和剪贴板历史功能。它基于 SwiftUI 和 AppKit 构建，无第三方依赖，内存占用低于 100 MB，并可运行 Raycast 扩展。该项目面向需要轻量、注重隐私的 macOS 效率工具用户。
