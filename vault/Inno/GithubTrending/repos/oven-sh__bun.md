# oven-sh/bun

> Bun 是一个用 Rust 编写的 JavaScript 运行时、打包器、测试运行器和包管理器，旨在替代 Node.js。它通过内置的 JavaScriptCore 引擎大幅缩短启动时间并降低内存消耗，同时提供了从开发到部署的全套工具链。该项目适合希望提高 JavaScript/TypeScript 应用性能并简化开发工具链的开发者。
