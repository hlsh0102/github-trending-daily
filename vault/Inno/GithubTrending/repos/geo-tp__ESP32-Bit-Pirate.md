# geo-tp/ESP32-Bit-Pirate

> ESP32 Bit Pirate 是一个基于 ESP32 的开源固件项目，它将设备转变为多协议开发与调试工具，灵感来源于经典的 Bus Pirate。它支持通过串口终端或基于 Web 的 CLI 界面，与 I2C、UART、SPI、1-Wire 等数字协议以及蓝牙、Wi-Fi、Sub-GHz、RFID 等无线协议进行交互，包括嗅探、发送、脚本编写等操作。该项目面向硬件爱好者、嵌入式开发者和安全研究人员，帮助他们分析和调试各种数字与无线通信接口。
