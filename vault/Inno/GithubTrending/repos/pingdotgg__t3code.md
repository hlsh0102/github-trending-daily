# pingdotgg/t3code

> T3 Code 是一个轻量级的 Web 界面，用于对接多种代码生成代理，包括 Codex、Claude、Cursor 和 OpenCode。它旨在为开发者提供统一的操作入口来调用不同 AI 编码工具，无需在多个终端或界面间切换。该项目适合已经安装并认证了至少一个代码代理服务的开发者，目前处于早期阶段，可能存在缺陷。
