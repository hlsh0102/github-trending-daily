# grokability/snipe-it

> Snipe-IT 是一个免费开源的 IT 资产/许可证管理系统，用于跟踪公司内部的硬件设备（如笔记本电脑）和软件许可证。它基于 Laravel 框架构建，采用 Web 方式运行，需要部署在服务器上通过浏览器访问。该项目适合 IT 运维人员使用，帮助管理资产的生命周期、折旧和合规性。
