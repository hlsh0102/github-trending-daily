# majd/ipatool

> ipatool 是一个命令行工具，用于在 App Store 中搜索 iOS、iPadOS、tvOS 和 visionOS 应用，并下载对应的 ipa 安装包。它解决了开发者和测试人员在非越狱设备上获取应用包进行调试或存档的需求。该工具支持 Windows、Linux 和 macOS，并可通过 Apple ID 进行认证。
