# gabime/spdlog

> spdlog 是一个快速且功能丰富的 C++ 日志库，支持 C++11 及更高版本。它以高性能和易用性为主要目标，提供了丰富的日志格式化选项、多种输出目标（如文件、控制台、系统日志等）以及灵活的日志级别和异步日志支持。该项目适用于需要高效、可靠日志记录的 C++ 应用程序开发者，尤其适合对日志性能有较高要求的场景。
