# WhiskeySockets/Baileys

> Baileys 是一个基于 WebSocket 的 TypeScript 库，用于与 WhatsApp Web API 交互。它允许开发者通过代码实现发送和接收 WhatsApp 消息等自动化操作，适用于需要将 WhatsApp 集成到自己的应用中的开发者。该项目以 MIT 许可证开源，在 GitHub 上拥有超过一万颗星，是社区中较为活跃的 WhatsApp 非官方 API 实现之一。
