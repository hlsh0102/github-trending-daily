# PrismML-Eng/Bonsai-demo

> Bonsai Demo 是一个用于在本地运行 Bonsai 系列语言模型的演示项目。它支持在 Mac（Metal）、Linux/Windows（CUDA、Vulkan、ROCm）或 CPU 上运行 1-bit 和三元量化的模型，并新增了 27B 参数的多模态视觉-语言模型，能够处理图像、截图和 PDF。该项目为开发者提供了便捷的工具调用和本地推理能力，适合需要高效运行量化语言模型的研究人员和工程师。
