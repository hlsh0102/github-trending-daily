# NanmiCoder/MediaCrawler

> MediaCrawler 是一个基于 Python 的多平台自媒体数据采集工具，支持小红书、抖音、快手、B站、微博、贴吧、知乎等主流网站的帖子、视频、评论等公开信息爬取。该项目利用 Playwright 等自动化技术模拟用户浏览行为，帮助开发者和研究人员高效获取社交媒体上的结构化数据，用于学习和研究目的。
