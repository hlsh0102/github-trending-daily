# roboflow/supervision

> Supervision 是 Roboflow 开发的开源 Python 工具包，为计算机视觉应用提供可复用的组件，包括数据加载、模型推理结果处理、目标检测跟踪、区域计数和标注等功能。它旨在简化计算机视觉项目从数据准备到部署的常见流程，适合需要快速构建视觉应用的开发者。
