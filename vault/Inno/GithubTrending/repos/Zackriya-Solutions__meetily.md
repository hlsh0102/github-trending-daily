# Zackriya-Solutions/meetily

> Meetily 是一款注重隐私的 AI 会议助手，基于 Rust 开发，支持在本地 100% 处理语音数据，无需依赖云端服务。它利用 Parakeet/Whisper 模型实现 4 倍速的实时语音转录、说话人分离，并能通过 Ollama 生成会议摘要。该项目适合需要在 macOS 或 Windows 上自行托管、且对数据隐私有严格要求的用户。
