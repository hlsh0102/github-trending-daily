# Universal-Debloater-Alliance/universal-android-debloater-next-generation

> Universal Android Debloater Next Generation 是一款基于 Rust 编写的跨平台图形界面工具，通过 ADB 连接无需 root 的 Android 设备，帮助用户移除不必要的系统和预装应用。该项目旨在提升设备隐私性、安全性和电池续航，降低攻击面。适用于希望精简 Android 系统、优化性能且不获取 root 权限的用户。
