# apache/ossie

> Apache Ossie（孵化中）是一个开源规范项目，旨在标准化数据分析、AI和商业智能平台之间的语义元数据交换格式。它通过提供供应商中立的JSON和YAML规范，解决数据栈中同一指标在不同工具定义不一致的问题，减少团队手动协调语义定义的工作量。该项目主要面向数据工程师、AI代理开发者和BI平台使用者，帮助他们在异构工具间维护一致的业务逻辑和数据定义。
