# Comfy-Org/ComfyUI

> ComfyUI 是一个基于节点/图界面的模块化扩散模型图形界面与后端引擎，专为内容创作而设计。它允许用户以灵活的方式组合和配置扩散模型工作流，适用于需要精细控制生成过程的艺术家、研究者和开发者。该项目提供了 API 和图形界面，使得复杂 AI 生成任务变得可定制和可复用。
