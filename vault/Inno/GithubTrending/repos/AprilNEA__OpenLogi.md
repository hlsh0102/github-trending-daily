# AprilNEA/OpenLogi

> OpenLogi 是一个用 Rust 编写的本地优先的罗技 Options+ 替代品，旨在通过 HID++ 和 UVC 协议解锁罗技鼠标、键盘和网络摄像头的完整功能，如按键重映射、DPI 调整和 SmartShift。它不需要账号，也没有遥测，注重隐私和本地控制。该项目目前处于积极开发阶段，适合希望深度定制罗技设备并避免官方软件限制的用户。
