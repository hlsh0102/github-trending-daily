# Mebus/cupp

> CUPP（Common User Passwords Profiler）是一个基于Python的命令行工具，用于根据用户个人信息生成可能的密码字典。它通过交互式问答收集目标用户的昵称、生日、宠物名等细节，结合常见模式生成候选密码列表，主要服务于合法的渗透测试和取证调查场景。
