# cursor/plugins

> Cursor/plugins 是 Cursor 官方维护的插件仓库，提供一系列用于开发者工具、框架和 SaaS 产品的插件。每个插件都包含独立的目录和 .cursor-plugin/plugin.json 清单文件，方便开发者集成到 Cursor 环境中。该项目主要面向使用 Cursor 进行代码开发的用户，帮助他们通过插件扩展编辑器的功能，如持续学习、团队工作流、代码审查等。
