# firecrawl/pdf-inspector

> pdf-inspector 是一个用 Rust 编写的快速 PDF 检查和分类库，能够智能区分文本型、扫描型和图像型 PDF，并提取文本及转换为 Markdown。该库无需 OCR，可在约 200 毫秒内处理文本型 PDF，帮助用户避免昂贵的 OCR 服务。适用于需要批量处理 PDF、进行文档路由或高效提取内容的开发者，并提供 Python、Node.js 和浏览器 WebAssembly 绑定。
