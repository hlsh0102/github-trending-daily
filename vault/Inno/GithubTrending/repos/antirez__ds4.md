# antirez/ds4

> DwarfStar（ds4）是一个专注于本地推理的引擎，优先支持 DeepSeek V4 Flash 模型，同时也兼容 GLM 5.2 和 DeepSeek V4 PRO。它针对 Apple Metal、NVIDIA CUDA 和 AMD ROCm 平台进行了优化，可在高内存 Mac、DGX Spark 或 Strix Halo 等消费级硬件上运行，并支持通过 SSD 流式加载以降低内存需求。项目面向希望在没有云端依赖的本地环境运行强大模型的开发者和研究者，提供自包含的推理、HTTP 服务器和编码代理功能。
