# andrewrabert/jellium-desktop

> Jellium Desktop 是一个非官方的 Jellyfin 桌面客户端，使用 Rust 语言开发，基于 CEF 和 mpv 构建。它解决了 Jellyfin 媒体服务器在桌面平台上缺乏原生客户端的问题，支持 Linux、macOS 和 Windows 系统。该应用适合希望获得更原生、更流畅的 Jellyfin 桌面体验的用户。
