# huxingyi/autoremesher

> AutoRemesher 是一个跨平台的自动四边形网格重拓扑工具，能够将高多边形网格转换为干净的四边形拓扑结构。它适用于需要低多边形网格的计算机图形学、游戏开发和数字雕刻领域，帮助用户自动生成适合动画和渲染的四边形网格。该项目基于 Geogram、libigl 等开源库构建，支持 Linux、Windows 和 macOS 系统。
