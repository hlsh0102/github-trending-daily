# opendataloader-project/opendataloader-pdf

> OpenDataLoader PDF 是一个开源的 PDF 解析器，专为 AI 数据提取而设计。它能将 PDF 文件转换为 Markdown、JSON（含边界框）和 HTML 格式，支持表格、公式、图像和图表等复杂元素的提取。该工具在多个基准测试中表现优异，适合需要从 PDF 中高效获取结构化数据的开发者和 AI 研究人员。
