# iOfficeAI/OfficeCLI

> OfficeCLI 是首个专为 AI 代理设计的 Office 套件，以单个二进制文件的形式提供对 Word、Excel 和 PowerPoint 文件的读取、编辑与自动化操作。它完全免费且开源，无需安装 Microsoft Office，通过内置的 HTML 渲染引擎实现高质量文档渲染，使 AI 代理能够完成“渲染-查看-修正”的闭环控制。
