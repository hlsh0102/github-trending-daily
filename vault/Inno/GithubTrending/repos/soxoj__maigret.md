# soxoj/maigret

> Maigret 是一款开源工具，仅通过用户名即可在超过 3000 个网站上搜索该用户的账号，并收集网页上公开的个人信息。它无需 API 密钥，适用于安全研究人员、调查记者或任何需要根据单一用户名快速汇总数字足迹的人员。项目采用 Python 编写，支持定期更新站点列表以保持覆盖率。
