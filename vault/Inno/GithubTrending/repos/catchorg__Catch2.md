# catchorg/Catch2

> Catch2 是一个现代 C++ 原生测试框架，支持单元测试、测试驱动开发（TDD）和行为驱动开发（BDD），兼容 C++14、C++17 及更高版本。它提供简单的断言语法、灵活的测试用例命名、嵌套的 section 机制用于共享 setup/teardown 代码，以及基础微基准测试功能，旨在简化测试编写流程。该框架适合希望用自然 C++ 表达式编写测试，同时需要轻量级基准测试支持的 C++ 开发者。
