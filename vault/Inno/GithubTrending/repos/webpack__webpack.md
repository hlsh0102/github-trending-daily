# webpack/webpack

> webpack 是一个开源的 JavaScript 模块打包器，它能够将项目中分散的多个模块（如 CommonJS、AMD、ES6 模块、CSS、图片等）打包成浏览器可直接加载的静态资源。它通过代码分割功能支持按需加载应用的部分代码，并借助 loader 机制支持各种自定义资源类型，适用于构建现代 Web 应用的前端开发场景。
