# AhmadIbrahiim/Website-downloader

> Website-downloader 是一个基于 Node.js 的工具，能够下载指定网站的完整源代码及其所有资源（包括 JavaScript、CSS 和图片）。它利用 wget 和 archiver 在后台抓取并压缩网站文件，再通过 Socket 通道将结果发送给用户。该项目适合需要离线保存网页内容或迁移网站资源的开发者。
