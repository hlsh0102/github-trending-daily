# VoltAgent/awesome-design-md

> awesome-design-md 是一个精选的 DESIGN.md 文件集合，这些文件源自知名品牌设计系统的分析。该项目的核心是提供预定义的设计规范（如模式、令牌和规则），开发者可以将一个 DESIGN.md 文件放入自己的项目中，然后让 AI 编码代理根据这些规范生成视觉一致的用户界面。它旨在通过使用纯文本的 Markdown 文件，简化 AI 驱动 UI 生成的设计保持过程，适合希望快速实现与品牌设计语言相一致的界面开发场景。
