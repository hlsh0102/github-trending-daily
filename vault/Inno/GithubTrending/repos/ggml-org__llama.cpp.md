# ggml-org/llama.cpp

> llama.cpp 是一个用 C/C++ 实现的大语言模型推理引擎，专注于在消费级硬件（如个人电脑和移动设备）上高效运行 LLaMA 系列模型。它通过量化、内核优化等手段降低显存与计算需求，使开发者无需昂贵服务器即可本地部署和运行大语言模型。该项目适合需要私有化部署、离线推理或研究模型高效运行原理的技术用户。
