# AgriciDaniel/claude-obsidian

> claude-obsidian 是一个基于 Obsidian 和 Claude Code 的本地优先知识管理系统，它能将你投入的任意源材料自动读取、链接并归档为相互关联的纯 Markdown 知识图谱。该项目解决了传统笔记工具中信息孤岛和手动整理成本高的问题，适合希望利用 AI 辅助进行个人知识管理、构建第二大脑的用户。它基于 Karpathy 的 LLM Wiki 模式，提供了一套 Agent Skills，可作为开源替代方案，同时确保用户完全拥有自己的文件数据。
