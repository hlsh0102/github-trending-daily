# aaif-goose/goose

> Goose 是一个开源的通用 AI 代理，能够安装、执行、编辑和测试代码，并支持多种大型语言模型（LLM）。它可以作为桌面应用、命令行工具或 API 使用，适用于编程、研究、写作、自动化和数据分析等任务，旨在在本地机器上运行并替代传统的代码补全工具。本项目已迁移至 Linux 基金会下的 Agentic AI Foundation（AAIF），并采用 Apache-2.0 许可证。
