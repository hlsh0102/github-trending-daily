# n0-computer/iroh

> iroh 是一个基于 Rust 的模块化网络栈，它通过公钥而非 IP 地址来建立连接。该项目解决了传统 IP 地址因网络变动而失效的问题，为需要可靠、快速连接的应用（如分布式系统、去中心化网络）提供了直接的连接或中继回退方案。iroh 集成了打洞技术和 QUIC 协议，旨在简化网络通信的复杂性。
