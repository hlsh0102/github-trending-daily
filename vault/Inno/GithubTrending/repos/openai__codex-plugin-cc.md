# openai/codex-plugin-cc

> 这是一个为 Claude Code 用户设计的插件，用于在现有工作流中直接调用 OpenAI Codex 进行代码审查或任务委派。它提供了多个斜杠命令（如 /codex:review 用于只读审查，/codex:rescue 用于后台任务委派），满足需要在不离开 Claude Code 环境的情况下利用 Codex 能力的开发者需求。用户需拥有 ChatGPT 订阅（含免费版）或 OpenAI API 密钥，并安装 Node.js 18.18 或更高版本。
