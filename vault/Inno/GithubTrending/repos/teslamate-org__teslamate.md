# teslamate-org/teslamate

> TeslaMate 是一个自托管的特斯拉车辆数据记录工具，能够自动收集并存储车辆的状态、行程、充电记录等信息。它基于 Elixir 构建，数据存储在 PostgreSQL 数据库中，并通过 Grafana 提供可视化分析面板。适用于希望深入了解自己车辆使用情况、进行数据分析和长期监控的特斯拉车主。
