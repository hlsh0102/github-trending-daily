# diegosouzapw/OmniRoute

> OmniRoute 是一个免费的 AI 网关，提供统一的 API 端点，连接 236 个 AI 提供商（其中 50 多个免费），支持 Claude、GPT、Gemini 等模型。它通过 RTK + Caveman 压缩技术可节省 15–95% 的 token，并具备自动故障转移功能，适用于需要稳定、低成本访问多种 AI 模型的开发者和工具（如 Claude Code、Coder、Cursor、Cline、Copilot）。该项目基于 TypeScript 构建，采用 MIT 许可证，旨在消除 API 限流和成本焦虑，实现不间断编码。
