# BuilderIO/agent-native

> Agent-Native 是一个开源框架，用于构建同时具备丰富用户界面和自主代理能力的应用。它解决了传统上用户界面与自主代理相互分离的问题，使二者能共享同一数据库和状态，实现双向实时同步。该框架适合希望开发兼具交互式界面与智能代理功能应用的开发者，支持多用户实时协作和上下文感知操作。
