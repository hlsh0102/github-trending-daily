# colbymchenry/codegraph

CodeGraph 是一个为 Claude Code、Cursor、Codex、OpenCode 和 Hermes Agent 等 AI 编码代理设计的语义代码知识图谱工具。它通过构建项目代码的预索引知识图谱，显著减少 AI 代理的 token 消耗和工具调用次数，从而降低使用成本（约 35%）并提高效率。该工具完全本地运行，无需 Node.js 环境即可一键安装，适合希望优化 AI 辅助编码体验的开发者。
