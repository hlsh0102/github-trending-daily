# pranshuparmar/witr

> witr 是一个用于排查系统进程、端口、容器或文件启动来源的命令行工具，提供 CLI 和交互式 TUI 两种界面，并支持输出机器可读的 JSON 格式。它通过追踪启动链（如 systemd → PM2 → node）来回答“为什么这个进程在运行”的问题，适用于需要快速定位系统异常进程或理解运行环境的运维人员和开发者。
