# Pumpkin-MC/Pumpkin

> Pumpkin 是一个使用 Rust 语言从头构建的 Minecraft 服务器软件，旨在提供高速、高效且高度可定制的游戏体验。它通过多线程架构优化性能，同时兼容最新版本的 Java 和 Bedrock 客户端，并支持插件扩展。该项目适合追求高性能和低资源占用的 Minecraft 服务器运维者，以及希望深入定制服务器行为的开发者。
