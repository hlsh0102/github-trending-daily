# vitali87/code-graph-rag

> code-graph-rag 是一个基于知识图谱的代码库检索增强生成（RAG）工具，专为大型单仓库（monorepo）设计。它通过构建代码间的依赖与调用关系图谱，帮助开发者用自然语言查询、理解并修改跨多种编程语言的代码库。该项目适用于需要高效导航复杂代码库的开发者团队，能够提升代码检索与理解的效率。
