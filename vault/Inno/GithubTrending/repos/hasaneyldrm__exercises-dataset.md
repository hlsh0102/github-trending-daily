# hasaneyldrm/exercises-dataset

> 这是一个包含1,324项健身练习的结构化数据集，为开发者构建健身应用后端提供脚手架。每条记录包含练习名称、类别、目标肌群、所需器材以及6种语言（英语、西班牙语、意大利语、土耳其语、俄语、中文）的分步教学说明。该项目专为需要快速搭建健身练习数据库、API或生成训练提示的开发者设计，但请注意练习的媒体文件（缩略图和动画）因版权争议未包含在内。
