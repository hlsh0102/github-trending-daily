# cloudflare/security-audit-skill

> security-audit-skill 是一个面向编码代理的安全审计技能，将代理转变为安全审计员。它通过侦察、覆盖驱动的漏洞搜寻、候选人验证、结构化输出、独立记录核验和目标中立的报告六个阶段执行多阶段审计，生成可独立验证的机器可读发现。该技能适合需要对单一代码仓库进行结构化安全审计的开发者和安全团队使用。
