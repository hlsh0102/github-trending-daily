# K-Dense-AI/scientific-agent-skills

> Scientific Agent Skills 是一个面向科学研究的 AI 智能体技能库，提供 163 个经过验证的即用技能和 100 多个科学数据库，覆盖生物学、化学、医学和药物发现等领域。该项目旨在将任何 AI 智能体（如 Cursor、Claude Code 等）转变为能够辅助科学研究的工具，适用于科研人员、药物研发人员等需要快速获取和分析科学数据的用户。它遵循开放的 Agent Skills 标准，兼容多种主流 AI 编程工具，并采用 MIT 许可证开源。
