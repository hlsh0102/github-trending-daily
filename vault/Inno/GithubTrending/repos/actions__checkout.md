# actions/checkout

> actions/checkout 是一个 GitHub Actions 的官方动作，用于在工作流程运行环境中检出仓库代码。它解决了自动化构建和测试流程中获取代码的初始步骤问题，支持多种配置选项，如指定分支、标签或提交哈希，以及适配不同触发场景下的安全策略。该工具主要面向使用 GitHub Actions 进行持续集成和部署的开发者。
