# microsoft/terminal

> Windows Terminal 是微软开发的一款现代、高性能的终端应用程序，支持命令行工具、PowerShell、WSL 等。它解决了传统 Windows 控制台在渲染、多标签页支持等方面的局限，提供 GPU 加速渲染、自定义主题和 Unicode 文本支持。该项目面向开发者和系统管理员，适合需要在 Windows 上高效管理多个命令行会话的用户。
