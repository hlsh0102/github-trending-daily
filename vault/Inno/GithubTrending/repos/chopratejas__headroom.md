# chopratejas/headroom

> Headroom 是一个上下文压缩层，用于在将工具输出、日志、文件和 RAG 分块发送给大语言模型（LLM）之前进行压缩。它可以将令牌数量减少 60–95%，同时保留原始答案的准确性。该项目适用于需要降低 API 成本或提升推理速度的 AI 代理和 LLM 应用开发者。
