# opengeos/GeoLibre

> GeoLibre 是一款免费开源、轻量级的云原生 GIS 平台，用于可视化、探索和分析地理空间数据。它能在 Web 浏览器、桌面端、移动端以及 Jupyter notebook 中运行，同时保证用户数据的本地化和隐私性。该项目适用于需要跨平台地理信息处理能力的研究者、开发者和数据分析师。
