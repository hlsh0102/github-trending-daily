# cordiverse/cordis

> Cordis 是一个基于 TypeScript 的元框架，专注于时空组合性的编程范式。它旨在解决在空间和时间维度上组合多个实时交互系统（如 AR、XR 或多智能体应用）时的复杂性问题，为开发者提供统一的抽象层。该项目处于积极开发阶段，API 尚未稳定，适合对新型编程模型有兴趣的研究人员和前沿应用开发者。
