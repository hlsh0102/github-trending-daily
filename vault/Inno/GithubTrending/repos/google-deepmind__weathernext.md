# google-deepmind/weathernext

> WeatherNext 是 Google DeepMind 和 Google Research 开发的全球中期天气预报与热带气旋预测模型的开源代码库，包含第二代模型 WeatherNext 2 以及前代模型 GraphCast 和 GenCast 的实现。该项目旨在利用人工智能技术提供比传统数值天气预报更快、更准确的预报结果，适合气象研究、灾害预警以及依赖天气数据应用的开发者使用。代码库还提供了通过多种云平台和 API 直接获取模型预测数据的途径，方便用户无需自行运行模型即可集成到业务中。
