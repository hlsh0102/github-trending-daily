# fmtlib/fmt

> {fmt} 是一个开源的 C++ 格式化库，旨在提供比 C 标准 stdio 和 C++ iostreams 更快、更安全的格式化替代方案。它实现了 C++20 的 std::format 和 C++23 的 std::print 标准，并支持位置参数，便于本地化。该项目适用于需要高效、类型安全且易用的格式化输出的 C++ 开发者，尤其是那些希望遵循现代 C++ 标准的项目。
