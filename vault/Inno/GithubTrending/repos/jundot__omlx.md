# jundot/omlx

> oMLX 是一个专为 Apple Silicon Mac 设计的 LLM 推理服务器，提供连续批处理和 SSD 缓存（分层 KV 缓存）以优化本地大语言模型的运行效率。它通过 macOS 菜单栏进行管理，用户无需深入命令行即可启动和管理推理服务。该项目适合希望在 Mac 上高效运行本地 LLM 的开发者、研究人员以及注重隐私的用户。
