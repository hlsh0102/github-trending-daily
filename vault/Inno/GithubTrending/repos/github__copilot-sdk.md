# github/copilot-sdk

> GitHub Copilot SDK 是一个多平台软件开发工具包，旨在将 GitHub Copilot 的代理工作流集成到各类应用程序中。它提供了 Python、TypeScript、Go、.NET、Java 和 Rust 等语言的 SDK，让开发者能够直接调用经过生产验证的代理运行时，无需自行构建编排逻辑。该项目适用于希望在其应用中嵌入 Copilot 代理功能（如自动规划、工具调用和文件编辑）的开发团队。
