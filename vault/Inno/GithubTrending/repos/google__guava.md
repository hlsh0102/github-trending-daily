# google/guava

> Guava 是 Google 提供的一套核心 Java 库，包含多种新集合类型（如 multimap 和 multiset）、不可变集合、图库以及并发、I/O、哈希、基本类型和字符串处理等工具。它广泛用于 Google 内部及众多其他公司的 Java 项目中。Guava 提供 JRE 和 Android 两种版本，分别适用于 Java 8+ 环境和 Android 平台。
