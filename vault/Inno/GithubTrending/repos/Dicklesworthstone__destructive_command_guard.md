# Dicklesworthstone/destructive_command_guard

> Destructive Command Guard (dcg) 是一个用 Rust 编写的高性能钩子程序，用于拦截 AI 编程助手（如 Claude Code、Codex CLI、Gemini CLI 等）执行的危险 git 和 shell 命令，防止意外删除或破坏代码。它通过在内核级（如 ptrace 或基于 eBPF 的方式）监控命令行为，在命令执行前将其阻断，适用于需要保护开发工作区安全的 AI 代理场景。
