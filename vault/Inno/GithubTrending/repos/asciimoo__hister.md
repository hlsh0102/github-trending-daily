# asciimoo/hister

> Hister 是一个私有的本地搜索引擎，用于索引用户访问过的网页和保存的文件，并对其完整内容建立索引，以便日后检索。它提供网页界面、终端以及通过 MCP 连接的 AI 助手等多种查询入口。该项目适合希望在本地自行管理浏览与文件搜索记录、避免依赖第三方搜索服务的个人用户。
