# infiniflow/ragflow

> RAGFlow 是一个开源的检索增强生成（RAG）引擎，它将 RAG 技术与 Agent 能力相结合，为大型语言模型（LLM）提供高质量的上下文层。该项目主要面向需要构建基于私有知识库的问答、文档分析等场景的开发者与企业用户，旨在解决大模型在专业领域知识不足和幻觉问题。它支持从多种格式的文档中提取信息，并通过可配置的流程优化检索结果，从而提升生成内容的准确性和可追溯性。
