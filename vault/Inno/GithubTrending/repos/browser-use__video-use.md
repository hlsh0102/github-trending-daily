# browser-use/video-use

> video-use 是一个开源工具，允许用户通过自然语言对话（例如与 Claude Code 交互）来编辑视频。它将原始素材文件夹作为输入，自动执行剪辑、去除填充词、调色、添加字幕和动画覆盖等任务，最终生成完成的视频文件。该项目面向需要快速、无模板视频编辑的内容创作者、开发者或任何希望通过代码而非传统界面进行视频处理的人。
