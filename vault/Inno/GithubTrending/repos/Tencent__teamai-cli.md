# Tencent/teamai-cli

> TeamAI 是一个基于 TypeScript 的命令行工具，用于在 Claude Code、Codex、CodeBuddy、WorkBuddy、OpenCode、Cursor 等多种 AI 编码代理之间统一管理团队共享的技能、规则、MCP 配置与知识库。它通过将共享经验存放在 Git 仓库中，解决团队成员在不同 AI 代理间配置分散、难以同步和复用的问题。该工具面向需要以团队为单位标准化使用 AI 编码代理的开发团队及个人开发者。
