# microsoft/TypeScript

> TypeScript 是 JavaScript 的超集，它在 JavaScript 的基础上增加了可选的静态类型系统。该语言旨在帮助开发者构建大规模应用程序，通过类型检查在开发阶段捕获潜在错误，从而提升代码质量和可维护性。编译后的代码是标准的、可读的 JavaScript，可运行于任何浏览器或宿主环境。它适合需要更高可靠性和工具支持的 JavaScript 开发者。
