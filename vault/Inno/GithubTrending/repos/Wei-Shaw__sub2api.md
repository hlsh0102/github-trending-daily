# Wei-Shaw/sub2api

> Sub2API 是一个开源的 AI API 网关中转服务，用于将 Claude、OpenAI、Gemini、Grok 等订阅统一接入并分配配额。它主要面向需要共享订阅以分摊成本的个人或小团队，支持拼车式多人共用，并允许现有工具直接兼容使用。该项目使用 Go 语言开发，并提供了相应的 Web 管理界面。需要注意的是，其使用可能违反上游服务商的服务条款，项目仅用于技术学习与研究。
