# alibaba/zvec

> zvec 是由阿里巴巴开源的一款轻量级、高性能的进程内向量数据库。它主要解决在资源受限环境（如边缘设备或单机应用）中，对向量数据进行快速索引和相似性搜索的问题，适用于需要本地化、低延迟向量检索的场景。该项目使用 C++ 编写，并提供 Python 和 Node.js 绑定，适合开发者将其作为嵌入式组件集成到自己的应用中。
