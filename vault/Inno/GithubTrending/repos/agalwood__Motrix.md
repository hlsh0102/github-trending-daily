# agalwood/Motrix

> Motrix 是一款功能全面的桌面下载管理器，支持 HTTP、FTP、BitTorrent 和磁力链接等多种下载协议。其 v2 版本（Motrix Turbo）使用 Electron、React 和 TypeScript 重新构建，将下载核心与界面分离，并通过开放的 MDXP 协议（基于 JSON-RPC 2.0）与浏览器扩展和命令行工具通信。该项目适合需要在 macOS、Windows 或 Linux 上管理多种下载任务，或在 NAS 和家用服务器上通过无头模式和 Web 界面进行下载的用户。
