# PaddlePaddle/PaddleOCR

> PaddleOCR 是一个由百度开发的开源 OCR 工具包，能将 PDF 或图片中的文字、表格、公式等内容提取为结构化的 JSON 或 Markdown 数据，供大语言模型直接使用。它支持 100 多种语言，内置了基于视觉语言模型的文档解析引擎，在文字识别、公式识别和表格识别方面达到业界领先水平。该工具适合需要从非结构化文档中提取信息以构建检索增强生成（RAG）或智能代理应用的开发者和企业。
