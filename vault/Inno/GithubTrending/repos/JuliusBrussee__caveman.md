# JuliusBrussee/caveman

> Caveman 是一个 Claude Code 技能插件，通过让 AI 代理以原始风格（类似“穴居人”）生成回复，可大幅降低输出字符数约 65-75%，同时保持技术准确性。它适用于 Claude Code、Codex、Gemini、Cursor 等 30 多种 AI 编码工具，旨在减少 API 调用成本并提升响应速度，尤其适合希望以简洁方式获取技术答案的开发者。
