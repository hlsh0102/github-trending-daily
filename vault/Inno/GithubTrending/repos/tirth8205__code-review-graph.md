# tirth8205/code-review-graph

> code-review-graph 是一个本地优先的代码智能图谱工具，专为 MCP（模型上下文协议）和命令行界面设计。它通过构建持久的代码库依赖关系图，让 AI 辅助编程工具只读取真正相关的代码片段，在代码审查和大型仓库工作流中实现了经基准测试验证的上下文缩减。该项目适合使用 AI 工具进行代码审查和大型项目开发的开发者和团队，旨在节省 API 调用消耗并提高处理效率。
