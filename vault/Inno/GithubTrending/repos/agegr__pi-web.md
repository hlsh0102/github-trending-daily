# agegr/pi-web

> Pi Web 是 pi 编程代理的本地 Web 界面，用于读取本机会话文件并提供浏览器工作空间。它支持会话浏览、实时聊天、模型配置、技能管理和项目文件预览，使开发者在 CLI 之外拥有更清晰、结构化的交互方式。该项目面向使用 pi 代理进行编程开发、希望获得更友好图形操作界面的用户。
