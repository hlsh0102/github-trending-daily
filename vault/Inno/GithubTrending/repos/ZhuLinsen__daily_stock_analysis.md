# ZhuLinsen/daily_stock_analysis

> 该开源项目是一个基于大语言模型的跨市场股票智能分析系统，支持A股、港股、美股、日股和韩股的自选股监控。它整合多源实时行情与新闻，自动生成决策仪表盘，并通过企业微信、飞书、Telegram、Discord、Slack或邮箱推送给用户。系统设计用于零成本定时运行，适合个人投资者和量化研究人员快速获取每日市场动态与持仓分析。
