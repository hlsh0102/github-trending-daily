# higgsfield-ai/higgsfield

> Higgsfield 是一个开源、容错的 GPU 编排与机器学习框架，旨在支持从数十亿到数万亿参数的大规模模型训练，如大型语言模型。它提供 GPU 工作负载管理、资源分配、基于 ZeRO-3 和 PyTorch 全分片数据并行的模型分片、训练任务监控、实验队列管理以及与 GitHub Actions 的持续集成，适用于需要多节点分布式训练大规模神经网络的研究人员和工程师。
