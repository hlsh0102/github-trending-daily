# Imbad0202/academic-research-skills

> 这是一个为 Claude Code 设计的学术研究技能套件，覆盖从文献调研、写作、审稿到修改和定稿的完整研究流程。它通过插件形式集成到 Claude Code 中，提供如规划论文结构、检索参考文献、格式化引文、校验数据和检查逻辑一致性等辅助功能，旨在帮助研究人员处理繁琐的机械性工作，从而专注于提出研究问题、选择方法、解释数据等核心智力活动。适用于使用 Claude Code 进行学术写作的研究人员，尤其是希望提高论文质量和效率的用户。该项目以 MIT 许可证发布。该工具强调 AI 作为辅助而非主导，不会替代用户完成论文撰写，并致力于帮助用户写出更好的文章而非掩饰 AI 的使用痕迹。
