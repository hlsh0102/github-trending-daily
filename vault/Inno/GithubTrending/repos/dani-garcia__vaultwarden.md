# dani-garcia/vaultwarden

> Vaultwarden 是 Bitwarden 客户端 API 的非官方服务端实现，使用 Rust 编写，并与官方 Bitwarden 客户端兼容，前身为 bitwarden_rs。它面向希望在自有服务器上部署密码管理服务的用户，在资源占用和运行开销上比官方服务端更轻量，适合硬件资源有限的自行托管场景。
