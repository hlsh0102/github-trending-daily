# google/agents-cli

> agents-cli 是一款专为 Google Cloud Gemini Enterprise Agent Platform 设计的命令行工具和技能集，可以将任意编码助手转变为构建、评估和部署 AI Agent 的专家。它提供了一系列 CLI 命令和预置技能，帮助开发者高效地创建和管理企业级 Agent，无需深入了解多个独立 CLI 和云服务。该项目面向需要在 Google Cloud 上快速开发、测试和运维 AI Agent 的开发者和数据科学家。
