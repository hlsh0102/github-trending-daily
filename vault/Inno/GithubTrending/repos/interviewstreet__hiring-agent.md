# interviewstreet/hiring-agent

> Hiring Agent 是一个基于 Python 的开源工具，用于自动化简历评估。它从 PDF 简历中提取结构化数据，通过 GitHub 公开信息进行丰富，并生成包含分类得分、加分项和扣分项的客观评估结果，旨在提供公平且可解释的候选人筛选流程。该工具适合需要批量处理简历的招聘人员或开发者，支持本地运行（如使用 Ollama）或通过云端 LLM 进行推理。
