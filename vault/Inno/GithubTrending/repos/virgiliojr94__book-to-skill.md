# virgiliojr94/book-to-skill

> book-to-skill 是一个开源工具，能将技术书籍的 PDF 文件或文档文件夹转换为可直接在 GitHub Copilot CLI、Amp 或 Claude Code 中使用的统一代理技能。该项目旨在帮助开发者将纸质或电子文档中的知识转化为可交互查询和参考的工作辅助，适合需要快速检索技术书籍内容并希望将其集成到 AI 编程助手工作流中的用户。
