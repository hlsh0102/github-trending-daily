# openai/plugins

> 这是一个由OpenAI维护的Codex插件示例集合，包含多个插件实现，例如Figma、Notion、iOS应用开发、macOS应用开发、Web应用开发、Expo、Netlify等。每个插件都包含`plugin.json`清单文件，并可扩展技能、命令、MCP服务器、Agent和钩子等组件，适用于需要在Codex环境中集成特定工具或工作流程的开发者。
