# denoland/celld

> celld 是一个开源的守护进程，用于在自有机器上运行 Cloudflare Workers 和 Durable Objects。它将每个对象视为独立的 SQLite 数据库，并通过 S3 兼容存储桶进行复制和协调，无需控制平面或共识协议。适用于希望自托管分布式应用、同时避免共享数据库瓶颈和故障影响范围的开发者和团队。
