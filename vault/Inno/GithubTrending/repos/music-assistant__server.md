# music-assistant/server

> Music Assistant 是一个免费、开源的音乐库管理工具，能够整合多种流媒体服务并连接各类智能音箱。其核心服务器需要运行在常开设备（如树莓派、NAS 或 Intel NUC）上，为用户提供统一的音乐播放与管理体验。该项目尤其适合与 Home Assistant 配合使用，以实现自动化场景下的音乐控制。
