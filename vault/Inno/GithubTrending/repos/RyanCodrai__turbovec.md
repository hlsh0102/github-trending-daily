# RyanCodrai/turbovec

> turbovec 是一个基于 Google TurboQuant 算法构建的向量索引库，使用 Rust 编写并提供 Python 绑定。它将 1000 万文档的浮点向量索引内存占用从 31 GB 降至 4 GB，同时搜索速度超过 FAISS。该项目适用于需要高效存储和快速检索大规模向量数据的应用场景，无需提前训练或参数调优。
