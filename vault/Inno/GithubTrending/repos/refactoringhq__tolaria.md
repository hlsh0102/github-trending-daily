# refactoringhq/tolaria

> Tolaria 是一款跨平台桌面应用，专为管理基于 Markdown 的知识库而设计。它支持个人知识管理、企业文档组织以及 AI 助手的记忆与流程存储等场景，采用文件优先和 Git 优先原则，确保笔记数据完全归用户所有且易于迁移。该项目适合希望以纯文本方式构建和维护知识体系的用户，尤其是需要管理大量笔记的个人或团队。
