# bigskysoftware/htmx

> htmx 是一个轻量级、无依赖的 JavaScript 库，它允许你直接在 HTML 属性中使用 AJAX、CSS 过渡、WebSocket 和服务器发送事件，从而无需编写 JavaScript 代码即可构建现代用户界面。该项目旨在通过消除传统上仅由 <a> 和 <form> 元素发起的 HTTP 请求限制，简化 Web 开发，适合希望以超文本方式构建动态网页的开发者。
