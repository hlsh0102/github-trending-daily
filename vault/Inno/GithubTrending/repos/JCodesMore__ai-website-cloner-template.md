# JCodesMore/ai-website-cloner-template

> AI Website Cloner Template 是一个基于 Next.js 的项目模板，用户只需提供目标网址，AI 编码代理即可自动分析网站结构、提取设计规范并生成对应的组件代码，最终重建出一个完整的网站副本。该项目专为希望快速逆向工程网站、获得可维护 React 代码库的开发者设计，支持 Claude Code 等多种 AI 工具。
