# run-llama/liteparse

> LiteParse 是一个开源的 PDF 解析工具，专注于快速、轻量级地提取文档内容。它能够在本地运行，无需依赖云端服务或大型语言模型，提供带有边界框的高质量空间文本解析。该项目适合需要高效解析普通文档（如文本和简单布局）的用户，对于复杂文档（如密集表格或扫描件）则推荐使用其云版本 LlamaParse。
