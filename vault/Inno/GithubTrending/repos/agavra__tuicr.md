# agavra/tuicr

> tuicr 是一个基于终端的代码审查工具，提供类似 GitHub 的连续差异视图和 Vim 键位绑定。它支持在行、范围、文件和审查级别添加评论，并能在会话间持久化审查进度。该工具适用于使用 Git、Jujutsu 或 Mercurial 的开发者，可以将审查结果导出到 GitHub、GitLab 或剪贴板。
