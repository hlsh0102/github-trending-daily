## 项目概述

Free Claude Code（FCC）是一个开源的命令行工具，旨在让开发者免费使用 Claude Code、Codex、Pi、OpenCode 等主流 AI 编程代理。项目聚合了 49 个符合服务条款（ToS）的模型提供商，每月可提供超过 13 亿个免费 token，用户可以通过终端、IDE、应用甚至手机随时调用这些能力。

该项目解决了两个核心痛点：一是 AI 编程工具订阅费用高昂，二是许多免费代理服务存在账号封禁风险。FCC 通过精选合规的提供商并严格遵循其服务条款，让开发者能够在安全的前提下免费使用先进的 AI 编程能力。项目独立于 Anthropic，与 Claude Code 商标持有者无任何关联。

目标用户包括个人开发者、开源贡献者、学生以及希望在低成本环境下探索 AI 编程的开发团队。

## 核心功能

- **多提供商聚合**：集成 49 个 ToS 友好的模型提供商，包括免费、付费、订阅和本地部署模型，统一在一个可搜索的界面中管理。
- **多代理支持**：支持 Claude Code、Codex、Pi、OpenCode、Cline、Hermes 等 9 种主流 AI 编程代理，提供一致的使用体验。
- **语音交互支持**：类似 OpenClaw 的语音控制功能，允许开发者通过语音指令与 AI 编程代理交互，提升操作效率。
- **客户端连接**：提供灵活的连接方式，可接入终端、Web IDE（如 VS Code）、移动应用或自定义工作流。
- **合规保障**：自动检测并移除不再被提供商允许的集成，确保使用过程始终符合服务条款，降低账号风险。
- **统一模型目录**：无论使用哪个代理，均可从同一模型库中选择所需模型，简化配置和切换流程。

## 技术架构

FCC 基于 Python 构建，充分利用了 Python 生态的成熟工具链。项目采用模块化设计，核心架构包含以下关键组件：

- **提供商抽象层**：将不同模型提供商的 API 差异封装为统一接口，支持动态添加和移除提供商，便于扩展和维护。
- **代理适配器**：为 Cluade Code、Codex 等每个编码代理实现适配器，将代理原生的 API 调用转换为内部统一格式，降低耦合度。
- **配置管理**：支持通过命令行和配置文件管理提供商、模型、密钥等参数，提供全局搜索和过滤功能。
- **测试与质量保障**：使用 GitHub Actions 进行持续集成，配合 `pytest`、`ruff` 和 `loguru` 分别处理测试、代码检查和日志记录，确保代码质量和可维护性。
- **依赖管理**：采用 `uv` 作为包管理器，加速依赖安装和解析，提升开发体验。

架构设计强调模块化和可插拔性，开发者可以轻松添加新的代理或提供商，而无需修改核心逻辑。

## 安装与使用

### 安装要求

- Python 3.9 或更高版本
- `uv`（推荐）或 `pip`

### 安装步骤

```bash
# 使用 uv 安装（推荐）
uv tool install free-claude-code

# 或使用 pip 安装
pip install free-claude-code
```

### 最小可用示例

安装完成后，通过以下步骤快速启动：

```bash
# 初始化配置
fcc init

# 搜索可用的提供商和模型
fcc search provider --keyword "free"

# 指定提供商和代理启动
fcc run --provider <provider-name> --agent claude-code
```

也可以直接连接到已有 IDE：

```bash
# 在终端中启动服务
fcc serve

# 在 VS Code 或其他客户端中配置连接
```

对于语音交互，FCC 支持通过麦克风输入指令：

```bash
fcc run --voice
```

## 适用场景

- **个人开发与学习**：开发者可在不产生费用的情况下体验 Claude Code、Codex 等先进工具，用于代码生成、调试和学习最佳实践。
- **开源项目协作**：为开源社区提供免费的 AI 编程资源，降低贡献者的工具门槛，提升协作效率。
- **低预算团队迭代**：启动阶段或预算有限的团队可利用 FCC 承担日常编码任务，减少订阅开支。
- **多代理对比与选型**：用户可在统一界面中切换不同代理，直观评估各工具的适用性，辅助技术选型。

## 项目亮点

- **高性价比**：每月超 13 亿的免费 token 池，覆盖多种任务需求，综合成本远低于商业订阅。
- **合规安全**：严格遵循提供商服务条款，与那些通过非官方手段获取免费额度的工具形成鲜明对比，有效保护用户账号安全。
- **多功能集成**：集多代理、多提供商、语音交互于一身，一个工具即可替代多个独立应用，减少环境配置和管理成本。
- **活跃维护**：项目在 GitHub 上拥有超过 4.8 万 star，且日增长量显著（+1081），社区活跃度高，版本迭代快速，功能持续丰富。
