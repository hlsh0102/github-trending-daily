## 项目概述

`mattpocock/skills` 是一个面向真实软件工程场景的 AI Agent 技能（Skills）集合，由知名 TypeScript 教育者 Matt Pocock 维护。该项目直接来源于作者日常使用的 `.agents` 目录，旨在解决开发者在实际工程中运用 AI 编码助手时遇到的“失控”问题。

与 GSD、BMAD、Spec-Kit 等试图接管整个开发流程的框架不同，这些技能被设计为**小粒度、易修改、可组合**的独立单元。它们不强迫开发者接受某一套特定的工作流，而是将数十年工程经验沉淀为可复用的提示词与脚本，让 AI 在任何模型下都能更可靠地完成真实编码任务——而非仅仅是“氛围编码”（vibe coding）式的表面功夫。

## 核心功能

- **真实工程技能**：涵盖代码审查、架构决策、重构建议等实际开发中频繁使用的场景，直接来源于作者生产环境的日常实践。
- **模型无关**：技能与具体 AI 模型解耦，可适配 Claude、GPT、Gemini 等主流模型，不绑定特定厂商。
- **可组合设计**：每个技能独立封装，开发者可按需选取、自由组合，形成适合自己团队的工作流。
- **透明可控**：技能文件以纯文本形式存储，所有逻辑一目了然，便于审查与自定义修改。
- **快速安装**：提供两种安装方式，包括 Claude Code 插件形式（托管式只读包）和直接复制到本地方案的灵活方式，30 秒内即可完成部署。
- **持续更新**：作者通过 newsletter 向约 6 万名开发者推送技能更新与新增内容，保持技能库的活跃演进。

## 技术架构

本项目以 Shell 脚本和 Markdown 文件为主要载体，遵循“约定优于配置”的简洁设计哲学。技能文件遵循一套轻量的结构规范，每个技能通常包含明确的触发条件、执行步骤和输出格式要求。这种基于文件的架构具有几个显著特点：

1. **零运行时依赖**：技能本身不依赖任何特定的 AI 框架或 SDK，只是一个包含指令的文本集合，大大降低了接入门槛。
2. **版本控制友好**：所有技能都以纯文本形式存储在 Git 仓库中，可方便地进行代码审查、差异比较和回滚，支持工程化的迭代方式。
3. **插件化分发**：通过 Claude Code 的插件机制，可以将整个技能集作为只读包安装，保证更新的一致性；同时保留直接复制到本地目录的选项，满足个性化定制的需求。

这种设计思路的核心理念是：AI 辅助编码工具的流程必须对开发者完全透明，任何试图“黑盒化”的流程抽象都可能导致问题难以排查——这正是作者对现有大型框架的批判点。

## 安装与使用

### 安装

**方式一：Claude Code 插件安装（推荐）**

```bash
# 在 Claude Code 中执行：
/plugin install mattpocock/skills
```

插件将以托管只读包的形式安装整套技能，后续可自动更新。

**方式二：本地直接复制**

```bash
git clone https://github.com/mattpocock/skills.git
cp -r skills/.agents ~/.agents
# 或在项目根目录创建 .agents 软链接
ln -s /path/to/skills/.agents .agents
```

### 最小使用示例

以“代码审查”技能为例，在项目目录中配置好 `.agents` 后，向支持 Agent Skills 的 AI 模型发出请求：

```
请使用 code-review 技能对 src/utils.ts 进行审查，重点关注：
- 潜在的类型安全问题
- 边界条件处理
- 可维护性改进建议
```

模型会自动加载对应技能定义，按照其中预设的审查清单和流程执行分析，并输出结构化结果。

## 适用场景

1. **日常编码辅助**：在处理复杂业务逻辑、重构现有代码库或跨模块修改时，通过技能约束 AI 的行为模式，获得更符合工程规范的输出。
2. **团队协作标准化**：将团队认可的编码规范、审查标准沉淀为技能文件，分发给所有成员，确保 AI 辅助行为的一致性。
3. **教育与技能传承**：资深工程师可将自己的经验提炼为技能，作为团队培训材料或公开分享，帮助新人快速建立工程直觉。
4. **个性化 AI 工作流定制**：开发者可以根据自身工作习惯，基于这些基础技能进行修改，构建完全符合个人偏好的 AI 助手配置。

## 项目亮点

- **反“黑盒”立场**：与当前主流的大型开发框架形成鲜明对比，坚持让开发者完全掌控 AI 交互的每一个环节，提高系统的可预测性。
- **工程经验的可移植化**：将“资深工程师如何在写代码前思考”这一隐性知识显性化，转化为可复制的技能文件，极具实践价值。
- **极低的学习成本**：技能采用自然语言书写，任何有基本编程经验的开发者都能在几分钟内理解并开始修改，无需学习专有格式或 API。
- **活跃的社区生态**：依托作者在 TypeScript 社区的影响力，项目积累了超过 23 万 Star，且有持续的 newsletter 更新机制，保证内容质量与时效性。
