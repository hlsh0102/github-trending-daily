## 项目概述

ECC（全称 Entity Control Center）是一个面向 AI 编程代理（Agent）的性能优化与增强系统。它并非单一工具，而是一套为 Claude Code、Codex、Opencode、Cursor 等主流 Agent 开发环境打造的“操作系统层”解决方案，通过注入技能（Skills）、直觉（Instincts）、记忆（Memory）和安全机制（Security），显著提升代理在复杂开发任务中的表现。

该项目解决的核心问题是：虽然现代 AI 编码代理能力强大，但它们在长会话中往往面临上下文丢失、行为不一致、安全边界模糊等痛点。ECC 通过结构化方式管理代理的长期记忆与行为规则，让代理在大型项目中保持“记忆清晰、行动果断、安全可靠”。目标用户包括重度依赖 AI 辅助开发的软件工程师、技术团队负责人，以及希望将 AI 代理集成到正式开发流程中的组织。

## 核心功能

- **技能系统**：为代理提供可复用的开发技能模块，支持自定义和共享，让代理能够执行复杂的多步骤任务（如代码重构、测试生成）。
- **记忆管理**：通过持久化记忆层，代理可以在会话间保留项目上下文、用户偏好和决策历史，避免重复解释需求。
- **安全防护**：内置权限检查与操作审计机制，限制代理对敏感文件、命令或外部资源的访问，降低误操作风险。
- **多平台支持**：无缝对接 Claude Code、Codex、Opencode、Cursor 等多个主流 Agent 环境，一套配置多处使用。
- **研究优先开发**：内置研究导向的开发流程，支持代理在行动前搜索文档、代码库或 Web 资源，提升决策质量。

## 技术架构

ECC 基于 **Node.js** 开发，采用模块化、插件式的架构设计。核心引擎通过“适配器”模式连接不同 Agent 平台，每个适配器负责将 ECC 的内部指令转换为对应平台的 API 调用或规则格式，从而实现对多种工具的统一管理。

系统分为四个主要层：**记忆层**（负责数据持久化与检索，支持基于关键词或向量的记忆提取）、**策略层**（定义权限规则、行为边界和技能触发条件）、**执行层**（调用 Agent 原生能力或外部工具完成具体操作）以及**接口层**（提供 CLI 与配置文件）。ECC 的设计哲学强调“配置即代码”，用户通过 `ecc.config.js` 或 YAML 文件即可定义完整的代理行为策略，无需修改任何 Agent 底层代码。

## 安装与使用

安装 ECC 十分简单，确保已安装 Node.js 18 以上版本，然后执行：

```bash
npm install -g ecc-agent
```

初始化配置：

```bash
ecc init
```

最小化使用示例——在项目中创建 `ecc.config.js`：

```javascript
module.exports = {
  platforms: ['claude', 'cursor'],
  memory: {
    type: 'local',
    path: './.ecc-memory'
  },
  security: {
    allowedCommands: ['git', 'npm test'],
    blockedPaths: ['env/*', '*.pem']
  },
  skills: ['./skills/refactor.js', './skills/review.js']
};
```

启动与 ECC 集成的代理会话：

```bash
ecc run --platform claude
```

随后代理将自动加载 ECC 提供的记忆、技能和安全策略。

## 适用场景

- **大型代码库重构**：当面临数百文件的架构调整时，ECC 帮助代理保持全局视角，通过记忆层记录每个模块的状态，避免遗漏或重复修改。
- **自动化代码审查与测试**：使用内置技能让代理在提交后自动生成测试计划、执行静态分析并汇报结果，适合已引入 CI/CD 的团队。
- **跨工具工作流统一**：团队中不同成员使用不同 Agent 工具，ECC 作为统一策略层，确保所有代理遵循一致的编码规范和安全规则。
- **研究与探索密集型开发**：代理需要频繁查阅 API 文档、开源代码或内部 Wiki，ECC 的研究优先模块可自动整理并保存有用信息。

## 项目亮点

- **灵活性与生态兼容**：不绑定某一特定 Agent 工具，而是主动适配最流行的多个平台，降低了迁移成本。
- **记忆的长期价值**：不同于多数工具的会话内记忆，ECC 的持久化记忆层使代理在数天甚至数周的项目中保持连续一致的决策逻辑。
- **安全设计的前置性**：将安全控制从“事后审计”转向“事中拦截”，通过允许列表和路径过滤机制主动防御高风险操作。
- **社区驱动与开源**：项目采用 MIT 许可，并已在 GitHub 上获得大量关注，拥有活跃的社区贡献和文档翻译，便于各类开发者采纳。
