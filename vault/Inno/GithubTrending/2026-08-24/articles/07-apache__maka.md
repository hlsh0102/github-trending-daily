## 项目概述

Apache Maka（孵化中）是一个面向真实工作的本地优先 AI Agent 工作空间。它解决了当前 AI 编程助手在复杂项目中缺乏透明度、可控性和可审计性的问题。Maka 允许 AI 模型在沙箱边界内检查项目、运行工具，并将模型消息、工具调用、工具结果、权限决策和终止事件全部记录为仅追加日志（append-only log）。目标用户是需要在本地环境中安全、可控地使用 AI Agent 辅助开发的专业开发者、技术团队以及对数据隐私有严格要求的组织。

## 核心功能

- **本地优先架构**：所有数据处理和 Agent 运行均在本地完成，无需将代码或敏感信息上传至云端，确保数据主权和隐私安全。
- **沙箱边界隔离**：工具调用被严格限制在沙箱边界内执行，防止 AI Agent 越权访问系统资源或执行危险操作，提供可控的运行环境。
- **完整审计日志**：模型消息、工具调用、工具结果、权限决策和终止事件全部以仅追加日志形式记录，提供端到端的操作追踪能力，便于调试和回溯。
- **跨平台支持**：目前已支持 macOS（Apple Silicon）和 Windows（预览版），Linux 版本正在开发中，覆盖主流开发平台。
- **实时权限决策**：在工具调用前进行权限检查，用户可以实时审批或拒绝 Agent 的操作请求，确保每一步行动都在授权范围内。
- **项目感知能力**：Maka 能够主动检查和分析项目结构，理解项目上下文，从而提供更精准的代码生成和修改建议。

## 技术架构

Maka 采用 TypeScript 作为主要开发语言，充分利用了静态类型检查和安全特性。其核心架构围绕“本地优先”和“可审计性”两个设计原则展开。架构中关键的设计特点包括：

1. **仅追加日志（Append-Only Log）**：所有与模型交互、工具执行相关的数据都写入不可篡改的日志中。这种设计不仅提供了完整的审计线索，还为将来的回放、分析功能奠定了基础。

2. **沙箱隔离机制**：Maka 在操作系统层面构建了轻量级沙箱环境，所有外部工具调用都被限制在沙箱内执行。这层隔离确保了即使 Agent 行为异常，也不会对宿主机造成实质性影响。

3. **事件驱动模型**：系统内部采用事件驱动架构，模型消息、工具调用、权限决策等都被抽象为离散事件，通过统一的事件流进行管理和分发，保证了系统的可扩展性和可观测性。

4. **模块化设计**：Maka 采用模块化架构，桌面应用、Agent 核心、工具执行器、权限管理器等模块相互独立，便于单独开发和测试，也为未来插件生态预留了接口。

## 安装与使用

### 安装

目前 Maka 提供预编译的桌面应用安装包，用户可以直接从官方 Releases 页面下载对应平台的安装文件：

- **macOS (Apple Silicon)**：下载 `.dmg` 文件并拖入 Applications 文件夹。
- **Windows**：下载预览版安装包，注意当前版本为未签名预览，系统可能显示安全警告，选择信任即可。

Linux 用户需等待官方后续支持。

### 最小可用示例

安装完成后启动 Maka，首次运行会引导用户创建一个本地工作区。基本使用流程如下：

1. **创建工作区**：选择一个本地项目目录作为 Agent 的工作目标。
2. **发起任务**：在对话界面输入自然语言任务描述，例如“分析项目的依赖结构并生成一份报告”。
3. **授权执行**：Maka 会展示将要执行的工具调用请求，用户确认授权后方可执行。
4. **查看日志**：在日志面板中查看每一步操作的详细记录，包括模型消息、工具输入输出等。

```typescript
// 开发人员可以通过 Maka 提供的 API 进行更细粒度的集成
// 以下为概念性示例，实际 API 以官方文档为准
import { MakaClient } from 'maka-sdk';

const client = new MakaClient({
  workspace: '/path/to/project',
  sandbox: true
});

const result = await client.executeTask('列出所有未提交的更改');
console.log(result.toolCalls); // 查看工具调用记录
```

## 适用场景

- **本地代码库维护与重构**：开发人员可以使用 Maka 对大型本地代码库进行依赖分析、代码质量检查、自动化重构等任务，所有操作均在本地完成，不泄露代码内容。
- **安全敏感的研发环境**：对于涉及核心算法、金融逻辑或未公开产品代码的团队，Maka 的本地优先特性使其成为理想选择，避免了代码外泄风险。
- **AI 行为审计与教学**：研究人员或技术管理者可以通过完整的事件日志，深入分析 AI Agent 的决策过程和行为模式，用于改进 Agent 设计或团队培训。
- **离线开发辅助**：在无网络或网络受限的环境中，开发者仍可利用 Maka 提供的本地 Agent 能力进行代码辅助、文档生成等工作。

## 项目亮点

与同类 AI Agent 工具相比，Maka 的差异化优势主要体现在：

1. **真正的审计完整性**：不同于其他工具仅记录最终结果，Maka 记录了完整的决策链路，包括权限决策和终止事件，真正做到“每一步都有据可查”。
2. **沙箱边界设计**：安全边界并非软性提示，而是硬性隔离。即使 Agent 意图恶意操作，也无法突破沙箱限制。
3. **Apache 基金会背书**：作为 Apache 孵化项目，Maka 遵循开源社区的最佳实践，拥有更透明的治理结构和长期稳定性保障。
4. **开发者体验优先**：TypeScript 全栈实现、跨平台支持和清晰的 API 设计，降低了开发者的学习和集成成本。
