## 项目概述

OpenLogi 是一款专为罗技（Logitech）外设用户打造的原生、本地优先的配置工具，旨在替代官方 Logitech Options+ 软件。项目完全使用 Rust 语言编写，通过 HID++ 和 UVC 协议直接与罗技的鼠标、键盘和网络摄像头通信，实现了按钮重映射、DPI 调节、SmartShift 等功能，全程无需创建账户、无需上传任何遥测数据。

对于许多罗技用户而言，官方 Options+ 软件虽然功能全面，但存在体积臃肿、强制联网、需要登录等问题，在 macOS 上还经常遭遇权限问题和内存占用过高的困扰。OpenLogi 以“本地优先”为设计哲学，所有配置均保存在本地设备上，采用原生 GUI 而非 Electron 架构，占用资源极小，为追求简洁、安全和高效的用户提供了一个全新的选择。

## 核心功能

- **按键重映射**：支持对罗技鼠标、键盘的所有按键进行自定义映射，包括单键、组合键以及多媒体键功能。
- **DPI 调节**：通过 HID++ 协议直接控制鼠标的 DPI 灵敏度，支持多档位切换和自定义预设值。
- **SmartShift 支持**：针对配备双模式滚轮的鼠标，允许用户自定义滚轮的普通/疾速滚动切换逻辑。
- **跨设备配置**：支持多设备配置文件管理，可针对不同应用或使用场景自动切换配置。
- **本地存储与隐私保护**：所有设置仅写入本地设备内存，无账户系统、无遥测，彻底断开与云端的连接。

## 技术架构

OpenLogi 基于 Rust 生态构建，采用分层架构设计。底层使用 `hidapi` 库与罗技的 HID++ 协议进行通信，该协议是罗技外设的私有通信标准，支持设备参数的读取与写入。上层则通过 Rust 编写跨平台原生界面（利用 Tauri 或 egui 等框架），确保在 Windows、macOS 和 Linux 上都能获得一致的体验。

一个值得注意的设计特点是其“配置即代码”的理念——OpenLogi 将复杂的 HID++ 指令封装为简洁的配置接口，用户可以通过命令行或 GUI 直观地操纵设备参数。同时，项目采用模块化设计，设备驱动层与 UI 层完全解耦，便于后续扩展对更多罗技外设型号的支持。

由于项目仍处于快速迭代阶段，架构上特别注重向后兼容性，通过版本化的配置文件和明确的 API 边界，最大程度降低未来版本升级对已有用户配置的影响。

## 安装与使用

### 安装

从 GitHub Releases 页面下载对应操作系统的二进制包：

- **Windows**：下载 `.msi` 或 `.exe` 安装包，双击运行即可。
- **macOS**：下载 `.dmg` 文件，拖拽至 Applications 文件夹。
- **Linux**：提供 `.deb`、`.rpm` 或 AppImage 格式。

### 最小使用示例

安装后，启动 OpenLogi 主程序。程序会自动扫描当前系统已连接的罗技外设。以下是一个通过命令行完成鼠标 DPI 调整的示例：

```bash
# 列出当前连接的设备
openlogi list

# 查看某设备的可用配置项
openlogi device 0 info

# 将设备 0 的 DPI 设置为 1600
openlogi device 0 set-dpi 1600
```

对于 GUI 用户，只需在图形界面中点击对应设备图标，拖动 DPI 滑块或直接点击按键重映射字段，即可在界面上完成同样操作。所有修改将即时写入设备。

## 适用场景

- **开源与隐私敏感用户**：拒绝官方软件强制性登录和数据回传，希望完全掌控自己外设的用户。
- **跨平台开发者和终端爱好者**：习惯使用命令行管理一切设备，或需要在 Linux 环境下获得与 Windows/macOS 相同的罗技外设配置能力。
- **性能追求者**：对官方 Options+ 的内存占用和响应速度不满，希望使用一个轻量级、原生运行的工具。
- **多系统办公环境**：在 Windows、macOS、Linux 之间频繁切换，需要一套统一的配置方案，避免在不同系统上重复设置。

## 项目亮点

- **纯 Rust 实现**：内存安全、性能卓越，不依赖 Electron 等重型运行时，安装包体积小，运行占用低。
- **本地优先与隐私**：所有数据留存在本地，无账户体系、无遥测上报，从根源上杜绝数据泄露风险。
- **HID++ 原生支持**：不依赖逆向或非官方协议库，直接与设备底层通信，功能覆盖范围广且稳定性高。
- **活跃社区与快速迭代**：项目已获得超过 15,000 个 Star，社区活跃度极高，开发和修复速度远超同类工具。
- **多语言文档**：提供中、英、日、德、法、韩等多种语言文档，降低了全球用户的上手门槛。
