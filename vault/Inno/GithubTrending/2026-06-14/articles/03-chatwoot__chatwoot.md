## 项目概述

Chatwoot 是一个开源的客户支持平台，旨在替代 Intercom、Zendesk、Salesforce Service Cloud 等商业客服工具。它提供多渠道消息集成、实时聊天、电子邮件支持等功能，帮助团队在一个统一的界面上管理所有客户对话。项目采用 Ruby 语言开发，源代码完全开放，允许企业自主部署和定制。目标用户包括中小型企业、初创团队、开源社区以及任何希望以较低成本获得专业客服能力的组织。

## 核心功能

- **多渠道收件箱**：统一管理来自网站聊天、电子邮件、Facebook Messenger、Twitter、WhatsApp 等多个渠道的客户消息，避免在多个平台间切换。
- **实时聊天组件**：提供可嵌入网站的聊天小部件，支持自定义外观、自动回复、离线消息收集，并可无缝集成到现有前端。
- **自动化工作流**：通过触发器规则自动分配对话、发送预设回复、标记工单优先级，减少人工操作，提升响应效率。
- **协作工具**：支持团队内部备注、@提及同事、共享对话上下文，便于多部门协同处理复杂问题。
- **客户资料管理**：自动记录客户历史对话、浏览行为和联系方式，帮助客服人员快速了解客户背景。
- **数据报表与分析**：提供对话量、响应时间、客户满意度等关键指标的可视化报表，辅助优化客服流程。

## 技术架构

Chatwoot 采用前后端分离的架构设计。后端基于 Ruby on Rails 框架，利用其成熟的 ORM 和 API 构建能力处理业务逻辑、数据存储和消息路由。前端使用 Vue.js 构建响应式界面，通过 RESTful API 与后端通信。消息传递部分依赖 WebSocket 协议实现实时推送，确保客服人员能即时收到新消息通知。数据存储方面，主体数据使用 PostgreSQL 数据库，同时集成 Redis 用于缓存和消息队列，提升高并发场景下的性能。部署上支持 Docker 容器化，便于在云服务器或自建环境中快速启动。项目还提供了完善的 API 接口，允许开发者通过 Webhook 或 SDK 扩展功能，与 CRM、工单系统等第三方工具集成。

## 安装与使用

Chatwoot 提供多种部署方式，以下是最简安装步骤：

1. **环境准备**：确保系统已安装 Docker 和 Docker Compose。
2. **克隆仓库**：`git clone https://github.com/chatwoot/chatwoot.git`
3. **配置环境变量**：复制 `.env.example` 为 `.env`，并设置数据库、Redis 等连接参数（Docker 模式通常无需调整）。
4. **启动服务**：在项目根目录执行 `docker-compose up -d`，等待所有容器启动完成。
5. **初始化数据库**：运行 `docker-compose exec rails bundle exec rails db:seed` 创建默认管理员账户和示例数据。
6. **访问系统**：在浏览器打开 `http://localhost:3000`，使用初始化生成的账户（默认邮箱 `admin@chatwoot.com`，密码 `Password@1`）登录。

**最小可用示例**：部署完成后，进入后台即可创建收件箱、添加网站聊天小部件，并在前端页面嵌入生成的 JavaScript 代码片段，实现实时聊天功能。

## 适用场景

- **电商售后支持**：在线商店可通过嵌入聊天组件，为顾客提供即时购物咨询、订单查询、退换货处理，结合邮件跟进复杂案件。
- **SaaS 产品客户服务**：软件即服务公司可利用多渠道收件箱整合来自官网、应用内和社交媒体的问题，团队协作快速解决用户故障。
- **开源社区运营**：开源项目可部署 Chatwoot 作为社区支持入口，处理 GitHub Issue、邮件咨询和 Discord 讨论中的技术疑问。
- **企业内部 IT 支持**：企业 IT 部门可将其作为内部工单系统，员工通过邮件或聊天提交技术求助，实现工单分配与流程追踪。

## 项目亮点

- **完全开源**：核心代码采用 MIT 许可证发布，无功能阉割、无用户数限制，数据完全掌控在自部署的服务器中。
- **多语言支持**：内置国际化框架，已翻译 10 余种语言，包括简体中文，降低非英语团队的使用门槛。
- **轻量级自托管**：相比商业产品动辄数十万起步的订阅费用，Chatwoot 仅需一台低配置云服务器即可运行，长期运维成本极低。
- **活跃社区与生态**：拥有 Discord 社区、官方文档以及丰富的插件市场，开发者可基于 API 快速开发自定义集成。
