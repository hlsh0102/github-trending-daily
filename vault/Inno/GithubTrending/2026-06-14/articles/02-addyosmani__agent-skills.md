## 项目概述

Agent Skills 是由 Google Chrome 团队高级工程师 Addy Osmani 开发的开源项目，旨在为 AI 编码代理提供一套生产级别的工程技能。该项目将资深软件工程师在开发过程中使用的工作流程、质量门禁和最佳实践进行系统化封装，使 AI 代理能够在软件开发的各个阶段一致地遵循这些工程规范。

项目解决的核心问题是：AI 编码代理虽然能够生成代码，但往往缺乏对完整软件开发流程的理解，容易跳过关键的质量检查环节，导致代码质量参差不齐。Agent Skills 通过预定义的命令和工作流，引导 AI 代理按照从需求定义到生产部署的完整工程生命周期进行操作。

目标用户主要包括：使用 AI 编码助手进行开发的软件工程师、希望标准化 AI 开发流程的技术团队、以及探索 AI 辅助开发最佳实践的创新者。

## 核心功能

- **七阶段开发命令系统**：提供 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/code-simplify` 和 `/ship` 共七个按开发阶段划分的斜杠命令，每个命令都激活对应的工程技能集合
- **流程化开发引导**：覆盖从想法提炼、规范编写、计划制定、增量构建、测试验证、代码审查到最终发布部署的完整开发生命周期
- **自动构建模式**：通过 `/build auto` 命令，在规范存在的前提下自动生成执行计划并完成实现，减少手动操作步骤
- **质量门禁机制**：在每个阶段设置质量检查点，确保代码在通过验证后才能进入下一阶段，防止质量问题的积累
- **持续代码改进**：专门的 `/code-simplify` 命令用于简化代码，遵循 "清晰胜过巧妙" 的工程原则
- **标准化发布流程**：`/ship` 命令确保生产发布遵循 "更快即更安全" 的部署理念

## 技术架构

Agent Skills 采用 Shell 作为主要实现语言，以轻量级脚本的形式将工程最佳实践打包为可执行技能文件。项目的架构设计遵循以下核心理念：

基于**开发阶段流水线模型**，将软件开发划分为定义、计划、构建、验证、审查和发布六个主要阶段，每个阶段对应一个专门的命令入口。这种架构将复杂的工程流程解耦为独立的模块，使得 AI 代理能够清晰地理解当前所处的开发阶段，并调用相应的技能集合。

命令系统采用**上下文感知设计**，每个斜杠命令不仅执行特定的任务，还根据开发阶段自动激活相关的技能文件。例如 `/spec` 命令会加载需求分析和规范编写的相关技能，而 `/test` 命令则加载单元测试和调试验证的技能。

项目遵循**渐进式详细化原则**，从高层的规范定义逐步向下细化到具体的代码实现和验证，确保每个步骤都有明确的前置条件和输出标准。这种架构降低了 AI 代理在复杂工程任务中的决策负担，使其能够按照既定的工程流程稳定产出高质量代码。

## 安装与使用

Agent Skills 的安装需要与支持斜杠命令的 AI 编码代理配合使用，具体步骤通常包括：

1. 将项目克隆或复制到 AI 代理的技能目录中
2. 配置 AI 代理以启用 Agent Skills 命令集合
3. 在开发流程中通过斜杠命令触发对应的工程技能

最小可用示例：

```shell
# 启动新功能开发
/spec 描述你想要构建的功能

# 根据生成的规范制定执行计划
/plan

# 开始增量构建实现
/build

# 验证代码正确性
/test

# 代码合并前的审查
/review

# 代码简化（可选）
/code-simplify

# 准备发布
/ship
```

对于已有规范的情况，可以直接使用自动模式：

```shell
/build auto 规范文件路径或名称
```

## 适用场景

- **新功能开发**：当需要从零开始构建新功能时，Agent Skills 提供了完整的流程引导，帮助开发者避免遗漏关键工程步骤
- **代码质量改进**：对于需要提升现有代码质量的项目，可以使用 `/review` 和 `/code-simplify` 命令进行系统化的代码审查和简化
- **团队开发标准化**：技术团队可以通过统一使用 Agent Skills 来确保所有成员（包括 AI 代理）遵循相同的工程标准和流程
- **持续集成与部署**：`/ship` 命令特别适合需要规范化发布流程的项目，确保每次发布都经过完整的验证和审查

## 项目亮点

Agent Skills 与其他同类项目相比，具有以下显著差异化优势：

- **资深经验编码**：项目由拥有多年 Chrome 开发经验的高级工程师设计，其技能集合反映了顶级工程团队的实际工作流程，而非理论化建议
- **完整的生命周期覆盖**：不同于仅关注代码生成或测试的工具，Agent Skills 覆盖了从需求定义到生产部署的完整端到端流程
- **清晰的操作接口**：通过直观的斜杠命令映射到开发阶段，降低了 AI 代理的学习和使用门槛，开发者可以快速上手
- **自动化程度可调**：提供从手动逐步操作到自动构建的多种工作模式，适应不同的开发场景和个人偏好
- **理念驱动设计**：每个命令都附有核心理念说明（如"规范先于代码"、"测试即证明"），帮助 AI 代理理解工程原则而非机械执行操作
