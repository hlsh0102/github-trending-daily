## 项目概述

RomM（ROM Manager）是一个自托管的游戏 ROM 管理与在线游玩平台。它解决了游戏收藏者、复古游戏爱好者在管理大量 ROM 文件时面临的杂乱无章、缺乏元数据、难以分享和在线游玩等问题。目标是提供一套干净、响应式、功能强大的网页界面，让用户能够集中扫描、美化、浏览并直接在浏览器中游玩自己收集的游戏 ROM。用户群体覆盖从个人收藏家到小型游戏分享社群。

## 核心功能

- **智能扫描与元数据增强**：自动识别游戏文件，并从 IGDB、Screenscraper、MobyGames 等多个权威数据库获取封面、简介、评分、发行日期等丰富的元数据，让杂乱的 ROM 文件夹变成精美的数字画廊。
- **多平台与文件格式支持**：支持超过 400 个游戏平台的 ROM，包括多碟游戏、DLC、MOD、汉化补丁、修改版及游戏说明书（PDF/图片），对复杂文件结构有良好的解析能力。
- **直接浏览器游玩**：集成 EmulatorJS（用于主流老游戏机模拟）和 RuffleRS（用于 Flash 游戏）引擎，无需安装任何本地模拟器，即可在 Chrome、Firefox 等现代浏览器中直接启动游戏。
- **标签与智能过滤**：支持从文件名中解析标签（如 [CHS]、[HACK]、[v1.1]），并可自定义标签，便于按语言、版本、类型等维度快速筛选和搜索游戏。
- **库共享与权限管理**：可与朋友或社群成员共享你的游戏库，支持细粒度的访问权限控制（如只读、仅限特定平台），保障收藏安全。
- **第三方集成与扩展**：提供 Playnite 桌面客户端应用、Android（Argosy）启动器、自定义固件（CFW）的专用客户端，以及丰富的 API 接口，方便与其他工具联动。

## 技术架构

RomM 采用 Python 语言开发，基于现代 Web 框架构建。其核心技术栈包括：

- **后端**：基于 FastAPI（异步 Python Web 框架），处理文件扫描、元数据抓取、用户认证、权限控制以及游戏流媒体传输。
- **前端**：使用 Vue.js 或类似现代前端框架构建响应式单页应用，界面美观、操作流畅，兼容桌面和移动端。
- **数据库**：采用 SQLite（默认）或可选的 PostgreSQL 存储游戏元数据、用户信息、播放记录等。轻量且易于部署。
- **模拟引擎**：通过内嵌 EmulatorJS（JavaScript 实现的老游戏模拟器集合）实现浏览器端即时游玩，无需后端转码，降低服务器负载。
- **元数据聚合**：通过异步任务队列调用多个外部 API（IGDB、Screenscraper、SteamGridDB 等），支持自定义优先级和回退策略，确保即使某个 API 不可用也能获得元数据。
- **文件系统感知**：直接处理本地或挂载的 NAS 文件系统，监控文件变化，保持游戏库实时更新。

架构设计上强调**一键部署、零配置运行**，通过 Docker 容器化分发，用户只需准备一个存放 ROM 的目录即可启动。

## 安装与使用

### 基础安装（Docker）

1.  确保已安装 Docker 和 Docker Compose。
2.  创建一个项目目录，并在其中编写 `docker-compose.yml`：

```yaml
version: "3.9"
services:
  romm:
    image: rommapp/romm:latest
    container_name: romm
    ports:
      - "8080:8080"   # Web 界面端口
    volumes:
      - ./roms:/roms  # 你的 ROM 文件夹路径
      - ./data:/data  # 数据库和缓存存储
    environment:
      - DB_PATH=/data/database.sqlite
      - SECRET_KEY=your_secret_key_here
```

3.  启动容器：`docker compose up -d`
4.  打开浏览器访问 `http://localhost:8080`，根据提示创建管理员账户。
5.  在设置中添加 ROM 扫描路径，点击“立即扫描”，等待元数据抓取完成。

### 最小可用示例

1.  将一些 ROM 文件（如 `Super Mario World.sfc`、`Sonic The Hedgehog 2.md`）放入 `./roms` 文件夹。
2.  按照上述步骤启动 RomM。
3.  扫描完成后，网页端会自动显示游戏名称、封面、简介等。
4.  点击任意游戏，选择“Play”即可通过浏览器开始游玩（需浏览器支持 WebGL 等）。

## 适用场景

- **个人游戏收藏管理**：整理散落在硬盘或 NAS 上成千上万的 ROM 文件，告别混乱的文件夹命名，通过封面和元数据快速找到想玩的游戏。
- **家庭或小型社群共享**：搭建一个内部游戏服务器，让家庭成员或朋友通过浏览器、平板、手机随时访问和游玩同一份游戏库，无需各自下载和配置模拟器。
- **复古游戏在线展示与体验**：游戏主播、内容创作者可以用 RomM 制作一个可玩的游戏目录，在直播中与观众互动，或者作为线上复古游戏博物馆。
- **跨设备无缝游玩**：借助浏览器兼容性，RomM 无缝支持 Windows、macOS、Linux、Android、iOS 设备，用户可以在不同设备间切换，进度通过云端存档同步。

## 项目亮点

与同类工具（如 Emby 的游戏功能、RetroArch 的浏览器版方案）相比，RomM 的差异化优势在于：

- **专为 ROM 设计的一体化体验**：从扫描、元数据抓取、库管理到在线游玩，流程完整闭环，无需跳转到多个工具。支持 DLC、汉化补丁、修改版等 ROM 特有的复杂文件结构。
- **极致的部署简洁性**：仅需一个 Docker Compose 文件、一个 ROM 文件夹即可启动，几乎零配置。而许多竞品需要单独部署模拟器、配置数据库繁冗步骤。
- **丰富的外部生态集成**：除图形界面外，提供 Playnite 客户端、Android 启动器、API 接口，玩家可以在不同设备和工具间无缝使用同一个游戏库。
- **美观且响应式的 UI**：界面设计精致，在桌面端和移动端都有出色表现，降低了非技术用户的使用门槛。
