## 项目概述

Caveman 是一个专为 AI 编码代理设计的技能/插件，支持 Claude Code、Codex、Gemini、Cursor、Windsurf、Cline、Copilot 等 30 多种主流代理工具。它的核心理念可以用一句话概括：“why use many token when few trick do”——通过让 AI 代理像穴居人一样说话，在不影响回答质量的前提下，平均减少 **65% 的输出 Token**。项目目标用户是所有使用 AI 编码助手进行开发的工程师，尤其是那些关注 API 调用成本、响应速度，或希望在有限预算内获得更多价值的开发团队。

## 核心功能

- **激进的 Token 压缩**：通过强制 AI 使用最精简的语言表达，平均减少 65% 的输出 Token，实测中有些场景压缩率甚至超过 70%。
- **30+ 代理即装即用**：无需逐个配置每个 AI 工具，一次安装即可在主流编码代理中生效，覆盖 Claude Code、Codex、Gemini、Cursor、Windsurf、Cline、Copilot 等。
- **可调节的“原始度”等级**：提供多个输出风格级别，从“稍微简洁”到“彻底穴居人”，用户可根据场景和接受程度自由选择。
- **零质量损失**：经基准测试验证，减少 Token 的同时，回答的准确性和完整性保持不变，只是去除了废话和重复性的过渡语。
- **极简安装流程**：通常只需几行配置或一个命令即可完成集成，不干扰现有工作流。
- **开源与 MIT 许可**：完全开源，可自由使用、修改和分发，社区可参与改进。

## 技术架构

Caveman 本质上是一个**系统提示词（system prompt）注入工具**。它并不修改 AI 模型本身，而是通过向代理注入一个经过精心设计的系统指令，改变模型的行为模式。这个指令构建了一个“穴居人”的角色设定，明确要求模型使用最简短的词汇、省略冠词和介词、去除任何形式的口语填充或过渡句。

项目的技术实现依赖于 AI 代理普遍支持的“自定义指令”或“系统提示词”接口。Caveman 提供了一个标准化的指令模板，并针对不同代理工具的配置方式做了适配。其核心设计思路是：**在保持语义完整的前提下，最大化信息的密度，最小化字符的冗余**。与传统的 prompt 压缩方案不同，Caveman 不是通过关键词提取或摘要来完成，而是改变模型生成时的策略，从根源上减少“废话”的产生。

## 安装与使用

Caveman 的安装非常简便。以 Claude Code 为例：

1. 确保已安装 Claude Code 并登录您的 CLI。
2. 在项目根目录下，创建或编辑 `.claude/settings.json` 文件。
3. 在自定义指令字段中添加 Caveman 提供的系统提示词文本（可从项目 README 或 INSTALL 文档中获取）。

对于其他支持的代理，安装流程类似，通常是在设置中启用一个插件或添加一行自定义配置。安装完成后，无需重启或额外操作，AI 回答将立刻变得简洁。

**最小可用示例**：安装后，您可以询问一个复杂的技术问题，比如“请解释在 Node.js 中使用 EventEmitter 的常见模式”。在没有 Caveman 的情况下，AI 可能会回答“好的，EventEmitter 是 Node.js 中一个非常核心的模块，它用于实现事件驱动架构……这里有一个详细的例子”。启用 Caveman 后，回答将变成：“EventEmitter 事件驱动。注册监听器用 `on`，触发用 `emit`。模式：`eventEmitter.on('data', handler)`。优势：解耦、异步。缺点：小心内存泄漏。”——信息量不变，字符量锐减。

## 适用场景

- **高频 API 调用开发**：对于每天调用 AI 代理数十数百次的开发项目，降低 Token 消耗直接转化为成本节省，尤其适合使用按量付费模式的团队。
- **快速迭代与原型设计**：当需要快速获得思路、代码片段或架构建议时，简洁的回答能减少阅读时间，让开发者更快地获取关键信息并投入编码。
- **终端/Low-Bandwidth 环境**：在 SSH 会话、远程开发环境或网络状况不佳时，减少输出 Token 意味着更少的网络传输和更快的响应，提升使用体验。
- **自主学习与教育**：学生或初学者通过阅读这种高度精炼的回答，能更快抓住核心概念，避免被冗长的解释分散注意力。

## 项目亮点

Caveman 与同类解决方案（如手动编写简短的 prompt、使用 Token 压缩代理、或者依赖模型自身的精简模式）相比，具有独特优势。首先，它**一次性解决所有代理的问题**，而不是逐个优化。其次，它**不牺牲准确性与完整性**，传统压缩可能会丢失细节，而 Caveman 是通过改变表达方式而非内容提取来实现压缩。最后，它的**社区活跃度与接受度极高**——超过 8.3 万个 GitHub Stars 和每日数千的增长，证明了开发者对这种“少即是多”理念的强烈共鸣。Caveman 用一种幽默而有效的方式，正面回应了 AI 服务成本高昂这一现实痛点，并将一个技术优化问题转化成了一个充满趣味性的文化 meme。
