## 项目概述

Astryx 是一个由 Meta 内部孵化并开源的设计系统，最初在 Meta 内部使用了八年，成长为该公司中使用最广泛、规模最大的设计系统，支撑超过 13,000 个应用的界面开发。它现在是专为“人机协同”的现代开发方式设计的开源方案——不仅服务于人类开发者，也面向与开发者并肩工作的 AI 代理。

项目基于 React 和 StyleX 构建，目前处于 Beta 阶段。它解决了设计系统在实际落地中常见的几个核心矛盾：一是组件库过于封闭导致定制困难，二是样式方案与项目技术栈耦合过深难以迁移，三是缺乏对 AI 辅助开发的原生支持。目标用户包括前端工程师、UI 设计师、产品团队，以及需要利用 AI 辅助快速生成 UI 的开发者。

## 核心功能

- **150+ 可访问组件**：涵盖表单、导航、数据展示、反馈提示等常见 UI 模块，均经过 Meta 内部大规模应用的验证，并遵循 WAI-ARIA 标准。
- **品牌级主题系统**：通过 CSS 自定义属性实现主题覆盖，支持从全局品牌色到组件级样式的分层定制，无需 Fork 仓库或封装组件。
- **内置暗色模式**：主题系统原生支持亮暗切换，开发者只需提供相应的 CSS 变量覆盖即可实现一键切换。
- **即用型模板**：提供预构建的页面级模板，覆盖后台管理系统、仪表盘、登录页等常见场景，可基于 CLI 快速生成。
- **命令行工具 CLI**：提供脚手架能力，一键安装、初始化项目、生成组件模板或代码片段。
- **“Swizzle”组件弹出机制**：当需要深度自定义时，可以将某个组件的完整源码“弹出”到项目目录中，获得完全控制权，同时保留系统的一致性。

## 技术架构

Astryx 的设计哲学是“开放内部（Open Internals）”——这与许多封闭 API 的设计系统截然不同。其核心架构特点如下：

- **基于 React 与 StyleX**：使用 StyleX 编写样式，但该库对终端用户完全透明，用户无需安装或学习 StyleX。
- **无样式锁定**：组件导出的 `className` 属性支持外部覆盖，允许开发者使用 Tailwind CSS、CSS Modules 或原生 CSS 进行样式扩展，不会强制项目迁移到特定样式方案。
- **CSS 自定义属性主题**：主题机制完全基于 CSS 变量（Custom Properties），这意味着设计师可以直接在设计工具中定义变量值，开发人员只需在项目中引用即可，无需编写额外的 JavaScript 逻辑。
- **类型完备的 React 组件**：所有组件均提供完整的 TypeScript 类型定义，支持 IDE 智能提示和严格类型检查。
- **内置 AI 友好设计**：组件的 API 设计兼顾人类阅读与机器解析，结构清晰、命名一致，便于 AI 代理通过代码生成或自动补全准确调用。

## 安装与使用

Astryx 的安装和使用非常轻量，无需额外的构建插件或样式库集成。

**安装**

```bash
npm install astryx
# 或
yarn add astryx
```

**最小使用示例**

```tsx
import { Button } from 'astryx';
import 'astryx/dist/theme.css'; // 导入基础主题

function App() {
  return (
    <Button variant="primary">
      提交
    </Button>
  );
}
```

**自定义主题**

```css
/* 覆盖主题变量 */
:root {
  --astr-color-primary: #0070f3;
  --astr-border-radius: 8px;
}
```

**使用 Swizzle 自定义组件**

```bash
npx astryx swizzle Button
# 这会将 Button 组件的源码复制到项目的 /components 目录下
```

## 适用场景

- **大型企业级应用开发**：需要统一、可扩展的 UI 规范，且团队规模大、组件复用率高。Astryx 经过 Meta 内部 13,000 多个应用的验证，能够应对复杂业务场景。
- **多品牌或多项目管理**：主题系统支持品牌级定制，适用于需要同时维护多个不同品牌视觉的应用（如子公司、SaaS 多租户场景）。
- **AI 辅助开发与自动化**：设计系统对 AI 代理友好，适合在自动化 UI 生成、低代码平台、以及借助 Copilot/Codex 等工具快速搭建原型的工作流中使用。
- **从已有设计系统迁移**：由于无样式锁定和渐进式采用特性，团队可以逐步替换现有系统中的组件，而无需一次性全面改造。

## 项目亮点

与市面上其他设计系统（如 Material UI、Ant Design、Chakra UI 等）相比，Astryx 的核心差异在于：

1. **完全开源且可被深度定制**。不是只开放顶层 API，而是开放整个组件的内部结构，通过 Swizzle 机制让开发者获得完整的控制权，而无需等待官方更新或维护一个 Fork。
2. **样式中立**。不强制使用任何特定样式方案，与 Tailwind、CSS Modules、普通 CSS 等主流方案兼容，降低了技术选型风险。
3. **“Agent-ready”设计哲学**。官方明确将 AI 代理作为第一类用户，组件 API 设计简洁、语义化，降低了机器生成代码的出错率，这是目前绝大多数设计系统尚未系统性解决的问题。
4. **经过大规模生产环境验证**。不是实验室产品，而是 Meta 内部 8 年投入、13,000+ 应用使用后的产物，稳定性和可靠性有保障。
5. **MIT 许可**。采用宽松的 MIT 许可，允许商业使用、修改和再分发。
