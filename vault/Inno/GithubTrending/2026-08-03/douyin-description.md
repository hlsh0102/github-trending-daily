今日 GitHub 开源项目日报 🚀

1️⃣ microsoft/AI-For-Beginners
微软专为新手打造的AI入门课，12周24课时，涵盖神经网络到深度学习。零基础也能系统掌握AI核心概念，Jupyter交互式学习还能动手跑代码，没有AI背景也能轻松上车。

2️⃣ usekaneo/kaneo
一款极简主义项目管理工具，真·"All you need. Nothing you don't."。没有复杂的面板和冗余功能，专注于任务本身，适合中小团队和独立开发者。

3️⃣ lyogavin/airllm
轻量级大模型推理方案再突破！单张4GB显存就能跑70B参数模型，甚至能跑Llama 3.1 405B和DeepSeek-V3 671B，完全不需要量化压缩。显存贫民玩家的福音。

4️⃣ iv-org/invidious
YouTube隐私友好替代前端，无广告、无追踪，不登录也能订阅频道、创建播放列表。轻量级播放器，低配设备也能流畅观看。

5️⃣ codecrafters-io/build-your-own-x
53万星的硬核教程合集，从零手写数据库、Docker、Git、操作系统到神经网络、区块链。24个领域全覆盖，"不能创造的东西，就是不了解"。

6️⃣ zhaoxuya520/reverse-skill
面向网络安全领域的AI技能路由包，一键匹配逆向工程、渗透测试、固件分析的专用工具链。支持Claude Code、Cursor等AI编码客户端自动路由。

7️⃣ different-ai/openwork
免费开源的AI工作流共享工具，作为Claude Cowork和Codex的替代方案。统一管理技能、MCP和外部服务连接，跨工具跨团队一键复用配置。

8️⃣ microsoft/generative-ai-for-beginners
微软又一力作，21节课带你从零构建生成式AI应用。覆盖提示工程、RAG模式、图像生成等核心主题，代码示例直接上手。

9️⃣ Panniantong/Agent-Reach
让AI代理免费访问全网内容！不再需要付费API，直接读取Twitter、Reddit、YouTube、B站、小红书等平台，统一CLI接口搞定。
