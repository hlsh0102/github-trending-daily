## 项目概述

reverse-skill 是一个面向网络安全领域的 AI 技能路由包，专注于逆向工程、授权渗透测试和安全研究。该项目通过在 AI 编码客户端（如 Claude Code、Kiro、Cursor、Cline 等）中注入结构化的技能路由规则，使 AI 助手能够根据当前任务自动选择最合适的工具链和分析策略。

该项目解决的核心问题是：在安全研究和渗透测试中，AI 助手往往缺乏对专业工具链和标准操作流程的深度理解，导致生成的辅助建议泛泛而谈或偏离实际需求。reverse-skill 通过预置分类技能树和路由规则，让 AI 能够精准识别任务类型（如固件分析、二进制逆向、Web 渗透等），并自动引导至对应的工具集和分析框架。

项目的目标用户包括：安全研究人员、红队测试人员、CTF 参赛者，以及希望在 AI 辅助下开展授权渗透测试的个人或团队。目前该项目在 GitHub 上已获得超过 1.4 万 Star，并处于持续活跃更新状态。

## 核心功能

- **AI 自动路由**：根据用户输入的任务描述，自动识别安全任务类型并匹配对应的分析路径，避免 AI 给出泛化建议。
- **按需自举工具链（Bootstrapping）**：在检测到任务需求时，自动下载、配置或启动所需的逆向/渗透工具，减少手动搭建环境的时间成本。
- **自进化知识库**：内置可扩展的知识管理机制，允许用户记录并沉淀每次分析过程中的经验、脚本和坑点，形成持续增长的团队知识资产。
- **多客户端兼容**：支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编码客户端，通过统一接口接入不同 AI 环境。
- **分类技能树**：预先定义了逆向工程、二进制分析、Web 渗透、密码学攻击等多个子领域的技能节点，每个节点包含工具清单和推荐流程。
- **MIT 开源协议**：完全开源，允许商业使用和二次开发，社区可自由贡献新的技能包或路由规则。

## 技术架构

reverse-skill 采用分层设计，最底层是 **技能节点库**，每个节点对应一类安全任务（例如 "PE 文件分析"、"Android 逆向"），节点内部包含工具列表、常用命令模板、参数说明和注意事项。

中间层是 **路由引擎**，它接收 AI 客户端传递的用户输入（通常是自然语言描述或初步输出结果），通过关键词匹配和语义评分，将输入映射到一个或多个技能节点上。路由引擎以 PowerShell 脚本为核心实现，利用 PowerShell 在 Windows 环境下的生态优势，同时兼容跨平台调用。

最上层是 **客户端适配层**，为不同 AI 编码客户端提供统一的上下文注入格式和调用接口。当 AI 需要执行某个技能节点时，适配层会生成包含工具路径、命令示例和预期输出的提示上下文，引导 AI 生成精准的下一步操作。

知识库部分采用轻量级文件数据库结构，支持 Markdown 格式的经验条目，并设计了自动回溯机制：当 AI 执行完某条命令后，其输出结果可以被一键收藏进知识库，形成经验闭环。

值得注意的是，项目特意设计了 **沙箱提示机制**，在路由到渗透测试相关操作时，会注入合规性提醒，强调仅在授权范围内使用，降低误用风险。

## 安装与使用

**前提条件**：Git、PowerShell 5.1+（建议 7.x），以及任一受支持的 AI 编码客户端（如 Claude Code、Cursor 等）。

**安装步骤**：

1. 克隆仓库到本地任意目录：

```bash
git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill
```

2. （可选）执行初始化脚本，自动生成配置文件：

```powershell
.\scripts\init.ps1
```

该脚本会检查系统已有的安全工具（如 Ghidra、IDA、Burp Suite、Wireshark 等），并生成 `config.json` 记录工具路径。

3. 在 AI 客户端配置文件中，引入 reverse-skill 的上下文注入文件（通常为 `skills/router.md` 或 `.cursorrules`）。以 Claude Code 为例，在项目根目录添加 `.claude/skills` 软链即可。

**最小可用示例**：

假设在 AI 客户端中提问："分析这个 ELF 文件的恶意行为，文件位于 `./samples/malware_0001`"。启用 reverse-skill 后，AI 会输出类似以下内容：

- 识别到需要 ELF 静态分析，路由至 `binary-analysis` 技能节点。
- 推荐工具链：Ghidra（反编译）、radare2（可执行文件解析）、strings（字符串提取）。
- 给出建议的命令序列，例如：

```bash
file samples/malware_0001
strings samples/malware_0001 | head -50
r2 -A ./samples/malware_0001
```

后续 AI 的每次动作都会与路由结果保持一致，避免跑偏。

## 适用场景

**1. CTF 赛事与安全训练**：在解题过程中，AI 辅助快速识别题目类型并给出相应工具链建议，减少翻找资料的时间。

**2. 恶意软件样本分析**：安全分析师接收可疑样本后进行初步鉴定时，reverse-skill 能自动引导至静态分析、动态调试或沙箱运行的规范化流程。

**3. 授权渗透测试项目**：在红队项目中，AI 根据目标类型（Web 应用、内网主机、移动 App）匹配对应的测试思路和工具集，提升测试覆盖度。

**4. 安全工具链的自主学习**：团队新成员借助 AI 路由包快速上手工具组合，同时通过知识库沉淀向团队反向贡献经验。

## 项目亮点

与现有的通用 AI 编程辅助工具相比，reverse-skill 的差异化优势体现在三个层面：

**领域深度**：普通 AI 助手不具备网络安全领域的先验知识，而 reverse-skill 的每个技能节点都是经过实战检验的工具组合和操作流程，显著提高了 AI 建议的专业性。

**自动化程度**：传统工作流中用户需要手动打开工具、切换环境，reverse-skill 的按需自举机制能将工具初始化过程自动化，让 AI 直接生成可执行命令。

**知识迭代机制**：大部分开源项目是静态的，而 reverse-skill 鼓励用户将每次分析中发现的独特技巧沉淀回知识库并提交 PR，这种自进化设计使其使用越久越贴合实际需求。

**多客户端适配**：同一套技能路由逻辑可以通过适配层无缝切换至不同 AI 环境，避免了团队统一 AI 客户端的绑定成本。
