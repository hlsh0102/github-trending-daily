## 项目概述

Kaneo 是一款开源的轻量级项目管理工具，旨在解决当今项目管理软件普遍存在的功能臃肿、界面复杂、使用成本过高的问题。它的核心理念是“All you need. Nothing you don't.”——提供您真正需要的一切功能，同时剔除所有不必要的干扰。

该项目由 usokaneo 团队使用 TypeScript 开发，采用 MIT 许可证分发。Kaneo 的目标用户是那些对现有项目管理平台感到厌倦的中小型团队、独立开发者以及任何希望专注于实际工作而非工具本身的用户。无论您是管理一个小型个人项目，还是协调一个跨部门团队，Kaneo 都力求做到“恰到好处”——每个功能都经过精心设计，以解决真实的问题，而不是为了在演示中显得好看而堆砌。

与市面上大多数项目管理工具不同，Kaneo 并不试图成为您工作流程的“管理者”，而是成为您团队自然工作方式的“放大器”。它相信最好的工具是“隐形的”——不会强迫用户适应工具的逻辑，而是顺应用户已有的工作习惯。

## 核心功能

- **极简任务管理**：提供直观的任务创建、分配、优先级设置和截止日期管理，没有繁琐的多级分类和复杂的自定义字段，让您几分钟内即可上手。
- **看板视图**：支持经典的看板（Kanban）布局，方便您通过拖拽方式管理任务在不同阶段之间的流转，直观呈现项目进度。
- **自托管部署**：您可以将 Kaneo 完全部署在自己的服务器上，数据完全掌控，无需担心隐私泄露或供应商锁定问题。
- **实时协作**：支持团队成员之间的实时更新与同步，确保所有人都能及时看到最新的项目状态变化。
- **善意的通知系统**：精简的通知机制，只在真正需要您关注时发出提醒，避免被无意义的系统消息打扰。
- **MIT 开源许可**：完全开源，您可以根据自己的需求自由定制、扩展或集成 Kaneo，无需支付任何许可费用。

## 技术架构

Kaneo 基于现代 TypeScript 技术栈构建，采用前后端分离的架构设计。前端使用 React 框架，结合现代化 UI 组件库，提供流畅且响应迅速的用户体验。后端基于 Node.js 运行环境，使用 Fastify 框架构建 RESTful API，确保接口的高性能和可扩展性。

在数据存储方面，Kaneo 依赖 PostgreSQL 数据库来持久化数据，并利用其关系型特性来高效管理任务、项目和用户之间的关联关系。对于实时协作功能，Kaneo 使用 WebSocket 协议实现浏览器与服务器之间的双向通信，使得多用户之间的状态同步延迟极低。

项目的架构设计遵循模块化原则，各个功能模块（如身份认证、项目、任务、通知等）相对独立，便于开发者理解和修改。同时，Kaneo 的构建流程和部署配置已完全容器化，您可以快速通过 Docker 镜像将其部署到任何支持容器化技术的环境，极大降低了部署门槛。

## 安装与使用

Kaneo 提供了多种安装方式，最快捷的方式是使用 Docker：

```bash
# 克隆仓库并构建
git clone https://github.com/usekaneo/kaneo.git
cd kaneo

# 使用 Docker Compose 快速启动
docker-compose up -d

# 或者构建为本地 Docker 镜像
docker build -t kaneo .
docker run -p 3000:3000 kaneo
```

如果您希望从源码运行，需要先确保本地已安装 Node.js（>= 18）和 PostgreSQL：

```bash
# 安装依赖
npm install

# 配置环境变量（创建 .env 文件并填入数据库连接等配置）
cp .env.example .env

# 初始化数据库
npm run migrate

# 启动开发服务器
npm run dev
```

启动后，您可以通过浏览器访问 `http://localhost:3000`，注册一个管理员账号后即可创建第一个项目。Kaneo 的界面设计非常简洁，创建任务只需点击“新建任务”按钮，填写标题和负责人，然后将其拖入对应的看板列即可开始协作。

## 适用场景

- **小型团队敏捷开发**：对于采用 Scrum 或看板方法的 5-20 人开发团队，Kaneo 提供了足够的架构来管理 Sprint、Backlog 和日常任务，同时不会让团队陷入繁琐的流程管理之中。
- **个人项目管理**：无论是个人学习项目、开源项目维护，还是自由职业者的客户项目，Kaneo 的轻量特性使其成为一个理想的选择——您不会被复杂的工具所阻碍，而是可以专注于工作本身。
- **对数据敏感的企业内部项目**：由于 Kaneo 支持自托管部署，对于受法规约束或对数据安全性有较高要求的企业，可以在内网环境中部署 Kaneo，在享受现代化项目管理的便利的同时，确保所有数据完全私有。

## 项目亮点

Kaneo 在众多项目管理工具中的差异化优势主要体现在以下几个方面：

- **真正意义上的“简洁”** ：几乎所有主流项目管理工具都在不断增加功能，而 Kaneo 反其道而行之，主动砍掉非核心功能。这种克制的设计哲学使得学习成本近乎为零，新成员加入团队后无需任何培训即可开始使用。
- **性能与体积的平衡**：由于去除了大量前端依赖和复杂组件，Kaneo 的页面加载速度和交互响应速度远快于同类产品，即使在低配硬件上自托管也能流畅运行。
- **社区驱动与开源精神**：项目在 GitHub 上已获得超过 6,000 颗星标，社区活跃度高，且采用 MIT 许可证，您可以随心所欲地修改和分发。这种开放性使得 Kaneo 不仅是工具，更是优秀开源思想的载体。
