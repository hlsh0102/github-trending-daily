## 项目概述

OpenLogi 是一个原生的、本地优先的 Logitech Options+ 替代品，使用 Rust 编写，旨在通过 HID++ 和 UVC 协议解锁罗技鼠标、键盘和网络摄像头的全部功能。该项目解决了罗技官方软件存在的隐私顾虑、强制账号体系和遥测数据收集等问题，为追求数据自主权的用户提供了一个完全本地运行、无需注册、无遥测的解决方案。目标用户包括对隐私敏感的高级用户、开发者以及希望摆脱官方软件限制的罗技外设用户。

## 核心功能

- **按键重映射**：支持对罗技鼠标和键盘的任意按键进行自定义功能映射，包括宏、组合键、启动应用程序等。
- **DPI 调整**：实时调整鼠标的灵敏度设置，并支持多种 DPI 档位切换，提供精确的指针控制。
- **SmartShift 支持**：完整实现 SmartShift 功能，允许在滚动模式和自由滚动模式之间无缝切换。
- **HID++ 协议支持**：通过低层 HID++ 协议与设备通信，绕过驱动层限制，实现真正的硬件级配置。
- **Webcam UVC 控制**：支持通过 UVC 协议调整罗技网络摄像头的焦距、曝光、白平衡等参数。
- **纯本地处理**：所有配置和操作均在本地完成，无需网络连接，不收集任何用户数据。

## 技术架构

OpenLogi 基于 Rust 语言构建，利用其内存安全和并发性能优势，确保外设控制的稳定性和响应速度。项目采用模块化架构，核心通信层通过 HID++ 协议栈直接与设备交互，该协议是罗技设备的低层通信标准，能够访问设备固件级别的设置。对于网络摄像头，则采用 UVC（USB Video Class）标准协议进行参数控制。

设计上，OpenLogi 遵循本地优先原则，所有设备配置以纯文本或数据文件形式存储在本机，不依赖云服务或远程服务器。项目还采用了事件驱动模型，能够实时监听设备状态变化并作出响应，确保用户的操作即时生效。配置系统设计为可扩展，未来将支持配置文件导入导出，便于用户备份和迁移设置。

## 安装与使用

目前项目正处于积极开发阶段，尚未发布稳定版本。用户可以通过以下方式尝鲜：

1. **从源码构建**：确保已安装 Rust 工具链，克隆仓库并执行 `cargo build --release`，生成的可执行文件位于 `target/release/` 目录。
2. **下载预发布版本**：关注 GitHub Releases 页面，获取最新的预编译二进制文件。

最小使用示例：

```bash
# 克隆仓库
git clone https://github.com/AprilNEA/OpenLogi.git
cd OpenLogi

# 构建项目
cargo build --release

# 运行 OpenLogi（需要管理员权限以访问 HID 设备）
sudo ./target/release/openlogi
```

启动后，OpenLogi 会自动检测连接的罗技设备，用户可通过图形界面或命令行工具查看设备信息并修改配置。详细的配置方法将在后续文档中完善。

## 适用场景

- **隐私敏感用户**：希望完全脱离罗技官方软件的账号体系和遥测追踪，在本地完成所有设备管理。
- **高级外设玩家**：需要精细调校鼠标 DPI、按键布局和宏命令，追求极致游戏或工作效率。
- **跨平台开发者**：在 Linux 等官方软件支持不完善的系统上，需要完整的罗技设备控制能力。
- **企业环境**：需要在无法连接外网的内部网络中部署外设管理方案，避免数据传输至外部。

## 项目亮点

OpenLogi 的核心优势在于其**原生本地化**特性。与 Logitech Options+ 相比，它不需要用户注册账号、不上传任何使用数据，完全离线运行。基于 Rust 的实现使其在资源占用和启动速度上远优于 Electron 架构的官方软件，同时具备跨平台潜力。项目采用开放的 HID++ 协议实现硬件级控制，而不是依赖驱动层的破解或模拟，确保了兼容性和稳定性。此外，Apache-2.0 许可允许商业使用和二次开发，为有定制需求的企业用户提供了法律保障。尽管项目仍处于早期阶段，但其社区活跃度（13000+ Star）和开发进度表明，它有望成为罗技外设管理的社区标准工具。
