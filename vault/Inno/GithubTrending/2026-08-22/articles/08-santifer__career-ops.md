## 项目概述

career-ops 是一个开源的 AI 求职辅助系统，旨在将求职过程中繁琐、主观且耗时的环节系统化和自动化。它直接切入求职者与招聘方之间的信息不对称问题：企业使用 AI 筛选候选人，而求职者却往往只能依赖手工方式逐条浏览职位、凭感觉评估匹配度、反复修改简历。

该项目由 santifer 开发，作者表示在经历数月传统求职方式的低效后，决定构建一套“希望当初就能拥有”的系统。career-ops 的核心价值在于：通过 AI 代理（Agent）自动化扫描职位门户、使用结构化的 A-F 评分体系将职位质量量化为 1.0-5.0 的分数、根据目标职位定制简历，并持续跟踪整个申请流程。项目采用 MIT 许可证，完全开源，所有操作均在本地的 AI 编程 CLI 环境中运行，无需将个人求职数据上传至第三方服务器。

目标用户包括正在积极求职的软件工程师、产品经理、设计师等技术人员，尤其是那些使用 Claude Code、Codex、OpenCode、Antigravity 等 AI 编码工具作为日常开发环境的开发者。

## 核心功能

- **职位门户自动扫描**：通过 AI 代理自动访问主流招聘网站和职位聚合器，抓取最新的职位信息，无需人工逐页浏览。

- **A-F 结构化评分**：每个职位列表都会根据预先定义的 A-F 评分标准（涵盖职位匹配度、公司质量、薪酬范围、技术要求、成长空间等维度）进行自动评估，并输出一个 1.0-5.0 的量化分数，帮助求职者快速识别最优机会。

- **简历智能定制**：针对每个高分职位，系统能够自动分析职位描述中的关键词、技能要求和职责重点，并据此调整和优化用户的简历内容，提高通过 ATS（申请人跟踪系统）筛选的概率。

- **申请全流程跟踪**：内置看板或表格视图，记录每个职位的申请状态、投递日期、反馈情况等所有元数据，让求职者对自己的求职进展一目了然。

- **本地化运行**：所有 AI 处理和数据处理均在用户本地的 CLI 环境中执行，确保数据隐私和完全控制权，不使用云端服务存储简历或职位数据。

## 技术架构

career-ops 以 JavaScript 为主要语言，设计为运行在主流 AI 编码 CLI 环境中的多代理（Multi-Agent）系统。其架构核心是一个任务编排层，负责调度不同的 AI 代理分别执行扫描、评估、定制和跟踪等任务。

系统采用模块化设计，各个功能组件（如职位抓取器、评分引擎、简历优化器）之间通过清晰定义的接口交互，允许用户根据需要启用或替换特定模块。在底层，career-ops 依赖 AI 编码 CLI 提供的工具调用能力来执行文件操作、网络请求和数据处理。其评分引擎使用一个可配置的评分卡片（scorecard），用户可以根据自己的求职偏好调整权重因子。

代码库遵循函数式编程风格，偏向于可测试性和可扩展性。由于项目运行在本地，其对网络和外部 API 的依赖进行了抽象化，允许用户接入不同的 AI 模型后端。项目采用零配置原则，但通过环境变量或配置文件支持高级自定义，例如设置目标职位类型、地理位置偏好和技能权重等。

## 安装与使用

**安装步骤（概述）**

由于 career-ops 针对 AI 编码 CLI 设计，安装通常涉及从 GitHub 克隆仓库并将项目目录添加到 CLI 环境的项目路径中。

```bash
# 克隆仓库
git clone https://github.com/santifer/career-ops.git
cd career-ops

# 安装依赖（使用 npm 或 yarn）
npm install

# 在 AI 编码 CLI（如 Claude Code）中启动会话并加载项目
```

**最小可用示例**

在支持工具调用的 AI 编码 CLI 中，用户可以通过自然语言指令驱动系统工作。例如，在会话中输入：

```
扫描最近 7 天的前端工程师职位，按评分排序显示前 5 个。
```

系统会触发代理执行职位扫描、评分，并返回一个结构化的结果表格，其中包含每个职位的标题、公司、评分和关键匹配理由。用户随后可以继续指令：

```
为评分最高的职位定制我的 resume.md 文件。
```

来生成针对该职位的优化简历版本。

## 适用场景

- **主动求职的技术从业者**：在准备跳槽或寻找新机会时，使用 career-ops 批量扫描市场机会，快速定位高匹配度职位，节省大量时间。

- **大规模海投策略**：需要短期内投递大量职位、以量取胜的求职场景。系统能够自动评分筛选，确保即使海投也优先处理最值得投入的职位。

- **简历优化与 ATS 规避**：对特定公司或岗位有强烈意向时，利用简历定制功能精准匹配职位描述，提升进入面试环节的概率。

- **求职数据跟踪与复盘**：长期求职过程中，希望通过结构化数据复盘自己的投递策略、分析失败原因的用户。

## 项目亮点

- **逆向思维解决信息不对称**：项目核心洞察在于“用 AI 对抗 AI”。当企业普遍使用 AI 筛选候选人时，求职者用 AI 来主动选择和评估企业，从被动等待变成主动出击，这是与传统求职工具最大的不同。

- **量化与结构化**：不同于市面上大多数提供模糊“匹配度百分比”的工具，career-ops 采用严格的 A-F 评分标准并将结果量化为 1.0-5.0 的小数分数，使得决策有明确的数据支撑，减少了主观情绪的干扰。

- **本地优先、数据自主**：所有数据和 AI 处理都在本地完成，不会在未知的云端服务器留下个人简历和求职数据。这对于注重隐私、或者对数据安全有合规要求的用户尤其重要。

- **深度集成开发工作流**：专为 AI 编码 CLI 设计，能够与开发者日常使用的工具链无缝融合，不增加额外的工作流切换成本。
