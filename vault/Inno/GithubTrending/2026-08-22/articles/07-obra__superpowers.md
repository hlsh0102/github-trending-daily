## 项目概述

Superpowers 是一套面向 AI 编码代理（coding agents）的完整软件开发方法论。它并非单纯的工具集或插件，而是将一套可组合的技能（skills）与初始化指令相结合，使你的编码代理能够以结构化和规范化的方式进行工作。该项目解决的核心问题是：如何让 AI 编码代理从“直接写代码”的盲目行为，转变为“先思考、再规划、后执行”的工程化流程。目标用户是所有使用 AI 辅助编码工具的开发者，尤其是那些希望提升代理输出质量、减少无效代码迭代、并让 AI 深度参与从需求分析到实现全过程的团队和个人。

## 核心功能

- **需求澄清引擎**：代理在开始编码前，会主动暂停并询问用户真正想要构建的内容，通过对话方式逐步提取出明确的规格说明（spec），避免因理解偏差导致的返工。
- **分块规格展示**：将生成的规格说明以短小、易于消化的块状形式呈现给用户，确保用户能真正阅读并理解，而不是给出冗长难以审阅的文档。
- **实现计划制定**：在规格获得用户确认后，代理会生成一份结构化的实现计划，该计划将复杂任务拆解为可执行的步骤，为后续编码提供清晰的路线图。
- **可组合技能库**：项目内置了一套模块化、可复用的技能（skills），这些技能覆盖了软件开发中的常见任务模式，代理可以根据具体需求灵活组合调用。
- **多平台适配**：提供了针对多款主流编码代理工具的安装与配置指南，包括 Claude Code、Cursor、Codex CLI、Gemini CLI、GitHub Copilot CLI 等十余种环境，实现了跨工具的兼容性。
- **方法论驱动**：不仅仅是指令集，更是一套完整的“工作流”，从启动代理开始，贯穿需求、设计、计划、编码全过程，将工程最佳实践固化到 AI 的工作方式中。

## 技术架构

Superpowers 的技术架构核心在于“指令”与“技能”的分离和组合。它主要使用 **Shell** 脚本作为技能的载体，通过一套精心设计的初始化指令（instructions）和提示词工程，引导编码代理在启动时加载并遵循特定流程。其设计思路是：

1. **指令层（Instruction Layer）**：作为代理的“大脑”，负责在会话开始时设定行为准则，例如“不要立即编码，先澄清需求”。
2. **技能层（Skills Layer）**：由一组可独立运行的脚本或命令组成，每个技能封装了特定的开发子任务（如生成测试、执行重构等），代理通过调用这些技能来执行具体操作。
3. **工作流层（Workflow Layer）**：通过指令层将技能编排成一个有序的流程（例如：澄清需求 -> 生成规格 -> 制定计划 -> 逐步实现），确保整个开发过程结构分明。

这种架构的显著特点是高度模块化和可组合。开发者可以像搭积木一样，根据项目需要启用或编写新的技能，而无需改动核心指令。同时，它充分利用了 Shell 脚本的跨平台和易调用特性，使得集成到不同的代理工具中变得异常简单。整体设计哲学强调“先想后做”，通过强制性的前置规划来减少 AI 编码的随机性和不可控性。

## 安装与使用

安装 Superpowers 非常直接，主要是将项目文件克隆到本地，并在你的编码代理工具中进行配置，使其在启动时加载该项目的指令。

**以 Claude Code 为例的基本安装步骤：**

1.  **克隆仓库**：将项目克隆到你的工作环境中。
    ```bash
    git clone https://github.com/obra/superpowers.git
    cd superpowers
    ```
2.  **运行安装脚本**：项目通常提供一键安装脚本，用于将必要的指令和技能文件复制到 Claude Code 的配置目录（如 `~/.claude`）。
    ```bash
    ./install.sh
    ```
3.  **配置代理**：确保你的 Claude Code 配置指向了 Superpowers 的技能目录，或者按照项目 README 中的指导修改配置文件，以便代理在启动时加载。

**最小可用示例（工作流）：**

1.  启动 Claude Code，并指定使用 Superpowers 项目作为工作目录。
2.  输入一个模糊的需求，例如：“帮我写一个 Python 脚本处理 CSV 文件。”
3.  代理不会立即写代码，而是会提问：“具体需要对 CSV 做什么操作？数据清洗、统计汇总还是格式转换？”
4.  你回答问题后，代理会生成一份简短的规格说明供你确认。
5.  确认后，代理会制定一个实现计划，然后才开始编写代码。

对于其他工具（如 Cursor、Codex CLI 等），安装方式类似，只需按照仓库中对应平台的说明文档进行操作即可。

## 适用场景

- **复杂项目开发**：当项目规模较大、需求不明确时，使用 Superpowers 可以强制进行需求梳理，避免 AI 在没有全貌的情况下生成错误架构。
- **团队协作与代码审查**：由于流程产生了清晰的规格和实现计划，团队成员可以更轻松地审查 AI 的工作成果，理解其逻辑，并在代码编写前纠正方向。
- **教育学习与最佳实践推广**：开发者可以通过观察代理如何遵循该流程，学习如何将大型任务结构化，并将其作为团队内部 AI 辅助开发的标准化流程。
- **跨工具统一体验**：对于在不同电脑或使用不同编码代理工具的开发者，Superpowers 提供了一套一致的开发方法论，确保无论是使用 Claude 还是 Cursor，AI 的工作方式都保持专业和规范。

## 项目亮点

与市场上大多数只提供“代码补全”或“代码生成”的 AI 工具不同，Superpowers 的核心优势在于其**工程化思维**的注入。它不追求一次性生成完美代码，而是通过强制引入“需求分析 -> 规格确认 -> 计划制定”的前置环节，从根本上提升了 AI 生成代码的可靠性和目的性。这种“先计划后执行”的策略，显著降低了后期调试和返工的成本。

此外，其**多平台兼容性**和**模块化技能库**的设计也极具前瞻性。开发者不会被困在单一工具生态中，而技能库的开放性允许社区和个人持续贡献，使项目拥有长久的生命力。它不仅仅是一个下载即用的工具，更是一套可以持续演进、适应不同团队工作流的开发框架。
