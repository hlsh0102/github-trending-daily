## 项目概述

Understand Anything 是一个开源的代码与知识可视化工具，能够将任何代码库、知识库或文档集转化为交互式知识图谱。用户可以在生成的图谱中自由探索、搜索，甚至直接向图谱提问，从而快速理解复杂的项目结构或知识体系。项目名称“Understand Anything”直观地表达了其核心目标：让理解和掌握任何信息源变得简单高效。

该项目由 Lum1104 开发并维护，采用 TypeScript 编写，获得了社区的广泛关注（GitHub 上已有超过 3.2 万颗 Star）。它特别适用于那些需要频繁接手陌生代码、管理知识文档或进行跨领域学习的开发者和知识工作者。项目目前已无缝对接 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等主流 AI 编程助手，进一步降低了使用门槛。

## 核心功能

- **代码转知识图谱**：自动解析代码库中的模块、函数、类、文件依赖等关系，生成结构化的交互式知识图谱，帮助用户快速梳理整体架构。
- **知识库与文档可视化**：支持将 Markdown 文档、Wiki、API 文档等非代码内容解析为图谱节点，展示概念间的关联与层级。
- **交互式探索与搜索**：用户可在图谱中自由拖拽、缩放、点击节点以查看详情，同时支持关键词搜索，快速定位特定模块或概念。
- **自然语言问答**：集成大语言模型，用户可以直接对图谱提问（如“这个函数被哪些文件调用了？”或“解释一下这个模块的整体逻辑”），系统会基于图谱语义生成回答。
- **多工具兼容**：原生支持与 Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等主流开发工具协同工作，无需额外配置。
- **导出与分享**：生成的图谱可以导出为图片或 JSON 格式，方便在团队协作中共享或嵌入文档。

## 技术架构

Understand Anything 的核心技术栈包括 TypeScript（主语言）、D3.js（用于图可视化渲染）、以及针对不同输入源的解析器（如 AST 解析器用于代码、Markdown 解析器用于文档）。其设计遵循以下原则：

- **模块化解析引擎**：项目采用插件化的解析架构，每种输入类型（代码、文档、知识库）对应独立的解析模块。用户可以根据需要选择或开发自定义解析器，而无需修改核心逻辑。
- **图谱数据模型**：所有节点和边被统一抽象为图数据结构，节点包含类型、名称、描述等元数据，边定义关系类型（如“调用”“继承”“引用”）。这种统一模型使得跨源数据的融合与查询变得容易。
- **语义层集成**：在图谱之上，项目构建了语义层，通过将图谱结构与自然语言处理模型结合，实现“提问-回答”功能。这一层利用了大模型的上下文理解能力，将用户问题映射到图谱中的路径和节点。
- **轻量级运行时**：项目本身不依赖复杂后端服务，可完全在浏览器或本地环境中运行。用户只需提供输入源，即可快速生成图谱，适合一次性分析或持续集成场景。

## 安装与使用

### 安装

1. **前提条件**：确保已安装 Node.js（v16 或更高版本）和 npm。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/Lum1104/Understand-Anything.git
   cd Understand-Anything
   ```
3. **安装依赖**：
   ```bash
   npm install
   ```
4. **全局安装（可选）**：为了方便在任意项目中使用，可以全局安装 CLI 工具：
   ```bash
   npm install -g .
   ```

### 最小可用示例

假设我们需要可视化当前目录下的一个简单代码库：

```bash
# 生成当前目录代码的图谱
understand-anything . -o output_graph

# 启动本地交互界面查看图谱
understand-anything serve output_graph
```

上述命令会解析当前目录中的代码文件，生成图谱数据并保存到 `output_graph` 目录，随后启动一个本地 Web 服务，在浏览器中打开即可看到交互式图谱。

对于文档库，同样简单：

```bash
# 可视化一个 Markdown 文档目录
understand-anything ./docs -o doc_graph --format markdown
```

如果使用 Claude Code，可以直接在对话中调用：

```plaintext
> /understand-anything /path/to/your/codebase
```

Claude Code 会自动调用 Understand Anything 生成图谱并返回交互式链接。

## 适用场景

1. **接手遗留代码库**：当你需要快速理解一个大型、缺乏文档的旧项目时，一键生成代码图谱，可以马上看清模块间的依赖关系和调用链，避免在代码中盲目翻找。
2. **团队新成员 onboarding**：新成员加入时，通过 Understand Anything 生成的项目知识图谱可以替代冗长的文档介绍。新成员可以自主探索图谱，并在遇到问题时直接提问，大幅缩短上手时间。
3. **知识库整理与文档编写**：对于团队维护的 API 文档、Wiki 或技术笔记，生成知识图谱可以直观展示概念间的关联，帮助发现知识漏洞或冗余内容。编辑时也可以将图谱作为结构化模板。
4. **AI 辅助编程的上下文增强**：当使用 Claude Code、Cursor 等 AI 编程助手时，Understand Anything 生成的图谱可以作为增强上下文输入，让 AI 更准确地理解项目整体结构，从而给出更高质量的代码建议或重构方案。

## 项目亮点

- **极致易用性**：一条命令即可完成从解析到可视化的全过程，无需复杂配置，适合所有技术水平的开发者。
- **强 AI 集成**：不仅支持常见的 AI 编程工具，还内置了自然语言问答能力，将图谱从静态展示进化为可交互的“知识助手”。
- **全类型输入支持**：代码、文档、知识库统一处理，打破了不同类型知识源之间的壁垒，尤其适合那些混合了代码和文档的复杂项目。
- **开源且高活跃度**：社区贡献活跃，每天都有大量更新和优化。官方文档和支持多语言（包括中文），降低了全球开发者的使用门槛。
- **轻量无侵入**：生成过程不会修改原始代码或文档，所有输出都是独立的图谱文件，不会对项目产生任何副作用。
