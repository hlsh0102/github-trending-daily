## 项目概述

ECC（Efficient Code Companion）是一个面向AI编程助手的代理框架性能优化系统。它旨在解决当前AI编程工具（如Claude Code、Codex、Opencode、Cursor等）在复杂任务执行过程中存在的效率瓶颈与能力局限问题。ECC通过提供技能化行为模块、环境感知记忆系统、安全执行沙箱以及研究优先的开发范式，让AI代理能够更聪明、更高效地理解和执行代码任务。该项目主要面向使用AI辅助编程的开发者、AI代理的构建者以及希望深度定制自己AI工作流的进阶用户。

## 核心功能

- **技能化行为系统**：将AI代理的常见操作（如代码搜索、重构、测试）模块化为独立“技能”，代理可根据上下文动态调用，避免重复加载无关能力，显著提升响应速度。
- **环境感知记忆系统**：代理能自动留存关键上下文信息，并在后续会话中智能检索，避免重复理解项目结构，实现长期任务连贯性。
- **本能级安全机制**：内置安全执行沙箱，对文件操作、外部API调用等敏感行为进行实时拦截和审核，防止AI代理误操作导致数据丢失或权限泄露。
- **多模型适配层**：统一接口兼容Claude Code、Codex、Opencode、Cursor等主流AI编程工具，代理行为与提示工程在此层自动标准化，降低切换成本。
- **研究优先开发模式**：提供一套实验性评测套件，开发者可快速验证新功能对代理性能的影响，支持A/B测试与数据驱动优化。
- **性能洞察仪表盘**：实时记录代理执行耗时、技能调用频次、记忆命中率等关键指标，帮助定位瓶颈并调优提示词或技能配置。

## 技术架构

ECC采用分层插件化架构。底层为**模型适配层**，通过统一Agent API规范屏蔽不同AI工具的差异；中间层为**运行时引擎**，负责技能调度、记忆管理及安全沙箱操作；顶层为**用户配置接口**，支持YAML/JSON格式定义技能集合、记忆规则和安全策略。核心实现使用JavaScript，利用了Node.js的事件驱动与非阻塞I/O特性来保证低延迟。记忆系统采用向量数据库（如LanceDB或Chroma）进行语义检索，技能模块遵循类似微服务的独立包设计，可单独更新。安全沙箱基于VM2或类似隔离技术，严格限制文件系统和网络访问权限。

## 安装与使用

1. **前提准备**：确保已安装Node.js（版本≥18）并拥有目标AI工具（如Claude Code或Cursor）的执行环境。
2. **安装ECC核心**：
   ```bash
   npm install -g @affaan/ecc
   ```
   或使用项目内特定版本：
   ```bash
   git clone https://github.com/affaan-m/ECC.git
   cd ECC
   npm install
   ```
3. **初始化配置**：
   在项目根目录创建`ecc.config.yml`：
   ```yaml
   skills:
     - refactor
     - search
   memory:
     enabled: true
     backend: "chroma"
   security:
     sandbox: "strict"
   ```
4. **与AI工具集成**：
   以Cursor为例，在`settings.json`中添加：
   ```json
   {
     "cursor.ecc.enabled": true,
     "cursor.ecc.configPath": "./ecc.config.yml"
   }
   ```
5. **最小可用示例**：启动AI代理并输入“重构当前函数，使用ECC技能”，代理将自动加载`refactor`技能完成重构，并在记忆系统中记录操作上下文。

## 适用场景

- **大型代码库维护**：当AI代理需要频繁在数千个文件间导航时，ECC的记忆系统和技能预加载可大幅减少重复解释项目结构的时间消耗。
- **安全敏感的自动化流水线**：在CI/CD流程中集成AI代理进行自动化代码审查或修复时，ECC的安全沙箱能有效防范代理误修改关键配置文件或触发未授权操作。
- **多AI工具协同工作流**：团队中同时使用Claude Code和Cursor的不同开发者，可通过ECC的统一配置层保证代理行为一致性，减少因工具差异导致的输出不可靠问题。
- **代理性能研究与实验**：AI研究团队需要量化不同提示策略或技能组合对任务完成率的影响时，ECC的评估套件和数据仪表盘可直接使用。

## 项目亮点

ECC的差异化优势在于其**系统级的性能优化思路**，而非单纯的提示词包装。它将代理行为从“每次重新开始”转变为“持续学习与调度”——记忆系统让代理记住前文，技能调度避免无关代码加载，安全沙箱则解决了普通提示词无法阻挡的误操作风险。此外，**多模型适配**的设计让ECC不绑定单一AI工具，用户可在不同平台间无缝迁移配置。相比同类项目（如LangChain的Agent实现），ECC更专注于编程场景下的精细化调优，开箱即用度更高。
