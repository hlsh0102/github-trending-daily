## 项目概述

Jellyfin 是一款完全免费、开源的媒体系统服务器后端与 API 实现。它允许用户将个人媒体库（电影、电视剧、音乐、照片等）集中存储在服务器上，并通过多种客户端设备（浏览器、智能电视、手机、平板、游戏主机等）进行远程访问和流式播放。该项目解决了传统媒体管理软件（如 Plex、Emby）因商业化转型带来的功能限制和许可证问题，为个人和家庭用户提供了一个完全自主可控的媒体中心解决方案。其目标用户包括家庭媒体爱好者、自建 NAS 使用者、开源软件倡导者以及需要低成本媒体管理方案的企业用户。

## 核心功能

- **多用户支持**：系统内置用户管理功能，支持创建独立账户，并为每个账户设置观看限制、播放权限和内容分级。
- **跨平台流媒体播放**：支持实时转码与直接串流，确保媒体内容在不同网络环境和设备上兼容播放，包括常见的 H.264、H.265、VP9 等编码格式。
- **元数据自动抓取**：内置元数据抓取引擎，能够从 TMDb、TheTVDB、MusicBrainz 等公共源自动下载封面、简介、演员信息、评分等数据，大幅减少手动整理的工作量。
- **插件扩展系统**：提供开放的插件框架，社区开发者已贡献了超 150 个插件，覆盖字幕下载、转码优化、外部通知、元数据补充等功能。
- **硬件加速转码**：支持 Intel QuickSync、NVIDIA NVENC、AMD VA-API 等硬件加速方案，降低 CPU 负载，提升多路并发转码性能。
- **媒体库同步与备份**：允许自动扫描文件系统变动，支持同步本地或远程存储的媒体内容，并配合工具实现元数据备份和恢复。

## 技术架构

Jellyfin 基于 .NET (C#) 构建，采用 MVC 架构模式。服务端核心包括：

- **媒体识别引擎**：通过 FFmpeg 进行媒体信息解析与转码作业，同时使用内置的媒体名分析算法与外部元数据 API 匹配内容。
- **API 层**：提供 RESTful API，覆盖播放控制、用户管理、媒体库管理等功能，所有客户端应用均基于此接口开发。
- **数据库持久化**：默认使用 SQLite 作为媒体库索引与用户配置的存储后端，同时提供可选的 PostgreSQL 支持，满足大规模部署需求。
- **事件驱动架构**：通过内部事件总线处理文件监控、播放状态变更、转码任务调度等异步操作，降低模块间耦合度。

前端客户端基于 React 开发的 Web 界面（Jellyfin-Web），并通过 Electron、React Native 等封装为桌面和移动应用。流媒体传输协议支持 HLS、DASH、WebSocket，确保低延迟和高质量体验。

## 安装与使用

Jellyfin 支持多种部署方式，以下以 Docker 为例说明基本安装步骤：

1. **拉取镜像**：
   ```bash
   docker pull jellyfin/jellyfin:latest
   ```

2. **运行容器**（假设媒体文件存储在 `/path/to/media` 目录）：
   ```bash
   docker run -d \
     --name jellyfin \
     -p 8096:8096 \
     -v /path/to/config:/config \
     -v /path/to/cache:/cache \
     -v /path/to/media:/media:ro \
     --user 1000:1000 \
     jellyfin/jellyfin
   ```

3. **访问 Web 界面**：打开浏览器访问 `http://<服务器IP>:8096`，按照初始化向导设置管理员账户、添加媒体库（指定路径 `/media` 下的子文件夹）。

**最小可用示例**：在添加媒体库时，选择电影目录 `/media/movies`，系统会自动扫描并抓取元数据，用户即可通过任意客户端或浏览器开始浏览和播放。

## 适用场景

- **家庭多屏媒体中心**：将家庭所有 DVD、蓝光或下载的数字影片集中管理，家庭成员通过电视、手机、笔记本自由点播，避免文件复制和格式转换的麻烦。
- **NAS 伴侣**：配合 Synology、QNAP 等 NAS 设备部署，利用 NAS 的存储能力和低功耗特性，提供 7×24 小时的媒体服务。
- **远程访问私人影音库**：在公网环境下，通过 HTTPS 或反向代理安全访问家中的媒体内容，适合出差或旅行时追剧。
- **教育或机构资源分发**：用于学校内部的教学视频、企业内部培训资料的集中管理和按权限分发，减少网络传输负担。

## 项目亮点

- **完全免费与开源**：采用 GPLv2 许可证，无任何付费订阅、功能锁定或广告植入。代码公开可审计，安全性透明。
- **零追踪隐私保护**：不收集用户播放行为数据，无第三方分析 SDK 嵌入，所有数据仅存储在用户自己的服务器上。
- **活跃的社区驱动**：GitHub 上拥有 5 万+ Stars，开发者社区持续贡献更新和维护。用户可通过论坛、Discord、Reddit 直接与核心团队沟通。
- **广泛的客户端兼容性**：除 Web 端外，提供 Android、iOS、Apple TV、Android TV、Roku、Kodi、DLNA 等多种客户端，覆盖几乎全部主流平台。
- **低门槛高扩展性**：单台普通 PC 即可运行，同时支持集群部署、硬件转码加速、LDAP 集成等企业级特性。
