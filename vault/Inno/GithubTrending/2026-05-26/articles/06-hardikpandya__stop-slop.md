## 项目概述

stop-slop 是一个专注于文本润色的技能文件集合，旨在帮助写作者和内容创作者从散文中移除人工智能生成的痕迹。该项目的核心目标是解决当前 AI 写作工具输出文本中常见的“AI味”问题，让文本回归自然、流畅、具有人类风格的状态。GitHub 仓库上目前获得了 4692 颗星，今日新增 345 颗星，表明社区对其需求旺盛。

对于使用 AI 辅助写作的用户而言，这一项目填补了关键需求：AI 模型往往生成结构工整但缺乏个性化表达的文本，容易被打上“机械感”、“套话”、“模式化”的标签。stop-slop 通过提供系统化的编辑指南，帮助用户识别并去除这些特征，使最终文本更接近人类自然写作的表达方式。

目标用户包括：内容编辑、文案写作者、博客作者、学术研究者、以及任何希望在使用 AI 写作工具后能产出更真实文本的个人或团队。

## 核心功能

- **AI 痕迹识别指南**：提供详细的规则和示例，帮助用户识别 AI 生成文本中常见的模式化表达、冗余词汇和流水账结构。
- **多语言支持适配**：覆盖中文、英文等主流语言的写作习惯差异，针对不同语言特点提出具体的修改建议。
- **逐层清理机制**：从词汇、句式到段落结构三个层面给出清理操作，用户可按需选择修改深度。
- **真实案例库**：附带大量“AI 原文-修改版”对比案例，直观展示如何将 AI 味浓重的文字转化为自然表达。
- **脚本化工具集成**：提供可直接在编辑器中运行的 shell 脚本或配置文件，通过自动化扫描实现初筛。

## 技术架构

本项目本质上是一套以规则驱动的文本处理技能文件。技术实现上采用轻量级架构：

- **核心文件格式**：以 YAML 或 JSON 配置文件存储识别规则，定义词法模式、句式特征和句法异常。例如，AI 生成文本中高概率出现的“此外”、“值得注意的是”、“无可争议”等短语被标记为待处理目标。
- **脚本层**：采用 Bash 或 Python 编写的脚本，对输入文本进行词频统计、模式匹配和异常检测。脚本输出为高亮列表，供用户手动判断是否需要替换。
- **规则引擎设计**：基于正则表达式和 NLP 特征库进行模式匹配，支持用户自定义扩展规则。每条规则都附带解释说明和修改建议，确保编辑过程有据可依。
- **无依赖性**：不依赖外部 API 或高性能计算资源，在普通笔记本电脑上即可运行。整个项目可在几秒内扫描数千字文本。
- **可扩展性**：规则文件采用标准格式，用户可自行添加新规则或社区贡献的规则包，形成持续更新的“反 AI 味”知识库。

## 安装与使用

安装过程非常简单：

1. **克隆仓库**
   ```bash
   git clone https://github.com/hardikpandya/stop-slop.git
   cd stop-slop
   ```

2. **运行扫描（示例）**
   在终端中执行：
   ```bash
   python scripts/scan.py input.txt --lang zh
   ```
   扫描完成后会输出一份高优先级修改建议列表，如：
   ```
   行 12: “此外” → 建议改为：“还有”或直接删除
   行 35: “严重关注” → 建议改为：“在意”或“在…上花费更多精力”
   ```

**最小可用示例：**

假设你有一段 AI 生成的文字：
“为了提升用户体验，我们持续优化产品功能，此外，团队也在不断学习新方法。”

运行扫描后，脚本会提示：
- “为了……，我们……”结构过于模式化 → 建议改成：“优化产品功能，团队也在学新方法，目的是让用户体验更好。”
- “此外”冗余 → 直接删除。

修改后的自然版本可能是：
“优化产品功能，团队也在学新方法，目的就是让用户体验更好。”

若编辑过程需要更精细的控制，可编辑 `rules/zh.yaml` 文件，调整替换阈值或添加新规则。

## 适用场景

- **内容营销文案润色**：企业博客、产品介绍、营销邮件等 AI 辅助撰写的商业内容，需去除“模板味”以建立品牌信任感。
- **学术论文语言优化**：研究人员使用 AI 辅助生成初稿后，通过 stop-slop 确保行文符合学术出版规范，避免被误判为机器写作。
- **社媒帖子个性化**：自媒体运营者需让 AI 生成内容更像真人手写，增加自然语态、口语化表达和情绪波动。
- **技术文档人性化**：手册、教程等常因 AI 生成显得生硬，stop-slop 可帮助融合技术准确性与阅读舒适度。

## 项目亮点

与同类工具相比，stop-slop 的核心差异化优势在于：

- **社区驱动模式**：项目规则动态更新，规则来自编者和用户的实际使用反馈，而非某家公司的封闭模型。4692 星和每日 345 星的增长量即说明其活力和认可度。
- **透明可解释**：每条修改建议都附带原因（如“避免模式化开头”“增强文本连贯性”），用户能理解并学习这些编辑决策，而不是黑箱替换。
- **轻量化与零成本**：无需云端服务或 GPU，在本地即可运行。规则文件可手动编辑，适合需要精细控制写作风格的专业用户。
- **跨平台兼容**：无论使用 VS Code、Sublime Text、Vim 还是 Notepad++，脚本均可集成到编辑器自动保存流程中，实现即时校对。
- **反套话训练集**：长期使用此工具的用户，能系统性地培养避开 AI 套话的写作直觉，形成自己的写作风格。
