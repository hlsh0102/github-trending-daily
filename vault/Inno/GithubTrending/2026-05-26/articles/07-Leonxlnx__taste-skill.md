## 项目概述

Taste-Skill 是一个为 AI 生成内容注入“品味”的开源工具，旨在解决当前大语言模型普遍存在的输出平庸、模板化、缺乏个性的问题。它的核心理念是：AI 不仅能正确回答，更能生成有风格、有辨识度、令人印象深刻的内容。目标用户包括内容创作者、开发者、产品经理以及任何希望从 AI 获得更高质量、更具人性化输出的使用者。通过简单的配置干预，Taste-Skill 能显著减少“AI 味”，让生成文本更接近人类专家的语感与创意。

## 核心功能

- **风格注入引擎**：允许用户通过配置文件定义 AI 输出的风格偏好，涵盖幽默、讽刺、优雅、冷峻、学术等多种维度，使回答不再千篇一律。
- **上下文感知的品味评分**：实时对 AI 生成内容进行“品味度”评估，自动过滤或调整机械重复、过度正式或无意义的“填充词”。
- **反模式识别**：内置对数十种常见 AI 写作劣化模式（如“在当今社会”“首先其次最后”等套话）的识别与抑制，从源头避免俗套。
- **细粒度控制**：支持对单次生成请求进行风格强度调节（0-100），开发者可在批量推理中灵活切换标准模式与品味增强模式。
- **轻量化集成**：以 Shell 脚本为核心，无需依赖复杂框架，兼容主流 AI API（如 OpenAI、Anthropic）的命令行调用，秒级部署。
- **社区风格市场**：提供预置模板库（如“科技博主”“诗人”“产品经理”），用户可共享自创风格配置，降低使用门槛。

## 技术架构

Taste-Skill 采用 **Shell + JSON 配置** 的极简架构，核心链路为：用户输入 → 品味策略编译器 → API 增强请求 → 输出后处理。其设计思路如下：

1. **前置过滤层**：通过正则表达式与启发式规则库，对用户输入进行“反平庸预处理”。例如，检测到“请用专业术语回答”这类保守命令时，自动修正为更开放的指令。
2. **提示词工程封装**：将风格偏好编译为结构化前缀/后缀提示，无缝嵌入到标准 API 调用中。用户无需手动编写复杂 prompt，所有风格参数通过键值对配置。
3. **后处理校验**：对 AI 返回的文本执行二次品味评分，若得分低于阈值，自动触发重试（使用不同温度参数或系统提示变体），直至输出满足风格要求。
4. **本地优先**：所有品味策略文件存储在本地 `~/.taste-skill/` 目录，不依赖云服务，保护用户数据隐私。核心脚本小于 200K，无运行时依赖。

这种设计让 Taste-Skill 既可作为独立命令行工具直接使用，也能通过管道集成到其他工具链中（例如与 `jq` 结合处理 JSON 格式响应，或嵌入 CI/CD 流程生成营销文案）。

## 安装与使用

### 安装

```bash
git clone https://github.com/Leonxlnx/taste-skill.git
cd taste-skill
chmod +x taste-skill.sh
# 建议将脚本软链到 PATH 中
ln -s $(pwd)/taste-skill.sh /usr/local/bin/taste-skill
```

### 最小可用示例

1. **配置 API 密钥**（以 OpenAI 为例）：
   ```bash
   export OPENAI_API_KEY="your-api-key-here"
   ```

2. **测试基本用法**：
   ```bash
   # 使用默认风格（文艺）生成一段关于“月亮”的描述
   taste-skill "写一段关于月亮的文字"
   ```

3. **切换风格**：
   ```bash
   # 使用预设的“冷峻”风格
   taste-skill --style cool "解释什么是区块链"
   
   # 手动指定风格强度（0 = 无干预，100 = 极致风格化）
   taste-skill --strength 90 "帮我写一封求职邮件"
   ```

4. **自定义风格配置文件**：
   ```bash
   echo '{"voice": "classical", "complexity": 0.7, "avoid": ["首先", "其次", "值得一提的是"]}' > my-style.json
   taste-skill --config my-style.json "描述一次日落"
   ```

## 适用场景

- **内容创作**：博客作者、社交媒体运营人员可使用它生成区别于 AI 堆砌感、更具个人品牌辨识度的文案，降低校对修改成本。
- **产品文案本地化**：跨境电商或出海产品的广告文案需要符合目标市场审美（如日本用户偏好含蓄，中东用户偏好华丽），通过切换风格模板快速适配。
- **开发者工具链集成**：在 CI/CD 流程中自动生成发版公告或 API 文档的示例描述，确保输出风格统一且不呆板。
- **教育与科研**：需要生成有“人类语感”的例题讲解或科普短文，避免学生察觉 AI 痕迹，保持阅读沉浸感。

## 项目亮点

- **零心智负担**：不同于需要学习复杂 prompt 工程的方案，Taste-Skill 将风格抽象为开关式参数，任何人 5 分钟即可上手。
- **可证伪的改进**：其“反模式识别”功能提供明确的干预效果验证。例如，运行 `taste-skill --audit` 可将原始 AI 输出与增强后输出进行对比，直观展示差异。
- **社区共驱**：GitHub 仓库已收录 50+ 用户贡献的风格配置文件，覆盖科学、艺术、商业等多个领域，形成可累积的品味知识库。
- **极低资源占用**：仅依赖 Shell 和 curl，能在树莓派、云函数等轻量环境中运行，而竞争对手多需要 Python 运行时或 Docker 环境。
- **持续进化**：项目维护者每周基于用户反馈更新反感模式列表（例如近期新增了对“作为一个人工智能模型...”等免责开头的抑制），确保工具能跟上大模型输出的演变。
