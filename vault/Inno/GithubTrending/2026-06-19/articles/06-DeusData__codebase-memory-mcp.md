## 项目概述

codebase-memory-mcp 是当前业界最快的代码智能 MCP 服务器。它能够将整个代码库索引为一个持久的知识图谱，对普通仓库的索引时间仅需毫秒级，对 Linux 内核（2800 万行代码、7.5 万文件）也只需 3 分钟。查询响应时间小于 1 毫秒，且比同类方案节省 99% 的 token 消耗。该项目以单一静态二进制文件发布，零外部依赖，开箱即用，专为提升 AI 编码代理（coding agent）的代码理解能力而设计。

## 核心功能

- **毫秒级全量索引**：对普通仓库的完整知识图谱构建时间仅为毫秒级，大幅降低等待延迟。
- **亚毫秒级结构查询**：支持对函数、类、调用链、HTTP 路由等结构信息的即时查询，响应时间低于 1 毫秒。
- **158 种语言的高质量解析**：基于 tree-sitter 实现 AST 分析，覆盖几乎所有主流编程语言。
- **混合 LSP 语义增强**：对 Python、TypeScript/JavaScript/JSX/TSX、PHP、C#、Go、C、C++、Java、Kotlin 和 Rust 等语言，利用 Hybrid LSP 技术进行类型解析，提升语义准确性。
- **持久化知识图谱**：索引结果持久存储，避免重复计算，支持跨会话重用。
- **14 个 MCP 工具**：提供丰富的工具接口，可与 11 种主流编码代理无缝集成。
- **零依赖单文件部署**：编译为单一静态二进制文件，下载后直接运行 `install` 即可完成部署。

## 技术架构

codebase-memory-mcp 采用分层架构设计，底层核心使用 C 语言编写，以保证极致性能。其技术栈包括：

1. **tree-sitter 解析层**：利用 tree-sitter 生成精确的 AST，支持 158 种语言的语法分析，确保对代码结构的准确提取。
2. **Hybrid LSP 层**：在树解析基础上，针对主要类型系统较强的语言，通过混合 LSP 协议获取语义类型信息，生成更精确的类型闭包和调用关系。
3. **知识图谱存储**：将解析结果组织为持久化的图结构，包含函数、类、调用链、HTTP 路由定义、跨服务调用关联等实体及关系。采用高效的序列化格式，支持快速索引和查询。
4. **MCP 协议层**：实现标准 MCP 服务器协议，暴露 14 个工具接口，使得任何遵循 MCP 协议的客户端均可使用。
5. **编译与部署**：采用静态编译策略，将所有依赖嵌入单一二进制中。支持 macOS、Linux 和 Windows 三平台，部署流程简化为一条命令。

架构设计上，代码库索引与查询分离：索引过程充分利用多线程和增量构建能力，查询则通过专有的图索引结构实现亚毫秒级响应。这种设计确保即使在大型仓库中，也能保持低延迟和高吞吐。

## 安装与使用

安装过程极为简便。以 macOS 或 Linux 为例：

1. 从 GitHub Releases 页面下载对应平台的最新二进制文件。
2. 在终端中运行以下命令完成安装：

```bash
# 下载后执行
chmod +x codebase-memory-mcp
./codebase-memory-mcp install
```

安装完成后，MCP 服务器会自动配置到系统中。用户可在支持的编码代理（如 Claude Desktop、VS Code 中的 MCP 插件等）中直接使用。

最小可用示例：在一个包含 Python 和 JavaScript 文件的项目中，启动 MCP 服务器后，向代理提问“请找到所有调用了 `authenticate` 函数的地方”或“列出此项目中所有 HTTP 路由定义”。服务器将在毫秒内返回精确结果。

对于自定义配置，用户可通过命令行参数指定索引路径、存储位置等选项。详细的配置说明可在项目文档中找到。

## 适用场景

- **AI 编码代理辅助**：在为 AI 代理提供代码上下文时，传统方法（如直接输入整个文件）常导致 token 爆炸。本服务通过知识图谱大幅压缩上下文，仅传递最相关的结构和类型信息。
- **大型代码库的即时导航**：在百万行级别的代码库中，快速定位函数定义、调用链、类型关系等，无需长时间等待索引完毕。
- **跨语言代码分析**：在混合语言项目中（例如前端 TypeScript、后端 Go、数据库层 Python），统一查询不同语言之间的调用关系和服务依赖。
- **持续集成与代码审查**：将 MCP 服务器集成到 CI 流水线中，自动生成代码结构报告，辅助代码审查和重构决策。

## 项目亮点

- **极致性能**：与同类方案（如基于完整文件索引的替代品）相比，索引速度提升数个数量级，查询延迟降低至 1 毫秒以下，token 消耗减少 99%。这是目前已知最快的商用级代码知识图谱引擎。
- **完整的独立部署**：单一静态二进制，零外部依赖。用户无需安装复杂的运行时环境（如 Node.js、Python、Docker），也无需管理依赖包版本冲突。
- **广泛的语言支持**：158 种语言的语法解析 + 11 种语言的语义增强，覆盖绝大多数现代软件开发场景。
- **与主流代理兼容**：提供标准 MCP 接口，直接兼容 11 种编码代理，无需额外适配工作。
- **研究与开源结合**：项目背后有学术研究成果支撑（参见 arXiv 论文），在保证前沿技术的同时保持完全开源（MIT 协议）。
