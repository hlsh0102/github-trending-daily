## 项目概述

DocuSeal 是一款开源的数字文档签署和表单填写平台，旨在作为 DocuSign 等商业解决方案的免费替代品。它允许用户创建 PDF 表单，并让签署人在任何设备上通过移动端优化的网页工具在线填写和签署文档。项目采用 AGPL-3.0 许可证，源代码托管在 GitHub，同时提供云端托管服务。目标用户包括需要电子签名功能的中小企业、独立开发者、法务团队以及任何希望以低成本实现文档数字化处理的个人或组织。

## 核心功能

- **PDF 表单字段可视化构建器（WYSIWYG）**：通过拖拽式界面，在 PDF 文档上直观添加表单字段，支持所见即所得的编辑模式。
- **12 种字段类型**：包括签名、日期、文件上传、复选框、单选框、文本输入、数字、下拉选择等，覆盖常见表单需求。
- **多签署人支持**：一份文档可以设置多个签署人或填写人，支持按顺序或并行完成签署流程。
- **自动化邮件通知**：通过 SMTP 服务器自动发送签署邀请和提醒邮件，无需手动操作。
- **灵活的文件存储**：支持将文档存储在本地磁盘或云存储服务（AWS S3、Google Cloud Storage、Azure Blob Storage）。
- **移动端优化**：响应式网页设计，确保在手机和平板上获得流畅的填写签署体验。

## 技术架构

DocuSeal 基于 Ruby 语言开发，使用 Ruby on Rails 框架构建后端服务。前端采用现代 JavaScript 框架实现交互式表单构建器和签署界面。项目利用 PDF 渲染技术解析和修改 PDF 文件，支持批量处理。部署方面通过 Docker 镜像提供一键式安装方案，简化环境配置。架构设计遵循 MVC 模式，确保代码的可维护性和可扩展性。存储层支持多种后端，允许用户根据需求和预算自由选择。整个系统以自托管为核心，用户数据完全掌握在自己手中，无需依赖第三方云服务。

## 安装与使用

### 安装步骤（Docker 方式）

1. 确保已安装 Docker 和 Docker Compose。
2. 拉取官方 Docker 镜像：
   ```
   docker pull docuseal/docuseal
   ```
3. 运行容器（快速启动示例）：
   ```
   docker run -p 3000:3000 docuseal/docuseal
   ```
4. 访问 `http://localhost:3000` 进入管理后台，首次使用需要注册管理员账号。

### 最小可用示例

1. 登录管理后台后，点击"创建表单"。
2. 上传一个 PDF 文件，使用可视化编辑器拖拽添加签名、日期等字段。
3. 保存表单后，点击"发送"输入签署人邮箱，系统自动发送签署链接。
4. 签署人打开邮件中的链接，在网页上完成填写和签署。
5. 管理员可在后台随时查看签署进度和下载完成的文档。

## 适用场景

- **合同签署流程**：企业使用 DocuSeal 发送销售合同、保密协议、服务条款等文件给客户或合作伙伴在线签署，无需打印邮寄。
- **人事管理**：人力资源部门用于发放和回收入职文件、绩效评估表、离职协议等员工文档。
- **表单数据收集**：学校、社区或非营利组织使用其创建报名表、申请表、反馈问卷，让填表人在线提交。
- **法律文件处理**：律师事务所或法务部门通过可配置的签署顺序，处理需要多方见证签字的文件。

## 项目亮点

与其他电子签名方案相比，DocuSeal 的主要优势在于：完全开源且可自托管，避免数据和隐私依赖商业云端服务；轻量级部署，通过 Docker 可在几分钟内搭建完整功能环境；提供实时演示站点，用户无需安装即可体验核心功能；社区活跃，在 Discord 和 GitHub 上保持快速响应；支持多种云存储集成，方便与企业现有基础设施对接。对于预算有限或对数据主权有严格要求的团队，DocuSeal 提供了一个功能完整度接近商业产品但成本极低的替代选择。
