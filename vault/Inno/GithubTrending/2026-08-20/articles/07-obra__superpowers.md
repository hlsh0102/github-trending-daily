## 项目概述

Superpowers 是一套面向编码代理（coding agents）的完整软件开发方法论。它建立在可组合的技能集合（composable skills）与初始指令之上，确保你的 AI 编码代理在执行任务时遵循经过验证的工程实践，而不是直接跳入代码编写。该项目解决的核心问题是：当前编码代理经常在需求不明确、设计未确认的情况下贸然生成代码，导致返工、架构混乱和难以调试等问题。Superpowers 通过引导代理遵循结构化流程——从需求澄清到规格确认，再到实现规划——帮助开发者和团队获得更可控、更高质量的 AI 辅助开发体验。目标用户包括使用 Claude Code、Cursor、Codex、Gemini CLI 等主流编码代理工具的个人开发者、技术团队以及任何希望提升 AI 编程效率与代码质量的工程组织。

## 核心功能

- **需求澄清引导**：当代理检测到正在构建功能时，不会立即写代码，而是主动提问并帮助用户梳理真实目标，提取清晰的需求规格。
- **分块规格确认**：将生成的规格说明书按可读的小块展示给用户审批，确保每一部分都被充分理解和确认，避免误解。
- **实现计划生成**：在规格获批后，代理会形成结构化的实现计划，明确任务拆解、依赖关系和执行顺序，作为编码的蓝图。
- **可组合技能体系**：提供一组模块化的技能（skills），涵盖设计、编码、测试、重构等环节，代理可根据项目需求动态组合使用。
- **多工具适配**：内置针对 Claude Code、Antigravity、Codex App/CLI、Cursor、Gemini CLI、GitHub Copilot CLI 等十余种主流编码代理工具的安装与配置指南，开箱即用。
- **持续更新与社区驱动**：由活跃社区维护，提供明确的更新机制与贡献指南，技能库可随最佳实践不断演进。

## 技术架构

Superpowers 的核心设计思路是“流程优先，技能复用”。它并非一个独立的代理程序，而是一组按标准格式编写的技能定义（通常为 Markdown 或结构化指令文件），存放在特定目录中。当用户启动任意兼容的编码代理时，代理会读取这些指令，从而在行为上“装配”出遵循方法论的工作流。这种设计具有高度可移植性：同一套技能库可以被不同工具加载，无需重复实现。

架构上突出“可组合性”（composability）。每个技能像一个函数，拥有明确的输入（上下文、用户输入）和输出（决策、文件变更或查询）。方法论通过编排这些技能的调用顺序，例如先启动规格提炼技能，再进入设计技能，最后触发实现技能，形成一个连贯的流程管道。此外，项目采用命名规范明确的技能目录结构，并通过初始指令（如 system prompt 文件）让代理在会话开始时就加载核心流程约定。整体架构不依赖特定云服务或专用后端，以本地文件与提示工程为核心，保证了灵活性和安全性。

## 安装与使用

安装流程因所用编码代理而异，但大体分为两步：克隆仓库到本地，然后在代理配置中指定技能目录路径。以 Claude Code 为例：

```bash
# 1. 克隆项目
git clone https://github.com/obra/superpowers.git

# 2. 进入项目目录
cd superpowers

# 3. 运行安装脚本（如提供）
./install.sh  # 参考 README 中的具体说明

# 4. 在 Claude Code 配置中启用技能库（将路径指向 ./skills 目录）
```

若使用 Codex CLI 或 Cursor，则分别将其技能目录映射到代理的 skills 路径。最小可用示例如下：启动代理后，简单地描述你要构建的功能（例如“写一个待办事项 CLI 工具”），代理会依据 Superpowers 方法论开始提问、输出规格片段，待你确认后生成实现计划并逐步执行。所有交互均在对话流中完成，无需额外操作。

## 适用场景

- **AI 辅助需求分析与原型开发**：当团队使用 AI 编码代理从零搭建新功能或 MVP 时，通过强制需求澄清和规格确认，避免代理生成与预期偏差过大的代码。
- **大型代码库维护与重构**：在涉及跨模块重构时，利用实现计划步骤拆分任务，降低 AI 批量编辑引发的回归风险。
- **教学与团队规范落地**：组织可将 Superpowers 作为团队编码协作的基线方法论，统一 AI 辅助开发的流程标准，便于代码审查与交接。
- **复杂系统设计讨论**：结合规格分块展示机制，帮助架构师与 AI 协作产出高质量系统设计文档，作为后续开发的基础。

## 项目亮点

与同类方案相比，Superpowers 最大的差异化在于它是一个“方法论工具包”，而非绑定单一平台的技能库。它成功让技能在不同代理之间迁移，这得益于其格式中立的设计，大大降低了用户更换工具的学习成本。同时，其强调“先想清楚再做”的工作流程精准打击了 AI 编程中最普遍的痛点——代码生成过快导致返工。此外，项目拥有高达 274k 以上的 Stars 与活跃社区，说明其方法论在实践中获得了广泛验证和持续优化，这是一个高活跃度、高信任度的开源项目，与许多仅提供单一脚本或 prompt 的项目形成对比。
