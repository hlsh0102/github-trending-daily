## 项目概述

career-ops 是一个开源的人工智能求职系统，旨在将求职过程中繁琐、重复且容易出错的工作流程自动化。项目作者在经历了数月低效的求职过程后，决定构建一套自己真正需要的系统，并将其开源供所有人使用。

该项目的核心理念是：企业使用 AI 筛选候选人，那么候选人同样可以使用 AI 来选择和评估企业。career-ops 不只是简单地聚合招聘信息，而是通过结构化的评估机制，帮助求职者从海量职位中筛选出真正值得投入精力的机会，并针对每个职位优化申请材料。

项目以 JavaScript 编写，完全在本地运行于 AI 编码命令行工具（如 Claude Code、Codex、OpenCode、Antigravity 等）中，不依赖任何云端服务。目标用户包括正在积极求职的开发者、希望系统化管理求职流程的职场人士，以及任何希望利用 AI 提升求职效率的个人。

## 核心功能

- **自动扫描招聘门户**：自动从多个主流职位发布平台抓取招聘信息，无需手动浏览多个网站。
- **结构化 A-F 评分体系**：根据用户设定的标准（如薪资范围、技术栈匹配度、远程办公政策、公司规模等）对每个职位进行评估，并转换为 1.0–5.0 的量化分数。
- **简历自动定制**：针对评分较高的职位，自动调整简历中的关键词、技能重点和项目描述，使其与职位要求精准匹配。
- **申请进度追踪**：内置跟踪系统，记录每个职位的申请状态、面试阶段、沟通记录等，形成完整的求职时间线。
- **多语言支持**：项目文档已翻译为多种语言，包括中文（简体和繁体）、西班牙语、德语、法语、日语、韩语等，方便全球用户使用。
- **完全本地运行**：所有数据处理均在本地完成，无需将简历或求职数据上传至第三方服务器，保护隐私安全。

## 技术架构

career-ops 基于多代理（Multi-Agent）架构设计，在 AI 编码 CLI 环境中运行。系统将求职流程拆分为多个独立的智能代理，每个代理负责一项特定任务：

- **扫描代理**：负责定期访问招聘网站，抓取新发布的职位信息，并去重、归档。
- **评估代理**：使用用户配置的评分标准，结合职位描述的语义分析，对每个职位进行 A-F 等级评定并映射为 1.0–5.0 的分数。
- **定制代理**：读取用户的主简历（Master Resume），针对目标职位生成定制化简历版本，并在关键位置嵌入与职位描述匹配的关键词。
- **跟踪代理**：维护申请数据库，记录申请状态、后续跟进事项，并生成进展报告。

系统通过配置文件控制各代理的行为参数，用户无需修改代码即可调整评分权重、扫描频率、关键词库等。由于完全运行在本地 CLI 环境中，整个过程透明可控，用户可以看到每一步的处理逻辑和中间结果。

项目采用模块化设计，核心逻辑与 CLI 界面解耦，未来可以方便地扩展新的招聘源或评估维度。所有数据以结构化格式（如 JSON）存储，便于用户自行导出或与其他工具集成。

## 安装与使用

**前提条件**：需要已安装 Node.js（建议 v18 或以上），并配置一个 AI 编码 CLI 工具（如 Claude Code 或 Codex）。

**安装步骤**：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/santifer/career-ops.git
   cd career-ops
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 复制配置文件并进行个性化设置：
   ```bash
   cp config.example.json config.json
   ```

4. 编辑 `config.json`，填写目标职位关键词、偏好公司列表、薪资期望、评分权重等参数。

**最小可用示例**：

在 AI 编码 CLI 中启动系统：

```bash
career-ops scan
```

该命令将触发扫描代理，从配置的招聘源抓取最新职位，并输出评估结果。用户可以通过交互界面查看每个职位的评分和详细分析，选择高评分职位后运行：

```bash
career-ops tailor --job-id JOB_123
```

该命令将调用定制代理，基于主简历生成针对该职位的定制版本，并保存到指定目录。

## 适用场景

- **全职求职者**：每天花费大量时间浏览招聘网站，希望系统化筛选和跟踪申请进度的求职者，可以将重复性工作交给 career-ops，专注于面试准备。
- **技术栈定向转换**：希望从当前技术栈转向新领域的开发者，可以通过设置关键词和评分权重，快速识别愿意接受转行候选人的职位类型。
- **批量申请策略**：采用“广撒网”策略的求职者，可以使用系统的自动化定制功能，为每个职位生成有针对性的简历，避免千篇一律的通用简历被筛选掉。
- **自由职业者或顾问**：需要持续关注市场机会、定期评估潜在客户项目的专业人士，可以利用评分体系筛选高价值机会。

## 项目亮点

- **反客为主的理念**：大多数求职工具帮助公司筛选候选人，career-ops 反向操作，让候选人用同样的 AI 技术来评估公司，真正实现双向选择。
- **量化决策依据**：通过结构化的 A-F 评分和 1.0–5.0 的数值打分，将模糊的“职位是否合适”转化为可比较的量化指标，减少决策疲劳。
- **本地运行与隐私保护**：所有数据处理都在本地完成，简历和个人数据不会发送到任何云服务器，特别适合注重隐私的用户。
- **高度可配置**：用户可以精细控制评分标准、扫描频率、关键词权重等，系统会根据反馈持续迭代，而不是固定的黑盒流程。
- **社区与透明度**：项目在 Trendshift 上持续获得高热度，社区贡献活跃，开发过程完全公开，用户可以参与功能改进和 Bug 修复。
