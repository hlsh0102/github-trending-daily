## 项目概述

Immich 是一款高性能、自托管的照片与视频管理解决方案，旨在为用户提供类似 Google Photos 的完整体验，同时将数据的完全控制权保留在用户自己手中。随着云存储服务的隐私问题日益凸显，以及用户对个人数据主权的需求不断增长，Immich 应运而生，为那些希望摆脱大型科技公司生态的用户提供了可靠的替代方案。

该项目采用 TypeScript 为主要开发语言，基于 AGPL-3.0 开源许可证发布，目前在 GitHub 上已获得超过 11 万颗星标，是一个活跃度极高、社区参与度旺盛的开源项目。Immich 的目标用户包括隐私敏感型个人用户、家庭用户，以及希望为组织内部搭建私有媒体管理平台的技术团队。无论是想要备份手机相册的普通用户，还是需要为团队提供共享媒体库的开发者，Immich 都能满足其需求。

## 核心功能

- **移动端与 Web 端应用**：提供 iOS、Android 原生应用以及基于浏览器的 Web 客户端，支持照片与视频的上传、浏览、管理、分享和下载。

- **自动备份**：移动端应用支持后台自动备份功能，可无缝将设备中的新照片和视频同步至自托管服务器，确保数据安全。

- **智能搜索**：内置基于机器学习的目标检测与图像分类能力，用户可以通过自然语言描述（如“海滩 2023”）快速检索历史媒体内容。

- **时间线与回忆**：按时间维度呈现媒体库，支持事件聚合、回忆推荐，以及按日期、地点、人物等维度进行照片浏览。

- **多用户与共享相册**：支持创建共享相册，可邀请其他用户共同查看、添加照片，适合家庭成员或团队协作场景。

- **极速响应体验**：通过流式加载、转码优化和高效的资源缓存机制，即使在低带宽环境下也能获得流畅的浏览体验。

## 技术架构

Immich 采用现代前后端分离架构，后端基于 Node.js 构建，前端使用 Flutter 开发跨平台应用，Web 端则采用 React 框架。整个系统由多个微服务模块组成，包括身份验证服务、媒体上传服务、元数据提取服务、搜索索引服务等，模块之间通过高效的内部通信协议协作。

在媒体处理层面，Immich 使用了专业级转码工具和图像处理库，支持包括 HEIC、RAW 在内的多种主流格式。搜索功能基于专门优化的数据库索引和机器学习模型，在保证准确性的同时控制资源消耗。系统设计遵循高可用原则，支持 Docker Compose 快速部署，也支持通过 Kubernetes 进行生产级扩展。值得一提的是，Immich 对硬件要求适中，家庭用户可以使用普通 NAS 或小型服务器运行，而大型部署则可以通过横向扩展来应对更高的并发需求。

## 安装与使用

Immich 提供了非常友好的安装流程，推荐使用 Docker Compose 进行一键部署。以下是基本的安装步骤：

1. **环境准备**：确保目标机器已安装 Docker 和 Docker Compose，并具备至少 2GB 内存和 20GB 可用磁盘空间。

2. **获取部署文件**：从官方仓库或部署文档获取现成的 `docker-compose.yml` 和环境变量示例文件。

3. **启动服务**：在部署目录下执行 `docker compose up -d` 命令，系统会自动拉取所需镜像并启动所有服务。

4. **初始化账户**：通过浏览器访问 `http://<服务器IP>:2283`，按照引导创建管理员账户并完成基础设置。

5. **安装移动端应用**：在 iOS App Store 或 Google Play Store 搜索 “Immich” 安装移动应用，然后在应用中配置服务器地址并登录即可开始上传照片。

最小可用示例（docker-compose.yml 核心片段）：

```yaml
version: "3.8"
services:
  immich-server:
    image: ghcr.io/immich-app/immich-server:release
    ports:
      - 2283:3001
    volumes:
      - UPLOAD_LOCATION:/usr/src/app/upload
    env_file:
      - .env
    depends_on:
      - redis
      - database
  redis:
    image: redis:6.2-alpine
  database:
    image: postgres:14
    environment:
      POSTGRES_PASSWORD: postgres
    volumes:
      - db-data:/var/lib/postgresql/data
```

## 适用场景

- **家庭媒体中心**：将全家人的照片与视频集中存储在家中 NAS 或闲置电脑上，彻底取代 iCloud 或 Google Photos，无需担心容量限制和隐私泄露。

- **摄影师与内容创作者**：作为作品集管理平台，支持高质量原片存储、RAW 文件管理以及智能标签功能，方便快速检索和展示。

- **小型团队协作**：用于组织内部的项目照片、活动记录或素材共享，通过多用户权限控制实现安全协作。

- **隐私敏感机构**：律师事务所、医疗机构等需要严格数据合规的场所，可以将媒体数据完全内网部署，杜绝第三方访问风险。

## 项目亮点

与同类开源方案（如 Photoprism、LibrePhotos）相比，Immich 最显著的优势在于其开箱即用的完整性和卓越的用户体验。项目借鉴了成熟的商业产品特性，并针对自托管场景进行了深度优化。

- **极致的性能表现**：每秒可处理数百张照片的转码任务，移动端浏览几乎无等待时间。

- **先进的智能搜索**：无需额外配置复杂的 AI 模型，Immich 内置的识别能力已经能准确理解中文等自然语言查询。

- **完善的生态配套**：拥有官方 Discord 社区、详细的部署文档以及活跃的版本迭代计划，用户可以快速获得问题解答。

- **全平台一致体验**：无论是手机、平板还是桌面浏览器，界面设计与功能表现保持高度统一，降低了学习成本。
