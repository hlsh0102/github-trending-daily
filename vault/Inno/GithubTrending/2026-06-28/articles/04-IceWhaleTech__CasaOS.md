## 项目概述

CasaOS 是一个简单、易用、优雅的开源个人云系统，由 IceWhaleTech 团队开发维护。它的核心理念是让每一位用户都能轻松搭建属于自己的私有云环境，摆脱对第三方云服务的依赖。CasaOS 的目标用户涵盖技术爱好者、家庭用户、小型团队以及任何希望拥有数据主权、降低 SaaS 成本的个人或组织。

该项目以“连接社区、建立自主权、降低 SaaS 成本、最大化个性化副手潜力”为宗旨，致力于将复杂的自建云服务流程简化为直观的图形化操作。通过 CasaOS，用户可以将闲置的硬件设备（如旧电脑、树莓派、NAS 设备）转化为功能完整的个人云，从而安全地存储文件、运行应用、共享资源，并完全掌控自己的数据。

## 核心功能

- **一键应用商店**：内置丰富的开源应用商店，支持 Docker 应用的一键部署与管理。用户无需手动编写 Docker Compose 文件，即可轻松安装 Nextcloud、Jellyfin、Home Assistant 等数十种流行服务，极大降低了技术门槛。
- **简洁直观的仪表盘**：提供美观的 Web 管理界面，实时展示系统资源使用情况（CPU、内存、磁盘、网络），并支持自定义首页布局，使设备状态一目了然。
- **文件管理**：内置功能完善的文件管理器，支持上传、下载、预览、编辑和分享文件。可以管理服务器本地存储以及挂载的外部存储设备，实现跨平台文件同步。
- **系统与用户管理**：支持多用户隔离，每个用户拥有独立的空间和权限。同时提供系统设置、网络配置、磁盘管理、备份恢复等基础管理功能，让用户像管理手机一样管理服务器。
- **扩展中心与定制化**：通过主题、小部件和插件系统，用户可以根据个人需求定制仪表盘的样式和功能。未来还将支持更多社区贡献的扩展能力。
- **远程访问与安全**：提供便捷的远程访问方案（如内置反向代理和 SSL 支持），并集成防火墙规则，确保个人云服务在网络中的安全性和可访问性。

## 技术架构

CasaOS 采用 **Go 语言**开发后端核心，保证了高性能和低资源占用，尤其适合在树莓派、低功耗 x86 设备上运行。前端基于现代化的 **Vue.js** 框架，提供响应式、交互流畅的用户体验。

系统架构遵循模块化设计原则，核心服务包括：

- **casaos-gateway**：统一网关，负责路由转发和 API 代理，保障前后端通信的安全性。
- **casaos-service**：主管理服务，处理应用管理、用户认证、系统配置等核心业务逻辑。
- **casaos-local-storage**：本地存储管理模块，自动检测并挂载外接磁盘。
- **casaos-message-bus**：内部消息总线，实现各服务模块间的解耦通信。

底层依赖 Docker 容器技术来运行应用，这使得 CasaOS 能够跨平台兼容 x86_64 和 ARM64 架构。应用商店中的每个应用均以独立的 Docker 容器运行，实现了隔离性、可移植性和便捷的版本回滚。

## 安装与使用

CasaOS 的安装过程极其简洁，仅需一行命令即可完成。系统会自动检测环境并拉取最新版本。

**安装命令（适用于 Linux 系统）**：

```bash
curl -fsSL https://get.casaos.io | bash
```

该脚本会自动完成以下步骤：
1. 安装必要依赖（如 Docker）。
2. 拉取 CasaOS 核心镜像。
3. 启动服务并将管理端口绑定到 **8080**。

**最小可用示例**：
1. 确保设备已安装 Linux 系统（推荐 Ubuntu 22.04/24.04 或 Debian 12+），并能正常连接互联网。
2. 执行上述安装命令，等待脚本运行完成。
3. 打开浏览器，访问 `http://<设备IP>:8080`，按照引导设置管理员账户和密码。
4. 进入主界面后，可立即在应用商店中搜索并安装所需服务，如 Nextcloud、Jellyfin 等，全程无需操作终端。

## 适用场景

- **家庭媒体中心**：在旧电脑或树莓派上部署 CasaOS，然后安装 Jellyfin 或 Plex，配合文件管理器管理电影、音乐、照片，家庭成员即可通过电视、手机、平板随时访问。
- **私有云存储**：安装 Nextcloud 或 Seafile，搭建完全自控的文件同步与共享平台，替代 Dropbox、Google Drive 等公共云服务，保护家庭照片、文档等隐私数据。
- **智能家居控制台**：在 NAS 或小主机上运行 CasaOS，安装 Home Assistant 或 ESPHome，统一管理家中智能设备，通过仪表盘实时监控传感器状态。
- **轻量级 Web 开发与测试环境**：开发人员可利用 CasaOS 一键启动多个 Docker 容器作为开发环境（如数据库、Web 服务器、应用后端），并在统一的界面上管理项目资源，提升效率。

## 项目亮点

- **极致易用**：CasaOS 将“入门级”体验做到了极致。从安装到部署第一个应用，普通用户几分钟即可完成，无需理解 Linux 命令行、Docker 原理或网络配置。这是它区别于 OpenMediaVault、TrueNAS 等专业 NAS 系统的主要优势。
- **对低功耗设备友好**：基于 Go 编写，内存占用极低，即使在仅有 1GB RAM 的树莓派 4 上也能流畅运行，非常适合利用闲置硬件。
- **现代化的视觉设计**：UI 风格简约清新，遵循现代设计语言，操作逻辑直观，与大多数开源 NAS 系统的“工业风”形成鲜明对比。
- **社区驱动与开源精神**：项目完全开源（Apache-2.0 许可），社区活跃度高，GitHub Star 数已超过 35,000。用户可以方便地贡献代码、提交应用模板或反馈建议，形成了良好的生态循环。
