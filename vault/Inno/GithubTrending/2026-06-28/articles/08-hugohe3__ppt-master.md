## 项目概述

PPT Master 是一个基于人工智能的开源工具，能够从任何文档自动生成原生可编辑的 PowerPoint 演示文稿。传统上，AI 生成 PPT 往往只能输出图片形式的幻灯片，无法真正编辑其中的文字、图形或动画。PPT Master 彻底解决了这一问题——它生成的每一页 PPT 都是原生形状与矢量元素，完全保留动态效果与讲者备注，甚至能将备注内容转化为语音旁白。该项目由 Hugo He 开发并维护，目标用户包括需要快速制作演示文稿的知识工作者、教育工作者、商业分析师以及任何希望借助 AI 高效产出高质量 PPT 的人士。

## 核心功能

- **原生可编辑的 PPTX 输出**：生成的每一页幻灯片均采用原生形状、文本框、图表等矢量元素，而非图片快照。用户可以在 PowerPoint 或 Keynote 中自由编辑文字、调整版式、修改配色。
- **智能动画与过渡效果**：根据内容逻辑自动添加合适的动画效果（如淡入、擦除、缩放）以及幻灯片之间的切换动画，使演示更流畅、生动。
- **讲者备注自动生成**：为每张幻灯片撰写结构化的讲者备注，包括关键要点、引导问题和演讲提示，帮助用户从容讲解。
- **备注转语音旁白**：支持将讲者备注内容通过文本转语音 (TTS) 引擎转化为音频文件，并自动嵌入 PPTX，实现一键生成带旁白的演示文稿。
- **自定义模板支持**：用户可以指定自己的 .pptx 文件作为模板。AI 会严格遵循模板中的主题、配色方案、字体和占位符布局，保证输出与品牌或个人风格一致。
- **全文档解析与大纲生成**：支持从纯文本、Markdown、PDF、Word 等多种文档格式提取内容，自动提炼核心要点并组织成逻辑清晰的演示大纲。

## 技术架构

PPT Master 的核心采用 Python 语言开发，充分利用了 `python-pptx` 库在底层操控 PowerPoint 文件的原生能力。前端提供简洁的命令行界面，并未来计划提供图形化或 Web 接口。

- **文档解析层**：集成了多种文档解析器（如 Markdown 解析、PDF 文本提取、DOCX 读取），将输入内容转换为结构化的文本块。
- **AI 编排引擎**：调用大语言模型 API（如 OpenAI GPT 系列或兼容的第三方服务）进行内容理解、大纲生成与幻灯片内容填充。用户可选择不同的模型和 API 端点。
- **PPT 构建层**：基于 `python-pptx` 逐页创建幻灯片。每一页的标题、正文、图片（若有）、表格、形状均以原生对象的方式构建，而非截图另存。动画效果通过操作 `<p:anim>` 项实现自定义添加。
- **TTS 集成**：支持调用本地或云端文本转语音服务（如 edge-tts、Google Cloud TTS），将讲者备注转换为音频文件后，使用 `python-pptx` 的媒体嵌入功能添加到对应页面。
- **设计思路**：采用模块化插件式架构，文档解析、AI 调用、PPT 构建、TTS 四大模块可独立替换或扩展。配置通过 YAML 文件管理，支持自定义模型参数、模板路径、语言偏好等。

## 安装与使用

**安装步骤**：

1. 确保系统已安装 Python 3.9 或更高版本。
2. 通过 pip 安装项目及依赖：
   ```bash
   git clone https://github.com/hugohe3/ppt-master.git
   cd ppt-master
   pip install -r requirements.txt
   ```
3. 设置 AI 服务所需的 API Key（如 OpenAI 的 `OPENAI_API_KEY` 环境变量）。

**最小可用示例**：

```bash
# 从 Markdown 文件生成演示文稿
python ppt_master.py --input docs/input.md --output output.pptx

# 使用自定义模板并生成带语音旁白的版本
python ppt_master.py --input docs/input.md \
                     --template my_template.pptx \
                     --tts true \
                     --output output_with_voice.pptx
```

工具会自动解析输入文件，调用 AI 生成大纲与幻灯片内容，构建可编辑的 PPTX 文件，并在命令行反馈进度与结果。

## 适用场景

- **教育与培训**：教师或培训师可以从讲义或教材中快速生成课程演示幻灯片，附带讲解要点与语音旁白，提高备课效率。
- **商业汇报**：分析师与项目经理可将长篇报告或数据文档一键转化为结构清晰的汇报 PPT，保留自定义公司模板，统一品牌形象。
- **会议分享**：团队内部可将讨论纪要、技术文档直接转化为演示文稿，用于周会汇报或知识分享，节省手动制作时间。
- **内容创作者**：自媒体作者或品牌策划者可将长文内容（如博客、白皮书）转化为视觉化演示，用于视频播录或演讲。

## 项目亮点

- **真正的可编辑性**：多数同类工具仅输出幻灯片截图或 PDF，而 PPT Master 生成原生 PPTX，用户可自由编辑文字、形状、动画与备注，如同手工制作的演示文稿。
- **模板严格兼容**：现有模板中的主题字体、颜色、标题样式、正文占位符均被完美保留，避免风格错乱或元素丢失。这对于企业统一视觉规范至关重要。
- **语音旁白一体化**：从备注到语音的端到端支持，使得演示文稿可直接用于自动播放或在线分享，尤其适合课件与产品讲解视频。
- **完全开源免费**：基于 MIT 许可证，无需注册付费，可自由部署、修改、集成到自有工作流。社区驱动的发展确保功能持续更新。项目在 GitHub 上已获得超过 33,000 个 Star，社区活跃度极高。
