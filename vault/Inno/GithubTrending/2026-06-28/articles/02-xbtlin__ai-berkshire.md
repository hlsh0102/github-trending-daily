## 项目概述

AI Berkshire 是一套面向价值投资者的 AI 驱动研究框架，兼容 Claude Code 与 Codex 两大 AI 开发环境。它将巴菲特、芒格、段永平、李录四位投资大师的分析方法论系统化、结构化，通过多个 AI Agent 并行协作，实现从信息收集到决策建议的全流程自动化。项目解决的核心问题是：普通用户直接向 AI 提问得到的往往是“一方面...另一方面...”的平衡分析，缺乏可执行的决策依据；而 AI Berkshire 强制输出有明确结论、有价格区间、有风险分层的可操作建议。目标用户是具有一定投资基础的个人投资者、价值投资研究爱好者，以及希望借助 AI 提升研究效率与纪律性的投资从业者。

## 核心功能

- **四大师方法论并行分析**：同时调用巴菲特（护城河与安全边际）、芒格（逆向思维与心理偏误）、段永平（敢为天下后与差异化）、李录（文明视角与长期确定性）的框架，产生互为补充且可能存在张力的独立观点。
- **强制决策输出**：分析结果不是模棱两可的“建议”，而是明确的“通过/不通过/灰色地带”判断，附带具体价格区间和激进型/稳健型/保守型三层建议。
- **多 Agent 对抗式研究**：每个大师视角由一个独立 Agent 执行研究，Agent 之间可以互相质疑、交叉验证，模拟真实投研团队的讨论与对抗过程。
- **真实账户回测验证**：项目已公开 2024 年全年 +69.29% 和 2025 年至今 +66.38% 的实盘收益数据，连续两年大幅跑赢全球主要指数，提供可追溯的业绩记录。
- **结构化研究模板**：内置统一的研究模板，确保每次分析覆盖竞争壁垒、管理层、估值、风险等关键维度，避免遗漏重要信息。
- **镜像测试与纪律检查**：集成“镜子测试”功能，要求在 5 句话内讲清投资逻辑，否则自动标记为“不通过”，强制执行决策纪律。

## 技术架构

AI Berkshire 基于 Python 开发，核心架构围绕“Skill 合集”概念设计。每个大师方法论封装为一个独立的 prompt 模板与逻辑单元，可在 Claude Code 或 Codex 中直接加载运行。项目采用模块化设计，支持按需启用或组合大师视角。多 Agent 并行研究的核心机制是通过 AI 平台的上下文管理与结果合并能力，将四个独立分析结果汇集到一个最终报告中，并由一个裁决 Agent 进行综合判断。每个 Agent 在运行时会自动执行数据查询、财报提取、可比公司分析等子任务，最终生成结构化的 Markdown 报告。框架不依赖外部 API 或数据库，所有分析基于 AI 模型自身的知识库与联网检索能力，部署成本极低。设计上强调“可验证”——所有分析步骤和输出格式都是固定的，用户可以对同一标的反复运行并对比结果。

## 安装与使用

项目以 GitHub 仓库形式发布，安装异常简单：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/xbtlin/ai-berkshire.git
   cd ai-berkshire
   ```

2. 在 Claude Code 或 Codex 中直接使用：将对应 Skill 的 prompt 文件按平台说明加载即可。

最小可用示例：在 Claude Code 中输入 `/ai-berkshire 分析 腾讯控股`，系统会自动执行四大师分析框架，输出包括：
- 每个大师的独立打分
- 最终裁决结果（通过/不通过/灰色地带）
- 建议操作与价格区间
- 风险评估与纪律检查结果

更详细的使用说明可参考仓库内 `USAGE.md` 文件。

## 适用场景

- **个股深度研究**：当投资者需要系统性地分析一只股票是否具备长期持有的价值时，AI Berkshire 可以快速生成一份包含四个视角、有明确结论的研究报告，耗时仅需几分钟。
- **持仓组合审查**：用户可定期将持仓股票逐一输入框架，检查是否仍符合买入标准，辅助做出持有/减持/清仓的决策。
- **投资机会筛选**：面对数百个潜在标的时，先用 AI Berkshire 快速过滤，只对“通过”或“灰色地带”的标的进行下一步深度研究，大幅提升效率。
- **投资纪律训练**：新手投资者可通过反复运行框架，学习巴菲特、芒格等人的系统化决策逻辑，培养“先框架后决策”的纪律性。

## 项目亮点

与直接问 AI“这只股票值不值得买”相比，AI Berkshire 的差异化优势体现在三个层面：第一，决策颗粒度不同——普通 AI 回答是“建议”级别的定性判断，而 AI Berkshire 输出的是带价格区间、仓位比例、风险分层的定量操作建议；第二，视角复杂度不同——单一 AI 回答本质上是一维的，而四大师并行会产生真实的观点碰撞，例如巴菲特视角可能因为护城河明确而建议买入，芒格视角可能因为管理层激励不当而建议放弃，这种张力本身就是重要的研究成果；第三，纪律约束不同——普通 AI 不会拒绝回答，而 AI Berkshire 内置了“5 句话讲不清就不买”的硬规则，对不符合条件的标的会直接给出“不通过”，避免投资者在模糊信息下做出冒险决策。更重要的是，项目的业绩是有实盘账户截图为证的，2024 年和 2025 年连续两年大幅跑赢指数，提供了可信的实证支撑。
