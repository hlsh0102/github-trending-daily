## 项目概述

SimpleX 是首个不依赖任何用户标识符（如电话号码、用户名、邮箱等）的即时通讯网络平台。它从根本上解决了传统通讯软件中用户身份与隐私数据的绑定问题——你无需提供任何个人身份信息即可创建账号并与他人通信。该项目面向所有关注数字隐私、希望完全掌控自身通信安全的用户，包括普通消费者、安全从业者以及匿名通信需求者。

SimpleX 的设计理念是“100% 私有”，其去身份化（de-identified）架构在通讯领域独树一帜。项目已在 GitHub 获得超过 14000 颗星，并完成了由 Trail of Bits 执行的第三方安全审计，同时被 Privacy Guides、Whonix 等知名隐私项目推荐。

## 核心功能

- **无用户标识符**：系统不存储任何用户名、手机号或公钥标识。每个用户仅通过临时生成的地址（SimpleX address）或邀请链接进行连接，连接本身不暴露任何持久身份。
- **端到端加密**：所有消息均使用现代加密协议（包括双棘轮算法）进行端到端加密，服务器无法读取内容。
- **无中央用户数据库**：服务器侧不保存用户账户信息、联系人列表或元数据。路由信息以加密格式存储，仅通信双方可关联。
- **支持多种客户端**：提供 iOS、Android 原生应用以及桌面版应用（使用 Electron 包装），覆盖主要移动端和桌面平台。
- **去中心化与多服务器支持**：用户可自建服务器或使用社区提供的服务器节点，消息通过分布式中继传递，不依赖单一服务商。
- **丰富的通信功能**：支持一对一聊天、群组聊天、文件传输、语音消息、表情回复以及消息删除和编辑。

## 技术架构

SimpleX 采用 Haskell 语言开发核心协议和服务器组件，利用了 Haskell 的强类型系统和函数式编程特性来保证安全性与正确性。其架构设计具有以下特点：

1. **无身份层**：传统通讯系统通常需要一个“身份层”（如 Matrix 中的用户 ID、Signal 中的电话号码），SimpleX 完全去除了这一层。每个用户的端点（Endpoint）是由一个临时随机生成的地址标识，该地址在一次会话后可被废弃，用户可自主选择何时切换。
2. **增量式路由**：消息通过“混合网络”（mix network）中继，每一步路由使用临时加密密钥，使得服务器无法将不同消息关联到同一用户。这种设计类似于 Tor 或 I2P 的思想，但更轻量级，专注于即时通讯场景。
3. **双向认证**：即使没有用户标识，SimpleX 仍通过公钥密码学实现通信双方的认证。首次连接时双方交换一次性密钥，后续通信使用长期密钥进行加密和签名。
4. **服务器无状态**：服务器仅负责消息的中转和存储（如离线消息），不维护用户帐户状态。用户的消息存储在本地客户端，加密后上传到服务器作为待发送队列。
5. **协议简洁性**：协议设计尽量保持简洁，核心协议仅需少量消息类型，降低了攻击面，同时便于第三方实现兼容客户端或服务器。

## 安装与使用

### 安装步骤

**移动端（iOS / Android）**：
- 从 Apple App Store（iOS）或 Google Play Store（Android）搜索“SimpleX”下载官方应用。也可通过 GitHub Releases 直接下载 APK 或 IPA 文件。
- 安装后首次启动无需注册或登录，应用会立即生成一个本地密钥对和一个临时 SimpleX 地址。

**桌面端（Windows / macOS / Linux）**：
- 访问 GitHub Releases 页面下载对应操作系统的安装包（例如 `.dmg`、`.exe`、`.AppImage`）。也可通过 Homebrew（macOS）或 `apt`（Ubuntu/Debian）安装。
- 桌面端启动后同样无需注册，可直接使用。

### 最小可用示例

1. **创建你的第一个连接**：
   - 在应用中点击“添加联系人”（Add Contact）→ “接受或连接”。
   - 你会看到一个一次性链接地址（形如 `simplex:/contact#...`）。将此链接分享给朋友（例如通过其他安全渠道发送）。
   - 朋友点击链接后，即建立双向加密连接，无需任何用户名或手机号。

2. **发送第一条消息**：
   - 在联系人列表中点击新连接，输入消息，点击发送。消息会加密后经过中继服务器传递，对方收到后自动解密显示。

3. **加入群组**：
   - 通过群组邀请链接（由群管理员生成加入）。每个群组拥有一个独立的加密频道，成员身份仅通过临时密钥关联。

## 适用场景

- **高隐私要求的个人通信**：用于记者、维权人士、敏感行业从业者等与机密对象的通信，避免因通讯平台泄露身份元数据。
- **匿名社区与讨论**：在群组中匿名参与讨论，无需绑定真实身份或社交账号，适合技术极客、隐私爱好者社群。
- **企业内敏感沟通**：作为替代内部即时通讯工具的选项，用于处理高度机密信息，避免传统工具（如 Slack、Teams）的用户痕迹和集中审计风险。
- **自建服务器部署**：对去中心化有需求的用户或组织，可自建 SimpleX 服务器节点，实现完全自主可控的通信基础设施。

## 项目亮点

- **彻底的去身份化**：与 Signal（仍需手机号）或 Matrix（需用户 ID）不同，SimpleX 真正实现了“零标识符”通信。这是其在隐私领域最大的差异化优势。
- **安全审计背书**：由 Trail of Bits 完成的安全审计，结果已公开，增强了项目的信任度。这对于开源隐私项目尤为重要。
- **多平台一致性体验**：移动端和桌面端采用一致的设计语言和核心功能，且消息同步通过本地导入导出而非云端，进一步降低元数据暴露风险。
- **轻量级架构**：服务器端采用 Haskell 编写，资源占用低，可在低端 VPS 上运行，适合个人或小团队自建。
- **活跃的社区与透明度**：项目代码完全开源（AGPL-3.0 许可），开发团队定期发布更新日志，并在 GitHub 和 Reddit 社区保持互动。
