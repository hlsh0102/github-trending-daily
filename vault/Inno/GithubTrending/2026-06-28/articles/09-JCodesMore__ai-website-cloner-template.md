## 项目概述

AI Website Cloner Template 是一个开源的网站克隆模板，它允许你通过一条命令，利用 AI 编码代理（如 Claude Code）将任意现有网站逆向工程并重建为一个干净、现代化的 Next.js 代码库。该项目解决了开发者需要快速分析、提取并复现现有网站的设计、结构和功能时所面临的繁琐手动工作问题。目标用户包括前端开发者、全栈工程师、UI/UX 设计师以及任何希望快速获得网站高保真复制品以便学习、改造或二次开发的人。

## 核心功能

- **一键克隆**：只需提供目标 URL，然后运行 `/clone-website` 命令，AI 代理即可自动完成整个克隆流程。
- **智能分析与提取**：AI 代理会自动访问目标网站，检查其页面结构、提取设计令牌（颜色、字体、间距等）以及相关资源。
- **组件规格生成**：AI 会根据分析结果自动编写每个 UI 部分（如导航栏、页脚、卡片等）的组件规格说明。
- **并行构建**：克隆过程的最后阶段会调度多个并行构建器，同步重建网站的每个部分，从而大幅缩短生成时间。
- **生成整洁的 Next.js 代码库**：最终输出是一个结构清晰、易于理解和维护的 Next.js 项目，便于后续开发。
- **支持多种 AI 代理**：虽然推荐使用 Claude Code（搭配 Opus 4.7 模型效果最佳），但该模板与多种 AI 编码代理兼容。

## 技术架构

该项目基于 TypeScript 和 Next.js 构建，设计为一个高度可复用的模板。其核心理念是将整个克隆流程分解为多个由 AI 代理驱动的工作流。具体来说，当用户提供 URL 后，模板会触发一个主代理，该代理负责将任务拆解：首先进行网站审计（包括视觉分析、HTML DOM 树解析、CSS 样式提取），接着为每个提取出的 UI 组件生成详细的技术规格（包括需要的属性、状态、样式参考），然后自动创建对应的 Next.js 组件文件，最后通过并行化的构建任务来整合所有生成的文件。这种设计充分利用了 AI 代理的推理能力和 Next.js 的模块化特性，避免了传统手动克隆的重复劳动。模板本身并不存储任何网站数据，而是作为一个工作流引擎，协调 AI 代理的每一步操作。

## 安装与使用

**第一步：创建你自己的仓库**

在 AI Website Cloner Template 的 GitHub 页面上，点击 `Use this template` 按钮，然后选择 `Create a new repository`。**请勿**直接克隆此模板仓库用于你的网站项目，也不要针对生成的网站提交 Pull Request 到此模板仓库。

**第二步：下载并配置环境**

将你新创建的仓库克隆到本地：`git clone <你的新仓库地址>`。然后进入项目目录，运行 `npm install` 安装所有依赖。

**第三步：启动开发服务器**

运行 `npm run dev` 启动 Next.js 开发服务器。

**第四步：运行克隆命令**

使用你选择的 AI 编码代理（例如 Claude Code），在项目根目录下输入 `/clone-website` 命令。在交互过程中，提供你想要克隆的目标网站 URL。AI 代理将开始分析并生成网站代码。

**最小可用示例：**

1. 点击 `Use this template` 创建你的仓库。
2. 运行 `npm install` 和 `npm run dev`。
3. 启动 Claude Code 并运行 `/clone-website`。
4. 输入目标 URL（例如 `https://example.com`）。
5. 等待 AI 代理完成工作，在浏览器中访问 `localhost:3000` 查看结果。

## 适用场景

- **快速原型开发**：当你需要参考一个现有网站的设计和布局来进行自己的项目时，可以使用此模板快速获得一个可运行的 Next.js 代码库，作为开发起点。
- **网站学习和研究**：对于希望学习如何构建特定类型网站（如企业官网、SaaS 登录页面、电商首页等）的开发者，可以克隆网站并研究其生成的组件代码。
- **设计与开发协作**：设计师可以提供目标网站的 URL，开发人员使用此模板快速生成基础代码，然后在此基础上进行定制化开发，从而节省大量从零开始编写样式和结构的时间。
- **技术演示与概念验证**：在需要向客户或团队展示一个基于现有网站风格的概念验证时，此模板可以快速生成高保真的互动原型。

## 项目亮点

与手动复制网站或使用传统屏幕抓取工具相比，AI Website Cloner Template 的最大优势在于其 **AI 驱动的智能化提取与重构**能力。它不仅仅是复制 HTML 和 CSS，而是通过 AI 代理理解网站的结构意图，生成合乎逻辑的组件化代码（基于 Next.js）。这使得最终代码非常干净、可读性强，并且可以直接用于开发，而不是一堆需要手动清理的混乱标记。此外，其 **并行构建** 架构显著提升了生成速度，而支持多种 AI 代理的灵活性也让它能够适应不同的开发环境和偏好。作为一个模板而非一次性工具，它允许开发者轻松地复用和扩展整个工作流。
