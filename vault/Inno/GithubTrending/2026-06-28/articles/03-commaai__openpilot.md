## 项目概述

openpilot 是一款面向机器人领域的操作系统，由 comma.ai 公司开发并开源。其核心用途是升级现有车辆的驾驶辅助系统，让原本仅支持基础辅助功能的车辆获得更高级的自动驾驶能力。目前，openpilot 已适配超过 300 款车型，覆盖市面上主流的乘用车品牌。项目目标用户包括希望体验先进辅助驾驶技术的车主、从事自动驾驶研究的开发者，以及汽车电子爱好者。通过安装 openpilot，用户可以将普通家用车转变为具备车道保持、自适应巡航、自动变道等功能的智能座驾。

## 核心功能

- **自适应巡航控制**：自动调节车速以保持与前车的安全距离，支持从静止到高速的全速域跟车，并能应对走走停停的拥堵路况。
- **车道保持辅助**：利用摄像头和神经网络模型实时识别车道线，将车辆维持在车道中央行驶，即使弯道也能平稳通过。
- **自动变道**：驾驶员只需拨动转向灯拨杆，系统便会自动判断相邻车道是否有可用空间，并完成变道操作。
- **导航辅助驾驶**：在支持的道路上，openpilot 可结合导航地图信息自动驶入/驶出匝道、切换高速公路，并能识别交通信号灯和停车标志（部分车型）。
- **驾驶员监控**：通过车内摄像头监测驾驶员状态，若检测到注意力分散或疲劳驾驶，系统会发出报警并逐步降低辅助级别，确保安全。
- **开放性与可扩展性**：基于 Python 和 C++ 开发，提供完整的 API 和模型训练工具，开发者可自定义驾驶策略或训练自己的感知模型。

## 技术架构

openpilot 采用模块化微服务架构，各组件独立运行并通过消息队列（基于 ZMQ）进行通信。核心架构包括：

- **感知模块**：基于卷积神经网络的视觉模型，实时处理来自车载摄像头和雷达的传感器数据，输出车道线、车辆、行人、交通标志等目标信息。
- **定位模块**：融合 GPS、IMU 和视觉里程计，提供高精度定位，同时利用地图数据实现车道级导航。
- **规划与控制模块**：根据感知结果和驾驶策略生成轨迹规划，并通过 PID 控制器或模型预测控制（MPC）向车辆 CAN 总线发送油门、刹车、转向指令。
- **自监督学习框架**：项目内置了一套完整的训练管线，允许用户利用收集到的行车数据训练自定义模型，持续提升系统性能。
- **安全监督层**：在设计上采用了冗余安全机制，包括看门狗定时器、硬件故障检测和异常状态回退逻辑，确保系统在极端情况下能安全降级。

## 安装与使用

**硬件需求**：需要一台经过认证的设备（如 comma 官方硬件 comma three 或 comma four），或自行准备计算平台（如 PC + 兼容的摄像头和 OBD-II 接口）。

**快速开始**：
1. 下载官方镜像或使用一键安装脚本（支持 Linux 和 macOS）：
   ```bash
   bash <(curl -fsSL openpilot.comma.ai)
   ```
2. 将设备通过 OBD-II 线缆连接至车辆的 CAN 总线。
3. 将摄像头固定在前挡风玻璃中央，确保视野清晰。
4. 启动设备，系统会自动校准摄像头和 IMU，校准完成后即可上路使用。

**使用示例**：启动后，中控屏幕会显示车道线、前方车辆和道路边界。驾驶员只需握住方向盘并保持目视前方，openpilot 会接管纵向和横向控制。如需变道，拨动转向灯，系统会在安全时自动完成。

**开发者环境**：项目提供了 Docker 镜像和完整的源码编译指南，开发者可在本地运行单元测试或模拟器，无需车辆即可调试算法。

## 适用场景

- **日常通勤**：在高速公路或城市快速路上大幅减轻驾驶疲劳，系统能自动跟车、车道保持，驾驶员只需监督路况。
- **长途旅行**：结合导航辅助驾驶功能，openpilot 可自动处理进出匝道和高速公路切换，让长途驾驶更加轻松。
- **研究与教育**：作为开源参考实现，用于学习自动驾驶感知、规划与控制算法，或作为二次开发的基础平台。
- **车辆升级改造**：为旧款车辆注入新活力，使其具备接近现代高端车型的辅助驾驶能力，无需购买新车。

## 项目亮点

- **广泛的车载兼容性**：已适配 300+ 款车型，涵盖丰田、本田、现代、宝马、特斯拉等主流品牌，且支持列表持续更新。
- **端到端的深度学习方案**：不同于传统模块化系统，openpilot 大量使用端到端神经网络，直接从传感器数据映射到控制指令，减少了人工规则维护成本。
- **开源与社区驱动**：基于 MIT 协议完全开源，拥有活跃的社区和官方 Discord 支持，用户可贡献代码、报告问题或共享驾驶数据。
- **持续迭代**：项目保持高频更新，每两周发布新版本，不断改进模型精度、算法稳定性和安全特性。
- **可扩展性**：支持自定义硬件和软件栈，开发者可以替换感知、规划或控制模块中的任意组件，灵活适配不同车型和场景。
