## 项目概述

Superpowers 是一个专为编码代理设计的完整软件开发方法论，它构建在一组可组合的技能集之上，并辅以初始指令，确保代理能够正确使用这些技能。与传统的让 AI 直接写代码的方式不同，Superpowers 从根本上改变了编码代理的工作流程——它首先引导代理理解你的真实意图，而不是贸然动手编码。

该项目由 Obra 团队开发，旨在解决当前 AI 编码工具中普遍存在的“跳跃式工作”问题。许多 AI 编码代理在接到指令后会直接生成大量代码，但缺乏对需求的理解、缺乏测试、缺乏结构化的开发流程。Superpowers 将这些缺失的部分重新引入，为用户提供了一个经过验证的、可复用的软件工程框架。它的目标用户是使用 AI 编码工具（如 Claude Code、Cursor、Github Copilot CLI 等）的开发者、团队以及希望将 AI 集成到标准软件开发流程中的组织。

## 核心功能

- **需求澄清机制**：代理启动后不会直接写代码，而是主动引导你明确真正想要解决的问题，通过对话逐步提炼出结构化的需求规格说明。
- **分块展示设计**：在需求澄清后，代理会将完整规格说明拆分成易于阅读的小块展示给你，确保你能够理解并确认每一个设计决策。
- **自动化实施计划**：获得你的设计批准后，代理会自动生成一个明确的实现计划。该计划假设执行者是一位热情但缺乏经验、没有项目上下文、且不习惯测试的初级工程师，从而迫使计划必须清晰、具体。
- **强制 TDD 与 YAGNI**：计划强调真正的红绿测试驱动开发（TDD）、避免过度设计（YAGNI）以及保持代码简洁（DRY），从根本上保证生成代码的质量和可维护性。
- **多平台兼容**：原生支持 Claude Code、Cursor、Github Copilot CLI、Codex CLI、Kimi Code、OpenCode 等主流 AI 编码代理工具。
- **可组合技能集**：核心能力由一组独立的、可自由组合的“技能”组成，你可以根据项目需求选择性地启用或扩展。

## 技术架构

Superpowers 的架构设计围绕“方法论 + 技能集”的双层结构展开。底层是一组用 Shell 脚本或配置定义的、可执行的“技能”文件，这些技能封装了诸如需求分析、计划生成、代码审查、TDD 循环等标准软件开发环节的具体实现。上层是初始指令（init instructions），这些指令定义了代理的行为范式——告诉代理在收到项目请求时，首先应加载并使用这些技能，而不是直接调用其通用代码生成能力。

项目使用 Shell 作为主要语言，这意味着它不需要复杂的运行时环境，只需一个支持 Shell 的执行环境（Linux、macOS 或 Windows 下的 WSL/类似环境）即可运行。这种设计使得 Superpowers 能够轻松嵌入到各种 AI 代理工具中，因为大多数代理工具都原生支持 Shell 命令的执行。

架构的关键特点在于“干预式工作流”：通过在代理的启动指令中嵌入特定的 Prompt Engineering，迫使代理在生成代码前必须先完成需求分析和设计确认，从而将人类反馈自然地嵌入到 AI 编码流程的每个关键节点。这种设计解决了当前 AI 编码最大的痛点——缺乏人类监督与设计迭代。

## 安装与使用

### 快速开始

以下以 Claude Code 为例，展示如何为你的编码代理赋予 Superpowers：

1. **安装 Claude Code**（如果你尚未安装）：
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

2. **为 Claude Code 配置 Superpowers**：
   - 在项目根目录创建或编辑 `.claude/instructions` 文件。
   - 将 Superpowers 仓库中的初始指令内容写入该文件。
   - 确保项目目录中包含 `skills/` 文件夹，它将 Superpowers 提供的技能文件自动集成。

3. **启动代理**：
   ```bash
   claude
   ```
   现在，当你向 Claude 提出需求时，它将先要求你明确目标，而不是直接生成代码。

### 最小可用示例

假设你想开发一个简单的 Todo 应用。当你向已配置 Superpowers 的代理提出请求时，预期流程如下：

- 代理会先提问：“请描述你真正想构建的功能是什么？它解决什么问题？”
- 你回答后，代理生成一份设计规格说明（以可读的小块展示）。
- 你确认设计后，代理生成实现计划（包含 TDD 步骤）。
- 你批准后，代理开始按计划逐步实现代码。

无需额外配置，Superpowers 会引导你完成整个流程。

## 适用场景

- **个人开发者使用 AI 编码助手**：当你使用 Cursor、Claude Code 等工具时，Superpowers 能帮助你避免生成低质量的、未经测试的代码，使 AI 的输出更符合工程规范。
- **团队协作开发**：团队成员共享同一套开发方法论，确保 AI 生成代码的风格一致性、测试覆盖率和设计质量，减少人工审查负担。
- **从零开始的绿色项目**：在启动新项目时，Superpowers 强制需求分析和设计确认流程，帮助团队从一开始就建立良好的开发习惯，避免后期重构的代价。
- **教育培训**：适合用于教学场景，帮助新入门的开发者理解标准软件工程流程（需求分析→设计→计划→TDD 实现），AI 代理在这一过程中充当了指导和监督角色。

## 项目亮点

- **方法论导向而非工具驱动**：大多数同类项目只提供工具或 Prompt 模板，而 Superpowers 提供的是完整的软件开发方法论，将人类工程实践（TDD、YAGNI、DRY）系统化地融入 AI 工作流。
- **主动干预式设计**：与其他让 AI 自由发挥的方案不同，Superpowers 通过强制流程确保每次代码生成前都经过了人类的需求确认和设计批准，大幅降低返工风险。
- **即插即用的跨平台兼容性**：不需要复杂的集成，只需简单的指令配置就能使 Claude Code、Cursor、Github Copilot CLI 等多个主流代理工具获得 Superpowers 能力，降低使用门槛。
- **可组合的模块化技能集**：每个技能独立且可替换，用户可以根据项目需求选择启用或定制特定技能，而不是被迫接受一个固定的整体框架。
- **活跃的社区驱动**：项目拥有超过 25 万 Star 数，且有专门的团队负责社区支持和代码工作，反映出项目的活跃度与影响力。
