## 项目概述

Last30Days 是一款面向 AI 代理（agent）的技能插件，旨在对任意话题进行跨平台研究，并在 Reddit、X（Twitter）、YouTube、Hacker News、Polymarket 及整个互联网上搜索过去 30 天内的高质量内容，最终合成一份有据可依的总结摘要。

该项目由 mvanhorn 开发并开源，作为一个 Agent Skills 生态中的技能包（skill），它并非传统搜索引擎，而是让 AI 代理以“人”而非“编辑”的视角来筛选信息——基于点赞、投票和真实市场的押注来评估内容质量。目标用户包括需要快速获取热点话题深入分析的研究者、内容创作者、投资者，以及希望提升 AI 代理信息采集能力的开发者。

## 核心功能

- **跨平台聚合搜索**：同时检索 Reddit、X、YouTube、Hacker News、Polymarket 以及通用网络，无需在多个平台间手动切换。
- **30 天时间窗口**：专注于近期内容（过去 30 天），确保信息时效性，适合快速变化的领域如科技、金融、政策讨论。
- **质量评分机制**：利用平台原生信号（Reddit 的 upvotes、X 的 likes、Polymarket 的真实资金押注）作为内容重要性的参考，而非依赖编辑推荐或算法排序。
- **AI 合成摘要**：自动将检索结果整理为一篇逻辑通顺的摘要，包含关键观点、数据来源和不同立场，减少人工阅读多条信息的时间成本。
- **多环境兼容**：支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等 50 多种 AI 代理工具，通过统一接口安装使用。
- **全局或项目级安装**：用户可选择将技能安装至全局环境（跨项目可用），或限定于特定项目目录。

## 技术架构

项目基于 Python 实现，核心设计分为三个层次：

1. **技能定义层**：通过 `skills/last30days/SKILL.md` 文件定义技能的命令、参数、行为逻辑和输出格式，这是运行时 AI 代理读取的源描述。该项目使用统一的 Agent Skills 规范，使得同一个技能包可以在多个不同的 AI 代理宿主中表现一致。

2. **搜索与获取层**：对每个目标平台实现专门的抓取或 API 调用模块，处理身份验证、速率限制、数据提取。对于 Reddit 和 Hacker News，利用其公开 API 获取 upvote 数据；X 平台依赖搜索 API；Polymarket 则通过链上数据或第三方接口获取投注金额作为置信度指标。通用网络搜索使用可配置的搜索引擎 API。

3. **合成与输出层**：收集到原始数据后，经过去重、排序、分类，由 AI 代理进行总结。合成过程遵循预定义的提示模板，确保输出包含：话题概述、各平台关键观点、分歧点、置信度评估（基于 upvotes/likes/money 的量化指标）以及原始链接引用。

架构上采用无状态设计，每个请求独立运行，便于在不同的 AI 环境中部署。通过 `npx skills` 命令加载后，运行时仅需一个 API 密钥配置即可开始使用。

## 安装与使用

**推荐方式（Claude Code 用户）：**
```bash
# 通过市场直接添加并安装
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

**通用方式（Codex, Cursor, Copilot, Gemini CLI 等）：**
```bash
npx skills add mvanhorn/last30days-skill -g
```
`-g` 表示全局安装，对所有项目生效；去掉 `-g` 则仅在当前项目目录可用。

**最小可用示例：**
在支持该技能的 AI 代理中，输入类似如下指令：
```
/last30days "AI regulation 2025"
```
代理将自动搜索上述多个平台，返回一份包含 Reddit 高赞讨论、X 热门推文、YouTube 高播放量视频、HN 评论、Polymarket 预测市场押注以及网络新闻的整合摘要。

更详细的命令和配置可参考项目 `SKILL.md` 文件中的说明。

## 适用场景

- **市场与投资研究**：快速了解某只股票、加密货币或新兴行业在过去 30 天的公众情绪、热门讨论和预测市场赔率变化，辅助短期判断。
- **新闻与事件追踪**：对突发新闻或争议话题（如新政策、科技事故、名人言论），聚合多平台观点，快速形成全局认知。
- **内容创作选题**：为博客、视频或社交媒体运营提供“近期最高讨论度”的话题素材，基于真实互动数据而非个人直觉。
- **技术趋势监控**：开发者可定期对某项新技术或框架执行 /last30days，获取社区最新反馈、使用案例和 bug 报告，替代手动翻阅多个论坛。

## 项目亮点

与传统搜索引擎或单纯的热点聚合工具相比，Last30Days 的核心差异化在于：

1. **以“人”为评分标准**：不是靠算法或编辑排名决定内容重要性，而是直接采用平台上真实用户的投票和金钱投注作为信号。Polymarket 的押注尤其独特——它代表用户用真金白银表达的对某个事件结果的确信度，这种信号比评论点赞更具判断价值。

2. **跨平台一站式合成**：大多数信息聚合工具要么专注单一平台，要么只是简单列出链接。该项目由 AI 代理进行深度合成，将不同平台的观点交叉比对并输出结构化摘要，节省用户自行拼图的精力。

3. **Agent Skills 生态兼容**：采用统一的技能规范，一次编写即可在 50 多种 AI 代理和 IDE 中运行，极大降低了开发者的适配成本。项目作为 GitHub 当日 #1 趋势仓库，社区反响热烈，目前已获得超过 5 万星标。

4. **时间窗口精准**：限制为过去 30 天，避免信息过载，同时确保结果的“当前”属性——这对时效性敏感的决策场景尤为重要。
