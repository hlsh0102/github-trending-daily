## 项目概述

π RuView 是一款利用普通 WiFi 信号实现实时空间感知、生命体征监测和人员存在检测的开源系统。它无需任何摄像头或可穿戴设备，仅通过分析环境中现有的 WiFi 信号波动，就能穿透墙壁、在完全黑暗的环境中完成对人体位置、呼吸频率和心率的感知。该项目旨在为智能家居、老人监护、安防监控等领域提供一种无侵入、保护隐私的感知解决方案，目标用户包括智能家居爱好者、养老护理机构、安防系统开发者和物联网研究人员。

## 核心功能

- **穿墙人体检测与定位**：利用 Commodity WiFi 信号的 CSI（信道状态信息）变化，实现隔墙检测人体位置和移动轨迹，无需部署额外传感器
- **呼吸与心率监测**：通过分析 WiFi 信号因人体胸腔起伏引起的微小波动，实时提取呼吸频率和心率数据，精度接近医疗级监测设备
- **存在检测**：区分房间内的人员静止存在与空房间状态，避免传统红外传感器因人体静止而误判为无人
- **多房间空间智能**：支持同时监测多个房间的人员分布、活动状态和人数统计
- **智能家居生态集成**：原生支持 Home Assistant、Apple Home、Google Home、Amazon Alexa 和 SmartThings，作为 MQTT 发布器或 Matter 桥接设备运行
- **隐私保护**：所有感知基于 WiFi 射频信号，不采集任何图像或声音数据，从根本上消除隐私泄露风险

## 技术架构

RuView 采用 Rust 语言编写，利用其高性能和内存安全特性处理实时信号分析。其核心原理基于 WiFi CSI 的变化规律——人体移动和生理活动会引起无线信号在传播路径上的相位和振幅变化，RuView 通过机器学习算法从这些信号噪声中提取出位置、心率、呼吸模式等特征信息。

系统设计采用模块化架构，信号处理层负责原始 CSI 数据的采集和预处理，特征提取层运行经过训练的深度学习模型，推理引擎负责实时生成空间热图和生理参数。应用层通过 RESTful API 或 WebSocket 输出结果，同时内置 MQTT 发布器和 HAP（HomeKit 协议）桥接器，方便接入智能家居平台。系统支持边缘运行在树莓派、NAS 或低功耗服务器上，无需云端处理。

## 安装与使用

**基本安装步骤：**

1. 确保环境中有兼容的 WiFi 网卡（支持 CSI 捕获的 Intel 或 Atheros 芯片组）
2. 从 GitHub 仓库克隆或下载预编译二进制文件
3. 根据文档配置 WiFi 接口和监测区域参数
4. 启动 RuView 守护进程

**最小可用示例（命令行启动）：**

```bash
# 下载 RuView 二进制文件
wget https://github.com/ruvnet/RuView/releases/latest/download/ruview-x86_64-linux

# 赋予执行权限
chmod +x ruview-x86_64-linux

# 启动 RuView，默认监听所有 WiFi 接口，输出到标准输出
./ruview-x86_64-linux

# 集成 Home Assistant 输出为 MQTT
./ruview-x86_64-linux --mqtt --mqtt-broker 192.168.1.100
```

启动后，系统会自动开始分析 WiFi 信号，并在终端输出检测到的人员位置、呼吸频率等信息。若配置了 MQTT 输出，Home Assistant 将自动发现并创建传感器实体。

## 适用场景

- **老年人居家监护**：在养老院或独居老人家中部署，无需佩戴任何设备即可实时监测老人的存在、活动状态和生命体征，为跌倒检测和健康预警提供基础数据
- **智能家居自动化**：根据房间内是否存在人员及人员活动强度，自动调节灯光、空调和安防系统，实现真正的“人在灯亮、人走灯灭”
- **商业空间人流分析**：在零售店、展厅或办公空间中分析人员分布和移动轨迹，无需摄像头即可获取客流数据，避免客户隐私顾虑
- **安防监控补充**：作为传统摄像头的补充方案，在走廊、仓库等不便于安装摄像头或需要隐蔽监测的区域实现入侵检测

## 项目亮点

RuView 与同类项目相比的差异化优势在于：

- **完全无摄像头**：与传统视觉方案相比，从根本上解决了隐私泄露问题，用户无需顾虑摄像头数据被滥用
- **穿墙感知能力**：WiFi 信号可以穿透非金属墙体，实现隔墙监测，这是红外、超声波等传感器无法做到的
- **生命体征监测**：不仅检测存在和运动，还能提取呼吸和心率数据，覆盖了健康监测需求
- **智能家居深度集成**：原生支持 Matter 和 HomeKit 协议，开箱即用对接主流智能家居平台，无需编写自定义代码
- **Rust 语言实现**：高性能、低资源占用，可以在老旧硬件上稳定运行，同时内存安全性保障了长时间运行的可靠性
