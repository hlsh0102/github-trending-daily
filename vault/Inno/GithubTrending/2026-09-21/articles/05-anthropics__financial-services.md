## 项目概述

Claude for Financial Services 是 Anthropic 官方维护的金融行业智能体参考实现仓库。它针对投资银行、股票研究、私募股权和财富管理等场景中反复出现的工作流，提供可复用的 agent 定义、技能（skills）与数据连接器，帮助金融机构在自有环境中快速搭建符合行业习惯的自动化工作流。

该项目解决的核心问题是：金融业务的智能化落地通常需要从零搭建 prompt、工具调用和数据管道，重复成本高且容易偏离合规要求。此仓库将这些资产标准化并开源，使团队可以直接引用经过设计的行业模板，而非从通用大模型能力起步。

目标用户包括金融机构内部的技术团队、量化与研究平台开发者，以及为金融客户构建解决方案的工程人员。仓库同时提供 Claude Cowork 插件与 Claude Managed Agents API 两种交付形式，同一份系统提示与技能可在两种运行环境下复用。需要特别注意的是，所有输出均为供专业人员复核的草稿类工作产物，不构成投资、法律、税务或会计建议，也不执行交易、记账或审批等具有约束力的操作。

## 核心功能

- **端到端命名 Agent**：提供 Pitch Agent、Market Researcher、GL Reconciler 等有明确职责边界的工作流 agent，每个都同时以 Cowork 插件和 Managed Agent 模板两种形式发布，可通过 `/v1/agents` 接口部署。
- **按垂直行业打包的插件**：将底层技能、斜杠命令与数据连接器按金融子行业组织，支持单独安装使用，例如直接调用 `/comps`、`/dcf` 等命令。
- **可复用技能库**：将建模、备忘录撰写、研究笔记整理、对账等常见任务封装为技能单元，便于跨 agent 组合与复用。
- **数据连接器**：为金融数据源提供标准化接入方式，降低 agent 获取行情、财报等外部数据时的集成成本。
- **双运行模式**：同源资产既可运行在 Claude Cowork 中，也可通过 Managed Agents API 挂载到用户自有的工作流引擎之后，便于控制部署位置与数据边界。
- **人工复核前置**：所有输出均以阶段性成果形式产出，等待具备资质的专业人员签署确认，符合金融机构的内控习惯。

## 技术架构

项目以 Python 为主要语言，整体结构围绕"同一份定义、多种交付形态"的思路设计。核心资产（系统提示、技能描述、连接器配置）与运行载体解耦，Cowork 插件与 Managed Agent 模板只是对同一份内容的不同打包方式，从而避免维护两套逻辑。

在能力层面，仓库区分了 agent、skill 与 connector 三个层次：agent 负责编排端到端流程与决策顺序，skill 封装单个可复用的专业能力，connector 负责外部数据与系统的对接。斜杠命令作为面向用户的入口，调用具体的 skill 或 agent。这种分层使团队既能整体启用某个垂直方案，也能只取其中一小块能力嵌入已有系统。

部署方面，Managed Agents API 路径允许将 agent 注册为模板并通过 API 调用，适合需要与内部权限系统、审计日志和审批流集成的机构。仓库遵循 Apache-2.0 许可，便于在企业内部做二次开发。

## 安装与使用

具体安装方式请以仓库 README 与 `managed-agent-cookbooks` 目录中的说明为准。常见做法包括：

1. 克隆仓库并进入目标插件或 agent 目录。
2. 按文档要求配置运行环境（Python 版本、依赖项及必要的凭证）。
3. 若使用 Cowork 路径，将对应插件安装到 Claude Cowork 中启用。
4. 若使用 Managed Agents API，通过 `/v1/agents` 接口注册仓库提供的模板，并接入自有的工作流引擎。

最小可用示例通常是从单个垂直插件入手，例如安装后直接调用 `/comps` 或 `/dcf` 命令，观察输出结构与数据来源，确认符合团队工作习惯后再扩展到完整 agent 流程。

## 适用场景

- **投资银行**：用于搭建 pitch 材料准备、可比公司分析等工作流的草稿生成环节。
- **股票研究**：辅助生成研究笔记、财务模型初稿，供分析师在此基础上修订。
- **私募股权**：支持标的筛选与初步尽调文档的整理。
- **财富管理**：用于对账、报表归集等重复性任务的自动化处理。

## 项目亮点

与通用 agent 框架相比，该项目的差异化在于行业针对性：agent 与技能围绕金融工作流的真实步骤设计，而非泛化的任务模板。双运行模式使同一套资产既可用于快速试用，也能进入受控的生产环境，减少从原型到部署的重复工作。作为 Anthropic 官方仓库，它与 Claude 系列模型及 Managed Agents API 的适配度较高，且以 Apache-2.0 许可开源，便于机构内审与二次开发。明确的"草稿产出、人工签署"定位也使其在合规讨论中更容易向风控与法务团队说明边界。
