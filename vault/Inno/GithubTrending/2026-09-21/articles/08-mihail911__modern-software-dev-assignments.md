## 项目概述

`mihail911/modern-software-dev-assignments` 是斯坦福大学 2025 年秋季课程 **CS146S: The Modern Software Developer** 的官方作业仓库。该课程面向希望系统掌握现代软件开发实践的学生与开发者，内容覆盖从本地开发环境搭建、依赖管理与测试，到持续集成、容器化部署以及 AI 辅助开发等当代工程流程。

仓库本身并不提供单一可运行的应用，而是一组按周组织的编程作业集合。每个作业都附带说明文档与初始代码骨架，要求学习者在已有结构上完成具体任务。它解决的问题是：市面上的软件开发教程往往只讲解孤立的知识点，缺少将版本控制、环境隔离、自动化测试、打包发布等环节串联起来的完整练习。此仓库通过可动手的作业将这些环节连接成一条真实的工程链路。

目标用户主要包括三类：选修 CS146S 课程的在校学生；希望对照斯坦福课程大纲自学的开发者；以及需要现成教学素材的讲师或训练营组织者。由于作业以 Python 为主要语言，具备基础 Python 语法知识即可上手，但部分任务会涉及命令行、Git 与容器等工具的使用。

## 核心功能

- **课程作业集合**：仓库按作业编号组织源码目录，每份作业包含任务说明与起始代码，覆盖课程不同阶段的教学主题。
- **可复现的开发环境**：通过 Conda 与 Poetry 组合锁定 Python 3.12 运行时和项目依赖，降低“在我机器上能跑”的环境差异问题。
- **依赖与项目管理实践**：使用 Poetry 管理第三方库和虚拟环境，作业流程本身即是对现代 Python 打包工具的演练。
- **测试与自动化流程**：作业中引入自动化测试与检查步骤，帮助学习者在提交前验证实现是否符合规格。
- **与课程站点联动**：仓库与 `themodernsoftware.dev` 课程页面互为补充，讲义、视频与作业源码可交叉参照。

## 技术架构

项目以 Python 3.12 为运行时基础，环境管理采用 **Conda**，依赖与打包采用 **Poetry**。这一组合的用意是把“解释器版本控制”和“项目依赖控制”分开：Conda 负责提供隔离的 Python 解释器环境，Poetry 在该环境内解析 `pyproject.toml` 并安装锁定的依赖集合，从而让作业环境在不同操作系统上保持一致。

仓库结构按作业拆分，各作业目录相对独立，包含自己的源码与配置。这种设计的思路是让每份作业可以单独运行和验证，避免跨作业依赖带来的耦合。代码以模块化方式组织，便于按功能定位、按测试反馈迭代。整体不依赖特定 IDE，纯命令行即可完成环境搭建、依赖安装、运行与测试，这也与课程强调的通用工程技能一致。

## 安装与使用

以下步骤以官方 README 为准，适用于 Python 3.12：

1. 安装 Anaconda（Individual Edition），安装后打开新的终端，确保 `conda` 已加入 `PATH`。
2. 创建并激活 Conda 环境：

   ```bash
   conda create -n cs146s python=3.12 -y
   conda activate cs146s
   ```

3. 安装 Poetry：

   ```bash
   curl -sSL https://install.python-poetry.org | python -
   ```

4. 在已激活的 Conda 环境中，从仓库根目录安装依赖：

   ```bash
   poetry install --no-interaction
   ```

完成上述步骤后，即可进入对应的作业目录查看说明文档并运行代码。最小可用流程是：克隆仓库、按上述方式准备环境、进入目标作业目录、依据该作业的 README 或讲义执行运行与测试命令。若 Poetry 未自动进入虚拟环境，可先执行 `poetry shell` 或使用 `poetry run <command>` 前缀调用脚本。

## 适用场景

- **课程学习**：选修 CS146S 的学生按周完成作业，作为课程评分的组成部分。
- **自学现代工程实践**：开发者按仓库结构逐份完成作业，补齐环境管理、打包与测试等环节的实操经验。
- **教学与培训**：讲师可将作业作为模板，改造为内部培训或大学课程的练习素材。
- **面试与技能评估**：团队可参考其任务设计，构建衡量候选人工程流程能力的评估题。

## 项目亮点

与常见的“单文件示例”型教学仓库相比，本项目的差异点在于**工程流程的完整性**：它不只教语法，而是把 Conda 环境隔离、Poetry 依赖锁定、自动化测试等真实项目中的必要环节纳入作业要求。其次，它来自**斯坦福正式课程**，内容经过课堂验证，并与公开讲义和视频配套，学习路径清晰。此外，仓库保持较高的社区关注度（Star 数超过 4600），意味着问题反馈与讨论相对活跃，学习者在遇到环境或工具问题时更可能找到已有解答。最后，作业目录彼此独立，便于按需选取其中一份练习，而不必一次性完成全部内容。
