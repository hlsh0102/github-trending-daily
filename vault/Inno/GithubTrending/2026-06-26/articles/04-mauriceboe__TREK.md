## 项目概述

TREK 是一款自托管的旅行/行程规划器，旨在帮助用户以实时协作的方式规划完整的旅行方案。无论是与家人、朋友还是团队成员共同策划一次旅行，TREK 都提供了从路线设计、预算管理到打包清单、旅行日志的一站式解决方案。目标用户包括个人旅行者、家庭出游组织者、小型旅行团以及希望自行掌控数据的隐私爱好者。通过自托管部署，用户可以将所有旅行数据存储在自己的服务器上，确保隐私安全的同时享受丰富的功能。

## 核心功能

- **实时协作**：支持多人同时编辑旅行计划，所有更改实时同步，方便团队成员共同决策。
- **交互式地图**：内置地图组件，可在地图上标记景点、餐厅、住宿等地点，并规划行程路线。
- **预算管理**：提供总预算、分类预算和支出追踪功能，帮助用户控制旅行开支。
- **打包清单**：自定义打包物品清单，支持分类和勾选，确保出发前不遗漏任何物品。
- **旅行日志**：记录每日行程、照片和笔记，形成完整的旅行回忆档案。
- **集成 AI**：借助人工智能辅助生成行程建议、优化路线或翻译信息，提升规划效率。
- **单点登录（SSO）**：支持 OAuth 等标准 SSO 协议，方便与企业或家庭现有的身份认证系统集成。
- **PWA 支持**：作为渐进式 Web 应用，可在移动设备上离线使用，获得类似原生应用的体验。

## 技术架构

TREK 主要使用 TypeScript 开发，前后端分离的架构设计。前端采用现代 JavaScript 框架（如 React 或 Next.js），后端基于 Node.js 构建。WebSocket 或类似技术用于实现实时协作功能，确保多用户编辑时的数据一致性。地图功能依赖 Leaflet 或 Mapbox 等开源地图库，预算和清单数据通过 REST API 或 GraphQL 进行交互。数据存储方面，TREK 使用 PostgreSQL 等关系型数据库，并支持通过 Docker 容器化部署。整体架构强调模块化和可扩展性，新功能（如 AI 模块）可通过插件或微服务方式集成。

## 安装与使用

TREK 提供 Docker 镜像，推荐使用 Docker Compose 进行快速部署。以下是最基本的安装步骤：

1. **环境准备**：确保服务器安装了 Docker 和 Docker Compose。
2. **获取配置**：从 GitHub 仓库下载 `docker-compose.yml` 文件。
3. **启动服务**：在终端中运行 `docker-compose up -d`，等待镜像拉取并启动容器。
4. **访问应用**：打开浏览器，访问 `http://localhost:3000`（或配置的端口），进入登录页面。
5. **创建旅行**：登录后，点击“新建旅行”，输入名称、日期和目的地，即可开始规划。

最小可用示例：直接使用官方提供的在线演示（`demo.liketrek.com`）体验所有功能，无需本地部署。

## 适用场景

- **家庭旅行策划**：多人共同决定目的地、住宿和活动，实时查看进度，避免反复沟通协调的麻烦。
- **小型旅行团管理**：领队规划整体路线，团员可查看并反馈，预算功能确保每个人了解费用分摊。
- **数字游民/自由职业者**：自托管保障数据隐私，PWA 支持离线使用，适合经常奔波、网络不稳定的场景。
- **企业团队建设活动**：HR 或组织者利用 TREK 规划集体出游，集成 SSO 实现统一身份认证。

## 项目亮点

- **完全自托管**：与绝大多数旅行规划工具不同，TREK 允许用户将数据保存在自己的服务器上，避免将行程信息交给第三方云服务。
- **实时协作深度集成**：不仅仅是同步编辑，从地图标记到预算调整，所有功能均支持多人实时协作，适合团队使用。
- **全面的功能矩阵**：一个应用同时覆盖地图、预算、清单、日志、AI 等常见需求，无需在多个工具间切换。
- **活跃的开源社区**：采用 AGPL-3.0 许可，鼓励社区贡献。提供 Discord 社区、公开路线图和捐赠通道，用户可直接参与功能建议和问题反馈。
- **现代技术栈**：TypeScript 全栈、PWA、SSO 支持，符合当下 Web 应用的最佳实践，便于二次开发和集成。
