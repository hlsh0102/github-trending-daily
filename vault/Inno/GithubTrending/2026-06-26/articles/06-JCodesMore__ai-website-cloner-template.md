## 项目概述

AI Website Cloner Template 是一个开源的模板项目，旨在通过一条命令和 AI 编码代理，将任意网站逆向工程为整洁、现代的 Next.js 代码库。用户只需提供一个目标 URL，AI 代理便会自动完成网站结构分析、设计令牌提取、组件规范编写，并并行构建每个区块，最终生成一个功能完整、可独立部署的克隆站点。该项目主要面向前端开发者、AI 工具使用者、以及需要快速复刻或学习现有网站设计方案的技术团队。

## 核心功能

- **一键克隆**: 通过 `/clone-website` 单条命令即可触发全流程克隆，无需手动配置或繁琐的步骤。
- **自动逆向工程**: AI 代理自动检查目标网站结构，提取设计令牌（如颜色、字体、间距）和资产（如图片、图标）。
- **并行构建**: 在分析完成后，代理会编写组件规范，并调用多个并行构建器同时生成不同的页面区块，大幅提升效率。
- **多代理兼容**: 虽然推荐使用 Claude Code 配合 Opus 4.7 获得最佳效果，但项目设计为可与多种 AI 编码代理协作工作。
- **Next.js 输出**: 生成结果是一个基于 Next.js 的现代化代码库，具备良好的可维护性和扩展性。

## 技术架构

项目以 TypeScript 为核心语言，基于 Next.js 框架构建。其架构围绕“分析-规范-并行构建”的非线性流程设计：首先，AI 代理通过浏览器或网络请求获取目标网站的 DOM 结构和样式信息；然后，代理解析并生成结构化的组件规范和设计令牌文件；最后，多个构建器同时根据规范生成独立的 React 组件，并自动组合成一个完整项目。这种设计充分利用了 AI 编码代理的并行处理能力，避免了传统手动逆向工程的线性瓶颈。项目本身作为模板存在，用户通过 GitHub 的 “Use this template” 功能创建自己的副本，从而避免污染原始仓库。

## 安装与使用

1. **创建你的项目副本**: 在 GitHub 上点击 `Use this template` 按钮，基于本模板创建一个新仓库（不要直接克隆此模板仓库）。
2. **克隆你的仓库**: 将刚创建的仓库克隆到本地。
3. **安装依赖**: 确保你的环境已安装 Node.js，然后在项目根目录运行 `npm install` 或 `yarn install`。
4. **启动开发服务器**: 运行 `npm run dev` 启动本地开发环境。
5. **运行克隆命令**: 在开发终端中输入 `/clone-website` 并回车，按照提示输入目标网站的完整 URL，AI 代理将开始执行克隆流程。等待构建完成后，即可在项目目录中查看生成的代码。

最小可用示例要求用户已配置好 AI 编码代理（如 Claude Code），并确保网络环境可以访问目标网站。项目本身无额外的复杂依赖。

## 适用场景

- **设计学习与复刻**: 前端开发者希望参考或复用某个优秀网站的设计方案和布局，快速获得可修改的 Next.js 代码。
- **快速原型开发**: 需要基于现有网站风格快速搭建新项目雏形，节省手动编写 CSS 和组件的时间。
- **迁移或改造**: 将旧版或第三方网站的功能和设计迁移到现代 Next.js 技术栈中，作为独立项目继续开发。
- **AI 代理能力测试**: 对于对 AI 编码代理工作流程感兴趣的用户，该项目提供了一个完整的实战模板，用于评估不同代理工具的效果。

## 项目亮点

与传统的网站克隆工具或手动逆向工程相比，AI Website Cloner Template 的核心差异化在于它完全由 AI 编码代理驱动，而非依赖规则引擎或固定模板。它不仅能复制外观，还能提取设计系统和组件逻辑，生成可维护、模块化的代码。项目采用“模板仓库”而非“直接克隆”的方式，保证了每个用户的生成成果互相独立，避免混乱。另外，对多种 AI 代理的支持使其具有灵活的适配性，用户可以根据预算和质量需求选择合适的后端 AI 模型。目前该项目在 GitHub 上已获得超过两万星标，社区活跃度极高，并配有 Discord 讨论群组。
