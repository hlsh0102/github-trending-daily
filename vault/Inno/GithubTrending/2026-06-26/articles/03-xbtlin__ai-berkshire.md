## 项目概述

AI Berkshire 是一套基于 Claude Code 的价值投资研究框架，将巴菲特、芒格、段永平、李录四位大师的投资方法论系统化、结构化，通过多 Agent 并行研究实现专业级投资分析。项目核心理念是“一个人 + Claude = 一个投研团队”，旨在解决传统 AI 投资分析“看起来对，但没法做决策”的痛点——直接问 AI 得到的往往是平衡但无用的泛泛之谈，而 AI Berkshire 强制输出有明确结论和操作建议的分析报告。

目标用户包括个人价值投资者、投研分析师、以及希望用 AI 提升投资决策效率的专业人士。项目已通过实盘验证：2024 年全年收益 +69.29%，2025 年至今收益 +66.38%，连续两年大幅跑赢全球主要指数，累计实盘收益超 146 万元。

## 核心功能

- **四大师方法论系统化**：将巴菲特、芒格、段永平、李录四位大师的核心理念编码为可执行的决策规则，每位大师对应一套独立的分析 Agent，而非简单的“用巴菲特方法分析”
- **多 Agent 对抗分析**：四个视角独立分析后自动产生观点冲突与矛盾，暴露单一视角可能忽略的风险与机会，最终合成更全面的投资结论
- **强制结论输出**：告别“一方面…另一方面…”的太极式分析，强制输出 **通过/不通过/灰色地带** 三档结论，附带具体价格区间和分层操作建议（激进型/稳健型/保守型）
- **镜子测试机制**：5 句话说不完整投资逻辑 = 不买，没有例外，强制执行决策纪律
- **实盘回测与跟踪**：提供基于真实交易记录的收益对比，与恒生指数、标普 500、沪深 300、纳斯达克进行年度和月度收益对比
- **Skill 合集形式**：基于 Claude Code 的 Skill 系统，可灵活组合调用，无需复杂配置即可开始使用

## 技术架构

项目采用 Python 开发，核心设计思路是 **方法论引擎 + Agent 编排**：

1. **方法论引擎层**：将四位大师的投资哲学转化为可计算的规则集，例如巴菲特的“护城河”分析、芒格的“逆向思考”、段永平的“本分”理念、李录的“复利思维”等，每条规则包含触发条件、权重和输出格式
2. **Agent 编排层**：每个大师对应一个独立的 Agent，Agent 之间通过消息传递机制进行并行研究并自动触发对抗讨论；当 Agent 间出现分析结论冲突时，系统会自动进入“会议模式”进行多轮辩论
3. **结论合成层**：收集所有 Agent 的分析结果和辩论记录，通过预设的决策矩阵生成最终报告，包括结论（通过/不通过/灰色地带）、价格区间、分层建议（激进/稳健/保守）、以及风险提示
4. **Claude Code 集成**：利用 Claude Code 的代码执行和工具调用能力，实现从数据抓取、财务分析到报告生成的全流程自动化

架构特点包括低耦合、可扩展（支持新增方法论或调整规则）、以及强制决策导向（每个 Agent 的输出必须包含明确的结论和依据）。

## 安装与使用

### 安装步骤

1. 克隆仓库：
   ```bash
   git clone https://github.com/xbtlin/ai-berkshire.git
   cd ai-berkshire
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. 配置 Claude Code 环境：确保已安装 Claude Code 并完成认证。详细配置可参考 [Claude Code 官方文档](https://claude.ai/code)。

4. 运行初始化脚本：
   ```bash
   python init.py
   ```

### 最小可用示例

分析一只股票（如拼多多）：
```bash
claude run research "PDD" --framework value
```

系统会自动启动四个大师 Agent 进行并行分析，数分钟后输出包含以下内容的完整报告：
- 四大师各自的分析结论
- Agent 间冲突与辩论记录
- 最终合成报告（通过/不通过/灰色地带 + 价格区间 + 分层建议）

更多示例和自定义配置请参考 [使用文档](docs/USAGE.md)。

## 适用场景

- **个人价值投资研究**：普通投资者无需专业分析团队，即可获得四位大师级方法论加持的深度分析报告，大幅提升个股研究效率和质量
- **投资组合再平衡**：定期对持仓标的进行多视角审查，避免单一视角导致的偏见或盲点，辅助做出更理性地加减仓决策
- **投研团队辅助工具**：专业分析师可用此框架快速生成初稿，再结合自身经验进行深度调整，将重复性分析工作压缩 80% 以上
- **投资策略验证与回测**：基于实盘数据验证方法论的有效性，并通过 Agent 对抗暴露持仓风险，适合需要量化验证投资逻辑的用户

## 项目亮点

与同类 AI 投资分析工具相比，AI Berkshire 的差异化优势主要体现在：

1. **实盘验证而非纸上谈兵**：项目附带 2024-2025 年真实交易账户收益截图，连续两年大幅跑赢全球主要指数，累计收益超 146 万元，具备可追溯的真实业绩
2. **多 Agent 对抗式分析**：不仅仅是“多角度分析”，而是强制产生观点冲突与辩论，暴露单一方法论可能忽略的风险，输出更全面的结论
3. **强制决策导向**：所有分析必须有明确结论和操作建议，不做“和稀泥”的平衡分析，真正服务于投资决策而非仅仅提供信息
4. **系统化且可扩展**：四位大师的方法论被编码为独立且可替换的规则集，用户可自由组合、调整权重、或新增自己的方法论，而非黑盒模型
5. **基于 Claude Code 的 Skill 体系**：低门槛使用，无需复杂部署，只需 Claude Code 环境即可运行，适合个人投资者和团队灵活调用
