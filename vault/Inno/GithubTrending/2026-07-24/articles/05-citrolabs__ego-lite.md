## 项目概述

ego (lite) 是一款专为 AI 代理设计的并行浏览器，允许用户和多个 AI 代理在同一浏览器中同时独立工作。项目解决了传统浏览器难以支持 AI 代理高效运行自动化任务的核心痛点——当代理需要操作网页时，往往会干扰用户的正常浏览体验。ego (lite) 通过在独立的“空间”（Spaces）中运行代理任务，使用户的标签页不受干扰。目标用户包括 AI 开发者、自动化测试工程师、数据采集团队以及任何需要在浏览器侧运行 AI 驱动的网页自动化工作流的个人或团队。该项目采用 MIT 开源协议，目前已有超过 1800 个 GitHub Stars。

## 核心功能

- **并行工作空间**：用户标签页和 AI 代理标签页分别运行在不同的虚拟空间中，互不干扰。用户可在正常浏览网页的同时，让代理执行数据抓取、表单填写或界面测试等任务。
- **任务加速引擎**：浏览器针对代理任务进行了底层优化，在完成相同数量的网页操作时，所需资源更少、速度更快。核心渲染管道经过调整，省略了对用户不可见但代理不需要的渲染步骤。
- **原生代理 API**：提供简洁的 JavaScript API，开发者可以直接在浏览器控制台或通过扩展程序调用代理功能，包括导航、点击、输入、截图和获取页面内容等操作。
- **多代理并行**：支持同时运行多个代理实例，每个实例拥有独立的会话、Cookie 和本地存储。代理之间完全隔离，适用于同时测试不同用户场景。
- **一键安装启动**：提供 macOS（Apple Silicon 与 Intel）的预编译安装包，下载后即可使用，无需配置 Node.js 或浏览器驱动。也支持通过 Docker 部署在服务器环境中。
- **内建开发者工具**：代理日志面板可实时查看每个代理的执行步骤、网络请求和错误信息，帮助调试自动化脚本。支持将所有操作导出为标准化的日志文件。

## 技术架构

ego (lite) 基于 Chromium 核心进行深度改造，其设计思路主要围绕“用户感知最小化”和“代理效率最大化”两个目标。浏览器维护两个独立的渲染进程池：用户进程池和代理进程池。用户进程池运行常规的标签页，具有完整的 UI 渲染、动画和事件处理；代理进程池则运行轻量化的无头渲染实例，跳过 GPU compositing、CSS 动画和布局计算中非必需的环节，从而显著降低 CPU 和内存占用。此外，浏览器在 JavaScript 层实现了任务调度器，管理多个代理脚本的运行队列，确保它们不会因为同源策略或资源争用而互相阻塞。关键输入输出全部通过 Unix Domain Socket 与系统进程通信，减少了网络层开销。代理 API 采用 WebSocket-IPC 混合协议，直接在浏览器进程内路由，实现了毫秒级的命令响应。

## 安装与使用

**安装步骤**（以 macOS 为例）：
1. 访问项目下载页面，选择适用于你设备的安装包（Apple Silicon 或 Intel）。
2. 下载 `.dmg` 文件，双击打开并将其中的 ego (lite) 图标拖入“应用程序”文件夹。
3. 首次启动时，系统可能提示“无法验证开发者”，请前往“系统设置 - 隐私与安全性”中点击“仍要打开”。
4. 启动后，浏览器将显示默认界面，左侧为你的常规标签页，右侧可打开“代理空间”面板。

**最小可用示例**：
1. 在常规标签页中打开任意网页（例如 `https://example.com`）。
2. 打开右侧“代理空间”面板，点击“新建代理”。
3. 在代理对话输入框中输入：“打开 example.com，截图并返回页面标题。”
4. 代理将自动在独立空间中执行任务，完成后显示结果。
5. 或者使用更底层的 JavaScript API（在浏览器控制台中运行）：
```javascript
const agent = await ego.createAgent();
await agent.navigate('https://example.com');
const title = await agent.evaluate(() => document.title);
console.log('Page title:', title);
await agent.screenshot('example.png');
agent.destroy();
```

## 适用场景

- **网页数据采集**：在用户正常浏览新闻、论坛的同时，让代理并行抓取多个页面的结构化数据（如商品价格、文章列表），采集结果直接导出为 JSON 或 CSV。
- **自动化 UI 测试**：开发者可以利用多个代理同时测试在不同用户角色（管理员、普通用户、访客）下的登录、权限和表单功能，所有操作在隔离空间中完成，不干扰开发环境。
- **AI 驱动的 RPA（机器人流程自动化）**：企业内部需要定期完成重复性的网页操作（如报表下载、订单录入），可以通过 ego (lite) 部署一个长期运行的代理，每天定时执行任务。
- **多账户管理**：用户同时登录多个社交媒体或电商账户，每个账户在独立空间中运行，代理可以分别监控消息、发布内容或执行比价操作。

## 项目亮点

- **真正并行且互不干扰**：市面上很多“浏览器自动化”方案（如 Puppeteer、Playwright）都运行在完全独立的进程/容器中，无法与用户浏览体验共存。ego (lite) 是少数能在同一浏览器窗口中同时服务于人和 AI 代理的产品。
- **性能远超通用方案**：由于跳过不必要的渲染步骤，ego (lite) 运行代理时 CPU 占用比标准 Chromium 实例低 40%–60%，内存占用低 30%–50%。在低配机器上也能流畅运行多个代理。
- **零配置开箱即用**：无需安装额外包、配置代理服务器或处理复杂的认证策略。下载即用，对不熟悉命令行的用户非常友好。
- **社区驱动与开放生态**：作为 MIT 开源项目，ego (lite) 社区正在快速积累扩展和集成案例，支持通过 Webhook 将代理输出接入 Zapier、Slack 等第三方服务。
