## 项目概述

Pumpkin 是一款完全使用 Rust 语言编写的 Minecraft 服务器软件，致力于为所有玩家提供快速、高效且高度可定制的游戏体验。项目在追求极致性能的同时，严格遵循 Minecraft 原版游戏机制，支持最新的 Java 版和基岩版协议。无论是希望搭建小型私人服务器的玩家，还是需要承载大规模在线用户的社区运营者，Pumpkin 都提供了一套现代化的解决方案。当前项目正处于密集开发阶段，社区活跃度极高，已在 GitHub 获得超过 9000 颗星标。

## 核心功能

- **多线程性能优化**：充分利用 Rust 语言的内存安全特性和并发模型，通过多线程架构实现服务器运算的极致效率。
- **双协议原生支持**：同时兼容 Minecraft Java 版和基岩版最新协议，允许不同平台的玩家在同一服务器中联机。
- **完善的基础设施**：内置加密通信、数据包压缩、世界加载与保存、光照计算、实体刷怪等核心系统。
- **灵活的配置系统**：采用 TOML 格式的配置文件，用户可精细调整服务器参数，并能按需禁用非必要功能。
- **模块化结构设计**：为未来的插件开发预留了扩展接口，社区可基于此构建丰富的功能生态。
- **安全防护机制**：将安全问题置于首位，主动防御已知的 Minecraft 服务端漏洞和攻击手段。

## 技术架构

Pumpkin 的技术核心建立在 Rust 语言的高性能基础之上。服务端采用多线程异步 I/O 模型，将网络通信、世界计算、玩家行为处理等任务分配到不同线程池，最大化利用多核 CPU 资源。协议层同时解析 Java 版和基岩版的数据包格式，实现跨平台的统一处理。

在世界管理方面，Pumpkin 实现了完整的区块加载、存储和光照更新系统，支持世界边界、游戏时间和计分板等标准功能。安全层面，协议层在握手阶段即启用加密和压缩，防止中间人攻击和数据篡改。

项目的架构特点在于解耦设计：核心引擎专注于性能与兼容性，而具体玩法功能则通过配置开关和未来插件机制来扩展。这种设计使得 Pumpkin 在保持轻量级的同时，具备了高度的可定制性。

## 安装与使用

由于 Pumpkin 尚处于开发阶段，目前主要通过源代码编译方式使用：

1. **环境准备**：确保系统已安装 Rust 工具链（rustc, cargo）。
2. **克隆仓库**：执行 `git clone https://github.com/Pumpkin-MC/Pumpkin.git`
3. **编译构建**：进入项目目录，运行 `cargo build --release`
4. **运行服务端**：编译完成后，在 `target/release` 目录执行 `./pumpkin`
5. **连接测试**：启动 Minecraft Java 版客户端（1.21+），在多人游戏界面添加本地服务器地址 `localhost:25565`

基础配置文件 `config.toml` 会在首次启动时自动生成，用户可修改其中的服务器名称、游戏模式、最大玩家数等参数。对于基岩版用户，需要在配置中启用对应的网络接口。

## 适用场景

- **高性能需求服务器**：需要承载数百人同时在线的生存、小游戏或大型社区服务器，Pumpkin 的多线程架构能有效降低延迟和卡顿。
- **跨平台联机组**：希望 Java 版和基岩版玩家能在同一世界里互动的个人或团队，无需搭建额外的协议转换代理。
- **安全敏感环境**：对服务器安全有较高要求的运营者，可借助 Pumpkin 内置的防护机制抵御常见攻击。
- **嵌入式/轻量化部署**：在树莓派、低配云服务器等资源受限设备上搭建 Minecraft 服务端，Rust 的编译优化能带来极高的资源利用率。

## 项目亮点

与现有的 CraftBukkit、Paper 等 Java 系服务端相比，Pumpkin 的最大差异化优势在于语言层面的性能革命。Rust 语言的内存安全性保障从根本上消除了因内存泄漏或空指针导致的服务器崩溃问题，而零成本抽象则让 CPU 密集型运算（如寻路算法、光照计算）达到接近 C 语言的执行效率。

另一个独特亮点是跨协议原生支持。传统方案需要通过 BungeeCord 等代理或第三方插件才能实现 Java/基岩互通，Pumpkin 在核心层面即实现了这一点，降低了部署复杂性和网络开销。

此外，Pumpkin 在开发初期就将安全防护作为一等公民设计，而非后期打补丁。项目团队积极追踪和防御 Minecraft 生态中已知的安全漏洞，这一点在同类新项目中较为罕见。
