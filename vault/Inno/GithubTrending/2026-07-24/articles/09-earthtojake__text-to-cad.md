## 项目概述

text-to-cad 是一个为 CAD、机器人学及硬件设计而生的智能体技能库。该项目由开发者 earthtojake 创建，旨在为大型语言模型（LLM）提供执行生成、检查、拆分、仿真和交接 CAD（计算机辅助设计）与机器人描述文件所需的专业“技能”。其核心目标用户包括硬件工程师、机器人开发者、创客以及对 AI 辅助设计感兴趣的任何人。通过将结构化的知识封装成可复用的技能模块，该项目解决了传统上 AI 难以直接操控复杂工程软件和数据格式的问题，让文本描述与三维模型之间的转换变得更加直接和高效。

## 核心功能

- **CAD 生成**：基于文本描述生成可预览的 CAD 几何体，支持常见的几何特征和约束。
- **文件检查与预览**：提供技能以检查生成的 CAD 文件或机器人描述文件（如 URDF、SDF、SRDF）的结构、关节和物理参数，并支持本地预览。
- **物料清单提取与采购**：能够从设计文件或描述中提取零件清单，并可对接在线采购或本地物料搜索工作流。
- **切片与制造准备**：支持将 3D 模型进行切片处理，以用于 3D 打印等制造工艺。
- **机器人描述文件生成**：专门为机器人仿真场景准备，可生成或修改 URDF、SDF、SRDF 等标准格式文件。
- **本地文件交接**：技能模块可以方便地与本地项目文件夹进行交互，支持文件的读写和版本管理。

## 技术架构

该项目基于 JavaScript 编写，采用“技能库”的架构模式。每个技能（Skill）都遵循统一的接口规范，以独立模块的形式存在。主要技术设计特点包括：

- **模块化封装**：每个 CAD 或机器人相关的功能被封装成一个独立的技能模块，便于维护、测试和扩展。开发者可以根据需要组合调用不同的技能。
- **提示工程驱动**：技能的核心在于精心设计的系统提示词（Prompt）和工作流定义，引导 LLM 按步骤生成正确的代码或执行特定操作，从而实现对 CAD 内核或 ROS 生态的间接控制。
- **与外部工具集成交互**：技能内部往往涉及调用外部工具或库（例如通过 `requirements.txt` 指定的 Python 依赖）来完成实际计算，并通过标准输入/输出与 LLM 通信。
- **本地优先**：强调在本地项目文件中工作，无需完全依赖云端服务，保护用户数据的隐私和安全性。
- **依赖管理**：每个技能附带独立的依赖清单（如 `skills/cad/requirements.txt`），确保运行环境的可复现性。

## 安装与使用

以下是基于常见做法的通用安装和入门步骤：

1. **克隆仓库**
   ```bash
   git clone https://github.com/earthtojake/text-to-cad.git
   cd text-to-cad
   ```
2. **设置运行环境**（推荐使用 Conda 或 venv）
   ```bash
   # 以创建 Python 虚拟环境为例（技能通常依赖 Python 后端）
   python -m venv venv
   source venv/bin/activate  # 在 Windows 上为 venv\Scripts\activate
   # 安装基础依赖，具体依赖请参考各技能文件夹内的 requirements.txt
   # 例如：pip install -r skills/cad/requirements.txt
   ```
3. **配置 LLM 接口**：项目需要配合支持工具调用的大语言模型（如 GPT-4 及以上版本）。通常需要设置 `OPENAI_API_KEY` 或其他提供商的环境变量。
   ```bash
   export OPENAI_API_KEY=你的密钥
   ```
4. **运行技能示例**：使用提供的交互式脚本或 API 调用技能。例如，调用 CAD 生成技能：
   ```python
   # 伪代码示例，实际实现细节请参考仓库内的 demo 或 skill 定义
   from skills.cad import CADSkill
   skill = CADSkill()
   result = skill.invoke("生成一个长 100mm、宽 50mm、高 20mm 的长方体，并在顶部中央开一个直径 10mm 的圆孔")
   print(result)  # 输出 CAD 文件路径或预览信息
   ```
5. **预览结果**：打开生成的 `.step`、`.stl` 或本地 URL 预览链接查看结果。

## 适用场景

- **AI 辅助机械设计**：设计师通过自然语言描述概念草图，AI 代理利用 CAD 技能快速生成初始三维模型，极大缩短早期迭代周期。
- **机器人仿真快速搭建**：机器人开发者可从文本描述生成标准的机器人描述文件（URDF/SDF），省去手动编码大量 XML 细节的时间，直接用于 Gazebo 或 RViz 等仿真环境。
- **硬件设计与制造自动化**：结合切片和采购技能，可从产品设计直接导出 3D 打印切片文件和物料清单，打通从设计到制造的自动化链条。
- **本地化知识库集成**：公司或个人可以将专有的设计规范、标准件库作为技能的一部分，集成到 AI 工作流中，确保设计符合内部标准。

## 项目亮点

- **开源与社区驱动**：与许多封闭的 AI 设计工具不同，该项目完全开源（MIT 许可），有活跃的社区支持（Discord 和 GitHub），用户可自由修改和扩展技能。
- **聚焦“技能”而非“模型”**：不依赖于特定的巨型模型，而是通过可组合的、轻量级的技能模块来实现复杂功能，具有更高的灵活性和更新速度。
- **深度集成机器人生态**：不仅支持普通 CAD，还特意提供了适用于 URDF、SDF、SRDF 等机器人描述文件的技能，填补了通用 CAD 生成工具在机器人领域的空白。
- **本地化与隐私友好**：大部分处理在本地完成，用户的数据和设计文件不会强制上传至第三方服务器，适合对保密性要求较高的硬件研发场景。
