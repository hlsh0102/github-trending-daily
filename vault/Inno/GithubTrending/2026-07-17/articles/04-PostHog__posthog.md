## 项目概述

PostHog 是一个面向现代产品团队的开源产品分析平台，旨在帮助开发者构建“自动驾驶”式的产品。它集成了产品分析、会话回放、功能开关、实验、错误追踪等多种工具，覆盖了产品从洞察、决策到验证的完整闭环。项目诞生于对传统数据分析工具的反思——那些工具往往过于昂贵、封闭、且不尊重用户隐私。PostHog 以开源、自托管为核心，让团队完全掌控自己的数据，同时提供丰富的功能来理解用户行为、优化产品体验。其目标用户包括产品经理、工程师、数据科学家以及任何希望基于数据而非直觉来驱动产品决策的团队。目前，PostHog 在 GitHub 上已获得超过 35,000 颗星，是一个广受认可的开源项目。

## 核心功能

- **产品分析与用户洞察**：支持事件追踪、漏斗分析、留存分析、趋势图等，帮助团队理解用户从注册到关键转化的完整行为路径。
- **会话回放**：以视频形式回放用户的实际操作过程，包括鼠标移动、点击、滚动等，配合控制台日志和网络请求，便于诊断用户体验问题。
- **功能开关（Feature Flags）**：允许团队在没有重新部署的情况下，按用户、群体或百分比动态开启或关闭功能，支持渐进式发布和 A/B 测试。
- **实验（Experiments）**：内置统计引擎，可对功能开关、界面变体等进行实验，自动计算置信度和统计显著性，帮助团队做出基于数据的决策。
- **错误追踪**：自动捕获前端 JavaScript 错误和后端异常，并关联到会话回放，让开发者能直接从崩溃现场回溯用户操作。
- **AI 可观测性与日志**：提供针对 AI 模型调用的监控工具（包括提示词追踪、成本分析、延迟等），以及结构化日志收集与分析能力，支持从 Slack、Web、桌面客户端或 MCP 进行管理。

## 技术架构

PostHog 采用微服务架构，后端核心由 **Python**（Django）编写，负责 API 和数据处理；事件摄取与实时分析引擎则基于 **Go** 构建，以应对高吞吐量的数据流。前端使用 **React** 和 **TypeScript**，提供现代化的交互界面。数据存储层混合了 **PostgreSQL**（用于元数据、用户属性等）、**ClickHouse**（用于事件和会话数据的列式存储，支持快速聚合查询）以及 **Redis**（用于缓存和队列）。整套系统支持 **Docker Compose** 一键部署，也可通过 **Kubernetes** 或 **Helm Chart** 在生产环境中水平扩展。设计上强调可插拔性：核心功能模块相互独立，用户可以通过插件系统或自定义事件管道来扩展能力。此外，PostHog 支持自托管（Self-Hosted）和云版（PostHog Cloud）两种模式，自托管版本完全不发送任何数据到外部服务器。

## 安装与使用

**快速启动（开发/小规模使用）**  
确保已安装 Docker 和 Docker Compose，然后在终端执行：

```bash
git clone https://github.com/PostHog/posthog.git
cd posthog
docker compose -f docker-compose.dev.yml up
```

访问 `http://localhost:8000` 即可看到 PostHog 界面，完成初始用户注册后，即可通过提供的 JavaScript 代码段将事件发送到本地实例。

**最小可用示例（Web 端事件追踪）**  
在你的网站或应用中添加以下 JavaScript 代码：

```javascript
// 初始化 PostHog（需替换为自己的 API Key 和 Host）
posthog.init('YOUR_API_KEY', {
  api_host: 'http://localhost:8000', // 自托管时使用
  loaded: function(posthog) {
    // 可选：获取已登录用户的身份信息
    posthog.identify('user_distinct_id');
  }
});

// 发送自定义事件
posthog.capture('signup_clicked', { plan: 'pro' });
```

之后便可在 PostHog 控制台看到事件数据，并进行漏斗分析、生成趋势图等。

## 适用场景

- **产品增长实验**：团队需要快速验证新功能或优化页面布局，PostHog 的实验与功能开关组合可帮助在真实用户中低成本进行 A/B 测试，并直接使用内置统计分析结果。
- **用户行为定性分析**：当发现转化率下跌或用户频繁流失时，可通过会话回放逐帧观察用户操作，结合错误追踪定位崩溃或 UI 卡顿的根源。
- **AI 产品可观测性**：针对生成式 AI 应用，PostHog 的 AI 监控能力可以追踪每次 LLM 调用的提示词、响应、延迟和费用，帮助团队优化模型选择与成本。
- **企业内部数据平台**：团队希望完全掌控用户数据，避免将敏感信息发送到第三方云服务，可以选择自托管 PostHog，实现数据安全与合规。

## 项目亮点

- **开源与自托管**：所有核心功能均以 MIT 许可开源，用户可以在自有服务器上部署，完全控制数据，避免了供应商锁定和隐私泄露风险。
- **功能一体化**：PostHog 将通常分散在多个 SaaS 工具中的分析、回放、实验、错误追踪整合在一个平台内，减少了工具切换成本和数据孤岛。
- **兼顾深度与易用性**：既有面向数据科学家的 SQL 查询接口，又提供了无代码的事件管理界面，降低了使用门槛。
- **活跃的社区与生态**：拥有丰富的插件市场、API 和客户端库（支持 JS、Python、Ruby、Node.js 等），并不断集成 MCP 等新兴协议，扩展性强。
