## 项目概述

Hallmark 是一个专为 Claude Code、Cursor 和 Codex 等 AI 编码工具设计的前端样式系统，其核心使命是让 AI 生成的用户界面“拒绝看起来像 AI 生成的”。该项目由 Together AI 开发，旨在解决当前大语言模型在生成网页 UI 时普遍存在的“模板化”问题——即所有 AI 生成的页面看起来都像是同一套模板的颜色互换，缺乏真正的设计差异性和手工质感。

目标用户包括使用 AI 编码工具进行前端开发的开发者、设计师，以及任何希望在 AI 辅助下获得独特、非模式化界面的创作者。Hallmark 不是一套普通的 UI 组件库，而是一套“反 AI 同质化”的设计方法论和工具集。

## 核心功能

- **四动词设计系统**：提供四个核心操作动词——默认（构建新 UI）、audit（审计现有代码）、redesign（推翻原有结构重建）、study（提取你欣赏设计的设计 DNA），覆盖从创建到分析的全链路。
- **二十种独立主题**：内置 20 种截然不同的视觉主题，每种主题拥有独特的颜色锚点、字体配对和宏观结构，确保不同项目的输出看起来完全不同。
- **57 道 Slop 测试门**：在最终输出前，系统会运行 57 道“反俗套”测试，检测并拒绝 LLM 训练数据中常见的默认设计模式，如过度的毛玻璃效果、千篇一律的卡片布局、固定的颜色渐变等。
- **预输出自我批判**：在代码交付前，Hallmark 会执行自我审查机制，主动识别并修正潜在的同质化问题。
- **设计 DNA 提取**：通过 `hallmark study` 命令，可分析你欣赏的设计截图或 URL，提取其宏观结构、字体配对和颜色锚点，并生成可移植的 `design.md` 文件，用于跨工具的设计交接。
- **按键切换主题**：在预览模式下按 `T` 键即可实时切换 20 种主题，方便快速比较不同视觉效果。

## 技术架构

Hallmark 基于 CSS 构建，其核心设计理念是“拒绝默认分布”。传统 LLM 在生成 UI 时，由于训练数据的高度相似性，会倾向于输出概率最高的“平均化”设计。Hallmark 通过以下方式打破这一模式：

1. **宏观结构选择器**：不为每个任务预定义固定模板，而是根据输入的 Brief 动态选择合适的页面宏观结构（如左右分栏、顶部导航、瀑布流等），确保不同任务的结构指纹不同。
2. **主题系统**：20 个主题并非简单的颜色变量替换，而是包含完整的排版系统、间距规则、交互动效和视觉语言。主题之间没有“颜色互换”关系，每个主题都是独立设计的。
3. **Slop-test 管道**：57 道测试构成一个规则引擎，在代码生成后逐项检查。检测项包括但不限于：是否使用了过度流行的样式库特征、是否出现了 LLM 训练数据中的高频设计模式、布局是否过于对称等。
4. **自我批判机制**：在代码交付前，系统会模拟设计师的评审视角，对输出进行质量评分。如果“AI 感”得分过高，会自动触发重构。

这种架构使得 Hallmark 的输出在保持高质量的同时，具有高度的不可预测性和独特性。

## 安装与使用

Hallmark 作为一个设计技能（design skill），需要与你使用的 AI 编码工具配合。基础安装步骤如下：

1. 将 Hallmark 的规则集添加到你的项目依赖中（具体方式取决于你使用的工具，通常是通过配置文件或插件系统加载）。
2. 在你的 AI 编码工具（如 Claude Code、Cursor）中启用 Hallmark 技能。
3. 在编写 UI 时，工具会自动应用 Hallmark 的设计规则。

**最小可用示例**：

在 Claude Code 中，你可直接输入如下指令：

```
帮我创建一个新的产品落地页
```

Hallmark 会自动生效，输出具有独特主题和结构的页面。如需指定主题，可使用：

```
帮我创建一个新的产品落地页，使用主题 7
```

运行审计功能：

```
hallmark audit ./src/components
```

提取设计 DNA：

```
hallmark study https://example.com/beautiful-design
```

## 适用场景

- **产品落地页开发**：需要为不同产品创建完全不同视觉风格的落地页面，避免用户产生“又是 AI 做的那套”的认知疲劳。
- **设计系统审计**：对现有项目中的 UI 组件进行“AI 同质化”检测，识别并替换过于模板化的设计模式。
- **竞品分析**：使用 `hallmark study` 提取你欣赏的设计网站的设计 DNA，理解其背后的结构逻辑和视觉语言。
- **跨 AI 工具设计协作**：通过导出 `design.md`，在不同 AI 编码工具之间共享设计意图，保持一致的视觉输出标准。

## 项目亮点

与同类项目相比，Hallmark 的差异化优势在于其“反 AI 同质化”的核心理念，而非简单的样式美化。它不是一套 UI 组件库或样式生成器，而是一套针对 AI 输出特性的批判性设计系统。57 道 slop 测试和预输出自我批判机制，是 LLM 原生设计工具中首创的功能。此外，其四动词设计系统覆盖了从创建到审计到学习的完整设计工作流，而不仅仅是生成静态页面。
