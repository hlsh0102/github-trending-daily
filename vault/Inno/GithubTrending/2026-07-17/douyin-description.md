今日 GitHub Trending TOP10 速览 🚀

1️⃣ **apache/ossie** - Apache 孵化中的语义元数据交换标准，通过 JSON/YAML 规范解决数据工具间指标定义不一致，面向数据工程师和 AI 开发者。

2️⃣ **Nutlope/hallmark** - 为 Claude Code、Cursor 等 AI 编码工具设计的“反 AI 同质化”样式系统，提供 20 种独立主题，让 UI 不“模板化”。

3️⃣ **OpenCut-app/OpenCut** - 开源的 CapCut 替代品，跨 Web、桌面、移动端，基于 Rust 核心，支持插件和 AI 交互。

4️⃣ **PostHog/posthog** - 开源产品分析平台，集成用户行为分析、会话重放、A/B 测试、特性开关等，适合自主托管数据的团队。

5️⃣ **openinterpreter/openinterpreter** - 用 Rust 写的低成本模型编程代理，支持自然语言转代码并自动执行，特别优化了 Kimi K3 等模型。

6️⃣ **PrismML-Eng/Bonsai-demo** - 本地运行 Bonsai 量化模型的演示，支持 Mac、Linux/Windows 及 CPU，新增 27B 多模态模型可处理图像和 PDF。

7️⃣ **hasaneyldrm/exercises-dataset** - 包含 1,324 个健身动作的结构化数据集，有名称、类别、目标肌群和多语言指导，适合健身应用开发。

8️⃣ **Shubhamsaboo/awesome-llm-apps** - 收录 100+ AI Agent 和 RAG 应用模板，支持本地运行，可克隆定制部署，覆盖多模型。

9️⃣ **lobehub/lobehub** - AI 代理编排平台，支持将多个 AI 代理组织成 7×24 小时自动运行的团队，提供招聘、调度和报告功能。

🔟 **YimMenu/YimMenuV2** - GTA 5 增强版实验性菜单工具，需外部注入器和 FSL 本地保存，暂不支持绕过 BattlEye。
