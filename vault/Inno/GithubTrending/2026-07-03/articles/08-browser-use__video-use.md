## 项目概述

video-use 是一个由 browser-use 团队推出的开源视频编辑工具，核心思路是用编码智能体（coding agents）代替传统视频编辑软件完成剪辑工作。用户只需将原始素材放入一个文件夹，通过自然语言与 Claude Code 等智能体对话，即可最终获得成品 `final.mp4`。该项目面向的内容创作者、视频编辑者以及开发者，无需掌握复杂视频编辑软件操作，也无需依赖预设模板或菜单，即可完成从口播视频到旅行记录等各类视频的编辑与后期处理。

## 核心功能

- **智能剪辑与填充词消除**：自动识别并剪切掉 `umm`、`uh` 等填充词、假开头以及不必要停顿，提升视频节奏与观感
- **自动调色**：支持暖色电影感、中性鲜明等调色风格，用户也可以自定义 ffmpeg 调色链，对每个视频片段独立应用
- **微秒级音频淡入淡出**：在每个剪切点自动添加 30ms 的音频淡入淡出，消除爆破音，保证音画过渡自然
- **字幕自动生成与样式定制**：默认采用 2 字大写分块格式，支持自定义字幕样式，无需手动添加字幕轨道
- **动画覆盖层生成**：利用 HyperFrames、Remotion、Manim 或 PIL 等工具，通过并行子智能体为每个动画片段独立生成动画叠加层
- **输出自我评估**：在呈现最终视频之前，智能体会在每个剪切边界自动评估渲染输出质量，确保剪辑效果达标后再交付用户
- **会话记忆持久化**：将项目状态自动保存至 `project.md` 文件，下次启动对话时可无缝恢复进度

## 技术架构

video-use 基于智能体驱动的视频处理管线设计，核心架构包括：

1. **智能体编排层**：Claude Code 等编码智能体作为调度中心，用户通过自然语言下达编辑指令，智能体将指令解析为具体操作步骤并调用工具执行。
2. **模块化后端**：依赖 ffmpeg 作为视频和音频处理的底层引擎，支持复杂的滤镜链和编解码操作；PyAV 或类似库提供 Python 层面的音视频处理 API。
3. **并行子智能体系统**：针对动画覆盖层等耗时任务，采用多进程并行方式派生子智能体独立生成，每个动画片段由专门的子智能体负责，提高整体处理效率。
4. **质量评估与反馈机制**：内置质量评估节点，在每个剪切点自动分析输出视频的连续性、音频同步、色彩一致性等指标，形成闭环优化。
5. **配置与状态管理**：`project.md` 文件充当项目状态存储库，记录当前进度、用户偏好、素材索引等，实现跨会话的连续性。

## 安装与使用

### 安装

```bash
# 克隆仓库
git clone https://github.com/browser-use/video-use.git
cd video-use

# 安装 Python 依赖
pip install -r requirements.txt

# 确保系统中安装了 ffmpeg（可通过 apt install ffmpeg 或从 ffmpeg.org 下载）
```

最小使用流程：

1. 将原始视频素材放入项目指定目录（如 `raw/`）。
2. 配置 Claude Code 或其他支持的编码智能体（如 Codex、Hermes、Openclaw）。
3. 将以下提示词粘贴给智能体会话：

```
Set up https://github.com/browser-use/video-use for me.

Read install.md first to install this repo, wire up ffmpeg, register my raw footage in /path/to/raw.
```

4. 用自然语言描述编辑需求，例如：“去掉所有空白停顿，暖色调调色，添加居中字幕，在开头添加一个 3 秒的动画标题”。
5. 智能体自动处理并输出最终视频为 `final.mp4`。

## 适用场景

- **口播与播客内容生产**：快速剪除说话中的填充词和空白停顿，自动调色并添加字幕，极大提升口播类视频的制作效率
- **视频教程与产品演示**：无需打开专业编辑软件，通过自然语言即可完成视频分段、调色、动画添加等操作，适合非专业编辑的技术内容创作者
- **旅行与生活 vlog**：支持批量处理原始素材，自动剪辑、调色、添加动画覆盖层，快速产出成片
- **视频片段质量检查**：利用自我评估功能，在正式渲染前自动检测输出质量，适合需要高频迭代编辑的项目

## 项目亮点

video-use 最大的差异化优势在于**完全抛弃传统视频编辑软件的可视化界面**，用编码智能体与自然语言替代了复杂的菜单和参数调节。这使得视频编辑可以无缝嵌入文本工作流，适合与文档、代码等其他内容生产工具协同使用。同时，100% 开源和 MIT 许可证降低了使用门槛和定制成本。此外，该项目通过并行子智能体架构解决了动画等计算密集型任务的效率问题，并内置自我评估机制，确保输出质量可控，这些都是同类项目难以同时具备的特性。
