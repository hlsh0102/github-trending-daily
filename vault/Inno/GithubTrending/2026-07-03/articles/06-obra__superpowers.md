## 项目概述

Superpowers 是一套专为编码代理（coding agents）设计的完整软件开发方法论，构建在一组可组合的技能（skills）与初始化指令之上。它的核心目标是解决当前 AI 编程工具在复杂项目中常见的“盲目编码”问题——即代理一上来就直接写代码，缺乏对项目全局的理解和系统化的开发流程。Superpowers 让编码代理从“会写代码”升级为“会做项目”，帮助开发者、团队以及 AI 工具本身以更结构化的方式完成从需求分析到实现部署的完整流程。

该项目的目标用户包括：
- 使用 Claude Code、Cursor、Codex CLI 等 AI 编程助手的个人开发者
- 希望通过代理工具提升团队协作效率的工程团队
- 对 AI 辅助软件开发流程有研究兴趣的技术人员

## 核心功能

- **需求挖掘与规格提取**：代理启动后不会直接开始编码，而是先通过对话引导用户明确真正的问题目标，并生成可读性强的规格文档。
- **分块展示设计**：将设计规格拆分为短小的段落，方便用户逐一阅读和确认，避免长篇文档带来的认知负担。
- **实现计划生成**：基于确认的设计，生成一份清晰的实现计划，遵循“热情初级工程师”也能执行的准则，强调 TDD、YAGNI 和 DRY 原则。
- **可组合技能系统**：提供一系列原子化的技能（skills），可像搭积木一样组合，适配不同项目类型的开发流程。
- **多代理平台支持**：开箱支持 Claude Code、Antigravity、Codex App、Codex CLI、Cursor、Factory Droid、GitHub Copilot CLI、Kimi Code、OpenCode、Pi 等主流编码代理工具。
- **MIT 许可开放框架**：完全开源，允许自由使用、修改和二次分发。

## 技术架构

Superpowers 的架构以“方法论驱动”为核心设计思路，而非单纯的工具增强。其技术基础主要包含以下层次：

1. **指令层（Instructions）**：一组初始指令，在代理启动时注入，定义了代理的行为模式和思考框架。这是整套方法论的“大脑”，告诉代理何时该做什么。
2. **技能层（Skills）**：一系列可复用的原子技能，每个技能封装了特定的开发子任务，例如“编写测试”、“重构代码”、“生成文档”等。技能之间可以相互调用或串联，形成工作流。
3. **适配器层（Adapters）**：针对不同编码代理工具（如 Claude Code、Cursor）的接口适配，确保技能和指令能在各平台上以相同的方式执行。项目以 Shell 脚本为主要实现语言，保持轻量和跨平台兼容性。
4. **执行引擎**：由代理自身的推理能力驱动，但通过上述三层结构约束其行为，减少无目的的试错。

设计上，Superpowers 强调“规格先行”（spec-first）和“测试驱动”（TDD-first）的哲学，试图将人类团队中良好的开发纪律映射到 AI 代理的自动执行流程中。这种架构让代理不会因缺乏项目上下文而做出糟糕的架构决策。

## 安装与使用

### 基本安装

Superpowers 的安装十分简单，无需复杂的依赖配置。以 Claude Code 为例：

1. 确保已安装 Claude Code（或其他支持的编码代理工具）。
2. 在终端中运行以下命令来获取 Superpowers 技能和指令：

```bash
git clone https://github.com/obra/superpowers.git
cd superpowers
```

3. 将 Superpowers 的指令文件添加到你的代理项目根目录，或按照 README 中的指示将其集成到代理的启动配置中。

### 最小可用示例

启动你的编码代理（例如 Claude Code），在项目目录中执行：

```bash
claude
```

代理启动后，Superpowers 的指令会被触发。此时，代理会先问：“你想构建什么？请描述一下你的想法。” 你需要输入一个需求描述，例如“一个待办事项列表 API”。代理随后会生成规格文档，并分块展示供你确认。确认后，代理生成实现计划，并等待你输入“go”后开始编写测试和代码。

整个过程无需你编写任何额外的配置或脚本，Superpowers 通过指令自动接管了开发流程的编排。

## 适用场景

- **从零开始的新项目**：当你搭建一个全新项目时，Superpowers 确保代理不会一头扎进代码细节，而是先帮你理清需求、设计规格，再逐步实现，避免后期大规模返工。
- **复杂系统的模块开发**：对于已有项目的新模块或功能点，Superpowers 的技能组合让代理能够遵循 TDD 和 YAGNI 原则，只写必要的代码，同时保持测试覆盖。
- **团队协作中的代理标准化**：团队成员使用不同 AI 工具时，Superpowers 提供了一个统一的方法论层，确保所有代理遵循相同的流程，产出可预期的代码质量。
- **学习和教学目的**：开发者可以通过 Superpowers 学习结构化软件开发方法，观察 AI 代理如何执行 TDD、DRY 和 YAGNI，从而反哺自身技能。

## 项目亮点

- **方法论而非工具**：与其在代理内部增加更多的“技能函数”，Superpowers 通过外部指令和组合技能来约束代理的行为模式，这种做法更轻量、更灵活，且不依赖于特定 AI 模型的能力边界。
- **可组合性**：技能不是硬编码的工作流，而是可拆卸、可重新排序的原子块，用户可以根据项目类型自定义组合，避免了“一刀切”的僵化。
- **多平台全支持**：覆盖了目前市面上几乎所有主流的 AI 编程代理工具，从 Cursor 到 Claude Code 再到 Kimi Code，无需针对每个工具重复配置。
- **关注点分离**：通过“挖掘需求→展示规格→制定计划→执行实现”四阶段流程，将“做什么”和“怎么做”清晰分离，让用户能够在早期就发现问题，而非在大量代码写完后才意识到偏差。
- **轻量且开源**：项目以 Shell 脚本实现，代码量小、易于理解和修改，MIT 许可证允许任意商用和二次开发，社区参与门槛低。
