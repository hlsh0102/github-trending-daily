## 项目概述

PentAGI 是一个基于大型语言模型的自主 AI Agent 系统，专门设计用于执行复杂的渗透测试任务。项目名称全称为“Penetration testing Artificial General Intelligence”，旨在通过 AI 技术赋能安全研究人员和渗透测试工程师，自动化完成从信息收集、漏洞扫描到利用验证的全流程安全评估工作。

该项目由 vxcontrol 团队开发并开源，采用 Go 语言编写，平均获得约 19500 颗 GitHub 星标。它解决了传统渗透测试工作中人力成本高、重复劳动多、技能门槛高等问题，让非专业安全人员也能高效完成安全评估，同时为专业渗透测试人员提供强大的自动化辅助工具。

## 核心功能

- **自主任务规划与执行**：AI Agent 能够根据用户输入的目标信息，自动规划完整的渗透测试流程，一步步执行并动态调整策略，无需人工干预。
- **多阶段渗透测试覆盖**：支持从侦察（Reconnaissance）、扫描（Scanning）、漏洞发现（Discovery）到利用（Exploitation）的完整渗透测试生命周期。
- **强大的工具链集成**：内置或可调用常见的渗透测试工具（如 Nmap、Metasploit、SQLMap、Burp Suite 等），AI Agent 可智能选择并调用合适的工具完成特定任务。
- **多种 LLM 提供商支持**：兼容 OpenAI、Anthropic、Google Gemini、AWS Bedrock、Ollama、DeepSeek、GLM、Kimi 等多种主流大语言模型，用户可根据需求选择。
- **详细记录与报告生成**：自动化记录整个渗透测试过程，包括发现的漏洞、使用的命令、输出结果等，并能够生成结构化的安全评估报告。
- **实时交互与人工干预**：用户可在 AI Agent 执行任务过程中实时查看进度，进行人工确认、添加提示或修改任务方向。

## 技术架构

PentAGI 采用模块化架构设计，核心组件包括：

- **Agent 核心引擎**：基于 LLM 的决策模块，负责理解用户意图、规划任务步骤、选择工具并解析输出结果。
- **工具执行层**：封装了各类渗透测试工具的执行环境，通过标准化的接口与 Agent 核心通信，支持本地工具调用和远程执行。
- **环境沙箱**：提供隔离的执行环境，确保渗透测试操作不会影响主机系统，同时便于管理和回滚。
- **数据持久层**：存储任务状态、中间结果、最终报告和历史记录，支持 SQLite 等轻量级数据库。
- **任务调度与监控**：管理多线程/并发任务，监控执行状态，处理超时和异常情况。

架构设计强调可扩展性：新增渗透测试工具只需实现标准化接口即可被 Agent 调用；支持多种 LLM 提供商也体现了设计灵活性。

## 安装与使用

### 安装步骤

1. **克隆项目**
```bash
git clone https://github.com/vxcontrol/pentagi.git
cd pentagi
```

2. **配置 LLM 提供方**
创建或编辑配置文件 `config.yaml`，指定你要使用的 LLM 提供方及其 API 密钥。例如使用 OpenAI：
```yaml
llm_provider: openai
openai:
  api_key: "your-openai-api-key"
  model: "gpt-4"
```

3. **运行程序**
```bash
go run main.go
```

### 最小可用示例

启动程序后，通过终端交互界面输入目标信息即可开始渗透测试。例如：

- 输入目标域名或 IP 地址：`example.com`
- AI Agent 会自动开始探测目标开放端口、服务版本、操作系统信息。
- 发现开放端口后，进一步检测是否存在已知漏洞，并尝试利用。
- 用户可以输入 `status` 查看当前进度，输入 `pause` 暂停，输入 `report` 查看已生成的报告片段。

## 适用场景

- **红队演练与安全评估**：安全团队可用 PentAGI 自动化执行对内网或外网系统的渗透测试，快速发现安全隐患，节省大量人力。
- **企业安全自查**：企业安全人员可定期使用 PentAGI 对关键业务系统进行安全扫描，及时发现并修复漏洞，提升整体安全水平。
- **安全培训与教育**：学员可通过观察 AI Agent 的决策过程，学习渗透测试的思路和技巧，加速技能成长。
- **DevSecOps 流水线集成**：可将 PentAGI 作为 CI/CD 流水线中的一个环节，在代码部署前自动执行安全测试，实现持续安全。

## 项目亮点

- **全自动化渗透测试**：与其他半自动化或需大量人工配置的安全工具不同，PentAGI 力求“输入目标，输出结果”，大幅降低使用门槛。
- **多 LLM 提供商兼容**：不绑定特定 AI 模型，用户可以自由选择性价比最高的模型，或使用本地部署的开源模型 (如 Ollama) 保证数据隐私。
- **Go 语言高性能**：采用 Go 语言开发，编译为单一二进制文件，部署简便且执行效率高，尤其适合资源受限的渗透测试环境。
- **社区驱动与开源**：项目在 GitHub 上积极维护，有活跃的 Discord 和 Telegram 社区，用户可快速获得支持并参与功能改进。
