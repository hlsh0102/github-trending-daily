## 项目概述

holehe 是一款基于 Python 的开源 OSINT（开源情报）工具，旨在通过电子邮件地址快速检测该邮箱是否在各大网站平台上注册过账号。它利用各平台的“忘记密码”功能进行非侵入式探测，能够精准判断邮箱与账号的关联性，而不会向目标邮箱发送任何通知或触发安全警报。该项目主要面向安全研究人员、渗透测试人员、隐私保护倡导者以及社交媒体调查人员，帮助他们在授权范围内高效梳理数字足迹。

## 核心功能

- **多平台覆盖**：支持检查 Twitter、Instagram、Imgur 等超过 120 个主流网站和社交平台的账号注册情况。
- **零接触探测**：完全依赖“忘记密码”功能的响应差异进行判断，不会向目标邮箱发送重置邮件或验证码，确保探测过程静默无痕。
- **异步高效并发**：基于 Python 异步框架（如 Trio 和 httpx）构建，能够并发请求多个站点，大幅缩短批量检查耗时。
- **可扩展模块化设计**：每个网站对应一个独立模块，用户可根据需求自定义添加新平台或移除已有模块，灵活适配特定场景。
- **CLI 与 API 双接口**：既提供简单的命令行工具，也可作为 Python 库嵌入其他应用中，方便自动化集成。
- **详细输出结果**：清晰展示每个网站的检查状态，包括是否存在账号、探测是否成功或站点是否可用，便于结果分析。

## 技术架构

holehe 采用轻量级异步架构，核心技术栈为 Python 3、Trio 异步框架和 httpx 异步 HTTP 客户端。项目将每个目标网站封装为独立的异步检查函数，统一接收邮箱地址、客户端对象和输出列表作为参数。整个探测流程基于对各平台密码找回接口的逆向分析——通过模拟“忘记密码”提交请求，并解析响应中的状态码、返回消息或页面特征来推断邮箱是否注册。这种设计避免了使用昂贵的爬虫或登录验证，降低了资源消耗。同时，异步模型允许所有网站检查并发执行，在保证信息准确的前提下显著提升速度。项目代码结构清晰，遵循 GPL-3.0 许可证，方便社区审计与二次开发。

## 安装与使用

**安装方式**：

- PyPI 安装：`pip3 install holehe`
- GitHub 源码安装：克隆仓库后执行 `python3 setup.py install`
- Docker 部署：构建镜像后运行容器

**CLI 最小示例**：

```bash
holehe test@gmail.com
```

执行后，holehe 会逐站显示检查结果，标记邮箱是否关联账号。

**Python 库调用示例**：

```python
import trio
import httpx
from holehe.modules.social_media.snapchat import snapchat

async def main():
    email = "test@gmail.com"
    out = []
    client = httpx.AsyncClient()
    await snapchat(email, client, out)
    print(out)
    await client.aclose()

trio.run(main)
```

用户仅需传入邮箱和选择的模块，即可将结果集成到自有工具链中。

## 适用场景

- **隐私审计**：个人用户可主动检查自己的邮箱在哪些平台留有注册痕迹，从而评估隐私暴露面，及时清理不用的旧账号。
- **安全渗透测试**：在合法授权下，测试人员利用 holehe 快速发现目标人员使用的第三方服务，为社工攻击或账号接管测试提供线索。
- **数字取证调查**：OSINT 调查人员通过邮箱关联账号，构建目标人物的在线行为画像，用于案件分析或背景调查。
- **账号风险管理**：企业安全团队可批量检查员工邮箱的外部注册情况，防止内部信息通过非授权平台泄露。

## 项目亮点

- **真正无痕探测**：与多数同类工具不同，holehe 不会触发任何邮件通知，极大降低了被检测目标发现的风险。
- **异常广泛的站点支持**：内置 120+ 常见平台，且覆盖社交、论坛、电商、开发者服务等多种类型，远超一般同类工具。
- **异步性能优势**：借助 Trio 异步框架，检查过程高效迅速，即使处理大量邮箱或站点也不会陷入阻塞等待。
- **活跃维护与社区支持**：项目在 GitHub 上拥有上万 Star，持续获得功能更新和站点模块修复，用户可快速获取新平台支持。
- **双许可模式支持**：除命令行工具外，清晰的模块接口让开发者能够轻松扩展自定义站点，适应私有化需求。
