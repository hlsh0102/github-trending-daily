## 项目概述

SpiderFoot 是一款开源情报（OSINT）自动化工具，旨在帮助安全专业人员、渗透测试人员和威胁情报分析师自动收集、分析和关联来自公开渠道的信息。它解决了安全团队在攻击面测绘和威胁情报收集过程中面临的数据碎片化问题——通过一个统一平台，将分散在互联网各处的信息源整合为结构化、可关联的情报数据。

该项目由 Robin Wood 发起并由社区持续维护，目前拥有超过 2 万个 Star，采用 MIT 许可证，使用 Python 3.7+ 编写。SpiderFoot 既可以作为独立的 Web 应用运行，也可以通过命令行接口使用，适用于从快速侦察到深度调查的多种安全场景。

## 核心功能

- **Web 界面与 CLI 双模式**：内置 Web 服务器提供直观的图形化操作界面，同时支持完全的命令行操作，满足不同用户的使用习惯。
- **超过 200 个集成模块**：覆盖域名、IP、电子邮件、用户名、组织机构等多种实体类型的查询，数据源包括搜索引擎、DNS 记录、证书透明度日志、社交平台、威胁情报源等。
- **YAML 配置的关联引擎**：内置 37 条预定义关联规则，可自动发现数据点之间的关系（如共享 IP、共同域名等），并支持自定义规则实现个性化分析。
- **多种数据导出格式**：支持 CSV、JSON、GEXF（图交换格式）导出，便于与其他工具集成或进行二次分析。
- **API 密钥管理**：支持 API 密钥的导入和导出，方便在多个实例间迁移配置。
- **SQLite 后端存储**：所有扫描结果存储在本地 SQLite 数据库中，支持自定义 SQL 查询，方便深度挖掘数据。

## 技术架构

SpiderFoot 采用事件驱动架构，核心设计围绕“扫描”（Scan）和“模块”（Module）两个抽象概念展开。一次扫描定义目标实体（如域名、IP 或邮箱）及相关参数，扫描过程由多个模块协同完成。

系统包含两种类型的模块：**用于数据收集的模块**和**用于数据分析的模块**。数据收集模块从外部数据源获取信息，分析模块则负责对收集到的数据进行处理、验证和关联。模块之间通过事件（Event）机制进行通信，每个模块可订阅特定类型的事件并生成新事件，形成灵活的数据流水线。

架构的另一个关键特点是**高度可配置性**。用户可以通过配置文件控制模块启用状态、扫描目标范围、结果过滤条件等，也可以利用内置的关联引擎规则自定义事件间的逻辑关系。这种设计使得 SpiderFoot 既能满足快速上手的需求，也能适应复杂的定制场景。

项目采用 SQLite 作为存储层，不仅保证了数据的原子性和一致性，还提供了 SQL 查询能力，便于用户直接对扫描结果进行复杂分析。TOR 集成支持通过匿名网络访问暗网资源，扩展了信息收集的边界。

## 安装与使用

### 安装步骤

SpiderFoot 支持多种安装方式，以下是基于源码安装的基本流程：

```bash
# 1. 克隆仓库
git clone https://github.com/smicallef/spiderfoot.git
cd spiderfoot

# 2. 安装依赖（推荐使用虚拟环境）
pip install -r requirements.txt

# 3. 启动 Web 界面（默认端口 5001）
python3 sf.py -l 127.0.0.1:5001
```

如需使用 Docker：

```bash
docker run -p 5001:5001 -d smicallef/spiderfoot
```

### 最小可用示例

启动 Web 界面后，浏览器访问 `http://127.0.0.1:5001`，即可进入图形化操作界面。第一次使用时需初始化数据库：

```bash
# 初始化数据库（首次运行必需）
python3 sf.py -d init
```

然后通过 Web 界面新建扫描：输入目标（如 `example.com`），选择扫描类型（如“所有模块”或“快速扫描”），点击“开始”即可。扫描完成后，可以在结果页面查看聚合数据、关联关系图和原始证据。

命令行模式则可以直接通过参数指定扫描目标和模块：

```bash
python3 sf.py -m DNS,SSL -s example.com -q
```

## 适用场景

- **攻击面检测与测绘**：安全团队可使用 SpiderFoot 对企业自有域名、IP 范围进行自动化信息收集，发现暴露的服务器、子域名、证书信息等，进而识别潜在风险面。
- **威胁情报收集与关联**：在事件响应或威胁狩猎中，分析师可输入 IOCs（如恶意域名、IP、邮件地址），SpiderFoot 会自动收集相关上下文信息并揭示关联关系，辅助溯源与研判。
- **钓鱼攻击与欺诈调查**：通过扫描邮箱、域名、社交媒体账号等实体，快速勾勒出攻击者或欺诈行为的基础设施轮廓，为执法或企业调查提供支持。
- **红队演练前的情报准备**：渗透测试团队在执行任务前，利用 SpiderFoot 进行被动侦察，收集目标的技术栈、网络结构、人员信息等，为后续主动测试打下基础。

## 项目亮点

与同类 OSINT 工具相比，SpiderFoot 的核心差异化优势体现在：

- **模块生态丰富度**：超过 200 个内置模块，覆盖绝大多数常见数据源，且社区持续贡献新的模块，避免了自行维护多工具组合的负担。
- **关联分析能力**：内置关联引擎能够自动连接不同数据点之间的关系，这是许多被动收集工具所欠缺的关键能力，能显著提升情报分析效率。
- **双模式交互设计**：同时提供完善的 Web 图形界面和完全可脚本化的 CLI 接口，兼顾了易用性与自动化集成需求。
- **配置透明与可扩展**：YAML 格式的关联规则配置和 SQLite 存储带来极高的可定制性，用户可以根据特定需求调整分析逻辑，而非受限于工具固定流程。
- **成熟的社区与文档**：项目维护活跃，拥有 Discord 社区和详尽文档，使用问题通常能获得及时支持，企业级采用风险更低。
