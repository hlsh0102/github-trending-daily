## 项目概述

FluidVoice 是一款专为 macOS 设计的开源语音转文字听写应用，致力于提供比现有商业解决方案（如 Wispr Flow）更快速、更注重隐私的本地听写体验。项目采用完全离线的自动语音识别（ASR）方案，并搭载了自定义训练的 AI 增强模型，在保护用户数据不外传的同时，实现接近实时的高精度文本输出。其核心目标用户包括内容创作者、程序员、医生、律师等需要大量文字输入的专业人士，以及对语音输入隐私性有严格要求的用户。

## 核心功能

- **全离线端侧 STT**：语音识别完全在本地设备完成，无需联网，杜绝音频数据上传风险，从根源上保障用户隐私。
- **自定义 AI 增强模型**：在基础识别结果之上，通过针对中英文混合、专业术语、口语习惯等场景专门训练的大模型进行二次处理，显著提升标点、断句和文字润色的准确度。
- **多引擎支持**：内置对 Nemotron Speech 3.5、NVIDIA Parakeet Flash/v3/v2、Cohere、Apple Speech、Whisper 等多种主流识别模型的支持，用户可根据设备性能在准确率和速度间自由权衡。
- **极低延迟交互**：利用实时端点检测（EOU）技术与流式处理管线，从说话结束到文字上屏的响应时间控制在亚秒级，大幅优于传统云端转写方案。
- **系统级全局唤起**：支持菜单栏常驻与自定义全局快捷键，在任何应用中均可一键呼出听写框，输出结果直接注入当前光标所在位置。
- **简洁原生体验**：基于 Swift 开发的轻量级应用，严格遵循 macOS 人机交互设计规范，对系统资源占用极小，常驻内存占用低于 100MB。

## 技术架构

FluidVoice 采用 Swift 原生栈构建，工程上划分为录音采集模块、推理调度模块和后处理增强模块三个层次。录音层利用 CoreAudio 的音频单元实现高质量采集并进行本地降噪预处理。推理层则通过动态加载技术将 XetHub 上的模型权重缓存至本地，并支持根据当前设备芯片（Apple Silicon/Intel）自动切换 Metal GPU 或 ANE 神经引擎加速，以最大化推理吞吐量。

项目的技术亮点在于其双阶段处理管线：第一阶段由快速 ASR 模型（如 Parakeet Flash）完成逐字块识别，第二阶段由自训练的 LLM 增强模型进行上下文纠错与格式优化。这种设计参考了端到端级联架构，既避免了单一大模型带来的高延迟，又解决了小型 ASR 模型在标点恢复与同音字纠错上的短板。此外，应用内置了针对不同声学场景的适配器，可动态调整波束搜索的宽度，在强噪环境下优先保证准召率，在安静环境下换取更低延迟。

## 安装与使用

**系统要求**：macOS 13.0 或更高版本，推荐 Apple Silicon 芯片。

安装方式一（Homebrew Cask）：

```bash
brew install --cask fluidvoice
```

安装方式二：直接从 [GitHub Releases](https://github.com/altic-dev/FluidVoice/releases/latest) 页面下载 dmg 文件，拖入应用程序文件夹。首次启动时，应用会引导下载所选的识别模型（约 150MB–1.5GB）。

**最小使用流程**：

1. 启动 FluidVoice，在菜单栏点击图标，进入设置选择所需的 STT 引擎（默认推荐 Parakeet Flash 以获得速度与精度的平衡）。
2. 在系统设置 > 隐私与安全性 > 麦克风中授权给 FluidVoice。
3. 设定一个全局快捷键（例如双击 ⌥ 键），在任意文本编辑器中按下快捷键即可开始说话，说完后自动转为文字并输入。

命令行方式启动：

```bash
open -a FluidVoice
```

## 适用场景

医疗与法律文书**：律所或医院对数据敏感，FluidVoice 的纯离线特性允许在涉密环境中进行长文档听写，同时 AI 增强模型能够准确补全法律/医学术语，显著减少手动校对时间。

编程与开发者写作**：程序员在撰写代码注释、设计文档或回复邮件时，通过全局快捷键快速输入自然语言，无需切换应用窗口，极大提升工作流连贯性。

远程会议与采访记录**：在 Zoom、飞书等会议软件中使用本地听写，会议结束后即可获得较干净的会议纪要草稿，且无需担心第三方语音服务存储会议敏感内容。

外语学习与双语写作**：内置模型对多语言混合（如中英夹杂）有专门优化，适合需要频繁交替使用两种语言的用户进行演讲稿或学术论文写作。

## 项目亮点

与市场现有方案相比，FluidVoice 的差异化优势主要体现在三个层面：第一，性能上针对 Apple Silicon 做了深度指令集优化，实测比 Whisper.cpp 的同等模型推理速度快约 3.5 倍，且不消耗网络带宽；第二，产品的开放生态策略——不同于 Wispr Flow 的闭源订阅制，FluidVoice 采用 GPL-3.0 许可，允许开发者替换核心模型或接入私有 API，甚至修改 UI 以适配专业工作流；第三，成本控制透明化，完整功能不收取订阅费用，且推理所需的硬件仅为 Mac 自带设备，不存在按量计费的后顾之忧。GitHub 上近万颗星及持续走高的趋势也侧面印证了社区的认可度。
