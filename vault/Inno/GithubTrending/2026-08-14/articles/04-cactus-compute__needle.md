## 项目概述

Needle 2 是一个面向资源受限设备的开源基础模型，专注于工具调用、设备控制与结构化信息提取。整个模型以单个 14MB 的二进制文件形式分发，能够在约 28MB 内存中完成完整会话推理，专为手机、可穿戴设备、智能家居和机器人等微小设备设计。

该项目由 cactus-compute 团队开发，基于其此前提出的 Simple Attention Network（简单注意力网络）研究成果构建，模型参数规模为 4500 万。与同量级竞品相比，Needle 2 在保持相近基准性能的同时，体积缩小 5 至 70 倍，并将权重压缩至 2-bit 精度。

本仓库为 Python 包，提供推理、LoRA 微调和模型导出能力。用户只需执行 `pip install cactus-needle`，描述工具接口，即可在 Python 环境中调用模型完成工具调度。

## 核心功能

- **完全自包含**：模型权重直接烘焙进单个 14MB 的引擎文件中，无需单独管理模型文件，推理过程完全离线、不依赖网络。
- **简洁的数据契约**：文本输入、JSON 输出，工具调用结果以结构化数据返回。系统会根据用户提供的 Schema 编译字节级语法，逐 token 约束模型输出，确保格式正确。
- **置信度门控**：模型每次输出都附带一个经过校准的置信度分数（由专门学习得到的头部分生成）。开发者可设置阈值，高于阈值时自动执行系统动作，低于阈值时转人工处理。
- **工具检索机制**：支持声明大型工具目录，内置检索头每次仅将最相关的五个工具渲染给模型，并将语法约束限定在该子集内，既节省计算资源又提升准确性。
- **有界内存占用**：采用 256 token 的滑动窗口机制，工具定义作为 KV 缓存固定驻留，无论对话多长，总内存始终稳定在 28MB 附近。

## 技术架构

Needle 2 的底层架构基于团队自研的 Simple Attention Network（SAN）。与标准的 Transformer 注意力机制相比，SAN 大幅简化了计算路径，在保持推理质量的前提下显著降低参数量与计算复杂度。

模型的精度压缩采用了名为 Cactus Quants 的量化方案，将权重降至 2-bit（CQ2），这是模型能达到 14MB 体积的关键技术支柱。2-bit 量化通常会导致严重的精度损失，但通过架构适配与训练策略调整，Needle 2 在基准测试中仍能与 270M、230M 等规模远大于自身的模型互有胜负。

推理引擎被直接烘焙进权重文件，形成一个自包含的运行时。该引擎从 Hugging Face 仓库一次性获取并缓存于本地，后续调用无需重复下载，也无编译环节。模型内部将工具描述作为 KV sink（固定锚点）与滑动窗口结合，实现了长对话场景下的内存恒定，这一设计在嵌入式场景中极具实用性。

## 安装与使用

安装过程十分简洁，只需通过 pip 安装 Python 包即可：

```bash
pip install cactus-needle
```

首次执行时会自动从 Hugging Face 获取引擎文件并缓存，后续使用完全离线。

最小使用示例如下（基于 README 描述的模式）：

```python
import needle

# 声明你的工具描述（示意）
tools = [
    {
        "name": "set_temperature",
        "description": "设置房间温度",
        "parameters": {"type": "object", "properties": {"value": {"type": "number"}}}
    },
    # ... 更多工具
]

# 初始化模型，传入工具目录
client = needle.Client(tools=tools, mode="call")

# 发起对话并获得结构化输出
response = client.chat("请把客厅温度调到 24 度")
# response.tool 为解析出的 JSON 动作
# response.confidence 为置信度分数
```

如需针对特定任务进行微调，仓库提供 LoRA 微调脚本，支持在低算力设备上完成领域适配。模型导出接口则允许开发者将微调后的模型重新烘焙为自包含引擎。

## 适用场景

- **智能家居设备**：在智能音箱、温控器、智能门锁等设备上本地运行，实现语音指令的设备控制与场景联动，无需云端依赖。
- **可穿戴设备**：在手表、手环等内存为数十 MB 级别的设备上执行意图识别、信息抽取等任务，适用于离线快速响应。
- **机器人端侧决策**：为小型机器人提供工具调用与任务规划能力，在无网络环境中完成结构化操作。
- **边缘数据抽取**：在传感器网关或嵌入式终端上直接从文本日志中抽取结构化信息，减少数据传输成本。

## 项目亮点

- **极致体积与精度的平衡**：在 45M 参数规模下实现接近 270M 级别模型的效果，2-bit 量化与 SAN 架构的组合是同类竞品中少有的技术方案。
- **端侧可微调**：通过 LoRA 实现低资源微调，使专用设备使用者能够以极低成本定制模型行为，这在如此小体量的模型中并不多见。
- **工程完整性极高**：单一二进制、零网络依赖、恒定内存、置信度输出，每一项都直击边缘设备的真实痛点，而非单纯追求模型指标。
- **开源许可友好**：项目以 MIT 许可证发布，允许商业使用与二次开发，降低了集成门槛。
