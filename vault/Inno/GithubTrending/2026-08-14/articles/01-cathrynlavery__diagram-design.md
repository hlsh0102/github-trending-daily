## 项目概述

diagram-design 是一个面向 Claude Code、Codex 和 Pi 等 AI 编程工具的 Agent Skill 项目，提供 29 种编辑级图表类型。项目核心目标是解决 AI 生成图表时常见的“工具味”过重问题——那些带有阴影、圆角渐变和模板化配色的 Mermaid 或 draw.io 导出图，往往无法直接用于正式文档、博客或客户演示。该项目将图表封装为自包含的 HTML + SVG 文件，无需任何外部依赖或 Figma 类设计工具，即可生成具有杂志排版水准的静态图表。项目主要面向技术写作者、独立开发者、产品经理以及任何需要在文档或交付物中嵌入高质量图表的创作者。

## 核心功能

- **29 种编辑级视觉类型**：涵盖架构图、流程图、金字塔图、时间线、循环/飞轮图等常见图表类型，每种都经过刻意设计，确保视觉密度和排版规范符合出版物标准。
- **语义模式驱动布局**：新的 v2.3 版本将行为语义（如队列、策略追踪、信任边界）从具体布局中解耦，使同一类型可自适应多种表达场景，无需无限增加类型数量。
- **自包含 HTML + SVG 输出**：所有图表均生成独立文件，复制即用，可嵌入任意 Markdown、HTML 或演示文稿中，无任何外部脚本或样式依赖。
- **静态输出为默认，可选有序动画**：默认输出始终为静态 HTML，适合打印和正式文档；仅当需要逐步讲解时，可启用内置的轻量级运动效果。
- **Mermaid / draw.io 源码重绘**：直接以 AI 生成或已有的 Mermaid 代码或 draw.io 源文件作为输入，按指定格式、尺寸和细节级别进行“重绘”，显著提升视觉质量。
- **跨代理工具兼容**：同一份 skill 定义可无缝应用于 Claude Code、Codex 和 Pi，无需针对不同平台重复调整。

## 技术架构

项目以 Agent Skill 为分发单元，全部内容由手写 HTML 与内联 SVG 构成，放弃使用任何图表生成库或重型前端框架。这种架构的核心设计思路是“静态优先”——保证生成的每个图表文件都是无状态的纯文档，从而保持可移植性和长期可存档性。语义模式的设计则通过描述性标签（data-semantic 属性）将图表意图与几何表达分离，让同一套代码库可以稳定支持不断增长的表达需求。同时，项目保留了从 Mermaid 和 draw.io 源码转换的解析层，利用 LLM 的代码理解能力将语义结构映射到本项目的视觉模板，从而实现对既有工作流的平滑替代。代码风格上，项目刻意规避阴影、渐变、圆角大盒子等现代 UI 元素，以等线字体、简约线框和克制配色实现编辑设计语言。

## 安装与使用

安装使用需配合支持 Agent Skills 的 AI 编程环境。以 Claude Code 为例：

1. 将 `diagram-design` 的 skill 文件夹链接到 Claude Code 的插件目录（具体路径参考官方文档）。Codex 和 Pi 的安装方式类似，均通过环境变量或配置文件注册 skill 路径。

2. 在对话中直接请求生成图表，例如：

```
> 在项目 README 中生成一张描述 CI/CD 流水线的时序图，风格使用 editorial，输出为静态 HTML。
```

3. 如需将现有 Mermaid 图转为此风格，只需给出 Mermaid 源码并附带重绘要求：

```
> 将这段 Mermaid 流程图重绘为高清时间线，尺寸 1200x800，细节等级为高。
```

4. 生成的 HTML 文件可直接用浏览器打开，或嵌入到文档系统中。若需要动效，只需在请求中声明“enable motion”并指定讲解顺序。

## 适用场景

- **技术文档与 README**：为开源项目或内部系统撰写结构清晰的架构说明、数据流图或依赖图谱，让文档直接具备出版物般的专业感。
- **客户交付物与提案**：在咨询报告、项目提案或战略规划中嵌入无版权负担、风格统一的自绘图表，避免使用剪贴画风素材。
- **博客与内容创作**：个人博主或独立编辑可快速生成高质量配图，无设计软件依赖，整个流程可完全在 AI 对话中完成。
- **教学与培训材料**：用于制作课程讲义中的概念模型图、对比图或流程图，静态输出便于打印和二次编辑。

## 项目亮点

与通用的 Mermaid 或 draw.io 插件相比，diagram-design 的最大优势在于视觉质量的跨越式提升。它从设计系统层面规避了 AI 生成图表的“廉价感”，通过限制设计元素种类强制形成统一风格，结果高度接近专业设计师的作品。其次，语义与布局分离的设计极具前瞻性，使得有限类型数量能覆盖近乎无限的信息表达需求，而不会导致类型爆炸。再次，自包含输出文件的特性，消除了云服务、账户或网络依赖，完全尊重文档的本地性和私密性。最后，该项目支持跨主流 AI 编程工具即时复用，并在一天内获得 4000+ 星标增长，说明了开发者社区对高质量 AI 辅助输出的强烈需求与认可。
