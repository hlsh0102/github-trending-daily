## 项目概述

Macro 是一个面向团队的全合一工作空间，旨在将电子邮件、即时消息、文档、任务管理、AI 代理、通话和 CRM 统一到一个快速、连贯的界面中。该项目由 macro-inc 团队开发，用 Rust 语言编写，采用 AGPL-3.0 许可证开源，目前在 GitHub 上已获得超过 2600 颗星。

Macro 的核心理念是构建一个团队的"操作系统"。作者在运营上一家创业公司时，团队扩张到约 20 人后，发现同时使用 Slack、Linear、Notion、HubSpot 和 Superhuman 等多个工具导致了严重的效率问题——各个工具之间互不连通，团队被各种 MCP 和 Zapier 集成拼凑在一起，整体运转变得"不可计算"。Macro 正是对这一痛点的彻底重新设计，目标是让团队不再需要在多个应用之间切换，所有工作数据都能通过 @ 提及相互关联，并共享团队级别的 AI 记忆。

## 核心功能

- **统一通信**：将电子邮件和即时消息整合到同一个收件箱视图中，支持无缝切换，用户无需在邮件客户端和聊天工具之间来回跳转。
- **文档与知识库**：内置文档编辑功能，支持团队协作编辑，所有文档可通过 @ 提及与其他工作项关联。
- **任务管理**：提供项目任务创建、分配、跟踪和提醒功能，任务可与邮件、聊天记录、文档等上下文链接。
- **内置 CRM**：客户关系管理功能直接集成在工作台中，联系人信息与所有相关沟通记录自动关联。
- **AI 代理支持**：平台设计为 AI-first，支持创建和部署代理，代理可访问统一的团队记忆库来辅助完成工作。
- **共享团队记忆**：所有工作数据（邮件、消息、文档、任务）在团队级别统一索引和存储，支持全局搜索，并可被 AI 代理引用。

## 技术架构

Macro 使用 Rust 作为主要开发语言，这为系统带来了高性能和内存安全的保证。前端采用现代 Web 技术构建，后端服务架构设计为支持实时通信和快速数据检索。

项目的关键架构特点包括：

- **统一数据层**：所有工作对象（邮件、消息、文档、任务、联系人）都有标准化的数据模型，并在底层互通，这是实现 @ 链接和全局搜索的基础。
- **实时同步引擎**：基于 Rust 的高并发能力，确保多用户协作时的数据一致性和低延迟体验。
- **AI 集成层**：系统设计为 AI-ready，代理可以访问统一的索引数据，并且搜索结果和 AI 响应都基于团队共享记忆而非孤立的单个应用数据。
- **可扩展接口**：虽然核心是统一工作空间，但系统架构允许通过 API 和集成扩展外部服务。

## 安装与使用

目前 Macro 主要提供 SaaS 云服务，用户可通过官网注册访问。对于希望自托管或参与开发的用户，可以按照以下方式获取项目：

**从源码构建（适用于开发者）**

```bash
# 克隆仓库
git clone https://github.com/macro-inc/macro.git
cd macro

# 安装 Rust 工具链（如已安装可跳过）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 构建项目（具体构建命令请参考仓库 CONTRIBUTING.md 文档）
cargo build --release
```

**快速体验**

1. 直接访问 [Macro 官网](https://macro.com/app) 注册账号。
2. 按照引导连接你的邮箱、导入联系人，并邀请团队成员。
3. 开始创建文档、任务，并通过 @ 提及将不同工作项关联起来。
4. 在设置中启用 AI 代理功能，让代理基于团队记忆辅助日常工作。

完整的使用指南和开发文档请参考官方文档站 [docs.macro.com](https://docs.macro.com)。

## 适用场景

- **初创团队全流程管理**：人数在 5–50 人之间、希望用一个工具覆盖内部沟通、客户管理和项目交付的团队，可以显著减少工具切换带来的信息碎片化。
- **客户支持与售后团队**：CRM 与邮件、聊天记录的深度集成，使得支持人员能在同一个界面中查看客户全貌、历史沟通记录和相关任务。
- **AI 驱动的知识管理**：对于希望在团队内部署 AI 代理来辅助信息检索、内容生成和任务自动化的组织，Macro 的统一索引和记忆机制提供了理想的基础设施。
- **寻求替代多工具订阅的团队**：当前订阅 Slack、Notion、HubSpot 等多个独立服务的团队，可以通过 Macro 整合预算，并享受更紧密的数据联动。

## 项目亮点

Macro 最核心的差异化优势在于其"系统性"而非"集成性"。不同于使用 MCP 或 Zapier 将多个独立工具拼接在一起，Macro 从底层数据模型开始就是统一设计的，这意味着：

- **真正意义上的全局记忆**：AI 代理和搜索功能引用的是一个完整的、跨应用的团队知识库，而非被工具边界割裂的数据孤岛。
- **零切换成本**：由于所有功能原生集成，界面响应速度快，用户体验一致，无需学习不同应用的操作逻辑。
- **高性能保障**：基于 Rust 构建的后端在处理大量并发操作时表现稳定，尤其适合对响应速度要求高的实时沟通场景。
- **开放性**：采用 AGPL-3.0 许可证，鼓励社区参与开发和自托管部署，同时官方也积极招募人才和技术贡献者。
