## 项目概述

Archify 是一款面向 AI 编程助手的 Node.js 渲染与验证系统，专为 Cursor、Claude Code、Codex CLI 和 OpenCode 等智能编码环境设计。它能够将代码库或系统描述直接转化为精美、可交互的系统地图——无需离开聊天界面，即可生成架构图、流程图、时序图、数据流图和生命周期图。

该项目解决了开发者在 AI 辅助编码过程中面临的一个核心痛点：当 AI 生成代码或重构建议时，往往缺乏对系统整体架构的可视化理解。Archify 通过引入**类型化 JSON 中间表示（IR）**和确定性编译机制，让 AI 代理能够生成规范的图表描述，再由引擎将其编译为自包含的 HTML/SVG 文件。这些文件可直接在浏览器中打开、演示，或导出为 PNG、SVG、WebM 及 1200×630 的分享卡片。

项目当前版本为 v2.16.0-dev.0，采用 MIT 许可证，在 GitHub 上已获得超过 25,000 颗星标，并在 Trendshift 排行榜上有亮眼表现。

## 核心功能

- **五种图表类型**：支持架构图、流程图、时序图、数据流图和生命周期图，覆盖软件系统设计的主要可视化需求。
- **四种预设与主题**：内置四个视觉预设方案，支持深色/浅色主题切换，并配备品牌标识元素与克制的动态效果，适合正式演示场景。
- **架构变更对比**：支持将两个已验证的快照进行 Before / Delta / After 三态对比，精确呈现新增、删除、修改、移动和重路由的变更事实，帮助团队在合并代码前审阅架构调整。
- **交互式探索**：可搜索节点、打开经修订验证的源码文件、追踪上游/下游的关联关系与精确路由、对比角色定义，以及播放引导式讲解——所有交互都基于真实的拓扑数据，杜绝虚构内容。
- **单文件交付**：类型化 JSON IR 与确定性检查机制产出自包含 HTML 文件，同时支持导出 PNG、SVG、WebM 视频和社交媒体分享卡片。
- **多平台支持**：作为 Agent Skill 集成于 Cursor、Claude Code、Codex CLI 和 OpenCode 等多种主流 AI 编码工具。

## 技术架构

Archify 的核心设计理念是**“由数据驱动”**。整个系统分为三个层次：

**第一层是输入协议层。** AI 代理（或开发者）按照严格的 TypeScript 类型定义生成 JSON IR 文件。这些类型定义了节点、边、层级、角色、生命周期等概念，确保任何代理产出的描述都遵循一致的模式。

**第二层是编译与验证层。** Node.js 引擎读取 JSON IR，执行一系列确定性校验（如检查重复节点、非法引用、孤立拓扑等），然后将其编译为结构化的 HTML/SVG 输出。这一层完全确定性——相同的输入必然产生相同的输出，保证了结果的可复现性和可审计性。

**第三层是渲染与交互层。** 生成的 HTML 文件包含全部样式、脚本和字体资源，不依赖外部 CDN，可在离线环境下完美运行。内置的交互引擎支持搜索、悬停高亮、路径追踪和引导式故事播放，所有交互逻辑都围绕真实的图数据实现。

架构上的关键决策包括：选择 SVG 而非 Canvas 以获得更好的无障碍性和可搜索性；采用自包含单文件输出以简化分发和存档；以及使用确定性编译而非模板字符串拼接，从而保证输出的可验证性。

## 安装与使用

Archify 以 Agent Skill 的形式分发，安装过程因目标平台而异：

**对于 Cursor 或 Claude Code：**

```bash
# 克隆仓库到本地 skills 目录
git clone https://github.com/tt-a1i/archify.git
# 将 archify 目录复制到项目的 .cursor/skills/ 或 .claude/skills/ 下
```

**对于 Codex CLI 或 OpenCode：** 遵循对应平台的 Agent Skill 安装规范，将项目目录链接到技能目录。

**最小使用示例：**

在支持 AI 编码的环境中，向代理发出指令：

```
使用 Archify 绘制当前代码库的架构图
```

代理会生成 JSON IR 描述，Archify 引擎自动编译为 HTML 文件，并输出保存路径。开发者打开对应的 HTML 文件即可查看并交互。

对于开发人员，也提供了 CLI 直接使用方式：

```bash
node archify.js compile input.ir.json -o output.html
```

支持的输出格式包括：`html`（默认）、`png`、`svg`、`webm` 和 `card`（社交媒体分享卡）。

## 适用场景

**代码评审与变更审计：** 在合并 PR 前，使用 Before / Delta / After 对比功能可视化架构层面的变更，帮助评审者快速理解改动的影响范围。

**系统设计与演示：** 架构师在会议中使用 Archify 生成的高保真系统地图进行讲解，支持主题切换、品牌定制和引导式故事播放，无需额外准备幻灯片。

**AI 辅助重构：** 当 AI 代理提出重构建议时，开发者可要求生成对应的架构图，直观评估新方案与现有结构的差异，降低大范围改动的不确定性。

**团队知识沉淀：** 将项目核心架构以自包含 HTML 文件的形式归档，新成员无需搭建环境即可在浏览器中探索系统全貌，支持追溯源码链接。

## 项目亮点

Archify 与同类图表生成工具相比，最突出的差异化优势在于**“可验证性”**。现有方案（如 Mermaid、PlantUML）虽然也能生成图表，但由 AI 产出的描述经常包含拓扑错误或虚构连接。Archify 通过类型化 IR 和确定性校验机制，从源头杜绝了这类问题——代理无法生成语义错误的图，因为验证层会在编译阶段拦截所有非法拓扑。

其次，**单文件交付**策略极大降低了使用门槛。生成的 HTML 不依赖网络资源，可以嵌入内部 Wiki、通过邮件分发或在演示环境中离线运行。配合 PNG/SVG/WebM 多种导出格式和专用的分享卡片尺寸，使得图表能够无缝融入现有工作流。

第三，**交互深度**远超同类工具。大多数静态图表工具仅支持简单的缩放平移，Archify 内置了节点搜索、路径追踪、角色对比和引导式故事等高级交互，将所有功能打包在一个文件中，无需后端服务。
