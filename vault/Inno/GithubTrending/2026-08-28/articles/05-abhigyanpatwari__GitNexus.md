## 项目概述

GitNexus 是一款运行在浏览器中的零服务器代码智能引擎，由 Akon Labs 开发。它能够在客户端本地为代码仓库构建知识图谱，并内置了基于图谱的 RAG（检索增强生成）智能代理，帮助开发者快速探索和理解任意规模的代码库。用户只需将 Git 仓库（支持 GitHub、GitLab、Azure Repos 或本地目录）或 ZIP 压缩包直接拖入浏览器，即可获得一个可视化的交互式代码知识图谱，并通过自然语言与代码进行对话式交互。该项目主要面向需要快速上手陌生代码库的开发者、进行代码审查的技术负责人，以及希望深入理解复杂项目架构的技术爱好者。GitNexus 尤其适合那些对代码隐私有严格要求、不希望将代码上传至第三方服务器的用户，因为所有处理均在浏览器本地完成。

## 核心功能

- **零服务器架构**：整个代码分析、图谱构建和检索过程完全在浏览器客户端执行，无需安装后端服务，不需要配置任何 API 密钥，代码数据不出本地，杜绝了代码泄露风险。
- **多源代码导入**：支持直接导入 GitHub、GitLab、Azure Repos 等远程仓库，也支持上传本地 Git 仓库或任意 ZIP 压缩包，覆盖了开发者日常使用的主要代码获取方式。
- **交互式知识图谱**：自动解析代码中的模块、函数、类、变量及其调用关系，生成可视化的知识图谱。图谱支持缩放、平移、点击节点查看详细信息，并且可以使用多种布局算法（如层次布局、力导向布局）调整视图。
- **Graph RAG 智能对话**：内置检索增强生成代理，用户可以使用自然语言提问（例如“这个项目中身份验证是如何实现的？”），系统会基于知识图谱进行检索和推理，返回带引用的精准答案，并高亮显示相关代码节点。
- **智能搜索与导航**：支持按名称、类型、标签等条件快速定位代码元素，同时提供类似 IDE 的“跳转到定义”“查找引用”等导航能力，帮助开发者快速在代码中定位目标。
- **跨平台与工具链集成**：提供 npm 包安装方式，支持通过 Command Line Interface（CLI）在本地启动服务，也可直接通过浏览器使用在线版本，后续还计划支持 VS Code 插件等集成方式。

## 技术架构

GitNexus 的核心架构建立在现代 Web 技术与图数据库概念之上。前端采用 TypeScript 构建，使用 React 进行界面渲染。代码解析方面，项目利用了树状数据结构（如 `tree-sitter`）来快速生成语法抽象树（AST），进而提取代码中的符号定义与引用关系。在性能优化上，GitNexus 引入了 **Code Splitting** 和 **Streaming Processing** 策略，将大型仓库的解析任务拆分为多个可并行的子任务，并优先分析用户当前关注的目录，从而显著缩短了图谱构建时间。

知识图谱的存储采用**内存中的图数据库**（基于 `graphology` 等库），节点代表文件、函数、类、变量等实体，边代表导入、调用、继承等关系。图谱构建完成后，系统会为每个节点计算描述性嵌入向量，用于后续的语义检索。Graph RAG 模块采用“检索-增强-生成”的经典框架，先通过图谱遍历和向量相似度计算召回相关代码片段，再将片段上下文拼接后交由大语言模型生成最终回答，同时返回所引用的图谱节点，确保答案的可追溯性。

项目还设计了**支持多语言**的解析器接口，目前内置了对 JavaScript、TypeScript、Python、Java、Go 等主流语言的支持，并预留了自定义解析器的扩展点。整体设计遵循 **PWA（渐进式 Web 应用）** 规范，支持离线使用。所有索引数据均保存在浏览器本地（如 IndexedDB），用户关闭页面后再次打开可以直接恢复之前的图谱状态。

## 安装与使用

GitNexus 提供了多种使用方式，从零配置的在线版本到本地自定义部署，都非常便捷。

**方式一：直接使用在线版本**

访问 GitNexus 的线上演示地址，进入页面后将 GitHub 仓库地址粘贴到输入框，或直接将本地文件夹/ZIP 文件拖放到页面中，系统即会自动开始解析并生成知识图谱。

**方式二：通过 npm 本地启动**

```bash
# 全局安装
npm install -g gitnexus

# 启动本地服务
gitnexus start

# 默认会在 http://localhost:3000 启动服务
```

随后在浏览器中打开上述地址，即可使用本地版本进行代码分析。

**方式三：作为前端组件嵌入（最小示例）**

```typescript
import { createGitNexus } from 'gitnexus';

// 初始化实例
const gitnexus = createGitNexus({
  container: document.getElementById('app'),
  onReady: (graph) => {
    console.log('知识图谱构建完成，包含节点数：', graph.nodes().length);
  },
});

// 加载本地仓库（假设用户已提供文件选择器）
const fileInput = document.getElementById('zip-upload');
fileInput.addEventListener('change', (e) => {
  gitnexus.loadLocalArchive(e.target.files[0]);
});

// 提问
gitnexus.ask('这个项目如何实现用户认证？').then((answer) => {
  document.getElementById('answer').innerText = answer.text;
});
```

## 适用场景

- **新员工入职与代码溯源**：当开发者加入一个新团队或接手一个历史遗留项目时，使用 GitNexus 可以在几分钟内掌握项目的整体结构、核心模块间的关系以及关键业务逻辑的实现路径，显著缩短“上手指南”的编写与学习周期。
- **复杂系统架构评审**：在进行代码重构、技术选型或架构调整前，技术负责人可以通过知识图谱直观地审视模块耦合度、循环依赖、以及不合理的函数调用链，为架构决策提供数据支撑。
- **开源项目快速探秘**：对于需要评估一个开源项目是否适合引入的开发者，或者希望快速找到某个特定功能实现代码的贡献者，GitNexus 允许不克隆整个仓库到本地，直接在云端仓库上下文上进行探索。
- **离线环境下的代码审计**：在涉及保密项目或安装在隔离网络中的代码审计场景中，利用本地处理能力避免外传代码数据，同时借助 Graph RAG 进行自然语言驱动的合规审查。

## 项目亮点

- **真正的零服务器部署**：与依赖后端服务和向量数据库的同类方案（如 GitHub Copilot Workspace、Sourcegraph 等）不同，GitNexus 将所有计算下沉至浏览器，用户无需购买昂贵的基础设施即可享受完整的代码理解能力。
- **隐私与安全优先**：代码数据从不离开浏览器，从根本上消除了上传至第三方服务器带来的数据泄露风险，这一点对于金融、医疗等强监管行业尤为重要。
- **跨越 IDE 隔离的知识图谱**：大多数 IDE 插件仅提供针对单一项目的索引，GitNexus 以仓库为单位生成独立知识图谱，使得在 Web 端、文档、聊天工具中分享和协作成为可能。
- **高扩展性与可嵌入性**：作为一款 npm 库，开发者可以将其灵活嵌入到自有工具链中，例如结合 CI/CD 生成架构报告，或作为内部代码问答平台的核心引擎。
- **活跃的社区与持续迭代**：项目在 GitHub 上获得了极高的关注度（目前已超过 4.6 万 Star），社区用户积极参与反馈和贡献，保证了功能的快速演进与缺陷的及时修复。
