## 项目概述

JetBrains 推出的 `go-modern-guidelines` 是一个专门为 AI 编码助手设计的指导性仓库，旨在帮助各类代码智能体编写更符合现代 Go 语言实践的高质量代码。该仓库的核心是一套精心整理的指南，覆盖了从 Go 1.0 到 Go 1.27 版本中最具实用价值的语言特性和标准库增强功能。

在实际开发中，无论是 GitHub Copilot、JetBrains AI Assistant 还是其他基于大语言模型的编码工具，生成的 Go 代码往往倾向于使用过时的语法模式。例如，一个没有经过训练的 AI 模型可能会使用传统的 `for i := 0; i < n; i++` 循环，而不是更简洁的 `for i := range n`；使用手写的 if-else 判断来处理空值，而非 `cmp.Or` 这样的现代工具函数。这个项目正是为了解决这一问题而生，目标用户是所有希望提升 Go 代码质量的 AI 编码工具使用者，以及 Go 语言开发者本身。

## 核心功能

- **版本感知的代码建议**：自动检测项目 `go.mod` 中声明的 Go 版本，仅建议该版本及之前可用的语言特性和标准库函数，避免生成当前项目无法编译的代码。

- **现代语法模式库**：提供大量从 Go 1.0 到 1.27 的语法模式对照，例如使用 `max(a, b)` 替代 if-else 比较、`slices.Contains` 替代手动遍历、`cmp.Or` 替代链式空值检查等。

- **最新特性覆盖**：包含 Go 1.26 等最新版本的新特性，如 `new(42)` 直接创建指向值的指针、`errors.AsType[T](err)` 进行类型安全的错误匹配等，确保 AI 模型能第一时间掌握前沿语法。

- **与 `modernize` 分析器协同**：指南内容覆盖了 Go 官方 `modernize` 分析器涉及的所有代码现代化规则，二者相互补充，共同提升代码质量。

- **结构化的技能文档**：仓库中的 `SKILL.md` 文件采用结构化格式编写，方便各种 AI 编码系统直接加载和使用这些指导规则。

- **持续更新**：指南内容随 Go 语言版本的发布持续同步更新，始终覆盖最新版本的功能，不会像模型训练数据那样存在滞后性。

## 技术架构

项目的技术架构围绕一个核心理念：将 Go 语言的最佳实践以可操作、可检索的格式提供给 AI 模型。其实现方式包括：

- **结构化 Markdown 文档**：核心指南存放在 `plugin/skills/use-modern-go/SKILL.md` 文件中，采用 Markdown 格式编写，方便解析和处理。这种格式既能被人类开发者阅读，也能被 AI 系统直接作为上下文信息加载。

- **版本驱动的内容组织**：所有建议都按 Go 语言版本进行组织和标注，使得内容可以按需动态加载。AI 编码代理通过读取项目的 `go.mod` 文件来确定目标版本，然后引用适合该版本的语法特性，确保生成的代码能顺利编译运行。

- **轻量化的集成方式**：仓库并不强制要求特定的 AI 工具或开发环境，而是提供一种通用的知识注入机制。用户可以将这个 SKILL 文件配置到任何支持外部知识输入的 AI 编码工具中，无需复杂的安装流程。

- **与现代 Go 工具链对齐**：指南内容与 `gopls`、`go vet` 等官方工具的分析逻辑保持一致，特别是 `modernize` 分析器的规则，确保 AI 生成的代码能够通过官方工具的质量检查。

## 安装与使用

该项目的使用方式非常灵活，支持多种集成场景：

**作为通用知识文件加载**

最简单的方式是直接获取 `SKILL.md` 文件，并将其内容注入到你的 AI 编码工具中：

```bash
# 克隆或下载仓库
git clone https://github.com/JetBrains/go-modern-guidelines.git

# 将 SKILL.md 文件添加到你的 AI 工具配置中
# 具体的集成方式取决于你使用的工具，例如：
# - 对于 JetBrains AI Assistant，可以添加到项目级提示词中
# - 对于其他支持自定义指令的工具，将文件内容粘贴到系统提示中
```

**最小可用示例**

假设你正在使用一个支持自定义指令的 AI 编码工具，通过在系统提示或项目说明中添加以下内容即可使用：

```markdown
你是一名 Go 语言专家。在生成代码时，请遵守以下现代 Go 实践：
- 使用 `for i := range n` 而非 `for i := 0; i < n; i++`
- 使用 `slices.Contains` 替代手写循环
- 使用 `errors.AsType[T](err)` 进行类型安全的错误处理
- 优先使用标准库中的现代函数，避免不必要的第三方依赖
- 确保使用的所有特性都兼容项目 go.mod 中声明的 Go 版本
```

**集成到 CI/CD 流程**

对于追求代码质量一致性的团队，可以将指南作为静态检查的一部分，将 AI 生成的代码与指南规则进行自动比对，识别不符合现代实践的部分。

## 适用场景

- **AI 辅助开发团队**：团队中广泛使用 AI 编程工具的开发者，可以通过统一的规则注入，确保 AI 生成的代码风格和质量保持一致，减少后期review和修改成本。

- **Go 代码重构项目**：对于维护多年、沉淀了大量陈旧代码风格的老项目，如果计划逐步现代化重构，可以使用该指南帮助 AI 生成符合现代规范的替代代码。

- **Go 新手培养**：培训机构或团队内部导师可以将这些指南作为教学辅助材料，让 AI 在生成示例代码时自动使用最新语法，帮助初学者学习现代 Go 编程方式。

- **开源项目开发**：维护者可以在项目配置中集成该指南，使得社区贡献者使用 AI 助手产生的代码更易通过审查，提升整个项目的代码一致性。

## 项目亮点

与市面上其他 Go 编码规范或 AI 提示词集合相比，该项目具有显著优势：

- **官方背景与权威性**：由 JetBrains（GoLand IDE 的开发商）官方发布，内容经过专业 Go 语言团队的验证，可信度和实用性远高于社区整理的零散规范。

- **版本精准适配**：不同于多数静态提示词，这个指南能够根据项目实际使用的 Go 版本动态调整建议内容，避免了推荐了项目无法使用的语法导致编译错误的问题。

- **覆盖面广且及时**：内容覆盖从 Go 1.0 到 1.27 的所有重要特性，而且随新版本发布持续更新，解决了 AI 模型训练数据滞后的问题。

- **双重问题针对性解决**：同时解决了训练数据滞后导致的"知识盲区"和频率偏差导致的"偏好旧写法"两个核心问题，为 AI 生成高质量的现代 Go 代码提供了完整的解决方案。
