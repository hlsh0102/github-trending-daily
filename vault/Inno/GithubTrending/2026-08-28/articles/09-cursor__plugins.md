## 项目概述

Cursor plugins 是 Cursor 官方维护的插件仓库，为开发者工具、框架和 SaaS 产品提供标准化插件规范与参考实现。该项目定义了 Cursor 插件的目录结构与 manifest 格式，并收录了多个由 Cursor 团队开发的官方插件，涵盖教学辅助、持续学习、团队协作、代码审查等多个领域。目标用户包括希望扩展 Cursor 编辑器能力的开发者、需要内部团队工作流自动化的工程团队，以及希望了解并创建自定义 Cursor 插件的开发者。

## 核心功能

- **标准化插件规范**：明确每个插件为仓库根目录下的独立文件夹，包含 `.cursor-plugin/plugin.json` 清单文件，为插件开发提供统一约定。
- **教学辅助插件（Teaching）**：提供技能映射、练习计划和复盘机制，帮助用户系统化提升编程技能。
- **持续学习插件（Continual Learning）**：基于增量对话记录，将高信号信息以要点形式更新至 `AGENTS.md`，实现驱动记忆的持续演进。
- **团队协同插件（Cursor Team Kit）**：覆盖 CI、代码审查、发布、本地自动化与验证等内部工程流程，适合团队标准化落地。
- **深度审查插件（Thermos）**：通过并行子代理执行安全/正确性审计与代码质量评估，支持可选的合并就绪 PR 流程，实现“热核”级别的分支评审。
- **插件脚手架工具（Create Plugin）**：提供插件的初始化生成与校验能力，降低创建新插件的手动成本。

## 技术架构

项目以 TypeScript 为主要语言，并围绕以下架构思路展开：

- **目录即插件**：每个插件独立成目录，不引入全局构建步骤，降低耦合，便于单独维护与分发。
- **Manifest 驱动**：`.cursor-plugin/plugin.json` 是插件的元数据核心，声明插件的名称、描述、作者与类别，供 marketplace 或 Cursor 运行时识别加载。
- **增量记忆机制**：持续学习插件采用对话驱动的内存更新策略，通过过滤高信号要点，避免 `AGENTS.md` 信息膨胀，提升上下文有效利用。
- **并行子代理协同**：Thermos 插件展示如何调度多个子代理并行执行不同审查任务，再由主控流程汇总结论，体现 Cursor 多代理编排能力。
- **CLI 辅助**：插件附带命令行工具，用于仓库兼容性校验等场景，增强插件的可操作性与集成度。

## 安装与使用

以仓库内任一插件为例，基本使用流程如下：

```bash
# 1. 克隆仓库（或单独复制所需插件目录）
git clone https://github.com/cursor/plugins.git

# 2. 进入目标插件目录，例如 continual-learning
cd plugins/continual-learning

# 3. 根据插件 README 完成配置（通常涉及环境变量或 AGENTS.md 路径）
# 4. 将插件目录链接或放置到 Cursor 插件扫描路径
```

最小示例（以持续学习插件为例）：

```bash
# 在 Cursor 中启用插件后，定义转录来源与目标文件
export TRANSCRIPT_SOURCE="/path/to/transcripts"
export AGENTS_FILE="/path/to/AGENTS.md"

# 执行插件提供的更新命令（具体命令以插件 README 为准）
cursor plugin run continual-learning
```

更详尽的配置参数与命令请参考各插件目录内的文档。

## 适用场景

- **个人技能提升**：利用 Teaching 插件规划学习路径，结合实时练习与阶段性复盘，适合自学编程或学习新框架的开发者。
- **团队工程效率**：通过 Cursor Team Kit 统一 CI/审查/发布流程，减少口头交接与重复劳动，适合中大型开发团队。
- **代码审查与安全加固**：使用 Thermos 插件对重要分支进行深度审计，适合对安全敏感或代码质量要求严格的项目，可显著降低合并风险。
- **插件开发入门**：参考 Create Plugin 与现有插件范式，快速构建自定义插件，适合希望扩展 Cursor 生态的个人或公司。

## 项目亮点

- **官方维护**：由 Cursor 团队直接维护，与编辑器特性保持同步，API 适配及时，稳定性和兼容性有保障。
- **低门槛扩展**：目录即插件的设计，让开发者只需遵循 manifest 格式，就能轻松创造并分享新插件，无需复杂的注册流程。
- **实战验证**：插件本身即包含生产级逻辑（如并行子代理、记忆增量更新），而非仅演示 API，具备较强的参考与落地价值。
- **清晰的分类**：通过表格和 `description` 字段规范管理插件集合，方便使用者按场景检索。
- **活跃迭代**：仓库保持高频更新（近期日增 stars 达 257），社区关注度高，反馈循环快。
