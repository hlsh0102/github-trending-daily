## 项目概述

screenshot-to-code 是一个开源的 AI 驱动开发工具，它能够将截图、设计稿、Figma 设计以及屏幕录制内容直接转换为可运行的代码。该项目解决了前端开发中从设计到代码这一环节的重复性劳动问题，让开发者能够将视觉设计快速转化为真实的界面实现。

项目的主要目标用户包括前端开发者、产品经理、UI/UX 设计师以及任何需要快速构建原型的技术人员。通过简单的拖拽或粘贴截图操作，用户可以在几秒钟内获得一份结构清晰、可复用的代码文件，从而显著缩短从设计到实现的周期。

该项目由 abi 开发并维护，在 GitHub 上获得了超过 75,000 个 Star，社区活跃度极高，是一个被广泛认可和使用的生产力工具。

## 核心功能

- **多框架代码生成**：支持 HTML + Tailwind、HTML + CSS、React + Tailwind、Vue + Tailwind、Bootstrap、Ionic + Tailwind 等多种主流前端技术栈，用户可根据项目需求自由选择输出格式。
- **截图直转代码**：只需上传一张界面截图或设计稿，AI 引擎即可自动分析布局结构、颜色搭配和组件关系，生成与之对应的干净、规范的代码。
- **屏幕录制转原型**：除了静态截图，项目还支持解析网站操作录屏，将动态交互过程转化为可交互的功能原型。
- **智能设计还原**：生成的代码能够保留原设计中的间距、颜色、字号、阴影等视觉细节，确保还原度达到较高水平。
- **多样化 AI 模型支持**：默认配置了 Gemini 3 Flash/Pro、GPT-5.5/5.4 Mini、Claude Opus 4.6/4.8 等目前最先进的视觉与代码生成模型，同时支持通过 Replicate 调用 z-image-turbo 进行图像生成。
- **本地或云端部署**：既可以选择在本地环境运行以保护隐私和定制能力，也可以直接使用作者托管的在线版本，零成本快速体验。

## 技术架构

项目底层采用 Python 构建，前端负责用户界面与上传交互，后端则是一套由 AI 模型驱动的代码生成流水线。整个架构的核心设计思路是“视觉识别 + 代码生成”的两阶段分离：

1. **视觉识别层**：接收输入的截图或视频帧，利用多模态大模型（如 Gemini、GPT、Claude 系列）提取界面中的布局结构、文本内容和视觉元素，输出结构化的中间表示。
2. **代码生成层**：基于结构化表示，结合用户选定的目标框架模板，生成对应的 JSX、Vue 模板或纯 HTML/CSS 代码，并自动构建组件层级和样式系统。

项目采用了模块化的服务划分，支持自定义模型接入和调用后端，用户可以通过环境变量切换不同的 AI 提供商。同时，生成过程具有较好的容错能力，在模型返回不理想时可针对局部进行重新生成或调整。这种架构使得工具既保持了灵活性，又能够复用成熟的云端 AI 能力。

## 安装与使用

**本地运行（适用于自定义或贡献）**：

1. 确保已安装 Python 3.10+ 和 Node.js 18+。
2. 获取相应 AI 提供商的 API 密钥（如 OpenAI、Anthropic 或 Google AI）。
3. 克隆仓库并安装依赖：
   ```bash
   git clone https://github.com/abi/screenshot-to-code.git
   cd screenshot-to-code
   pip install -r requirements.txt
   npm install
   ```
4. 配置环境变量（如 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`），然后分别启动后端和前端服务。

**快速体验（在线版本）**：

无需任何本地配置，直接访问 [https://screenshottocode.com](https://screenshottocode.com)，上传截图即可在浏览器中看到生成的代码结果。

**最小可用示例**：

在本地或在线版本中，上传一张如登录页面或仪表盘的截图，系统会自动识别技术栈偏好，并返回一份带有完整样式定义和组件结构的代码片段。你可以将该片段直接粘贴到自己的项目中，或进一步基于生成结果进行微调。

## 适用场景

- **设计交接与快速实现**：设计师交付高质量视觉稿后，前端开发者可免去手动还原的繁琐过程，直接获得可运行代码，将更多精力投入到业务逻辑和交互细节上。
- **原型验证与演示**：产品经理或创业团队在早期验证阶段，可通过截图快速生成可点击的原型，向客户或投资人展示产品流程，无需等待开发排期。
- **学习与教学辅助**：前端初学者可以上传参考网站的截图，观察 AI 如何组织语义化 HTML 和类名，从而学习优秀的编码实践和布局技巧。
- **旧项目重构**：企业需要升级旧版网页的 UI 时，可以通过截取现有界面快速生成新框架下的代码，加快技术债务清理进度。

- **极低的门槛**：在线即时体验，上传即得结果，无需搭建模型或编写提示词。

- **持续演进的模型集**：项目团队持续跟进最新的大模型版本，默认配置了当前性能最强的视觉理解模型，确保生成效果始终处于行业前沿。
- **社区驱动的发展模式**：凭借 MIT 许可和活跃的贡献者社区，项目功能迭代快速，不断加入如屏幕录制转原型等新特性。
