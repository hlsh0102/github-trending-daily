## 项目概述

God's Eye View 是一个运行在浏览器中的开源“间谍卫星模拟器”，但它使用的数据全部来自公开的实时信号源。项目将飞行应答机、船舶信标、卫星轨道要素、地震仪、公共摄像头等分散的开放数据，整合到一个照片级真实的 3D 地球上，构建出直观的实时空间情报界面。

该项目由 YouTube 上播放量超过 500 万的 God's Eye View 系列视频背后的开发者 bilawalsidhu 创建（前身为 WorldView），旨在解决开源情报（OSINT）领域的一个核心痛点：信号无处不在，但缺乏有效的交互界面。传统上，追踪全球动态需要在多个浏览器标签页之间切换，而 God's Eye View 将这些信号转化为一个可导航、可交互的“地点”，让用户像使用地图一样浏览全球实时态势。

目标用户包括地理空间爱好者、飞行和船舶追踪爱好者、新闻工作者、教育工作者，以及任何对实时全球数据感兴趣的技术用户。项目完全开源，鼓励用户探索、扩展甚至改进它。

## 核心功能

- **照片级真实 3D 地球**：基于高精度地形和影像数据渲染，提供沉浸式的全球浏览体验，支持缩放、旋转和平移。
- **多源实时数据叠加**：在地球上实时显示民航客机、海上船舶、在轨卫星、地震活动、交通流量和公共摄像头画面，数据源均为公开可访问的实时信号。
- **模型化视图标注**：当某个位置没有实时视频源时，项目会提供清晰标注的 3D 模型视图，模拟该位置的景象，避免用户产生误解。
- **语音控制交互**：集成实时 AI 代理，用户可以通过自然语言语音指令来控制地图的移动、筛选数据图层或询问特定对象的信息，实现免提操作。
- **数据图层筛选**：用户可以根据需要，独立开关不同类型的图层（如仅显示船舶或仅显示地震），并按区域、高度、速度等属性进行过滤。
- **开源可扩展**：项目代码完全公开，数据接入和 UI 组件模块化设计，方便开发者接入新的数据源或定制功能。

## 技术架构

项目以 JavaScript 为主要语言，核心架构围绕高性能 3D 渲染和实时数据流处理展开。前端采用 WebGL 技术实现照片级真实的 3D 地球渲染，结合地理空间数据可视化库（如 CesiumJS 或类似库）处理投影、瓦片加载和实体标注。

数据层方面，项目通过 WebSocket 或轮询机制连接多个公开数据 API，例如 ADS-B 飞行数据、AIS 船舶数据、USGS 地震 API 以及卫星 TLE 轨道数据。为保证实时性，前端采用增量更新策略，仅对变化的数据实体进行局部渲染更新，避免全量重绘。

语音控制功能依托于实时 AI 代理服务，将用户的语音输入转换为结构化指令，并映射到地图操作 API 上。AI 代理还具备上下文理解能力，可以处理如“放大到东海岸并显示所有货轮”之类的复合指令。

项目在设计上强调清晰的数据标注与视觉区分，确保实时数据与模拟/模型化视图在视觉上有明确差异，这在情报展示类应用中至关重要。

## 安装与使用

由于项目运行在浏览器中，最简单的使用方式是直接访问在线部署的版本。如需本地运行，基本步骤如下：

1. **克隆仓库**：
   ```bash
   git clone https://github.com/bilawalsidhu/gods-eye-view.git
   cd gods-eye-view
   ```

2. **安装依赖**：项目基于 Node.js 生态，使用 npm 或 yarn 管理依赖。
   ```bash
   npm install
   ```

3. **配置 API 密钥**：部分数据源（如实时地图瓦片、AI 语音代理）需要 API 密钥。复制 `.env.example` 为 `.env`，并填入相应的密钥（参见仓库中的 Keys 部分说明）。

4. **启动开发服务器**：
   ```bash
   npm run dev
   ```

5. **打开浏览器**：访问 `http://localhost:3000`，即可看到全球实时态势。首次加载时，建议先关闭部分图层，以加速地图渲染。

最小可用示例：启动后，使用鼠标拖拽旋转地球，滚动缩放至感兴趣的区域；点击右上角的图层按钮，开启“飞机”或“船舶”图层，即可看到代表实时位置的图标移动。

## 适用场景

- **新闻与事件追踪**：当重大事件发生时（如地震、飞机失联、海上事故），记者和编辑可以在一个界面中快速定位相关区域，获取实时的交通流量、地震数据和附近航班/船舶动态，辅助报道决策。
- **教育与科普**：教师可以利用该工具向学生展示全球航运路线、航空网络、卫星分布和地球构造活动，将抽象的地理和物理概念转化为可视化的现实世界。
- **个人兴趣探索**：无论是追踪某一特定航班的实时位置，还是观察全球范围内的船舶密度，爱好者可以获得比传统追踪网站更沉浸式的体验。
- **数据分析与可视化原型**：对于从事地理空间数据开发的工程师，该项目可作为演示前端能力的可靠原型，展示如何将多源异构数据流整合为交互式 3D 界面。

## 项目亮点

与传统的单一数据追踪网站（如只提供航班或只提供船舶）相比，God's Eye View 的差异化优势在于：

1. **多源情报的综合呈现**：将空、天、地、海的数据整合在一个统一的时空坐标系中，提供了“上帝视角”的综合态势感知。
2. **照片级真实的沉浸感**：区别于简单的地图图标标注，它利用 3D 渲染技术，让用户仿佛在操控一个真实的卫星系统，极大降低了理解空间关系的心智负担。
3. **人机交互的革新**：率先引入了实时 AI 语音代理作为标准交互方式，用户无需学习复杂的 UI 操作，即可通过自然语言探索数据。
4. **透明度与真实性**：坚决区分实时画面与模型视图，并公开所有数据来源，这在信息真实性备受关注的时代尤为可贵。
5. **开放的社区基础**：背靠数千万播放量的视频系列，项目拥有活跃的社区关注度和持续的开发动力。
