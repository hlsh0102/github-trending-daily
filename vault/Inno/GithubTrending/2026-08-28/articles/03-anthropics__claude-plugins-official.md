## 项目概述

Claude Code Plugins Official 是 Anthropic 官方维护的高质量 Claude Code 插件目录。该项目旨在为 Claude Code 用户提供一个集中、可信赖的插件发现和安装源，解决了用户难以找到可靠插件以及无法确认插件安全性的问题。它面向所有 Claude Code 用户，包括开发者、技术团队以及希望在 Claude Code 环境中扩展功能的个人用户。通过官方管理和审核机制，该项目确保列出的插件符合一定的质量标准，帮助用户降低选择成本和安全风险。

## 核心功能

- **官方插件目录**：包含由 Anthropic 团队内部开发和维护的插件，这些插件直接集成在 `plugins` 目录中，代表了官方推荐的最佳实践。
- **第三方插件市场**：在 `external_plugins` 目录中收录来自合作伙伴和社区的第三方插件，为用户提供更广泛的功能选择。
- **命令行安装**：支持通过 Claude Code 的插件系统直接安装，用户只需在 Claude Code 环境中执行 `/plugin install {plugin-name}@claude-plugins-official` 命令即可完成安装。
- **交互式发现**：提供 `/plugin > Discover` 浏览界面，用户可以在 Claude Code 内直接搜索和浏览可用插件。
- **标准化插件结构**：所有插件遵循 `.claude-plugin/plugin.json` 等标准结构，确保插件可被正确识别和加载，同时便于开发者理解和贡献。
- **安全的贡献流程**：为内部和外部开发人员分别定义了明确的插件提交流程，外部插件需经过质量与安全标准审核，维护了目录的整体可信度。

## 技术架构

该项目采用简洁的目录结构设计，核心区分内部插件和外部插件，便于管理和隔离不同来源的代码。每个插件遵循标准化的文件组织：

- `plugin-name/` 为插件根目录，包含插件全部内容。
- `.claude-plugin/plugin.json` 是必需的元数据文件，定义了插件的名称、版本、描述、入口点等关键信息。
- `.mcp.json` 可选，用于配置 MCP（Model Context Protocol）服务器，使得插件能够与外部工具或数据源交互。
- `commands/` 目录存放插件提供的斜杠命令（Slash Commands），扩展 Claude Code 的对话交互能力。

该项目本身以 Python 作为主要语言，但插件内容本身可以是任意语言，只要遵循 Claude Code 插件的规范。整个架构强调模块化和可扩展性，允许开发者在不修改核心代码的情况下，通过添加新插件快速增强 Claude Code 的能力。此外，项目将安全警告置于显要位置，提示用户在安装、更新或使用插件前务必确认其来源和可信度，因为 Anthropic 无法验证第三方插件包含的 MCP 服务器、文件或其他软件的安全性。

## 安装与使用

**环境要求**：需要已安装并配置好 Claude Code。若尚未安装，请参考 Claude Code 官方文档进行配置。

**步骤一：发现插件**

可以通过以下两种方式发现可用插件：
1. 命令行：在 Claude Code 环境中输入 `/plugin` 命令，查看插件管理界面。
2. 浏览目录：直接访问本 GitHub 仓库的 `/plugins`（内部插件）和 `/external_plugins`（第三方插件）目录，查看插件列表。

**步骤二：安装插件**

使用以下命令直接安装指定插件：
```
/plugin install plugin-name@claude-plugins-official
```
其中 `plugin-name` 替换为你想要安装的插件名称。安装过程中 Claude Code 会提示确认，请务必确认插件来源可信。

或者，你也可以在 Claude Code 中运行 `/plugin > Discover`，浏览并选择插件进行安装。

**步骤三：使用插件**

安装完成后，插件提供的功能通常可以通过斜杠命令或自动触发的方式使用。具体用法请参考每个插件自带的 README 文件或文档，一般可在插件目录中找到。

> **安全提示**：在安装任何插件之前，请检查该插件的来源、维护者信息以及代码内容（如果可见）。仅从可信来源安装插件，并定期审查已安装插件是否存在更新或异常更改。

## 适用场景

- **扩展 Claude Code 功能**：用户需要通过插件为 Claude Code 添加定制化命令、工作流或外部集成，提升日常开发效率。
- **企业内部工具集成**：开发团队可以基于此目录的结构创建内部插件，并采用相同的规范管理和分发，确保团队使用一致且可靠的工具链。
- **社区分享与协作**：第三方开发者可以通过提交外部插件，将优质的工具和功能分享给更广泛的 Claude Code 用户群体，并获得官方市场的曝光。
- **安全审计与合规要求**：对于对软件供应链安全有严格要求的组织，官方目录的审核机制和清晰的结构有助于追踪和控制插件的使用。
