## 项目概述

DESIGN.md 是一个用于向编码代理（coding agents）描述视觉身份规范的格式说明。传统上，AI 辅助编码工具在生成用户界面时，往往缺乏对设计系统的持续、结构化理解，导致输出的 UI 在视觉风格上不一致或偏离原有设计意图。本项目通过提供一个标准化的文件格式，让设计团队能够将设计系统的核心规范——包括颜色、排版、间距等设计令牌（design tokens）以及使用这些设计元素的设计原理——编码进一个单一的、可由 AI 读取的 `DESIGN.md` 文件中。目标用户包括前端开发者、设计系统维护者，以及所有希望借助 AI 编码工具生成符合品牌视觉规范的 UI 代码的团队。

## 核心功能

- **设计令牌数据化**：在 YAML 前置元数据中定义精确的颜色、字体、字号、圆角、间距等设计令牌值，为代理提供严格的数值参考。
- **设计原理文档化**：在 Markdown 正文中以自然语言描述设计系统的核心理念、色彩含义和使用规则，帮助代理理解“为什么”这样设计，从而做出更符合预期的决策。
- **机器与人可读**：文件格式同时面向两大受众。AI 编码代理可以解析结构化的令牌数据并遵循文字说明，人类设计师和开发者也可以直接阅读和编辑，方便团队协作与版本管理。
- **品牌一致性保障**：每次生成 UI 时，代理都会从 DESIGN.md 中获取一致的设计规范，避免因上下文丢失或模型偏见导致的风格偏差，确保输出视觉风格统一。
- **简单文件驱动**：无需额外配置工具或平台，只需在项目根目录下放置一个 `DESIGN.md` 文件，即可被支持该规范的工具链自动识别。

## 技术架构

DESIGN.md 采用复合文档架构，将两种数据格式融合在单一 `.md` 文件中。上层是 YAML 格式的元数据区块（front matter），使用三个短横线分隔，用于定义定量化的设计令牌。这些令牌包括颜色（支持十六进制等标准格式）、排版（字体族、字号、字重等）、间距和圆角半径等 CSS 相关属性。下层是 Markdown 格式的正文，用于承载定性化的设计说明。整体架构简洁，不依赖任何外部运行时，仅依赖文件系统。任何能够解析 YAML + Markdown 的工具都可以理解此文件。这种设计降低了集成门槛，使其可以嵌入到现有的版本控制系统（如 Git）和 CI/CD 工作流中。

## 安装与使用

DESIGN.md 是一个格式规范，不需要“安装”任何软件。你需要做的是在项目仓库的根目录创建一个 `DESIGN.md` 文件，并遵循其格式。

**基本步骤：**

1.  在项目根目录新建文件 `DESIGN.md`。
2.  在文件开头，用三个短横线包裹 YAML 格式的设计令牌定义。
3.  在 YAML 区块之后，编写 Markdown 格式的设计说明正文。

**最小可用示例：**

```md
---
name: MyBrand
colors:
  primary: "#0052FF"
  neutral: "#FFFFFF"
typography:
  body:
    fontFamily: Inter
    fontSize: 1rem
---

## Overview

This is a clean, modern design system for an enterprise application.

## Colors

- **Primary (#0052FF):** Used for primary actions, links, and key accents.
- **Neutral (#FFFFFF):** Used for backgrounds and card surfaces.
```

将文件放入仓库后，支持 DESIGN.md 的编码代理（如特定版本的 IDE 插件或 CLI 工具）在读取仓库上下文时，会自动识别并使用此文件中的规范来生成 UI 代码。

## 适用场景

- **品牌一致的 UI 生成**：当使用 AI 编码代理（如 GitHub Copilot、Codex CLI 等）生成前端页面或组件时，通过 DESIGN.md 指导代理严格遵循品牌色板与字体规范，减少视觉偏差。
- **设计系统迁移与维护**：当设计系统更新（例如品牌色变更）时，只需修改 `DESIGN.md` 中的一处令牌值，所有后续由代理生成的 UI 将自动使用新值，大幅降低维护成本。
- **跨团队协作**：设计团队输出 DESIGN.md 文件，前端团队和 AI 代理基于同一份规范工作，避免因沟通不畅或理解偏差导致的实现错误。
- **快速原型开发**：开发者可以在已有 DESIGN.md 的项目中，通过自然语言指令要求代理生成新页面，代理能自动复用设计系统中的所有样式，实现快速且风格统一的原型迭代。

## 项目亮点

- **零工具主义**：DESIGN.md 不是一个需要安装和学习的新工具，而是一个开源格式。任何团队都可以立即采用，无需改变现有工作流，只需添加一个文件。
- **机器原生理解**：相比传统的 UI 设计稿或设计文档，DESIGN.md 是为 AI 的阅读理解能力优化的。结构化的 YAML 数据确保了精确性，自然语言的 prose 弥补了上下文的模糊性。
- **开源社区采纳度高**：该项目已获得 17644 个星标（截至撰写时），并在一天内获得 600+ 新增星标，显示出开发者社区对此类标准化 AI 协作规范的强烈需求。
- **低门槛高收益**：只需几分钟撰写一个简单的 DESIGN.md 文件，即可显著提升 AI 生成 UI 的一致性和质量，投入产出比极高。
