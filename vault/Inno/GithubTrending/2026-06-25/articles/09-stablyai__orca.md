## 项目概述

Orca 是一个专为高效并行管理多个 AI 编码代理而设计的集成开发环境（ADE, Agentic Development Environment）。该项目解决了开发者在同时运行多个 AI 编程代理（如 Codex、Claude Code、OpenCode 等）时面临的任务分散、环境隔离和状态追踪困难等问题。Orca 的目标用户是频繁使用 AI 辅助编程工具的开发者，尤其是那些需要并行执行多项编码任务、追求极致开发效率的“百倍效率建造者”。

通过 Orca，用户可以在一个统一的应用界面中同时运行多个编码代理，每个代理都拥有独立的工作目录（worktree），所有代理的活动状态和输出都被集中追踪和记录。项目目前支持 macOS、Windows 和 Linux 三大主流桌面平台，并提供了移动端访问能力。

## 核心功能

- **多代理并行管理**：支持同时运行多个 AI 编码代理，包括但不限于 Codex、Claude Code、OpenCode 和 Pi，每个代理在独立的会话中运行。
- **独立工作目录（Worktree）**：每个代理自动分配一个独立的工作目录，避免不同代理之间的文件冲突或状态污染，确保任务隔离性。
- **统一状态追踪**：所有代理的运行状态、输出日志和结果都在一个界面中集中显示，方便开发者全局监控和快速切换。
- **自带订阅接入**：用户可以使用自己的 API 订阅来连接各个 AI 代理服务，无需依赖第三方共享账户，保证了使用灵活性和数据隐私。
- **跨平台桌面客户端**：提供 macOS、Windows 和 Linux 的原生桌面应用体验，同时支持移动端访问。
- **一键代理启动**：通过简洁的界面操作即可快速启动或停止某个代理，无需手动配置复杂的运行环境。

## 技术架构

Orca 基于 TypeScript 构建，采用了跨平台桌面应用的技术栈。其核心设计围绕“代理编排”这一概念，借鉴了编排（Orchestration）的设计模式，将多个独立的 AI 代理作为可管理的工作单元。

从架构上看，Orca 包含以下几个关键层次：

1.  **代理抽象层**：定义了统一的代理接口，使得不同类型的 AI 编码代理（如 Claude Code 和 OpenCode）可以以一致的方式被管理和调度。每个代理实例都与一个独立的工作目录绑定，实现了沙箱化的隔离运行环境。
2.  **工作空间管理**：负责维护所有代理实例的元数据、运行状态和输出历史。这一层提供了全局的监控能力，允许用户随时了解每个代理的实时状态。
3.  **跨进程通信**：Orca 需要与多个外部代理进程进行通信，其底层实现了可靠的进程管理和消息路由机制，确保不同代理的输出可以正确路由到对应的界面面板。
4.  **用户界面层**：基于现代前端框架构建，提供了直观的多面板布局，每个面板对应一个代理会话。界面设计注重信息密度和操作效率，方便用户快速切换和查看。

值得注意的是，Orca 本身不作为 AI 能力的提供者，而是作为“代理的代理”——它不介入具体的 AI 推理过程，只负责调度、隔离和展现，这种轻量级的设计使其能够快速适配新的 AI 编码工具。

## 安装与使用

Orca 提供了便捷的安装方式，用户可以直接从项目官网下载对应平台的安装包。

**快速安装步骤：**

1.  访问 [onOrca.dev](https://onorca.dev) 官网，点击“Download”按钮。
2.  根据操作系统选择对应版本（macOS DMG、Windows EXE/MSI 或 Linux AppImage/deb）。
3.  安装完成后启动应用。

**最小可用示例：**

1.  启动 Orca 应用，进入主界面。
2.  点击“添加代理”或“New Agent”按钮。
3.  在弹出的配置窗口中，选择你想使用的 AI 代理类型（如 Codex、Claude Code 等）。
4.  输入你的 API 密钥或相关认证信息（使用你自己的订阅）。
5.  系统会自动为该代理创建一个独立的工作目录。
6.  点击“启动”，代理即开始运行，其输出将实时显示在主界面的对应面板中。
7.  重复以上步骤可以添加和管理多个并行运行的代理。

## 适用场景

- **并行编码任务管理**：当开发者需要同时进行多个独立的编码任务（例如修复一个 bug、编写一个新功能、重构另一段代码），可以为每个任务启动一个独立的 AI 代理，Orca 帮助保持任务之间的环境隔离和状态清晰。
- **多模型对比实验**：研究人员或高级开发者可能希望对比不同 AI 编码模型（如 Claude Code vs. Codex）在同一任务上的表现。通过 Orca，可以同时启动多个代理并使用相同的指令，直观比较结果。
- **团队协作与任务分发**：在团队开发中，Orca 可以配置为运行多个代理来处理不同的子任务模块，每个代理的输出可以被团队中的不同成员独立审查和集成。

## 项目亮点

- **真正的多代理并行能力**：与大多数只支持单一代理的 IDE 插件不同，Orca 从一开始就设计为多代理并行环境，这是其最核心的差异化优势。
- **环境隔离的巧思**：通过引入独立工作目录（worktree），解决了并行代理场景下最棘手的文件冲突问题，这在实际使用中极其重要。
- **用户自有订阅模型**：用户使用自己的 API 密钥连接各代理服务，避免了共享订阅带来的配额限制、数据安全和延迟问题，同时赋予了用户完全的自主权。
- **轻量级编排而非深度集成**：Orca 不试图替代既有的 AI 编码工具，而是作为“指挥官”来协调这些工具。这种设计降低了项目本身的复杂性，也使其更具扩展性。
