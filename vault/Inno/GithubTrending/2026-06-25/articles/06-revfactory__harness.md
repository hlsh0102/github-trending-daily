## 项目概述

Harness 是一个专为 Claude Code 设计的团队架构工厂插件。它的核心理念是“元技能”（meta-skill）：你只需告诉它“为这个项目构建一个 harness”，Harness 就会自动分析你的项目领域，设计出对应的专业代理团队，并为这些代理生成它们所需的技能。本质上，Harness 解决的是如何将通用 AI 编码助手（Claude Code）快速适配到特定领域、特定项目结构中的问题。目标用户是希望利用 AI 进行复杂项目开发、但又不想手动定义每个代理角色和技能集的开发者或团队。

## 核心功能

- **领域感知的代理团队设计**：Harness 能够理解项目所属的领域（如后端微服务、前端组件库、数据管道等），并基于领域最佳实践设计出由多个专业代理组成的协作团队。
- **自动化技能生成**：为每个代理角色自动生成所需的“技能”（即 Claude Code 的指令集）。这些技能覆盖了代码生成、测试、调试、文档编写等常见开发活动。
- **多语言自然语言触发**：支持英文、韩文、日文三种语言的自然语言命令。例如说“build a harness for this project”（英文）或“하네스 구성해줘”（韩文）或“ハーネスを構成して”（日文）即可启动。
- **团队架构模式库**：内置了 6 种架构模式，覆盖了从单体应用到微服务、从数据处理到前端开发的常见团队结构。
- **无缝集成 Claude Code**：作为 Claude Code 的插件，Harness 完全嵌入现有的 AI 辅助工作流中，无需切换工具。
- **可扩展与定制**：用户可以在生成的团队架构基础上进一步调整代理角色、技能定义或团队协作流程。

## 技术架构

Harness 的架构围绕“元工厂”模式设计，分层清晰：

- **L3 元工厂层**：这是 Harness 的核心定位——它不直接处理具体代码，而是作为更高层次的“工厂”，根据输入的项目上下文来生成适用于该项目的“工厂”（即代理团队和技能）。这种设计使得 Harness 可以适配任意领域。
- **6 种架构模式**：提供了 6 种预定义的团队拓扑结构，例如“单代理模式”、“专家协作模式”、“管道处理模式”等。每种模式都对应不同的项目需求和复杂度。
- **代理团队子层**：在具体的项目中，Harness 会实例化一个由多个代理组成的团队，每个代理有明确的角色（如架构师、开发者、测试员、文档作者）和对应的技能定义。
- **技能生成引擎**：根据代理角色和项目上下文自动合成技能指令。这些技能并非静态模板，而是通过分析项目结构、依赖关系和技术栈动态生成的。
- **跨语言支持**：通过 i18n 机制，支持英文、韩文、日文三种语言的命令和输出，使非英语用户也能流畅使用。

## 安装与使用

假设你已经安装了 Claude Code，Harness 的安装和基本使用步骤如下：

1. **克隆仓库并安装插件**：
   ```bash
   git clone https://github.com/revfactory/harness.git
   cd harness
   # 根据 Claude Code 插件机制将 Harness 注册为插件
   ```

2. **在项目中初始化 Harness**：
   在目标项目根目录中运行：
   ```bash
   claude --command "build a harness for this project"
   ```

3. **与生成的代理团队协作**：
   Harness 完成配置后，你可以使用自然语言与生成的代理团队互动。例如：
   - “请架构师分析项目的模块依赖”
   - “让测试代理为新功能编写单元测试”

4. **自定义团队配置**（可选）：
   生成的配置文件通常位于 `.harness/` 目录，可以手动编辑代理角色、技能或选择不同的架构模式。

## 适用场景

- **复杂微服务项目的开发**：当一个项目包含多个独立服务时，Harness 可以生成一个包含架构师、各服务开发者、集成测试员等角色的团队，确保每个服务得到专注的 AI 辅助。
- **前端组件库的维护**：对于需要保持组件一致性、编写 Storybook 文档、进行视觉回归测试的项目，Harness 可以生成专门负责 UI 组件设计、文档编写和测试的代理。
- **数据管道与 ETL 项目**：处理数据提取、转换、加载的复杂流程时，Harness 能设计出包含数据建模师、管道工程师和质量验证员的分工团队。
- **开源项目的新人 onboarding**：为新贡献者提供清晰的项目结构、开发规范和测试指南，Harness 可以生成专注于文档编写和代码评审的辅助代理。

## 项目亮点

- **真正的“元技能”实现**：不同于传统插件仅提供固定功能，Harness 本身是一项“元技能”——它能根据输入动态生成新的技能和代理，极大地提高了 AI 辅助开发的适应性和深度。
- **领域自适应**：通过分析项目上下文而非依赖预设模板，Harness 能够更好地贴合真实项目需求，减少了人工定制的工作量。
- **多语言自然语言接口**：支持三种主流语言的自然语言触发，降低了使用门槛，尤其方便韩国和日本开发者。
- **内置成熟模式库**：6 种经过验证的团队架构模式让用户无需从零设计，可以直接选择适合的起点。
- **开源且社区驱动**：代码在 Apache 2.0 许可下开源，欢迎贡献和改进。超过 7800 个 Star 和活跃的每日 Stars 增长证明其社区认可度。
