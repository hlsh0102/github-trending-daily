## 项目概述

Agent Skills 是一个为 AI 编程代理提供生产级工程技能的开源项目。它通过预定义的技能集和工作流程，将资深工程师的开发实践、质量门禁和最佳实践编码为 AI 代理可执行的工作流。项目解决了 AI 编程中常见的“有代码无流程”问题——AI 代理往往能生成代码，但缺乏对开发流程的理解和遵守。目标用户包括正在使用或评估 AI 编程工具的开发者、团队管理者，以及希望提升 AI 代理代码质量的工程团队。

## 核心功能

- **生命周期映射**：将软件开发全流程（从想法到交付）细分为 DEFINE、PLAN、BUILD、VERIFY、REVIEW、SHIP 六个标准化阶段
- **7 个斜杠命令**：`/spec`、`/plan`、`/build`、`/test`、`/review`、`/code-simplify`、`/ship`，每个命令对应特定开发阶段的技能激活
- **自动化构建**：`/build auto` 命令在规范文档就绪后自动生成计划并实现所有代码
- **质量门禁**：每个阶段内置检查点，确保测试完备（`/test`）、代码整洁（`/review`、`/code-simplify`）、交付安全（`/ship`）
- **渐进式开发**：强调“一次只处理一个切片”的原子化任务分解
- **规范驱动**：强制“规范先于代码”原则，避免 AI 代理跳过需求分析直接编码

## 技术架构

Agent Skills 采用 Shell 脚本实现，基于一套可组合的技能库（skills）和流程引擎（orchestrator）。核心设计思路是“流程即代码”——将人类工程师的隐性知识（如“先写规范再编码”、“小步提交”）显式编码为可执行的命令和规则。架构特点包括：
- **命令式交互**：通过简单的斜杠命令触发复杂技能链，降低 AI 代理的使用门槛
- **阶段化管道**：遵循严格的线性流程，每个阶段输出作为下一阶段输入
- **技能可组合**：提供基础技能（如代码分析、测试生成、审查检查），可按需组合成高阶工作流
- **生产级校验**：所有技能内置质量检查（如代码风格一致性、测试覆盖率基线）
- **自包含运行**：不依赖外部 AI 服务，完全基于本地环境执行

## 安装与使用

**安装步骤**：
1. 克隆仓库：
   ```bash
   git clone https://github.com/addyosmani/agent-skills.git
   cd agent-skills
   ```
2. 确保系统具备 Bash 4.0+ 和基础 Unix 工具链（grep、sed、awk 等）
3. 根据文档配置 AI 代理环境变量（如有）

**最小可用示例**：
1. 定义新功能需求并生成规范：
   ```bash
   ./agent-skills /spec "添加用户登录功能"
   ```
2. 审核规范后生成实施计划：
   ```bash
   ./agent-skills /plan
   ```
3. 自动生成代码并验证：
   ```bash
   ./agent-skills /build
   ./agent-skills /test
   ```
4. 交付前进行代码整洁度和安全性检查：
   ```bash
   ./agent-skills /review
   ./agent-skills /code-simplify
   ./agent-skills /ship
   ```

## 适用场景

- **AI 辅助的敏捷开发**：团队在使用 AI 编程助手时，确保其遵循 Scrum 或看板流程的节奏和质量门禁
- **跨团队代码质量标准化**：多个开发小组采用统一的 AI 开发规范，减少因代理行为不一致导致的冲突
- **大型项目重构**：AI 代理需要在不破坏现有代码结构的前提下进行分步骤、小批量的代码优化
- **新人入职引导**：将资深工程师的技能和流程经验通过 AI 代理传递给新开发者

## 项目亮点

- **工程化思维**：不同于其他 AI 工具仅关注代码生成，Agent Skills 强调整个软件开发流程的工程化执行
- **可验证的流程**：每个阶段都有明确的输入/输出检查点，而非黑盒自动化
- **低侵入性**：仅需 Shell 环境即可运行，不绑定特定 AI 模型或云服务
- **开源可定制**：MIT 许可，团队可自由修改技能库以适配内部开发规范
- **实时优化反馈**：通过 `/code-simplify` 等命令持续改进代码质量，而非一次性输出
- **经验可迁移**：项目内置的技能模式可拆解为通用工程原则，适用于各类编程语言和框架
