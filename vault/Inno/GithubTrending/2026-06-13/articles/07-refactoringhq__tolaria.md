## 项目概述

Tolaria 是一款专为 macOS、Windows 和 Linux 设计的桌面应用，用于管理 **Markdown 知识库**。它由 RefactoringHQ 团队开发，核心理念是让用户以纯文本 Markdown 文件的形式存储、组织和检索个人或团队的知识资产。项目目前拥有超过 15,000 颗星，并持续获得社区关注。

Tolaria 的目标用户包括需要构建“第二大脑”的个人知识管理者、需要为 AI 提供上下文的团队文档维护者，以及希望系统化存储各类系统（如 OpenClaw/assistants）记忆与操作流程的开发者。项目的创建者 Luca 本人使用 Tolaria 管理一个包含 10,000 多篇笔记的大规模工作区，涵盖出版工作、个人日志和知识管理。

## 核心功能

- **纯文件优先**：所有笔记均为纯 Markdown 文件，不依赖任何专有格式。用户可以使用任何文本编辑器打开、编辑这些文件，且无需执行任何导出步骤即可迁移数据。
- **Git 原生集成**：每个知识库（vault）本质上是一个 Git 仓库。版本控制、变更追踪、团队协作等功能开箱即用，用户可以自由选择任何 Git 托管平台。
- **多平台支持**：统一在 macOS、Windows 和 Linux 上运行，提供一致的桌面体验。
- **高效检索与管理**：支持快速的全文搜索、标签管理以及灵活的笔记组织结构，帮助用户在大规模笔记库中快速定位信息。
- **灵活的工作流**：提供收件箱工作流、网页资源保存等功能，用户可以通过简单的操作将外部信息纳入知识库管理。
- **开源与自主**：采用 AGPL-3.0 开源协议，用户可以完全掌控自己的数据和应用行为。

## 技术架构

Tolaria 使用 **TypeScript** 作为主要开发语言，这为项目提供了类型安全性和现代化的开发体验。项目架构以以下设计原则为核心：

- **文件系统优先**：Tolaria 没有自己的数据库或后端服务，所有数据直接存储在用户的本地文件系统中。应用本身只是一个友好的文件浏览器和编辑器，这种设计确保了数据的高度便携性和安全性。
- **Git 深层集成**：将 Git 作为知识库的底层版本控制系统，用户无需离开应用即可执行提交、查看历史版本、处理分支等操作。这种设计让团队协作变得自然且透明。
- **跨平台桌面技术**：采用跨平台的桌面应用开发框架，使得同一套代码库可以编译为 macOS、Windows 和 Linux 的原生应用，保证了各平台下一致的用户体验和性能表现。
- **模块化与可扩展**：应用内部采用模块化设计，核心功能（文件管理、搜索、编辑、Git 集成）相互独立，便于后续功能的添加和维护。

## 安装与使用

**安装步骤**

1. 访问项目的 [GitHub Releases 页面](https://github.com/refactoringhq/tolaria/releases) 下载对应操作系统的最新版本安装包。
2. 对于 macOS 用户：下载 `.dmg` 文件并拖入 Applications 文件夹。
3. 对于 Windows 用户：下载 `.exe` 安装程序并运行安装向导。
4. 对于 Linux 用户：下载 `.AppImage` 文件，赋予可执行权限后运行。

**最小可用示例**

1. 启动 Tolaria 后，点击“新建知识库”或选择已有的 Markdown 文件夹。
2. 应用会自动将文件夹识别为一个知识库，并扫描其中的所有 `.md` 文件。
3. 在左侧导航栏点击任意文件即可在编辑器区域查看和编辑内容。
4. 使用快捷键 `Cmd/Ctrl + K` 打开快速搜索框，输入关键词即可查找笔记。
5. 若要启用版本控制，确保知识库文件夹已初始化为 Git 仓库，Tolaria 会自动检测并显示 Git 状态。

## 适用场景

- **个人知识管理（第二大脑）**：作家、研究者或任何需要管理大量笔记的人，可以将所有想法、读书笔记、项目笔记以 Markdown 格式组织起来，并通过 Tolaria 实现高效检索和回顾。
- **团队文档协作**：团队可以将所有文档以 Markdown 形式存储在 Git 仓库中，Tolaria 提供友好的浏览和编辑界面，同时保留完整的版本历史和协作能力。
- **AI 辅助的知识库构建**：开发者或团队可以构建结构化的 Markdown 文档库，并将其作为上下文提供给 AI 助手（如 ChatGPT 或本地模型），实现更精准的问答和任务执行。

## 项目亮点

与同类知识管理工具（如 Obsidian、Notion、Roam Research）相比，Tolaria 的差异化优势主要体现在：

- **极致的文件化**：其他工具虽然也支持 Markdown，但往往在内部维护复杂的索引或缓存文件。Tolaria 严格以文件系统为基础，这意味着你可以随时用任何编辑器（Vim、VS Code 等）处理笔记，没有任何应用锁定。
- **天生的 Git 集成**：Git 不仅仅是备份工具，而是知识库的核心结构。团队协作、分支实验、变更回滚等操作完全基于 Git 工作流，无需学习专有协作协议。
- **极简与专注**：Tolaria 专注于“管理 Markdown 知识库”这一核心任务，不内置复杂的插件系统、数据库或云同步。对于追求简洁、可移植、自托管的用户而言，这是显著优势。
- **完全开源与自主**：AGPL-3.0 协议保证了用户可以自由查看、修改和分发代码，没有功能限制或付费墙，数据完全由用户掌控。
