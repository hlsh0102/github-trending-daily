## 项目概述

IPTV 是一个全球公开可用的 IPTV 频道集合项目，由 iptv-org 团队在 GitHub 上维护。该项目收集并整理了来自世界各地的公开 IPTV 频道，用户可以通过播放列表文件直接在支持直播流的视频播放器中观看。项目以 TypeScript 为主要语言，采用社区驱动的维护模式，解决了用户难以找到高质量、稳定更新的免费 IPTV 播放源的问题。目标用户包括希望免费观看全球电视频道的普通用户、开发者、研究人员以及需要测试 IPTV 相关应用的从业人员。

## 核心功能

- **全球频道播放列表**：提供包含所有可用频道的主播放列表，地址为 `https://iptv-org.github.io/iptv/index.m3u`，支持在多种视频播放器中直接打开使用
- **分类播放列表**：除主列表外，项目还提供按国家、语言、内容类型等维度分类的多个子播放列表，详细信息记录在 PLAYLISTS.md 文件中
- **电子节目指南（EPG）**：为大部分频道提供电子节目指南数据，用户可通过 iptv-org/epg 仓库中的工具下载节目时间表
- **结构化频道数据库**：所有频道信息存储在 iptv-org/database 仓库中，支持社区提交错误报告和更新请求
- **开放 API 接口**：提供完整的 API 文档，位于 iptv-org/api 仓库，便于开发者集成频道数据到自己的应用中

## 技术架构

项目采用模块化设计，将频道数据、播放列表生成、EPG 服务和 API 分别放在独立的仓库中管理。核心技术栈基于 TypeScript，利用 GitHub Actions 实现播放列表的自动更新和发布。频道数据存储在结构化的数据库中，通过社区的 Issue 和 Pull Request 机制进行维护。播放列表以标准的 M3U 格式输出，兼容绝大多数媒体播放器。EPG 数据通过独立的工具链处理，确保与频道信息同步。整个架构强调去中心化和开放协作，所有数据来源均公开可查，降低了单点故障风险。

## 安装与使用

使用该项目不需要安装任何软件，只需一个支持 M3U 播放列表的视频播放器即可。以下是基本步骤：

1. **选择播放器**：推荐使用 VLC、MPC-HC、PotPlayer 等支持直播流的播放器，或参考 awesome-iptv 列表中的推荐应用
2. **获取播放链接**：复制主播放列表地址 `https://iptv-org.github.io/iptv/index.m3u`，或从 PLAYLISTS.md 中选择特定分类的链接
3. **在播放器中打开**：
   - VLC：点击“媒体” -> “打开网络流”，粘贴链接并播放
   - PotPlayer：右键点击播放窗口 -> “打开” -> “打开链接”，粘贴链接
   - 其他播放器通常有类似操作

最小可用示例如下：

```
# 在 VLC 中打开网络流
1. 打开 VLC
2. 点击“媒体” (Media) -> “打开网络串流” (Open Network Stream)
3. 输入: https://iptv-org.github.io/iptv/index.m3u
4. 点击“播放” (Play)
```

播放列表会自动加载所有可用频道，用户可通过播放器的频道列表功能浏览和切换。

## 适用场景

- **个人娱乐**：用户可以通过 IPTV 免费收看全球公开频道的新闻、体育赛事、影视节目等，无需订阅有线电视或流媒体服务
- **开发测试**：开发者使用该项目的 API 或数据库进行 IPTV 相关应用的开发与测试，例如播放器开发、频道扫描工具、数据分析等
- **教育与研究**：研究人员分析全球电视节目的地域分布、语言多样性或内容类型，该项目提供标准化数据源
- **应急与备用**：在无法接入传统电视服务或主要流媒体平台中断时，IPTV 可作为应急信息来源

## 项目亮点

- **规模庞大且更新频繁**：收录超过 100,000 个频道，每天通过 GitHub Actions 自动化更新，确保播放质量
- **社区驱动与开放治理**：所有数据通过 Issue 和 Pull Request 由全球社区共同维护，任何人都可以提交频道信息或报告问题
- **标准化与互操作性**：采用 M3U 标准格式和公开 API，兼容几乎所有主流播放器和应用程序
- **模块化与可扩展**：数据库、播放列表、EPG、API 分离设计，便于其他项目按需集成或扩展
- **零许可限制**：采用 Unlicense 许可证，完全公共领域，用户可自由使用、修改和分发
