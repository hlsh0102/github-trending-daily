## 项目概述

Superpowers 是一套为编码代理（coding agents）设计的完整软件开发方法论与技能框架。它解决了当前主流编码代理在自主开发过程中常见的痛点：缺乏项目上下文、缺乏测试意识、代码品味不佳、容易偏离原始需求。项目目标用户是使用 AI 编码助手（如 Claude Code、Codex CLI、Cursor 等）的开发者与团队，希望通过结构化的工作流程，让代理能够在较长时间内稳定、高效地完成开发任务。项目采用 MIT 许可证，目前拥有超过 22.6 万星标。

## 核心功能

- **需求探索与规范生成**：代理启动后不会直接写代码，而是先引导用户明确真正要解决的问题，从对话中逐步提炼出可读、可审查的规范文档。
- **分块呈现设计**：将设计规范分为足够小的段落，方便用户实际阅读与消化，避免一次性输出过长而难以理解。
- **实现计划制定**：基于确定的设计方案，代理会生成一份清晰的实现计划，其目标是让一个“热情但缺乏判断力和项目背景的初级工程师”也能准确执行。
- **严格测试驱动开发**：在实施过程中强制遵循红色/绿色 TDD 流程，强调 YAGNI（你不会需要它）与 DRY（不要重复自己）原则。
- **子代理驱动开发**：在用户确认“开始”后，系统会启动子代理（subagent）逐一完成各个工程任务，每个子代理完成后会被自动审查，然后继续下一个任务。
- **长时间自主运行**：借助上述结构，项目宣称 Claude 等代理能够连续自主工作数小时而不偏离最初制定的计划。

## 技术架构

项目的核心思想是将“方法论”与“技能框架”分离。Superpowers 本身是一组可组合的技能（skills）和一组初始指令（initial instructions），这些指令确保代理在启动时自动加载合适的技能集。其工作流程是典型的“需求→设计→计划→执行→审查”五步法，但每一步都由代理自动或半自动完成。技术栈上，项目以 Shell 脚本为主，用于定义触发条件、指令注入和子代理通信，但具体实现依赖于底层 AI 代理平台（如 Claude Code、Codex 等）的能力。设计上强调经验性：从对话中提取规范、从规范生成计划、从计划分解为可执行任务，每个子任务都内置 TDD 循环，从而在缺乏人工介入时保持代码质量。

## 安装与使用

1. **选择代理平台**：Superpowers 支持多种主流编码代理，包括 Claude Code、Codex CLI、Codex App、Factory Droid、Gemini CLI、OpenCode、Cursor 及 GitHub Copilot CLI。
2. **获取配置**：根据所选平台，从项目仓库中获取对应的初始指令文件（通常为 Markdown 或 YAML 格式）。
3. **注入指令**：将指令配置到你的代理启动配置中，确保代理在会话开始时自动加载 Superpowers 框架。
4. **开始项目**：启动代理，描述你的目标。代理将按照前述工作流程逐步引导你完成需求澄清、规范确认、计划制定，最终进入自动化开发阶段。

> **最小可用示例**：在 Claude Code 中，只需将项目提供的系统提示（system prompt）添加到会话启动参数，然后输入“我想为我的 CLI 工具添加日志功能”，代理便会开始询问具体需求。

## 适用场景

- **独立开发者处理复杂项目**：当一个人需要管理多个模块或功能时，Superpowers 的结构化流程可减少上下文切换，让代理在数小时内自主完成阶段性开发。
- **团队集成 AI 开发流程**：团队成员可以统一使用同一套方法论，确保不同代理生成的代码风格、测试覆盖度和设计文档化程度一致。
- **快速原型与迭代**：对于需求不明确但需要快速出结果的场景，代理通过对话式规范生成可以更快捕获用户意图，并自动产出可测试的原型。
- **教育与培训**：新人可以通过观察代理如何遵循 TDD 和 YAGNI 原则，学习良好的软件工程实践。

## 项目亮点

与同类项目（如直接使用 ChatGPT 或其他通用 prompt 模板）相比，Superpowers 的差异化优势在于：

1. **全流程覆盖**：不仅是 prompt，而是一套从需求到测试的完整方法论，每个环节都有明确的代理行为定义。
2. **子代理驱动**：通过子代理+自动审查的机制，大幅减少了人工干预需求，真正实现了“长时间自主运行”。
3. **平台无关性**：框架定义与具体 AI 平台解耦，用户可选择最适合自己生态的编码代理。
4. **经验驱动**：项目强调“对初级工程师友好”的设计，意味着它特别关注对项目上下文缺乏、自发判断力弱的情况做了针对性补偿。
5. **开源与社区支持**：MIT 许可 + 超过 22 万星标，意味着项目已获得广泛验证，并有活跃的社区贡献。
