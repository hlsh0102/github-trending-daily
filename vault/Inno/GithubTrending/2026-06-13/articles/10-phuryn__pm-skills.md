## 项目概述

PM Skills Marketplace 是一个面向产品经理（PM）的开源技能市场，旨在将 AI 助手（如 Claude Code、Cowork 等）从通用文本生成工具转变为结构化的产品决策系统。该项目解决了传统 AI 工具缺乏领域知识、无法执行严谨产品框架的问题，提供超过 100 种经过实战验证的 PM 技能、命令和插件，覆盖从产品发现到增长的全流程。目标用户是希望借助 AI 提升产品决策质量的产品经理、产品负责人、初创团队创始人以及任何参与产品开发的专业人士。

## 核心功能

- **技能库（Skills）**：内置 68 种独立 PM 技能，涵盖用户研究、需求分析、优先级排序、战略规划、实验设计等核心领域，每种技能都封装了特定的产品管理方法论（如假设映射、北星指标定义）。
- **链式工作流（Chained Workflows）**：提供 42 个预定义的工作流，将多个技能按任务逻辑串联，例如从用户访谈到需求优先级排序的完整流程，减少手动切换的认知负担。
- **插件系统（Plugins）**：9 个专用插件，分别聚焦不同 PM 子领域（如竞品分析、路线图生成、发布管理），可独立启用或组合使用。
- **智能命令（Commands）**：通过 `/discover`、`/strategy`、`/write-prd`、`/plan-launch`、`/north-star` 等快捷命令，用户可直接跳转到特定 PM 任务的执行界面，无需重复配置。
- **多 AI 助手兼容**：优先支持 Claude Code 和 Cowork，同时保持与其他主流 AI 助手的兼容性，降低迁移成本。

## 技术架构

项目基于模块化设计，核心层分为三个部分：
1. **技能引擎**：每个技能是一个独立的 Markdown 或 JSON 配置文件，包含上下文提示词、分析框架模板和输出格式规范。技能之间通过依赖注入机制共享数据。
2. **工作流编排器**：采用声明式 YAML 定义链式工作流，支持条件分支、重复步骤和异步执行。工作流可嵌套调用技能，并自动追踪执行状态。
3. **插件 API**：提供标准化的接口规范，允许社区开发者贡献新插件。插件可以扩展技能库、添加自定义命令或集成外部数据源（如 Jira、Notion）。

设计上强调“低耦合、高内聚”——每个技能独立可复用，工作流按任务动态组合。项目根目录的 `pm-brain` 子仓库（链接指向）作为全局知识库，存储产品决策的通用模式和历史经验，供技能和插件共享调用。

## 安装与使用

### 安装步骤
1. **环境要求**：需要安装 Claude Code 或 Cowork（推荐最新版本），或任意支持 OpenAI 格式 API 的 AI 助手。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/phuryn/pm-skills.git
   cd pm-skills
   ```
3. **加载技能库**：将 `skills/` 目录下的配置文件导入 AI 助手的技能加载目录（具体取决于所选工具，Claude Code 需按官方文档配置环境变量）。
4. **初始化配置**：运行 `setup.sh`（可选），自动检测 AI 助手类型并生成最小配置文件。

### 最小可用示例
启动 AI 助手后，直接在对话中输入以下命令之一：
- 需要验证新产品创意：`/discover`
- 需要制定季度战略：`/strategy`
- 需要撰写产品需求文档：`/write-prd`
- 需要规划产品发布节奏：`/plan-launch`
- 需要定义核心指标：`/north-star`

系统会自动加载对应的技能和工作流，引导用户完成结构化输出。例如输入 `/write-prd` 后，AI 会依次要求输入问题陈述、目标用户画像、功能需求列表、成功率指标，最后生成格式化的 PRD 草案。

## 适用场景

- **新产品创意评估**：使用 `/discover` 命令，结合假设映射和快速实验设计技能，在数小时内完成对多个创意的初步验证，而非传统的一周以上。
- **季度战略规划**：调用 `/strategy` 命令，利用北星指标定义、竞品分析和资源分配技能，生成包含目标、关键结果、战术里程碑的季度路线图。
- **PRD 撰写与评审**：团队协作时，通过 `/write-prd` 命令创建标准化文档，再使用 `/review-prd` 技能自动进行完整性检查（如是否包含异常流程、是否定义了取消条件）。
- **发布后增长优化**：使用 `/plan-launch` 插件，结合 A/B 测试设计、用户反馈分析和留存率跟踪技能，制定发布后的最小化增长实验方案。

## 项目亮点

- **方法论固化**：将 Teresa Torres（用户发现）、Marty Cagan（产品战略）、Alberto Savoia（实验驱动开发）等大师的框架转化为可执行的 AI 指令，而非仅仅是文本参考。
- **可扩展社区**：MIT 许可+贡献指南（`CONTRIBUTING.md`），社区开发者可以添加新的技能或插件，目前已有 176+ 活跃贡献（仓库简介数据）。
- **从文档到决策**：区别于只生成“好看的报告”的工具，PM Skills Marketplace 强调输出可执行的下一步行动（如实验计划、优先级矩阵），直接推动产品决策落地。
- **渐近学习曲线**：新手可先用 `/` 命令完成单一任务，高级用户可通过链式工作流和自定义插件构建全自动产品管理流水线。
