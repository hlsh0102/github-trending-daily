## 项目概述

Harness 是一个专为 Claude Code 设计的团队架构工厂插件。它解决的核心问题是：如何将通用 AI 编码助手转变为能够适应特定领域需求的专家代理团队。当你在项目中说出“build a harness for this project”时，Harness 会自动分析你的项目领域，设计出专用的代理团队结构，并为每个代理生成所需的专业技能。

目标用户包括：使用 Claude Code 进行日常开发的软件工程师、需要处理跨领域复杂项目的技术团队、以及希望提升 AI 辅助开发效率和组织能力的个人开发者。Harness 定位为 L3 元工厂层，属于团队架构工厂子层，它本身不直接解决具体问题，而是创建能够解决问题的代理系统。

## 核心功能

- **领域感知的代理团队设计**：自动分析项目上下文，识别出所需的专业角色（如架构师、测试工程师、安全专家等），并为每个角色定义清晰的职责边界。
- **专业技能自动生成**：为每个代理生成其工作所需的技能定义，包括知识库、工作流程和输出规范，确保每个代理都能在其专业领域高效作业。
- **多语言自然语言触发**：支持英语、韩语和日语三种语言的指令输入，用户可以用母语直接启动团队构建流程。
- **六种架构模式支持**：内置六种不同的代理团队架构模式，可根据项目复杂度选择合适的组织结构。
- **Claude Code 深度集成**：作为 Claude Code 的插件运行，无缝融入现有开发工作流，无需切换工具环境。
- **可复用的团队模板**：构建完成的代理团队配置可导出为模板，供同一组织或类似项目重复使用。

## 技术架构

Harness 基于“元技能”设计理念，其核心是一个能够生成其他技能的系统。技术栈层面，它主要依赖 HTML/JavaScript 实现与 Claude Code 的插件交互，并通过结构化的配置文件定义代理团队的组织方式。

架构上，Harness 采用了分层设计：最底层是基础技能库，包含通用的编码、调试、测试等能力；中间层是领域适配层，负责将项目特征映射到合适的代理角色；最顶层是团队编排层，管理多个代理之间的协作与任务分配。

Harness 的创新之处在于引入了“元工厂”模式——它不预设固定的专家团队，而是根据每个项目的具体需求动态生成。这种设计使得同一个系统能够适应从 Web 开发到嵌入式系统，再到机器学习项目等截然不同的技术领域。

## 安装与使用

### 安装步骤

1. 确保已安装并配置好 Claude Code。
2. 克隆 Harness 仓库到本地：
```bash
git clone https://github.com/revfactory/harness.git
```
3. 将 Harness 作为 Claude Code 的插件加载，按照 Claude Code 插件安装指南完成配置。

### 最小可用示例

在 Claude Code 中导航到你的项目根目录，然后输入以下指令：

英文：
> "Build a harness for this project"

中文（实际支持韩语/日语，此处理解为示例）：
> "为这个项目配置团队架构"

Harness 会自动分析项目结构、依赖关系和代码风格，然后输出一个定制的代理团队方案，包括：
- 团队角色定义（3-7个专业代理）
- 每个代理的技能描述
- 团队协作工作流
- 初始化启动命令

## 适用场景

- **大型项目重构**：当对遗留系统进行重大重构时，Harness 可以生成包含架构师、代码分析员、测试验证员等角色的专业团队，确保重构过程系统化且风险可控。
- **跨技术栈项目**：对于前后端分离、微服务架构或多语言项目，Harness 能为每个技术栈分配专门的代理，避免单个通用代理在不同领域间切换导致的效率损失。
- **团队协作开发**：在多人协作的项目中，Harness 创建的代理团队可以作为虚拟开发辅助力量，帮助团队成员在统一框架下高效配合。
- **快速原型验证**：当需要快速验证技术方案可行性时，Harness 能迅速构建出一个最小化的专家团队，加速从概念到原型的过程。

## 项目亮点

与同类项目相比，Harness 最显著的差异化优势在于其“元技能”设计哲学。大多数 AI 辅助开发工具只是提供固定的功能集合，而 Harness 则具备生成新技能的能力，这使得它能够适应无限多的技术领域和项目类型。

另一个亮点是其团队架构的自动化设计能力。传统上，为 AI 定义不同的工作角色需要手动编写复杂的提示词和规则，而 Harness 通过分析项目上下文自动完成这一过程，大幅降低了使用门槛。

Harness 本身收获的社区关注度（4793+ 星标）也证明了其独特的价值定位，尤其在 Claude Code 用户群体中已经形成了良好的口碑。
