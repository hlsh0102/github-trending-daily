## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的高清短视频自动生成工具。用户只需提供一个视频主题或关键词，系统即可全自动完成视频文案撰写、素材抓取、字幕生成、背景音乐搭配，最终合成一个完整的短视频。该项目由 harry0703 开发维护，采用 MIT 开源协议，目前在 GitHub 上已获得超过 75,000 颗星标。

项目致力于解决内容创作者在短视频制作中面临的高门槛、低效率问题。无论你是不擅长剪辑的普通用户，还是需要批量产出视频的运营人员，都可以通过这个工具快速生成质量稳定的短视频内容。核心亮点在于“一键式”操作——从创意到成品，几乎不需要手动干预。

## 核心功能

- **智能文案生成**：基于用户输入的主题或关键词，利用 AI 大模型自动撰写视频脚本，支持多种语言和风格。
- **高清视频合成**：自动匹配与文案内容相关的视频素材（来自线上资源或本地库），并合成清晰度达 720p 甚至 1080p 的最终视频。
- **自动字幕添加**：依据生成的语音内容自动识别并添加字幕，支持字体、颜色、位置等自定义调整。
- **背景音乐匹配**：根据视频氛围自动选择或生成合适的背景音乐，支持节奏同步和音量平衡。
- **多语言与国际化**：项目提供简体中文、英文、阿拉伯文等多语言 README，AI 模型也支持多语种内容生成。
- **可配置化参数**：用户可以通过 Web 界面或命令行参数控制视频时长、画幅比例、配音语种、语速等细节。

## 技术架构

项目主要采用 Python 作为后端开发语言，整体架构分为以下几个层级：

- **前端交互层**：基于 Web 的图形化界面，用户通过浏览器输入主题和参数，发起视频生成任务。
- **AI 模型层**：对接 OpenAI、Claude、Gemini、DeepSeek、智谱、千问等多个大语言模型，负责文案生成和内容规划。项目赞助方 AIHubMix 提供了模型接入的中间层，支持快速切换模型版本。
- **媒体处理层**：使用 FFmpeg、PIL 等工具进行视频合成、字幕嵌入、音频混流。素材检索和筛选通过预构建的搜索引擎或第三方 API 实现。
- **任务调度层**：支持异步任务队列，多用户并发请求时能公平分配计算资源。
- **存储与缓存层**：本地文件系统或云存储（如 S3）用于保存素材和生成的视频，Redis 或内存缓存用于加速模型响应。

架构设计上强调“模块解耦”和“可替换性”。例如，文案生成模块可以无缝切换不同 LLM 后端，素材来源也可以从网络图库替换为本地文件夹，方便用户根据需求定制。

## 安装与使用

### 基本安装步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/harry0703/MoneyPrinterTurbo.git
   cd MoneyPrinterTurbo
   ```

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

3. **配置 API 密钥**  
   复制配置模板并填写 AI 模型 API 密钥（如 OpenAI 或 AIHubMix）。
   ```bash
   cp config.example.yaml config.yaml
   # 编辑 config.yaml 填入 KEY
   ```

4. **启动 Web 服务**
   ```bash
   python app.py
   ```
   默认访问 `http://localhost:8080`。

### 最小可用示例

在 Web 界面中输入主题“科普：黑洞的形成”，选择视频时长 60 秒，语言中文，点击生成。等待约 1-3 分钟，系统便会输出一个带配音、字幕和背景音乐的短视频文件。

若使用命令行模式，只需执行：
```bash
python run.py --topic "科普：黑洞的形成" --duration 60 --language zh
```

## 适用场景

- **自媒体内容制作**：短视频博主可以快速产出科普、资讯、影评等类型视频，极大降低日更压力。
- **企业营销推广**：产品介绍、活动宣传等短视频需求量大，通过此工具可批量生成不同主题的宣传片。
- **教育与培训**：教师或培训师可将课程要点自动转化为短视频，便于学员碎片化学习。
- **个人灵感实验**：创意工作者可用它快速将脑洞（如解说一支虚构电影）落地为可观看的短片。

## 项目亮点

- **极低的输入门槛**：同类工具通常要求用户提供详细文案、素材关键词或字幕 SRT，而 MoneyPrinterTurbo 只需一个主题词即可，其余全部自动化。
- **多模型兼容**：不绑定单一 LLM 供应商，支持 OpenAI、Claude、本地模型等，用户可根据成本或质量偏好灵活选择。
- **高清输出**：最终视频清晰度可达到 1080p，满足主流短视频平台的上传要求。
- **高度可定制**：从配音语速、字幕风格到背景音乐类型，均有参数可供调整，不是“千篇一律”的模板式产出。
- **活跃的社区与商业支持**：项目位居 GitHub 趋势榜单前列，拥有大量 Star 和镜像，赞助方 AIHubMix 提供了稳定的模型接入通道，降低了用户的使用门槛。
