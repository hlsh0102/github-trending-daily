## 项目概述

Compound Engineering Plugin 是一个面向 AI 编程助手（如 Claude Code、Codex、Cursor 等）的官方插件，由 EveryInc 开发。该项目旨在解决软件开发过程中普遍存在的技术债务累积问题——每一次功能添加或 Bug 修复都会增加代码库的复杂性，使得后续的工程工作越来越困难。

该插件的核心理念是让**每一个工程单元都为后续工作提供正向积累**，而不是制造障碍。它将 80% 的精力投入在规划和评审阶段，20% 用于执行，通过结构化的 AI 工作流帮助开发者构建可持续的工程体系。目标用户是使用 AI 编程工具的专业开发者、技术团队以及任何希望提升代码质量和开发效率的工程师。

## 核心功能

- **智能规划（/ce-brainstorm 和 /ce-plan）**：在编写代码前进行结构化头脑风暴和方案规划，帮助开发者理清思路、识别风险，生成可执行的执行计划，减少盲目编码带来的返工。
- **代码评审（/ce-code-review）**：基于项目上下文和最佳实践进行自动化代码审查，不仅发现 Bug 和性能问题，还能识别设计模式中的隐患，校准开发者的工程判断。
- **文档评审（/ce-doc-review）**：对项目文档进行一致性、完整性和可理解性检查，确保技术文档与代码实现同步，降低新成员的上手成本。
- **知识固化（/ce-compound）**：将评审中学到的经验、发现的模式、解决的典型问题转化为可复用的“复合笔记”，让未来相同的任务不再需要重新学习，实现知识的持续积累。
- **多平台支持**：兼容 Claude Code、Codex、Cursor 等多种主流 AI 编程助手，开发者无需切换工具即可获得一致的工程体验。

## 技术架构

该插件基于 TypeScript 开发，采用模块化设计，核心架构分为三个层次：

1. **命令层**：定义了一系列以 `/ce-` 为前缀的 Slash 命令（如 `/ce-plan`、`/ce-code-review`），每个命令封装了特定的 AI 能力，通过自然语言接口与开发者交互。
2. **工作流层**：每个命令背后都包含精心设计的提示词模板和上下文管理逻辑，能够自动收集当前项目文件、Git 历史、依赖关系等信息，确保 AI 输出的准确性和相关性。
3. **知识库层**：支持将评审和规划中产生的结构化知识持久化存储，形成团队可共享的“工程记忆”，随着项目发展持续丰富。

架构上的关键设计思路是“轻执行、重思考”——插件并不追求自动化完成所有编码任务，而是通过 AI 辅助强化开发者的决策质量。这种设计使得工具本身不会增加额外复杂性，反而通过提前发现问题来减少后期的返工成本。

## 安装与使用

### 安装

该插件可通过 npm 安装，并配置到 AI 编程工具中：

```bash
npm install @every-env/compound-plugin
```

在支持的 AI 编程工具（如 Claude Code、Codex）中，按照官方文档将该插件添加到环境配置中即可启用。

### 最小可用示例

假设你正在开发一个新功能，可以这样使用插件：

1. **启动规划**：在 AI 编程助手中输入 `/ce-plan "为用户模块添加邮箱登录功能"`，插件会自动分析现有代码结构，生成包含任务拆解、风险点预测和技术方案的执行计划。
2. **执行代码**：根据计划编写代码。
3. **代码评审**：完成编写后，运行 `/ce-code-review`，插件会审查代码质量，指出潜在问题，并给出改进建议。
4. **知识固化**：如果评审过程中发现了值得记录的模式或技巧，运行 `/ce-compound "邮箱验证的最佳实践"`，保存结构化笔记供将来复用。

## 适用场景

- **新功能开发**：在编写新功能前进行系统规划，确保方案经过充分推演，减少后期重构风险。
- **代码重构**：利用评审功能识别技术债务，规划渐进式重构路径，避免大规模重写带来的冲击。
- **团队协作**：通过知识固化功能，将资深工程师的经验转化为可查询的知识库，降低团队沟通成本。
- **开源项目维护**：在合并 Pull Request 前使用代码评审功能，确保贡献代码符合项目风格和质量标准。

## 项目亮点

与同类 AI 编程插件相比，Compound Engineering Plugin 的差异化优势在于：

- **关注长期价值**：大部分 AI 插件专注于帮助“更快地写代码”，而该插件更注重“写更可持续的代码”，通过规划和评审环节提前节省未来的维护精力。
- **知识复用机制**：独创的“复合笔记”功能，让 AI 辅助的经验可以像代码一样版本管理和复用，避免每次都需要重复教导 AI 同样的上下文。
- **低侵入性**：遵循 80/20 原则，只增加必要的规划和评审环节，不强制改变开发者的工作习惯，可根据需要灵活启用特定命令。
- **跨平台兼容**：支持主要 AI 编程工具，避免被单一平台绑定，团队可以在不同工具间保持一致的工程流程。
