## 项目概述

diagram-design 是一个面向 AI 编程助手（Claude Code、Codex、Pi 等）的图表设计工具包，提供 39 种编辑级（editorial-grade）图表类型。项目的核心主张是：生成的图表应该让专业设计师看了不皱眉，而不是千篇一律的 Mermaid 默认风格或带阴影的通用圆角矩形。

该项目的目标用户是需要在文档、演示、架构说明中展示高质量图表的开发者、技术写作者和产品团队。它解决了当前 AI 生成图表时普遍存在的视觉粗糙问题——默认样式缺乏设计感，难以直接用于对外发布的技术文档或博客。

项目采用完全自包含的 HTML + SVG 方案，不依赖 Figma 或任何外部编辑器。MIT 许可证允许自由使用和修改，GitHub 上已累积超过 3 万星标，社区认可度极高。

## 核心功能

- **39 种编辑级图表类型**：涵盖架构图、流程图、循环图、Sankey 图、鱼骨图、Wardley 地图、看板、用户旅程图、部署图、依赖关系图、UML 类图、故事地图和数据库模式图等多种布局语法。
- **语义模式与布局分离**：通过语义模式（semantic patterns）描述行为而非特定布局，队列、策略追踪、信任边界等概念可以复用现有类型，无需扩充类型数量。
- **零依赖静态输出**：所有图表均为自包含 HTML + SVG 文件，无阴影、无 Mermaid "流水线产物"风格，视觉风格干净、编辑级。
- **可选无障碍动态效果**：静态 HTML 为默认输出，同时也支持为有序讲解提供可选的动画效果，兼顾可访问性。
- **外部源文件重绘**：能接收 draw.io 或 Mermaid 格式的源文件，按要求格式、尺寸和细节级别重新绘制，提升视觉质量。
- **多平台兼容**：适配 Claude Code、Codex、Factory Droid、Pi 及任何符合 Agent Skills 规范的宿主环境。

## 技术架构

项目以一套精心设计的 HTML + SVG 模板库为核心，每个图表类型都是独立的、可移植的 HTML 片段。其架构设计有几个显著特点：

1. **语义层与布局层解耦**：这是项目最核心的设计思想。语义模式（如"队列排队"）被抽象描述，与视觉呈现方式分离。这意味着同一个语义概念可以套用多种已有布局，而不必为每个新概念单独发明一种图表类型。

2. **设计规范内置**：每个模板都经过视觉设计考量——配色、字体、间距、对齐方式等细节都被精心处理，避免了常见的"AI 生成图表"视觉缺陷（如阴影过重、圆角滥用、色彩搭配混乱）。

3. **零运行时依赖**：输出结果是纯静态 HTML+SVG，无需加载任何 JavaScript 库或外部字体，可在任何现代浏览器中直接打开，也方便嵌入文档系统，或进一步人工定制。

4. **开放性接口**：作为 Agent Skill，它适配现有 AI 编码助手的工具调用约定，可无缝集成到工作流中。

## 安装与使用

安装和使用都非常直接。以 Claude Code 为例：

1. **Clone 仓库**：
   ```bash
   git clone https://github.com/cathrynlavery/diagram-design.git
   ```

2. **安装为 Skill**（或直接引用目录）：
   在 Claude Code 的技能配置中添加本仓库路径，使工具提示词和模板可被模型调用。

3. **调用示例**——在对话中提出如下指令：
   ```
   请绘制一个系统架构图，包含用户、网关、三个微服务和数据库。
   使用 diagram-design 的 architecture 类型，输出 HTML+SVG。
   ```

4. **修改输出**：如需调整尺寸、配色或细节层级，可以直接指定，例如"以 1024px 宽、低细节模式输出"，技能会自动重绘。

5. **从现有源文件改善**：将 Mermaid 或 draw.io 的 XML 内容提供给 Agent，指示"用 diagram-design 按编辑标准重画这张图"，即可获得风格统一的图表。

## 适用场景

- **技术文档与博客配图**：为教程、API 文档、产品说明绘制视觉上可发布的架构图与流程图，不再是"程序员默认手绘风"。
- **企业内部工具与演示材料**：在幻灯片、Notion 页面、Confluence 等内部系统中，生成风格统一、信息清晰的图表。
- **AI 编码辅助的日常输出**：当 AI 助手需要解释代码结构、数据流或部署拓扑时，直接生成高视觉质量的图表，减少后续人工处理。
- **从旧工具链迁移视觉升级**：将既有 Mermaid 或 draw.io 图表交给本工具重绘，快速整体提升团队文档的视觉标准。

## 项目亮点

同类项目中不乏图表工具，但 diagram-design 的差异化优势十分明显：

- **设计标准先行**：大多数 AI 图表工具输出的是"无设计"的默认样式，本项目则内置了专业视觉规则，从根上消除"廉价感"。
- **无依赖、易嵌入**：相比在线工具或需要特定运行时，自包含 HTML+SVG 意味着图表文件可直接分享、嵌入、二次修改。
- **语义设计让类型更精简**："38 种类型"覆盖的范围远超同类（凭借语义复用），用户无需记住海量模板名。
- **顺应 AI 工作流**：作为 Agent Skill 而非独立应用，它贴合"对话即交互"的趋势，可以自然地融入编码助手的输出习惯。
- **开源与社区驱动**：MIT 许可，结合高星标趋势，表明其已被大量开发者验证并采纳。
