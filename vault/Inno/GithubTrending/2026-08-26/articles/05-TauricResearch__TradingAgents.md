## 项目概述

TradingAgents 是一个基于多智能体（Multi-Agent）大语言模型（LLM）的金融交易框架，由 TauricResearch 团队开发并开源。该项目旨在利用多个具备不同角色和职责的 LLM 智能体，模拟真实金融分析团队的工作流程，从而为股票交易提供全面、理性的决策支持。

传统量化交易系统往往依赖于历史数据的统计分析，而 TradingAgents 则另辟蹊径，通过构建一个由“基本面分析师”、“情绪分析师”、“技术分析师”、“风险管理顾问”和“交易员”等角色组成的智能体团队，让它们协同工作。每个智能体负责特定的分析维度，通过多轮讨论、辩论和共识达成，最终形成投资决策。项目已在 arXiv 发表论文（arXiv:2412.20138），并获得了社区的高度关注，目前已在 GitHub 上累积超过 10 万 Star。

该项目的目标用户包括：希望借助 LLM 能力辅助投资决策的个人投资者、研究金融 AI 方向的高校科研人员、以及探索智能体协作在垂直领域落地的开发者。

## 核心功能

- **多角色智能体协作**：内置基本面分析师、情绪分析师、技术分析师、风险管理顾问、交易员等多个智能体，每个智能体都由独立的 LLM 提示词驱动，模拟不同领域的专家。
- **辩论式决策机制**：不同智能体之间可以进行多轮辩论与讨论，通过观点的碰撞与融合，模拟真实投研团队的决策流程，最大程度减少单一模型“幻觉”或偏见的干扰。
- **多维度市场分析**：各智能体分别从财务数据、新闻舆情、技术指标、宏观经济等多个维度对目标股票进行深入分析，输出结构化的分析报告。
- **综合决策输出**：交易员智能体在综合各维度分析报告与风险提示后，生成最终的投资建议，包括买入/卖出/持有评级、建议仓位及风险提示。
- **一站式研究面板**：提供交互式的 Gradio Web 界面，用户可以通过图形化界面输入股票代码，直观查看所有智能体的分析过程与最终交易决策。
- **基于真实数据的回测支撑**：支持接入多种市场数据源（如 Yahoo Finance），为智能体提供真实的历史与实时行情数据，保证分析的时效性与可用性。

## 技术架构

TradingAgents 的核心架构建立在“角色化提示词”与“多轮对话管理”之上。项目基于 Python 开发，深度整合了 LangChain 生态，利用其标准化的 LLM 调用接口与链式处理能力来编排复杂的多智能体逻辑。

在数据层面，框架通过 YFinance 等工具获取实时与历史股票数据，并配合如 `NewsSentiment` 等 NLP 工具对新闻进行情感分析。所有外部数据经过预处理后，被格式化打包为统一的知识上下文，注入到相应角色的提示词中。

在流程编排层面，项目的核心设计并非简单的流水线，而是一个**有向图结构的工作流**。其遵循经典金融分析逻辑，即“自下而上与自上而下相结合”：首先由各个分析师智能体并行进行独立分析，随后进入一个由 LLM 驱动的“讨论与辩论”环节，最后风险管理顾问对拟议交易进行审查，最终由交易员综合所有意见下达指令。这种架构使得系统具备高度的模块化特性，开发者可以轻松替换或扩展不同的智能体角色，或调整辩论轮数。

## 安装与使用

项目支持通过 pip 快速安装依赖，并提供了开箱即用的 Gradio 界面。

**1. 克隆仓库并安装依赖**
```bash
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
pip install -r requirements.txt
```

**2. 配置环境变量**
在项目根目录创建 `.env` 文件，并填入你的 LLM API 密钥（默认支持 OpenA 等模型）：
```
OPENAI_API_KEY=你的_API_密钥
```
如需自定义模型或使用代理，可在 `config.py` 中进行调整。

**3. 启动 Web 界面**
```bash
python app.py
```
启动后，在浏览器中打开 `http://localhost:7860`，输入股票代码（如 `AAPL`、`TSLA`），点击提交即可运行完整的分析流程并输出交易决策。

**4. 命令行模式（可选）**
对于需要批量处理或集成的场景，你可以直接调用核心脚本：
```python
from tradingagents import TradingAgents
from utils import *

# 初始化配置与LLM
llms = LLM_config()
ta = TradingAgents(llms_config=llms, stock='AAPL')

# 运行分析
result = ta.run()
print(result)
```

## 适用场景

- **个人投资辅助研究**：对于缺乏专业金融分析团队的个人投资者，TradingAgents 可作为一个强大的研究助手，快速归纳多维度信息并提供结构化的投资论点，辅助用户做出更审慎的决策。
- **金融 AI 学术研究**：作为多智能体系统（MAS）在金融领域的典型应用案例，研究者可以基于该框架验证不同的智能体交互策略（如辩论、投票、分层管理）对决策质量的影响。
- **量化策略的信号增强**：量化爱好者可以将该框架输出的综合分析结论（如情绪打分、风险等级）作为额外的 alpha 信号因子，融合进传统的量化回测系统中。
- **金融教育演示**：对于金融科技相关课程，该项目的可视化界面和透明化推理过程，是讲解 AI 如何与金融投资理论结合的优秀教学演示工具。

## 项目亮点

与市面上其他针对特定金融任务的 AI 工具（如单纯的情感分析 API 或财报解读工具）相比，TradingAgents 的最大差异化优势在于**模拟了真实的群体决策生态**。它不仅仅依赖单一模型，而是通过多角色辩论机制有效制衡了单一大模型的偏差，提升了决策的稳健性。

此外，该项目在学术严谨性和工程可用性之间取得了很好的平衡。它不仅以高质量论文的形式发表了方法论，还提供了完整可运行、界面友好的开源代码，拥有 Apache 2.0 宽松许可证，开发者可以自由地将其集成到自有系统中，甚至完全替换底层的 LLM 模型，极大降低了二次开发的门槛。
