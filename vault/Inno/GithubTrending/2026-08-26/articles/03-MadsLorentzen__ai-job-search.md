## 项目概述

AI Job Search 是一个运行在你本机上的 AI 求职应用框架，基于 Claude Code 构建。它解决了求职过程中的一个核心痛点：大量重复性、高认知负担的工作——评估职位匹配度、定制简历、撰写求职信、准备面试——原本需要花费数小时甚至数天，现在可以交由 AI 辅助完成。

该项目由地球物理学家 Mads Lorentzen 在 2025 年底因职位被裁后创建，最初是用于管理自己求职流程的内部工具，后来开源并迅速获得社区关注。目标用户是正在积极寻找工作的求职者，尤其是那些希望利用 AI 技术提升求职效率、同时又不愿将个人数据上传到云端服务的人群。

项目的核心理念是"Fork it and own it"——你将整个仓库复制到自己的账号下，填入个人资料，即可拥有一个完全属于你自己的 AI 求职助手。所有数据和处理都发生在你的机器上，没有云端依赖，没有订阅费用，也没有隐私泄露的担忧。

## 核心功能

- **职位评估**：AI 自动分析招聘启事，对比你的技能与岗位要求，给出匹配度评分和关键差异点分析。
- **简历定制**：根据目标职位自动调整简历中的技能排序、经历描述和关键词，使其更贴合 ATS（申请人跟踪系统）和招聘官的需求。
- **求职信生成**：基于职位描述和你的个人背景，自动生成有针对性、个性化的求职信草稿。
- **面试准备**：根据具体职位生成模拟面试问题，并提供回答思路和建议，帮助你提前演练。
- **申请跟踪**：内置流程管理，记录每个职位的申请状态、沟通历史和后续跟进计划。
- **全本机运行**：所有 AI 调用和数据处理都在本地完成，你的简历、求职信和求职历史不会被发送到第三方服务器。

## 技术架构

项目建立在 Claude Code 之上，这是一款由 Anthropic 推出的命令行 AI 编程工具。AI Job Search 利用 Claude Code 的 agentic 能力——即 AI 不仅能回答问题和生成文本，还能自动执行文件操作、运行命令、管理复杂任务流程。

整个框架的核心设计思路是将求职流程拆解为多个可复用的 prompt 和脚本模块。每个模块对应一个求职子任务（如职位评估、简历定制、求职信写作），并通过标准的文件结构进行数据传递。用户只需在配置文件中填写个人信息（工作经历、技能、教育背景等），AI 就能基于这些信息执行上述功能。

仓库采用 Python 作为主要语言，辅以脚本化的 prompt 文件管理 AI 交互逻辑。项目的设计强调"透明可控"——所有 AI 生成的中间结果都以 Markdown 文件形式保存在本地，用户可以随时检查和修改，而不是作为一个不可干涉的黑盒。

架构上的另一个特点是高度的可定制性。由于整个框架以文件和 prompt 的形式组织，用户可以方便地修改任何环节的提示词，调整 AI 的行为风格，甚至添加新的功能模块。

## 安装与使用

基本安装步骤如下：

1. 在 GitHub 上 Fork [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search) 仓库到自己的账号。
2. 将仓库克隆到本地：`git clone https://github.com/your-username/ai-job-search.git`
3. 安装 Claude Code（需具备 Anthropic API 访问权限）。
4. 在 `profile.yaml` 或对应的配置文件中填写你的个人信息：姓名、工作经历、技能列表、目标行业、简历文件路径等。
5. 在配置中填入常用求职网站（如 LinkedIn、公司招聘页）的搜索偏好。

最小可用示例：

```bash
# 在仓库根目录下启动 Claude Code
claude

# 运行职位搜索与评估
/assess https://example.com/job-posting

# 生成定制化简历
/tailor resume

# 撰写求职信
/cover-letter https://example.com/job-posting
```

首次使用建议先运行 `/help` 查看完整的命令列表和推荐工作流。

## 适用场景

- **大规模求职**：当你同时申请多个职位，需要高效批量评估和材料定制时，本框架能显著节省时间。
- **隐私敏感型求职**：当前在职或对数据隐私高度关注的人，不愿将求职意向和简历数据提交至第三方 SaaS 服务，本项目的全本机运行特性是理想选择。
- **开发者/技术从业者**：熟悉命令行和 Git 工作流的人群能更快上手，并且可以根据自身需求修改框架代码。
- **非英语母语求职者**：AI 辅助生成的求职信和简历能帮助克服语言障碍，产出更规范、专业的申请材料。

## 项目亮点

- **数据主权**：求职数据完全存储在本机，没有云端中间商，从根本上解决了求职数据隐私问题。
- **完全免费**：除 Anthropic API 调用费用外，项目本身完全开源且免费，没有任何隐藏付费模式或代币机制。
- **高度可定制**：不同于封闭的 SaaS 求职工具，用户可以修改任何 prompt、调整 AI 行为、扩展功能，真正"拥有"你的求职流程。
- **真实世界验证**：项目作者使用该框架成功完成了自己的求职过程，不是实验室产物，而是经过实战检验的工具。
- **社区驱动**：以 35k+ stars 的规模快速增长，社区活跃度高，持续有改进和功能扩展。
