## 项目概述

claude-obsidian 是一个面向 Obsidian 与 Claude Code 的自组织 AI 第二大脑系统。它允许用户将任何来源的资料（网页、文档、笔记等）直接导入，由 Claude 自动完成阅读、关联和归档，最终形成一张彼此连接的个人知识图谱，所有内容均以纯 Markdown 格式保存，用户完全拥有自己的数据。

该项目解决了个人知识管理（PKM）中的核心痛点：知识碎片化与关联缺失。传统笔记工具依赖用户手动整理标签和链接，而 claude-obsidian 通过 AI 自动识别概念之间的语义关系，将散落的资料编织成有机的知识网络。它既是 AI 笔记工具，也是一个开源的非 Notion 替代方案，基于 Karpathy 提出的 "LLM Wiki" 模式构建——即利用大语言模型将非结构化信息转化为结构化的、可检索的维基式知识库。

项目主要面向 Obsidian 重度用户、研究者、知识工作者以及所有希望构建长期个人知识库但对数据隐私有要求的用户。无论您是学生整理课程资料，还是专业人士沉淀行业洞察，都能从中获益。

## 核心功能

- **多源输入与自动处理**：支持网页链接、PDF、Markdown 文件等多种来源，一键导入后由 Claude 自动提取关键信息。
- **智能关联与图谱构建**：AI 自动分析笔记内容，识别概念、主题之间的语义联系，生成双向链接并更新知识图谱。
- **基于知识库的问答检索**：可以针对已建立的知识库提问，系统基于库内内容生成有据可查的回答，而非依赖模型固有知识。
- **主动的库健康维护**：自动检测并修复断链、重复笔记、未归类文件等问题，保持知识库整洁有序。
- **15 个专用技能模块**：内置 15 个面向不同场景的技能（如摘要、对比、时间线生成等），覆盖知识管理的全过程。
- **本地优先与完全所有权**：所有数据以纯 Markdown 格式存储在本地，不依赖云端服务，用户随时可迁移、备份或二次处理。

## 技术架构

claude-obsidian 采用 Python 构建，作为 Claude Code 插件及兼容 Agent Skills 标准的宿主系统运行。其设计核心遵循 Karpathy 的 "LLM Wiki" 模式：不试图用 AI 替代用户的思考，而是利用 AI 的语言理解能力，将输入的原始材料转化为带语义结构的 Markdown 笔记，并通过链接形成可导航的图谱。

架构上，系统采用技能（Skill）模块化设计，每个技能封装特定的 AI 提示词与处理流程，可独立调用、组合或扩展。这种设计允许用户根据需求灵活装配工作流，例如先"导入并总结"再"关联到现有主题"。

在数据流层面，输入源首先被转换为标准 Markdown 中间格式，然后经过 Claude 的分析（提取实体、识别主题、生成摘要），最后写入 vault 并在 Obsidian 中呈现为带 frontmatter 和双向链接的笔记。整个流程在本地执行，仅将必要的内容发送给 Claude API（用户可配置），最大程度保护隐私。同时，系统与 Obsidian 的文件结构完全兼容，可直接使用其图谱视图、搜索等原生功能进行可视化与浏览。

## 安装与使用

### 基本安装（以 Claude Code 插件方式）

1. **前置要求**：确保已安装 Node.js（≥16）、Python（≥3.9）以及 Claude Code。
2. **安装插件**：在 Claude Code 中执行插件安装命令，或者在项目目录下克隆仓库并运行 `pip install -r requirements.txt`。
3. **配置 API 密钥**：如使用 Anthropic API，需在环境变量中设置 `ANTHROPIC_API_KEY`。
4. **初始化 vault**：在 Obsidian 中创建（或指定）一个空仓库目录，作为知识库根目录。

### 最小可用示例

```python
# 在 Claude Code 中发送指令
/import https://example.com/article   # 导入网页
/claude-obsidian summarize            # 让 AI 总结内容
/claude-obsidian ask "什么是 X？"       # 基于库内内容提问
```

运行后，打开 Obsidian 即可看到新生成的笔记，其中包含 AI 提取的摘要、原始链接以及自动添加的相关主题链接。详细信息请参阅 `docs/install-guide.md`，Windows 用户可参考 WSL 指南。

## 适用场景

- **研究文献管理**：对学术论文、技术文章进行批量导入和自动关联，构建个人学术知识库，支持按主题检索与观点溯源。
- **产品与市场洞察**：收集竞品信息、用户反馈、行业报告，自动聚类并生成趋势分析，辅助战略决策。
- **团队内部 Wiki 升级**：将分散在文档、聊天记录、会议纪要中的知识统一导入，由 AI 整理成结构化的内部百科。
- **持续学习与创作输出**：将阅读笔记、课程资料、灵感碎片系统化，形成相互连接的知识体系，为写作或课程设计提供素材。

## 项目亮点

- **真正的"自组织"体验**：不同于传统笔记工具需要用户手动维护，该插件实现了知识库的自我整理与进化，使用越频繁，图谱连接越丰富。
- **开箱即用的完整系统**：提供 15 个预构建技能，覆盖从捕获到检索的完整闭环，无需用户编写任何 Python 或提示词即可上手。
- **数据主权与可移植性**：所有笔记均为标准 Markdown 文件，无专有格式锁定，用户可以随时离开或迁移到其他工具。
- **本地优先的隐私设计**：默认配置下，文本内容在本地处理，仅将必要数据发送给 API，且支持完全离线运行（如使用本地模型）。
- **活跃的社区与扩展生态**：遵循 Agent Skills 标准，可与其他 1500+ 技能组合使用，且项目自身迭代迅速（当前 v2.1.1），保持与最新模型功能同步。
