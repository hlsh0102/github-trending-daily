## 项目概述

Apache Maka（孵化中）是一个面向真实工作场景的本地优先 AI Agent 工作空间。它由 Apache 软件基金会孵化，旨在解决 AI 智能体在实际开发与运维任务中缺乏透明度、可控性和可审计性的问题。Maka 允许智能体检查项目、在沙箱边界内运行工具，并将模型消息、工具调用、工具结果、权限决策和终止事件全部记录为追加式日志。目标用户包括开发者、DevOps 工程师、技术负责人以及任何需要在本地环境中安全、可控地运行 AI 代理完成实际任务的个人或团队。

## 核心功能

- **本地优先架构**：所有数据和日志默认存储在本地，无需将敏感项目信息上传至云端，保障数据主权与隐私安全。
- **追加式日志系统**：完整记录模型消息、工具调用、工具结果、权限决策及终止事件，形成不可篡改的审计轨迹，方便事后回溯与调试。
- **沙箱工具执行**：工具调用在受限的沙箱边界内运行，有效隔离智能体行为，降低误操作或恶意指令对宿主机的影响。
- **权限决策控制**：在执行关键操作前，Maka 会请求用户授权，用户可逐条批准或拒绝工具调用，实现细粒度的控制。
- **跨平台桌面应用**：提供 macOS（Apple Silicon）原生支持，Windows 提供未签名预览版，Linux 支持正在规划中。
- **Apache 2.0 开源许可**：完全开源，允许自由使用、修改和分发，适合个人和企业级二次开发。

## 技术架构

Maka 采用 TypeScript 作为主要开发语言，结合现代桌面应用框架构建跨平台客户端。其核心设计思路围绕“事件溯源”与“可控执行”展开：

- **事件溯源模型**：智能体的每一次动作（模型输出、工具调用、结果返回）都作为不可变事件追加到日志中。这种设计使得整个执行过程可以重放、校验和审计，极大提升了系统的可观测性。
- **沙箱隔离机制**：工具执行环境被封装在独立的沙箱进程中，通过系统级权限控制（如 macOS 的 Seatbelt 或 Windows 的 AppContainer）限制文件系统访问和网络请求，确保智能体行为不会越界。
- **权限决策引擎**：在工具调用链中嵌入决策点，根据预设策略（如白名单、每次询问）来决定是否放行操作。决策结果本身也作为事件记录，形成完整的责任链。
- **前端与后端分层**：桌面 UI 负责展示日志与交互，核心 Agent 引擎与日志存储服务分离，便于独立演进和测试。

## 安装与使用

### 安装步骤

1. **下载客户端**：前往 [GitHub Releases](https://github.com/apache/maka/releases) 页面，根据操作系统下载对应的安装包（macOS arm64 或 Windows 预览版）。
2. **安装应用**：macOS 用户将应用拖入“应用程序”文件夹；Windows 用户运行安装程序（注意预览版未签名，需手动确认）。
3. **首次启动**：启动 Maka 后，按照引导创建本地工作区并配置默认沙箱权限策略。

### 最小可用示例

以下为在 Maka 中配置一个简单任务的基本流程：

```typescript
// 1. 在 Maka 工作区中初始化一个项目
import { createWorkspace } from '@apache/maka';

const ws = await createWorkspace({
  projectPath: '/path/to/your/project',
  sandbox: { strict: true } // 开启严格沙箱
});

// 2. 向智能体发送指令
const task = ws.agent.run('列出当前目录结构并统计 .ts 文件数量');

// 3. 查看追加式日志
ws.logs.forEach(entry => {
  console.log(`[${entry.type}] ${entry.content}`);
});
// 输出会包含模型消息、工具调用（如 ls, find）、返回结果及权限决策记录

实际使用中，用户主要通过桌面 GUI 操作，无需编写代码。上述示例仅展示 API 设计思路。

## 适用场景

- **本地代码库分析与重构**：智能体在沙箱中安全地扫描项目结构、分析依赖、识别潜在重构点，全程日志可追踪。
- **自动化运维任务**：执行脚本、检查服务状态、处理日志文件等运维操作，沙箱边界防止误伤生产环境。
- **AI 辅助调试与测试**：让智能体自动运行测试用例、生成故障报告，所有执行细节均留有记录，便于开发者审查。
- **敏感数据环境中的 AI 应用**：对于金融、医疗等对数据合规有严格要求的场景，本地优先特性确保敏感代码与数据不出内网。

## 项目亮点

- **可审计性标杆**：绝大多数同类工具缺乏完整的操作日志，Maka 将“记录一切”作为默认行为，这在企业级应用中具有重大价值。
- **沙箱与权限的深度集成**：不只是简单限制，而是将授权决策纳入事件日志，实现“谁在何时因何原因批准了什么操作”的完整链路。
- **Apache 基金会背书**：作为 Apache 孵化项目，拥有成熟的开源治理模式、社区审查和持续集成保障，路线图透明。
- **本地优先的隐私理念**：与主流云端 AI Agent 服务形成差异化，满足离线环境与高保密性需求。
