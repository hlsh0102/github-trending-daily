## 项目概述

**AI Engineering from Scratch** 是一个面向 AI 工程师的开源学习资源库，旨在帮助开发者从零基础逐步掌握人工智能工程的核心技能，并将其应用于实际项目中。项目的口号是“Learn it. Build it. Ship it for others.”——它不只是一本教科书，更是一部从理论学习到工程实践的完整行动指南。

该仓库由开发者 rohitg00 发起，目前包含 **511 节课程**，被系统性地划分为 **20 个阶段**，覆盖从 Python 基础、机器学习原理，到深度学习、自然语言处理、LLM 应用开发，再到部署上线、系统设计等完整工程链路。项目采用 MIT 许可证，完全免费开放，并已在 GitHub 上获得超过 4.9 万颗星。

项目的目标用户包括：希望进入 AI 领域的软件工程师、计算机专业学生、转行学习者，以及希望系统梳理知识体系的在职 AI 从业者。无论你是从未写过一行代码的初学者，还是已有经验但缺乏工程化视角的开发者，都能从中找到适合自己的学习路径。

## 核心功能

- **分阶段系统课程**：511 节课程被组织为 20 个逻辑连贯的阶段，从基础到高级、从理论到实践，形成一条清晰的学习路径，避免常见的“知识碎片化”问题。
- **理论 + 实践 + 项目三位一体**：每门课程不仅讲解原理，还配备可运行的代码示例、动手练习和完整项目，确保你能将所学立即转化为成果。
- **项目驱动学习**：项目强调“为他人构建”，鼓励学习者将作业项目发布为开源软件或线上服务，真正体验从编码到交付的完整流程。
- **多语言支持**：除了英文原文，项目已提供了包括西班牙语、法语、葡萄牙语、中文、日语、韩语、印地语、阿拉伯语、俄语等数十种语言的翻译落地页，课程页面仍在持续翻译中，极大地降低了非英语使用者参与的门槛。
- **社区友好与开放协作**：通过 GitHub Issues、Discussions 和微信群等渠道，学习者可以获得帮助、分享经验，并直接参与项目内容的改进与扩展。

## 技术架构

从技术栈来看，项目以 **Python** 作为主要教学语言，这符合 AI 领域的主流实践。课程内容涉及 NumPy、Pandas、Scikit-learn、TensorFlow/PyTorch、Hugging Face Transformers、FastAPI、Docker、Kubernetes 等主流工具与框架。

在内容组织结构上，项目采用了 **教科书式的手写课程结构**，所有内容均以 Markdown 编写，存储在仓库的 `lessons/` 与 `projects/` 目录下。这种纯文本格式具有极高的可移植性和版本控制友好性，方便开发者通过 `git clone` 直接获取全部内容，并可在本地离线阅读和定制。

项目的设计思想是“**从第一性原理出发**”。它尽量减少对黑盒 API 的依赖，侧重于让学习者理解算法背后的数学原理和工程实现细节。例如，在 LLM 部分，课程会引导你从 tokenizer 构建、注意力机制实现，到微调与部署一步步完成。此外，项目在开篇阶段还会帮助你配置本地开发环境（VS Code、Git、Jupyter、Anaconda 等），确保所有实验都可在非云端环境顺利运行。

## 安装与使用

使用该项目非常简单，无需安装任何特殊软件。你只需具备 Git 和 Python 基础环境（建议 3.9+），然后执行以下命令：

```bash
git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
```

仓库根目录下的 `README.md` 提供了整个学习路径的地图。建议你从 `contents.md` 或 README 的目录表入手，按照阶段顺序开始学习。对于每门课程，都会有一个对应的 Markdown 文件，其中包含详细的代码示例与练习。你可以将示例代码复制到 Jupyter Notebook 或本地脚本中运行。

对于想要直接体验项目实战的同学，可以跳转到 `projects/` 文件夹，这里包含了多个可交付的迷你项目（如文本分类器、RAG 问答机器人、模型 API 服务等），每个项目都附有明确的需求描述和验收标准，建议在学习完前置课程后动手完成。

## 适用场景

- **系统性自学**：如果你有几个月时间想从零入门 AI 工程，可以将本项目作为唯一的主线课程，按部就班地完成 20 个阶段的全部内容和项目。
- **高校课程补充教材**：教授 AI、机器学习或数据科学课程的老师，可以直接将课程中的讲义、示例和作业布置给学生作为课外延伸阅读或实验内容。
- **企业内部培训**：团队想要提升成员的 AI 工程能力时，可以挑选其中特定的阶段（如 LLM 应用开发、模型部署）进行内部 workshops 或训练营。
- **快速迁移与项目参考**：对于已有一定经验的开发者，在寻找特定主题（如 RAG、LoRA 微调、模型打包）的工程实现时，可以直接翻看对应课程的代码片段，快速获取灵感。

## 项目亮点

与市面上大多数视频教程或付费课程不同，该项目的核心亮点在于其**深度与广度的平衡**和**真正的开放开源精神**。

首先，它拥有令人印象深刻的完整体系。511 节课程不是零散教程的堆砌，而是经过精心设计的课程地图，知识结构环环相扣。从“配置开发环境”到“微调大语言模型”，所有课程均为纯文字与代码，没有视频时长和网络带宽的局限，学习节奏完全由自己掌控。

其次，项目并不仅仅停留在教授模型调用的层面。它强调**手写实现**关键组件，深入理解底层原理，这使得学习者能够获得在普通 API 用户之上更高层次的“工程手感”。

此外，项目在**本地优先**（Local-first）方面做得非常出色。它指导你如何在自己的电脑上运行大模型、训练小型模型，减少对昂贵云服务的依赖，让学习成本降到最低。

最后，生态系统的活跃度也是其重亮点之一。近 5 万的 Stars、持续活跃的贡献者、以及快速增长的 Stars 数量都证明了其内容质量和社区信任度，这在开源教育项目中实属罕见。
