今日 GitHub 开源热点日报来了🔥 看看全球开发者都在追什么！

1️⃣ awesome-gpt-image-2 火了🔥 一个GPT-Image2的工业级提示词库。逆向工程530多个案例，提炼出20多套可复用模板，主打“提示词即代码”，让AI出图更快更稳。

5️⃣ TradingAgents 是一个多智能体LLM金融交易框架📈 让不同AI角色扮演分析员、风控官、交易员，一起讨论决策。虽然很酷，但金融投资有风险，玩玩技术就好。

6️⃣ claude-obsidian 是给Obsidian用户打造的AI第二大脑🧠 扔进去任何资料，AI自动阅读、关联、归档成Markdown知识图谱，本地优先，数据绝对掌握在自己手里。

8️⃣ OpenHuman 是个“个人AI超级智能”项目🧠 用Rust写，主打本地优先，记录你的生活记忆，可当智能体集群与工作流编排器，还能做深度研究，隐私党福音。

9️⃣ Omarchy 是DHH出品的Linux发行版🐧 主打美观现代、开箱即用且意见鲜明，内置精选工具和快捷键体系，适合追求统一高效桌面体验的开发者。
