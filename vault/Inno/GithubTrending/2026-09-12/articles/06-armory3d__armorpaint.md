## 项目概述

ArmorPaint 是一款面向 3D 美术工作流的 PBR（Physically Based Rendering，基于物理的渲染）纹理绘制软件。它的核心目标是在实时渲染环境下完成材质贴图的绘制、分层与导出，相当于把传统需要离线渲染等待的纹理绘制流程，搬到了可交互的实时视口中。

该项目由 armory3d 团队维护，采用 C 语言为主要实现语言，底层依托 Kha 多媒体框架与自研的渲染管线。整个仓库以开发者为主要受众：官方明确说明此仓库面向开发者、可能不够稳定，而面向普通用户的预编译二进制版本则通过付费下载的方式分发，用以支撑项目的持续开发。这种“源码开放、成品付费”的模式让所有开发过程对社区透明，同时也为项目提供了资金支持。

目标用户包括：需要为游戏资产、产品可视化模型制作 PBR 材质的 3D 美术师；希望将纹理绘制功能集成进自有管线的技术美术与引擎开发者；以及对实时 PBR 渲染与节点式材质系统感兴趣、希望研究或二次开发的程序员。

## 核心功能

- **实时 PBR 纹理绘制**：在实时视口中直接对 3D 模型进行材质绘制，配合基于物理的着色模型，所见即所得地预览金属度、粗糙度、法线等通道效果。
- **图层化材质系统**：将不同材质通道以图层方式叠加管理，支持图层遮罩、混合模式与不透明度调节，便于非线性地调整和回退修改。
- **节点式程序化材质**：提供基于节点的材质编辑方式，可组合生成程序化纹理与遮罩，减少对手绘笔刷的依赖。
- **多通道贴图导出**：支持将绘制结果导出为标准 PBR 通道贴图（如 base color、roughness、metallic、normal、occlusion 等），并提供预设以适配主流游戏引擎。
- **跨平台运行**：通过 Kha 框架支持 Windows、Linux、macOS、Android 与 iOS 多平台构建，覆盖桌面与移动端。
- **笔刷与投射工具**：内置多种笔刷类型与投射方式，用于在模型表面精确绘制细节、贴花与纹理延续。

## 技术架构

ArmorPaint 在架构上分为若干个相对独立的部分。渲染层基于 Kha 框架，向下对接 Direct3D、Metal、Vulkan、OpenGL 等不同图形后端，从而实现同一套绘制逻辑在多个平台上的复用。核心逻辑使用 C 语言编写，通过 Kha 提供的跨平台 API 抽象了窗口、输入、文件系统与图形设备的差异。

构建系统并未采用 CMake 等常见方案，而是通过 `base/make` 脚本为不同平台生成对应的工程文件——Windows 生成 Visual Studio 解决方案，macOS/iOS 生成 Xcode 工程，Android 生成 Android Studio 工程。这把平台工具链的选择交给各平台的原生 IDE，降低了跨平台构建脚本的维护成本。

绘制管线围绕 PBR 材质通道展开，图层与节点构成的材质图最终被编译成可在 GPU 上执行的着色器程序，笔刷操作则以渲染 pass 的形式写入对应的通道纹理。这种设计使得绘制过程与最终渲染共享同一套着色模型，保证了预览与导出结果的一致性。此外，仓库中还包含材质库、示例资产与文档等辅助内容，方便开发者理解整体数据结构。

## 安装与使用

由于面向开发者，ArmorPaint 需要从源码编译，且必须预先安装编译器与 Git：

- Windows：Visual Studio（含 clang 工具链）
- Linux：clang 及相应依赖（仓库 `base/docs/linux_deps.md` 中有依赖清单）
- macOS / iOS：Xcode
- Android：Android Studio

基本步骤如下：

```bash
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
```

随后按平台生成并构建工程。Windows（x64）：

```bash
..\base\make
# 打开 build\ArmorPaint.sln 进行构建与运行
```

Linux（x64）可直接构建并运行：

```bash
../base/make --run
```

macOS（arm64）：

```bash
../base/make
# 打开 build/ArmorPaint.xcodeproj 构建运行
```

Android（arm64）与 iOS（arm64）则通过 `--target` 参数指定目标平台后，在对应 IDE 中构建。首次运行后可导入模型，创建材质并添加图层，使用笔刷在模型表面绘制，最后导出 PBR 贴图。具体操作细节可参阅官方 manual。

## 适用场景

- **游戏资产材质制作**：为角色、道具、场景模型绘制并导出符合引擎规范的 PBR 通道贴图。
- **产品与工业可视化**：为预览模型快速迭代表面材质，实时查看不同粗糙度与金属度下的外观。
- **引擎与工具链集成**：开发者可基于其节点系统与绘制管线，将纹理绘制能力嵌入自有的资产管线。
- **图形与渲染研究**：作为开源实时 PBR 绘制实现，可用于学习跨平台渲染抽象与节点材质编译等课题。

## 项目亮点

与同类纹理绘制工具相比，ArmorPaint 的差异点在于：其一，完全基于实时渲染管线，绘制与预览使用同一套着色模型，避免了离线渲染带来的反馈延迟；其二，源码开放且构建目标覆盖桌面与移动端，便于在多种设备上验证与部署；其三，采用节点与图层混合的材质模型，兼顾程序化生成与手绘控制；其四，项目由 Armory3D 生态支撑，与 Armory 引擎在资源格式与工作流上有天然的衔接性。需要注意的是，官方下载的稳定版本为付费分发，克隆仓库自行编译得到的版本可能包含未经充分测试的改动。
