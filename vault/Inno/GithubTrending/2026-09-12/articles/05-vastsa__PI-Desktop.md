## 项目概述

PI-Desktop 是一款面向 AI 编程代理（AI Coding Agent）的桌面工作空间，采用本地优先（Local-first）的设计理念。它将模型调用、项目文件访问和代理执行过程统一放在用户自己的机器上完成，避免强制账号注册、强制中转服务和编辑器绑定。

项目解决的核心问题是：现有 AI 编程工具通常要求用户将代码上传至云端、绑定特定编辑器或依赖厂商提供的中转服务，导致隐私、可控性和灵活性受限。PI-Desktop 允许用户自带模型（Bring Your Own Model），直接连接自配置的模型服务商或 API 端点，同时在本机打开任意本地项目，让代理在用户可观察、可干预的前提下执行任务。

目标用户包括：需要处理私有代码库、对数据外流敏感的开发者和团队；希望自由切换不同模型供应商的高级用户；以及希望通过插件扩展代理能力的技术人员。项目采用 LGPL-3.0 许可，目前支持 macOS、Windows 和 Linux 三大平台。

## 核心功能

- **本地优先的会话与项目存储**：项目文件和会话记录保存在用户机器上，模型请求直接发送至用户配置的服务商或端点，不经过项目方的中转服务器。
- **模型无关（Model-agnostic）接入**：用户可自行配置模型来源，支持对接不同的模型服务商与自建端点，不锁定单一厂商。
- **pi Agent Harness 代理运行时**：内置代理执行框架，负责任务编排、工具调用与上下文管理，驱动 AI 代理完成编程任务。
- **可安装插件系统**：提供插件开发机制，用户可按需安装扩展，为代理增加新能力或集成新工具。
- **多平台桌面客户端**：基于 Electron 构建，覆盖 macOS、Windows、Linux 桌面环境，提供统一的图形化工作空间。
- **过程可控与可干预**：代理工作过程中用户保持在环（stay in control），可观察并介入代理行为。

## 技术架构

PI-Desktop 采用前后端分层架构，主要技术栈为 TypeScript，并结合 Rust 构建核心宿主层。

- **Electron 桌面外壳**：负责窗口管理、跨平台打包与用户界面呈现，是用户直接交互的图形层。
- **Rust Host Core**：作为宿主核心，承担性能敏感或需要系统级能力的基础设施职责，为上层提供稳定的本地运行时支持。
- **pi Agent Harness**：代理运行框架，位于核心之上，统一管理代理的生命周期、工具调用与任务执行流程。
- **插件层**：用户可安装的插件作为扩展点接入代理能力，形成开放的生态边界。

这种"Electron + Rust + Agent Harness + 插件"的分层设计，将界面、系统能力与代理逻辑解耦，使各部分可独立演进。本地优先的设计意味着数据流不依赖中心化服务，模型请求由客户端直接发往用户配置的端点，从而在架构层面保障隐私与可控性。

## 安装与使用

1. 前往项目的 Releases 页面下载对应平台（macOS / Windows / Linux）的最新安装包。
2. 按系统提示完成安装并启动应用。
3. 在设置中配置模型来源：填写所使用模型服务商的 API 端点与凭据，或指向自建端点。
4. 打开本地项目目录，创建会话，即可让代理在项目上下文中开始工作。
5. 如需扩展能力，可参考插件开发文档安装或自行构建插件。

最小的可用路径是：下载安装 → 配置一个模型端点 → 打开一个本地项目 → 发起一次代理任务。具体界面操作与配置项细节可查阅官方文档。

## 适用场景

- **私有代码库的 AI 辅助开发**：代码与会话不出本地，模型请求直连自选端点，适合对数据外流敏感的场景。
- **多模型对比与自由选型**：因模型无关，用户可在不同服务商或自建模型之间切换，评估效果与成本。
- **需要扩展的团队工作流**：通过插件机制将内部工具或流程接入代理，形成定制化能力。
- **跨平台桌面开发环境**：在 macOS、Windows、Linux 上获得一致的代理工作空间体验。

## 项目亮点

与同类 AI 编程工具相比，PI-Desktop 的差异化主要体现在三点。其一，**本地优先且无强制账号与中转**，项目方不设账号体系，也不强制流量经过其服务器，数据边界清晰。其二，**模型无关与开放接入**，用户自带模型、直连端点，避免供应商锁定。其三，**可扩展的插件架构**配合独立的代理运行时，使代理能力可持续演进，而非封闭固化的功能集合。此外，Rust 宿主核心的引入在保证跨平台一致性的同时兼顾了系统级性能需求。
