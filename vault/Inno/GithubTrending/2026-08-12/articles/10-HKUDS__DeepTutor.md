## 项目概述

DeepTutor 是一个面向终身学习场景的个性化智能辅导系统，由香港大学数据科学实验室（HKUDS）开发并开源。该项目旨在解决传统人工智能教育工具中“千人一面”的问题，通过深度对话理解与自适应学习路径规划，为每位学习者提供持续演进、随学随长的个性化辅导体验。

与市面上常见的问答式教育机器人不同，DeepTutor 强调“终身”与“个性化”两个核心维度。它不仅能够回答学科问题，更能追踪学习者的知识掌握情况、识别薄弱环节，并在此基础上动态调整教学策略与内容难度，从而真正实现因材施教。项目以 Apache-2.0 许可证开源，目前已在 GitHub 上获得超过 34,000 颗星，成为 AI 教育领域备受关注的明星项目。

DeepTutor 的目标用户包括：需要个性化辅导的学生、希望构建智能教学系统的教育科技开发者、以及从事学习科学与人工智能交叉研究的科研人员。无论你是初学者还是进阶学习者，DeepTutor 都能根据你的学习历史与实时表现，提供量身定制的辅导内容。

## 核心功能

- **自适应学习路径规划**：基于学习者历史答题数据与知识图谱，动态生成个性化学习路线，自动调整内容难度与学习顺序。
- **多轮深度对话辅导**：支持复杂的多轮对话交互，能够理解上下文关联的追问、澄清与打断，模拟真人教师的辅导节奏。
- **知识掌握度实时评估**：通过嵌入式的诊断性提问与隐性评估机制，实时更新每个知识点的掌握度评分。
- **终身学习记忆管理**：跨会话保存学习者画像，在不同学习阶段之间迁移知识状态，实现真正的长期学习追踪。
- **可插拔的学科适配器**：内置数学、编程、语言学习等多个学科的知识建模模块，同时支持开发者自定义学科领域。
- **可解释的反馈机制**：每一次辅导建议都会附带推理依据，帮助学习者与教师理解“为什么这样教”。

## 技术架构

DeepTutor 采用模块化的分层架构设计，核心分为三层：

**交互层**负责自然语言理解与生成，基于大型语言模型（LLM）构建对话引擎。项目设计了专门的状态跟踪器，能够跨对话轮次维护上下文状态，并通过意图识别模块区分教学型、诊断型与评估型对话。

**知识层**是 DeepTutor 的差异化核心。它构建了结构化的学科知识图谱，每个知识点包含前置依赖关系、难度系数与关联题目。在此基础上，项目引入认知诊断模型（如 IRT、DINA 等），将学习者的答题表现映射为多维能力向量，从而支撑精细化的学情分析。

**策略层**负责决策与规划。基于强化学习框架，DeepTutor 将教学策略建模为序贯决策问题——每一次题目选择或讲解策略都视为一个动作，以学习者长期学习收益为奖励信号进行优化。同时，项目采用元学习机制，让系统在多个学习者的交互数据中提取共性规律，加速新学习者的冷启动过程。

在工程实现上，项目使用 Python 作为主要语言，提供了简洁的 API 接口与可配置的模块化设计，方便开发者替换或扩展各个组件。整体遵循事件驱动的异步架构，能够高效处理并发的辅导会话。

## 安装与使用

DeepTutor 依赖 Python 3.9 及以上环境。推荐使用虚拟环境进行安装，最简单的安装方式如下：

```bash
# 克隆仓库
git clone https://github.com/HKUDS/DeepTutor.git
cd DeepTutor

# 安装基础依赖
pip install -r requirements.txt

# 可选：安装 LLM 推理后端（如 vLLM 或 HuggingFace transformers）
pip install vllm  # 或 pip install transformers
```

最小可用的辅导会话示例：

```python
from deeptutor import TutorAgent

# 初始化辅导代理
agent = TutorAgent(subject="math", model="gpt-3.5-turbo")

# 开始一次辅导会话
session_id = agent.start_session(user_id="learner123")

# 进行一次提问
response = agent.turn(session_id, "请帮我复习一下二次函数的顶点式")
print(response)

# 结束并保存学习进度
agent.end_session(session_id)
```

如果你希望使用本地模型进行推理，只需在初始化时指定模型路径即可：

```python
agent = TutorAgent(subject="programming", model="local", model_path="./models/llama-3-8b")
```

## 适用场景

- **K12 学科辅导**：为中小学生提供数学、物理等学科的课后个性化辅导，系统能识别学生的易错知识点并针对性地出题训练。
- **在线教育平台集成**：教育科技公司可将 DeepTutor 作为智能答疑与学习引擎，嵌入现有学习管理系统（LMS），为其用户提供增值辅导服务。
- **成人职业教育与技能提升**：面向编程、数据分析等职业技能领域，DeepTutor 能够根据学习者的目标职位定制学习路径，并在学习过程中持续调整难度。
- **教育研究实验平台**：研究人员可利用 DeepTutor 开放的认知诊断模块与对话日志，验证新的教学策略或认知模型的有效性。

## 项目亮点

DeepTutor 在同类 AI 教育项目中展现出多项差异化优势。首先，其“终身学习”设计理念突破了传统辅导工具仅关注单次会话的局限，通过持久化的用户画像与跨会话记忆，实现学习状态的平滑延续。

其次，项目将知识图谱、认知诊断与强化学习三者有机结合，形成了从“知识表示”到“能力评估”再到“教学决策”的完整技术闭环。这种将教育学理论深度融入系统设计的做法，在开源项目中少有先例。

第三，DeepTutor 保持了良好的可扩展性。无论是添加新学科、替换底层大模型，还是接入不同的认知诊断算法，都通过模块化接口实现，降低了二次开发门槛。此外，项目提供了完善的中英文文档与示例代码，对开发者友好。
