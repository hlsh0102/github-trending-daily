## 项目概述

Diagram Design 是一个面向 Claude Code、Codex 和 Pi 等 AI 编程助手的技能包，包含 29 种编辑级质量的图表类型。该项目解决了 AI 生成图表时普遍存在的“千图一面”问题——所有图表都使用通用的圆角矩形、花哨阴影和 Mermaid 风格模板，与使用者的品牌形象和内容气质完全脱节。

目标用户是需要在文档、博客、演示文稿或产品页面中频繁使用图表的内容创作者、技术写作者、产品经理和独立开发者。项目的核心承诺是：让 AI 生成的图表达到设计师认可的质量水准，同时将品牌适配时间压缩到 60 秒以内。

## 核心功能

- **29 种编辑级图表类型**：覆盖架构图、流程图、金字塔图、循环图、飞轮图等常见信息图表类型，每种图表都经过精心设计，摒弃了臃肿的阴影和装饰性元素。
- **品牌自动适配**：技能会读取你的网站，自动提取颜色方案和字体搭配，并将这些品牌元素应用到所有生成的图表中。
- **draw.io 文件重绘**：可以直接读取现有的 draw.io 图表文件，按目标受众的需求重新绘制，调整格式、尺寸和细节层级。
- **三种变体输出**：每种图表类型都提供 minimal、标准、详细三种变体，满足从快速草稿到正式发布的不同使用场景。
- **Loop 循环图（2.0 新特性）**：支持带共享内存中枢的飞轮图表，用虚线表示数据写回路径，适合描述自我强化的系统。
- **跨平台兼容**：通过 Agent Skill 标准实现，同时适配 Claude Code、Codex 和 Pi 三个主流 AI 编程环境。

## 技术架构

项目采用**自包含 HTML + SVG** 的架构方案，这是其设计核心。每个图表都是一个独立的 HTML 文件，内嵌 SVG 矢量图形，不依赖任何外部库或运行时环境。这种设计带来几个关键优势：图表可以离线渲染、可以直接嵌入任何网页、也方便在浏览器中快速预览和修改。

项目以 Claude Code 技能（Skill）的形式分发，这是一种结构化的指令集，定义了 AI 如何理解需求并生成图表。技能内部包含了 29 种图表类型的模板、设计规范和品牌适配的逻辑。当你将网站地址提供给技能时，它会通过 HTTP 请求抓取页面的 CSS 变量、字体声明和颜色使用情况，然后将这些信息映射到 SVG 模板中的对应属性。

设计理念上，项目遵循“删除即最高品质”的原则——每个节点都应有存在的理由，强调色只用于读者应该最先注意的一两个元素，目标信息密度控制在 4/10（即 40% 的视觉占用率）。这与当前许多 AI 生成工具“信息越密集越好”的默认倾向形成鲜明对比。

## 安装与使用

安装 Diagram Design 需要先将它作为技能安装到你的 AI 编程环境中。以 Claude Code 为例，基本步骤如下：

1. 克隆仓库到本地目录：
   ```bash
   git clone https://github.com/cathrynlavery/diagram-design.git
   ```

2. 将技能目录添加到 Claude Code 的配置路径中，或直接复制到你的项目 `.claude/skills/` 目录下。

3. 在 Claude Code 会话中加载技能，通常通过斜杠命令或自动发现机制完成。

最小可用示例：

```
你：请使用 diagram-design 技能，为我们的用户登录流程创建一个时序图，
    品牌参考：https://example.com（我们的官网）
    图表要求：标准变体，强调 MFA 验证步骤。

Claude Code：正在读取 example.com 的品牌信息……
             已提取颜色 #2D6A4F（主色）、#1B4332（辅助色）……
             正在生成 时序图（标准变体）……
             完成，输出文件：login-flow.svg
```

如果你已有 draw.io 格式的流程图，也可以这样使用：

```
你：使用 diagram-design 重绘 docs/architecture.drawio，受众是产品团队，
    需要标注关键依赖和故障风险点。
```

## 适用场景

- **产品文档与架构说明**：为技术文档绘制清晰、风格统一的系统架构图、数据流图和组件关系图，提升文档的专业感。
- **内容营销与博客配图**：博主和内容创作者可以用它快速生成与品牌风格一致的信息图表，替代耗时费力的 Figma 手动设计。
- **演示文稿与内部报告**：在制作面向管理层或客户的关键汇报时，用品牌化图表替代默认模板，增强信息传达效果。
- **设计系统与品牌规范延伸**：当你的设计系统需要从网页延伸至图表维度时，该项目提供了一种程序化的色彩和字体映射方案。

## 项目亮点

与 Mermaid、PlantUML 等传统文本制图工具或直接依赖 Figma 手动设计相比，Diagram Design 的差异化优势非常明显。

**设计质量优先**：项目宣称“你的设计师不会讨厌这些图表”，背后是严格的视觉设计规范——无阴影、无冗余装饰、严格控制信息密度。这是目前 AI 生成图表工具中最接近专业设计水准的方案。

**品牌一致性自动化**：通过自动读取网站并提取品牌元素，解决了跨工具品牌一致性维护的痛点。60 秒的品牌适配速度远快于手动设置主题的时间成本。

**轻量自包含**：HTML + SVG 的输出格式意味着每个图表都是一个可独立分发的文件，没有运行时依赖，没有权限问题，不存在“打开工具才能看图”的局限。

**社区验证**：项目在 GitHub 上获得了超过 7000 颗星，单日新增星标超过 1600，说明开发者社区对它的认可度非常高，其“去 Mermaid 化”的定位确实击中了许多人的真实需求。
