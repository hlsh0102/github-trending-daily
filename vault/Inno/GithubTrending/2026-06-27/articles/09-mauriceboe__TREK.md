## 项目概述

TREK 是一款自托管的旅行/行程规划工具，专为需要精细管理旅途细节的用户设计。无论是家庭度假、商务差旅还是背包客探险，TREK 都能帮助你一站式组织行程、共享信息并实时协作。项目以“你的旅行、你的计划、你的服务器”为核心理念，强调数据隐私与完全控制权，适合对第三方旅行平台数据安全存有顾虑的用户。

## 核心功能

- **实时协作**：支持多人同时编辑行程，所有变更即时同步，团队成员可随时查看最新安排。
- **交互式地图**：集成地图服务，在地图上直观标记地点、规划路线，并可添加备注。
- **预算管理**：创建旅行预算，跟踪各项支出，支持多币种和分类统计。
- **打包清单**：自定义行李清单，按类别分组（衣物、证件、药品等），防止遗漏。
- **旅行日志**：记录每日行程、照片和感悟，生成可分享的旅行回忆。
- **单点登录支持**：集成 SSO 功能，可接入现有身份认证系统，统一管理用户。
- **PWA 支持**：作为渐进式 Web 应用，支持离线访问和移动端安装，无需原生应用。
- **AI 辅助**：内置 AI 功能，可智能推荐景点、优化行程或生成描述。

## 技术架构

TREK 采用现代前后端分离架构，后端基于 TypeScript 构建，利用 Node.js 运行时提供高性能服务。前端使用 React 框架，配合地图库实现流畅的交互体验。数据存储采用 PostgreSQL 数据库，确保关系型数据的完整性与查询效率。实时协作功能通过 WebSocket 或类似实时通信协议实现，使多端同步延迟控制在极低水平。项目整体以 Docker 容器化部署为核心，提供一键启动方案，降低自托管门槛。此外，TREK 遵循 AGPL-3.0 开源协议，代码完全透明，鼓励社区贡献与定制。

## 安装与使用

TREK 推荐通过 Docker 部署，这是最快捷的方式。首先确保系统已安装 Docker 和 Docker Compose。然后执行以下步骤：

```bash
# 克隆仓库
git clone https://github.com/mauriceboe/TREK.git
cd TREK

# 启动服务（使用 Docker Compose）
docker-compose up -d
```

首次启动后，访问 `http://localhost:3000` 进入初始化页面。根据向导设置管理员账号，创建你的第一个行程。如需使用 AI 或 SSO 功能，可参考 `.env.example` 文件配置环境变量。

最小可用示例：启动后直接创建一个新行程，添加目的地和日期，邀请朋友通过链接加入即可开始实时协作。地图和预算功能可即时启用，无需额外配置。

## 适用场景

- **家庭旅行规划**：多个家庭成员共同编辑行程，分配任务，管理预算，避免信息碎片化。
- **小团队商务差旅**：同步会议安排、酒店预订和交通信息，领导可实时查看团队成员动态。
- **背包客与数字游民**：在移动设备上通过 PWA 离线使用，记录沿途日志，管理多变路线。
- **旅行社或活动组织者**：为客户定制行程，提供可视化地图和在线协作功能，提升服务体验。

## 项目亮点

与主流旅行规划工具（如 TripIt、Google Trips）相比，TREK 的核心优势在于**完全自托管**——你的所有行程数据存储在自己的服务器上，不受第三方平台服务关停或政策变更影响。实时协作功能对标 Notion 或 Google Docs 的编辑体验，但针对性优化了旅行场景。此外，集成的 AI 辅助、预算和打包清单等功能形成完整闭环，无需在多款应用间切换。项目当天获得 1000+ 星标，社区活跃度高，更新频繁，表明其质量与需求匹配度获得广泛认可。
