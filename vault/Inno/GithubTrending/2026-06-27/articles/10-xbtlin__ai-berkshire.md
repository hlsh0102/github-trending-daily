## 项目概述

**AI Berkshire** 是一个将价值投资大师方法论与 AI Agent 技术相结合的开源研究框架。项目由开发者 xbtlin 创建，基于 Claude Code 构建了一套结构化的投资研究 Skill 合集，系统化整合了沃伦·巴菲特、查理·芒格、段永平、李录四位顶级价值投资者的核心理念。

该项目解决的核心问题是：普通投资者在直接向 AI 提问时，往往只能得到“一方面…另一方面…”的中庸式分析，缺乏可操作的决策依据。AI Berkshire 通过强制输出结论、多视角对抗分析、分层投资建议等方式，将 AI 从“信息整理器”升级为“决策辅助工具”。

目标用户是具备一定投资基础、希望借助 AI 提升研究深度和效率的个人投资者，以及希望系统化学习价值投资方法论的研究者。项目提出的核心理念是“一个人 + Claude = 一个投研团队”，旨在降低专业级投资研究的门槛。

项目在 GitHub 上已获得超过 3200 颗星，社区反响热烈。核心验证数据来自开发者本人的实盘收益：2024 全年收益 +69.29%，2025 年至今收益 +66.38%，连续两年大幅跑赢全球主要指数，累计实盘收益超 146 万元。

## 核心功能

- **四大师方法论系统化**：将巴菲特（护城河与安全边际）、芒格（多元思维模型与逆向思考）、段永平（本分文化与企业价值）、李录（确定性优先与长期持有）四位大师的投资框架转化为可执行的 AI Prompt 和检查清单，确保每次分析都覆盖核心决策维度。

- **多 Agent 对抗分析**：不是单一视角的分析，而是让四位“大师 Agent”从各自的立场出发，对同一标的进行独立研究。当不同视角产生矛盾时（例如巴菲特的“护城河”与芒格的“竞争毁灭”），系统会暴露这些分歧，迫使使用者深入思考，而非接受表面和谐的结论。

- **强制输出可操作结论**：AI Berkshire 的关键创新在于绕过 AI 常见的“平衡但无用”的回答模式。系统强制输出三种结论之一：**通过**、**不通过**、**灰色地带**，并附带具体价格区间和分层投资建议（激进型、稳健型、保守型）。例如，对于某只股票，系统会直接给出“当前价位可建仓 20%，价格区间 $95-105”这样的具体指引。

- **“镜子测试”与决策纪律**：项目内置了著名的“镜子测试”——用 5 句话讲不清楚的投资逻辑，一律不买。该规则被硬编码进分析流程，防止使用者被复杂信息迷惑而忽视最基本的决策逻辑。系统还提供一系列强制执行的检查清单，确保每个投资决策都经过系统化过滤。

- **实盘验证与回测工具**：项目公开了开发者的真实账户收益数据（2024 年 +69.29%，2025 年 +66.38%），并提供工具帮助使用者将自己的持仓与四大师框架进行对比分析，检视决策偏差。

## 技术架构

AI Berkshire 基于 Claude Code 的基础能力构建，核心技术思路是“提示工程 + 结构化输出 + 多 Agent 协调”。

- **核心载体**：Claude Code 作为底层的 AI 推理引擎，提供强大的长文本理解与多步推理能力。项目本质是一系列高度结构化的 Skill（技能）文件，通过精心设计的 Prompt 控制 AI 的行为模式。

- **四 Agent 模型**：系统内部维护四个独立的“身份预设”，每个预设包含对应大师的核心原则、决策清单、典型偏好与禁忌。当用户输入一个标的时，系统会依次或并行调用这四个 Agent，每个 Agent 独立输出其分析结论。

- **对抗与融合机制**：四个 Agent 的分析结果不是简单加权平均。系统设计有“矛盾暴露层”，当不同 Agent 的结论存在显著分歧时，会高亮显示这些冲突点，并引导使用者去理解分歧背后的根本假设差异，进而形成自己的判断。

- **分层输出结构**：不同于自由文本输出，AI Berkshire 采用结构化的输出模板。每个分析结果都包含“决策结论→价格区间→仓位建议→风险提示”的固定层级，确保信息完整性且便于使用者快速抓取关键点。

- **Python 工具链支持**：项目使用 Python 作为辅助脚本语言，用于数据抓取、财务指标计算、估值模型搭建等自动化任务，与 Claude 的推理能力形成互补。

## 安装与使用

AI Berkshire 的使用流程相对轻量，适合有一定命令行基础的用户。

**前置要求**：
- 安装 [Claude Code](https://claude.ai/code)（需要拥有 Claude API 访问权限）
- Python 3.8 以上环境

**安装步骤**：

1. 克隆项目仓库：
```bash
git clone https://github.com/xbtlin/ai-berkshire.git
cd ai-berkshire
```

2. 安装 Python 依赖（如有需要）：
```bash
pip install -r requirements.txt
```

3. 启动 Claude Code 并加载 Skill 集合：
```bash
claude
```

4. 在 Claude Code 中加载对应的 skill 文件或使用项目提供的初始化命令。

**最小可用示例**：

在加载完 Skill 集合后，你可以直接输入研究请求，例如：
```
分析腾讯控股（0700.HK）
```
系统会自动调用四位大师 Agent，依次输出巴菲特的护城河分析、芒格的逆向思考清单、段永平的本文化判断、李录的确定性评估，最后整合成一份包含“通过/不通过/灰色地带”判断以及具体价格区间的完整报告。

更详细的参数配置和自定义检查清单修改方法，请参考项目仓库中的 `docs/` 目录。

## 适用场景

- **个人投资者深度研究**：当投资者需要对一个标的进行系统化调研，但又缺乏专业团队支持时，AI Berkshire 可以提供“四个分析师”的力量，覆盖行业竞争、管理层素质、财务健康、安全边际等多个维度。

- **投资组合检视与纠偏**：投资者使用 AI Berkshire 对自己已有的持仓进行分析，检视是否违背了某位大师的原则。例如，当发现某只持仓在“芒格视角”下存在明显的“竞争毁灭”风险，却因为“巴菲特视角”的护城河故事而被持有，系统会推动使用者进行重新评估。

- **研究观点碰撞与学习**：对于投资学习者，可以输入同一个标的，观察四位大师的分析思路为何会导向不同结论。这本身就是深入理解价值投资各流派的绝佳学习过程。

- **量化研究与复现**：开发者可以利用项目提供的 Python 工具链，结合四大师框架构建自动化的估值模型或筛选策略，进行系统性的回测与优化。

## 项目亮点

AI Berkshire 区别于通用 AI 投资助手和传统投资分析工具的核心差异：

- **解决“AI 打太极”的痛点**：这是最直接的差异化优势。普通 AI 在投资分析上的最大问题是“输出看起来很专业，但根本无法用于决策”。AI Berkshire 通过强制输出具体结论和价格区间，彻底改变了 AI 在投资领域的应用范式。

- **大师方法论的真实对抗**：项目不是简单地将四个人的名言拼凑在一起，而是构建了可以产生“真实矛盾”的多视角系统。当四位大师的观点在同一个标的上发生冲突时（这是常有的事），系统会暴露这些分歧，而非掩盖它们。这种设计远比单一方法论的分析框架更有实际价值。

- **实盘验证而非纸上谈兵**：项目公开了连续两年大幅跑赢全球主要指数的实盘收益数据，这种透明度和结果导向在投资类开源项目中极为罕见。虽然历史收益不代表未来，但这种实证精神是项目可信度的重要支撑。

- **轻量级与模块化**：无需搭建复杂的后端或数据管道，只需要 Claude Code 和 Python 环境即可运行。每个 Skill 文件都是独立的模块，使用者可以自由组合、修改，甚至基于框架构建自己的全新分析 Agent。
