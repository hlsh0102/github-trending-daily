## 项目概述

DESIGN.md 是一个用于将视觉设计系统描述给编码智能体（coding agents）的格式规范。该项目解决了前端开发中的一个核心痛点：AI 编码工具在生成用户界面时，往往缺乏对设计系统的系统性理解，导致生成的 UI 风格不一致、设计细节丢失。

通过定义一种标准化的文件格式，DESIGN.md 让开发者能够将设计系统中的关键信息——如颜色、排版、间距、圆角等设计令牌（design tokens），以及设计背后的理性思考——以结构化的方式呈现给编码智能体。目标用户包括：使用 AI 辅助编码工具的前端开发者、需要维护多项目设计一致性的设计系统团队，以及探索 AI 驱动 UI 生成的开发者。

## 核心功能

- **设计令牌标准化**：通过 YAML front matter 定义颜色、排版、间距、圆角等可量化的设计参数，为智能体提供精确的数值参考。
- **设计意图传达**：使用 Markdown 正文描述设计理念和视觉原则，让智能体理解“为什么这样设计”而非仅仅“数值是什么”。
- **组合式灵活性**：支持定义多种字体族和层级（标题、正文、标签），以及不同规格的间距和圆角系统，适应复杂的设计需求。
- **颜色体系声明**：明确主色、辅助色、强调色和中性色的角色分配，帮助智能体理解每个颜色的使用场景和限制。
- **可读性与机器性统一**：文件对人类开发者同样可读，兼具设计文档和智能体配置文件的双重用途。

## 技术架构

DESIGN.md 采用“双引擎”结构设计，将机器可读部分和人类可读部分融合在同一个文件中：

- **YAML 前置区块**：包含结构化的设计令牌数据，使用标准的 YAML 格式。智能体可将其解析为 JSON 对象或配置文件，直接应用于样式生成过程。
- **Markdown 正文**：包含设计说明、使用指南和视觉原则。这部分采用自然语言，智能体通过语义理解和上下文推理来内化设计意图。

该格式以 **TypeScript** 编写，但不依赖特定框架或运行时。其核心设计哲学是“描述性而非命令式”——不规定智能体如何实施设计，而是提供足够的信息使其自主推导出合理的实现方案。这种松耦合的架构允许在任何支持 Markdown 解析的 AI 编码环境中使用，无需修改工具链。

## 安装与使用

DESIGN.md 本身不是一个需要安装的包，而是一个文件格式规范。要使用它，你只需在项目根目录或设计系统中创建一个名为 `DESIGN.md` 的文件。

**基本步骤：**

1. 在项目根目录下创建 `DESIGN.md` 文件。
2. 定义 YAML front matter 部分，包含设计令牌。
3. 在 Markdown 正文部分描述设计原则和视觉系统。

**最小示例：**

```yaml
---
name: My Design System
colors:
  primary: "#1A1C1E"
  secondary: "#6C7278"
  tertiary: "#B8422E"
  neutral: "#F7F5F2"
typography:
  h1:
    fontFamily: "Public Sans"
    fontSize: "3rem"
  body-md:
    fontFamily: "Public Sans"
    fontSize: "1rem"
---
```

创建完成后，AI 编码工具（如 GitHub Copilot、Cursor 等）在生成 UI 代码时，会自动识别并应用这些设计规范。

## 适用场景

- **AI 辅助 UI 开发**：在使用 AI 生成前端页面时，确保输出结果符合统一的设计语言，避免混用字体和颜色。
- **设计系统文档化**：将设计系统的核心参数和理念以标准化格式记录，方便团队成员和 AI 工具共同引用。
- **多项目风格统一**：跨项目复用同一个 DESIGN.md 文件，或通过不同文件快速切换整套视觉方案。
- **AI 编码插件集成**：为开发工具中的 AI 功能提供精确的样式参考，使生成的代码可以直接用于生产环境。

## 项目亮点

DESIGN.md 的核心优势在于其**人机双读**特性。与传统的设计令牌文件（如 JSON 或 CSS 变量文件）不同，它不仅提供准确数值，还通过自然语言解释设计的上下文和意图。这使得 AI 智能体不仅能够复制颜色值，还能理解何时使用某种颜色、为何选择某种字体和间距。

此外，该格式的**低侵入性**也值得称道。它不要求修改现有工具链或框架，只需放置一个文件即可让多种 AI 工具协同工作。而 **Apache-2.0** 的开源许可也为商业使用提供了便利。

与同类方案（如 Storybook 的设计令牌导出、Figma API 集成）相比，DESIGN.md 更轻量、更通用，尤其适合快速搭建 AI 友好型设计系统。
