## 项目概述

SimpleX 是第一款完全不需要任何用户标识符的消息网络。它从根本上改变了传统即时通讯软件依赖手机号、邮箱、用户名或设备 ID 来识别用户的设计范式，实现了 100% 的隐私保护。该项目由 Haskell 语言编写，支持 iOS、Android 和桌面端，旨在为对隐私有极致要求的用户提供一个安全、去中心的通信解决方案。

与 Signal、Telegram 等主流端到端加密消息应用不同，SimpleX 不存储任何用户身份信息，没有用户 ID、没有用户名、没有手机号绑定。每个用户仅通过临时、一次性、可轮换的地址（SimpleX Address）建立连接，这种设计使得即使服务端被攻破，也无法关联用户的任何社交图谱或通信模式。

## 核心功能

- **无用户标识符设计**：不需要手机号、邮箱、用户名或任何持久化 ID 来注册或使用。每个用户的身份仅由客户端生成的密钥对代表，服务端无法获知用户身份信息。
- **端到端加密**：所有消息、文件、群组通信均使用现代密码学算法（如 Curve25519、X3DH、Double Ratchet）进行端到端加密，确保只有通信双方能解读内容。
- **去中心化架构**：不依赖中央服务器存储用户身份或消息队列。消息通过去中心化的 relay 服务器路由，任何人都可以自建 relay，完全控制自己的数据流转路径。
- **隐私保护群组**：群组聊天中，每个成员仅知道自己的上级或下级节点，无法获取完整成员列表，有效防止群组暴露。
- **匿名文件传输**：支持点对点文件发送，传输过程经过端到端加密，且不会在服务端留下元数据。
- **跨平台支持**：提供统一的 iOS、Android 原生应用和桌面端（支持 macOS、Windows、Linux）体验，同步聊天历史和密钥。

## 技术架构

SimpleX 的技术架构以**无状态服务端**和**客户端驱动的隐私模型**为核心。其关键设计思想包括：

- **Haskell 语言实现**：后端核心逻辑使用 Haskell 编写，利用其强类型系统和函数式编程特性，确保代码的安全性和可靠性。Haskell 的内存安全特性天然适合构建对安全敏感的加密通信协议。
- **无服务器用户数据库**：服务端（称为 relay）仅负责临时存储排队中的加密消息，完全不了解用户身份或社交图谱。用户的所有会话密钥、联系人列表、群组信息都存储在客户端本地。
- **异步消息队列**：消息传递采用类似 SMTP 的异步模型。发送方将加密消息提交到接收方指定的 relay 队列，接收方拉取时解密。这种设计避免了同时在线要求，同时保护了通信双方的 IP 地址。
- **地址轮换与一次性连接**：每个 SimpleX Address 都是临时生成，可以被轮换或删除。连接建立过程中的握手协议确保双方能够安全交换一次性密钥，之后地址即可废弃，防止长期追踪。
- **混合密码学协议**：结合 X3DH 密钥握手协议（用于初始会话建立）和 Double Ratchet 算法（用于持续消息加密），提供前向安全性（PFS）和未来安全性（FS），即使长期密钥泄露也无法解密历史或未来消息。

## 安装与使用

**iOS 用户**：可在 App Store 搜索“SimpleX Chat”直接安装。

**Android 用户**：从 Google Play 或 F-Droid 下载安装。

**桌面端（macOS/Windows/Linux）**：从 GitHub Releases 页面下载对应平台的安装包，或通过 Homebrew（macOS）、Scoop（Windows）、`apt`（Debian/Ubuntu）等包管理器安装。

**最小可用示例**：

1. 打开应用后，首先创建本地配置文件（无需任何注册信息）。
2. 生成自己的 SimpleX Address（连接码），可通过 QR 码或分享链接发送给好友。
3. 对方收到码后，在应用中点击“添加联系人”扫描或输入该码，即可建立端到端加密连接。
4. 连接建立后，双方可发送文本消息、图片、文件，并创建或加入加密群组。

**自建 Relay 服务器**（可选）：项目提供了 `simplex-chat` 的服务器端组件，可在自己的 VPS 上运行，进一步减少对第三方 relay 的依赖。启动命令示例：
```bash
cabal run simplex-chat-server -- -p 5225
```

## 适用场景

- **记者与消息人士通信**：保护爆料者身份，确保消息来源和内容都不被第三方或政府监控机构追踪。
- **企业隐私合规**：在受监管行业（如金融、医疗）中，需要对内部通信进行最高级别隐私保护，且不希望依赖供应商的中央服务器。
- **隐私爱好者和技术研究者**：探索通讯系统安全性极限的用户，或希望建立完全去中心化、无信任依赖的通信网络。
- **规避互联网审查**：在存在网络监控或审查的地区，SimpleX 的无标识符设计使得它极难被封锁或流量分析。

## 项目亮点

- **真正的无标识符**：这是目前唯一一个不依赖任何持久化用户标识符的端到端加密消息网络。相比于 Signal（仍需手机号）或 Matrix（需要用户名），SimpleX 在隐私根本层实现了突破。
- **已通过独立安全审计**：2022 年 11 月，知名安全审计公司 Trail of Bits 对 SimpleX 协议进行了第三方审计，确认其加密实现的安全性。
- **隐私指南与安全社区推荐**：已被 Privacy Guides、Whonix、Kuketz Blog 等权威隐私资源推荐，证明了其在隐私社区中的认可度。
- **开源与 AGPL-3.0 许可**：全部代码开源，任何人都可以审查、审计或自建服务端，确保透明度和可验证性。
- **活跃的开发与社区**：拥有 12000+ GitHub Stars，持续高频更新，社区活跃度极高（Reddit、Mastodon 均有官方账号）。
