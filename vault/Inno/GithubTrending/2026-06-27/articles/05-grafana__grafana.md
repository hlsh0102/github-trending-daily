## 项目概述

Grafana 是一个开源的可观测性与数据可视化平台，旨在帮助用户查询、可视化、告警并理解其指标数据，无论这些数据存储在何处。它解决了现代运维和开发中数据分散、难以统一监控和分析的问题，让团队能够通过统一的仪表板查看来自 Prometheus、Loki、Elasticsearch、InfluxDB、Postgres 等多种数据源的指标、日志和链路追踪数据。目标用户涵盖 DevOps 工程师、SRE、后端开发者、数据分析师以及任何需要监控系统状态或分析时间序列数据的团队。

## 核心功能

- **丰富的可视化能力**：提供快速灵活的前端图表，支持多种面板插件，如折线图、柱状图、热点图、仪表盘等，满足不同数据展示需求。
- **动态仪表板**：通过模板变量实现可复用、可交互的仪表板，变量以下拉菜单形式展示在顶部，用户可动态切换过滤条件，无需为每个场景创建独立仪表板。
- **临时查询探索**：支持通过临时查询和动态钻取深入探索指标数据，并支持分屏对比不同时间范围、查询条件或数据源，便于分析异常或趋势变化。
- **日志实时流式查询**：支持无缝从指标切换到日志，保留标签过滤条件，可快速搜索历史日志或实时流式查看日志输出，助力故障排查。
- **灵活告警管理**：支持通过可视化界面定义告警规则，对关键指标进行持续评估，并将告警通知发送至 Slack、PagerDuty、VictorOps、OpsGenie 等外部系统。
- **多数据源混合查询**：在同一张图表中混合查询不同的数据源，支持按查询粒度指定数据源来源，包括自定义数据源，极大增强了数据整合的灵活性。

## 技术架构

Grafana 采用前后端分离架构。前端基于 TypeScript 与 React 框架构建，提供响应式、交互丰富的用户界面；后端使用 Go 语言开发，提供高性能的数据查询与代理服务。其核心设计思想是“数据源抽象层”：通过插件化架构统一各类数据源的接入方式，无论底层存储是时序数据库、日志系统还是关系型数据库，Grafana 都以一致的查询接口与面板组件呈现。此外，仪表板采用 JSON 格式存储，便于版本管理与自动化部署。告警引擎独立运行，支持基于规则的周期性评估，并与多种通知渠道集成。

## 安装与使用

**安装步骤**（以 Docker 快速启动为例）：

1. 确保已安装 Docker。
2. 运行以下命令启动 Grafana：
   ```bash
   docker run -d -p 3000:3000 grafana/grafana
   ```
3. 访问 `http://localhost:3000`，使用默认管理员账户 `admin` / `admin` 登录（首次登录会要求修改密码）。

**最小可用示例**：
- 添加数据源：在左侧菜单选择“Configuration” → “Data Sources”，添加一个 Prometheus 数据源，填写地址（如 `http://localhost:9090`）并保存。
- 创建仪表板：点击“+” → “Dashboard”，添加一个“Graph”面板，在查询编辑器中输入 PromQL 查询（如 `up`），保存仪表板。
- 设置告警：在面板编辑中切换到“Alert”选项卡，配置触发条件和通知渠道。

更多安装方式（如二进制包、Kubernetes 部署）请参考[官方安装指南](https://grafana.com/docs/grafana/latest/setup-grafana/installation/)。

## 适用场景

- **基础设施监控**：通过 Prometheus 采集服务器 CPU、内存、磁盘等指标，在 Grafana 中构建系统健康仪表板，并设置资源阈值告警。
- **应用性能监控（APM）**：结合 Loki 日志与 Tempo 分布式追踪，快速从指标异常下钻到具体日志和调用链路，定位性能瓶颈。
- **业务数据可视化**：连接 Postgres 或 MySQL，将业务数据库中的销售数据、用户行为数据以图表形式实时展示，辅助运营决策。
- **云原生环境运维**：在 Kubernetes 集群中部署 Grafana，聚合多个 Prometheus 实例数据，统一监控集群节点、Pod 状态及服务性能。

## 项目亮点

- **数据源无关性**：支持超过数十种数据源，且通过插件系统可无限扩展，真正实现“一次学习，到处监控”。
- **用户友好**：可视化界面直观，模板变量、动态钻取等高级功能降低使用门槛，非技术用户也能快速创建视图。
- **强大告警体系**：告警规则可基于查询结果灵活定义，支持 silences、分组、路由等高级功能，与主流通知服务深度集成。
- **活跃的社区生态**：拥有超过 7 万 GitHub 星标，大量社区贡献的仪表板插件和面板扩展，官方持续迭代维护。
- **符合开源精神**：采用 AGPL-3.0 许可，允许自由使用、修改和分发，同时提供 Grafana Cloud 托管版本供企业选择。
