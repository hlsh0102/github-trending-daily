## 项目概述

张雪峰.skill 是一个基于认知科学方法论构建的实战思维框架项目，由女娲.skill 自动生成。它并非简单的语录合集或段子合集，而是一套可运行、可交互的“认知操作系统”。项目将张雪峰关于高考志愿、考研决策和职业规划的核心方法论进行结构化提炼，形成了可被 AI 代理直接调用的决策模型。目标用户包括高考考生及家长、考研学生、职业规划迷茫者、以及需要思维框架辅助决策的 AI 开发者。

## 核心功能

- **实战思维框架**：内置 5 个核心心智模型，包括就业倒推法、社会筛子论、资源分流法等，可直接用于回答志愿填报、考研择校、职业赛道选择等具体问题。
- **决策启发式引擎**：提炼 8 条决策启发式，帮助用户在面对复杂选择时快速找到关键判断依据，如“理工科选专业，文科选学校”“看中位数去向而不是天花板”等。
- **完整表达基因复制**：不仅复制思维逻辑，还保留了张雪峰标志性的表达风格，包括反问句式、场景化比喻、数据引用和口语化节奏。
- **严格调研蒸馏**：基于 5 本著作、15+ 篇权威媒体深度采访、30+ 条一手语录、11 个关键决策记录和完整人生时间线的系统调研，确保决策模型的真实性和深度。
- **AI 原生可调用**：项目输出为标准的 skill 格式，可直接被 AI 代理（如女娲.skill）加载，实现智能问答和决策支持。
- **开源可扩展**：采用 MIT 许可证，用户可自由查看、修改或二次开发，适用于不同场景的定制化需求。

## 技术架构

张雪峰.skill 的技术架构体现了“认知蒸馏”的核心思想。项目首先通过系统化的调研，从大量原始资料中提取关键概念、决策案例和认知模型，然后利用女娲.skill 的生成能力将这些碎片化知识结构化，形成一个包含心智模型、决策启发式和表达基因的三层架构。底层是基础数据层，包含经过标注的语录、采访记录和时间线数据；中间层是模型层，包含 5 个核心心智模型和 8 条决策启发式；顶层是表达层，负责按照张雪峰的认知风格输出结果。这种设计使得项目既能保持原汁原味的表达感染力，又能提供结构化的决策支持。

## 安装与使用

安装张雪峰.skill 非常简便，只需将项目克隆到本地或直接集成到 AI 平台中：

```bash
git clone https://github.com/alchaincyf/zhangxuefeng-skill.git
cd zhangxuefeng-skill
```

在 AI 代理配置中加载 skill 文件即可。例如，在女娲.skill 环境中，添加以下配置：

```json
{
  "skill": "v1",
  "source": "local",
  "path": "./zhangxuefeng-skill"
}
```

最小可用示例如下，询问志愿填报问题：

> 问：我孩子今年高考，560分，河南的，想学金融，你怎么看？

系统将立刻调用就业倒推法、家庭背景分流和社会筛子论三个心智模型，输出经过结构化推理的回答。

## 适用场景

- **高考志愿填报咨询**：家长或考生输入分数、省份、意向专业，系统基于就业数据和决策模型给出合理建议，识别常见误区（如盲目追热门专业）。
- **考研择校指导**：针对不同专业、不同本科背景，系统评估考研回报率，判断是否值得“双非冲击985”，并指出行业倾向性差异。
- **职业规划决策**：对于即将毕业的大学生或职场转型者，系统可基于资源背景、行业趋势和个人特质，给出优先考公、就业还是深造的建议。
- **AI 代理集成开发**：开发者可直接将此 skill 嵌入到自己的 AI 项目中，获得一个专业、接地气的志愿规划助手，无需从零训练。

## 项目亮点

与同类“名言集锦”或“语录合集”项目相比，张雪峰.skill 的最大差异化优势在于其“可运行性”。它不是静态的文字集合，而是经过系统性调研和结构化蒸馏的决策框架，能被 AI 动态调用并生成符合张雪峰认知风格的回答。项目对原始资料的调研深度和广度远超普通项目，5 本著作、30+ 条一手语录、11 个关键决策记录的调研基础保证了输出的真实性和准确性。同时，其三层架构设计（心智模型 + 决策启发式 + 表达基因）让 AI 既能做出理性决策，又能以富有感染力的方式输出，兼顾了实用性和传播力。最后，MIT 开源许可证允许社区自由使用和扩展，降低了使用门槛。
