## 项目概述

`free-for.dev` 是一个由社区维护的精选资源列表，专门收集为开发者提供免费层的 SaaS、PaaS 和 IaaS 服务。项目的核心目标是解决开发者和开源作者在寻找免费云服务时面临的信息分散问题——市面上有大量服务提供免费额度，但逐个发现和评估这些服务需要耗费大量时间。这个列表将分散的信息集中整理，帮助基础设施开发者（系统管理员、DevOps 实践者等）快速做出知情决策。

项目由开发者社区共同驱动，已有超过 1600 人通过 Pull Request 贡献内容。列表严格限定范围，只收录与基础设施开发相关的免费层服务，并设定了明确的准入标准：必须提供真正的免费层（而非仅限时试用），时间限制型的免费层至少持续一年，并且不限制 TLS 等安全功能在付费层才提供。

## 核心功能

- **分类整理的服务目录**：按照服务类型划分，涵盖云服务商、分析工具、监控系统、数据库、CI/CD、域名管理等 50 多个类别，便于按需查找
- **严格的免费层筛选标准**：排除仅提供短期试用或功能受限的服务，确保列出的每项服务都能长期免费使用
- **社区驱动的质量保障**：通过集体审核和持续更新，及时移除已变更或退役的服务，保持列表的准确性和时效性
- **可视化状态追踪**：与 Track Awesome List 集成，提供实时动态追踪，方便了解项目更新频率和新增服务
- **安全性与合规性考量**：明确收录免费层中必须包含 TLS 等基础安全功能，确保用户在生产环境中使用不会降低安全标准
- **二级标题锚点导航**：Markdown 文件自带目录锚点，支持快速跳转到特定服务类别，提高查找效率

## 技术架构

项目本质上是一个精心维护的 Markdown 文档，采用以下技术策略：

- **纯 Markdown 格式**：使用 GitHub Flavored Markdown，包含目录、链接、代码块等元素，无需构建工具即可直接在 GitHub 上呈现
- **目录锚点系统**：通过二级标题自动生成锚点，配合 Table of Contents 实现快速导航
- **社区协作机制**：基于 GitHub Pull Request 工作流，贡献者提交新服务或更新信息后，由维护者审核合并
- **持续集成检查**：使用 GitHub Action 自动检查 Pull Request 是否符合格式规范，确保列表结构一致性
- **Track Awesome List 集成**：自动追踪仓库的 Star 变化和更新频率，为用户提供可视化数据
- **零依赖部署**：无需服务器、数据库或构建步骤，直接作为静态 Markdown 文件托管在 GitHub 上

## 安装与使用

该资源列表无需安装，通过浏览器即可直接使用：

1. 访问 `https://github.com/ripienaar/free-for-dev`
2. 浏览或搜索 README.md 中的内容
3. 使用目录快速跳转到感兴趣的类别

**最小可用示例**：查找云服务时，直接查看“Major Cloud Providers”部分，AWS、Azure、GCP 等主要云厂商的永久免费层信息已按类别列出，并附带直达免费层注册页面的链接。

若希望本地使用，可克隆仓库并在本地编辑器中查看：

```bash
git clone https://github.com/ripienaar/free-for-dev.git
cd free-for-dev
# 直接打开 README.md 浏览
```

## 适用场景

- **初创企业冷启动**：预算有限时，利用列表中的免费服务搭建 MVP（最小可行产品），涵盖数据库、CI/CD、监控、域名等关键基础设施
- **开源项目托管**：寻找为开源项目提供免费层的 CI/CD 平台、代码质量工具或静态托管服务，降低项目维护成本
- **学习与实验环境**：开发者学习云计算时，通过列举的永久免费层资源搭建实验环境，无需产生任何费用
- **DevOps 工具选型评估**：系统管理员在评估监控、日志、安全扫描等工具时，参考列表中的免费版功能，作为选型的起点

## 项目亮点

- **社区驱动的持续更新**：已有 1600+ 贡献者参与维护，确保信息的时效性和覆盖面远超个人维护的类似列表
- **严格的筛选准则**：明确区分“免费层”和“免费试用”，要求免费层至少持续一年且不限制基础安全功能，避免用户陷入试用陷阱
- **精准的受众定位**：专注于基础设施开发者，不收录前端、设计等非 DevOps 领域工具，减少无关信息干扰
- **无商业干扰**：纯公益性质的列表，不包含推广内容或付费链接，完全基于社区共识
- **低维护成本**：采用纯 Markdown 存在 GitHub 上，无需服务器或持续维护资源
