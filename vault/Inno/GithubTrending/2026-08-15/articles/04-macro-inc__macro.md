## 项目概述

Macro 是一个面向团队的一体化工作空间，旨在将日常工作中分散的各类工具统一到一个快速、高效的界面中。它整合了电子邮件、即时消息、文档、任务管理、AI 代理、通话和客户关系管理（CRM），并通过共享的团队级记忆和 @ 链接机制将这些模块有机连接。

该项目源于创始团队在运营初创公司时的真实痛点：当团队规模扩大到约 20 人时，使用 Slack、Linear、Notion、HubSpot 和 Superhuman 等独立工具导致信息孤岛严重，团队协作变得混乱且低效。Macro 希望通过一次彻底的重新设计，让工作软件真正成为一个可计算的统一系统，而不是通过 MCP 或 Zapier 等中间件勉强拼凑。

项目使用 Rust 语言开发，采用 AGPL-3.0 开源许可证，目前在 GitHub 上已获得超过 3000 星标，适合追求高效协作的初创团队、中小型企业以及关注开源 AI 工作流工具的开发者。

## 核心功能

- **一体化信息聚合**：将电子邮件、聊天消息、文档、任务、CRM 数据统一在一个界面中呈现，无需在多个应用间切换。
- **@ 链接机制**：任何工作项（联系人、文档、任务、邮件）都可以通过 @ 符号相互引用，形成知识网络，方便快速跳转和关联。
- **共享团队级 AI 记忆**：AI 助手能够访问团队统一的历史上下文，提供基于全量信息的智能建议和自动化操作。
- **内置 AI 代理**：支持创建和运行自动化代理，可基于团队记忆执行任务，减少重复性人工操作。
- **统一的搜索体验**：跨模块的全局搜索，可以同时检索邮件、文档、聊天记录和 CRM 信息。
- **快速响应界面**：基于 Rust 的高性能底层设计，确保界面交互流畅，不受数据量增长影响。

## 技术架构

Macro 以 Rust 作为主要开发语言，这为其带来了内存安全和并发性能上的优势。在架构设计上，Macro 采用中央化的数据模型，所有模块（邮件、聊天、文档、任务、CRM）共享同一套数据结构，这是实现跨模块 @ 链接和统一搜索的基础。

团队级 AI 记忆是 Macro 架构的核心创新之一。系统会将团队的历史交互、决策和知识沉淀为结构化记忆，并让 AI 代理基于这些记忆进行推理和操作，而非像传统工具那样每个模块拥有独立且割裂的数据上下文。

在客户端层面，Macro 强调“单一快速界面”的设计哲学，通过 Rust 实现的高性能数据层支撑即时响应。与多数协作工具采用 Electron 等跨平台框架不同，Rust 原生实现有助于降低内存占用并提升渲染效率。整个系统遵循 AGPL-3.0 许可证，鼓励社区参与开发和自托管部署。

## 安装与使用

由于 Macro 当前主要作为云端服务提供，用户可以直接访问 [macro.com/app](https://macro.com/app) 注册账号使用。对于开发者或希望自托管的用户，可以通过以下方式获取源码：

```bash
git clone https://github.com/macro-inc/macro.git
cd macro
# 根据项目文档配置环境变量和依赖
cargo build --release
```

最小使用示例：注册或登录后，首先导入企业邮箱和通讯录，系统会自动同步历史邮件和联系人。随后可以通过 @ 符号在任意输入框中引用联系人、文档或任务，例如在聊天中发送“请将 @产品需求文档 同步给 @张三”，AI 代理会自动解析链接并执行对应操作。团队记忆会在使用过程中自动累积，AI 助手可基于此提供越发精准的建议。

详细的部署指南和 API 文档请参阅 [docs.macro.com](https://docs.macro.com)。

## 适用场景

- **初创公司统一协作平台**：从零搭建团队工具链，避免多个 SaaS 订阅和割裂的数据孤岛，降低协作成本。
- **客户关系驱动型团队**：销售与客户成功团队需要同时管理邮件、通话记录、CRM 数据和内部协作，Macro 可将客户全生命周期信息集中在同一界面。
- **AI 驱动的知识型团队**：希望在文档、任务和沟通中嵌入 AI 代理，利用团队历史记忆实现半自动化操作的研究团队或咨询机构。
- **厌倦了工具切换的重度协作者**：每天花费大量时间在邮件、聊天、文档之间切换的个体用户，可以借助 Macro 的 @ 链接和统一搜索大幅减少上下文切换。

## 项目亮点

与市面上其他“一站式”协作工具相比，Macro 的核心差异化在于四个方面。其一，**原生的 AI 记忆层**：大多数工具将 AI 作为附加功能，而 Macro 从底层设计就将团队记忆作为一等公民，AI 代理和搜索均建立在这一共享记忆之上。其二，**Rust 技术栈**：不同于主流协作工具采用的 JavaScript 生态，Rust 带来了更高的性能和更低的资源占用，为用户提供媲美本地应用的响应速度。其三，**真正的模块互通**：@ 链接并非简单的文本提及，而是数据结构层面的关联，意味着任务可以自动关联相关邮件和文档，CRM 记录可即时显示全部沟通历史。其四，**开源可自托管**：作为 AGPL-3.0 项目，企业可以自主部署并掌控数据，避免了闭源 SaaS 的锁定风险。
