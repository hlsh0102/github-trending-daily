## 项目概述

RAGFlow 是一款开源的检索增强生成（Retrieval-Augmented Generation, RAG）引擎，由 infiniflow 团队开发并维护。该项目旨在将先进的 RAG 技术与智能体（Agent）能力深度融合，为大语言模型（LLM）构建一个高质量、高可靠性的上下文层。

在实际应用中，大语言模型常常面临知识过时、产生幻觉、无法访问私有数据等挑战。RAGFlow 通过从用户提供的知识库中检索相关信息，并将其注入到模型的生成过程中，有效地缓解了这些问题。与传统的 RAG 解决方案不同，RAGFlow 不仅关注检索的准确性，还引入了深度文档理解、Agent 自主规划等机制，使得整个系统能够应对更复杂的知识密集型任务。

项目的目标用户包括：需要构建企业级知识库问答系统的开发者、希望利用私有数据增强大模型能力的 AI 应用团队、以及对 RAG 技术有深入研究需求的研究人员。凭借其 Apache-2.0 开源协议和活跃的社区支持，RAGFlow 已获得超过 88,000 个 GitHub Star，成为该领域内最受关注的项目之一。

## 核心功能

- **深度文档理解**：内置 Visual Transformer 等深度学习模型，能够精准解析非结构化文档（如 PDF、Word、PPT 等）中的表格、图片、版面信息，确保文本分块的逻辑性和完整性。
- **基于模板的文本分块**：提供多种分块模板，支持根据文档结构（如标题、段落）智能切分，有效避免字符串长度截断导致的语义丢失。
- **可解释的引用溯源**：系统在生成回答的同时，会输出相关的引用来源，用户可以对回答进行逐句追根溯源，大幅降低幻觉风险，提升答案的可信度。
- **Agent 化 RAG 工作流**：将 RAG 流程封装为 Agent 能力，支持复杂的多跳推理、工具调用和动态规划，使得系统不再局限于简单的“检索-生成”模式。
- **灵活的配置与集成**：支持多种文档解析方法、嵌入模型和向量数据库（如 Elasticsearch、Milvus、Qdrant）的自由组合，并兼容主流的大模型 API。
- **可视化流程编排**：提供了一个友好的 Web UI，让用户可以通过拖拽方式配置知识库解析、检索策略和 Agent 流程，无需深度编程即可完成系统搭建。

## 技术架构

RAGFlow 的核心架构设计遵循“深度解析—智能检索—Agent 决策—可靠生成”的流水线理念。

在底层，项目采用 Go 语言编写性能关键组件，并深度融合 Python 生态的 AI 能力，实现了两者的无缝衔接。Go 在高并发、网络吞吐和资源管理方面表现出色，确保了数据摄取和 API 服务的稳定性；而 Python 侧则承载了深度学习模型推理和复杂的 Agent 逻辑。

文档解析是 RAGFlow 的技术亮点之一。它引入了基于视觉的文档结构识别技术，能够将 PDF 中的表格、图像转换为可读的 Markdown 或结构化数据。这一步骤显著提升了后续向量化和检索的质量，相较于仅依赖文本提取的方案，RAGFlow 在处理复杂版面文档时优势明显。

检索层面，RAGFlow 支持混合检索策略（稠密向量检索与稀疏关键词检索结合），并允许用户配置重排序（Rerank）模型，以进一步提高召回内容的精准度。Agent 机制则负责解析用户意图，决定是否需要多轮检索、是否需要调用外部工具，并在最终生成前对选中的上下文片段进行聚合和压缩。

## 安装与使用

RAGFlow 提供了基于 Docker Compose 的一键部署方案，非常适合快速启动和体验。硬件方面，建议 CPU 至少 4 核，内存至少 16 GB，磁盘空间充足。如果启用内置的 embedding 模型，则需要配置带有至少 8 GB 显存的 GPU。

**安装步骤如下：**

1. 确保已安装 Docker 和 Docker Compose（版本要求 v2.0 及以上）。
2. 克隆仓库并进入目录：
   ```bash
   git clone https://github.com/infiniflow/ragflow.git
   cd ragflow
   ```
3. 复制配置文件（如需修改端口或模型接入，请编辑 `.env` 文件）：
   ```bash
   cp docker/.env.example .env
   ```
4. 基于 `.env` 中的配置生成 Docker 服务编排文件：
   ```bash
   docker compose -f docker/docker-compose.yml up -d
   ```
5. 启动后，访问 `http://localhost:9380` 进入 Web 界面。首次使用需通过 `docker logs -f docker-ragflow-server-1` 查看日志获取初始登录密码。

**最小使用示例：** 登录系统后，进入“知识库”页面创建一个新知识库，上传若干 PDF 文档，等待解析完成。随后进入“聊天”页面，创建一个新的对话助手，关联刚建成的知识库，即可开始提问。系统会基于文档内容生成回答并标注引用来源。

## 适用场景

- **企业知识库问答**：将企业内部的规章制度、产品手册、技术文档等导入 RAGFlow，员工即可通过自然语言查询获取准确答案，无需翻阅海量资料。
- **智能客服与工单助手**：结合 Agent 能力，自动检索历史工单和解决方案库，辅助客服人员快速定位问题，甚至生成初步回复草稿。
- **金融与法律文档分析**：针对财报、合同、判决书等格式严谨、信息密度高的文档，利用其深度解析能力进行事实核查、信息抽取和风险点分析。
- **学术研究与教育辅助**：研究人员可上传论文库，快速进行文献综述、观点对比；学生则可利用其对教材进行问答式学习。

## 项目亮点

- **卓越的文档解析效果**：与多数仅做文本切片的方案不同，RAGFlow 对版面结构（表格、多栏、图片注脚）的还原能力出色，极大地减少了信息丢失，从源头上保障了 RAG 质量。
- **“求真”的生成机制**：强制性的引用追溯功能让模型的每一次回答都有据可依，在需要高度可信的场景下具有不可替代的价值。
- **开箱即用的完整闭环**：项目不仅提供了检索和生成引擎，还自带简洁的 Web 界面、API 服务和完整的文档管理机制，降低了用户从零搭建的难度。
- **活跃的开源生态**：项目受到全球开发者高度关注，迭代速度快，社区提供了丰富的多语言文档支持和插件集成方案。
