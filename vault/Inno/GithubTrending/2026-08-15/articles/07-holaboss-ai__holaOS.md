## 项目概述

holaOS 是一个开源的 All in One AI Agent 工作台，旨在解决当前 AI 代理工具碎片化的问题。如今，开发者常常需要同时使用 Claude Code、Codex 等多种 AI 代理，而这些代理之间缺乏统一的运行环境和共享上下文。holaOS 将这一切整合到一个本地优先的工作空间中，让用户可以在一个统一的界面中运行任意 AI 代理，并让它们协同操作各类工具、应用、浏览器和文件，同时共享同一份记忆。

该项目主要面向 AI 重度使用者，包括开发者、技术研究人员以及自动化流程设计者。其核心目标是成为"你和你的代理的计算机"——一套为 AI 代理优化的工作环境，而非简单的聊天界面。

## 核心功能

- **多代理支持**：原生支持 Claude Code、Codex 以及 holaOS 自身的代理，未来可扩展更多代理类型。用户可以在同一工作空间中切换不同代理，比较其表现或分工协作。
- **100+ 集成与 MCP 支持**：内置超百种常用工具和服务的集成，同时完整支持 MCP（Model Context Protocol），使得用户可以接入任意支持该协议的第三方工具生态。
- **跨工具操作能力**：代理不仅可以读取文件，还可以直接操作浏览器、桌面应用，真正实现"代理动手干活"而非仅生成建议。
- **共享记忆系统**：所有代理共享一个统一的记忆存储，这意味着你可以让 Claude Code 处理代码，再让 Codex 继续处理，两者都能获取前后文信息，无需重复交代背景。
- **内置模型与 BYOK**：开箱即可使用内置的前沿模型，同时也支持用户携带自己的 API Key（BYOK），在隐私和成本控制上更加灵活。
- **本地优先架构**：所有数据处理和存储优先在本地完成，代理运行环境也支持完全离线部署，保障用户数据主权。

## 技术架构

holaOS 采用 TypeScript 作为主要开发语言，这保证了代码的可维护性和类型安全性。从架构设计上看，项目遵循以下核心思路：

首先是**统一运行时层**。holaOS 为不同代理提供了标准化的运行环境适配层，通过适配器模式将 Claude Code、Codex 等代理的输入输出转换为内部统一格式，从而实现跨代理的工作流编排。

其次是**本地优先的存储设计**。项目使用嵌入式数据库和文件系统来管理共享记忆与工作区状态，所有数据默认存放在本地磁盘中，只有在用户明确授权时才与云端服务通信。

第三，**安全边界的处理**。由于代理需要操作浏览器、应用和文件，holaOS 在系统层面实现了细粒度的权限控制，用户可以为每个代理设置可访问的工具与资源范围，避免权限滥用。

此外，MCP 支持采用动态加载机制，用户可以在运行时新增或移除工具协议，而无需重启整个工作台。

## 安装与使用

holaOS 目前提供多种安装方式，具体取决于您的操作系统。基础安装步骤如下：

```bash
# 通过 npm 全局安装
npm install -g holaos

# 启动工作台
holaos start
```

对于本地开发或贡献代码的开发者：

```bash
git clone https://github.com/holaboss-ai/holaOS.git
cd holaOS
npm install
npm run dev
```

最小使用示例——在 holaOS 中运行 Claude Code：

```bash
# 启动后，在交互终端中输入：
holaos run --agent claude-code "优化当前目录下的代码性能"
```

如需使用自带 API Key：

```bash
holaos config set ANTHROPIC_API_KEY "sk-xxx"
holaos run --agent claude-code --byok "分析项目依赖"
```

## 适用场景

- **跨代理代码审查与重构**：用 Codex 进行代码扫描，再用 Claude Code 执行重构，两者共享分析结果，极大提升效率。
- **自动化工作流编排**：在浏览器中获取数据、在文件系统中生成报表、再通过桌面应用发送通知——一个代理完成全链路操作。
- **个人 AI 知识库管理**：多代理共享记忆适合构建个人知识库，让不同代理在长期记忆中积累和沉淀特定领域知识。
- **本地优先的企业内部 AI 工具整合**：无需将敏感数据上传至云端，在完全本地化的环境中完成文档处理、数据分析等任务。

## 项目亮点

holaOS 的差异化优势主要体现在三个维度：

其一，**多代理编排能力**。不同于只能绑定单一模型的工具，holaOS 从一开始就为多代理协作而设计，这是其社区热度快速上升的重要原因。

其二，**本地优先与数据主权**。在面对云端 AI 工具日益普及的背景下，holaOS 坚持内容默认本地存储，这对于处理敏感数据的企业用户极具吸引力。

其三，**开放生态而非封闭平台**。通过 MCP 支持和 BYOK 模式，holaOS 没有将用户锁死在特定模型或工具链中，而是成为各种 AI 能力的统一集线器。
