## 项目概述

SpiderFoot 是一款开源情报（OSINT）自动化工具，由 Robin Wood 发起、Steve Micallef 持续维护，旨在帮助安全研究人员、渗透测试人员和威胁情报分析师自动化收集与分析公开信息，从而精准映射自身攻击面。它能与超过 200 个数据源集成，涵盖域名、IP、电子邮件、社交媒体、暗网等多个维度，将分散的公开情报整合为结构化、可导航的数据，解决了传统 OSINT 调研中手工收集效率低、数据碎片化、关联分析困难等核心问题。无论您是负责企业安全防御的蓝队成员，还是从事红队评估的渗透测试专家，SpiderFoot 都能显著缩短情报收集时间，提升威胁发现能力。

## 核心功能

- **双模式交互**：提供基于 Web 的图形界面和纯命令行（CLI）两种使用方式，满足不同用户习惯与自动化场景需求。
- **超过 200 个集成模块**：内置丰富的数据源解析模块，覆盖 WHOIS、DNS、SSL 证书、社交网络、搜索引擎、暗网市场等，可灵活启停与组合。
- **关联规则引擎**：采用 YAML 配置的关联引擎，内置 37 条预定义规则，可自动识别不同数据点之间的潜在关联（如 IP 与域名、邮箱与社交账号）。
- **多样化导出格式**：支持 CSV、JSON、GEXF（图形交换格式）数据导出，便于导入其他分析工具或进行二次加工。
- **数据持久化与查询**：基于 SQLite 后端存储扫描结果，支持自定义 SQL 查询，方便历史数据回溯与深度分析。
- **API 密钥管理**：支持数据源 API 密钥的导出与导入，便于在多环境间同步配置，保持扫描一致性。
- **可视化与暗网支持**：内置图形可视化功能，直观展示实体间关系；集成 TOR 网络，支持对暗网资源的搜索与情报收集。

## 技术架构

SpiderFoot 完全使用 **Python 3.7+** 编写，遵循 MIT 开源许可协议。其架构设计以模块化和可扩展性为核心：

- **模块化扫描引擎**：每个数据源或分析能力被封装为独立模块，模块间通过统一的输入/输出数据结构进行通信。扫描任务由调度器驱动，通过依赖关系图决定模块执行顺序，例如先收集域名信息，再基于关联的 IP 进行端口扫描。
- **嵌入式 Web 服务器**：内置轻量级 Web 服务器，提供响应式界面，所有操作通过 RESTful API 与后端交互，使得用户无需安装额外依赖即可通过浏览器完成完整扫描配置与结果审查。
- **关联引擎**：基于规则的关联引擎读取 YAML 格式的规则文件，对扫描产生的事件进行模式匹配。规则可定义条件（如“事件类型为域名解析且目标 IP 属于特定网段”）与动作（如“生成新关联事件”），实现了自动化威胁狩猎。
- **数据存储层**：所有扫描事件、模块配置和结果统一存储在 SQLite 数据库中，这种设计既保证了单机环境下的高性能，也便于用户直接使用 SQL 进行复杂查询，为后续与 SIEM 等系统集成提供了灵活性。
- **可配置性与 TOR 集成**：通过配置文件可精细控制模块启用、扫描速率、代理设置等；内置对 TOR 的支持，可将流量路由至暗网进行匿名侦察。

## 安装与使用

SpiderFoot 支持通过 pip 直接安装，或使用 Docker 容器化部署。以下为两种常用方式：

**方式一：pip 安装（命令行模式）**
```bash
# 安装
pip install spiderfoot

# 启动命令行扫描
python3 sf.py -m ALL -s example.com -o csv
```
上述命令会对 `example.com` 执行所有模块扫描，并以 CSV 格式输出结果至标准输出。

**方式二：Docker 部署（Web 界面模式）**
```bash
# 拉取镜像并运行容器
docker run -p 5001:5001 -v /path/to/data:/home/spiderfoot/data smicallef/spiderfoot
```
随后访问 `http://localhost:5001` 即可打开 Web 界面，通过图形化向导创建扫描任务，并实时查看扫描进度与可视化关系图。

**最小可用示例**：在 Web 界面中新建扫描，输入目标域名，选择“所有模块”，点击启动。扫描完成后，可浏览事件列表、关联分析结果，并导出 JSON 文件用于其他工具。

## 适用场景

- **红队攻击面测绘**：在渗透测试初期，快速收集目标组织的域名、子域名、员工邮箱、技术栈等信息，为后续漏洞探测提供输入。
- **蓝队安全监控增强**：定期对外部暴露的 IP、域名进行自动扫描，及时发现新增的未经授权服务或数据泄露迹象。
- **威胁情报关联分析**：结合内置关联规则，将 IOC（入侵指标）与其他公开数据进行交叉验证，扩充威胁情报上下文。
- **隐私暴露评估**：面向个人或企业，检查自身信息在互联网的暴露程度，识别可被非法利用的公开数据。

## 项目亮点

- **全面性**：相较于其他 OSINT 工具，SpiderFoot 覆盖数据源数量众多，且模块持续更新，几乎“一网打尽”多数公开数据源。
- **自动化与智能**：内置的关联引擎让工具能够自动“思考”数据之间的关系，而非仅仅罗列聚合信息，极大提升分析效率。
- **部署灵活性**：同时提供 Web UI 和 CLI，既适合 GUI 用户，也便于集成到 CI/CD 流水线中实现持续监控。
- **透明度与可扩展性**：MIT 许可证允许商用与二次开发，模块化架构鼓励社区贡献新数据源插件，保持了项目的活跃度与生命力。
