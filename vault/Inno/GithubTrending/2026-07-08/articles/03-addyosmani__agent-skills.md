## 项目概述

Agent Skills 是一个面向 AI 编码助手的生产级工程技能集。该项目由 Addy Osmani 创建，旨在将资深工程师在软件开发中使用的规范工作流、质量门禁和最佳实践封装成标准化技能模块，使 AI 代理能够在开发的每个阶段一致地遵循这些流程。

项目解决了 AI 编码助手在实际开发中的核心痛点：缺乏标准化的开发流程指导。通过定义明确的阶段划分和对应的技能集，Agent Skills 确保 AI 代理不仅能生成代码，还能遵循专业的工程实践，从而提升代码质量和团队协作效率。

目标用户包括使用 AI 编码辅助工具的开发团队、希望提升 AI 代码生成质量的个人开发者，以及研究 AI 辅助软件工程的研究人员。

## 核心功能

- **六阶段开发流程**：定义了从需求定义到产品发布的完整生命周期（Define → Plan → Build → Verify → Review → Ship），每个阶段都有对应的技能模块。
- **八个斜杠命令**：通过 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等命令，开发者可以一键激活对应阶段的技能集。
- **规范优先**：强制要求先编写规范后编写代码（spec before code），确保开发过程有明确的指导文档。
- **原子化任务分解**：在规划阶段将大型任务拆分为小粒度的原子任务（small, atomic tasks），降低实现复杂度。
- **增量构建**：鼓励一次只实现一个功能切片（one slice at a time），降低变更风险。
- **测试即证明**：将测试作为代码质量的证明依据（tests are proof），确保每个功能点都有相应的验证。

## 技术架构

Agent Skills 采用模块化的技能包架构，每个技能包对应一个开发阶段，包含该阶段所需的提示词模板、工作流定义和质量标准。技能包之间通过约定的接口进行衔接，形成完整的开发流水线。

项目的核心设计思路是将软件工程的最佳实践编码为 AI 可理解的指令集。每个技能包不仅包含操作指令，还嵌入了质量门禁（quality gates），在阶段转换时自动进行质量检查。例如，从 Build 阶段进入 Verify 阶段前，必须有一组通过测试。

技术实现上，项目使用 JavaScript 编写，通过明确定义的命令接口与 AI 代理交互。每个命令对应一个技能包，技能包内部包含提示词模板、工作流步骤和验证规则。这种设计使得技能包可以独立更新和扩展，而不影响整个流程的运作。

## 安装与使用

Agent Skills 的安装和使用非常直接：

1. 克隆仓库：`git clone https://github.com/addyosmani/agent-skills.git`
2. 将技能包配置到你的 AI 编码代理设置中（具体配置方式取决于使用的 AI 代理工具）。
3. 在开发过程中使用斜杠命令激活对应的技能包：

```bash
# 定义要构建的功能
/spec "用户认证模块"

# 制定实现计划
/plan "实现邮箱密码登录"

# 开始构建
/build "用户注册功能"
```

## 适用场景

- **新功能开发**：从需求定义到发布的完整流程，确保每个步骤都有标准化的指导。
- **代码审查**：通过 `/review` 命令激活审查技能包，自动执行代码质量检查和最佳实践验证。
- **项目协作**：团队使用统一的开发流程和术语，减少沟通成本和理解偏差。
- **AI 代理训练**：作为 AI 编码代理的培训材料，帮助其学习专业的软件开发流程。

## 项目亮点

与同类项目相比，Agent Skills 的核心差异化优势在于：

1. **生产级质量**：技能集来自资深工程师的实际工作经验，而非理论化的开发流程。
2. **明确的阶段划分**：六阶段模型覆盖了从想法到发布的完整生命周期，每个阶段都有具体的产出物和质量标准。
3. **命令驱动**：使用简洁的斜杠命令切换技能包，学习成本极低，开发者可以快速上手。
4. **质量门禁嵌入**：每个阶段转换时内置质量检查，防止有问题的代码进入下一阶段。
5. **开源贡献良好**：项目在 GitHub 上拥有超过 7 万星标，社区活跃度高，持续获得改进和扩展。
