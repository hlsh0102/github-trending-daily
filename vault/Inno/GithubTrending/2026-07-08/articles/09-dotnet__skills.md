## 项目概述

.NET Agent Skills 是由 .NET 团队官方维护的一套核心技能与自定义代理集合，专门用于增强 AI 编码代理（如 GitHub Copilot、Cursor 等）在 .NET 和 C# 开发场景下的能力。该项目解决了 AI 编码代理在处理 .NET 特定任务时知识不足、上下文理解不准确、操作不规范等问题，为开发者提供了经过验证的、结构化的编程指导。

目标用户是使用 AI 编码代理进行 .NET 开发的工程师，包括但不限于：日常使用 Copilot 的 .NET 开发者、依赖 AI 辅助进行代码审查和调试的团队、需要自动化处理 .NET 构建与包管理的运维人员，以及正在迁移升级 .NET 项目的技术负责人。

## 核心功能

- **C# 语言服务器集成**：提供标准化的 LSP（语言服务器协议）集成，让编码代理能准确理解 .NET 项目的类型系统、成员定义和语法结构。
- **高级 .NET 开发技能**：覆盖特殊场景下的 .NET 编码任务，如异步编程、内存管理优化、反射使用等高级主题。
- **数据访问与 Entity Framework 支持**：专门为 .NET 数据层操作优化的技能，包括 EF Core 的查询编写、迁移管理和性能调优。
- **性能诊断与调试**：提供性能分析、内存转储分析、事件追踪等诊断技能，帮助代理协助排查运行时问题。
- **MSBuild 构建系统集成**：涵盖构建失败诊断、性能优化、代码质量检查和项目现代化改造的全套技能。
- **NuGet 包管理**：支持依赖管理、版本冲突解决、包迁移和现代化升级建议。
- **项目迁移与升级**：针对跨 .NET Framework、.NET Core 和最新 .NET 版本的迁移场景，提供框架适配、语言特性迁移和兼容性分析。
- **.NET MAUI 开发支持**：为跨平台移动和桌面应用开发提供专门技能，包括平台特定代码处理和 UI 优化。

## 技术架构

项目采用插件化架构，每个插件（Plugin）代表一个独立的功能域，遵循 [agentskills.io](https://agentskills.io) 定义的 Agent Skills 标准。这种设计确保了：

- **模块化**：各技能插件相互独立，可以根据项目需要选择性加载，降低整体复杂度。
- **可扩展性**：外部贡献者可以基于标准协议创建新的技能插件，丰富 .NET 生态的 AI 辅助能力。
- **可测试性**：项目自带精确度与效率评分机制，通过 [📊 Dashboard](https://dotnet.github.io/skills/) 持续追踪各插件的实际表现。

每个插件使用 JSON Schema 定义技能接口，通过标准化的输入输出格式与编码代理交互。例如 `dotnet` 插件定义了 C# 代码生成、类型解析、命名空间管理等基本能力，而 `dotnet-diag` 则定义了性能计数器分析、堆栈跟踪解读等诊断能力。这种结构化的定义方式使得编码代理不需要理解底层实现细节，就能准确调用相应技能。

## 安装与使用

.NET Agent Skills 的设计初衷是与支持 Agent Skills 标准的编码代理配合使用。基本使用流程如下：

1. **确认代理兼容性**：确保使用的编码代理（如 GitHub Copilot、VS Code 内建助手等）支持 agentskills.io 协议。
2. **加载技能插件**：在代理配置中指定需要加载的技能插件。例如，如果项目使用 EF Core，可以加载 `dotnet-data` 插件。
3. **触发技能调用**：在对话中自然表达需求，代理会根据上下文自动匹配并调用适合的技能。

对于最小可用示例，假设你正在使用一个兼容的编码代理，并希望它帮助你创建一个 .NET 控制台应用：

```
用户： "创建一个使用 EF Core 的 .NET 8 控制台应用，包含一个 Blog 实体和对应数据库上下文。"

代理（经 dotnet + dotnet-data 技能加持后）：
- 调用 dotnet 技能生成项目骨架
- 调用 dotnet-data 技能配置 EF Core 连接字符串和模型
- 输出完整的 Program.cs、Blog.cs 和 DbContext 代码
```

项目 README 提供了各插件更详细的使用说明和示例场景，位于 `plugins/` 目录下。

## 适用场景

- **日常 .NET 开发辅助**：在编写 CRUD 代码、处理依赖注入、配置中间件等日常工作场景中，让 AI 代理理解 .NET 特有的编码模式。
- **构建与部署自动化**：当构建失败或出现性能瓶颈时，`dotnet-msbuild` 和 `dotnet-diag` 插件能指导代理定位问题根源并给出修复建议。
- **项目迁移升级**：将传统 .NET Framework 项目迁移到 .NET 6/8 时，`dotnet-upgrade` 插件提供框架版本适配、API 替换和兼容性检查。
- **包管理问题排查**：当 NuGet 依赖出现版本冲突或安全漏洞时，`dotnet-nuget` 插件能帮助代理分析依赖关系并提出升级方案。

## 项目亮点

- **官方维护与认证**：由 .NET 团队直接维护，确保技能准确反映最新框架的最佳实践和 API 变化，避免了第三方技能可能存在的过时或错误信息。
- **持续的质量追踪**：Dashboard 提供每项技能插件的准确性和效率评分，用户可以根据客观数据选择使用哪些技能，也为技能改进提供了量化的反馈依据。
- **模块化与可组合性**：开发者可以根据项目实际需求，只加载必要的技能插件，而不是加载一个笨重的全功能包。这种按需加载的方式既节省资源，也减少了代理的决策噪声。
- **标准化接口**：遵循 agentskills.io 标准，不绑定特定编码代理，未来可以与更多支持该标准的 AI 工具集成，具有良好的生态兼容性。
