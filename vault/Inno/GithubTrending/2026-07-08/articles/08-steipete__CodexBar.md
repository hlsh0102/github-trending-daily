## 项目概述

CodexBar 是一款专为 macOS 14+ 设计的菜单栏应用，用于实时监控和显示 OpenAI Codex、Claude 等众多 AI 编码提供商的使用配额与限制。它解决了 AI 开发者频繁切换网页、反复登录查看 API 使用情况的痛点，让用户无需打开浏览器或登录控制台，即可在菜单栏中一目了然地掌握所有 AI 编码服务的剩余额度、花费和重置时间。目标用户是重度依赖 AI 编程助手（如 Codex、Claude Code、Cursor、Copilot 等）的开发者、研究人员以及所有需要管理多个 AI 服务预算的使用者。

## 核心功能

- **多提供商统一监控**：支持超过 57 个 AI 编码提供商，包括 Codex、OpenAI、Claude、Cursor、Gemini、GitHub Copilot、Grok、GroqCloud、ElevenLabs、Deepgram、Vertex AI、AWS Bedrock、OpenRouter、LiteLLM 等，并在持续增加。
- **智能图标显示**：可为每个提供商分别显示独立的菜单栏图标，或启用“合并图标模式”将所有提供商整合为一个图标，通过弹出菜单进行切换。
- **配额与重置倒计时**：显示每个提供商的会话、每周和每月的使用窗口，并带有精准的倒计时，帮助用户规划任务，避免在接近限制时启动长时间运行的工作。
- **详细财务信息**：提供信用额度余额、管理员 API 花费看板、提供商账单摘要，以及针对部分提供商的本地成本扫描功能。
- **实时状态与事件通知**：持续轮询提供商状态，当服务中断或出现问题时，在菜单栏图标上显示事故徽章，并支持自定义通知。
- **精选极简 UI**：无 Dock 图标，完全运行在菜单栏中，弹出面板采用卡片式设计，显示进度条、重置时间等核心信息，交互干净利落。

## 技术架构

CodexBar 基于 Swift 开发，充分利用了 macOS 14+ 的菜单栏扩展和 SwiftUI 框架。应用本身是一个无界面进程，仅通过菜单栏和弹出面板与用户交互，保持了极高的运行效率。其架构核心是一个可扩展的提供商适配器层：每个 AI 服务对应一个独立的适配器，负责与各自的 API 通信、解析响应数据，并统一转换为应用内部的使用量模型。这种插件式设计使得新增提供商的支持非常简单，无需修改核心代码。应用通过定时轮询机制获取数据，并利用本地缓存减少不必要的网络请求。数据呈现方面，CodexBar 采用动态 SVG 图标技术，直接在菜单栏绘制实时更新的进度条和状态图标，避免了静态图标的局限性。整体设计强调轻量、低资源占用，确保在后台运行时几乎不消耗系统资源。

## 安装与使用

安装 CodexBar 有多种方式，推荐以下两种：

1.  **Homebrew 安装（推荐）**：
    ```bash
    brew tap steipete/homebrew-tap
    brew install --cask codexbar
    ```

2.  **手动安装**：
    从 [GitHub Releases 页面](https://github.com/steipete/CodexBar/releases/latest) 下载最新版本的 `.dmg` 文件，打开后将应用拖入 `Applications` 文件夹。

首次启动后，应用会出现在菜单栏。点击图标打开弹出面板，你将看到一个提供商列表。要添加提供商：

1.  点击面板底部的 "+" 按钮或进入偏好设置。
2.  从列表中选择你使用的 AI 服务（如 OpenAI、Claude 等）。
3.  输入对应的 API 密钥或凭据。应用会安全地存储在系统钥匙串中。
4.  选择是否启用“合并图标模式”（如果你同时使用多个提供商，推荐开启）。

完成配置后，菜单栏图标将实时显示你的使用情况。点击图标即可查看详细的使用条、花费和重置倒计时。你还可以在偏好设置中调整轮询频率、通知规则等。

## 适用场景

- **多服务开发者**：同时使用 OpenAI Codex、Claude Code 和 Cursor 的开发者，需要快速对比各平台剩余额度，合理分配任务，避免因某个服务超限而中断工作流。
- **团队管理员**：管理多个团队成员的 API 成本，通过 CodexBar 的 Admin API 集成，无需登录云端控制台即可监控团队整体花费和使用趋势。
- **预算敏感型用户**：对 API 调用成本有严格限制的独立开发者或小型团队，利用 CodexBar 的实时花费显示和本地成本扫描功能，精确控制每个项目的月度开支。
- **服务状态监控**：需要依赖多家 AI 提供商服务的应用开发者，CodexBar 的实时状态徽章可以第一时间发现服务中断，快速调整后端调用策略。

## 项目亮点

与同类工具相比，CodexBar 的差异化优势体现在：

- **全平台覆盖**：支持 57+ 提供商，覆盖了市面上几乎所有主流和新锐 AI 编码服务，远超过大多数仅支持个别平台的解决方案。
- **零登录体验**：用户无需登录任何第三方平台或注册账号，所有凭据安全存储在本地钥匙串，隐私和安全性优于云端控制台替代方案。
- **极致的视觉整合**：动态菜单栏图标和 Merge Icons 模式的设计，在有限的菜单栏空间内提供了丰富的状态信息，既美观又高效。
- **实时性与精准度**：采用轮询机制配合缓存策略，在保证信息及时性的同时，避免对提供商 API 造成过多请求压力，比浏览器书签或者手动的定时检查更可靠。
- **开源与社区驱动**：基于 MIT 协议开源，社区可以自由贡献新的提供商适配器，项目更新活跃（自发布以来已获得超过 17000 颗星标）。
