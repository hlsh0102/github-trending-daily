## 项目概述

AI Job Search 是一个基于 Claude Code 构建的 AI 驱动求职应用框架。它解决了求职过程中重复、耗时且容易疲劳的环节——从评估职位匹配度、定制简历、撰写求职信到面试准备，全部由 AI 自动完成。目标用户是正在积极寻找工作、希望提升申请效率和质量的技术求职者，尤其是那些熟悉 Git 工作流和 Claude 命令行工具的开发者。

该项目目前拥有超过 11,000 个 GitHub Star，并且增长迅速，表明它在开发者社区中引起了广泛共鸣。

## 核心功能

- **自我画像配置**：通过 `/setup` 命令引导用户填写个人资料，包括技能、经历、目标职位偏好，形成结构化的求职档案。
- **职位信息抓取与评估**：内置针对丹麦求职网站（如 Jobindex、Jobnet、Akademikernes Jobbank）的抓取技能；同时支持通过 `/apply <url>` 直接评估任意职位链接，自动分析匹配度并给出评分与建议。
- **定制化简历生成**：根据职位描述和画像，自动调整并生成针对特定岗位的专属简历，突出相关经验和关键词。
- **求职信撰写**：基于职位要求和用户背景，生成专业、个性化的求职信草稿。
- **面试准备支持**：分析职位需求，生成可能的面试问题列表及作答思路，帮助用户提前准备。
- **完整的申请管线**：采用“起草者-评审者”双角色流程，先由 AI 生成申请材料，再由另一个 AI 实例进行审查和优化，确保输出质量。

## 技术架构

项目以 TypeScript 为主要语言，核心工作流构建在 Claude Code 的命令行接口之上。架构设计遵循模块化与可插拔原则：

- 核心工作流（自我画像、匹配评估、起草-评审管线）是**语言和地区无关的**，可通用于全球求职场景。
- 职位搜索爬虫部分则作为“技能插件”，目前内置了丹麦市场的求职网站，但设计上支持轻松替换为其他地区的招聘门户。
- 用户通过命令行触发不同阶段的操作（`/setup`、`/scrape`、`/apply <url>`），每个命令对应一个独立的 AI 协作流程。
- 整个框架依托 Git 进行版本管理，用户的所有画像和生成材料都作为代码库的一部分，支持分支、合并与回滚，为求职过程提供了前所未有的可追溯性和迭代能力。

## 安装与使用

1. **前提条件**：确保已安装 [Claude Code](https://claude.com/claude-code) 并配置好 Anthropic API 密钥。
2. **Fork 仓库**：访问 [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search) 并 Fork 到自己的 GitHub 账户。
3. **克隆仓库**：将 Fork 的仓库克隆到本地。
   ```bash
   git clone https://github.com/你的用户名/ai-job-search.git
   cd ai-job-search
   ```
4. **设置个人资料**：运行 `/setup` 命令，按照交互提示填写你的技能、经历、求职目标等信息。这部分信息将存储在你的仓库中。
5. **抓取职位或直接评估**：
   - 运行 `/scrape` 自动抓取已配置的求职网站上的最新职位。
   - 如果已有心仪的职位链接，直接运行 `/apply <职位URL>`，Claude 将自动分析职位并启动申请材料生成管线。
6. **审查与提交**：AI 生成的简历、求职信等材料保存在本地文件中，你可以审查、修改后用于实际申请。

## 适用场景

- **海量职位初步筛选**：当你每天需要浏览数十个职位时，让 AI 先按你的画像进行评估并打分，快速锁定最有潜力的机会。
- **针对不同职位的批量定制**：对于相似但略有差异的多个职位，AI 可快速为每个职位生成定制化简历和求职信，大幅节省重复劳作的时间。
- **非母语求职市场**：如果你正在丹麦等非英语国家求职，AI 可以帮助你更好地理解本地职位描述，并生成符合当地文化习惯的申请材料。
- **系统化求职管理**：将整个求职过程纳入 Git 版本控制，可以追踪每次申请的迭代历史，复盘哪些材料获得了面试邀请，持续优化。

## 项目亮点

- **本地区域与全球通用的平衡**：核心工作流不受地区限制，而爬虫模块可轻松切换，既开了箱即用的本地体验，又保留了全球适配的灵活性。
- **AI 双角色审核管线**：不依赖单一 AI 生成，而是采用“起草者+评审者”的双轮机制，有效降低幻觉和错误，大大提升输出材料的专业度。
- **版本控制的天然优势**：用户画像、历史生成、迭代过程全部由 Git 管理，这在同类 AI 求职工具中属于首创，使得求职策略的优化和复盘变得清晰可见。
- **开源与社区驱动**：MIT 许可证让任何人都可以自由使用、修改和贡献，社区发展的爬虫技能和配置模板将不断丰富工具的可用性。
