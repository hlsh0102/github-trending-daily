## 项目概述

Meetily 是一款以隐私为先的 AI 会议助手，专注于为用户提供完全本地化的会议记录与摘要服务。它基于 Rust 构建，内置了比标准 Whisper 快 4 倍的 Parakeet/Whisper 实时转录引擎，支持说话人分离（Speaker Diarization），并能通过 Ollama 在本地生成会议摘要。项目完全开源，无需依赖任何云服务，所有数据处理均在用户自己的设备上完成。主要面向注重数据隐私的个人用户、团队以及企业，特别是那些对会议记录有高频需求但又担心信息外泄的 macOS 与 Windows 用户。

## 核心功能

- **高速实时转录**：采用优化的 Parakeet/Whisper 模型，转录速度可达标准 Whisper 的 4 倍，确保会议过程中几乎无延迟的文字呈现。
- **说话人分离**：自动识别并区分不同发言人的声音，在转录文本中标注说话人身份，便于后续回溯谁在何时说了什么。
- **本地 AI 摘要**：集成 Ollama，在本地运行大语言模型，无需联网即可自动生成会议纪要、待办事项和关键决策点。
- **100% 本地处理**：所有音频数据处理、转录和摘要生成均在设备本地完成，无任何数据上传至云端，从根源杜绝隐私泄露风险。
- **跨平台桌面支持**：为 macOS 和 Windows 提供原生桌面应用，安装便捷，启动后即可在后台静默运行。
- **开源与自托管**：项目完全开源（MIT 许可），用户可自行审计代码、定制功能，并一键部署到自己的服务器或本地环境。

## 技术架构

Meetily 的核心架构围绕“本地优先”和“高性能”两大原则设计。底层采用 Rust 语言编写，利用其内存安全和高并发特性，确保转录引擎在 CPU 或 GPU 上的高效运行。转录部分基于 Candle 机器学习框架（Hugging Face 的 Rust 版）加载并运行 Parakeet/Whisper 模型，通过模型量化和算子优化实现 4 倍速度提升。说话人分离功能则利用基于 Pyannote 或类似声纹识别模型的轻量级实现，在转录的同时对音频流进行分段标记。摘要生成侧，通过调用本地运行的 Ollama 服务（支持 Llama、Mistral 等模型），将转录文本异步送入大模型，生成结构化的会议纪要。整体采用事件驱动架构，通过后台守护进程监听系统音频输入，实时处理并缓存转录结果，UI 层则基于 Tauri（Rust 封装 WebView）或原生框架构建，确保界面流畅且与底层逻辑解耦。

## 安装与使用

**安装步骤（以 macOS 为例）：**

1. 前往 [GitHub Releases 页面](https://github.com/Zackriya-Solutions/meeting-minutes/releases) 下载最新版 `.dmg` 安装包。
2. 双击安装并拖拽 Meetily 到 Applications 文件夹。
3. 首次启动时，系统会请求麦克风权限，请允许授予。
4. 如果希望使用 AI 摘要功能，请确保已安装 [Ollama](https://ollama.ai) 并下载所需的模型（例如 `ollama pull llama3.2`）。

**最小可用示例：**

1. 启动 Meetily 应用，界面中央会显示“开始录制”按钮。
2. 点击按钮，软件即刻开始捕捉系统音频或麦克风输入。
3. 会议进行中，右侧实时显示带说话人标签的转录文本。
4. 会议结束后，点击“生成摘要”，等待数秒即可获得包含会议要点、行动项的 AI 总结。
5. 转录文本和摘要可一键导出为 Markdown、TXT 或直接复制到剪贴板。

> 注意：首次运行需等待模型下载（约 1-2GB），请确保网络连接稳定。

## 适用场景

- **企业内部会议**：特别是涉及商业机密、客户信息或财务数据的讨论，无需担心转录内容被第三方云服务记录。
- **远程团队协作**：结合 Zoom、Teams 等会议软件，实时生成文字记录和摘要，方便未参会者快速了解会议内容。
- **学术与研究讨论**：访谈、研讨会等场景，精确的说话人分离能帮助研究者快速定位特定发言人的观点。
- **个人笔记与复盘**：每日站会、头脑风暴或听课记录，本地运行无需联网，随时随地使用。

## 项目亮点

与 Otter.ai、Fireflies.ai 等云服务以及同类本地项目相比，Meetily 的核心差异化在于：

1. **极致的隐私保护**：所有计算和数据停留在本地，彻底避免云端泄露风险，符合 GDPR、HIPAA 等高隐私合规要求。
2. **速度与性能的平衡**：通过 Rust 和模型优化实现 4 倍转录加速，在主流笔记本上即可流畅运行，无需高价 GPU。
3. **开源可控**：MIT 许可允许商业使用、二次开发和私有化部署，用户拥有完全的自主权。
4. **集成简洁**：直接集成 Ollama，无需配置复杂的外部 AI 服务链路，安装即用。
5. **双平台原生支持**：同时提供 macOS 和 Windows 的稳定原生体验，无需 Electron 类臃肿框架。
