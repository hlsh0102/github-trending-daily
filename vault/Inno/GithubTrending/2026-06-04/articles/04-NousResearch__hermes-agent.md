## 项目概述

Hermes Agent 是由 Nous Research 开发的一款开源自改进化 AI 智能体。与传统 AI Agent 不同，Hermes Agent 内置了持续学习循环：它能够从与用户的交互中提取经验并形成技能，在使用过程中不断优化，自动将重要知识持久化，并跨会话构建对用户需求的深度理解。项目致力于解决当前 AI 助手缺乏长期记忆和自主进化能力的问题，让 Agent 不仅是一个问答工具，更是一个随用户一同成长的智能伙伴。

目标用户包括需要智能助手的开发者、希望构建个人 AI 助理的终端用户、以及探索自主 AI 系统的研究人员。项目采用 MIT 许可协议，完全开源，已获得广泛社区关注（17.9 万星标）。

## 核心功能

- **技能自动生成与优化**：Agent 能从日常交互中提取有效模式，自动创建可复用技能，并在后续使用中根据反馈持续改进这些技能。
- **持久化知识管理**：系统可以自动识别重要信息并将其存储到长期记忆库中，包括用户偏好、关键事实和历史上下文。
- **多会话记忆建模**：跨越不同对话会话构建用户画像，随着使用时间增加，Agent 对用户的理解逐渐深化。
- **对话历史搜索**：支持在历史对话中高效检索，用户可以快速找到之前讨论过的任何内容。
- **多平台访问**：支持通过 Telegram 等消息平台远程交互，让 Agent 在云端 VM 上运行，用户从任意设备访问。
- **任意模型兼容**：支持接入 Hugging Face 上的任意开放语言模型，用户可自由选择最适合自己需求的模型（如 Nous 家族模型）。

## 技术架构

Hermes Agent 基于 Python 开发，采用模块化设计。核心技术特性包括：

- **学习循环引擎**：与常规 Agent 的"查询-响应"模式不同，Hermes 内置了一个持续运行的反馈循环。每次交互后，系统会评估是否需要更新技能库、记忆或用户模型，从而实现自主进化。
- **分层记忆系统**：将记忆分为工作记忆（当前会话）、短期记忆（近期交互）和长期记忆（持久化存储）三层，采用高效索引机制实现快速检索。
- **工具与技能框架**：技能以可插拔插件的形式存在，Agent 在运行时动态加载与任务最匹配的技能，支持自定义扩展。
- **轻量部署设计**：核心推理可在低至 5 美元/月的 VPS 上运行，支持 GPU 集群或 Serverless 架构，空闲时几乎零成本。这种设计使得用户无需昂贵的硬件即可获得稳定的 AI 助理服务。
- **模型无关接口**：通过统一的 API 层抽象，支持无缝切换不同语言模型，从 7B 到 70B 参数规模的模型均可兼容。

## 安装与使用

**基本安装步骤**：

1. **克隆仓库**：
```bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
```

2. **安装依赖**：
```bash
pip install -r requirements.txt
```

3. **配置模型和平台**：
   - 在环境变量中设置要使用的模型 ID（支持 Hugging Face 上的任何模型）
   - 可选配置 Telegram Bot Token 等平台连接信息

4. **运行 Agent**：
```bash
python main.py
```

**最小可用示例**：启动后，Agent 会开始监听用户输入。通过命令行或已配置的消息平台，用户可以开始对话。例如，用户可以告诉 Agent **"请帮我整理本周的项目进度，并记住我偏好简洁的风格"**——Agent 会执行任务，并自动将风格偏好记录到长期记忆，在后续回复中应用该偏好。

## 适用场景

- **个人知识管理助手**：持续帮助用户整理笔记、管理待办、检索过往信息，随着使用时间增加，对用户的思维模式和工作风格有更精准的把握。
- **开发者编程搭档**：可以学习用户的代码风格和常见工具链，在代码审查、问题排查、文档生成等任务中提供个性化辅助。
- **长期项目协作**：适用于需要跨多天、多会话推进的研发项目，Agent 能记住之前的技术决策、会议纪要、实验记录，并在当前上下文中智能关联。
- **远程任务自动化**：部署在云端 VM 后，通过 Telegram 等轻量客户端远程指挥 Agent 执行任务，适合移动办公或需要随时调用的场景。

## 项目亮点

- **真正的持续学习能力**：与多数 Agent 的"一次性交互"不同，Hermes Agent 拥有跨会话的进化机制，这是其区别于其他开源 Agent 项目的核心差异化优势。
- **极致轻量部署**：支持低至 $5 VPS 的运行环境，大幅降低了 AI Agent 的生产部署门槛。
- **模型自由选择**：不绑定特定模型，用户可以根据成本、延迟和性能需求选择任意 Hugging Face 模型，避免了锁定风险。
- **开源透明**：作为 Nous Research 的开源作品，社区可以审查、修改和扩展所有代码，确保了可信度和可定制性。
