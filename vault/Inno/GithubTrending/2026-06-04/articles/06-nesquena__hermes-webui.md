## 项目概述

Hermes WebUI 是一个轻量级、深色主题的 Web 界面，专为 [Hermes Agent](https://hermes-agent.nousresearch.com/) 设计。Hermes Agent 是一个运行在服务器上的自主智能体，能够通过终端或消息应用访问，具备持续学习能力——它会记住所学内容，运行时间越长，能力越强。

该项目解决了 Hermes Agent 用户的一个核心痛点：随时随地通过浏览器或手机访问智能体，无需依赖终端或命令行。目标用户包括开发者、AI 研究人员、以及希望在任何设备上高效管理和使用 Hermes Agent 的进阶用户。WebUI 实现了与 CLI 体验的完全对等，所有终端操作均可通过图形界面完成。

## 核心功能

- **三面板布局**：左侧边栏用于会话管理和导航，中央区域展示聊天内容，右侧面板提供工作区文件浏览。界面设计一目了然，操作高效。
- **内嵌组合器页脚**：模型选择、配置文件切换和工作区控件始终可见，方便用户在编写消息时快速调整设置。
- **语境环**：以环形可视化方式显示 Token 使用量，让用户实时掌握资源消耗情况。
- **Hermes 控制中心**：位于侧边栏底部，集中管理所有设置和会话工具，简化配置流程。
- **完整文件系统支持**：通过右侧面板可直接浏览、打开和编辑工作区文件，无需切换到其他工具。
- **密码保护与多主题**：支持自定义设置和密码配置，同时提供深色和浅色两种显示模式，适应不同使用环境。

## 技术架构

Hermes WebUI 采用极简的技术栈设计。后端使用 Python，前端使用纯 JavaScript（Vanilla JS），不依赖任何现代前端框架（如 React、Vue 或 Svelte），也没有构建步骤、打包工具或模块加载器。这种架构选择带来了几个显著优势：

- **零构建流程**：无需运行 `npm install` 或 `yarn build`，代码直接运行，部署简单快捷。
- **低资源消耗**：没有框架开销，适用于资源受限的服务器环境。
- **易于定制**：熟悉 HTML、CSS 和 JS 的开发者可以直接修改代码，无需学习复杂的工具链。
- **自适应布局**：三面板设计在桌面和移动设备上均能良好适配，环形语境图等 UI 元素使用 Canvas 绘制，性能高效。

后端与 Hermes Agent 通过 API 通信，所有会话记录和配置数据存储在服务器本地文件系统中。界面采用深色主题为主，同时提供浅色主题切换，满足不同用户的视觉偏好。

## 安装与使用

安装 Hermes WebUI 非常简单，前提是你已经运行了 Hermes Agent：

1. 克隆仓库：
```bash
git clone https://github.com/nesquena/hermes-webui.git
cd hermes-webui
```

2. 安装依赖（推荐使用虚拟环境）：
```bash
pip install -r requirements.txt
```

3. 启动服务：
```bash
python app.py
```

4. 在浏览器中访问 `http://localhost:5000`（默认端口）即可开始使用。

最小可用示例：启动后，你将看到三面板布局。左侧选择或创建新会话，中央区域输入消息与智能体交互，右侧浏览工作区文件。在组合器页脚中选择模型和配置文件，通过 Hermes 控制中心调整高级设置。所有功能无需额外配置即可使用。

## 适用场景

- **远程管理与监控**：在手机或平板等移动设备上，通过浏览器实时与 Hermes Agent 交互，查看会话历史、调整配置、浏览文件，无需登录服务器终端。
- **快速原型与测试**：开发者在本地开发环境中快速测试新模型、新提示词或代理行为，图形界面比命令行更直观，适合快速迭代。
- **团队协作演示**：向团队成员或客户展示 Hermes Agent 的能力时，WebUI 提供了更友好的交互方式，降低了使用门槛。
- **日常自动化任务**：用户可以通过 WebUI 管理多个会话，每个会话针对不同的工作流（如代码生成、文档整理、数据分析），快速切换并执行任务。

## 项目亮点

- **CLI 功能完全对等**：所有终端操作均可通过 WebUI 完成，不存在功能阉割，用户无需在界面和终端之间反复切换。
- **极简架构，零依赖前端框架**：与大多数现代 Web 工具不同，Hermes WebUI 使用纯 JavaScript 构建，部署简单、性能轻量，适合服务器端长期运行。
- **三面板 + 控制中心优化工作流**：会话、聊天、文件浏览三管齐下，设置和控制集中在底部和侧边，用户体验经过精心设计，操作高效流畅。
- **实时资源可视化**：语境环提供了即时的 Token 使用数据，帮助用户合理控制模型调用成本，这是 CLI 界面难以直观呈现的功能。
- **跨平台无缝体验**：WebUI 本质是 Web 应用，无论是桌面浏览器还是手机端，都能获得一致的操作体验。
