今日 GitHub Trending TOP10 速览 👇

1️⃣ JustVugg/colibri（C）
纯 C 实现的 MoE 推理引擎，无外部依赖。把磁盘、内存、显存当作统一分层架构，让消费级和异构硬件也能跑 744B–2.8T 参数的前沿 MoE 模型，支持 GLM、Kimi、DeepSeek、Qwen、OLMoE 等家族，提供 chat / serve / web 三种前端。

2️⃣ alibaba/open-code-review（Go）
阿里开源、经大规模验证的代码审查工具。确定性流水线 + LLM Agent 混合架构，输出精确到行的评论，内置 NPE、线程安全、XSS、SQL 注入等微调规则集，兼容 OpenAI 与 Anthropic 接口。

3️⃣ multimodal-art-projection/YuE（Python）
开源音乐生成项目 YuE2，把符号音乐与音频音乐生成统一到同一框架，支持符号化规划、零样本翻唱和智能体音乐编辑。主模型与配套权重已开放下载，原 YuE 代码保留在 YuE-v1 分支。

4️⃣ debpalash/VoiceStudio（Python）
完全本地运行的语音工具集，定位 ElevenLabs 自托管替代。语音克隆、语音设计、视频配音、听写、转录、有声书制作一站集成，内置 16 种 TTS、11 种 ASR 引擎，覆盖 646 种语言，无需账号和 API Key。

5️⃣ 666ghj/MiroFish（Python）
多智能体预测引擎。从新闻、政策、金融信号中提取种子信息，自动构建平行数字世界，让数千个带独立人格、长期记忆和行为逻辑的智能体自由互动、模拟社会演化，用于推演复杂事件走向。

6️⃣ Panniantong/Agent-Reach（Python）
让 AI 代理零 API 费用访问互联网的命令行工具。统一接口读取和搜索 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书等平台内容，省去逐平台对接 SDK 和认证的麻烦。
