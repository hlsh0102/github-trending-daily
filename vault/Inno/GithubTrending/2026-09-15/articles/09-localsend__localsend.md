## 项目概述

LocalSend 是一个免费、开源、跨平台的文件与消息传输工具，常被视为 AirDrop 的开放替代方案。它允许用户在同一局域网内的多台设备之间安全地发送文件和文本消息，而无需依赖互联网连接，也无需经过任何第三方服务器中转。

传统的跨设备文件传输往往面临几个痛点：Apple 生态中的 AirDrop 只能用于苹果设备之间；各大厂商推出的互传工具通常存在平台限制；而通过即时通讯软件或云盘中转，则可能涉及隐私泄露、文件大小限制或上传下载耗时等问题。LocalSend 正是为解决这些限制而生——只要设备处于同一网络，无论是 Windows、macOS、Linux、Android、iOS 还是通过命令行运行的服务器，都可以互相发现并直接收发文件。

项目的目标用户包括需要在不同操作系统设备间频繁传输文件的普通用户、注重数据隐私而不愿将文件上传至云端的技术用户，以及在无外网环境下（如内网、隔离网络）仍需进行文件交换的开发者和运维人员。

## 核心功能

- **跨平台互传**：支持 Windows、macOS、Linux、Android、iOS 等主流操作系统，桌面端和移动端可相互通信，并额外提供命令行接口供脚本和服务器环境使用。
- **局域网直连传输**：设备通过本地网络直接通信，无需接入互联网，文件不经过任何中心服务器，减少对外部网络的依赖。
- **自动设备发现**：基于局域网广播机制自动扫描并列出附近正在运行的 LocalSend 设备，用户无需手动配置 IP 地址即可开始发送。
- **安全加密通信**：设备之间通过 HTTPS 建立连接并使用自签名证书，配合一次性令牌等机制，避免传输内容被局域网内其他设备窃听。
- **文件与文本消息发送**：除文件外，还支持发送剪贴板文本或短消息，方便在设备间快速传递链接、验证码等内容。
- **多语言与开源协议**：借助 Weblate 进行社区翻译，支持多种语言界面；项目基于 Apache-2.0 许可证开源，便于审计和二次开发。

## 技术架构

LocalSend 使用 Dart 语言开发，并基于 Flutter 框架构建跨平台界面，因此能够以相对统一的代码库覆盖桌面端与移动端。传输协议方面，项目采用 REST API 风格的通信方式，设备在本地网络中以 HTTPS 提供服务端点，通过自签名证书进行加密，并借助多播（Multicast）或 UDP 广播实现设备发现。

整体设计遵循去中心化思路：不存在中心服务器，每台运行 LocalSend 的设备既是客户端也是服务端。这种点对点架构让传输速度直接受本地网络带宽影响，同时也意味着服务可用性不依赖任何外部基础设施。项目还提供了命令行接口，方便在无图形界面的环境（例如服务器或树莓派）中调用同样的传输能力。

## 安装与使用

用户可以从项目官网或 GitHub Releases 页面下载对应平台的安装包：Windows 提供安装程序或便携版，macOS 提供 dmg 或 Homebrew 安装方式，Linux 可通过发行版仓库、Flatpak、AppImage 等渠道获取，Android 通过应用商店或 APK 安装，iOS 通过 App Store 安装。部分 Linux 发行版和包管理器已收录该软件。

使用流程较为直接：

1. 在需要互传文件的设备上分别安装并打开 LocalSend，确保它们连接到同一个局域网。
2. 在接收端设备中保持应用运行，发送端会自动在设备列表中看到它；若未自动发现，可手动输入对方 IP。
3. 在发送端选择要发送的文件或输入文本，点击发送。
4. 接收端会弹出接收确认请求，用户确认后即可开始传输，文件默认保存到应用设置的下载目录中。

对于命令行场景，可通过 `localsend_cli` 或类似入口指定目标 IP 和文件路径完成发送，具体参数以仓库文档为准。

## 适用场景

- **多系统家庭或办公环境**：家中同时存在 Windows 电脑、Mac、Android 手机和 iPhone 时，可用同一款工具完成互传，避免为每种组合寻找不同方案。
- **隐私敏感的文件交换**：传输合同、证件扫描件等敏感文件时，不希望内容经过第三方服务器，局域网直连可以降低泄露风险。
- **无外网的内网环境**：在离线机房、实验室隔离网络或企业内网中，仍可通过本地网络完成设备间文件分发。
- **服务器与无界面设备**：借助命令行接口，可在没有图形界面的服务器或嵌入式设备上接收和发送文件，便于自动化脚本集成。

## 项目亮点

与 AirDrop 相比，LocalSend 的最大差异在于跨平台能力——它不局限于苹果生态，而是让不同厂商、不同操作系统的设备能够平等互通。与通过云盘或即时通讯软件传输相比，它不依赖互联网、不上传文件到第三方服务器，隐私性和速度都更有保障。

与部分同类开源方案相比，LocalSend 提供了较为完善的图形界面和移动端支持，并已进入多个 Linux 发行版的软件仓库，装机与维护成本较低。项目拥有活跃的社区翻译和持续集成流程，代码托管于 GitHub 和 Codeberg 两个平台，也在一定程度上降低了单一平台依赖的风险。凭借超过九万的 Star 数量，它已经成为开源跨平台文件传输领域中较受关注的项目之一。
