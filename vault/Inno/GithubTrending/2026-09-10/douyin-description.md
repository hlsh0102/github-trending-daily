今日 GitHub Trending TOP10 速览，来看看开源圈今天都在关注什么👇

1️⃣ ayghri/i-have-adhd
Python 项目，今日 +4650 星。一个给编程助手用的输出风格插件，强制结论前置、步骤编号、去掉客套话，让 AI 回复更快抓重点。适配 Claude Code、Codex 等工具，不需要 ADHD 诊断也能用。

2️⃣ Tencent/teamai-cli
腾讯开源的 TypeScript 命令行工具，用于统一管理团队在多种 AI 编码代理之间的技能、规则、MCP 配置和知识库，把共享经验放进 Git 仓库同步。

3️⃣ obra/superpowers
Shell 项目，一套面向编程代理的软件开发方法论。让代理先明确规格、制定计划，再进入子代理驱动的开发流程，覆盖十多种主流编码代理环境。

4️⃣ pascalorg/editor
基于 React Three Fiber 和 WebGPU 的 3D 建筑编辑器，本地优先，数据存本机 SQLite，同时提供浏览器和 CLI 入口，内置 MCP 服务。

5️⃣ earthtojake/text-to-cad
Python 写的智能体技能库，面向 CAD、CAE、CAM 工作流。把几何建模、检查、切片等操作拆成可组合技能，供不同智能体框架调用。

6️⃣ cathrynlavery/diagram-design
给 Claude Code 等工具用的图表技能包，提供几十种编辑级图表类型，输出自包含 HTML + SVG，能读取网站自动匹配配色字体，还能重绘 draw.io 文件。

7️⃣ TauricResearch/TradingAgents
基于多智能体 LLM 的金融交易框架，模拟真实交易团队的分析、辩论、决策与风控流程，适合量化与 AI 投研方向的研究者。

8️⃣ liquidslr/system-design-notes
《System Design Interview》第一卷和第二卷的学习笔记，按章节整理，涵盖限流器、一致性哈希、键值存储、聊天系统、YouTube 设计等主题。

9️⃣ openai/plugins
OpenAI 官方维护的 Codex 插件示例集合，包含 Figma、Notion、iOS、macOS、Web、Expo、Netlify 等…
