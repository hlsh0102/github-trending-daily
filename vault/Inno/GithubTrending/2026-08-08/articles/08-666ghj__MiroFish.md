## 项目概述

MiroFish 是一个基于多智能体（Multi-Agent）技术的下一代 AI 预测引擎。它从现实世界提取种子信息（如突发新闻、政策草案或金融信号），自动构建一个高保真的平行数字世界。在这个数字空间中，数千个拥有独立性格、长期记忆和行为逻辑的智能体自由交互并进行社会演化。

该项目由盛大网络（Shanda）支持，旨在解决传统预测模型难以模拟复杂社会系统动态变化的问题。目标用户包括金融分析师、政策研究者、市场研究人员以及对群体智能和复杂系统模拟感兴趣的开发者和学术研究人员。MiroFish 的设计哲学是“简洁通用”，力求以最小的复杂度实现跨领域的预测能力。

## 核心功能

- **种子信息驱动的世界构建**：用户只需输入新闻、政策或市场信号等文本信息，引擎自动生成对应的模拟世界初始状态，无需手动配置复杂参数。
- **大规模智能体模拟**：支持同时运行数千个具有独立人格特质、情感模型和决策逻辑的智能体，每个智能体拥有长期记忆，行为模式随时间演化。
- **动态变量注入**：提供“上帝视角”控制台，允许用户在模拟运行期间实时注入新事件或修改环境参数，观察系统如何响应变化并调整预测。
- **社会演化与意见形成**：智能体之间通过自发对话和互动进行信息传播、观点博弈和社会学习，模拟真实世界中的舆论形成和集体决策过程。
- **预测结果可视化**：内置数据分析与可视化模块，输出群体意见分布、情绪指数、关键转折点等量化指标，支持导出为图表或数据文件。
- **跨域通用接口**：统一的输入/输出抽象层，使用户能够轻松将引擎应用于金融、政治、市场研究等不同领域的预测任务。

## 技术架构

MiroFish 的核心架构采用分层设计，主要由三个层次组成：

**1. 世界编译层（World Compiler）**：负责解析自然语言形式的种子信息，通过自然语言处理（NLP）技术将其结构化为世界初始状态，包括实体、关系和事件图谱。这一层使用了大语言模型（LLM）作为基础组件，并结合了领域知识库进行知识增强，以提升对专业术语和复杂政策文本的理解能力。

**2. 模拟引擎层（Simulation Engine）**：这是系统的核心，采用基于智能体建模（Agent-Based Modeling, ABM）范式。每个智能体由一个轻量级的状态机加上 LLM 驱动的决策模块组成。系统使用异步消息传递机制在智能体间进行通信，以支持高并发交互。为了管理大规模模拟的计算开销，引擎实现了动态调度算法，根据智能体的活跃度分配计算资源，并对长时间未参与关键事件的智能体进行状态压缩。

**3. 分析聚合层（Analytics Aggregator）**：实时收集所有智能体的状态和行为记录，通过统计学方法和机器学习算法聚合出群体层面的洞察。该层支持流式计算，能够以秒级延迟更新预测指标，并在检测到系统出现临界转变（Critical Transition）时发出预警。

整个系统采用模块化设计，各层之间通过标准化的 JSON 数据结构进行交互，便于独立扩展和替换组件。后端基于 Python 的异步框架（如 FastAPI）构建，前端提供 RESTful API 和 WebSocket 接口，支持跨语言调用。

## 安装与使用

MiroFish 支持通过 Docker 和 pip 两种方式安装。

**前置要求**：Python 3.9+ 或 Docker，以及一个可用的 OpenAI API Key（或兼容的 LLM 接口）。

**方式一：Docker 安装（推荐）**

```bash
docker pull 666ghj/mirofish
docker run -d -p 8000:8000 -e OPENAI_API_KEY=your_key_here 666ghj/mirofish
```

**方式二：pip 安装**

```bash
git clone https://github.com/666ghj/MiroFish.git
cd MiroFish
pip install -r requirements.txt
export OPENAI_API_KEY="your_key_here"
python app.py
```

**最小使用示例**（Python 脚本方式）：

```python
from mirofish import MiroFishEngine

# 初始化引擎
engine = MiroFishEngine()

# 加载种子信息（模拟一条金融新闻）
seed_info = "美联储宣布加息50个基点，市场反应不一。"

# 构建模拟世界
world = engine.create_world(seed=seed_info, agent_count=1000)

# 设置模拟步数并运行
results = engine.run(world, steps=50)

# 获取预测结果：群体情绪分布、主流意见演变等
output = engine.analyze(results)
print(output.summary())
```

## 适用场景

- **金融市场预测**：输入宏观经济政策或公司公告，模拟投资者群体的情绪波动与预期变化，辅助判断市场短期趋势。
- **舆情与社会趋势分析**：针对突发公共事件，构建模拟社会网络，预测舆情走向、公众态度的极化概率以及潜在的社会行为后果。
- **政策影响评估**：在政策正式实施前，模拟不同利益群体对政策的反应和适应行为，评估政策落地的潜在阻力与风险。
- **产品市场测试**：在虚拟用户群体中模拟新产品的口碑传播路径，预测市场接受度和早期用户反馈模式。

## 项目亮点

- **极低的启动门槛**：传统群体模拟系统需要用户具备大量的领域知识和建模经验，而 MiroFish 只需一段自然语言描述即可自动构建模型。
- **动态干预与情景推演**：支持在模拟运行中实时加入“扰动”（如突发变量），使得用户可以探索多种“如果……会怎样”的假设情景，这区别于大多数只能从头运行的固定模拟引擎。
- **通用性与可扩展性**：不绑定任何特定领域的知识表示，通过替换 LLM 及其提示词即可适配新场景，且智能体规模可按需水平扩展。
- **兼顾微观与宏观洞察**：系统同时输出单个智能体的行为日志和群体层面的统计指标，满足不同细粒度的分析需求。
