📢 今日 GitHub 开源日报来了！10 个优质项目，从 AI 编程助手到 C++ 底层库，一文全掌握 🚀

1️⃣ mattpocock/skills — 资深开发者 Matt Pocock 亲用的 AI 编程技能集。不同于 GSD 等重流程框架，它主打小巧、可组合，帮你在用 Claude 这类工具做真实项目时，既享受 AI 效率，又稳住工程掌控权。主打「小而美」的 Agent 技能哲学。

2️⃣ DietrichGebert/ponytail — 专治 AI 乱写代码！这个提示词工具把「最懒的资深开发者」思维注入代理，让它先想「这代码真的需要吗」，能省则省。官方称可大幅削减无效代码，兼容 20 多种主流 AI 代理框架。一句话总结：最好的代码是你没写的那行。

3️⃣ fmtlib/fmt — C++ 现代格式化库的「老大哥」。比 printf 和 iostream 更快、更安全，实现了 C++20 的 std::format 和 C++23 的 std::print。告别难用的格式化符号，类型安全不崩溃，现代 C++ 项目必备。

4️⃣ affaan-m/ECC — 一个「代理操作系统」。它给 Claude Code、Codex、Cursor 等加上技能库、直觉引擎和跨会话记忆，让 AI 编码代理不只是工具，而是能在长期项目里越用越顺手。适合团队和个人深度开发者。

5️⃣ anthropics/skills — Anthropic 官方的 Agent Skills 合集驾到！每个技能都是一个自带 SKILL.md 的文件夹，让 Claude 按需加载专业知识。涵盖创意、技术、企业工作流等场景，是给 Claude 扩展能力的官方权威参考。

6️⃣ blader/humanizer — 去 AI 味神器。它基于维基百科「AI 写作迹象」检测表，用 35 种模式重写文本，让 AI 生成的文字更像人类写的，且严格不改动事实。适合需要让 AI 初稿变得更自然的内容创作者。

7️⃣ NousResearch/hermes-agent — 能自我进化的 AI 代理。它内置学习循环，能从任务中创建技能、记住交互并给你建模。官方表示低至 5 美元的 VPS 就能跑，适合想低成本拥有个人定制 AI 助理的玩家。
