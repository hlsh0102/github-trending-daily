## 项目概述

Caveman 是一个为 Claude Code 等 AI 编码代理（coding agent）设计的技能包（skill），其核心理念可以用一句话概括："why use many token when few do trick"（能用少量 token 解决的事，何必用大量 token）。该项目通过强制 AI 代理以极简的"原始人"风格进行沟通与代码生成，平均可削减约 65% 的 token 消耗，从而显著降低使用 AI 编程工具的成本。对于重度依赖 AI 代理进行日常开发、对 API 费用敏感的个人开发者与团队而言，Caveman 提供了一种经济高效的解决方案。

## 核心功能

- **极简语言风格强制**：通过内置的提示词与行为约束，让 AI 代理在解释问题、生成代码和更新日志时使用最精炼的词汇和句式，避免冗长的自然语言输出。
- **65% Token 削减**：在典型代码任务中（如编写函数、修改 Bug、撰写提交信息），大幅压缩输入与输出的 token 数量，官方测试显示平均节省可达 65%。
- **无缝集成 Claude Code**：作为技能包（skill）安装后，不对现有工作流做破坏性修改，只需在项目上下文中激活，即可让模型自动切换到节省模式。
- **多代理适配**：不仅支持 Claude Code，项目还提供了灵活的封装方式，可适配 30+ 种其他主流 AI 编码代理（通过简易包装脚本）。
- **轻量级 Go 工具链**：附带的命令行工具用于激活/停用配置，以及生成任务报告，帮助用户直观对比节省效果。
- **上下文优化**：在维持代码质量与逻辑正确性的前提下，自动忽略无实际信息量的寒暄与重复性说明（如"Certainly!""Here's the breakdown"等）。

## 技术架构

Caveman 的底层并非修改模型权重，而是通过**提示工程与上下文注入**的方式实现。项目核心是一个精心设计的系统提示词（system prompt），在启动时被加载进 AI 代理的上下文窗口。该提示词通过具体指令与示例（few-shot）塑造模型的输出风格，例如要求将解释限制在 5 个词内、代码注释仅保留必要说明，并将"礼貌用语"替换为单字响应。

项目主代码使用 Go 编写，提供一个轻量级 CLI 工具，主要承担两对职责：一是为支持的代理创建配置环境（自动寻找配置文件路径），二是提供 `wrap` 命令，通过环境变量或 API 代理的方式，将任何兼容的编码代理进程进行"风格包裹"。此方案无需深度集成，仅需在发起请求时注入提示词。这种设计使得 Caveman 不依赖特定模型版本，任何支持系统提示词或上下文注入口的模型都能受益。

## 安装与使用

**前置条件**：需已安装 Claude Code 或其他兼容 AI 编码代理。建议使用 Go 1.21 以上版本进行工具编译。

**安装步骤**（以 Claude Code 为例）：

1. 克隆仓库并构建工具：
   ```bash
   git clone https://github.com/JuliusBrussee/caveman.git
   cd caveman
   go build -o caveman ./cmd/caveman
   ```

2. 执行安装脚本，将技能配置注入 Claude Code 的配置目录：
   ```bash
   ./caveman install --agent claude-code
   ```

3. 激活技能（在需要节省 token 的项目中执行）：
   ```bash
   ./caveman activate
   ```

**最小使用示例**：

激活后，在 Claude Code 中发起一个典型的修复请求。对比激活前后效果，你可能会看到如下差异：

- **未激活时**：AI 输出一段长文解释原因，附带多步骤改动计划及详细代码注释。
- **激活后**：AI 直接输出 `fix: off-by-one in loop` 以及仅包含必要改动的代码块。

当你完成阶段任务，可运行 `./caveman deactivate` 恢复正常交流风格。

## 适用场景

- **对 API 成本敏感的大规模重构**：当你需要 AI 辅助执行涉及数百个文件的机械性重构时，节省的 token 意味着显著的成本降低。
- **高频使用 AI 结对编程的日常开发**：长期活跃的编码代理用户每分钟都在消耗成本，Caveman 可自动将多轮对话中的冗词压缩。
- **CI/CD 管道中的自动代码审查**：在自动化工作流程中集成 Caveman，让 AI 审查意见更精简直接，减少日志存储与解析成本。
- **教育场景下的学习辅助**：对于希望快速获取关键代码逻辑，而非长篇解释的初学者，Caveman 提供了无干扰的极简解答格式。

## 项目亮点

与市面上同类 token 优化工具（如提示词压缩器或自定义缓存）相比，Caveman 的差异化优势明显：它不需要修改 API 调用逻辑、不牺牲对话历史理解能力，**完全依赖行为风格引导**——这是无侵入式的优化。项目始终强调"脑力不变"（Brain still big），只牺牲修辞不牺牲智力，因此代码的安全性、准确性不受影响。

此外，Caveman 以单仓库、低依赖的 Go 二进制分发，安装极简，并且具备**跨代理兼容性**，打破了特定厂商绑定。这种工具在 GitHub 上迅速获得了超过 10 万 Star 的认可，很好地契合了当前 AI 费用高企背景下开发者对降本增效的迫切需求。
