## 项目概述

ECC（Enhanced Claude Code）是一个面向 AI 编程代理（Agent）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流代理工具提供统一的能力增强层。项目将代理所需的核心能力——技能管理、直觉反馈、记忆机制、安全防护和研究驱动的开发模式——整合为一个可插拔、可配置的“代理操作系统”。

该项目解决的核心问题是：在使用 AI 编程代理时，开发者往往面临技能分散、上下文丢失、缺乏安全边界等痛点。ECC 通过系统化的方式为代理提供结构化的运行环境，让代理不仅能够执行代码任务，还能在长期项目中保持一致性、安全性和高效性。无论是个人开发者还是团队协作，ECC 都能显著提升 AI 代理的工作质量与可靠性。

## 核心功能

- **技能系统**：内置丰富的技能库，支持自定义技能注册与优先级配置，让代理在特定场景下能够调用最合适的工具和流程。
- **直觉（Instinct）引擎**：通过预设的启发式规则，让代理在遇到常见问题时自动采取推荐行动，减少重复决策，提升开发效率。
- **持久化记忆**：提供跨会话的记忆存储与检索机制，使代理能够记住用户偏好、项目历史决策和代码库关键信息，解决上下文丢失的根本问题。
- **安全防护层**：内置权限管理、敏感信息屏蔽和命令白名单/黑名单机制，防止代理在执行任务时造成意外破坏或数据泄露。
- **研究优先的开发模式**：支持代理在执行任务前自动进行代码库探索、文档查询和最佳实践检索，确保决策基于全面的上下文。
- **多代理适配**：使用统一的配置接口，可无缝适配 Claude Code、Codex、OpenCode 等主流工具，无需重复学习。

## 技术架构

ECC 采用模块化、声明式的架构设计，核心运行时代码使用 JavaScript 编写，保证了广泛的兼容性。项目架构围绕“配置即代码”的理念展开，所有技能、记忆和安全策略均以结构化的配置文件定义，允许开发者通过简单的 YAML 或 JSON 格式进行定制。

在实现层面，ECC 提供了一系列钩子（Hooks）和中间件机制，可以在代理的执行流程中注入自定义逻辑。记忆系统采用向量数据库加缓存的双层结构，兼顾检索速度与存储容量。技能模块则通过依赖注入的方式动态加载，避免了模块间的高耦合。

系统设计特别强调“零侵入性”，ECC 作为外层代理包装器存在，不需要修改原有代理工具的内部实现。这意味着开发者可以随时启用或禁用 ECC，而不会影响现有的开发工作流。

## 安装与使用

安装 ECC 非常简单，推荐使用 npm 进行全局安装：

```bash
npm install -g ecc-agent
```

安装完成后，通过以下命令初始化项目配置：

```bash
ecc init
```

该命令会在当前目录下生成 `.ecc` 配置文件结构。最基础的配置示例如下：

```yaml
# .ecc/config.yaml
agent:
  provider: claude-code  # 或 codex、opencode、cursor

memory:
  provider: local
  options:
    path: ./.ecc/memory

skills:
  enabled: true
  defaults: autogenerate

security:
  allowed_commands: ["npm", "git", "npx"]
  ignore_patterns: [".env", "*.pem"]
```

完成配置后，即可通过 ECC 启动代理：

```bash
ecc run "修复 src/main.js 中的内存泄漏问题"
```

首次运行时，ECC 会自动创建记忆存储并加载默认技能。用户可以与代理进行自然对话，ECC 将在后台同步管理记忆与技能调用。

## 适用场景

- **大型代码库重构**：当面对包含数万文件的代码库时，ECC 的记忆机制可以帮助代理记录完成的区域和待处理的任务，避免重复探索，大幅提升重构效率。
- **自动化开发流程集成**：团队可以将 ECC 接入 CI/CD 流水线，利用其安全防护层确保自动生成的代码符合特定的安全策略和编码规范。
- **多代理协作项目**：在一个研发项目中同时使用不同类型的代理时（例如代码审查代理和代码生成代理），ECC 的统一配置层可以让所有代理共享同一套记忆与安全策略，保证一致性。
- **新手开发者学习引导**：ECC 的研究优先模式可以引导初学者在编码前先探索项目结构和既有模式，帮助其做出符合项目惯例的决策。

## 项目亮点

与市面上的单一代理增强工具相比，ECC 具备以下差异化优势：

- **综合性的“操作系统”定位**：大多数工具只关注单点能力（如仅记忆或仅安全），ECC 则将技能、直觉、记忆、安全和研究机制整合为完整系统，提供了集成化的开发体验。
- **广泛的多工具支持**：无需为每种 AI 编程工具单独寻找插件，ECC 通过适配层连接主流代理，一套配置多处生效，显著降低了工具链的管理成本。
- **研究驱动而非盲目生成**：ECC 内建的 pre-action research 机制，使得代理的每次修改都建立在理解代码库的基础上，比仅靠大模型记忆的代理更可靠。
- **社区活跃度高**：项目在 GitHub 上拥有超过 24 万 Star，日增过千，活跃的社区保证了持续的功能更新和生态扩展。
