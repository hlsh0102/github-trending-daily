## 项目概述

DeerFlow 是一个开源的长跨度超级智能体框架，由字节跳动开发并发布。项目全称为 **D**eep **E**xploration and **E**fficient **R**esearch **Flow**（深度探索与高效研究流），旨在构建一个能够自动执行复杂、耗时长（从几分钟到几小时）的多步骤任务的智能体系统。

DeerFlow 的核心定位是“SuperAgent harness”，即超级智能体控制器。它通过编排多个子智能体（sub-agents）、管理长期记忆（memory）、提供安全的沙箱执行环境（sandboxes），并结合可扩展的技能库（skills）和工具调用能力，让开发者能够构建出能够自主进行研究、编写代码、进行内容创作等复杂工作的智能体应用。

该项目的主要目标用户包括：AI 应用开发者、研究人员、自动化工程师，以及任何希望利用大语言模型（LLM）处理长时、多步骤任务的团队或个人。

值得注意的是，DeerFlow 2.0 是一次从零开始的重写，与 1.x 版本不共享任何代码。当前活跃开发已全面迁移到 2.0 版本。

## 核心功能

- **多智能体编排**：自动创建和管理多个子智能体，支持任务分解与并行/串行协作，能够处理需要多步推理和工具调用的复杂工作流。
- **沙箱执行环境**：提供安全、隔离的代码和命令执行环境，让智能体能够安全地运行生成的代码、操作文件系统，而不会影响宿主系统。
- **持久化记忆系统**：支持会话间记忆存储与检索，允许智能体在长时间运行的任务中保持上下文，并能够回顾和利用历史经验。
- **可扩展技能库**：内置一组常用工具和技能（如 web 搜索、文件操作、API 调用），并允许开发者通过标准接口轻松添加自定义技能。
- **消息网关（Message Gateway）**：统一的消息通信层，负责在智能体、子智能体、工具和外部系统之间传递事件和指令，支持异步处理。

## 技术架构

DeerFlow 采用高度模块化的架构设计，核心组件包括：

1. **Orchestrator（编排器）**：任务分解与执行控制的核心模块，负责接收用户请求，将复杂任务拆解为子任务，并协调子智能体的执行顺序和依赖关系。
2. **Sub-agent Manager（子智能体管理器）**：动态创建、监控和销毁子智能体实例，支持按需扩展。每个子智能体可以拥有独立的大语言模型实例、工具集和记忆空间。
3. **Memory Store（记忆存储层）**：基于向量数据库或键值存储实现，支持短期工作记忆和长期持久记忆，具备语义检索和重要性排序能力。
4. **Sandbox Manager（沙箱管理器）**：基于容器化技术（如 Docker）或轻量级虚拟化，提供标准化的执行环境 API。每个沙箱实例拥有独立的文件系统和网络访问控制。
5. **Skill Registry（技能注册表）**：插件化技能管理，支持热加载和版本控制。技能可定义为 Python 函数、API 封装或完整的服务。
6. **Message Gateway（消息网关）**：基于发布/订阅模式的事件流系统，负责组件间异步通信，支持消息路由、队列和错误重试。

技术栈方面，DeerFlow 使用 Python 作为主要开发语言，充分利用 asyncio 实现异步并发执行。项目没有绑定特定的大语言模型提供商，通过统一的 LLM 接口抽象层支持多种模型后端。

## 安装与使用

**前提条件**：
- Python 3.10 或更高版本
- 可选：Docker（用于沙箱功能）
- 有效的大语言模型 API 密钥（如 OpenAI、Claude 等）

**基本安装步骤**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
   ```

2. 安装核心依赖：
   ```bash
   pip install -e .
   ```

3. 配置环境变量（创建 `.env` 文件）：
   ```
   LLM_API_KEY=your_api_key_here
   LLM_MODEL=gpt-4o
   ```

4. 启动服务（可选沙箱模式需先启动 Docker）：
   ```bash
   deer-flow run
   ```

**最小可用示例**：

创建一个 Python 脚本 `simple_task.py`：

```python
from deer_flow import SuperAgent

async def main():
    agent = SuperAgent.create(
        instruction="搜索最新的人工智能新闻，然后总结成三句话。"
    )
    result = await agent.run()
    print(result.output)

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())
```

更复杂的使用可以参考项目提供的示例目录 `examples/`，其中包含了研究型任务、代码生成任务和内容创作任务的完整案例。

## 适用场景

- **自动化研究**：自动搜索、阅读和总结多个信息源，生成结构化研究报告，适用于市场调研、技术跟踪、学术文献梳理等场景。
- **复杂代码生成**：根据需求描述自动分析、设计架构、编写代码、编写测试，并在沙箱中验证运行结果，适用于快速原型开发和代码重构。
- **内容创作工作流**：从选题研究、大纲生成、内容撰写到最终润色的全流程自动化，适用于博客、技术文档和营销文案的批量生产。
- **智能运维助手**：通过工具调用和记忆系统，自动诊断系统问题、执行修复脚本、记录变更历史，适用于 IT 运维团队的自助化助手。

## 项目亮点

- **企业级开源**：由字节跳动开发并维护，拥有活跃的社区和持续迭代保障，代码质量与稳定性经过内部验证。
- **灵活的可扩展性**：子智能体、工具、记忆策略和沙箱环境均为可插拔设计，开发者可以替换任意组件以适应特定业务需求。
- **安全第一**：内置沙箱机制隔离代码执行风险，相比无隔离的智能体方案更适合生产环境。
- **长任务友好**：通过记忆系统和异步编排架构，原生支持耗时从数分钟到数小时的长周期任务，解决了传统智能体任务中断后无法恢复的问题。
