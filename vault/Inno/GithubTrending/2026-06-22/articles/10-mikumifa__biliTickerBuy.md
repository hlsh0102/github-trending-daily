## 项目概述

biliTickerBuy 是一款开源免费的 B 站会员购辅助工具，旨在帮助用户更高效地完成 B 站会员购平台上的商品抢购与购票流程。该项目由个人开发者维护，使用 Python 语言编写，面向需要购买 B 站会员购限定商品（如演唱会门票、漫展门票、手办等）的用户群体。在热门商品开售时，B 站官方页面通常面临并发请求激增、界面加载缓慢等问题，手动操作往往难以抢到心仪商品。biliTickerBuy 通过自动化脚本简化选购、提交订单和支付等环节，显著提升抢购成功率。

## 核心功能

- **自动抢购**：支持定时监控商品开售状态，在指定时间点自动触发购买流程，避免人工刷新延迟。
- **多任务并发**：允许同时监控多个商品链接，并行处理不同场次的抢购任务，提升效率。
- **智能下单**：自动填充预设的收货地址、票种、数量等信息，减少手动填写步骤。
- **验证码处理**：集成简单的验证码识别或人工介入机制，应对常见的滑动验证或点击验证。
- **日志与通知**：记录抢购过程的详细日志，并支持通过自定义 Webhook（如 Server酱、PushPlus）发送成功或失败通知。
- **配置灵活**：通过 JSON 或 YAML 配置文件设置账号 Cookie、商品 ID、目标场次等参数，无需修改代码。

## 技术架构

项目基于 Python 3.8+ 开发，主要依赖以下技术组件：

- **网络请求**：使用 `requests` 和 `httpx` 库处理 HTTP 请求，模拟浏览器行为，支持 Session 持久化。
- **异步支持**：借助 `asyncio` 和 `aiohttp` 实现异步并发请求，减少等待时间。
- **定时任务**：利用 `schedule` 或 `APScheduler` 库实现精确到秒级的定时触发。
- **Cookie 管理**：通过读取本地配置文件获取 B 站用户 Cookie，支持多账号切换。
- **验证码识别**：内置简单的 OCR 识别模块（基于 `ddddocr`），或通过开放接口请求人工打码服务。

架构设计上采用模块化分层：
- **核心层**：封装了 B 站会员购 API 的调用逻辑，包括商品查询、订单提交、支付状态轮询等接口。
- **业务层**：定义了抢购流程（如预热、抢购、重试），并为不同商品类型（门票、实物）提供差异化处理。
- **配置层**：独立管理用户设置，支持热加载与参数校验。
- **用户接口层**：提供命令行（CLI）和简单图形化界面（GUI）两种操作方式，降低使用门槛。

## 安装与使用

### 安装步骤

1. **环境准备**：确保已安装 Python 3.8 或更高版本，并配置好 pip。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/mikumifa/biliTickerBuy.git
   cd biliTickerBuy
   ```
3. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
4. **使用说明**：详细指南请参考项目中的 `docs/installation.md` 文档，或访问飞书在线文档。

### 最小可用示例

1. 从浏览器开发者工具中复制 B 站用户 Cookie（登录会员购后获取）。
2. 将 Cookie 填入项目根目录下的 `config.json` 中相应字段。
3. 运行主程序：
   ```bash
   python main.py
   ```
4. 按照提示输入目标商品 ID（可从商品页 URL 获取）和抢购场次。
5. 程序将自动监测开售时间，并在开售后尝试点击购买。成功下单后会在终端显示订单号。

## 适用场景

1. **热门演出票务秒杀**：如 B 站会员购独家发售的演唱会、漫展、Livehouse 门票，抢票难度极高，biliTickerBuy 可助力准时抢购。
2. **限量手办/周边抢购**：对首发限定手办、联名周边等商品，用户可提前设定脚本，免除手动反复刷新。
3. **多账户批量操作**：适合代购或团队用户，同时管理多个账号进行抽签或限购商品的购买。
4. **个人参与测试与学习**：作为开源项目，其代码结构可供开发者学习自动化脚本编写、API 调用与异常处理。
