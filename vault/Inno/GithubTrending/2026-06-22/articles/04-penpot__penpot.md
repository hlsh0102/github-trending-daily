## 项目概述

Penpot 是一款开源的设计工具，专为设计与开发协作而打造。它解决了传统设计工具中设计师与开发者之间工作流割裂的问题——设计师使用昂贵的商业软件制作原型，开发者则需要将设计稿手动转换为代码，过程繁琐且容易出错。Penpot 的目标用户包括 UI/UX 设计师、前端开发者、产品经理以及任何需要快速创建和分享界面原型的团队成员。项目采用 Mozilla 公共许可证 (MPL-2.0)，这意味着任何人都可以自由使用、修改和分发，无需担心许可证费用或供应商锁定。

## 核心功能

- **基于 Web 的实时协作**：无需安装客户端，通过浏览器即可访问。支持多人同时编辑同一个设计文件，所有更改实时同步，团队成员可以即时看到彼此的操作。
- **矢量设计与原型制作**：提供完整的矢量图形编辑工具，包括路径、布尔运算、蒙版等。同时支持创建交互式原型，可定义页面间的链接、手势和过渡动画。
- **开放格式与代码集成**：设计文件以 SVG 为基础格式，支持直接导出为标准 SVG 和 CSS 代码。设计师完成设计后，开发者可直接从 Penpot 中复制 CSS 属性或导出 SVG 元素，无需额外转换工具。
- **组件与样式系统**：支持创建可复用的设计组件（类似 Figma 的组件），以及全局颜色、排版和阴影样式。更改组件或样式后，所有实例会自动更新。
- **插件系统与 API**：提供开放的插件 API，允许社区开发自定义插件以扩展功能。同时支持通过 REST API 与 CI/CD 流程或其他工具集成。
- **自托管部署**：支持在自有服务器上部署 Penpot，数据完全由用户掌控，适合对数据安全有严格要求的企业或组织。

## 技术架构

Penpot 的技术栈以 Clojure 和 ClojureScript 为核心。后端使用 Clojure 构建，基于 Ring 和 Compojure 等 Clojure Web 框架，采用函数式编程范式，保证了代码的简洁性和可维护性。前端则使用 ClojureScript，结合 React 库（通过 Reagent 或类似封装），实现了高性能的用户界面和响应式交互。

数据库方面，Penpot 使用 PostgreSQL 存储设计数据和项目元信息，同时使用 Redis 处理会话管理和实时协作消息。实时协作功能基于 WebSocket 实现，通过 CRDT（无冲突复制数据类型）算法处理多用户同时编辑的冲突问题，确保所有用户看到一致的设计状态。

设计文件以 JSON 和 SVG 混合格式存储，既保留了矢量图形的原生结构，又支持自定义元数据。这种设计使得 Penpot 设计文件可以直接与版本控制系统（如 Git）进行 diff 对比，这是许多商业设计工具不具备的特性。

## 安装与使用

Penpot 提供多种安装方式：

**Docker（推荐）**：
```bash
git clone https://github.com/penpot/penpot.git
cd penpot
docker-compose up -d
```
启动后访问 `http://localhost:9001` 即可进入 Penpot 工作台。

**手动部署**：需要 Java 运行时（JDK 11+）、Node.js、PostgreSQL 和 Redis。具体步骤请参考项目的 `README.md` 或官方文档。

**最小使用示例**：
1. 打开浏览器访问 Penpot 实例，注册或登录账号。
2. 创建一个新项目，添加一个画板（Artboard）。
3. 使用矩形工具绘制一个卡片，添加文本和图像。
4. 创建组件：选中卡片，右键选择“创建组件”。
5. 将组件复制到其他画板或页面，修改任意实例，观察其他实例是否自动同步。
6. 导出卡片为 SVG：右键点击卡片，选择“导出”>“SVG”。

## 适用场景

- **设计团队与开发团队协同工作**：设计师在 Penpot 中完成界面设计后，开发者可直接复制 CSS 属性或下载 SVG，无需第三方工具，大幅减少沟通成本和错误率。
- **开源项目或社区驱动的设计工作**：项目可托管 Penpot 实例，允许外部贡献者参与设计讨论和原型制作。设计文件公开可查，任何人都可 fork 和修改。
- **教育机构或培训课程**：Penpot 免费且无需许可证，适合学校或培训课程中教授 UI/UX 设计。学生可在任何设备上访问，无需安装软件。
- **对数据隐私有严格要求的组织**：企业可自托管 Penpot，设计数据存储在自己的服务器上，不经过第三方云服务，满足 GDPR 或内部安全规范。

## 项目亮点

- **完全开源且免费**：与 Figma、Sketch 等商业工具不同，Penpot 的源代码完全公开，无功能限制、无用户数量限制，也不存在供应商锁定风险。
- **设计到代码的流畅转换**：基于标准 Web 技术（SVG、CSS），设计元素可以直接转为可用的代码片段，这是许多专业设计工具需要插件才能实现的功能。
- **自托管能力**：大多数 SaaS 设计工具不支持自部署，而 Penpot 提供了完整的 Docker 部署方案，让用户可以完全控制自己的数据。
- **活跃的社区与开源生态**：项目在 GitHub 上拥有超过 5 万星标，社区论坛活跃，提供了大量插件、主题和教程。同时，Penpot 被认证为“数字公共产品”，符合开源软件的国际标准。
- **跨平台与低门槛**：任何拥有现代浏览器的设备（包括 Linux、ChromeOS）都可使用，无需特定操作系统。对于无法安装商业软件的团队（如公共部门的电脑），Penpot 是一个理想的替代方案。
