## 项目概述

PM Skills Marketplace 是一个面向产品经理的 AI 技能市场，提供了 100 多种智能体技能、命令和插件，覆盖从产品发现、战略规划、执行、发布到增长的全流程。该项目旨在解决通用 AI 工具缺乏产品管理领域专业知识的问题，让 AI 助手能够像资深产品经理一样思考和工作。

目标用户包括产品经理、产品负责人、创业者、增长团队以及任何需要做出产品决策的人员。通过将行业最佳实践编码为可直接调用的技能，项目帮助用户在日常工作中应用 Teresa Torres、Marty Cagan、Alberto Savoia 等产品管理大师的方法论，从而做出更好的产品决策，而不仅仅是生成更快的文档。

目前项目包含 68 项独立技能和 42 个链式工作流，分布在 9 个插件中，专为 Claude Code 和 Cowork 设计，同时兼容其他 AI 助手。

## 核心功能

- **产品发现技能**：提供 `/discover` 等命令，引导用户完成用户研究、问题定义和机会评估，确保产品方向建立在真实用户需求基础上
- **战略规划能力**：通过 `/strategy` 命令，帮助用户制定产品战略、绘制路线图、进行机会评估和假设映射
- **文档自动化**：`/write-prd` 命令能根据简单描述生成结构完整的产品需求文档，包含背景、目标、范围、验收标准等关键要素
- **发布管理**：`/plan-launch` 命令提供从发布检查清单、沟通计划到风险缓解的完整发布流程
- **指标驱动决策**：`/north-star` 命令帮助定义北极星指标、关键结果和产品健康仪表盘，确保团队专注于正确的度量标准
- **链式工作流**：42 个预构建的工作流将多个技能串联，实现从想法到代码交付的端到端自动化流程

## 技术架构

PM Skills Marketplace 采用模块化插件架构设计，每个技能独立封装，可单独加载或组合使用。技术实现基于以下原则：

- **技能作为基本单元**：每个技能包含领域知识、分析框架和引导式工作流，部分技能作为多个命令共享的基础组件
- **上下文感知加载**：技能根据当前对话上下文自动加载，确保 AI 助手在合适的时间拥有合适的知识
- **插件化扩展**：9 个专业插件按产品管理领域划分，用户可根据项目需求选择性启用
- **链式编排**：通过预定义的工作流将多个技能串联，形成完整的端到端产品管理流程
- **兼容性设计**：虽然为 Claude Code 和 Cowork 优化，但技能定义遵循通用标准，可适配其他 AI 助手

这种架构使项目既保持了单个技能的专注性和可复用性，又通过工作流实现了复杂的多步骤产品管理任务。

## 安装与使用

PM Skills Marketplace 作为开源项目，使用方式简单直接：

1. 克隆或下载项目仓库：
```bash
git clone https://github.com/phuryn/pm-skills.git
```

2. 根据使用的 AI 助手（如 Claude Code、Cowork）配置技能加载路径

3. 在对话中直接使用预设命令开始工作

最小可用示例：

- 有新想法时，输入 `/discover` 启动需求发现流程
- 需要战略规划时，输入 `/strategy` 获得结构化分析引导
- 撰写 PRD 时，输入 `/write-prd` 让 AI 辅助生成完整文档
- 准备发布时，输入 `/plan-launch` 获得完整的发布计划框架
- 定义关键指标时，输入 `/north-star` 建立产品健康监控体系

具体安装步骤和配置方式可能因使用的 AI 助手版本而异，建议参考项目 README 中的详细指引。

## 适用场景

- **新产品构思阶段**：当团队有一个模糊的想法时，使用 `/discover` 技能进行系统化的用户研究和需求验证，避免在错误的方向上投入资源
- **冲刺规划与执行**：在每轮冲刺规划中，利用战略和优先级排序技能快速评估任务价值，确保团队始终在处理最有影响力的事项
- **产品发布管理**：从发布计划制定、沟通协调到上线后监控，`/plan-launch` 插件提供完整的管理框架，减少发布故障
- **产品指标体系建设**：为新产品或现有产品建立科学的指标体系，使用 `/north-star` 技能确定北极星指标和关键结果

## 项目亮点

- **专业领域深度**：与通用 AI 工具不同，项目将经过验证的产品管理方法论编码为可直接执行的技能，让 AI 真正理解产品管理的核心概念和工作流程
- **即装即用**：无需漫长配置，通过简单的命令就能调用专业的产品管理能力，降低使用门槛
- **可扩展的模块化设计**：技能和插件作为独立模块，用户可以按需加载，也可以基于框架开发自定义技能
- **端到端覆盖**：从市场发现、战略定位、产品规划、开发执行到发布增长，一个项目覆盖产品管理的完整生命周期
- **开源社区驱动**：项目采用 MIT 许可证，鼓励社区贡献和定制，这在 GitHub 上获得了超过 12,900 颗星标，表明其价值和影响力
