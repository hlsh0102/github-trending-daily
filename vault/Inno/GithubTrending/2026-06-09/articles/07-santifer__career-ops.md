## 项目概述

Career-Ops 是一个基于 AI 的智能求职系统，由开发者 santifer 在 Claude Code 之上构建。该项目源于作者在求职过程中的亲身痛点——花费数月时间以传统方式投递简历，但效果甚微。与许多求职者一样，他意识到公司正在使用 AI 来筛选候选人，而求职者却缺乏对等的 AI 工具来主动选择和评估公司。Career-Ops 的核心理念就是让求职者“重新获得主动权”，借助 AI 来高效筛选职位、定制申请材料，而不是盲目地海投简历。该项目开源并托管在 GitHub 上，主要面向技术领域的求职者、开发者以及任何希望通过智能化手段提升求职效率的用户。

## 核心功能

- **14 种技能模式**：内置多达 14 种不同的技能模式，覆盖软件工程、数据科学、DevOps、产品管理等常见技术岗位，用户可根据自身背景快速切换和匹配。
- **Go 语言仪表盘**：使用 Go 语言编写的仪表盘，提供直观的求职进度可视化。用户可以清晰地看到已投递的职位、面试邀请、各阶段转换率等关键指标。
- **PDF 简历生成**：支持直接将求职材料导出为 PDF 格式，方便投递到各类招聘平台或直接发送给招聘方。输出的简历格式专业且可定制。
- **批量处理能力**：能够同时对多个职位进行申请材料生成和筛选，大幅减少重复性劳动。用户只需提供一份基础简历即可批量定制不同公司的求职信。
- **AI 驱动的职位匹配**：自动解析职位描述，基于用户的技能和经验进行智能匹配，并给出匹配度评分，帮助用户优先申请最合适的机会。
- **多语言支持**：README 提供了英语、西班牙语、葡萄牙语、韩语、日语、简体中文、繁体中文、乌克兰语和俄语共 9 种语言版本，降低了全球用户的使用门槛。

## 技术架构

Career-Ops 的核心架构建立在 **Claude Code** 之上，借助其强大的代码生成和推理能力来驱动求职相关的自动化任务。项目的主要编程语言是 **JavaScript**，同时包含 **Go** 编写的独立仪表盘模块。整体设计遵循“智能体（Agent）”模式——系统被拆解为多个小型 AI 智能体，分别负责职位搜索、简历优化、求职信撰写、进度追踪等不同环节，通过管道化的方式协同工作。

数据流向大致为：用户输入个人简历和求职偏好 → AI 智能体基于 Claude Code 引擎解析职位信息 → 生成量身定制的申请材料 → 通过 Go 仪表盘追踪全过程状态。项目的架构特点是高内聚低耦合、易于扩展，用户可以很轻松地添加新的技能模式或自定义输出格式。此外，由于是本地运行的设计，用户的简历数据和求职记录都保留在自己的机器上，无需上传到第三方服务器，在隐私保护方面具有天然优势。

## 安装与使用

前提条件：需要拥有一个可用的 **Claude Code** 客户端（支持 Anthropic 的 API），并安装 Node.js（推荐 v18 及以上）和 Go（用于仪表盘）。

基本安装步骤如下：

1. 克隆仓库：
   ```bash
   git clone https://github.com/santifer/career-ops.git
   cd career-ops
   ```

2. 安装前端依赖：
   ```bash
   npm install
   ```

3. 构建 Go 仪表盘（可选，如果不使用仪表盘可跳过）：
   ```bash
   cd dashboard && go build -o career-dashboard
   ```

4. 配置环境变量，在项目根目录创建 `.env` 文件，填入你的 Anthropic API Key：
   ```
   ANTHROPIC_API_KEY=你的密钥
   ```

5. 启动系统：
   ```bash
   npm start
   ```

最小可用示例：将你的个人简历保存为 `resume.md` 放在项目 `inputs/` 目录下，然后在终端运行 `career-ops search --skills "React,Node.js,AWS"`，系统会自动从配置的招聘源拉取职位，并使用 AI 分析匹配度，输出推荐列表。之后运行 `career-ops generate --job "job-id"` 即可自动生成一份定制化的求职信与简历组合，输出为 PDF。

## 适用场景

- **技术求职者主动筛选公司**：你不必再被动等待猎头或 HR 联系。Career-Ops 可以每天自动扫描海量职位，根据你的技能和薪资期望给出排名，让你把精力集中在最有价值的 offer 上。
- **批量求职申请**：当你需要快速申请多家公司时，传统的手工定制材料变得不现实。该系统可以批量生成差异化的求职信和简历，确保每份申请都有针对性，但只需一次配置。
- **求职进度管理**：借助 Go 仪表盘，你可以把整个求职过程变成一个透明的 Pipeline。从投递到面试，每一步的耗时和转化率一目了然，便于及时调整策略。
- **多技能背景的求职者**：如果你同时具备前后端、DevOps 或数据工程等多种能力，可以在 14 种技能模式间灵活切换，确保针对不同岗位展示最相关的能力组合。

## 项目亮点

与市场上现有的求职辅助工具（如 Jobscan、Simplify 或各种 ChatGPT 简历插件）相比，Career-Ops 的核心差异化在于：

- **本地运行，隐私优先**：所有 AI 推理和数据存储都在用户本地完成，不依赖第三方云服务，简历和求职信中的敏感信息不会被泄露。
- **完整的工作流而非零散功能**：它不是单一功能的小工具，而是覆盖“搜索→分析→生成→跟踪”全链路的系统，用户无需在多个工具间切换。
- **基于多智能体（Multi-agent）架构**：每个环节由专门 AI 代理负责，比传统的单个 Prompt 生成更精准。智能体之间的协同设计使其在面对复杂多变的职位描述时，依然能产出高质量结果。
- **开源且高度可定制**：开发者可以 Fork 后自由修改技能模式、投递模板、仪表盘指标等一切环节。项目的 MIT 许可进一步降低了使用和二次开发的门槛。
- **活跃的开源社区驱动**：项目在 GitHub 上收获超过 5 万 Star，并多次被 Trendshift、Product Hunt 等平台推荐，持续的社区贡献保证了功能的快速迭代。
