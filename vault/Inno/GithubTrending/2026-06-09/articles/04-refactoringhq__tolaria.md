## 项目概述

Tolaria 是一款面向 macOS、Windows 和 Linux 的桌面应用程序，专门用于管理 **Markdown 知识库**。它致力于解决知识工作者面临的核心难题：如何在多个设备和应用程序之间，以可移植、可版本控制的方式存储、组织和检索大量笔记与文档。目标用户包括个人知识管理者（进行第二大脑或个人知识管理）、需要为 AI 提供上下文的企业文档团队，以及希望存储智能助手记忆和操作流程的开发者。

项目由 Refactoring 创始人 Luca Ronin 个人开发，他本人拥有一个包含超过 10,000 条笔记的工作空间，这些笔记涵盖日常工作、个人日记和第二大脑系统。Tolaria 正是他用来“运转人生”的核心工具。

## 核心功能

- **文件优先架构**：所有笔记以纯 Markdown 文件形式存储，不依赖任何专有格式。用户可以使用任何文本编辑器直接编辑文件，无需导出步骤，数据完全归用户所有。
- **Git 优先版本控制**：每个知识库（Vault）本身就是一个 Git 仓库。这带来了天然的版本历史、分支管理、协作和备份能力，适合需要长期维护和团队协作的场景。
- **跨平台桌面应用**：提供原生桌面体验，支持 macOS、Windows 和 Linux 三大操作系统，确保在不同平台上拥有一致的用户界面和交互逻辑。
- **工作流管理系统**：内置收件箱工作流和资源保存机制，支持快速捕捉灵感、网页资源，并按照用户自定义流程进行组织。
- **知识库可视化与导航**：提供直观的笔记图谱和交互式视图，帮助用户理解笔记之间的关联，快速定位和发现信息。

## 技术架构

Tolaria 采用 TypeScript 作为主要开发语言，基于现代桌面应用技术栈构建。项目的核心设计遵循两个关键原则：

1. **无锁数据层**：由于文件以纯文本 Markdown 存储，用户完全避免了厂商锁定风险。即使停止使用 Tolaria，所有笔记仍然可以直接访问和编辑。
2. **去中心化存储**：每个知识库都是一个独立的 Git 仓库，这意味着数据可以托管在任何 Git 服务器（如 GitHub、GitLab、自建 GitLab）上，不依赖特定云服务。

项目架构上采用模块化设计，将界面展示、文件操作、版本控制逻辑分离。界面层负责提供流畅的交互体验；文件操作层负责 Markdown 文件的读取、写入和解析；Git 集成层则封装了常见的版本控制操作，如提交、分支切换、历史查看等。这种分层设计使得 Tolaria 能够保持轻量、可扩展，同时易于维护和贡献。

## 安装与使用

Tolaria 提供适用于各操作系统的安装包，用户可以从 GitHub Releases 页面下载对应平台的版本：

- **macOS**：下载 `.dmg` 文件并拖入 Applications 文件夹
- **Windows**：下载 `.exe` 或 `.msi` 安装程序并运行
- **Linux**：下载 `.AppImage` 或 `.deb` 文件

安装完成后，首次启动会引导用户创建一个新的知识库或打开已有知识库。一个最小可用的使用示例如下：

1. 创建一个新的文件夹（例如 `my-vault`），并在其中初始化一个 Git 仓库（可选，但推荐）。
2. 在 Tolaria 中打开该文件夹，即可开始创建和编辑 Markdown 笔记。
3. 使用内置的收件箱功能快速捕捉想法。
4. 所有修改会实时保存在本地文件中，并可通过 Git 进行版本管理。

开发者也可以克隆项目仓库本地构建：
```bash
git clone https://github.com/refactoringhq/tolaria.git
cd toilaria
npm install
npm run dev
```

## 适用场景

- **个人知识管理（第二大脑）**：适合希望构建个人知识体系、长期积累笔记和思考的独立用户。文件优先和 Git 版本控制确保笔记的长期可访问性和可追溯性。
- **企业文档与 AI 上下文管理**：团队可以将公司文档存储在 Tolaria 中，利用 Git 的协作能力进行编辑和审核。Markdown 格式也方便作为 AI 代理的上下文输入，实现更智能的文档驱动。
- **智能助手记忆与程序存储**：开发者和操作者可以使用 Tolaria 存储 AI 助手的记忆、运行策略和流程文档，使得助手行为可追溯、可修改。

## 项目亮点

与大多数现代笔记应用（如 Notion、Obsidian、Roam Research）相比，Tolaria 的核心差异化优势在于：

- **彻底的文件优先哲学**：不仅支持导出，而且使用天生就是纯文本文件。这意味着用户无需担心数据迁移或格式锁定，任何支持 Markdown 的编辑器都可以使用这些笔记。
- **原生 Git 集成**：不是简单地在应用内嵌入 Git，而是将 Git 作为知识库的核心组织单位。这带来了极致的版本控制、分支管理和协作能力，这在个人知识管理工具中非常罕见。
- **轻量且专注**：聚焦于知识管理核心需求，避免功能膨胀。没有数据库依赖、没有复杂的权限系统，保持了工具的纯粹性和高性能。
- **开放许可与社区驱动**：采用 AGPL-3.0 许可，鼓励社区贡献和二次开发。项目的设计决策公开透明，用户不仅是使用者，也是共建者。
