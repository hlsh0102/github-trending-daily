## 项目概述

Superpowers 是一套面向编码代理（coding agent）的完整软件开发方法论，它通过一组可组合的技能（skills）和精心设计的初始指令，让 AI 代理从“会写代码”进化到“会做软件工程”。该项目解决了当前 AI 编码工具普遍存在的一个核心问题——代理拿到需求后立即跳入代码实现，缺乏需求澄清、方案设计、分步实施等关键工程环节，导致产出质量不稳定、返工频繁。

Superpowers 的目标用户是重度使用 AI 编程助手的开发者与团队，特别是那些使用 Claude Code、Codex、Cursor、Gemini CLI 等主流 Agent 工具，并希望将 AI 从“结对程序员”提升为“独立工程师”的用户。该项目由 obra 发起并维护，目前已在 GitHub 上获得超过 28 万 Star，是 AI 辅助开发领域最受关注的开源项目之一。

## 核心功能

- **启动即介入**：当代理发现你在构建项目时，不会立即写代码，而是先退一步，询问你真正要解决的问题
- **规格说明提炼**：从对话中逐步提炼出需求规格（spec），并将内容分块展示，确保你能完整阅读和确认
- **实现计划生成**：在规格确认后，代理会生成结构化的实施方案，明确任务拆解和执行顺序
- **可组合技能库**：内置一组互相组合、按需调用的技能，覆盖需求分析、编码、测试、修复等全流程
- **跨工具适配**：支持 Claude Code、Antigravity、Codex App/CLI、Cursor、Gemini CLI、GitHub Copilot CLI 等十余种主流编码代理环境
- **方法论内嵌**：将成熟的软件工程实践（如先设计后编码、分步验证）编码为代理的行为准则

## 技术架构

Superpowers 的核心架构可以概括为“指令 + 技能”双层驱动模式。

第一层是**初始指令层（bootstrap instructions）**。项目提供一系列精心编写的系统提示词，当代理启动时会加载这些指令，从而改变其默认行为模式——从被动响应转变为主动引导。这一层类似于为代理注入了一套“工作方法论”，确保它在处理任何任务时都遵循既定的工程流程。

第二层是**技能层（skills）**。每个技能是一个独立、可复用的功能模块，封装了特定任务的处理逻辑。技能之间可以相互组合，形成复杂的工作流。例如，“需求澄清”技能可以与“方案设计”技能串联使用，前者产出规格说明，后者基于规格生成实施计划。这种模块化设计使技能可以像乐高积木一样自由拼装，适应不同项目的特定需求。

项目整体使用 Shell 作为主要脚本语言，用于管理技能的加载、更新和配置。在兼容性方面，Superpowers 通过适配层对接不同的编码代理平台，每个平台（如 Claude Code、Codex、Cursor）都有对应的安装与引导机制，确保方法论可以无缝嵌入各类主流工具链。

架构设计上的一个关键决策是**透明性与可控性**。整个流程中，代理所有的推理步骤和生成产物（规格、计划）都会明确呈现给用户，用户可以随时介入修正方向。这意味着 Superpowers 并非将决策权完全交给 AI，而是强调人机协作——AI 负责结构化和执行，人类负责方向与质量把关。

## 安装与使用

Superpowers 的安装因编码代理平台而异，一般流程如下（以 Claude Code 为例）：

1. 将项目克隆或下载到本地，建议放在独立目录（如 `~/.superpowers`）
2. 在 Claude Code 的配置文件中引入 Superpowers 的初始指令（通常为 `.claude/commands` 下的引导文件）
3. 启动 Claude Code 并新开会话，验证代理是否已加载 Superpowers 技能集
4. 如果项目有更新，运行项目提供的更新脚本即可拉取最新技能与指令

对于其他平台（如 Cursor、Gemini CLI），README 中均提供了对应的安装步骤，整体思路相近，具体路径和命令略有差异。

**最小可用示例**：安装完成后，在一个空目录中启动你的编码代理，输入任务描述。此时代理不会直接编码，而会先引导你进行需求澄清，逐步确认规格，然后生成实现计划并在你的批准后执行。整个流程可从代理的响应中明显观察出来——第一步输出是提问，而非代码。

## 适用场景

- **复杂功能开发**：当需求本身模糊或多变时，Superpowers 引导先写规格再动手，显著减少方向性返工
- **代码库维护与重构**：代理会先分析现有代码结构，制定重构策略，再逐步执行，避免破坏性修改
- **多步骤工程任务**：涉及环境配置、依赖管理、测试验证等多个环节的任务，Superpowers 能规划有序的执行序列
- **团队 AI 工作流规范化**：团队可统一使用 Superpowers 方法论，使 AI 辅助开发流程保持一致，便于审查与协作

## 项目亮点

- **回归工程本质**：在多数 AI 工具追求“更快写代码”的潮流中，Superpowers 反其道而行，强调需求澄清、方案设计、分步实施，回归经典软件工程的核心价值
- **平台无关设计**：并非绑定某个特定编辑器或工具链，而是通过技能组合适配所有主流编码代理，具有极好的可移植性
- **开源与社区驱动**：作为 MIT 协议的开源项目，Superpowers 吸收了来自全球开发者的贡献，技能库持续演进，已有庞大的用户社区
- **透明的人机协作**：不同于自动执行一切任务的“自动驾驶”模式，Superpowers 在关键节点始终保留用户的决策权，提升最终结果的可控性与可靠度
- **完整的体系化思维**：项目提供的不只是几个提示词，而是一套从启动、规格到实施、验证的完整方法论，直接改变了编码代理的工作模式
