## 项目概述

diagram-design 是一个面向 AI 编程助手（如 Claude Code、Codex、Pi 等）的图表设计技能包，提供 38 种编辑级（editorial-grade）图表类型。该项目解决的核心问题是：AI 生成图表时常见的“千篇一律的圆角盒子、默认阴影、Mermaid 风格”的低质量视觉输出，这些图表往往难以直接用于报告、文档或客户演示。

项目的目标用户是需要在工作流中频繁生成图表的开发者、技术写作者、产品经理和设计师。通过让 AI 使用精心设计的 HTML + SVG 模板，用户可以在几秒内获得具有出版级排版和视觉一致性的图表，无需在 Figma 等工具中手动调整。

## 核心功能

- **38 种编辑器级图表类型**：覆盖架构图、流程图、循环图、Sankey 图、鱼骨图、Wardley 地图、看板、用户旅程图、部署图、依赖关系图、UML 类图、故事地图和数据库模式图等常见场景。
- **语义化模式设计**：将行为与布局分离，通过语义模式（如队列、策略追踪、信任边界）复用现有图表类型，无需为每个新概念创建新的类型。
- **自包含 HTML + SVG**：每张图表都是单文件自包含的输出，无需外部依赖或运行时环境即可直接嵌入任何 HTML 页面。
- **静态输出为主，动效可选**：默认输出静态 HTML，适合文档和打印；在需要按序讲解时，可以开启可访问的动效（accessible motion），且不会牺牲可读性。
- **格式转换与重绘能力**：能读取 draw.io 或 Mermaid 的源文件，并按指定格式、尺寸和细节级别重新绘制为统一风格的图表。
- **零美学妥协**：无阴影、无通用的圆角盒子、无需手动挑选配色。每个模板都经过设计考量，色彩搭配和排版直接可用，无需额外设计工具。

## 技术架构

该技能包基于以下设计思路构建：

- **类型约束 + 布局语法**：每种图表类型对应一套严格的布局语法，定义了节点、连线和标签的排布规则。SVG 结构通过内部视觉语法（例如，虚线与实线的语义区分）进行组织，例如共享内存中枢的回写操作使用虚线表示。
- **语义层与表现层分离**：这是架构的核心创新。用户传入的行为模式（如“队列”“信任边界”）被映射到最接近的已有图表类型，而不要求新增类型。这种抽象保持了类型数量的有限，同时覆盖了广阔的建模需求。
- **版本演进的插件化机制**：项目通过持续的增量更新（例如 2.0 新增 Loop 模式，2.3 引入语义系统模式和可选动效，2.5.10 增补十个布局语法）展示了模块化的内部扩展机制，新图表类型可以以较低耦合度加入。
- **可访问性支持**：动效支持 prefers-reduced-motion 等可访问性标准，确保静态输出始终作为默认值，而对动效敏感的用户可以安全浏览。

## 安装与使用

diagram-design 不是传统意义上的 npm 包，而是以 Claude Code / Codex / Pi 等 AI 助手的“技能”（Skill）形式分发。基本安装步骤：

1. **获取技能包**：从 GitHub 仓库下载或克隆最新版本到本地目录。
2. **配置 AI 助手**：根据所用平台（Claude Code、Codex 等）将其标记为可用技能或导入为自定义指令。
3. **调用方式**：在对话中直接描述你想要的图表，例如“画一个显示三阶段流水线处理的架构图”，AI 会自动匹配最合适的模板。

最小可用示例（在与你配置好的 AI 助手的会话中）：

```
用户：请用 diagram-design 技能画一个 show 一个用户认证流程，包含 token 验证和图解边界。
AI 输出：返回一个完整的自包含 HTML 文件，其中包含内联 SVG，可直接在浏览器中打开或嵌入文档。
```

如果有 draw.io 或 Mermaid 的现有图源，直接提供源文件内容，技能会按设定要求（如尺寸偏好）重新绘制。

## 适用场景

- **技术文档与架构设计**：需要向团队或客户呈现系统架构、依赖关系或部署拓扑，并要求图表具备专业外观。适合快速生成可交付的面向甲方或社区的正式架构图。
- **顾问与咨询交付物**：在咨询项目中，图表占据视觉沟通的核心。使用该技能可以快速产出风格统一的工作坊、流程分析或路线图图表，节省大量排版时间。
- **产品与 UX 展示**：制作用户旅程地图、故事地图或服务蓝图，尤其在需要体现行为边界和反馈回路（如 Loop 模式）的讨论中。
- **基于文本源的图表再加工**：团队或社区中已有大量 Mermaid 生成的图表，需要统一升级为编辑级高质量视觉，直接重绘即可获得一致表现力。

## 项目亮点

- **设计审美作为第一优先级**：大多数代码生成的图表工具优先考虑语法的完备性而牺牲视觉。diagram-design 率先将“设计师审美”系统地编码为模板，目标是让你的设计师称赞，而不是勉强接受。
- **无需 Figma，无需调整样式**：从 AI 生成到最终交付，路径极短。输出是无外部引用的独立 HTML 文件，插画级别的排版精准，避免了“30 分钟配色”的尴尬。
- **抽象与复用设计独特**：借助语义化类型映射，用 38 种类型覆盖了通常需要上百种图型的场景，技术架构上极具扩展性和可维护性。
- **默认静态，支持动效**：考虑到使用场景的差异，项目在文档友好性和表达力之间取得了优雅的平衡。
