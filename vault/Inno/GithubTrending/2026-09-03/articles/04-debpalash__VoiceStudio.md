## 项目概述

VoiceStudio 是一款开源、完全本地化的语音工具套件，定位为 ElevenLabs 的开源替代方案。它集语音克隆、语音设计、视频配音、听写转写、语音转录和有声书制作于一体，支持 646 种语言，且无需注册账户、不需要 API 密钥，也没有订阅费用或使用量限制。项目前身为 OmniVoice-Studio，目前已在 GitHub 上获得超过 15,000 颗星标。VoiceStudio 面向配音创作者、视频制作者、语言学习者和内容本地化团队，让每一位用户都能在自己的硬件上完成专业级语音处理任务。

## 核心功能

- **语音克隆**：支持从少量样本中克隆任意说话人的音色，保留语气、语调和个性化特征。
- **语音设计**：内置多种参数化语音合成引擎，可灵活调整音高、语速、情感色彩等属性，从零打造合成嗓音。
- **视频配音与音频转写**：为视频自动生成多语言配音，支持时间轴对齐；同时提供精准的语音转文字功能，覆盖 11 种主流语音识别引擎。
- **听写与转录工作流**：面向笔记、会议和访谈场景的听写工具，可一键将录音转换为结构化文本。
- **有声书与长音频制作**：支持长文本分段合成和批量处理，适合制作有声书及其他长篇音频内容。
- **多引擎统一接口**：集成 16 种 TTS 引擎与 11 种 ASR 引擎，通过统一接口调用，并支持跨引擎对比和切换。

## 技术架构

VoiceStudio 采用 Python 构建，以模块化设计整合多个开源语音引擎，形成前后端分离的架构。核心技术特征包括：

- **引擎适配层**：所有 TTS 和 ASR 引擎通过抽象接口接入，只需实现标准方法即可注册为新引擎，用户可在界面中动态切换。
- **本地推理管线**：所有语音处理均在用户本地硬件上执行，不依赖云端服务；项目利用 GPU 加速（如 CUDA）和 CPU 优化策略，适应不同配置的设备。
- **跨平台兼容**：提供 macOS、Windows、Linux 原生支持，并通过 Docker 容器化方案简化部署和环境管理。
- **长文本处理引擎**：针对有声书等长音频场景，实现了分段切分、批量合成和音频拼接的逻辑，确保长文本的连贯性与稳定性。
- **REST API 层**：除了交互式界面，项目暴露了完整的 HTTP API，便于开发者集成到自定义工作流中。
- **数据格式标准化**：所有语音任务采用统一的任务描述格式，支持音频样本、文本片段、说话人标签等结构化输入。

## 安装与使用

### 安装步骤

1. **克隆仓库**：
   ```bash
   git clone https://github.com/debpalash/VoiceStudio.git
   cd VoiceStudio
   ```

2. **创建虚拟环境并安装依赖**（推荐 Python 3.9 以上版本）：
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows 下使用 venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **通过 Docker 安装**（可选）：
   ```bash
   docker build -t voicestudio .
   docker run -p 8000:8000 voicestudio
   ```

### 最小可用示例

启动 Web 界面：

```bash
python app.py
```

访问 `http://localhost:8000` 即可进入控制台。在界面左侧选择语音引擎，上传一段 10 秒以上的参考音频，输入目标文本，点击“合成”即可生成克隆语音。若使用 API，可通过以下方式调用：

```bash
curl -X POST http://localhost:8000/api/synthesize \
  -H "Content-Type: application/json" \
  -d '{
    "engine": "voice_clone_engine",
    "text": "你好，欢迎使用 VoiceStudio",
    "reference_audio": "/path/to/sample.wav"
  }'
```

视频配音功能可在界面中上传视频文件，选择目标语言后自动生成配音轨并返回下载链接。

## 适用场景

- **视频内容本地化**：为 YouTube 视频、课程录像、企业宣传片批量生成多语言配音，显著降低制作成本。
- **个人有声书与播客制作**：独立作者和创作者可将文字稿快速合成为高质量语音，无需专业录音设备。
- **语音资产备份与克隆**：为游戏角色、虚拟主播或个人语音库创建长期可用的可复用音色。
- **会议与访谈文字化**：利用听写与转录模块，将长语音记录快速转为可检索的文本资料。

## 项目亮点

VoiceStudio 与同类工具相比，其差异化优势明显：

- **完全本地化运行**：不依赖远程 API，数据不出设备，适合处理敏感内容并规避隐私风险。
- **零使用门槛**：无需注册账户、免费无限制，解决了主流商业产品在订阅和用量上的约束。
- **多语言与多引擎覆盖**：646 种语言的语音目录在开源生态中极为罕见，多引擎汇聚让用户可在同一工作台对比效果。
- **一体化的完整流程**：从语音克隆到视频配音再到文本转写，项目覆盖了语音处理链路中的大多数核心环节，避免了工具链切换成本。
- **活跃的社区治理**：项目处于高频更新状态（近 24 小时获得 800 多颗星），社区驱动的发展模式保证了功能的快速迭代。
