## 项目概述

Atlas 是一个专为编码代理（Coding Agents）设计的源代码控制工具。随着 AI 编程代理的普及，开发者在同时使用多个代理时会面临一个核心问题：每个代理的修改如何追踪、管理并回溯？Atlas 将 Git 的版本控制理念延伸至 AI 代理的工作流中，每次代理运行都会产生检查点（Checkpoints），并通过提交（Commits）将会话与代码变更关联起来。

该项目由 pacifio 团队开发，使用 Rust 语言编写，采用 MIT 许可证开源。目标用户包括重度使用 AI 编程助手的开发者、在多个代理间切换的团队，以及希望为代理行为建立审计轨迹的工程组织。Atlas 在 GitHub 上已获得超过 3000 颗星，并登上 Trendshift 趋势榜，显示出社区对代理工作流管理的迫切需求。

## 核心功能

- **统一会话管理**：将不同编码代理（如 Claude Code、Codex 等）的会话集中到一个界面中，开发者可以随时查看任意代理当前的工作状态和历史操作记录。
- **自动检查点与提交**：每次代理执行的关键步骤都会自动生成检查点，并与会话上下文链接，形成完整的操作时间线。
- **多代理变更追踪**：清晰区分不同代理产生的代码改动，可按照代理维度筛选和浏览文件修改历史。
- **集中式查询**：通过统一的搜索与查询接口，快速定位特定代理在某次会话中修改了哪个文件、为何做出该改动。
- **会话历史回放**：支持回溯任意时刻的代码状态，理解代理的推理过程及其对代码库的具体影响。
- **轻量级本地运行**：Atlas 设计为本地优先的桌面应用，数据存储在你的机器上，不需要上传代码至第三方服务器。

## 技术架构

Atlas 以 Rust 为后端核心语言，利用 Rust 在性能和内存安全方面的优势处理大量变更数据。前端采用桌面应用形式，提供原生级的交互体验。在数据模型层面，Atlas 借鉴 Git 的对象模型思想但进行了适配性扩展：每个代理会话（Session）被抽象为一等实体，提交对象不仅记录代码差异（diff），还附带产生该差异的代理上下文、输入提示和决策过程。

架构上，Atlas 实现了与主流编码代理（如 Claude Code、Codex、Aider 等）的适配层，通过插件机制捕获代理的工具调用和文件写入事件。存储引擎负责高效管理多代理产生的增量数据，支持按时间、代理和文件路径的多维索引。值得注意的是，Atlas 不依赖远程服务器即可工作，所有数据默认存储在本地，兼顾了隐私和离线使用的需求。

## 安装与使用

Atlas 提供预编译的桌面应用程序，支持主流的操作系统。你可以直接从项目的 GitHub Releases 页面下载对应的安装包进行安装。

以 macOS 为例，使用 Homebrew 安装：

```bash
brew install atlas
```

安装完成后，启动 Atlas 应用，按照以下最小步骤开始使用：

1. 在设置中添加你常用的编码代理（如 Claude Code 或 Codex），并授权 Atlas 监听其运行日志。
2. 正常使用你的编码代理完成一次代码修改任务。
3. 回到 Atlas 界面，你会看到刚才的会话已自动生成一系列检查点。点击任意检查点可查看该时刻的完整代码快照以及代理当时的操作记录。
4. 在搜索框中输入文件名或代理名称，即可筛选出所有相关的变更历史。

对于技术细节和扩展配置，请参考官方文档：[https://docs.tryatlas.cc/](https://docs.tryatlas.cc/)。

## 适用场景

- **多代理 A/B 测试**：在同一个代码库上让两个不同代理（或同一代理的不同配置）完成同一任务，通过 Atlas 对比它们的改动路径与最终结果，评估哪个代理更适合特定类型的工作。
- **代理行为审计与合规**：当团队使用 AI 代理提交大规模改动时，管理者可以通过 Atlas 追溯代码来源，确认每一行代码是由哪个代理依据什么指令产生的，满足代码审查的合规性要求。
- **复杂重构的可视化管理**：在进行跨文件的架构重构时，代理可能产生大量非预期改动。Atlas 提供全局视角，帮助开发者快速定位异常修改并回滚不理想的变更。

## 项目亮点

与将 Git 提交日志简单关联的做法不同，Atlas 的核心差异化在于建立了“代理会话-检查点-代码提交”的三层映射模型。它不是将代理的输出强行塞进传统 Git 工作流工具中，而是从零设计了一套适合代理工作节奏的版本控制机制。

此外，该项目对代理工具生态表现出高度的开放性——通过适配层支持现有的多种 AI 编码工具，而非强制开发者迁移到一个新的“全家桶”环境。Rust 带来的性能优势使得即使面对超大规模的变更历史，查询和渲染依然保持流畅。最后，其本地优先的隐私设计在同类 SaaS 产品中独树一帜，特别适合对代码安全有严格要求的组织。
