## 项目概述

Hermes Agent 是由 Nous Research 开发的一款具备自我改进能力的开源 AI 代理框架。其核心理念是“The agent that grows with you”——一个能够随着使用者交互不断成长、持续积累技能的智能体。与市面上大多数仅提供固定工具链的 Agent 不同，Hermes Agent 内置了一条独特的学习回路：它能够在执行任务的过程中自主创建新的技能模块，并将这些技能沉淀为可复用的资产，从而让代理本身变得越来越强大、越来越懂你。

该项目主要面向两类用户：一是希望快速搭建个人 AI 助手、自动化工作流的开发者与研究者；二是对 AI 代理进阶能力感兴趣、希望探索“可进化智能体”理念的技术爱好者。凭借其 MIT 开源协议和活跃的社区生态，Hermes Agent 在 GitHub 上已累计获得超过 24 万 Star，是目前增长最快的 AI 代理项目之一。

## 核心功能

- **内置学习回路**：Hermes Agent 的核心特性。它在每次任务执行后，会尝试将解决方案抽象为可复用的“技能”（Skill）。用户无需手动编写完整代码，只需用自然语言描述想要的技能，代理便会自主生成并安装这些技能，实现“用一次，会一次”的能力扩展。

- **技能感知与自动调用**：代理具备对自身技能库的完整感知能力。当你提出一个新的问题或任务时，它会自动检索并匹配最合适的既有技能，并以 JSON 形式进行结构化调用，确保响应的高效性与准确性。

- **多工具链编排**：支持 Python 代码执行、文件系统读写、Web 搜索、爬虫抓取、API 调用等多种基础操作，并允许用户根据自己的工作流，将这些操作与自定义技能混合编排，完成复杂的端到端任务。

- **交互式命令行界面**：项目提供了一个功能完善的 `hermes` 交互式终端，支持多轮对话、进程内快捷键（如 `/exit` 退出）以及对当前工作目录的完整感知，让开发调试过程一目了然。

- **高度可配置与扩展**：支持通过环境变量或 `.env` 文件对推理端点、模型名称、温度、上下文窗口等参数进行精细配置，可灵活切换至 OpenAI、Fireworks AI 等主流推理服务，也能够轻松对接本地或自建的模型服务。

## 技术架构

Hermes Agent 基于 Python 构建，设计上采用了一种“轻核心、重技能”的架构理念。整个系统由一个负责对话调度与推理的 Agent 核心引擎、一个负责管理与持久化技能集合的技能库（Skill Store）以及一组可插入的基础工具集组成。

其最关键的架构创新在于技能生成器（Skill Generator）：当系统判断当前任务缺少合适的处理方式时，Agent 会利用大语言模型的代码生成能力，实时编写一个新的 Python 函数作为技能，并通过一个“技能中介”（Skill Mediator）将该函数注册进技能库中。技能以代码文件形式存储在本地目录（如 `skills/` 文件夹），用户可以随时查看、修改或删除这些技能，整个过程透明可控。

在推理层面，Hermes Agent 使用了结构化输出的策略，要求模型在内部推理步骤中明确标注是否调用技能以及调用哪个技能。这种设计使得代理的执行路径清晰可审计，大大减少了黑盒式调用的不可预测性。整体架构强调模块化与可插拔性，使得社区贡献新的技能或工具集变得非常直接。

## 安装与使用

Hermes Agent 的安装非常简便，推荐使用 `pip` 进行安装：

```bash
pip install hermes-agent
```

如果你希望从源码运行或参与开发，可以克隆仓库并执行：

```bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
pip install -e .
```

安装完成后，你需要在环境变量中配置至少一个大语言模型的 API 密钥（例如 `OPENAI_API_KEY`），然后即可启动交互式终端：

```bash
hermes
```

在终端中，你可以直接开始对话。一个最小可用的示例如下：

```
你: 帮我在当前目录下创建一个名为 example.txt 的文件，内容为 "Hello, Hermes!"。

Hermes: 好的，我将使用文件操作技能来完成这个任务。
[调用技能 fs_write_file 成功]
文件已创建。你希望我继续做什么吗？
```

此时，Hermes 已经通过这次简单的交互（或者你后续的指引）学习了 `fs_write_file` 相关的技能。下次你再提出类似需求时，它将直接调用已掌握的技能，无需从头推理。

## 适用场景

- **个人效率助手**：作为一款随用随学的桌面终端助手，你可以让它帮你管理文件、归纳笔记、自动化日常的重复性编程任务，并观察它如何逐渐成为你最懂行的“私人助理”。

- **研究与数据收集**：利用其内置的 Web 搜索与爬虫技能，快速从互联网上抓取和分析数据。当需要定期执行某类数据整理任务时，只需教会 Hermes 一次，它就能沉淀出相关技能供你复用。

- **轻量级自动化平台**：开发者可将 Hermes Agent 作为后端服务，通过编写技能库来定义特定的业务逻辑，然后利用其交互接口或 API 完成内部工具链的调用，构建一个低成本、可进化的自动化中枢。

## 项目亮点

与 LangChain、AutoGPT 等传统的 Agent 框架相比，Hermes Agent 最大的差异化优势在于它跳出了“智能体只能使用开发者预设的工具”这一樊笼。大多数框架要求用户先定义好工具列表，而 Hermes Agent 则从“技能”的视角出发，让代理在运行时自主生成与改进自己的工具。这意味着它的“生态位”是动态扩展的，其能力边界也会随着使用时间的增长而持续拓宽。

此外，透明的技能存储机制（纯 Python 代码文件）大大降低了用户的审视成本，你始终清楚代理正在“想什么”和“会什么”，这在需要信任和可控性的场景中价值显著。背靠 Nous Research 的研究团队与 MIT 开源协议，Hermes Agent 兼顾了前沿的 AI 研发能力和社区驱动的健康生态。
