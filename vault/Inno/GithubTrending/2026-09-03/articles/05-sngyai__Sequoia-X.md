## 项目概述

Sequoia-X 是一款面向 A 股市场的自动化选股系统，由独立开发者 sngyai 创建并维护。项目名称取意自“王者回归”，定位于量化策略的自动化执行与信号推送。它解决了个人投资者在收盘后需要耗费大量时间手工筛选股票、复盘技术形态的痛点，通过定时任务在每日收盘后自动完成数据更新、策略扫描和结果推送的全流程。系统的目标用户是具备一定技术分析基础、希望借助量化手段提高选股效率的 A 股个人投资者，以及对自动化交易信号生成感兴趣的量化爱好者。

## 核心功能

- **多策略技术形态扫描**：内置六种经典技术分析策略，覆盖趋势突破、量价关系、K 线形态和相对强度等多个维度，包括海龟突破（TurtleTrade）、均线放量突破（MaVolume）、高而窄旗形整理突破（HighTightFlag）、涨停洗盘回踩（LimitUpShakeout）、趋势中跌停反包（UptrendLimitDown）和欧奈尔 RPS 相对强度突破（RpsBreakout）。

- **全市场自动数据更新**：基于 baostock 免费数据源，自动拉取全市场约 5200 只 A 股的历史后复权日 K 线数据，并支持增量更新，确保数据库与交易日同步。

- **每日收盘后自动运行**：设计为适合 crontab 定时调用的命令行工具，可在每个交易日下午自动执行完整的“补数据→跑策略→推结果”流程，运行时长约 2-3 分钟。

- **飞书机器人即时推送**：策略筛选结果通过飞书群机器人 Webhook 自动推送至指定群聊，选股结果在收盘后第一时间送达，无需人工盯盘或查看报告。

- **双模式运行架构**：支持日常增量模式和一次性历史回填模式，首次部署时通过回填模式快速建立历史数据库，之后日常运行仅需增量更新。

- **SQLite 本地数据存储**：所有行情数据持久化于本地 SQLite 数据库，无外部数据库依赖，数据文件自动生成，便于迁移和备份。

## 技术架构

Sequoia-X 采用现代 Python 工程化标准从零重构，抛弃了初代版本可能存在的脚本式混乱，以面向对象编程（OOP）作为核心组织方式。系统模块位于 `sequoia_x` 包内，入口文件 `main.py` 通过 argparse 实现命令行参数分发，区分日常运行与回填模式。

在数据处理层面，系统以向量化计算为设计原则，利用 pandas 等库的批量运算能力替代逐行循环，显著提升策略回测与信号生成的效率。增量数据更新机制是架构中的关键设计，系统能够识别每个交易日新增的 K 线数据，仅下载缺失部分，避免重复拉取全量历史，大大降低每日运行的网络开销和时间成本。

数据源选型上，项目避开了常见但存在反爬限制的东方财富等接口，转而使用 baostock——一个免费、无需注册且无访问频次限制的数据服务。历史数据采用后复权方式计算，保证价格因除权除息导致的跳空不影响技术指标计算，这为后续的策略信号准确性奠定了基础。环境配置通过 `.env` 文件管理，符合行业惯例的 12-factor 风格。项目使用 `pyproject.toml` 声明依赖，兼容 uv 与 pip 两种包管理工具，并集成了 ruff 和 pytest。

## 安装与使用

**环境要求**：Python 3.10 或更高版本。

**第一步：安装依赖**

推荐使用 uv（高性能 Python 包管理器）完成依赖安装：

```bash
uv sync
```

也可以使用传统 pip 方式：

```bash
pip install .
```

**第二步：配置环境变量**

将环境变量模板复制并填写飞书 Webhook 地址：

```bash
cp .env.example .env
# 编辑 .env 文件，填入飞书机器人 Webhook URL
```

**第三步：首次历史数据回填**

首次部署执行回填模式，全量下载约 5200 只股票的历史日 K 数据，整个过程约 12 分钟：

```bash
python main.py --backfill
```

**第四步：日常自动运行**

完成回填后，日常模式下每天手动或定时执行：

```bash
python main.py
```

推荐使用 crontab 在交易日 19:15 自动运行：

```cron
15 19 * * 1-5 cd /root/Sequoia-X && .venv/bin/python main.py >> log.txt 2>&1
```

## 适用场景

- **收盘后快速复盘**：每天收盘后自动获得当日满足技术突破、放量上涨或形态反转条件的股票列表，省去人工翻看数千只个股 K 线图的繁琐过程。

- **量化策略验证与迭代**：内置策略模块化设计，方便使用统一的历史数据回测不同技术形态的有效性，为策略调参和新增策略提供基础设施。

- **多信号交叉确认**：将 Sequoia-X 作为信号源，可同时运行多个策略，通过不同技术维度的信号叠加来寻找共振选股机会，提高选中强势股的概率。

- **定时推送至团队/社群**：飞书推送机制适合小型投资研究团队或付费社群，将每日选股结果自动分享至群聊，降低信息分发成本。

## 项目亮点

- **免费且合规的数据获取**：规避了市面上多数选股工具依赖的东方财富等可能存在反爬限制的接口，转而使用 baostock 免费无限制的数据源，在降低使用成本的同时保证了数据获取的稳定性。

- **真正的开箱即用**：从零到产生第一条选股结果最短仅需约 15 分钟，无需额外安装数据库服务、无需注册任何 API 密钥（飞书 Webhook 除外），配置过程简化到复制一个文件。

- **实用的策略库而非晦涩因子**：内置策略均为技术分析流派中的经典范式（海龟法则、欧奈尔 RPS、旗形整理等），以交易者熟悉的语言命名，而非令人望而生畏的量化公式堆砌，更适合技术面投资者理解信号含义。

- **轻量级架构设计**：SQLite 本地存储配合增量更新机制，使系统可在低配置云主机或家用电脑上长期运行，且每日常规执行时间控制在 3 分钟以内。

- **工程标准化程度高**：作为开源项目，其代码组织、注释和文档都遵循了主流的 Python 工程实践，易于开发者阅读、修改和贡献。
