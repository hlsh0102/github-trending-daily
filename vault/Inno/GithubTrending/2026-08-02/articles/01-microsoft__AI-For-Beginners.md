## 项目概述

[AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners) 是微软开源的一套面向初学者的人工智能入门课程，采用 12 周、24 课的结构化设计，旨在帮助零基础学习者系统掌握人工智能的核心概念与实践技能。课程内容涵盖从传统符号推理到现代神经网络、从深度学习框架到 AI 伦理等多个维度，既有理论讲解，也有可运行的代码示例和实验练习。项目采用 Jupyter Notebook 格式，支持在浏览器中直接运行，适合学生、转行开发者、产品经理以及任何对 AI 感兴趣的个体自学或作为教学辅助材料使用。该课程完全免费，基于 MIT 许可证开源，目前已在 GitHub 上获得超过 5.7 万颗星，是微软开源教育系列中最受欢迎的项目之一。

## 核心功能

- **结构化课程路径**：12 周学习计划，每周 2 课，每课包含视频讲解、文字教程、代码示例、知识测验和动手实验，帮助学习者按节奏稳步推进。
- **双框架覆盖**：同时介绍 TensorFlow 和 PyTorch 两大主流深度学习框架，培养学习者根据任务选择合适工具的能力。
- **内置 Jupyter 实验环境**：所有代码示例和练习题均以 Notebook 形式提供，支持本地运行或通过 Binder 在线执行，无需复杂环境配置。
- **AI 伦理与责任讨论**：专门设置课程模块，探讨公平性、偏见、隐私与安全等 AI 应用中的关键社会议题，培养负责任的 AI 开发意识。
- **多语言翻译支持**：通过 GitHub Action 自动化维护多语言版本，目前已覆盖阿拉伯语、孟加拉语、保加利亚语、缅甸语、简体中文、繁体中文等十余种语言，方便全球学习者使用。
- **社区互动与支持**：项目设有 Discord 和 Gitter 讨论频道，学习者可以交流问题、分享经验，获得社区帮助。

## 技术架构

课程内容组织上采用“概念讲解 + 代码演示 + 实践任务”的三段式结构，每个单元均以独立 Jupyter Notebook 呈现，便于学习者按需加载和运行。课程体系分为若干核心模块：首先从 AI 概述与符号推理切入，帮助学习者建立宏观认知；随后进入神经网络基础，涵盖感知机、反向传播、梯度下降等核心算法；接着深入卷积神经网络（CNN）与循环神经网络（RNN），通过图像分类和文本生成等真实任务，让学习者掌握深度学习模型的训练与调优方法；最后引入强化学习与生成对抗网络（GAN）等前沿主题，并辅以 AI 伦理模块，形成完整的知识闭环。

技术选型上，课程兼顾易用性与行业通用性：使用 Python 作为主要编程语言，以 TensorFlow 和 PyTorch 为双主线，两种框架的代码示例并行呈现。所有 Notebook 均配有依赖清单（`requirements.txt`），并支持通过 Binder 一键启动在线环境，降低了本地安装的复杂度。此外，项目利用 GitHub Actions 实现翻译文件的自动同步与质量检查，确保多语言内容的一致性和时效性。

## 安装与使用

要使用本课程，你可以选择在线方式或本地环境运行 Notebook：

**在线使用（推荐入门）**：直接访问 GitHub 仓库，浏览课程目录。要运行代码示例，点击 README 顶部的 Binder 徽章，系统会自动构建并打开 Jupyter 环境，无需安装任何软件。

**本地使用**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/microsoft/AI-For-Beginners.git
   cd AI-For-Beginners
   ```

2. 安装 Python（建议 3.8 或更高版本），然后安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. 启动 Notebook：
   ```bash
   jupyter notebook
   ```

4. 按照 `README.md` 中建议的学习顺序，从第一课开始逐个打开 `.ipynb` 文件，运行代码单元并完成课后练习。

如果你希望使用简体中文学习，直接进入 `translations/zh-CN/` 目录下的对应课程文件即可。

## 适用场景

- **个人自学 AI 入门**：适合完全没有机器学习背景的初学者，通过 12 周的系统学习，建立起从基础概念到实际建模的完整知识体系。
- **高校或培训机构教学**：课程结构清晰、课时安排合理，附有测验和实验，教师可直接作为教学大纲或参考教材使用，节省备课时间。
- **企业内部技术培训**：针对想了解 AI 原理和应用的非 AI 岗位员工（如产品、运营、管理层），提供直观的图形化解释和低门槛的动手实践，有助于跨团队沟通协作。
- **职业转型与面试准备**：课程覆盖了 AI 领域的高频知识点和实践技能，配合社区讨论和项目练习，可作为面试前的系统复习资料。

## 项目亮点

与市面上其他 AI 入门资源相比，本项目具有几个显著优势。其一，**课程设计极为完整且系统**，从符号推理到深度学习前沿，由浅入深、环环相扣，避免了一般碎片化教程“只见树木不见森林”的缺点。其二，**双框架并行教学**是同类课程中少见的做法，让学习者在起步阶段就了解不同生态的优劣，为未来工程选型打下基础。其三，**强调动手实践**，每课附有可运行的代码和独立实验，确保学习者不是“只看不练”。其四，**重视 AI 伦理教育**，这在初级课程中尤为难能可贵，帮助学习者提前建立风险意识。最后，**全球社区与多语言支持**，使得学习不再受语言和地域限制，同时活跃的讨论平台让学习者能够获得及时帮助。
