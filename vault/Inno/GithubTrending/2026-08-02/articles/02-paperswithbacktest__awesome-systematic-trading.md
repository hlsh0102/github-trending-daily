## 项目概述

Awesome Systematic Trading 是一个专注于系统化交易（量化交易）领域的精选资源列表，由 paperswithbacktest 团队维护。该项目系统地收集并整理了从事量化策略研究、开发和实盘交易所需的各类资源，包括软件库、交易策略、书籍、视频、博客和课程等。

对于量化交易从业者和研究者而言，最大的痛点在于信息分散、质量参差不齐。本项目通过人工筛选和分类，将分散在网络各处的优质资源汇聚到一个仓库中，解决了资源发现和甄别的难题。目前该项目已在 GitHub 上获得超过 12000 颗星标，社区活跃度极高。

目标用户包括：希望入门量化交易的程序员和金融从业者、正在寻找特定交易策略或工具的研究人员、以及需要系统性学习资料的学生和爱好者。

## 核心功能

- **精选库与包集合**：收录 97 个用于研究和实盘交易的库与包，按功能细分为回测框架、实盘交易系统、数据获取、风险管理和技术指标计算等类别，其中回测框架又进一步区分为事件驱动型和向量化型。
- **策略库**：整理 40 多个由机构投资者和学术界描述的交易策略，涵盖趋势跟踪、均值回归、统计套利、期权定价等多种类型，每个策略均附有原始来源说明。
- **书籍推荐**：精心挑选 55 本适合从入门到专业水平的量化交易书籍，覆盖 Python 编程、金融理论、算法交易和风险管理等主题。
- **视频与访谈**：收录 23 个高质量视频和访谈内容，包括知名量化基金创始人的分享、学术会议演讲和技术教程。
- **博客与课程**：持续更新的博客列表和在线课程资源，帮助读者跟踪行业最新动态和系统学习。
- **中文支持**：提供完整的中文版本 README，方便中文用户快速了解项目内容。

## 技术架构

该项目本质上是一个精心组织的 Markdown 资源索引，采用单一仓库结构，通过清晰的目录层级和锚点链接实现快速导航。主要特点包括：

- **分类体系**：采用两级分类结构，先按资源类型（库、策略、书籍等）划分，再按功能或难度进行细分，例如回测框架被拆分为事件驱动和向量化两小类，以适应用户的不同需求。
- **可折叠导航**：使用 GitHub 支持的 `<details>` HTML 标签实现全目录的可折叠展示，在保持 README 首页简洁的同时提供完整索引能力。
- **外部链接整合**：项目主页通过醒目位置推广配套网站 paperswithbacktest.com，该网站提供 Python 实现的交易策略集合，形成仓库与网站之间的流量闭环。
- **社区驱动**：通过 GitHub Issues 和 Pull Requests 接受社区贡献，所有资源均经过维护者审核，保证列表质量。

## 安装与使用

由于这是一个资源索引仓库，无需安装。使用方式十分简单：

1. 克隆或直接访问仓库：

```bash
git clone https://github.com/paperswithbacktest/awesome-systematic-trading.git
```

2. 打开 `README.md` 文件，浏览目录并点击感兴趣的资源链接。

3. 如需快速定位特定类型资源，可直接在 GitHub 搜索框中输入关键词，如 `trend following` 或 `backtesting`，仓库的锚点结构会帮助快速跳转。

4. 若偏好中文阅读，可点击 README 中的中文版链接，或直接访问 `README_zh.md` 文件。

最小可用示例：假设你是一名刚接触量化交易的 Python 开发者，想要寻找一个回测框架开始实践，可以在 README 的 "Libraries and packages" 部分找到 "Backtesting and Live Trading" 分类，从中选择如 Backtrader、Zipline 或 VectorBT 等流行框架，访问其 GitHub 仓库即可获取安装和使用文档。

## 适用场景

- **量化研究入门**：对于刚进入量化领域的新手，本书单和博客列表提供了一条清晰的学习路径，从基础理论到实战工具一应俱全。
- **策略开发与选型**：策略研究者需要参考多种实现思路时，策略库中 40 多个经过学术验证的策略提供了丰富的灵感来源。
- **实盘交易系统搭建**：工程师需要选择合适的技术栈时，可按事件驱动/向量化框架的分类快速评估候选库，并参考相关书籍中的系统设计经验。
- **教学与培训**：高校教师或培训讲师可将本仓库作为课程资料的索引，直接引用其中高质量的视频、论文和代码资源。

## 项目亮点

- **单一入口覆盖全链路**：从研究到实盘，从理论到代码，一个仓库覆盖量化交易全生命周期所需资源，省去在搜索引擎中反复筛选的时间。
