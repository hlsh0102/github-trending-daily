## 项目概述

reverse-skill 是一个面向网络安全领域的技能路由包，专为 AI 编程客户端（如 Claude Code、Kiro、Cursor、Cline 等）设计。该项目解决了安全研究人员在使用 AI 辅助工具进行逆向工程、授权渗透测试和安全研究时，缺乏系统性技能引导和工具链支持的问题。

该项目本质上是一个“技能路由器”，它能够根据用户当前的任务类型，自动路由到对应的技能模块，并引导 AI 客户端加载合适的工具链。同时，它内置了一个自进化的知识库，能够在实践中不断积累经验，形成可持续增长的领域知识体系。

目标用户包括：从事逆向工程的安全研究员、进行授权渗透测试的红队成员、以及开展安全学术研究的学者。无论你是使用 Claude Code 还是 Cursor，都能通过这个项目获得一致的安全技能支持体验。

## 核心功能

- **AI 自动路由**：根据用户输入的任务描述，自动匹配并路由到最合适的技能模块，无需手动切换上下文。
- **按需工具链自举**：在识别到特定任务后，自动引导 AI 客户端加载对应的逆向/渗透工具链，支持动态扩展工具集合。
- **自进化知识库**：内置经验库能够在每次成功执行任务后自动沉淀有效模式，形成不断增长的安全知识图谱。
- **多客户端兼容**：支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端，提供统一的路由接口。
- **技能模块化设计**：每个安全领域（逆向、渗透、漏洞研究等）都封装为独立模块，便于按需加载和升级。
- **任务日志与审计**：记录每次路由决策和工具链使用情况，便于安全团队的审计和复盘。

## 技术架构

reverse-skill 采用分层架构设计，从底层到上层依次为：

1. **客户端适配层**：负责与不同 AI 编程客户端（Claude Code、Cursor、Cline 等）进行协议适配，屏蔽客户端差异，向上提供统一的能力接口。
2. **技能路由引擎**：核心决策组件，基于规则匹配和启发式算法，根据任务类型、关键词、上下文状态等输入，确定最优的技能模块路由路径。
3. **工具链仓库**：按安全领域（逆向工程、Web 渗透、二进制分析等）分类的工具集合，每个工具链都包含工具清单、调用方式和参数模板。
4. **经验库层**：采用时序数据库存储结构化经验记录，包含任务特征、采用策略、执行结果等字段，支持基于相似度的经验检索。
5. **自举更新机制**：当某个技能模块或工具链执行成功时，系统会自动提取模式并更新到经验库，形成正向循环。

项目使用 PowerShell 作为主要实现语言，这使其能够深度集成到 Windows 安全测试环境中。设计上遵循“约定优于配置”原则，尽可能减少使用者的手动配置负担。

## 安装与使用

### 安装步骤

1. 克隆仓库到本地：

```bash
git clone https://github.com/zhaoxuya520/reverse-skill.git
```

2. 进入项目目录并初始化：

```bash
cd reverse-skill
./init.ps1
```

3. 将项目路径添加到环境变量（PowerShell）：

```powershell
$env:REVERSE_SKILL_HOME = (Get-Location).Path
```

4. 如果你是 Claude Code 用户，在 `.claude/commands` 目录中添加路由入口：

```json
{
  "name": "reverse-skill",
  "command": "powershell -ExecutionPolicy Bypass -File $REVERSE_SKILL_HOME/router.ps1",
  "description": "Reverse engineering / penetration testing skill router"
}
```

### 最小可用示例

以 Claude Code 为例，在对话中输入：

```
使用 reverse-skill 分析这个 Android APK 的签名校验逻辑
```

路由引擎会自动识别任务类型为“Android 逆向 - 安全机制分析”，加载对应的 Frida/APKTool 工具链模板，并输出结构化的分析步骤供 AI 客户端执行。

## 适用场景

- **移动应用安全审计**：当需要分析 Android/iOS 应用的签名校验、通信加密或代码混淆逻辑时，路由包能够快速引导 AI 加载对应的逆向工具链。
- **授权渗透测试**：在获得授权的 Web/内网渗透测试中，自动路由到攻击面分析、漏洞验证等模块，帮助红队成员高效完成测试任务。
- **恶意软件分析**：面对未知样本时，按需加载静态分析、动态沙箱和反混淆工具链，辅助 AI 客户端进行行为分析和特征提取。
- **安全研究知识管理**：团队内共享经验库，新成员可以借助路由包的引导快速掌握特定领域的方法论和工具使用方式。

## 项目亮点

- **模块化路由优于单体指令**：不同于普通的安全提示词工程，该项目提供了真正结构化的技能路由机制，而非将所有知识塞入一个 prompt 中。
- **可进化的知识沉淀**：大多数同类项目是静态的，而 reverse-skill 的经验库能够根据历史执行结果自动更新，越用越“聪明”。
- **多客户端覆盖**：一次配置，多处使用。无需为 Claude Code 和 Cursor 分别维护不同的安全技能配置。
- **面向实战的轻量设计**：不依赖重量级框架，使用 PowerShell 即可驱动整个路由流程，适合在隔离的安全测试环境中部署。
- **社区驱动的工具链扩展**：工具链仓库设计为可扩展结构，社区贡献者可以轻松添加新的安全工具模板。
