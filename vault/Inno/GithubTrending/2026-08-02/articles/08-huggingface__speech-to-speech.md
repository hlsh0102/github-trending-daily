## 项目概述

Speech To Speech 是 Hugging Face 团队开源的一个低延迟、模块化的语音代理（Voice Agent）流水线项目。它将完整的语音交互链路抽象为 **VAD（语音活动检测）→ STT（语音转文字）→ LLM（大语言模型）→ TTS（文字转语音）** 四个标准阶段，并通过与 **OpenAI Realtime API 兼容的 WebSocket 接口**对外暴露服务。这意味着任何为 OpenAI Realtime 编写的客户端（如浏览器、移动应用或机器人控制程序）都可以通过简单地更换服务器地址，无缝切换到由开源模型驱动的本地语音代理后端。

该项目解决的核心问题是：**如何用开源模型构建一套完整、可定制且能本地化部署的实时语音对话系统**。它面向的受众包括 AI 应用开发者、机器人工程师、智能硬件创业者，以及任何希望在私有环境（如企业内部、个人电脑或边缘设备）中运行语音交互能力的研究者与开发者。该项目已在生产环境中经受考验，作为数千台 Reachy Mini 机器人的对话后端持续运行。

## 核心功能

- **一键启动的语音代理服务**：通过 `pip install speech-to-speech` 安装后，运行一条命令即可启动完整的语音对话服务，极大降低了搭建复杂语音流水线的门槛。
- **OpenAI Realtime 兼容接口**：服务暴露的 WebSocket API 与 OpenAI 的 Realtime 接口兼容，现有客户端无需修改即可切换到本地服务，实现了从云端 API 到本地模型的平滑迁移。
- **全组件可替换架构**：VAD、STT、LLM、TTS 四个核心组件全部支持替换。用户可根据具体需求（如延迟、精度、语言）选择不同的实现，自由组合搭建定制化的语音链路。
- **灵活的 LLM 接入方案**：LLM 模块支持任何兼容 OpenAI 协议的服务，包括 Hugging Face 托管推理端点、vLLM 或 llama.cpp 自建服务器，以及 OpenAI 官方 API，完美适配从云端到完全本地的不同部署场景。
- **支持完全本地化部署**：通过搭配本地运行的 STT、TTS 和 LLM（如 vLLM、llama.cpp），可以实现不依赖任何外部网络的纯离线语音代理，保障数据隐私安全。

## 技术架构

项目的技术核心在于其**组件化、协议标准化的流水线设计**。整个系统以事件驱动的方式串联四个关键环节：

1. **VAD 层**：负责检测用户语音的起点与终点，有效过滤环境噪声和静音，触发后续处理流程。
2. **STT 层**：将捕获的语音片段实时转换为文本，通常采用流式识别以降低延迟。
3. **LLM 层**：接收转换后的文本，结合对话上下文生成响应内容。该模块是系统的“大脑”，通过 OpenAI 兼容的 HTTP 协议与各类推理服务通信，这为接入任何支持该协议的模型（从云端大模型到本地小模型）提供了极强的灵活性。
4. **TTS 层**：将 LLM 生成的文本流式合成为语音，并回传给客户端，完成对话闭环。

架构的最大亮点是**接口标准化**。通过将整个流水线封装为一个符合 OpenAI Realtime 规范的服务，该项目将不同组件的技术差异完全隐藏在接口背后。开发者无需理解底层复杂的技术栈，只需使用标准的客户端库进行交互，即可构建出功能完整的语音代理。此外，系统在设计与实现上高度关注低延迟指标，通过流式处理和高效的组件间通信机制，确保端到端的对话响应足够快速，满足实时交互的体验要求。

## 安装与使用

**第一步：安装**

项目已发布至 PyPI，支持直接通过 pip 安装，需要 Python 3.10 或更高版本环境。

```bash
pip install speech-to-speech
```

**第二步：配置 API 密钥**

如果希望使用 OpenAI 的模型作为 LLM 后端，需要设置 API 密钥；如果使用本地模型或 Hugging Face 托管服务，则配置相应的访问凭证。

```bash
export OPENAI_API_KEY=your_api_key_here
```

**第三步：启动服务**

在终端中执行以下命令，即可启动一个 OpenAI Realtime 兼容的 WebSocket 语音服务：

```bash
speech-to-speech
```

默认情况下，服务会监听本地端口。启动后，开发者可以使用任何支持 OpenAI Realtime 协议的客户端库或 Web 应用进行连接。例如，在网页前端使用 OpenAI 提供的 JavaScript SDK，只需将连接地址指向本服务的 WebSocket 端点，即可实现浏览器端的语音对话体验。

**快速验证**：Hugging Face 官方提供了一个基于 Gradio 的演示页面，可以在浏览器中直接体验对话效果，同时也可以在 `examples/` 目录下找到更多自定义接入示例。

## 适用场景

- **智能机器人对话**：为实体机器人（如 Reachy Mini）提供实时语音交互能力，使机器人能够理解用户指令并通过语音回应，适用于导览、陪伴、教育等场景。
- **本地化语音助手**：在数据敏感的办公环境或家庭中部署完全离线的语音助手，确保语音数据不出本地网络，满足企业合规与个人隐私保护需求。
- **实时语音翻译与转录服务**：结合不同的 LLM 和 TTS 模型，构建低延迟的跨语言语音翻译工具或会议实时字幕与摘要系统。
- **语音交互原型快速开发**：为 AI 产品经理与开发者提供一个开箱即用的语音对话后端，无需从零搭建复杂流水线，即可快速验证产品创意与用户反馈。

## 项目亮点

- **真正的生产级验证**：不同于许多停留在演示阶段的开源项目，Speech To Speech 已被 Hugging Face 团队用于大规模机器人集群的日常运营，其稳定性与可靠性经过了真实业务的考验。
- **极低的接入成本**：兼容 OpenAI Realtime 接口的设计是核心差异化优势。开发者基于 OpenAI 开发生态构建的应用，可以通过一行配置切换至本地服务，免去了客户端适配的繁琐工作。
- **灵活性与开源性并存**：项目既支持完全使用开源模型构建端到端本地堆栈，也允许用户混合使用云端与本地资源。这种灵活性让开发者能够根据预算、性能与隐私需求进行动态取舍。
- **社区活跃与热度极高**：项目在 GitHub 上拥有超过 1 万 Star，且增长迅速，反映出社区对构建本地语音代理解决方案的强烈需求，以及对该项目技术路径的高度认可。
