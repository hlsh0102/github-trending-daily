今日 GitHub 开源日报来了，十个项目，个个有看点 ☕️

1️⃣ cloudflare/computer：Cloudflare 官方虚拟文件系统，SQLite 做底层存储，支持容器、Shell、JS 三种后端执行。给 AI 代理一个能持久化操作的“电脑”，边缘跑 Linux 二进制不再是问题。

2️⃣ huangruiteng/loopx：轻量级循环工程状态内核。专治 AI 智能体多轮协作中的目标漂移、证据过期和任务交接混乱。相当于给长跑 Agent 团队装了个“本地控制塔”。

3️⃣ TencentCloud/TencentDB-Agent-Memory：腾讯云开源，AI Agent 的团队级记忆中枢。把对话、文档、代码变成对话记忆、技能、知识库、代码图谱四种资产，让智能体经验能在团队里流通复用。

4️⃣ donnemartin/system-design-primer：36 万星的系统设计面试圣经。CAP、一致性、微服务等 30+ 核心主题全覆盖，还带 Anki 闪卡帮助记忆，备战架构面试首选。

5️⃣ firecrawl/pdf-inspector：Rust 编写的高性能 PDF 分类检查库。200 毫秒内判断 PDF 是文本型还是扫描型，省掉大量不必要的 OCR 费用，支持 Python、Node、WebAssembly 绑定。

6️⃣ esengine/DeepSeek-Reasonix：专为 DeepSeek 模型优化的终端 AI 编程代理。核心思路是前缀缓存稳定，让代理长时运行、持续复用缓存，降低推理成本和响应延迟。

7️⃣ addyosmani/agent-skills：Chrome 工程总监开源。把资深工程师的开发流程做成 7 个斜杠命令，从 /spec 到 /plan、/build，给 AI Agent 装上工程纪律和质量门禁。

8️⃣ obra/superpowers：26 万星的编码代理方法论。强制代理在写代码前先理清需求规格、制定计划、走子代理驱动流程。治“AI 拿到需求直接开写”的毛病，就靠它。

9️⃣ roboflow/supervision：计算机视觉工具库。提供 20+ 种标注器、模型结果统一接口，支持检测跟踪、区域计数。YOLO 用户强烈关注，4.9 万星稳定输出。
