## 项目概述

DeepSeek-Reasonix 是一款专为终端环境设计的 AI 编程代理，以 DeepSeek 模型为核心驱动，由 esengine 团队开发并采用 Go 语言实现。该项目的核心理念围绕「前缀缓存稳定性」（prefix-cache stability）展开，鼓励用户让代理保持长时间运行，在持续交互过程中复用已计算的缓存，从而显著降低每次请求的推理成本与响应延迟。

对于日常依赖命令行工具进行开发、希望在不离开终端的情况下获得 AI 辅助编码能力的开发者而言，Reasonix 提供了一个轻量、快速且可深度定制的解决方案。它天然适配 DeepSeek 系列模型的推理特性，通过精细的上下文管理策略，让长会话中的每一次交互都更加高效。

## 核心功能

- **前缀缓存优化**：自动管理会话上下文，确保重复的提示前缀能够命中缓存，大幅减少 API 调用开销。
- **终端原生交互**：提供流畅的交互式命令行界面，支持多行输入、语法高亮和流式输出，贴近现代终端用户体验。
- **可扩展插件体系**：内置扩展机制（见 docs/EXTENSIONS.md），允许用户编写自定义命令、工具和上下文加载器，灵活适配不同工作流。
- **协作协议支持**：实现了 ACP（Agent Collaboration Protocol，见 docs/ACP.md），支持多个 AI 代理实例之间的协作与任务分发。
- **跨平台安装分发**：通过 npm 包（reasonix）分发，兼容主流操作系统，提供简洁的命令行安装方式。
- **多种运行模式**：既支持单次指令执行的快速模式，也支持交互式长会话的守护模式，满足不同使用偏好。

## 技术架构

Reasonix 完全采用 Go 语言编写，利用其出色的并发模型和编译后单二进制分发的优势。在架构设计上，项目遵循以下关键思路：

首先，**会话状态管理**采用持久化存储设计。代理在运行期间会将对话历史、令牌统计和缓存索引写入本地存储，即使终端意外关闭，重启后也能无缝恢复会话状态，避免缓存失效。

其次，**缓存感知的提示组装层**是核心组件。该层负责将用户输入与系统提示、历史消息拼接为最终的请求负载，并智能地分析提示文本的前缀重复性，向 DeepSeek API 显式传递可复用的缓存块标识，确保服务端能最大程度命中 KV Cache。

再次，**模块化扩展架构**。核心代理引擎与扩展工具解耦，通过定义清晰的接口和事件钩子，第三方开发者可以独立开发新功能而无需修改主程序逻辑。整个项目还提供了完善的规格文档（docs/SPEC.md），对协议交互和内部数据结构进行了细致说明。

此外，项目通过 GitHub Actions 搭建了持续集成流程，确保每次代码提交后都能在多种操作系统上通过自动化测试，保障了项目的稳定性。

## 安装与使用

**安装**

Reasonix 以 npm 包形式分发，需要 Node.js 环境。执行以下命令进行全局安装：

```bash
npm install -g reasonix
```

安装完成后，你可以通过 `reasonix --version` 验证是否安装成功。

**使用**

首次启动时需要配置 DeepSeek API 密钥，通过环境变量或命令参数指定：

```bash
export DEEPSEEK_API_KEY="你的API密钥"
```

启动交互式会话：

```bash
reasonix
```

在交互界面中直接输入自然语言指令即可，例如：

```
> 帮我写一个 Go 函数，用于计算斐波那契数列，要求使用迭代方式避免栈溢出。
```

Reasonix 会流式输出生成的代码和解释。若希望使用会话扩展或协作协议，可参考官方文档中的 GUIDE 进行进阶配置，例如通过 `--profile` 参数加载不同场景的配置文件。

## 适用场景

- **日常编码辅助**：在终端内快速获取代码生成、重构建议、Bug 修复方案，无需切换上下文去浏览器中操作 Web 界面。
- **长时运行的后台任务代理**：利用前缀缓存优化，将 Reasonix 作为持续驻留的编程助手，同一会话内处理多个相关任务（如批量文件重构），节省大量 Token 费用。
- **多代理协作开发**：在复杂项目中，将不同代理实例分配给不同类型任务（如一个负责代码生成，另一个负责代码审查），通过 ACP 协议进行协调。
- **资源受限的服务器开发环境**：在仅有终端访问权限的远程开发机上，通过轻量级的 Go 二进制文件获得完整的 AI 编程支持，不依赖图形界面。

## 项目亮点

与市面上类似终端 AI 编程代理相比，Reasonix 的差异化优势主要体现在以下几点：

第一，**为缓存而生的设计哲学**。多数代理把「长上下文」简单理解为窗口长度，而 Reasonix 主动从工程层面维护前缀稳定性，这使得它在多轮对话场景下的单位成本显著低于同类产品，对高频使用者尤其友好。

第二，**Go 语言带来的性能优势**。相较于 Electron 或 Python 构建的代理工具，Reasonix 启动速度极快、内存占用极低，在性能受限的终端环境中表现出色。

第三，**面向协议与扩展的开放思路**。率先支持 ACP 协作协议，意味着它能融入更复杂的 AI 工具链生态，而非只是一个孤立工具；搭配规范的扩展文档，企业团队可以快速将其集成进自有研发流水线。
