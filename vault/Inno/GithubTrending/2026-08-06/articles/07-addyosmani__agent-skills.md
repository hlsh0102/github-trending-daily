## 项目概述

`agent-skills` 是一个面向 AI 编码代理（AI coding agent）的生产级工程技能集合，由 Google Chrome 团队工程总监 Addy Osmani 开源维护。该项目将资深软件工程师在构建软件时使用的工作流程、质量门禁和最佳实践进行系统化编码，打包成 AI 代理可以在开发各个阶段一致遵循的“技能模块”。

项目的核心洞察在于：当前 AI 编码工具已经能够生成代码，但往往缺乏工程纪律——跳过需求澄清、不做测试、忽略代码审查规范，最终产出质量不可控的代码。`agent-skills` 试图解决这一问题，通过将成熟的软件工程方法论（如规格先行、小步迭代、测试即证明）转化为 AI 代理可执行的命令集，让自动化编码过程也能遵循人类团队的质量标准。

项目的目标用户包括：依赖 AI 编程助手（如 Claude Code、GitHub Copilot 等）的个人开发者，希望在团队中推行 AI 辅助开发并保证代码质量的工程管理者，以及研究 AI 代理行为规范的技术人员。

## 核心功能

- **8 个开发周期斜杠命令**：覆盖从需求定义到上线的完整生命周期，包括 `/spec`（定义需求）、`/plan`（制定计划）、`/build`（增量构建）、`/test`（测试验证）、`/review`（代码审查）等，每个命令自动激活相应的技能模块。

- **技能自动激活机制**：AI 代理执行特定命令时，会加载对应的技能指令集，无需用户手动切换或提示，确保工作流程的一致性。

- **质量门禁内置**：将代码审查、测试覆盖等质量要求编码为代理的强制检查点，在合并请求前自动执行，减少人工监督成本。

- **工作流可视化映射**：通过清晰的开发周期图示（Define → Plan → Build → Verify → Review → Ship），帮助用户理解每个命令的定位和前后依赖关系。

- **轻量级配置**：项目以简洁的目录结构和命令配置为主，不依赖特定 AI 平台，可适配多数主流编码代理工具。

## 技术架构

项目采用纯 JavaScript 实现，核心设计思路是将“技能”抽象为可复用的命令模块。架构上分为三个层次：

**命令层**：定义 `/spec`、`/plan` 等斜杠命令的入口，负责解析用户意图并触发对应的技能模块。每个命令都有明确的目标描述（如“规格先于代码”）和适用阶段。

**技能层**：包含具体技能的指令模板，这些模板以结构化文本（如 Markdown）形式存在，描述了某个开发活动中应遵循的步骤、检查点和输出格式。技能内容参考了业界成熟的工程实践，例如将用户故事拆分为原子任务、强制编写测试用例等。

**适配层**：通过标准的命令输入输出接口与不同 AI 代理工具对接。这种设计使得技能集不绑定特定平台，用户可以根据自己的工具链自由组合。

架构上强调“约定优于配置”——技能的定义遵循一致的格式规范，便于扩展和维护。同时，项目采用 MIT 许可证，允许商业使用和二次开发。

## 安装与使用

要使用 `agent-skills`，请先将仓库克隆到本地：

```bash
git clone https://github.com/addyosmani/agent-skills.git
cd agent-skills
```

将项目中的技能目录配置到你的 AI 编码代理环境中。以常见的代理工具为例，通常需要在代理的配置文件中指定技能加载路径，或直接将仓库内容复制到代理的工作目录中。具体配置方式取决于你的工具，请参考对应工具的文档。

最小可用示例：在配置好技能的代理环境中，当你需要定义一个新功能需求时，只需输入：

```
/spec 实现用户登录功能
```

代理会自动加载规格定义技能，引导你逐步澄清使用场景、功能边界、验收标准，并生成结构化的 PRD 文档。随后可以依次使用 `/plan` 将需求拆分为小任务，用 `/build` 实现一个垂直切片，用 `/test` 验证功能正确性，最后通过 `/review` 进行代码审查。

## 适用场景

- **AI 辅助的敏捷开发**：团队将需求拆解、迭代开发、测试验证等环节交由 AI 代理按技能流程执行，人类工程师专注于架构决策和代码审查，提升开发效率。

- **代码质量标准化**：在多团队协作或外包场景中，通过强制 AI 代理遵循统一的质量门禁，减少因个人习惯差异导致的代码风格和测试实践不一致。

- **AI 代理行为研究**：开发者或研究者可以分析技能集如何约束代理行为，观察在不同命令下代理解决策策的变化，为设计更可靠的 AI 工程助手提供参考。

- **教育与培训**：将技能集作为教学材料，帮助开发者理解从需求到上线的完整工程流程，以及每一步应关注的质量要点。
