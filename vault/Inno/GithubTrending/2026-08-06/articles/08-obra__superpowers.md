## 项目概述

Superpowers 是一套面向编码代理（coding agents）的完整软件开发方法论，它建立在可组合的技能（skills）集合和初始指令之上，确保你的编码代理能够真正遵循这些方法论。该项目解决的核心问题是：当前编码代理（如 Claude Code、Cursor、Copilot 等）在生成代码时往往缺乏系统性的工程实践，容易跳过需求分析、设计评审和测试驱动开发等关键环节，导致产出代码质量不稳定、难以维护。Superpowers 的目标用户是重度依赖 AI 编码代理的开发者、技术团队以及希望将 AI 编码流程标准化的工程管理者。项目采用 MIT 许可证，目前已在 GitHub 上获得超过 26 万星标，社区关注度极高。

## 核心功能

- **强制需求澄清**：当编码代理检测到用户开始构建任务时，不会立即跳入代码编写，而是主动后退一步，询问用户真正想要达成的目标，通过对话逐步梳理出明确的需求规格。
- **分块规格展示**：将从对话中抽取出的需求规格以短小的块（chunks）形式呈现给用户，确保每块内容足够短小、便于用户真正阅读和理解，避免信息过载。
- **实施计划生成**：在用户确认设计后，代理会生成一份清晰、可执行的实施计划，该计划假设执行者是“一位热情但缺乏品味、没有判断力、缺乏项目上下文且厌恶测试的初级工程师”，以此确保计划足够具体且不依赖隐性知识。
- **TDD/YAGNI/DRY 纪律**：实施计划强调真实红绿测试驱动开发（TDD）、严格遵循 YAGNI 原则（不构建当前不需要的功能）以及 DRY 原则（避免重复代码），从方法论层面规范代理的编码行为。
- **子代理驱动开发**：用户批准后，代理会启动“子代理驱动开发”流程，让多个代理分别处理各个工程任务，并对它们的工作进行检查和评审，然后持续推进。这一过程往往能让代理连续自主工作数小时，极大提升开发效率。

## 技术架构

Superpowers 的技术架构围绕“技能”这一核心抽象展开。技能是一组高度内聚、可组合的能力单元，每个技能封装了特定类型的工程任务执行逻辑和最佳实践。项目通过一组初始指令将代理的基座行为导向为“先思考、后编码”，并确保代理在遇到任务时优先调用合适的技能组合。其设计思路类似于“协议 + 技能库”的模式：协议定义了代理与用户之间的交互流程（澄清需求、展示规格、确认计划、执行开发），而技能库则提供了具体工程任务（如测试编写、重构、代码评审）的可复用实现。整体架构强调可插拔性，用户可以根据需要引入或自定义技能，从而适配不同团队的工作流。此外，项目支持多种主流编码代理平台，包括 Claude Code、Antigravity、Codex App、Codex CLI、Cursor、Factory Droid、Gemini CLI、GitHub Copilot CLI、Kimi Code、OpenCode 和 Pi，体现了架构层面的高兼容性。

## 安装与使用

以 Claude Code 为例，快速启用 Superpowers 的基本步骤如下：

1. 从 GitHub 仓库获取项目文件（通过 `git clone https://github.com/obra/superpowers` 克隆或下载压缩包）。
2. 根据所选代理平台的说明，将 `skills` 目录下的导入脚本或技能文件复制到代理的有效技能目录中。例如，对于 Claude Code，可能需要执行项目提供的安装命令或手动将技能注册到 Claude Code 的配置目录。
3. 在代理会话中开始一个开发任务，代理会自动加载初始指令并展示 Superpowers 的交互流程。

最小可用示例：假设你要求代理“为我的 REST API 添加一个用户认证端点”。启用 Superpowers 后，代理不会直接编写代码，而是先询问你端点的具体行为（如认证方式、权限要求、错误处理等），然后分块展示需求规格，经你确认后生成实施计划，最后启动子代理完成编码、测试和评审。整个过程你只需要逐步确认或修改代理提出的方案。

各平台的具体安装路径和脚本略有差异，项目 README 中提供了针对每种代理的详细安装指引，建议按对应平台的说明操作。

## 适用场景

- **大型功能开发**：当任务涉及多个模块、需要完整的需求分析和实施规划时，Superpowers 能防止代理“边写边猜”，确保整体设计合理。
- **自动化批处理开发**：适合需要代理长时间自主工作的场景，例如批量生成接口实现、数据迁移脚本或内部工具，子代理驱动开发可以并行处理多个任务。
- **代码质量敏感型项目**：对于有严格测试覆盖率要求和架构规范的企业项目，Superpowers 强制 TDD 和代码评审流程，能显著降低技术债。
- **团队协作标准化**：当团队希望统一所有成员使用的编码代理行为，使其遵循相同的工程流程时，Superpowers 提供了一套可复制的实践框架。

## 项目亮点

与市面上其他“prompt 优化”类方案不同，Superpowers 不只是一堆提示词的集合，而是一套完整的、结构化的方法论体系。其最大差异化优势在于“过程强制”而非“结果建议”——通过初始指令约束代理必须经历需求澄清、规格确认、计划评审等步骤，而非仅输出代码。此外，它的子代理驱动开发模式在同类工具中较为先进，使得复杂任务可以被拆分、并行执行并自动完成代码审查，大幅提升自动化程度。同时，项目对多平台的支持广度（覆盖 11 种主流编码代理工具）也使其具备很强的生态适配能力。最重要的是，其设计哲学（假设执行者是“初级工程师” ）使得生成的实施计划对任何执行者都足够具体，从而保证了方法论的可复制性和一致性。
