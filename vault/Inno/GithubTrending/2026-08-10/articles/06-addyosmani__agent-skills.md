## 项目概述

Agent Skills 是一个面向 AI 编码代理（AI coding agents）的生产级工程技能集合。它解决的问题非常明确：当前 AI 编程工具虽然能生成代码，但往往缺乏资深工程师在真实软件开发流程中所遵循的工作规范、质量门禁和最佳实践。该项目将这一系列隐性知识显性化、结构化，并以 slash commands 的形式打包，使 AI 代理能在软件开发的每个阶段——从需求定义到最终发布——都保持一致的高水准行为。

项目目标用户是依赖 AI 编程助手进行日常开发工作的工程师、技术团队负责人，以及正在构建或定制 AI 编码代理工具链的开发者。无论你是想规范 Co-pilot 类工具的生成代码质量，还是想为自家团队的自研 AI 工作流注入工程纪律，该项目都提供了一个开箱即用的参考实现。

## 核心功能

- **八条开发生命周期命令**：提供 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等 8 个斜杠命令，分别对应需求定义、方案规划、增量编码、测试验证、代码审查和发布上线等关键环节，每条命令自动激活对应阶段所需的技能集合。

- **“规格先于代码”的工作流约束**：强制 AI 代理在设计阶段先产出明确的需求规格（PRD）和实现方案，避免直接跳入编码导致的返工与偏差。

- **小步原子化任务拆分**：通过 `/plan` 命令将大型开发任务拆分为小型、可独立验证的原子任务，降低每次变更的风险并提高可追踪性。

- **测试即证明的验证机制**：将写测试、跑测试作为验证代码正确性的核心手段，确保 AI 生成的代码不仅“能跑”，而且“有据可查”。

- **合并前质量门禁审查**：在代码合并之前执行系统性的质量检查与审查流程，拦截潜在缺陷、安全隐患和风格问题。

- **可适配的工程流程封装**：技能以结构化目录组织，便于团队根据自身工程规范进行修改与扩展，而非一成不变的教条。

## 技术架构

Agent Skills 采用纯 JavaScript 实现，本质上是一组精心编排的提示词模板、工作流定义和质量检查规则的集合。其核心设计思想是将“技能”抽象为可独立加载、按需激活的模块，每个技能模块封装了特定阶段所需的知识、步骤和输出格式。

在架构上，项目以软件开发全生命周期（SDLC）为主线，将六个关键阶段——定义（Define）、规划（Plan）、构建（Build）、验证（Verify）、审查（Review）、发布（Ship）——映射到对应的命令和目录结构（如 `/spec`、`/plan`、`/build` 等）。这种按阶段划分的目录设计使技能的组织与发现变得直观，AI 代理能根据当前任务状态快速定位并加载合适的技能集。

此外，项目还包含若干贯穿全流程的横切技能（如安全防护、性能优化等），这些技能不会被某一阶段独占，而是会在多个命令执行时被自动激活，确保最佳实践在各环节的一致性应用。

## 安装与使用

以下基于常见的 AI 编码代理工具（如 Claude Code、Cline 等）的使用方式，具体命令可能因工具而异。

1. **克隆仓库到本地代理工作目录**：
   ```bash
   git clone https://github.com/addyosmani/agent-skills.git your-agent-skills
   ```

2. **配置代理技能路径**：将项目路径添加到 AI 编码代理的技能加载目录中。以 Claude Code 为例，可在全局配置中指定技能目录：
   ```json
   {
     "skills_dir": "./your-agent-skills/skills"
   }
   ```

3. **开始使用**：在对话中直接调用命令。最小示例——定义一个新功能需求：

   ```
   用户输入：/spec 实现用户登录功能，支持邮箱密码验证
   ```

   AI 代理会加载 /spec 技能，按照“规格先于代码”的原则，首先输出产品需求文档（PRD），包含功能范围、用户故事、验收标准、边界条件等，待用户确认后再建议执行 `/plan` 进行任务拆解。

## 适用场景

- **个人开发者使用 AI 进行复杂项目开发**：当 AI 代理面对多模块、长周期的项目时，使用 Agent Skills 可避免其“边想边写”导致的结构混乱，让整个开发过程条理清晰、步步为营。
- **技术团队制定 AI 编码规范**：团队可以基于该项目参考或直接 fork，将自身的命名规范、代码风格、测试要求、安全清单等嵌入到技能中，形成团队统一的 AI 开发行为基线。
- **搭建企业级 AI 编码流水线**：对于 CI/CD 与 AI 代理深度集成的团队，可将 `/test`、`/review` 等命令引入流水线，实现 AI 生成代码的自动质量门禁。
- **研究和教学演示**：用于展示高效 AI 辅助开发的标准工作流，或作为 Prompt Engineering 中“结构化技能”设计的教学案例。

## 项目亮点

与其他类似的开源提示词库或 AI 开发规范项目相比，Agent Skills 的核心优势在于：

1. **覆盖完整生命周期的体系化设计**：市面上多数项目只关注单独的代码生成或测试环节，而该项目提供了从需求定义到生产发布的一站式全流程技能，强调各阶段的衔接与一致性。

2. **“技能”而非“提示词”的理念升华**：提示词只是一次性指令，技能则是一整套包含步骤、规则、质量门禁的完整工作流封装。这种抽象使 AI 代理能在复杂场景下保持专业水准，如同为每位开发者配备了一位随叫随到的资深工程导师。

3. **高度的可定制性与扩展性**：技能文件清晰分离，团队可轻松修改或新增技能以适配自身流程，而不需要改动核心框架。

4. **切实的生产级导向**：项目由 Google Chrome 团队工程总监 Addy Osmani 发起，作者拥有丰富的 Web 性能优化与工程管理经验，项目所沉淀的实践贴合真实工程项目需要，而非纸上谈兵。
