## 项目概述

Agency Agents 是一个面向 AI 编程助手（如 Claude Code、Cursor、Codex 等）的专家代理人格集合。该项目源于一个 Reddit 讨论帖，经过数月迭代发展而来，提供了一套精心设计的 AI 代理人格体系。每个代理都拥有明确的专业领域、鲜明的个性特征、标准化的处理流程以及经过实战验证的交付成果。

与常见的通用提示词模板不同，Agency Agents 中的每一个代理都不是简单的“角色扮演”设定，而是围绕特定任务场景构建的完整工作系统。项目旨在解决 AI 辅助编程中“会而不精”的痛点，让开发者能够按需调用高度专业化的 AI 专家，覆盖从前端开发到社区运营、从创意注入到质量审查的广泛需求。

项目采用 MIT 许可证开源，目前已在 GitHub 上获得超过 14 万星标，日均新增关注超过 800 次，是 AI Agent 领域备受瞩目的开源项目之一。

## 核心功能

- **专家化代理体系**：提供覆盖前端开发、Reddit 社区运营、创意设计、质量审查等多个领域的专业代理，每个代理均具备深度的领域知识，而非浅层的通用对话技巧。
- **人格化交互体验**：每个代理拥有独特的交流风格和思维方式，使其在协作时能提供差异化视角，例如“Whimsy Injector”负责注入创意灵感，“Reality Checker”则专注于可行性验证。
- **流程化任务执行**：代理内置标准化的处理流程和交付规范，确保从需求接受到最终产出都遵循最佳实践，输出结果可量化、可验证。
- **跨平台无缝集成**：支持通过官方配套应用（Agency Agents App）一键安装到 Claude Code、Cursor、Codex、Gemini、Osaurus 等多种主流 AI 编程环境，无需手动克隆仓库或编写脚本。
- **持续更新的代理库**：项目保持高频迭代，持续新增代理类型并优化现有代理的性能，确保代理能力与最新技术趋势同步。
- **自动化版本管理**：官方原生应用支持 macOS、Linux 和 Windows，可自动更新代理库，免去手动维护的繁琐过程。

## 技术架构

Agency Agents 本质上是一个基于 Shell 脚本和结构化 Markdown 描述文件的代理定义集合。其技术架构具有以下几个鲜明特点：

**声明式代理定义**：每个代理的“人格”、专业知识、工作流程都以结构化的配置文件形式存在，这种方式使得代理的创建、修改和复用变得异常灵活。开发者可以像编写文档一样定义代理的行为模式，而不需要深入了解复杂的编程逻辑。

**插件式安装机制**：项目设计了一套与 AI 编程工具兼容的安装协议。通过官方桌面应用，可以将代理配置自动写入各个目标工具的配置目录，实现零代码接入。这种设计将代理生态与应用生态解耦，使得同一套代理可以运行在不同的 AI 工具之上。

**分层组合模式**：代理之间并非孤立存在，而是可以根据任务需要组合使用。例如，一个项目可以同时引入“Frontend Wizard”负责界面实现，引入“Reality Checker”进行可行性验证，形成类似于真实 agency 的协作网络。

**脚本驱动的自动化和可持续集成**：底层使用 Shell 脚本实现代理库的版本控制、依赖检查和环境配置等基础能力，保证了项目在各种 Unix 环境下的可移植性和安装的便捷性。

## 安装与使用

安装 Agency Agents 有以下两种方式：

**方式一：使用官方应用（推荐）**

1. 访问 [Agency Agents 官方应用发布页](https://github.com/msitarzewski/agency-agents-app/releases/latest)，下载对应操作系统（macOS、Linux、Windows）的安装包。
2. 安装并启动应用，浏览完整的代理名册。
3. 选择需要安装的代理，一键写入 Claude Code、Cursor、Codex 等目标工具。
4. 应用会自动更新，确保代理库始终处于最新状态。

**方式二：手动克隆**

```bash
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
# 根据 README 指引将代理配置文件复制到目标 AI 工具的配置目录
```

**最小使用示例**：以 Claude Code 为例，安装若干代理后，在使用 Claude Code 进行开发时，可以通过唤起相应的代理名称来激活其专属工作流程。例如，在需要快速搭建一个 React 组件时，可以激活“Frontend Wizard”代理，其会自动按照预设的代码风格、组件结构和测试规范输出成果。

## 适用场景

- **跨领域项目开发**：当项目涉及前端、后端、设计、文案等多方面能力时，可以利用不同代理各司其职，模拟一个真实 Agency 团队的分工协作。
- **质量把关与代码审查**：引入“Reality Checker”等审查类代理，可在开发过程中对 AI 产出内容进行严格检验，确保技术方案的可行性和代码质量。
- **创意头脑风暴与策划**：借助“Whimsy Injector”等创意型代理，为产品设计、营销文案或用户界面注入新颖想法，打破思维惯性。
- **社区运营与内容创作**：利用“Reddit Community Ninja”等代理，辅助生成讨论话题、回复社区反馈，提升内容生产效率。

## 项目亮点

Agency Agents 在同类 AI Agent 管理项目中脱颖而出，主要得益于以下几点差异化优势：

- **从真实需求中诞生**：项目源于社区讨论，所有代理的设定都基于实际开发痛点，而非理论构想，因此每个代理都具备很强的实战属性。
- **人格即功能**：不只是简单地预设角色，而是将人格特质、专业技能与交付流程深度绑定，使得代理输出具有高度的一致性。
- **零门槛接入**：官方应用支持图形化操作和自动更新，极大降低了安装和维护成本，即使非技术用户也能轻松上手。
- **活跃的社区生态**：项目不仅自身迭代迅速，还形成了活跃的贡献者社区，持续有新的代理创意被采纳和实现。
- **跨平台兼容性**：通过标准化的代理定义格式，实现了对主流 AI 编程工具的广泛兼容，打破了特定工具的平台锁定。
