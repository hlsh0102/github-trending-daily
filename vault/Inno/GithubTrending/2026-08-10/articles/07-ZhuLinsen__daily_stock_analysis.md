## 项目概述

daily_stock_analysis 是一个基于 AI 大模型的智能股票分析系统，覆盖 A股、港股、美股、日股、韩股和台股六大市场。它通过接入多源行情数据与实时新闻资讯，借助大语言模型的语义理解能力，自动生成包含技术面、基本面、消息面等多维度信息的「决策仪表盘」，并通过企业微信、飞书、Telegram、Discord、Slack 或邮箱等渠道定时推送至用户终端。

项目主要解决个人投资者在自选股跟踪中的信息过载问题：无需手动刷新行情页面、翻阅大量新闻公告，系统会每日自动汇聚并提炼关键信息，以结构化的卡片形式呈现，帮助用户快速掌握持仓或关注标的的动态变化。目前项目在 GitHub 上已获得超过六万 Star，属于社区中活跃度较高的开源量化分析工具。

## 核心功能

- **多市场覆盖**：支持 A股、港股、美股、日股、韩股、台股六大市场的自选股分析，用户可按需配置关注的股票代码。
- **多源数据聚合**：接入行情数据、实时新闻、公告事件等多类数据源，确保分析结果既有价格走势也有消息面支撑。
- **AI 决策看板生成**：利用大语言模型对数据进行分析归纳，自动生成包含趋势研判、风险提示、关注事件等内容的可视化决策仪表盘。
- **多渠道自动推送**：内置企业微信、飞书、Telegram、Discord、Slack、邮箱六大通知渠道，用户可自由绑定接收终端。
- **定时自动运行**：支持通过 GitHub Actions 或 Docker 实现完全免费或低成本的每日定时执行，无需自行搭建服务器。
- **零门槛配置**：提供详细的中英文文档和示例配置，通过环境变量即可完成个性化设置，无须修改代码。

## 技术架构

项目采用 Python 为核心开发语言，整体架构围绕「数据采集—信息提炼—报告生成—消息分发」四个环节设计。

在数据层，系统通过异步 HTTP 请求对接多个公开行情接口和新闻源，以统一的数据模型标准化不同市场的行情与资讯数据。在分析层，系统调用大语言模型 API，将原始行情数据、涨跌幅、技术指标、相关新闻标题等结构化信息拼装为提示词，由模型生成自然语言的投资分析摘要。在分发层，系统将模型输出结果渲染为各类聊天工具支持的消息卡片（如企业微信的 markdown 消息、Telegram 的 HTML 消息），通过各自 Webhook 或 Bot API 推送给用户。

需要特别说明的是，系统支持大模型服务的通用接入，用户可以选择 OpenAI 兼容接口、国内主流模型服务商或者本地部署的模型，这一设计在降低使用成本的同时，也提高了数据隐私的可控性。此外，项目支持 GitHub Actions 的定时触发方式，用户只需将仓库 fork 到自己的账号下并配置 Secrets，即可实现每日自动运行且不产生任何服务器费用；对于有自建服务器需求的用户，项目也提供了 Docker 镜像，支持一键部署。

## 安装与使用

**方式一：GitHub Actions（零成本推荐）**

1. Fork 本项目到自己的 GitHub 账号。
2. 在仓库 Settings → Secrets and variables → Actions 中配置必要的环境变量，包括大模型 API 密钥、股票代码列表、推送 Webhook 地址等。
3. 在仓库的 Actions 页面启用 Workflow，系统默认按每日定时任务运行。

**方式二：Docker 部署**

```bash
docker run -d --name stock-analysis \
  -e LLM_API_KEY=your_key \
  -e STOCK_CODES=SH600000,HK00700,USAAPL \
  -e PUSH_CHANNEL=telegram \
  -e TELEGRAM_BOT_TOKEN=your_bot_token \
  -e TELEGRAM_CHAT_ID=your_chat_id \
  zhulinsen/daily_stock_analysis
```

**方式三：本地运行**

```bash
git clone https://github.com/ZhuLinsen/daily_stock_analysis.git
cd daily_stock_analysis
cp .env.example .env  # 编辑 .env 填入自己的配置
pip install -r requirements.txt
python main.py
```

配置完成后，系统将按照设定的时间点自动抓取数据、调用模型进行分析，并将结果推送到指定渠道。详细的环境变量说明与各推送渠道的配置指引，可参考项目文档中心。

## 适用场景

- **个人投资者日常盯盘**：用户在多个市场拥有自选股，希望每天开盘前或收盘后能快速获得一份整合了价格变动、新闻事件和趋势判断的概要报告，系统即可准时推送到手机。
- **量化交易辅助决策**：量化研究者或程序化交易员可将系统作为信息预处理的辅助模块，模型生成的文本摘要可作为交易信号之外的参考因子。
- **资讯聚合与舆情监控**：对于需要持续跟踪特定公司或行业动态的从业者，系统将分散在多个信息源的相关新闻实时汇总并提炼要点，提高信息获取效率。
- **免费自动化实践教学**：项目完整展示了如何以极低成本（甚至零成本）实现一个覆盖数据获取、AI 处理、消息推送全链路的自动化应用，适合作为个人开发者的学习范例。

## 项目亮点

与其他股票分析工具相比，daily_stock_analysis 的差异化优势主要体现在三个方面：

第一，**使用成本极低**。项目设计之初就考虑了个人用户的实际负担，借助 GitHub Actions 的免费额度或 Docker 自托管，用户无需购买服务器即可获得稳定的每日定时分析服务；同时，大模型接入层兼容多种服务商，用户可以选择免费或低价的模型接口。

第二，**推送渠道丰富且开箱即用**。市面上多数工具只支持单一通知方式，而本项目一次性适配了六种主流通讯平台，覆盖了国内外的办公协作和社交软件，用户无需额外开发即可接入自己常用的工具。

第三，**多市场统一分析**。跨越六大股票市场的支持在同类开源产品中较少见，尤其对同时关注两岸三地和美日韩市场的用户来说，一个配置即可覆盖所有关注标的，省去了在多个平台间切换的麻烦。
