## 项目概述

ComfyUI 是一款面向内容创作者和开发者的模块化 AI 引擎，以图/节点（Graph/Nodes）为核心交互方式，提供强大的扩散模型图形界面、API 和后端服务。它解决了传统 AI 生成工具在流程灵活性、可控性和可扩展性上的不足——用户不再受限于固定的操作流程，而是可以通过连接不同的节点，自由编排从模型加载、提示词处理、采样生成到后处理的全链路流程。

项目定位于专业用户和开发者，尤其适合需要对生成过程进行精细控制、批量处理或集成到自有系统中的场景。凭借高度可定制的架构和活跃的社区生态，ComfyUI 已成为 AI 生成领域最受欢迎的开源框架之一，目前 GitHub 星标已超过 12.5 万。

## 核心功能

- **可视化节点编辑**：通过拖拽和连接节点构建工作流，直观呈现数据流向，支持保存和复用完整流程。
- **模块化架构**：模型加载、采样器、解码器、图像后处理等均为独立节点，可按需组合，轻松扩展自定义节点。
- **多模型支持**：兼容 Stable Diffusion 系列（SD1.5、SDXL、SD3 等）以及 Flux 等主流扩散模型，支持 LoRA、ControlNet、T2I-Adapter 等扩展组件。
- **高性能后端**：针对显存优化和低显存运行设计了多种优化策略，支持 CPU 推理和 GPU 加速，并可在低配置硬件上运行。
- **API 与命令行接口**：提供完整的 HTTP API 和命令行工具，支持远程调用、批量生成以及与外部程序（如 Python 脚本）集成。
- **异步与队列管理**：内置任务队列和异步执行机制，支持并发生成、中断/恢复操作，满足批处理和生产级需求。

## 技术架构

ComfyUI 采用前后端分离的设计，整体以 Python 实现，核心逻辑基于图执行引擎。前端为基于 WebSocket 和 Canvas 的浏览器界面，通过 JSON 定义节点图结构；后端则负责解析图、调度任务并调用 PyTorch 等深度学习框架执行计算。

架构上的关键特性包括：

- **图执行引擎**：将用户构建的节点图转换为可执行的计算图，支持惰性求值和动态拓扑排序，能够高效处理复杂依赖关系。
- **内置系统**：提供模型管理、采样器、CLIP 文本编码、VAE 解码等基础节点，同时允许通过 Python 插件机制添加第三方自定义节点，形成庞大的扩展生态。
- **跨平台兼容**：支持 Windows、Linux 和 macOS，并提供预编译的安装包，同时可运行于云端 GPU 环境或本地工作站。
- **性能优化**：针对显存有限的环境实现了模型部分加载（offloading）和顺序处理策略，并针对不同 GPU 架构（NVIDIA、AMD、Apple Silicon）进行适配。

## 安装与使用

### 安装

推荐使用 Git 克隆并安装依赖：

```bash
git clone https://github.com/Comfy-Org/ComfyUI.git
cd ComfyUI
pip install -r requirements.txt
```

如需启用 GPU 加速，请根据自身环境安装对应的 PyTorch 版本（支持 CUDA、ROCm 或 MPS）。项目也提供 Windows 独立安装包，可直接从 Release 页面下载使用。

### 最小使用示例

启动服务：

```bash
python main.py
```

浏览器访问 `http://127.0.0.1:8188` 打开工作台。默认加载一个最基础的文生图流程：将模型加载节点、正向提示词节点、采样器节点和保存图像节点连接即可生成图片。

通过 API 调用（Python 示例）：

```python
import json
import requests

workflow = {...}  # 从工作台导出的 JSON 定义

response = requests.post(
    "http://127.0.0.1:8188/prompt",
    json={"prompt": workflow}
)
```

## 适用场景

- **AI 艺术创作**：艺术家和设计师可利用节点编排高效探索不同风格组合（提示词、LoRA、ControlNet 叠加），批量生成设计稿或概念图。
- **工作流自动化**：内容团队将反复使用的生成流程固化为模板，通过 API 集成到内容生产管道，实现自动出图、海报生成等任务。
- **科研与模型开发**：研究人员可灵活组合采样器和模型变体，进行对照实验、模型微调效果评估或生成数据集。
- **教育培训**：作为学习扩散模型原理的直观工具，教师和学生可通过可视化图结构理解各组件的作用和协作方式。

## 项目亮点

- **无与伦比的灵活度**：几乎所有生成参数和中间流程都可被显式编排，支持任何可以想象的工作流，远超传统 UI 的固定模式。
- **高显存效率**：在相同硬件条件下，通常能运行比其他框架更复杂的模型或更大的 batch，对低显存用户友好。
- **活跃的生态与社区**：拥有庞大的自定义节点库，涵盖动画、放大、修复、视频生成等前沿功能，社区持续贡献新能力。
- **生产级集成能力**：完善的 API 设计使得从交互式创作平滑过渡到离线批量生成，支持与现有生产系统无缝对接。
- **持续演进**：项目维护活跃，社区贡献度高，持续快速跟进开源模型社区的最新进展。
