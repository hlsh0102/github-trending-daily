## 项目概述

PentAGI（Penetration testing Artificial General Intelligence）是一个基于 Go 语言构建的完全自主 AI 智能体系统，专注于执行复杂的渗透测试任务。项目的核心目标是将大语言模型（LLM）的推理能力与真实环境中的安全测试工具链相结合，让 AI 智能体能够在受控环境中自主规划、执行并推进渗透测试流程。

传统渗透测试高度依赖人工经验，测试人员需要手动完成信息收集、漏洞探测、利用尝试和结果整理等多个阶段，耗时长且对技能要求高。PentAGI 试图通过多智能体协作的方式自动化这一过程：由 AI 负责策略制定与任务分解，由工具执行层负责实际命令调用，并将结果反馈给智能体进行下一步决策。它的目标用户包括安全研究人员、渗透测试工程师、红队成员，以及希望研究自主智能体在安全领域落地方式的 AI 开发者。

项目采用 MIT 许可证开源，目前在 GitHub 上已获得超过 2.4 万颗星标，社区活跃度较高。

## 核心功能

- **全自主任务执行**：智能体能够根据给定目标自主规划渗透测试步骤，从信息收集到漏洞验证形成完整闭环，无需逐条人工指令。
- **多智能体协作与监督**：系统内置智能体监督机制，通过角色分工与相互校验降低单一模型产生错误决策的风险。
- **工具链集成**：集成常见的渗透测试与侦察工具，智能体可调用外部命令并在沙箱环境中获取执行结果。
- **多 LLM 提供商支持**：兼容 OpenAI、Anthropic、Google Gemini、AWS Bedrock 以及本地部署的 Ollama，用户可按需切换模型后端。
- **容器化隔离执行**：通过 Docker 为智能体提供受限的运行环境，使 AI 能够获得容器级操作能力而不直接暴露宿主机。
- **多实例与 API 访问**：支持通过 `tenant_id` 运行多个独立实例，并提供 API 接口以便与外部系统集成。

## 技术架构

PentAGI 使用 Go 作为主要开发语言，整体采用面向服务的架构设计。系统大致可分为几个层次：负责与 LLM 交互的模型接入层、负责任务规划与状态管理的智能体编排层、负责实际命令执行的工具与沙箱层，以及面向用户的 Web 界面与 API 层。

在模型接入方面，项目通过统一的提供商抽象屏蔽了不同 LLM 服务之间的接口差异，使得切换模型后端只需调整配置。在智能体设计上，系统并非依赖单一智能体串行工作，而是引入监督与协作机制，让不同角色的智能体在任务执行过程中相互检查，从而提升复杂任务下的稳定性。

执行环境方面，PentAGI 将智能体的操作限制在 Docker 容器内，通过容器隔离避免 AI 直接接触宿主机资源。这一设计既满足了渗透测试对真实工具环境的需求，也在一定程度上控制了自主执行带来的安全风险。部署层面，项目以 Docker 容器方式分发，简化了依赖管理与环境搭建。

## 安装与使用

PentAGI 以容器化方式部署，通常需要预先安装 Docker 与 Docker Compose。基本流程如下：

1. 克隆仓库：

   ```bash
   git clone https://github.com/vxcontrol/pentagi.git
   cd pentagi
   ```

2. 准备环境变量文件，配置 LLM 提供商的 API Key 与相关参数（例如 OpenAI 或 Anthropic 的密钥，或指向本地 Ollama 服务的地址）。

3. 使用 Docker Compose 启动服务：

   ```bash
   docker compose up -d
   ```

4. 待服务启动后，通过浏览器访问本地暴露的 Web 界面进行登录，并在界面中创建渗透测试任务、查看智能体的执行过程与结果。

若需要让智能体访问 Docker 环境，可按文档中的说明配置受限的 Docker 访问方式，避免直接挂载宿主机 socket。对于多租户场景，可通过设置 `tenant_id` 在同一套部署中运行多个相互隔离的实例。

需要注意的是，具体端口、环境变量名称与配置项会随版本变化，实际部署时应以仓库 README 与文档为准。

## 适用场景

- **自动化渗透测试**：在授权范围内对目标系统进行自主侦察与漏洞验证，减少重复性人工操作。
- **安全研究与教学**：作为研究自主智能体在真实安全任务中表现的实验平台。
- **红队演练辅助**：在受控演习环境中作为辅助角色，快速完成初步信息收集与攻击面梳理。
- **AI 智能体开发参考**：为研究多智能体协作、工具调用与沙箱执行提供可复用的工程实现。

## 项目亮点

与多数将 LLM 用于对话式安全问答的工具不同，PentAGI 的定位是端到端的自主执行系统，强调真实环境中的工具调用与任务闭环。其差异化体现在三个方面：一是通过多智能体监督机制提升复杂任务的可靠性；二是以容器隔离方式在获得真实操作能力的同时控制风险；三是提供对多种 LLM 提供商的原生支持，包括本地模型，兼顾了灵活性与数据可控性。此外，Go 语言实现的单体服务在部署和资源占用上相对轻量，配合 Docker 分发降低了上手门槛。
