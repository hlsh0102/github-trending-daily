## 项目概述

God's Eye View（原名 WorldView）是一个运行在浏览器中的“间谍卫星模拟器”，但它所呈现的数据全部来自公开渠道。项目将摄影测量级别的三维地球作为底图，把航班、船舶、卫星、地震、交通流量以及公共摄像头等实时开源情报（OSINT）数据叠加在同一空间上下文中，让使用者在类似情报指挥中心的界面里观察真实世界的动态。

传统上，获取和关联这类数据需要分别访问多个专业平台，并在二维地图和表格之间来回切换。God's Eye View 解决的问题是把分散的公开数据源聚合到一个统一的三维可视化环境中，降低空间情报的观察门槛。它的目标用户包括对 OSINT 感兴趣的普通用户、记者、研究人员、地理信息爱好者，以及需要快速掌握全球态势的开发者与分析师。

## 核心功能

- **摄影级三维地球**：以高保真纹理和地形渲染全球表面，支持自由缩放、旋转与视角切换，作为所有数据的统一空间参考。
- **多源实时图层**：在同一地球上叠加实时航班、船舶、卫星轨道、地震事件、交通状况和公共摄像头画面，各图层可独立开关。
- **语音免手控制**：集成实时 AI 智能体，通过自然语言语音指令完成视角跳转、图层切换和目标检索，无需键盘鼠标操作。
- **公开数据接入**：所有图层均对接公开数据源，用户可自行核查来源，不依赖非公开或私有数据。
- **零密钥启动**：项目设计为无需预先申请 API 密钥即可启动，降低首次体验的配置成本。
- **CI 与持续集成**：仓库内置 GitHub Actions 工作流，保证主分支代码的基本可用性。

## 技术架构

项目主体使用 JavaScript 编写，运行于浏览器端。三维地球的渲染建立在 WebGL 图形管线之上，通过分层渲染将底图与动态图层解耦，使各数据源可以独立更新而不影响整体性能。空间数据以统一的地理坐标系统接入，确保不同来源的航班、船舶和卫星轨迹能在同一坐标系中对齐。

前端采用组件化组织各数据图层，每个图层独立管理自己的数据获取、解析与渲染生命周期。语音控制部分通过实时 AI 智能体将自然语言指令解析为对图层和相机的操作，形成一个从语音到视图状态的闭环。整体架构偏向“数据源可插拔”，新增一类公开数据只需要实现对应的图层适配器，而不必改动地球渲染核心。

## 安装与使用

项目提供两种上手方式。最简路径是通过 Pinokio 安装：在 Pinokio 中搜索 `github-com-bilawalsidhu-gods-eye-view` 或访问其应用页面，按提示一键安装并启动，无需手动配置 API 密钥。

如果希望本地运行，可从 GitHub 克隆仓库，确认本机已安装 Node.js，然后按常规 JavaScript 项目流程执行依赖安装与开发服务器启动：

```bash
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm install
npm run dev
```

启动后在浏览器中打开本地开发地址即可看到三维地球。首次加载会请求各公开数据源的实时数据，具体图层可用性和刷新频率取决于对应数据源的可访问性。语音控制功能通常需要授予浏览器麦克风权限。

## 适用场景

- **OSINT 观察与教学**：用于演示公开数据的可获取性与关联方式，适合新闻院校、研究机构和安全培训场景。
- **全球态势感知**：在单一视图中同时查看航班、船舶和地震等信息，快速建立对某一区域的整体理解。
- **地理信息可视化开发**：作为三维地球与多源实时图层集成的参考实现，供开发者学习数据适配与渲染分层思路。
- **内容创作与演示**：该项目是同名 YouTube 系列的技术底座，适合制作空间数据相关的视频与交互演示。

## 项目亮点

与常见的二维地图聚合工具相比，God's Eye View 的差异在于把“模拟器体验”和“真实公开数据”结合：界面借鉴了间谍卫星的操作感，但每一个数据点都可以追溯到公开来源。三维地球比二维地图更能表达卫星轨道、航空高度和船舶航向等具有空间结构的信息。

项目在 2026 年 8 月同时登上 GitHub Trending 日榜和周榜第一，并在 Product Hunt 获得当日第八名，受到 JavaScript 创造者 Brendan Eich 的公开评价。其语音免手控制由实时 AI 智能体驱动，使得在大屏或演示环境下操作更为自然。项目还实现了无需 API 密钥即可启动，显著降低了初次使用的门槛。
