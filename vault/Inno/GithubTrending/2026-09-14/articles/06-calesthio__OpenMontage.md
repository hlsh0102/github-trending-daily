## 项目概述

OpenMontage 是一个开源、智能体（agentic）驱动的视频制作系统，目标是把 AI 编程助手转化为完整的视频制作工作室。传统视频制作流程需要在剪辑软件、音频工具、动效脚本和素材管理之间反复切换，且高度依赖人工操作；OpenMontage 通过让编程助手直接调用一整套视频生产管线，把「写代码」和「做视频」合并到同一个对话式工作流中。

项目面向希望借助 AI 助手批量生产视频的开发者和内容团队，尤其是那些已习惯用 AI 编程工具处理文本、代码任务，但希望把能力延伸到视频产出环节的用户。它并不要求用户掌握专业剪辑软件，而是通过提示词驱动一系列预定义的制作流程完成从素材到成片的转换。

## 核心功能

- **12 条生产管线**：覆盖从短视频、解说、产品演示到字幕、配音等常见视频类型的标准化制作流程，用户可根据目标选择对应管线。
- **100+ 工具集**：提供视频剪辑、音频处理、字幕生成、画面合成、格式转换等可直接被智能体调用的工具。
- **700+ 智能体技能与制作知识文件**：把视频制作领域知识结构化，供 AI 助手在规划与执行时参考，提升生成结果的稳定性。
- **从已有视频起步**：支持粘贴一个已有视频作为参照，让系统分析其风格与结构，再据此生成新内容。
- **多供应商支持**：通过 Provider 机制接入不同的模型与服务，用户可按需切换底层能力。
- **提示词驱动工作流**：内置可直接尝试的示例提示词，降低上手门槛。

## 技术架构

OpenMontage 以 Python 为主要实现语言，整体围绕「智能体 + 管线 + 工具」三层结构设计。

管线层定义了视频生产的标准步骤，把复杂的制作过程拆解为可被智能体逐步执行的阶段；工具层封装了具体操作能力，作为智能体可调用的原子接口；知识层则通过大量技能与制作知识文件，为智能体提供决策依据，使其在编排流程时不至于偏离视频制作的实际逻辑。

这种设计的核心思路是把领域知识显式化，而不是完全依赖模型隐式推理。项目还提供了 Provider 抽象，使不同模型和外部服务可以替换接入，避免绑定单一供应商。许可证为 AGPL-3.0，属于强 copyleft 开源协议。

## 安装与使用

由于 README 未展示完整安装命令，以下为基于项目形态的常见做法概述：

1. 克隆仓库：
   ```bash
   git clone https://github.com/calesthio/OpenMontage.git
   cd OpenMontage
   ```
2. 准备 Python 环境并安装依赖（建议使用虚拟环境）：
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. 按 `docs/PROVIDERS.md` 配置所需的服务供应商与密钥。
4. 在受支持的 AI 编程助手中打开该仓库，参考 `AGENT_GUIDE.md` 让助手加载技能与知识文件。
5. 最小可用示例：向助手输入类似「用产品演示管线，基于我提供的脚本生成一段 30 秒视频」的提示词，由助手按管线步骤调用工具完成制作。

实际命令与配置请以仓库内文档为准。

## 适用场景

- **内容团队的批量视频生产**：借助标准管线稳定产出格式统一的解说或演示视频。
- **开发者制作技术演示**：用代码仓库本身作为上下文，生成产品介绍或功能演示视频。
- **风格迁移与再创作**：粘贴已有视频作为参照，快速产出风格一致的新内容。
- **AI 助手能力扩展实验**：研究智能体在复杂多步骤生产任务中的编排与执行表现。

## 项目亮点

与单一功能的视频生成脚本相比，OpenMontage 的差异在于把视频制作拆解为可复用的管线和工具，并用大量领域知识文件约束智能体行为，使输出更可控、更贴近真实制作流程。它并不试图替代专业剪辑软件，而是把已有的 AI 编程助手变成一个可以调度的视频制作中枢。多供应商设计与 AGPL-3.0 开源许可，也便于社区在此基础上扩展新的管线和工具。
