🚀 GitHub Trending 今日速报 (2025/07/26)

1️⃣ **destructive_command_guard** 🛡️
Rust 编写的高性能钩子程序，拦截 AI 编程助手误触 `rm -rf`、`git push --force` 等危险命令。给 AI Agent 上道保险。

2️⃣ **DesktopCommanderMCP** 💻
让 Claude 等 AI 助手直接控制终端、搜索文件、编辑代码。MCP 协议加持，AI 从“建议者”变成“执行者”。

3️⃣ **Vibe-Trading** 📈
一句话搞定自动化交易。支持多交易所、内置策略模板，还带 React 可视化仪表盘。个人投资者的量化入门利器。

4️⃣ **Prefect** 🔧
Python 工作流编排框架。数据管道编排、任务重试、UI 监控一应俱全。数据工程与 MLOps 的靠谱选择。

5️⃣ **awesome-llm-apps** 🧩
100+ 个可本地运行的 AI Agent & RAG 应用示例。克隆即用，适合快速实验与二次开发。

6️⃣ **claude-cookbooks** 📘
Anthropic 官方的 Jupyter Notebook 合集。覆盖 Prompt 工程、API 调用、代码生成等技巧。Claude 高级用法宝典。

7️⃣ **home-assistant/core** 🏠
开源家庭自动化平台，本地控制+隐私优先。支持 2000+ 设备，树莓派即可部署。DIY 智能家居首选。

8️⃣ **project-nomad** 🌍
离线优先的知识与教育服务器。内置 AI 引擎、离线知识库，浏览器访问。应急场景与偏远地区的数字中枢。

9️⃣ **background-agents** 🤖
后台编码代理系统。在不中断你当前工作时，让 AI 在后台自动写代码、修 Bug。支持 Slack、GitHub PR、Linear 接入。

🔟 **Wand-Enhancer** 🎮
开源互操作性工具，专为 Wand 应用增强。提供本地配置管理、主题定制与自动化兼容适配。注重安全和隐私。
