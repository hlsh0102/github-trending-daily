## 项目概述

Background Agents（Background-Agents）是一个开源的**后台编码代理系统**，灵感来源于 Ramp 公司内部使用的 Inspect 系统。该项目旨在提供一个托管式的后台编码助手，让你在处理其他事务的同时，让代理在后台自动完成编码任务。

对于开发团队而言，日常工作中常常需要在多个任务之间切换，或者在等待代码审查、构建、测试时打断思路。Background Agents 正是为解决这类痛点而生——它像一个“隐形协作者”，能够接收任务并自动在隔离环境中执行，目标用户包括个人开发者、开源项目维护者，以及需要自动化代码协作流程的中小型开发团队。

## 核心功能

- **后台任务执行**：代理可以在你专注于其他工作时，异步处理代码编写、修复、重构等任务，并通过通知返回结果。
- **完整的开发环境访问**：代理运行在独立的沙盒环境中，支持 Node.js、Python、git、浏览器自动化以及 VS Code 等工具。
- **多渠道接入**：可通过 Web UI、Slack 消息、GitHub Pull Request、Linear 工单或自定义 Webhook 触发任务，实现全工作流覆盖。
- **多人实时协作**：支持多人同时在同一个任务或终端会话中实时协作，适合团队配对编程或故障排查。
- **智能代码提交**：代理创建的 Pull Request 能够正确归属提交人，即发起任务的用户会显示为 PR 作者，而非系统默认用户。
- **定时与事件触发**：支持通过 cron 表达式定时执行任务，也可响应 Sentry 告警、Webhook 事件自动触发工作流。
- **并行子任务**：允许代理将复杂任务拆分为多个子任务，在独立的沙盒中并行执行，加速大规模代码变更。

## 技术架构

项目基于 **TypeScript** 构建，采用单租户部署模型，适合组织内部使用。其架构核心包括以下几个层次：

1. **控制平面**：负责接收来自各个渠道的任务请求，管理任务队列，生成短期 GitHub 安装令牌，并协调沙盒的创建与销毁。
2. **沙盒环境**：每个任务运行在独立的隔离环境中，包含完整的操作系统级开发工具链（Node.js、Python、git、browser 等），确保任务互不干扰。
3. **Git 凭证桥接**：控制平面通过自定义 git credential helper 将短期令牌安全地下发到沙盒，沙盒在需要执行 git 操作时主动请求令牌，实现安全且透明的身份认证。
4. **AI 模型集成**：支持灵活切换底层大语言模型，包括 Anthropic Claude、OpenAI Codex（通过 ChatGPT 订阅）以及 OpenCode Zen。

这种设计使得代理既能获得执行代码所需的完整权限，又避免了长期凭据泄露的风险，是安全性与灵活性之间的平衡。

## 安装与使用

由于项目为单租户部署，安装步骤如下：

1. **创建 GitHub App**：在 GitHub 上为你的组织创建一个 GitHub App，授予所需权限（如读写仓库、创建 PR 等），并安装到目标仓库。
2. **克隆仓库**：`git clone https://github.com/ColeMurray/background-agents.git`
3. **配置环境变量**：配置 `GITHUB_APP_ID`、`GITHUB_APP_PRIVATE_KEY` 等必要变量，并设置 AI 模型的 API Key。
4. **启动服务**：按照项目文档启动控制平面和沙盒服务。

最小可用示例——通过 Webhook 触发后台任务：

```bash
# 发送 POST 请求触发任务
curl -X POST https://your-instance.example.com/webhook \
  -H "Content-Type: application/json" \
  -d '{"repo": "owner/repo", "task": "修复所有 ESLint 报错"}'
```

代理会立即在后台启动沙盒、克隆代码、执行修复并提交 PR，任务状态可通过 Web UI 实时查看。

## 适用场景

- **自动化代码审查与修复**：当 CI 检查失败或收到 Sentry 告警时，代理可自动分析错误、修复问题并创建 PR，节省人工排查时间。
- **异步代码变更**：将大型重构、依赖升级等耗时任务委托给代理在后台执行，开发者可同时推进其他工作。
- **多人协作核查**：团队成员可通过共享终端会话，与代理一同调试复杂问题，或让代理生成初步代码后供人工审查。
- **定时维护任务**：通过 cron 设置周期间隙性任务，如自动清理过期分支、生成代码覆盖率报告等。

## 项目亮点

与市面上其他 AI 编码工具相比，Background Agents 的差异化优势在于：

- **真正后台执行**：多数 AI 编码助手需要用户在线等待回复，而该项目允许异步执行，用户可随时离开或切换任务。
- **完整环境模拟**：沙盒提供终端、文件系统、git 和浏览器，代理可以像真实开发者一样执行复杂操作，而不仅仅是生成代码片段。
- **多渠道触发**：从 Slack 到 GitHub 到自定义 Webhook，无需离开当前工作流即可调用代理。
- **并行子任务**：对于大型任务，代理可自动拆解并在多个沙盒中同时工作，显著缩短整体执行时间。
