## 项目概述

WandEnhancer 是一款面向 Wand（WeMod）应用的开源互操作性增强工具。它的核心目标是扩展本地客户端的配置能力，改善用户的操作体验。该项目由开发者 k1tbyte 维护，采用 Apache-2.0 开源协议，在 GitHub 上已获得超过 7000 颗星标，社区关注度极高。

该工具主要服务于 Wand 应用的现有用户，帮助他们绕过官方客户端的配置限制，实现更灵活的本地设置管理、界面定制以及远程控制。请注意，WandEnhancer 本身不提供任何游戏修改功能，而是专注于增强 Wand 应用的交互层与配置层。

## 核心功能

- **本地环境配置管理**：允许用户精细化调整 Wand 客户端的本地配置文件，包括启动参数、缓存策略和语言设置等，无需依赖官方提供的有限选项。
- **自动化兼容性适配**：当 Wand 客户端更新版本时，自动检测并调整配置项，确保旧版用户的自定义设置与新版本保持兼容，减少因更新导致的配置失效问题。
- **高级布局与主题定制**：在客户端本地层面，提供对 Wand 界面元素的深度定制能力，例如调整窗口透明度、自定义快捷键、修改主题配色方案等，所有改动仅影响本地显示。
- **AI 功能集成**：作为一项额外增强，WandEnhancer 引入了对 AI 特性的支持（具体功能需结合 Wand 应用自身是否开放相关接口），旨在提升智能推荐或自适应体验。
- **远程控制面板（Remote Connect）**：内置一个基于网页的远程控制面板，用户可以通过手机或平板等移动设备，在局域网内远程操作 Wand 应用的部分功能，例如启动/停止游戏、调整设置等。

## 技术架构

WandEnhancer 使用 C# 语言开发，面向 .NET 平台。其核心设计遵循以下原则：

1. **纯本地运行**：代码完全在用户本地执行，不进行任何网络请求，也不与远程服务器通信。所有操作均围绕本地文件系统和进程间通信展开。
2. **配置劫持与注入**：通过读取、修改和注入 Wand 客户端的本地配置文件（如 JSON/XML 格式的偏好设置），实现对客户端行为的干预。改动仅在运行时生效，不影响原有安装包结构。
3. **模块化设计**：项目按功能拆分为多个独立模块，例如配置管理、自动化适配、远程控制面板等。每个模块可独立启用或禁用，降低资源占用。
4. **嵌入式 Web 服务**：远程控制面板使用轻量级 HTTP 服务器（如 Kestrel 或其他自托管方案）在本地启动一个 Web 服务，移动端通过局域网 IP 和端口访问该服务完成交互。

这种架构确保 WandEnhancer 具备极高的安全性与可控性，同时也为二次开发提供了清晰的扩展点。

## 安装与使用

**重要安全提醒**：本项目官方仅通过 GitHub Releases 发布源码和更新说明，**不提供任何预编译的 `.exe` 或 `.zip` 下载包**。请务必仅从官方仓库获取代码并自行编译，警惕第三方渠道的欺诈性下载。

### 安装步骤

1. **环境准备**：确保系统已安装 .NET 8.0 SDK 或更高版本（可从 dotnet.microsoft.com 获取）。
2. **获取源码**：
   ```bash
   git clone https://github.com/k1tbyte/Wand-Enhancer.git
   cd Wand-Enhancer
   ```
3. **编译项目**：
   ```bash
   dotnet build -c Release
   ```
4. **运行**：编译完成后，在 `bin/Release/net8.0/` 目录下找到可执行文件，以管理员权限运行（因需修改本地配置文件）。

### 最小可用示例

启动 WandEnhancer 后，工具会自动检测当前运行的 Wand 客户端进程。在默认模式下，它将:

- 读取并备份现有配置。
- 应用预设的兼容性调整。
- 在系统托盘内显示图标，右键菜单中可快速启用/禁用特定功能（如远程控制面板）。

若需定制配置，可编辑 `WandEnhancer.json` 文件（首次运行后会自动生成），按需修改主题、快捷键或远程端口等参数。

## 适用场景

1. **重度 Wand 用户**：希望突破官方客户端的设置限制，实现更个性化的界面和操作流程。
2. **版本回退或兼容性维护**：当 Wand 新版本导致旧版配置文件失效时，使用自动化适配功能快速恢复并保持业务连续性。
3. **移动端远程操控**：用户在电脑前运行 Wand 应用时，通过手机端的远程控制面板随时管理游戏启动或暂停，尤其适合游戏多开或挂机场景。
4. **开发与调试**：开发者可利用其模块化架构，基于 WandEnhancer 搭建自己的辅助工具，或在本地环境中测试 Wand 应用的配置行为。

## 项目亮点

- **安全透明**：纯本地、零网络请求的设计，配合 100% 开源可审计的代码，从根本上杜绝了数据泄露或恶意行为风险。项目在 README 中明确警告欺诈性下载渠道，展现高度社区责任感。

- **移动端扩展**：内置的远程控制面板将桌面的游戏管理能力延伸至移动端，填补了此类应用在跨设备交互上的空白。
