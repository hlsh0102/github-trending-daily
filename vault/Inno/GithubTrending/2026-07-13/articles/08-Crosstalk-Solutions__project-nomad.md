## 项目概述

Project N.O.M.A.D.（Node for Offline Media, Archives, and Data）是一个完全离线优先的知识与教育服务器。该项目旨在为用户提供一个自包含、可离线运行的生存计算环境，其中集成了关键工具、知识库和人工智能能力，确保用户在任何时间、任何地点都能获得信息获取与决策支持。它的目标用户包括应急准备者、数字游民、知识工作者、教育者以及对离线计算和本地知识管理有需求的个人或组织。

简而言之，Project N.O.M.A.D. 将一台普通的 Debian 系统设备转化为一个强大的离线信息中枢，让你无需依赖互联网即可访问高质量的知识资源、运行实用工具，并与 AI 进行本地交互。

## 核心功能

- **离线知识库**：内置经过精选的离线知识资源，涵盖实用技能、应急指南、教育内容等，所有数据本地存储，无需联网。
- **本地 AI 引擎**：集成轻量级 AI 模型，支持在无网络环境下进行对话、信息检索和问题解答，保障隐私与自主性。
- **浏览器访问界面**：所有操作通过浏览器完成，无需安装额外客户端；支持多设备从同一服务器访问，可作为家庭或局域网的共享节点。
- **一键安装部署**：提供简洁的终端安装脚本，支持任何 Debian 系操作系统（推荐 Ubuntu），全程自动化，降低使用门槛。
- **完全自包含**：项目将所有依赖、数据、工具封装在本地，不依赖外部服务或云平台，确保在断网环境下的完整可用性。
- **开源与可扩展**：基于 Apache-2.0 开源协议发布，用户可根据自身需求修改、定制和扩展项目功能。

## 技术架构

Project N.O.M.A.D. 采用 **离线优先** 的设计哲学，核心架构围绕以下原则构建：

- **底层系统**：基于 Debian 系 Linux 操作系统，安装脚本通过 apt 管理依赖，确保系统兼容性与稳定性。
- **前端界面**：使用 TypeScript 开发，提供现代化的浏览器 UI，用户通过 HTTP 协议访问 `localhost:8080` 或局域网 IP 地址进行交互。
- **本地 AI 集成**：集成轻量级 AI 模型（如通过 llama.cpp 或类似框架），所有推理在本地 CPU/GPU 完成，无数据外传风险。
- **数据存储**：知识库、配置和用户数据全部存储在本地文件系统，无需数据库或外部存储服务。
- **模块化设计**：工具、AI、知识库作为独立模块运行，方便用户按需启用或扩展。
- **网络可选**：虽然设计为离线优先，但在具备网络连接时，项目也支持可选的在线更新或同步功能（如知识库增量更新）。

## 安装与使用

### 安装要求
- 一台运行 Debian 系操作系统（如 Ubuntu 22.04+）的设备
- 拥有 `sudo`/`root` 权限
- 至少 4GB 内存（推荐 8GB+，用于本地 AI 模型运行）
- 至少 20GB 可用磁盘空间

### 快速安装
在终端中执行以下命令即可自动完成安装：

```bash
sudo apt-get update && \
sudo apt-get install -y curl && \
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh \
  -o install_nomad.sh && \
sudo bash install_nomad.sh
```

### 使用方式
安装完成后，打开浏览器并访问：
- 本地访问：`http://localhost:8080`
- 局域网访问：`http://设备IP:8080`

首次启动将加载知识库索引，此后你即可：
- 浏览离线百科和指南
- 与本地 AI 对话
- 使用内置工具（如文件管理、计算器、数据可视化等）

## 适用场景

- **应急与灾害应对**：在自然灾害、网络中断或紧急情况下，提供离线生存指南、急救知识、通信工具和决策 AI，助力用户维持基本生活与安全。
- **远程/野外工作**：为科考队员、野外摄影师、探险者等提供无网络环境下的知识参考、日志记录和轻量级 AI 辅助，降低对卫星互联网的依赖。
- **教育与学习**：在学校、图书馆或家庭网络中搭建离线知识节点，用户（尤其是学生）可在无互联网接入时继续学习、查阅资料。
- **隐私敏感场景**：记者、法律工作者、研究人员等需要保障信息获取隐蔽性的人群，可通过本地 AI 获取信息而不留下在线痕迹。

## 项目亮点

- **真正离线可用**：与大多数“离线模式”需要事先缓存不同，Project N.O.M.A.D. 安装后即可在无网络环境下提供完整核心功能，包括 AI 交互，这是同类项目（如 Kiwix、Wikipedia 离线镜像等）尚未完全做到的。
- **一体化集成**：将知识库、工具、AI 塞进一个安装包，用户无需分别部署多个组件，大大降低了配置复杂度。
- **隐私与自主权**：所有数据归属用户，AI 模型本地运行，不受云服务商的限制、审查或数据采集，适合高隐私需求场景。
- **低门槛部署**：一键脚本安装，无需深入 Linux 或容器技术，普通用户也能轻松搭建自己的离线服务器。
