## 项目概述

Skills for Real Engineers 是 TypeScript 与前端教育领域知名专家 Matt Pocock 开源的一套 AI Agent 技能（Skills）集合，直接来源于其个人日常开发工作流中的 `.agents` 目录。该项目旨在解决一个现实问题：当前流行的 AI 辅助开发方法论（如 GSD、BMAD、Spec-Kit 等）虽然试图通过主导整个开发流程来提升效率，但这种方式往往剥夺了工程师对过程的控制权，一旦流程本身出现缺陷，便难以定位和修复。

与那些重量级、强约束的框架不同，这套技能被刻意设计为**小巧、易于修改、可自由组合**的模块，并且**不绑定特定模型**。项目沉淀了作者数十年的真实工程经验，以轻量、透明的方式交给开发者，鼓励使用者根据自身需求进行改造，而非盲目遵循一套固定的流程。

## 核心功能

- **Agent Skill 定义**：每个技能均为结构化的指令包，定义了 AI 在特定工程任务中的行为模式、思考步骤与输出规范，可直接被 Claude Code 等支持 Agent Skills 的工具加载。
- **即插即用安装**：提供了两种安装方式——通过 Claude Code 插件市场安装为受管、只读的完整包，或直接拷贝仓库中的技能目录到本地 `.agents` 文件夹，实现完全自由的定制。
- **可组合的工作流**：各技能之间相互独立，开发者可以像搭积木一样，根据当前任务选择并组合不同的技能，而非被迫接受一套完整但僵硬的流程。
- **模型无关设计**：技能内容不依赖特定 LLM 的私有 API 或特殊能力，可在不同 AI 编程助手之间迁移使用，降低了切换工具时的学习成本。
- **透明可审计**：技能文件以纯文本 Markdown 编写，逻辑一目了然，工程师可审查 AI 行为准则的来源和正确性，避免黑盒式流程带来的隐患。

## 技术架构

该项目的技术实现极为轻量，其核心载体是一系列结构化的 Markdown 文件（通常为 SKILL.md）。每个文件内部定义了技能的元信息（如名称、描述）、触发条件、执行步骤，以及明确的输入/输出约束。这种设计并非简单的提示词堆砌，而是对复杂工程任务的**步骤化拆解与决策逻辑的显性化**。

架构上的关键决策在于**去中心化**：仓库本身只是一个文件集合，没有构建脚本、没有运行时依赖，也没有强制性的全局状态。技能通过文件系统的目录结构进行组织，安装过程不过是复制文件或添加一个插件引用。这种极简哲学带来了两个显著优势：其一，任何工程师都能轻松阅读和修改技能文件，使其适配个人偏好；其二，技能之间没有隐式耦合，使用者可以随时增删某一个技能，而不用担心破坏整体。

此外，项目充分利用了 Claude Code 等工具对 Agent Skills 的官方支持协议，通过标准的 `SKILL.md` 格式完成对接，这使得该仓库既能作为一个独立的参考实现，也能无缝集成到现有的 AI 编程环境中。

## 安装与使用

**安装（30 秒完成）**

该项目提供两种安装路径，对应两种使用理念：

1. **推荐快速体验**：若你使用 Claude Code，可直接通过其插件市场安装 "Skills" 插件。该方式会将整套技能作为受管的只读包自动部署，便于统一升级和维护。
2. **高级自定义**：直接将本仓库克隆或下载到本地，并将所需的技能文件夹复制到你的项目根目录下的 `.agents/` 目录中。例如：

```bash
git clone https://github.com/mattpocock/skills
# 假设你只需要 code-review 技能
cp -r skills/code-review .agents/
```

**最小使用示例**

安装完成后，在支持 Agent Skills 的终端工具（如 Claude Code）中，技能会自动被识别。你可以通过自然语言请求唤起相应技能，例如：

- 在对话中输入“请对本次代码变更进行审阅”，工具会加载 `code-review` 技能，按照其内置的步骤输出审查意见。
- 当需要规划一个复杂功能时，运行 `plan` 技能，AI 将遵循其中定义的架构设计步骤，产出一份结构化的技术方案。

## 适用场景

- **追求掌控力的全栈开发**：不适合完全依赖 AI 生成代码、缺乏深度思考的“Vibe Coding”。对于需要确保代码质量、遵循特定架构规范的正式项目，使用这些技能可在 AI 辅助的同时维持工程师对关键决策的最终裁定权。
- **团队 AI 工作流规范化**：团队可将此仓库作为基底，将内部编码规范、评审清单等技术决策固化为标准技能文件，并纳入版本控制，从而让团队所有成员（包括 AI）遵循同一套协作契约。
- **探索与学习 AI Agent 工程**：对于那些想深入理解如何编写高质量 Agent 指令或构建可定制 AI 工作流的开发者，该仓库是一个优秀的最佳实践范例，其文件简洁，易于拆解学习。
- **跨工具 AI 环境切换**：由于技能不依赖特定模型，开发者从 Claude Code 切换到其他支持 Skills 协议的工具时，可以直接复用这些指令文件，显著降低迁移成本。

## 项目亮点

- **反宏大叙事，回归工程本质**：敢于对 GSD、Spec-Kit 等流行但重量级的流程说“不”，坚持“小而美”的 Unix 哲学。它不试图用一套工具解决所有问题，而是提供可拼装的零件，将选择权和组合权交还开发者。
- **源自一线实践，而非理论构建**：这些技能来自作者在真实工程环境中的日常使用，经过了大量生产环境代码的打磨，其内容和颗粒度贴近实际痛点，而非纸面上的宏达设计。
- **极简透明，易于信任**：全部技能以可读的 Markdown 实现，无任何神秘黑盒。用户可以放心地进行分叉、修改，甚至将修改后的版本回馈社区，这是其开放精神的最佳体现。
