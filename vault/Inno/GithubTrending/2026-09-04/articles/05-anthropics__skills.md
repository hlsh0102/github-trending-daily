## 项目概述

anthropics/skills 是 Anthropic 官方维护的公开仓库，集中存放了为 Claude 设计的 Agent Skills 实现。Agent Skills 是一组结构化的文件夹，包含指令、脚本和资源，Claude 可以按需动态加载这些内容，以提升在特定任务上的表现。简单来说，Skills 就像是 Claude 的“技能插件”——当你需要它完成某类专业工作时，它可以加载对应的技能包，学习其中的工作流程和规则，从而给出更精准、更符合预期的结果。

这个仓库的目标用户包括：使用 Claude 进行复杂任务自动化的开发者、希望将品牌规范或内部流程嵌入 AI 助手的企业团队、以及所有希望探索 Claude 能力边界的 AI 爱好者。无论你是想生成符合公司规范的文档，还是想分析特定领域的数据，这里提供的技能示例都能为你提供直接可用的参考。

## 核心功能

- **丰富的技能示例**：仓库收录了覆盖创意应用（艺术、音乐、设计）、技术任务（Web 应用测试、MCP 服务器生成）和企业工作流（沟通、品牌管理）等多个领域的技能包，每个技能都独立成文件夹，并包含完整的 `SKILL.md` 指令文件。
- **标准化技能格式**：每个技能文件夹都遵循统一的 `SKILL.md` 结构，包含元数据和详细操作说明，使 Claude 能够准确理解何时加载该技能以及如何执行其中的任务。
- **即插即用设计**：技能包自包含所有必要的指令、脚本和资源，用户可以直接将技能文件夹放入 Claude 的配置目录中即可生效，无需额外安装或配置。
- **文档与教程配套**：仓库链接了详尽的官方文档，包括什么是 Skills、如何在 Claude 中使用、如何创建自定义技能等，让用户可以快速上手并自行扩展。
- **社区与生态协同**：作为 Anthropic 官方仓库，它配套 agentskills.io 标准网站，推动 Agent Skills 成为跨平台的开放标准，而不仅仅是单一产品的功能。

## 技术架构

Agent Skills 的设计理念是将“指令、代码和资源”打包为一个可复用的单元。从技术角度看，每个技能包本质上是一个文件夹，核心文件是 `SKILL.md`，该文件采用 Markdown 格式书写，包含两大部分：一是元数据头部，用于描述技能的适用场景、需要条件等信息，帮助 Claude 判断何时调用该技能；二是正文指令，详尽描述了完成特定任务所需的步骤、规则和参考示例。

Skills 的加载机制是动态的。与传统的固定 prompt 不同，技能只在相关任务出现时才会被 Claude 加载，这种按需获取的方式显著降低了上下文窗口的压力，使得模型可以在必要时调用专门的工具和流程。实际运用中，一个技能文件夹内除了 `SKILL.md`，还可以携带辅助脚本（如 Python 脚本）、模板文件、参考数据等，Claude 在执行过程中可读取并运行这些资源。

仓库本身采用简单的目录结构管理，每个技能一个文件夹，彼此独立，便于维护和版本控制。这种模块化设计让用户可以像安装依赖一样添加新技能，也让组织内部可以轻松共享和复用已验证的工作流。

## 安装与使用

要使用这个仓库中的技能，你首先需要有一个支持 Agent Skills 的 Claude 环境。基本步骤如下：

1. 克隆仓库或直接下载你感兴趣的技能文件夹：
   ```bash
   git clone https://github.com/anthropics/skills.git
   ```
2. 将需要的技能文件夹复制到你的 Claude 技能目录中（通常位于 `~/.claude/skills/` 或项目目录下的 `.claude/skills/`）。
3. 启动 Claude，并通过自然语言描述你的任务需求。Claude 会自动判断是否加载相应技能。

以仓库中的一个技能为例，假设你使用文档生成类技能，只需在对话中说明“请用公司品牌规范创建一份产品介绍”，Claude 就会自动加载品牌技能包中的 `SKILL.md`，按照其中的格式、语气和视觉规范来生成内容。

如果你希望创建自己的技能，可以参考仓库中现有技能的结构：新建一个文件夹，编写 `SKILL.md`，在元数据中写清楚技能的“名称”、“描述”和“适用条件”，然后在正文中给出详细的步骤指引，即可让 Claude 在遇到相关请求时自动调用。

## 适用场景

- **企业内容标准化**：企业可将官方品牌指南、文档模板、写作风格等固化为 Skills，确保所有 AI 生成的对内对外内容都符合统一标准，适用于市场部、公关部和行政部门的日常工作。
- **技术工具调用**：开发团队可以利用 Skills 封装特定的测试流程、代码审查规范或运维脚本，让 Claude 能够直接执行 Web 应用测试、生成 MCP 服务器代码等技术任务。
- **个人效率提升**：个人用户可以将日常重复性工作（如报销单整理、行程规划、周报生成）制作成技能包，让 Claude 按既定的个性化方式处理，节省大量操作时间。
- **跨平台生态建设**：由于 Agent Skills 是一个开放的轻量级标准，团队可以围绕该规范开发并共享技能，实现不同 AI 工具间的技能互通，适合开源社区和行业联盟场景。

## 项目亮点

与传统的 prompt 工程或微调方案相比，Agent Skills 提供了一种更加结构化、可复用的能力扩展方式。其最显著的差异化优势体现在以下几点：

- **模块化与可维护性**：每个技能是独立版本化的文件夹，便于团队按项目分别管理和更新，不必反复修改全局系统提示。
- **动态按需加载**：技能只在被需要时才进入上下文，提高了 Claude 的响应质量和运行效率，降低了无关信息对判断的干扰。
- **开放标准潜力**：Anthropic 将这一实现开源并与 agentskills.io 协同推动标准化，意味着社区可以共同定义未来 AI 代理的能力接口。
- **与生态深度集成**：仓库由 Anthropic 官方维护，与 Claude API 和产品功能保持同步，稳定性和前瞻性有保障。
