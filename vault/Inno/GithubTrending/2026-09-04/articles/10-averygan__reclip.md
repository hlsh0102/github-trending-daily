## 项目概述

ReClip 是一款轻量级、可自托管的开源视频与音频下载工具，提供简洁清爽的 Web 界面。用户只需粘贴来自 YouTube、TikTok、Instagram、Twitter/X 等 1000+ 网站的链接，即可轻松将内容保存为 MP4 视频或 MP3 音频文件。

该项目解决了两个核心问题：一是跨平台媒体下载需求分散，用户通常需要为不同网站寻找不同工具；二是现有下载工具普遍冗重，需要繁琐的环境配置或不必要的后台服务。ReClip 以极简的架构（后端仅约 150 行 Python 代码）实现了强大的下载能力，目标用户包括内容创作者、媒体研究者、个人媒体库管理者，以及任何需要离线保存网络媒体的普通用户。

项目采用 MIT 开源协议，已在 GitHub 上获得超过 8500 颗星标，社区热度持续上升，反映了其轻量设计受到了广泛认可。

## 核心功能

- **广泛网站支持**：基于 yt-dlp 引擎，支持 YouTube、TikTok、Instagram、Twitter/X、Reddit、Facebook、Vimeo、Twitch、SoundCloud、Loom、Streamable、Pinterest、Tumblr、Threads、LinkedIn 等 1000+ 网站，几乎覆盖主流媒体平台。
- **双格式输出**：一键选择 MP4 视频或 MP3 音频提取，满足视频存档与音频收听两种核心场景。
- **清晰度选择器**：自动获取视频可用清晰度/分辨率列表，用户可自由选择最合适的画质。
- **批量下载与智能去重**：支持一次性粘贴多个 URL，自动识别并去除重复链接，大幅提升批量处理效率。
- **纯前端响应式 UI**：界面无框架依赖、无需构建步骤，适配桌面与移动设备，交互流畅直观。
- **极简部署方式**：单文件 Python 后端脚本，配合一键启动 Shell 脚本即可运行，也支持 Docker 容器化部署。

## 技术架构

ReClip 的设计哲学是“极简但功能完备”。项目整体采用前后端分离但同仓管理的模式：

- **后端**：以 Python 编写，核心逻辑封装在一个约 150 行的单文件脚本中。后端负责接收前端请求、调用 yt-dlp 执行下载任务、处理媒体信息提取以及与文件系统的交互。这种扁平化设计减少了模块耦合，降低故障点，便于审计和维护。
- **下载引擎**：底层深度集成 yt-dlp（youtube-dl 的活跃分支），借助其持续更新的站点解析器，确保了对众多网站协议变更的快速适配，这是项目能够覆盖千余网站的关键技术支撑。
- **媒体处理**：依赖 FFmpeg 完成视频与音频的转码、封装和提取操作。安装脚本中明确包含该依赖，确保运行时功能完整。
- **前端**：采用原生 HTML/CSS/JavaScript 构建，不使用任何现代前端框架（如 React、Vue）。这一选择带来了零构建步骤、零 Node.js 依赖的优势，开箱即用，页面加载速度极快。
- **API 设计**：前端通过轻量 HTTP 接口与 Python 后端通信，实现 URL 信息预览、下载任务提交与状态反馈。

整体架构设计强调资源占用低、部署门槛低，非常适合在 NAS、树莓派或小型 VPS 上持久运行。

## 安装与使用

### 环境准备

首先确保系统已安装 yt-dlp 和 ffmpeg：

```bash
# macOS (Homebrew)
brew install yt-dlp ffmpeg

# Debian/Ubuntu (APT)
sudo apt install ffmpeg
pip install yt-dlp
```

### 从源码启动

```bash
git clone https://github.com/averygan/reclip.git
cd reclip
./reclip.sh
```

启动后，浏览器访问 **http://localhost:8899** 即可看到 Web 界面。

### 使用 Docker

```bash
docker build -t reclip .
docker run -p 8899:8899 reclip
```

### 典型使用流程

1. 将一个或多个视频链接粘贴到输入框。
2. 选择输出格式（MP4 视频或 MP3 音频）。
3. 点击 **Fetch** 按钮，系统自动抓取视频信息与缩略图。
4. 如有需要，在下拉菜单中选择清晰度或分辨率。
5. 点击单个视频的 **Download** 按钮，或使用 **Download All** 批量下载全部链接。

## 适用场景

- **个人媒体库离线化**：将常看的 YouTube 教程、音乐 MV 或社交平台视频下载保存，用于通勤途中或在无网络环境下观看。
- **内容二次创作素材收集**：创作者需要从多平台收集视频片段或音频样本，ReClip 的批量下载与统一格式输出可极大加速素材整理流程。
- **本地化数据归档**：研究人员或媒体从业者需要将特定在线视频资源备份至本地存储，确保内容的长期可访问性。
- **自托管替代在线服务**：用户不愿使用有文件大小限制、速度限制或隐私顾虑的在线下载网站，选择在自己的设备上部署 ReClip，完全掌控数据流。

## 项目亮点

与同类图形化下载工具或基于 Web 的下载服务相比，ReClip 具备以下差异化优势：

- **极致轻量**：后端 150 行代码、前端无框架，这种克制的设计在同类项目中颇为罕见，资源占用小，适合低配设备常驻运行。
- **零构建步骤**：下载即用，无需执行 npm install 或等待前端工程编译，消除了不必要的复杂环节。
- **自主可控**：作为自托管应用，媒体下载行为完全在用户自己的网络和设备环境中执行，规避了隐私泄露与文件留存限制风险。
- **亮眼界面设计**：尽管代码极简，但界面质量并未妥协。干净清爽的 UI 风格，配合流畅的交互反馈，颠覆了“自建工具普遍简陋”的刻板印象。
- **批量处理打磨细致**：自动去重、批量信息抓取与一键下载，让大量链接的处理效率显著提升，超越了逐条粘贴的操作模式。
