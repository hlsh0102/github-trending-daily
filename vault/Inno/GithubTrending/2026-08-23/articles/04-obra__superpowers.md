## 项目概述

Superpowers 是一套面向编程代理（coding agent）的完整软件开发方法论，它建立在可组合的技能（skills）集合与初始指令之上，确保代理在实际开发中遵循这些规范。该项目解决了当前 AI 编程代理普遍存在的问题——代理在接到任务后直接开始编写代码，缺乏对需求本质的理解和系统性的开发流程，导致生成代码质量不稳定、与预期目标偏离。Superpowers 的目标用户是使用 Claude Code、Cursor、Codex 等主流 AI 编程工具的开发者和团队，帮助他们将代理从“代码生成器”升级为“真正的开发伙伴”。

## 核心功能

- **需求澄清机制**：代理在接到任务后不会立即编码，而是主动引导用户明确目标、约束条件和验收标准，通过多轮对话提炼出可执行的需求规格说明。
- **分块确认设计**：将产出的需求规格和设计方案以短小的片段展示给用户，确保用户能够完整阅读并理解每个决策点，避免信息过载。
- **自动生成实施计划**：在用户确认设计后，代理会制定结构化的实施计划，合理拆解任务并确定依赖关系与实施顺序。
- **可组合技能体系**：内置一套模块化的技能库，覆盖需求分析、架构设计、编码实现、测试验证等开发全生命周期，代理按需调用。
- **多平台适配**：提供统一的安装与配置方式，支持超过 14 种主流 AI 编码工具，包括 Claude Code、Cursor、Codex CLI、Gemini CLI、GitHub Copilot CLI 等。
- **持续更新机制**：项目提供便捷的更新工具和社区驱动的内容演进路径，确保方法论和技能库保持最新。

## 技术架构

Superpowers 的核心架构由三层组成：**指令层**（初始 prompt 与规则）、**技能层**（可组合的模块化技能文件）和**适配层**（针对不同代理平台的配置接口）。指令层负责设定代理的基本行为和思考框架，确保代理在任何任务开始前优先调用需求分析技能。技能层采用类似 Unix 哲学的“单一职责 + 可组合”设计，每个技能解决一个特定问题，技能之间通过标准化的输入输出接口相互协作，代理可以根据任务复杂度动态组合所需技能。适配层则通过各平台的插件或配置机制（如 Claude Code 的插件系统、Cursor 的规则文件）将指令和技能加载到具体工具中，保持跨平台体验一致性。

与传统的单一大 prompt 方案不同，Superpowers 将方法论拆分为独立技能文件，代理只在需要时加载对应技能，避免了上下文窗口的浪费和指令混乱。安装过程中，项目会将核心指令写入代理的全局配置，确保代理在首次交互时即启用正确行为模式。

## 安装与使用

以 Claude Code 为例，安装步骤如下：

1. 确保已安装并登录 Claude Code（版本 ≥ 2.0）。
2. 运行以下命令安装插件：
   ```bash
   /plugin install obra/superpowers
   ```
3. 重启 Claude Code 会话，插件会自动加载初始指令。

安装完成后，启动任一编码任务。当你向代理描述需求时，代理会首先询问“你真正想要解决的问题是什么”，并引导你一步步澄清需求。你需要回答代理提出的问题，审阅它生成的规格说明和实施计划，确认后代理才会进入编码阶段。

对于其他平台（如 Cursor、Codex CLI、Gemini CLI 等），只需将仓库中的对应 skill 文件复制到平台的全局配置目录即可，各平台详细步骤见项目 README 的安装章节。

## 适用场景

- **复杂功能开发**：当任务涉及多模块、多步骤的设计与实现时，Superpowers 帮助代理先明确边界，再逐步实施，大幅降低返工率。
- **团队协作与代码审查**：代理生成的结构化规格和实施计划可作为团队评审文档，提高沟通效率，减少理解偏差。
- **跨工具迁移**：团队若在不同项目中使用不同 AI 工具，Superpowers 的统一方法论可确保开发流程一致性，降低工具切换成本。
- **教育与技能提升**：开发人员可通过观察代理的工作流程，学习系统化的软件开发方法论，提升自身分析与设计能力。

## 项目亮点

- **强调“先思考，后编码”**：与传统代理开箱即写的模式形成鲜明对比，从根源上提升代码质量。
- **技能可组合且开放**：技能库以文件形式提供，开发者可以自由修改、扩展或分享自定义技能，形成社区生态。
- **多平台覆盖范围极广**：几乎涵盖当前所有主流 AI 编码工具，无需为不同工具维护多套工作流。
- **轻量且透明**：所有指令和技能均为可读的文本文件，用户可完全理解并控制代理的行为逻辑。
- **活跃的社区驱动**：项目拥有庞大的用户基数（276k+ Stars）和每日新增星标，迭代速度快，社区反馈直接转化为功能改进。
