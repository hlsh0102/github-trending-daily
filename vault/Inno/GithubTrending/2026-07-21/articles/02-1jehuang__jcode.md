## 项目概述

jcode 是一个为代码任务而生的下一代智能体编排平台，旨在突破当前编码助手的性能天花板。该项目由 Rust 语言构建，专注于多会话工作流、无限可定制性和极致性能。主要解决传统 AI 编码工具在复杂、长期运行任务中容易丢失上下文、资源消耗高、扩展性差的问题。目标用户包括需要处理大型代码库的开发者、规模化自动化测试与重构的团队，以及追求高度定制化 AI 工作流的进阶用户。

## 核心功能

- **多会话工作流**：支持同时运行多个独立的编码会话，每个会话维护完整的上下文状态，互不干扰，适合并行处理不同模块或任务。
- **持久化记忆系统**：内置高级记忆管理机制，可在会话间保持关键信息，避免重复告知上下文，大幅减少 token 消耗并提升一致性。
- **无限可定制性**：提供灵活的配置接口和插件系统，用户可深度定制工作流程、提示模板、工具集和行为规则。
- **极致性能优化**：通过 Rust 实现底层引擎，原生支持异步 I/O 和零成本抽象，确保在多会话场景下的低延迟和高吞吐。
- **资源高效管理**：精细控制内存和 CPU 使用，在密集任务中依然保持系统响应性，适合在开发笔记本或 CI 环境运行。
- **智能上下文压缩**：自动识别和压缩冗余上下文，在保持关键信息的前提下最大限度减少 token 开销。

## 技术架构

jcode 采用 Rust 语言作为核心引擎，利用 Rust 的内存安全特性和无垃圾回收机制实现高性能。架构设计围绕“会话-代理-工具”三层模型展开：

- **会话层**：管理独立的工作空间和上下文状态，每个会话拥有专属的内存和文件系统视图，支持隔离执行。
- **代理层**：实现与大型语言模型的交互逻辑，包括请求构建、响应解析、工具调用调度等。代理设计为可替换单元，支持接入不同云模型或本地模型。
- **工具层**：提供丰富的代码操作原语，如文件读写、代码搜索、语法分析、版本控制交互等，用户可注册自定义工具扩展功能。

此外，jcode 采用事件驱动架构，通过异步消息传递协调各组件工作，避免阻塞。上下文管理使用 LRU 缓存与策略性压缩算法，在保证准确性的同时动态调整内存占用。

## 安装与使用

**安装方式**：

macOS 和 Linux 用户可使用一键脚本：
```bash
curl -fsSL https://jcode.sh/install | bash
```

Windows 11 用户（PowerShell 5.1+）：
```powershell
irm https://jcode.sh/install.ps1 | iex
```

也支持 Homebrew 安装、源码构建以及使用代理自动配置。

**最小可用示例**：

安装后，进入项目目录，启动一个简单的代码重构会话：
```bash
cd your-project
jcode init
jcode session start --model gpt-4o
jcode ask "请将此模块中的重复逻辑提取为公共函数"
```

jcode 会自动分析代码结构，执行重构建议，并展示 diff 供确认。

## 适用场景

- **大规模代码重构**：当需要跨多个文件执行系统性重构（如重命名 API、提取公共组件）时，jcode 的多会话功能可并行处理不同模块，保持上下文一致性。
- **自动化代码审查与修复**：集成到 CI 流水线中，自动审查 PR 的代码质量、检测潜在 bug，并生成修复补丁。
- **长期运行的后台编码任务**：例如持续优化算法性能、自动生成单元测试、同步更新文档等，可持久运行并保持上下文积累。
- **多模型协作开发**：利用不同模型的优势（如专用模型处理特定语言、通用模型处理复杂逻辑），在同一工作流中协调多个模型完成编码任务。

## 项目亮点

与同类编码代理工具相比，jcode 的差异化优势体现在：

- **极致性能**：Rust 底层带来毫秒级响应，即使同时运行数十个会话，资源占用依然可控，远超 Python/Node.js 实现的同类工具。
- **会话级隔离**：每个会话拥有独立的环境和记忆，避免任务间干扰，适合团队协作或复杂项目中的模块化开发。
- **深度定制能力**：不仅支持配置提示模板，还开放底层代理和工具接口，允许用户构建专属的编码工作流自动化系统。
- **记忆持久化**：不同于许多工具仅在单次对话中保持记忆，jcode 支持跨会话持久化关键上下文，极大提升长期任务的效率。
