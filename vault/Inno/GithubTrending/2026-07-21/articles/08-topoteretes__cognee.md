## 项目概述

Cognee 是一个开源的人工智能记忆平台，专为智能体（agents）设计。它解决了当前 AI 系统的一个重要缺陷：缺乏持久化的长期记忆能力。多数 AI 对话系统在会话结束后即遗忘历史信息，无法跨会话保持对用户、上下文和知识关系的理解。Cognee 通过自托管的**知识图谱引擎**，赋予 AI 智能体跨会话的持久记忆能力，让 AI 能够记住过往交互、积累知识并基于历史上下文做出更智能的回应。

项目面向 AI 开发者、研究者和企业团队，特别是那些正在构建需要长期上下文理解能力的智能体（如助手、客服、知识管理、教育 Agent 等）的团队。Cognee 完全开源，采用 Apache 2.0 许可证，可自由部署和二次开发。

## 核心功能

- **跨会话记忆管理**：将 AI 交互产生的信息持久化存储，智能体在后续对话中可检索和利用历史记忆，实现真正的连续对话体验。
- **知识图谱引擎**：自动将非结构化文本、对话记录等数据转化为结构化的知识图谱，支持实体识别、关系抽取和语义推理。
- **向量与图谱混合检索**：结合向量相似度搜索和知识图谱遍历，同时支持基于语义相似性和结构化关系两种方式的记忆检索，大幅提升召回准确率。
- **自托管架构**：所有数据存储在用户自己的基础设施上，支持本地或私有云部署，确保数据隐私和安全。
- **模块化插件系统**：提供社区插件和扩展机制（cognee-community），用户可以自定义存储后端、图谱构建策略或集成外部工具。
- **简单 API 集成**：提供 Python SDK 和简洁的 API 接口，开发者可以快速将 Cognee 集成到现有 AI 工作流或智能体框架中。

## 技术架构

Cognee 采用分层模块化设计，核心架构包含以下几个关键组件：

- **数据摄取层**：接收多种输入格式（文本、对话日志、文档等），进行预处理（分词、实体识别、关系抽取）。
- **记忆表示层**：将处理后的信息同时转化为两种表示：向量嵌入（用于语义搜索）和知识图谱三元组（用于关系推理）。这种双重表示机制让系统能充分利用非结构化与结构化信息的优势。
- **存储层**：支持多种后端（如 PostgreSQL + pgvector、Neo4j、SQLite 等），用户可根据场景选择最合适的存储方案。图谱存储推荐使用原生图数据库，向量存储可使用专用向量数据库或支持向量索引的关系型数据库。
- **检索层**：实现混合检索策略——当查询到达时，分别从向量索引和知识图谱中召回相关记忆片段，然后通过重排序或融合算法输出最优结果。
- **API 层**：提供统一的 RESTful 接口和 Python SDK，开发者通过几行代码即可完成记忆的写入、检索和更新操作。

架构设计强调可插拔性：每个组件都有清晰的接口，用户可以实现自定义模块替换默认实现。数据流是异步的，支持批量写入和流式处理，适合高频交互场景。

## 安装与使用

**安装方式**（使用 pip）：

```bash
pip install cognee
```

**最小可用示例**：

```python
import cognee

# 初始化记忆引擎，指定存储后端（以 SQLite + 本地文件为例）
cognee.config.set_storage("sqlite")

# 写入记忆：将一段对话内容存入知识图谱
cognee.add("用户在2024年3月提到喜欢科幻小说，尤其对《沙丘》系列非常熟悉")

# 检索记忆：根据当前查询检索相关历史信息
results = cognee.search("这个用户对哪类书籍感兴趣？")
print(results)
# 输出：基于知识图谱推理，返回相关记忆片段

# 跨会话使用：在新的会话中同样可以检索到之前存储的记忆
new_results = cognee.search("推荐几本类似《沙丘》的科幻小说")
print(new_results)
```

更多集成方式（如连接到 Neo4j 图数据库、配置 OpenAI 嵌入模型等）请参考官方文档。

## 适用场景

- **智能客服机器人**：利用跨会话记忆，记住用户的历史偏好、投诉记录和解决方案，避免用户重复描述问题，提升客服效率。
- **个人知识助手**：记录用户的学习笔记、阅读历史和兴趣标签，当用户提问时能从长期记忆中调取相关内容，提供个性化建议。
- **企业内部知识管理**：整合企业文档、会议记录、邮件等异构数据，自动构建知识图谱，员工可通过自然语言查询快速获取关联知识，支持决策支持。
- **教育 AI 辅导系统**：持续跟踪学生的学习进度、易错知识点和理解程度，基于历史记忆动态调整教学策略和推荐学习材料。

## 项目亮点

- **开源与自托管**：完全开源（Apache 2.0），数据所有权和隐私完全掌控在用户手中，避免依赖第三方云服务。与许多闭源记忆方案形成鲜明对比。
- **知识图谱驱动的记忆**：不仅仅是简单的向量存储，Cognee 的核心创新在于将结构化的知识图谱与向量检索结合，能够显式表示实体之间的关系，支持推理和联想，比纯向量检索更加智能。
- **跨会话持久化**：原生设计支持长期记忆，智能体可以积累数月甚至数年的交互历史，真正实现持续学习和上下文感知。
- **轻量级集成**：通过简单的 pip 安装和几行代码即可启用记忆功能，无需搭建复杂的微服务架构，适合快速原型开发和迭代。
- **活跃的社区生态**：拥有独立的 Discord 社区、Reddit 讨论区和社区插件库，项目获得近 2.9 万颗 Star，表明其受到广泛关注和认可。
