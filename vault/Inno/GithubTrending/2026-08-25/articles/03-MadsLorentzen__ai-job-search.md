## 项目概述

AI Job Search 是一个完全运行在你本地机器上的 AI 求职应用框架，基于 Claude Code 构建。它解决了求职过程中最耗时、最重复的几个环节：评估职位描述、定制简历、撰写求职信和准备面试。用户只需将仓库 Fork 到自己的 GitHub 账号，填写个人资料，即可让 Claude 处理求职流程中的繁琐事务。该项目由一位地球物理学家在 2025 年底被裁员后创建，用于管理自己的求职过程，目前已在 GitHub 上获得超过 34,000 颗星。

## 核心功能

- **职位评估**：自动抓取并分析职位描述，判断与个人背景的匹配程度，提供结构化评估结果。
- **简历定制**：根据目标职位的具体要求，自动调整简历中的技能关键词、项目经历和成就描述，使其更贴合招聘方需求。
- **求职信生成**：基于职位描述和个人资料，生成针对性强的求职信草稿，并支持迭代修改。
- **面试准备**：针对特定职位生成模拟面试问题，提供回答思路和要点提示。
- **全流程自动化**：通过 Claude Code 的 agent 能力，将职位筛选、材料生成、投递跟踪等任务串联成完整工作流。
- **完全本地运行**：所有数据和个人信息均保留在本机，无需上传至第三方服务器。

## 技术架构

该项目以 Python 为主要语言，构建在 Anthropic 的 Claude Code 工具链之上。核心设计思路是“配置即工作流”——用户通过 YAML 或 JSON 配置文件定义个人资料、目标岗位类型和偏好，系统则将这些配置注入到 Claude Code 的提示词模板中，驱动 AI 执行各个环节。

架构上采用模块化设计，主要包含以下几个部分：

- **配置层**：存储个人资料、求职偏好和输出格式设置，以纯文本文件形式存在，便于版本管理。
- **提示词工程**：精心设计的 system prompt 和任务模板，确保 Claude 输出符合求职场景要求的格式和内容。
- **文件处理模块**：负责解析 PDF 格式的简历和职位描述，提取结构化信息供 AI 使用。
- **输出管理**：自动生成 Markdown 或 PDF 格式的求职材料，并按职位归入独立目录。
- **CI/CD 集成**：内置 GitHub Actions 工作流，支持自动化测试和格式校验。

这种设计使整个系统完全可审计、可修改。由于所有流程都在本地执行，用户无需担心简历内容或个人数据泄露给第三方服务。

## 安装与使用

**前提条件**：确保已安装 Python 3.10+ 和 Claude Code CLI，并完成 Anthropic API 认证。

**安装步骤**：

1. 将仓库 Fork 到自己的 GitHub 账号，然后克隆到本地：
   ```bash
   git clone https://github.com/你的用户名/ai-job-search.git
   cd ai-job-search
   ```
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 编辑 `profile.yaml` 文件，填写你的个人信息、工作经历、教育背景和求职偏好。
4. 运行主命令开始处理职位：
   ```bash
   python main.py --job-url https://example.com/job-posting
   ```

**最小可用示例**：假设你找到了一个感兴趣的职位链接，只需运行上述命令，系统便会自动提取职位描述、生成匹配度评估、撰写定制简历和求职信，并将所有结果保存在 `output/` 目录下对应的职位文件夹中。整个过程通常只需几分钟。

## 适用场景

- **大规模求职者**：正在广泛投递职位、需要批量处理不同公司求职材料的用户，可大幅节省时间。
- **转行或跨领域求职者**：需要针对不同行业定制多版本简历和求职信的用户，AI 能快速调整表达重点。
- **非英语母语求职者**：希望以地道语言撰写英文求职材料和面试准备的用户，AI 可帮助提升专业表达水平。
- **开源工具爱好者**：喜欢掌控全流程、愿意通过修改代码和提示词来优化求职策略的技术型用户。

## 项目亮点

与市面上其他 AI 求职工具相比，该项目有几个显著差异：

- **数据主权**：所有个人数据始终留在本地机器上，不经过任何第三方服务器，从根本上规避了隐私泄露风险。
- **完全可定制**：由于是开源框架，用户可以自由修改提示词模板、配置文件乃至核心逻辑，根据自身行业特点进行深度调整。
- **成本可控**：只需支付 Claude API 的使用费用，没有按月订阅的 SaaS 费用，长期使用成本更低。
- **透明度高**：每一份生成的求职材料都可以追溯其生成逻辑，用户能清楚了解 AI 做了哪些修改，避免盲目信任。
- **生态验证**：项目作者亲历了真实的求职成功案例，其实际使用效果得到了大量开发者和求职者的验证。
