## 项目概述

Apache Maka（孵化中）是一个本地优先的 AI Agent 工作区，专为真实工作场景而设计。它允许 AI 代理在沙箱边界内检查项目、运行工具，并将模型消息、工具调用、工具结果、权限决策和终止事件记录为仅追加的日志。该项目由 Apache 软件基金会孵化，目前处于积极开发阶段。

Maka 解决了当前 AI Agent 工具普遍存在的一个核心问题：缺乏透明的操作审计和可靠的状态记录。在传统 AI Agent 工具中，模型与外部环境的交互往往以黑盒方式运行，用户难以追踪每一次工具调用的原因和结果。Maka 通过引入不可变的事件日志，为每次 AI 决策和操作提供完整、可验证的审计轨迹，特别适合需要高可靠性、可追溯性的专业工作环境。

目标用户包括需要精细控制 AI 行为的开发者、关注数据隐私和审计合规的企业团队，以及希望深入理解 Agent 决策过程的研究人员。此外，Maka 采用本地优先架构，所有数据默认存储于本地，无需强制云端中转，对于处理敏感代码和业务数据的使用者尤为友好。

## 核心功能

- **本地优先架构**：默认所有数据保存在本机，无强制云端依赖，保障敏感项目数据的安全性和隐私性，同时支持离线操作。
- **沙箱工具执行**：所有工具调用在受限的沙箱边界内运行，避免 AI 操作对宿主系统造成意外影响，提升整体安全性。
- **不可变事件日志**：模型消息、工具调用、工具结果、权限决策和终止事件全部记录为仅追加（append-only）日志，确保审计轨迹的完整性和不可篡改性。
- **权限决策记录**：每次涉及敏感操作的权限判断都会被完整保存，用户可事后复核授权决定是否符合预期，有助于建立信任和纠错。
- **原生桌面应用**：目前提供针对 macOS Apple Silicon 的正式版本，以及 Windows 平台的无签名预览版，计划后续支持 Linux。
- **开源与可扩展**：基于 Apache 2.0 许可，完全开源，开发者可自由扩展工具集、定制沙箱策略并集成至自有工作流。

## 技术架构

Maka 使用 TypeScript 作为主要开发语言，保证了代码的类型安全性和可维护性。在架构设计层面，项目遵循几个关键原则：

首先是**事件溯源（Event Sourcing）**。所有系统状态变化被建模为一系列有序事件，并持久化到仅追加的日志中。这种设计带来显著优势：不仅支持完整的审计回溯，还能在任意时间点重建系统状态，对于 AI 调试和性能分析极具价值。无论是模型生成的消息、工具执行的输入输出，还是权限校验的结果，都以结构化事件形式存储。

其次是**严格边界分离**。Maka 将 AI 模型、工具执行器和权限决策引擎作为独立组件隔离，通过明确定义的接口通信。沙箱边界确保工具运行不会直接影响操作系统核心资源，降低了误操作或恶意行为带来的风险。

第三是**本地优先的存储策略**。事件日志和项目元数据默认存储于用户本机，避免了不必要的网络传输和云端依赖。同时，这种架构也为未来可选的同步或多人协作功能预留了扩展空间。

在交互层面，Maka 桌面应用提供了图形化界面，便于用户直观地查看事件流、审查工具调用和调整权限策略。整个系统设计强调透明性、可控性和可审计性，这也是它与众多“黑盒” AI 助手最大的区别。

## 安装与使用

### 安装步骤

1. **系统要求**：目前支持 macOS（Apple Silicon 芯片）和 Windows（预览版）。Linux 版本正在开发中，暂不建议使用。
2. **获取安装包**：
   - macOS 用户可直接从 [GitHub Releases](https://github.com/apache/maka/releases) 下载 `.dmg` 安装文件。
   - Windows 用户可下载未签名的预览版安装程序，安装时需忽略 SmartScreen 提示。
3. **安装与启动**：按照操作系统标准流程完成安装，首次启动会引导创建本地工作区。

### 最小使用示例

```bash
# 示例：在命令行中启动 Maka 并加载项目目录
maka run --project /path/to/your/project

# 查看当前工作区的事件日志
maka log --tail 50

# Windows 用户如果使用开发版本，可先通过 npm 全局安装
npm install -g @apache/maka-cli
maka --help
```

启动后，Maka 会扫描项目结构，允许用户通过自然语言与 AI 代理交互。所有模型消息和工具调用都会实时反映在事件日志中，用户可随时查看 Agent 的决策依据和操作结果。有关更完整的配置说明和 API 文档，建议查阅仓库内 `docs/` 目录。

## 适用场景

1. **安全敏感的项目开发**：企业开发团队在处理具备商业机密或合规要求的代码时，可以利用 Maka 的沙箱机制和事件日志，确保 AI 助手的每次操作都有迹可循，并满足内部审计要求。

2. **AI Agent 行为研究与调试**：AI 研究人员需要观察模型如何推理、为何做出某些工具调用时，Maka 的不可变日志提供了宝贵的第一手数据，有助于提高模型的可解释性和调试效率。

3. **自动化运维与代码重构**：开发人员可以委托 Maka 在本地沙箱中执行批量代码替换或重构任务，利用严格的权限审批机制和完整日志记录来降低误操作风险，一旦发现问题可以快速定位到具体操作。

4. **个人知识工作者的可信助手**：对于需要处理个人敏感信息（如财务数据、私人文档）的用户，本地优先架构确保数据不出个人电脑，配合透明的决策日志，让用户放心将日常数据处理任务交给 AI 执行。

## 项目亮点

与市面上其他 AI Agent 工具相比，Maka 拥有以下差异化优势：

- **全面事件审计**：大多数 AI Agent 工具仅记录对话历史，而 Maka 将工具调用、权限决策、终止条件等全部固化为不可变事件流，提供了业界罕见的细粒度审计能力。
- **真正的沙箱隔离**：Maka 在 Agent 与系统之间建立了清晰的安全边界，而不只是依赖提示词约束模型行为，从机制上降低了风险。
- **本地优先承诺**：无需注册账号、无需上传数据到云端，这一设计特别契合企业对数据主权的要求，也让使用体验更简洁高效。
- **中英双语支持**：项目提供完整的中文文档（README.zh-CN.md），为中文开发者降低了上手门槛，这是很多国际开源项目尚不具备的本地化优势。
- **Apache 治理背书**：作为 Apache 孵化项目，Maka 遵循开放、透明的社区治理模式，长期可持续性和代码质量均有保障。
