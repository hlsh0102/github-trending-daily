## 项目概述

`andrej-karpathy-skills` 是一个极简但极具影响力的开源项目，其核心交付物仅为一个 `CLAUDE.md` 文件，用于系统性改善 Claude Code 等 AI 编程助手的行为模式。该项目源自 Andrej Karpathy 在社交媒体上对 LLM（大语言模型）编码常见缺陷的深刻观察，将这些观察转化为四条可执行的原则，帮助开发者约束和引导 AI 编码工具，使其更加可靠、严谨和高效。

项目主要解决的是当前 LLM 编程工具在实际使用中普遍存在的三大类问题：**错误假设**（模型替开发者做决定而不验证）、**过度设计**（代码臃肿、抽象泛滥）以及**破坏性编辑**（在任务之外误改无关代码）。目标用户是所有使用 Claude Code、Cursor 等 AI 编程助手的开发者，尤其是那些希望在团队中建立统一 AI 协作规范的技术负责人。

## 核心功能

- **Think Before Coding（先思后码）**：强制模型在生成代码前先阐述其对问题的理解、识别潜在的不确定性，并主动向开发者提问澄清，而非仅凭猜测直接动手。
- **Simplicity First（简约优先）**：明确引导模型倾向使用最直接的方案解决问题，避免创建不必要的抽象层、过度设计 API 或为实现小功能编写数百行冗余代码。
- **Surgical Changes（外科手术式修改）**：严格限制 AI 的修改范围，确保它只触碰与当前任务直接相关的代码和注释，杜绝“顺手”改动行为，避免因领域知识不足而破坏原有逻辑。
- **Goal-Driven Execution（目标驱动执行）**：引导模型始终围绕任务的最终目标优化执行路径，避免在非关键细节上耗费过多轮次，提升迭代效率。

## 技术架构

项目的技术架构极为精简，体现了“约定优于配置”的设计理念。其核心是一个遵循 Claude Code 规则的 `CLAUDE.md` 文件，该文件使用 Markdown 语法编写，被 Claude Code 自动加载为系统级行为准则。

设计思路并非罗列大量命令或奇技淫巧，而是模仿 Karpathy 提出的“脑内激励”（thought prompts）机制，将四条宏观原则转化为模型在每次响应前会自我提示的具体问题清单。例如，“Think Before Coding”原则会要求模型在代码块之前，先展示 `# Step 1: Understand the problem` 等结构化思考步骤。这种设计使得文件可以被轻松移植到任何支持指令文件的 AI 编码工具（如 Cursor 的 `.cursorrules`）中，具有极高的通用性和可维护性。

## 安装与使用

使用此项目非常简单，只需将 `CLAUDE.md` 文件复制到您的项目根目录或用户级别的 `~/.claude/` 目录中。推荐将其放置在项目根目录，以便团队所有成员共享同一套 AI 行为准则。

**最小可用示例：**

1. 克隆或下载本仓库。
2. 将 `CLAUDE.md` 复制到您的项目根目录下。
3. 重新启动 Claude Code（或重新加载会话），使其读取新规则。
4. 正常发起编程任务，例如：“请修复 `utils.py` 中的函数 `calculate_total` 在输入为空列表时崩溃的问题。”

之后，Claude Code 的响应将呈现以下变化：它会先输出对问题根因的分析、确认假设、提出至少一个澄清问题（如果信息不足），然后给出最小化的修复代码，并明确声明未改动其他无关部分。

## 适用场景

- **个人开发者日常编码**：作为开发者的“AI 副驾驶”行为守则，确保工具不“越权”自作聪明，减少代码审查时的返工量。
- **团队协作与代码审查**：当团队使用 Claude Code 进行代码生成时，统一的行为规范可以显著降低因 AI 生成风格差异导致的合并冲突和审查成本。
- **学习与教学**：该文件的原理部分（对 Karpathy 帖子的归纳）本身即为一份极佳的提示工程（Prompt Engineering）教学案例，适合作为 AI 编程实践课程的辅助材料。
- **开源项目贡献**：在大型开源项目中，设置此文件可以有效防止 AI 提交“附带修改”，守护项目的代码整洁和提交历史清晰度。

## 项目亮点

与市面上众多“规则大全”类的 AI 提示词项目不同，本项目的差异化优势在于其 **“少即是多”** 的哲学。它仅用一个文件、四条原则，直击 LLM 编码中最核心的痛点，避免了规则间的相互冲突和冗余。

此外，项目具有极强的**可溯源性和权威性**。所有规则并非凭空捏造，而是源自 Andrej Karpathy 这位 AI 领域顶尖专家的一线观察，每条原则均对应其具体的痛点陈述，这使得内容极具说服力和针对性。同时，它**不绑定特定工具**，可轻松适配 Claude Code、Cursor 等多种主流环境，具有极佳的生态兼容性。
