## 项目概述

OpenLogi 是一款开源的 Logitech 外设配置工具，旨在替代罗技官方的 Options+ 软件。项目以 Rust 语言编写，采用原生、本地优先的设计理念，通过 HID++ 和 UVC 协议直接与罗技鼠标、键盘、网络摄像头等设备通信，让用户无需安装罗技官方软件或注册账号即可解锁设备的全部功能。

该项目由 AprilNEA 发起并维护，目前处于积极开发阶段，功能与配置格式仍在持续迭代中。对于追求设备控制自由、关注隐私保护、或对罗技官方软件臃肿体积与遥测功能感到不满的用户来说，OpenLogi 提供了一个轻量、透明的替代方案。

## 核心功能

- **按键重映射**：支持对鼠标、键盘的任意按键进行功能重映射，可自定义为组合键、多媒体键、宏命令或系统操作。
- **DPI 调节**：直接通过 HID++ 协议修改鼠标 DPI 设置，支持多档位切换与自定义灵敏度值。
- **SmartShift 支持**：兼容罗技的 SmartShift 功能，允许在滚轮的无极滚动与刻度滚动模式间自动或手动切换。
- **多设备配置管理**：为不同型号的罗技设备提供独立的配置存储，支持配置文件的导入与导出。
- **本地优先与隐私保护**：所有配置数据仅保存在本地，不包含账户系统、无遥测收集、无网络请求。
- **跨平台支持**：作为原生应用运行，支持多操作系统平台，性能优秀且资源占用低。

## 技术架构

OpenLogi 的核心架构基于 Rust 语言构建，利用其内存安全、零成本抽象和出色的并发能力来实现高性能的硬件通信。项目直接使用 HID++ 2.0/4.0 协议与罗技设备通信，绕过了官方软件私有的协议封装，使得数据交互更加简洁透明。

对于带摄像头的罗技设备，OpenLogi 引入了 USB Video Class（UVC）协议支持，实现摄像头参数的本地控制。现代架构中，项目将 UI 与底层驱动分离，当前版本采用 Tauri 框架构建桌面界面，利用系统 WebView 渲染，前端与 Rust 后端通过 IPC 通信，兼顾开发效率与运行性能。

设备通信层使用 rusb 或 hidapi 等库实现对 USB HID 的底层访问，通过异步运行时处理多个设备之间的并发事件流。配置存储采用轻量级格式（如 JSON 或 TOML），确保读取与写入的高效性，同时方便用户的版本管理与迁移。

## 安装与使用

OpenLogi 目前处于开发阶段，尚未发布正式稳定版本。可以从 GitHub Releases 页面获取预构建的安装包，或从源码自行编译。

**从源码编译（需 Rust 工具链）：**

```bash
# 克隆仓库
git clone https://github.com/AprilNEA/OpenLogi.git
cd OpenLogi

# 安装系统依赖（以 Ubuntu 为例）
sudo apt install libgtk-3-dev libayatana-appindicator3-dev

# 编译运行（开发模式）
cargo tauri dev
```

**最小使用示例：**

1. 连接罗技设备到电脑，启动 OpenLogi。
2. 应用会自动检测并列出所有兼容的 HID++ 设备。
3. 选择目标设备，进入按键配置面板。
4. 点击需要修改的按键，从弹出菜单中选择功能（如“媒体播放/暂停”“音量调节”或自定义快捷键）。
5. 调整 DPI 设置，移动滑块至偏好的灵敏度数值。
6. 保存配置，设置会立即通过 HID++ 指令写入设备。

## 适用场景

- **隐私敏感用户**：不希望安装罗技官方软件、接受任何形式的用户行为追踪或遥测数据上传的用户。
- **跨平台开发者或设计师**：需要在 Linux、部分 BSD 等官方 Options+ 不支持的系统上使用高级鼠标功能的人群。
- **追求极致性能者**：减少后台常驻内存占用，拒绝 Electron 等重型框架的消费者硬件用户。
- **定制化玩家**：希望突破官方软件限制，为不同游戏或应用程序设置完全独立的按键与 DPI 配置文件的人群。

## 项目亮点

与罗技官方 Options+ 及同类配置工具相比，OpenLogi 的差异化优势明显：

- **本地优先，零遥测**：应用完全离线工作，不创建任意后台网络连接，充分尊重用户隐私。
- **原生性能**：基于 Rust 构建的二进制文件启动迅速，内存占用低，响应速度快，远优于基于 Electron 的官方工具。
- **协议透明**：直接以 HID++ 协议通信，不包含任何闭源组件，有利于社区审查与贡献扩展。
- **跨平台覆盖更广**：原生支持 Linux 等罗技官方软件未覆盖的系统，填补市场空缺。
- **轻量配置文件**：基于文本的配置格式便于版本管理与自动化配置脚本，高级用户可以轻松编写配置模板。
