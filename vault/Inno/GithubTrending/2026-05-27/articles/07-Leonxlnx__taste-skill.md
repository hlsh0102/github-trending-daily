## 项目概述

Taste-Skill 是一个为 AI 代理设计的“反平庸”前端框架，旨在解决生成式 AI 在构建用户界面时普遍存在的低质量、模板化输出问题。当开发者使用 Codex、Cursor、Claude Code 等 AI 编程工具生成前端界面时，常常得到千篇一律、缺乏设计美感的“样板间”页面——无论是布局、排版、动效还是间距，都显得生硬粗糙。

该项目通过提供一套可移植的 **Agent Skills**（代理技能），为 AI 注入“好品味”，使其生成的界面具备更强的布局结构、更精致的排版、更流畅的动效以及更合理的间距控制。此外，它还包含面向图像生成的能力，用于制作参考版（Web、移动端、品牌套件），可与 ChatGPT Images 等图像生成工具配合使用，再将生成的界面框架交给代码生成工具进行实现。

项目目标用户包括：使用 AI 辅助编码的前端开发者、希望快速获得高质量 UI 原型的极客用户、以及追求视觉品味的独立开发者和小团队。

## 核心功能

- **布局增强**：AI 生成的界面不再使用默认的居中布局或简单横向排列，而是获得更复杂的多栏、不对称、栅格化布局能力，适应更真实的用户界面需求。
- **排版升级**：内置细粒度排版规则，避免 AI 使用无差异的通用字体与字号组合，代之以层次清晰、字重合理、行距考究的排版方案。
- **动效注入**：通过预定义的动效规则，让生成的界面具备平滑过渡、悬停反馈、入场动画等交互细节，提升用户体验。
- **间距精细化**：解决 AI 常犯的“间距失调”问题——元素挤在一起或过度留白——通过语义化间距变量确保视觉节奏一致。
- **图像生成参考板**：提供 Web、移动端、品牌套件等类型的图像生成技能，可生成高质量参考图作为设计指引，再交由代码工具实现。
- **工具链兼容**：直接兼容 Codex、Cursor、Claude Code 等主流 AI 编程工具，无需额外适配。

## 技术架构

Taste-Skill 的核心设计理念是 **“技能即配置”**——一组自包含的规则和提示词集合，而非传统意义上的软件库或 NPM 包。项目主要由 Shell 脚本和 Markdown 文档构成，通过结构化的提示词描述前端设计的最佳实践。

技术实现上，它采用分层架构：
1. **技能规则层**：明确定义布局、排版、动效、间距等维度的“好品味”标准，每条规则都有具体的数值范围或原则描述。
2. **提示工程层**：将设计规则转化为 AI 可理解的提示词模板，确保 AI 能够准确执行。
3. **集成适配层**：提供与主流 AI 编程工具的集成脚本，一键激活所有技能。

这种轻量化设计使得无论使用何种底层 AI 模型，只要正确加载技能，都能显著改善输出质量。项目本身不依赖任何前端框架或运行时，完全通过 AI 提示词层面进行干预。

## 安装与使用

**快速安装**（适用于 macOS/Linux 终端）：

```bash
# 克隆仓库
git clone https://github.com/Leonxlnx/taste-skill.git

# 进入项目目录
cd taste-skill

# 执行安装脚本（将技能注入到 AI 工具配置中）
./install.sh
```

**最小可用示例**：

1. 安装完成后，启动 Codex、Cursor 或 Claude Code。
2. 输入一个常见的前端界面构建提示，例如：
   > "生成一个 SaaS 产品的定价页面，包含三种套餐方案，使用 Taste-Skill 增强布局和排版。"
3. 观察输出与未使用 Taste-Skill 时的差异——此时生成的界面将具备更精良的布局结构、一致的间距系统、以及更富有层次的排版与动效。

若需生成参考图像，可在支持图像生成的工具中（如 ChatGPT Images）加载对应的图像技能规则后描述需求。

## 适用场景

- **SaaS 产品界面构建**：快速生成包含定价页、仪表盘、设置页等常见页面的高质量原型，避免千篇一律的模板化设计。
- **移动端应用 UI 设计**：利用移动端参考板技能生成 App 界面框架，配合工具链实现从设计到代码的顺畅过渡。
- **品牌套件快速初始化**：生成品牌色彩、字体、组件等设计系统雏形，作为团队视觉规范的起点。
- **前端原型验证**：在概念验证阶段快速产出视觉上可接受的界面，加速与客户或团队的设计评审过程。

## 项目亮点

- **轻量化反范式设计**：不像传统 UI 库那样提供组件代码，而是从 AI 的思考层面进行干预，从根本上改善生成质量。
- **零运行时依赖**：不引入任何前端框架或第三方库，对项目无侵入性，安装后即可生效。
- **工具链透明适配**：直接兼容主流 AI 编程工具，无需学习新的工作流或 API。
- **持续更新的品味规则**：随前端设计趋势迭代，社区驱动完善，确保 AI 始终输出符合当代审美的界面。
- **开源与社区化维护**：MIT 许可证，用户可自由修改、扩展技能规则，形成针对特定需求的定制版本。
