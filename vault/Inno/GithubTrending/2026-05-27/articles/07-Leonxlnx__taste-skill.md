## 项目概述

Taste-Skill 是一套专为 AI 代理设计的“反模板化”前端技能框架。它解决的核心问题是：当前 AI 生成的用户界面往往千篇一律、缺乏设计感，呈现出“样板房”式的平庸视觉效果。该项目通过提供可移植的 Agent Skills，赋予 AI 对布局、排版、动效和间距等前端要素的“审美判断力”，使其能够生成更具专业设计感的界面。

目标用户包括使用 Codex、Cursor、Claude Code 等 AI 编程工具的前端开发者、UI 设计师，以及希望通过 AI 提升产出质量的创意工作者。项目不仅关注代码生成，还延伸到图像生成领域，支持生成参考板（网页、移动端、品牌套件）等视觉素材。

## 核心功能

- **布局增强能力**：提供强化布局结构的技能，使 AI 生成的分栏、网格、对称/不对称排列更加专业，避免常见的松散或拥挤布局
- **排版与字体策略**：内置字体搭配方案和排版规则，帮助 AI 正确选择字重、字号层级与行高，呈现更具可读性和视觉层次感的文字内容
- **动效与微交互**：指导 AI 在界面中加入合理的过渡动画、悬停效果和微交互，提升用户体验的流畅度和精致感
- **间距系统**：建立统一的间距规范，使 AI 生成的元素间距、内边距和外边距保持一致且符合设计系统逻辑
- **图像生成技能**：支持生成参考板、视觉概念图、品牌套件和组件演示图，可与 ChatGPT Images 等图像生成工具配合使用
- **跨工具兼容**：设计为与多种 AI 编程工具（Codex、Cursor、Claude Code 等）兼容，提供统一的前端“品味”标准

## 技术架构

Taste-Skill 采用轻量级的 Shell 脚本作为主要实现语言，核心设计思路是“技能即配置”——将设计规范和审美规则编码为可被 AI 代理理解和执行的指令集。

架构特点：
- **声明式规则系统**：将设计原则转化为结构化的指令，AI 代理在执行任务时读取这些规则并应用到前端代码生成中
- **模块化技能包**：每个设计维度（布局、排版、动效、间距）作为独立模块，可以按需加载组合
- **中介层设计**：在人机之间建立审美共识层，一方面将人类设计师的经验转化为机器可读的规则，另一方面确保 AI 输出的结果符合高质量的设计标准
- **可移植性优先**：不绑定特定的 AI 工具或前端框架，技能可以通过标准化的导入方式添加到任何兼容的 AI 代理工作流中

## 安装与使用

**前提条件**：需要安装 Git 以及支持 Agent Skills 的 AI 编程工具（如 Codex、Cursor、Claude Code）。

**安装步骤**：

```bash
# 克隆仓库
git clone https://github.com/Leonxlnx/taste-skill.git

# 进入目录
cd taste-skill

# 赋予脚本执行权限
chmod +x install.sh

# 运行安装
./install.sh
```

**最小可用示例**：

安装完成后，可在 AI 编程工具中加载技能包。例如在 Cursor 中使用：

```
@taste-skill 为这个 React 组件应用布局增强和对齐规则
```

或通过 Shell 直接调用：

```bash
# 激活布局技能包
source skills/layout.sh

# 应用排版技能到指定文件
taste-typography ./src/components/header.jsx
```

## 适用场景

- **快速原型设计**：产品团队使用 AI 生成界面试样时，Taste-Skill 确保产出物具有基础审美水准，减少反复修改的时间
- **前端开发辅助**：开发者在编写复杂布局和组件时，通过加载技能包让 AI 补全符合设计规范的结构和样式
- **设计师与 AI 协作**：设计师先用参考板功能生成视觉概念图，再将图像传递给 AI 编程工具进行实现，Taste-Skill 在中间充当审美翻译器
- **教育场景**：学习前端开发的人员可以通过分析技能包的设计规则，理解专业 UI 背后的设计原则

## 项目亮点

与同类项目相比，Taste-Skill 的差异化优势体现在：

- **聚焦审美层面**：传统前端 AI 框架关注功能实现和代码质量，Taste-Skill 专门解决“好看”的问题，填补了 AI 生成 UI 美的空白
- **轻量可移植**：不依赖重量级框架或复杂的配置系统，通过 Shell 脚本实现核心功能，兼容性极强
- **双向工作流**：同时覆盖代码生成和图像生成两个维度，形成从视觉概念到代码实现的全链路审美把控
- **社区增长强劲**：GitHub 星数达 22,000+，日增 1,430+，反映出市场需求和社区的积极反响
