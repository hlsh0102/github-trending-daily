## 项目概述

Understand Anything 是一个能够将任意代码库、知识库或文档转化为交互式知识图谱的开源工具。它解决了开发者在理解复杂代码结构、文档体系或技术概念时面临的认知负担——传统方式需要逐行阅读代码或文档，难以快速建立整体认知。该项目的目标用户包括软件开发者、技术文档撰写者、AI 编程助手用户（如 Claude Code、Codex、Cursor、Copilot 等）、以及任何需要快速理解复杂信息体系的知识工作者。

## 核心功能

- **一键生成知识图谱**：将任意代码库或文档内容自动解析为结构化的知识图谱，节点代表模块/概念，边代表依赖或关联关系。
- **交互式探索**：支持缩放、拖拽、点击节点展开详情，用户可以在图谱中自由导航，从宏观结构深入微观细节。
- **语义搜索**：基于图谱的自然语言搜索，用户可以用提问的方式查询代码逻辑、API 定义或文档要点。
- **AI 问答集成**：与主流 AI 编程助手深度集成，用户可以在 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等工具中直接调用知识图谱进行上下文丰富的问答。
- **多格式支持**：不仅支持代码文件（支持主流编程语言），也能处理 Markdown 文档、配置文件、API 规范等知识库内容。
- **导出与分享**：支持将知识图谱导出为图片或交互式 HTML 文件，方便团队协作或文档归档。

## 技术架构

Understand Anything 使用 TypeScript 作为主要开发语言，技术架构分为三层：

**解析层**：采用模块化的语言解析器，针对不同文件类型（代码、文档、配置）调用对应的解析引擎。代码解析支持 AST（抽象语法树）分析，提取函数、类、模块、依赖关系；文档解析则通过正则与 NLP 技术提取章节结构、术语定义和引用关系。

**图谱构建层**：将解析结果映射为图数据结构，节点（Node）存储实体信息，边（Edge）表示关联类型（如“依赖”、“继承”、“引用”）。内部使用高效的图数据库或内存图引擎（如 Neo4j 或 custom Graph），支持增量更新和缓存。

**交互层**：基于 Web 技术栈（React + D3.js/WebGL）实现前端可视化组件，支持高帧率渲染大规模图（数千节点）并保持流畅交互。接口层提供 RESTful API 和 WebSocket，方便外部工具（如 AI 编程助手）调用查询。

项目的关键设计思路是“解析-索引-查询”分离：解析任务可离线批量执行，索引过程支持增量，查询响应在毫秒级别。这保证了即便在处理大型项目（百万行代码级别）时，知识图谱的构建和探索依然高效。

## 安装与使用

**前提条件**：Node.js 18+ 和 Git。

**安装步骤**：

```bash
# 克隆仓库
git clone https://github.com/Lum1104/Understand-Anything.git
cd Understand-Anything

# 安装依赖
npm install

# 构建项目
npm run build

# 启动服务
npm start
```

**最小可用示例**：在项目根目录下，使用以下命令将当前代码库转化为知识图谱：

```bash
npx understand --input ./my-project --output ./graph
```

然后打开浏览器访问 `http://localhost:3000`，即可看到交互式知识图谱。如果想要在 Claude Code 中集成，只需在对话中引用生成的图谱文件路径。

更高级用法包括指定语言过滤器（`--lang python,javascript`）、深度限制（`--depth 3`）和排除路径（`--exclude node_modules`）。

## 适用场景

- **新成员入职快速掌握项目**：团队成员接手遗留代码或新项目时，无需逐行阅读，通过知识图谱即可理解模块依赖、核心逻辑和关键接口。
- **大型代码库重构与评审**：在进行架构重构或代码评审时，图谱能清晰展示模块间的耦合关系，帮助识别高危区域。
- **AI 辅助开发深度集成**：开发者在使用 Claude Code 或 Copilot 时，将知识图谱文件作为上下文注入，AI 能给出更准确的代码建议和问题回答。
- **文档体系可视化维护**：技术团队可以将内部文档库（API 说明、架构设计、会议纪要）转化为知识图谱，搜索和回溯效率大幅提升。

## 项目亮点

与同类工具（如代码依赖图生成器、静态分析工具）相比，Understand Anything 的核心差异化优势在于：

1. **全认知覆盖**：不仅分析代码依赖，还能整合文档、配置、注释等多维信息，真正实现“理解一切”。
2. **AI 原生集成**：专为 AI 编程助手设计，提供标准化接口和上下文输出格式，而非仅提供静态图表。
3. **交互式探索**：用户可以在图谱中自由导航、提问、过滤，动态调整理解深度，而不是一次性输出一张固定图片。
4. **零配置使用**：开箱即用，无需手动配置语言解析器或数据库，对常见项目目录结构自动适配。
5. **开放生态**：支持多种语言和工具链，不锁定于特定 AI 平台，用户可以自由组合使用。
