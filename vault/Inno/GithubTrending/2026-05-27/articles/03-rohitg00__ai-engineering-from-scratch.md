## 项目概述

AI Engineering from Scratch 是一份面向 AI 工程实践的全面开源课程体系。项目旨在解决当前 AI 教育中的一个核心矛盾：大量学生已经在使用 AI 工具，但只有极少数人具备将其投入专业生产环境的能力。根据项目引用的数据，84%的学生已经使用 AI 工具，但仅 18%的人认为自己做好了专业使用的准备。

该项目提供了一套从零基础到专业水平的渐进式学习路径，包含 435 节课程、20 个阶段，总学习时长约 320 小时。课程覆盖 Python、TypeScript、Rust 和 Julia 四种编程语言，每节课都会产出可复用的成果，包括提示词模板、技能模块、AI 智能体或 MCP 服务器。项目完全免费、开源，采用 MIT 协议。

## 核心功能

- **渐进式课程结构**：从基础概念起步，逐步深入到高级工程实践，每个阶段都建立在前一阶段的基础之上
- **多语言支持**：使用 Python、TypeScript、Rust 和 Julia 四种语言授课，覆盖 AI 工程中常见的工具栈
- **产出导向学习**：每节课不仅讲解理论，更要求学习者产出可复用的工程制品（prompt、skill、agent、MCP server）
- **端到端实践**：涵盖从数据处理、模型训练到部署运维的完整 AI 工程链条
- **社区驱动更新**：项目在 GitHub 上持续维护，根据 AI 技术发展动态调整课程内容
- **20 个独立阶段**：每个阶段聚焦一个 AI 工程子领域，便于学习者按需选择学习路径

## 技术架构

该项目采用模块化的课程设计架构。整个课程体系被划分为 20 个独立的阶段，每个阶段聚焦特定的 AI 工程主题。这种设计允许学习者根据自己的背景和目标灵活选择学习路径，而不必从头到尾全部学完。

在技术栈选择上，项目采用了 Python 作为主要教学语言（这是 AI 领域最广泛使用的语言），同时引入 TypeScript（用于 Web 端 AI 应用开发）、Rust（用于高性能 AI 系统）和 Julia（用于科学计算和原型设计）。这种多语言策略反映了真实 AI 工程中的多语言协作现实。

每节课的 "shipping" 机制是项目的核心创新——学习者不是被动吸收知识，而是主动构建可工作的 AI 系统组件。这种实践驱动的方式确保了知识能够转化为实际工程能力。

## 安装与使用

要开始学习，首先克隆项目仓库：

```bash
git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
```

各个阶段的学习材料以目录和 Markdown 文件的形式组织。建议从第一阶段开始，按照 README 中的指引逐步推进。对于每个阶段，先阅读介绍文档了解该阶段的目标和前置知识，然后按照课程顺序完成各个模块的学习和实践。

项目不依赖特定的运行环境，所有示例代码均可在标准开发环境中执行。建议使用 Python 3.10+、Node.js 18+、Rust 1.70+ 和 Julia 1.9+ 以获得最佳兼容性。

## 适用场景

- **计算机科学/数据科学学生**：希望将课堂理论知识转化为可上手的 AI 工程技能，弥补校内教育与工业实践之间的差距
- **转行进入 AI 领域的开发者**：已有编程基础但缺乏 AI 工程经验，需要一个系统化的学习路径来快速进入 AI 工程领域
- **寻求职业进阶的 AI 工程师**：已经掌握 AI 基础但希望拓宽技能栈（如学习 Rust 或 Julia），或进一步提升工程化能力的专业人士
- **技术团队培训**：企业或组织内部培训 AI 工程团队时，可以将本课程作为系统化的参考教材

## 项目亮点

AI Engineering from Scratch 与传统 AI 课程最大的区别在于其 "learn it, build it, ship it" 的教学理念。大多数 AI 课程止步于讲解原理和展示示例，而该课程要求学习者每节课都产出可运行的工程制品。这种 "教学产出" 模式确保了知识的真正内化。

另一个显著优势是其多语言覆盖。主流 AI 课程通常只使用 Python，但现实中的 AI 工程需要 TypeScript 来构建界面、需要 Rust 来优化性能瓶颈、需要 Julia 来做快速原型。该项目是少数真正触及多语言 AI 工程实践的课程体系。

课程的高频率更新也是重要亮点。在 AI 技术日新月异的当下，一个固定内容的课程很快就会过时。该项目在 GitHub 上以 MIT 协议开源，社区可以贡献更新，课程内容保持了较高的时效性。
