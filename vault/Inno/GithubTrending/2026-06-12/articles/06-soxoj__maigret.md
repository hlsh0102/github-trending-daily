## 项目概述

Maigret 是一款开源的人物档案收集工具，主要功能是通过用户名在超过 3000 个网站中搜索并聚合公开信息。用户只需要提供一个用户名，Maigret 就能自动遍历数以千计的社交平台、论坛、社区等在线站点，检查该用户名是否被注册，并提取页面中公开的个人资料、简介、头像、地理位置等元数据，最终生成一份结构化的人物档案报告。

该项目解决了以下核心问题：在互联网上分散于数百个平台的数字身份信息难以集中获取，传统的人工搜索方式效率极低且容易遗漏。Maigret 通过大规模站点覆盖和自动化提取，将数小时的手动工作压缩到几分钟内完成。它的目标用户包括安全研究人员、渗透测试工程师、数字取证分析师、记者，以及任何需要从公开渠道快速了解某人数字足迹的从业人员。项目采用 MIT 开源许可协议，Python 3.10+ 环境即可运行，无需任何商业 API 密钥。

## 核心功能

- **大规模站点覆盖**：内置超过 3000 个目标站点的检测规则，涵盖主流社交网络、编程社区、图床、论坛、电商平台、博客服务等，且规则文件可自由扩展。
- **零 API 依赖**：所有检测均通过模拟浏览器请求或解析公开页面完成，完全不需要注册任何第三方 API 密钥或支付费用。
- **智能检测算法**：针对不同站点的页面结构，自动选择最有效的检测方法（如 URL 模式匹配、HTML 解析、JSON API 响应分析），支持验证码或反爬机制的站点会绕过或标记失败。
- **多格式报告输出**：支持生成 HTML、JSON、PDF、屏幕截图等多种格式的报告，JSON 输出便于程序化处理，HTML 报告包含可视化摘要和链接直达功能。
- **AI 概要生成**（实验性）：集成大型语言模型，可自动从已提取的原始数据中提炼出人物概要，包括可能的身份描述、职业推测、地域关联等，但对于隐私风险敏感场景可完全禁用此功能。
- **代理与并发控制**：内置 SOCKS/HTTP 代理支持，可设置请求延迟和并发度，避免对目标站点造成过大负载，同时适应不同网络环境。

## 技术架构

Maigret 采用模块化设计，核心分为三层：

**引擎层**：基于 asyncio 异步框架的请求调度器，负责管理并发连接池和代理轮换。所有站点检测任务以协程形式并发执行，充分利用 I/O 等待时间。引擎内置了智能重试和错误分类逻辑：将 4xx/5xx 错误识别为站点拒绝请求（标记为“可能存在”但无法确认），将超时或连接重置视为“不确定”，将 200 OK 但内容不匹配视为“未找到”。

**检测器层**：每个目标站点对应一个检测器（检测器以 YAML 格式定义），包含 URL 模板、请求头参数、响应验证规则（检查页面中是否包含指定文本、元素、HTTP 状态码或正则模式）。检测器分为“强检测”（能确认用户名确实存在）和“弱检测”（只检查 URL 可访问性，存在假阳性可能）。用户可通过 `--sites` 参数按类别（如 `social`, `forums`）或具体名称筛选检测范围。

**输出层**：收集所有有效结果后，调用报告生成器。HTML 报告使用 Bootstrap 框架提供响应式布局，每个发现结果按站点分类并用不同颜色的徽章标识可信度。JSON 报告返回完整的数据结构，包括站点名称、用户名、提取的 tag/description/location 等字段。PDF 报告通过 Playwright 截取 HTML 报告内容生成。

项目的核心设计思路是“通用性优先”——通过统一的检测器定义格式支持任意站点，无需修改代码即可添加新站点；同时保持“可预测性”——对所有检测失败或不确定的结果都明确标记，避免误导使用者。

## 安装与使用

**安装方式**（任选其一）：

```bash
# 通过 pip 安装（推荐）
pip install maigret

# 从 GitHub 源码安装
git clone https://github.com/soxoj/maigret.git
cd maigret
pip install -r requirements.txt
python setup.py install

# Docker 方式
docker build -t maigret .
docker run -it maigret <username>
```

**最小可用示例**：

```bash
# 基础搜索：检查 johndoe 这个用户名在全部站点上的注册情况
maigret johndoe

# 指定输出格式为 JSON，保存到文件
maigret johndoe --json --output report.json

# 只检查社交类站点，并设置 10 秒超时
maigret johndoe --sites social --timeout 10

# 启用代理，并使用 3 个并发连接
maigret johndoe --proxy socks5://127.0.0.1:1080 --max-connections 3
```

**重要提示**：首次运行时会自动下载并缓存最新的站点规则包。所有检测结果仅基于公开页面信息，不涉及破解或未授权访问。建议搭配 `--timeout` 和 `--max-connections` 参数控制请求频率，避免被目标站点封禁 IP。

## 适用场景

- **安全评估 & 渗透测试**：在获得授权的前提下，通过发现测试目标在 GitHub、LinkedIn、Stack Overflow 等站点的账号，快速绘制其数字身份图谱，辅助社会工程学攻击面分析。
- **数字取证 & 开源情报（OSINT）**：调查人员通过已知用户名追溯嫌疑人在多个平台的活动轨迹，收集公开信息中的位置标记、职业经历、联系方式等线索。
- **企业账号风控**：企业安全团队使用 Maigret 验证新注册用户的唯一性，或批量检查离职员工是否在非授权平台使用公司相关用户名。
- **个人隐私自查**：普通用户可以用自己的用户名搜索，快速了解自己的哪些数字足迹被公开暴露，从而有针对性地调整隐私设置或删除无关账号。

## 项目亮点

- **规模碾压**：3000+ 站点的覆盖量远超同类工具（如 Sherlock 约 400+ 站点），并且在持续更新中，社区可通过 Pull Request 轻松贡献新站点。
- **零成本运行**：完全无需任何第三方 API 密钥或付费服务，适合预算有限的个人研究者和小型团队。所有规则都是开源可审计的。
- **报告丰富度**：其他类似工具通常只返回“存在/不存在”的二元结果，Maigret 能够从页面中提取头像、简介、位置等元数据，生成结构化、带可视化图表的报告，信息密度更高。
- **AI 辅助分析**：虽然仍在实验阶段，但 AI 概要将无结构文本自动转换为人物描述，在 OSINT 工作流中节省大量手动梳理时间。该功能默认关闭，需要时通过 `--ai` 参数启用。
- **工程化程度高**：支持异步 I/O、代理轮换、错误自动分类、站点分类筛选、Docker 容器化部署等特性，经得起生产环境大规模使用的考验。
