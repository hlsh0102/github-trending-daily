## 项目概述

PM Skills Marketplace 是一套为人工智能助手（特别是 Claude Code 和 Cowork）设计的技能、指令和插件集合，旨在将产品管理（PM）的最佳实践系统化地融入 AI 工作流程。该项目解决了“通用 AI 只生成文本，但缺乏结构化思考框架”的痛点，为产品经理提供了一个开箱即用的“AI 操作系统”，帮助用户从产品发现、战略制定、执行落地到发布增长的全链路做出更优决策。目标用户包括产品经理、创业者、技术负责人以及任何参与产品决策的从业者。

## 核心功能

- **结构化技能库**：包含 68 个独立 PM 技能，每个技能编码了经过验证的 PM 框架，如用户探索、假设映射、优先级排序、战略规划等，引导 AI 按步骤输出结构化分析。
- **链式工作流**：42 个可串联的预定义工作流，覆盖从产品发现到代码交付的完整周期，支持多技能自动编排，减少手动切换。
- **插件系统**：9 个插件分别对应不同场景（如发现、战略、执行、发布、增长），实现领域内的高效垂直封装。
- **快速启动指令**：提供 `/discover`、`/strategy`、`/write-prd`、`/plan-launch`、`/north-star` 等预设指令，用户可直接键入执行复杂任务。
- **智能上下文加载**：技能根据当前任务自动触发相关模块，无需用户手动选择；技能间支持复用（如多个命令共享基础分析技能）。
- **与主流 AI 助手兼容**：专为 Claude Code 和 Cowork 设计，同时技能接口对其他 AI 助手保持开放。

## 技术架构

项目采用 **模块化技能** + **指令触发** + **插件编排** 三层架构：

- **技能层**：每个技能是一个独立的知识单元，包含领域知识、分析框架或引导工作流。技能设计遵循“编码化 PM 框架”原则，将特蕾莎·托雷斯（Teresa Torres）、马蒂·卡根（Marty Cagan）、阿尔贝托·萨瓦（Alberto Savoia）等专家方法论转化为计算机可执行的逻辑。
- **指令层**：预定义以斜杠开头的命令（如 `/discover`），用户通过自然语言或特定关键词触发。指令内部可调用一个或多个技能，并指定执行顺序与输出格式。
- **插件层**：将多个相关技能和工作流打包为插件，支持横向扩展。插件之间通过标准接口通信，避免耦合。
- **自动化依赖**：项目本身不依赖后端服务，所有逻辑通过 AI 助手的上下文理解与代码生成能力执行。安装后，AI 会读取技能描述文件并自动解析，无需额外部署。

## 安装与使用

### 安装步骤

1. 确保你已安装并配置好 Claude Code 或 Cowork 作为 AI 助手。
2. 将仓库克隆到本地：  
   `git clone https://github.com/phuryn/pm-skills.git`
3. 按照仓库中的 `INSTALL.md`（或 README）说明，将技能文件链接到 AI 助手的配置目录中（通常为 `.claude/` 或 `.cowork/` 文件夹）。
4. 重启 AI 助手会话，技能将自动加载。

### 最小可用示例

在 AI 助手的聊天窗口中直接输入指令：

```text
/discover
```

AI 会执行产品发现技能，引导你依次完成：定义问题领域、识别用户角色、输出探索计划。如需更复杂的工作流，可输入：

```text
/strategy
```

此时会触发战略技能链，自动进行竞争分析、SWOT 评估、OKR 对齐等结构化输出。所有技能均为交互式，AI 会询问关键信息并生成文档初稿。

## 适用场景

- **产品经理日常工作**：快速编写 PRD（`/write-prd`）、规划产品上线（`/plan-launch`）、定义核心指标（`/north-star`），将重复性任务标准化。
- **初创团队决策辅助**：从零开始的新项目，团队可以使用 `/discover` 启动探索流程，使用 `/strategy` 制定竞争策略，避免早期决策盲区。
- **AI 辅助开发流程**：结合 Claude Code 的代码生成能力，PM 可在同一会话中完成需求分析、原型设计甚至代码交付，实现“从文档到产品”的端到端闭环。
- **PM 方法论学习与落地**：对于不熟悉特定框架的 PM，技能会引导其一步一步实践大师方法，降低学习门槛并确保产出质量。

## 项目亮点

- **从“生成文本”到“引导思考”**：与通用 AI 工具不同，该项目不追求生成速度，而是强调结构化的思维过程，帮助用户做出更理性的产品决策。
- **专家方法论的工程化封装**：将 100+ 分析框架转化为可重复的机器指令，让“特蕾莎·托雷斯的发现习惯”和“马蒂·卡根的策略思维”真正进入日常工具链。
- **零配置体验**：无需搭建服务器、无需 API 密钥（依赖用户已有的 AI 助手），克隆即用。技能自动根据上下文激活，用户只需输入指令。
- **开源且可贡献**：MIT 许可证，鼓励社区贡献新技能和插件。仓库已获得超过 16000 星，社区活跃度高。
