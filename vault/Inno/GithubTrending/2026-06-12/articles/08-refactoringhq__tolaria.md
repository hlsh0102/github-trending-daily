## 项目概述

Tolaria 是一款跨平台桌面应用，专为管理 **Markdown 知识库** 而设计。它支持 macOS、Windows 和 Linux，致力于帮助用户以纯文本文件的形式构建和管理个人或团队的知识体系。

该项目的核心理念是“文件优先”和“Git 优先”。这意味着你的所有笔记都是标准的 Markdown 文件，完全可移植，无需依赖特定编辑器，且数据永远属于你自己。同时，每个知识库（Vault）都是一个 Git 仓库，天然支持版本控制与协作。

Tolaria 的目标用户包括：
- 需要运营“第二大脑”或个人知识管理的深度用户
- 希望组织公司文档以作为 AI 上下文的企业团队
- 需要为 AI 助手（如 OpenClaw）存储记忆和流程手册的开发者

项目作者 Luca 本人就使用 Tolaria 管理超过 10,000 条笔记的庞大工作区，涵盖工作、日记和个人知识管理。项目目前拥有超过 15,500 颗 Star，社区活跃度极高。

## 核心功能

- **文件优先的知识管理**：所有笔记均为纯 Markdown 文件，可直接用任意编辑器打开、编辑和备份，无需导出步骤
- **Git 原生集成**：每个知识库自动初始化为 Git 仓库，支持版本历史、分支管理、团队协作和远程同步
- **跨平台支持**：在 macOS、Windows 和 Linux 上提供一致的使用体验
- **灵活的收件箱工作流**：提供快速捕获和整理笔记的机制，支持将网页资源直接保存到知识库
- **AI 上下文组织**：支持将文档结构化整理，便于作为大语言模型的上下文输入
- **开源与社区驱动**：基于 AGPL-3.0 开源协议，代码完全透明，社区可贡献和定制

## 技术架构

Tolaria 采用主流的 Electron + TypeScript 技术栈构建桌面应用。TypeScript 作为主要开发语言，带来了类型安全和更好的代码可维护性。

架构设计上遵循以下原则：
- **本地优先**：所有数据存储在用户本地，仅在用户需要同步时才与 Git 远程仓库交互，保障数据隐私
- **文件系统直接操作**：直接读写 Markdown 文件，不依赖私有数据库格式，确保文件的通用性和可迁移性
- **插件化思维**：项目结构模块化，便于社区开发扩展功能

项目采用了持续集成（GitHub Actions）和代码覆盖率测试（Codecov），同时通过 CodeScene 进行代码健康度分析，保证了代码质量。

## 安装与使用

Tolaria 目前通过 GitHub Releases 发布安装包。安装步骤通常如下：

1. 访问项目的 [GitHub Releases 页面](https://github.com/refactoringhq/tolaria/releases)
2. 根据操作系统下载对应的安装包（.dmg 用于 macOS，.exe 或 .msi 用于 Windows，.AppImage 用于 Linux）
3. 安装并启动应用

使用示例：

1. **创建新知识库**：启动应用后，选择或创建一个本地文件夹作为你的 Vault
2. **初始化 Git**：在 Vault 目录中，Tolaria 会自动初始化 Git 仓库（或连接到已有仓库）
3. **添加笔记**：直接在应用内创建 Markdown 文件，支持标准 Markdown 语法
4. **保存网页资源**：通过收藏夹或扩展工具，将网页内容保存为 Markdown 笔记
5. **同步与备份**：通过 Git 命令推送/拉取变更，或使用自动同步功能

最小可用配置只需一个本地文件夹，无需任何外部服务。

## 适用场景

- **个人知识管理（PKM）**：构建第二大脑，管理读书笔记、学习记录、项目经验、日记等海量信息
- **AI 上下文仓库**：将公司文档、技术规范、产品手册整理成结构化的 Markdown 文件，作为 AI 助手的上下文语料
- **AI 助理记忆与流程**：为 OpenClaw、自建 AI 助理等存储长期记忆和操作流程手册，实现可持续的智能辅助
- **技术写作与文档协作**：团队基于 Git 协同编写 Markdown 文档，享受版本控制和代码审查的优势

## 项目亮点

与同类 Markdown 知识管理工具相比，Tolaria 有几个显著差异化优势：

- **文件优先哲学极彻底**：许多工具虽然声称支持 Markdown，但内部仍使用私有数据格式或依赖网络服务。Tolaria 直接以纯文本 Markdown 文件为唯一存储格式，这是从用户所有权出发的纵深设计
- **Git 原生融合**：不只是“支持 Git 导出”，而是将 Git 作为第一公民。知识库本身就是 Git 仓库，版本控制、分支协作、远程同步都是原生能力，无需额外配置插件
- **轻量级且功能聚焦**：不追求大而全，专注于笔记管理核心体验，启动快、内存占用低、响应灵敏
- **社区信任度高**：开源、AGPL-3.0 许可、15,500+ Star、活跃的社区贡献，意味着长期可维护性和透明度
