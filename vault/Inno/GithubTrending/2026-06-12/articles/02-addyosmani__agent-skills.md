## 项目概述

Agent Skills 是一个开源项目，旨在将资深软件工程师的工作流、质量门禁和最佳实践封装成 AI 编程代理可执行的技能集。该项目由 Google Chrome 团队的高级工程师 Addy Osmani 创建，解决了当前 AI 编码代理在缺乏工程规范指引时容易产生混乱代码的根本问题。

项目的目标用户包括使用 AI 辅助编程的开发者、希望统一团队开发规范的工程团队，以及需要为 AI 编码代理提供结构化工作指令的技术管理者。通过将成熟的工程方法论编码为可重复执行的技能，Agent Skills 让 AI 代理能够像经验丰富的工程师一样，在开发全生命周期中保持一致的产出质量。

## 核心功能

- **七阶段开发生命周期技能**：覆盖从需求定义到生产部署的完整流程，包括 `/spec`（需求定义）、`/plan`（规划）、`/build`（构建）、`/test`（测试）、`/review`（审查）、`/code-simplify`（代码简化）和 `/ship`（发布）七个阶段，每个阶段都嵌入了对应的工程技能和最佳实践。
- **自动构建模式**：`/build auto` 命令能够在需求定义完成后自动生成实施计划并执行代码实现，减少人工干预步骤。
- **规范优先的执行逻辑**：强制要求“先写规范再写代码”，通过 `/spec` 命令确保每个功能在实现前都有明确的规格说明。
- **增量式构建策略**：通过 `/plan` 命令将复杂任务分解为细粒度的原子任务，每次只构建一个功能切片。
- **测试即证明的质量机制**：`/test` 命令将测试视为功能完成的证明，而非可选的附加步骤。
- **代码健康审查与简化**：`/review` 命令提供代码审查技能以提升代码质量，`/code-simplify` 则专注于简化复杂实现。

## 技术架构

项目基于 Shell 脚本实现，核心设计理念是将开发工作流编码为可被 AI 代理解析和执行的命令系统。架构上采用“阶段式技能封装”原则，将每个开发阶段定义为一个独立的命令模块，模块内嵌该阶段所需的所有工程技能和检查点。

技术设计上遵循了“渐进式复杂度”的思路：底层提供基础的命令执行接口，上层则通过组合多个命令形成完整的开发流水线。项目没有采用复杂的框架，而是通过极简的 Shell 命令实现了动态技能加载——AI 代理根据当前阶段自动调用对应的技能集。这种设计使得技能可以独立更新和扩展，也便于与其他工具链集成。

## 安装与使用

安装 Agent Skills 非常简单，只需克隆仓库并使其命令在终端中可用：

```bash
git clone https://github.com/addyosmani/agent-skills.git
cd agent-skills
# 将命令文件夹添加到 PATH，或直接使用别名
```

最小可用示例：在 AI 编码代理的工作环境中，完成需求定义后可以直接输入 `/plan` 命令，代理将自动执行项目规划阶段的技能——分析需求、分解任务、生成实施步骤。继续输入 `/build` 则会进入构建阶段，代理根据规划执行增量式代码实现。

更高效的工作流可以这样做：在需求明确后直接使用 `/build auto`，代理会自动执行从规划到构建的整个过程，包括生成必要的测试用例。

## 适用场景

- **AI 辅助代码生成**：开发者在与 AI 编码代理交互时，通过 Agent Skills 确保代理的输出符合工程规范，避免产生散乱、不可维护的代码。
- **团队开发流程标准化**：工程团队可以将 Agent Skills 作为统一的质量门禁，让所有通过 AI 辅助产生的代码都遵循相同的工程标准。
- **自动代码审查与质量提升**：在代码审查阶段使用 `/review` 和 `/code-simplify` 命令，AI 代理能够发现潜在的代码问题并提供改进建议。
- **快速原型到生产部署**：从 `spec` 到 `ship` 的完整流水线，特别适合需要从概念快速迭代到生产环境的开发场景。

## 项目亮点

与同类项目相比，Agent Skills 最大的差异化优势在于其“工程化基因”。它不是简单地提供命令集合，而是将资深工程师多年积累的工作智慧（如“先规范后代码”、“增量构建”、“测试即证明”等原则）系统化地编码到每个技能中。

项目采用的“七阶段开发生命周期”设计，覆盖了从需求到部署的全流程，而非仅仅聚焦于代码生成这一个环节。这种全链路的覆盖使得 AI 代理能够像人类资深工程师一样思考，在开发早期就考虑测试、审查和部署等后续环节的需求。

另外一个突出优势是项目的“渐进自动化”理念：不强制全自动化，而是让用户可以根据实际需求选择手动分步执行或自动批量执行。这种灵活性使其既能适用于经验丰富的开发者，也能服务于对工程规范不太熟悉的新手。
