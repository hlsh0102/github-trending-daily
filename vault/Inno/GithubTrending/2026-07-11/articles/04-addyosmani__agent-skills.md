## 项目概述

Agent Skills 是一个开源项目，旨在为 AI 编码智能体提供生产级别的工程技能。该项目将资深软件工程师在构建软件时使用的工作流程、质量门禁和最佳实践编码为可复用的技能包，使 AI 代理能够在每个开发阶段一致地遵循这些规范。项目的主要目标用户是使用 AI 辅助编程工具的开发者、希望建立标准化 AI 开发流程的团队，以及研究 AI 软件工程应用的工程师。

## 核心功能

- **八种斜杠命令（Slash Commands）**：覆盖完整开发生命周期，包括 `/spec`（需求定义）、`/plan`（规划）、`/build`（构建）、`/test`（测试）、`/review`（审查）、`/ship`（交付）等，每种命令自动激活对应的技能集。

- **阶段化工作流指引**：将开发过程划分为 DEFINE（定义）、PLAN（规划）、BUILD（构建）、VERIFY（验证）、REVIEW（审查）、SHIP（交付）六个阶段，每个阶段包含明确的质量门禁和检查点。

- **技能自动激活机制**：根据开发者当前所处的开发阶段，自动加载相应的技能包，无需手动配置或切换上下文。

- **可扩展技能模型**：支持添加自定义技能，允许团队或组织根据自身开发规范扩展技能库，保持与现有工作流程的兼容性。

- **一致性保障**：确保 AI 代理在不同项目、不同开发人员之间遵循相同的质量标准和工作流程，减少主观差异导致的输出偏差。

## 技术架构

Agent Skills 基于 JavaScript/TypeScript 构建，采用模块化设计理念。其核心架构围绕“技能”（Skill）这一抽象单元展开，每个技能封装了特定的工程实践、提示模板和质量检查规则。项目定义了清晰的技能注册与激活机制，通过解析输入的斜杠命令，动态加载并执行对应的技能集。

设计上强调“工作流即代码”（Workflow as Code），将传统的开发阶段以程序化的方式表达，使得 AI 代理能够理解并执行复杂的软件工程流程。技能之间通过优先级和依赖关系形成层级结构，确保了多技能协作时的有序执行。项目还内置了上下文感知能力，能够根据项目类型、开发阶段和用户输入自动调整技能的行为参数。

## 安装与使用

**安装方式：**

Agent Skills 作为一个通用的技能定义库，推荐通过以下方式集成：

```bash
# 通过 npm 安装（如果作为依赖）
npm install agent-skills

# 或者直接克隆项目仓库
git clone https://github.com/addyosmani/agent-skills.git
```

**最小可用示例：**

1. 在项目根目录创建 `.cursorrules` 或类似配置文件，引用所需的技能包。
2. 在 AI 编码环境中使用斜杠命令启动技能：

```
# 定义需求阶段
/definespec  "用户需要一个新的登录功能"

# 规划开发任务
/plan  "基于规范制定开发计划"

# 开始构建
/build  "实现用户认证模块"
```

3. Agent 会自动加载对应的技能，执行规范化的工作流程，包括生成文档、编写测试用例、进行代码审查等步骤。

## 适用场景

- **新项目启动**：在创建新项目时，使用 `/spec` 和 `/plan` 技能快速定义需求并制定开发计划，确保从一开始就遵循最佳实践。

- **代码审查与质量控制**：在提交代码前使用 `/review` 技能进行自动化审查，检查代码风格、潜在缺陷和安全性问题，提高代码质量。

- **CI/CD 集成**：将技能作为 CI/CD 流程的一部分，在构建、测试和部署阶段自动执行质量检查和工作流验证。

- **团队标准化培训**：新成员加入团队时，通过技能包快速了解团队的开发规范和最佳实践，减少上手时间。

## 项目亮点

与同类项目相比，Agent Skills 的差异化优势在于：

- **生产级质量导向**：技能定义直接来源于资深工程师的实践经验，而非通用 AI 提示模板，专注于解决真实开发中遇到的具体问题。

- **完整开发生命周期覆盖**：不同于仅关注编码阶段的工具，该项目从需求定义到交付部署提供了端到端的支持，形成闭环开发流程。

- **高度可定制化**：支持团队根据自身需求自定义技能，与其他 AI 代理工具链（如 Cursor、GitHub Copilot 等）兼容，降低集成成本。

- **持续进化能力**：项目保持活跃更新，随着软件工程最佳实践的演进而不断丰富技能库，确保长期有效性。
