## 项目概述

Superpowers 是一套为编程代理（coding agents）设计的完整软件开发方法论和技能框架。它解决了当前 AI 编程工具在自动生成代码时常见的问题——缺乏系统性思考、跳过需求分析和设计阶段、直接陷入代码实现从而产生混乱、不可维护的结果。Superpowers 的目标用户是所有使用 AI 编程助手进行实际开发工作的工程师，特别是那些希望将 AI 代理从“自动代码生成器”升级为“可信赖的协作开发者”的团队和个人。

## 核心功能

- **需求驱动开发流程**：代理不会一上来就写代码，而是先通过对话澄清用户真正想要解决的问题，提取出可执行的需求规格说明。
- **增量式设计展示**：将设计文档以足够小的块呈现给用户，确保每一步都经过人工审阅，避免一次性抛出大量不可读的设计文本。
- **迭代式实现计划**：代理生成一份清晰到足以让“热情的初级工程师”（缺乏判断力、没有上下文、不喜欢测试）都跟着执行的实施计划，强调真正的红绿测试驱动开发（TDD）、YAGNI（你不会需要它）和 DRY（不要重复自己）。
- **多平台支持**：开箱即用地支持 Claude Code、Antigravity、Codex App、Codex CLI、Cursor、Factory Droid、GitHub Copilot CLI、Kimi Code、OpenCode、Pi 等多种主流 AI 编程工具。
- **可组合的技能系统**：基于一组可组合的技能构建，代理可以根据项目需求动态组合使用这些技能。

## 技术架构

Superpowers 的技术架构围绕“技能组合”和“方法论指令”两个核心概念展开。项目本身是一个 Shell 脚本仓库，提供一组技能定义和初始指令文件。当代理开始工作时，会被这些指令引导进入结构化的开发循环：首先是需求澄清阶段，代理与用户对话提取规格；然后是设计拆分阶段，代理将整体设计拆分成可消化的小块，逐步向用户展示和确认；最后是实施规划阶段，在得到用户对设计的认可后，代理生成详细的实现步骤，并进入编码-测试的迭代周期。

这种架构的关键特点在于其“元编程”性质——它并不替换现有的 AI 编程工具，而是作为一层覆盖在它们之上的工作流程指南。项目通过环境变量、配置文件或直接的系统提示词注入来让代理遵循这套方法论。技能系统支持灵活的组合，不同项目可以根据需要启用或禁用特定技能模块，使得这套方法论可以适用于从个人脚本到企业级应用的广泛范围。

## 安装与使用

Superpowers 的安装非常直接，主要分为两步：

1. 克隆仓库到本地
```bash
git clone https://github.com/obra/superpowers.git
```

2. 配置你的 AI 编程代理使用这些技能。根据你使用的工具（如 Claude Code、Cursor 等），将仓库中的系统指令或技能文件关联到代理。不同的工具有不同的集成方式，通常包括设置环境变量、指定配置文件路径或在启动时加载特定的提示词文件。

最小可用示例：对于 Claude Code，你可以将仓库中的 `.superpowers` 目录结构复制到项目根目录，然后启动 Claude Code 时它会自动加载这些指令。当你在 Claude Code 中开始一个开发任务时，代理会按照 Superpowers 的方法论进行交互，而不是直接开始编写代码。

## 适用场景

- **复杂项目的需求澄清与设计**：当项目需求模糊、需要大量前期的理解时，Superpowers 的需求驱动流程能有效防止代理想当然地写出无用代码。
- **多人协作的 AI 辅助开发**：团队共享同一套代理技能配置，确保所有成员使用一致的开发方法论，减少沟通成本和代码风格差异。
- **遗留系统改造成增量式迭代**：面对既有代码库时，TDD、YAGNI 和 DRY 原则能帮助代理避免引入不必要的重构或过度工程，保持改动最小化。
- **教育和新手指导**：方法论的结构化流程可以作为教学工具，帮助初级工程师理解正确的软件开发流程。

## 项目亮点

Superpowers 最大的差异化优势在于它把关注点从“让代理更会写代码”转向了“让代理更会做设计”。大多数 AI 编程工具都倾向于直接生成大量代码，而 Superpowers 反其道而行之——它强制代理在动手之前先进行对话、思考、分解和规划。这种“慢下来”的哲学在 AI 驱动的开发中显得尤为珍贵。

另一个显著特点是其可移植性。项目不绑定于特定工具或 IDE，设计成一套通用的方法论描述，理论上可以适配到任何支持系统提示词注入的 AI 编程代理上。现有的 10+ 种工具的官方支持已经验证了这种跨平台的可行性。

最后，项目以极低的熵值获得了超过 25 万颗 GitHub Stars 和每日 1000+ 的新增 Stars，这说明社区对它的认可度非常高，也反映了这种系统化方法切中了当前 AI 编程实践中的真实痛点。
