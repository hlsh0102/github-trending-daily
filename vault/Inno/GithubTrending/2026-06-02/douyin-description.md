今日 GitHub Trending TOP10 来了！

1️⃣ microsoft/markitdown：微软新开源的轻量级工具，把 PDF、Word、PPT、Excel 等格式秒变 Markdown，保留结构信息，方便 AI 直接读取。适合批量文档处理。

2️⃣ nesquena/hermes-webui：为 Hermes Agent 设计的 Web 界面，三面板布局，浏览器或手机直接操作 AI 代理，无需命令。远程/移动端友好。

3️⃣ supermemoryai/supermemory：AI 记忆引擎，让 LLM 不再“金鱼记忆”。在 LongMemEval 等三个基准测试中均排第一，支持多模态、长对话上下文。

4️⃣ harry0703/MoneyPrinterTurbo：短视频自动生成工具。输入主题，自动写文案、搜素材、加字幕和背景音乐，直接输出高清视频。内容创作者福音。

5️⃣ D4Vinci/Scrapling：自适应 Web 抓取框架，自动处理反爬、页面渲染和异常，简化从单次请求到大规模爬取的流程。稳定高效。

6️⃣ pbakaus/impeccable：前端设计语言工具集，专为 AI 代码生成而生。提供 7 个领域文件、23 条设计命令、27 条反模式规则，打破 AI 输出雷同 UI。无需额外 LLM。

7️⃣ p-e-w/heretic：自动去除 LLM 安全对齐工具，通过方向消融和 TPE 优化，无需后训练，减少模型过度拒绝行为。适合模型研究人员。

8️⃣ EveryInc/compound-engineering-plugin：为 Claude Code 等 AI 编程助手设计的插件，强调 80% 精力放在规划和审查，20% 执行。反转技术债务。

9️⃣ TauricResearch/TradingAgents：多智能体金融交易框架，模拟分析师、交易员、风险官协作，基于 LLM 理解市场数据，自动化生成交易信号。

🔟 revfactory/harness：Claude Code 的团队架构工厂，自动设计专属智能体团队、定义角色和技能。一句话就能搭建协作式 AI 系统。
