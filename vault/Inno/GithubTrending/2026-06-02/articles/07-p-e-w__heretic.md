## 项目概述

Heretic 是一个针对基于 Transformer 架构的语言模型的全自动审查去除工具。大型语言模型在发布前通常会经过“安全对齐”（safety alignment）微调，以防止生成有害或不当内容，但这种机制同时也会造成模型在回答敏感话题时反复拒绝用户。Heretic 通过方向消融（directional ablation，即“abliteration”）技术，能够在不进行昂贵后训练的前提下，移除这些人为施加的约束，使模型恢复其原有的开放式表现能力。该项目的目标用户包括 AI 研究人员、模型部署工程师以及对模型行为可控性有深入需求的高级用户，所有希望绕过模型因安全对齐而产生的过度拒绝行为的人都可以受益于 Heretic。

## 核心功能

- **全自动参数优化**：Heretic 集成了基于 TPE（Tree-structured Parzen Estimator）的超参数优化器（由 Optuna 驱动），能够自动寻找最佳的消融参数，无需用户手动微调。
- **方向消融（Abliteration）实现**：基于 Arditi 等人 2024 年的研究成果，结合改进的投影消融（Projected Abliteration）与保范双投影消融（Norm-Preserving Bi-Projected Abliteration）技术，实现对拒绝行为的精准移除。
- **无监督评估与训练**：自动计算拒绝率与 KL 散度，在最小化模型行为改变的同时最大化审查去除效果，整个过程无需标注数据或人工介入。
- **广泛模型兼容性**：支持绝大多数密集模型（dense models），包括多模态模型，以及多种 MoE（混合专家）架构。
- **轻量级命令行接口**：用户仅需运行一条命令即可完成从参数搜索到模型生成的完整流程，无需深入理解 Transformer 内部机制。

## 技术架构

Heretic 采用 Python 语言开发，核心技术栈包括 PyTorch（用于模型加载与推理）、Hugging Face Transformers（标准模型接口）、以及 Optuna（用于超参数优化）。其设计思路是将科学计算与机器学习优化方法转化为一个可直接使用的工作流：

1. **模型分析**：首先加载目标语言模型，检测其特有的“拒绝方向”向量（即在安全对齐模型中抑制有害回答的层内隐状态方向）。
2. **参数搜索**：通过 TPE 优化器在消融方向与强度参数空间中搜索，目标函数同时最小化评估集上的拒绝次数（衡量审查去除效果）和 KL 散度（衡量与原模型的偏差）。
3. **最终模型生成**：根据搜索到的最优参数，对模型进行一次性消融操作，输出一个移除拒绝行为但保持原有推理能力的新模型。

这种架构的显著特点是高度自动化与可复现性：由于优化过程完全由算法驱动，不同用户对同一模型应用 Heretic 可得到稳定、可比的结果，克服了手动调参带来的经验依赖问题。

## 安装与使用

**安装**：Heretic 通过 pip 发布，建议在虚拟环境中安装：
```bash
pip install heretic
```
项目要求 Python 3.10 或更高版本，推荐使用 GPU（CUDA 或 MPS 后端）以加速模型处理。

**最小可用示例**：对 Hugging Face 上最广泛部署的指令模型（如 `mistralai/Mistral-7B-Instruct-v0.2`）进行审查去除：
```bash
heretic --model mistralai/Mistral-7B-Instruct-v0.2
```
Heretic 会自动下载模型、执行拒绝方向检测与参数优化，并在完成后输出一个包含了消融参数的文件夹。用户随后可从该文件夹加载模型并使用。对于更高级用户，可指定评估数据集、调整优化迭代次数或修改 KL 散度权重：
```bash
heretic --model meta-llama/Llama-3.1-8B-Instruct --eval-samples 500 --n-trials 100 --kl-weight 0.25
```

## 适用场景

- **研究比较不同安全对齐策略的差异**：研究人员可以使用 Heretic 来快速解除模型审查，对比不同模型在去除拒绝方向前、后的行为差异，从而分析安全对齐对模型知识表达的影响。
- **文化敏感内容的本地化适应**：在一个国家或文化环境中被认为合适的回答，在另一文化环境下可能被标注为违规。部署团队可借助 Heretic 对模型做定制化调整，以更好地服务当地用户。
- **大模型下游任务中的开放性测试**：需要对模型做压力测试（例如：询问有争议的历史事件、医学伦理困境）时，去除审查后的模型能提供更丰富、更真实的回答，从而评估模型的实际知识边界。
- **无审查的开源模型再分发**：社区希望构建允许自由问答的镜像模型时，可借助 Heretic 自动处理公开权重的审查去除，降低技术门槛和计算成本。

## 项目亮点

- **完全自动化**：同类工具大多需要用户手动定位拒绝方向、设置消融强度或进行多次人工评估。Heretic 将整个过程集成在一个命令行工具中，真正做到“一键去审”。
- **无后训练需求**：传统的方法需要对模型进行全参数微调或 LoRA 微调，昂贵且耗时。Heretic 使用纯推理阶段的消融技术，在数分钟到数十分钟（取决于模型大小）内即可完成。
- **保留智能水平**：通过共最小化拒绝率和 KL 散度，Heretic 在移除审查的过程中最大程度保留了模型的事实知识和推理能力，而暴力屏蔽或粗放消融常常会导致模型质量下降。
- **数据驱动且可复现**：使用自动化优化而非手动猜测，结果具备高度可复现性；同时，优化过程基于用户提供的评估数据，可根据应用场景做针对性调整。
- **积极的社区与维护**：项目在 GitHub 与 Discord 上有活跃的讨论社区，持续迭代消融算法与模型兼容性列表，确保覆盖最新的开源模型。
