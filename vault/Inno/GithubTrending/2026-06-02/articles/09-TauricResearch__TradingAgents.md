## 项目概述

TradingAgents 是一个基于大语言模型（LLM）的多智能体金融交易框架，由 TauricResearch 团队开发并开源。该项目旨在通过模拟专业交易团队的协作模式，将多个具备不同角色与职责的 AI 智能体组合起来，共同完成股票、期货等金融产品的投资决策与交易执行。

传统量化交易系统通常依赖于预设规则、统计模型或单一机器学习模型，难以灵活应对市场的快速变化和复杂信息。TradingAgents 的核心思路是让多个智能体分别扮演分析师、交易员、风险官等角色，各自基于 LLM 对市场数据、新闻、技术指标等信息进行理解和推理，再通过讨论、辩论和投票等方式达成共识，从而生成交易信号。其目标用户包括对 AI 驱动的量化交易感兴趣的研究者、量化开发者，以及希望探索新型交易策略的个人或机构投资者。

## 核心功能

- **多角色智能体协作系统**：内置多个预设的智能体角色，如负责基本面分析、技术分析、新闻情绪分析、风险管理等，每个智能体具备独立的记忆和推理能力，模拟真实投研团队的协作流程。
- **基于 LLM 的市场理解**：利用大语言模型处理非结构化数据（如财经新闻、研报、社交媒体情绪）和结构化数据（如 OHLCV、技术指标），从中提取交易信号。
- **辩论与共识机制**：智能体之间通过结构化对话（如辩论、投票）交换观点并达成最终决策，提高了决策的鲁棒性和可解释性。
- **模块化与可扩展架构**：支持自定义智能体角色、添加新的数据源、替换 LLM 后端（如 OpenAI、本地模型），方便用户根据需求调整策略。
- **回测与实时交易**：提供历史数据回测功能以评估策略表现，同时也支持对接交易所 API 进行实时模拟或实盘交易。
- **可视化监控面板**：提供简易的仪表盘，用于观察智能体的推理过程、持仓变化和绩效统计，便于调试和分析。

## 技术架构

TradingAgents 的技术架构围绕“智能体-环境-协调”三层设计：

1. **智能体层**：每个智能体是一个独立的 LLM 实例，配有专属的系统提示词（system prompt），定义了其角色、技能和约束。不同智能体可接入不同的数据源（如技术分析智能体读取历史价格，新闻智能体调用新闻 API），并使用 LangChain 等框架管理与大模型的交互。
2. **环境层**：负责维护市场状态（当前持仓、账户余额、订单历史），并对外提供统一的执行接口。环境层还封装了市场数据获取和订单执行的逻辑，支持虚拟（回测）和真实（实盘）两种模式。
3. **协调层**：核心是一个“辩论与投票”引擎。每次决策周期，协调层将当前市场数据广播给所有智能体，收集它们的观点和理由后，启动多轮结构化辩论。智能体可以根据其他角色的观点调整自己的立场，最终通过加权投票或共识算法生成买入、卖出、持有或调整仓位的指令。协调层还记录完整的决策日志，供后续分析。

关键技术依赖包括：Python（主要语言）、LangChain（LLM 编排）、Pandas/NumPy（数据处理）、FastAPI（API 服务）、以及可选的数据提供库（如 yfinance、ccxt）和可视化工具（如 Plotly、Streamlit）。

## 安装与使用

推荐使用 Python 3.10 及以上版本，并建议在虚拟环境中安装。

**基本安装步骤：**

```bash
# 1. 克隆仓库
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境变量
# 复制示例配置文件，填入你的 LLM API Key（如 OpenAI API Key）
cp .env.example .env
# 编辑 .env 文件，设置 OPENAI_API_KEY 等参数
```

**最小可用示例：**

使用预置的多智能体策略进行回测，查看性能摘要：

```python
from trading_agents import TradingEnvironment, MultiAgentEnsemble
from trading_agents.strategies import DefaultStrategy

# 初始化交易环境（使用内置历史数据）
env = TradingEnvironment(symbol="AAPL", start_date="2023-01-01", end_date="2023-12-31")

# 创建多智能体策略（默认包含分析师、交易员、风险官等角色）
strategy = DefaultStrategy(llm_backend="openai", model_name="gpt-4")

# 运行回测
results = env.backtest(strategy, initial_capital=100000)

# 输出结果摘要
print(results.summary())
```

如需进行实时模拟交易，可配置交易所 API（如 Alpaca、Binance）并在 `env` 中切换到实时模式。

## 适用场景

- **投资研究辅助**：研究团队可使用 TradingAgents 自动分析市场新闻和财务数据，快速生成多角度观点摘要，辅助人工决策。
- **个人策略探索**：个人交易者可以快速搭建一个包含多个分析视角的 AI 交易机器人，进行历史回测验证，或在小额资金上测试新想法。
- **教育与教学**：适用于金融科技课程或量化交易入门教学，通过观察智能体之间的“辩论”过程，帮助学生理解不同交易逻辑及其相互作用。
- **策略原型验证**：量化开发者可基于框架快速原型化新的交易策略，例如替换新闻智能体为一个基于特定财报指标的智能体，验证其效果后再移植到正式交易系统。

## 项目亮点

- **多智能体协作范式**：与常见的单一 LLM 交易智能体不同，TradingAgents 通过模拟团队分工与辩论，显著提升了决策的稳健性和逻辑性，避免了个体偏见。
- **高度的可解释性**：每个决策步骤都伴有详细的推理日志和智能体间对话，用户可以回查为何某个交易信号被发出，便于调试和信任评估。
- **开源与社区驱动**：采用 Apache-2.0 许可证，代码完全公开；社区活跃，支持 Discord、GitHub 讨论及多语言文档，降低了使用门槛。
- **模块化设计**：角色、数据源、LLM 后端均可灵活替换，适应从研究到实盘的不同阶段需求，不依赖于特定商业服务。
