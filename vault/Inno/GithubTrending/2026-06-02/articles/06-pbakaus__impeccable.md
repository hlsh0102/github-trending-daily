## 项目概述

Impeccable 是一个为 AI 前端代码生成提供设计语言和约束的开源项目。它解决了当前大语言模型在生成前端 UI 时普遍存在的“千篇一律”问题——例如滥用 Inter 字体、紫蓝色渐变、卡片套卡片的布局、灰色文字配彩色背景等 SaaS 模板化的审美疲劳。目标用户是使用 AI 辅助前端开发的设计师和工程师，特别是那些希望让 Claude、GPT 等模型输出更高质量、更具独特性 UI 代码的开发者。

## 核心功能

- **7 个领域参考文件**：涵盖排版、色彩、动效、间距、交互、响应式、UX 写作等设计核心领域，作为每一条命令的上下文，让 AI 理解设计规范的基本约束。
- **23 条设计指令**：定义了一套与 AI 共享的设计词汇，包括 `polish`（打磨）、`audit`（审计）、`critique`（批评）、`distill`（提炼）、`animate`（动画化）、`bolder`（更粗犷）、`quieter`（更安静）等，实现精准的设计意图传达。
- **27 条确定性反模式规则**：无需 LLM 和 API Key，通过 CLI 和浏览器扩展即可运行，可自动检测并纠正常见的设计反模式。
- **12 条 LLM 评审规则**：结合模型能力的二次审查机制，对生成结果进行更智能的设计质量评估。
- **品牌与产品寄存器**：自动调整默认设计参数，使输出更贴合特定品牌或产品场景，而非通用的模板风格。
- **完整的设计技能包**：无需额外配置即可直接加载到支持的 AI 工具中，降低使用门槛。

## 技术架构

Impeccable 基于以下技术思路构建：

- **模块化参考文件**：将设计知识拆分为 7 个独立领域文件，每个文件聚焦单一设计维度，便于维护和扩展。这些文件作为 prompt 上下文直接注入 AI 的生成过程。
- **指令驱动的交互模式**：23 条命令构成一个受控的词汇表，将人类设计师的意图通过精确的指令传递给 AI，减少模糊性的误解。
- **双轨质量控制**：结合确定性规则（通过正则和 AST 分析实现）与 LLM 评审，在静态检查和智能评估两个层次确保输出质量。确定性规则部分可离线运行，无需 API 调用。
- **跨平台支持**：提供 CLI 工具可在本地项目中使用，同时也有浏览器扩展方便网页开发场景。核心逻辑在 skill 目录下的 markdown 文件中定义，具有高度可移植性。
- **源自业界最佳实践**：基于 Anthropic 的 frontend-design skill 进行扩展和深化，继承其设计理念的同时增加了更多约束和规则。

## 安装与使用

**快速开始**：直接访问 [impeccable.style](https://impeccable.style) 下载预打包好的使用包，无需安装。

**CLI 使用方式**（假设有 npm）：
```bash
# 全局安装（如果提供）
npm install -g @impeccable/cli

# 运行设计审计
impeccable audit ./src/components/

# 运行反模式检测（无需 API Key）
impeccable check ./src/styles.css
```

**浏览器扩展**：安装后即可在选择 AI 生成结果时右键使用 Impeccable 的评审功能。

**集成到 Claude 或自定义 AI 工具**：
1. 从仓库 `skill/` 目录获取所需的参考文件。
2. 将参考文件内容作为系统提示（system prompt）的一部分注入。
3. 使用 23 条命令中的指令进行交互，例如 `polish` 指令会自动触发设计打磨流程。

## 适用场景

- **AI 辅助的 UI 原型开发**：设计师使用 Claude 或 GPT 快速生成前端代码时，通过 Impeccable 提升设计质量的基准线，避免重复修改。
- **设计系统实施**：团队在设计系统建设初期，利用 Impeccable 的规则集作为自动化的代码审查工具，确保组件符合统一的设计规范。
- **代码质量审计**：在 CI/CD 流程中集成 `impeccable check` 命令，自动检测提交的 CSS/HTML 是否存在常见的 UI 反模式。
- **教育与培训**：新手开发者通过 Impeccable 的规则学习什么是好的前端设计，反模式规则本身构成了可执行的设计规范教材。

## 项目亮点

- **零 API 需求**：确定性反模式检测可以在没有网络和 LLM 的情况下运行，降低部署成本和延迟。
- **模块化设计知识**：7 个领域参考文件可单独使用或组合，适应不同项目的设计需求，比单一的全尺寸 prompt 更灵活。
- **可执行的规范**：将抽象的设计原则转化为具体可测试的规则（如“避免 5 个以上嵌套的卡片”、“控制字号梯度不超过 3 级”），比单纯的说教更有用。
- **双向沟通机制**：23 条指令让人类可以精确表达设计意图，同时 AI 也能通过这些指令了解人类的期望，形成高效的设计对话。
- **开源且可扩展**：采用 Apache-2.0 协议，任何人都可以 fork 并扩展新的规则或领域参考，社区可以共同维护这一设计标准。
