## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的短视频自动生成工具。用户只需提供一个视频主题或关键词，系统就能自动完成视频文案创作、素材搜索、字幕生成、背景音乐匹配等多个环节，最终合成一个高清的短视频。该项目解决了传统短视频制作流程繁琐、耗时长的痛点，特别适合内容创作者、营销人员和自媒体运营者快速批量生产视频内容。项目完全开源，基于 MIT 协议发布，目前在 GitHub 上已获得超过 77000 颗星标。

## 核心功能

- **一键生成完整视频**：只需输入一个主题或关键词，系统自动完成从文案到成片的全部流程，无需任何人工剪辑操作。
- **智能化文案生成**：集成主流 AI 大语言模型（如 OpenAI、DeepSeek、智谱、千问等），根据主题自动生成结构合理、语言流畅的视频脚本。
- **自动匹配视频素材**：基于生成的文案内容，自动从素材库或网络搜索匹配的高质量视频片段和图片。
- **字幕与语音合成**：自动为视频生成对应字幕，并支持多种语言的语音合成，提供丰富的发音人选择。
- **背景音乐集成**：自动选择并合成与视频风格匹配的背景音乐，提升视频整体观感。
- **多种输出格式**：支持生成高清 MP4 视频，可自定义分辨率、帧率、字幕样式等参数。

## 技术架构

该项目采用 Python 作为主要开发语言，后端基于成熟的 Web 框架构建，前端提供简洁的交互界面。核心架构围绕“主题输入→文案生成→素材匹配→音视频合成”这一流水线设计：

- **AI 模型集成层**：通过统一的接口适配多种大语言模型，包括 OpenAI GPT 系列、Claude、Gemini、DeepSeek、智谱 GLM、千问等，用户可根据需求选择或切换底层模型。同时，语音合成部分支持多种 TTS 引擎。
- **素材管理系统**：内置或通过 API 连接多个素材来源，能根据文案中的关键词智能检索和筛选匹配度最高的视频片段和图片。
- **视频合成引擎**：使用 FFmpeg 等底层工具完成视频拼接、字幕叠加、音频混流等操作，确保输出视频的清晰度和流畅度。
- **任务队列与异步处理**：视频生成是计算密集型任务，系统采用异步任务队列机制，支持多个生成请求并发处理，避免阻塞。
- **配置化设计**：绝大多数参数（如视频尺寸、字幕字体、背景音乐风格等）均可通过配置文件或前端界面调整，灵活性高。

架构设计上强调模块解耦，每个功能环节都可以独立替换或升级，例如可以更换文案生成模型而不影响其他模块。

## 安装与使用

**环境要求**：Python 3.8 及以上版本，FFmpeg 已安装并配置到系统 PATH。

**基本安装步骤**：

```bash
# 克隆仓库
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt
```

**配置 API 密钥**：在项目根目录创建 `.env` 文件，填入至少一个 AI 模型的 API Key，例如：

```
OPENAI_API_KEY=你的OpenAI密钥
```

**启动 Web 界面**：

```bash
python app.py
```

启动后访问 `http://localhost:5000` 即可进入操作界面。在输入框中填写视频主题（如“人工智能发展简史”或“如何制作咖啡”），点击生成按钮，系统会逐步显示文案生成、素材匹配、视频合成的进度，最终输出可下载的高清短视频。

**命令行快捷使用**（适用于自动化脚本）：

```bash
python generate.py --topic "你的主题" --output output.mp4
```
