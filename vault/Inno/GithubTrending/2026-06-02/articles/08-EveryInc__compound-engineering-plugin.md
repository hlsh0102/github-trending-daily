## 项目概述

Compound Engineering Plugin 是一个面向 AI 辅助编程场景的官方工程插件，专为 Claude Code、Codex、Cursor 等主流 AI 编码工具设计。该项目由 EveryInc 开发，旨在解决软件开发过程中不断积累的技术债务问题——传统开发模式下，每一次功能添加、每一个 Bug 修复都会留下局部知识，代码库越来越大，上下文越来越难以把握，后续变更变得越来越慢。

该项目提出了“复合工程”理念：每个工程单位应该让后续单位更容易，而不是更难。通过将 80% 的精力投入在规划与审查，20% 投入在执行，从而形成正向循环的知识沉淀与复用机制。目标用户是使用 AI 辅助编程工具的开发团队和个人开发者，尤其是那些希望通过系统化方法提升代码质量和团队效率的工程师。

## 核心功能

- **`/ce-brainstorm`（头脑风暴）**：在编写代码前进行系统性思考，探索多种解决方案和设计权衡，确保方向正确后再动手。
- **`/ce-plan`（生成计划）**：将头脑风暴结果转化为可执行的实施计划，明确变更步骤和预期效果。
- **`/ce-code-review`（代码审查）**：自动化代码审查，不仅发现 Bug，更识别模式性问题和改进机会。
- **`/ce-doc-review`（文档审查）**：审查相关文档的准确性和清晰度，确保文档与代码保持一致。
- **`/ce-compound`（知识固化）**：将审查和开发过程中学到的经验转化为可复用的知识笔记，供后续 AI 代理直接引用。
- **质量保持**：通过持续审查和知识积累，确保代码库长期保持高质量，降低未来变更的难度。

## 技术架构

该项目采用 TypeScript 开发，作为插件形式集成到多种 AI 编码环境中。核心设计思路是“技能与代理”（skills and agents）模式，每个命令对应一个独立的 AI 技能单元，负责特定的工程环节。

架构特点包括：
- **环境无关**：同时支持 Claude Code、Codex、Cursor 等多个主流 AI 编码工具，用户无需为不同工具切换工作流。
- **模块化设计**：每个命令都是独立的插件模块，可单独启用或禁用，方便根据项目需求定制工作流。
- **知识持久化**：通过 `ce-compound` 命令生成的知识笔记采用结构化格式，确保 AI 代理能够有效索引和复用。
- **聚焦规划与审查**：与大多数 AI 插件“直接生成代码”不同，该插件将绝大多数能力集中在规划和审查环节，强调“想清楚再写”。

## 安装与使用

安装方式取决于使用的 AI 编码工具。以 Claude Code 为例：

```bash
# 在项目目录中安装
npm install @every-env/compound-plugin

# 配置 Claude Code 加载该插件
# 具体配置方式请参考官方文档
```

使用示例：

1. 面对新功能时，先运行 `/ce-brainstorm` 进行方案探索。
2. 确认方案后，运行 `/ce-plan` 生成详细实施计划。
3. 实施计划后，运行 `/ce-code-review` 审查变更代码。
4. 审查完成后，运行 `/ce-compound` 将新学到的知识记录下来。

对于 Cursor 等其他工具，安装方式类似，具体步骤可参考各工具的插件机制。

## 适用场景

- **团队新功能开发**：在开发复杂功能前通过头脑风暴和计划生成，减少返工并统一团队认知。
- **代码库维护与重构**：利用代码审查和知识固化，系统性地降低技术债务，确保每次变更都让代码库更健康。
- **知识交接与新人 onboarding**：通过 `/ce-compound` 积累的领域知识，新成员在 AI 代理的协助下能更快理解项目上下文。
- **跨工具团队协作**：团队中使用不同 AI 编码工具的成员，可以共享相同的工作流程和知识库。

## 项目亮点

- **理念创新**：不追求“一键生成代码”，而是强调规划与审查的价值，从根本上逆转技术债务的积累方向。
- **多环境支持**：同时支持 Claude Code、Codex、Cursor 等主流工具，覆盖绝大多数 AI 编码场景。
- **知识复用机制**：`ce-compound` 命令让 AI 代理能够从每次工程操作中学习，形成持续改进的闭环。
- **高社区认可**：GitHub 上获得 19000+ Star（单日新增 400+），说明其理念和实现获得了广泛认同。
- **来自实战**：项目由 Every 公司开发，其理念已在实际工程中得到验证，并非空洞的理论框架。
