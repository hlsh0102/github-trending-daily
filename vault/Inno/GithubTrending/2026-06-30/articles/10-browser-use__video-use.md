## 项目概述

`video-use` 是一个基于 Python 的开源项目，旨在让用户通过 Claude Code 等编码智能体（agent）来编辑视频。你只需将原始素材放入一个文件夹，与 Claude Code 对话，即可获得最终的 `final.mp4` 文件。该项目 100% 开源，适用于各类视频内容——人物讲话、混剪、教程、旅行记录、访谈等，完全无需预设模板或菜单界面。

对于希望以自然语言驱动视频编辑流程的用户，`video-use` 提供了一种全新的工作方式：将视频编辑能力直接交由 AI 代理调用，从而大大降低传统视频编辑软件的学习成本。

## 核心功能

- **自动消除填充词与静默片段**：智能识别并剪切掉 `umm`、`uh` 等口头禅、假启动以及拍摄间隙中的空白静音，使成片更加流畅。
- **自动色彩校正**：支持为每个片段应用统一的色彩风格，包括暖色电影感、中性鲜明调色，或通过自定义 ffmpeg 滤镜链实现任意调色方案。
- **精准音频淡入淡出**：在每个剪切点自动添加 30 毫秒的音频淡入淡出，彻底消除切换过程中的爆音或杂音。
- **自动字幕烧录**：支持自定义字幕风格，默认采用每两个字一组、大写字母显示的方式。字幕格式完全可定制。
- **动画叠加与并行生成**：可通过 HyperFrames、Remotion、Manim 或 PIL 生成动画覆盖层，每个动画由独立的并行子代理生成，互不干扰。
- **自评估渲染结果**：在向用户展示最终视频之前，系统会自动在每个剪切边界对渲染输出进行评估，确保效果符合预期。
- **会话记忆持久化**：将项目状态和用户偏好保存在 `project.md` 文件中，下一周的编辑会话可以无缝衔接，无需从零开始。

## 技术架构

`video-use` 的核心设计思路是“代理驱动 + 可插拔工具链”。项目以 Python 为主要语言，依赖以下关键技术：

- **ffmpeg**：作为底层视频/音频处理引擎，负责实质性的剪切、拼接、调色、音频淡入淡出、字幕烧录等操作。
- **Claude Code 或兼容代理**：作为用户与视频编辑流程之间的接口，接收自然语言指令并调度各种视频处理子任务。
- **多代理并行架构**：在生成动画覆盖层时，会为每个动画启动一个独立的并行子代理，从而充分利用计算资源，提高处理效率。
- **可插拔的动画引擎**：支持多种动画生成方案（HyperFrames、Remotion、Manim、PIL），用户可根据自身技术栈和需求选择合适的工具。
- **状态持久化机制**：通过 `project.md` 文件记录项目配置、用户偏好和编辑进度，确保编辑工作流的连续性与可恢复性。

整体架构强调模块化与可扩展性，便于开发者自行添加新的视频处理功能或替换默认实现。

## 安装与使用

**基本安装步骤：**

1. 克隆仓库：
   ```bash
   git clone https://github.com/browser-use/video-use.git
   cd video-use
   ```

2. 阅读 `install.md` 完成环境配置，包括安装 ffmpeg、注册 `video-use` 技能到所使用的编码智能体，以及设置 ElevenLabs API 密钥（如需要语音合成功能）。

3. 在使用 Claude Code 或其他兼容代理时，通过以下启动提示词开始：
   ```
   Set up https://github.com/browser-use/video-use for me.

   Read install.md first to install this repo, wire up ffmpeg, register the skill with whichever agent you're running under, and set up the ElevenLabs API key — ask me to paste it when you need
   ```

**最小可用示例：**

将原始视频素材放入项目指定的文件夹，然后通过智能体输入自然语言指令（如“将这段讲话的停顿去掉，添加暖色调调色并生成字幕”），即可获得处理后的 `final.mp4` 文件。

## 适用场景

- **内容创作者**：播主、YouTuber、视频博主需要快速剪辑日常 vlog、采访或教学视频，希望省去繁琐的手动剪辑步骤。
- **小型制片团队**：需要批量处理粗剪片段，自动完成去填充词、色彩校正和字幕添加等重复性工作。
- **教育培训场景**：教师或培训师录制课程视频后，快速生成去除错误和无效停顿的精修版本。
- **个人视频爱好者**：没有专业视频编辑基础，但希望借助 AI 代理以对话方式完成高质量的视频剪辑。

## 项目亮点

- **自然语言驱动编辑**：与传统图形界面视频编辑器截然不同，用户只需用自然语言描述需求，AI 代理自动执行底层 ffmpeg 命令，极大降低使用门槛。
- **并行处理能力**：动画覆盖层生成采用并行子代理架构，避免串行等待，显著提升复杂视频的渲染效率。
- **自检机制**：每次渲染后自动进行边界质量评估，在输出前确保视频质量，减少后期手动复查与修正。
- **零预设理念**：不依赖固定模板或菜单预设，完全通过代码和对话来定义视频风格和处理逻辑，灵活性极高。
- **纯开源与 MIT 许可**：项目完全开源，允许自由使用、修改和商用，社区活跃（12000+ 星标），持续迭代。
