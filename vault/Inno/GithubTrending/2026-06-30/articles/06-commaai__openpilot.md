## 项目概述

openpilot 是由 comma.ai 开发的开源机器人操作系统。其最直接的应用是升级车辆的高级驾驶辅助系统（ADAS），目前已经支持超过 300 款车型。项目通过一套完整的软件栈，让普通车辆具备类似自动辅助驾驶的能力，包括车道保持、自适应巡航控制等功能。目标用户包括希望在自己车上获得更好驾驶辅助体验的车主、投身自动驾驶研究的开发者，以及希望探索车辆控制技术的黑客与爱好者。

## 核心功能

- **车道保持与自适应巡航**：在高速和城市主干道上，openpilot 能够自动控制方向盘，使车辆保持在车道中央，同时根据前车速度自动调节车速，实现跟车行驶。
- **多品牌多车型支持**：项目维护了丰富的车辆接口数据库，支持包括本田、丰田、现代、起亚、宝马等主流品牌在内超过 300 款车型，用户通常只需安装设备并连接车辆 OBD-II 接口即可使用。
- **主动安全干预**：具备前向碰撞预警、车道偏离预警以及自动紧急刹车等安全功能，能够在驾驶员操作失误时主动介入，降低事故风险。
- **实时数据记录与远程监控**：系统会持续记录行驶过程中的传感器数据（摄像头、GPS、IMU 等），并可选通过云端服务远程查看车辆状态和行程回放。
- **开放接口与可定制性**：提供 Python 和 C++ 的编程接口，开发者可以根据需要修改驾驶策略、添加新的传感器输入或适配更多车型。
- **社区共享模型**：用户可以通过 comma.ai 提供的网络平台分享和下载经过验证的驾驶模型，互相协作优化驾驶表现。

## 技术架构

openpilot 的核心技术栈主要基于 Python 和 C++，依托以下关键技术构建：

- **深度学习模型**：系统使用端到端的深度神经网络处理前置摄像头输入，直接输出方向盘转角、油门和刹车控制信号。模型在 comma.ai 内部及社区收集的真实驾驶数据上训练，并持续通过 OTA 更新。
- **传感器融合**：融合来自摄像头、毫米波雷达（通过车辆 CAN 总线读取）、GPS 和 IMU（惯性测量单元）的数据，获得对车辆周围环境以及自身状态的准确感知。
- **基于 CAN 总线的控制**：所有车辆控制指令都通过标准的 CAN 总线协议发送给车辆的电子控制单元（ECU）。项目为每种车型维护了精确的 CAN 消息映射表，包括方向盘转角、油门踏板位置、刹车压力等信号的映射。
- **模块化进程架构**：系统采用多进程架构，各功能模块（如视觉感知、规划控制、车辆接口）独立运行，并通过共享内存或消息队列通信，确保系统稳定性和实时性。
- **实时操作系统（RTOS）内核**：底层运行在定制版的 Linux 实时内核上，配合 comma.ai 自研的硬件（如 comma three / comma four）可提供纳秒级时序保障。

## 安装与使用

### 硬件准备
openpilot 需要以下硬件支持：
- 一台兼容的 comma.ai 设备（如 comma three、comma four）
- 一根兼容的车辆接口线束（用于连接 OBD-II 和 CAN 总线）
- 白色或红色 panda（车辆网关桥接器）

### 快速安装（适用于开发设备）
1. 在预装了 openpilot 的 comma 设备上，通过 SSH 连接。
2. 运行以下命令更新至最新版本：
```bash
bash <(curl -fsSL openpilot.comma.ai)
```

### 最小可用示例
对于已在支持车型上安装好硬件的用户，使用步骤如下：
1. 将 comma 设备固定于挡风玻璃下方，确保前向摄像头视野清晰。
2. 接通设备电源并连接车辆 OBD-II 接口。
3. 启动车辆，设备将自动识别车型并加载对应配置。
4. 在设备屏幕或手机端 comma 应用上完成初始校准（需行驶几分钟使车辆保持直线）。
5. 校准完成后，在高速道路行驶中按下方向盘上的 “SET” 或对应按键即可激活 openpilot 的自适应巡航与车道保持功能。

## 适用场景

- **长途高速通勤**：在高速公路上，openpilot 可大幅减轻驾驶员负担，自动保持车道和车速，降低疲劳感。
- **城市主干道跟车**：在城市快速路或拥堵路段，系统能够平稳地跟随前车启停，提升通行效率与舒适性。
- **自动驾驶研究教学**：作为开源系统，openpilot 为高校和研究机构提供了完整的车载自动驾驶框架，便于学生理解感知、规划、控制的工程实现。
- **个人车辆能力升级**：许多出厂仅配备基础 ADAS 的车型，通过安装 openpilot 可获取接近高阶辅助驾驶的体验，例如更平稳的车道居中和更自然的加速刹车。

## 项目亮点

- **开源且可复现**：相比绝大部分车企封闭的驾驶辅助系统，openpilot 的源代码、训练数据和模型权重均完整开放，任何人均可自行编译构建。
- **车厂级别稳定性**：经过数百万公里的真实道路测试，系统在控制的平滑性和安全性上达到了接近商业化水平的稳定度。
- **快速演进的能力**：依托活跃的社区（Discord 频道、GitHub 讨论）和 comma.ai 的持续研发，项目每月都会发布重要更新，包括新车型适配、模型改进和安全热补丁。
- **透明与可控**：用户可随时通过设备查看系统日志、传感器原始数据和决策过程，不存在“黑箱”问题，符合对自动驾驶系统安全性的高要求。
