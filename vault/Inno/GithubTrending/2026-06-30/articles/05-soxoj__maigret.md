## 项目概述

Maigret 是一个开源的个人信息收集工具，能够通过用户名在超过 3000 个网站上进行跨平台搜索，帮助用户快速构建目标人物的数字档案（dossier）。该项目由开发者 soxoj 创建并维护，采用 MIT 许可证发布，目前已在 GitHub 上获得超过 34,000 颗星标。

该项目的核心目标是解决“人在互联网上留下哪些痕迹”这一开放性问题。当你只需要一个用户名时，Maigret 可以自动访问大量网站，检查该用户名是否已被注册，从而揭示目标账号在各平台上的分布情况。其目标用户包括安全研究人员、渗透测试人员、数字取证分析师、社工调查人员，以及任何需要了解网络身份关联性的普通用户。

## 核心功能

- **超大规模站点覆盖**：支持检测 3000 多个网站，涵盖社交媒体、论坛、博客、电子商务平台、开发者社区、视频网站、即时通讯工具等各类互联网服务。
- **智能检测与结果分类**：能够区分用户名是否存在、是否明确属于目标用户、以及是否存在歧义（如同名但不一定是同一个人），提供多种分类标记便于筛选。
- **报告生成功能**：支持将搜索结果导出为 HTML、PDF、JSON、CSV 等多种格式的报告，方便归档或与他人共享。
- **标签系统与站点筛选**：所有检测站点都带有标签（如“社交”、“媒体”、“编程”、“游戏”等），用户可用 `--retries`、`--timeout` 等参数控制搜索行为，也可通过 `--site` 或 `--exclude-site` 精确指定站点范围。
- **多线程异步请求**：采用异步 I/O 和多线程机制，在保持较低资源占用的同时大幅提升扫描速度。
- **代理与 Tor 支持**：支持配置 HTTP/HTTPS 代理，并可搭配 Tor 网络使用，增强调查时的匿名性。

## 技术架构

Maigret 使用 Python 3.10+ 开发，核心架构由以下几个关键部分组成：

- **站点引擎**：每个检测站点对应一个 JSON 配置文件，定义了检测 URL、响应判断逻辑（如 HTTP 状态码、页面内容中的特定字符串）、请求头等信息。这种设计使得新增站点只需编写配置文件，无需修改代码。
- **异步请求处理**：基于 `aiohttp` 和 `asyncio` 实现异步网络请求，能够同时发起数百个检测请求，显著减少总等待时间。同时采用 `tqdm` 进度条反馈扫描进度。
- **智能分析模块**：当发现某个用户名在多个平台存在时，系统会进一步分析账号之间的关联性，例如通过邮箱、头像 URL 等辅助信息判断是否为同一个人。
- **可视化界面**：除命令行模式外，还提供可选的网页图形界面（基于 Flask 框架），适合非技术人员使用。

项目的设计亮点在于“配置驱动的扩展性”——新增一个社交媒体平台只需编写一个短小的 JSON 配置文件，社区贡献者可以轻松加入支持站点。整个代码结构清晰，搜索引擎的逻辑与具体站点的检测规则完全解耦。

## 安装与使用

**基本安装：**

使用 pip 从 PyPI 安装：

```bash
pip install maigret
```

从 GitHub 安装最新开发版：

```bash
git clone https://github.com/soxoj/maigret.git
cd maigret
pip install .
```

**最小可用示例：**

搜索用户名 “johndoe” 的所有关联账号：

```bash
maigret johndoe
```

指定输出为 JSON 格式：

```bash
maigret johndoe --json output.json
```

在 Tor 网络下运行：

```bash
maigret johndoe --tor
```

生成详细的 HTML 报告：

```bash
maigret johndoe --html report.html
```

对于高级用户，可以使用 `--recursive-search` 启动递归搜索模式，不仅检索用户名，还会尝试通过找到的邮箱进一步扩展搜索范围。

## 适用场景

- **安全研究与渗透测试**：在红队演练中，通过目标已知用户名快速发现其使用的更多服务，扩大攻击面。也可以用于社工前期信息收集。
- **数字取证与分析**：当需要追溯某个网络身份的真实关联信息时（例如在反诈骗调查、网络犯罪追查中），Maigret 可大幅减少人工逐一检查各平台的时间成本。
- **个人隐私管理**：用户可以运行 Maigret 搜索自己的用户名，了解自己在哪些平台注册过账号，识别信息泄露风险，评估个人数字足迹的暴露程度。
- **社交媒体管理与品牌保护**：企业可以使用该工具监控品牌名称是否被冒用在不同平台注册，及时发现假冒账号。

## 项目亮点

- **站点数量领先**：Maigret 支持超过 3000 个站点，远超同类工具（如 Sherlock 仅支持约 1000 个站点），覆盖范围极为广泛。
- **结果精准度高**：通过对响应内容的深度分析，Maigret 能够有效减少误报，区分“用户名可用”、“用户名已注册但与目标无关”和“用户名已注册且疑似属于目标”等不同情况。
- **活跃的社区贡献**：项目拥有超过 300 位贡献者，站点列表持续更新，用户也可以直接通过 Pull Request 快速添加新平台。
- **报告工具完善**：原生支持多种报告格式，且 HTML 报告视觉效果友好，适合直接交付给客户或同事。
- **开源且轻量**：作为 MIT 许可的开源项目，完全免费，且安装依赖简单（仅需 Python 标准库外的少数包），无需数据库或复杂环境。
