## 项目概述

FluidVoice 是一款面向 macOS 的开源离线语音转文字听写应用，其核心目标是让用户在完全本地化、无网络依赖的环境下，实现高速且精准的语音输入。项目解决了传统云端语音服务存在的延迟、隐私泄露和网络依赖等问题，尤其适合追求数据安全、注重效率的专业用户和开发者。通过集成本地 AI 增强模型，FluidVoice 在无需任何 API 密钥或与外部服务器通信的情况下，即可提供媲美甚至超越云端服务的听写体验。

## 核心功能

- **离线高速听写**：基于优化后的 Parakeet 实时语音识别模型，实现近乎零延迟的语音转文字，说话后文字几乎立即出现在屏幕上。
- **本地 AI 增强（Fluid Intelligence）**：完全运行在设备上的 AI 模型，可自动修正语法错误、优化标点符号，显著提升听写文本的准确性和可读性，无需任何网络连接。
- **自适应主题与简洁界面**：支持自动切换的浅色/深色主题，并提供紧凑的工具栏切换器，减少界面干扰，专注于听写任务。
- **语言优先的引导流程**：首次使用时，系统会引导用户选择语言、配置语音引擎，并通过实时试听体验帮助用户快速上手，简化设置过程。
- **Homebrew 一键安装与自动更新**：支持通过 Homebrew Cask 快速安装和更新，同时提供手动下载最新版本的选项，降低部署门槛。

## 技术架构

FluidVoice 采用纯 Swift 语言开发，充分利用 macOS 的原生能力。其核心推理引擎基于 NVIDIA 开源的 Parakeet 实时语音识别模型（如 `parakeet_realtime_eou_120m-v1`），通过对模型加载和执行流程的深度优化，实现了从语音捕获到文字输出的极低延迟。本地 AI 增强模块（Fluid Intelligence）则是一个独立的轻量级语言模型，专门针对听写场景进行微调，负责对原始识别结果进行后处理，包括纠错和格式调整。整个系统完全离线运行，所有模型和数据处理均发生在用户设备上，从源头杜绝了数据外泄的风险。项目采用 GPLv3 许可证，确保了开源生态的持续性和社区贡献的平等性。

## 安装与使用

**安装方式：**

1. **推荐方式（Homebrew）**：在终端中运行以下命令：

```bash
brew install --cask fluidvoice
```

2. **手动下载**：访问 [GitHub Releases 页面](https://github.com/altic-dev/FluidVoice/releases/latest)，下载最新的 .dmg 文件并安装。

**基本使用步骤：**

1. 首次启动时，跟随引导界面选择您的母语并配置语音引擎。
2. 应用将自动下载所需的离线语音模型（大小约几百 MB），请确保网络可用。
3. 在任意支持文本输入的应用程序（如备忘录、邮件、浏览器、代码编辑器）中将光标放置在输入框。
4. 点击 FluidVoice 工具栏中的麦克风按钮，或使用全局快捷键开始说话。
5. 说完后停止，文字将自动识别并输入到光标位置。
6. 启用 Fluid Intelligence 后，系统会自动优化识别结果，消除常见错误。

## 适用场景

- **日常办公与文档撰写**：在书写长电子邮件、报告、会议纪要时，使用语音输入替代键盘打字，可显著提升效率，尤其适合需要频繁切换中文与英文的混合输入场景。
- **编程与代码注释**：开发者可在 Xcode、VS Code 等 IDE 中使用 FluidVoice 快速录入代码注释、文档字符串或编写文档，减轻打字负担。
- **无障碍与特殊需求**：为因身体原因（如手部受伤、残障）难以长时间使用键盘的用户提供可靠的替代输入方案，离线特性确保在无网络环境下也能正常工作。
- **隐私敏感场景**：在处理涉及商业机密、个人隐私或法律文书的文本时，完全离线运行避免了云端传输和存储带来的安全风险。

## 项目亮点

与市面上其他 macOS 听写应用（如 macOS 自带听写、Dragon Dictate 或各类云端服务）相比，FluidVoice 的核心差异化优势在于：

- **极致本地化与隐私保护**：所有语音数据无需离开用户的 Mac 设备，不存在数据泄露或被滥用的风险，完全满足对数据主权有严格要求的用户。
- **超低延迟体验**：通过精心优化的 Parakeet 模型，从语音输入到文字显示的延迟几乎不可感知，远低于同类的离线解决方案。
- **开源与社区驱动**：采用 GPLv3 许可证，代码完全公开。用户不仅可以免费使用，还能参与改进、审计安全性。项目积极寻求社区赞助以支持多平台（iOS、Windows）的发展。
- **集成式 AI 后处理**：Fluid Intelligence 作为内置功能，无缝地修正听写结果，无需用户手动编辑或调用其他服务，提供开箱即用的高质量体验。
