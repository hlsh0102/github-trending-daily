## 项目概述

AI Berkshire 是一套面向价值投资者的 AI 辅助研究框架，它深度融合了巴菲特、芒格、段永平、李录四位投资大师的方法论，并借助 Claude Code 与 Codex 等 AI Agent 实现专业级投资分析。项目核心目标并非让 AI 给出“万金油”式的分析报告，而是通过结构化、强制结论、多视角对抗的方式，提升投资研究的深度与决策纪律。目标用户是希望借助 AI 工具提升投研效率、避免情绪化决策的个人投资者与小型投资团队。该项目已在实盘中取得显著收益验证，2024 全年收益达+69.29%，远超全球主要指数。

## 核心功能

- **四大师方法论系统化**：将巴菲特、芒格、段永平、李录各自独特的投资哲学（如巴菲特的护城河理论、芒格的多模型思维、段永平的“买股票就是买公司”逻辑、李录的长期主义）转化为可量化的分析模板与检查清单。
- **多 Agent 对抗式分析**：并非让单一 AI 模型分析，而是模拟四位大师的视角对同一标的进行独立研判，生成存在真实矛盾和张力的多份报告，最终通过辩论机制收敛到一个结论。
- **强制结论输出机制**：严格区分于普通 AI 的“一方面……另一方面……”式平衡分析。项目强制要求输出明确的“通过/不通过/灰色地带”结论，附带详细的价格区间和不同风险偏好的建仓策略。
- **镜子测试与决策纪律**：内置“镜子测试”——要求用户在5句话内说清买入逻辑，说不清即触发不买规则。同时提供完整的决策日志，便于复盘与纪律遵守。
- **实盘业绩追踪与回测**：项目公开了基于该框架产生的真实交易记录与收益数据，支持用户对比参考，并内置历史回测能力。

## 技术架构

项目基于 Python 开发，核心设计思路是“方法论驱动 + Agent 协作”。其架构特点如下：

- **模块化 Method 库**：将四位大师的投资方法论拆解为独立的模块，每个模块包含：核心原则、检查清单、定性/定量指标、决策树。这些模块可以自由组合或单独调用。
- **Agent 编排层**：使用类似 LangChain / CrewAI 的多 Agent 框架，定义每个分析 Agent 的角色（如：巴菲特 Agent、芒格 Agent）、记忆、工具（如财务数据API、新闻抓取）与目标。系统控制 Agent 间的通信与辩论流程。
- **强制结论引擎**：独立于分析流程之外的决策引擎，接收各 Agent 的输出，根据预设的冲突解决规则（如当巴菲特视角与段永平视角冲突时，以现金流确定性优先）生成最终推荐“通行证”。
- **数据管道**：自动从指定源（如Yahoo Finance、东方财富、公司财报PDF）抓取并清洗数据，供 Agent 使用。数据缓存机制保证分析效率。
- **可观测性**：所有 Agent 的思考过程、中间变量、最终决策均被记录，支持导出为 JSON 或 Markdown 报告，便于用户复盘与审计。

## 安装与使用

### 安装

```bash
# 克隆仓库
git clone https://github.com/xbtlin/ai-berkshire.git
cd ai-berkshire

# 安装依赖（推荐使用虚拟环境）
pip install -r requirements.txt

# 设置 API Key（根据使用的AI服务）
export ANTHROPIC_API_KEY="你的Claude API Key"   # 如使用Claude
# 或
export OPENAI_API_KEY="你的OpenAI API Key"       # 如使用Codex
```

### 最小可用示例

```bash
# 分析某支股票（如：腾讯控股）
python berkshire.py --ticker 0700.HK --master buffet,munger

# 输出结果保存在 output/reports/ 目录下
# 包含：各大师独立分析、对抗辩论记录、最终决策卡
```

## 适用场景

- **个人投资者的深度研究**：一个散户可以利用该框架，在几分钟内完成过去需要专业团队数天才能完成的全面基本面分析，并得到可执行的买卖建议。
- **投资团队的第一道筛选**：基金经理或分析师可以将其作为初步筛选工具，对候选标的进行快速且系统化的评估，将精力集中在最有潜力的目标上。
- **投资纪律训练与复盘**：新手投资者可以利用框架内置的强制结论与镜子测试，练习如何像一个成熟的价值投资者一样思考，并通过回顾历史分析日志纠正决策偏差。

## 项目亮点

与市面上主流的 AI 投资助手或通用 LLM 分析方案相比，AI Berkshire 拥有以下差异化优势：

- **实盘业绩验证**：不同于多数开源项目仅有理论模型，该项目提供了连续两年的真实收益数据，并大幅跑赢全球主要指数，可信度极高。
- **对抗式分析而非单一模型**：避免了大语言模型的“讨好性”输出（即过度迎合用户预设观点）。四个视角的对抗确保了结论的多维度审视。
- **强制决策而非分析报告**：项目产出不是一篇可读可忽略的分析文章，而是一张带有明确结论和行动清单的“决策卡”，直接服务于投资执行。
- **方法论深度而非广度**：聚焦于四大师的价值投资体系，而非泛泛的“基本面分析”。这使得研究框架具有明确的哲学内核和可复现的决策逻辑。
