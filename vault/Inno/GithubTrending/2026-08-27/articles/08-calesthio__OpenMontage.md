## 项目概述

OpenMontage 是全球首个开源的智能体视频制作系统。它将传统视频制作流程中的策划、脚本、分镜、拍摄、剪辑、调色、音效、字幕等环节，抽象为可编排的自动化管线，让开发者能够通过自然语言指令，将 AI 编码助手（如 Cursor、Copilot 等）直接转变为功能完整的视频制作工作室。

该项目由 calesthio 开发并维护，采用 AGPL-3.0 许可协议。目前仓库已获得超过 5 万颗星标，并持续保持高热度增长。OpenMontage 的核心目标用户是具备一定编程基础的视频创作者、内容团队以及希望将视频生产流程自动化的企业开发者。它消除了传统视频制作中高昂的软件成本和复杂的学习曲线，将专业级的制作能力以代码和提示词的形式开放给所有人。

## 核心功能

- **12 条专业制作管线**：覆盖从短视频、纪录片、教学课程、产品宣传到电影预告片等不同类型视频的完整生产流程。每条管线都经过精心设计，包含从创意孵化到成片输出的所有必要步骤。

- **100+ 集成工具**：内置了与主流视频处理软件、云服务和 AI 模型的接口，包括 FFmpeg、Whisper、Stable Diffusion、各大 LLM 提供商等，无需额外配置即可调用。

- **700+ 技能与知识文件**：项目携带庞大的提示词库、分镜模板、剪辑规范、色彩理论、音效设计指南等专业知识文件，为 AI 智能体提供深度的行业认知支持。

- **“粘贴视频”反向工程**：支持用户直接粘贴一个喜欢的视频链接，系统会自动分析其结构、节奏、运镜和剪辑风格，并生成可复用的制作方案。

- **多提供商适配**：通过统一的 Provider 抽象层，支持接入 OpenAI、Anthropic、Google 等多家模型服务商，用户可根据成本和质量自由切换。

- **智能体协作模式**：针对 AI 编码助手的特性进行了优化，能够将复杂的制作任务拆分为可逐步执行的子任务，并支持断点续跑和结果校验。

## 技术架构

OpenMontage 采用 Python 构建，其架构核心是“管线-工具-技能”三层解耦设计。

**管线层（Pipeline Layer）** 定义了视频制作的高级流程。每条管线是一个有向无环图（DAG），节点代表制作阶段（如企划、脚本、分镜、素材生成、剪辑、后期），边代表数据依赖。这种设计使得流程清晰可溯，并允许用户对任意节点进行插拔或定制。

**工具层（Tool Layer）** 封装了所有外部依赖。无论是调用本地 FFmpeg 命令，还是请求远程 AI 服务，都以统一的 `Tool` 接口暴露给管线。这使得替换或新增工具变得异常简单，只需遵守接口约定即可。

**知识层（Knowledge Layer）** 是项目的灵魂。超过 700 个 Markdown 文件构成了一个结构化的知识库，包含专业的制作技巧、风格指南和行业术语。这些知识通过检索增强生成（RAG）技术被注入到 AI 智能体的上下文中，确保生成的脚本和指令具备专业水准，而非空泛的套话。

整个系统采用事件驱动机制，各管线节点通过消息队列进行通信，支持异步执行。这意味着长耗时的视频渲染或模型推理任务不会阻塞整个生产流程。

## 安装与使用

**安装步骤：**

1. 克隆仓库并安装依赖：
```bash
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
pip install -r requirements.txt
```

2. 配置 API 密钥。在项目根目录创建 `.env` 文件，填入你的模型服务商密钥：
```bash
OPENAI_API_KEY=your_key_here
```

3. 启动交互式智能体环境（以 Cursor 为例），将 `AGENT_GUIDE.md` 添加到项目上下文中。

**最小可用示例：**

启动你的 AI 编码助手，在对话中直接输入：

```
使用短视频管线，制作一段 30 秒的科技产品介绍视频，主题是“无线降噪耳机”。
```

OpenMontage 会自动调用管线，依次完成以下工作：
- 生成创意脚本与分镜大纲
- 调用图像生成模型创建视觉素材
- 合成配音与背景音乐
- 执行剪辑并输出最终 MP4 文件

用户只需要在管线执行过程中对关键节点（如脚本确认）进行简短审核即可。

## 适用场景

- **内容创作者自动化**：个人 YouTuber 或短视频博主可以使用 OpenMontage 批量生成视频素材和初剪版本，将精力集中在创意和个性化调整上，单日产量可从 1 条提升至 5-10 条。

- **企业内部培训与营销**：市场团队或 HR 部门可预设公司产品知识库和品牌视觉规范，通过对话式操作快速产出产品演示、员工培训等标准化视频，极大缩短制作周期。

- **教学资源快速构建**：教育机构可将课件内容输入系统，自动生成包含动画演示、字幕和讲解的课程视频，并能根据不同的课程要求切换讲解风格。

- **视频风格研究与仿制**：利用“粘贴视频”功能，创作者可以快速解构热门视频的叙事节奏和手法，将其转化为可编辑的模板，辅助创作灵感。

## 项目亮点

- **真正意义上的“零配置”体验**：与其他需要复杂工作流编排的工具相比，OpenMontage 提供了一个开箱即用的智能体入口。用户只需要描述需求，系统会自动选择并执行合适的管线。

- **深度“知识注入”机制**：多数同类项目仅依赖大模型的通用能力，而 OpenMontage 内置的 700+ 专业知识文件，使其在分镜语言、剪辑节奏等专业维度上远超通用模型输出。

- **开放、可扩展的生态**：作为开源项目，用户可以自由查看、修改和贡献管线、工具与知识文件。对于有特殊需求的团队，可以轻松基于此构建内部专属的视频生成平台。

- **模型无关的设计**：通过 Provider 抽象层，避免了对单一 AI 供应商的锁定。用户可以在不修改任何业务代码的情况下，切换至更便宜或更强大的模型。
