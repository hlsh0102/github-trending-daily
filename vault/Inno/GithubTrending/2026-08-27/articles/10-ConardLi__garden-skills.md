## 项目概述

Garden Skills 是一个由 ConardLi 开源维护的 Agent Skills 精选集合，专为 Claude Code、Cursor、Codex 等主流 AI 编程代理设计。该项目旨在解决 AI 编程代理在实际开发任务中缺乏专业化、可复用技能的问题——默认情况下，AI 代理虽然具备通用对话和代码生成能力，但在网页设计、图像生成、内容排版等垂直领域往往表现得不够稳定和精细。Garden Skills 将这些高频、复杂度高的任务封装为即插即用的“技能包”，使开发者可以像安装插件一样快速增强 AI 代理的能力。项目目前已在 GitHub 上获得超过 11000 颗星，主要面向使用 AI 辅助开发的前端工程师、全栈开发者、内容创作者以及希望提升 AI 代理输出质量的技术团队。

## 核心功能

- **网页视频演示（web-video-presentation）**：提供专业的网页视频和幻灯片演示技能，支持从内容大纲到视觉呈现的完整流程，适合技术分享、产品发布等场景。
- **网页设计工程师（web-design-engineer）**：封装了完整的网页设计方法论和前端实现规范，涵盖布局、配色、响应式设计等关键环节，帮助 AI 生成视觉美观且代码规范的页面。
- **图像生成（gpt-image-2）**：针对 GPT Image 2 模型优化了提示词工程和参数配置，让 AI 能够更准确地理解设计意图，生成高质量、风格一致的产品图或概念图。
- **精美文章排版（beautiful-article）**：专注于富文本内容的排版优化，自动应用优秀的排版规则，使 AI 产出的长文、博客或文档具备清晰的信息层级和舒适的阅读体验。

## 技术架构

Garden Skills 基于 Anthropic 提出的 Agent Skills 标准进行构建。每个技能包本质上是一个包含 `SKILL.md` 定义文件和若干辅助资源的目录结构，其中 `SKILL.md` 使用 YAML frontmatter 声明技能名称、描述、触发条件等元数据，正文则使用 Markdown 编写结构化的操作指令、设计原则和代码模板。这种设计使得技能包具备高度的可移植性和兼容性——只要 AI 代理支持 Skills 协议，就能直接加载并执行。项目在实现上有几个显著特点：首先是**渐进式披露**，技能文件不会一次性注入全部上下文，而是按需加载，从而节省 token 并避免干扰核心任务；其次是**模块化组合**，不同技能之间可以互相引用或串联，例如使用网页设计技能生成页面后，再调用图像生成技能补充视觉素材；最后是**生产级验证**，每个技能都经过真实项目的测试打磨，而非纯粹的理论模板，确保在复杂场景下也能稳定输出。

## 安装与使用

安装 Garden Skills 非常简单，适用于所有支持 Agent Skills 的编程工具。以 Claude Code 为例，你只需将对应的技能目录复制到项目的 `.claude/skills/` 文件夹下即可：

```bash
# 克隆仓库（或手动下载所需技能目录）
git clone https://github.com/ConardLi/garden-skills.git

# 将需要的技能复制到你的项目配置目录
cp -r garden-skills/skills/web-design-engineer .claude/skills/
```

对于 Cursor 或 Codex，安装路径略有不同，但思路一致——将技能目录放入工具指定的 skills 配置路径。安装完成后，AI 代理会自动识别并在相关任务中激活技能，无需额外编写调用代码。以下是一个最小使用示例：当你在 Claude Code 中提出“帮我设计一个产品介绍落地页”时，代理会自动匹配 `web-design-engineer` 技能，并按照技能中定义的步骤生成完整页面。你也可以在提示中显式指定技能名称，例如：“使用 web-design-engineer 技能，为这款 SaaS 产品创作一个现代风格的首页”。

## 适用场景

- **快速原型设计**：在项目早期阶段，利用网页设计技能快速产出可交互的高保真原型，替代手工编写 HTML/CSS，大幅缩短设计验证周期。
- **内容生产流水线**：内容团队可以组合使用文章排版和图像生成技能，让 AI 完成从选题到配图再到样式美化的完整创作流程，提升内容发布效率。
- **前端项目开发**：开发者在实现复杂 UI 组件或页面时，可以借助网页设计技能获得规范的代码结构和设计建议，减少视觉还原偏差。
- **知识库构建与文档美化**：当需要将零散的技术笔记整理为结构化文档时，文章排版技能可以自动优化标题层级、代码块样式和列表格式，提升可读性。

## 项目亮点

与市场上其他 Agent 技能集合相比，Garden Skills 最突出的差异在于其**精选与质量把控**。项目并非简单堆砌大量低质技能，而是每个技能都经过真实业务场景的检验，去掉泛化而无效的内容，保留真正能提升 AI 代理生产力的部分。其次，项目保持了**零依赖的纯净设计**，所有技能均以标准 Markdown 编写，不依赖特定平台或运行时，用户可以在任何支持 Skills 的代理中无缝迁移使用。此外，作者 ConardLi 作为知名开源开发者，持续维护并更新技能库，紧跟 AI 模型迭代步伐（例如针对 gpt-image-2 的专项优化），确保技能始终与最新能力对齐。最后，项目采用 MIT 许可证，鼓励社区贡献和定制，使得技能库能够从集体智慧中获益，不断进化。
