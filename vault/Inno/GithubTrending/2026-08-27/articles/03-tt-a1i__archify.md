## 项目概述

Archify 是一个面向 AI 编程代理（Agent）的图表渲染与校验系统，它能够将代码库或系统描述直接转化为精美的交互式系统地图。该项目由 Node.js 驱动，专为 Cursor、Claude Code、Codex CLI 和 OpenCode 等主流 AI 编程工具设计。Archify 的核心价值在于：AI 代理生成类型化的 JSON 中间表示（IR），然后由 Archify 以确定性方式编译为自包含的 HTML/SVG 图表，从而确保每次生成的图表不仅视觉效果出色，而且内容完全可验证、可追溯。

该项目的目标用户包括：使用 AI 辅助编程的开发者、需要快速可视化系统架构的技术负责人、以及希望在代码审查前直观理解架构变更的团队成员。Archify 目前拥有超过 2.1 万 Star，活跃度极高，正处于 v2.16.0-dev.0 开发版本阶段。

## 核心功能

- **五种图表类型**：支持架构图、工作流图、时序图、数据流图和生命周期图，覆盖系统描述的绝大多数场景。
- **四种预设风格**：内置多套视觉主题，配合深色/浅色主题切换，以及品牌标志集成，让图表开箱即可用于演示和汇报。
- **架构变更对比**：支持将两个经过校验的快照进行 Before / Delta / After 三种视图对比，精确显示节点和连接的添加、删除、修改、移动及重路由事实。
- **交互式探索**：图表内可搜索节点，能够打开经修订验证的源代码，追踪上下游可达性与精确路由，对比不同角色职责。
- **多格式导出**：除自包含 HTML 外，还支持 PNG、SVG、WebM 视频格式，以及 1200×630 尺寸的分享卡片，满足文档、演示和社交媒体分享需求。
- **类型化 JSON IR**：以结构化中间表示作为事实来源，确保所有渲染结果具有确定性和可校验性。

## 技术架构

Archify 采用两段式设计架构。前端由 AI 代理生成类型化的 JSON IR，这是一种严格定义的数据结构，包含所有图元、连接关系和属性信息；后端由 Archify 的 Node.js 渲染引擎接收 JSON IR，执行确定性编译，输出最终的 HTML/SVG 产物。

这种设计带来了几个关键架构特性：首先，JSON IR 作为中间层，使 AI 代理无需关心渲染细节，只需关注系统事实；其次，确定性编译意味着相同输入必然产生相同输出，这为自动化测试和版本对比奠定了基础；第三，所有输出都是自包含的单一文件，不依赖外部资源，便于分发和长期保存。

在验证机制方面，Archify 内置了类型检查和结构校验，能够在渲染前发现拓扑错误或不一致之处。交互层则通过轻量级 JavaScript 实现搜索、导航和故事导览功能，同时保持动画效果克制，不干扰信息传达。

## 安装与使用

Archify 以 Agent Skill 形式集成到主流 AI 编程工具中，安装过程非常直接：

```bash
# 以 Claude Code 为例，在项目目录中安装 skill
# 将 archify 目录复制到 .claude/skills/ 下
```

安装后，AI 代理即可自动调用 Archify 生成图表。最小使用流程如下：

1. 在 AI 编程工具中打开目标代码库或描述系统架构；
2. 向代理提出请求，例如"为当前代码库生成架构图"；
3. 代理分析代码或描述，输出类型化 JSON IR；
4. Archify 自动编译为自包含 HTML 图表，可直接在浏览器中打开。

对于架构变更审查场景，可以分别在两个 git 提交点生成快照，然后使用对比功能查看差异详情。

## 适用场景

- **架构文档与汇报**：将复杂的微服务系统、分布式架构或业务流转化为直观、可交互的图表，直接用于内部文档或客户演示。
- **代码审查辅助**：在合并请求前对比架构快照，快速定位新增模块、移除的依赖或变更的路由，显著提升大型重构的审查效率。
- **AI 编程辅助**：当 AI 代理需要理解大型代码库结构时，生成可视化地图作为上下文参考，减少遗漏和幻觉。
- **技术分享与教学**：导出 SVG 或 PNG 用于技术博客，或利用 WebM 动画展示系统动态过程，帮助读者快速建立心智模型。

## 项目亮点

与传统的图表工具（如 Mermaid、PlantUML 或 draw.io）相比，Archify 的差异化优势十分明显：

- **专为 AI 代理设计**：不同于需要开发者手工编写语法的工具，Archify 完全由 AI 代理驱动生成，开发者只需要表达意图。
- **确定性渲染**：输出结果可预测、可测试，适合纳入 CI/CD 流程中做架构变更检测。
- **所见即所得**：生成的是可直接展示的高质量图表，而非需要二次排版的原始语法。
- **细粒度的变更追踪**：对比功能不仅显示"有变化"，还精确到每个节点和连接的事实差异。
- **自包含交付**：单一 HTML 文件包含全部样式、脚本和交互逻辑，发送给任何人即可查看和交互。
