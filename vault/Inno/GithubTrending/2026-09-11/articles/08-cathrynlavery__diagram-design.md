## 项目概述

Diagram Design 是一个面向 AI 编程助手（Claude Code、Codex、Factory Droid、Pi 以及兼容 Agent Skills 的宿主环境）的图表生成技能库。它提供了 39 种编辑级（editorial）图表类型，覆盖架构图、循环图、Sankey 图、鱼骨图、Wardley 地图、看板、用户旅程图、UML 类图、数据库模式图等常见与专业场景。所有图表以自包含的 HTML + SVG 形式输出，不依赖外部渲染服务，也不使用投影等装饰效果。

该项目要解决的问题是：在 AI 辅助写作与开发流程中，图表通常依赖 Mermaid 等文本到图形工具，产出样式单一、缺乏排版控制，或者需要设计师在 Figma 中反复调整颜色与圆角。Diagram Design 让 AI 助手直接生成结构可控、风格克制的静态图表，减少“Mermaid 味”和重复的设计决策。目标用户是需要在文档、博客、技术说明或产品材料中快速嵌入图表的开发者、技术写作者和设计师。

## 核心功能

- **39 种编辑级图表类型**：涵盖架构、循环（飞轮）、Sankey、鱼骨、Wardley 地图、看板、用户旅程、部署、依赖图、UML 类图、故事地图、数据库模式等，每种类型有独立的布局语法。
- **语义系统模式**：将“行为”与“布局”分离，队列、策略追踪、信任边界等语义模式可以复用最接近的现有图表类型，而不需要新增图表种类。
- **自包含 HTML + SVG 输出**：每个图表是一个独立文件，可直接嵌入网页或文档，无需外部 CSS、JS 或字体依赖。
- **可选动效，静态为默认**：静态 HTML 是默认输出；当需要按顺序解释时，可选择开启无障碍动效，不影响静态可读性。
- **源文件重绘**：可将 draw.io、Mermaid 或 Excalidraw 源文件按指定格式、尺寸和细节层级重新绘制。
- **兼容多种 AI 宿主**：支持 Claude Code、Codex、Factory Droid、Pi 以及 Agent Skills 兼容环境。

## 技术架构

项目以 HTML 为语言载体，核心产物是结构化的 SVG 与 HTML 模板。设计思路强调“无阴影、无通用圆角盒子”，通过排版层级、留白和线条来表达关系，而不是依赖装饰性视觉效果。语义模式层把图表的行为语义（例如队列、策略追踪、信任边界）抽象出来，与具体布局语法解耦，使同一语义可以映射到多种视觉类型。

2.5.10 版本新增了十种布局语法，包括 Sankey、鱼骨、Wardley 地图、看板、用户旅程、部署、依赖图、UML 类图和数据库模式。2.3 版本引入语义系统模式和可选动效，同时保持静态输出为默认。这种分层设计让图表类型数量可控，同时提升语义覆盖范围。

## 安装与使用

由于项目以 AI 技能形式发布，安装方式取决于宿主环境。通常需要将仓库内容放入对应 AI 助手的技能目录，或在配置中注册该技能。常见做法是克隆仓库后，在 Claude Code 或兼容宿主中启用该技能，之后通过自然语言指令生成图表。

最小可用示例：向 AI 助手描述“生成一个三节点的架构图，包含客户端、API 网关和数据库”，技能会输出一个自包含的 HTML + SVG 文件。也可以指定图表类型，例如“用 Sankey 图展示用户从注册到付费的转化路径”。若已有 draw.io 或 Mermaid 源文件，可要求按指定尺寸和细节层级重绘。

## 适用场景

- **技术文档与博客配图**：为架构说明、数据流、部署拓扑生成风格统一的静态图表。
- **产品与用户研究材料**：绘制用户旅程、故事地图、看板或 Wardley 地图。
- **数据库与系统设计**：输出数据库模式图、UML 类图、依赖图或信任边界图。
- **旧图重制**：将 draw.io、Mermaid、Excalidraw 源文件按新的格式和细节要求重新绘制。

## 项目亮点

与 Mermaid 等文本图表工具相比，Diagram Design 提供更接近编辑排版的视觉控制，避免默认样式带来的“通用感”。与 Figma 等设计工具相比，它不需要手动选色和调整圆角，图表由 AI 直接生成且可复现。语义模式与布局分离的设计，使其在有限图表类型下覆盖更广的行为表达。项目采用 MIT 许可证，输出为自包含 HTML + SVG，便于嵌入和长期维护。GitHub 星标数超过 3.8 万，当日新增约 1294，说明其在 AI 辅助图表生成领域有较高关注度。
