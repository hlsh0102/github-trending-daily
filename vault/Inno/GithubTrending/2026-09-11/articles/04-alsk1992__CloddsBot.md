## 项目概述

CloddsBot 是一个开源的自主 AI 交易代理，目标是把“发现机会—执行交易—风险控制”这一整套流程交给一个可自托管的智能体来完成。它同时覆盖预测市场、加密货币现货/合约以及多个链上的去中心化交易场所，聚合了 Polymarket、Kalshi、Binance、Hyperliquid、Solana DEX 以及 5 条 EVM 链上的行情与交易通道，宣称可触达 1000 多个市场。项目名称来自 “Claude + Odds”，底层基于 Claude 构建，用自然语言与推理能力驱动交易决策。

它试图解决的问题主要有两类：一是跨平台、跨链的行情与流动性分散，人工难以同时监控大量市场的定价偏差；二是自动化交易策略通常需要自行搭建行情接入、下单、风控与资金结算的完整管线。CloddsBot 以 TypeScript 实现，提供统一的市场扫描与执行层，让用户通过配置与技能（Skills）组合出策略，而不必从零开发每个交易所的适配代码。目标用户包括个人量化交易者、加密与预测市场的活跃参与者，以及希望自托管 AI 交易代理、对资金和数据保留控制权的开发者。

## 核心功能

- **多市场行情扫描与边缘发现**：同时接入预测市场、中心化交易所与链上 DEX，跨市场比对定价，识别潜在的错价与套利机会。
- **自动执行与订单管理**：在发现机会后直接下发交易指令，覆盖 Binance、Hyperliquid、Solana DEX 及 EVM 链上交易，减少人工响应延迟。
- **内置风险管理**：在执行过程中进行仓位与风险约束管理，使代理可以在无人值守的状态下持续运行。
- **技能系统（119+ Skills）**：以技能为粒度组织能力，用户可按需启用或组合，扩展代理可执行的操作范围。
- **Agent 商务协议与机器间支付**：内置面向 agent-to-agent 的支付协议，支持自动化场景下的机器间结算。
- **自托管部署**：全部运行在用户自己的环境中，私钥与策略配置不由第三方托管。

## 技术架构

项目使用 TypeScript 5.3 编写，运行环境要求 Node.js 22 及以上，通过 npm 包 `clodds` 分发，采用 MIT 许可。架构上可以理解为三层：底层是面向各交易场所的适配与连接层，负责行情订阅、订单路由与链上交互；中间是技能与工具层，把具体能力拆分为可组合的技能单元，供代理按任务调用；上层是以 Claude 为核心的决策与编排层，将市场信息转化为交易动作，并配合风险控制模块约束执行。

这种设计的要点在于解耦——新增一个市场或交易场所，只需增加对应适配器；新增一种策略能力，则以技能形式接入，而不影响既有逻辑。代理通过统一的接口访问异构市场，从而在预测市场与链上交易之间共享同一套扫描、执行与风控流程。自托管意味着运行实例、API 憑证与私钥都掌握在用户侧，代理的自主性建立在用户可控的部署之上。

## 安装与使用

前置条件为 Node.js 22+。基本安装方式为全局或本地安装 npm 包：

```bash
npm install -g clodds
```

安装后需配置运行所需的憑证，包括所用模型服务（Claude）的访问凭据，以及各交易场所/链的 API Key 或钱包配置。具体配置项以仓库文档为准。

最小可用流程是：完成配置后启动代理，指定要扫描的市场范围与启用的技能，代理即开始周期性地获取行情、评估机会并按风控规则执行。建议先在只读或模拟模式下验证行情接入与决策逻辑，再逐步开放真实下单权限。仓库 README 及配套文档包含更完整的配置示例与技能清单。

## 适用场景

- **预测市场套利与做市**：在 Polymarket、Kalshi 等平台之间比对赔率，捕捉定价偏差。
- **跨场所加密交易**：在中心化交易所与链上 DEX 之间监控价差并执行。
- **无人值守的自动交易**：以预设风控约束让代理在非交易时段持续运行。
- **Agent 商务与机器支付实验**：借助内置的 agent commerce 协议，构建机器间自动结算的场景。

## 项目亮点

与仅针对单一交易所的机器人相比，CloddsBot 的差异在于覆盖面的广度——预测市场、CEX、Hyperliquid 与多链 DEX 被纳入同一代理的统一视图中，机会发现不再局限于单一平台。技能化的能力组织使其具备较强的可扩展性，119+ 技能提供了开箱可用的操作集合。基于 Claude 的决策层让策略可以用更接近自然语言的方式表达与调整。加之自托管与 MIT 许可，用户在资金控制与二次开发上保有较大自由度，该项目也为 Colosseum Agent Hackathon 而构建。
