## 项目概述

God's Eye View 是一个运行在浏览器中的“间谍卫星模拟器”，其核心特征在于所展示的数据全部来自公开来源。项目以一个逼真的 3D 地球为可视化载体，将航班、船舶、卫星、地震、交通流量与公共摄像头等实时空间信息叠加在同一张球体上，形成一套面向普通用户的开放空间情报（OSINT）界面。

它解决的问题在于：公开的时空数据分散在数十个不同的数据源中，格式、坐标体系与刷新频率各不相同，普通用户很难在统一视图中同时观察它们。God's Eye View 将这些数据源聚合、对齐到统一的地球坐标系，并配合自然语言语音控制降低操作门槛，使非专业用户也能直观地“俯瞰”全球动态。目标用户包括 OSINT 研究者、地理信息爱好者、新闻与事实核查从业者，以及对实时全球数据可视化感兴趣的一般技术用户。

## 核心功能

- **照片级 3D 地球渲染**：以球体形式呈现地球表面，支持自由旋转、缩放与视角切换，作为所有数据图层的统一空间底图。
- **多源实时数据图层**：同时叠加实时航班、船舶、卫星、地震、交通与公共摄像头等公开数据，各图层可独立开关。
- **语音免手控制**：集成实时 AI 代理，用户可通过自然语言指令完成视角切换、图层过滤和地点定位等操作，无需手动交互。
- **零 API 密钥启动**：默认配置下无需任何私有密钥即可运行，可选密钥在应用内按需补充，降低初次使用门槛。
- **多平台启动支持**：提供 Pinokio 一键安装和终端本地运行两种方式，适配不同技术背景的用户。

## 技术架构

项目主体使用 JavaScript 编写，运行于浏览器环境，属于典型的前端可视化应用。整体架构围绕“渲染层 + 数据层 + 交互层”展开：

渲染层负责 3D 地球的建模与绘制，需要处理大规模几何体和纹理贴图的实时加载，对 WebGL 性能有较高要求。数据层负责对接多个公开数据源，将不同坐标系（经纬度、高度、时间戳）的数据统一转换并挂载到球体对应位置，同时管理各图层的刷新节奏与生命周期。交互层则承担相机控制、图层管理与语音指令解析，其中语音部分依赖实时 AI 代理完成自然语言到具体操作参数的映射。

设计上的一个关键取舍是“数据真实性优先”：项目定位为模拟器的外观、真实数据的实质，因此所有可视化元素都对应可追溯的公开来源，而非预制演示数据。这种设计也意味着系统对网络可用性和数据源稳定性有一定依赖。

## 安装与使用

推荐使用 Pinokio 进行安装：在 Pinokio 中搜索并选择 God's Eye View 应用，一键完成环境准备与启动，无需手动配置 API 密钥。

也可以从终端本地运行，基本流程如下：

```bash
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
# 按仓库 README 说明安装依赖
npm install
npm start
```

启动后浏览器会打开 3D 地球界面。最小可用示例：在地球上旋转到目标区域，打开“航班”图层即可看到该空域内的实时飞机；若需要更完整的数据覆盖，可在应用内设置页填入可选 API 密钥。语音控制功能在麦克风权限授予后即可使用。

## 适用场景

- **OSINT 教学与演示**：在课堂或分享中直观展示公开数据的空间分布与关联，作为开源情报方法的入门工具。
- **新闻与事实核查**：结合航班、船舶与摄像头图层，对特定区域的动态进行多源交叉观察。
- **地理与数据可视化研究**：作为多图层实时渲染的参考实现，研究大规模点数据在球面上的呈现方式。
- **个人探索与兴趣使用**：以近似“卫星视角”的体验观察全球实时活动，兼具工具性与观赏性。

## 项目亮点

与常见的静态地图或单一数据源可视化工具相比，God's Eye View 的差异主要体现在三点。第一是**数据真实性**：项目以公开数据为核心卖点，避免了“模拟器只有外观、没有实据”的常见问题。第二是**多源融合规模**：在同一球体上同时承载航班、船舶、卫星、地震、交通与摄像头等异构图层，聚合度较高。第三是**交互门槛低**：零 API 密钥即可启动，配合语音控制，使非技术用户也能快速上手。项目在 GitHub Trending 日榜与周榜曾达到第一，并衍生出播放量较大的视频系列，社区关注度可作为其可用性的侧面参考。
