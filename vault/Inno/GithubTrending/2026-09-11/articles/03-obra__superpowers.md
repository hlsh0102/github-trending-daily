## 项目概述

Superpowers 是一个面向编码智能体（coding agent）的软件开发方法论框架。它并不直接提供某个 AI 模型或编程助手，而是通过一组可组合的“技能（skills）”和初始指令，规范智能体在接到开发任务后的行为方式。其核心目标是解决当前编码智能体普遍存在的一个问题：一旦识别到用户在“构建某样东西”，就立即跳入代码编写环节，缺乏需求澄清、设计确认和实施规划，导致返工、偏离预期或产出难以维护的代码。

Superpowers 试图把一套完整的软件工程流程——从需求挖掘、规格确认、方案设计、实施计划到执行与验证——嵌入到智能体的工作流中，让智能体在动手前先“退后一步”，与用户共同明确真正要解决的问题。目标用户是使用各类编码智能体（如 Claude Code、Codex、Cursor、Gemini CLI 等）进行实际开发的工程师、技术团队以及希望规范化 AI 辅助开发流程的组织。

## 核心功能

- **需求澄清前置**：智能体在检测到构建意图后，不会直接编写代码，而是主动询问用户真正想达成的目标，从对话中提炼出规格说明。
- **分块式规格确认**：将提炼出的规格以足够短、可阅读的片段呈现给用户逐段确认，避免一次性输出难以消化的长文档。
- **实施计划生成**：在用户确认设计后，智能体生成一份实施计划，作为后续编码执行的依据。
- **可组合的技能体系**：整套方法论构建在一组可组合的 skills 之上，每个技能可独立使用，也可按需组合成完整流程。
- **多智能体平台支持**：提供针对 Claude Code、Antigravity、Codex App/CLI、Cursor、Devin CLI、Factory Droid、Gemini CLI、GitHub Copilot CLI、Grok Build CLI、Kimi Code、OpenCode、Pi、Hermes Agent 等多种平台的接入方式。
- **引导式初始指令**：通过初始指令确保智能体在会话开始时即加载并遵循这套方法论，而非依赖用户手动提醒。

## 技术架构

Superpowers 以 Shell 为主要实现语言，整体设计围绕“技能”这一抽象单元展开。每个技能是一段自包含的指令集，描述在特定开发阶段智能体应执行的步骤与应遵循的约束。这些技能通过可组合的方式串联，形成从需求到实施的完整工作流。

项目的关键设计思路是“方法论优先于编码”：智能体的第一反应不是生成代码，而是启动交互式澄清流程。初始指令作为入口，负责在会话启动阶段把技能集注入智能体的上下文，从而保证方法论被实际执行，而不是停留在文档层面。

从 README 目录可以看出，项目还包含 Visual companion telemetry 等与可视化配套组件相关的部分，说明除核心技能框架外，还存在一些辅助观测或交互组件。整体架构强调跨平台适配——同一套方法论通过不同的安装与接入说明，落到十余种编码智能体环境中。

## 安装与使用

Superpowers 的安装方式随所使用的智能体平台而异。README 中为每类平台提供了独立的接入章节，包括 Claude Code、Codex CLI、Cursor、Gemini CLI、GitHub Copilot CLI 等。基本流程可概括为：

1. 根据所使用的编码智能体，找到 README 中对应的平台章节。
2. 按该章节的说明执行安装命令（通常为 Shell 脚本或配置写入操作）。
3. 确认初始指令已被加载，使智能体在启动时能够识别并使用这些技能。
4. 启动智能体并描述你要构建的内容，观察其是否进入需求澄清流程。

最小可用示例的形态通常是：在安装完成后，用户向智能体提出一个开发任务，智能体随即反问目标与约束，随后分块呈现规格并请求确认，确认后再给出实施计划。由于具体命令依赖平台，建议直接参照仓库中对应平台的安装小节执行。

## 适用场景

- **从零开始的功能开发**：在需求尚不清晰时，借助前置澄清流程明确目标，减少方向性返工。
- **团队协作中的 AI 辅助开发**：用统一的技能与流程约束不同成员使用的智能体行为，提升产出的一致性。
- **复杂任务的分阶段推进**：将大型开发任务拆分为规格、设计、计划、实施等阶段，逐段确认后再执行。
- **多平台智能体环境**：在团队内部混用多种编码智能体时，通过同一套方法论保持流程对齐。

## 项目亮点

与通常只提供提示词模板或单一技能的项目不同，Superpowers 强调的是“完整方法论”而非零散技巧。它的差异点主要体现在：把需求澄清和设计确认设为默认前置步骤，而非可选项；通过初始指令保证技能被自动加载，降低对用户自觉性的依赖；技能之间可组合，能按任务复杂度灵活编排；并且对主流编码智能体平台做了广泛适配，跨平台可用性较强。此外，项目以 MIT 许可证开源，便于二次修改与集成。
