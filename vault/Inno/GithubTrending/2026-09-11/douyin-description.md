今日 GitHub Trending TOP10 速览 👇

1️⃣ ayghri/i-have-adhd
给编程助手用的输出风格插件。核心思路是“先给答案，再说细节”：动作放最前、步骤编号、去掉客套话。适用于 Claude Code、Codex 等，不需要 ADHD 诊断也能用，本质是减少阅读负担。

2️⃣ bilawalsidhu/gods-eye-view
浏览器里的 3D 地球空间情报可视化工具。把公开的航班、船舶、卫星、地震、交通、公共摄像头等数据叠在同一颗地球上，还支持语音控制。面向 OSINT 和地理可视化爱好者。

3️⃣ obra/superpowers
一套给编码代理用的软件开发方法论。它不让你一上来就写代码，而是先澄清需求、确认规格、做计划，再子代理驱动执行。想把 AI 辅助开发流程规范化的团队可以看看。

4️⃣ alsk1992/CloddsBot
开源 AI 交易代理，基于 Claude 构建，覆盖 Polymarket、Kalshi、Binance、Hyperliquid、Solana DEX 及 5 条 EVM 链，宣称触达 1000 多个市场。支持自托管，做跨市场扫描与执行。注意：这不是投资建议。

5️⃣ Tencent/teamai-cli
腾讯开源的命令行工具，用来统一管理团队在 Claude Code、Codex、Cursor 等不同 AI 编码代理之间的技能、规则、MCP 配置和知识库。共享经验放 Git 仓库，解决配置分散、难同步的问题。

6️⃣ AlexsJones/llmfit
Rust 写的命令行工具，一条命令帮你判断本机硬件能跑哪些开源大模型。自动探测 GPU 显存、CPU、内存，再和内置的数百个模型目录比对，输出可运行列表和推荐配置，还带基准测试。

7️⃣ liquidslr/system-design-notes
《System Design Interview》第一、二卷的学习笔记，按章节整理。覆盖从零扩展到百万用户、限流器、一致性哈希、键值存储、唯一 ID、短链接、爬虫、通知系统、新闻 feed、聊天系统、搜索自动补全、YouTube 设计等。笔记仍在完善中。
