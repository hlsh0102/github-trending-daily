## 项目概述

AI Engineering from Scratch 是一份面向 AI 工程师的开源参考手册，旨在帮助学习者从零开始系统掌握 AI 工程领域的核心知识、工具与实践方法。该项目由 Agent Memory（排名第一的持久内存库）的创建者 Rohit G. 发起，目前包含 503 节课、20 个阶段，覆盖从基础理论到生产部署的完整学习路径。

项目解决的核心问题是：当前 AI 领域的学习资源多聚焦于模型训练或 API 调用，缺乏系统化的工程实践指南。许多开发者掌握了算法原理，却不知道如何构建可扩展、可维护的 AI 系统。本仓库填补了这一空白，为希望成为全能型 AI 工程师的学习者提供了一条清晰的进阶之路。

目标用户包括：希望在 AI 领域深耕的软件工程师、正在转型 AI 方向的技术人员、需要系统化知识体系的 AI 初学者，以及希望在实际项目中应用 AI 技术的研究者和开发者。

## 核心功能

- **结构化课程体系**：包含 503 节课程，按 20 个阶段有机组织，从基础概念到高级主题循序渐进，每节课都配有可运行的代码示例
- **动手实践导向**：强调"学、建、交付"三步法，每个知识点都有对应的编程练习和项目实践，确保学习者能够将理论转化为实际能力
- **生产级代码示例**：所有代码都遵循工程最佳实践，包括错误处理、日志记录、测试和文档编写，可以直接用于实际项目
- **交互式学习体验**：通过 GitHub 仓库的 issue 和讨论区，学习者可以提问、分享心得，形成活跃的学习社区
- **持续更新内容**：项目保持活跃维护，定期添加新章节和更新现有内容，紧跟 AI 领域的最新发展
- **开源且免费**：基于 MIT 许可证发布，任何人都可以自由使用、修改和分享，降低了学习门槛

## 技术架构

项目以 Python 为主要编程语言，充分利用了 Python 在 AI 生态中的主导地位和丰富的第三方库生态系统。整体架构遵循模块化设计原则，每个阶段独立且相互衔接，形成完整的知识图谱。

核心设计思路包括：
- **层次化学习路径**：20 个阶段被划分为基础、进阶和高级三个层次，每个阶段都是一个独立的学习模块，包含理论讲解、代码实现和项目实践三个环节
- **示例先行**：每个概念都先通过简单可运行的代码示例引入，再进行深入解释，降低理解门槛
- **工程化视角**：不仅仅讲解算法原理，更关注如何将模型集成到实际系统中，包括 API 设计、数据流程规划、性能优化和部署策略
- **版本控制集成**：所有课程内容和示例代码都托管在 GitHub 上，学习过程本身就是一次完整的开源协作实践

技术栈涵盖：Python、NumPy、Pandas、Scikit-learn、PyTorch、TensorFlow、FastAPI、Docker、MLflow 等现代 AI 工程工具链。

## 安装与使用

由于项目主要以学习参考为主，不需要传统意义上的"安装"。建议的使用方式如下：

1. **克隆仓库**
```bash
git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
```

2. **选择学习起点**
根据 README 中的阶段划分，定位自己的知识水平，从合适的阶段开始学习

3. **运行示例代码**
每个课程文件夹都包含独立的 Python 脚本，可以直接运行：
```bash
python phase-01/lesson-01/example.py
```

4. **完成练习**
每个阶段末尾都有对应的编程练习，建议动手完成后再进入下一阶段

5. **参与社区**
在 GitHub Discussions 中提问或分享学习心得，与其他学习者交流

- **高校课程辅助**：计算机科学或数据科学专业的师生可以将本项目作为课外学习资源，弥补传统课程中工程实践的不足
