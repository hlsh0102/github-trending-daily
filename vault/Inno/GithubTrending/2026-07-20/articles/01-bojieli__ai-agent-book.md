## 项目概述

《深入理解 AI Agent：设计原理与工程实践》是一本由李博杰撰写、面向 AI 开发者和研究者的开源书籍。该项目旨在系统性地讲解 AI Agent 的设计原理与工程实现方法，帮助读者从理论到实践全面掌握构建智能代理的核心技术。与传统 AI 书籍不同，该项目不仅提供完整的电子书正文，还配套了可运行的示例代码，使读者能够边学边练。目标用户包括希望深入理解 LLM 应用的 AI 工程师、对 Agent 架构感兴趣的学术研究者，以及希望将 AI Agent 落地到实际产品的技术人员。

## 核心功能

- **完整开源书籍**：提供全书 10 章的 Markdown 正文和编译好的 PDF 文件，覆盖从基础知识到高级实践的完整知识体系。
- **多语言支持**：除中文原版外，还提供英文、泰米尔语和越南语社区翻译版本，便于全球读者阅读。
- **配套示例代码**：每章均配有可直接运行的 Python 代码，帮助读者复现关键实验和工程示例。
- **可编译源文件**：提供 pandoc 和 xelatex 编译脚本，读者可自行构建定制版 PDF。
- **交互式学习路径**：书籍内容围绕核心公式“Agent = LLM + 上下文 + 工具”展开，逐步深入上下文工程、工具使用等关键主题。
- **社区协作机制**：鼓励读者通过 issue 和 PR 参与内容改进，支持社区翻译和代码贡献。

## 技术架构

该项目采用纯文本与编译工具链相结合的技术方案。书籍正文以 Markdown 格式存储于 `book/` 目录，使用 pandoc 和 xelatex 编译为 PDF，采用 ElegantBook 文档类确保排版质量。图表由 Python 脚本（`gen_*_figs.py`）自动生成，存于 `images/` 目录。配套代码复用书籍中的 Python 环境，用户只需安装常见依赖即可运行示例。多语言版本通过独立的目录结构管理，社区翻译与中文原版保持同步但内容更新节奏独立。项目遵循 Apache-2.0 开源协议，所有内容均可在 GitHub 上自由访问和分叉。

## 安装与使用

要使用本书的内容，您可以通过以下步骤获取和编译：

1. **下载或克隆仓库**：
   ```bash
   git clone https://github.com/bojieli/ai-agent-book.git
   cd ai-agent-book
   ```

2. **阅读电子书**：直接访问 `book/` 目录下的 PDF 文件，或阅读 Markdown 格式的正文（`introduction.md`、`chapter1.md` 等）。

3. **编译 PDF（可选）**：
   - 安装依赖：pandoc、xelatex、ElegantBook 文档类和相关字体。
   - 运行编译脚本：
     ```bash
     cd book && bash build_pdf.sh
     ```
   - 生成的 PDF 位于同一目录。

4. **运行示例代码**：
   - 每章对应的 Python 代码存放在 `code/` 目录（根据 README 推断）。
   - 安装 Python 3.8+ 和必要的依赖（如 `openai`、`langchain` 等）。
   - 直接运行对应文件的示例脚本。

最小可用示例（以第 1 章为例）：
```python
# 假设代码位于 code/chapter1/example.py
python code/chapter1/example.py
```
