## 项目概述

Wigolo 是一个面向 AI 编程代理的本地优先网络智能工具集。它通过 MCP（Model Context Protocol）协议，为 AI 代理提供搜索、抓取、爬取和研究等网络能力，且完全无需 API 密钥、不依赖云端服务、每次查询零成本。项目目前处于公开测试阶段，旨在让 AI 代理能够像人类一样高效地获取和理解网络信息，而无需为每次查询付费或受限于第三方 API 的配额限制。

项目主要面向使用 Claude Code、Cursor、Codex、Gemini CLI、VS Code、Windsurf、Zed 等 AI 编程工具的开发者，以及基于 LangChain、CrewAI、LlamaIndex、Vercel AI SDK、n8n 等框架构建 AI 应用的用户。

## 核心功能

- **网页搜索**：为 AI 代理提供强大的搜索引擎接口，支持关键词搜索和语义搜索，返回结构化结果
- **网页抓取与爬取**：能够完整抓取网页内容，包括动态渲染的页面，支持深度爬取
- **内容提取**：从抓取的页面中智能提取核心内容，去除广告和无关元素
- **缓存机制**：本地缓存已获取的页面内容，避免重复请求，提升响应速度
- **相似内容查找**：基于语义分析，查找与当前内容相似的网页资源
- **自主研究循环**：支持 AI 代理自动执行多轮“搜索-抓取-分析”的循环，完成复杂的研究任务

## 技术架构

Wigolo 采用 MCP 协议作为核心通信机制，这意味着它可以无缝集成到任何支持 MCP 的 AI 代理系统中。项目以 TypeScript 编写，作为 MCP 服务器运行在 AI 代理的本地环境中，不依赖外部云服务或第三方 API。

技术栈方面，Wigolo 充分利用了 Node.js 的异步 I/O 能力和网络请求处理能力。其核心设计理念是“本地优先”——所有数据抓取、处理和缓存都在用户本地完成，确保数据隐私和低延迟。传输层使用标准 HTTP/HTTPS 协议，内容解析模块支持 HTML、JavaScript 渲染页面等多种格式。

架构特点包括模块化工具设计，每个网络操作（搜索、抓取、爬取等）都是独立的工具模块，便于扩展和维护。缓存层使用本地文件系统或内存存储，支持可配置的过期策略。

## 安装与使用

**安装**

通过 npm 全局安装 wigolo：

```bash
npm install -g wigolo
```

**快速启动**

启动 wigolo MCP 服务器：

```bash
wigolo start
```

**集成到 AI 代理**

在 Claude Code 中配置 MCP 服务器（`claude.json`）：

```json
{
  "mcpServers": {
    "wigolo": {
      "command": "wigolo",
      "args": ["start"]
    }
  }
}
```

**最小可用示例**

启动后，AI 代理可以直接调用工具：

```
/use wigolo-search "最新的 TypeScript 5.0 特性"
```

代理将返回搜索结果，包括标题、链接和摘要。继续对话即可利用爬取、研究等更多功能。

## 适用场景

- **AI 编程辅助**：开发者在编码过程中需要查找文档、示例代码或技术方案时，AI 代理可自动搜索并整合网络信息
- **自动化研究**：构建需要持续收集和分析网络信息的 AI 应用，如市场调研、竞品分析、技术趋势追踪
- **数据采集与处理**：需要从多个网页提取结构化数据并进行分析的场景，如舆情监控、价格比较
- **本地知识库建设**：通过自主研究循环，持续抓取和缓存特定领域的网页内容，构建本地化的知识库

## 项目亮点

相比同类项目，Wigolo 的差异化优势在于：

1. **零成本**：无需任何 API 密钥，无需绑定信用卡，每次查询完全免费，消除了使用门槛
2. **完全本地化**：所有操作在用户本地执行，数据不经过第三方服务器，保障隐私安全
3. **MCP 原生支持**：作为 MCP 服务器运行，可无缝集成到主流 AI 编程工具和框架中，无需额外适配
4. **开箱即用**：安装后只需一条命令即可启动，无需配置复杂的环境变量或 API 端点
5. **功能全面**：搜索、抓取、爬取、提取、缓存、研究循环等能力一应俱全，满足各种网络智能需求
6. **开源透明**：项目代码完全开源，用户可以审计和自定义所有功能
