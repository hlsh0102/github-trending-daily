## 项目概述

code-review-graph 是一个“本地优先”的代码智能图工具，专为 MCP（Model Context Protocol）和命令行环境设计。它能够为你的代码库构建一个持久化的语义映射，让 AI 辅助编程工具仅读取真正需要关注的部分，从而大幅减少 Token 消耗。无论是在代码审查还是大型仓库的工作流程中，该项目都经过了基准测试，能显著降低上下文开销——实测中，它能将审查单次变更所需的 Token 减少约 90%（从 57k 降至 6k），将大型仓库工作流（如 TensorFlow 核心贡献）的 Token 使用量降低 76%（从 244k 降至 60k）。

该项目主要面向使用 AI 编程助手（如 Cursor、Claude、Copilot 等）的开发者，特别是那些在大型代码库中工作、经常遭遇 Token 费用高企或上下文窗口溢出问题的人。通过建立一个轻量级、可复用的代码语义图，code-review-graph 让 AI 工具能够精准地定位与分析相关代码，而不是盲目地消化整个文件。

## 核心功能

- **语义代码索引**：自动解析代码库的结构（函数、类、依赖关系等），构建一个智能、可查询的图，而不仅仅是简单的文件列表。
- **上下文优化**：根据指定的变更或任务（如一个 Git diff），只提取图中最相关的节点（代码片段），而不是将整个文件或目录塞入 AI 的上下文窗口中。这直接翻译为更少的 Token 消耗和更低的使用成本。
- **MCP 服务集成**：提供 MCP 兼容的服务器，可无缝接入支持 MCP 的 AI 助手。这意味着你可以将代码评审图作为一个额外的“工具”直接供 AI 调用，无需切换环境。
- **本地优先与隐私保护**：所有代码索引和分析都在你的本地机器上进行，无需将代码发送到任何外部服务器，确保了代码的隐私与安全。
- **CLI 工具**：提供直观的命令行界面，用于快速生成代码库图、启动 MCP 服务器或执行单次上下文优化任务。例如，`code-review-graph build` 和 `code-review-ggraph review` 等命令。
- **Hugging Face 模型支持**：利用 Hugging Face 的模型（如 `BAAI/bge-small-en-v1.5`）进行语义嵌入，以精确理解代码片段的含义，并将相似或相关的代码片段关联起来。

## 技术架构

code-review-graph 采用 Python 3.10+ 开发，其核心架构围绕“索引-图-查询”模型构建。

- **索引层**：通过静态分析（AST）提取代码库的符号（函数、类、变量）、它们的定义位置、引用关系以及调用图。这一步不涉及 AI 模型，速度极快。
- **图存储**：利用 `networkx` 库在本地内存中构建一个有向图。图的节点代表代码单元（如一个函数或一个文件），边代表依赖或调用关系。这个图可以被持久化到磁盘，以实现跨会话复用。
- **语义嵌入层**：对于每个代码节点，使用 Hugging Face 的句子变换器模型生成嵌入向量。这使得工具能够超越精确匹配，进行语义相似度搜索。例如，如果修改了一个数据库连接函数，它能够找到所有逻辑上相关的、使用了相似模式的代码段。
- **MCP 服务器**：该项目实现了 MCP 协议，允许它作为一个外部工具暴露给 AI 客户端。AI 可以发送“analyze this diff”之类的命令，code-review-graph 会返回一个高度浓缩的相关代码上下文，供 AI 进一步思考。
- **CLI 接口**：通过 `click` 库构建，提供如 `build`（构建图）、`review`（分析 diff）、`serve`（启动 MCP 服务）等子命令，使集成和自动化变得简单。

## 安装与使用

**安装**：确保你的 Python 版本 >= 3.10，然后通过 pip 安装：

```bash
pip install code-review-graph
```

**最小可用示例**：假设你在一个 Git 仓库中工作。

1.  **构建代码图**：在仓库根目录运行以下命令来索引你的代码库。
    ```bash
    code-review-graph build
    ```
    这会生成一个 `.code-review-graph` 目录，包含序列化后的图数据。

2.  **优化代码审查**：当你想审查当前未推送的变更时，运行：
    ```bash
    code-review-graph review
    ```
    该命令会分析 `git diff`，并输出一个 Markdown 格式的、只包含相关代码上下文的摘要。你可以直接将其复制粘贴到 AI 聊天窗口或 Co-pilot 中。

3.  **集成到 MCP 客户端**：启动 MCP 服务器，你的 AI 助手（如 Claude Desktop）就能自动发现并使用它。
    ```bash
    code-review-graph serve
    ```

## 适用场景

- **大型仓库的代码审查**：在处理含有数千个文件的仓库（如 TensorFlow、PyTorch）时，传统的代码审查工具或 AI 模型不得不处理庞大的上下文。code-review-graph 可以精确定位与每次提交相关的代码，将上下文压缩至原来的 10%-25%，极大地节省费用并提高准确性。
- **AI 驱动的代码补全与生成**：当你的 IDE 插件（如 Copilot）需要理解项目结构以便生成更合适的代码时，code-review-graph 生成的本地图可以作为“第二大脑”，让 AI 知道“这个类在哪里定义”、“这个函数有哪些调用者”等信息。
- **重构与依赖分析**：在重构一个核心模块前，使用 `code-review-graph build` 生成依赖图，直观地看到哪些文件或模块会受到影响，从而帮助开发者制定更周密的计划。
- **持续集成/持续交付（CI/CD）工作流**：在 CI 中使用 `code-review-graph review` 命令，自动生成带有精简上下文的代码审查报告，提交给 AI 进行初步审查，再交由人工审核，提升审查效率。

## 项目亮点

- **极高的 Token 效率**：与直接将文件内容喂给 AI 模型相比，code-review-graph 通过语义图显著减少冗余上下文。其基准测试结果（90% 和 76% 的降低）是目前同类工具中最突出的。
- **本地优先，保护隐私**：所有处理都在本地完成，代码不会离开你的机器，解决了企业和开发者对代码安全的顾虑。这与云端的代码分析服务形成了鲜明对比。
- **MCP 原生支持**：作为最早一批原生支持 MCP 协议的工具之一，它可以无缝集成到新一代的 AI 编程生态中，无需繁琐的 API 适配。
- **与工作流深度结合**：不只是命令行工具，它能与 Git、CI/CD 管道轻松集成，作为常规开发流程的一部分运行，无需改变用户现有的工作习惯。
- **活跃的开源社区**：项目在 GitHub 上线后迅速获得超过 2 万星标，社区关注度高，持续迭代和维护有保障。
