## 项目概述

Voicebox 是一款开源的 AI 语音工作室，旨在为用户提供完整的语音输入输出（I/O）技术栈，并且全部运行在本地机器上。该项目解决了语音领域长期存在的几个核心问题：如何安全地克隆任意人的声音、如何在本地高效生成真实自然的语音、如何将语音识别（听写）无缝集成到任何应用程序中，以及如何让用户在与 AI 代理对话时使用自己拥有（而非平台授权）的声音。

目标用户覆盖广泛，包括内容创作者（播客、配音、视频制作）、开发者（需要语音功能的 app 或集成）、隐私敏感用户（希望本地处理语音数据）、以及追求高效输入方式的办公人员。简单来说，Voicebox 想做语音领域的“个人工作站”，把原来分散在多个商业 API 或专有软件中的能力集中到一个开源、离线可用的工具中。

## 核心功能

- **声音克隆**：只需提供一段目标声音的样本（通常几十秒到几分钟），Voicebox 即可提取声音特征，生成克隆模型，之后可以使用该模型合成任意文本的语音。克隆结果支持导出和复用。
- **文本转语音（TTS）**：内置多种预训练语音模型，支持从文本生成自然流畅的语音。支持克隆声音后的自定义 TTS，也支持选用预设的通用音色。
- **语音识别（ASR/听写）**：将麦克风输入或音频文件的语音实时转换为文本。支持连续听写，准确率与主流云端服务相当。
- **应用内听写集成**：系统级或应用级别的听写功能，允许用户在任何输入框中通过语音输入文本，实现“嘴动打字”。
- **AI 代理语音交互**：支持与本地或远端的大型语言模型（LLM）代理进行实时语音对话，代理的回复将使用用户指定或克隆的声音朗读出来。
- **完全本地运行**：所有模型推理都在用户的 CPU 或 GPU 上执行，无需网络连接，数据不出本地，保障隐私安全。

## 技术架构

Voicebox 基于 TypeScript 开发，主要技术栈包括：
- **前端框架**：使用 Electron + React 构建跨平台桌面应用，提供美观、直观的图形界面。
- **AI 推理引擎**：核心语音模型基于 Transformer 架构，采用 ONNX Runtime 进行跨平台推理优化，支持 GPU（CUDA）加速。声音克隆使用了类似 SV2TTS 的 speaker encoder + vocoder 架构，轻量化且效果良好。
- **音频处理管道**：WebRTC 用于低延迟麦克风输入，FFmpeg 用于音频格式转换和处理，WebAudio API 用于实时播放和效果处理。
- **模块化设计**：TTS、ASR、声音克隆等功能被封装为独立模块，通过事件驱动机制通信。用户可自行替换或升级单个模块的模型文件。
- **本地优先架构**：模型文件通过应用初次启动时自动下载（可离线缓存），数据存储使用 SQLite 管理用户生成的克隆模型、自定义音色和听写历史。

## 安装与使用

**安装步骤：**

1. 访问 [GitHub Releases 页面](https://github.com/jamiepine/voicebox/releases) 下载最新版本的安装包。提供 Windows (.exe)、macOS (.dmg/.app) 和 Linux (.AppImage) 版本。
2. 双击安装包完成安装。macOS 用户可能需要允许“来自未知开发者”的软件。
3. 首次启动时，应用会自动下载约 1-2GB 的基础模型文件（进度条可见），之后即可离线使用。

**最小可用示例：**

- **克隆声音**：进入“Clone”标签页，上传一段干净的音频样本（建议 30 秒以上），点击开始克隆。几分钟后即可在“TTS”标签页中选择该新声音进行语音合成。
- **听写测试**：打开“Dictate”标签页，点击麦克风按钮开始录音，语音将实时转为文字显示在文本框。可在任意文本输入框（如记事本、浏览器搜索栏）中右键选择“Voicebox 听写”来调用。
- **AI 代理对话**：在“Agent”标签页配置 LLM 端点和 API 密钥（支持 OpenAI、Ollama、Llama.cpp 等）。选择语音作为代理的输出，即可进行语音对话。

## 适用场景

1. **内容创作者**：独立播客主或视频创作者需要为自己的内容配音，但不想租用昂贵的录音棚或购买商业 TTS 许可。可以使用 Voicebox 克隆自己的声音（或创建独特音色），快速生成旁白、对话。
2. **无障碍辅助**：视力障碍者或行动不便的用户，可以完全通过语音操作电脑，听写输入文字，并用语音朗读屏幕内容。
3. **语言学习**：学习者可以克隆标准发音者的声音，反复聆听单词和句子的正确读音，或者用自己的声音与 AI 代理进行口语对话练习。
4. **专业会议记录**：在会议中启用听写功能，自动生成会议记录文字稿，无需手动打字。结束后可将会议重点用克隆的语音合成摘要，分发给与会人员。

## 项目亮点

- **开源 vs 封闭生态**：与 ElevenLabs、OpenAI TTS 等商业服务形成鲜明对比。Voicebox 完全开源（MIT 协议），用户拥有克隆声音和模型的所有权，不会被平台锁定，也没有按字符付费的限制。
- **本地优先**：所有处理在本地完成，无网络延迟和数据泄露风险。对于企业内部、医疗、法律等对数据安全有严格要求的领域至关重要。
- **全栈一体化**：大多数开源语音项目专注于单一功能（如 TTS、ASR），Voicebox 则提供了“克隆→合成→听写→对话”的完整工作流，且界面友好，非开发者也能直接使用。
- **活跃社区与模型更新**：项目有 43,000+ 星标，社区提交的模型质量不断提高。不同于传统开源项目的“一次性发布”，Voicebox 允许用户通过市场下载社区共享的声音、提示词和配置，形成生态。
