## 项目概述

Hallmark 是一个专为 Claude Code、Cursor 和 Codex 等 AI 编程工具设计的前端设计技能。它解决了一个核心问题：AI 生成的界面往往带有千篇一律的“机器感”，缺乏人类设计师的独特性和审美。Hallmark 的目标用户是那些希望利用 AI 快速生成界面，但又要求结果看起来是“由人类精心设计”的前端开发者、设计师和产品团队。

该项目通过一套严格的反模式检测机制和丰富的主题系统，确保生成的 UI 不落俗套，每份设计都拥有独特的指纹，而非简单的模板替换。

## 核心功能

- **四动词系统**：提供四种核心操作，覆盖从新建到审计、重构和学习的设计全流程。
- **57 道 Slop 检测门**：在代码生成前执行严苛的反模式检测，自动识别并拒绝 AI 常见的“偷懒”设计。
- **二十套主题**：内置 20 种风格迥异的主题，确保不同设计目标之间的视觉差异化，而非仅仅换色。
- **自检机制**：在输出前进行自我批判，进一步减少 AI 生成痕迹。
- **设计基因提取**：通过 `hallmark study` 命令分析目标设计，提取其宏观结构、字体搭配和色彩锚点，并生成可复用的 `design.md` 文件。
- **重构能力**：支持保留文案、信息架构和品牌元素的前提下，完全重构界面结构。

## 技术架构

Hallmark 是一个基于 CSS 的设计系统，其核心是通过一套规则引擎和评分系统来对抗 AI 生成界面的常见问题。

- **核心技术栈**：纯 CSS 实现，无需额外运行时依赖，可无缝集成到 Claude Code、Cursor 和 Codex 等工具的 prompt 流程中。
- **反模式引擎**：内置 57 个“slop-test 门”，每个门针对一种特定的 AI 生成模式（例如：过度使用卡片布局、对称排列、固定宽度等）。
- **宏观结构选择器**：根据用户输入的 brief，自动匹配最合适的页面宏观结构（例如：信息型、营销型、工具型），而非总是使用相同的布局骨架。
- **主题系统**：20 个独立主题互不耦合，每个主题拥有自己的颜色、字体、间距和阴影系统，设计上刻意避免 AI 训练的常见分布。
- **自省机制**：在最终输出前，系统会对自身生成的代码进行一轮语法和模式层面的评估，拒绝淘汰项。

## 安装与使用

Hallmark 的使用方式非常直接，主要作为 CLI 工具集成到 AI 编程助手的 prompt 中。

**安装步骤：**

1. 将 Hallmark 添加到你的项目依赖中（例如作为 npm devDependency）：
   ```bash
   npm install hallmark --save-dev
   ```

2. 或者在 Claude Code、Cursor 或 Codex 的配置文件中引入该 skill。

**最小可用示例：**

在 AI 编程助手的对话中，输入以下指令即可：

1. **新建界面**：只需要给出 brief，Hallmark 会自动选择结构和主题。
2. **审计已有代码**：
   ```
   hallmark audit ./src/components/Header.jsx
   ```
3. **研究现有设计**：
   ```
   hallmark study ./screenshot.png
   ```
4. **重构**：
   ```
   hallmark redesign ./src/pages/Home.jsx
   ```

所有操作均可在终端中直接执行，无需启动额外服务。

## 适用场景

- **快速原型设计**：产品经理或设计师需要快速制作初稿，但希望看起来不像 ChatGPT 生成的模板。
- **前端组件库审计**：团队希望找出项目中老旧的、带有 AI 生成痕迹的 UI 组件，进行统一重构。
- **设计系统规范**：设计师通过 `hallmark study` 提取竞品或灵感来源的设计基因，形成可复用的设计规范文档。
- **AI 辅助开发**：开发者使用 Claude Code 等工具生成 UI 代码时，通过 Hallmark 确保输出的质量和独特性。

## 项目亮点

- **拒绝模板化**：与同类项目（如通用 UI 库或模板生成器）不同，Hallmark 的核心目标是让两个不同 brief 生成的页面像两个完全独立的网站，而非同一套模板换色。
- **主动反模式**：许多工具只负责生成，不负责质检。Hallmark 内置了基于大量 AI 生成样本训练的“臭虫”识别系统，在生成阶段就过滤掉常见 AI 痕迹。
- **设计 DNA 提取**：`hallmark study` 功能不仅能够分析视觉风格，还能生成标准化的描述文档，使人类设计师和 AI 工具之间的交接变得平滑。
- **轻量无侵入**：作为 CSS 技能，它不会引入复杂的框架或构建流程，可以零成本地嵌入到已有的 AI 工作流中。
- **开源与社区驱动**：项目采用 MIT 协议开放，用户可以自由定制和扩展主题或检测规则。
