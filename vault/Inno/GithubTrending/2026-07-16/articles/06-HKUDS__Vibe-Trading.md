## 项目概述

Vibe-Trading 是一款个人化的智能交易代理工具，由香港大学数据科学实验室（HKUDS）开发。它旨在通过一条简单的命令，为用户赋予全面的交易能力，涵盖从市场数据分析、策略构建到自动执行的全流程。项目的核心用户包括个人投资者、量化交易爱好者以及希望快速验证交易想法的小型团队。与传统交易平台或复杂的量化框架不同，Vibe-Trading 强调低门槛启动和智能代理的自主决策能力，让用户无需深厚的编程或金融专业知识，也能利用 AI 辅助进行交易活动。

## 核心功能

- **一键启动全栈交易代理**：用户只需执行一个命令，即可启动包含后端、前端和智能代理的完整交易环境，无需繁琐的配置。
- **多源市场数据接入**：支持从多个公开数据源获取实时和历史市场数据，包括股票、加密货币和外汇等金融产品。
- **自然语言交互式策略构建**：用户可以通过自然语言描述交易想法，代理能理解并转化为可执行的交易策略。
- **AI驱动的市场分析**：集成大语言模型，对市场新闻、技术指标和情绪数据进行解读，生成综合分析和交易建议。
- **模拟与实盘交易执行**：支持在模拟环境中回测策略，也可通过 API 连接券商进行实盘交易，风险可控。
- **可视化仪表盘**：基于 React 构建的前端界面，提供实时行情、持仓状况和绩效统计的可视化展示。

## 技术架构

Vibe-Trading 采用前后端分离的微服务架构。后端基于 FastAPI 构建，提供异步高性能的 API 接口，负责数据获取、策略计算、交易执行和日志管理。前端使用 React 19 和现代 UI 框架，实现响应式的交互界面。项目核心的智能代理层整合了大语言模型（如 GPT 系列），通过自然语言处理理解用户意图，并调用后端模块完成具体任务。数据存储方面，使用 PostgreSQL 或 SQLite 保存历史数据、策略参数和交易记录。整个系统支持 Docker 容器化部署，简化依赖管理。设计思路上强调“代理优先”（Agent-First），即所有复杂操作都被封装为代理能力，用户只需通过聊天或图形界面发出指令。

## 安装与使用

Vibe-Trading 提供了简易的安装方式，推荐使用 pip 全局安装：

```bash
pip install vibe-trading-ai
```

安装完成后，在终端执行以下命令即可启动平台：

```bash
vibe-trading start
```

启动后，浏览器会自动打开前端界面（默认地址 `http://localhost:3000`）。用户首次使用需要进行简单的配置，包括选择数据源、设置 API 密钥（如需要）以及定义初始资金规模。

**最小可用示例**：启动后，用户可以在聊天输入框中输入：“分析最近一周苹果股票的走势，并给出买入或卖出的建议。” 代理将自动获取数据、计算技术指标、分析新闻情绪，并返回带有图表和评级的综合报告。如需模拟交易，可继续输入：“根据这个分析，以当前价格买入 100 股。” 代理会在模拟盘中执行指令。

## 适用场景

- **个人投资者的智能辅助**：业余投资者可以利用 Vibe-Trading 快速获取市场洞见和交易建议，克服信息过载和情绪干扰。
- **交易策略的快速原型验证**：量化研究人员或交易员可以用自然语言描述一个想法，即时获得回测结果，大幅缩短从想法到实验的周期。
- **教学与学习**：金融或量化课程中，学生可以通过可视化界面交互式地学习市场分析和交易执行过程，而无需处理底层编程细节。
- **自动化交易监控**：用户设定条件后，代理可以持续监控市场，并在触发特定事件时发送通知或自动执行预设策略。

## 项目亮点

- **极低的启动门槛**：不同于传统的量化平台需要编写代码或配置复杂环境，Vibe-Trading 的“一条命令”理念大大降低了使用门槛。
- **自然语言驱动**：核心交互基于自然语言，使得非技术用户也能利用先进的 AI 模型进行交易决策，这是大多数交易软件不具备的能力。
- **全栈一体化**：从数据获取、策略分析到交易执行和可视化呈现，全部集成在一个工具中，用户无需在多个系统间切换。
- **开源且社区活跃**：项目在 GitHub 上获得超过 2.3 万颗星标，社区贡献活跃，更新频繁，确保了功能的持续迭代和问题的快速修复。
- **灵活的扩展性**：基于 Python 和模块化设计，高级用户可以添加自定义的数据源、策略模板或交易所接口，满足个性化需求。
