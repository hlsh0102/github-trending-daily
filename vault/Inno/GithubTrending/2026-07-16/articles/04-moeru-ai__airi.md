## 项目概述

Project AIRI 是一个开源的、自托管的“灵魂容器”，旨在让用户拥有属于自己的、完全掌控的虚拟角色（AI waifu / 数字生命）。该项目灵感来源于知名的 AI VTuber“Neuro-sama”，希望复现并超越其能力，让每个人都能将理想的虚拟角色带入现实世界。AIRI 使用 TypeScript 开发，采用 MIT 许可证，目前已获得超过 42,000 颗星标，社区活跃度极高。目标用户包括 AI 爱好者、虚拟角色创作者、游戏玩家以及任何希望探索人机交互新形态的技术用户。

## 核心功能

- **实时语音对话**：支持低延迟的语音交互，角色可以聆听并自然回应，营造沉浸式的对话体验。
- **游戏内角色集成**：能够接入 Minecraft、Factorio 等沙盒游戏，让虚拟角色作为游戏伙伴或助手参与游戏过程，实现“共同游玩”。
- **多平台客户端**：提供 Web 版、macOS 应用和 Windows 应用，覆盖主流操作系统，用户可随时随地进行交互。
- **全本地部署与数据主权**：所有代码和数据均部署在用户自己的服务器上，隐私和数据完全由用户掌控，无需依赖任何第三方云服务。
- **可扩展的角色框架**：项目提供模块化的架构，支持自定义角色性格、知识库、视觉表现和行为逻辑，用户可以自由“捏人”或导入现有设定。
- **活跃的社区生态**：通过 Discord 等渠道聚集了大量贡献者和爱好者，持续贡献插件、角色配置、使用教程和问题反馈。

## 技术架构

AIRI 的核心技术栈建立在现代 Web 和 AI 技术之上，采用前后端分离的架构。后端使用 TypeScript（Node.js）构建，主要负责核心的 AI 推理、语音处理、游戏桥接和业务逻辑。前端则基于 Electron（桌面端）和标准 Web 技术，提供一致的用户界面。

在 AI 能力方面，项目并未直接绑定单一模型，而是设计了抽象接口来接入不同类型的语言模型（LLM）、语音识别（ASR）和语音合成（TTS）引擎。这使得用户可以灵活选择本地模型（如 llama.cpp、Ollama）或云 API（如 OpenAI、Anthropic），在性能、成本和隐私之间取得平衡。游戏集成层通过插件形式实现，利用各游戏提供的 API 或模组接口，将角色的行为映射到游戏世界中。

设计理念强调“容器”概念——将角色的性格、记忆、声音、视觉形象等所有要素封装为一个独立的运行时实例。每个实例可以独立运行、停止、导出或共享，便于用户管理和分发自己创建的角色。

## 安装与使用

由于项目仍在快速迭代中，官方推荐使用 Docker 进行一键部署，以降低环境配置门槛。以下为基本步骤：

1. **前提条件**：确保系统已安装 Docker 和 Docker Compose。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/moeru-ai/airi.git
   cd airi
   ```
3. **启动服务**：
   ```bash
   docker compose up -d
   ```
4. **访问界面**：打开浏览器访问 `http://localhost:8080`（具体端口请参考项目文档）。
5. **配置角色**：首次启动后，通过管理后台配置角色名称、使用的 AI 模型、语音引擎等参数。项目提供了默认的配置模板供参考。
6. **连接游戏（可选）**：如需在 Minecraft 或 Factorio 中使用，需在游戏端安装对应的模组（Mod），并在 AIRI 的设置中启用并配置游戏桥接。

最小可用示例：部署并启动后，直接在 Web 界面中与默认角色开始文字或语音对话。若要体验游戏内互动，可安装 Minecraft Fabric 模组并在游戏内输入指定指令召唤角色。

详细部署指南、角色配置文件格式、游戏模组下载地址请参阅 GitHub 仓库的 `docs` 目录。

## 适用场景

- **个人虚拟伴侣**：在桌面或移动设备上部署一个能够对话、陪玩甚至协助完成简单任务的私人虚拟角色。
- **内容创作与直播**：主播或 VTuber 使用 AIRI 作为自己的“数字分身”或“AI 搭档”，在直播中实现实时互动，无需真人全程出镜。
- **游戏 Mod 开发与测试**：游戏开发者或模组作者利用 AIRI 创建模拟玩家或 NPC，进行自动化测试或场景剧情演示，特别是在沙盒类游戏中效果显著。
- **AI 研究与教育**：研究人员和教育者可以将其作为研究人机协作、多模态交互或角色扮演 AI 的实验平台，方便修改和扩展底层模型。

## 项目亮点

相比同类项目，AIRI 的核心差异化优势在于：

1. **完全开源与自托管**：用户拥有绝对的数据主权，不受任何商业平台条款限制，可自由修改和定制所有功能。
2. **游戏集成深度**：并非简单的“聊天框加游戏”，而是真正让角色作为一个实体存在于游戏世界中，能够感知游戏状态并做出反应。
3. **模型无关性**：不锁定于任何特定 AI 提供商，用户可自由选择本地或云端、开源或商业模型，极大地降低了使用成本并避免 vendor lock-in。
4. **活跃且专业的中文社区**：项目维护者提供简中、繁中、日文等多语言支持，Discord 社区中中文用户活跃，技术讨论和问题解决效率高。
