## 项目概述

Cursor 官方插件仓库（cursor/plugins）是 Cursor 团队为开发者工具、框架和 SaaS 产品维护的一个官方插件集。该仓库不仅定义了插件规范（`.cursor-plugin/plugin.json` 清单文件），还包含了多个由 Cursor 团队亲自开发、维护的插件。每个插件以独立目录形式存在于仓库根目录下，通过各自的插件清单文件进行声明和配置。

该项目解决了两个核心问题：一是为开发者提供一套标准化、可复用的插件扩展机制，二是为常见开发工作流提供开箱即用的官方解决方案。目标用户是使用 Cursor 编辑器的开发者，特别是希望将 AI 辅助开发流程与现有工具链深度集成的团队和个人。

## 核心功能

- **插件规范定义**：通过 `.cursor-plugin/plugin.json` 清单文件定义插件元数据、入口点和配置项，为第三方插件开发提供统一标准。
- **教学辅助（Teaching）**：提供技能映射、练习计划和复盘机制，帮助用户系统化学习新技术栈。
- **持续学习（Continual Learning）**：通过增量转录驱动的记忆更新机制，自动将高信号要点写入 `AGENTS.md`，实现跨会话的知识积累。
- **团队协作套件（Cursor Team Kit）**：覆盖 CI 流程、代码审查、发布流程、本地自动化与验证等团队内部开发环节。
- **深度审查（Thermos）**：内置"热核级"分支审查功能，包括安全/正确性深度审计、严格的代码质量评分标准、并行子代理编排以及可选的合并前 PR 流程。
- **插件脚手架（Create Plugin）**：提供快速创建和验证新插件的脚手架工具。

## 技术架构

该项目基于 TypeScript 开发，采用模块化设计思路。每个插件是独立目录，包含自己的清单文件、实现代码和资源配置。清单文件（`plugin.json`）遵循统一规范，定义插件的名称、作者、类别、描述和入口等信息。

架构上主要有以下特点：

1. **清单驱动**：所有插件通过 `plugin.json` 声明自身能力，Curson 编辑器读取清单后按需加载，实现松耦合。
2. **独立版本管理**：每个插件目录独立版本化，可单独发布和更新，降低维护复杂性。
3. **多类别支持**：覆盖工具类、开发者工具类等不同类别，体现通用扩展框架的设计目标。
4. **组合式编排**：部分插件（如 Thermos）支持并行子代理编排，体现 Cursor 在多代理协作方面的架构能力。

## 安装与使用

### 安装步骤

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/cursor/plugins.git
   ```

2. 在 Cursor 编辑器中，将所需的插件目录复制到你的项目或全局配置目录中。

3. 根据需要修改 `plugin.json` 中的配置项（如 `AGENTS.md` 路径、CI 触发器规则等）。

### 最小使用示例

以 `thermos` 插件为例，在项目根目录添加以下配置：

```json
{
  "name": "thermos",
  "version": "0.1.0",
  "description": "Deep branch review and PR flow",
  "hooks": {
    "branch:review": {
      "type": "command",
      "command": "thermos review --security --correctness"
    }
  }
}
```

然后在 Cursor 中触发分支审查命令即可。对于 `continual-learning` 插件，只需将插件目录放置到项目中，它便会自动监听高信号代码变更，并更新 `AGENTS.md`。

## 适用场景

1. **个人学习与技能提升**：`teaching` 插件可为开发者制定学习路径，`ralph-loop` 则适用于探索性编程场景。
2. **团队协作流程标准化**：`cursor-team-kit` 覆盖从 CI 到代码审查的完整开发闭环，适合规模型团队采用。
3. **高风险代码变更审查**：`thermos` 插件适合金融、安全等领域，在上线前进行深度审计。
4. **知识管理**：`continual-learning` 适用于长期维护的项目，帮助 AI 助手保持对代码库的动态认知。
