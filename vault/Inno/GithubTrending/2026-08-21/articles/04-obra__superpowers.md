## 项目概述

Superpowers 是一套面向编码代理（coding agent）的完整软件开发方法论，它构建在一组可组合的技能（skills）和初始指令之上，确保你的代理在启动时就能遵循这套方法论工作。该项目解决的核心问题是：当前 AI 编码助手往往在收到指令后立刻跳入代码编写，缺乏需求澄清、方案确认、计划制定等关键环节，导致生成结果与用户真实意图偏差较大、返工频繁。Superpowers 通过结构化的流程引导，让编码代理从"快速写代码的工具"进化为"具备完整软件开发流程意识的协作者"。目标用户是重度使用 Claude Code、Cursor、Codex、Gemini CLI 等 AI 编程工具的专业开发者与技术团队，尤其是那些希望将 AI 编码从"玩具级"提升到"生产级"的用户。

## 核心功能

- **需求澄清机制**：代理在动笔写代码前，会主动询问并梳理用户真正想要达成的目标，避免"答非所问"
- **分块规格展示**：将提炼出的规格说明（spec）以短小、易读的块状形式呈现，用户无需翻阅长文档即可理解并确认
- **实现计划生成**：在用户确认设计后，代理会自动生成分步骤的实现计划，确保开发过程有序推进
- **多平台兼容**：原生支持 Claude Code、Cursor、Codex（App/CLI）、Gemini CLI、GitHub Copilot CLI、OpenCode、Devin CLI、Factory Droid、Kimi Code 等十余种主流编码代理环境
- **可组合技能体系**：以技能（skills）为单位封装各类开发能力，可按需组合，灵活性高
- **持续更新与社区驱动**：项目活跃迭代，提供社区讨论渠道，用户可贡献新技能或改进方法论

## 技术架构

Superpowers 的架构设计围绕"流程控制层 + 技能层"展开。最上层是初始指令（initial instructions），它们在代理启动时即被加载，定义了一套开发流程的"元规则"：先问目标、再出规格、后定计划、最后写码。这一层确保代理不会跳过关键环节。第二层是一组可组合的技能（composable skills），每个技能封装了特定开发任务所需的提示词、工作流和最佳实践，例如代码审查、测试驱动开发、重构、文档生成等。技能之间通过标准化的输入/输出接口进行衔接，用户可以根据项目需要自由选配。底层则是对接各编码代理平台的适配层，通过环境变量或配置文件将同一套方法论桥接到不同的 CLI 工具上。整体设计秉持"约定优于配置"理念，通过显式的流程把控，让 AI 协作写代码从"碰运气"转变为"可预测的受控过程"。

## 安装与使用

安装过程因平台而异，但整体非常简洁。以 Claude Code 为例：

```bash
# 克隆仓库（或直接在你的代理配置中引用）
git clone https://github.com/obra/superpowers.git

# 在 Claude Code 设置中指定技能目录
claude config set skills /path/to/superpowers/skills
```

对于其他平台（如 Cursor、Codex CLI、Gemini CLI 等），仓库提供了逐一的安装说明，通常只需将技能路径填入对应配置即可。最小使用流程如下：

1. 启动你的编码代理，并确保已加载 Superpowers 技能
2. 用自然语言描述你想要构建的功能或需求
3. 代理会先提问澄清目标，然后展示分块规格说明，等待你的确认
4. 确认后，代理生成实现计划，交由你审阅
5. 审阅通过后，代理才开始编写代码

## 适用场景

- **中大型功能开发**：当任务涉及多个模块或较复杂的业务逻辑时，先确认规格和计划能显著减少返工
- **团队协作与代码交接**：显式的规格说明和实现计划让 AI 生成的工作成果更易于人工审查与交接
- **测试驱动开发**：技能库中包含 TDD 相关技能，适合对代码质量有严格要求的项目
- **多代理协作环境**：若团队在多种编码 CLI 之间切换，Superpowers 能提供一致的开发方法论，降低切换成本

## 项目亮点

- **补齐 AI 编码的关键短板**：绝大多数同类工具直接输出代码，而 Superpowers 从流程层面解决了需求确认和规划问题，直击 AI 编码返工率高的痛点
- **极致可移植性**：一套方法论，覆盖从 Claude Code 到 Grok Build 等十余种主流平台，无需为每个工具重新学习工作流
- **技能可组合而非重写**：用户不需要为每个新工具编写全新的提示词，只需组合现有技能即可应对新场景
- **社区驱动并持续迭代**：项目由知名开发者 obra 发起，社区活跃。当前已获得超过 27 万 Star（含外部仓库引用），且日均增长显著
