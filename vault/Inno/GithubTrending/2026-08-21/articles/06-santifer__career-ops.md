## 项目概述

career-ops 是一个开源的 AI 求职助手系统，旨在将繁琐、低效的传统求职流程自动化。项目作者曾花费数月时间以传统方式投递简历，最终决定为自己打造一套理想中的求职系统——利用 AI 技术帮助求职者主动筛选公司，而非被动等待 AI 筛选。该项目完全运行在本地 AI 编码 CLI 环境中（如 Claude Code、Codex、OpenCode、Antigravity 等），支持扫描招聘门户、评估职位质量、定制简历并跟踪申请进度。目标用户是正在积极求职的开发者、工程师及其他技术从业者，尤其是那些希望以数据驱动方式优化求职策略、提升投递命中率的人群。

## 核心功能

- **职位门户智能扫描**：自动扫描多个主流招聘平台，聚合职位信息，避免手动浏览大量页面的低效操作
- **A-F 评估体系**：采用结构化的 A-F 评分标准，从职位描述、公司背景、技能匹配度等多个维度对每个职位进行量化评估，并转化为 1.0-5.0 的综合评分
- **简历智能定制**：根据目标职位的具体要求，自动调整简历内容，优化关键词匹配度，提升简历通过 ATS（申请者追踪系统）筛选的几率
- **申请全流程跟踪**：内置申请状态管理功能，清晰掌握每个职位的投递时间、当前阶段（已投递、面试中、被拒绝等）及后续动作
- **本地化安全运行**：所有数据处理均在本地环境中完成，保护个人隐私和求职数据安全，不依赖第三方云服务
- **多语言支持**：项目文档已翻译成 17 种语言，方便全球开发者使用和参与贡献

## 技术架构

career-ops 基于 JavaScript 构建，充分利用了现代 AI 编码 CLI 的扩展能力。项目核心设计思路是将 AI 的多代理（multi-agent）机制引入求职流程，通过多个专用代理协同工作，分别负责职位扫描、评估、简历优化和进度跟踪等不同任务。这种架构允许用户在不离开编码环境的前提下，完整管理整个求职生命周期。

在职位评估环节，系统将复杂的职位质量判断转化为可量化的 A-F 评分体系（对应 1.0-5.0 数字评分），这种设计不仅提高了评估结果的客观性，也便于用户快速比较不同职位之间的优劣。系统采用模块化设计，各功能组件可以独立使用或组合调用，用户可以根据自身需求灵活配置。由于完全运行在本地环境，career-ops 不需要部署独立服务端，降低了使用门槛，同时也避免了简历等敏感信息泄露到第三方平台的风险。

## 安装与使用

### 安装步骤

1. 确保已安装 Node.js（建议 v18 及以上版本）及你偏好的 AI 编码 CLI 工具（如 Claude Code、Codex 等）
2. 在目标目录中克隆仓库：

```bash
git clone https://github.com/santifer/career-ops.git
cd career-ops
```

3. 安装依赖：

```bash
npm install
```

4. 在 AI 编码 CLI 中加载项目，并按照提示完成基础配置（包括招聘平台 API 密钥或抓取设置）

### 最小可用示例

启动职业扫描：

```bash
npm run scan
```

系统将自动扫描配置的招聘源，并为每个职位生成包含 A-F 评分和 1.0-5.0 分数的评估报告。输出示例：

```
职位: Senior Frontend Engineer @ TechCorp
评分: A (4.7)
匹配度: 92% | 薪资范围: $150k-$180k | 远程: 支持
```

根据评估结果，选择目标职位并生成定制简历：

```bash
npm run tailor -- --job-id=abc123
```

## 适用场景

- **求职冲刺期**：当求职者希望在短时间内高效筛选大量职位、集中投递时，career-ops 可自动完成前期调研和评估工作，将精力集中在最有希望的职位上
- **职业转型探索**：计划转岗或进入新领域的开发者，可利用系统的职位评估功能快速了解目标方向的技能需求、薪资水平分布，辅助决策是否值得转型
- **留学或海外求职**：对于有意向在海外（如美、欧、日、韩等地）求职的技术人员，项目提供的多语言支持和全球招聘源扫描能力可显著减轻跨文化求职的信息壁垒
- **求职流程规范化管理**：习惯于量化管理个人事务的用户，可利用系统内置的跟踪面板将求职过程数据化，复盘投递策略的有效性

## 项目亮点

- **真正本地化运行**：与其他 SaaS 求职工具不同，career-ops 完全在用户自己的开发环境中运行，不传输简历等个人数据到第三方服务器，在隐私安全方面具有天然优势
- **反客为主的求职思维**：传统求职是求职者从雇主视角展示自己，而 career-ops 将主动权交还给求职者，让 AI 辅助用户评估公司，从而做到信息对称下的理性选择
- **量化评估体系**：A-F 评分与 1.0-5.0 分数的双重评估机制，改变了求职决策依赖直觉和运气的现状，使职位选择变得系统化、可比较
- **与 AI 编码工具深度整合**：用户无需切换应用，在熟悉的 Claude Code、Codex 等 CLI 环境中即可完成全部求职操作，极大降低了工具切换成本
