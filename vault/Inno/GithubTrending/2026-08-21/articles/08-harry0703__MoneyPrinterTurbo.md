## 项目概述

MoneyPrinterTurbo 是一款开源的 AI 短视频生成工具，旨在通过自动化工作流将视频创作从繁琐的手工流程中解放出来。用户只需提供一个主题或关键词，系统便会利用大语言模型自动完成脚本撰写、素材匹配、字幕生成与背景音乐合成等环节，最终产出一段高清短视频。该项目主要面向内容创作者、自媒体运营者、营销人员以及任何需要快速产出视频内容的个人或团队，尤其适合批量生产短视频的场景。

项目采用 Python 编写，基于 MIT 许可证开源，目前在 GitHub 上已获得超过 11 万星标，受到社区广泛关注。其核心理念是“一键生成”，将传统视频制作中耗时数小时甚至数天的工作压缩到分钟级完成。

## 核心功能

- **主题驱动生成**：输入任意主题或关键词（支持中英文），系统自动构建视频脚本结构，包括标题、正文和结尾。
- **AI 脚本创作**：集成多种大语言模型（如 Kimi、GPT 系列等），根据关键词生成逻辑清晰、口语化的视频文案。
- **智能素材匹配**：从 Pexels、Pixabay 等免费图库中自动检索与脚本内容匹配的高清视频片段，支持按场景切换。
- **自动字幕生成**：通过语音识别技术将脚本转换为精确的时间轴字幕，支持多种字幕样式与位置调整。
- **背景音乐与配音**：内置多种音色选择，自动生成语音旁白，并从版权免费音乐库中匹配适合的背景音乐。
- **多格式输出**：支持生成竖屏（9:16）、横屏（16:9）和方形（1:1）视频，适配抖音、快手、YouTube Shorts 等不同平台。
- **WebUI 与 API 双模式**：提供可视化网页操作界面，同时开放 RESTful API，便于集成到其他自动化流程中。

## 技术架构

MoneyPrinterTurbo 采用模块化设计，核心流程分为四个阶段：脚本生成、素材获取、语音合成、视频组装。

- **脚本生成层**：通过抽象接口接入多家大语言模型供应商，使用提示词工程引导模型输出结构化的视频文案。该层支持自定义 API Key，用户可切换不同模型以平衡成本与效果。
- **素材管理层**：内置媒体资源下载器，对接 Pexels 等平台的无版权 API。系统根据脚本中的关键词和场景描述自动匹配视频片段，并缓存至本地以减少重复请求。
- **媒体处理层**：使用 FFmpeg 作为底层视频处理引擎，负责片段裁剪、拼接、转码和画质优化。同时集成 TTS（文本转语音）引擎（如 Edge-TTS）生成配音，并通过字幕渲染模块将 SRT 文件烧录到画面上。
- **服务接口层**：基于 FastAPI 构建 RESTful API，并提供基于 Gradio 的 WebUI 前端。该层负责任务调度、参数配置和状态回传，支持异步处理多个生成任务。

架构的亮点在于将 AI 生成与人工程序处理解耦：大模型只负责创意内容，而视频合成则依赖成熟的媒体处理工具链，这既保证了输出的稳定性，又降低了对单一 AI 服务的依赖。

## 安装与使用

项目支持 Docker 与源码两种部署方式。以下是源码部署的基本步骤（需 Python 3.10+ 和 FFmpeg）：

1. 克隆仓库并安装依赖：
```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
pip install -r requirements.txt
```

2. 配置环境变量：复制 `.env.example` 为 `.env`，填入大模型 API Key（如 OpenAI 或 Moonshot）以及数据库连接信息。

3. 启动 Web 服务：
```bash
python main.py
```
服务启动后，浏览器访问 `http://localhost:8072` 进入 WebUI 界面。

4. 在界面中输入主题，如“人工智能未来趋势”，选择视频比例、音色和字幕样式，点击“生成视频”按钮。系统会依次执行脚本生成、素材下载、配音合成等步骤，并在几分钟内输出 MP4 文件。

对于开发者，也可直接调用 API：
```bash
curl -X POST http://localhost:8072/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject": "夏日海滩指南", "video_aspect": "9:16"}'
```

## 适用场景

- **自媒体矩阵运营**：运营多个短视频账号的团队可通过关键词批量生成不同领域的视频，保持高频更新。
- **产品营销快速测试**：营销人员可用不同卖点关键词生成多版视频广告，快速验证创意效果并投放测试。
- **知识科普内容生产**：教育类创作者将文章或选题转化为口播视频，降低录播成本，覆盖更多平台。
- **本地化内容批量改写**：结合翻译 API 与多语言 TTS，可将同一脚本快速转换为多语言版本，服务海外用户。

## 项目亮点

与同类 AI 视频生成工具（如剪映的图文成片）相比，MoneyPrinterTurbo 具备以下优势：

- **完全开源免费**：代码透明，无隐藏收费，用户仅需自备大模型 API 费用（可选用低成本模型）。
- **高度可定制**：从脚本风格、字幕字体到视频素材来源均可自定义，支持接入私有化大模型，满足企业内部合规要求。
- **API 友好**：提供完整的 REST API 文档，方便与其他系统（如 CMS）集成，实现视频生成的自动化流水线。
- **社区活跃**：项目拥有活跃的贡献者社区，持续迭代功能，并有多个语言版本的 README 与使用文档。
