## 项目概述

last30days 是一个面向 AI 代理（AI Agent）的技能包（Skill），它让 AI 代理能够自主研究任意主题在过去 30 天内的网络讨论，并生成有依据、可溯源的总结报告。与传统的搜索引擎不同，last30days 的搜索对象是「人」而不是「编辑」——它直接检索 Reddit、X（原 Twitter）、YouTube、Hacker News、Polymarket 等平台上由真实用户生成的内容，并以点赞数、投票数甚至真实货币（预测市场）作为相关性排序的依据，从而避开传统搜索引擎中存在的 SEO 污染和编辑偏见问题。

该项目由开发者 mvanhorn 创建，采用 MIT 许可证开源。其核心目标是解决一个普遍存在的痛点：当你想了解一个话题的最新动态时，传统搜索往往返回过时的文章或低质量的 SEO 内容，而 last30days 通过聚合多个社交平台和内容社区的实时讨论，让 AI 代理为你呈现「过去 30 天里真实的人在说什么」——而非「编辑认为你应该知道什么」。

项目的目标用户包括：需要快速进行市场调研的产品经理、需要追踪行业动态的技术从业者、内容创作者、投资者，以及所有希望获得更真实、更及时网络舆情洞察的 AI 工具使用者。

## 核心功能

- **多平台聚合检索**：一次命令即可同时搜索 Reddit、X、YouTube、Hacker News、Polymarket 和通用网页，覆盖主流讨论阵地。
- **时间窗口限定**：所有结果默认限定在最近 30 天内，确保信息的新鲜度与时效性。
- **社区信号加权排序**：结果按照 Reddit 的 upvotes、X 的 likes、YouTube 的观看量以及 Polymarket 的真实资金流动进行排序，让高质量、高关注度的内容自然浮现。
- **AI 驱动的总结生成**：AI 代理会对收集到的信息进行综合归纳，生成结构化的摘要报告，包括关键观点、分歧意见、情感倾向等维度。
- **来源可追溯**：生成的每一条结论都附带原始出处链接，方便用户核实与深入了解。
- **广泛兼容性**：作为 Agent Skill，可运行于 Claude Code、Codex、Cursor、Copilot、Gemini CLI 以及 50+ 支持 Agent Skills 的主机环境。

## 技术架构

last30days 基于 Anthropic 提出的 **Agent Skills** 规范构建，这是一个用于扩展 AI 代理能力的标准化框架。项目采用 Python 作为主要实现语言，其核心目录结构遵循 Agent Skills 的标准布局。

项目当前版本为 v3 管道，架构特点包括：

- **声明式技能规范**：`skills/last30days/SKILL.md` 文件是技能的「事实来源」（source of truth），详细定义了命令语法、参数说明和执行行为。Skill 的安装、调用和管理均通过该规范文件进行描述，使得 AI 代理能够理解并正确执行。
- **模块化设计**：整个技能被拆分为多个职责单一的模块，包括搜索调度、平台适配器（针对每个数据源的 API 封装）、数据清洗、评分聚合、总结生成等。这种模块化设计便于维护和扩展新的数据源。
- **插件化安装**：项目支持通过 `plugin marketplace add` 命令进行安装，并可通过 marketplace 机制实现自动更新。同时支持 `npx skills add` 方式，兼容非 Claude Code 的其他 AI 代理环境。
- **多语言文档支持**：项目维护了法语、德语、西班牙语、日语等多国语言的 README，降低了全球开发者的使用门槛。

在数据处理流程上，last30days 采用「多源并行获取 → 统一标准化 → 社区信号加权 → LLM 综合生成摘要」的管道设计。每个平台的数据先被转换为统一的内部格式，再结合各平台特有的互动指标进行加权评分，最终由大语言模型（LLM）根据评分结果生成有侧重点的总结报告。

## 安装与使用

**环境要求**：需要安装 Claude Code 或其他支持 Agent Skills 的 AI 代理工具，并具备相应的 API 访问权限（如 Anthropic API key）。

**安装步骤**：

**方式一：Claude Code（推荐，支持自动更新）**

```bash
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

**方式二：其他 AI 代理（Codex、Cursor、Copilot、Gemini CLI 等）**

```bash
npx skills add mvanhorn/last30days-skill -g
```

**最小使用示例**：

安装完成后，在 AI 代理的对话界面中直接输入命令：

```
/last30days "AI coding agents"
```

AI 代理会自动执行以下操作：
1. 并行搜索多个平台中过去 30 天内与该主题相关的讨论。
2. 收集各平台的高赞/高互动内容。
3. 生成一份综合摘要报告，列出关键发现、主流观点和重要争议点，并附上原始链接。

## 适用场景

- **行业趋势追踪**：产品经理或创业者希望快速了解某个新兴技术（如「量子计算」「具身智能」）在过去一个月的真实讨论热度、主要正面观点和担忧，以辅助技术选型或投资决策。
- **投资情报收集**：投资者关注 Polymarket 上的预测市场动态，同时希望结合 Reddit 和 X 上的散户情绪，形成对某个事件（如「美联储降息」「某公司财报」）的综合判断。
- **内容创作选题**：自媒体作者需要确认某个话题是否「正在风口」——通过查看多平台的互动数据，可以判断该话题的讨论浓度、热度走势和受众反应，从而决定是否值得围绕其创作内容。
- **市场舆情监测**：企业市场部门希望追踪用户对自家产品或竞品的真实评价，尤其是关注过去 30 天内出现的负面反馈和高赞批评帖。

## 项目亮点

last30days 与同类工具相比的主要差异化优势：

- **以人为中心的排序算法**：不同于谷歌等传统搜索引擎以页面权重和反链为排序依据，last30days 直接采用用户在社交平台上的真实互动数据（点赞、投票、资金）作为相关性信号，从根本上规避了 SEO 优化带来的内容质量下降问题。
- **跨平台信息融合**：单一平台的讨论往往存在信息茧房效应。last30days 将 Reddit 的深度、X 的速度、YouTube 的视觉、HN 的技术感和 Polymarket 的金钱信号糅合在同一份报告中，提供多维度的视角。
- **真实资金信号**：Polymarket 的整合是该项目的一大特色——预测市场中的资金分配反映了参与者「用钱投票」的真实判断，这是其他信息聚合工具所不具备的独特维度。
- **即插即用的技能生态**：作为标准 Agent Skill，它无需单独部署服务或编写复杂脚本，只需一条命令即可在任何支持该规范的 AI 代理中运行，开箱即用。
