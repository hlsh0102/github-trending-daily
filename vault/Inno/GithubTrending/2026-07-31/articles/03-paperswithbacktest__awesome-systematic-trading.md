## 项目概述

Awesome Systematic Trading 是一个精心策划的资源列表，旨在为系统化交易（量化交易）领域的研究者、开发者与交易员提供一站式导航。该项目由 paperswithbacktest 团队维护，目前已在 GitHub 上获得超过 11200 颗星，并持续保持活跃更新。它系统性地收集并组织了研究系统化交易策略所需的库、软件、书籍、文章与视频，覆盖从策略研究、回测到实盘交易的完整流程。无论你是刚进入量化领域的新手，还是希望扩展工具链的专业从业者，都能在此找到经过筛选的高质量资源。

## 核心功能

- **97 个精选库与软件包**：涵盖回测框架、实盘交易系统、数据处理、机器学习等类别，并细分为事件驱动框架与向量化框架等子类，方便按需选取。
- **40+ 机构与学术策略**：汇总了由专业机构和学术界提出的经典及前沿交易策略，为策略研发提供直接参考。
- **55 本推荐书籍**：根据读者水平分层（入门、进阶、专业），覆盖量化交易、统计套利、风险管理等多个主题。
- **23 个视频与访谈**：精选高质量的技术讲解、策略分享与行业专家对谈，适合视听学习偏好者。
- **博客与课程导航**：持续更新的博客推荐及系统性课程链接，帮助用户建立完整的知识体系。
- **中文版支持**：提供完整的中文翻译版本（README_zh.md），降低母语为中文用户的使用门槛。

## 技术架构

该仓库本质上是一个结构清晰的 Markdown 目录文件，但它在信息组织上体现了专业量化社区的共识。项目将资源按照「研究-开发-运行」的流程逻辑进行分层：首先按资源类型（库、策略、书籍、视频、博客、课程）划分大类，再在库与包分类下细分为「回测与实盘交易」和「通用」等子类，其中回测部分又进一步区分事件驱动框架（如 Backtrader、Zipline）与向量化框架（如 VectorBT），这种细粒度分类反映了量化开发中两种重要的技术路径。项目采用持续集成的方式维护资源的质量与时效性——通过社区贡献与维护者审核，定期更新链接和新增项目。此外，仓库内嵌了指向配套网站 paperswithbacktest.com 的引导模块，该网站提供更深入的策略实现示例，形成了从资源索引到实战代码的完整技术闭环。

## 安装与使用

由于本仓库是一个静态资源列表，无需进行任何安装。使用方式非常直接：

1. 直接访问 GitHub 仓库页面，阅读 README 文件。
2. 根据目录导航（Table of Contents）跳转至感兴趣的章节，例如「Libraries and packages」或「Books」。
3. 点击资源条目中的外部链接，即可跳转至对应的 GitHub 项目、书籍购买页面或视频平台。

例如，若你希望寻找一个 Python 回测库，可导航至「Libraries and packages → Backtesting and Live Trading」，在列出的框架（如 Backtrader、Zipline、VectorBT）中选择一个，点击其名称即可进入该项目的详细页面。若需要中文阅读体验，可点击 README 顶部的「希望阅读中文版？」链接，或访问仓库中的 `README_zh.md` 文件。

## 适用场景

- **量化策略研究入门**：初学者可通过「Books」与「Courses」章节建立系统化交易的理论基础，再借助「Strategies」部分了解经典的因子模型、动量策略与统计套利方法。
- **回测与实盘框架选型**：当需要为特定策略选择开发框架时，可直接对比「Libraries and packages」中事件驱动与向量化框架的优缺点，快速定位适合自身技术栈与策略类型的工具。
- **持续学习与业界追踪**：专业量化研究员可将此列表作为知识更新的「信息源」，通过博客与视频栏目跟踪最新行业动态、开源项目与学术进展。
- **构建个人量化工具箱**：开发者可以根据列表自行构建完整的「研究 + 回测 + 实盘」技术栈，将其中推荐的库组合成自己的量化平台。

## 项目亮点

与同类资源列表相比，该项目具有几个显著优势。第一，它是少有的**同时覆盖学术与业界视角**的系统化交易资源集，策略部分不仅收录了经典学术论文，还包含了机构实际使用的方法，弥合了理论与实践之间的鸿沟。第二，**分类粒度极细**，尤其在库的分类上，区分了事件驱动与向量化框架，这对开发者选型具有非常实际的指导价值，而非简单罗列。第三，**内容持续更新**，该仓库不仅保持高频的 GitHub 更新（单日星标增长超过 600），还会根据社区反馈不断调整分类与新增资源，确保信息的时效性。第四，**多语言支持**，提供官方中文翻译，这在同类英文主导的项目中颇为罕见，显著扩大了其受众范围。最后，项目与配套网站 paperswithbacktest.com 形成联动，用户可以在阅读资源列表后，直接访问网站获取对应的 Python 实现代码，实现从「知道什么」到「知道怎么做」的跨越。
