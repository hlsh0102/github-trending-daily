## 项目概述

Ever Gauzy 是一个开源的企业经营管理系统，覆盖 ERP（企业资源计划）、CRM（客户关系管理）、HRM（人力资源管理）、ATS（招聘跟踪系统）与 PM（项目管理）等多个业务领域。项目的目标是为中小型企业和团队提供一套可自托管、可扩展的统一业务管理平台，替代需要分别采购和集成的多套商业 SaaS 工具。

传统上，一家公司往往需要同时使用财务系统、客户管理系统、员工考勤工具和项目看板，这些系统之间数据割裂，集成成本高。Gauzy 试图将人员、时间、财务、客户与项目这几类核心业务对象放在同一个数据模型和权限体系中管理，从而降低信息孤岛问题。

项目的主要用户包括：希望自建内部管理系统的技术团队、需要一体化工具的中小企业、以及希望基于开源平台做二次开发的集成商与开发者。项目使用 TypeScript 编写，采用 AGPL-3.0 许可证。

## 核心功能

- **人力资源管理（HRM）**：员工档案、组织架构、部门与团队管理、考勤与工时记录、休假与费用报销流程。
- **时间跟踪与生产力统计**：支持桌面端与网页端的时间追踪，提供活动水平、屏幕截图、应用与网页使用统计等度量指标。
- **客户关系管理（CRM）**：联系人、客户、潜在客户管道、销售任务与邀约管理。
- **项目管理（PM）**：任务、看板、Sprint、团队协作与进度跟踪。
- **招聘管理（ATS）**：职位发布、候选人管道、面试安排与录用流程。
- **财务与发票**：收入/支出记录、发票生成与管理、与时间跟踪数据联动的计费支持。

## 技术架构

项目主体使用 TypeScript，采用前后端分离的多应用结构：

- **后端**：基于 Node.js 与 NestJS 框架，按业务领域划分为多个模块（如 HR、CRM、Time Tracking、Invoice 等），通过依赖注入组织服务层。数据访问使用 TypeORM，支持多种关系型数据库（PostgreSQL、MySQL、SQLite 等）。
- **前端**：使用 Angular 构建的 Web 管理界面，配合 RxJS 与 NgRx 管理状态。
- **桌面端**：基于 Electron 的时间跟踪与截屏应用。
- **移动端**：提供移动端应用能力，便于远程与现场办公场景。
- **单体仓库（Monorepo）**：多个应用与共享库置于同一仓库，通过 Nx 等工具统一构建与依赖管理，公共逻辑（如实体定义、DTO、认证）以共享包形式复用。

整体设计强调模块化与可插拔，不同业务模块共享统一的用户、组织与权限模型，便于跨模块的数据联动（例如工时数据直接用于发票计费）。

## 安装与使用

由于项目是包含后端、前端、桌面端的 Monorepo，本地运行通常需要先准备 Node.js、包管理器（Yarn/NPM）与数据库。

基本步骤概述：

```bash
# 1. 克隆仓库
git clone https://github.com/ever-co/ever-gauzy.git
cd ever-gauzy

# 2. 安装依赖
yarn install

# 3. 配置环境变量（数据库连接、API 地址等）
#    复制示例 env 文件并按需修改

# 4. 启动 API 服务
yarn start:api

# 5. 启动 Web 前端
yarn start:gauzy
```

启动后，通过浏览器访问前端地址并使用默认管理员账号登录即可进入管理界面。生产环境部署建议参考官方文档中的 Docker 或 Kubernetes 方案。项目同时支持通过 Gitpod 快速在线体验，无需本地配置环境。

由于版本迭代较快，具体命令与环境变量名称请以仓库中 README 和 `docs` 目录的最新说明为准。

## 适用场景

- **中小企业一体化管理**：用一套系统替代分散的 HR、CRM 与项目管理工具，减少系统间集成成本。
- **外包与咨询服务公司**：依托时间跟踪与计费功能，将工时直接转化为客户发票。
- **远程/混合办公团队**：通过桌面端时间追踪与生产力统计了解团队工作状态。
- **技术团队二次开发**：基于开源代码与模块化架构，定制符合自身业务流程的内部系统。

## 项目亮点

- **业务覆盖面广**：将 ERP、CRM、HRM、ATS、PM 等能力整合在同一平台，而非单一功能工具。
- **多端支持**：同时提供 Web、桌面端与移动端，适配不同办公场景。
- **开源可自托管**：采用 AGPL-3.0 许可，企业可将数据保存在自有基础设施中，避免数据外流。
- **技术栈现代且统一**：以 TypeScript 贯通前后端，配合 NestJS 与 Angular，便于全栈团队维护和扩展。
- **活跃的社区关注度**：项目在 GitHub 上拥有较高的 Star 数，社区迭代频繁。
