## 项目概述

Anki 是一款基于间隔重复（Spaced Repetition）原理的智能记忆辅助程序，其桌面版源代码托管在 `ankitects/anki` 仓库中。该项目的核心目标是帮助用户高效地进行长期记忆训练：通过算法安排复习时间，让学习者在即将遗忘某个知识点的临界点进行复习，从而以较低的复习次数获得较高的记忆保持率。

Anki 解决的问题是传统重复学习中的效率低下问题。死记硬背或按固定周期复习往往导致已经掌握的内容被反复消耗时间，而真正薄弱的内容又得不到足够强化。Anki 通过为每张卡片维护独立的记忆状态，动态调整其下次出现时间，把复习资源集中在最需要的地方。

目标用户包括语言学习者、医学生、法律与工程等需要大量记忆专业知识的备考人群，以及任何需要长期保持特定知识记忆的个人。卡片内容完全由用户自定义，因此适用范围不局限于某一学科。

## 核心功能

- **间隔重复调度**：基于 SM-2 及其后续演进的调度算法，根据用户对每张卡片的评分（如“重来”“困难”“良好”“容易”）计算下一次复习间隔。
- **卡片与笔记模型**：区分“笔记”（Note，存储字段数据）与“卡片”（Card，由笔记按模板生成），支持一张笔记生成多张正反向或 cloze 填空卡片。
- **牌组与筛选牌组**：支持按主题组织牌组，并可通过筛选牌组临时组合来自不同牌组的卡片进行集中复习。
- **多媒体与富文本**：卡片字段可包含图片、音频、视频、LaTeX 公式以及 HTML/CSS 样式，模板系统允许对卡片外观进行深度定制。
- **同步与多端支持**：通过 AnkiWeb 在桌面、移动端与网页端之间同步集合与复习进度，并支持导入导出 `.apkg` 牌组包。
- **插件扩展**：提供 add-on 机制，用户可安装第三方插件扩展统计、编辑、导入等功能。

## 技术架构

Anki 桌面版采用多层架构。核心逻辑位于 Rust 编写的 `rslib` 中，负责集合（collection）存储、调度算法、卡片生成、同步协议等关键部分，并通过 SQLite 持久化数据。Rust 层对外暴露接口，供上层调用。

用户界面基于 Python 与 Qt（通过 PyQt）构建，负责牌组管理、复习界面、统计图表与偏好设置等交互部分。Rust 与 Python 之间通过 PyO3 等绑定机制通信，使性能敏感的逻辑运行在 Rust 侧，而界面与插件生态保留在 Python 侧。

调度器被抽象为可替换组件，除内置的 SM-2 外还支持 FSRS（Free Spaced Repetition Scheduler）等现代算法。同步功能采用基于变更日志与分块传输的设计，以在不同设备间合并集合修改。

## 安装与使用

普通用户可直接从官网下载对应平台的安装包，无需从源码构建。若需从源码运行，仓库的 `docs/development.md` 给出了完整流程，大致步骤为：安装 Rust 工具链、Python 与 Qt 依赖，使用项目提供的构建脚本编译 Rust 组件，再启动 Python 前端。

最小使用流程如下：

1. 启动 Anki，创建一个牌组。
2. 添加笔记，选择笔记类型（如“基础”），填写正面与背面字段。
3. 进入复习界面，对每张卡片根据回忆情况选择评分按钮。
4. 系统按评分更新该卡片的间隔，并在到期时再次呈现。

## 适用场景

- **语言词汇记忆**：为单词、例句、发音创建卡片，利用音频与图片字段强化多通道记忆。
- **医学与专业考试备考**：记忆解剖学、药理学、法规条文等大体量知识点，通过 cloze 填空卡片提高覆盖率。
- **长期知识维护**：对工作中需要持续记住的 API、命令、流程等制作卡片，以低频复习保持熟悉度。
- **自定义题库学习**：将已有问答资料导入为牌组，配合筛选牌组在考试前集中突击薄弱部分。

## 项目亮点

与普通的闪卡应用相比，Anki 的差异化主要体现在三点。其一，调度算法可配置且支持 FSRS 等更贴近记忆曲线的模型，而非简单的固定间隔。其二，笔记与卡片分离的数据模型允许一份内容按多种方式出题，显著减少录入成本。其三，围绕 AnkiWeb 同步、`.apkg` 共享格式与插件系统形成了成熟的生态，用户可以获取他人整理的牌组并用插件扩展功能。此外，核心逻辑以 Rust 实现，在保持跨平台一致性的同时兼顾了性能与可维护性。
