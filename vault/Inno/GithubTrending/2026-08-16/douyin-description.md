2️⃣ cathrynlavery/diagram-design：给 Claude Code 等 AI 工具用的图表技能包，27 种编辑级风格，纯 HTML+SVG 输出，不依赖 Figma，还能读网站自动匹配配色字体，告别“AI 图表丑”难题。

3️⃣ cursor/plugins：Cursor 官方插件仓库，规范化插件清单格式，提供持续学习、代码审查、团队协作等官方插件，开发者可参考实现自定义扩展。

4️⃣ cactus-compute/needle：45M 参数的开源小模型，打包后仅 14MB 二进制，约 28MB 内存跑完整会话，专注工具调用和结构化数据提取，为物联网和边缘计算而生。

5️⃣ unslothai/unsloth：本地桌面应用，可视化运行和微调 LLM 与扩散模型，支持 Qwen3.8、Kimi K3、DeepSeek-V4、FLUX 等，零脚本即可上手训练。

6️⃣ public-apis/public-apis：46 万星的老牌项目，免费公开 API 大全，涵盖动物、区块链、金融、天气等几十个分类，一站式接口索引，开发者必备收藏。

7️⃣ MakazhanAlpamys/Soup：命令行微调工具，一个 YAML 配置搞定训练。Layer Streaming 技术让你在 4GB 显存笔记本上训练 8B 参数模型，大模型微调门槛再降。

8️⃣ github/spec-kit：GitHub 官方出品，规范驱动开发工具包。先写规范再让 AI 编码，内置流程模板，适配 Copilot、Cursor 等主流 AI 编程工具。

9️⃣ megadose/holehe：OSINT 工具，检查邮箱在 120+ 平台是否注册过账号，利用“忘记密码”接口探测，不发通知邮件，适合安全研究和渗透测试。
