## 项目概述

FluidVoice 是一款专为 macOS 平台打造的开源语音转文字（STT）听写应用，其核心定位是成为 Wispr Flow 的本地替代方案。它最大的特点在于实现了完全离线的设备端语音识别，并在此基础上叠加了自定义训练的 AI 增强模型，从而在无需联网、无需上传语音数据的情况下，获得快速且准确的听写体验。该项目主要面向注重隐私、追求低延迟响应、且希望摆脱订阅制商业软件束缚的 macOS 重度用户，如开发者、内容创作者、科研人员和文字工作者。

FluidVoice 不仅仅是一个简单的音频转录工具。它通过本地化的 AI 模型，对初始识别结果进行语法、上下文和标点的智能修正与润色，致力于解决传统离线语音识别“听写出来但语句不通顺”的痛点。项目采用 GPL-3.0 开源协议，并已获得超过一万颗 GitHub Star，社区活跃度极高，体现了其作为优质开源工具的强大吸引力。

## 核心功能

- **全离线语音识别**：所有音频处理均在设备本地完成，不依赖云端服务，确保语音数据不出设备，彻底保障用户隐私安全。
- **AI 增强与润色**：内置基于 NVIDIA Nemotron Speech 3.5 等技术训练的增强模型，能够对识别出的文本进行实时修正，包括智能断句、上下文语义理解以及错别字纠错，使输出文本更接近自然语言表达。
- **多主流模型支持**：内置多种先进的 STT 模型选择，包括 NVIDIA 的 Parakeet 系列（v2/v3/Flash）、Cohere 模型、Apple 原生 Speech 框架以及 OpenAI 的 Whisper 模型，用户可根据设备性能和精度需求灵活切换。
- **极低延迟响应**：专为追求“即时反馈”场景设计，利用优化过的模型推理流程，实现边说话边出字的流畅体验，显著提升工作和创作效率。
- **全局快捷听写**：支持系统级快捷键调用，在任何应用（如浏览器、IDE、邮件客户端）中均可快速呼起听写窗口，实现无缝跨应用输入。
- **Sponsor 赞助支持**：项目通过 GitHub Sponsors 接受捐赠，支持者可以推动项目持续迭代，获得更稳定的模型更新和优先的技术支持。

## 技术架构

FluidVoice 使用 Swift 语言开发，深度结合了 macOS 系统生态。其底层架构高度模块化，核心由两大引擎构成：**语音识别引擎** 和 **文本增强引擎**。

- **语音识别引擎**：利用苹果的 Speech 框架作为基础兼容层，同时集成了针对高性能场景的私有推理后端以运行 Parakeet 和 Whisper 等模型。为了确保低延迟，引擎采用了流式（streaming）音频处理技术，使得音频数据可以被分块处理并逐步输出识别结果，而非等待整段音频录完后再一次性处理。
- **文本增强引擎**：这是 FluidVoice 区别于其他 STT 工具的核心。该引擎运行一个经过特殊训练的精调模型（基于 Nemotron Speech 3.5 等基础模型），它接收识别引擎的原始输出作为输入，执行“清洗”和“润色”操作。该模型常驻内存并利用 GPU 加速（Apple Silicon 的 Neural Engine），以保证增强过程对用户无感知。同时，架构预留了模型热插拔接口，用户可以便捷地切换不同的增强模型版本。

## 安装与使用

FluidVoice 提供了非常便捷的安装方式，推荐使用 Homebrew 进行管理：

```bash
brew install --cask fluidvoice
```

对于不熟悉命令行的用户，也可以直接访问项目的 [Releases 页面](https://github.com/altic-dev/FluidVoice/releases/latest) 下载最新的 `.dmg` 安装包，拖拽至应用程序文件夹即可。

**最小可用示例：**

1. 安装完成后，启动 FluidVoice，应用会出现在菜单栏（Menu Bar）中。
2. 点击菜单栏图标，进入设置界面，选择你偏好的本地识别模型（推荐选择 Parakeet Flash 以获得速度与精度的平衡）。
3. 在系统设置中，为 FluidVoice 授予“麦克风访问权限”。
4. 在任意文本输入框中，按下预设的全局快捷键（默认如 `Option + Space`），开始说话。
5. 说话完毕后再次按下快捷键或停顿数秒，听写文本将自动输入至光标处，无需手动复制粘贴。

## 适用场景

- **隐私敏感的专业写作**：对于记者、律师或处理敏感信息的人员，FluidVoice 确保所有语音内容都在本地处理，避免将机密对话上传至公共云服务器，从源头阻断数据泄露风险。
- **需要高效长文输入的场景**：对于需要撰写长文、会议纪要或代码注释的开发者，FluidVoice 的高精度 AI 润色能力可以减少后期编辑时间，大幅提升“语音转文字”的可用性，让内容以更流畅的形态落地。
- **无网络或弱网环境办公**：在飞机上、地铁中或网络不稳定的区域，FluidVoice 的离线特性保证了生产力工具不受网络状况影响，随时可用。
- **寻找商业软件替代品**：厌倦了 Wispr Flow 或类似工具的订阅费用，同时希望拥有更透明代码和可定制性的用户，可以将 FluidVoice 作为 100% 免费的本地替身。
