## 项目概述

`diagram-design` 是一个为 Claude Code、Codex 和 Pi 等 AI 编程助手设计的可视化图表生成技能包，内置了 29 种编辑级图表类型。它的核心目标非常明确：让 AI 生成的图表不再“辣眼睛”，而是达到设计师愿意直接放进文章、演示稿或客户提案中的水准。

项目采用自包含的 HTML + SVG 方案，不依赖任何外部库或在线服务。与市面上泛滥的 Mermaid 风格图表（作者戏称为 “Mermaid-slop”）不同，它摒弃了默认的圆角矩形堆砌、花哨阴影和杂乱配色，转而提供干净、克制、具有编辑设计感的视觉语言。无论你是独立开发者、技术写作者，还是需要快速产出高质量架构图的产品经理，都能从这个项目中受益。

项目的设计哲学很直接：与其让 AI 生成一张需要花费 30 分钟调整颜色和布局的“草图”，不如从一开始就约束为结构化、语义化的高质量输出。库本身基于 MIT 许可证开源，当前已获得超过 18700 个 Star，并入选 Trendshift 趋势榜，社区认可度相当高。

## 核心功能

- **29 种编辑级图表类型**：从流程图、架构图、金字塔图到飞轮图（Loop）、时间线、泳道图等，覆盖绝大多数技术写作与产品表述场景。所有类型统一设计语言，视觉风格高度一致。
- **自包含 HTML + SVG**：每张图都是一个独立的 HTML 文件，内嵌 SVG 矢量图形，无需加载外部字体、脚本或 CDN 资源，复制即用，离线可用。
- **语义模式系统**：将“行为”（如队列、策略轨迹、信任边界）与“布局”分离。不同的语义概念可以复用同一种图表类型，而无需为每种新场景单独增加类型，保持整体类型数量精简。
- **可选无障碍动效**：默认输出静态 HTML，确保打印和复制时无损；但对于需要逐步讲解的复杂流程，可以开启可访问的运动过渡，帮助观众按顺序理解节点关系。
- **多平台兼容**：同一个技能包文件即可用于 Claude Code、Codex 和 Pi，无需为不同 AI 工具维护多套提示词或配置。
- **导入再设计能力**：支持读取现有的 draw.io 或 Mermaid 源文件，并按照可指定的格式、尺寸和细节级别重新绘制为编辑级图表，帮助旧项目快速升级视觉质量。

## 技术架构

该项目在技术选型上刻意保持轻量与克制。其核心产物是单个自包含的 HTML 文件，内部使用内联 SVG 进行图形绘制。这种方式的优点在于零依赖——无论是浏览器直接打开、嵌入文档系统，还是通过版本工具追踪变更，都不会遇到外部资源失效的问题。

设计思路上最大的特色是“语义模式”系统。传统图表库往往用“类型+布局”的二维矩阵来枚举所有可能性，导致类型数量失控；而这里通过将语义（这个节点代表什么）与布局（节点如何摆放）解耦，用有限的核心类型搭配灵活的语义标注来覆盖更多业务场景。例如，一个“信任边界”和一个“资源队列”在布局上可能属于同一种类型，但语义标记不同，对应的视觉符号和连线规则也不同。

针对 AI 辅助生成的场景，项目内置了高度结构化的提示词（Skill），使模型能够理解设计约束——包括间距规范、连接线走线规则、颜色语义等。每个类型均提供了示例输出，方便用户对照复制和修改。作者还考虑到了可访问性，对动态效果进行了 optional 设计，默认关闭，确保视觉障碍用户和打印场景的兼容性。

## 安装与使用

无需安装任何软件或依赖。只需将项目仓库克隆到本地，然后按照以下步骤操作：

```bash
git clone https://github.com/cathrynlavery/diagram-design.git
cd diagram-design
```

最低可用示例：在 Claude Code、Codex 或 Pi 中，将项目目录下的 skill 文件作为技能加载，然后自然语言描述你需要的图表，例如：

```
请用编辑级图表生成一张微服务架构图，突出 API 网关与各服务间的数据流。
```

AI 会从 29 种类型中选择最合适的样式，生成一个完整的 .html 文件，直接用浏览器打开即可查看或导出为图片。若已有 Mermaid 或 draw.io 源文件，可以直接在提示中附上源文件路径或内容，要求 AI 进行重新绘制。

## 适用场景

1. **技术文档与博客写作**：当你在撰写架构设计文档、API 参考或技术 blog 时，需要清晰、美观、无版权风险的图表，本库的静态 HTML 输出可以直接嵌入页面或转成 PNG 用于发布。
2. **产品与商业提案**：创业者或产品经理在准备融资 PPT、客户方案时，经常需要绘制业务飞轮、信任边界、策略流程等图表。本库的编辑级视觉风格，可以在不求助设计师的情况下产出足够专业的图形。
3. **内部系统设计评审**：工程团队在方案评审时，快速生成一致风格的系统架构图、时序图或网络拓扑图，所有队员在同一个视觉基准下讨论问题，降低沟通成本。
4. **旧图表视觉迁移**：将历史遗留的 Mermaid 或 draw.io 图表批量重新渲染为统一的编辑风格，提升整个知识库的视觉一致性和专业感。

## 项目亮点

- **审美克制**：不跟随“圆角渐变阴影”的流行模板，而是回归编辑设计风格的简洁线框与克制配色，适配专业出版与打印场景。
- **无人力依赖**：无需 Figma 账号、无需设计师介入，通过 AI 提示即可生成接近专业水准的图表，且可反复迭代。
- **语义驱动的类型管理**：通过语义与布局解耦，用更少类型覆盖更多场景，降低了学习成本和维护负担。
- **可访问性优先**：默认静态输出保证了无障碍阅读与打印，运动效果作为可选增强而非默认功能。
- **跨 AI 平台复用**：一个技能包同时适配当前主流的三个 AI 编程工具，无需重复编写提示词。
