## 项目概述

Cursor plugins 是 Cursor 官方维护的插件仓库，旨在为流行的开发者工具、框架和 SaaS 产品提供标准化、可复用的插件规范与实现。该仓库不仅定义了插件清单文件 `.cursor-plugin/plugin.json` 的格式规范，还收录了多个由 Cursor 团队编写的官方插件，覆盖持续学习、团队协作、代码审查、插件脚手架创建、代理兼容性检测以及 CLI 设计模式等多个开发场景。

该项目的核心目标是解决 Cursor 生态中插件分散、标准缺失的问题。通过将插件定义为仓库根目录下独立的目录，每个目录内含自己的 `plugin.json` 清单，开发者可以快速浏览、安装和分发插件。同时，官方插件的存在也为社区开发者提供了高质量的参考实现，降低了编写自定义插件的门槛。目标用户包括 Cursor 的日常使用者、团队技术负责人以及希望扩展 Cursor 能力的插件开发者。

## 核心功能

- **规范化插件清单**：每个插件目录包含 `plugin.json` 清单文件，声明插件名称、作者、分类、描述等信息，确保插件可被 Cursor 市场统一识别与安装。
- **持续学习插件（Continual Learning）**：基于增量对话记录，自动更新 `AGENTS.md`，采用高信号要点提取机制，帮助代理从历史交互中沉淀有效经验。
- **团队工具包（Cursor Team Kit）**：提供内部团队工作流支持，涵盖 CI 集成、代码审查、发布流程、本地自动化与结果验证，适合团队协作环境。
- **Thermos 代码审查**：实现“热核级”分支审查，包含深度安全与正确性审计、严格的代码质量评分规则，并通过并行子代理与可选的合并就绪 PR 流程增强审查效果。
- **插件脚手架生成器（Create Plugin）**：提供脚手架命令，快速生成并验证新的代理插件，简化插件开发流程。
- **代理兼容性扫描**：基于 CLI 完成仓库兼容性扫描，并附带审计启动、校验与文档一致性的代理组件，确保插件与目标环境契合。

## 技术架构

该仓库以 TypeScript 为主要语言，采用多目录单仓库（monorepo）结构。每个插件在根目录下拥有独立子目录，核心元数据由 `.cursor-plugin/plugin.json` 承载。这种设计使得插件之间逻辑隔离清晰，便于独立维护与版本管理。

在实现层面，插件大量依赖 CLI 工具与代理（agent）的协同。例如，`agent-compatibility` 插件通过 CLI 扫描仓库状态，再由代理读取扫描结果并执行审计任务；`cli-for-agent` 则总结了一套 CLI 设计模式，强调标志位清晰、帮助信息含示例等原则，以确保编码代理能够稳定地调用命令行工具。这种“CLI + 代理”的架构模式提升了自动化任务的可靠性，也降低了代理与环境交互的不确定性。

仓库整体遵循声明式配置与可验证的原则。所有插件均附带 `plugin.json` 清单，并鼓励开发者通过 `create-plugin` 工具进行初始化与验证，以保证插件符合 Cursor 生态规范。

## 安装与使用

使用 `cursor/plugins` 仓库中的插件通常遵循以下步骤：

1. **克隆仓库**：
   ```bash
   git clone https://github.com/cursor/plugins.git
   cd plugins
   ```

2. **选择需要的插件目录**，例如 `cursor-team-kit`。

3. **将插件目录安装到您的项目中**。以 Zsh 为例，可将插件目录复制到您的 Cursor 工作区，并确保 `.cursor-plugin/plugin.json` 存在于插件根目录。

4. **验证插件**：若您要开发新插件，可使用 `create-plugin` 插件提供的脚手架功能：
   ```bash
   cd create-plugin
   # 按照 README 指引运行脚手架命令，生成标准插件结构
   ```

最小可用示例：若您只需使用 `continual-learning` 插件，只需将其目录放置在项目根目录，并在 Cursor 中启用该插件。插件将随代理运行自动监控对话增量，并定期更新 `AGENTS.md` 文件，无需额外配置。

## 适用场景

- **团队内部开发流程标准化**：通过 `cursor-team-kit` 统一 CI、代码审查、发布和验证流程，尤其适合中型及以上团队追求一致性的场景。
- **高质量代码审查**：在合并关键分支前，利用 `thermos` 插件进行深度安全审计与质量评分，适用于对代码安全性与规范性要求严格的开发团队。
- **代理长期记忆维护**：在频繁使用 Cursor 代理进行编码辅助时，`continual-learning` 插件可帮助代理从历史会话中提取高价值信息，持续优化 `AGENTS.md`。
- **CLI 工具代理化集成**：如果您正在开发面向编码代理的 CLI 工具，可以参考 `cli-for-agent` 中总结的设计模式，提升工具在自动化环境中的可用性。

## 项目亮点

- **官方背书与质量保障**：所有插件由 Cursor 团队维护，确保与 Cursor 主产品的高度兼容性和稳定性。
- **清晰统一的结构规范**：`plugin.json` 清单标准化，大幅度降低插件开发与分发的认知负担。
- **覆盖场景全面**：从个人开发辅助（持续学习）到团队协作（ Team Kit ）、再到代码审查与插件开发本身，形成了完整的工具链。
- **强调工程化实践**：仓库内插件普遍采用 CLI 与代理协作的模式，体现了对自动化可靠性、可验证性的现实考量，而非停留在概念层面。
