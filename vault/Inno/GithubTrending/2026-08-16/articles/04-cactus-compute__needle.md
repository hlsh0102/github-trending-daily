## 项目概述

Needle 2 是一个面向极小型设备的开源基础模型，由 cactus-compute 团队开发。整个模型仅为一个 14MB 的二进制文件，参数规模为 4500 万（45M），却能在约 28MB 内存中运行完整会话。该项目专注于工具调用、设备使用和结构化信息提取，让手机、可穿戴设备、智能家居和机器人等资源受限的终端设备也能具备本地智能推理能力。

Needle 2 的核心突破在于其极端的压缩效率：相比同类小模型（如 FunctionGemma 270M、LFM2.5 230M 和 Apple FM），它在体积上缩小 5 到 70 倍，同时以 2-bit 量化精度对标这些模型的 f16 精度。该项目的目标用户包括嵌入式开发者、物联网工程师、边缘计算研究人员，以及所有希望在无网络环境下运行智能应用的开发者。

## 核心功能

- **自包含引擎**：权重直接烘焙进单个 14MB 的二进制文件，无需管理独立模型文件，推理过程完全离线，不发起任何网络请求。
- **简洁的调用契约**：文本输入、JSON 输出——工具调用以结构化数据返回；基于用户声明的 schema 编译出字节级语法，约束每一次 token 生成，确保输出格式严格合规。
- **置信度门控**：每个响应都附带来自学习头的校准置信度分数；开发者可设定阈值，高于阈值时自动执行，低于阈值时升级处理或转交人工。
- **工具检索**：支持声明大型工具目录，内置检索头在每轮交互中只渲染排名前五的工具，且语法约束被限定在该子集内，显著提升推理效率。
- **有界内存**：采用 256 token 的滑动窗口机制，配合工具截断策略，保证长会话中的内存占用始终受限，适配极低端硬件。

## 技术架构

Needle 2 建立在 Simple Attention Network（简单注意力网络）的研究成果之上。与标准 Transformer 架构不同，它大幅简化了注意力机制，减少了计算和存储开销，同时保持了足够的表达能力以完成工具调用和结构化提取任务。

模型权重采用 Cactus Quants 压缩至 CQ2-bit 精度，这是 cactus-compute 自研的量化方案。量化过程将模型从原始浮点表示压缩约 16 倍，但通过精心设计的量化策略，在 2-bit 精度下依然能与同级别 f16 模型在基准测试中互有胜负。

推理引擎是自研的运行时，不对接 PyTorch、ONNX 或 TensorFlow Lite。这个引擎天然支持 byte-level 语法约束——它直接在 token 采样时对候选集做严格过滤，确保输出永远符合用户 JSON Schema 的格式要求。整个推理引擎在首次使用时从 Hugging Face 拉取一次并缓存，之后完全离线运行；针对气隙环境（如封闭内网），官方文档 `doc/apis.md` 提供了完整的离线部署指引。

Python 包 `cactus-needle` 负责推理、LoRA 微调和导出。开发者只需用 `pip` 安装，描述工具后即可从 Python 中调用，无需编译任何原生代码。

## 安装与使用

安装过程非常直接：

```bash
pip install cactus-needle
```

安装后，首次调用时推理引擎会自动从 Hugging Face 下载并缓存。最小可用示例：

```python
from cactus_needle import Needle

# 初始化模型（引擎首次下载并缓存在本地）
model = Needle.from_pretrained()

# 描述你的工具（JSON Schema 格式）
tools = [
    {
        "name": "get_weather",
        "description": "查询指定城市的当前天气",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名称"}
            },
            "required": ["city"]
        }
    }
]

# 绑定工具并执行调用
response = model.call("北京天气怎么样？", tools=tools)

# 返回结构化 JSON，可直接用于后续逻辑
print(response)
# 输出: {"city": "北京", "temperature": "22°C", "condition": "晴"}
```

离线部署时，参考 `doc/apis.md` 文档，将引擎二进制预先拷贝到目标设备，即可在完全无网络的环境下正常运行。

## 适用场景

- **智能家居设备**：嵌入式控制面板通过本地工具调用执行场景联动（如“关灯并锁门”），无需依赖云端大脑，响应更迅速且保护隐私。
- **可穿戴设备**：智能手表或健身手环上实现本地语音助手，调用提醒、健康数据查询等工具，功耗和内存占用均能承受。
- **机器人嵌入式控制**：在机器人主控板上直接完成简单的指令解析和技能调用，避免将每次指令都回传服务器。
- **隐私敏感的终端应用**：如医疗辅助或企业内网助手，所有数据在本地处理，响应置信度低时再考虑升级处置。

## 项目亮点

Needle 2 与同类小模型相比，最显著的差异化优势在于：

1. **极致的压缩率**：14MB 的二进制对 45M 参数，同精度下比同类模型小 5–70 倍。2-bit 量化在保持可用精度的前提下，将内存占用压到仅 28MB，这让模型首次真正意义上“塞进”了单片机和低端 SoC。
2. **推理零网络依赖**：权重烘焙在引擎中，离线即可全功能运行，天然满足气隙部署和隐私合规要求。
3. **产物级格式保证**：byte-level 语法约束是硬性机制，而不是软性提示，输出永远是合法 JSON，避免了解析失败的工程噩梦。
4. **置信度校准**：每次响应都附带分数，开发者可以构建可靠的人机协作流程——低置信度时转人工或回退规则引擎。
5. **超低门槛接入**：一条 pip 命令即完成安装，无 native 编译过程，上手成本极低。
