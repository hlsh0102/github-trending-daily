## 项目概述

Soup 是一个用于微调和后训练大语言模型（LLM）的命令行工具，它将原本复杂、繁琐的模型训练流程简化为一条 YAML 配置文件加一个命令。项目的核心目标是大幅降低大模型微调的技术门槛，让开发者无需配置 SSH 环境、无需处理各类底层框架的兼容性问题，就能在本地完成模型的定制化训练。

Soup 特别针对资源受限的个人开发者设计。通过其独创的 Layer Streaming 技术，即使是参数量高达 80 亿（8B）的模型，也能在仅有 4 GB 显存的笔记本电脑 GPU 上完成训练。这意味着，过去需要昂贵云服务器或多卡集群才能进行的微调任务，现在在普通消费级硬件上即可实现。

## 核心功能

- **一条命令启动训练**：只需在终端执行 `soup train`，Soup 会自动处理数据集加载、模型下载、训练循环、检查点保存等全部流程，无需手动编写训练脚本。
- **YAML 声明式配置**：所有训练参数（模型名称、数据集路径、学习率、批次大小、训练轮数等）均通过一个 YAML 文件声明，结构清晰、易于版本管理和团队协作。
- **Layer Streaming 内存优化**：采用分层流式加载技术，仅在需要计算时加载模型的特定层参数到显存，从而在极低显存条件下训练大型模型。
- **多任务覆盖**：既支持传统的监督式微调（SFT），也支持继续预训练（继续训练）、偏好对齐（DPO）等后训练任务，满足从领域适配到行为对齐的多样化需求。
- **模型广泛兼容**：内置对 Llama、Mistral、Qwen、Phi 等主流开源模型家族的适配，支持 Hugging Face 格式直接导入。
- **自动检查点与恢复**：训练过程中定期保存检查点，支持意外中断后从上次进度无缝恢复，避免算力浪费。

## 技术架构

Soup 基于 Python 3.10–3.12 构建，核心依赖 PyTorch 和 Hugging Face Transformers 库。其技术架构围绕“极简化用户接口”与“底层资源高效利用”两个目标展开。

在用户接口层，Soup 定义了一套 YAML 配置规范（Schema），将训练相关的所有参数统一映射为结构化字段。配置解析器会校验字段的合法性与依赖关系，并将配置转换为内部训练调度器可执行的指令。

在底层执行层，Soup 的核心创新是 Layer Streaming 引擎。传统全参数微调（Full Fine-tuning）需要将整个模型（包括所有层和优化器状态）加载进 GPU 显存，导致 8B 模型在 4GB 显存上根本无法运行。Soup 将模型按层切分，并维护一个动态加载队列：前向传播和反向传播时，仅将当前正在计算的层驻留于显存；计算完成后立即将该层参数移出，并加载下一层。这本质上是一种以计算换空间的策略，通过牺牲少量 I/O 带宽，换取了 GPU 显存利用率的数量级提升。

此外，Soup 内部实现了训练循环的自动化管理，包括梯度累积、混合精度训练（fp16/bf16）、学习率调度（余弦退火、线性预热等）、梯度裁剪等常用技术。所有功能均封装为模块化组件，便于后续扩展新训练方法。

## 安装与使用

### 安装

Soup 已发布至 PyPI，通过 pip 即可安装：

```bash
pip install soup-cli
```

安装完成后，可通过 `soup --version` 验证是否安装成功。

### 最小使用示例

1. **准备一个 YAML 配置文件**（假设命名为 `train.yaml`）：

```yaml
model: Qwen/Qwen2.5-1.5B-Instruct
dataset:
  path: ./my_dataset.jsonl
  format: chat          # 或 completion、instruction
train:
  epochs: 3
  batch_size: 2
  learning_rate: 2e-5
output_dir: ./soup_output
```

2. **运行训练命令**：

```bash
soup train --config train.yaml
```

Soup 会自动下载模型权重与分词器，加载本地数据集，并在训练完成后将 LoRA（低秩适配）权重保存至 `./soup_output`。如需对训练好的模型进行推理验证，可运行：

```bash
soup chat --model ./soup_output
```

## 适用场景

- **个人开发者模型定制**：在小显存 GPU 上对开源模型进行领域微调，例如打造个人代码助手、写作辅助工具或特定行业的问答机器人，无需租用昂贵的云 GPU 实例。
- **学术研究快速迭代**：研究人员需要对多个模型或多种超参数进行快速对比实验，Soup 的 YAML 配置和命令行接口能极大提升实验效率，减少环境配置的重复劳动。
- **中小企业垂直场景部署**：在资源有限的情况下，企业 IT 团队可根据私有业务文档微调开源模型，构建内部知识库问答系统或自动化客服机器人，同时避免将敏感数据上传至第三方训练平台。
- **教学与技能习得**：作为学习 LLM 微调原理和工程实践的入门工具，Soup 降低了初学者接触真实训练流程的硬件门槛，可在普通笔记本电脑上完成从数据准备到模型部署的完整闭环。

## 项目亮点

- **极低显存门槛**：Layer Streaming 技术是 Soup 与同类工具（如 Axolotl、LLaMA-Factory）最本质的区别，它将 LLM 微调的硬件准入标准从行业主流的 24 GB+ 显存直接降至 4 GB。
- **零配置痛苦**：无需手动安装 CUDA 相关依赖、无需配置分布式训练环境、无需编写复杂的训练循环脚本，一个 YAML 文件覆盖所有关键设置。
- **功能一体化**：从数据格式识别、模型加载到训练收尾、推理预览，Soup 在一个工具中完成全流程闭环，减少在多个工具间切换的摩擦。
- **迭代活跃、社区驱动**：项目在 GitHub 上拥有近 1700 颗星，近期增长迅速，开发者社区活跃，反馈响应及时，持续集成测试确保版本稳定性。
