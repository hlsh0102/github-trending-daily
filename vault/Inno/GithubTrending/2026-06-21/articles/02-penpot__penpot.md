## 项目概述

Penpot 是一款面向设计与开发协作的开源设计工具，旨在打破设计师与开发者之间的壁垒。它基于 Web 技术构建，无需安装任何本地软件即可在线使用。Penpot 的目标用户包括 UI/UX 设计师、前端开发人员以及需要跨团队协作进行界面设计的产品团队。作为一个被认证为数字公共产品的项目，Penpot 强调开放、免费和社区驱动，致力于为企业与个人提供不依赖商业许可的持久设计解决方案。

## 核心功能

- **跨平台 Web 设计**：Penpot 完全基于浏览器运行，支持 Windows、macOS、Linux 以及 Chromebook 等任何现代浏览器环境，无需安装或配置。
- **SVG 原生支持**：所有设计元素均以标准 SVG 格式存储，生成的矢量图形可直接被开发者提取并嵌入到实际代码中，大幅减少设计到开发的转化误差。
- **设计到代码的无缝衔接**：开发者可以通过浏览器直接查看和复制元素的 CSS 样式、属性及资源，实现了“所见即所得”的代码提取。
- **实时多人协作**：支持多用户在同一项目中同时编辑，实时同步变化，并可通过评论功能进行非即时沟通。
- **组件化与样式系统**：支持创建可复用的组件和全局样式变量，方便维护统一的设计规范，并支持响应式布局设计。
- **自托管部署能力**：作为开源软件，Penpot 允许用户在自己的服务器上部署实例，确保数据完全掌控于自己手中，满足高合规性组织的需求。

## 技术架构

Penpot 采用前后端分离的架构。前端基于 React 构建，利用 WebAssembly 技术优化关键性能路径，实现了在浏览器中高效处理复杂矢量图形的能力。后端服务则使用 Clojure 语言编写，依赖 PostgreSQL 数据库进行数据持久化，并通过 Excalidraw 系统存储和同步操作历史。整体架构强调数据标准化：所有设计产物都以标准 SVG、CSS 等 Web 原生格式保存，而非采用私有二进制格式，这使得设计文件天生具备跨工具和数据迁移的兼容性。此外，Penpot 提供了完善的 RESTful API 以及可被 Git 版本化的导出功能，方便与 CI/CD 流水线或其他工具链集成。

## 安装与使用

**安装方式（以 Docker 部署为例）**：
1. 确保服务器安装了 Docker 和 Docker Compose。
2. 克隆官方仓库并进入目录：
   ```bash
   git clone https://github.com/penpot/penpot.git
   cd penpot/docker
   ```
3. 复制环境配置模板并设置必要参数（如域名、邮箱等）：
   ```bash
   cp config.env.sample config.env
   ```
4. 启动服务：
   ```bash
   docker-compose -p penpot up -d
   ```
5. 访问 `http://<你的服务器IP>:9000`，注册第一个管理员账号即可开始使用。

**最小可用示例**：
1. 登录后创建一个新项目。
2. 在画布里绘制一个矩形，并为其设置圆角、填充色和边框。
3. 点击右侧面板的“查看代码”按钮，直接复制该矩形的 CSS 属性（如 `border-radius: 8px`）。
4. 邀请团队成员加入项目共享编辑权限。

## 适用场景

- **设计与开发协作团队**：当设计师使用 Sketch、Figma 等工具输出设计稿后，开发者常需手动测量尺寸、提取图标或颜色值。Penpot 的实时代码提取功能可直接消除这一鸿沟。
- **对数据主权有严格要求的组织**：金融机构、政府部门或军工企业由于安全合规要求不能使用第三方云服务，可以在内网部署 Penpot，实现私有化设计管理。
- **开源项目与社区贡献**：开源项目需要免费、无限制的协作设计工具来管理 UI 资源，Penpot 完全符合这一需求，且社区贡献者可直接修改设计源文件。
- **教育与培训**：学校或在线课程中可以使用 Penpot 教授 UI/UX 设计基础，学生无需付费即可获得完整的设计体验。

## 项目亮点

与 Figma、Sketch 等同类工具相比，Penpot 具备以下差异化优势：
- **完全开源**：采用 MPL 2.0 许可，没有任何付费墙或使用限制，代码可审计、可修改。
- **无锁定风险**：所有设计数据均以标准 SVG 格式存储，用户随时可以迁移至其他支持 SVG 的工具，而不会损失数据。
- **原生自托管**：在支持 Docker 的环境下，五分钟内即可完成私有化部署，无需处理复杂的许可证问题。
- **零依赖本地安装**：无需安装任何客户端，甚至可以在 Chromebook 或平板电脑的浏览器中直接使用，降低了硬件门槛。
- **社区驱动发展**：活跃的社区 (community.penpot.app) 不仅提供技术支持，还通过 Taiga 平台公开管理项目路线图和 Bug 跟踪，透明度极高。
