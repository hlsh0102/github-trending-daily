## 项目概述

Palmier Pro 是一款为 macOS 构建的开源视频编辑器，其核心理念是“为 AI 而生”。它不仅仅是一个传统的非线性编辑工具，更是一个让人类编辑者与 AI 智能体在同一个时间线上协作创作的平台。该项目由 Y Combinator S24 孵化，使用 Swift 原生语言从零开发，旨在重新定义视频编辑工作流，让生成式 AI 和 AI 智能体成为编辑流程中自然的组成部分。目标用户包括视频创作者、内容制作团队、AI 研究者以及任何希望在视频编辑中高效集成 AI 能力的开发者。

## 核心功能

- **原生 Swift 时间线编辑器**：从零构建的高性能视频时间线编辑引擎，支持多轨道剪辑、转场、关键帧动画等专业级编辑操作，对标行业标准 Premiere Pro 的用户体验。
- **内置生成式 AI 能力**：直接在时间线内调用 Seedance、Kling、Nano Banana Pro 等领先的 AI 视频与图像生成模型，无需切换应用即可完成从生成到编辑的全流程。
- **AI 智能体协作**：通过 MCP（Model Context Protocol）连接 Claude、Codex、Cursor 等外部 AI 代理，或使用内置的智能体与用户在同一项目上协同工作，实现“人机共编”。
- **纯原生 macOS 体验**：针对 Apple Silicon 芯片深度优化，充分利用 macOS 26（Tahoe）的系统特性，确保流畅的编辑与渲染性能。
- **开源与可扩展**：基于 GPL-3.0 许可证开源，允许开发者自由查看、修改和扩展编辑器功能，同时内置 MCP 服务器接口，便于第三方工具集成。
- **简洁直观的界面**：采用现代化 macOS 设计语言，减少操作层级，让创意工作而非工具使用成为焦点。

## 技术架构

Palmier Pro 采用 **纯 Swift 原生技术栈** 构建，不依赖 Electron 或 Web 技术，从而在 macOS 上获得最佳的性能表现和系统集成度。其架构核心在于将 **传统视频编辑引擎** 与 **AI 推理管道** 无缝融合：

- **渲染引擎**：基于 Metal 和 Core Media 框架，实现 GPU 加速的实时预览与渲染，支持多轨道高清视频的流畅播放。
- **AI 集成层**：通过模块化的插件架构，封装不同 AI 模型（如图像生成、视频生成、增强等）的 API 调用和本地推理，使其表现为时间线上可拖拽的“媒体生成器”。
- **MCP 服务器**：内置实现 MCP 协议的服务端，允许外部 AI 智能体（如 Claude 桌面版或自定义代理）通过标准化接口读写项目数据、添加剪辑、调整参数，实现远程协作。
- **项目数据结构**：采用基于文件的项目格式（推测为 JSON 或二进制序列化），支持版本控制和跨工具数据交换。

这种架构的设计思路是：将 AI 能力视为编辑流程的一等公民，而非简单的插件。用户或 AI 智能体可以在时间线的任何位置插入 AI 生成的内容，并像处理常规素材一样进行剪辑、滤镜、关键帧等操作。

## 安装与使用

### 安装
1. 确保你的 Mac 搭载 Apple Silicon 芯片并运行 macOS 26 (Tahoe) 或更高版本。
2. 从 [GitHub Releases 页面](https://github.com/palmier-io/palmier-pro/releases/latest/download/PalmierPro.dmg) 下载最新版 `PalmierPro.dmg`。
3. 打开 DMG 文件，将 Palmier Pro 拖入“应用程序”文件夹。
4. 首次启动时，可能需要允许来自未识别开发者的应用（前往系统设置 > 隐私与安全性 > 仍要打开）。

### 最小可用示例
1. 启动 Palmier Pro，创建一个新项目。
2. 导入一段本地视频文件（支持常见格式如 MP4、MOV）。
3. 将视频拖入时间线轨道。
4. **AI 生成示例**：在时间线空白处右键，选择“AI 生成” > “视频”，在弹出窗口中选择 Seedance 模型并输入“一只在草地上奔跑的猫”，点击生成后，AI 视频片段将自动出现在时间线上。
5. **智能体协作**：若已配置 Claude 或其他 MCP 客户端，可通过应用菜单中的“连接智能体”功能输入你的 API Key，然后在对话中自然语言下达指令，如“将这段视频的亮度提高 20%”或“在第三段后插入 5 秒的 AI 生成星空转场”，智能体将直接操作项目。

## 适用场景

- **独立内容创作者**：快速生成素材、自动完成重复剪辑任务（如智能字幕、自动标记关键帧），将更多精力放在创意构思上。
- **AI 工作流研究者**：在一个统一环境中实验不同视频生成模型的效果，并直接与传统的编辑功能对比，优化“生成+编辑”的混合流程。
- **开发团队与AI Agent 开发者**：通过 MCP 接口测试和调试自己的 AI 代理在不同视频编辑场景下的表现，将 Palmier Pro 作为 Agent 的“沙盒环境”。
- **教学与演示**：在需要同时展示 AI 生成能力和传统剪辑技术的场景中，使用一个工具完成端到端的演示，避免在多个应用间切换。

## 项目亮点

Palmier Pro 与同类项目（如 Premiere Pro + AI 插件、Runway、Captions 等）相比，最核心的差异化优势在于 **“时间线内的原生 AI 协作”**：

1. **真正的开源原生应用**：大多数 AI 视频工具是闭源 SaaS，而 Palmier Pro 提供完整的 Swift 源码和 GPL-3.0 开源许可证，让开发者可以深度定制、审计安全或构建自己的分支。
2. **AI 作为编辑流程的一部分**：不同于简单的“AI 生成视频，然后导入传统编辑器”的分割工作流，Palmier Pro 将 AI 生成、图像增强、智能剪辑等功能直接嵌入时间线轨道操作，用户无需中断编辑状态。
3. **MCP 协议驱动的智能体生态**：通过标准化的 MCP 接口，不仅仅是内置 AI 可以工作，任何支持 MCP 的 AI 智能体（如通用大模型、专业剪辑助手）都可以直接操作项目，形成了开放的协作生态。
4. **纯原生性能**：相较于基于 Web 技术构建的 AI 编辑器，Palmier Pro 在 macOS 上的启动速度、渲染性能和交互响应都有着本质优势，特别适合处理 4K 及以上的高分辨率素材。
