## 项目概述

Twenty 是一款开源客户关系管理（CRM）系统，定位为 Salesforce 的现代化开源替代品。项目从设计之初就融入了 AI 能力，旨在为企业提供灵活、可定制且数据完全可控的 CRM 解决方案。目标用户包括中小型企业、初创团队以及希望摆脱传统 CRM 高昂授权费用和封闭生态的开发团队与技术决策者。通过开放源代码，Twenty 让用户不仅拥有数据的所有权，还能深度定制业务流程，同时利用内置的 AI 功能提升销售与客户管理效率。

## 核心功能

- **现代可视化数据模型**：采用灵活的对象模型设计，用户无需编写代码即可自定义字段、关系与布局，快速构建符合业务需求的客户数据结构。
- **内置 AI 增强**：原生集成 AI 引擎，支持智能记录推荐、自动化摘要生成、相似客户识别等功能，提升数据录入与分析效率。
- **实时协作与活动流**：记录所有客户交互历史，支持团队内部评论与实时动态更新，确保每个客户触点的上下文完整可追溯。
- **高度可扩展的 API**：提供 GraphQL 接口，支持与第三方工具（如邮件、日历、营销平台）的无缝集成，方便构建自动化工作流。
- **自定义仪表盘与报表**：用户可自由组合图表与列表视图，创建个性化的业务分析看板，实时监控销售漏斗、客户活跃度等关键指标。
- **多用户角色与权限管理**：支持细粒度的访问控制，可针对不同团队（销售、支持、管理层）设置字段级与记录级权限。

## 技术架构

Twenty 采用现代全栈 TypeScript 技术栈构建，前端基于 React + Apollo Client，后端使用 Node.js + Apollo Server 提供 GraphQL 服务。数据持久化层采用 PostgreSQL，结合 Redis 实现缓存与实时更新。架构上采用微服务理念，核心逻辑与 AI 推理服务分离，支持独立扩展。项目强类型化的代码组织方式保障了代码的可维护性与可测试性。前端采用模块化组件设计，结合 GraphQL 订阅实现实时数据同步，用户界面流畅且响应迅速。AI 模型部分通过专门的嵌入与推理服务提供，可基于本地数据或可选的外部模型端点运行，兼顾隐私与性能。

## 安装与使用

Twenty 提供了基于 Docker 的一键部署方案，适用于本地开发环境与生产服务器。以下是快速启动步骤：

1. **前提条件**：确保系统已安装 Docker 和 Docker Compose（v2+）。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/twentyhq/twenty.git
   cd twenty
   ```
3. **启动服务**：
   ```bash
   docker compose up -d
   ```
4. **访问系统**：浏览器打开 `http://localhost:3000`，按照引导页面完成管理员账号创建。
5. **最小可用示例**：启动后即可创建客户记录，添加联系人、公司信息，并利用内置的邮件同步功能绑定邮箱，自动归档通信记录。开发模式下支持热重载，便于进行二次开发。

## 适用场景

- **中小型销售团队**：快速部署轻量级 CRM，管理客户线索、商机与合同，无需前期高额投入。
- **SaaS 企业**：作为内部客户管理后台，利用 API 与外部系统（如计费、客服平台）集成，构建统一客户视图。
- **开发者与集成商**：基于开源代码深度定制行业专属 CRM 解决方案，例如针对法律、咨询等垂直领域调整字段与流程。
- **AI 应用开发测试**：利用 Twenty 内置的 AI 接口与结构化客户数据，测试智能推荐、自动化营销等场景的算法效果。

## 项目亮点

Twenty 最显著的差异化优势在于其“开源 + 原生 AI”的双重定位。与 Salesforce 等传统商业 CRM 相比，Twenty 完全开源，用户无需支付高昂许可费即可拥有完整功能，且数据主权完全可控。与同类开源 CRM（如 SuiteCRM、CiviCRM）相比，Twenty 采用现代化技术栈（TypeScript + GraphQL + React），开发体验与 UI 交互更接近当前主流软件标准。此外，AI 功能并非后期插件，而是深度融入数据录入、搜索与推荐等核心流程，降低了用户使用门槛。项目团队保持活跃的社区维护与周迭代节奏，从 GitHub 上的高星数（超 50,000 星）即可印证其受欢迎程度。
