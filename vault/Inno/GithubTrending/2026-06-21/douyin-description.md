🔥 GitHub Trending TOP10 开源日报 | 2025/7/1

1️⃣ Palmier Pro
macOS 原生开源视频编辑器，为 AI 工作流而生。内置 Seedance 等生成式模型，支持时间线内直接生成视频/图像；通过 MCP 协议与 Claude 等 AI 代理协作编辑，Y Combinator 孵化。

2️⃣ Penpot
面向设计师与开发者的开源 UI 设计工具。纯 Web 运行，存储为 SVG 标准格式；支持实时多人协作、CSS 代码直接提取，是 Figma 的开源替代。

3️⃣ OpenMontage
全球首个开源智能体视频制作系统。将 Cursor 等 AI 编码助手变身为完整视频工作室：12 条流水线、52 个工具、500+ 代理技能，从创意到成片全自动。

4️⃣ Turso
进程内 SQL 数据库，完全兼容 SQLite。嵌入式运行、零网络延迟；支持分布式部署与边缘计算，提供 Rust/JS/Python 等多语言绑定，性能极致轻量。

5️⃣ codebase-memory-mcp
高性能代码智能 MCP 服务器。将代码库索引为知识图谱，毫秒级完成普通仓库索引；支持 158 种语言，单个静态二进制文件无依赖分发。

6️⃣ TimesFM by Google Research
时间序列预测基础模型。Decoder-only 架构，支持零样本预测多元时间序列；无需针对特定数据重新训练，适用于金融、气象等场景。

7️⃣ Twenty
开源 CRM 系统，Salesforce 替代品。灵活的数据模型、AI 智能推荐与摘要生成、实时协作活动流；自托管部署，数据完全可控。

8️⃣ Insomnia by Kong
跨平台 API 客户端，支持 GraphQL/REST/WebSockets/gRPC。集调试、设计、测试于一体，提供本地/ Git/云端三种数据管理方式，内置 OpenAPI 编辑器。

9️⃣ Headroom
AI 代理上下文压缩层。可将工具输出、日志等压缩 60-95% token 量，同时保持回答准确性。支持六种压缩算法，以 Python 库或代理方式部署。

🔟 Voicebox
开源 AI 语音工作室。本地运行语音克隆、TTS、语音听写及 AI 智能体对话；完全离线工作，隐私优先，跨平台支持。
