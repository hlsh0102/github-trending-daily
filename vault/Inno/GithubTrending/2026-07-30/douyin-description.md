每天 GitHub Trending TOP10 来了！🔥

1. **opengeos/GeoLibre** 🌐 一个免费开源的云原生 GIS 平台，支持在 Web、桌面、移动端甚至 Jupyter notebook 中跑，数据全在本地，隐私很靠谱。适合搞地理信息的朋友。

2. **moeru-ai/airi** 💖🧸 自托管 AI 伴侣框架，支持实时语音对话，还能在《我的世界》和《异星工厂》里自主操作。灵感来自 Neuro-sama，跨平台，可高度定制。

3. **affaan-m/ECC** 🧠 专为AI编码助手设计的性能优化系统。通过技能、直觉、记忆和安全模块，帮 Claude Code、Cursor 等工具表现更好。开发者必备。

4. **huggingface/speech-to-speech** 🎤🔥 Hugging Face 官方的低延迟语音智能体管道。模块化设计，VAD→STT→LLM→TTS 全流程替换，兼容 OpenAI Realtime API。适合构建本地语音助手。

5. **1jehuang/jcode** 🦀 用 Rust 写的极致内存优化代理框架。多会话工作流下省内存到惊人，适合资源敏感的开发场景。原生支持 macOS、Linux、Windows。

6. **grokability/snipe-it** 📦 老牌开源 IT 资产管理系统，基于 Laravel。管理硬件和软件许可证，支持生命周期追踪、报告与审计。IT 运维人的好帮手。

7. **deepfakes/faceswap** 🧬 人脸交换的经典开源工具。完整训练推理流程，多种模型可选。做计算机视觉实验和创意视频的好选择。

8. **microsoft/VibeVoice** 🗣️ 微软开源的前沿语音 AI，统一 ASR 和 TTS。异构量化后模型 1.58 GB，边缘 CPU 可实时跑。语音技术普及利器。

9. **different-ai/openwork** 🛠️ 开源的 AI 工作流共享桌面应用。MCP 技能和配置可跨 AI 代理复用，支持团队统一管理。是 Claude Cowork 和 Codex 的开源替代。

10. **obra/superpowers** ⚡ 一套给编程代理的完整软件开发方法论。要求先明确规格、再生成实现计划，最后由子代理协作…
