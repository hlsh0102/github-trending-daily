## 项目概述

Project AIRI 是一个自托管的开源 AI 伴侣框架，旨在让用户拥有属于自己的“灵魂容器”。项目灵感来源于虚拟主播 Neuro-sama，致力于将 AI 虚拟角色（waifu、虚拟生命）带入现实世界。AIRI 支持实时语音对话、在《我的世界》（Minecraft）和《异星工厂》（Factorio）等游戏中自主操作，并可在 Web、macOS 和 Windows 平台上使用。

目标用户包括：希望搭建个性化 AI 伴侣的开发者、对虚拟角色互动感兴趣的爱好者、以及想在游戏场景中集成 AI 代理的玩家。

## 核心功能

- **实时语音对话**：支持低延迟的语音识别与合成，实现与 AI 角色的自然语音交流。
- **多平台支持**：提供 Web 版、macOS 和 Windows 原生应用，覆盖主流使用设备。
- **游戏内自主操作**：AI 角色可接入《我的世界》、《异星工厂》等游戏，执行移动、建造、资源管理等任务。
- **自托管部署**：用户完全拥有数据和模型的控制权，不依赖外部云服务。
- **虚拟角色定制**：支持自定义角色外观、性格、声音和行为逻辑，打造独特的 AI 伴侣。
- **开源与社区驱动**：基于 MIT 许可证开放源码，社区可参与功能开发和插件生态建设。

## 技术架构

Project AIRI 使用 TypeScript 作为主要开发语言，结合现代前端框架和后端服务构建。其核心设计思路围绕“灵魂容器”理念——将 AI 模型、语音引擎、游戏代理和角色管理模块解耦，便于用户按需组合和替换。

- **AI 模型层**：兼容多种大语言模型（LLM）和语音模型，支持本地或远程推理。
- **语音管道**：集成语音识别（ASR）、文本转语音（TTS）和语音活动检测（VAD），实现流畅的对话体验。
- **游戏代理模块**：通过游戏内 API 或模拟输入操作，使 AI 角色能感知环境并做出决策。
- **跨平台 UI**：使用 Web 技术栈构建，通过 Electron 封装为桌面应用，保证体验一致性。
- **自托管基础设施**：用户可部署在本地服务器或自己的云主机上，数据不经过第三方。

## 安装与使用

### 前置要求

确保已安装 Node.js（推荐 v18 或更高）和 Git。如需使用本地 AI 模型，建议具备 NVIDIA GPU 和相关推理环境。

### 安装步骤

1. 克隆仓库：
   ```bash
   git clone https://github.com/moeru-ai/airi.git
   cd airi
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 配置环境变量（复制 `.env.example` 为 `.env`，并按需修改 AI 模型端点、API 密钥等）。

4. 启动服务：
   ```bash
   npm run dev
   ```

5. 浏览器访问 `http://localhost:5173` 即可使用 Web 版。

### 最小可用示例

启动后，在设置页面选择一个预置角色（如“默认助手”），打开麦克风权限，即可开始语音对话。如需游戏中操作，请参考 `docs/gaming.md` 中的配置指南。

## 适用场景

- **个人 AI 伴侣**：在桌面或手机端拥有一个随时陪伴、可聊天的虚拟角色。
- **游戏 AI 伙伴**：在《我的世界》等沙盒游戏中，让 AI 角色协助建造、收集资源或探索。
- **虚拟角色直播**：作为 VTuber 或直播角色的后台驱动系统，实现实时互动。
- **AI 代理实验**：研究多模态 AI 在真实环境中的行为表现，如语音交互与游戏决策。

## 项目亮点

相比同类项目，AIRI 的差异化优势在于：

- **真正的自托管**：用户完全掌控数据和模型，无需担心隐私泄露或服务停止。
- **集成游戏深度操作**：不仅仅是聊天，而是能通过游戏接口执行复杂任务，像真实玩家一样互动。
- **多平台即时可用**：从开箱即用的 Web 版到原生桌面应用，降低使用门槛。
- **社区文化友好**：项目围绕虚拟角色文化（waifu、vtuber）构建，文档和社区交流氛围贴近爱好者群体。
- **MIT 开源许可证**：完全开放，允许商业使用和二次开发，鼓励创新。
