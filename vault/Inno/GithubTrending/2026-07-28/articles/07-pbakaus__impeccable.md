## 项目概述

Impeccable 是一个面向 AI 编程助手的前端设计指导工具。它解决了当前 AI 生成前端界面时普遍存在的设计同质化问题——无论使用何种模型，最终产出的 UI 往往充斥着千篇一律的 Inter 字体、紫蓝渐变、嵌套卡片和灰色文字。该项目为 AI 编码代理提供了一套结构化的设计语言，包含 1 个核心技能、23 个设计命令、实时浏览器迭代能力以及 60 条确定性检测规则。目标用户是所有使用 Claude、Cursor、Copilot 等 AI 编码工具进行前端开发的工程师和设计师，希望提升 AI 生成界面的设计质量与品牌一致性。

## 核心功能

- **一键初始化流程**：运行 `/impeccable init` 即可自动创建 `PRODUCT.md` 文件，并可选生成 `DESIGN.md`，让 AI 了解项目的受众、品牌定位、语调风格、色彩体系、排版规范和组件库。
- **23 个设计命令**：提供一套共享的设计词汇表，包括 `polish`（打磨）、`audit`（审计）、`critique`（批评）、`distill`（提炼）、`animate`（动画）、`bolder`（加强）、`quieter`（减弱）等，让开发者能以统一语言指挥 AI 进行设计调整。
- **60 条确定性检测规则**：包含一套可执行的前端设计质量检查规则，覆盖色彩对比、排版一致性、间距节奏、交互可用性等方面。这些规则可通过 CLI 或浏览器扩展运行，无需 LLM 或 API 密钥。
- **实时浏览器迭代**：支持在浏览器中直接运行检测规则，提供即时设计反馈，帮助开发者在开发过程中持续保持设计质量。
- **LLM 辅助审查**：在确定性规则之外，还提供基于大语言模型的批评式审查，针对设计中的主观审美问题给出建议。
- **产品上下文注入**：通过 `PRODUCT.md` 和 `DESIGN.md` 文件，将项目的品牌、目标用户、设计参考等信息持续注入到 AI 对话上下文中，确保每次生成的界面都符合整体设计方向。

## 技术架构

Impeccable 采用分层架构设计。底层是一套用 JavaScript 编写的 CLI 工具和浏览器扩展，负责执行 60 条确定性设计检测规则。这些规则是纯功能性的，不依赖任何外部 API 或模型，可以在本地环境中快速运行。上层是 AI 技能层，通过一个 `impeccable` 命令挂载到 Claude、Cursor 等 AI 编码工具中，用于指导 AI 生成符合设计系统的代码。中间层是上下文管理机制，通过 `PRODUCT.md` 和 `DESIGN.md` 文件持久化项目的设计偏好，使得不同会话间的设计风格保持一致。整个项目采用 Apache-2.0 许可证，支持按需安装，不强制绑定任何特定 AI 服务。

## 安装与使用

### 安装

在项目根目录下运行以下命令进行安装：

```bash
npx impeccable install
```

该命令会将 Impeccable 的核心文件复制到项目中，并创建必要的配置文件。

### 初始化

在 AI 编码工具中（如 Claude 或 Cursor），运行以下命令开始配置：

```
/impeccable init
```

此命令会引导你创建 `PRODUCT.md` 文件（必需）和 `DESIGN.md` 文件（可选）。`PRODUCT.md` 用于描述产品的目标用户、品牌定位和核心价值；`DESIGN.md` 则记录色彩系统、排版规范、组件库等设计细节。

### 基本使用

初始化完成后，可以在 AI 编码工具中使用 23 个设计命令。例如：

```
/impeccable polish 当前页面
```

这会让 AI 对当前页面进行设计打磨，应用之前配置的设计规范。其他常用命令包括：

- `/impeccable audit 页面` — 运行设计审计
- `/impeccable critique 组件` — 进行批评式审查
- `/impeccable animate 按钮` — 为指定元素添加合适动画
- `/impeccable bolder 标题` — 增强标题的视觉权重

## 适用场景

- **统一团队设计语言**：团队使用 AI 编码工具时，通过 Impeccable 确保所有成员生成的界面都遵循相同的设计规范，避免风格不一致。
- **快速原型迭代**：设计师或开发者可以用 `polish`、`distill` 等命令快速调整 AI 生成的原型设计，无需手动修改每个细节。
- **设计质量检查**：在代码提交前运行 `audit` 命令，自动检测界面中的设计问题，如色彩对比不足、排版混乱、间距不一致等。
- **品牌一致性维护**：长期项目可以通过 `PRODUCT.md` 和 `DESIGN.md` 持续注入品牌信息，让 AI 始终生成符合品牌调性的界面。

## 项目亮点

Impeccable 与同类项目相比具有三大差异化优势。首先，它提供了 60 条无需 LLM 的确定性检测规则，这些规则可以离线运行，不受模型可用性或 API 限速的影响，适合集成到 CI/CD 流程中。其次，它的上下文管理机制通过文件持久化而非对话记录来维护设计规范，使得跨会话的一致性更强，不会因为 AI 的上下文窗口限制而丢失设计信息。最后，23 个设计命令为人和 AI 之间建立了一套标准化的设计沟通语言，减少了因表述模糊导致的设计偏差。项目本身基于 Anthropic 的 `frontend-design` 技能发展而来，继承了其最佳实践并围绕在实际开发中遇到的常见设计问题进行了大量扩展。
