## 项目概述

MediaCrawler 是一个功能强大的多平台自媒体数据采集工具，专注于从小红书、抖音、快手、B站、微博、百度贴吧、知乎等主流中文社交媒体平台抓取公开的帖子、视频、评论等数据。该项目由 NanmiCoder 发起并维护，在 GitHub 上已获得超过 5.8 万星标。

该项目主要解决了以下问题：研究者和数据分析人员需要批量获取社交媒体平台公开内容以进行舆情分析、市场调研、内容监控等工作，但手动收集效率低下且缺乏标准化工具。MediaCrawler 提供了一套统一的、可配置的爬虫框架，帮助用户高效、稳定地采集目标数据。目标用户包括数据科学家、市场分析师、内容创作者、学术研究人员以及对社交媒体数据感兴趣的开发者。

## 核心功能

- **多平台覆盖**：支持小红书（笔记、评论）、抖音（视频、评论）、快手（视频、评论）、B站（视频、评论）、微博（帖子、评论）、百度贴吧（帖子、评论回复）、知乎（问答文章、评论）等 7 个主流平台。
- **数据获取全面**：针对每个平台，不仅支持抓取主内容（帖子、视频、笔记等），还支持抓取对应的评论数据，满足完整的社交互动分析需求。
- **基于 Playwright 的高效爬取**：底层采用 Playwright 自动化框架，模拟真实浏览器行为，有效应对反爬机制，提升数据获取成功率。
- **配置化抓取**：支持通过配置文件指定目标关键词、平台、时间范围等参数，无需修改代码即可启动不同抓取任务。
- **数据持久化**：支持将抓取结果保存为 JSON、CSV 等常见格式，便于后续分析和处理。
- **异常处理与重试机制**：内置网络错误、页面加载失败等异常处理逻辑，自动重试，保障抓取任务的稳定性。

## 技术架构

MediaCrawler 采用模块化设计，核心基于以下技术栈构建：

- **编程语言**：Python 3.8+，充分利用其丰富的生态和异步 I/O 能力。
- **自动化浏览器框架**：Playwright，支持 Chromium、Firefox、WebKit 多种浏览器，能够模拟人类浏览行为，处理动态加载内容。
- **异步并发**：利用 asyncio 和 aiohttp 实现并发请求，提升抓取效率。
- **配置管理**：通过 YAML 或 JSON 配置文件管理抓取参数，包括平台选择、搜索关键词、保存路径等。
- **数据存储**：内置 CSV 和 JSON 写入器，用户也可扩展为数据库存储。

架构上遵循关注点分离原则：每个平台对应一个独立的爬虫模块（如 `CrawlerPlatformWeibo`、`CrawlerPlatformXiaohongshu`），共享基础框架（请求管理、浏览器实例管理、数据格式化）。这种设计使得添加新平台或修复某个平台的问题时不会影响其他模块。

## 安装与使用

**前提条件**：
- 安装 Python 3.8 或更高版本
- 安装 Playwright 浏览器驱动：`playwright install`

**安装步骤**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/NanmiCoder/MediaCrawler.git
   cd MediaCrawler
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

3. 配置抓取任务：编辑 `config/config.yaml` 文件，设置目标平台、搜索关键词、抓取数量等参数。

**最小可用示例**（以微博为例）：

配置文件 `config/config.yaml` 样例如下：
```yaml
platform: weibo
keyword: "人工智能"
max_count: 100
save_type: csv
```

启动抓取：
```bash
python main.py
```

程序会自动打开浏览器，根据配置的关键词搜索微博，抓取帖子内容和评论，并保存至 `output/weibo_人工智能_20240101.csv`。

## 适用场景

- **社交媒体舆情监控**：持续跟踪特定话题或品牌在不同平台上的讨论热度、情感倾向和关键意见领袖发言。
- **竞品分析与市场调研**：采集竞争对手在多个平台上的内容发布策略、用户反馈和互动数据，辅助商业决策。
- **学术研究与数据分析**：获取社交媒体公开数据进行社会学、传播学、自然语言处理等领域的定量研究。
- **内容创作素材收集**：为自媒体运营者、视频创作者提供参考素材，了解热门话题和用户兴趣点。

## 项目亮点

- **一站式多平台覆盖**：相比其他仅支持单个平台的爬虫工具，MediaCrawler 将 7 个主流中文社交媒体整合到同一框架下，降低多数据源采集的集成成本。
- **开箱即用**：配置驱动，用户无需深入理解爬虫技术细节，通过简单配置即可启动抓取任务，降低使用门槛。
- **社区活跃**：拥有超过 5.8 万星标，问题反馈和 Pull Request 响应迅速，持续更新适配各平台反爬策略变化。
- **技术透明且可扩展**：基于 Playwright 的抓取逻辑清晰，代码注释完整，开发者可轻松修改或扩展新平台支持。
- **强调合法合规**：项目在 README 中明确强调仅用于学习和研究目的，并附有免责声明，引导用户遵守法律法规。
