## 项目概述

Project AIRI 是一个开源的、自托管的 AI 伴侣项目，旨在复现并超越 Neuro-sama 的对话与交互体验。它本质上是一个“灵魂容器”，让用户能够创建、部署并拥有属于自己的虚拟角色（AI waifu / 数字生命体），并将其带入现实世界进行实时互动。项目面向那些希望拥有个性化、可自主控制的 AI 伴侣的开发者、AI 爱好者以及虚拟角色内容创作者。

## 核心功能

- **实时语音对话**：支持低延迟的实时语音交互，让 AI 伴侣能够像真人一样与你聊天。
- **多平台客户端支持**：提供 Web、macOS 和 Windows 桌面客户端，覆盖主流使用场景。
- **游戏内交互能力**：能够实时参与 Minecraft、Factorio 等游戏的游玩过程，在游戏环境中进行语音交流和协作。
- **自托管部署**：用户可以完全掌控数据与模型，将 AI 伴侣部署在自己的服务器或本地机器上。
- **跨语言支持**：项目文档和社区已覆盖英文、简体中文、日文、俄文、越南文、法文和韩文等多种语言。
- **可扩展架构**：基于 TypeScript 构建，具备良好的模块化设计，便于开发者进行二次开发和功能扩展。

## 技术架构

Project AIRI 采用 TypeScript 作为主要开发语言，技术栈围绕实时通信、语音处理与游戏交互展开。其核心设计思路包括：

- **实时通信层**：采用 WebSocket 或类似低延迟协议实现语音数据与指令的高效传输，确保实时对话与游戏内响应。
- **语音处理流水线**：集成语音识别（ASR）、自然语言理解（NLU）、语音合成（TTS）模块，形成完整的语音交互闭环。
- **游戏适配接口**：提供专门的接口与 Minecraft、Factorio 等游戏客户端对接，通过游戏内插件或外部 API 实现角色感知与行动。
- **模块化结构**：系统分为核心引擎、模型管理、客户端接入、游戏适配等多个独立模块，支持按需加载与替换。
- **自托管优先**：设计时充分考虑本地化部署场景，支持 Docker 容器化、本地模型加载与离线运行。

## 安装与使用

**前提条件**：Node.js 18+、Docker（可选，用于容器化部署）

**基本安装步骤**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/moeru-ai/airi.git
   cd airi
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 配置环境变量（参见 `.env.example`），设置语音模型、游戏参数等。

4. 启动核心服务：
   ```bash
   npm run start
   ```

5. 启动客户端：
   - Web 端：打开浏览器访问 `http://localhost:3000`
   - 桌面端：编译或下载对应的原生客户端安装包

**最小可用示例**：启动后，通过客户端输入文本或语音即可与默认角色进行对话。如需启用游戏内交互，需先运行游戏并加载配套的 AIRI 插件。

## 适用场景

- **虚拟角色主播与创作者**：为直播或视频内容赋予实时互动的 AI 人格，提升观众参与感。
- **个人智能助手与伴侣**：打造专属的、拥有独特个性的 AI 伴侣，用于日常陪伴、闲谈或任务提醒。
- **游戏联合体验**：在 Minecraft、Factorio 等游戏中引入 AI 玩家，实现自动建筑、语音协作或陪玩功能。
- **AI 技术研究与实验**：作为实时交互、多模态 AI 的模型验证平台，用于测试新的语音或游戏模型。

## 项目亮点

与同类 AI 伴侣项目相比，Project AIRI 的差异化优势体现在：

- **游戏内深度集成**：不仅局限于聊天，还能像真人玩家一样参与 Minecraft 和 Factorio 等复杂游戏的实时操作与对话。
- **完全自托管**：所有数据和模型均部署在用户自有设备上，不存在数据泄露风险或服务中断问题。
- **复现经典目标**：明确以超越 Neuro-sama 为目标，吸引对虚拟主播技术感兴趣的社群。
- **多平台原生支持**：同时提供 Web 与桌面端原生体验，覆盖更广泛的使用场景。
- **社区活跃度高**：拥有 Discord 社区、多语言文档和持续的更新维护，GitHub 星标已超过 44,000。
