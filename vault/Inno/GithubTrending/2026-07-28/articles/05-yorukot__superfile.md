## 项目概述

superfile 是一个面向终端用户的现代化文件管理器，旨在提供美观且功能强大的命令行文件管理体验。该项目由社区驱动开发，使用 Go 语言编写，支持 macOS、Linux 和 Windows 三大主流操作系统。与传统的终端文件管理器（如 ranger、lf、nnn）相比，superfile 更注重视觉设计和用户体验，同时保持了轻量级和高效的核心特性。

## 核心功能

- **双面板文件浏览**：主界面默认采用左右双面板设计，用户可以在两个目录之间快速切换和操作文件，提高管理效率。
- **预览面板**：支持对文本文件、图片、PDF 等常见格式进行快速预览，无需打开独立编辑器。
- **快捷键驱动操作**：提供丰富的键盘快捷键，覆盖文件复制、移动、重命名、删除、搜索、过滤等几乎所有文件操作。
- **主题系统**：内置多套主题并支持自定义配色方案，允许用户根据个人偏好定制终端界面外观。
- **插件扩展机制**：通过插件系统支持额外功能，如集成 fzf 模糊搜索、zoxide 路径跳转等工具。
- **多平台支持**：通过统一的二进制分发形式，在 macOS（Intel/Apple Silicon）、Linux（amd64/arm64）和 Windows 上提供一致的使用体验。

## 技术架构

superfile 使用 Go 语言构建，充分利用了 Go 的跨平台编译特性和高性能并发模型。其核心架构围绕终端用户界面（TUI）设计，依赖于以下几个关键技术：

- **tview/tcell 库**：用于构建基于文本的用户界面，支持丰富的颜色、键盘事件处理和面板布局管理。
- **异步文件操作**：文件系统操作（如复制大文件、递归删除）在后台 goroutine 中执行，避免阻塞用户界面响应。
- **插件系统**：通过执行外部命令或加载预定义的脚本模块，实现功能扩展，保持核心代码简洁。
- **热键映射层**：提供可配置的键盘映射表，用户可以通过配置文件自定义快捷键行为。
- **主题配置文件**：采用 YAML 格式的配置文件管理主题和用户设置，易于编辑和分享。

设计上，superfile 遵循模块化原则，将文件浏览、预览、搜索、批量操作等功能分成独立的组件，便于维护和增强。

## 安装与使用

**安装方式（推荐使用包管理器）**：

**macOS/Linux (使用 Homebrew/Linuxbrew)**
```bash
brew install superfile
```

**Windows (使用 Scoop)**
```bash
scoop bucket add extras
scoop install superfile
```

**手动安装（通用）**
- 从 [GitHub Releases 页面](https://github.com/yorukot/superfile/releases) 下载对应操作系统和架构的压缩包。
- 解压后将二进制文件放入系统 `PATH` 目录（如 `/usr/local/bin` 或 `C:\Windows\System32`）。

**启动和使用**

```bash
# 启动 superfile，默认进入当前目录
spf

# 指定启动目录
spf /path/to/directory

# 查看帮助信息
spf --help
```

进入界面后，可以通过方向键或 `Tab` 在面板间切换，使用 `Enter` 进入目录或打开文件，`h`/`l` 键用于在布局间切换，`?` 键调出完整快捷键帮助菜单。

## 适用场景

1. **日常文件管理**：对于习惯在终端操作的用户，superfile 提供了比纯命令行更直观的文件浏览和组织体验，适合快速浏览目录结构、批量重命名文件。
2. **开发工作流集成**：开发者可以在代码编辑器中直接调用 superfile 打开项目目录，或在终端中将其设置为默认文件管理器，与 Git、Lint 等工具配合使用。
3. **远程服务器管理**：通过 SSH 连接到服务器后，superfile 可以作为轻量级的远程文件管理工具，无需图形化桌面环境即可完成文件操作。
4. **学习与演示**：其清晰的代码结构和丰富的主题系统，适合作为学习 Go 语言 TUI 开发或终端工具设计的参考项目。

## 项目亮点

- **高颜值终端界面**：superfile 在保持终端效率的同时，通过精心的排版、色彩搭配和动画效果，提供了接近桌面应用的视觉体验，打破了终端工具“简陋”的刻板印象。
- **跨平台一致性**：在 Windows、macOS 和 Linux 上提供几乎一致的外观和快捷键体验，解决了不同平台间文件管理器行为差异的问题。
- **社区驱动且活跃**：项目在 GitHub 上有超过 2 万颗星标，社区活跃度高，问题响应及时，插件和主题生态持续增长。
- **轻量且高性能**：基于 Go 编译的单一二进制文件，无外部依赖，内存占用低，启动速度快，即使处理包含数千文件的目录也能保持流畅。
