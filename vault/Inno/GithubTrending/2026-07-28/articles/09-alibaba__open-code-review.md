## 项目概述

OpenCodeReview 是阿里巴巴开源的一款免费代码审查工具。它采用混合架构，将确定性管道与 LLM Agent 相结合，在阿里巴巴内部经过大规模实际业务场景的验证。项目目标是为开发者和技术团队提供一款高效、精准且易于集成的代码审查方案，能够自动检测 NPE（空指针异常）、线程安全、XSS（跨站脚本攻击）、SQL 注入等常见代码缺陷。主要面向需要提升代码质量、加速审查流程的软件工程师、技术主管以及各类规模的开发团队。

## 核心功能

- **确定性管道与 LLM Agent 混合审查**：结合传统的静态分析规则和基于大语言模型的智能分析能力，既能确保规则层面的准确覆盖，又能利用 AI 理解代码上下文和潜在逻辑问题。
- **精准的行级注释**：审查结果直接关联到具体代码行，生成精确的注释，减少开发者阅读审查报告时的认知负担，提高问题定位与修复效率。
- **内置精调规则集**：预置针对 NPE、线程安全、XSS、SQL 注入等高危缺陷的检测规则，这些规则经过阿里巴巴内部海量代码的验证和优化，可直接开箱使用。
- **支持 OpenAI 与 Anthropic 兼容模型**：集成多种主流大语言模型的 API，用户可以根据成本、隐私和性能需求灵活选择底层模型，无需绑定单一 AI 服务。
- **免费开源**：基于 Apache-2.0 许可证，完全开放源代码，用户可自行部署、修改和扩展功能，无使用上限或商业限制。

## 技术架构

OpenCodeReview 采用混合架构设计，主要由以下两层构成：

1. **确定性管道层**：处理规则明确、无需理解的检测任务。该层通过内置的精调规则集（如 NPE、SQL 注入模式匹配）和传统静态分析方法，快速扫描代码并提供可靠的检测结果。这一步骤保证了基础质量门的稳定性，即便 AI 组件因故障不可用，仍能提供基本审查能力。

2. **LLM Agent 层**：负责需要语义理解和上下文推理的复杂任务。面向代码中的业务逻辑模糊点、潜在设计缺陷和跨函数调用链的风险，LLM Agent 使用用户配置的 AI 模型（如 OpenAI 的 GPT 系列或 Anthropic 的 Claude）分析代码差异，生成类似人工审查员的建议和问题描述。Agent 的输出与确定性管道的结果合并，形成最终的行级注释。

项目后端使用 Go 语言开发，保证了高性能和低资源消耗。插件机制（npm 包 `@alibaba-group/open-code-review`）使其易于集成到 CI/CD 流程和代码托管平台中。整体设计注重模块化，用户可以独立替换 AI 模型或自定义规则集，而无需修改核心逻辑。

## 安装与使用

OpenCodeReview 提供多种安装方式，以下为常见的 npm 集成步骤（假设已有 Node.js 环境）：

1. 在代码仓库根目录安装插件：
   ```bash
   npm install @alibaba-group/open-code-review --save-dev
   ```

2. 在 CI 配置文件（如 GitHub Actions 的 `.yml`）中添加步骤：
   ```yaml
   - name: Run OpenCodeReview
     run: npx @alibaba-group/open-code-review
     env:
       OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
       # 或 ANTHROPIC_API_KEY
       GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   ```

3. 执行审查后会收到包含行级注释的分析报告。也可通过命令行直接运行：
   ```bash
   npx @alibaba-group/open-code-review --target-branch main
   ```

最小可用示例仅需配置 AI 密钥和 GitHub Token，插件会自动识别当前 PR 或代码更改并执行审查。详细配置选项（如自定义规则集、排除路径等）可参考项目文档。

## 适用场景

- **代码拉取请求（PR）审查自动化**：集成到 GitHub、GitLab 等平台的 CI 流程，在每次 PR 提交时自动执行代码审查，减少人工 review 的重复工作，加快合入速度。
- **高危缺陷批量检测**：使用内置规则集在大型代码仓库中批量扫描 NPE、XSS、SQL 注入等安全与稳定性风险，特别适合在发布前或代码迁移阶段快速排查问题。
- **跨团队代码质量统一管控**：作为团队共用的代码审查标准，覆盖不同部门或项目的代码，降低因开发者经验差异导致的质量风险，确保输出一致。
- **AI 辅助人工审查**：在人工审查过程中，OpenCodeReview 提供第一轮的问题列表，审查者只需验证结果并关注 AI 遗漏的深层设计问题，从而提升整体效率。

## 项目亮点

与同类工具（如 SonarQube、CodeQL 或纯 LLM 审查方案）相比，OpenCodeReview 的核心差异化优势在于：

- **混合架构的实用性**：不像传统静态分析工具只能检测模式化问题，也不像纯 LLM 审查那样结果不稳定且成本高。OpenCodeReview 的确定性管道保证了基础检测的零误报，LLM Agent 则填补了语义理解空白，二者互补形成更全面的覆盖。
- **大规模生产环境验证**：源自阿里巴巴内部使用，经过海量代码和真实业务场景的检验。内置规则集直接提取自企业的实际经验，比其他开源工具的预置规则更具针对性。
- **轻量级与低耦合**：以 npm 插件形式提供，安装仅需数分钟，不依赖单独的服务端部署，非常适合中小型团队快速上手。同时支持主流 AI 模型，用户无需搭建或管理私有模型即可获得智能分析能力。
- **完全免费的开源许可**：与许多商业审查工具（尤其是提供类似 AI 能力的 SaaS 产品）不同，OpenCodeReview 的源代码和功能对所有人免费开放，不存在用户数、代码行数或调用次数的限制。
