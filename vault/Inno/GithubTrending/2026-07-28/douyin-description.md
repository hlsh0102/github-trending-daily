🔝 GitHub 今日热榜 Top10 来了，一起围观今日开源亮点！

1️⃣ bitchat：完全去中心的蓝牙Mesh聊天工具 🔵  
无账户、无服务器，离线也能聊，有IRClike体验。

2️⃣ amnezia-client：自托管VPN客户端 🛡️  
跨平台开源，支持一键部署服务器+多协议+混淆，隐私优先。

3️⃣ airi：自托管AI伴侣 🤖  
实时语音对话、能打Minecraft、Factorio，支持多端，可自由定制角色。

4️⃣ GeoLibre：云原生GIS平台 🌍  
轻量跨平台（Web/桌面/移动/Jupyter），支持多格式地理数据可视化。

5️⃣ superfile：时髦终端文件管理器 🖥️  
双面板+预览+快捷键+主题系统，Go编写，Linux/macOS/Windows通用。

6️⃣ MediaCrawler：多平台自媒体爬虫 🕸️  
爬小红书、B站、抖音等7平台帖子/评论，Playwright驱动，适合研究和数据分析。

7️⃣ impeccable：AI前端设计语言工具 🎨  
7领域参考+23设计命令+27反模式规则，让Claude/Cursor生成更专业UI。

8️⃣ Kronos：金融语言模型 📈  
理解市场“语言”，支持趋势预测、信号生成、多模态输入，可微调。

9️⃣ open-code-review：阿里开源代码审查工具 🔍  
混合架构，传统规则+LLM，精准行级注释，内置NPE/XSS/SQL注入检测。

🔟 jenkins：经典CI/CD自动化服务器 ⚙️  
2000+插件，持续集成/交付，分布式构建，流水线即代码。
