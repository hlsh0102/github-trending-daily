## 项目概述

Harness 是一个面向 Claude Code 的团队架构工厂（Team-Architecture Factory），它本质上是一种“元技能”（meta-skill）。当用户对 Claude Code 说出“为这个项目构建一个 harness”时，Harness 会自动分析当前项目的领域特征，设计出专属的领域智能体团队，定义每个智能体的专业角色，并生成它们执行任务所需的技能。项目解决了智能体协作中“从零开始定义团队和技能”的重复性劳动问题。目标用户是使用 Claude Code 进行复杂项目开发的开发者、架构师和技术团队，尤其是那些需要管理多领域、多模块协作场景的团队。

## 核心功能

- **领域智能体团队自动设计**：根据项目上下文自动识别领域边界，设计由多个专业智能体组成的协作团队，每个智能体承担独立的职责范围。
- **智能体角色定义**：为每个生成的智能体赋予明确的职业角色（如代码审查员、文档工程师、测试架构师等），并配置其行为准则和交互协议。
- **技能自动生成**：为每个智能体生成其在团队中执行任务所需的专业技能，技能文件可直接被 Claude Code 加载和使用。
- **多语言自然语言触发**：支持英语、韩语、日语三种语言的自然语言指令启动，用户只需说出“build a harness”或对应的韩语/日语短语即可。
- **即插即用集成**：作为 Claude Code 的插件，无需额外基础设施，安装后即可在对话中激活 Harness 的元技能。
- **六种架构模式支持**：内置 6 种团队架构设计模式，可根据项目复杂度自动匹配最合适的模式。

## 技术架构

Harness 位于“元工厂层（L3 Meta-Factory）”下的“团队架构工厂（Team-Architecture Factory）”子层。其核心设计思路基于元编程（meta-programming）思想：Harness 本身不直接解决具体业务问题，而是生成解决业务问题的智能体团队和技能。技术实现上，Harness 利用 Claude Code 的插件系统作为运行载体，通过预定义的架构模式模板和技能生成框架，将项目的领域描述转化为结构化的智能体定义文件（如 JSON 或 YAML 格式）和技能文件（Markdown 或类似格式）。项目体现了“智能体即配置”和“架构即代码”的理念，每个生成的团队都可以独立演进和复用。

## 安装与使用

**安装步骤：**
1. 确保已安装 Claude Code 并具备插件扩展能力。
2. 将 Harness 插件安装到 Claude Code 的插件目录中。
3. 重启 Claude Code 以加载插件。

**最小可用示例：**
1. 在 Claude Code 的对话界面中，打开一个已有的项目目录。
2. 输入指令：“build a harness for this project”（英文）或“하네스 구성해줘”（韩文）或“ハーネスを構成して”（日文）。
3. Claude Code 将自动分析项目结构，输出一个包含智能体团队定义和技能文件的“harness”目录。
4. 用户可直接使用生成的团队和技能进行后续开发任务。

## 适用场景

- **多模块大型项目**：当项目包含前端、后端、数据库、API 等多个模块时，Harness 可生成对应领域的智能体团队，实现分工协作和上下文隔离。
- **团队级代码审查与重构**：生成专门的代码审查智能体和重构技能，辅助团队在代码质量检查、技术债务清理等任务中保持一致性。
- **创业项目快速原型**：在项目初期快速搭建智能体协作框架，让开发和测试任务可以并行推进，缩短验证周期。
- **教学与知识传承**：将项目的最佳实践和领域知识编码为智能体技能，方便新成员快速上手并遵循团队规范。

## 项目亮点

与同类项目相比，Harness 的差异化优势在于：
- **元技能而非技能本身**：传统插件提供的是固定功能，Harness 提供的是“生成功能的能力”，适应不同项目的动态需求。
- **多语言自然语言接口**：支持三种语言的一句话触发，降低了工具的使用门槛，无需记忆复杂命令。
- **即用即弃的轻量哲学**：生成的团队和技能文件是静态的，用户可以随时丢弃或重新生成，不影响项目基础结构。
- **与 Claude Code 深度集成**：直接利用已有生态，无需额外运行时或基础设施，安装即用。
- **架构模式选择智能**：6 种内置模式覆盖从简单到复杂的团队规模，系统自动匹配最合适的模式。
