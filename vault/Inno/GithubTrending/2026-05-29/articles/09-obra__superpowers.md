## 项目概述

Superpowers 是一套为编码代理（coding agents）设计的完整软件开发方法论，它建立在一组可组合的技能（composable skills）和一条初始指令之上，确保你的编码代理能够正确地使用这些技能。该项目旨在解决编码代理在软件开发过程中经常出现的“盲目写代码”问题，即代理在没有充分理解需求、没有合理规划和测试的情况下就直接开始编码。目标用户是所有使用编码代理进行软件开发的开发者，尤其是希望提升代理工作效率和代码质量的团队和个人。

## 核心功能

- **需求澄清**: 当你启动编码代理后，它不会立即开始写代码，而是先退一步，询问你真正的目标，帮助你理清需求。
- **规格展示**: 代理会将从对话中提炼出的需求规格以可读的短段落形式展示给你，确保你能够理解和消化。
- **实施计划**: 在确认规格后，代理会制定一个清晰的实施计划，该计划强调真正的红/绿 TDD（测试驱动开发）、YAGNI（你不需要它）和 DRY（不要重复自己）。
- **子代理驱动开发**: 一旦你确认“开始”，代理会启动一个子代理驱动的开发流程，让多个代理分别处理各项工程任务，并对它们的工作进行检查和审查。
- **自主工作能力**: 得益于计划的清晰度和子代理的协同工作，代理（如 Claude）能够自主工作长达数小时，而不会偏离你之前制定的计划。
- **多平台支持**: 支持在多种编码代理平台上运行，包括 Claude Code、Codex CLI、Codex App、Factory Droid、Gemini CLI、OpenCode、Cursor 以及 GitHub Copilot CLI。

## 技术架构

Superpowers 的核心架构基于一套可组合的技能（composable skills）和一条初始指令（initial instruction）。这些技能是预定义的行为模块，覆盖了从需求分析、规格编写、任务分解到测试驱动开发、代码审查等软件开发全过程。初始指令则定义了代理如何选择和组合这些技能，以确保代理遵循既定的方法论。项目采用 Shell 语言编写，主要逻辑通过脚本和指令注入实现，使得它可以方便地集成到各种编码代理平台中。设计思路强调“流程先行”，即先确保代理理解完整的开发流程，再按部就班地执行，从而避免无计划的代码生成。

## 安装与使用

基本安装步骤如下：

1. 将 Superpowers 仓库克隆到本地：
```bash
git clone https://github.com/obra/superpowers.git
```

2. 根据你的编码代理平台，按照 README 中的指引进行配置。例如，对于 Claude Code，你需要将项目的初始化指令添加到代理的系统提示中。

3. 启动你的编码代理，开始开发。代理会自动遵循 Superpowers 的方法论，首先询问你的需求。

最小可用示例：

1. 在配置好 Superpowers 的编码代理中，输入类似“我想搭建一个 RESTful API 服务”这样的任务描述。
2. 代理会询问更多细节，帮助你明确需求。
3. 确认规格后，代理会展示实施计划。
4. 你批准计划后，代理自动开始基于子代理驱动开发的工作流程。

## 适用场景

- **复杂项目开发**: 当你需要开发一个具有多个模块和复杂逻辑的软件项目时，Superpowers 的方法论可以帮助代理分解任务、制定计划，并确保代码质量。
- **团队协作开发**: 在多代理或多开发者协作的场景下，Superpowers 提供了一套统一的工作流程，使不同代理能够高效协同，减少沟通成本。
- **高质量代码交付**: 对于对代码质量和测试覆盖率有严格要求的项目，Superpowers 强制的红/绿 TDD、YAGNI 和 DRY 原则能够显著提升代码的健壮性和可维护性。
- **代理学习与优化**: 对于希望训练或调优编码代理的团队，Superpowers 提供了一个结构化的框架，用于评估和改进代理在软件开发全生命周期中的表现。

## 项目亮点

与同类项目相比，Superpowers 的差异化优势在于：

- **完整的开发方法论**: 不仅仅是工具或模板，而是一套完整的软件开发方法论，覆盖从需求分析到代码审查的全流程。
- **强制的工程实践**: 内置了 TDD、YAGNI、DRY 等业界公认的最佳实践，并且强制代理遵循，避免了短期效率驱动下的代码质量妥协。
- **子代理驱动架构**: 通过代理间的分工协作和互相审查，实现了高水平的自主工作能力，同时保证了代码的一致性和质量。
- **高度可组合**: 技能模块是可组合的，用户可以根据项目需求选择和调整，灵活适应不同类型的开发任务。
- **跨平台支持**: 支持多种主流的编码代理平台，降低了切换和学习成本，提高了可用性。
