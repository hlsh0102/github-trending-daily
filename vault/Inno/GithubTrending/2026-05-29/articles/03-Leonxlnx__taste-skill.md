## 项目概述

Taste-Skill 是一个专为 AI Agent 设计的「反套话」前端技能框架，旨在解决 AI 生成的界面千篇一律、缺乏设计感的问题。项目名称中的 "Taste" 直指审美品味——当 AI 生成网页、应用界面或设计素材时，往往会产出充满 Bootstrap 样式的「模板化界面」，而 Taste-Skill 通过注入经过精心编排的布局、字体、动效和间距规则，让 AI 的输出从根本上告别「工业感」，拥有真正的人类设计师般的美学判断。

项目目标用户包括使用 Cursor、Codex、Claude Code 等 AI 编程工具的开发者，以及利用 ChatGPT Images 等图像生成工具进行设计参考和品牌套件制作的设计师。无论你是想快速搭建一个具有高级审美的落地页，还是需要一套可复用的界面设计规范，Taste-Skill 都能将你的 AI 助手从「代码生成器」升级为「有品位的设计搭档」。

## 核心功能

- **布局技能**：提供经过验证的栅格系统、对称与非对称布局模板，确保页面结构具有呼吸感与视觉层次，避免常见的居中或全宽平铺模式。
- **字体技能**：内置精选字体组合与排版规则，覆盖标题、正文、标签、引用等场景，自动生成字号比例和行高建议，告别 AI 默认的「14px 常规体」。
- **动效技能**：定义光标悬停、页面滚动、元素入场等交互动效的参数与触发方式，让界面具备精致的微交互，而不只是静态的组件堆叠。
- **间距技能**：通过统一的空间节奏系统（如 4px 基数的拾取式间距），确保元素之间的间距具有数学美感，避免出现随机留白或过度拥挤。
- **图像生成技能**：专为参考板（Web、移动端、品牌套件）设计的提示词模板，配合 ChatGPT Images 或同类工具使用，快速产出具有一致视觉语言的图像素材。
- **技能可移植性**：所有技能以独立文件形式组织，可无缝导入到 Codex、Cursor、Claude Code 等主流 AI 编程环境，无需额外配置或插件。

## 技术架构

Taste-Skill 采用纯 Shell 脚本与标记文件相结合的轻量架构。核心设计遵循「声明式技能」理念——每个技能单元（如 `layout.skill`、`typography.skill`）都是一个结构化的文本文件，包含参数说明、使用示例和上下文提示。这种设计使得技能文件可读性强、版本控制友好，并且不依赖任何特定框架或运行时。

项目没有引入复杂的 CLI 工具或后台服务，而是在 README 和技能文件中直接说明如何将这些技能文件加载到 AI Agent 的工作上下文中。例如，在 Cursor 中只需将技能文件内容粘贴到系统提示词或项目说明中，即可让后续的代码生成严格遵守这些设计规则。这种「零依赖」的策略降低了使用门槛，也保证了技能文件可以在任何文本编辑器或 AI 对话界面中直接使用。

架构上还特别强调「图像-代码分离」的工作流设计：先通过图像生成技能产出高质量的设计参考图，再将这些参考图作为视觉输入，交由代码生成 AI（如 Claude Code）进行像素级还原。这种闭环工作流确保了最终输出的界面与设计意图高度一致。

## 安装与使用

Taste-Skill 的安装过程极其简洁，因为项目本身就是一组可复用的文本资源。以下是典型的使用流程：

1. **克隆仓库**：将仓库下载到本地，或直接访问 GitHub 页面复制所需技能文件的内容。
   ```bash
   git clone https://github.com/Leonxlnx/taste-skill.git
   ```

2. **选择技能**：根据项目需求，从 `skills/` 目录中选择对应的技能文件，例如 `typography.skill`（字体技能）。

3. **注入 AI Agent**：
   - 若使用 Cursor：在项目创建时，将技能文件内容添加到 `.cursorrules` 或项目文档中。
   - 若使用 Codex：在对话开始时，复制技能文件内容作为系统提示词的一部分。
   - 若使用 ChatGPT：在生成图像前，先声明「遵循 Taste-Skill 的图像生成技能」。

4. **执行生成**：向 AI 描述你想要的界面效果，AI 将依据技能规则生成符合美学标准的设计或代码。

最小可用示例——使用字体技能生成一段排版样式的 HTML：
```
系统提示词（包含 typography.skill 内容）后，输入：
"生成一个关于咖啡品牌的产品介绍页，包含标题、副标题、三个特色介绍卡片和底部引用。"
```

AI 将自动应用技能中定义的字体组合、字号比例、行高和颜色方案，输出具有杂志级排版的 HTML/CSS 代码。

## 适用场景

- **落地页与品牌网站设计**：快速生成具有高级视觉风格的商业页面，适用于初创公司展示产品、个人作品集展示或活动宣传页面。
- **UI 组件与设计系统搭建**：在开发设计系统初期，使用 Taste-Skill 的布局和间距技能定义基础组件（按钮、卡片、导航栏）的视觉规范，确保后续开发的一致性。
- **设计参考板与品牌套件制作**：利用图像生成技能，配合 ChatGPT Images 生成多个方向的设计参考图，用于客户提案或内部设计评审。
- **AI 编程教学与模板输出**：教育场景中，使用 Taste-Skill 作为教学辅助工具，让学习者直观理解良好设计与平庸设计的差异，并快速产出可复用的高质量代码模板。

## 项目亮点

与同类项目相比，Taste-Skill 的核心差异体现在以下几个方面：

- **零学习成本**：不需要安装任何运行时、框架或插件。技能文件本身就是可阅读的规则说明，任何熟悉 AI 对话或提示词的开发者都能在 5 分钟内上手使用。
- **跨平台兼容**：不锁定特定的 AI 生成工具。无论是代码生成类的 Cursor/Codex，还是图像生成类的 DALL·E/Stable Diffusion，Taste-Skill 的技能都可以通过简单的文本注入生效。
- **设计而非代码**：多数同类项目侧重于提供代码片段库或 UI 组件库，而 Taste-Skill 聚焦于设计理念的传达——它教给 AI 的是「为什么这样设计更好看」，而非「这段代码怎么写」。
- **持续更新与社区贡献**：作为开源项目，接受社区提交的设计技能，让审美规则不断迭代，避免演变成另一套「公认的好看但用久了也腻」的模板。
- **轻量化与可定制**：单个技能文件通常不超 50 行，开发者可以快速浏览、理解并修改其中的规则，使其匹配自己的品牌调性或特定项目需求，而不需要承受一个庞大框架的约束。
