## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的高清短视频自动生成工具。用户只需提供一个视频**主题**或**关键词**，系统即可全自动完成视频文案撰写、视频素材匹配、字幕添加和背景音乐合成，最终输出一个完整的短视频。该项目主要面向内容创作者、自媒体运营者、营销人员以及对视频制作有批量需求的个人或团队，目标是大幅降低视频制作的门槛和时间成本。

## 核心功能

- **主题驱动一键生成**：仅需输入视频主题或关键词，系统自动完成从文案到成片的全流程，无需手动剪辑。
- **AI 文案自动生成**：内置大语言模型（LLM）接口，可根据主题自动生成高质量的视频文案脚本。
- **自定义文案支持**：用户也可手动输入或粘贴自有文案，系统基于文案内容自动匹配视频素材和字幕。
- **多种高清视频尺寸**：支持竖屏 9:16（1080x1920）和横屏 16:9（1920x1080）输出，适配抖音、视频号、B站等主流平台。
- **素材与音频自动合成**：自动从免费图库或视频来源获取与文案匹配的视频片段，并自动添加背景音乐和字幕，生成最终视频文件。
- **Web 界面与 API 双模式**：提供直观的浏览器操作界面，同时也开放 RESTful API，便于集成到其他自动化工作流中。

## 技术架构

项目采用 **MVC 架构**（Model-View-Controller），代码层次清晰，便于维护和扩展。核心技术栈包括：

- **Python**：作为主要编程语言，负责业务逻辑、AI 模型调用及视频合成调度。
- **AI 大语言模型**：集成 OpenAI、国内大模型等接口，用于文案生成。用户需配置对应的 API Key。
- **视频与音频处理**：使用 `moviepy`、`ffmpeg` 等库进行视频拼接、字幕叠加、音频混流等操作。
- **前端界面**：基于 Web 框架（如 FastAPI + Vue/HTML）提供用户交互页面，支持参数配置和任务管理。
- **素材来源**：通过接口调用免费图库（如 Pexels、Pixabay）获取视频片段，系统自动根据文案关键词选取最匹配的素材。

整体设计思路是将“视频制作”这一复杂流程拆解为多个独立模块：文案生成、素材检索、字幕渲染、音视频合成，每个模块可独立配置和调用。这种松耦合架构使得项目易于二次开发，用户可替换或定制任意模块（如更换文案模型或素材源）。

## 安装与使用

### 环境要求
- Python 3.8+
- ffmpeg（用于视频编码）
- 可访问互联网（用于调用 AI 模型及视频素材 API）

### 安装步骤
1. 克隆仓库：
   ```bash
   git clone https://github.com/harry0703/MoneyPrinterTurbo.git
   cd MoneyPrinterTurbo
   ```
2. 安装 Python 依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 配置环境变量或修改配置文件，填入 AI 模型的 API Key（如 OpenAI API Key）以及视频素材 API Key（如 Pexels API Key）。
4. 启动 Web 服务：
   ```bash
   python app.py
   ```
5. 打开浏览器访问 `http://localhost:8080` 进入 Web 界面。

### 最小可用示例
在 Web 界面输入视频主题（例如“雪景”），选择视频尺寸为竖屏 9:16，点击“生成”按钮。系统将自动生成文案、检索相关素材、合成字幕并添加背景音乐，约数十秒后即可下载生成的 MP4 视频文件。

## 适用场景

- **自媒体批量内容生产**：每日需要发布多条短视频的创作者，可利用该工具快速生成多个主题的视频，保持更新频率。
- **营销推广素材生成**：电商、品牌方可根据产品关键词快速制作推广短视频，用于社交媒体投放。
- **教育与科普内容制作**：教师或知识博主输入课程主题，自动生成带字幕和配乐的教学短视频，降低制作成本。
- **个人创意实验**：对视频制作感兴趣的用户可快速验证不同的文案与素材组合，探索创意方向。

## 项目亮点

- **完全自动化**：从文案到成片全程无需人工干预，传统需要数小时的视频制作压缩至几分钟。
- **清晰的项目结构**：采用 MVC 架构，代码模块化，开发者可轻松理解、修改或扩展功能。
- **双模式灵活使用**：既提供可视化 Web 界面供非技术用户操作，又提供 API 供开发者集成到自有系统中。
- **开源免费**：基于 MIT 协议，可自由使用、修改和商用，无需担心授权问题。项目拥有超过 6 万 GitHub Stars，社区活跃，持续迭代。
- **模型可插拔**：文案生成模块支持多种 LLM（如 OpenAI、国内模型），用户可根据成本和质量需求自由切换。
