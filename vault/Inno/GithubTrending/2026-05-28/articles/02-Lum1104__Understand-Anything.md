## 项目概述

Understand Anything 是一个开源工具，能够将任何代码库、知识库或文档转换为交互式知识图谱，让开发者可以通过探索、搜索和问答的方式深入理解复杂项目。该项目由 Lum1104 开发，使用 TypeScript 编写，旨在解决开发者在面对陌生大型项目时难以快速掌握整体结构与关键逻辑的痛点。目标用户包括参与代码审查的开发者、接手遗留系统的工程师、需要快速上手新框架的学习者，以及希望直观展示项目架构的技术管理者。

## 核心功能

- **一键生成知识图谱**：扫描指定目录或仓库，自动提取代码中的文件结构、类、函数、接口、依赖关系等元素，并生成可视化的交互式图谱，支持缩放、拖拽与节点展开。
- **多模态搜索**：在图谱内进行文本搜索，快速定位特定函数、类或模块；同时支持基于自然语言的问题查询，例如“这个模块负责什么逻辑？”或“有哪些地方调用了这个函数？”。
- **与主流 AI 编码工具集成**：原生支持 Claude Code、Codex（OpenAI）、Cursor、Copilot、Gemini CLI 等工具，允许用户在 AI 辅助理解代码时一键调用知识图谱，提升上下文获取效率。
- **导入外部知识源**：不仅支持本地代码目录，还可导入 Markdown 文档、API 文档、README 文件等，将文档与代码关联，形成统一的知识网络。
- **信息导出与共享**：将当前图谱状态导出为 JSON、HTML 或截图，方便团队协作或在其他文档中引用。
- **增量更新与版本历史**：支持对已生成的图谱进行增量更新（仅扫描变更部分），并保留版本历史，便于追踪知识结构的变化。

## 技术架构

Understand Anything 采用前端图形渲染引擎（如 D3.js 或类似力导向图库）结合后端解析器（基于抽象语法树分析）的架构。核心解析层使用 TypeScript 编写，可处理 JavaScript、TypeScript、Python、Java、Go 等多种主流语言。设计上强调模块化与可扩展性：解析器以插件形式提供，用户可自定义语言支持；图谱渲染层与数据模型解耦，便于替换为不同的可视化方案。项目本身不含持久化数据库，所有图谱数据以 JSON 文件形式缓存于用户本地，保证了数据隐私与轻量部署。此外，该项目提供 CLI 命令行界面和可编程的 API，支持在 CI/CD 流水线中自动化生成知识图谱。

## 安装与使用

安装前提：需要 Node.js 18+ 环境。可通过 npm 全局安装：

```bash
npm install -g understand-anything
```

使用示例：为本地代码仓库生成知识图谱并启动交互式查看：

```bash
ua init /path/to/your/repo
ua start
```

若希望集成到 AI 工具中，例如配合 Claude Code，可在 .claude/settings.json 中添加：

```json
{
  "plugins": [{
    "name": "understand-anything",
    "command": "ua query"
  }]
}
```

之后在 Claude Code 对话中即可直接调用图谱进行查询。更多集成方式请参考项目文档。

## 适用场景

- **接手遗留系统**：当开发者需要维护一个没有足够文档的古老项目时，通过一键生成图谱快速获取整体架构图，理清模块间的依赖关系，降低学习成本。
- **代码审查与重构**：审查大型 Pull Request 时，生成前后代码的图谱对比，直观识别出新的依赖引入或架构变动；重构前可基于图谱评估影响范围。
- **团队知识 onboarding**：新成员加入团队时，通过交互式图谱探索项目核心模块，结合搜索和问答功能快速解答“这个函数是做什么的”之类的常见问题。
- **文档与代码联动**：将 Markdown 技术文档与相关代码模块关联到同一图谱中，形成“文档-代码”双向索引，方便查阅时快速跳转。

## 项目亮点

与同类知识图谱工具相比，Understand Anything 的最大差异化在于：**专注于“教”而非“炫”**。许多图谱工具侧重于生成美观的静态图表，而本项目强调交互式探索能力——用户可以直接在图谱上提问、搜索、展开节点，甚至让 AI 工具直接引用图谱中的结构信息来回答更复杂的问题。此外，它对 Claude Code、Codex 等前沿 AI 编码工具的深度集成，使得知识图谱不再是一个孤立工具，而是成为开发者与 AI 协同工作流中的无缝环节。项目同时支持多语言代码解析，并允许用户自由导入外部知识源，使其不仅能用于代码理解，还能扩展至技术文档、学习资料等场景。开源 MIT 协议也让社区贡献和二次开发非常友好。
