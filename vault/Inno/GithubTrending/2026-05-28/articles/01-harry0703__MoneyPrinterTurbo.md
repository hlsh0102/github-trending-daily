## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的开源工具，能够实现一键生成高清短视频。用户只需提供一个视频主题或关键词，系统便会自动完成视频文案生成、素材匹配、字幕制作、背景音乐合成等全流程工作，最终输出一个完整的高清短视频。该项目主要面向内容创作者、自媒体运营者、营销人员和短视频爱好者，帮助他们大幅提升视频制作效率，降低创作门槛。

## 核心功能

- **全自动视频生成**：输入主题或关键词，系统自动完成文案撰写、素材检索、字幕生成、背景音乐合成及最终视频合成
- **支持自定义文案**：除了 AI 自动生成文案，用户也可以自由编辑和输入自己的文案内容
- **多种高清视频尺寸**：支持竖屏 9:16（1080×1920）和横屏 16:9（1920×1080）等多种主流分辨率
- **Web 界面与 API 支持**：提供直观的 Web 操作界面，同时开放 API 接口便于集成到其他工作流中
- **AI 驱动的素材匹配**：利用大模型理解文案语义，自动匹配相关视频素材片段
- **字幕与配音集成**：自动生成时间轴精准的字幕，并支持多种语音合成选项

## 技术架构

MoneyPrinterTurbo 采用完整的 **MVC（Model-View-Controller）架构**，代码结构清晰，模块间解耦良好，便于扩展和维护。项目核心技术栈包括：

- **AI 大模型**：用于文案自动生成和语义理解，支持对接主流的 LLM 服务，如 GPT、Claude 等
- **视频处理引擎**：基于 FFmpeg 等工具实现视频素材的裁剪、拼接、转码、合成等操作
- **素材管理模块**：内置素材库或可配置外部素材源，根据文案语义自动匹配最合适的视频片段
- **音频处理模块**：支持背景音乐自动加载、音量平衡、进度匹配，以及 TTS（文本转语音）配音
- **字幕生成引擎**：基于语音识别或文案时间轴，自动生成 SRT 格式字幕文件并嵌入视频
- **后端框架**：采用 Python 主流 Web 框架（如 Flask 或 FastAPI）提供 Web 界面和 RESTful API
- **前端界面**：响应式 Web 界面，支持参数配置、任务提交、进度查看和结果下载

设计上强调**自动化**和**易用性**，用户无需掌握视频编辑技能，只需描述想要的视频主题，系统即可完成后续所有复杂工作。

## 安装与使用

### 环境要求
- Python 3.8 或更高版本
- FFmpeg（用于视频处理）
- 至少 4GB 可用内存（推荐 8GB 以上）

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt

# 配置 AI 模型 API Key
# 编辑 config.py 或设置环境变量，填入你使用的 LLM 服务 API Key

# 启动 Web 服务
python app.py
```

### 最小可用示例

1. 启动服务后，在浏览器中打开 `http://localhost:5000`
2. 在输入框中填写视频主题，例如：“春天公园的樱花盛开”
3. 选择视频尺寸（竖屏/横屏）
4. 点击“生成视频”按钮
5. 等待系统自动完成文案生成、素材匹配和视频合成
6. 下载生成的 MP4 视频文件

也可以直接通过 API 调用：

```python
import requests

response = requests.post("http://localhost:5000/api/generate", json={
    "topic": "春天公园的樱花盛开",
    "size": "9:16",
    "duration": 30
})
print(response.json()["video_url"])
```
