## 项目概述

Twenty 是一款开源的客户关系管理（CRM）系统，旨在成为 Salesforce 的替代品。它采用现代技术栈构建，特别为 AI 时代进行了优化设计。无论是中小团队希望摆脱昂贵且复杂的传统 CRM，还是大型企业需要高度可定制、数据自控的客户管理方案，Twenty 都提供了一个强大而灵活的答案。项目的核心目标是让客户管理不再成为业务增长的瓶颈，而是驱动协作与洞察的引擎。

## 核心功能

- **灵活的客户数据库**：支持自定义对象、字段和视图，你可以像搭建积木一样构建完全符合业务逻辑的数据模型，而非被预设的表格限制。
- **内置的 AI 能力**：原生整合 AI 功能，用于智能数据补全、自动摘要、线索评分和预测分析，让 CRM 从记录工具变为决策助手。
- **协同工作与权限管理**：提供实时协作功能，支持任务分配、内建注释和 @ 提及。精细的权限体系确保数据安全，控制谁可以查看或编辑哪些信息。
- **API 优先与可扩展性**：提供 REST 和 GraphQL API，支持 Webhook 和自定义集成。你可以轻松将 Twenty 与现有工具链（如邮件、日历、Slack）连接起来。
- **现代化的 UI/UX**：采用清新、响应式界面设计，操作流畅直观。数据展示支持表格、看板、日历等多种视图，满足不同角色的工作习惯。
- **自托管或云服务**：你可以选择部署在自己的服务器上，完全掌控数据；也可以使用官方云服务，享受持续更新和托管便利。

## 技术架构

Twenty 基于 TypeScript 全栈开发，前后端均采用现代化框架。前端使用 React，搭配状态管理库和 GraphQL 层，实现流畅的交互与高效的数据获取。后端基于 Node.js，采用微服务化的架构设计，核心服务围绕 GraphQL 网关组织，便于独立扩展和维护。数据库层使用 PostgreSQL，结合自定义的 ORM 层，支持复杂查询和全文搜索。项目的设计思路强调模块化与可测试性，代码仓库内包含了清晰的包划分（如 `twenty-server`、`twenty-front`、`twenty-website` 等），便于社区贡献和二次开发。值得一提的是，Twenty 在架构之初就考虑到了 AI 模型的接入点，通过插件化的方式预留了推理接口，使得 GPT 等模型可以自然融入数据处理流程。

## 安装与使用

Twenty 提供了多种安装方式，以下是通过 Docker 快速启动的步骤：

1. **克隆仓库**
   ```bash
   git clone https://github.com/twentyhq/twenty.git
   cd twenty
   ```

2. **使用 Docker Compose 启动**
   ```bash
   docker compose up -d
   ```
   这会启动 PostgreSQL 数据库、后端服务、前端应用等所有必要组件。

3. **访问应用**
   打开浏览器访问 `http://localhost:3000`，按照初始化向导创建管理员账户并配置基本设置。

4. **最小可用示例**
   - 进入「人员」模块，点击「新建」添加一个联系人（姓名、邮箱、公司）。
   - 切换到「公司」模块，创建一家公司记录，并将其与该人员关联。
   - 尝试在搜索框输入关键词，查看即时搜索结果。
   - 点击界面右上角的「AI」按钮，体验智能建议功能（需要配置 API key）。

对于需要定制化部署的用户，官方文档提供了详尽的配置说明，包括 SSL 证书、外部认证集成（如 OAuth）、邮件服务配置等。

## 适用场景

- **创业公司与中小团队**：需要一个经济、灵活且功能完整的 CRM，无需前期投入高额许可费用，同时能随着业务成长快速调整数据模型。
- **数据敏感型企业**：法规要求或安全策略禁止将客户数据存储在第三方云服务中，通过自托管 Twenty 可以完全掌控数据主权。
- **希望用 AI 优化销售流程的团队**：利用内置 AI 功能自动分析客户互动历史、生成跟进建议，或预测交易关闭概率，提升转化效率。
- **需要高度自定义工作流的组织**：从教育机构管理学生信息，到非营利组织追踪捐助者关系，Twenty 的自定义能力可以适配非标需求。

## 项目亮点

与 Salesforce、HubSpot 等商业 CRM 以及 SuiteCRM 等传统开源方案相比，Twenty 的差异化优势明显：
- **真正的开源精神**：采用 AGPLv3 许可，代码完全透明，没有隐藏的企业版功能。社区版本即包含完整功能，无功能阉割。
- **AI 原生设计**：并非在传统 CRM 上简单叠加 AI 按钮，而是从数据模型层次就支持 AI 推理，使得智能分析、自动填充等能力浑然天成。
- **现代化技术体验**：基于 TypeScript 和最新 Web 标准构建，UI 响应迅速，开发体验友好。对比一些老旧开源 CRM 的 PHP + jQuery 栈，Twenty 无疑更贴近当下开发者习惯。
- **活跃的社区生态**：项目在 GitHub 上拥有超过 47,000 颗星，社区贡献活跃。官方提供了完善的文档、清晰的发展路线图以及活跃的 Discord 社区，用户遇到的问题往往能得到快速响应。
