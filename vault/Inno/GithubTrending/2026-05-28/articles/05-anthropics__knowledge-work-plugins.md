## 项目概述

Knowledge Work Plugins 是由 Anthropic 开源的一套插件集合，旨在将 Claude 转变为特定角色、团队和公司的专属专家。这些插件专为 Claude Cowork 构建，同时也兼容 Claude Code。项目解决的核心问题是：虽然 Claude 能够完成专业工作，但不同团队、不同角色有各自独特的工作方式、工具链和业务流程。通过插件机制，用户可以让 Claude 了解自己的工作偏好、连接内部工具、处理关键工作流，并暴露自定义的斜杠命令，从而获得更一致、更高质量的输出。

项目主要面向知识工作者、团队负责人和工程管理者，特别是那些希望在日常工作中深度集成 AI 助手，但又不满足于通用解决方案的用户。

## 核心功能

- **角色特定技能包**：每个插件捆绑了针对特定岗位（如销售、工程、运营）的专业技能，让 Claude 开箱即用地理解该角色的工作语境和常见任务。
- **多工具连接器**：插件内置与 Slack、Notion、Asana、Linear、Jira、HubSpot、ZoomInfo 等数十种主流 SaaS 工具的集成能力，可以直接拉取数据或执行操作。
- **自定义工作流**：用户能够定义自己的流程、术语和偏好，让 Claude 按照团队既有的工作方式协作，而无需团队成员适应新的工具。
- **斜杠命令系统**：插件可暴露专用的斜杠命令，快速触发频繁使用的操作，减少重复沟通成本。
- **子代理协作**：部分插件包含子代理机制，能够将复杂任务分解为多个步骤，由不同子代理协同完成，提升任务处理效率。
- **即插即用与可定制**：11 个预构建插件可直接使用，同时支持深度定制，用户可根据自身业务需求调整逻辑和连接器。

## 技术架构

项目采用 Python 作为主要开发语言，遵循模块化设计。每个插件是一个独立的目录，包含特定的技能定义、连接器配置、工作流逻辑和斜杠命令注册。核心架构围绕“插件 ↔ Claude Cowork/Claude Code”的通信协议展开：

1. **插件注册与加载**：Claude 启动时读取插件配置，加载对应的技能包和连接器，构建上下文环境。
2. **技能定义文件**：使用结构化格式描述角色所需的知识、工具偏好和处理规则，类似于可执行的知识图谱。
3. **连接器层**：通过 API 封装对外部服务的访问，包括 OAuth 认证、数据拉取、写入操作等，支持插件间共享连接器。
4. **工作流引擎**：支持定义多步骤工作流，包括条件分支、循环和子任务分发，确保复杂业务逻辑可被准确执行。
5. **斜杠命令处理**：将用户输入的斜杠命令映射到具体操作，支持参数传递和上下文感知。

这种架构使得新增或修改一个插件非常轻量，不需要修改 Claude 本体，也方便社区贡献和私有化部署。

## 安装与使用

**前提条件**：
- 拥有 Claude Cowork 或 Claude Code 的访问权限。
- 安装 Python 3.10+ 环境（如需要本地测试）。

**快速开始（以 Claude Code 为例）**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/anthropics/knowledge-work-plugins.git
   cd knowledge-work-plugins
   ```

2. 选择需要的插件，例如销量插件：
   ```bash
   cd sales
   ```

3. 在 Claude Code 中加载插件（具体方式取决于 Claude 版本，通常通过配置文件声明插件路径）。

4. 配置所需工具的 API 凭据（如 Slack token、HubSpot API key 等），放置在插件目录的配置文件中。

5. 启动 Claude Code 后，即可使用插件暴露的功能，例如输入 `/research-prospect` 来研究客户背景。

**最小可用示例**：
```bash
# 在 Claude Code 中加载 productivity 插件后，可执行：
/inbox - 查看待办事项
/create-task "编写 Q3 报告" due:2025-09-01 - 在 Linear 中创建任务
/summarize-channel #engineering - 总结 Slack 频道最近消息
```

## 适用场景

- **销售团队日常协作**：销售代表可以使用 sales 插件快速研究潜在客户、准备会议议程、回顾销售漏斗进度、生成竞争分析战报，无需在不同工具间切换。
- **工程管理提效**：技术负责人使用工程插件从 Jira 获取任务状态、在 Linear 中分配工作、审查 PR 动态、自动生成周报摘要，减少管理层中的信息同步负担。
- **运营与项目协调**：运营人员通过生产力插件管理日历、跟踪多个工具中的任务、自动整理会议纪要、设置提醒，将重复性工作自动化。
- **新成员入职加速**：团队可以基于现有插件定制公司专属版本，新成员直接使用，快速掌握团队的工作流程、常用工具和术语体系，缩短适应周期。

## 项目亮点

- **角色深度定制**：不同于通用 AI 助手，Knowledge Work Plugins 让 Claude 深入理解特定岗位的工作语境和处理习惯，输出与团队风格高度一致。
- **开箱即用的 11 个插件**：覆盖产品、销售、工程、运营、市场营销等常见角色，用户可直接使用，无需从零构建。
- **强生态兼容性**：同时支持 Claude Cowork 和 Claude Code，且连接器覆盖 20+ 主流办公工具，适应不同企业的技术栈。
- **社区友好许可**：采用 Apache-2.0 开源协议，允许商业使用、修改和再分发，适合企业内部二次开发。
- **可扩展架构**：插件定义清晰，开发者可以快速创建新的角色插件或修改现有插件，满足高度定制化需求。
