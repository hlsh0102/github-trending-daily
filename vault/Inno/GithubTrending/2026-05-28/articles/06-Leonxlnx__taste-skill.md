## 项目概述

Taste-Skill 是一个开源的前端代理技能（Agent Skills）框架，旨在解决当前 AI 生成界面普遍存在的“千篇一律、毫无品味”的问题。该项目通过提供精心设计的布局、排版、动效和间距规范，让 AI 在构建用户界面时不再输出“模板化的垃圾”（slop），而是生成具有专业设计感的高质量界面。

Taste-Skill 的目标用户包括使用 Cursor、Codex、Claude Code 等 AI 编码工具的前端开发者，以及希望通过 AI 生成更具视觉吸引力界面内容的设计师和产品经理。无论是 Web 应用、移动端界面还是品牌设计，Taste-Skill 都能作为 AI 的“审美指南”，帮助其产出更优雅、更具辨识度的设计结果。

## 核心功能

- **布局规范**：提供经过验证的网格系统、间距规则和响应式布局方案，避免 AI 生成拥挤或不对称的界面。
- **排版系统**：预设字体层级、行高和最适阅读宽度，让 AI 生成的文字内容更具可读性和设计感。
- **动效指南**：包含过渡动画、微交互动效和页面切换效果的描述规范，使 AI 能构建出流畅自然的用户交互体验。
- **参考图生成**：支持为 Web、移动端及品牌套件生成参考图（reference boards），可配合 ChatGPT Images 或同类图像生成工具使用。
- **便携式技能包**：设计为可移植的技能文件，可轻松集成到 Codex、Cursor、Claude Code 等主流 AI 编码工具中。
- **反模式识别**：内置常见“AI 风格”的识别与修正规则，帮助 AI 自觉避开那些被过度使用的模板化设计。

## 技术架构

Taste-Skill 本质上是一套结构化的设计系统指令和配置文件的集合，而非一个传统的软件库。其核心载体是 Shell 脚本和 Markdown 文档，通过这些轻量级文件封装设计规范和模式知识。

项目采用分层设计架构：

- **基础层**：包含颜色、字体、间距等设计令牌（design tokens）的定义，为 AI 提供最底层的设计约束。
- **规则层**：描述布局、排版、动效的具体实现规则，如“正文行宽不超过 75 个字符”、“导航项间距不小于 24px”等。
- **示例层**：提供参考图和注释示例，帮助 AI 理解特定设计目标的视觉表现。

这种架构的独特之处在于其“元指令”性质——它不直接生成代码，而是指导 AI 如何更好地生成代码。由于采用纯文本格式，Taste-Skill 的技能包可以轻松复制、修改，并适配不同的 AI 前端生成工具，具有良好的跨平台兼容性。

## 安装与使用

Taste-Skill 的安装和使用过程非常简洁：

1. **克隆仓库**：
   ```bash
   git clone https://github.com/Leonxlnx/taste-skill.git
   cd taste-skill
   ```

2. **选择技能包**：根据项目需求，从仓库中选择对应的技能文件（如 `web-layout.md`、`mobile-design.md` 等）。

3. **集成到 AI 工具**：将技能文件的内容粘贴到 Cursor、Codex 或 Claude Code 的对话上下文中，或按照工具标准指令配置方式加载。

4. **生成界面**：向 AI 提出具体的界面设计需求，如“生成一个包含三个功能模块的仪表盘页面”。AI 将根据 Taste-Skill 提供的设计规范输出具有更高质量标准的前端代码。

最小可用示例仅需三步：克隆仓库 → 加载技能文件 → 开始生成。无需安装额外的依赖包或配置复杂的运行环境。

## 适用场景

- **快速原型设计**：产品团队在使用 AI 快速搭建页面原型时，通过 Taste-Skill 的指导让原型从一开始就具备良好的视觉结构，减少后续迭代修改的成本。
- **电商/品牌页面生成**：品牌官网、落地页等对视觉品质有较高要求的场景，Taste-Skill 能帮助 AI 避免使用陈旧的模板风格，生成更具品牌感和现代感的设计。
- **移动应用界面设计**：针对手机屏幕的有限空间，确保 AI 生成的布局、字号及交互方式符合移动端最佳实践。
- **设计系统初稿辅助**：设计师可以借助 Taste-Skill 作为灵感来源和规范参考，加速设计系统的基础框架搭建。

## 项目亮点

Taste-Skill 的差异化优势在于它并非又一个设计工具或组件库，而是直接作用于 AI 的“审美训练集”。它与现有设计系统（如 Material Design、Ant Design）的理念互补——不是提供具体组件，而是传递设计判断力。

- **零依赖、插件化集成**：无需安装 npm 包或配置开发环境，通过纯文本文件即可将设计规范注入 AI 工作流。
- **聚焦“反模板”**：专门针对 AI 生成界面的常见问题（过度对称、无重点的空洞排版、色彩滥用等）给出纠正指导。
- **多工具兼容**：同时支持 Cursor、Codex、Claude Code 等主流 AI 编码助手，覆盖当前最广泛的前端 AI 开发场景。
- **社区驱动迭代**：MIT 许可证鼓励社区贡献新的技能包和案例，持续提升 AI 界面的品质标准。
