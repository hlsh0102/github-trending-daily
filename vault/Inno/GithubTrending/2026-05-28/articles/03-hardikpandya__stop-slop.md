## 项目概述

Stop Slop 是一份专为大型语言模型（如 Claude）设计的技能文件，用于自动检测并清除 AI 生成文本中常见的“AI 腔调”。这些腔调表现为可预测的短语、句式结构和行文节奏，让读者一眼就能识别出内容出自 AI 之手。该项目由开发者 hardikpandya 创建，目标用户包括所有需要与 AI 协作写作的群体——无论是使用 Claude Code 的开发者、依靠 Claude Projects 的知识工作者，还是通过 API 调用 LLM 的内容创作者。Stop Slop 提供了一套系统化的规则和参考文件，帮助 LLM 在输出时自动遵循“人类写作”的标准，消除机械感，让文本更自然、更可信。

## 核心功能

- **禁止短语识别与清除**：收录了大量 AI 生成的“标志性”短语，包括铺垫式开头（如“It is worth noting that”）、强调性措辞（如“It is important to highlight”）、商业术语、所有副词及模糊声明语句。详细列表见 `references/phrases.md`。
- **结构陈词滥调检测**：针对 AI 常用的句式结构进行拦截，包括二元对立（如“on one hand...on the other hand”）、负面列表、戏剧性断句、修辞性设问、虚假主体性、叙述者视角距离过远（如“the author explains that”），以及被动语态。详细规则见 `references/structures.md`。
- **句子级规则强制**：禁止以疑问词（如 What、Why、How）开头的句子、禁止使用破折号、避免断奏式碎片化句型、限制极端表达词（如 “extremely”“incredibly”），并强制使用主动语态。
- **评分机制**：提供一套 1–10 分的评估维度，覆盖被禁止模式、被消除模式、语气一致性及被动语态等，用于量化文本的自然度提升效果。
- **多平台适配**：文件包以标准 Markdown 格式编写，可直接用于 Claude Code（作为 Skill 文件夹）、Claude Projects（上传至项目知识库）、自定义指令复制、以及 API 调用时的系统提示词中。

## 技术架构

Stop Slop 的核心设计围绕“规则+参考文件”的结构展开。项目根目录包含 `SKILL.md` 作为主指令文件，定义了总体目标、评分标准和基本规则。`references/` 目录下存放三类辅助文件：`phrases.md` 列出待删除的具体短语清单、`structures.md` 描述结构模式、`examples.md` 提供前后对比示例。这种分层架构使得指令可以灵活扩展——用户可以根据需要只上传主文件，或选择性加载参考文件以降低上下文占用。工作时，LLM 在处理提示词时被要求先扫描输出、识别并移除所有符合“slop”特征的元素，然后再生成最终文本。设计思路强调“去模式化”，即打破 AI 在训练语料中习得的统计规律，迫使模型模仿人类写作的多样性。

## 安装与使用

### 安装步骤
1. 从 GitHub 仓库 hardikpandya/stop-slop 下载或克隆整个文件夹。
2. 根据使用平台选择加载方式：
   - **Claude Code**：将 `stop-slop/` 文件夹放置在项目目录中，在项目配置中引用该 Skill。
   - **Claude Projects**：进入项目知识库设置，上传 `SKILL.md` 及所需的参考文件（建议至少上传 `references/phrases.md` 和 `references/structures.md`）。
   - **自定义指令**：直接复制 `SKILL.md` 中的核心规则到 Claude 或任何兼容 LLM 的自定义指令区域。
   - **API 调用**：在系统提示词中包含 `SKILL.md` 的完整内容，参考文件可按需加载。

### 最小可用示例
假设你在使用 Claude Projects，只需执行以下两步：
1. 在项目知识库中上传 `SKILL.md`。
2. 开始对话，输入类似指令：“请撰写一篇关于量子计算的 300 字介绍，按 Stop Slop 规则去除所有 AI 腔调。”
Claude 会自动应用规则，输出更接近人类写作者的文本。

## 适用场景

- **学术与技术文档写作**：在撰写论文、技术博客或产品文档时，避免出现“In this paper, we will explore”等 AI 痕迹，让内容更专业、更直接。
- **商业沟通与报告**：消除“It would be beneficial to”“Let’s dive into”等商业化铺垫，使邮件、提案和报告的语言更简洁务实。
- **内容创作与编辑**：帮助自媒体作者、编辑团队在批量生成初稿后快速校正“AI 味”，保持统一的自然风格。
- **AI 工具输出优化**：对于使用 LLM 生成客服回复、产品描述或用户界面文本的应用开发者，通过集成 Stop Slop 规则提升输出的人类可信度。

## 项目亮点

- **精准定位痛点**：直接针对 AI 文本中最容易被识别的模式化问题，而非泛泛要求“写得更自然”。规则覆盖了从词汇到句法再到篇章结构的全层级。
- **轻量可复用**：整个项目仅依赖 Markdown 文件和文件夹结构，无任何运行时依赖或库，可以零成本集成到任何 LLM 工作流中。
- **透明可扩展**：所有规则以纯文本方式公开，用户可以根据自身领域需要添加自定义短语或调整评分维度，项目本质是一套可以增量改进的“反模式规则集”。
- **量化评估体系**：评分机制让用户能够客观衡量规则的生效程度，便于迭代优化，而不是依赖主观感受。
- **出自实战**：该项目在 GitHub 上获得了 5900+ 星标，并在发布当天迅速上涨，证明其解决了大量用户的真实痛点。
