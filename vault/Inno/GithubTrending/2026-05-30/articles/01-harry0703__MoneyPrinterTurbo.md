## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的开源短视频自动生成工具，能够通过用户提供的主题或关键词，全自动完成视频文案创作、素材检索、字幕合成、背景音乐搭配等一系列流程，最终生成高质量短视频。该项目由 harry0703 开发并维护，目前在 GitHub 上获得超过 70,000 颗星，社区活跃度极高。

项目主要面向内容创作者、自媒体运营者、短视频从业者以及希望快速生成视频素材的个人用户。其核心理念是“只需一个主题，即可获得一条完整的视频”，大幅降低了视频制作的门槛和人力成本。

## 核心功能

- **AI 文案自动生成**：支持调用大语言模型根据用户输入的标题或关键词自动生成视频文案，同时也支持用户自定义文案内容，灵活满足不同需求。
- **多种视频尺寸支持**：提供竖屏 9:16（1080×1920）和横屏 16:9（1920×1080）两种主流高清分辨率，适配抖音、快手、B 站等不同平台发布要求。
- **全自动素材组装**：内置视频素材库或通过指定来源自动匹配与文案匹配的视频片段、图片素材，并自动合成视频、添加字幕和背景音乐。
- **Web 界面与 API 双模式**：提供直观的 Web 操作界面，用户无需编程即可使用；同时支持 RESTful API 接口，方便开发者集成到自己的工作流程中。
- **字幕与背景音乐自动生成**：自动将文案转换为字幕（支持 SRT 格式或硬字幕），并根据视频风格推荐或选取合适的背景音乐。
- **完整 MVC 架构设计**：代码采用前后端分离的设计模式，结构清晰，易于二次开发和功能扩展。

## 技术架构

MoneyPrinterTurbo 采用现代化的前后端分层架构。

- **后端**：基于 Python 开发，使用流行的 Web 框架（如 Flask 或 FastAPI）提供 HTTP 服务。核心逻辑包括文案生成（调用 OpenAI 类 API）、素材检索（调用视频/图片搜索引擎或本地素材库）、视频合成（使用 FFmpeg 处理音视频叠加）、字幕渲染（基于字幕库或图片叠加技术）等模块。
- **前端**：提供基于 HTML/CSS/JavaScript 的 Web UI，支持用户输入主题、选择视频参数、启动生成任务并查看结果。
- **AI 集成**：项目对接大语言模型服务（如 OpenAI GPT 系列或兼容的 API），实现从关键词到完整文案的生成。用户也可以选择本地部署模型，实现离线使用。
- **视频处理**：核心依赖 FFmpeg 完成视频拼接、格式转换、大小调整等操作。字幕通过字体渲染库在视频上叠加文字，背景音乐自动裁剪并匹配视频时长。
- **状态管理**：通过 WebSocket 或轮询方式实现任务状态实时推送，用户在 Web 界面可以查看视频生成进度。

架构设计上充分考虑了扩展性，用户可以方便地替换 AI 模型、添加新的素材源或修改视频模板。

## 安装与使用

项目提供了详细的部署文档，支持 Docker 容器化部署和本地 Python 环境两种方式。

**方式一：Docker 部署（推荐）**

```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
docker-compose up -d
```

启动后打开浏览器访问 `http://localhost:8501` 即可进入 Web 界面。

**方式二：本地 Python 环境**

环境要求：Python 3.9+，FFmpeg 已安装并配置到环境变量。

```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
pip install -r requirements.txt

# 启动 Web 服务
python app.py
```

**最小可用示例**：
1. 打开 Web 界面，在输入框中填写视频主题（例如“春日赏花攻略”）。
2. 选择视频尺寸（竖屏或横屏）和时长偏好（如 30 秒至 1 分钟）。
3. 点击“开始生成”按钮。
4. 等待系统自动完成文案生成、素材匹配、视频合成，下载最终视频文件。

API 使用示例（Python 调用）：

```python
import requests

# 启动 API 服务后
response = requests.post(
    "http://localhost:8000/api/v1/video/generate",
    json={
        "topic": "春日赏花攻略",
        "video_aspect": "portrait",  # portrait 竖屏, landscape 横屏
        "duration": 60
    }
)
print(response.json())
```
