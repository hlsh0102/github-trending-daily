## 项目概述

`harvard-edge/cs249r_book` 是哈佛大学开设的 CS249r 课程（机器学习系统）的配套开源教材及教学资源库。该项目旨在系统性地阐述“工程化人工智能系统”的原则与实践，覆盖从基础理论到边缘部署的完整知识体系。它的目标用户包括计算机科学及相关专业的学生、希望深入了解机器学习系统底层实现的研究者、以及希望在嵌入式或边缘设备上部署 AI 模型的工程师。通过提供一本活页式教材、一个微型自动微分框架 TinyTorch、配套实验和硬件套件，该项目将学术课程的严谨性与开源社区的开放性有机结合。

## 核心功能

- **交互式教材**：以 Markdown 格式编写的完整课程教材，支持多语言（英文、中文、日文、韩文），内容涵盖机器学习系统的设计原理、优化策略和工程实现。
- **TinyTorch 框架**：一个从零构建的微型自动微分与神经网络库，用于教学用途。代码简洁，便于学生理解反向传播、张量运算等核心机制。
- **配套实验（Labs）**：与教材章节对应的 Jupyter Notebook 实验，提供动手编码练习，强化理论所学。
- **硬件套件（Kits）**：针对边缘 AI 场景设计的实验套件，支持 Arduino 等微控制器平台，实现真实世界的数据采集与模型部署。
- **自动化验证流水线**：项目通过 GitHub Actions 对教材、TinyTorch、实验和套件代码进行持续集成验证，确保内容的准确性和可复现性。
- **社区驱动更新**：采用公开工作流和版本管理，鼓励社区贡献和改进，教材内容可随机器学习领域的发展而迭代。

## 技术架构

该项目的技术架构围绕教学与自动化验证双核心设计。教材部分使用纯 Markdown 格式，通过 Git 进行版本管理，并利用 GitHub Actions 实现多语言翻译的自动校验和发布。TinyTorch 框架以 Python 实现，专注于张量操作和自动微分，设计上强调代码可读与教学清晰，而非追求运行效率或功能完整。实验部分基于 Jupyter Notebook，能够直接在教材仓库中预览和运行，降低了学生环境配置的门槛。硬件套件部分使用 Arduino 生态，提供与 TinyTorch 和教材理论相衔接的固件代码和数据接口。所有子模块（Book、TinyTorch、Labs、Kits）均有独立的 CI 验证工作流，确保代码变更不破坏既有功能，从而实现“教材即代码，代码即测试”的现代教学资源管理理念。

## 安装与使用

由于该项目主要提供教材和教学代码，使用方式较为灵活。以下为基本使用步骤：

1.  **获取项目**：
    ```bash
    git clone https://github.com/harvard-edge/cs249r_book.git
    cd cs249r_book
    ```

2.  **浏览教材**：直接打开仓库中的 Markdown 文件（如 `README.md` 或其语言版本）即可阅读。最方便的体验是通过 GitHub 的网页渲染或克隆后使用本地 Markdown 阅读器。

3.  **运行实验**：
    - 确保已安装 Python（建议 3.8 或更高版本）及 Jupyter Notebook 或 JupyterLab。
    - 进入实验目录，启动 Jupyter：
    ```bash
    cd labs
    jupyter notebook
    ```
    - 按照 Notebook 中的说明逐步执行代码。

4.  **探索 TinyTorch**：
    - 核心代码位于 `tinytorch` 目录。
    - 可以在 Python 环境中导入并测试：
    ```python
    import sys
    sys.path.append('tinytorch')
    import tinytorch as tt
    # 创建张量并运行自动微分示例
    ```

5.  **硬件套件**：参考 `kits` 目录下的说明，需要 Arduino IDE 或兼容的开发环境，以及对应的开发板（具体型号见套件文档）。

## 适用场景

- **大学课程教学**：作为“机器学习系统”或“深度学习系统”课程的教材或补充材料，提供从理论到实践的一站式学习路径。
- **自学入门**：适合有一定编程基础的开发者，通过阅读简洁的 TinyTorch 代码和完成实验，深入理解机器学习框架的工作原理。
- **边缘计算研究**：利用硬件套件和实验内容，快速原型化小型的端到端 AI 系统，用于物联网、嵌入式 AI 等领域的教学或验证。
- **贡献与协作**：开源社区成员可参与教材翻译、实验改进或 TinyTorch 代码优化，共同维护高质量的教育资源。

## 项目亮点

与同类机器学习教材或开源课程相比，该项目具有以下差异化优势：

- **全链路覆盖**：不仅讲解模型原理，还深入系统层面（如训练、部署、硬件），并配有可运行的代码和真实硬件套件，形成完整学习闭环。

- **多语言支持**：内置对中、日、韩等语言的支持，降低了非英语使用者参与前沿课程的门槛。
