## 项目概述

Meetily（曾用名 Meetly AI）是一款以隐私为首要原则的开源 AI 会议助手，专注于为 macOS 和 Windows 用户提供本地化的会议记录与总结服务。该项目基于 Rust 语言构建，核心能力包括 4 倍速的实时语音转录（支持 Parakeet / Whisper 模型）、说话人分离（Speaker Diarization）以及基于 Ollama 的本地摘要生成。无论用户参与的是 Zoom、Teams、Google Meet 还是腾讯会议等平台，Meetily 都能在本地完成全部处理流程，无需将语音数据上传至任何云端服务器。项目目标是成为顶尖的自托管开源会议笔记工具，赋予用户对会议数据的完全掌控权。

## 核心功能

- **实时语音转录**：采用优化后的 Parakeet 与 Whisper 模型，实现高达 4 倍速的本地实时转录，延迟极低，支持多语言识别。
- **说话人分离**：自动区分并标记会议中的不同发言者，使转录文本清晰区分对话主体，便于后续回顾。
- **本地 AI 摘要生成**：集成 Ollama 框架，用户可在本地运行 Llama、Mistral 等大语言模型，自动生成会议要点总结、待办事项及关键决策。
- **全离线处理**：转录、说话人识别、摘要生成均在用户计算机本地完成，100% 不依赖任何外部云服务，彻底保障数据隐私。
- **跨平台桌面支持**：提供原生 macOS 与 Windows 应用，界面简洁，可无缝融入系统音频流，自动捕获会议音频。
- **开源与自托管**：基于 MIT 许可证开源，用户可自行编译、定制或审计代码，部署属于自己的隐私友好型会议助手。

## 技术架构

Meetily 的技术栈围绕性能与隐私两大核心设计：

- **底层引擎**：使用 Rust 编写核心音频处理与转录调度模块。Rust 的内存安全特性与高性能计算能力，使得实时音频流处理高效稳定，且资源占用可控。
- **转录模型**：支持多种语音识别模型，包括 OpenAI 的 Whisper 系列以及优化后的 Parakeet 模型。通过模型量化和推理优化，实现在消费级 GPU 或 CPU 上的 4 倍速实时转录。
- **说话人分离**：采用独立的声纹嵌入模型，在转录过程中动态分析音频特征，识别不同说话人的切换，并将对应文本分配给正确的发言者。
- **摘要集成**：通过 Ollama 这一本地大模型运行框架，调用如 Llama 3、Mistral 等模型对整段或分段的转录文本进行语义理解与信息提取，生成连贯的结构化摘要。
- **桌面层**：基于 Tauri 或类似轻量级桌面框架构建 UI，兼顾原生性能与现代界面体验。音频捕获依赖操作系统的音频路由 API，能够自动监听系统输出或麦克风输入。

## 安装与使用

### 安装步骤

1. **下载安装包**：访问 [GitHub Releases 页面](https://github.com/Zackriya-Solutions/meeting-minutes/releases)，根据操作系统（macOS 或 Windows）下载最新的预发布或稳定版本安装包。
2. **运行安装程序**：macOS 用户直接拖动应用至 Applications 文件夹；Windows 用户运行安装向导完成安装。
3. **首次启动**：应用会自动检测系统音频设备，并引导用户授予麦克风或系统音频捕获权限。
4. **配置模型**：（可选）在设置中指定本地 Whisper 或 Parakeet 模型路径，或选择自动下载轻量模型。如需摘要功能，需额外配置本地运行的 Ollama 服务及指定模型。

### 最小可用示例

1. 启动 Meetily，软件将显示一个悬浮窗或状态栏图标。
2. 点击“开始转录”按钮，应用开始监听系统音频输出（或选择麦克风输入）。
3. 打开任意在线会议软件（如 Zoom、Teams），加入会议并正常沟通。
4. 实时转录文本将在 Meetily 界面中逐条显示，并自动标记说话人。
5. 会议结束后，点击“生成摘要”按钮，应用将调用本地 Ollama 模型处理本次会议记录，生成要点总结。
6. 用户可以导出完整的转录文本（.txt / .srt）或摘要（.md），所有数据保留在本地。

## 适用场景

- **职场会议记录**：适用于日常团队站会、项目评审、客户沟通等会议，自动生成高准确度的文字记录与要点总结，解放手动记笔记的工作量。
- **远程教育与在线讲座**：学生或学员可以利用 Meetily 实时捕捉讲师语音，配合说话人分离功能，清晰区分提问与解答环节，事后快速定位重点内容。
- **个人笔记整理**：记者、作家或研究人员在访谈或头脑风暴时，使用 Meetily 替代录音笔，直接获得结构化文字稿，并借助本地 AI 提炼核心观点。
- **隐私敏感行业**：金融、医疗、法律等对数据外流有严格限制的行业，选择离线全本地方案处理机密会议内容，满足合规要求。

## 项目亮点

- **完全隐私优先**：市面上大多数 AI 会议助手依赖云端处理，而 Meetily 坚决执行 100% 本地化流水线，用户音频数据从不离开设备，从根本上杜绝数据泄露风险。
- **Rust 构建的极致性能**：相比同类 Python 或 Electron 方案，Meetily 的 Rust 核心带来了更低的 CPU 占用与更快的转录速度，特别是 4 倍速实时转录能力领先于多数开源项目。
- **开源且可审计**：MIT 许可证允许自由使用、修改与分发。安全专家或深度用户可直接审查代码逻辑，确保无后门或隐藏数据上传行为。
- **端到端自托管生态**：从转录模型、说话人分离到大语言模型摘要，全部环节均采用本地可运行的开源组件，用户无需注册任何外部账号，真正实现数据主权。
