## 项目概述

ego-lite 是一款专为 AI 代理设计的极速浏览器，旨在解决传统浏览器与 AI 自动化工具协作时的痛点——用户需要将自己的登录状态、会话信息和浏览器上下文共享给代码助手（如 Codex 或 Claude Code），但又不希望被频繁的页面标签切换或身份验证流程打扰。该项目提供零成本、零配置的解决方案，让 AI 代理能够在一个隔离但共享状态的浏览器环境中高效执行网页自动化任务，同时保证用户自身浏览体验的流畅与安全。

目标用户包括：使用 AI 代码助手进行 Web 自动化开发的技术人员、依赖浏览器驱动的自动化测试工程师、以及需要将网页会话状态传递给 AI 代理以执行复杂操作的专业用户。

## 核心功能

- **无干扰会话共享**：将您当前浏览器中的 Cookie、Token 和登录状态安全地共享给 AI 代理，无需反复登录或授权，代理在后台运行，不会弹出窗口覆盖您的当前工作。
- **极速启动与运行**：基于轻量级内核设计，启动速度比传统浏览器快数倍，AI 代理发起请求后几乎瞬时响应，适用于高频交互场景。
- **零配置集成**：与主流 AI 工具（如 Codex、Claude Code）直接搭配使用，无需手动调整代理设置或编写复杂脚本，下载后即可开始工作。
- **隔离的执行环境**：AI 代理在其独立的浏览器上下文中执行操作，不会干扰您的主浏览器历史记录、扩展或个人信息，同时共享必要的身份验证凭据。
- **跨平台支持**：提供适用于 Apple Silicon 和 Intel Mac 的原生安装包，方便不同硬件配置的用户快速部署。
- **开源且免费**：采用 MIT 许可证发布，代码完全开放，用户可以自行审计、修改或扩展功能，无需任何付费订阅。

## 技术架构

ego-lite 基于 JavaScript 构建，核心设计理念是“最小可用性”与“代理优先”。项目没有采用传统的多进程浏览器架构来承载完整用户界面，而是精简渲染组件与网络层，专注于为 AI 代理提供稳定的 HTTP/WebSocket 接口。其技术亮点包括：

- **会话注入机制**：通过底层网络钩子拦截并管理 Cookie 和认证头，将当前主浏览器的有效会话安全地映射到代理隔离环境，避免直接暴露敏感凭据。
- **轻量级渲染引擎**：剔除了传统浏览器的标签管理、书签、开发者工具等前端模块，仅保留解析、渲染和脚本执行核心，显著降低内存占用和启动时间。
- **基于消息的通信层**：所有 AI 代理发出的指令（打开页面、点击、表单填写）都通过标准化消息格式传递，后端异步处理并返回结果，支持并发任务。
- **一次性配置存储**：用户的偏好设置和会话映射关系缓存在本地，无需云端同步，保障隐私的同时实现即装即用。

## 安装与使用

**安装步骤：**

1. 根据您的 Mac 硬件类型（Apple Silicon 或 Intel），点击项目 README 中的对应下载链接，获取 `.dmg` 安装文件。
2. 双击 `.dmg` 文件，将 ego-lite 应用拖动到 `Applications` 文件夹中完成安装。
3. 首次启动时，系统可能提示安全性验证，请前往“系统设置 -> 隐私与安全性”中允许打开来自未知开发者的应用。

**最小可用示例：**

1. 启动 ego-lite 应用，它会在后台运行并在菜单栏显示图标。
2. 打开您的终端，确保已安装 Codex 或 Claude Code 等兼容工具。
3. 使用以下命令（以 Codex 为例）启动自动化任务，ego-lite 将自动接管浏览器操作：
   ```bash
   # 假设您已登录目标网站，ego-lite 会共享当前会话
   codex run "登录到我的邮箱并获取最新三封邮件的标题"
   ```
4. 任务执行期间，ego-lite 不会弹出新窗口或干扰您的桌面，执行结果会直接输出到终端。

## 适用场景

- **AI 辅助的网页抓取与数据提取**：当 AI 代码助手需要访问登录后可查看的网页数据（如内部仪表盘、社交平台私信）时，ego-lite 提供已认证的浏览器环境，无需手写登录脚本。
- **自动化表单填写与操作**：适用于需要重复执行登录、提交表单、翻页等流程的自动化测试，AI 代理可快速完成操作并验证结果。
- **多会话并行管理**：开发者可同时在多个环境下运行代理任务（如不同账号的邮箱操作），ego-lite 确保各会话隔离，互不干扰。
- **集成开发环境中的隐形助手**：在 VS Code 或 JetBrains IDE 中使用 AI 插件时，ego-lite 作为后台浏览器引擎，让 AI 能够访问开发文档、运行在线演示而不打断编码流程。

## 项目亮点

- **速度优势突出**：相比基于 Chromium Full Stack 的自动化方案（如 Puppeteer 或 Playwright），ego-lite 的启动时间缩短 80% 以上，内存占用降低约 60%，特别适合需要频繁启动/销毁浏览器实例的代理场景。
- **真正的“零干扰”体验**：同类产品常通过弹出窗口或系统通知请求用户授权，而 ego-lite 完全在后台静默运行，AI 代理无法操纵您的鼠标或键盘，也不会改变您正在浏览的页面。
- **会话共享最简化**：无需学习复杂的身份验证库（如 Selenium 的 Cookie 管理），ego-lite 自动捕获可用会话，且每次共享都会刷新 Token 有效期，避免过期问题。
- **社区驱动与快速迭代**：项目日增超 900 颗星，反馈活跃，开发者根据用户需求频繁推送更新，并建有 Discord 社区提供直接技术支持。
