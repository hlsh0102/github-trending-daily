## 项目概述

Impeccable 是一个专为 AI 编码助手设计的设计语言系统，旨在解决 AI 生成前端界面时普遍存在的“千篇一律”问题。当开发者让 AI 生成网页时，无论使用什么模型，最终往往得到相似的结果：所有文字都用 Inter 字体、紫色到蓝色的渐变、嵌套的卡片、彩色背景上的灰色文字、每个标题上方都配一个圆角方形图标——这些都是 AI 模型在 SaaS 模板上训练后留下的固有痕迹。

该项目提供了一个结构化的设计指导系统，包含 1 个技能、23 个命令、实时浏览器迭代能力以及 60 条确定性检测规则。目标用户是使用 AI 编码工具（如 Claude、Copilot 等）进行前端开发的设计师和开发者，他们希望 AI 生成的设计更具原创性、与品牌一致且视觉上更协调。

## 核心功能

- **一键初始化流程**：运行 `/impeccable init` 后自动生成 `PRODUCT.md` 文件，并提供 `DESIGN.md` 模板，让 AI 了解产品受众、品牌定位、语气风格、色彩系统、字体选择、组件库等关键设计信息。
- **23 条设计命令**：提供一套共享的设计词汇表，包括 `polish`（打磨）、`audit`（审计）、`critique`（批评）、`distill`（提炼）、`animate`（动效）、`bolder`（更醒目）、`quieter`（更温和）等命令，实现与 AI 的精确设计沟通。
- **60 条确定性检测规则**：通过 CLI 工具或浏览器扩展对 AI 生成的界面进行自动化检测，这些规则无需调用大语言模型即可运行，不消耗 API 额度。
- **实时浏览器迭代**：支持在浏览器中实时预览和调整设计，让开发者能够即时看到修改效果。
- **基于 Anthropic 前端设计技能改进**：以 Anthropic 的 `frontend-design` 技能为基础，解决其在实际使用中暴露的设计同质化问题。
- **跨平台兼容**：作为 CLI 工具运行，支持在各种 AI 编码工具和终端环境中使用。

## 技术架构

Impeccable 采用模块化设计，核心架构分为三个主要部分：

首先是**技能层**，即 `impeccable` 命令，它作为 AI 编码工具的扩展，通过 `/impeccable <command> <target>` 的语法与用户交互。安装后它会将自身注入 AI 的提示上下文，使 AI 能够理解并执行设计相关指令。

其次是**配置层**，通过 `PRODUCT.md` 和 `DESIGN.md` 两个结构化文档存储项目的设计规范。这些文件不仅是 AI 的设计参考，也是团队间共享的设计语言，确保不同开发阶段、不同 AI 工具产出的界面风格一致。

第三是**检测引擎**，包含 60 条确定性规则和基于 LLM 的批评检查。确定性规则引擎独立于 LLM 运行，可以快速检测常见的“AI 通病”——例如字体使用不当、颜色对比度不足、不必要的冗余修饰等。LLM 批评检查则提供更深入的设计质量评估。

项目使用 JavaScript 编写，以 npm 包的形式发布，通过 `npx` 即可直接运行，无需全局安装。

## 安装与使用

安装 Impeccable 非常简单，只需在项目根目录下运行：

```bash
npx impeccable install
```

然后在你的 AI 编码工具（如 CLI、IDE 插件或 Web 应用）中发送：

```bash
/impeccable init
```

这个命令会引导你完成初始化设置，创建 `PRODUCT.md` 文件。AI 会询问你关于项目的一些关键问题，如产品定位、目标用户、品牌调性等。之后可以再运行：

```bash
/impeccable polish index.html
```

这个命令会让 AI 按照你设定的设计规范对 `index.html` 文件的界面进行打磨。

## 适用场景

- **初创产品开发**：当团队缺乏专业设计师，需要依靠 AI 生成 UI 时，Impeccable 可以确保 AI 产出的界面具有一致的设计语言和更专业的视觉效果。
- **设计师与 AI 协作**：设计师可以设定好设计规范文件，然后让 AI 按照这些规范生成界面草案，提高产出效率同时保证设计品质。
- **原型迭代**：在设计迭代过程中，使用 `audit`、`critique` 等命令快速获得 AI 对界面设计的中立反馈，提升设计决策质量。

## 项目亮点

Impeccable 与其他 AI 设计工具最大的区别在于其**结构化设计语言**的理念。大多数 AI 编码工具只是简单地将设计技能注入提示词，而 Impeccable 提供了一整套完整的设计管理方案：从最初的品牌定义、到具体的设计命令、再到自动化的设计质量检测。

另一个重要优势是**零成本运行**的确定性检测规则。60 条规则完全不需要调用 LLM，这意味着开发者可以在不消耗 API 额度的情况下快速发现并修正常见的设计问题，大幅降低设计迭代的成本。

此外，Impeccable 的**实时浏览器迭代能力**让开发者能够在实际浏览器环境中直接观察修改效果，避免了离线预览与真实环境之间的偏差。
