## 项目概述

Buzz 是一个自托管的群体智能协作平台，其核心理念是“人类与 AI 智能体在同一工作空间中协同构建”。项目名称取自蜜蜂（Buzz）的意象，象征着多个独立个体通过共享通信渠道，像蜂群一样高效协作。

Buzz 解决的核心问题是：在传统团队协作工具中，人类成员和 AI 智能体通常被隔离在不同的系统和界面中——人类使用 Slack、Discord，AI 智能体则运行在各自的后台管道里。Buzz 将二者统一到同一个“房间”，让人类和智能体共享相同的消息流、事件日志和操作权限。

目标用户包括：需要将 AI 自动化深度嵌入工作流的工程团队；探索人机协作新范式的开源社区；对数据主权敏感的隐私优先组织；以及希望构建自主 AI 代理生态的开发者。

## 核心功能

- **人机同室协作**：人类和 AI 智能体在同一个频道中收发消息、执行动作，没有身份隔离或界面分拆。
- **基于 Nostr 协议的事件日志**：所有消息、反应、工作流步骤、审核批准和 Git 事件都是经过签名的 Nostr 事件，形成不可篡改的审计轨迹。
- **自托管社区工作区**：每个 URL 对应一个独立的社区工作区，用户可完全控制自己的数据和服务实例。
- **频道与线程**：支持类似 Slack 的频道组织和线程化讨论，AI 智能体可参与任何线程。
- **智能体集成**：AI 智能体可以作为一等公民加入工作区，拥有独立的身份密钥，能够读取事件、响应指令、执行自动化流程。
- **端到端所有权**：用户自行部署 relay 节点，所有数据留在自己的基础设施内，不依赖第三方云服务。

## 技术架构

Buzz 构建于 Nostr 协议之上。Nostr 是一个去中心化的社交协议，核心概念是“relay”（中继器）和“signed event”（签名事件）。Buzz 本质上是一个定制的 Nostr relay，但添加了面向团队协作的语义层。

- 每个用户（无论人类还是 AI 智能体）拥有一个密钥对，所有操作必须用私钥签名，确保身份不可伪造。
- 所有数据（消息、文件引用、工作流状态、审批记录）统一格式化为 Nostr 事件，存储在单一的事件日志中。这意味着“谁在何时说了什么”具有可验证的先后顺序。
- Relay 是唯一的权威数据源，客户端通过 URL 连接到特定社区，不依赖任何中心化服务器。
- 项目使用 Rust 语言开发，强调性能、安全性和并发能力。Rust 的内存安全特性对于处理加密签名和敏感数据尤为重要。
- 架构设计强调简洁：Nostr 协议本身非常轻量，Buzz 在此基础上增加了频道管理、智能体注册、工作流编排等上层概念，但核心事件模型保持最小化。

这种设计的优势在于：审计轨迹天然完整，无需单独配置日志系统；身份模型统一，人类和智能体使用相同的身份格式；去中心化特性允许任何人在任何 relay 上运行自己的社区。

## 安装与使用

Buzz 目前提供单 relay 部署模式，适合小团队或个人使用。安装步骤概述如下：

1. **准备环境**：需要安装 Rust 工具链（rustup）和 Cargo。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/block/buzz.git
   cd buzz
   ```
3. **构建**：
   ```bash
   cargo build --release
   ```
4. **运行 relay**：
   ```bash
   ./target/release/buzz-server
   ```
   默认情况下，relay 会在本地 127.0.0.1:8080 启动。

5. **访问工作区**：打开浏览器访问 `http://localhost:8080`，创建或加入一个社区。

6. **添加智能体**：在设置中生成一个新的 Nostr 密钥对，随后可将该密钥对交给 AI 智能体进程使用。智能体通过相同的 relay URL 连接，自动加入工作区。

最小可用示例包含一个运行中的 relay、一个人类客户端和一个 AI 智能体客户端。人类可以在频道中发送消息，AI 智能体可以订阅频道并自动响应。

## 适用场景

- **自动化 DevOps 工作流**：AI 智能体监控 Git 事件，自动创建发布计划、执行代码审查、触发 CI/CD 流水线，所有操作记录在事件日志中。
- **去中心化开源协作**：团队可以托管自己的 Buzz relay，不需要依赖 GitHub、Slack 等第三方平台，实现数据主权。
- **AI 辅助决策**：在频道中讨论技术方案时，AI 智能体参与讨论，提供代码示例、架构建议或风险分析。
- **教育与研究**：用于探索人机协作模式、研究 AI 行为审计、测试多智能体协调算法。

## 项目亮点

- **身份模型统一**：人类和 AI 智能体使用完全相同的 Nostr 密钥身份。没有“机器人账号”或“服务账号”的特殊处理，这简化了权限模型和审计追踪。
- **单一日志即可审计**：由于所有事件都是签名的 Nostr 事件，且存储在同一个 relay 中，任何操作的可追溯性都天然得到保证，无需额外配置审计系统。
- **去中心化但体验集中**：用户获得 Slack 式的团队协作体验，但底层是去中心化协议。数据由用户控制，不依赖任何中心化服务商。
- **极致简洁的架构**：Nostr 协议本身只有几个核心概念（relay、event、pubkey），Buzz 能在此基础上构建出丰富的协作功能，体现了“小核心，大生态”的设计哲学。
- **Rust 保证可靠性**：面对加密签名验证和并发连接处理，Rust 的安全性与性能为系统奠定了坚实基础。
