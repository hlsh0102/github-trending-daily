## 项目概述

MoneyPrinterTurbo 是一款开源的 AI 短视频生成工具，旨在通过自动化工作流，将视频创作从繁琐的手工流程中解放出来。用户只需提供一个视频主题或关键词，工具便会自动完成从脚本撰写、素材匹配、字幕生成、配音合成到最终视频渲染的全链路工作，最终输出一段高清短视频。

该项目主要面向内容创作者、自媒体运营者、营销人员以及希望低成本批量生产视频的团队。它解决了传统视频制作中耗时长、技能门槛高、素材获取困难等痛点，让不具备专业剪辑能力的用户也能在短短几分钟内生成质量可观的视频内容。目前该项目在 GitHub 上已获得超过十万星标，社区活跃度高，持续迭代迅速。

## 核心功能

- **一键式视频生成**：输入主题或关键词，系统自动完成脚本撰写、素材匹配、字幕制作与视频合成，无需手动干预。
- **智能脚本生成**：内置多种 AI 大模型接口（如 Kimi、OpenAI 等），可根据关键词自动生成逻辑通顺、风格可调的短视频脚本。
- **自动化素材匹配**：自动从 Pexels、Pixabay 等免费图库中下载匹配的垂直或横屏视频素材，并在本地进行剪辑拼接。
- **高清视频合成**：支持 1080p 乃至更高分辨率的视频输出，可自定义视频尺寸、帧率、字幕样式等参数。
- **背景音乐自动配置**：自动下载并嵌入适合视频气氛的背景音乐，同时支持背景音乐音量调节、淡入淡出效果，并可通过 AI 语音生成解说旁白。
- **图形化界面与 API 双重支持**：内置基于 Streamlit 的 WebUI 界面，用户无需编写代码即可操作；同时提供 HTTP API 接口，方便开发者集成到自己的系统中。

## 技术架构

MoneyPrinterTurbo 的核心架构基于 Python 构建，充分利用了 AI 大模型能力和多媒体处理库。项目主要的技术栈包括：

- **AI 内容生成层**：通过集成多个大语言模型（LLM）服务（如 Kimi、OpenAI 等），负责根据用户输入的主题生成视频脚本、摘要和关键词，并通过语音合成服务（如 Azure TTS）生成配音音频。
- **素材获取层**：自动调用 Pexels、Pixabay 等图库的开放 API，根据关键词检索并下载符合要求的视频片段，存储至本地临时目录。
- **视频合成层**：使用 FFmpeg 进行视频片段裁剪、拼接和转码，同时借助 Pillow 生成字幕图片或使用字幕滤镜进行渲染，最终将视频、音频、字幕合成输出为 MP4 文件。
- **交互层**：项目提供两种交互方式——基于 Streamlit 的 WebUI 界面（支持浏览器操作和进度展示）以及基于 FastAPI 的 REST API 服务，便于自动化调用和二次开发。

在架构设计上，项目采用了模块化解耦的思路，每一层均可独立替换或升级（例如更换不同的 AI 模型、图库源），同时引入了配置驱动的工作流机制，用户可通过修改配置项来控制视频的语调、风格、字幕形状等细节。这种设计使得工具具备较强的适应性和扩展性。

## 安装与使用

MoneyPrinterTurbo 支持多种运行方式，但最便捷的是使用 Docker。在安装 Docker 后执行以下命令即可拉取镜像并运行 WebUI：

```bash
docker run -it -p 8501:8501 harry0703/moneyprinterturbo
```

随后在浏览器中访问 `http://localhost:8501` 即可进入操作界面。

若希望在本地环境直接运行，需先准备 Python 3.9+ 环境，然后克隆仓库并安装依赖：

```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
pip install -r requirements.txt
```

在启动前，需要复制 `config.example.toml` 为 `config.toml`，并填入所需的 API Key（包括 AI 大模型服务、图库 API、语音合成服务的密钥）。完成后执行：

```bash
streamlit run app.py
```

即可启动 WebUI 界面。在界面中输入视频主题，点击“开始生成”即可看到全自动的生成流程。

## 适用场景

- **自媒体快速内容生产**：抖音、快手、YouTube 创作者可借助该工具批量生成短视频，覆盖新闻、知识科普、产品种草等题材，大幅提升日更频率。
- **营销与广告素材制作**：电商运营和广告投放人员可快速生成多版本视频素材，进行 A/B 测试或针对不同用户群体定制内容，降低素材制作成本。
- **教育与培训视频制作**：教师或培训机构可输入知识点关键词，自动生成带有配音和字幕的讲解视频，辅助在线课程建设。
- **个人创意与娱乐**：普通用户也可以用其实现“说出想法，生成大片”，用于个人 Vlog、节日祝福等个性化视频创作。

## 项目亮点

MoneyPrinterTurbo 之所以能在同类开源工具中脱颖而出，主要在于以下几点：

- **极高的自动化程度**：从内容策划到成片输出，全流程无需人工参与，实现真正的“一键生成”。
- **灵活的技术集成**：支持多家 AI 模型和素材服务商，用户可根据成本和质量自由搭配，且项目提供了丰富的参数配置（如视频比例、语音音色、字体字号等）。
- **双界面与 API 设计**：既为普通用户提供友好的 WebUI，也为开发者提供规范的 API 接口，满足了从个人使用到系统集成的不同需求。
- **积极的社区与迭代**：项目保持着高频的版本更新，社区贡献活跃，用户反馈的问题通常能快速得到修复，同时作者也开通了赞助渠道以维持项目的持续发展。
