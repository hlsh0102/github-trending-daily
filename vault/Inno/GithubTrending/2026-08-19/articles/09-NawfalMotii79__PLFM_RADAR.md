## 项目概述

AERIS-10（项目代号 PLFM_RADAR）是一个开源、低成本的 10.5 GHz 相控阵雷达系统，采用脉冲线性调频（Pulse Linear Frequency Modulated, PLFM）调制技术。该项目旨在将雷达技术民主化，为研究人员、无人机开发者以及资深软件无线电（SDR）爱好者提供一个完全开源、模块化且可自由修改的雷达实验平台。

AERIS-10 提供两个版本：AERIS-10N（Nexus），探测距离 3 公里；以及 AERIS-10X（X-Treme），探测距离 20 公里。无论您来自高校实验室、初创无人机公司，还是资深创客社群，都能利用 AERIS-10 深入探索波束成形、脉冲压缩、多普勒处理和目标跟踪等尖端雷达技术。

## 核心功能

- **全开源硬件与软件**：项目提供完整的原理图、PCB 布局、固件源码和上位机软件，用户可完全掌控系统的每个细节。
- **双版本可选**：AERIS-10N（Nexus）面向短距离应用，探测范围 3 公里，配置 8 个收发通道；AERIS-10X（X-Treme）面向远距离探测，范围达 20 公里，通道数相应扩展。
- **脉冲线性调频（LFM）调制**：采用经典的 LFM 波形，支持脉冲压缩处理，在较低峰值功率下获得高距离分辨率。
- **相控阵波束成形**：支持电子扫描波束，无需机械转动即可实现快速目标搜索与跟踪。
- **多普勒处理能力**：内置多普勒滤波器组，可区分静止与运动目标，提取目标径向速度信息。
- **模块化设计**：射频前端、数字基带、控制接口相对独立，便于用户替换或升级特定模块。

## 技术架构

AERIS-10 在架构上采用经典的相控阵雷达设计范式，将射频前端与数字信号处理分离。系统核心基于 10.5 GHz 频段（属于 X 波段），该频段在气象监测、无人机探测和交通管理等领域应用广泛。

从硬件层面看，每个收发通道包含低噪声放大器（LNA）、功率放大器（PA）、移相器和 T/R 开关，通过 PCB 微带线实现相位一致性布局。本振信号经功分网络分配到各通道，借助移相器实现波束指向控制。数字部分采用 FPGA 完成波形产生、采集时序控制和实时信号处理，包括匹配滤波、MTI（动目标指示）和 FFT 多普勒处理。

软件架构上，项目提供跨平台的 Python/Matlab 控制接口，支持通过 USB 或以太网与雷达硬件交互。用户可借助 API 配置波形参数（如调频带宽、脉冲宽度、PRF），并实时获取处理后的点迹数据。整个系统的设计强调低成本和可复制性，核心器件均选用易于采购的商用现货（COTS）组件。

## 安装与使用

AERIS-10 的部署分为硬件搭建和软件环境配置两步：

1. **硬件组装**：根据项目提供的原理图和 PCB Gerber 文件，通过常规 PCB 打样服务制作电路板。采购 BOM（物料清单）中所列的射频芯片、FPGA 开发板和无源器件，手工焊接或委托 SMT 加工。建议参照项目 Wiki 中的装配指南逐步完成调试。
2. **软件环境**：首先安装 Vivado（FPGA 工具链）并编译固件，烧录到目标 FPGA 开发板。然后在主机上安装 Python 控制库（通过 `pip install aeris_radar` 或从源码构建），运行提供的示例脚本进行功能验证：
   ```python
   from aeris_radar import AERISRadar
   
   radar = AERISRadar(interface='usb', config='nexus_3km.yaml')
   radar.start()
   data = radar.capture_frames(100)
   radar.process_doppler(data)  # 输出距离-多普勒图
   ```

默认配置可在 `config/` 目录下找到，用户可以修改调频带宽、脉冲重复频率等参数以适配不同探测需求。

## 适用场景

- **高校雷达教学与科研**：作为课程实验平台，学生可直观理解波束成形和脉冲压缩原理，并基于开源代码开展二次开发。
- **无人机探测与避障**：AERIS-10N 的 3 公里探测能力适合小型无人机集群的感知与防撞，开发者可集成飞控系统。
- **安防监控与周界防护**：固定安装后，通过电子扫描覆盖重点区域，检测入侵目标并输出预警信号。
- **气象与环境监测**：借助 X 波段对雨滴、气溶胶的散射特性，开展局部气象观测实验。

## 项目亮点

与商业雷达或其它开源雷达项目相比，AERIS-10 的差异化优势十分明显：

- **极致成本**：整个硬件 BOM 成本控制在数百美元级别，不足商业等效性能设备的十分之一，真正实现雷达技术普惠。
- **全面开放**：不仅开放软件，还开放硬件设计文件，用户可自由定制天线阵列规模、频段甚至调制方式，不受厂商锁定。
- **高性能参数**：20 公里版本（X-Treme）在同类开源项目中具有显著的距离优势，覆盖更多长距离探测场景。
- **社区活跃**：项目在 GitHub 上获得超过 2.4 万星标，且日增关注迅速，活跃的社区保障了问题反馈的及时性和文档的持续完善。
