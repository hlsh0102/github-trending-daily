## 项目概述

Goose 是一个开源、可扩展的通用 AI 智能体，旨在超越传统的代码补全建议，提供安装、执行、编辑和测试等完整的开发与工作流自动化能力。该项目由 Agentic AI Foundation（AAIF）在 Linux 基金会下维护，最初由 block 迁移而来。无论你是开发者、研究人员、写作者还是数据分析师，Goose 都可以在本地机器上运行，为你处理代码编写、研究探索、文档撰写、流程自动化以及数据分析等各类任务。它提供桌面应用（macOS、Linux、Windows）、命令行界面（CLI）和 API 三种交互方式，目标是成为你日常工作中的原生 AI 助手。

## 核心功能

- **多模态交互**：支持桌面应用、CLI 和 API 三种使用方式，适应不同工作场景。
- **代码全流程支持**：不仅能生成代码建议，还能自动安装依赖、执行脚本、编辑文件并进行测试验证。
- **任意 LLM 兼容**：可与多种大语言模型配合使用，不限定于某一特定厂商的模型。
- **可扩展架构**：通过插件或模块机制，用户可以自定义功能、添加新的工具或集成外部服务。
- **本地优先运行**：所有操作在本地机器上执行，确保数据隐私和低延迟。
- **通用任务处理**：不限于编程，还支持研究、写作、自动化、数据分析等广泛场景。

## 技术架构

Goose 采用 Rust 语言开发，保证了高性能和跨平台兼容性。其架构设计核心包括：

- **插件化扩展系统**：通过明确定义的接口，允许用户和社区开发新的功能模块，扩展智能体的能力范围。
- **统一的执行引擎**：将代码生成、执行、编辑和测试整合为一条流水线，减少上下文切换开销。
- **多模态接口层**：桌面应用（基于原生 GUI 框架）、CLI（终端交互）和 API（程序化调用）共享同一后台逻辑，实现“一次开发，多处运行”。
- **模型抽象层**：通过标准化的接口与多种 LLM 交互，用户可根据任务需求灵活选择最合适的模型。
- **事件驱动架构**：利用异步事件处理模型，高效处理长时间运行的任务和实时交互反馈。

## 安装与使用

### 安装步骤

1. **桌面应用**：访问 [GitHub Releases 页面](https://github.com/aaif-goose/goose/releases) 下载对应操作系统（macOS、Linux、Windows）的安装包，按提示安装即可。
2. **CLI 工具**：在终端中运行以下命令快速安装：
   ```bash
   # macOS (Homebrew)
   brew install goose-cli

   # Linux (通过包管理器)
   sudo apt install goose-cli   # Debian/Ubuntu
   sudo yum install goose-cli   # CentOS/Fedora
   ```
3. **从源码编译**：
   ```bash
   git clone https://github.com/aaif-goose/goose.git
   cd goose
   cargo build --release
   ./target/release/goose --help
   ```

### 最小可用示例

```bash
# 启动 Goose CLI 并开启交互式会话
goose start

# 在会话中，你可以直接输入自然语言指令：
# "帮我写一个 Python 脚本，读取当前目录下的 CSV 文件并绘制折线图"
# Goose 会自动生成代码、安装所需库、执行并展示结果

# 非交互模式：一次性执行任务
goose run "将 README.md 翻译成简体中文并保存为 README_zh.md"
```

## 适用场景

1. **软件开发工作流**：从需求分析、代码生成、单元测试到持续集成，Goose 可自动完成多个环节，减少手动操作。
2. **科研与数据分析**：自动处理数据清洗、统计建模、可视化生成，并撰写分析报告，适合快速探索新数据集。
3. **文档与内容创作**：帮助撰写技术文档、博客文章、营销文案，并自动检查语法和格式。
4. **日常自动化**：如批量文件处理、系统管理脚本编写、定时任务配置等，节省重复性劳动。

## 项目亮点

- **真正通用性**：不同于那些仅聚焦于代码补全的 AI 工具，Goose 能处理从代码到文本、从研究到自动化的广泛任务，真正适配多样化工作流。
- **本地优先 + 可扩展**：在保障数据隐私的同时，通过插件机制允许社区贡献特性，避免了闭源方案的局限性。
- **跨平台原生体验**：桌面应用和 CLI 都经过精心打磨，提供与操作系统深度集成的流畅体验。
- **开放生态与治理**：项目隶属于 Linux 基金会下的 AAIF，采用 Apache-2.0 许可证，并设有活跃的 Discord 社区，确保长期健康发展。
