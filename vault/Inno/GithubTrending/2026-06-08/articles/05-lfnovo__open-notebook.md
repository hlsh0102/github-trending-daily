## 项目概述

Open Notebook 是一个开源的、注重隐私的 Notebook LM 替代方案。Google 的 Notebook LM 是一款 AI 笔记与知识管理工具，能够帮助用户基于上传的文档进行问答、生成摘要和见解。但作为闭源 SaaS 服务，用户无法自由定制功能、控制数据存储位置，也无法脱离 Google 生态使用。

Open Notebook 解决了这些问题。它提供了与 Notebook LM 类似的核心体验——让 AI 理解你的文档并与之对话——同时给予了用户更高的灵活性和自主权。你可以将其部署在自己的服务器上，自由选择底层 AI 模型，甚至根据工作流需求扩展功能。项目的目标用户包括：技术开发者、隐私敏感的知识工作者、研究团队，以及任何希望在安全可控的环境中利用 AI 处理文档的个人或组织。

## 核心功能

- **文档驱动的 AI 问答**：上传 PDF、Markdown、网页链接等多种格式的文档，AI 会基于这些内容理解上下文，你可以像与人对话一样提问，获得准确、有依据的答案。
- **灵活的 AI 模型选择**：支持接入多种开源或闭源语言模型（如 GPT、Claude 或本地部署的 Llama 等），不锁定单一供应商，用户可根据性能、成本和隐私需求自由切换。
- **工作流自动化与定制**：允许创建自定义的 AI 工作流，例如自动对上传文档进行摘要、关键词提取、翻译或多角度分析，并将结果整合到笔记中。
- **多源知识库管理**：可以将不同来源的文档组织到独立的笔记本（Notebook）中，每个笔记本拥有独立的上下文和设置，方便不同项目或主题的知识管理。
- **协作与分享**：支持多用户协作，可以邀请团队成员共同编辑笔记本、共享查询结果，并通过 Web 界面直接访问。
- **隐私优先的自托管部署**：整个系统可由用户自行部署在私有服务器或云服务器上，所有数据本地化处理，避免敏感信息泄漏。

## 技术架构

Open Notebook 采用现代化的全栈 TypeScript 技术栈构建。前端使用 React 框架，提供了响应迅速、交互流畅的用户界面。后端基于 Node.js，结合了数据库（如 PostgreSQL 或 SQLite）来存储文档、笔记和用户数据，以及向量数据库（如 Qdrant 或 pgvector）来实现高效的语义搜索和文档检索。

项目的核心设计思路是组件化和可扩展性。它定义了一套清晰的 API 和插件接口，允许开发者为系统添加新的文档解析器、AI 模型适配器或工作流节点。例如，你可以编写一个插件，使系统能够处理 EPUB 电子书或特定格式的数据库导出文件。这种架构使得 Open Notebook 不只是一个封闭的应用，而是一个可以不断演进的 AI 知识工作平台。

在 AI 交互层面，系统采用了检索增强生成（RAG）模式。当用户提问时，先通过语义搜索从用户文档集合中找到最相关的片段，然后将这些上下文注入到 AI 模型的 prompt 中，从而生成准确、有引用依据的回答，大大减少了幻觉现象。

## 安装与使用

Open Notebook 提供了多种部署方式以适应不同技术水平的用户：

**Docker 部署（推荐）**：
1. 确保系统已安装 Docker 和 Docker Compose。
2. 克隆仓库：`git clone https://github.com/lfnovo/open-notebook.git`
3. 进入目录：`cd open-notebook`
4. 复制环境配置：`cp .env.example .env`，并根据需要修改配置（如数据库连接、AI API 密钥）。
5. 启动服务：`docker compose up -d`
6. 打开浏览器访问 `http://localhost:3000`，按引导完成初始设置。

**手动部署**：需要 Node.js 18+、PostgreSQL 和可选向量数据库。依次执行 `npm install`、数据库迁移、以及前后端构建与启动命令。

**最小可用示例**：
- 启动后，创建第一个“笔记本”。
- 从本地计算机上传一个 Markdown 文件或 PDF 论文。
- 系统会自动解析文档并建立索引。
- 在聊天界面输入：“这篇文档的核心论点是哪些？”AI 将基于文档内容给出总结，并标明信息来源。

## 适用场景

- **学术研究**：研究人员可以上传大量论文到特定笔记本，快速进行文献综述、对比不同论文的观点，或基于文献回答复杂问题，提升文献整理效率。
- **企业知识管理**：团队可以将内部文档、会议记录、技术方案等资料集中管理，新人培训、知识问答和决策支持都可直接通过 AI 查询完成，避免信息孤岛。
- **个人学习助理**：学生或自学者可以上传教材、课程笔记或网络文章，利用 AI 生成学习摘要、练习问答，加深对知识点的理解。

## 项目亮点

- **真正开源与可控**：与谷歌闭源的 Notebook LM 不同，Open Notebook 代码完全公开，任何人可以审计、修改和自由使用。用户可以自行控制数据主权，无需担心服务关闭或隐私政策变更。
- **模型中立性**：不绑定任何特定 AI 服务商。你可以使用 OpenAI、Anthropic 的闭源模型，也可以选用 Meta 的 Llama、Mistral 等开源模型，甚至通过 Ollama 或 llama.cpp 完全本地运行，实现完全离线的 AI 体验。
- **深度可定制性**：从 UI 主题、工作流逻辑到后端插件，几乎所有层面都可扩展。用户可以根据特定领域需求（如法律、医疗）定制专用分析流程，这是通用 SaaS 工具无法做到的。
- **积极活跃的社区**：项目在 GitHub 上拥有 27,000 多颗星标，Discord 社区活跃，文档完善且支持多语言，新手也能快速上手，开发者能够参与贡献。
