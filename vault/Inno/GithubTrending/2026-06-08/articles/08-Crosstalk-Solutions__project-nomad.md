## 项目概述

Project N.O.M.A.D.（Node for Offline Media, Archives, and Data）是一个面向离线环境的知识与教育服务器。它被设计为完全自包含的“生存计算机”，集成了关键工具、知识库和人工智能能力，确保用户在任何时间、任何地点——即使在没有网络连接的情况下——都能获取信息并保持决策能力。

该项目主要面向以下用户群体：经常在偏远或无网络区域工作的人员、数字隐私倡导者、应急准备爱好者、教育工作者，以及任何希望建立一个持久、自主的知识备份系统的人。

## 核心功能

- **完全离线运行**：所有核心功能和服务均可在无互联网连接时独立工作，仅需本地设备即可访问全部内容。
- **集成知识库**：预装或可导入大量结构化的知识资源，涵盖技术文档、生存指南、学术参考资料等，形成可搜索的离线智库。
- **本地AI辅助**：包含轻量级的人工智能模型，支持在离线环境下进行问答、内容摘要和知识检索，无需依赖云端API。
- **浏览器访问**：所有工具和资源均通过Web界面提供，用户无需安装任何客户端，仅需浏览器即可操作全部功能。
- **即装即用**：提供一键安装脚本，可快速部署在Debian系操作系统上，从安装到使用仅需几分钟。

## 技术架构

Project N.O.M.A.D. 基于TypeScript开发，采用模块化架构设计。其核心是一个自托管的Web服务，运行在用户本地设备上，通过HTTP协议提供服务。

关键设计思路包括：
- **离线优先（Offline-First）**：所有数据、模型和工具资源均存储在本地，核心功能不依赖任何外部网络服务。
- **轻量级部署**：针对低功耗设备（如树莓派、老旧笔记本、VPS）进行了优化，能够在资源受限的环境中稳定运行。
- **终端安装与Web UI分离**：安装过程完全在终端中完成，但用户交互全部通过浏览器进行，降低了使用门槛。
- **数据持久化**：采用标准文件系统或轻量级数据库存储知识内容，确保数据在设备重启或断电后保持完整。

## 安装与使用

**前提条件**：
- 一台运行Debian系操作系统的设备（推荐Ubuntu 20.04或更新版本）。
- 需要sudo/root权限以执行安装脚本。

**快速安装**：
打开终端，逐行执行以下命令：

```bash
sudo apt-get update && \
sudo apt-get install -y curl && \
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh \
  -o install_nomad.sh && \
sudo bash install_nomad.sh
```

安装脚本会自动下载所需文件、配置依赖并启动服务。整个过程需要5-15分钟，具体取决于网络速度和设备性能。

**启动使用**：
安装完成后，打开浏览器并访问：
- 本机：`http://localhost:8080`
- 局域网内其他设备：`http://DEVICE_IP:8080`（将DEVICE_IP替换为实际IP地址）

首次访问时，系统会引导用户完成初始化配置，包括设置管理员密码、选择知识库组件等。

## 适用场景

- **灾备与应急通信**：在自然灾害、网络中断或基础设施受损的情况下，作为独立的本地信息枢纽，提供离线地图、急救指南、通讯录等关键资源。
- **远程教育与培训**：为偏远地区学校、野外考察团队或船只提供不受网络限制的教育内容库与AI辅导工具。
- **隐私保护环境**：研究敏感课题或处理机密信息时，确保所有数据处理和知识检索均在本地完成，无外部数据泄露风险。
- **数字游民与旅行者**：在移动网络不稳定或昂贵的地区，建立一个可随身携带的微型知识服务器，随时随地查阅资料。

## 项目亮点

与同类离线知识管理工具相比，Project N.O.M.A.D. 的独特优势在于：

- **完整离线生态**：并非简单缓存网页，而是构建了包含AI、知识库、工具链的完整本地服务栈，真正摆脱网络依赖。
- **低门槛部署**：仅需一条命令即可完成安装，无需复杂的Docker配置或手工编译，对非技术人员友好。
- **活跃社区与持续更新**：项目拥有活跃的Discord社区，并定期发布更新，持续改进知识库内容和软件功能。
- **开源与可扩展**：基于Apache-2.0许可开源，用户可自由修改、扩展或集成自定义知识模块。
