## 项目概述

Taste-Skill 是一个为 AI 前端界面生成提供“品控”的开源工具包，旨在解决当前 AI 生成界面普遍存在的“千篇一律、乏味俗套”（slop）问题。该项目通过一系列可移植的 Agent Skills（代理技能），指导 AI 在构建用户界面时遵循更优秀的布局、排版、动效和间距规范，从而产出具有高级审美、而非模板化外观的前端代码。目标用户包括使用 Codex、Cursor、Claude Code 等 AI 编程助手的前端开发者、设计师以及希望提升 AI 生成 UI 质量的任何技术人员。

项目还包含图像生成技能，用于创建参考板（涵盖 Web、移动端、品牌套件等），可配合 ChatGPT Images 或其他图像生成工具使用，生成高质量视觉参考，再交由编码 AI 实现。项目基于 MIT 开源协议，在 GitHub 上已获得超过 3.7 万星标，社区活跃度极高。

## 核心功能

- **布局优化技能**：指导 AI 避免使用简单堆叠的 block 布局，转而采用网格、弹性盒等现代布局模式，实现更丰富的页面结构。
- **排版与字体技能**：内建对可变字体、层级化字号、行高、字间距的精确控制逻辑，使 AI 生成的文字排版具备专业设计水准。
- **动效与过渡指引**：提供微交互、悬停效果、页面加载动画等标准，避免 AI 生成静态、呆板的界面。
- **间距与节奏规则**：制定一致的间距体系（如基于 4px 或 8px 的栅格），确保 AI 生成的元素间隔协调、视觉平衡。
- **图像生成参考板**：包含面向 Web、移动端、品牌套件的提示词模板，可生成高质量设计参考图，作为后续编码的视觉锚点。
- **多平台兼容**：技能文件可无缝导入 Codex、Cursor、Claude Code 等主流 AI 编码工具，即插即用。

## 技术架构

Taste-Skill 采用模块化、声明式的设计思路。其核心技能以纯文本形式（如 Markdown、YAML 或特定结构化的指令文件）存储，不依赖任何特定运行时或框架。每个技能文件聚焦一个设计维度（如布局、色彩、动效），包含明确的规则定义、示例代码片段以及前后对比案例。

项目根目录按技能类型组织子目录（如 `skills/layout`、`skills/typography`、`skills/motion`），每个技能文件内采用“规则 + 示例 + 反例”的格式，便于 AI 理解并遵守。图像生成技能则封装为提示词模板（prompt templates），用户可将其直接复制到 ChatGPT、Midjourney 等工具中使用。

架构特点包括：
- **零依赖**：纯文本文件，无需安装包或构建工具。
- **可扩展**：用户可基于现有模板自定义新技能。
- **测试友好**：每个技能均可独立验证其对 AI 输出的影响。

## 安装与使用

Taste-Skill 无需传统意义上的“安装”。使用方式极为简单：

1. **克隆或下载仓库**
   ```bash
   git clone https://github.com/Leonxlnx/taste-skill.git
   ```
2. **选择技能文件**：进入 `skills/` 目录，挑选所需技能文件（如 `skills/layout/layout-rules.md`）。
3. **导入 AI 工具**：
   - **Codex/Cursor**：将技能文件内容复制到项目的 `.cursorrules`、`.clinerules` 或系统提示词中。
   - **Claude Code**：在对话中粘贴技能内容，或作为项目文档附加上下文。
4. **使用图像技能**：打开 `skills/image-gen/` 下的提示词模板，复制到 ChatGPT 或 Midjourney 中生成设计参考图。
5. **迭代与调整**：将生成的设计图作为视觉参考，结合编码技能文件，指导 AI 进行前端实现。

**最小可用示例**：将一个布局技能文件作为前置指令，然后对 AI 说“根据这个布局规则，为我的电商首页生成一个响应式导航栏”，即可获得符合设计规范的代码。

## 适用场景

- **前端开发提速**：团队使用 AI 编码工具时，通过 Taste-Skill 确保生成代码从一开始就遵循优秀设计原则，减少后期重构。
- **设计系统构建**：在搭建组件库或设计系统时，用技能文件统一 AI 的输出风格，保证所有组件在字体、间距、动效上的一致性。
- **创意原型生成**：设计师或产品经理可先用图像技能生成高品质视觉参考，再交由 AI 编码实现，缩短从概念到可交互原型的周期。
- **教育与文档**：作为设计规范指南，教导新人理解什么是“好品味”的 UI，附带具体代码示例和反例对照。

## 项目亮点

- **极低上手门槛**：无需学习新工具或框架，只需将文本文件内容粘贴到 AI 工具中即可生效，真正做到“即插即用”。
- **聚焦本质问题**：不同于其他仅提供代码模板的项目，Taste-Skill 直接解决 AI 输出审美缺失这一根本问题，强调“品味”而非“功能”。
- **视觉 + 编码双轨支持**：同时提供图像生成技能和编码技能，覆盖从设计构思到代码实现的全流程。
- **社区驱动进化**：基于开源社区反馈不断迭代技能文件，用户可贡献自己发现的优秀规则或反例，形成正向循环。
- **跨工具兼容**：单一技能格式同时适配 Codex、Cursor、Claude Code 等主流工具，无供应商锁定。
