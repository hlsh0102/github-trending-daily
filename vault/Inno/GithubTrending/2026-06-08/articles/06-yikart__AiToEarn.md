## 项目概述

AiToEarn 是一个面向 OPC（一人公司）、创作者和企业的 AI 内容营销智能体平台。它通过 AI Agent 自动化技术，帮助用户在抖音、小红书、YouTube、TikTok 等 13 个全球主流社交平台上完成内容创作、分发和变现的全流程管理。项目旨在解决个人或小团队在多平台内容运营中效率低下、创意枯竭和变现困难的痛点，让用户无需技术背景即可借助 AI 实现自动化营销。

## 核心功能

- **多平台内容一键分发**：支持抖音、小红书、快手、B 站、视频号、YouTube、Facebook、Instagram、Threads、Twitter（X）、Pinterest、LinkedIn 等主流平台，实现跨平台内容同步发布。
- **AI 驱动的内容生成**：集成多种 AI 模型（包括 HappyHorse 1.0、Seedance 2.0 等），支持视频/图文草稿的批量生成、多模型选择、参考图片/视频上传以及定制化文案提示词。
- **内容交易市场**：用户可直接在平台上进行内容素材、模板和创作资源的买卖交易，将内容创作能力变现。
- **自动化社交媒体互动**：支持 Twitter/X 的自动探索与互动功能，帮助用户持续活跃帐号、扩大影响力。
- **灵活的使用方式**：提供网页端直接使用、集成到 Claude/Cursor 等 AI 助手、Docker 私有化部署、源码开发等多种接入方式，满足不同用户需求。
- **OpenClaw（龙虾）集成**：支持在龙虾平台中直接接收并执行内容变现任务，进一步扩展自动化营销的边界。

## 技术架构

AiToEarn 采用前后端分离的架构设计，后端基于 TypeScript 开发，利用现代 Node.js 运行时提供高性能 API 服务。前端采用响应式界面，适配电脑端和移动端使用。项目核心设计思路是“Agent 自动化 + 通用适配”，通过封装统一的平台 API 接口层，实现对 13 个社交平台的内容发布、数据获取和互动操作的标准化适配。同时，项目支持 MCP 协议，使其可以与 Claude、Cursor 等主流 AI 工具无缝集成，作为外部工具扩展使用。对于需要私有化部署的用户，项目提供了完整的 Docker 一键部署方案，保证了数据安全和自主可控。

## 安装与使用

AiToEarn 提供了 5 种使用方式，用户可根据自身需求选择：

1. **直接打开网站**：访问 aitoearn.ai 即可使用所有功能，无需安装任何软件。
2. **在龙虾 OpenClaw 中使用**：龙虾用户可直接在平台内启用 AiToEarn 插件，接收和执行内容变现任务。
3. **在 Claude/Cursor 等 AI 助手中使用**：通过 MCP 协议集成，将 AiToEarn 作为外部工具调用。
4. **Docker 一键部署**：
   ```bash
   docker pull aikart/aitoearn:latest
   docker run -d -p 3000:3000 --name aitoearn aikart/aitoearn:latest
   ```
   部署后访问 `http://localhost:3000` 即可使用。
5. **源码开发**：克隆仓库后，执行 `npm install` 安装依赖，配置 `.env` 环境变量，然后 `npm run dev` 启动开发服务器。

使用方式 ②③④ 需要先获取 API Key，具体操作方法请参考仓库文档中的“如何获取 API Key”部分。

## 适用场景

- **一人公司（OPC）的日常运营**：个人创业者或自由职业者，需要同时管理多个社交平台的内容发布和互动，利用 AiToEarn 的自动化生成和分发功能大幅提升效率。
- **品牌内容矩阵管理**：中小企业希望通过多个平台建立品牌影响力，但人力有限，可将内容创作、排期发布交由 AI 智能体自动化处理。
- **内容创作者的变现补充**：在各大平台创作内容的个人创作者，可以在内容交易市场上出售自己的模板、素材或作品，开辟新的收入来源。
- **AI 工具使用者的工作流增强**：已经使用 Claude、Cursor 等 AI 工具的用户，可以通过 MCP 协议集成 AiToEarn，将内容营销能力直接纳入现有工作流程。
