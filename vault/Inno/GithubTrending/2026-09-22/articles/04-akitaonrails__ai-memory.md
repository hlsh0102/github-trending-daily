ai-memory 是一个为 AI 编码代理提供长期记忆的解决方案，使用 Rust 编写。它解决了代理在任务中断或切换不同代理工具（如从 Claude Code 切换到 OpenAI Codex）后，需要重新解释项目架构、失败尝试和未决问题的问题。该项目适合需要在同一目录下跨不同 AI 代理工具进行连续开发，并希望保留上下文和工作进度的开发者。
