## 项目概述

Superpowers 是一套面向编码代理（coding agents）的完整软件开发方法论，基于一组可组合的技能（skills）和初始指令构建，确保你的编码代理在开发过程中始终遵循系统化的流程。该项目解决的核心问题是：当前编码代理往往在接到任务后直接跳入代码编写，缺乏需求澄清、设计确认、任务分解和质量保障的系统性方法，导致生成代码质量不稳定、返工频繁、维护困难。

Superpowers 的目标用户是深度使用 AI 编码工具的开发者和团队，适用于 Claude Code、Cursor、Codex 等主流 AI 编程平台。无论你是在构建小型脚本还是大型项目，Superpowers 都能通过结构化的开发流程，让编码代理从 "随意写代码" 转变为 "遵循工程方法论的专业开发者"。

## 核心功能

- **需求驱动的开发起点**：编码代理启动后不会立即写代码，而是主动询问用户真正想要实现的目标，从对话中提炼出清晰的规格说明，并以可理解的块状方式展示给用户确认。
- **规格驱动的设计流程**：在用户签署设计后，代理会生成一份实现计划，该计划足够明确，即使是 "热情但缺乏经验、没有判断力、没有项目上下文、厌恶测试的初级工程师" 也能照着执行。
- **严格的 TDD/DRY/YAGNI 方法论**：强调真实红绿测试驱动开发（TDD），遵循 YAGNI（你不需要它）原则避免过度设计，并严格执行 DRY（不要重复自己）原则。
- **子代理驱动开发**：一旦用户批准，代理会启动子代理驱动开发流程，逐个完成工程任务，每个任务完成后进行审查和检查，确保代码质量符合预期。
- **自主工作时间长**：得益于上述结构化流程，编码代理能够自主工作数小时而无需频繁干预，大幅提升开发效率。
- **多平台支持**：内置对 Claude Code、Cursor、Codex、Gemini CLI、GitHub Copilot CLI 等主流编码工具的开箱即用支持。

## 技术架构

Superpowers 的技术架构基于 "组件化技能 + 初始指令" 的轻量级设计。核心是一个可组合的技能集合，每个技能封装了软件开发中的一个特定环节（如需求分析、测试编写、代码审查），技能之间通过明确的输入输出接口互相协作。

项目采用 Shell 语言实现（也可嵌入其他语言环境），通过初始化指令将技能绑定到用户的编码代理上。一旦绑定，代理每收到新的开发请求，都会自动按照预定义的心智模型分步执行：先询问目标，再生成规格，然后确认设计，最后以 TDD 方式实现。这种设计使得方法论本身与具体 AI 模型解耦，在不同工具间具备良好的可移植性。

架构上的关键点是 "流程优于提示词"。Superpowers 没有依赖苛刻的提示词工程，而是通过将软件开发流程拆解为可独立执行的子任务，让代理能够在每个阶段清晰地知道自己在做什么、下一步要做什么，以及如何验证当前产物是否合格。

## 安装与使用

Superpowers 的安装方式依据你所使用的编码工具而有所不同。以 Claude Code 为例，基本步骤如下：

1. 在项目目录下初始化编码工具的环境。
2. 将 Superpowers 仓库克隆或复制到合适的位置，并在你的代理配置中引用其 skill 文件夹和初始化指令。
3. 对于其他工具（如 Cursor、Codex CLI、Gemini CLI 等），遵循 README 中对应的快速入门指引进行类似配置。

配置完成后，最小可用示例：启动你的编码代理，输入一个开发请求（例如 "实现一个用户登录 API"）。你会看到代理**不会**立即生成代码，而是返回一系列澄清问题，例如 "用户如何注册？密码加密要求？是否支持第三方登录？" 在对话完成后，代理向我展示规格说明，待你确认后，它才会进入实现阶段。

例如：

```
用户：写一个 URL 缩短服务
代理：好的，我需要确认几个问题。1. 用户是否登录后使用？2. 短链接有效期？3. 是否需要统计点击次数？...
用户：匿名即可，永久有效，需要点击统计。
代理：好的，以下是规格草案，请确认...（略）
用户：确认。
代理：下一步是制定实现计划，我将采用 TDD 方式，先写测试，再实现代码。是否开始？
用户：开始。
代理：已启动子代理执行任务，预计 20 分钟完成。完成后我会汇报测试结果和代码摘要。
```

## 适用场景

- **大型项目开发流程管理**：当项目规模较大、模块较多时，Superpowers 可以确保每个功能都经过需求确认、测试验证，避免代理在无人监督的情况下写出难以维护的代码。
- **团队协作中的一致性保障**：当多人共用编码代理时，Superpowers 能够统一代理解题套路，减少个人经验差异导致的风格混乱，让代码审查和改进更加顺畅。
- **外包或远程开发**：当你把任务交给编码代理后需要长时间离开（例如晚上或周末），Superpowers 可以让代理在无干预状态下持续工作并产生高置信度输出。
- **教育培训与学习**：对于希望通过 AI 工具学习软件开发规范的新手，Superpowers 展示了一种 "专业开发者的工作方式"，潜移默化地传递工程实践。

## 项目亮点

- **真正的方法论，而非提示词集合**：Superpowers 将软件工程中成熟的实践（TDD、YAGNI、DRY、子代理分工）结构化封装，而非依赖临时性的暗示或技巧。
- **流程驱动的质量保障**：通过强制前置规格设计和实现计划，显著降低了代理返工的概率，提升了最终代码的可测试性和可维护性。
- **跨平台兼容性强**：官方提供对超过 10 种主流编码代理工具的一键接入方案，覆盖面广，用户可以无缝迁移。
- **完全开源合规**：采用 MIT 许可证，允许自由使用、修改和商用，社区活跃度极高（已获超过 26 万 Star），持续获得改进。
- **极低的接入成本**：不需要修改底层模型，只需复制技能文件和初始指令即可启用，普通开发者也能轻松上手。
