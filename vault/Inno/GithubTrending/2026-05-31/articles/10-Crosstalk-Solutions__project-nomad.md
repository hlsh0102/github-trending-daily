## 项目概述

Project N.O.M.A.D.（Node for Offline Media, Archives, and Data）是一个面向离线场景的知识与教育服务器。它是一台“自给自足的生存计算机”，内置关键工具、知识库和人工智能能力，旨在让用户在无网络、无基础设施的环境中依然能够获取信息、学习知识和执行关键任务。

该项目的目标用户包括：应急准备者、野外考察人员、偏远地区工作者、数字隐私倡导者，以及任何希望在不受互联网依赖的情况下保持信息掌控力的个人或组织。

## 核心功能

- **离线 AI 助手**：内置本地运行的 AI 模型，无需网络即可进行问答、信息检索和知识推理，支持自然语言交互。
- **预载知识库**：包含百科全书、技术手册、医疗指南、生存技能等经过精选的离线内容，涵盖多个关键领域。
- **工具集整合**：提供实用工具如计算器、单位换算、文本处理、文件转换等，全部在浏览器中离线运行。
- **离线媒体服务**：支持离线播放视频、音频、PDF 和其他文档，无需流媒体或云端依赖。
- **自托管与便携部署**：可安装在 Debian 系统（推荐 Ubuntu）上，完全通过终端安装，所有功能通过浏览器访问，无需桌面环境。
- **一键安装与更新**：提供简单的命令行安装脚本，支持通过脚本快速部署和后续更新。

## 技术架构

Project N.O.M.A.D. 采用 TypeScript 为主要开发语言，使用 Node.js 作为后端运行环境。其核心设计围绕“离线优先”理念展开：

- **本地运行**：所有组件和服务均在本地启动，不需要外部服务器或网络连接。前端通过浏览器访问本地运行的 HTTP 服务器（默认端口 8080）。
- **模块化内容管理**：知识库和工具集以模块化方式组织，便于扩展和定制。内容预打包在安装包中，首次安装后即可离线使用。
- **嵌入式 AI 引擎**：集成了轻量级 AI 推理引擎，支持无网络环境下的自然语言处理和知识问答。AI 模型经过优化以在低功耗设备上运行。
- **全浏览器访问**：所有用户界面均为 Web 应用，通过浏览器渲染。这意味着用户可以通过任何有浏览器的设备（包括手机、平板）连接到服务器进行使用。
- **Debian 系适配**：安装脚本针对 Debian 系统优化，利用系统包管理器和本地依赖，确保兼容性和稳定性。

## 安装与使用

### 系统要求
- 操作系统：Debian 系（推荐 Ubuntu）
- 权限：需要 sudo/root 权限执行安装脚本
- 硬件：至少 2GB 内存，10GB 可用磁盘空间

### 快速安装

在终端中执行以下命令：

```bash
sudo apt-get update && \
sudo apt-get install -y curl && \
curl -fsSL https://raw.githubusercontent.com/Crosstalk-Solutions/project-nomad/refs/heads/main/install/install_nomad.sh \
  -o install_nomad.sh && \
sudo bash install_nomad.sh
```

### 启动与访问

安装完成后，打开浏览器，访问：
- 本地访问：`http://localhost:8080`
- 局域网访问：`http://设备IP地址:8080`

首次访问将进入主界面，您可以通过导航菜单浏览知识库、使用工具、与 AI 助手对话。

### 最小可用示例

1. 安装完成后，在浏览器打开项目主页。
2. 点击“AI 助手”图标，输入问题如“如何进行人工呼吸？”或“解释光合作用过程”，AI 将基于本地知识库回答。
3. 浏览“百科全书”模块，搜索“急救”获取离线医疗指南。
4. 使用“工具箱”中的单位换算器或文本编辑器完成日常任务。

## 适用场景

- **应急与灾难恢复**：在自然灾害、网络中断或基础设施损坏时，N.O.M.A.D. 提供离线知识检索和通信替代方案，帮助救援人员和受灾者获取生存指南、医疗建议和应急工具。
- **野外考察与科学探索**：地质学家、生物学家或探险家在无网络区域进行野外工作时，可携带 N.O.M.A.D. 作为便携知识库，查阅野外手册、记录数据、分析样本。
- **隐私敏感环境**：对于需要完全脱离网络监控的领域（如政府机构、军事基地、安全研究），N.O.M.A.D. 提供零网络依赖的信息处理环境。
- **教育普惠**：在偏远学校或网络覆盖不足的地区，部署 N.O.M.A.D. 作为离线教学服务器，学生可以通过本地网络访问教育资源和 AI 教学助手。

## 项目亮点

- **真正的离线可用**：不同于许多“离线”方案需要首次在线下载或定期同步，N.O.M.A.D. 安装后即可完全离线运行，无需任何网络连接。
- **集成 AI 能力**：在其他离线工具中，这是为数不多提供本地 AI 知识问答功能的项目，且对硬件要求低，普通 PC 即可流畅运行。
- **一键部署友好性**：单条 curl 管道安装命令，无需手动配置依赖、数据库或环境变量，非常适合非技术用户快速上手。
- **开源与可定制**：基于 Apache-2.0 许可证开源，用户可根据需要修改知识库内容、扩展工具集或开发自定义功能。
- **便携服务器设计**：安装过程不依赖桌面环境，意味着可以安装在树莓派、老笔记本或小型服务器上，真正实现“随身携带的知识节点”。
