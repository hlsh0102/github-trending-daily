## 项目概述

VoxCPM2 是由 OpenBMB 团队开发的一款基于 Transformer 的无分词器（Tokenizer-Free）文本到语音（TTS）模型。它无需依赖传统的音素或声学特征提取流程，直接以原始文本和音频波形为输入，通过端到端训练实现高质量的多语言语音合成。该项目解决了传统 TTS 系统在多语言支持、声音克隆和语音创意设计等方面的局限性，尤其适用于需要高自然度、多语言混合或个性化定制的语音生成场景。目标用户包括语音应用开发者、内容创作者、研究人员以及需要在教育、娱乐、辅助技术等领域使用合成语音的开发者。

## 核心功能

- **多语言语音生成**：支持包括中文、英文在内的多种语言，能够处理混合语言输入，无需预先指定语言标签
- **去分词器设计**：直接对原始文本和音频波形进行建模，跳过了传统 TTS 中音素标注、声学特征提取等复杂预处理步骤
- **真实感声音克隆**：仅需数秒参考音频样本，即可高保真地克隆目标说话人的音色、语调和韵律风格
- **创意声音设计**：支持通过提示词或条件控制调节声音属性，如年龄、性别、情感、语速等，实现定制化的声音风格
- **零样本适应**：在未见过的说话人声音上也能快速适应，无需重新训练模型
- **低延迟推理**：基于 Transformer 的高效解码架构，支持实时或接近实时的语音合成

## 技术架构

VoxCPM2 的核心创新在于其“无分词器”方案。传统 TTS 系统通常需要先将文本转换为音素序列，再将音频转换为声学特征（如梅尔频谱），然后通过各自的模型进行转换。VoxCPM2 则使用统一的 Transformer 架构直接处理原始文本和音频波形，采用自监督学习方式学习文本到语音的映射关系。

模型基于编码器-解码器结构，编码器处理文本输入，解码器生成连续的音频波形。训练过程中，模型通过对比学习和掩码建模等策略，从大量无标注语音-文本对中学习跨模态对齐。这种设计减少了信息丢失，同时避免了因分词错误引入的偏差。架构上还采用了多尺度注意力机制，以同时捕捉局部音素细节和全局韵律结构。

模型的另一个关键设计是“条件控制嵌入”模块，它允许用户通过嵌入向量控制生成语音的说话人特征、情感风格等属性，而无需修改模型内部权重。这使得单次训练出的模型即可适应多种下游任务。

## 安装与使用

VoxCPM2 基于 Python 开发，依赖 PyTorch。推荐通过 pip 安装：

```bash
pip install voxcpm
```

最小可用示例：

```python
from voxcpm import VoxCPM2

# 加载预训练模型
model = VoxCPM2.from_pretrained("openbmb/VoxCPM2")

# 文本到语音
audio = model.synthesize("你好，欢迎使用 VoxCPM2 语音合成系统。")

# 保存音频文件
model.save_audio(audio, "output.wav")

# 声音克隆（使用参考音频）
reference_audio = "speaker_sample.wav"
audio_cloned = model.synthesize_with_reference(
    text="这是通过声音克隆生成的语音。",
    ref_audio=reference_audio
)
```

更多高级用法，包括多语言输入、情感控制、批量处理等，请参考[官方文档](https://voxcpm.readthedocs.io/)。

## 适用场景

- **多语言内容创作**：为视频、播客、有声书等生成多语言旁白或配音，支持在同一段语音中混合使用不同语言，实现自然的语码转换效果
- **个性化语音助手**：为智能音箱、手机助手或车载系统定制专属语音，通过声音克隆实现熟悉或喜爱的声音叙事
- **辅助技术**：为视力障碍者或阅读困难者提供高自然度的语音阅读服务，支持定制语速和音调以满足不同需求
- **游戏与交互设计**：在游戏角色、虚拟主播、教育机器人等应用中生成个性化的语音对话，增强用户沉浸感

## 项目亮点

与同类项目（如传统 Tacotron、VITS 或 FastSpeech 系列）相比，VoxCPM2 的核心差异化优势在于其“无分词器”架构。传统 TTS 系统需要经过音素标注、音节分割等繁琐的预处理，且这些步骤通常依赖特定语言的规则。VoxCPM2 跳过了这一环节，直接学习文本到音频的映射，不仅降低了部署门槛，也天然支持多语言混合输入，无需为每种语言单独训练。

此外，VoxCPM2 在声音克隆和创意设计方面表现出更高的保真度。仅需数秒参考音频即可实现高还原度的声音克隆，并且支持零样本适应，大大降低了定制声音的门槛。模型的创意声音设计能力（如控制年龄、情感等）也为语音应用开辟了新的可能性，这在传统 TTS 中通常需要额外训练或修改模型。

项目采用 Apache 2.0 开源协议，提供了完整的文档、预训练模型和多种交互式演示，降低了使用门槛。同时，团队持续更新社区版本，并提供了 Hugging Face 和 ModelScope 上的模型权重，方便研究者快速复现和二次开发。
