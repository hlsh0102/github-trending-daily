## 项目概述

Harness 是一个为 Claude Code 设计的“团队架构工厂”式元技能插件。它的核心使命是：当用户对 Claude Code 说出“为这个项目构建一个 harness”或韩语/日语的类似指令时，Harness 能够自动分析当前项目的领域上下文，设计出专门针对该领域的智能体团队，定义每个智能体的专业角色，并生成它们实际使用的技能（Skills）。简而言之，Harness 解决了如何让 AI 编码助手从“单兵作战”升级为“专业化团队协作”的问题。目标用户是所有希望利用 Claude Code 进行复杂软件开发、希望获得更精准、更结构化 AI 辅助的开发者与团队。

## 核心功能

- **领域驱动团队设计**：自动分析项目代码库的领域、技术栈和业务逻辑，设计出由多个角色（如架构师、测试专家、API 开发者等）组成的专用智能体团队。
- **智能体角色定义**：为团队中的每个智能体定义明确的职责、知识边界、输入输出规范，确保各司其职。
- **技能自动生成**：为每个智能体生成其专属技能（Skills），这些技能是高度定制化的提示词集合，使智能体能够高效执行特定任务。
- **多语言指令支持**：支持英文（“build a harness for this project”）、韩文（“하네스 구성해줘”）、日文（“ハーネスを構成して”）等多种自然语言指令触发。
- **架构模式选择**：内置 6 种经典团队架构模式，可根据项目需求灵活选择，如“开发者-评审者”、“前端-后端-测试”等模式。
- **即插即用集成**：作为 Claude Code 的插件，安装后即可在对话中按需触发，无需复杂的配置流程。

## 技术架构

Harness 的技术设计分为三个关键层：

1.  **元层（Meta Layer）**：Harness 本身不直接执行代码任务，而是作为一个 L3（第三层）的元工厂。它位于 AI 对话之上，负责接收用户的高级指令，分析项目，并根据这些分析结果生成新的、定制化的 AI 交互模式。
2.  **团队架构工厂（Team-Architecture Factory）**：项目的核心机制是一个生成式工厂。它将用户的项目作为输入，使用预定义的架构模式库（6 种模式）和领域分析引擎，输出一套完整的团队定义文件（如`harness.team.json`或类似的结构化配置）。
3.  **技能生成流水线（Skill Generation Pipeline）**：针对分析出的每个智能体角色，Harness 会运行一个专门的生成器。这些生成器基于模板和项目上下文，填充具体的提示词、知识上下文和 API 调用示例，形成最终可执行的“技能”文件。

从设计思路上，Harness 借鉴了“微服务架构”和“领域驱动设计”的概念，但将其应用到了 AI 智能体的组织与管理中。它强调模块化、职责单一和可组合性，使得生成的团队既专业又灵活。

## 安装与使用

以下安装步骤基于常见的 Claude Code 插件安装方式（因官方可能更新，请以仓库最新 README 为准）：

1.  **环境准备**：确保你已安装 Claude Code 客户端，并拥有一个可用的 Anthropic API Key。
2.  **安装 Harness**：在终端中，进入你的项目根目录，运行以下命令安装 Harness 插件（假设为 Claude Code 的 `install` 命令）：
    ```bash
    claude install revfactory/harness
    ```
    或手动将仓库中的 `harness` 文件夹放置到 Claude Code 的插件目录中。
3.  **触发构建**：在 Claude Code 对话界面中，输入触发指令。例如：
    ```
    build a harness for this project
    ```
4.  **选择模式**：Claude 会分析你的项目，然后列出可选的团队架构模式（如“开发者-测试者合作模式”、“全栈分离模式”等）。根据项目特点选择一个。
5.  **使用团队**：Harness 生成配置后，你的 Claude Code 会话中就会自动激活一个专业化团队。你可以开始提问如“前端智能体，帮我重构这个组件的样式”，后续的 AI 回复将自动由对应的团队角色处理。

**最小可用示例**：
用户只需一条指令，即可将一个通用编码助手升级为一个包含“架构师”和“代码实现者”的二人团队，从而在复杂重构项目中获得更高质量的方案建议和代码输出。

## 适用场景

- **大型企业级项目重构**：当需要重构一个包含多模块、多语言的大型项目时，Harness 可以组建包含“架构师-后端开发者-测试专家”的团队，确保重构安全性和一致性。
- **微服务开发与治理**：在开发微服务架构时，可以为每个服务或服务组设计一个专门的智能体团队，进行独立的开发、测试和文档生成。
- **多角色协作开发**：在需要前端、后端、数据库、UI/UX 等多角色协作的场景下，Harness 能够生成相应的全栈团队，让 AI 输出更贴近真实开发流程。
- **AI 辅助代码审查**：通过自动生成“代码审查员”智能体，Harness 可用于对每日提交的代码进行系统化的、基于项目规则的审查，降低人工审查压力。

## 项目亮点

与常见的单点 AI 编码辅助工具不同，Harness 的独特之处在于：

- **元技能思维**：它不是教你写代码的技能，而是教你如何组织 AI 智能体的“技能”。这属于更高阶的 AI 能力编排，能从根本上改变 AI 的协作效率。
- **自动化工厂**：用户无需手动定义角色和技能，整个过程是自动化的。输入一个指令，得到一整套团队配置，这极大降低了使用门槛。
- **领域自适应**：Harness 会读取项目代码，理解其领域，从而生成的团队和技能是高度定制化的、针对当前项目的，而不是千篇一律的模板。
- **架构模式库**：内置的 6 种经典架构模式覆盖了大多数开发场景，用户无需从零设计团队结构，开箱即用且可选可配。
