## 项目概述

ECC（Effective Control of AI Agents）是一个面向 AI 编程代理的工具链性能优化系统。它并非简单的配置文件集合，而是一套完整的体系化工具，旨在提升 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程代理在实际开发中的表现。该项目解决了多个代理工具在混合使用时的效率低下、记忆碎片化、安全风险不可控以及缺乏持续学习能力等核心问题。目标用户包括使用 AI 辅助编程的专业开发者、DevOps 工程师以及对代理工作流有深度定制需求的团队。

## 核心功能

- **技能模块化**：将常用开发操作封装为可复用的技能单元，支持跨工具、跨项目的移植与组合，减少重复性指令编写。
- **直觉系统**：通过上下文感知和模式匹配，让代理能根据项目结构和历史行为智能预测下一步操作，提升交互流畅度。
- **记忆优化**：实现跨会话的长期记忆管理，自动压缩、索引和检索关键上下文信息，避免代理在长对话中遗忘重要约束。
- **安全扫描**：内置安全检测引擎，在代理执行代码生成、文件修改或网络请求前自动评估风险，拦截潜在的注入攻击或敏感数据泄露。
- **持续学习**：支持从用户反馈和运行日志中自动提取经验，动态更新代理的行为策略，实现开箱即用后的自我进化。
- **多代理编排**：统一管理不同底层框架的代理实例，协调它们在同一个工作流中的角色与任务分配，避免资源冲突。

## 技术架构

ECC 采用插件化的分层架构，核心引擎使用 JavaScript 编写，底层通过标准化的协议接口与各类 AI 代理工具进行通信。上层提供一套声明式配置系统，用户通过 YAML 文件定义技能、直觉规则和记忆策略。中间层是运行时管理器，负责解析配置、调度代理执行并收集反馈数据。最底层是安全防护层，结合静态分析和运行时监控实现双向保护。项目还设计了一个轻量级的嵌入式数据库，专门用于存储和检索事件驱动的记忆片段，支持高效的模糊匹配和时间线回溯。架构的亮点在于其松耦合设计，使得对某一功能的升级不会影响其他模块的正常运行。

## 安装与使用

ECC 可通过 npm 全局安装：
```bash
npm install -g ecc-universal
```

安装后，在项目根目录创建 `ecc.config.yaml` 配置文件，定义代理类型和基础规则：
```yaml
harness: claude-code
skills:
  - git-flow
  - unit-test
memory:
  retention: session
  index: true
```

初始化工作区：
```bash
ecc init
```

启动代理工作台：
```bash
ecc run
```

对于多代理场景，可使用 `ecc orchestrate` 命令启动编排模式：
```bash
ecc orchestrate --agents claude-code,opencode --task "实现 API 接口"
```

项目还提供了 VSCode、JetBrains 等主流 IDE 的插件扩展，通过界面直接操作管理功能。

## 适用场景

- **跨工具 AI 开发工作流**：团队同时使用 Claude Code 编写复杂业务逻辑、用 Cursor 进行前端调试、用 Opencode 处理后端框架搭建，ECC 可统一协调这些工具，确保上下文连贯。
- **企业级安全审计**：在金融、医疗等对代码安全性要求高的领域，利用 ECC 的安全扫描功能，在代理生成或修改代码时自动拦截风险操作。
- **长期维护的大型项目**：对于代码库庞大、分支历史复杂的项目，ECC 的记忆优化功能帮助代理快速掌握项目结构和团队规范，减少重复提问。
- **个人开发者效率提升**：独立开发者可利用技能模块化功能，将常用的开发模式（如数据库迁移、API 文档生成）封装为指令模板，一键执行。

## 项目亮点

ECC 与同类项目的核心区别在于其系统思维。大多数解决方案只关注单一工具或单个功能（如记忆或安全），而 ECC 将技能、直觉、记忆、安全、学习整合为一个闭环系统。其多层架构设计使得用户可以在不改变代理底层模型的情况下，大幅提升输出质量。内置的持续学习机制更是罕见——它会记录代理的失误与成功，并在后续任务中自动调整行为策略，能够减少开发者的重复纠正次数。此外，项目对多代理编排的原生支持，使其在复杂工程流水线中表现突出。
