## 项目概述

MoneyPrinterTurbo 是一个基于 AI 大模型的全自动短视频生成工具。用户只需提供一个视频主题或关键词，系统就能够自动完成视频文案创作、素材匹配、字幕生成和背景音乐合成等全流程工作，最终输出一个高清短视频。该项目主要面向内容创作者、社交媒体运营人员、营销从业者和对短视频制作有需求的普通用户，帮助他们大幅降低短视频制作门槛，提高内容产出效率。

## 核心功能

- **自动文案生成**：集成 AI 大模型，根据用户输入的主题或关键词自动生成视频文案，同时也支持用户手动输入自定义文案
- **多尺寸高清输出**：支持竖屏 9:16（1080x1920）和横屏 16:9（1920x1080）两种主流视频尺寸，满足不同平台发布需求
- **全自动素材处理**：自动匹配视频素材、生成字幕、选择背景音乐，无需人工介入
- **API 与 Web 双模式**：提供完整的 API 接口和友好的 Web 界面，便于集成和直接使用
- **MVC 架构设计**：代码结构清晰，模型（Model）、视图（View）、控制器（Controller）分离，易于维护和扩展
- **多语言支持**：项目同时提供简体中文和英文文档，适应不同语言用户

## 技术架构

该项目采用 Python 开发，基于 MVC（Model-View-Controller）架构设计。前端 Web 界面基于主流框架构建，提供直观的用户操作界面；后端通过 API 接口暴露核心功能，便于第三方系统集成。在 AI 能力方面，项目集成了大语言模型用于文案生成，并利用计算机视觉技术进行视频素材的自动筛选与匹配。视频合成模块则负责将文案、素材、字幕和背景音乐按预设规格合并为最终视频文件。整体设计注重模块化和可扩展性，使得不同组件可以独立升级或替换。

## 安装与使用

### 安装步骤

1. 确保系统已安装 Python 3.8 及以上版本和 FFmpeg
2. 克隆仓库到本地：
```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
```
3. 安装依赖：
```bash
pip install -r requirements.txt
```
4. 配置 AI 大模型 API 密钥等相关参数（参考项目中的配置文件示例）

### 最小可用示例

启动 Web 界面：
```bash
python app.py
```

访问 `http://localhost:5000`，在页面中输入视频主题（例如“春日樱花摄影”），选择视频尺寸，点击生成按钮即可自动完成视频制作。若需要使用 API 模式，可参考项目文档中的接口说明进行调用。

## 适用场景

- **社交媒体内容批量生产**：适合需要在抖音、快手、小红书等平台高频发布短视频的个人或团队
- **营销推广素材制作**：企业营销人员可用于快速生成产品介绍、活动宣传等短视频内容
- **教育科普类视频创作**：教师或知识博主可用来自动化制作知识讲解类短视频
- **个人创意表达**：普通用户无需专业剪辑技能即可制作个性化短视频
