## 项目概述

AiToEarn 是一个面向 OPC（一人公司）、创作者和企业的 AI 内容营销智能体平台。它通过 AI Agent 自动化技术，帮助用户在全球主流社交平台上构建、分发并变现内容。项目名称直译为“用 AI 赚钱”，核心愿景是让内容创作者能够借助 AI 的力量，以更低的成本和更高的效率实现内容变现。项目由 yikart 在 GitHub 上以 MIT 协议开源，目前已获得超过 2 万星标，活跃度极高。

## 核心功能

- **多平台内容分发**：支持抖音、小红书、快手、B 站、视频号、TikTok、YouTube、Facebook、Instagram、Threads、Twitter（X）、Pinterest、LinkedIn 等 13 个国内外主流平台，实现一键分发或差异化分发。
- **AI Agent 自动化创作**：集成多种 AI 模型（如 HappyHorse、Seedance 等），可自动生成视频、图文草稿，支持参考图片/视频、目标平台限制与自定义文案提示词。
- **内容交易市场**：内置内容交易模块，创作者可在平台上承接内容变现任务，直接获得收益。
- **草稿批量生成**：支持批量生成多个格式（视频、图文）的草稿，并提供多模型选择和参考素材上传功能。
- **平台探索与互动**：增强对 Twitter/X 等平台的探索与互动能力，帮助用户发现热点并快速参与。
- **多接入方式**：支持通过 Web 网站、OpenClaw（龙虾）、Claude/Cursor 等 AI 助手、Docker 部署以及源码开发五种方式使用。

## 技术架构

项目采用 TypeScript 作为主要开发语言，具有良好的类型安全性和可维护性。其技术架构核心包括以下几个层面：

1. **AI Agent 引擎**：基于大语言模型（LLM）和生成式 AI 技术，构建内容创作与分发的自动化流程。引擎能够理解用户指令，调用不同 AI 模型生成适配各平台特性的内容。
2. **统一平台适配层**：通过抽象化的 API 接口层，对接 13 个主流社交平台的不同 API 规范，实现内容的上传、发布和互动。
3. **任务调度与队列系统**：支持批量内容生成和定时发布，将耗时的创作任务异步处理，提升用户体验。
4. **MCP 协议支持**：实现 Model Context Protocol（MCP）协议，使得项目可以作为 AI 工具（如 Claude、Cursor）的后端能力源，扩展 AI 助手的自动化范围。
5. **插件化架构**：通过 OpenClaw（龙虾）等插件机制，允许第三方开发者或平台扩展功能，目前已有内容变现任务的支持。

## 安装与使用

AiToEarn 提供了五种使用方式，以下介绍最常用的两种：

### 1. 直接使用 Web 网站（无需部署）
访问 [aitoearn.ai](https://aitoearn.ai) 即可开始使用，适合所有用户。注册后即可体验内容创作、分发和变现功能。

### 2. Docker 一键部署（私有化部署）
适用于想在自有服务器上部署的用户。前提条件：已安装 Docker 和 Docker Compose。

```bash
# 克隆仓库
git clone https://github.com/yikart/AiToEarn.git
cd AiToEarn

# 使用 Docker Compose 启动
docker-compose up -d
```

访问 `http://localhost:3000` 即可进入管理界面。

### 获取 API Key
使用 Docker 部署或在 AI 助手中使用前，需要先获取 API Key。请参考项目文档中的“如何获取 API Key”部分进行操作。

### 最小可用示例
以 Web 方式为例，注册登录后：
1. 选择目标平台（如微信公众号和 Twitter）。
2. 输入内容主题（如“AI 写作工具推荐”）。
3. 选择 AI 模型和内容格式（视频或图文）。
4. 点击“生成草稿”，系统自动生成并预览内容。
5. 确认后一键分发到所选平台。

## 适用场景

- **一人公司/独立创作者**：个人运营多个平台账号，需要高效产出并分发内容，同时希望将内容直接变现。AiToEarn 可以批量生成不同平台所需的不同风格内容，减少重复劳动。
- **品牌营销团队**：品牌方需要在多个社交媒体上保持账号活跃，但人力有限。AiToEarn 的自动化创作和任务调度能力可以帮助团队高效覆盖多个平台。
- **AI 应用开发集成**：开发者可以将 AiToEarn 作为后端能力，通过 MCP 协议集成到自己的 AI 助手或自动化流程中，实现内容营销的闭环。
- **内容变现探索者**：希望利用 AI 能力在社交平台上尝试内容变现的新手或进阶用户，可以通过内置的内容交易市场直接接单变现。

## 项目亮点

- **开源且商业友好**：采用 MIT 协议，个人和商业项目均可免费使用、修改和再分发，降低了 AI 内容营销的门槛。
- **多平台全覆盖**：同时支持国内外 13 个主流平台，是目前市场上支持平台最广的开源内容营销工具之一。
- **灵活的使用方式**：从零门槛的 Web 应用到高级的源码开发，满足从普通用户到技术团队的各种需求。
- **活性的社区生态**：项目活跃度极高，定期发布更新（如 2.4 版本新增 HappyHorse 1.0 和 Seedance 2.0），并积极拓展 OpenClaw 等插件生态，形成内容变现的良性循环。
- **AI Agent 而非简单模板**：使用 AI Agent 技术实现内容创作流程的自动化，而非简单的模板填充，生成的文案和视频更具个性化和平台适配性。
