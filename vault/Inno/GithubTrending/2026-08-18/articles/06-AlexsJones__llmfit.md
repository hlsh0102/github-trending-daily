## 项目概述

llmfit 是一个用 Rust 编写的开源命令行工具，旨在解决大语言模型（LLM）本地部署中的一个核心痛点：**如何快速判断一个模型能否在你的硬件上流畅运行**。它聚合了数百个模型和数十家模型提供方，通过一条命令即可基于你的 GPU 显存、内存和算力，给出模型运行可行性评估与推理性能估算。

该项目面向的典型用户包括：希望本地运行 LLM 的开发者、需要为团队选型硬件的技术负责人、以及任何想在购买或下载模型前预先了解其硬件适配情况的 AI 爱好者。llmfit 将原本需要查阅多份文档、手动比对模型参数与硬件规格的繁琐工作，压缩为一次终端操作。

## 核心功能

- **跨提供方模型搜索**：统一索引 Hugging Face、Ollama、LM Studio 等主流模型仓库的元数据，支持按名称、参数量、量化级别等条件过滤。
- **硬件适配诊断**：自动检测本机 GPU（NVIDIA/AMD/Apple Silicon）、显存容量、可用内存及 CPU 算力，并生成可运行的模型候选清单。
- **推理性能估算**：基于模型参数量、量化位数与硬件算力，估算每秒 token 生成速度（tok/s）及单次请求延迟，辅助模型选择。
- **一键基准测试与共享**（新增）：下载候选模型、自动启动本地推理服务，实测真实吞吐量，并将结果以 PR 形式回传至项目仓库，用真实数据持续优化全局估算模型。
- **本地优先与可审计**：所有测量结果先写入本地日志，再手动触发上传；不依赖任何第三方账号或 `gh` CLI，数据透明可查。
- **交互式 TUI 界面**：在终端内提供类表格的交互视图，支持键盘导航、排序与详细参数展开，无需离开终端即可完成全流程操作。

## 技术架构

llmfit 采用纯 Rust 实现，兼顾性能、内存安全与静态编译分发便利性。其架构分为三个核心层：

1. **硬件探测层**：通过 `sysinfo` 与平台专用 API（如 NVIDIA 的 NVML、Apple 的 `sysctl`）采集物理设备信息，统一归一化为内部硬件模型，屏蔽不同操作系统与 GPU 厂商的差异。
2. **模型匹配引擎**：内置启发式算法，结合模型参数量、量化位宽（4-bit/8-bit）、KV cache 占用等维度，计算模型对显存的占用曲线，并与探测到的硬件容量进行匹配。估算公式部分源自公开的推理性能数据，且会随社区提交的实测结果自动校准。
3. **TUI 与任务编排**：基于 `ratatui` 实现响应式终端界面，并通过异步任务管理模型下载（支持断点续传）、本地推理进程（兼容 llama.cpp 的 `/completion` 接口）以及结果回传流程。

设计上强调 **“先测量，后估计”** 的原则：系统的估算值仅作为初始参考，鼓励用户通过内置基准测试获取自身机器的真实数据，并通过贡献机制惠及整个社区。

## 安装与使用

### 安装

```bash
# 使用 Cargo 安装（需 Rust 工具链）
cargo install llmfit

# 或者从 GitHub Releases 下载预编译的 Linux/macOS/Windows 二进制
```

### 最小使用示例

```bash
# 1. 列出当前硬件可流畅运行的模型
llmfit suggest

# 2. 搜索特定模型的适配性
llmfit search --query "qwen2.5:7b" --quantization 4bit

# 3. 对某个模型进行实测基准
llmfit bench --model qwen2.5:7b --quantization 4bit
```

执行 `suggest` 命令后，TUI 会展示一个表格，列出模型名称、参数量、预估显存占用、预测 tok/s 等字段，并使用颜色高亮“推荐运行”和“勉强可跑”两类模型。`bench` 命令会自动完成下载、服务启动与测量，结束后询问是否将结果提交至上游仓库。

## 适用场景

- **硬件选购与升级辅助**：在购置新 GPU 或整机前，使用 `llmfit suggest` 对比不同配置下可运行的模型范围，避免买错硬件。
- **本地开发环境快速搭建**：开发者需要本地运行 Llama、Qwen、Mistral 等模型用于调试或私有化部署，通过 llmfit 一步获得可启动的模型清单。
- **模型量化方案选择**：同一模型在不同量化位数（8bit/4bit/2bit）下，运行可行性差异显著；llmfit 可以按量化级别对比显存占用与性能损失，辅助决策。
- **社区数据贡献与优化**：通过提交实测 benchmark 结果，间接帮助所有用户获得更精准的估算，形成良性循环。

## 项目亮点

- **极低的决策成本**：将过去需要数小时的人工调研压缩至数秒，且完全离线完成探测，不依赖云端服务。
- **众包校准的估算模型**：区别于静态查表或纯理论计算，llmfit 接受来自真实硬件的测量反馈，使其预测精度随使用人数增长而持续提升。
- **完善的工程化细节**：支持断点续传、异步任务、多平台签名（SignPath 验证），以及三语文档（中/英/日），在开源工具中展现出较高的完成度。
- **TUI 交互范式创新**：将原本属于 Web 界面或 GUI 的“适配推荐”流程，完整移植到终端，配合流畅的键盘操作，契合开发者日常习惯。
