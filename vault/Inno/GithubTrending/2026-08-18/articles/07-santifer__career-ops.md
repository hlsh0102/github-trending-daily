## 项目概述

career-ops 是一个开源的 AI 求职系统，它将传统求职流程中分散的环节——职位搜索、机会评估、简历定制和投递跟踪——整合到一个可在本地 AI 编码 CLI（如 Claude Code、Codex、OpenCode、Antigravity 等）中运行的自动化工作流中。

项目的核心理念是：当企业使用 AI 筛选候选人时，候选人同样应该拥有借助 AI 来选择企业的能力。career-ops 通过多智能体（Multi-Agent）架构，自动扫描职位门户，使用结构化的 A-F 评分标准对每个职位进行 1.0 到 5.0 分的量化评估，并基于评估结果针对性地定制简历，最终实现职位投递的全流程追踪。

该项目的主要目标用户是正在积极寻找工作机会的开发者、技术从业者以及其他需要高效管理求职流程的专业人士，尤其适合那些希望摆脱手动重复浏览职位、主观判断职位匹配度、低效修改多份简历的求职者。

## 核心功能

- **自动职位扫描**：自动连接并扫描主流职位门户，持续获取最新职位信息，无需手动打开多个招聘网站反复搜索。
- **结构化职位评分**：使用内置的 A-F 评估标准，从多个维度对每个职位进行考量，最终生成一个 1.0 到 5.0 的量化评分，让不同职位之间的比较变得客观且直观。
- **AI 简历定制**：根据职位评分结果和职位描述的具体要求，自动针对目标职位调整和优化简历，突出最相关的技能与经验，提升简历与职位的匹配度。
- **求职进度追踪**：对已投递的职位进行多状态管理，清晰记录从发现、评估、定制简历到最终投递的每一步，并提供全局视图以掌握求职进展。
- **本地化运行**：所有数据处理和 AI 推理均在本地环境中执行，保护个人隐私和求职数据安全，不依赖任何外部云服务进行简历内容处理。
- **多语言与多平台支持**：项目支持包括英文、中文、日文、韩文等在内的 16 种语言文档，适配主流的 AI 编码 CLI 平台。

## 技术架构

career-ops 基于 JavaScript 构建，采用多智能体（Multi-Agent）的系统设计，将复杂的求职流程拆解为多个职责单一、协同工作的智能代理模块：

1. **搜索代理（Search Agent）**：负责与外部职位门户 API 交互，执行搜索任务并拉取原始职位数据，作为整个系统的信息输入源。
2. **评估代理（Evaluation Agent）**：接收搜索代理获取的职位数据，应用 A-F 评分标准进行逐项分析。该评分标准不仅仅考虑薪资和技能匹配，还综合考量公司技术栈、远程政策、发展潜力等硬性指标，最终输出一个结构化的 1.0-5.0 数值评分。
3. **定制代理（Tailoring Agent）**：基于评估代理的详细打分结果，结合目标职位的描述，自动提取简历中的相关经历进行重点重写或重排，生成匹配度更高的定制化简历版本。
4. **跟踪代理（Tracking Agent）**：建立应用状态数据库，记录每一份投递的简历版本、职位链接、投递时间及当前状态，提供可查询的追踪面板。

整个系统的架构特点在于其“流程化的 Agent 编排”。用户通过自然语言或简单的 CLI 指令启动流程，各个代理按顺序执行，将原本需要数小时的人工重复劳动压缩为一次自动化的命令执行。由于全部运行在本地 AI 编码 CLI 环境中，用户无需在终端、浏览器和文档编辑器之间来回切换，所有操作可以在同一个开发工作流上下文内完成。

## 安装与使用

**前置要求**：需要安装 Node.js 环境，并准备一个可用的 AI 编码 CLI 环境（如 Claude Code 或 Codex）。

**安装步骤**：

1. 克隆仓库到本地目录：
   ```bash
   git clone https://github.com/santifer/career-ops.git
   ```

2. 进入项目目录并安装依赖：
   ```bash
   cd career-ops
   npm install
   ```

3. 配置环境变量或配置文件，填入你的 AI 平台 API 密钥以及需要扫描的职位门户源（如特定国家的招聘网站或公司招聘页面）。

**最小可用示例**：

在配置完成后，直接在 AI 编码 CLI 环境中调用核心工作流：

```bash
# 启动多智能体求职流程，扫描“前端工程师”职位
career-ops run "前端工程师"

# 查看本次扫描的所有职位及其 1.0-5.0 评分
career-ops list --scored

# 对评分最高的职位进行简历定制和投递跟踪
career-ops apply --top-rated
```

上述命令会自动触发搜索、评分、及简历定制流程，完成后可在终端中查看结果列表，并根据评分选择最优职位执行后续操作。

## 适用场景

- **高密度投递与筛选**：对于需要每天浏览大量信息、快速筛选潜在机会的求职者，该工具的自动化扫描和量化评分能够显著提升初期筛选效率。
- **远程或跨国求职**：当求职者需要多线程评估不同国家、不同公司类型（如远程优先、混合办公)的职位时，客观评分标准有助于在复杂条件下进行理性决策。
- **简历策略优化**：当求职者投递多个不同方向的职位（如同时考虑技术管理与资深开发角色）时，自动定制功能可以快速生成多套侧重点不同的简历版本，避免重复手工修改。
- **求职数据复盘**：对于希望回顾自己求职周期数据、分析哪种类型职位成功率更高的求职者，跟踪代理提供的进度记录和统计功能可以辅助进行后期的经验总结。

## 项目亮点

- **将“被动筛选”转为“主动选择”**：大多数求职者的流程是“海投”后等待回音，而 career-ops 通过结构化的评分机制，让求职者在投递前就能对机会进行客观比较，避免在低质量的职位上浪费时间和定制简历的精力。
- **本地化的隐私保护**：与多数云端 SaaS 求职工具不同，career-ops 完全本地运行。个人简历、职业偏好和 AI 反馈均不经过第三方服务器，对于数据敏感的用户而言，这是显著的安全优势。
- **与开发者工作流无缝融合**：无需打开新的网页应用，不需要在不同软件间复制粘贴。所有求职操作和 AI 交互都发生在开发者日常使用的 AI 编码 CLI 中，上下文切换成本极低，非常适合开发者使用习惯。
- **可观赏性与透明性**：与使用通用大模型直接生成简历不同，career-ops 的 A-F 评分体系是可解释、可验证的。用户可以查看每一个职位被打分的依据，而非接受一个黑盒推荐结果，增加了整个求职过程的可控性。
