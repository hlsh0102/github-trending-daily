## 项目概述

Immich 是一个高性能、自托管的照片与视频管理解决方案，专为那些希望完全掌控自己影像数据的用户而设计。在当今云存储服务日益普及的背景下，许多用户对照片和视频的隐私、存储位置和长期可访问性感到担忧。Immich 通过提供一个功能丰富、性能卓越的自托管平台，让用户能够在不依赖第三方云服务的情况下，安全地存储、组织、浏览和分享他们的珍贵回忆。

该项目采用 TypeScript 开发，遵循 AGPL-3.0 开源许可证，目前已在 GitHub 上获得超过 11 万星标，社区活跃度极高。Immich 的目标用户包括摄影爱好者、家庭用户、隐私倡导者以及任何对数据主权有明确要求的个人或组织。无论是希望替代 Google Photos 或 iCloud Photos 的用户，还是需要为团队或家庭搭建私有媒体库的开发者，Immich 都能提供一套可靠且易于扩展的解决方案。

## 核心功能

- **自动备份**：支持手机端和桌面端的自动照片与视频上传，可根据网络条件（如仅在 Wi-Fi 下）进行配置，确保媒体文件实时同步至服务器。
- **智能搜索**：内置基于机器学习的对象识别、场景分类和人脸识别功能，用户可通过自然语言关键词（如“海滩”、“生日聚会”）快速定位照片。
- **时间线浏览**：提供类似主流云相册的流式时间线界面，支持按日期、文件夹或相册进行浏览，并包含地图视图展示拍摄地点。
- **多用户支持**：支持创建多个用户账户，每个用户拥有独立的媒体库和隐私空间，适合家庭或小型团队共享使用。
- **元数据管理**：自动提取 EXIF 数据（拍摄时间、相机型号、GPS 位置等），并支持手动编辑和批量更新照片信息。
- **共享与协作**：允许创建共享相册，支持链接分享和嵌入式播放，便于与家人、朋友或客户协作。

## 技术架构

Immich 采用前后端分离的现代 Web 架构。后端基于 **NestJS** 框架构建，使用 **PostgreSQL** 作为主数据库存储元数据和用户信息，并利用 **Redis** 实现缓存和任务队列。媒体文件本身存储于本地文件系统或其他兼容对象存储中，保证了数据的高可移植性。前端则使用 **Flutter** 开发跨平台应用，支持 iOS、Android 和 Web，确保用户在不同设备上获得一致体验。

项目的核心设计亮点在于其 **微服务化** 和 **可扩展性**。Immich 将机器学习任务（如人脸识别、对象检测）独立为可异步执行的工作进程，避免阻塞主服务，大幅提升了高负载场景下的响应速度。此外，通过 RESTful API 和 WebSocket 通信，客户端与服务器之间的交互高效且实时，例如上传进度和后台处理状态都能即时反馈给用户。对于有高级需求的用户，Immich 还提供了 CLI 工具和丰富的配置选项，支持 Docker Compose 一键部署，便于本地或云服务器上快速启动。

## 安装与使用

Immich 的安装过程十分简便，官方推荐使用 Docker Compose 方式部署。以下是一个最小化的启动示例：

1. **前置要求**：确保已安装 Docker 和 Docker Compose。
2. **获取配置文件**：克隆仓库或下载 `docker-compose.yml` 文件。
3. **启动服务**：
   ```bash
   docker compose up -d
   ```
   该命令会拉取所需镜像并启动 Immich 的服务器、数据库、Redis 等依赖服务。
4. **访问界面**：在浏览器中打开 `http://<服务器IP>:2283`，完成管理员账户的初始化设置。
5. **客户端应用**：从应用商店下载 Immich 移动应用（iOS/Android），或使用 Web 版本，登录后即可开始上传照片和视频。

对于开发者或希望自定义配置的用户，Immich 提供了详细的官方文档，涵盖环境变量、存储路径调整、机器学习模型加载等高级主题。项目还内置了健康检查接口和日志系统，方便排查问题。

## 适用场景

- **家庭私有相册**：家庭成员将手机中的照片统一备份至家庭 NAS 或服务器，实现集中存储和跨设备共享，无需担心云服务容量限制或隐私泄露。
- **摄影师工作流**：专业摄影师可借助 Immich 的 RAW 文件支持和元数据管理功能，快速整理拍摄素材，并通过智能搜索高效筛选作品。
- **数据敏感型机构**：法律、医疗或研究机构需要对媒体文件进行合规存储，Immich 的自托管特性确保数据完全在内部网络流转，满足审计要求。
- **离线环境媒体库**：在无互联网接入的内网环境（如户外活动基地、船上）中，Immich 可提供完整的媒体管理能力，不依赖外部服务。

## 项目亮点

与 Google Photos、Nextcloud 或 PhotoPrism 等替代方案相比，Immich 最突出的优势在于其**性能和功能完整性**的平衡。它拥有商业级云相册的丝滑体验（如同步、人脸识别和搜索），但完全开源且自托管。此外，Immich 的**活跃开发节奏**也值得一提，项目几乎每周发布新版本，社区贡献者持续优化机器学习模型和 UI 交互。对于普通用户而言，轻量级的 Docker 部署和直观的移动端应用降低了上手门槛；对于开发者，完善的 API 和模块化架构则提供了深度定制的可能性。尽管仍处于快速迭代期，但 Immich 的稳定性和核心功能已足以胜任日常使用，并展现出持续进化的潜力。
