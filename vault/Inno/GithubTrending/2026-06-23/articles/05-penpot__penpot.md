## 项目概述

Penpot 是一款开源的设计与原型制作工具，专注于消除设计师与开发者之间的协作鸿沟。它由社区驱动开发，基于 Web 技术构建，不依赖任何商业云服务或专有组件。无论是 UI/UX 设计师、前端开发者还是产品团队，都可以在 Penpot 中完成从设计稿到代码实现的完整工作流。Penpot 的目标是成为真正开放、可自托管的设计基础设施，让团队完全掌控自己的设计资产。

## 核心功能

- **矢量图形编辑**：支持完整的矢量绘图、路径编辑、布尔运算、渐变与蒙版，满足高质量 UI 设计需求。
- **组件与样式系统**：可创建可复用的组件、文本样式、颜色变量和网格布局，支持全局更新与实例覆盖。
- **多用户实时协作**：支持多人同时编辑同一文件，实时同步光标、选择和修改内容，类似 Figma 的协作体验。
- **开发者友好导出**：可直接复制 CSS 样式、SVG 代码、JSON 设计规范，并支持 Figma 文件导入，降低迁移成本。
- **原型与交互设计**：可添加热点、过渡动画和交互流程，生成可交互的演示原型，支持浏览器内预览。
- **自托管部署**：提供基于 Docker 的完整部署方案，数据完全存储在自有服务器，无需担心数据隐私或第三方服务中断。

## 技术架构

Penpot 后端使用 Clojure 编写，采用函数式编程范式，核心逻辑通过 Tokens 和 Spec 进行严格类型约束。前端则基于 React 与 SVG 渲染引擎，所有图形操作均在浏览器端完成，仅在保存或协作时与后端通信。这种架构使得 Penpot 能够在低延迟下提供流畅的画布操作体验，同时后端只负责持久化、用户管理与协作同步。数据库方面默认使用 PostgreSQL，文件存储可对接本地文件系统或 S3 兼容的云存储。整个系统通过 Docker Compose 编排，部署简单且高度可定制。

## 安装与使用

**快速启动（Docker）**：
1. 确保已安装 Docker 与 Docker Compose。
2. 克隆官方部署仓库：
   ```bash
   git clone https://github.com/penpot/penpot-docker.git
   cd penpot-docker
   ```
3. 使用默认配置启动：
   ```bash
   docker compose up -d
   ```
4. 浏览器访问 `http://localhost:9001`，使用默认管理员账户 `admin@example.com` 与密码 `changeme` 登录。

**最小可用示例**：
- 登录后创建项目，从模板或空白画布开始。
- 使用左侧工具栏的矩形、椭圆、文字工具绘制基础界面。
- 选中任意图层，在右侧属性面板调整填充色、描边、圆角等。
- 点击顶部“原型”模式，为按钮添加“点击 -> 页面跳转”交互。
- 点击“预览”按钮即可进行原型演示。

## 适用场景

- **设计团队自建工具栈**：对设计数据主权有严格要求的企业或机构，可自托 Penpot 替代 Figma/Sketch，避免授权费用与数据外流风险。
- **开源项目设计协作**：开源社区可以免费搭建 Penpot，让全球贡献者同时参与界面设计与评审，无需购买商业许可。
- **设计稿到代码的快速转化**：前端开发者可直接从设计图层复制 CSS 代码或 SVG 资源，减少手动测量与还原误差。
- **教学与培训**：设计院校或培训机构可部署实例供学生使用，无用户数限制，降低教育成本。

## 项目亮点

- **完全开源与社区驱动**：采用 MPL-2.0 许可证，代码完全公开，任何人可审计、修改或贡献功能。相较于商业软件的闭源组件，Penpot 的透明度是最大优势。
- **跨平台与零客户端安装**：只需现代浏览器即可使用，无需安装任何桌面软件或插件，同时支持 Windows、macOS、Linux 以及移动设备。
- **真正的设计-开发桥梁**：不只是一个设计工具，而是将设计文件直接输出为 CSS/SVG/JSON 等开发者原生格式，减少沟通与转换成本。
- **数字公共产品认证**：已被认定为数字公共产品（Digital Public Good），体现了其在社会价值和技术开放性上的认可。
