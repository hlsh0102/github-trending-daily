## 项目概述

Palmier Pro 是一款专为 AI 时代设计的 macOS 视频编辑器，由 Y Combinator S24 孵化的 Palmier 团队开发。该项目旨在解决传统视频编辑软件在 AI 集成方面普遍存在的痛点：操作复杂、AI 功能作为附属插件、工作流割裂。Palmier Pro 将 AI 深度嵌入编辑器的核心，让用户能够以自然语言驱动剪辑流程，从而大幅降低视频创作的门槛。

目标用户覆盖内容创作者、短视频制作者、AI 技术爱好者以及需要快速处理视频素材的专业人士。无论是生成式 AI 视频的后期精修，还是传统素材的智能剪辑，Palmier Pro 都提供了一个原生、高效的解决方案。

## 核心功能

- **AI 原生工作流**：支持通过自然语言指令控制剪辑操作，例如描述想要的效果或场景转换，编辑器即可自动执行，无需手动拖拽时间线。
- **智能素材管理**：自动识别并分类素材中的场景、人物和物体，提供基于内容的搜索和排序，帮助用户快速定位需要的片段。
- **实时协作编辑**：支持多人同时编辑同一个项目，云端同步更改，适合团队远程协作。
- **一键式 AI 特效**：集成多种 AI 驱动的视频特效，包括智能风格迁移、背景替换、动态字幕生成等，无需额外插件。
- **高性能渲染引擎**：基于 Apple Silicon 原生优化，利用 Metal 和 Swift 实现硬件加速，支持实时预览 4K 甚至 8K 视频。
- **导出优化**：针对主流平台（如 TikTok、YouTube、Instagram）提供一键导出预设，自动调整分辨率和编码参数。

## 技术架构

Palmier Pro 使用 Swift 语言开发，深度依赖 macOS 26 (Tahoe) 的原生框架：

- **前端 UI**：采用 SwiftUI 构建响应式界面，支持动态布局和暗黑模式，适配不同尺寸的 Mac 屏幕。
- **AI 后端**：集成本地运行的轻量级 AI 模型（基于 Core ML），实现离线时的智能剪辑和特效处理；同时支持通过云端 API 调用更强大的模型（如 OpenAI GPT 或自研模型）进行高级推理。
- **视频处理引擎**：基于 AVFoundation 和 Metal Performance Shaders 构建，实现高效解码、编码和滤镜处理。引擎支持 GPU 加速，确保时间轴拖拽和特效应用的流畅性。
- **协作层**：使用 CloudKit 或自研同步协议管理项目文件版本，支持无冲突的并发编辑（CRDT 算法）。
- **插件系统**：开放插件 API，允许第三方开发者创建自定义 AI 工具和特效，通过 Swift Package Manager 分发。

架构特点是“AI 原生”——AI 不是作为一个独立面板存在，而是嵌入时间轴、素材浏览器和特效面板的每一个操作中。例如，选中片段后直接输入“将这里的背景替换为海滩”，编辑器会即时调用 AI 模型进行处理。

## 安装与使用

### 系统要求
- macOS 26 (Tahoe) 或更高版本
- Apple Silicon 芯片（M1 及以上）

### 安装步骤

1. 从 [GitHub Releases](https://github.com/palmier-io/palmier-pro/releases/latest/download/PalmierPro.dmg) 下载最新 DMG 文件。
2. 双击打开 DMG，将 Palmier Pro 拖入 Applications 文件夹。
3. 首次启动可能需要授予摄像头、麦克风及文件访问权限。

### 最小可用示例

1. 打开 Palmier Pro，点击“新建项目”。
2. 导入一段视频素材（支持 .mp4、.mov、.m4v 等格式）。
3. 在时间轴中选中该片段，按下 `Cmd + K` 打开 AI 指令框。
4. 输入“添加白色字幕，字体使用 Helvetica，位于底部”，编辑将自动生成字幕轨道。
5. 点击“导出”，选择“TikTok”预设，即可生成优化后的视频。

## 适用场景

- **内容创作**：YouTube、TikTok 创作者快速剪辑视频，利用 AI 指令完成剪辑、特效和字幕添加，显著缩短后期流程。
- **企业营销**：团队协作制作广告片或产品演示，多人在线编辑同一项目，并通过云端同步保持版本一致。
- **教育讲师**：录制课程后进行智能切片、添加自动字幕和章节标记，提升课程制作效率。
- **原型验证**：AI 开发者或设计师快速制作概念验证视频，使用自然语言描述界面动画或特效，即时生成预览。

## 项目亮点

- **AI 深度融合**：与市场上大多数“AI 作为后续添加”的视频编辑器不同，Palmier Pro 从底层设计时就以 AI 为核心，自然语言驱动的剪辑是默认交互方式。
- **macOS 原生体验**：完全使用原生 Swift 开发，针对 Apple Silicon 深度优化，启动速度快、资源占用低，与系统其他应用（如 Finder、QuickTime）紧密结合。
- **开源与社区驱动**：采用 GPL-3.0 协议开源，任何开发者都可以检查代码、提交 PR 或基于此构建衍生项目。活跃的 Discord 社区提供及时支持与反馈。
- **Y Combinator 背书**：作为 YC S24 孵化的项目，背后有成熟的产品与商业经验，保证长期维护与功能迭代。
- **多语言支持**：项目 README 已被翻译成 16 种语言，面向全球用户，社区本地化程度高。
