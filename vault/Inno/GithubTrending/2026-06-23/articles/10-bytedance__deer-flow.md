## 项目概述

DeerFlow（全称 **D**eep **E**xploration and **E**fficient **E**research **Flow**）是由字节跳动开源的一款长周期超级智能体编排框架。它能够协调多个子智能体、记忆系统、沙箱环境以及可扩展工具集，自主完成从研究、编码到内容创作的复杂任务——这些任务通常需要数分钟到数小时才能完成。

传统工作流引擎往往只能处理确定性流程，而 DeerFlow 的定位则是面向非确定性、需要探索和迭代的长期任务。它的目标用户包括 AI 应用开发者、自动化流程工程师、数据科学团队，以及任何希望将重复性研究或开发工作交给自动化智能体完成的技术人员。

项目采用 MIT 开源协议，目前已在 GitHub 上获得超过 73,000 颗星标，并在 2026 年 2 月 28 日凭借 2.0 版本的发布登顶 GitHub Trending 榜首。

## 核心功能

- **多智能体编排**：支持创建和协调多个子智能体，每个子智能体可独立执行特定子任务，并通过消息网关互相通信。
- **持久化记忆系统**：内置记忆模块，让智能体能够在长时间任务中保持上下文一致性，避免重复学习和遗忘。
- **沙箱执行环境**：提供隔离的沙箱运行环境，智能体可以在其中安全地执行代码、测试脚本，而不会影响宿主系统。
- **可扩展技能库**：预置了多种常用技能，并支持用户以插件形式添加自定义技能，覆盖数据抓取、API 调用、文件操作等场景。
- **消息网关**：统一的通信枢纽，负责在不同子智能体和外部服务之间路由消息，支持异步和同步两种模式。
- **分级任务处理**：根据任务复杂度自动选择处理策略，从简单的单步操作到需要数小时的多阶段探索，灵活适配。

## 技术架构

DeerFlow 采用模块化设计，核心架构围绕“智能体治理层”展开。该层之上是任务调度引擎，之下是沙箱、记忆、技能等基础设施。

关键技术选择包括：

- **Python 生态**：项目以 Python 为主要实现语言，利用成熟的异步编程框架（如 asyncio）管理并发任务。
- **沙箱隔离**：基于容器或虚拟环境技术实现沙箱，确保每个子任务在独立空间中执行，避免资源竞争和安全隐患。
- **事件驱动架构**：消息网关基于事件驱动模型，支持智能体之间以及智能体与外部系统之间的解耦通信。
- **可组合技能系统**：技能以独立模块形式存在，通过标准化接口注册到治理层，支持热加载和动态发现。

设计思路方面，DeerFlow 不试图成为“万能 AI”，而是提供一个可靠的“智能体土壤”——开发者只需定义子智能体的行为逻辑和通信规则，剩下的编排、调度、错误恢复都由框架自动完成。

## 安装与使用

DeerFlow 的安装遵循 Python 项目的标准流程。以下是最小可用示例：

```bash
# 克隆仓库
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Windows 下使用 venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

配置完成后，可以通过配置文件定义主智能体和子智能体的行为。一个典型的工作流定义包含以下要素：

1. 设置 LLM 后端（推荐使用豆包 Seed 2.0、DeepSeek v3.2 或 Kimi 2.5）
2. 注册需要使用的技能包
3. 定义触发条件和任务分解规则
4. 启动消息网关并开始任务

详细的使用文档和真实演示案例可在[官方网站](https://deerflow.tech)上找到。

## 适用场景

- **自动化研究分析**：智能体可以自主搜索资料、对比数据、生成研究报告，适合市场调研、竞品分析等知识密集型任务。
- **代码生成与验证**：子智能体负责分模块编码，另一个子智能体负责在沙箱中测试和调试，适用于小型功能模块的自动化开发。
- **内容创作流水线**：从资料收集到大纲生成再到初稿撰写，多阶段任务可由不同子智能体接力完成，同时借助记忆系统保持风格一致。
- **持续集成辅助**：将 DeerFlow 嵌入 CI/CD 流程，自动分析代码变更、编写测试用例、生成变更日志，减轻开发者重复劳动。

## 项目亮点

DeerFlow 与同类智能体框架相比，核心差异化优势体现在：

- **长周期任务原生支持**：大多数智能体框架针对单轮或短对话设计，而 DeerFlow 从架构层面支持运行数小时的多阶段任务，内置持久化记忆和错误恢复机制。
- **开源且生产友好**：字节跳动内部实践验证过的框架，具备企业级稳定性，同时完全开源（MIT 协议），便于社区定制和二次开发。
- **多语言社区支持**：提供英文、中文、日文、法文、俄文等多语言文档，降低了全球开发者的使用门槛。
- **沙箱安全设计**：代码执行场景中，沙箱隔离确保宿主安全，这是许多同类项目欠缺的关键设计。
- **社区活跃度高**：版本 2.0 是从头重写的全新架构，不与 1.x 版本共享代码，但仍维护了旧分支供过渡使用，体现了对生态的负责态度。
