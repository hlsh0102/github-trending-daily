## 项目概述

`gstack` 是由 Y Combinator 总裁兼 CEO Garry Tan 开源的一套 Claude Code 配置工具集。该项目旨在将一位资深工程师、产品经理和设计师的二十年产品构建经验，封装为 23 个高度专业化的 AI 工具，让开发者能够以接近零手动编码的方式，独自完成从前端设计、后端开发、工程管理到发布运维的全流程工作。

项目名称中的 “stack” 并非指技术栈，而是指一套完整的、可复用的 AI 代理工具栈。其核心目标用户是希望借助 AI 提升个人生产力的独立开发者、初创团队，以及那些像当年车库里的 Coinbase、Instacart 一样，以极少数人承担全栈角色的早期项目创始人。

## 核心功能

- **23 个角色化工具**：预定义了覆盖 CEO、设计师、工程经理、发布经理、文档工程师、QA 测试员等关键角色的 Claude Code 工具，每个工具聚焦特定任务且经过实践验证。
- **CEO 视角的决策辅助**：包含用于产品方向分析、用户需求洞察、优先级排序的工具，帮助开发者在编码前做出正确的战略判断。
- **设计与前端生成**：提供能够直接生成 UI 组件、管理设计系统、优化用户体验的工具，使非设计师也能产出高质量界面。
- **工程管理与技术规划**：包含代码审查、技术债务分析、架构决策记录、任务分解与排期等工程管理工具。
- **自动化发布与文档**：实现一键式版本发布、变更日志生成、API 文档编写，覆盖 DevOps 和文档工程职责。
- **QA 与测试驱动**：提供测试案例生成、边界条件分析、回归测试自动化的工具，确保代码质量。

## 技术架构

`gstack` 基于 TypeScript 构建，本质上是一组 Claude Code 的配置文件（`.claude` 或 `.md` 格式规则文件）。其设计思路遵循 “单点责任” 原则：每个工具只做一件事且做好一件事。这些工具通过 Claude Code 的指令系统被调用，形成一个可组合的 AI 工作流。

项目并不引入新的编程语言或框架，而是深度利用 Claude Code 的扩展能力，通过精心编写的提示词和结构化规则，将大语言模型的能力约束为特定的专业行为。这种设计使得工具之间可以灵活组合——例如，先调用设计师工具生成 UI 原型，再调用工程师工具实现后端逻辑，最后调用发布经理工具打包上线。

架构的关键特点包括：工具命名清晰（如 `ceo/strategy-review`、`designer/ui-review`），便于按需调用；工具描述中包含了上下文指令和输出格式要求，确保 AI 输出的稳定性和可复现性；并且支持无缝集成到现有 CI/CD 流程中。

## 安装与使用

`gstack` 的安装非常轻量。由于它本质上是一组配置文件，用户只需克隆仓库并将其中的工具配置文件复制到自己的 Claude Code 工作目录下。

**基本安装步骤：**

1. 确保已安装并配置好 Claude Code（Anthropic 的命令行工具）。
2. 克隆 gstack 仓库：
   ```bash
   git clone https://github.com/garrytan/gstack.git
   ```
3. 将 gstack 中的工具配置文件（通常以 `.claude` 扩展名存放）复制到你的项目根目录下的 `.claude/` 文件夹中：
   ```bash
   cp -r gstack/tools/* your-project/.claude/
   ```
4. 在 Claude Code 中运行 `claude` 命令，即可看到所有 gstack 工具已就绪。

**最小可用示例：**

假设你想让 AI 以工程经理角色审查你当前分支的代码变更：
```bash
claude "使用 eng-manager/code-review 工具，审查当前分支相对于 main 分支的所有变更"
```
或者，你想让 AI 生成一个新功能的测试用例：
```bash
claude "使用 qa/generate-tests 工具，为 src/user-service.ts 中的 UserService 类生成单元测试"
```

工具名称与对应角色紧密相关，用户可以根据实际需要组合调用多步骤工作流。

## 适用场景

- **独立开发者构建 MVP**：一个人同时扮演设计师、后端工程师、前端工程师和运维，使用 gstack 快速将想法转化为可上线的产品，跳过不必要的团队沟通成本。
- **早期创业团队加速交付**：2-5 人的小团队可以利用 gstack 让每位成员都具备全栈能力，缩短从构思到部署的周期，典型如 Garry Tan 本人 60 天内从零交付 3 个生产服务。
- **大型团队中的个人增效**：即使身处大公司，工程师也可以利用 gstack 完成跨角色任务——例如前端工程师需要独立进行后端 API 设计，或产品经理需要生成技术可行性分析。
- **学习与实践全栈开发**：对于希望理解完整产品开发流程的学习者，gstack 提供了结构化的指引，让 AI 在每一步给出专业的指导和建议。

## 项目亮点

与市面上其他 AI 编码助手相比，`gstack` 的独特之处在于其**角色化、结构化的工作流设计**。它不仅仅是一个代码生成器，而是一套完整的 “AI 虚拟团队”——每个工具都对应一个真实团队角色的职责范围，从战略到执行、从设计到运维全覆盖。

另一大亮点是**实战验证性**。Garry Tan 本人使用这套工具，在 YC 全职工作的同时，以业余时间实现了 60 天上线 3 个生产服务、交付 40+ 功能、逻辑代码产出达到 2013 年的 810 倍。这不是一个理论框架，而是一个经过高强度实践检验的生产力系统。

此外，`gstack` 保持了**极致的易用性和可扩展性**。用户无需学习新框架，只需在 Claude Code 中调用预定义的工具名称；同时可以自由添加、修改或组合工具，适配特定项目的工作流。
