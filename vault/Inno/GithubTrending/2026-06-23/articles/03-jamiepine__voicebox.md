## 项目概述

Voicebox 是一个开源的 AI 语音工作室，旨在为用户提供完整的语音输入输出（I/O）堆栈，并完全在本地机器上运行。项目解决了当前语音 AI 领域普遍存在的两个核心问题：一是用户语音数据的隐私和所有权问题，二是对第三方云服务的依赖。Voicebox 让用户可以克隆任何人的声音、生成语音、在任何应用中进行语音听写，以及用自己拥有的声音与 AI 智能体对话。其目标用户包括内容创作者、播客制作者、有声书创作者、希望实现语音交互的开发者、以及重视数据隐私的个人用户。

## 核心功能

- **声音克隆**：通过少量样本音频，即可克隆任何人的声音，生成高度相似的语音输出。
- **语音生成**：基于文本输入，利用克隆的声音或内置声音模型，生成自然流畅的语音。
- **实时听写**：在任何桌面应用中实现实时语音转文字，支持多种语言和自定义词汇。
- **AI 智能体对话**：与 AI 智能体进行语音对话，智能体可使用用户克隆的声音进行回应。
- **完全本地运行**：所有语音处理均在本地设备上完成，无需上传数据到云端，确保隐私安全。
- **多平台支持**：提供跨平台桌面应用，支持 Windows、macOS 和 Linux 系统。

## 技术架构

Voicebox 采用 TypeScript 作为主要开发语言，结合 Electron 框架构建跨平台桌面应用。在语音处理层面，项目深度整合了业界领先的 AI 语音模型——包括用于语音合成的 CosyVoice 和用于语音识别的 SenseVoice。这些模型经过优化后可在消费级 GPU 上本地运行，降低了硬件门槛。架构上采用模块化设计，将录音、语音识别、语音合成、音频播放等核心功能解耦为独立模块，便于扩展和维护。音频处理方面使用 Web Audio API 和 Node.js 原生音频库实现低延迟的实时处理管线。项目还提供了 RESTful API 接口，方便开发者将其集成到其他应用中，或构建自定义的工作流。

## 安装与使用

**安装步骤：**

1. 前往 [GitHub Releases 页面](https://github.com/jamiepine/voicebox/releases) 下载对应操作系统的最新版本安装包。
2. 运行安装程序，按照向导完成安装。
3. 首次启动时，应用会自动下载所需的 AI 模型文件（约 2-5GB，取决于所选模型）。
4. 选择默认的输入/输出音频设备。

**最小可用示例：**

安装完成后，打开 Voicebox 应用：

- **语音合成**：在“文本转语音”选项卡中输入文本，选择声音模型，点击“生成”，即可听到合成语音。
- **声音克隆**：在“声音克隆”模块中上传一段 10-60 秒的干净音频，点击“开始克隆”，完成后该声音会出现在声音列表中。
- **实时听写**：在“听写”选项卡中，选择输入设备和语言，点击“开始”，对着麦克风说话，文字会实时出现在输出区域。
- **API 调用**：启动 Voicebox 后，可通过 HTTP 接口调用语音服务，例如：
  ```bash
  curl -X POST http://localhost:8080/tts \
    -H "Content-Type: application/json" \
    -d '{"text": "你好，这是一段测试语音", "voice": "default"}'
  ```

## 适用场景

- **内容创作与有声书制作**：播客主和视频创作者可以利用声音克隆功能，快速生成旁白或角色语音，无需专业录音设备。
- **无障碍辅助**：为语言障碍人士或视障用户提供实时语音合成和听写服务，提升信息获取效率。
- **智能语音助手开发**：开发者可将 Voicebox 作为本地语音引擎，为智能家居、车载系统或聊天机器人应用提供低延迟、隐私保护的语音能力。
- **多语言学习与翻译**：利用语音合成功能，生成多种语言的发音示例，辅助语言学习者练习听力和发音。

## 项目亮点

- **开源与隐私优先**：与商业语音云服务不同，Voicebox 完全开源（MIT 协议），所有数据处理均在本地完成，用户拥有对语音数据的完全控制权。
- **一站式语音解决方案**：集声音克隆、语音合成、语音识别、实时听写于一体，无需整合多个不同服务。
- **低门槛本地部署**：支持消费级 GPU 运行，无需昂贵的企业级硬件，且提供了友好的图形化界面，非技术用户也可直接使用。
- **积极社区与持续更新**：项目在 GitHub 上拥有超过 32,000 星标，社区活跃，定期发布新功能和性能优化。
