## 项目概述

AI Hedge Fund 是一个基于人工智能的对冲基金概念验证项目。该项目通过模拟多位传奇投资大师的决策逻辑，构建了一支由多个AI Agent组成的“投资团队”，共同完成股票分析与交易决策。项目的核心目标是探索AI在交易决策中的应用可能性，而非提供真实的交易或投资建议。

该项目定位为**教育目的**，适合对AI、金融科技以及量化投资感兴趣的开发者、研究人员和投资者学习与实验。目前项目正在向更完善的架构演进，目标是将概念验证转变为持久运行的AI对冲基金系统，支持回测、模拟交易和可选实盘运行。

## 核心功能

- **多智能体协作分析**：系统由多位模拟不同投资大师的AI Agent组成，每位Agent拥有独立的投资理念和分析逻辑，通过协作投票方式产生最终交易决策。
- **模拟投资大师风格**：集成了包括Aswath Damodaran、Ben Graham、Bill Ackman、Cathie Wood、Charlie Munger、Michael Burry、Mohnish Pabrai、Nassim Taleb、Peter Lynch等传奇投资者的决策框架。
- **可扩展的Alpha模型**：将投资者Agent重新设计为可插拔的“Alpha模型”，支持用户自定义和添加新的投资策略。
- **完整回测支持**：支持历史数据回测，评估不同策略组合的历史表现。
- **模拟/实盘交易接口**：提供模拟交易环境，并支持可选的实盘运行模式。
- **持久化运行架构**：正在重构为始终运行的持久化系统，以“基金”作为一等公民实体进行管理。

## 技术架构

项目采用Python作为主要开发语言，核心架构围绕多智能体系统展开：

- **Agent框架**：每个投资大师作为一个独立的Agent运行，拥有独立的参数配置和决策逻辑。Agent之间通过消息传递机制协作，最终汇总形成综合交易建议。
- **数据驱动流水线**：系统接入市场数据API，实现数据获取、清洗、特征工程和策略执行的自动化流水线。
- **模块化设计**：Agent、数据源、交易执行、风险管理等模块均采用解耦设计，便于扩展和替换。
- **回溯测试引擎**：内置高性能回测引擎，支持多策略并行回测，并提供详细的绩效分析报告。
- **状态持久化**：支持运行状态的持久化存储，使系统能够连续运行并记录历史决策记录。

架构的演进方向是构建一个微服务化的金融AI系统，每个Agent作为独立服务运行，通过事件驱动的方式进行通信和协作。

## 安装与使用

### 安装
```bash
# 克隆仓库
git clone https://github.com/virattt/ai-hedge-fund.git
cd ai-hedge-fund

# 安装依赖
pip install -r requirements.txt
```

### 最小可用示例
配置需要接入的数据源API密钥（如Yahoo Finance、Alpha Vantage等），然后运行主程序：

```python
from hedge_fund import AIHedgeFund

# 初始化基金实例
fund = AIHedgeFund(
    agents=["graham", "buffett", "lynch"],  # 选择使用的Agent
    tickers=["AAPL", "MSFT", "GOOGL"],      # 关注的股票
    mode="paper_trading"                    # 运行模式
)

# 运行一次分析周期
fund.run()
```

更详细的配置和使用说明请参考项目中的`examples/`目录和`README.md`文件。

## 适用场景

- **AI与金融交叉研究**：作为研究AI在复杂决策场景应用的实验平台，探索多智能体协作在投资分析中的效果。
- **投资策略开发与验证**：开发者可以基于项目框架，快速实现和回测自己的投资策略，尤其是融入多维度分析框架的策略。
- **金融科技教育**：适合高校金融工程、量化投资课程的教学案例，帮助学生理解不同投资哲学的实现方式和比较。
- **个人投资助手**：为个人投资者提供一个可定制的辅助决策工具，结合多种价值投资理念进行股票分析。

## 项目亮点

- **多大师协同作战**：项目最具特色之处在于集成了不同时代的投资大师思维，从价值投资到成长投资，从风险对冲到逆向投资，实现了跨流派的多维度分析。
- **高度可扩展性**：Agent被设计为插件式组件，用户可以轻松添加新的投资策略模型，或替换现有Agent的决策逻辑。
- **教育优先的设计理念**：项目明确声明为教育目的，降低了金融领域的技术门槛，让更多人能够理解和实践经典投资理论。
- **持续进化的架构**：从简单的概念验证到正在构建的持久化基金系统，项目保持着活跃的演进状态，体现了从玩具到工具的发展路径。
- **MIT开源协议**：项目采用MIT协议，允许自由使用、修改和再发布，促进了社区的参与和贡献。
