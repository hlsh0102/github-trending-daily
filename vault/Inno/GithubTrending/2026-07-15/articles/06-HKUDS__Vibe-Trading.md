## 项目概述

Vibe-Trading 是一个开源的个人交易助手项目，旨在让用户通过一条命令快速部署具备全面交易能力的 AI 智能体。该项目由香港大学数据科学实验室（HKUDS）开发，目标用户涵盖个人投资者、量化交易爱好者、AI 开发者以及希望利用自然语言驱动交易策略的研究人员。

传统量化交易工具往往需要复杂的编程技能和漫长的环境配置过程，而 Vibe-Trading 将交易策略制定、回测、执行、监控等环节集成到一个以智能体为核心的平台中，用户只需通过简单的自然语言或配置文件即可启动交易任务，大幅降低了交易智能化的准入门槛。

## 核心功能

- **一键部署交易智能体**：用户只需执行一条命令，即可启动一个完整的交易智能体后端服务，无需手动配置数据库、API 或复杂的依赖环境。
- **自然语言策略生成**：支持以文字描述交易思路（如“当比特币 20 日均线上穿 50 日均线时买入”），智能体自动解析并生成可执行的交易策略代码。
- **多市场支持**：内置对股票、加密货币等主流金融市场的支持，可通过插件方式扩展更多资产类别或交易所接口。
- **实时数据与回测引擎**：集成实时行情数据获取及历史数据回测功能，帮助用户在实盘前验证策略的有效性。
- **可视化前端仪表盘**：基于 React 构建的 Web 前端界面，提供盈亏统计、持仓管理、历史交易记录等清晰直观的可视化组件。
- **模块化插件架构**：允许开发者通过自定义插件接入新的数据源、策略模型或交易所 API，满足个性化需求。

## 技术架构

Vibe-Trading 整体采用前后端分离的微服务架构，后端核心基于 **Python 3.11+** 和 **FastAPI** 框架构建，提供高性能的异步 API 接口和数据流处理能力。前端则使用 **React 19** 开发，通过 RESTful API 与后端通信，实现实时交互和图表渲染。

项目设计强调 **智能体（Agent）驱动** 的理念，核心引擎包含三个关键组件：策略解析模块（将自然语言或配置文件转化为可执行规则）、执行模块（对接交易所 API 完成实际下单）、以及监控模块（持续跟踪持仓状态与市场变化）。其中，策略执行引擎支持向量化回测和事件驱动回测两种模式，以适应不同场景下的性能需求。

在数据层，Vibe-Trading 通过插件式数据源适配器对接各类金融数据提供商，并内置缓存机制以减少对实时 API 的依赖。项目还集成了简单的风险管理组件，允许用户设置最大回撤、单笔风险比例等参数，由智能体自动控制交易行为。

## 安装与使用

安装 Vibe-Trading 非常简便，推荐使用 pip 直接安装：

```bash
pip install vibe-trading-ai
```

启动智能体后端服务，只需在终端执行：

```bash
vibe-trading start
```

服务启动后，浏览器访问 `http://localhost:8000` 即可进入前端仪表盘。在仪表盘中，你可以：

1. 连接交易所账户（支持模拟盘和实盘模式）。
2. 在策略编辑器中输入自然语言描述的交易思路。
3. 点击“运行回测”验证历史表现。
4. 确认无误后，启动实盘或模拟交易。

以下是一个最小可用的 Python 脚本示例：

```python
from vibe_trading import TradingAgent

agent = TradingAgent()
agent.connect_broker("binance", api_key="your_key", secret="your_secret")
agent.set_strategy("当 BTC/USDT 的 RSI 低于 30 时买入，高于 70 时卖出")
agent.run_backtest(start="2024-01-01", end="2024-12-31")
agent.start_live_trading()
```

## 适用场景

- **个人量化策略探索**：普通投资者无需编程经验，即可用自然语言构思并快速测试交易想法，感受量化交易的基本流程。
- **自动化交易部署**：开发者或交易员可以将 Vibe-Trading 部署在云端服务器上，24 小时运行自定义策略，自动执行买卖操作。
- **教育与研究实验**：金融科技课程或研究团队可以用它作为实验平台，对比不同策略或验证市场假说，支持快速迭代。
- **策略集成与二次开发**：高级用户通过插件 API 接入自有模型或数据源，将 Vibe-Trading 作为交易中台使用。

## 项目亮点

与同类交易框架（如 Backtrader、QuantConnect、CCXT 等）相比，Vibe-Trading 的核心差异在于 **智能体优先的设计理念**。传统工具要求用户书写 Python 脚本或复杂的配置文件，而 Vibe-Trading 允许用户用自然语言定义策略，智能体自动完成翻译、执行和监控任务，极大降低了使用门槛。

此外，项目提供了一键部署的完整体验——从安装到拥有一个带 Web 界面的交易系统，只需两条命令。这种开箱即用的特性在开源交易工具中较为少见。再加上 MIT 许可证的宽松授权，使得个人和商业用户可以自由地修改、集成和分发。
