## 项目概述

Skills for Real Engineers 是一个由 TypeScript 专家 Matt Pocock 维护的开源项目，源自其个人 `.claude` 目录下的 Agent 技能集合。该项目解决的核心理念问题是：在 AI 辅助编程日益普及的今天，许多“Vibe Coding”式的方法将软件工程全权交给 AI 代理掌控（如 GSD、BMAD、Spec-Kit），虽然简化了流程，却剥夺了开发者的控制权，且流程中的错误难以定位和修复。

该项目的目标用户是**专业软件工程师**，特别是那些希望在不失去代码控制权的前提下，利用 AI 代理提升日常工作效率的开发者。它倡导“小而精、可适配、可组合”的 Agent 技能，让工程师能够自主掌控 AI 工具的行为。

## 核心功能

- **集成即用技能文件**：提供可直接引入 AI 代理配置文件（如 Claude、Cursor 等）的 Skill 文件，无需复杂配置。
- **工程级代理策略**：技能设计基于真实软件工程经验，而非泛化提示词，聚焦于代码质量、测试、重构等硬核任务。
- **多模型兼容**：技能不锁定特定 AI 模型，可在 Claude、GPT、Gemini 等多种 LLM 上运行。
- **模块化与可组合**：每个技能职责单一，开发者可根据项目需求自由组合，避免“一刀切”式代理方案。
- **30 秒快速安装**：通过 `npx skills@latest add` 命令即可将精选技能注入自己的 Agent 配置。
- **持续更新与社区驱动**：项目保持活跃迭代，用户可通过 Newsletter 获取最新技能更新信息。

## 技术架构

该项目本质上是一个 **Agent 技能配方仓库**，核心资产是存放在 `claude/` 目录下的 Markdown 格式技能文件。技术架构特点包括：

- **声明式配置**：技能通过 Markdown 文件定义，遵循 Claude Code 和通用 AI Agent 的 Prompt 规范，易于人类阅读和修改。
- **零运行时依赖**：技能文件本身不包含代码，不依赖特定编程语言或框架，仅需 AI 代理能读取 Markdown 指令即可。
- **安装器轻量化**：`skills.sh` 安装脚本采用 Shell 和 Node.js（通过 `npx`）实现，从远程仓库拉取技能文件并写入本地 Agent 配置，最小化用户操作成本。
- **版本化分发**：借助 GitHub 仓库的版本控制，技能可追踪变更、回滚，并支持按需选择特定版本。

## 安装与使用

### 快速安装（30 秒）

1. 在终端中运行以下命令：
```bash
npx skills@latest add mattpocock/skills
```

2. 根据交互式提示，选择你需要的技能以及要安装到的 Coding Agent（如 Claude Code、Cursor 等）。安装器会自动将所选技能映射到正确的 Agent 配置文件中。

### 手动使用

你也可以直接从仓库的 `claude/` 目录中复制 `.claude` 或 `.md` 文件到本地 AI 代理的技能目录下，进行个性化调整。

### 最小可用示例

安装完成后，在支持自定义技能的 AI 代理中，直接提问：

> “请按照本项目的工程规范，帮我重构这个函数并添加单元测试。”

AI 代理将自动加载已安装的技能指令（如代码评审、测试生成、类型安全等），按照设定的工程标准执行任务。

## 适用场景

- **日常代码重构**：在大型项目中，开发者可借助 AI 代理的技能进行安全、符合团队规范的重构，无需来回手动审核每个细节。
- **Pull Request 代码评审**：将 AI 代理配置为自动化 Code Review 助手，利用技能文件定义评审标准（如 TypeScript 严格模式、边界条件检查）。
- **测试与文档生成**：基于已有代码，自动生成结构化的单元测试和 API 文档草案，开发者只需调整而非从头编写。
- **新人 onboarding**：新成员可将仓库技能集成到自己的 Agent 中，快速上手项目的代码风格和工程实践，缩短适应周期。

## 项目亮点

- **反“Vibe Coding”立场**：与主流“全权托管”式 Agent 项目不同，Skills 强调工程师对过程的绝对控制，技能文件本身就是可读、可改、可审计的资产。
- **实战驱动**：项目直接复制自作者日常使用的 `.claude` 目录，是经过真实工程场景检验的“生产级”技能，而非理论性 Prompt 集合。
- **极低的加入成本**：安装过程仅需 30 秒，依赖极简（仅需 Node.js），对现有开发流程零侵入性。
- **普适性与定制性兼得**：虽然提供了默认技能，但每个文件都鼓励用户 Fork 后按需修改，真正实现“从借用到自有”的进化路径。
