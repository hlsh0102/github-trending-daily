## 项目概述

Penpot 是一个面向产品团队的开源设计平台，旨在解决传统设计工具在协作、可扩展性和成本方面的核心痛点。作为市场上首个也是目前最成熟的开源设计协作工具，Penpot 让设计师、开发者和产品经理能够在同一平台上进行高效、实时的协同工作。

项目主要面向需要跨团队协作的产品设计团队、追求低成本设计解决方案的初创企业和中小企业，以及希望摆脱商业软件许可证限制、拥有完全数据控制权的组织。Penpot 完全基于 Web 浏览器运行，无需安装任何客户端，实现了真正的跨平台设计协作。

## 核心功能

- **实时协作设计**：支持多人同时编辑同一设计文件，所有修改实时同步，团队成员可以即时看到彼此的操作，如同在线文档协作般流畅。
- **矢量图形编辑**：提供完整的矢量编辑工具链，包括路径操作、布尔运算、贝塞尔曲线编辑等功能，满足专业级界面设计需求。
- **组件与样式系统**：支持创建可复用的设计组件和样式库，组件更新时所有引用实例自动同步，确保设计一致性。
- **原型与交互**：无需切换工具即可创建可交互的原型，支持页面跳转、悬停状态、过渡动画等交互逻辑模拟。
- **开发友好导出**：支持将设计稿一键导出为 SVG、PNG、PDF 等格式，并提供 CSS 代码片段生成功能，方便开发人员直接复制样式属性。
- **开源与自托管**：遵循 Mozilla Public License 2.0 协议，支持企业私有化部署，用户拥有对平台和数据的完全控制权。

## 技术架构

Penpot 采用前后端分离的现代架构设计，核心技术栈基于 Clojure 和 ClojureScript 构建，这一选择体现了对函数式编程范式的高要求。

后端使用 Clojure 语言运行在 JVM 之上，采用分布式架构设计，支持水平扩展。数据存储采用 PostgreSQL 关系型数据库，并利用其 JSONB 数据类型存储设计元素的复杂结构化数据。文件系统支持本地存储和 S3 兼容的对象存储，适配不同规模的部署需求。

前端采用 ClojureScript 编写，利用 React 框架作为 UI 层的基础。设计画布部分使用 WebGL 进行硬件加速渲染，确保复杂设计文档的流畅操作体验。实时协作功能基于 WebSocket 协议实现，通过 CRDT（Conflict-free Replicated Data Types）算法处理多用户并发编辑冲突。

整套系统通过 Docker 容器化部署，提供完整的 docker-compose 配置，降低运维复杂度。架构设计充分考虑了模块化，后端服务可以独立扩展，适应从单机开发到多节点生产环境的灵活部署。

## 安装与使用

Penpot 提供多种部署方式，其中最推荐的是 Docker 容器化部署：

```bash
# 克隆仓库
git clone https://github.com/penpot/penpot.git
cd penpot

# 启动所有服务
docker-compose -p penpot up -d
```

启动后，浏览器访问 `http://localhost:9001` 即可进入 Penpot 界面。首次使用时需创建管理员账号，然后即可开始创建团队、项目和设计文档。

对于希望快速体验的用户，也可以访问 Penpot 官方提供的在线演示环境（需注册账号）。最小可用流程包括：创建一个新文件 → 使用矩形、圆形等基础工具绘制元素 → 应用颜色和样式 → 添加交互链接 → 预览原型效果。

需要说明的是，Penpot 完全支持离线模式开发，用户可以在浏览器中无网络连接时继续编辑本地缓存的设计文件，重新联网后自动同步到服务器。

## 适用场景

- **产品设计协作**：产品团队可以创建统一的设计系统，设计师、产品经理和开发人员在同一个文件上实时协作，减少沟通成本和信息不同步的问题。
- **开源项目设计**：开源社区可以利用 Penpot 的免费特性进行 UI 设计，无需为每个贡献者购买商业设计软件许可，所有设计资产公开透明。
- **教育机构**：学校和培训机构可以使用 Penpot 进行 UI/UX 设计教学，学生无需支付高昂的商业软件费用，同时学习专业级设计工具操作。
- **企业内部设计平台**：对数据安全和合规性要求高的企业（如金融、医疗行业），可通过自托管方式部署 Penpot，确保敏感设计数据不出公司网络边界。

## 项目亮点

相比 Figma、Sketch 等主流商业设计工具，Penpot 的核心差异化优势体现在三个方面：

首先是**真正的开源与自由**。Penpot 是 MPL 2.0 协议下的完全开源项目，用户可以自由查看、修改和分发源代码，没有任何功能限制或用户数量限制。这使企业能够完全掌控自己的设计资产和技术栈，避免供应商锁定风险。

其次是**浏览器原生运行**。Penpot 基于现代 Web 技术构建，无需安装任何客户端软件。这一特性不仅降低了使用门槛，也使得在不同操作系统（Windows、macOS、Linux、ChromeOS）上获得完全一致的设计体验成为可能。

最后是**活跃的社区生态**。Penpot 已获得 Digital Public Goods 认证，拥有活跃的社区论坛和技术支持渠道。项目在 GitHub 上获得超过 5.6 万星，展现了强大的社区认可度和持续开发活力。
