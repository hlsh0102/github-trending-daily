## 项目概述

Clypra 是一款现代化、免费开源的视频编辑器，基于 Tauri v2、React 19 和 Rust 构建。该项目旨在提供媲美专业视频编辑软件（如 CapCut）的核心功能，同时保持永久免费、无水印、无功能限制的开源特性。其目标用户包括内容创作者、视频剪辑爱好者、开发者以及需要跨平台视频处理能力的专业用户。Clypra 强调硬件加速渲染和跨平台支持，覆盖桌面端（macOS、Windows、Linux）和移动端（iOS、Android），并可选配 AI 驱动的高级功能。

## 核心功能

- **多格式媒体导入**：支持 MP4、MOV、WebM、MKV、M4V、AVI 等视频格式，MP3、WAV、AAC 等音频格式，以及 JPG、PNG、WebP 等图片格式。
- **帧精确剪辑**：提供毫秒级精度的时间线控制，支持逐帧修剪和拼接。
- **多轨道时间线**：专业级时间线界面，包含标尺和视觉反馈，支持无限轨道叠加。
- **100 级撤销/重做**：完善的撤销/重做系统，确保编辑操作可回溯。
- **硬件加速渲染**：利用 Rust 和系统 GPU 实现高效视频处理，提升导出速度。
- **可选 AI 功能**：通过 Pro 层提供自然语言编辑、自动字幕、智能重构图等高级能力。

## 技术架构

Clypra 采用混合架构，结合了前端 UI 和后端高性能处理：

- **桌面端框架**：基于 Tauri v2 构建，提供跨平台桌面应用基础，相比 Electron 更轻量、内存占用更低。
- **前端技术栈**：使用 React 19 和 TypeScript 开发用户界面，确保现代、响应式且类型安全的交互体验。
- **后端处理引擎**：使用 Rust 编写核心视频处理逻辑，利用其内存安全和并发优势，同时通过系统级硬件加速（如 GPU 解码/编码）提升渲染效率。
- **跨平台扩展**：移动端通过 Capacitor 适配 iOS 和 Android，共享核心编辑器代码，实现“一次编写，多端运行”。
- **开放核心模型（Open Core）**：基础编辑功能完全开源（MIT 许可证），AI 功能作为可选 Pro 扩展，通过插件机制提供，不锁定核心体验。

## 安装与使用

### 桌面端安装

目前 Clypra 处于活跃开发阶段，以下为通用安装方式：

1. **从 GitHub Releases 下载**：访问 [GitHub 仓库](https://github.com/AIEraDev/Clypra) 的 Releases 页面，根据系统选择对应安装包（macOS 为 `.dmg`，Windows 为 `.msi`/`.exe`，Linux 为 `.AppImage`/`.deb`）。
2. **通过包管理器安装（未来支持）**：项目计划支持 Homebrew、Scoop 等工具一键安装。

### 最小使用示例

1. **导入媒体**：点击“导入”按钮或拖拽文件到项目面板。
2. **创建时间线**：将媒体拖入时间线轨道，自动对齐。
3. **剪辑操作**：使用时间线工具进行裁剪、分割、调整顺序。
4. **添加效果**：选择内置滤镜或过渡效果，拖拽应用到片段。
5. **导出视频**：设置分辨率、格式、编码参数，点击导出。

## 适用场景

- **内容创作**：为 YouTube、抖音、Bilibili 等平台制作视频，进行剪辑、加字幕、添加特效。
- **教学演示**：录制屏幕并快速编辑，添加标注、转场和背景音乐。
- **跨平台工作流**：在桌面完成精细编辑后，在移动端预览或轻量调整。
- **开发测试**：开发者可基于开源代码二次开发，定制专属视频编辑工具。

## 项目亮点

- **完全免费开放**：核心编辑器永久免费，无任何水印或功能限制，对比 CapCut 等商业软件需订阅或付费解锁专业功能，Clypra 将基础能力完全开放。
- **高性能架构**：Rust + Tauri 组合相比 Electron 方案更轻量且更高效，硬件加速确保 4K 视频流畅处理。
- **跨平台兼容**：同时覆盖桌面与移动端，同一个项目文件可在不同设备上编辑，无需重复操作。
- **可选 AI 扩展**：保持基础功能纯净，AI 能力作为可选插件，用户可按需启用，避免功能臃肿。
- **现代开发体验**：基于 React 19 和 TypeScript 的现代化前端架构，便于开发者贡献和二次开发。
