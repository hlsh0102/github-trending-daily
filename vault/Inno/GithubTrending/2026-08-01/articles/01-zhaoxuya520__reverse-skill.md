## 项目概述

reverse-skill 是一个面向网络安全领域的**技能路由包**，专为 AI 编程客户端设计，用于在逆向工程、授权渗透测试和安全研究场景下提供智能化的技能调度与工具链管理能力。该项目解决了安全工程师在使用 AI 辅助工具时面临的“技能碎片化”问题——不同的安全任务需要不同的工具链、知识库和操作流程，而传统方式需要手动切换和配置，效率低下且容易出错。

该项目定位为 AI 时代的网络安全操作中枢，通过自动路由机制，让 AI 客户端（如 Claude Code、Kiro、Cursor、Cline 等）能够根据当前任务的类型和上下文，自动选择并加载对应的安全技能模块，并按需自举所需的工具链。目前项目在 GitHub 上已获得超过 1 万 Star，社区关注度持续攀升。

## 核心功能

- **AI 自动路由**：基于任务语义分析，自动将安全任务路由到对应的技能模块（逆向、渗透、分析等），无需人工干预。
- **按需工具链自举**：根据当前任务需求，自动发现、下载并配置所需的逆向/渗透工具链，支持离线缓存与增量更新。
- **自进化知识库**：内置可持久化的经验数据库，每次成功执行的安全任务都会沉淀为可复用的知识条目，随使用时间不断优化路由准确性。
- **多客户端兼容**：原生支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端，提供统一的技能调用接口。
- **会话上下文感知**：自动跟踪当前会话的工程上下文，在多任务切换时保持技能状态与工具链的连续性。
- **安全合规边界**：内置授权检测机制，确保所有操作均在合法授权范围内进行，防止未授权的安全测试行为。

## 技术架构

项目基于 PowerShell 实现，利用了 PowerShell 在 Windows 环境下的强大脚本能力和系统集成能力。整体架构分为三层：

- **路由层（Router）**：核心是一套基于规则+语义匹配的路由引擎，接收来自 AI 客户端的任务描述，通过关键词解析、意图识别和上下文关联，将任务映射到具体技能模块。路由决策支持动态权重调整，随知识库的积累逐步优化。
- **工具链层（Toolchain）**：维护一个工具清单数据库，记录各类安全工具的名称、版本、依赖关系、适用平台和调用方式。当某个技能模块被激活时，工具链层自动检测本地环境，缺失的工具按需下载（支持代理与镜像源），并自动配置环境变量和路径。
- **知识库层（Knowledge Base）**：采用 JSON 结构的本地存储，记录历史任务的成功模式、失败原因、工具兼容性信息和操作经验。知识库支持主动学习——当某个新工具被成功使用后，会自动生成条目并关联到相关技能模块。

三个层级通过 PowerShell 模块化的函数接口相互调用，保持松耦合设计，便于扩展新的技能类型或支持新的客户端平台。

## 安装与使用

**前提条件**：Windows 10/11 或 Windows Server 2019+，PowerShell 5.1 或 PowerShell 7+，以及任意受支持的 AI 编程客户端。

**安装步骤**：

1. 克隆仓库到本地：

```powershell
git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill
```

2. 执行安装脚本，自动配置路由引擎与默认规则：

```powershell
.\install.ps1
```

3. 在 AI 客户端中配置 reverse-skill 的调用路径（以 Claude Code 为例），在客户端配置文件中指定 skills 目录即可。

**最小使用示例**：

在 AI 客户端中，直接以自然语言描述任务：

```
我需要逆向分析这个 Android APK 的签名校验逻辑
```

AI 客户端会将任务描述转发给 reverse-skill，路由引擎自动加载 Android 逆向技能模块，检查本地是否具备 `apktool`、`jadx`、`frida` 等工具，若缺失则自动安装，然后返回可执行的操作步骤供 AI 客户端执行。

## 适用场景

- **移动应用安全审计**：对 APK/IPA 进行逆向分析、签名校验绕过检测、漏洞挖掘，适用于企业内部安全团队或第三方安全评估机构。
- **红队/渗透测试项目**：在授权范围内进行 Web 应用、API 接口和基础设施的渗透测试，route-skill 负责调度 Nmap、Burp Suite、Metasploit 等工具链。
- **安全研究与漏洞分析**：对已知漏洞样本或恶意软件进行行为分析和特征提取，快速搭建分析环境并复用历史分析经验。
- **AI 驱动的安全自动化**：将 reverse-skill 作为安全运营平台的技能引擎，通过 AI 客户端实现安全任务的半自动化与自动化编排。

## 项目亮点

与同类安全工具集或 AI 插件相比，reverse-skill 的优势体现在：

- **技能路由而非工具堆砌**：绝大多数同类项目只是简单罗列工具清单，而 reverse-skill 实现了智能路由，让 AI 客户端能准确选择“当前任务最需要的能力”。
- **自进化能力**：知识库的持续积累使系统越用越精准，这一点在设计上与其他静态配置类项目有本质区别。
- **零配置接入**：在受支持的 AI 客户端中，仅需一条命令即可完成安装，无需手动配置复杂的插件或依赖。
- **工具链自愈**：自动检测工具缺失、版本不匹配等问题并主动修复，省去大量环境搭建时间。
