## 项目概述

tuicr 是一款专为代码审查场景设计的终端用户界面（TUI）工具，核心特色是支持完整的 vim 键位绑定。它的名字读作 "tweaker"，灵感来源于为开发者提供一种快速、高效、沉浸式的代码审查体验。该项目解决了代码审查过程中常见的痛点：传统网页端审查界面交互繁琐、上下文切换成本高，而命令行工具又往往只提供静态 diff 查看，缺乏评论、跟踪和与代码托管平台交互的能力。tuicr 的目标用户是习惯使用终端和 vim 快捷键的开发者，尤其是那些需要频繁进行代码审查、维护多个分支或参与开源项目的工程师。

## 核心功能

- **连续流式 diff 展示**：采用 GitHub 风格的连续 diff 视图，所有变更文件在一个流中平滑滚动，无需在多个文件间来回切换。
- **多层级评论系统**：支持行级、范围级、文件级和整个审查级别的评论，评论可即时保存并在后续会话中恢复。
- **审查进度跟踪**：可以按文件或 hunk（差异块）粒度标记审查进度，进度数据跨会话持久化，方便中断后继续工作。
- **多目标导出**：支持三种导出方式——直接将评论推送到 GitHub 或 GitLab 创建正式审查，将结构化 Markdown 复制到剪贴板，或通过管道输出到 stdout 配合其他工具使用。
- **多版本控制系统兼容**：不仅支持 git，还支持 jj（Jujutsu）和 mercurial，同时可以处理未提交的更改、提交区间，以及 GitHub PR 或 GitLab MR。

## 技术架构

tuicr 使用 Rust 语言开发，充分受益于 Rust 的高性能、内存安全性和丰富的终端生态。在架构设计上，它将 diff 解析、评论存储、VCS 交互和终端渲染进行模块化隔离，核心设计思路体现为以下三点：

1. **终端 UI 层与逻辑层分离**：UI 层专注于键盘事件处理和界面渲染，逻辑层则独立处理 diff 解析、评论管理和导出任务，这种分层设计使得工具易于扩展新功能。
2. **持久化状态管理**：通过本地存储机制保存评论和审查进度，使得每次会话可以无缝接续，这对于大范围代码审查尤其重要。
3. **多后端抽象**：通过 trait 抽象对 git、jj 和 mercurial 的调用，同时封装了 GitHub 和 GitLab 的 API 交互，用户可以在一条命令中完成从本地检出到远程提交审查的完整流程。

安装层面，tuicr 提供了极为灵活的安装方式，包括官方安装脚本、Homebrew、Cargo、Mise、Nix 和预编译二进制，并内置了 `tuicr update` 命令自动检测并更新到最新版本。

## 安装与使用

**安装**（任选一种）：

```bash
# 推荐：使用官方脚本
curl -fsSL tuicr.dev/install.sh | sh

# 或使用 Homebrew（macOS/Linux）
brew install agavra/tap/tuicr

# 或使用 Cargo
cargo install tuicr
```

**最小使用示例**：

```bash
# 审查当前未提交的更改
tuicr diff

# 审查最近的提交（例如 HEAD~3 到 HEAD）
tuicr diff HEAD~3 HEAD

# 审查指定的 GitHub PR（需配置 token）
tuicr pr 1234 --remote origin

# 导出审查为 Markdown 到剪贴板
tuicr diff --export clipboard
```

启动后，使用 vim 风格的 `j/k` 移动，`n/N` 跳转下一个/上一个差异块，按 `i` 进入插入模式添加评论。所有操作均可通过 `:help` 查看完整键位映射。

## 适用场景

- **本地代码审查**：在提交或推送前，快速浏览未提交的更改，添加评论标记问题，审查进度可随时暂存，下次继续。
- **远程 PR/MR 审查**：无需打开浏览器，直接在终端下拉取 GitHub PR 或 GitLab MR 的变更上下文，完成审查后一键创建正式评论。
- **多 VCS 环境下的统一工作流**：无论是使用 git、jj 还是 mercurial，tuicr 提供一致的审查体验，减少工具切换带来的认知负担。
- **自动化审查流程集成**：通过 `--export stdout` 将结构化评论输出到管道，可集成到 CI 脚本或与其他工具（如通知机器人）联动。

## 项目亮点

- **极致的终端体验**：不同于一般的 diff 查看器，tuicr 将评论、导航、跟踪和导出融为一个无缝的 vim 风格交互流程，显著降低审查时的干扰。
- **跨工具、跨平台的数据连贯性**：本地保存的评论和进度可随时切换到其他工具（如浏览器）查看，同时支持多种 VCS 和代码托管平台，这是同类终端审查工具中少见的集成度。
- **轻量而高可移植性**：单二进制文件，无需外部依赖，安装方式覆盖主流包管理器，且内置自更新能力，非常契合现代开发环境的效率要求。
