## 项目概述

Chatwoot 是一款开源的客户支持平台，旨在为企业提供现代化的全渠道客户服务解决方案。作为 Intercom、Zendesk、Salesforce Service Cloud 等商业产品的免费替代品，Chatwoot 让企业能够以完全自主可控的方式构建自己的客户支持系统。无论是初创公司还是大型企业，都可以通过 Chatwoot 统一管理来自网站实时聊天、电子邮件、社交媒体等多种渠道的客户对话，在一个简洁的界面中完成所有客服工作。项目采用 Ruby 编写，拥有活跃的社区和持续的功能迭代，目前在 GitHub 上已获得超过 35,000 颗星。

## 核心功能

- **实时聊天（Live Chat）**：在网站或应用中嵌入可自定义的聊天组件，支持访客与客服进行即时文字对话，并提供丰富的消息格式（文本、图片、文件等）。
- **多渠道整合**：除网页聊天外，还支持接入电子邮件、Facebook Messenger、Twitter、WhatsApp、Telegram、Line 等主流通讯渠道，统一收件箱管理所有对话。
- **团队协作与分配**：支持创建多个客服团队、设置自动分配规则（轮询、基于能力），并可将对话分配给特定客服或团队，实现高效协作。
- **对话管理**：提供标签、优先级、状态（未处理、已处理、挂起）、私有备注、自动回复（机器人/触发器）等功能，帮助客服团队高效组织和跟踪每个对话。
- **数据分析与报告**：内置仪表盘，展示对话量、响应时间、解决率、客服绩效等关键指标，帮助管理者了解团队表现并优化服务流程。
- **多语言与多品牌支持**：界面支持数十种语言，并允许在一个实例中管理多个品牌的独立客服门户和配置。

## 技术架构

Chatwoot 采用现代 Web 应用架构，技术栈以 Ruby on Rails 为核心，前端使用 Vue.js 构建交互式单页应用。后端通过 Rails API 模式提供 RESTful 接口，支持 WebSocket 用于实时通信，确保聊天消息的即时推送。项目使用 PostgreSQL 作为主数据库，并可选集成 Redis 用于缓存和队列任务。Chatwoot 的设计强调模块化和可扩展性，提供了丰富的 Webhook 机制和 API，允许开发者将 Chatwoot 与现有 CRM、ERP、工单系统等第三方工具进行深度集成。部署方面，官方提供 Docker 镜像和 Docker Compose 脚本，支持一键部署至云服务器或私有环境。此外，项目还拥有成熟的插件体系，可通过自定义机器人或触发器实现业务自动化。整体架构既保证了高可用性和高性能，也兼顾了自托管用户的易用性与灵活性。

## 安装与使用

Chatwoot 提供了多种安装方式，其中最简便的是使用 Docker。以下为基于 Docker Compose 的最小部署示例：

1. **克隆仓库并进入目录**：
   ```bash
   git clone https://github.com/chatwoot/chatwoot.git
   cd chatwoot
   ```

2. **配置环境变量**：
   复制 `.env.example` 为 `.env`，并设置必要的变量，如 `SECRET_KEY_BASE`、`POSTGRES_PASSWORD` 等。

3. **启动服务**：
   ```bash
   docker-compose up -d
   ```
   首次运行会自动初始化数据库并启动 Web 服务。稍等片刻后，访问 `http://localhost:3000` 即可看到 Chatwoot 的登录页面。

4. **创建管理员账号**：
   通过 Web 界面注册第一个账号，该账号将自动成为超级管理员。之后即可进入后台，创建客服团队、配置渠道并开始使用。

对于生产环境，推荐使用 Kubernetes 或专业的 PaaS 平台，并配置 HTTPS 和持久化存储。此外，项目也支持直接从源码部署（要求 Ruby、Node.js 和 PostgreSQL 环境）。

## 适用场景

- **中小企业客户支持**：预算有限但又需要专业客服系统的企业，可通过自托管 Chatwoot 获得近乎商业级的功能，无需支付高昂的按座席订阅费用。
- **数据敏感行业**：金融、医疗、政府等对数据主权要求严格的机构，可将全部客户数据保存在自有服务器，满足合规要求。
- **产品团队快速集成**：SaaS 产品团队可通过 API 和 Webhook 将 Chatwoot 嵌入自有产品，作为内置帮助中心或工单系统的核心组件。
- **多品牌或多部门运营**：需要为不同产品线或地区部门提供独立客服入口的企业，可在单一实例中管理多个品牌和独立团队。

## 项目亮点

- **真正的开源替代品**：与 Intercom、Zendesk 等商业产品在功能上高度对标，却基于开源许可发布，用户可以自由修改、审计和分发，彻底摆脱厂商锁定。
- **全渠道统一收件箱**：将来自不同渠道的对话汇聚于一个界面，客服无需在多个工具间切换，显著提升处理效率。
- **高度可定制与自托管**：提供完整的 API、Webhook 和主题定制能力，支持任意云或本地部署，数据完全自主掌控。
- **活跃社区与持续迭代**：项目在 GitHub 上拥有超过 35,000 星标和大量贡献者，社区提供丰富的插件、教程和第三方集成，功能更新频繁，生态日益完善。
