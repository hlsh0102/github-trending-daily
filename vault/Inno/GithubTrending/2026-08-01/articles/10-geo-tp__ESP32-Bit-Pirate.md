## 项目概述

ESP32 Bit Pirate 是一款基于 ESP32 芯片的开源固件，它将你的开发板转变为一台多协议硬件分析与调试工具。项目灵感来源于经典的 Bus Pirate，但完全基于现代且廉价的 ESP32 平台。该工具通过串行终端或基于 Web 的 CLI，支持对 I2C、UART、1-Wire、SPI 等常见数字协议进行嗅探、发送、脚本编写和交互操作。此外，它还能通过 ESP32 自带的无线电模块，与蓝牙、Wi-Fi、Sub-GHz 和 RFID 等无线协议通信。

项目目标是降低硬件黑客、嵌入式开发者和安全研究者的入门门槛，提供一套开源、可扩展且功能全面的硬件调试解决方案。官方项目网站集中了所有资源，包括固件安装、Web 工具、硬件指南、使用示例和完整文档。

## 核心功能

- **交互式命令行界面**：通过 USB 串口或 Wi-Fi Web 提供一致的交互式 CLI，用户可以在浏览器中或传统终端中操作。
- **多协议支持**：内置 HiZ（高阻态，默认模式）、I2C、SPI、UART、半双工 UART 等多种数字协议模式，每种模式均提供丰富的子命令。
- **I2C 高级功能**：支持总线扫描、电压毛刺注入（glitch）、从机模式、总线数据转储（dump）以及 EEPROM 读写。
- **SPI 存储操作**：针对 SPI 接口的 EEPROM、Flash、SD 卡提供专门的读写和擦除指令，并支持从机模式。
- **无线协议通信**：利用 ESP32 的射频能力，实现对蓝牙、Wi-Fi、Sub-GHz 和 RFID 等无线协议的抓取与交互。
- **脚本与自动化**：支持通过编写脚本批量执行命令，便于复杂测试流程的自动化。

## 技术架构

该项目的核心是运行在 ESP32 上的 C++ 固件，利用了 ESP-IDF 框架实现底层硬件控制。架构设计借鉴了 Bus Pirate 的模块化理念，将不同协议封装为独立的“模式”模块，每个模块内部实现了协议特有的命令解析和硬件操作逻辑。

CLI 层与传输层解耦，使得同一套命令逻辑可以通过 USB 串口和 WebSocket 两种物理通道访问。Web CLI 基于 ESP32 内置的 Wi-Fi 能力，在设备上运行一个轻量级 HTTP 服务器，用户通过浏览器访问即可获得与串口终端几乎相同的交互体验，这在移动设备或无串口线缆场景下尤为实用。

固件中硬件抽象层（HAL）的设计使得协议切换时对 GPIO 引脚的重配置高效且可靠。对于无线协议，固件直接调用 ESP32 的 Bluetooth Classic/BLE 栈以及 802.11 和 Sub-GHz 相关的驱动接口，实现统一命令入口下的多协议覆盖。

## 安装与使用

安装过程通过项目网站的 Web Flasher 工具完成，无需本地编译环境。用户只需使用 Chrome 或 Edge 浏览器，将 ESP32 开发板通过 USB 连接到电脑，然后在 [Web Flasher 页面](https://geo-tp.github.io/ESP32-Bit-Pirate/webflasher/) 点击“连接”并选择对应固件即可刷写。

最小使用示例如下：

1. 将 ESP32 开发板（如 DevKitC）通过 USB 线连接到电脑。
2. 使用串口终端软件（如 PuTTY 或 minicom）打开对应端口，波特率建议为 115200。
3. 上电或按复位键，终端会显示欢迎信息和提示符 `HiZ>`。
4. 输入 `m` 进入模式选择菜单，然后按提示输入 `2` 切换至 I2C 模式。
5. 在 `I2C>` 提示符下输入 `scan` 即可扫描 I2C 总线上的设备地址。

若使用 Web CLI，则确保 ESP32 已连接 Wi-Fi（可通过串口命令 `wifi join <SSID> <password>` 配置），然后在浏览器中访问设备显示的 IP 地址即可开始操作。

## 适用场景

- **嵌入式开发调试**：在开发 I2C 或 SPI 传感器驱动时，使用 Bit Pirate 快速验证总线通信、读取设备寄存器或抓取通信波形。
- **硬件安全研究**：安全研究员可利用其 I2C 毛刺注入功能进行故障注入测试，或通过嗅探 UART/SPI 数据来分析固件更新流程。
- **电子维修与逆向**：维修人员可通过读取 EEPROM 或 Flash 芯片内容来备份配置或分析设备行为，尤其在无法拆下芯片的场景下。
- **无线协议分析**：在物联网设备测试中，利用其 Wi-Fi/蓝牙功能捕获设备通信，辅助分析协议格式或调试无线连接问题。

## 项目亮点

与经典的 Bus Pirate 或其他逻辑分析仪相比，ESP32 Bit Pirate 的最大优势在于**极低的硬件成本**和**无线协议支持**。ESP32 开发板价格低廉且随处可见，用户无需购买专用硬件即可获得相似甚至更丰富的功能。将 Wi-Fi、蓝牙与数字协议工具整合在一个设备中，极大扩展了应用范围。

另一个亮点是**Web 端 CLI**。用户无需安装任何桌面软件，只要有浏览器和 Wi-Fi 即可操作，这在现场调试或远程作业时极为便利。同时，项目的模块化固件设计和活跃的社区生态（5000+ Stars）意味着持续的功能更新和丰富的使用文档（Recipes），用户可以快速找到针对特定芯片或总线的现成解决方案。
