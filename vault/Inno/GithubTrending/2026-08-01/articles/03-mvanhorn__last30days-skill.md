## 项目概述

`last30days` 是一个面向 AI 代理（AI Agent）的搜索技能（Skill），它能够跨越 Reddit、X（原 Twitter）、YouTube、Hacker News、Polymarket 以及整个开放网络，对任意主题进行深度调研，并最终合成一份有据可查的摘要报告。该项目由 mvanhorn 开发，以 MIT 协议开源，目前在 GitHub 上已获得超过 56,000 颗星标，并曾登上 GitHub 趋势榜首位。

这个项目的诞生源于一个朴素的观察：传统搜索引擎由编辑算法决定内容排序，而 `last30days` 反其道而行之，让 AI 代理直接检索“人”的讨论——以点赞数、评论热度、甚至真金白银的预测市场作为信号，从而捕捉到真正被社区热议的话题。它解决的痛点是：当你想快速了解一个新兴技术、一场舆论风波或一个商业趋势时，与其翻阅被 SEO 污染的网页，不如直接看看过去 30 天里，真实的人们在各大平台上都在讨论什么。

目标用户非常明确：需要快速做市场调研的产品经理、追踪技术热点的开发者、关注舆论动向的媒体从业者，以及任何希望借助 AI 获得高质量信息综述的知识工作者。

## 核心功能

- **多渠道数据采集**：同时检索 Reddit、X、YouTube、Hacker News、Polymarket 和通用网络搜索，覆盖社交媒体、视频平台、技术社区和预测市场。
- **AI 代理驱动的搜索**：由 AI 代理自主规划搜索路径、执行查询、筛选信息，而非简单返回链接列表。
- **基于社交信号的排序**：结果评分依据 upvotes、likes、评论数和预测市场资金流向，而非编辑推荐或广告排名。
- **有据可查的摘要合成**：自动生成一份结构化摘要，每条关键结论都附带来源链接，便于追溯验证。
- **即插即用的 Skill 生态**：支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等 50+ 主流 AI 编码工具，通过一行命令安装。
- **多语言文档支持**：README 提供英、法、德、西、葡、日、简体中文七种语言版本，降低全球开发者使用门槛。

## 技术架构

`last30days` 本质上是一个遵循 [Agent Skills](https://agentskills.io) 规范的技能包，其核心运行时规范定义在 `skills/last30days/SKILL.md` 文件中，这是所有命令和行为的最新事实来源。

从实现层面看，它采用 Python 编写，充分利用了 AI 代理的规划与工具调用能力。技术栈的核心设计思路可以概括为“搜索即服务”：技能包向宿主 AI 代理暴露一组搜索工具，代理根据用户的自然语言请求，动态决定调用哪个平台的 API、以什么关键词检索、如何聚合结果。

值得关注的设计亮点在于其评分机制。不同于简单地并列展示各平台结果，它会将不同来源的信号（Reddit 的 upvote、YouTube 的 like、Polymarket 的交易额）归一化处理，并通过加权计算得出一个综合热度分数。这种跨平台信号融合机制，让最终摘要能够反映“全网讨论热度”，而非单一平台的局部热点。

此外，项目采用了插件市场（marketplace）机制，使得技能可以自动更新——用户通过 `plugin marketplace add` 安装后，后续版本迭代无需手动干预。

## 安装与使用

安装过程极其简单，根据所使用的 AI 编码工具选择对应命令：

**方式一：Claude Code（推荐，支持自动更新）**

```
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

**方式二：其他 AI 工具（Codex、Cursor、Copilot、Gemini CLI 等）**

```
npx skills add mvanhorn/last30days-skill -g
```

安装完成后，你只需要在对话中向 AI 代理提出研究请求即可。最小可用示例如下：

> 请研究一下“开源大模型”在过去 30 天的社区讨论，重点关注 Reddit 和 Hacker News 上的热点话题，并给我一份带来源的摘要。

AI 代理会调用 `last30days` 技能，自动检索各平台，最终返回一份包含关键观点、争议点、热度趋势的综述报告，并在文末附上所有引用来源。

## 适用场景

1. **技术趋势追踪**：开发者或技术决策者需要快速了解某项新技术（如 Rust、WebGPU、向量数据库）在开发者社区的讨论热度、主流观点和潜在风险，无需逐一翻阅各大论坛。

2. **市场与舆情调研**：产品经理或品牌公关人员需要评估某个新品的市场反响，或监测某个话题的舆论风向。通过跨平台数据，可以捕捉到从 Reddit 深度讨论到 X 平台即时反应的全貌。

3. **投资与预测参考**：Polymarket 的预测数据提供了“用真金白银投票”的信号。投资者可以结合社区讨论热度与预测市场价格，辅助判断某些事件的发展概率。

## 项目亮点

与传统的搜索 API 封装或简单的 RSS 聚合工具相比，`last30days` 的差异化优势非常明显：

- **“搜人”而非“搜网页”**：核心哲学是搜索真实用户的讨论，以社交信号替代算法排名，这使其结果更贴近社区真实关注点。
- **跨平台信号归一化**：不是简单拼接结果，而是将不同平台的异构数据（点赞、评论、交易额）统一为可比较的热度指标，这在同类开源项目中较为罕见。
- **零配置、秒级接入**：通过标准的 Agent Skills 生态，一行命令即可在数十种 AI 工具中使用，无需申请多个 API Key 或配置复杂的数据管道。
- **完全开源、透明可追溯**：MIT 协议，代码完全开放，且摘要中每条结论都能追溯到具体来源，保证了调研结果的可验证性。
