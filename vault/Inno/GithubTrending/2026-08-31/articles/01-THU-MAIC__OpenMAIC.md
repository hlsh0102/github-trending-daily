## 项目概述

OpenMAIC（Open Multi-Agent Interactive Classroom）是一个开源的**多智能体互动课堂**项目，由清华大学 THU-MAIC 团队开发。它通过将多个 AI 智能体组织在一个虚拟课堂环境中，为用户提供沉浸式的多智能体学习体验——用户只需要一次点击，就能进入一个由 AI 驱动的互动教学场景。

该项目解决了传统在线教育中互动性不足、个性化欠缺的问题。在 OpenMAIC 构建的虚拟课堂里，多个具备不同角色和知识背景的 AI 智能体可以相互协作、辩论和教学，营造出类似于真实课堂的讨论氛围。目标是让学习者不再被动地接收视频或文字内容，而是通过与 AI 教师、AI 同学的多轮对话，主动探索知识。

目标用户包括：
- 希望以互动方式学习新知识的个人学习者
- 需要快速搭建 AI 教学原型的高校教师和科研人员
- 对多智能体系统感兴趣的开发者与研究者

## 核心功能

- **一键部署课堂**：通过 Vercel 等平台即可快速部署，无需复杂配置，点击即可获得完整的互动课堂体验。
- **多智能体角色编排**：内置教师、助教、学生等多种角色智能体，每个智能体拥有独立的人设、知识库和对话策略，形成活跃的课堂讨论。
- **多 LLM 提供商适配**：支持 OpenAI、Anthropic 等主流大语言模型提供商，用户可自由选择或混合使用不同模型，且所有提供商均为可选配置。
- **沉浸式交互界面**：提供类似真实课堂的聊天界面，支持多人对话流展示，智能体之间的交互清晰可见。
- **可配置的课堂流程**：支持设定课堂主题、学习目标、讨论轮次等参数，灵活控制教学节奏。
- **基于浏览器的一键克隆**：支持通过 Vercel 平台直接克隆仓库并进行部署，同时提供在线演示环境。

## 技术架构

OpenMAIC 基于 **TypeScript** 开发，采用现代前端技术栈构建。项目的核心架构围绕多智能体协同引擎展开，主要设计特点包括：

- **智能体通信框架**：项目内部实现了结构化的智能体消息传递机制，支持一对多、多对多的对话模式，并能够在对话中维持角色一致性。
- **模型无关层**：通过抽象封装，OpenMAIC 不绑定特定的大语言模型。用户只需配置相应的 API Key（如 `OPENAI_API_KEY`、`ANTHROPIC_API_KEY`），即可接入不同提供商，降低了迁移成本。
- **浏览器优先的部署策略**：项目被设计为可快速部署到 Vercel 等无服务器平台，前后端逻辑高度集成，使得部署和运行的门槛降到最低。
- **模块化组件设计**：界面与逻辑分离，各个功能模块（如课堂管理、智能体调度、消息渲染）均以独立组件或服务形式存在，便于二次开发和功能扩展。

该架构设计的核心优势在于：将复杂的多智能体协调逻辑封装为简单的配置项和 API，让普通用户无需了解底层原理即可使用，同时也为研究人员提供了清晰的可扩展接口。

## 安装与使用

OpenMAIC 提供了极其简便的部署方式，推荐使用 Vercel 进行一键部署。

**步骤一：克隆与配置**

使用 Git 克隆仓库并安装依赖：

```bash
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC
npm install
```

在项目根目录创建 `.env` 文件，并至少配置一个 LLM 提供商的 API Key（所有提供商均为可选项，但至少需要一个才能运行智能体）：

```bash
# 可选配置，任意一个或多个
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
```

**步骤二：启动本地开发环境**

```bash
npm run dev
```

访问 `http://localhost:3000` 即可进入互动课堂界面。

**步骤三：最简使用示例**

1. 在课堂设置界面中，选择一个预设的教学场景（如“量子物理基础”或“西方哲学史”）。
2. 点击“开始课堂”，系统会自动创建一组包含教师和学生角色的 AI 智能体。
3. 用户以旁听生身份加入对话，可以直接向 AI 教师提问，或观察不同智能体之间的讨论。
4. 可随时调整对话轮次或切换讨论主题，课堂将根据新指令继续推进。

## 适用场景

- **个性化自学辅助**：对于希望深入理解某一学科的独立学习者，OpenMAIC 可以提供一个 24 小时在线的“私人学习小组”，通过多角度辩论深化理解。
- **高校教学与课程设计**：教师可利用此工具创建课前的预习讨论场景，或在课堂上演示多智能体协作的案例，增强教学的直观性与趣味性。
- **多智能体系统的科研实验**：研究人员无需从零搭建复杂的前后端框架，可直接在此项目基础上修改角色设定或通信逻辑，快速验证多智能体协作算法。
- **线上教育产品原型验证**：教育科技公司可以基于 OpenMAIC 快速构建概念验证（PoC），评估用户对 AI 互动课堂的接受度。

## 项目亮点

- **极低的进入门槛**：与业界普遍“重部署、重配置”的多智能体框架不同，OpenMAIC 将复杂的系统封装为开箱即用的产品，通过 Vercel 即可在几分钟内上线。
- **教学场景的深度优化**：并非简单地将多个 AI 聊天机器人堆砌在一起，而是针对课堂互动模式（如教师提问、学生抢答、小组辩论）做了精细的用户体验设计。
- **学术与工程的双重背书**：项目源自清华大学，且已发表相关学术论文（JCST '26），在理论严谨性和工程实现上均有保障。作为一个开源项目，其 MIT 许可允许自由的商业与学术使用。
- **极高的开放性与可组合性**：支持多种 LLM 混用，且前后端代码完全开源，便于开发者将其作为子模块集成到更大的业务系统中。
