## 项目概述

Heretic 是一款面向开源社区的语言模型审查消除工具，能够以全自动化的方式移除基于 Transformer 架构的大语言模型中的“安全对齐”（即审查机制），且无需昂贵的后训练过程。该工具由研究者 p-e-w 开发，在 GitHub 上已获得超过 29000 颗星，是目前该领域最受关注的项目之一。

对于 AI 研究者、模型微调工程师以及追求模型自由表达的开发者而言，Heretic 解决了当前主流语言模型普遍存在的过度审查问题。许多模型在发布时会植入拒绝回答某些类型问题的机制，这限制了模型在创意写作、角色扮演、学术研究等场景下的实用性。Heretic 通过一种名为“方向消融”（Directional Ablation，又称 abliteration）的先进技术，在保留模型原有智能水平的前提下，精准识别并去除这些审查路径。

Heretic 的核心理念是“零门槛”。使用者无需理解 Transformer 内部结构，只需具备基本的命令行操作能力，即可完成模型去审查的全部流程。这一设计理念使得模型定制不再是少数专家的专利，极大地降低了技术门槛。

## 核心功能

- **全自动去审查流程**：内置基于 Optuna 的 TPE 参数优化器，自动搜索最优的消融参数，无需人工干预或手动调参。
- **KL 散度约束**：在最小化模型拒绝回答次数的同时，通过 KL 散度度量确保去审查模型与原始模型的行为差异最小，最大限度保留原有智能。
- **广泛的模型兼容性**：支持大多数密集型 Transformer 模型，包括多种多模态模型，覆盖当前主流开源模型家族。
- **命令行接口设计**：提供简洁易用的 CLI 工具，用户只需输入模型路径和输出路径，即可完成全部操作。
- **社区生态集成**：提供 Discord、Matrix 交流群组以及 Hugging Face 组织页面，方便用户共享去审查模型和优化经验。

## 技术架构

Heretic 的技术核心建立在两项前沿研究的交叉点上。第一项是 Arditi 等人于 2024 年提出的方向消融技术，该技术通过分析模型内部的残差流表示，识别出负责“拒绝回答”行为的线性方向，并将这些方向从模型中消去。第二项是 Lai 在 2025 年引入的改进变体，包括投影消融（Projected Abliteration）和范数保持双投影消融（Norm-Preserving Biprojected Abliteration），这些变体在消融过程中考虑了更复杂的向量空间关系，能够以更高精度定位审查机制。

Heretic 的架构设计亮点在于其将这一复杂的算法过程封装为自动化流水线。位于核心的是一个基于 Optuna 框架的 TPE（Tree-structured Parzen Estimator）贝叶斯优化器，它负责搜索消融参数的配置空间。优化目标是一个双目标函数：一方面最小化模型在敏感提示语下的拒绝率，另一方面最小化去审查模型与原始模型之间的 KL 散度。这两个目标的平衡确保了去审查模型不会因为过度修改而“变笨”。

整个工具以 Python 为主要实现语言，依赖 Hugging Face Transformers 等主流深度学习生态库，能够在配有 NVIDIA GPU 的机器上高效运行。其设计思路是将复杂的算法细节抽象为用户无需感知的黑盒，从而实现了“完全自动”的使用体验。

## 安装与使用

Heretic 的安装采用标准的 Python 包管理方式。建议在具备 Conda 或虚拟环境的 Python 3.10+ 环境中进行安装，并确保系统内已配置 CUDA 环境以利用 GPU 加速。

```bash
git clone https://github.com/p-e-w/heretic.git
cd heretic
pip install .
```

安装完成后，最基本的使用方式只需一行命令，指定输入模型路径与输出目录：

```bash
heretic --model /path/to/your/model --output /path/to/output_dir
```

其中 `--model` 参数接受本地模型路径，也可以直接指定 Hugging Face 仓库的模型 ID。工具会自动加载模型、执行优化流程、生成去审查后的模型权重并保存到目标目录。对于内存有限的环境，可以通过 `--dtype float16` 参数降低显存占用。

Heretic 同时提供一系列高级参数，如 `--eval-batch-size` 用于控制评估批次大小、`--n-trials` 用于设定优化轮次上限等，用户可根据硬件条件和时间预算进行调整。完成后的模型可以直接加载到任何标准的 Hugging Face Transformers 环境中继续使用。

## 适用场景

- **创意写作与角色扮演**：小说作者或游戏玩家常遇到模型因审查机制而拒绝生成成人向、暴力或争议性主题内容，Heretic 可让模型保持“角色”而不会频繁跳出对话发出免责声明。
- **学术研究与安全分析**：AI 安全研究人员需要研究模型审查机制的内部工作原理，通过对消融方向的剖析，可以更深入了解模型行为。
- **企业定制化模型开发**：企业客户在部署通用模型时，常需去除与自身业务场景不符的过度限制，Heretic 的自动化流程可大幅缩短模型定制周期。
- **模型能力评估基准测试**：开发者在评估模型知识边界时，审查机制的存在会干扰测试结果，使用 Heretic 可还原模型真实的知识水平。

## 项目亮点

与同类工具相比，Heretic 最显著的差异化优势在于其完全自动化的设计。传统上，abliteration 技术需要用户具备扎实的机器学习背景，手动分析模型激活值、绘制可视化图谱并手动挑选消融方向与强度。Heretic 通过将参数搜索交给贝叶斯优化器，将这一过程精简为“输入模型，得到结果”。

其次，Heretic 在自动化过程中引入了 KL 散度约束，这是同类工具大多缺乏的特性。该约束确保了去审查后的模型在能力保留上显著优于简单粗暴地删除激活方向的方法，使得用户在获得自由表达的同时，不损失模型原本的推理、写作和编码能力。

此外，Heretic 对多模态模型的支持也使其适用面更广，能够处理视觉语言模型等新型架构，这在该领域工具中较为少见。项目采用 AGPL-3.0 开源协议，完全开放源代码，社区活跃度高，讨论氛围浓厚。
