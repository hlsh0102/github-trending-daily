## 项目概述

last30days 是一个面向 AI 代理（Agent）的技能包（Skill），它构建了一个以 AI 代理为主导的搜索引擎，能够针对任意主题，在 Reddit、X（原 Twitter）、YouTube、Hacker News、Polymarket 以及整个互联网上进行深度调研，并最终综合生成一份有据可依的摘要报告。

该项目解决的核心痛点是：传统搜索引擎由编辑算法和 SEO 排名主导，返回的结果往往与真实用户的声音脱节。而 last30days 的核心理念是“搜索人，而非编辑”——它直接抓取真实用户在各大社交平台上的发言、投票和讨论，并以赞同数、点赞数和真金白银的预测市场数据作为排序依据，让搜索结果反映的是大众的真实观点和热度，而非网站编辑的推荐。

该项目的目标用户包括：需要快速了解某话题近期舆论走向的市场研究员、需要追踪产品反馈的产品经理、希望紧跟热点的内容创作者，以及所有希望绕过信息茧房、直接获取“街头智慧”的普通用户。它可作为 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等 50 多个支持 Agent Skills 标准的开发工具中的即插即用功能。

## 核心功能

- **多源聚合搜索**：一键同时查询 Reddit、X、YouTube、Hacker News、Polymarket 和通用网页搜索，覆盖主流舆论阵地。
- **基于真实参与度的排序**：结果按照 Reddit 的 upvotes、X 的 likes、YouTube 的点赞数以及 Polymarket 的预测市场资金流动进行加权排序，确保高亮内容来自真实的社区认可。
- **时间窗口聚焦**：专门优化“最近 30 天”的时间跨度，自动筛选出近期发布或讨论度飙升的内容，避免过时信息干扰。
- **AI 摘要综合**：利用大语言模型对收集到的多源数据进行交叉比对和去重，生成结构化的、带有引用来源的摘要报告。
- **即装即用的 Skill 规范**：遵循 Agent Skills 标准，提供标准化的 `SKILL.md` 指令文件，任何兼容主机都能加载并理解其用法。
- **跨平台无缝集成**：提供两种安装方式，分别面向 Claude Code 的插件市场和其他所有兼容主机，支持通过 npx 一键部署。

## 技术架构

该项目采用“技能包（Skill）”作为分发单元，其核心是一个符合 [Agent Skills](https://agentskills.io) 规范的 `SKILL.md` 文件。该文件作为运行时技能规范，是命令和设置行为的唯一权威来源，包含了完整的指令、参数定义和环境配置说明。

底层实现基于 Python，设计了模块化的抓取与解析层，针对每个数据源（Reddit、X、YouTube 等）封装独立的适配器，通过统一的接口输出标准化数据模型。架构上采用两阶段流水线：第一阶段是并行抓取与预处理，利用异步 IO 提升多源请求效率；第二阶段是综合推理，将预处理后的结构化数据注入精心设计的提示词模板，经由大语言模型生成带有内联引用的 Markdown 格式摘要。

设计上的一个显著特点是“代理主导”（agent-led）。这意味着工具本身不预设搜索结果的展示模板，而是赋予 AI 代理足够的自由度，让它根据用户意图自主决定如何组合不同来源的数据、如何权衡跨平台冲突的信息。此外，项目在 README 中明确了 v3 流水线的当前状态，并强调了 `SKILL.md` 作为事实来源，这保证了在不同 AI 主机间行为的一致性和可维护性。

## 安装与使用

安装过程针对不同 AI 宿主分两种情况。

对于 Claude Code（推荐方式，支持通过市场自动更新）：

```bash
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

对于 Codex、Cursor、Copilot、Gemini CLI 或任何其他兼容 Agent Skills 标准的主机（共 50 余种）：

```bash
npx skills add mvanhorn/last30days-skill -g
```

安装完成后，在支持 Agent Skills 的对话界面中，直接使用斜杠命令调用 `/last30days` 并输入你关心的主题即可。一个最小可用示例如下：

```text
/last30days 电动车价格战
```

该命令会触发技能执行完整的调研流水线，收集各平台近 30 天与此话题相关的热门讨论和帖子，并在数秒内生成一份包含各平台关键观点、点赞量对比以及综合结论的摘要报告。用户可以进一步追问细节，例如“Reddit 上对此的主流情绪是什么？”或“Polymarket 上关于该话题的预测概率有何变化？”以获取更细粒度的信息。

## 适用场景

- **市场与竞品情报调研**：在新产品立项或营销策略制定前，快速摸清目标市场在各大社区对竞品的真实吐槽点与好评点，基于点赞数判断主流口碑。
- **舆情热点追踪**：新闻编辑或媒体从业者可用它在 30 分钟内掌握某一社会事件在多个平台的发酵脉络，找到最有影响力的原始讨论帖。
- **投资决策辅助**：结合 Polymarket 的预测市场数据和 Reddit/华尔街见闻的讨论热度，对某个政策或行业事件的市场预期形成多维度的交叉验证。
- **内容创作选题**：博主或视频创作者通过搜索“开源 代码审查”等主题，直接获取近期高赞的问题清单和用户痛点，作为视频脚本或文章框架的素材来源。

## 项目亮点

与普通搜索引擎或单平台分析工具相比，last30days 的差异化优势十分明显。首先是**数据源正交性**——它将社交新闻、微博客、视频平台、技术论坛和真金白银的预测市场糅合在一个查询中，提供了独一无二的跨维度视角。其次是**反编辑立场**：算法明确排斥编辑推荐和 SEO 权重，只以用户的真实参与行为（点赞、投币、下注）为信号，这使其结果更贴近地气。

技术上，该项目严格遵循 Agent Skills 标准，而非绑定特定厂商 API，这使它天生具有**可移植性**。同一个技能文件，在 Claude Code 中是通过插件市场管理的自动更新版本，在其他 50 多个主机中是通过 npx 安装的通用版本，这意味着用户的学习成本极低，且社区维护的更新能统一触达所有平台。

此外，该项目在 GitHub 上表现异常亮眼，曾获得全球趋势榜“当日第一仓库”的荣誉，目前拥有超过 6 万 Star 且日增约 230，这既是社区对其实用性的检验，也是对其设计理念的认可。它不是一个演示性的玩具项目，而是一个经过真实用户高强度使用验证的成熟开源工具。
