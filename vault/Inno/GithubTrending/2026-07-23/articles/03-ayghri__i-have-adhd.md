## 项目概述

`i-have-adhd` 是一个专为编码助手设计的技能插件，旨在改变 AI 助手输出信息的方式，让回答更加直接、结构化、易于快速获取关键信息。项目的核心理念是“ADHD 友好输出”，即优先呈现答案、使用编号步骤、去除冗余客套话，帮助用户在信息过载的环境中高效定位所需内容。目标用户是所有希望 AI 助手更简洁、更聚焦的开发者，无论是否被诊断为 ADHD，都能从中受益。

## 核心功能

- **答案优先呈现**：AI 助手会直接输出答案或解决方案，而不是以“这是一个好问题”之类的开场白开始。
- **步骤编号化**：所有操作步骤自动编号，便于用户按顺序执行和快速回溯。
- **去除无效修饰**：省略“希望这对你有帮助！”、“如果你需要更多细节，请告诉我”等客套语句，直接进入正题。
- **即装即用**：通过插件市场一键安装到 Claude Code、Codex 等主流编码代理，无需手动配置复杂规则。
- **跨平台支持**：除了 Claude Code 和 Codex，还提供对其他编码代理的安装指引（见 `INSTALL.md`）。
- **持久化选项**：支持通过创建标记文件（如 `~/.claude/.i-have-adhd-always`）将技能永久应用到所有会话。

## 技术架构

该项目本质上是一个编码代理的技能定义包，以 Python 语言编写，遵循插件市场标准格式。其核心机制是通过拦截和修改 AI 助手的输出提示结构，在执行前注入特定的输出约束规则。项目不涉及复杂的后端架构或外部依赖，设计上强调轻量、可移植和零侵入性——安装无需克隆仓库，由插件市场自动拉取并保持更新。技能逻辑以声明式规则为主，通过配置文件定义输出行为，使不同的编码代理能根据自身适配层解析并应用这些规则。

## 安装与使用

**安装步骤（以 Claude Code 为例）：**

1. 打开终端，执行以下命令添加插件市场：
   ```bash
   claude plugin marketplace add ayghri/i-have-adhd
   ```
2. 安装插件：
   ```bash
   claude plugin install i-have-adhd@i-have-adhd
   ```
3. 在对话中输入 `/i-have-adhd` 即可激活技能。注意，无需手动克隆仓库，Claude Code 会自动获取并更新。

**在 Codex 上的安装：**

```bash
codex plugin marketplace add ayghri/i-have-adhd --ref main
codex plugin add i-have-adhd@i-have-adhd
```
然后在对话中输入 `$i-have-adhd` 显式应用输出风格。当 Codex 识别到任务适合使用该技能时，也会自动触发。

**其他代理：** 请参考项目中的 `INSTALL.md` 获取安装指引。

**最小可用示例：** 安装并激活后，向 AI 助手提问“如何用 Python 读取 CSV 文件？”，你将会看到类似这样的输出：

```
1. 导入 csv 模块
2. 使用 open() 打开文件  
3. 调用 csv.reader() 读取数据
4. 遍历 reader 对象
```

而非传统的冗长回答。

## 适用场景

- **快速获取技术方案**：当需要立即知道某个问题的解决步骤时，例如调试错误、配置环境、实现特定功能。
- **多步操作任务**：需要严格按照顺序执行的操作，如部署脚本、数据库迁移、API 调用链。
- **信息密集的文档查询**：在阅读长文档或代码注释时，希望助手能直接提取并总结关键要点。
- **分心环境下的开发**：在容易被打断的工作场景中（如开放式办公室、多任务处理），减少阅读负担，提高聚焦能力。

## 项目亮点

- **聚焦信息提取效率**：直接输出答案和步骤，省去用户筛选和解析信息的时间成本，特别适合高频查询场景。
- **零心智负担**：用户无需学习复杂命令或规则，安装后只需一个简单触发命令即可切换输出风格。
- **生态兼容性**：设计上对主流编码代理（Claude Code、Codex 等）提供原生支持，同类项目常限定于单一平台。
- **开源与社区驱动**：采用 MIT 许可，允许自由修改和分发，用户可以根据自身习惯调整输出规则。
