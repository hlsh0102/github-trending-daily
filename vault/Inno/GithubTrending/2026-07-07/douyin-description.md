📡 GitHub 开源日报｜当日热门 TOP10

1️⃣ system_prompts_leaks
一个系统提示词收藏库，收集了 Claude、ChatGPT、Gemini、Grok 等 AI 的“隐藏指令”。帮助理解模型行为边界，由《华盛顿邮报》报道，星标 5 万+ ⭐️

2️⃣ agent-skills
AI 编码智能体的“技能包”。把开发流程变成 /spec、/plan、/build 等 7 个斜杠命令，让 Agent 自动遵守工程最佳实践，提升代码质量与可重复性。

3️⃣ meetily
100% 本地运行的会议助手，基于 Rust 开发。4 倍速实时转录、说话人分离、通过 Ollama 生成摘要，隐私优先，支持 macOS/Windows。

4️⃣ RuView
用普通 WiFi 信号感知空间、监测心率和呼吸频率，无需摄像头或可穿戴设备。可集成 Home Assistant、Apple Home 等智能家居平台。

5️⃣ taste-skill
给 AI 注入“审美品味”的脚本库。通过规则与代码示例，抑制 AI 输出千篇一律的布局与字体，生成更有设计感的前端界面。

6️⃣ claude-skills
包含 355+ 个生产级技能与插件，覆盖工程、营销、合规、财务等场景。适配 Claude Code、OpenAI Codex、Gemini CLI 等 13 种编码代理。

7️⃣ codex-plugin-cc
为 Claude Code 设计的插件，让你直接在 Claude 会话里调用 OpenAI Codex 进行代码审查或异步任务委派，无需来回切换工具。

8️⃣ last30days-skill
AI 智能体自动从 Reddit、X、YouTube、Hacker News 等平台搜索指定话题，基于点赞、投票生成有据可查的摘要，适合追踪近30天热点。

9️⃣ herdr
终端里的智能体多路复用器，基于 Rust。为每个 AI 编码代理提供独立终端，支持分屏、拖拽、标签页管理，断线后可通过 SSH 重连，无需注册。

🔟 claude-video
给 Claude 装上“眼睛”的 Python 工具。输入视频 URL 或本地路径，自动提取关键帧和字幕，让 AI 同时“看”画面、“听”音频后回答问题。
