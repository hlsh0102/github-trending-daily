## 项目概述

herdr 是一个运行在终端中的智能体复用器（agent multiplexer），专门为同时管理多个 AI 编码智能体而设计。它解决了开发者在终端中同时运行多个 AI 智能体时面临的混乱问题——无法快速查看每个智能体的状态、无法有效管理并行工作流、以及在断线或切换设备后丢失会话的痛点。

目标用户是日常使用 AI 编码助手的开发者，尤其是在同一终端环境中运行多个智能体进行代码生成、调试、重构等任务的团队和个人。herdr 适用于任何可以通过 SSH 访问的环境，包括本地机器、远程服务器、云实例等。

## 核心功能

- **每个智能体分配真实终端**：每个智能体获得一个真正的终端模拟器，而不是应用模拟的伪终端，因此即使需要全屏 TUI 交互的智能体也能完美渲染。
- **窗格管理**：支持点击、拖拽、拆分窗格，可创建工作区（workspace）和标签页（tab）来组织多个智能体会话。
- **状态监控**：实时查看每个智能体的运行状态——阻塞中、工作中、已完成。所有状态一目了然。
- **断线重连**：关闭笔记本或中断网络后，所有会话不会丢失；可从另一台终端甚至手机通过 SSH 重新连接，继续之前的工作。
- **跨平台运行**：单一 Rust 二进制文件，无需 GUI、无需 Electron、无 macOS 专有封装、无需注册账号、无遥测数据。
- **类 tmux 体验**：对于熟悉 tmux 的用户，herdr 相当于专门为 AI 智能体重构的版本，保留了 tmux 的会话持久化和多窗格优势。

## 技术架构

herdr 采用 Rust 语言开发，核心设计理念是“终端优先的智能体管理”。项目的技术架构具有以下特点：

- **单一二进制部署**：编译后生成一个独立的可执行文件，不依赖任何运行时环境或外部依赖，用户只需下载一个文件即可使用。
- **真实终端映射**：与常见的模拟终端方案不同，herdr 为每个智能体分配系统级的真实伪终端（PTY），确保兼容所有终端交互模式。
- **会话持久化**：采用类 tmux 的会话管理机制，将智能体会话与用户终端断开生命周期绑定，即使前端断开连接，后台进程继续运行。
- **无外部依赖**：项目完全自主实现终端复用和窗口管理核心逻辑，不依赖 tmux、screen 等外部工具，降低了安装复杂度和版本兼容性问题。
- **轻量级设计**：Rust 的无运行时特性和内存安全特性，使 herdr 在资源占用方面远小于基于 Electron 或 Web 技术的同类方案。

## 安装与使用

**安装**（以 Linux/macOS 为例，具体方式请参考仓库文档）：

```bash
# 通过 Cargo 安装
cargo install herdr

# 或从 GitHub Releases 下载对应平台的二进制文件
curl -L https://github.com/ogulcancelik/herdr/releases/latest/download/herdr-$(uname -s)-$(uname -m).tar.gz | tar xz
sudo mv herdr /usr/local/bin/
```

**最小可用示例**：

```bash
# 启动 herdr 守护进程
herdr

# 创建一个新的智能体工作区
herdr new workspace my-agents

# 在窗口中启动一个 AI 智能体（假设已安装终端中的 AI 工具）
herdr run "aider --model gpt-4"

# 从另一个终端查看所有智能体状态
herdr list

# 热键操作（默认 Ctrl+B）进行窗格管理
# Ctrl+B %  垂直拆分窗格
# Ctrl+B "  水平拆分窗格
# Ctrl+B 方向键  切换窗格
# Ctrl+B d  断开但保持会话运行
```

## 适用场景

- **多智能体并行编码**：同时运行多个 AI 智能体处理不同模块的代码生成任务，一个负责 API 开发，一个负责测试编写，另一个负责文档生成，在统一终端中监控进度。
- **远程开发环境**：通过 SSH 连接到远程服务器或开发机，启动多个智能体进行长时间的代码分析和重构，断开连接后重新附加上午的工作。
- **团队协作调试**：团队成员在不同的终端窗口中运行相同的代码库，各自启动智能体进行独立调试，使用窗格管理进行比较和协作。
- **智能体工作流编排**：将需要多步骤处理的复杂任务拆分为多个智能体，每个智能体专注于一个子任务，观察各步骤的完成状态，在关键阻塞点手动干预。

## 项目亮点

- **与同类方案的根本性差异**：herdr 不模拟终端，它提供真实的终端。这意味着所有需要全屏渲染、ANSI 转义码、光标控制等高级终端功能的智能体都能完美运行，而不会出现渲染错乱。
- **极致的轻量化和独立性**：一个 Rust 二进制文件，没有 Electron 的几百 MB 体积，没有 GUI 框架的依赖，没有账号系统的烦扰，没有遥测数据的隐私担忧。它只是工作，且工作得高效。
- **类 tmux 的成熟范式**：借鉴了 tmux 经过时间考验的会话管理模型，但针对 AI 智能体场景进行了专门优化，增加了状态监控、智能分组等现代开发者需要的功能。
- **真正的跨平台可移植性**：无论是 macOS、Linux、Windows（通过 WSL），还是任何支持 SSH 的 Unix 环境，herdr 都能一致地工作。你可以在树莓派、云 VPS、公司开发机甚至手机上通过 SSH 运行。
