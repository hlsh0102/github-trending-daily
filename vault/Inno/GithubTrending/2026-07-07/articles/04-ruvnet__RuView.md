## 项目概述

π RuView 是一个基于 Rust 的开源项目，它利用普通的 WiFi 信号实现空间感知、生命体征监测和人员存在检测。该项目由 ruvent 团队开发，目前拥有超过 77000 颗星标，在社区中引起了广泛关注。RuView 的核心能力在于，它能够通过分析 WiFi 信号的细微变化，推断出环境中的人体姿态、位置、呼吸频率和心率，而无需任何摄像头、可穿戴设备或专用传感器。目标用户包括智能家居爱好者、安防从业者、医疗监护研究人员以及任何希望以非侵入方式感知室内环境的人。

## 核心功能

- **隔墙人体检测**：通过穿墙的 WiFi 信号，实时感知房间内是否有人，以及人员的数量和位置。
- **生命体征监测**：测量呼吸频率和心率，支持在静止状态下（如睡眠时）持续追踪生命指标。
- **实时空间追踪**：生成类似“密度图”的空间热力图，展示人群分布和移动轨迹，支持多房间覆盖。
- **智能家居集成**：原生支持 Home Assistant、Apple Home（HomePod）、Google Home、Amazon Alexa 和 SmartThings，通过 MQTT 或 Matter 协议提供 21 类实体数据。
- **零隐私侵犯**：不采集任何视频或图像数据，仅基于 WiFi 信号的物理变化进行分析，保障用户隐私。
- **多环境适应**：无需校准即可在典型家庭、办公室或小型商业空间内运行，不受光照、烟雾或墙壁遮挡影响。

## 技术架构

RuView 采用 Rust 语言开发，利用其高性能、内存安全和并发优势处理实时的 WiFi 信号流。核心技术基于信道状态信息（CSI）分析：当 WiFi 信号在空间中传播时，人体移动或呼吸会引起信号相位和幅度的微小扰动，RuView 通过捕获这些扰动并应用机器学习模型，重建出人体姿态（DensePose 风格）和生命体征。项目设计为轻量级守护进程，可运行在 Raspberry Pi 或普通 PC 上，通过标准 WiFi 网卡（如 Intel AX200）采集 CSI 数据。架构上分为三层：底层信号采集模块、中层特征提取与模型推理模块、上层 MQTT/Matter 协议输出模块，确保各组件可独立升级。RuView 特别强调低延迟，从信号输入到事件输出通常在 100 毫秒以内，满足实时监控需求。

## 安装与使用

RuView 的安装基于 Rust 工具链和特定 WiFi 网卡驱动。以下是典型步骤：

1. **准备硬件**：一台带有 Intel AX200 或类似支持 CSI 提取的 WiFi 网卡的计算机（如 Raspberry Pi 4/5）。
2. **安装 Rust**：执行 `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`，然后安装依赖。
3. **克隆仓库**：`git clone https://github.com/ruvnet/RuView.git && cd RuView`
4. **编译运行**：`cargo run --release -- --mqtt broker.local`，其中 `broker.local` 是 MQTT 代理地址。
5. **集成 Home Assistant**：在配置文件中添加 RuView 生成的 MQTT topic，即可在仪表板看到人员存在、心率、呼吸率等传感器实体。

最小可用示例：启动后，RuView 会自动扫描 2.4GHz 和 5GHz 频段，在无任何手动配置的情况下，即可在 Home Assistant 中看到“客厅”区域的人员存在状态和实时心率曲线。如果仅需基本检测，可使用 `--no-vitals` 参数关闭生命体征监测以降低计算负载。

## 适用场景

- **智能家居自动化**：根据房间是否有人自动控制灯光、空调和窗帘，实现真正的“人来灯亮，人走灯灭”。
- **独居老人监护**：非接触式监测老人的日常活动规律，一旦检测到跌倒或长时间无呼吸/心率异常，立即向家属或紧急服务发送警报。
- **医疗睡眠分析**：在无需穿戴设备的情况下，持续跟踪睡眠期间的呼吸频率和心率变异性，辅助睡眠障碍诊断。
- **办公空间管理**：统计各工位区域的人员密度，优化清洁排班和空调分区控制，降低能耗。

## 项目亮点

与同类方案（如摄像头视觉方案、雷达方案）相比，RuView 的差异化优势显著。首先，它完全基于现有的 WiFi 基础设施，硬件成本极低，不需要额外购买专用传感器。其次，它从根本上杜绝了隐私泄露风险：没有摄像头，就不存在偷拍或人脸数据滥用问题，WiFi 信号本身无法被逆向还原为图像。最后，它的穿墙能力远超红外和超声波传感器，可以覆盖多个房间，且不受黑暗或烟雾影响。此外，项目采用 Rust 语言开发，运行稳定可靠，内存安全，适合 24/7 长期运行。开源许可证为 MIT，允许商业使用和二次开发，社区活跃度高。
