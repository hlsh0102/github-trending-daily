## 项目概述

Meetily 是一款以隐私优先为核心理念的 AI 会议助手，专为 macOS 和 Windows 平台设计。它通过 100% 本地化处理，实现了会议实时转录、说话人分离和会议纪要生成等功能，完全无需依赖云端服务。项目基于 Rust 语言构建，核心引擎采用了优化的 Parakeet/Whisper 模型，转录速度比原始模型快 4 倍，同时支持通过 Ollama 进行本地摘要生成。Meetily 的目标用户是那些对会议数据隐私有严格要求的企业团队、自由职业者、开发者以及任何希望在不将音频数据传输至第三方服务器的情况下自动化会议记录的人士。

作为一款自托管的开源软件，Meetily 在 GitHub 上获得了近 2 万颗星标，社区活跃度极高。它解决了传统在线会议记录工具普遍存在的隐私泄漏风险、云端依赖、以及转录延迟等问题，为用户提供了完全可控的本地会议智能解决方案。

## 核心功能

- **4 倍速实时转录**：基于改进的 Parakeet/Whisper 模型，转录速度比标准 Whisper 模型快 4 倍，实现近乎实时的语音转文字体验，大幅缩短等待时间。
- **说话人分离（Speaker Diarization）**：自动识别并区分会议中的不同发言者，在转录文本中清晰标注谁说了什么，使会议记录条理分明。
- **AI 摘要与纪要生成**：集成 Ollama，在本地完成会议内容的智能摘要、要点提取和待办事项整理，无需将数据发送到外部 AI 服务。
- **100% 本地处理**：所有音频捕获、转录、说话人识别和摘要生成均在用户设备上完成，音频数据和转录内容永不离开设备，彻底杜绝云端泄漏风险。
- **多平台桌面支持**：提供原生 macOS 和 Windows 桌面应用程序，用户体验流畅，可直接与系统音频输出/输入集成。
- **开源与自托管**：完整代码以 MIT 许可证开放，用户可以自行审计、修改和部署，确保透明度和长期可维护性。

## 技术架构

Meetily 的核心技术栈围绕高性能和隐私保护设计。其转录引擎基于优化的 Parakeet/Whisper 模型，通过针对本地推理环境的量化（Quantization）和模型剪枝技术，在保持较高识别准确率的同时将推理速度提升至原生模型的 4 倍。整个推理过程完全在 CPU 或本地 GPU 上执行，不依赖任何云端推理服务。

说话人分离功能采用了基于音频特征的聚类算法，能够在捕获的音频流中实时分离不同声纹，并与转录文本进行对齐。由于所有处理均在本地完成，用户无需将音频流上传至云端分析。

摘要生成部分通过 Ollama 接口调用本地运行的大语言模型（如 Llama、Mistral 等），实现会议记录的智能总结。这种设计避免了将转录文本发送到商业大模型 API，同时允许用户自由选择和更换本地模型。

项目整体使用 Rust 语言开发，充分利用其在内存安全、并发性能和跨平台编译方面的优势。Rust 保证了底层音频处理管线的高效和稳定，同时避免了传统 C++ 项目容易出现的内存泄漏和并发问题。应用层则提供了跨平台的 macOS 和 Windows 桌面界面，与系统音频 API 深度集成。

## 安装与使用

### 安装步骤

1. **下载安装包**：访问 [GitHub Releases 页面](https://github.com/Zackriya-Solutions/meething-minutes/releases/)，根据操作系统选择对应的安装程序（macOS 为 `.dmg`，Windows 为 `.exe`）。
2. **运行安装程序**：双击下载的文件，按照向导完成安装。macOS 用户可能需要前往“系统偏好设置”->“隐私与安全性”中允许应用运行。
3. **首次启动配置**：启动 Meetily 后，应用会自动检测本机音频输入设备。如果希望捕获系统音频（如在线会议），需要在系统音频设置中启用虚拟音频设备或选择“捕获系统音频”选项。
4. **可选：配置 Ollama**：如果需要 AI 摘要功能，请确保已安装并启动 [Ollama](https://ollama.ai/)，并下载一个模型（如 `ollama pull llama3`）。然后，在 Meetily 的设置中指定 Ollama 端点（默认为 `http://localhost:11434`）。

### 最小可用示例

1. 启动 Meetily 后，点击主界面上的“开始录制”按钮。
2. 应用立即开始捕获音频并进行实时转录，转录文本会在界面中逐行显示，同时标注说话人。
3. 单击“停止录制”结束会话。
4. 会话结束后，转录全文会自动保存，并触发 Ollama 生成会议摘要。
5. 在“历史记录”中可以浏览所有保存的会议记录，包括完整转录文本和 AI 生成的摘要。

## 适用场景

- **企业日常会议记录**：团队会议、晨会、周会等场景下，自动记录讨论内容、决策要点和行动项，减少人工记笔记的负担。
- **远程协作与在线会议**：集成 Zoom、Microsoft Teams、Google Meet 等平台的系统音频，实现无感录制和实时转录，特别适合需要事后回顾的远程团队。
- **自由职业者与独立开发者的知识管理**：客户沟通、项目讨论或技术研讨会后，快速生成结构化的会议纪要和待办清单，提高工作效率。
- **研究与访谈记录**：学术访谈、用户调研或焦点小组讨论的实时转录和摘要，帮助研究者快速提取关键信息，避免漏记和忘记。

## 项目亮点

- **隐私优先的本地化方案**：与市面上大多数云端会议记录工具不同，Meetily 的整个处理流程完全在用户设备上完成。音频数据不离开本地硬盘，转录内容也不需上传至第三方 AI 服务，从根源上杜绝了数据外泄风险。这对于处理敏感商业信息、法律咨询或医疗讨论的用户尤为重要。
- **4 倍速实时转录的性能优势**：通过模型优化，Meetily 在主流消费级硬件上即可实现接近实时的转录体验，延迟远低于传统的云端转录方案。在慢速网络或离线场景下，这一优势更加明显。
- **开源透明与社区驱动**：采用 MIT 许可证，项目代码完全公开，任何人都可以检查、修改或贡献代码。这种透明度增加了用户的信任，也鼓励了社区的持续改进和创新。
- **Rust 语言的高性能基础**：底层采用 Rust 构建，带来了出色的内存安全性和并发处理能力，确保长时间会议转录的稳定性和低资源占用，避免了其他语言项目中常见的内存泄漏和性能瓶颈问题。
