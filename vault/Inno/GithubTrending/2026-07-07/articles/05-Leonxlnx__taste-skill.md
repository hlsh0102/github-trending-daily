## 项目概述

Taste-Skill 是一个开源的前端智能体技能（Agent Skills）框架，旨在解决当前 AI 生成界面中普遍存在的“模板化”和“空洞”问题。当用户使用 ChatGPT、Claude、Gemini 等大语言模型构建前端 UI 时，模型往往会输出千篇一律的布局、乏味的字体和缺乏生机的交互效果，这种输出被项目称为“slop”（空洞内容）。Taste-Skill 为 AI 代理注入“良好品味”，使其能够生成具有专业设计感、布局合理、排版考究、动效流畅且间距舒适的界面，显著提升 AI 生成界面的视觉质量。

该项目面向 AI 前端开发者、Prompt 工程师、UI/UX 设计师，以及任何希望利用大语言模型快速构建高质量用户界面的技术人员。通过引入 Taste-Skill，用户可以让 AI 从“能写出代码”升级为“能写出好看的代码”。

## 核心功能

- **强化布局与排版**：指导 AI 使用现代 CSS 布局技术（如 Flexbox、Grid），并遵循视觉层次与对齐原则，自动生成结构清晰、信息层级分明的界面，避免左右不成直线、间距随意等常见问题。
- **精良的字体系统**：内置字体选择与组合建议，帮助 AI 自动搭配和谐的字体对（如标题与正文），并正确应用字重、字号和行高，提升文本可读性与美学表现。
- **流畅的动效与过渡**：引导 AI 为界面元素添加自然的悬停状态、入场动画、加载微交互等动效，使静态 AI 界面具备专业级交互体验，而非生硬的瞬间切换。
- **一致的间距与间距系统**：定义标准化的间距比例（如 4px 或 8px 的倍增序列），让 AI 在生成过程中自动维持元素内边距、外边距和网格间距的一致性，消除无规律的间隔。
- **图像生成增强**：集成对图像生成命令的支持，使 AI 能够协同生成与界面风格匹配的插图或图标，实现从 UI 到视觉资产的端到端优化。
- **可移植的 Agent Skills**：所有设计规则与技巧被打包为可插拔的技能模块，支持在不同的提示上下文或前端框架（React、Vue、Svelte 等）中复用，轻量且无侵入。

## 技术架构

Taste-Skill 构建在纯 JavaScript 之上，不依赖任何重量级 UI 框架或后端服务。其核心设计理念是“以提示词为接口”：项目将设计原则、CSS 代码片段、动效资源和最佳实践整理为结构化的知识库，当 AI 模型在生成界面代码时，这些技能会被自动或按需注入到提示上下文中。

技术栈上，项目使用模块化的 JavaScript 文件组织各类技能，并利用现代 Node.js 工具链进行打包与分发的优化。架构上强调“可移植性”——技能定义不绑定特定宿主环境，用户可以将其作为 npm 包引入自己的项目，或直接复制技能片段嵌入到任意 AI 聊天工具中。此外，项目还提供了示例 HTML 与 CSS 文件，帮助开发者快速理解技能的实际应用效果。

## 安装与使用

Taste-Skill 的使用方式灵活，主要有以下几种途径：

**方式一：作为 npm 包安装**
```bash
npm install taste-skill
```
在项目中引入技能集：
```javascript
import { tasteSkill } from 'taste-skill';
// tasteSkill 对象包含了所有布局、字体、动效等规则
```

**方式二：直接用于 AI 提示**
将项目仓库中的 `skill-pack.md` 或核心规则复制粘贴到您的大语言模型会话中，作为系统提示或上下文指令。例如在 ChatGPT 或 Claude 中，先粘贴规则再提出 UI 生成请求。

**最小可用示例**（以提示词方式）：
1. 复制 `skill-pack/layout-rules.md` 和 `skill-pack/typography-rules.md` 中的内容。
2. 在 AI 聊天中输入：
   ```
   请使用以下设计规则生成一个登录页面：
   <粘贴的规则内容>
   要求：包含邮箱、密码输入框、登录按钮和注册链接。
   ```
3. AI 将按照规则输出具有良好布局、字体和间距的代码。

## 适用场景

- **快速原型设计**：产品经理或设计师使用 AI 快速生成高质量界面原型，无需手动调整大量 CSS 细节，直接从 AI 获得几乎可交付的代码。
- **AI 驱动的前端开发**：开发者在编写组件时，借助 Taste-Skill 让 AI 助手写出更符合企业级设计规范的代码，减少代码审查中关于视觉一致性的返工。
- **教育与内容创作**：用于教学案例或技术博客中，演示如何通过提示工程优化 AI 生成内容的质量，特别是前端 UI 开发场景中的最佳实践。
- **自定义聊天机器人的 UI 生成模块**：在构建自己的 AI 助手（如基于 OpenAI API）时，将 Taste-Skill 集成到系统提示中，为用户提供“一键生成专业界面”的能力。

## 项目亮点

与同类“提示词模板”或“UI 生成工具”相比，Taste-Skill 的突出优势在于其**系统性与可移植性**。它不是零散的提示词片段，而是经过精心设计的完整技能体系：从布局到动效，每个技能都独立封装、可单独启用或组合，且遵循设计系统的一致性。同时，项目完全开源（MIT 许可证），社区可以轻松贡献、扩展或自定义技能，适应不同的设计语言。

另一个亮点是**低侵入性**：用户不需要切换工具或学习新框架，只需在现有 AI 工作流中加入一段规则即可，零成本迁移。项目还得到了如 Vercel 等知名开源项目支持，进一步验证了其技术价值与社区认可度。
