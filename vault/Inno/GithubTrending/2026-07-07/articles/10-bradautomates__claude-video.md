## 项目概述

`/watch` 是一个为 Claude 赋予视频“观看”能力的开源插件工具。当你向 Claude 粘贴一个视频 URL 或本地文件路径并提问时，它不再像以前那样只能通过标题或残缺的转录文本猜测视频内容。`/watch` 会自动获取字幕、下载必要的数据、提取关键帧（支持场景感知或快速关键帧模式）、生成带时间戳的转录文本（优先使用免费字幕，视频无字幕时回退到 Whisper API），最后将每一帧作为图像让 Claude “阅读”。最终，Claude 回答问题时，已经同时“看到”了画面和“听到”了音频。该项目主要面向 AI 开发者、内容创作者、研究人员以及任何需要让 AI 理解视频内容的用户。

## 核心功能

- **多源视频支持**：支持 YouTube 等主流视频平台 URL 以及本地视频文件路径，只需粘贴链接即可开始分析。
- **智能帧提取**：提供两种精度模式——`scene-aware`（场景感知）模式能捕捉场景切换的关键帧；`efficient`（高效）模式使用快速关键帧提取，在性能与细节之间取得平衡。
- **自动字幕与转录**：优先免费获取公开视频的可用字幕，当视频无字幕时自动切换至 Whisper API 进行语音识别，生成带时间戳的完整转录文本。
- **零配置快速启动**：核心依赖（`yt-dlp` 和 `ffmpeg`）在首次运行时自动安装——macOS 使用 `brew`，Linux 和 Windows 则会打印精确的安装命令。
- **跨平台兼容**：支持 Claude Code（官方推荐，可通过 marketplace 自动更新）、Codex、Cursor、Copilot、Gemini CLI 以及 50 多种 Agent Skills 托管环境。
- **灵活部署**：提供多种安装方式，包括全局安装（所有项目可用）和项目级安装，适配不同的工作流需求。

## 技术架构

该项目采用 Python 开发，核心架构围绕“下载-解析-转录-分析”四个阶段设计。首先，`yt-dlp` 负责从视频平台下载视频元数据和内容；随后 `ffmpeg` 进行视频帧提取和音频处理；字幕获取优先通过平台 API 获取免费字幕，失败时调用 Whisper API 进行音频转录；最后将所有提取的视觉帧和文本转录一并交给 Claude 的多模态能力进行理解。这种分阶段流水线架构使得各环节可以独立优化和替换——例如用户可以切换不同的转录服务商、调整帧提取策略（场景感知 vs. 快速关键帧），而无需修改整体逻辑。设计上特别注重效率：仅下载必要的数据片段而非完整视频，避免不必要的带宽和存储消耗。同时支持通过 [Agent Skills](https://agentskills.io) 标准接口集成到多种 AI 宿主环境，极大拓展了使用场景。

## 安装与使用

**前提条件**：需要已有 Claude Code 或其他兼容的 AI 宿主环境。

**推荐安装（Claude Code）**：
```bash
# 通过 marketplace 安装（支持自动更新）
claude /plugin marketplace add bradautomates/claude-video
claude /plugin install watch@claude-video
```

**其他宿主环境（Codex、Cursor、Copilot、Gemini CLI 等）**：
```bash
# 全局安装（所有项目可用）
npx skills add bradautomates/claude-video -g

# 项目级安装（去掉 -g 标记）
npx skills add bradautomates/claude-video
```

**基本使用示例**：
向 Claude 发送类似以下指令即可开始分析视频：
```
/watch https://youtu.be/dQw4w9WgXcQ 请描述视频中发生了什么，重点关注第 30 秒到第 45 秒的内容
```
Claude 会自动分析整个视频，并基于提取的画面和转录文本来回答你的问题。首次运行时依赖安装会自动完成（macOS 用户会通过 `brew` 安装 `yt-dlp` 和 `ffmpeg`，其他平台会收到手动安装指引）。

## 适用场景

- **内容摘要与审核**：快速处理长视频或直播回放，让 AI 提取核心内容、识别敏感画面或生成摘要总结，节省人工逐帧查看的时间。
- **教学与科研辅助**：分析教学视频或科研演示，让 AI 回答关于特定时间点的内容细节，例如“这个实验在第 3 分钟操作了什么步骤”。
- **多模态 AI 开发测试**：为 AI 模型开发者提供标准化的视频理解测试框架，评估多模态模型在视觉-时序联合理解上的表现。
- **无障碍辅助**：为有视觉或听力障碍的用户提供视频内容的文字描述与语音转写，提升信息获取的平等性。

## 项目亮点

与同类视频分析工具相比，`/watch` 的核心优势在于它完全无缝地集成了“观看”和“聆听”两种模态，而不只是单纯的转录或帧抓取。大多数工具要么只做语音转文字（丢失画面信息），要么只做静态帧分析（丢失时序和音频上下文）。`/watch` 将两者结合，让 Claude 能够同时理解视觉内容（画面中的物体、动作、场景变化）和听觉内容（对话、背景音、音效），输出更全面、更准确的回答。此外，零配置自动安装依赖、优先利用免费字幕降低运营成本、场景感知帧提取优化效率，这些设计都体现了对用户体验和资源效率的重视。作为开源项目（MIT 许可），它还提供了极高的可定制性，开发者可以自由修改、扩展或集成到自己的工具链中。
