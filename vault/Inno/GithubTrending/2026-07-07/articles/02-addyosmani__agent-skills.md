## 项目概述

Agent Skills 是一个为 AI 编程代理提供生产级工程技能的开源项目。它通过一系列结构化的“技能”封装了资深工程师在软件开发全流程中的工作方法、质量门禁和最佳实践，使 AI 代理能够在每个开发阶段一致地遵循这些流程。项目的目标用户是所有希望让 AI 代理更专业、更可靠地参与实际软件开发工作的开发者，尤其是那些希望将 AI 代理从简单代码生成提升到完整工程协作层面的团队。

## 核心功能

- **生命周期映射**：项目将软件开发划分为六个关键阶段——定义、计划、构建、验证、审查和发布，并为每个阶段提供对应的技能包。
- **八条斜杠命令**：提供 `/spec`、`/plan`、`/build`、`/test`、`/review` 等八条命令，每条命令对应开发周期中的一个特定活动，代理会自动加载相应的技能。
- **原则驱动的工作流**：每条命令都遵循一个核心原则，例如“先规格后代码”（Spec before code）、“小粒度原子任务”（Small, atomic tasks）、“每次只切一片”（One slice at a time）、“测试即证明”（Tests are proof）等。
- **自动化技能激活**：当开发者执行某个命令时，项目会自动激活与该阶段相关的最佳实践、质量门禁和检查清单，确保代理不会跳过关键步骤。
- **生产级质量门禁**：在审查和发布阶段内置了代码审查标准、质量门禁和发布检查，模拟资深工程师的审查流程。

## 技术架构

项目采用模块化的技能定义方式，每个技能都是独立的知识单元，包含了特定开发活动所需的工作流程、约束条件和检查点。技能以结构化的形式组织，可以被 AI 代理解析和执行。架构的核心是一个命令路由系统，它将用户的斜杠命令映射到对应的技能集合，并按照预定义的顺序逐步执行。技能之间相互独立又彼此衔接，形成一个完整的开发流水线。项目基于 JavaScript 实现，具有较好的跨平台兼容性和可扩展性。

## 安装与使用

Agent Skills 的使用非常简便，主要通过与 AI 代理的交互命令来完成。典型的使用方式如下：

1. 在支持 Agent Skills 的 AI 编程环境中（如 VS Code 或相关 IDE 扩展），安装 Agent Skills 插件或导入技能包。
2. 通过斜杠命令与代理交互，例如：
   - 当需要定义新功能时，输入 `/spec`，代理会根据当前上下文生成功能规格说明。
   - 当需要制定实施计划时，输入 `/plan`，代理会将规格分解为小粒度的原子任务。
   - 当开始编码时，输入 `/build`，代理会按照“单一切片”原则逐步构建代码。
   - 当需要测试时，输入 `/test`，代理会生成并运行测试用例。
3. 所有命令都遵循“先规划后执行”的原则，确保每个步骤都有明确的输入和输出。

## 适用场景

- **企业级软件开发**：团队需要一个标准化的开发流程，确保所有 AI 代理的代码生成质量一致且符合企业规范。
- **AI 辅助代码审查**：在代码合并前，使用 `/review` 命令让代理执行自动化的代码质量检查和安全审查。
- **新手开发团队**：团队成员可以使用该工具学习和遵循资深工程师的开发工作流，减少因经验不足导致的常见错误。
- **自动化 CI/CD 流水线**：将 Agent Skills 集成到持续集成和持续交付流程中，实现从需求定义到发布的全程自动化 。

## 项目亮点

与其他 AI 编程辅助工具相比，Agent Skills 的独特之处在于：它不只是一个代码生成工具，而是一个完整的工程方法论注入系统。它将资深工程师的隐性知识——比如如何定义需求、如何规划任务、如何保证代码质量——显式地编码为可重复执行的技能包。这解决了当前 AI 代理在复杂工程场景中常见的“跳跃式”工作模式问题，即直接生成代码而忽略前期的规划和规范。项目强调“原则驱动”，每条命令都绑定一个核心原则，确保代理的行为始终与最佳实践对齐。此外，项目采用开源 MIT 许可证，任何人都可以自由使用、修改和分发，形成了一个开放、协作的开发文化。
