## 项目概述

Agent Skills 是一个面向 AI 编码代理（AI Coding Agent）的工程技能库，由 Addy Osmani 发起并维护。它要解决的问题是：AI 编码代理虽然具备生成代码的能力，但在真实软件项目中往往缺乏稳定的工作流程、质量门槛和工程规范，导致输出质量参差不齐、难以在团队协作中复用。

该项目将资深工程师在构建软件时使用的流程、质量关卡和最佳实践，编码为一组可被 AI 代理直接调用的“技能”（Skills），使代理在开发的每个阶段都能遵循一致的做法。目标用户包括：使用 Claude Code、Cursor、Copilot 等 AI 编码工具的开发者、希望把 AI 代理纳入团队工程规范的工程团队，以及希望标准化代理行为的技术负责人。

## 核心功能

- **全生命周期命令体系**：提供 9 个斜杠命令（如 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship`），覆盖从需求定义到发布上线的完整流程，每个命令会自动激活对应的技能集合。
- **阶段化工作流映射**：将开发过程划分为 DEFINE、PLAN、BUILD、VERIFY、REVIEW、SHIP 六个阶段，明确每个阶段的输入、输出与关键原则。
- **质量关卡与约束**：通过 `/constraints` 等命令设定质量基线，把代码规范、测试标准、审查要点固化为可执行的检查项。
- **技能自动激活**：命令与技能之间建立映射关系，代理在执行某一阶段任务时会自动加载相关技能，无需人工切换上下文。
- **规范先于代码**：强调“Spec before code”，把需求精炼和 PRD 编写作为编码前的必要步骤，降低返工率。
- **小步增量交付**：以“一次一个切片”的原子化任务为原则，便于验证、回滚与持续集成。

## 技术架构

项目以 JavaScript 实现，核心设计思路可以概括为“把工程方法论封装成代理可调用的能力单元”。

- **命令层**：9 个斜杠命令作为用户与代理的交互入口，每个命令对应开发生命周期中的一个动作。
- **技能层**：具体技能封装了流程步骤、检查清单和最佳实践，作为可复用的知识模块。
- **映射机制**：命令触发后，系统根据当前所处阶段自动选择并激活合适的技能集，代理按技能中定义的流程执行。
- **生命周期模型**：DEFINE → PLAN → BUILD → VERIFY → REVIEW → SHIP 构成线性管线，每一环都有明确的完成标准，前一环的输出是后一环的输入。

这种分层的设计让工程规范与具体 AI 代理实现解耦，便于在不同代理平台之间迁移和扩展。

## 安装与使用

由于 README 未提供完整安装细节，以下为基于常见做法的概述：

1. 克隆仓库到本地：
   ```
   git clone https://github.com/addyosmani/agent-skills.git
   cd agent-skills
   ```
2. 根据项目说明安装依赖（通常为 `npm install`）。
3. 将技能库接入你所使用的 AI 编码代理（具体接入方式取决于代理平台，一般涉及配置指向技能目录或注册命令）。
4. 在代理会话中调用斜杠命令开始工作：

   ```
   /spec    # 定义要构建的内容
   /plan    # 规划如何构建
   /build   # 增量实现
   /test    # 验证功能
   /review  # 质量审查
   /ship    # 发布上线
   ```

最小可用示例：从一个想法出发，先用 `/spec` 精炼需求并生成 PRD，再用 `/plan` 拆分为原子任务，最后通过 `/build` 逐片实现。

## 适用场景

- **个人开发者使用 AI 代理做副项目**：借助标准化流程避免“想到哪写到哪”，提升代码可维护性。
- **团队引入 AI 代理参与协作开发**：用统一的质量关卡和命令约定，让不同成员使用代理时保持一致的交付标准。
- **教学与培训**：将资深工程师的工作流显式化，作为新人学习工程规范的参考。
- **多代理/多平台统一规范**：在不同 AI 编码工具之间复用同一套技能定义，减少重复配置。

## 项目亮点

与一般的 prompt 集合或代理配置模板相比，Agent Skills 的差异化在于：

- **覆盖完整生命周期**：不是零散的提示词，而是与开发阶段一一对应的体系化命令与技能。
- **质量内建**：把约束和审查作为流程中的显式环节，而非事后补救。
- **来源可信**：由具有一线工程经验的作者维护，内容贴近真实生产实践。
- **社区认可度高**：仓库累计获得超过 96,000 个 Star，单日新增约 675 个，说明其在 AI 编码工具生态中具有较高的关注度。
