## 项目概述

Anki 是一款基于间隔重复（Spaced Repetition）理念的记忆辅助程序。间隔重复是一种经过认知心理学研究验证的学习方法：将复习内容按照遗忘曲线安排在逐渐拉长的时间间隔中重现，从而在保持长期记忆效果的同时，显著减少无效的重复劳动。Anki 将这一方法工程化，用户可以把需要记忆的知识点制作成正面与背面构成的卡片，程序则依据每张卡片的难度与用户的回忆表现，自动计算下一次出现的时间。

本项目是 Anki 桌面版的源代码仓库，覆盖 Windows、macOS 与 Linux 三个平台。它解决的核心问题是：面对大量需要长期留存的信息（外语词汇、医学知识、法律条文、考试要点等），如何用可管理的时间投入换取稳定的记忆保持率。目标用户包括语言学习者、备考学生、医学与法律等专业人士，以及任何需要长期维护知识库的个人。

## 核心功能

- **卡片与笔记系统**：以“笔记”存储原始内容，以“卡片”定义问答形式，一条笔记可按不同模板生成多张卡片，避免内容重复维护。
- **间隔重复调度**：内置 SM-2 系列算法的演进版本，根据每次复习的评分动态调整间隔，并提供“再次学习”“困难”“良好”“简单”等反馈选项。
- **牌组与筛选**：支持牌组分组、子牌组、按标签或条件筛选的临时牌组，便于针对薄弱内容集中复习。
- **多媒体与模板**：卡片支持图片、音频、视频与自定义 HTML/CSS 模板，可构建填空、选择题等多样题型。
- **同步与多端协作**：通过 AnkiWeb 在桌面端、移动端与网页端之间同步学习进度。
- **扩展机制**：提供插件（Add-on）体系与脚本接口，用户可自定义导入导出、复习行为与界面。

## 技术架构

Anki 的代码库采用多语言分层架构。核心调度逻辑、数据模型与后端服务以 **Rust** 编写，主要集中在 `rslib` 中，对外提供稳定的 Rust API 与 Python 绑定。桌面界面层使用 **Python** 与 **TypeScript**（基于 Svelte 等前端技术），负责渲染与交互。Rust 与前端之间通过 Protocol Buffers 定义的服务接口通信，保证跨语言边界的类型安全与版本演进能力。

在数据层，集合（collection）以 SQLite 数据库存储，卡片、笔记、复习记录与配置均在本地维护，因此程序可在完全离线状态下工作，同步是可选项而非依赖项。这种“本地优先”的设计降低了服务不可用对学习流程的影响，也便于用户自行备份与迁移数据。

构建系统由 Cargo（Rust）、Python 打包工具与 npm/pnpm（前端）共同组成，仓库中提供了统一的构建脚本与持续集成配置，便于在三大平台上复现构建产物。

## 安装与使用

普通用户无需编译源码，直接从官方网站下载对应平台的安装包即可：

1. 访问 `https://apps.ankiweb.net`，下载 Windows、macOS 或 Linux 版本。
2. 安装后首次启动，可创建本地账户或登录 AnkiWeb 以启用同步。
3. 新建牌组，添加笔记并选择卡片模板，即可开始学习。

若需从源码构建，流程大致如下（具体以仓库 `docs/development.md` 为准）：

1. 安装 Rust 工具链、Python 3 与 Node.js/pnpm。
2. 克隆仓库并进入项目根目录。
3. 运行仓库提供的构建脚本（如 `./tools/build` 或 `just` 任务）完成依赖拉取与编译。
4. 通过 `./run` 之类的脚本启动开发版本。

最小可用示例：创建一个名为“日语 N2”的牌组，添加一条“正面：勉強／背面：学习”的笔记，选择“基础”模板生成卡片，随后在复习界面中按提示评分，程序会自动安排该卡片的后续出现时间。

## 适用场景

- **语言学习**：记忆词汇、句型、汉字读音与语法点，配合音频卡片训练听力与发音。
- **专业考试备考**：医学、法律、工程类考试中大量需要精确记忆的条目，可按科目分牌组管理。
- **知识长期维护**：将阅读笔记、术语定义、代码片段等整理成卡片，形成可检索、可复习的个人知识库。
- **共享牌组协作**：教师或学习小组可导出 `.apkg` 牌组文件分发给他人，统一学习材料。

## 项目亮点

与同类记忆软件相比，Anki 的主要差异在于：**调度算法可调且经过长期验证**，用户可通过插件替换调度器或调整参数；**完全本地化的数据存储**，离线可用且数据归用户所有；**高度可定制的卡片模板与插件生态**，能够适配从简单问答到复杂交互题型的多种需求；以及**跨平台的统一体验**，桌面端、移动端与网页端共享同一套同步协议。其 Rust 核心层的引入也使得调度与数据处理在性能敏感的批量操作中表现更稳定。
