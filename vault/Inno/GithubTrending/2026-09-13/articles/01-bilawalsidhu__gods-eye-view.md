## 项目概述

God's Eye View（原名 WorldView）是一个运行在浏览器中的“间谍卫星模拟器”，其特殊之处在于：它并不依赖虚构数据，而是汇聚了公开可查的真实空间情报源。项目在一个照片级逼真的 3D 地球上，实时叠加飞机、船舶、卫星、地震、交通流量以及公共摄像头等图层，让用户以类似情报中心的视角观察世界的实时动态。

它试图解决的问题是：公开的空间数据虽然数量庞大，但分散在数十个来源各异、格式不一的接口与平台中，普通用户很难将其整合成直观的地理视图。God's Eye View 把这些数据源统一到同一个三维球体上，并提供语音控制等交互方式，降低检索与观察的门槛。目标用户包括开源情报（OSINT）研究者、地理信息爱好者、新闻从业者、教育工作者，以及对实时世界动态感兴趣的一般用户。

## 核心功能

- **照片级真实 3D 地球**：以高精度地形与影像渲染地球表面，支持缩放、旋转与视角切换，作为所有数据图层的统一载体。
- **多源实时图层叠加**：在同一地球上同时呈现实时飞行的飞机、航行中的船舶、在轨卫星、地震事件、交通状况以及公共摄像头画面。
- **免手动语音控制**：由实时 AI 智能体驱动的语音交互，用户可通过自然语言指令切换图层、定位区域或查询目标，无需鼠标操作。
- **真实公开数据源**：所有展示数据来自公开可访问的接口与数据集，而非模拟生成，因此观察结果具有现实对应。
- **开箱即用，无需 API 密钥**：项目支持在不配置任何 API 密钥的情况下启动，也提供通过 Pinokio 一键安装的方式。

## 技术架构

项目以 JavaScript 为主要开发语言，整体运行于浏览器环境，属于典型的前端密集型应用。核心渲染依赖 WebGL 类技术实现三维地球与海量地理要素的实时绘制；数据层通过聚合多个公开数据源，将飞机、船舶、卫星、地震等异构数据统一转换为地理坐标与时间戳，再叠加到地球表面。

设计思路上，项目强调“数据真实”与“低门槛启动”两个原则：一方面尽可能对接公开可用的实时接口，避免私有或付费数据依赖；另一方面通过免 API 密钥的默认配置和 Pinokio 集成，降低部署与上手成本。语音控制模块接入实时 AI 智能体，将自然语言指令解析为对地图状态与图层的操作。项目配有 CI 工作流（GitHub Actions），用于持续集成与质量保障。

## 安装与使用

项目提供两种常见启动方式。

方式一：通过 Pinokio 一键安装。Pinokio 是一个面向本地 AI 应用的安装器，可直接从其应用页面安装 God's Eye View，适合不希望手动配置环境的用户。

方式二：本地运行。基本步骤如下：

1. 克隆仓库：`git clone https://github.com/bilawalsidhu/gods-eye-view.git`
2. 进入目录并安装依赖（通常为 `npm install`）。
3. 启动开发服务器（通常为 `npm run dev` 或 `npm start`）。
4. 在浏览器中打开本地地址，即可看到 3D 地球界面。

最小可用示例即“启动后直接在界面中浏览地球”：无需填写任何 API 密钥，默认图层即可加载公开数据。随后可通过界面控件或语音指令切换与筛选图层。由于 README 未给出精确的脚本名称与端口，具体命令请以仓库文档为准。

## 适用场景

- **开源情报与地理研究**：将飞机、船舶、卫星等多类实时目标集中观察，辅助分析特定区域的动态。
- **新闻与事实核查**：通过公共摄像头与实时交通、地震数据，快速核验事件发生地点与时间。
- **教学与科普演示**：以直观的三维地球展示空间数据的组织方式，帮助理解遥感与地理信息概念。
- **个人探索与兴趣观察**：普通用户以近似“卫星视角”浏览全球实时动态，满足好奇心与观察需求。

## 项目亮点

与同类地球可视化项目相比，God's Eye View 的差异化优势主要体现在三点。第一，数据真实且来源公开：它不是演示用的模拟数据，而是对接现实世界的实时信息源，观察结果具备现实意义。第二，交互方式更自然：集成实时 AI 智能体的语音控制，使用户可以“动口不动手”地操作复杂的地图图层。第三，启动门槛低：无需 API 密钥即可运行，并支持 Pinokio 一键安装，显著降低了部署成本。

此外，项目在社区中获得了较高关注度，曾在 GitHub Trending 日榜与周榜登顶，并获得 Product Hunt 当日第八名，多个技术社区人士对其进行了推荐。项目同时配有 YouTube 视频系列，便于用户理解其能力边界。
