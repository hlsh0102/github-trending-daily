## 项目概述

Flowseal/zapret-discord-youtube 是一个面向 Windows 平台的网络流量处理工具集合，基于 bol-van 开发的 zapret 项目构建。zapret 是一款用于绕过深度包检测（DPI）的开源工具，通过修改和过滤网络数据包，使特定服务在受网络限制的环境中恢复正常访问。本项目是其在 Windows 上的一套封装与配置方案，重点针对 Discord 语音/文字通信以及 YouTube 视频播放这两类常被干扰的服务。

该项目的目标用户主要是处于网络审查或运营商 DPI 干扰环境下的普通 Windows 用户。与直接使用 zapret 官方源码或原始命令行工具相比，本项目提供了预置的批处理脚本（Batchfile）和配置文件，降低了上手门槛，用户无需自行编译或深入理解 DPI 绕过原理即可完成部署。仓库在 GitHub 上获得了较高的关注度，累计 Star 数超过三万，属于该领域内被广泛引用的方案之一。

需要注意的是，项目本身只是 zapret 的 Windows 分发形态之一，并不改变 zapret 的核心工作机制，其价值主要体现在配置整理、启动脚本封装和常见场景的调优上。

## 核心功能

- **DPI 绕过**：基于 zapret 的 WinDivert 驱动拦截并修改 TCP/UDP 数据包，绕过运营商或网络设备对特定流量的深度包检测。
- **针对 Discord 的优化**：预置了适用于 Discord 连接与通信的脚本配置，缓解加载失败、消息发送失败或语音不可用等问题。
- **针对 YouTube 的优化**：提供面向 YouTube 视频加载与播放的参数配置，改善缓冲、卡顿或无法打开的情况。
- **批处理启动脚本**：以 `.bat` 文件形式提供一键启动/停止入口，用户无需记忆复杂命令行参数。
- **可替换的配置与服务列表**：允许用户按需调整目标域名/IP 列表与策略参数，以适配不同网络环境。
- **多方案切换**：通常内置多种策略档位（如不同混淆/分段方式），便于在效果与稳定性之间做取舍。

## 技术架构

项目工作在 Windows 网络栈的用户态与内核态交界处。核心依赖包括：

- **WinDivert**：一个 Windows 内核级的数据包拦截与过滤库，负责在数据包进入协议栈之前将其捕获并交由上层逻辑处理。项目 README 特别说明，WinDivert 是通用流量拦截工具，可能被部分杀毒软件误报，需要用户自行判断与加白名单。
- **zapret 核心逻辑**：对捕获到的数据包按预定义规则进行修改，例如调整 TCP 分段、伪造 TTL、修改报文特征等，使 DPI 设备无法正确识别流量所属的应用层协议。
- **配置文件与批处理层**：项目以 Batchfile 为主要语言，通过脚本组织参数、调用 `winws` 等可执行文件、加载配置文件，最终形成对用户友好的操作界面。

架构上，项目不引入额外服务端或云端组件，所有处理均在本地完成。其设计思路是“原样封装 + 场景化配置”，而非对 zapret 做功能扩展。这种轻量方式便于维护，但也意味着项目能力上限取决于上游 zapret 的更新。

## 安装与使用

由于项目属于二进制分发型工具，通常的安装流程如下：

1. 在 GitHub 仓库的 Releases 页面下载最新压缩包，解压至本地目录（路径建议不含中文与空格）。
2. 关闭或暂时停用可能拦截的杀毒软件，或将解压目录加入白名单。
3. 以管理员身份运行目录中的批处理脚本（通常包含启动与停止两个入口）。
4. 脚本会自动加载 WinDivert 驱动并启动流量处理逻辑，此时可测试 Discord 或 YouTube 是否恢复。
5. 如需停止，运行对应的停止脚本或关闭窗口即可卸载驱动。

最小可用示例可概括为：解压 → 管理员运行启动脚本 → 打开目标服务验证 → 需要时运行停止脚本。不同版本脚本名称可能有差异，建议以仓库当前 README 的说明为准。

## 适用场景

- 在运营商对 Discord 语音或消息通道实施干扰的网络中恢复通信。
- 在 YouTube 访问受限、视频频繁缓冲或无法加载的环境中改善播放体验。
- 需要对比不同 DPI 绕过策略、寻找适合本地网络参数的用户进行测试。
- 作为 zapret 在 Windows 上的开箱即用入口，供不熟悉命令行的用户直接使用。

## 项目亮点

与直接使用 zapret 源码或 bol-van/zapret-win-bundle 相比，本项目的差异化在于针对 Discord 与 YouTube 做了面向场景的配置整理，并配合批处理脚本简化了启动流程。对普通用户而言，省去了自行编译、编写启动参数与调试策略的步骤。同时，项目在 README 中明确标注了仿冒风险与杀毒软件误报问题，提示用户从官方仓库获取文件，这在一定程度上降低了被第三方恶意打包误导的可能。
