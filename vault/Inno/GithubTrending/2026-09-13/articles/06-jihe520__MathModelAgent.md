## 项目概述

MathModelAgent 是一个面向数学建模竞赛的自动化智能体（Agent）项目，使用 Python 编写，旨在将数学建模从选题、建模、求解到论文撰写的全流程自动化。传统数学建模竞赛（如全国大学生数学建模竞赛、美国大学生数学建模竞赛 MCM/ICM）通常需要在三到四天内完成问题分析、模型选择与建立、编程求解、结果可视化以及论文排版等工作，对参赛者的综合能力提出较高要求。MathModelAgent 试图通过大语言模型驱动的 Agent 与配套的 SKILLS 技能体系，把这一过程压缩到较短的时间内，并输出一份结构完整、可直接提交的论文。

该项目的目标用户主要是参加数学建模竞赛的学生、指导教师，以及希望借助 AI 辅助完成建模分析任务的研究人员。项目同时提供桌面应用与开发者自部署两种使用方式，降低了非计算机专业用户的上手门槛。

## 核心功能

- **全流程自动化建模**：从读题、审题到模型构建与求解，Agent 可自动完成多阶段任务编排，减少人工干预。
- **论文自动生成**：在建模与求解完成后，自动生成包含摘要、问题重述、模型假设、符号说明、模型建立与求解、结果分析等标准章节的完整论文，可直接用于提交。
- **SKILLS 技能体系**：项目内置一整套数学建模相关 SKILL，覆盖数据分析、优化求解、图表绘制等环节，桌面版已预装全部技能。
- **桌面客户端**：提供 macOS（Apple 芯片与 Intel）和 Windows 安装包，内置 Claude Code 与全部 SKILLS，无需配置 Python、Node.js、Redis 等运行环境。
- **模型 API 灵活接入**：安装后只需填写一个模型 API Key 即可开始建模，支持用户自行选择底层大模型。
- **自动更新机制**：桌面版会检查更新，macOS 端已支持自动更新，Windows 端待代码签名配置完成后启用。

## 技术架构

项目以 Python 为主要实现语言，整体采用「LLM Agent + SKILLS 插件」的分层设计思路。上层是由大语言模型驱动的任务规划与执行 Agent，负责将建模问题拆解为若干子任务并调度对应技能；下层是模块化的 SKILLS 集合，每个技能对应一类具体操作（例如数据处理、数值求解、图形绘制）。这种设计使技能可以独立扩展或替换，而无需修改 Agent 主流程。

桌面版集成了 Claude Code 作为运行内核，把 Python 运行时、依赖环境与 SKILLS 一并打包，用户侧不再感知底层的环境配置。项目由 jihe520 维护，采用桌面分发 + 开源仓库双轨模式：普通用户下载安装包即用，开发者则可基于仓库源码自行部署与二次开发。项目另有姊妹项目 sci-box，提供科研图表与流程图的 SKILL 合集，二者在技能层面形成互补。

## 安装与使用

对于绝大多数用户，推荐直接使用桌面版：

1. 访问 Releases 页面，下载与操作系统匹配的安装文件：macOS（M 系列芯片选 arm64，Intel 芯片选 x64）或 Windows 64 位。
2. macOS 包已完成 Developer ID 签名并通过 Apple 公证；Windows 包当前未签名，如遇 SmartScreen 提示，选择「更多信息」→「仍要运行」，并确保从官方 Releases 页面下载。
3. 安装后打开应用，填入一个模型 API Key。
4. 输入建模题目，由 Agent 自动执行建模与论文生成流程。

若需自行部署或参与贡献，可参考仓库中的 SKILLS 与「使用教程」章节，基于源码搭建 Python 环境并配置相应模型接口。最小可用路径即为「下载桌面版 → 填 API Key → 输入题目」，无需额外依赖。

## 适用场景

- **数学建模竞赛备赛与实战**：在有限时间内快速产出可提交的论文初稿，供参赛者在此基础上修改完善。
- **建模思路参考**：通过 Agent 给出的模型选择与求解过程，辅助参赛者理解题目、比较不同建模方案。
- **教学与培训**：教师在课堂上演示从问题到论文的完整链路，帮助学生建立对建模流程的整体认知。
- **科研辅助分析**：对需要快速完成数据分析与图表输出的场景，可借助其 SKILLS 能力提升效率。

## 项目亮点

与同类通用 LLM 对话工具相比，MathModelAgent 的差异主要体现在三点。其一是垂直定位，整个 Agent 与技能体系围绕数学建模这一特定任务设计，而非泛化的问答或写作。其二是交付物完整，最终输出的是符合竞赛格式要求的整篇论文，而非零散的分析片段。其三是使用门槛低，桌面版把运行环境与技能包一并内置，免去 Python、Node.js、Redis 的安装与 SKILL 手动配置，填一个 API Key 即可运行。此外，项目在 GitHub 上已获得约 5200 个 Star，具备一定的社区关注度与活跃维护迹象。
