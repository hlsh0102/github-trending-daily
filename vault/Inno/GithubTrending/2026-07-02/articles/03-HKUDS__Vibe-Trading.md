## 项目概述

Vibe-Trading 是一个基于大语言模型的个人化交易智能体项目，由香港大学数据科学实验室（HKUDS）开发。它旨在让用户仅通过一条命令，就能为 AI 智能体赋予全面的交易能力，包括股票分析、市场趋势研判、投资组合管理以及交易执行。项目的目标用户包括个人投资者、量化交易爱好者、金融科技开发者以及希望利用 AI 辅助决策的交易新手。Vibe-Trading 将复杂的技术栈封装为简洁的命令行接口，降低了打造专属交易助手的门槛。

## 核心功能

- **智能数据分析**：集成多种金融数据源，自动获取股票行情、财务指标、新闻情绪、技术指标等，为交易决策提供数据基础。
- **自然语言交互**：用户可直接用日常语言向智能体提问，例如“分析近期最值得关注的科技股”或“帮我优化当前持仓”，无需编写公式或代码。
- **策略生成与回测**：智能体可根据用户风险偏好与目标，自动生成交易策略，并利用历史数据进行回测，评估策略表现。
- **实时市场监控与预警**：支持持续跟踪指定标的，当价格、成交量等技术信号触发预设条件时，通过通知渠道提醒用户。
- **多资产覆盖**：涵盖股票、ETF、加密货币等常见交易品种，支持跨市场组合管理。
- **一键部署与扩展**：采用 FastAPI 后端与 React 前端，提供标准 RESTful API，用户可方便地集成到自有系统或二次开发。

## 技术架构

Vibe-Trading 核心技术栈包括 Python 3.11+、FastAPI 后端框架、React 19 前端界面以及大语言模型（LLM）作为智能体“大脑”。后端负责数据处理、策略计算与 API 服务；前端提供直观的仪表盘，展示市场数据、持仓状况与对话记录。智能体引擎通过 LLM 实现自然语言理解与决策逻辑调用，同时连接多种金融数据 API（如 yfinance、alpha vantage 等）和模拟交易接口。

架构设计上，Vibe-Trading 采用了模块化与插件化思路：数据源、策略模块、执行器均可独立替换，便于用户自定义。系统还内置了状态管理机制，支持会话保持与历史复盘。整个项目注重可观察性，提供详细的日志和调试接口，方便用户理解智能体的每一步决策依据。

## 安装与使用

### 安装

通过 pip 快速安装：

```bash
pip install vibe-trading-ai
```

若需从源码安装：

```bash
git clone https://github.com/HKUDS/Vibe-Trading.git
cd Vibe-Trading
pip install -r requirements.txt
```

### 最小可用示例

安装后，在终端中运行以下命令启动智能体：

```bash
vibe-trading --start
```

系统将自动配置默认数据源与模拟交易环境。启动后，您可在浏览器中访问 `http://localhost:8000` 查看前端界面，或通过命令行交互。例如，在终端输入：

```bash
vibe-trading ask "当前市场有哪些热门板块？"
```

智能体会返回基于最新数据的分析结果。

若需配置具体交易标的或 API 密钥，可编辑 `config.yaml` 文件，或通过 `vibe-trading config` 子命令设置。

## 适用场景

- **个人投资辅助**：普通投资者可利用 Vibe-Trading 快速获取市场洞察，生成个人化的买入/卖出建议，减少信息筛选成本。
- **量化策略开发实验**：开发者或研究员可以基于 Vibe-Trading 的模块快速验证策略想法，使用自然语言描述策略逻辑，降低编码负担。
- **金融教育演示**：教学场景中，教师可通过智能体演示技术指标概念、组合优化原理，学生可自主提问并观察系统响应。
- **自动化交易监控**：用户可设置长期运行的任务，让智能体在后台跟踪持仓标的，定期输出报告或触发警报。

## 项目亮点

Vibe-Trading 相比同类交易助手项目的差异化优势体现在：

1. **极低的准入门槛**：仅需一条命令即可启动完整的交易智能体，无需配置服务端环境或编写复杂脚本。
2. **深度结合大语言模型**：不同于传统基于规则或简单 ML 模型的交易工具，Vibe-Trading 利用 LLM 的自然语言理解与推理能力，实现更灵活、更具解释性的决策过程。
3. **全栈开源与可定制**：后端、前端、智能体逻辑全部开源，用户可任意修改、扩展或集成到个人工作流中。
4. **社区驱动与活跃迭代**：项目日增数百 Star，拥有活跃的飞书社群（Feishu Group），持续更新功能与修复问题。
5. **多语言支持**：README 提供了英、中、日、韩、阿拉伯语等多种版本，降低了全球用户的使用障碍。
