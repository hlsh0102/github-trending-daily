## 项目概述

Astryx 是一个由 Meta（原 Facebook）内部孵化并开源的设计系统，在过去八年中成长为该公司规模最大、使用最广泛的设计系统——支撑着 13,000 多个应用的界面开发。如今它以开源形式发布，旨在为人机协同的现代开发模式提供基础设施支持。

该项目解决了传统设计系统在灵活性和可定制性方面的核心痛点：多数设计系统要么提供封闭的顶层 API，导致深度定制困难；要么与特定样式库强绑定，迫使整个项目迁就设计系统的技术选型。Astryx 的目标用户包括需要快速构建一致界面的前端开发者、希望保留品牌个性的设计师，以及日益依赖 AI 辅助编码的现代开发团队。

## 核心功能

- **150+ 无障碍组件**：覆盖表单、导航、布局、数据展示等常见场景的组件库，所有组件均遵循 WAI-ARIA 无障碍规范。
- **品牌级主题系统**：通过 CSS 自定义属性覆盖实现主题定制，无需包装或 Fork 代码库即可应用品牌标识、色彩体系与排版规范。
- **内置暗色模式**：提供现成的暗色主题支持，开发者无需额外配置即可实现明暗模式切换。
- **即用型模板**：附带可直接部署的页面模板，涵盖登录、仪表盘、设置等典型页面结构。
- **命令行工具 (CLI)**：提供脚手架工具，支持项目初始化、组件安装和主题快速配置。
- **Swizzle 机制**：允许将任意组件“弹出”为全量源代码放入项目目录，实现底层组件的直接拥有和深度定制。

## 技术架构

Astryx 基于 **React** 构建，样式层使用 **StyleX** 编写。StyleX 是 Meta 开发的一种零运行时 CSS-in-JS 方案，在编译阶段提取静态样式，生成极小体积的原子化 CSS，同时保留完整的 JavaScript 变量引用能力。

架构上最大的设计特点在于 **“开放式内部结构”**（Open Internals）。传统设计系统通常将组件封裝成黑盒，只暴露有限的配置接口；Astryx 则将组件的组成模块直接导出——内部的子结构、状态管理逻辑、动画片段等均为公开 API。开发者可以直接在项目中组合这些底层模块，而不必受限于顶层组件接口。

对于需要更深度控制的场景，Swizzle 机制提供了“所有权转移”路径：执行一条命令后，指定组件的完整源代码（包括样式、类型定义、测试文件）会被复制到项目中，开发者可以完全接管该组件的后续维护。这种方式避免了传统“继承+重写”模式带来的样板代码和版本冲突。

值得强调的是，样式层的 StyleX 对终端用户完全透明。开发者可以用熟悉的 CSS 方案覆盖样式——无论是 Tailwind 的实用类、CSS Modules 还是原生 CSS——通过 `className` 属性传入即可，无需安装 StyleX 或配置任何构建插件。

## 安装与使用

**前提条件**：Node.js 18+、npm/yarn/pnpm

**基本安装**：

```bash
npm install @astryx/react
```

**最小可用示例**：

```tsx
import { Button, Card } from '@astryx/react';
import '@astryx/react/styles.css';

function MyComponent() {
  return (
    <Card>
      <h2>欢迎使用 Astryx</h2>
      <p>这是一个完全可定制的设计系统。</p>
      <Button variant="primary">了解更多</Button>
    </Card>
  );
}
```

**使用主题覆盖创建品牌外观**：

```css
/* 在你的全局样式文件中 */
:root {
  --ast-color-brand: #6C5CE7;
  --ast-color-bg-primary: #F8F9FA;
  --ast-border-radius: 8px;
}
```

**通过 CLI 快速初始化项目**：

```bash
npx @astryx/cli init my-project
cd my-project
npm run dev
```

## 适用场景

- **企业内部应用套件**：同一公司内多个团队开发不同的内部工具时，Astryx 提供一致的基础界面结构，同时允许每个应用保留独立的品牌配色。
- **AI 辅助开发环境**：由于 Astryx 的组件结构清晰且类型定义完善，AI 代码助手能够更准确地理解组件意图，生成符合设计系统规范的代码。
- **白标产品 (White-Label)**：SaaS 产品需要为不同客户提供定制化界面时，主题系统允许仅通过 CSS 变量覆盖即可完成品牌替换，无需分叉代码库。
- **大型开源项目**：需要贡献者遵守统一的界面规范，但又不能要求所有人学习特定 CSS 框架，Astryx 无锁定特性的优势凸显。

## 项目亮点

与 Material-UI、Chakra UI、Ant Design 等主流设计系统相比，Astryx 的差异化优势清晰可见：

1. **真正的无锁定**：不是口头承诺的“可定制”，而是在架构层面确保开发者可以用任意 CSS 方案覆盖，且无需依赖 StyleX。
2. **从八年前战场中沉淀**：支撑 Meta 13,000 多个应用的实战验证，Bug 修复、性能优化和性能边界经过极大规模检验。
3. **人机协同友好**：CLI + Swizzle + 开放内部结构的组合，让人类和 AI 都能以同样的方式理解组件——通过类型定义和可导出的模块，而非文档中的 API 描述。
4. **主题系统的最小成本**：仅需覆盖 CSS 变量即可实现完整主题，设计人员无需编写代码即可预览效果，开发人员无需修改组件实现。
