## 项目概述

Karukan 是一个面向 Linux 和 macOS 平台的开源日语输入法系统，其核心亮点在于采用神经网络驱动的假名汉字转换引擎。该项目由 Rust 语言编写，旨在为日语用户提供更加智能、流畅的输入体验。传统日语输入法（如 Mozc 或 Anthy）依赖于规则和统计语言模型进行转换，而 Karukan 引入了基于 GPT-2 的神经网络模型，通过 llama.cpp 进行高效推理，实现了上下文感知的高精度转换。项目目标用户包括日语母语者、日语学习者以及需要频繁输入日语的技术人员。

## 核心功能

- **神经假名汉字转换**：基于 GPT-2 架构的语言模型，通过 llama.cpp 推理引擎运行，能够根据上下文生成更为自然的转换结果，显著降低传统规则引擎常见的误转换率。
- **实时转换（Live Conversion）**：在用户输入过程中即时显示转换候选，无需按空格键即可看到转换进度。用户可通过 `Ctrl+Shift+L` 快捷键切换该模式的开闭。
- **上下文感知转换**：模型能够参考输入光标周围的文本内容（如前后句子），从而做出更符合语境的转换决策，尤其在处理同音异义词时优势明显。
- **用户转换学习**：系统会记忆用户选中的转换结果，并在后续输入中优先展示。同时支持基于前缀匹配的预测转换，用户在输入部分假名时即可看到匹配的学习候选。
- **系统词典集成**：利用 [SudachiDict](https://github.com/WorksApplications/SudachiDict) 构建高质量的底层词典，覆盖新词、专有名词和常用短语。
- **候选重写器（源自 Mozc）**：自动生成半角片假名、英文字母大小写与全半角转换、符号相关候选、以及数字的各种写法（如汉字数字、大字、罗马数字、带圈数字、十六进制/八进制/二进制表示），大幅提升了输入效率。

## 技术架构

Karukan 采用模块化的多 crate 设计，分为五个独立但相互协作的部分：

- **karukan-fcitx5**：Linux 平台的 IME 前端，以 fcitx5 插件形式存在，通过 C FFI 与核心引擎通信。
- **karukan-macos**：macOS 平台的 IME 前端，基于 Swift 和 InputMethodKit 框架开发，提供原生级别的输入体验。
- **karukan-im**：共享的 IME 引擎层，包含状态机、罗马字到假名转换逻辑，以及为 macOS 设计的 JSON-RPC 服务器（karukan-imserver）。
- **karukan-engine**：核心库，负责罗马字到平假名的转换以及基于 llama.cpp 的神经假名汉字推理。这是整个系统的“大脑”。
- **karukan-cli**：命令行工具和服务器组件，提供词典构建、Sudachi 词典生成、词典查看、基准测试（AJIMEE-Bench）以及 HTTP 服务器功能。

这种分层架构使得前端（键盘事件处理）与后端（语言模型推理）解耦，允许开发者独立更新模型或前端适配层。神经模型采用 GPT-2 架构，通过 ONNX 格式导出并由 llama.cpp 加载，带来了跨平台的高效运行能力。用户数据的学习与存储通过轻量级数据库实现，以保持低延迟响应。

## 安装与使用

### 系统要求

- **Linux**：需要安装 fcitx5 输入法框架。
- **macOS**：支持 macOS 10.15 及以上版本（推荐 Big Sur 或更新版本）。

### 安装步骤（以 Linux 为例）

1. 克隆仓库并进入目录：
   ```bash
   git clone https://github.com/togatoga/karukan.git
   cd karukan
   ```

2. 构建核心引擎与 fcitx5 插件（确保已安装 Rust 工具链和 Cargo）：
   ```bash
   cargo build --release
   ```

3. 安装 fcitx5 插件（可能需要 sudo 权限）：
   ```bash
   # 具体安装路径因发行版而异，请参考项目 README
   cp target/release/libkarukan-fcitx5.so ~/.local/share/fcitx5/inputmethod/
   ```

4. 将 karukan 添加到 fcitx5 的输入法列表：通过系统设置或 `fcitx5-configtool` 启用。

### 最小使用示例

以 CLI 模式测试引擎工作：
```bash
./target/release/karukan-cli --text "わたしはがくせい"
```
预期输出将显示转换候选列表，并支持通过 `-l` 参数调整学习模型权重。

macOS 用户可编译后直接将产物拖入“输入法”偏好设置中启用。

## 适用场景

- **日常日语写作**：无论是撰写邮件、文档还是聊天，Karukan 的实时转换和上下文感知能力都能显著提升输入速度和准确度。
- **日语学习工具**：学习者可以通过预测转换和候选重写功能，快速了解假名对应的汉字、数字或英文变体，辅助语言习得。
- **编程中嵌入日文注释**：开发者在 Linux 或 macOS 上编码时，无需切换到笨重的输入法，即可流畅输入日文注释或文档。
- **研究与比较**：对照神经引擎与传统规则引擎（如 Mozc）的转换质量，Karukan 可作为 NLP 或输入法研究领域的参考实现。

## 项目亮点

- **神经引擎 vs 传统规则**：相较于 Mozc 等基于动态规划或统计语言模型的方案，Karukan 的 GPT-2 模型能够捕捉更长的文本依赖关系，在处理语义模糊时表现更佳。
- **跨平台原生体验**：Linux 通过 fcitx5 集成，macOS 借助 InputMethodKit，两者均贴近系统原生的输入法交互方式，无需额外配置环境。
- **用户学习能力**：系统不仅记住用户选择，还能在下一次输入时自动排序候选，形成个性化的输入习惯适应，这在大规模通用输入法中较为少见。
- **Rust 性能优势**：整个系统以 Rust 编写，内存安全且低开销，确保神经模型推理与前端 I/O 的高效协同，即使在老旧硬件上也能保持流畅。
