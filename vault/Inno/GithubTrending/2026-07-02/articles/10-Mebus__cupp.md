## 项目概述

CUPP（Common User Passwords Profiler）是一个基于 Python 的开源工具，专门用于根据目标用户的个人信息生成可能的密码字典。在安全测试和数字取证领域，密码强度评估是重要的一环。许多用户倾向于使用与自身紧密相关的信息（如生日、昵称、爱人姓名、宠物名、地址等）作为密码，这些密码虽然易于记忆，但也极易被针对性破解。CUPP 正是针对这一现象设计，通过交互式问答收集目标用户的基本信息，然后智能组合生成大量可能的密码组合，为渗透测试人员、安全审计人员以及取证调查人员提供高效的密码猜测字典。

目标用户包括：渗透测试工程师、安全研究人员、企业内网安全审计人员、数字取证专家，以及对密码安全有研究兴趣的个人。

## 核心功能

- **交互式信息收集**：通过命令行交互模式，引导用户输入目标个体的各类个人信息，包括姓名、生日、配偶/子女姓名、宠物名、昵称、喜欢的运动/球队、常用数字等，自动构建个人画像。
- **智能密码生成**：基于收集到的个人信息，按照常见密码构造逻辑（如姓名+生日、昵称+年份、多种信息的拼接与变体）生成大量候选密码，覆盖大小写、数字、特殊符号的各种组合。
- **现有字典增强**：支持对已有密码字典文件进行“个人化”加工，将标准字典与目标个人信息结合，生成更具针对性的扩展字典，提高破解效率。
- **WyD.pl 输出兼容**：能够处理由 WyD.pl 等工具生成的模式化输出，将其转化为可直接用于密码猜测的字典格式。
- **轻量级零依赖**：仅需 Python 3 运行环境，无需安装任何第三方库，开箱即用，适合在各类 Linux/Unix 及 Windows 环境下快速部署。
- **命令行友好**：提供简洁明了的参数选项，支持 `-h` 查看帮助、`-i` 进入交互模式、`-w` 扩展字典，学习成本极低。

## 技术架构

CUPP 采用纯 Python 编写，设计上遵循“单文件 + 命令行界面”的极简架构。其核心逻辑分为三个模块：

1. **交互式对话引擎**：通过一系列预设问题（如“What's the target's name?”、“What's the target's date of birth?”）逐步引导用户输入信息，并将这些碎片化数据存储为字典对象。
2. **密码组合算法**：基于安全领域常见的密码构造模式（如“Name+Year”、“Nickname+Symbol+Number”、“PetName+LoverName”），对收集到的信息进行排列组合，同时自动生成大小写变化、数字后缀、符号插入等变体。
3. **文件扩展模块**：读取用户提供的现有字典文件，将其中每条记录与目标个人信息进行拼接、前缀/后缀添加等操作，产出新的增强字典。

设计上强调“针对性强”与“效率优先”：不采用暴力穷举所有可能，而是集中精力生成与目标高度相关的候选密码，减少无用尝试，使密码猜测更精准。整个工具无图形界面，完全依赖命令行，适合在自动化脚本或远程服务器环境运行。

## 安装与使用

**环境要求**：Python 3.x（推荐 3.6 及以上版本）

**安装方式**：直接从 GitHub 克隆仓库

```bash
git clone https://github.com/Mebus/cupp.git
cd cupp
```

**最小可用示例**：

1. **进入交互模式**
   ```bash
   python3 cupp.py -i
   ```
   随后按照提示依次输入目标信息（如姓名、生日、配偶、宠物等），程序将自动生成字典文件并保存为 `{name}.txt`。

2. **查看帮助**
   ```bash
   python3 cupp.py -h
   ```
   显示所有可用参数说明。

3. **增强现有字典**
   ```bash
   python3 cupp.py -w /path/to/your/dictionary.txt
   ```
   程序会读取指定字典，结合交互输入的个人信息，输出增强版字典。

生成的文件默认保存在当前工作目录，以目标姓名命名（例如 `john_doe.txt`），每行一个密码。

## 适用场景

- **内部网络安全审计**：企业安全团队在对员工密码强度进行评估时，使用 CUPP 模拟针对性攻击，识别使用个人生日、昵称等弱密码的账户，推动密码策略整改。
- **渗透测试前期侦察**：在获取目标少量个人信息后（如社交网络公开资料），渗透测试人员利用 CUPP 快速生成专属字典，尝试突破 Web 后台、VPN、SSH 等登录点。
- **数字取证与犯罪调查**：法证调查人员通过嫌疑人亲属关系、重要日期等信息生成密码字典，尝试解锁加密设备、邮箱或社交媒体账户。
- **安全培训与意识提升**：演示密码不安全的场景时，培训讲师现场使用 CUPP 基于学员信息生成密码，直观展示个人化密码的风险。

## 项目亮点

- **精准高效的针对性攻击**：相比通用字典（如 rockyou.txt），CUPP 生成的密码高度个性化，在目标信息已知的情况下，命中率显著更高，大幅减少爆破时间。
- **极简部署，零依赖**：无需配置复杂环境或安装数据库，一条 git clone 命令即可开始使用，适合临时或受限环境。
- **交互式引导降低使用门槛**：用户无需记忆复杂语法，通过一问一答即可完成字典生成，尤其适合安全初学者快速上手。
- **持续活跃的社区支持**：项目在 GitHub 上拥有超过 6000 颗星，日增关注度说明其工具价值被广泛认可，且有大量用户贡献改进建议与分支版本。
