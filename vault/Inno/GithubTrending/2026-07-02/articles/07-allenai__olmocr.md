## 项目概述

olmocr 是由艾伦人工智能研究所（Allen Institute for AI, Ai2）开发的一个开源工具包，专门用于将 PDF 及其他基于图像的文档格式（如 PNG、JPEG）转化为干净、可读的纯文本格式。该项目解决了当前大语言模型（LLM）训练和数据处理中的一个核心痛点：大量知识存储在 PDF 文件中，但这些格式通常包含复杂的排版、表格、公式、页眉页脚等元素，直接提取的文本质量低、噪声大、难以直接用于模型训练。olmocr 的目标用户包括机器学习工程师、数据科学家、学术研究者，以及任何需要从 PDF 中高效、高质量提取文本内容的开发者和团队。

## 核心功能

- **多格式文档转换**：支持 PDF、PNG、JPEG 等常见文档格式输入，输出为结构化清晰的 Markdown 格式文本。
- **复杂内容支持**：能够准确解析并转换文档中的数学公式、表格、手写内容以及多栏、多层级等复杂排版元素。
- **自动清理噪声元素**：智能识别并移除文档中的页眉、页脚、页码等无关内容，输出更整洁、更适合下游任务的文本。
- **自然语言处理友好**：输出的文本保持自然的阅读顺序和段落结构，方便直接用于 LLM 训练数据构建或知识库索引。
- **高性能批处理**：支持大批量文档的并行处理，满足工业级数据处理需求。
- **在线演示与快速集成**：提供可直接在线体验的 demo（olmocr.allenai.org），同时作为 Python 包可轻松集成到现有工作流中。

## 技术架构

olmocr 基于 Python 语言开发，核心技术思路是运用深度学习和视觉识别模型来理解文档的语义结构，而非简单的文本提取。其架构特点包括：

1. **视觉-语言模型结合**：利用预训练的视觉模型（如基于 Transformer 的架构）对文档页面进行图像级理解，再通过语言模型生成结构化的文本描述，从而实现对复杂排版的端到端处理。
2. **模块化设计**：系统分为页面图像预处理、版面分析、内容识别与结构化输出等独立模块，便于扩展和定制。例如，用户可针对特定类型的文档（如科学论文、表格表单）调整处理流程。
3. **训练数据驱动**：项目基于大规模高质量的人工标注数据（包括公式、表格、手写等场景）进行模型训练，确保在各类复杂情况下的输出鲁棒性。论文版本 v1（arXiv:2502.18443）和 v2（arXiv:2510.19817）详细介绍了技术细节。
4. **高效推理优化**：通过模型量化和批处理优化，在保障精度的同时提升处理速度，使得数千页的大型文档集可在合理时间内完成转换。

## 安装与使用

安装简单，通过 pip 即可一键完成：

```bash
pip install olmocr
```

最小使用示例，转换单个 PDF 文件为 Markdown：

```python
from olmocr import convert_pdf

# 转换本地 PDF 文件
result = convert_pdf("path/to/document.pdf")
# result 为包含 markdown 文本的字符串或结构化对象
print(result)

# 也可处理图片文件
result = convert_pdf("path/to/page.png")
```

对于批量处理，建议使用库内置的并发功能或结合外部队列进行：

```python
from olmocr import batch_convert
import glob

pdf_files = glob.glob("documents/*.pdf")
results = batch_convert(pdf_files, num_workers=4)
for pdf_path, markdown in results:
    with open(pdf_path.replace('.pdf', '.md'), 'w') as f:
        f.write(markdown)
```

更多高级配置如自定义公式处理策略、表格保留格式等，请参考项目文档。

## 适用场景

- **大语言模型训练数据构建**：将海量 PDF 论文、书籍、报告等转换为纯文本，构建高质量、格式统一的训练语料库，避免噪声数据对模型性能的影响。
- **文档知识库与检索系统**：企业或机构需将内部 PDF 文档（如合同、规范、技术手册）转换为可搜索的文本形式，支持语义搜索、问答系统或 RAG 管线的构建。
- **学术研究与期刊处理**：研究者在文献综述、元分析或数据集构建中，需要从 PDF 格式的学术论文中批量提取全文内容，olmocr 能较好地处理公式和表格。
- **无障碍与内容再加工**：将扫描版文档或图像化 PDF 转换为机器可读的文本，用于转写为音频、简化排版或在其他平台上发布。

## 项目亮点

- **专为 LLM 设计**：与通用 OCR 或 PDF 解析工具不同，olmocr 将输出结构化和自然流畅的 Markdown 文本作为首要目标，更适合作为 LLM 训练和推理的输入格式。
- **开源透明、社区活跃**：基于 Apache 2.0 许可，拥有活跃的 GitHub 社区和 Discord 交流频道，用户可自由使用、修改和贡献，且技术报告公开发表，算法可复现。
- **由顶尖 AI 研究机构维护**：来自艾伦人工智能研究所（Ai2），该机构是 OLMo 大模型系列、AI2 Scholar 等知名项目的发源地，项目质量和持续研发能力有保障。
- **效果与速度的平衡**：相较于传统的 PDF 提取方案，olmocr 在保留复杂结构（公式、表格）方面表现更优，同时处理速度可满足常见数据管线需求。
