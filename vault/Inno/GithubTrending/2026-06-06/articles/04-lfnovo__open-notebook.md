## 项目概述

Open Notebook 是一款开源、注重隐私的 Notebook LM 替代品，由 lfnovo 团队基于 TypeScript 构建。该项目旨在为用户提供一个功能更灵活、完全可控的笔记与知识管理平台，解决了传统笔记工具数据锁定、功能单一以及缺乏 AI 能力的问题。目标用户包括研究人员、知识工作者、技术爱好者以及任何希望以结构化方式管理信息、并利用大语言模型进行深度分析的人群。

## 核心功能

- **多模态内容支持**：用户可导入文本、PDF、网页、图片等多种格式的内容，平台自动提取文字并进行结构化索引。
- **AI 增强分析**：集成多种大语言模型，支持自动摘要、问答、内容关联分析以及知识点提取，帮助用户快速理解复杂材料。
- **隐私优先**：所有数据可本地部署，支持自托管运行，确保用户对数据的完全控制权，避免数据上传至第三方服务器。
- **灵活的工作流引擎**：支持用户自定义处理流程，例如自动标签、分类、标记，以及基于规则的自动化操作。
- **团队协作**：提供互动的知识空间，允许多用户协同编辑、分享笔记，并保留版本历史。
- **丰富插件生态**：开放 API 接口，社区可开发扩展功能，如集成外部 OCR、翻译服务或自定义 AI 模型。

## 技术架构

Open Notebook 采用现代全栈架构，前端基于 React 组件库构建，后端使用 Node.js 运行时，结合 PostgreSQL 或 SQLite 作为数据存储。其核心设计特点包括：

1. **微服务式模块**：核心功能被拆分为独立服务（如内容提取服务、AI 推理服务、索引服务），便于扩展和维护。
2. **AI 模型抽象层**：通过统一的接口支持对接 OpenAI、Anthropic、本地运行的 Llama 等模型，用户可自由切换或并行使用多家服务。
3. **安全隔离沙箱**：所有外部内容提取和脚本执行均在隔离沙箱中进行，防止恶意代码影响主机系统。
4. **端到端加密**：用户可选启用 E2E 加密，确保即使在服务端也无法读取明文笔记内容。

## 安装与使用

### 快速安装（Docker）

```bash
# 克隆仓库
git clone https://github.com/lfnovo/open-notebook.git
cd open-notebook

# 使用 Docker Compose 一键部署
docker compose up -d
```

### 最小可用示例

1. 访问 `http://localhost:3000` 进入注册页面。
2. 创建一个新笔记本（Notebook），例如“研究笔记”。
3. 点击“导入”按钮，上传一篇 PDF 文章。
4. 等待系统自动提取内容后，在右侧面板输入提问：“请总结这篇文章的核心观点”。
5. 平台将调用默认 AI 模型生成摘要，并根据文中引用的论文自动生成参考文献列表。

## 适用场景

- **学术研究**：研究人员可收集论文、书籍章节、实验报告，利用 AI 快速提取关键结论和方法论，并建立知识图谱。
- **企业知识管理**：团队可将培训资料、项目文档、会议纪要统一管理，通过问答功能快速检索历史信息。
- **个人学习成长**：学生或自学者可构建个性化的知识库，导入在线课程笔记、文章剪报，利用自动化工具定期复习记忆。
- **内容创作**：作家、博主可收集灵感素材，AI 辅助分析文章结构，生成内容大纲和初稿。

## 项目亮点

与 Notebook LM 等同类项目相比，Open Notebook 的差异化优势体现在：

- **完全开源**：代码透明，无商业锁定风险，社区可审查、贡献和定制。
- **多模型兼容**：不绑定特定 AI 厂商，支持本地模型运行，节省 API 费用同时保护数据隐私。
- **自托管自由**：用户可部署在自己的服务器上，无需依赖第三方云服务。
- **主动处理能力**：不仅是被动存储，还具备预设规则、自动化工作流等高级特性，提升知识管理效率。
- **活跃社区**：拥有 Discord 群组和趋势榜徽章，社区积极贡献插件、功能建议和文档翻译（已有德语、西班牙语、法语等多语言版本）。
