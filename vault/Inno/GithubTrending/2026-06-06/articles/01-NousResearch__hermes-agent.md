## 项目概述

Hermes Agent 是一个由 Nous Research 构建的、具备自我进化能力的 AI 代理框架。与传统 AI 助手不同，Hermes Agent 的设计核心在于“与用户一同成长”——它内置了一个持续学习循环，能够从每次交互中提取经验、生成新的技能模块，并在后续对话中逐步优化自身行为。该项目主要面向希望获得个性化、可扩展且长期运行 AI 代理的开发者、研究人员以及高级用户。你可以用不到一杯咖啡的月费（低至 $5 VPS）部署它，并自由选择任何底层模型，从 OpenAI 到开源模型均可。

## 核心功能

- **技能自生成与进化**：代理在运行过程中会不断从对话历史中提取模式，自动创建、改进并淘汰技能（Skill），形成动态的知识能力库。
- **长期记忆与持久化**：具备跨会话的持久记忆能力，能够主动“提醒”自己保留重要信息，并回顾过去对话中的上下文，实现对用户需求的深层理解。
- **独立运行与远程交互**：不依赖本地设备，可部署在云服务器上持续运行。通过 Telegram 等聊天平台即可与代理对话，即使关闭终端也保持活跃。
- **模型无关性**：支持接入任意主流语言模型（如 GPT-4、Claude、Llama 系列），用户可通过 Nous Portal 或自定义接口自由切换底层模型。
- **成本优化设计**：支持无服务器架构，代理在空闲时近乎零成本运行；同时提供丰富的配置选项以平衡性能与花费。
- **模块化系统与热更新**：技能、记忆、工具等组件均可热替换，无需重启即可扩展能力，适合长期迭代维护。

## 技术架构

Hermes Agent 采用分层架构设计，核心由三层构成：
1. **感知与执行层**：负责接收用户输入（如 Telegram 消息、API 请求），调用底层 LLM 生成回应，并执行工具调用。
2. **技能系统层**：这是项目最独特的部分。技能被定义为可重用的行为模板，包含触发条件、上下文约束和执行逻辑。代理会定期分析对话记录，通过元学习算法抽象出新的技能或优化现有技能。
3. **持久化与记忆层**：采用向量数据库与结构化存储组合，实现语义搜索（回顾过去对话）和显式记忆（保存用户偏好、重要信息）。代理还会通过“元记忆提示”（meta-memory prompting）主动决定哪些信息需要跨会话保留。

项目使用 Python 编写，主要依赖异步框架（如 asyncio）实现高并发长连接。整个系统设计为微服务友好，支持 Docker 容器化部署，并通过插件系统实现与 Telegram、Slack 等平台的无缝集成。

## 安装与使用

### 快速开始（Docker 推荐）
```bash
# 克隆仓库
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent

# 使用 Docker Compose 启动（需要 Docker 和 docker-compose）
docker-compose up -d
```

### 最小可用示例
1. 配置环境变量（创建 `.env` 文件）：
```
OPENAI_API_KEY=your_openai_key
TELEGRAM_BOT_TOKEN=your_bot_token
AGENT_NAME=MyHermes
```
2. 启动代理后，在 Telegram 中与你的 Bot 对话。代理会自动开始构建技能，第一次对话可能较为基础，但随着交互累积，回应的质量与个性化程度将逐步提升。

对于非 Docker 部署，请参考项目文档中的手动安装说明（要求 Python 3.10+ 和 Poetry 包管理器）。

## 适用场景

- **个人知识管理助手**：部署在云服务器上，持续记录、整理用户的思考、项目进度或研究笔记，并随着时间推移形成个人化的工作流技能。
- **长期项目协作代理**：团队成员可通过 Telegram 等渠道与统一代理交互，代理能记忆项目上下文、自动提炼常见问题的解决方案，并生成可复用的自动化脚本作为新技能。
- **AI 研究与实验平台**：研究人员可以利用其模块化架构测试不同的学习算法、记忆机制或提示策略，观察代理在不同模型下的自我进化表现。
- **小团队自动化运营**：代替固定工位服务，以低成本 7×24 小时处理客户咨询、数据收集或系统监控任务，且能根据反馈自动改进响应流程。

## 项目亮点

与 LangChain、AutoGPT 等通用代理框架相比，Hermes Agent 的核心差异在于引入了**持续学习循环**：大多数代理依靠开发者手动编写工具和技能，而 Hermes 能根据交互历史自主生成并优化技能。另外，其**独立运行 + 远程访问**的设计使得代理可以真正成为“永不离线的搭档”，而非仅在当前终端会话中有效。最后，**模型自由**和**极低部署成本**的结合，让它在灵活性和经济性之间取得了良好的平衡，尤其适合个人开发者或小型团队使用。
