## 项目概述

PaddleOCR 是百度飞桨（PaddlePaddle）推出的开源 OCR 工具包，旨在将 PDF 文档和图像高效转换为结构化的、可供大语言模型（LLM）直接使用的数据。它解决了从非结构化视觉数据（图片、扫描件、PDF）到结构化文本（JSON/Markdown）的转换难题，弥合了图像/PDF 与 LLM 之间的鸿沟。项目目标用户涵盖 AI 应用开发者、数据工程师、文档处理团队以及需要构建智能检索增强生成（RAG）和智能体（Agent）应用的专业人员。凭借超过 70,000 颗 GitHub Stars，PaddleOCR 已成为社区公认的文档理解基础设施，被 Dify、RAGFlow、Cherry Studio 等顶级项目广泛采用。

## 核心功能

- **智能文档解析**：提供从 PDF 或图像到结构化文本（JSON/Markdown）的全流程转换，输出格式直接适配 LLM 输入，无需额外后处理。
- **多语言识别**：支持 100 种以上语言的文字识别，覆盖全球主流语系，包括中文、英文、日文、韩文、法文、阿拉伯文等。
- **高精度版面分析**：自动识别文档中的文本区块、表格、公式、标题、页眉页脚等复杂版面结构，保留原始逻辑顺序。
- **表格还原**：能够将图片或 PDF 中的表格内容准确提取并还原为 Markdown 表格或结构化数据，支持合并单元格等复杂场景。
- **公式识别**：支持印刷体和手写体数学公式的识别，输出 LaTeX 格式，便于科研文档的数字化处理。
- **端到端训练与部署**：提供完整的模型训练、微调、量化与部署工具链，支持 CPU/GPU 加速，可快速适配特定业务场景。

## 技术架构

PaddleOCR 采用模块化设计，核心技术栈包括：

- **深度学习框架**：基于 PaddlePaddle 构建，充分利用飞桨的动态图机制和高性能算子库，实现高效的模型训练与推理。
- **多阶段处理流水线**：从图像预处理（倾斜校正、降噪）、文字检测（如 DB、EAST）、方向分类到文字识别（如 CRNN、SVTR），各环节模块化，可独立替换或升级。
- **视觉-语言模型（VLM）**：最新推出的 PaddleOCR-VL-1.6（0.9B）是行业领先的轻量级文档理解大模型，首次将版面分析与文字识别统一为端到端流程，在 OmniDocBench v1.6 基准测试中达到 96.3% 的准确率，显著领先同量级模型。
- **多模型协作**：针对古籍生僻字、公章压字、手写体等挑战场景，通过检测、识别与后处理模型的协同优化，大幅提升鲁棒性。
- **轻量化与跨平台**：经过模型剪枝、量化与知识蒸馏，核心模型体积极小（最小模型仅 2.3MB），可在移动端、边缘设备及云端无缝部署。

## 安装与使用

### 安装

推荐使用 pip 快速安装：

```bash
pip install paddlepaddle paddleocr
# 如需 GPU 支持，安装 paddlepaddle-gpu 版本
```

### 最小可用示例

以下代码演示如何从图片中提取文字并以 JSON 格式输出：

```python
from paddleocr import PaddleOCR

ocr = PaddleOCR(use_angle_cls=True, lang='ch')  # 启用方向分类，指定语言
result = ocr.ocr('example.jpg', cls=True)

# 打印所有识别结果
for line in result[0]:
    print(f"文本: {line[1][0]}, 置信度: {line[1][1]:.2f}")
```

若需要将 PDF 转换为 Markdown 格式：

```bash
paddleocr --image_dir ./docs.pdf --type doc --format markdown
```

## 适用场景

- **智能文档管理系统**：企业将扫描合同、发票、财务报表自动转化为可搜索、可编辑的结构化数据，供后续审计或分析使用。
- **RAG 知识库构建**：为 LLM 应用构建知识库时，将 PDF 论文、技术手册、历史文档解析为分块文本，支持高精度检索。
- **自动化表格与公式录入**：科研机构批量处理文献中的表格和数学公式，避免手动录入错误，加速数据整理流程。
- **多语种文档翻译辅助**：先通过 OCR 提取多语言文档原文，再对接机器翻译管线，实现跨语言内容生产。

## 项目亮点

- **领先的文档理解精度**：PaddleOCR-VL-1.6 在多项基准测试中超越同类开源模型，特别是在公式、表格和生僻字场景下表现突出。
- **极致轻量与高速**：核心模型小至 2.3MB，单张图片推理速度可达毫秒级，适合部署至边缘设备或集成到实时系统。
- **100+ 语言全面覆盖**：预训练模型支持全球主要语言，无需额外训练即可处理多语种混合文档。
- **活跃的生态与社区**：拥有 70,000+ Stars，完善的文档、教程与模型库，且被 Dify、RAGFlow 等知名项目集成，降低用户集成成本。
- **全栈自研与 Apache 2.0 许可**：基于国产深度学习框架，无外部依赖隐患；开源协议友好，商用不受限。
