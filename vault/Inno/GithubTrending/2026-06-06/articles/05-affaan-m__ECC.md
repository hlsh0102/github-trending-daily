## 项目概述

ECC（Efficient Cognitive Core）是一个面向 AI 编程助手的“智能体工具链性能优化系统”。该项目旨在解决当前 AI 编程代理（如 Claude Code、Codex、OpenCode、Cursor 等）在多工具协同、记忆管理、安全扫描和持续学习等方面存在的效率瓶颈。目标用户包括使用 AI 编程助手进行日常开发工作的软件工程师、DevOps 工程师、AI 研究者，以及任何希望提升 AI 辅助编程工作流效率和可控性的技术团队。

ECC 不仅仅是一套配置集合，而是一个完整的智能体运行系统，内置技能模块、本能响应、内存优化、持续学习机制、安全扫描以及研究优先的开发范式。它帮助用户在多个编程代理之间建立统一的、高效的工作流，实现真正的“跨工具协同”。

## 核心功能

- **跨工具工作流统一**：支持 Claude Code、Codex、OpenCode、Cursor 等多个主流 AI 编程代理，可实现同一任务在不同工具间的无缝切换与协作。
- **智能体技能与本能系统**：预置大量可配置的技能模块，并赋予智能体“本能”级别的自动响应能力，减少人工干预。
- **记忆优化与管理**：通过智能缓存和上下文压缩技术，优化 AI 代理的记忆使用效率，避免长对话中的上下文丢失问题。
- **安全扫描与防护**：内置安全检测模块，自动识别并阻止可能有害的代码生成请求，防止敏感信息泄露或恶意代码注入。
- **持续学习与适应**：支持从历史对话和任务中学习，自动调整智能体的行为模式，提升长期使用中的个性化表现。
- **研究优先的开发范型**：内置实验追踪和数据记录功能，便于开发者在真实工作流中测试和优化智能体行为。

## 技术架构

ECC 项目采用模块化设计，以 JavaScript 为核心语言，利用 npm 包管理器进行分发。架构上主要分为以下几层：

- **核心运行时层**：提供跨工具的兼容性抽象，与 Claude Code、Cursor 等多达十几种 AI 编程代理的 API 或 CLI 接口对接，确保指令和事件在不同工具间能够正确传递和解析。
- **技能与本能引擎**：基于事件驱动架构，允许用户通过配置文件或编程方式定义技能触发条件。本能层则采用优先级队列机制，确保高优先级响应（如安全警告）能够立即执行。
- **内存与上下文管理器**：使用持久化存储（如本地 JSON、SQLite）与缓存策略相结合，对 AI 代理的交互历史进行压缩、索引和快速检索，在支持向量数据库（如 ChromaDB）扩展方面也预留了接口。
- **安全扫描模块**：集成基于规则和轻量级机器学习模型的代码分析管道，对生成的代码片段进行实时评估。
- **研究数据记录**：通过可插拔的记录器，将每次交互的元数据（耗时、成功率、错误类型等）输出为结构化日志，便于后续分析。

整个系统遵循“插件优先”的设计哲学，核心功能之外的所有特性均可通过 npm 包扩展，目前已发布 `ecc-universal` 和 `ecc-agentshield` 两个主要包，以及 GitHub Marketplace 上的 `ecc-tools` 扩展集。

## 安装与使用

ECC 支持通过 npm 全局安装，适用于 Node.js 18+ 环境。

**基本安装步骤：**

```bash
# 安装核心通用包
npm install -g ecc-universal

# (可选) 安装安全防护扩展
npm install -g ecc-agentshield
```

**最小可用示例：**

1. 初始化 ECC 配置（首次使用）：
   ```bash
   ecc init
   ```
   该命令会在当前目录生成 `.ecc/config.json` 配置文件。

2. 激活核心技能（以 Claude Code 为例）：
   ```bash
   ecc activate --model claude-code --project .
   ```
   ECC 会自动检测项目结构，加载内置技能，并开始监控 AI 代理的行为。

3. 运行一个简单的安全扫描任务：
   ```bash
   ecc scan --path ./src --aggressive
   ```
   该命令将对指定路径下的所有代码（包括历史 AI 生成代码）进行安全检查。

详细使用文档可参见仓库的 `docs/` 目录，其中包含了针对不同语言和不同 AI 代理的专门教程。

## 适用场景

- **多工具开发团队**：团队中不同开发者使用不同的 AI 编程代理（如一部分用 Cursor，一部分用 Claude Code），ECC 可以统一工作流标准，降低切换成本。
- **安全敏感型项目**：金融、医疗等领域的开发项目中，需要自动对 AI 生成的代码进行安全审查，ECC 的安全扫描功能可在代码提交前阻止潜在风险。
- **AI 代理调优与研究**：AI 研究者或高级用户希望对比不同模型、不同配置下的代码生成质量，ECC 的研究记录功能提供了数据基础。
- **个人高效开发**：重度依赖 AI 编程助手的个人开发者，利用 ECC 的记忆优化和持续学习功能，从 AI 代理获得更个性化和成功率更高的代码建议。

## 项目亮点

ECC 与同类项目相比具有显著优势：

- **跨工具兼容性**：大多数智能体优化工具仅支持单一平台，ECC 从设计之初就支持 Claude Code、Codex、OpenCode、Cursor 等十几个主流编程代理，这是其最大差异化价值。
- **完整系统而非工具**：不是简单的配置管理器或提示词库，而是包含生命周期的完整运行系统，从安全到记忆再到持续的自我优化，功能覆盖全面。
- **研究优先的可观测性**：内置数据记录功能使得用户可以像实验一样对待 AI 代理的使用，这对追求可衡量改进的工程团队尤为重要。
- **庞大的社区生态**：超过 18 万星标、2.8 万 fork、170 多位贡献者以及支持 12 种以上语言生态，证明了其活跃度和用户认可度。
- **模块化扩展体系**：通过 npm 包分发的设计使得用户只需安装自己需要的模块，保持了系统的轻量化。
