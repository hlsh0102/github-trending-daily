## 项目概述

/last30days 是一个 AI 智能体（Agent）技能，旨在解决互联网信息过载与低质内容泛滥的问题。传统搜索引擎通常依赖 SEO 和编辑推荐，而 /last30days 则聚合 Reddit、X（Twitter）、YouTube、Hacker News、Polymarket 以及通用网络上的信息，依据点赞数、收藏数、真实金钱押注（Polymarket）等社区信号对搜索结果进行排序，并利用大语言模型生成一份有据可依的摘要报告。项目主要面向开发者、研究人员、投资者以及任何需要快速了解某个话题在过去30天内社区讨论热点的用户。项目采用 MIT 许可证，目前已在 GitHub 上获得超过28000星。

## 核心功能

- **多源聚合搜索**：同时从 Reddit、X、YouTube、Hacker News、Polymarket 以及通用网络抓取与话题相关的帖子、视频、讨论和预测市场数据，无需用户逐一访问不同平台。
- **社区信号评分**：搜索结果依据各平台的真实参与数据（如 Reddit 的 upvotes、X 的 likes、YouTube 的观看数、Polymarket 的流动金额）进行排序，优先展示获得社区高度认可的内容，而非 SEO 优化后的内容。
- **自动摘要合成**：AI 智能体将来自不同来源的零散信息整合，生成一份逻辑连贯、涵盖不同观点且附有引用来源的摘要报告，节省用户阅读大量原文的时间。
- **零配置起步**：安装后无需任何 API Key 或复杂设置即可使用。Reddit、Hacker News、Polymarket 和 GitHub 等数据源开箱即用。
- **30秒设置向导**：首次运行后，内置的设置向导会引导用户快速配置 X、YouTube、TikTok 等需要额外授权的平台，整个过程不超过30秒。
- **跨平台兼容**：支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 等50多种支持 Agent Skills 标准的主机环境，一次安装，随处可用。

## 技术架构

项目采用 AI 智能体（Agent）架构设计，主要由两部分组成：运行时技能规范（skill spec）和实际的执行逻辑。运行时技能规范存放在 `skills/last30days/SKILL.md` 文件中，是整个项目的实际行为定义来源，包含最新命令和设置行为的详细说明。执行逻辑用 Python 编写，负责通过各平台 API 或爬虫接口收集数据，并对收集到的数据进行清洗、评分和组织。AI 摘要生成环节调用大语言模型（如 Claude 或其他支持 agent 调用的模型），将非结构化的社区数据转化为结构化的摘要报告。架构上强调模块化与可扩展性，每个数据源作为一个独立的插件或适配器实现，便于后续增加新的社交平台或搜索源。设计思路的核心是将搜索从算法推荐回归到社区共识：信任大量真实用户的集体判断，而不是少数编辑或机器的权重。

## 安装与使用

**推荐方式（Claude Code 用户）**：

```bash
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

**通用方式（Codex, Cursor, Copilot, Gemini CLI 等所有支持 Agent Skills 的宿主）**：

```bash
npx skills add mvanhorn/last30days-skill -g
```

`-g` 参数表示全局安装，对所有项目可用；省略该参数则仅在当前项目范围内安装。

**使用示例**：

安装完成后，在与 AI 智能体对话时直接输入命令 `/last30days` 后跟上你想研究的话题，例如：

```
/last30days 人工智能在医疗影像诊断的最新进展
/last30days 以太坊合并后的影响
/last30days 2024年最受欢迎的编程语言
```

智能体会自动跨多个平台搜索相关信息，并返回一份包含关键发现、社区热议趋势以及来源链接的摘要报告。

## 适用场景

- **技术趋势调研**：开发者或产品经理希望快速了解某个技术框架、语言或工具在过去一个月内的社区活跃度、主要讨论点和争议话题，帮助做出技术选型决策。
- **投资与市场分析**：投资者可以查询特定行业、公司或加密货币在 Polymarket 上的预测市场走势，结合 Reddit 和 X 上的社区情绪，获得更立体的判断依据。
- **内容创作参考**：博主、视频创作者或记者需要为选题寻找素材时，可以一键获取各大平台上的热门讨论、高赞观点和争议焦点，快速把握话题脉络。
- **学术与深入研究**：研究人员在正式系统综述之前，先利用 /last30days 快速了解领域内近期的社区动态、新兴观点和实证讨论，高效锁定关键文献或讨论线程。

## 项目亮点

与传统的搜索结果聚合工具或专业搜索引擎（如 Feedly、Google News）相比，/last30days 的核心差异化优势在于：**评分信号源自真实社区行为，而非算法或编辑**。它直接引用 Reddit 的 upvote 数（代表社区赞同）、X 的 like 数（代表个人认可）、YouTube 的观看数（代表传播广度）以及 Polymarket 的流动金额（代表真实金钱下注者的判断），这些信号比单一的搜索引擎排名更能反映真实世界中人们关注和认可的信息。同时，AI 生成的摘要不仅整理信息，更强调“有据可依”——每一条结论都附有原始来源链接，方便用户追溯验证。此外，项目支持零配置快速上手，并且适配超过50种 AI 宿主环境，无需学习多种不同的配置方式。
