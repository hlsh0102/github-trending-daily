📅 开源日报 | GitHub Trending TOP10

1️⃣ Hermes Agent
NousResearch 出品，自改进型 AI 代理。内置持续学习循环，记忆交互、生成技能，还能在 5 美元 VPS 上运行。面向需要个性化 AI 助手的开发者。

2️⃣ Headroom
上下文压缩层，专为 AI 代理设计。将工具输出、日志、RAG 分块压缩 60-95%，同时保留答案精度，大幅降本提速。

3️⃣ CopilotKit
前端 AI 代理开发工具集，支持 React、Vue、Angular。能动态生成 UI、共享状态、实现人机协同工作流。

4️⃣ Open Notebook
开源的 Notebook LM 替代品，注重隐私与自部署。支持多模态内容导入、AI 分析，数据完全可控。

5️⃣ ECC
AI 编码助手优化系统。为 Claude Code、Cursor 等代理注入技能、记忆与安全机制，实现跨工具协同，提升编码效率。

6️⃣ Agent Reach
开源 CLI 工具，让 AI 代理无需 API 即能访问 Twitter、Bilibili、小红书等平台内容，统一接口，零费用。

7️⃣ Cosmos
NVIDIA 的物理世界模型平台，预训练模型+数据集。支持视频生成、物理推理，加速机器人、自动驾驶研发。

8️⃣ MiroFish
多智能体预测引擎。自动构建平行数字世界，数千智能体自由交互，模拟社会演化，用于预测事件走向。

9️⃣ last30days
AI 技能，聚合 Reddit、X、YouTube、Hacker News 多平台信息，按社区信号排序，生成 30 天热点摘要报告。

🔟 PaddleOCR
百度开源 OCR 工具，PDF/图片转 JSON/Markdown，结构直接喂给大模型。支持 100+ 语言，表格公式识别业界领先。
