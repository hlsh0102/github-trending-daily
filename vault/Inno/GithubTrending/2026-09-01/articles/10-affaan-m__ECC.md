## 项目概述

ECC（Enhanced Claude Code）是一个面向 AI 编程代理（Agent）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编码工具提供统一的运行时增强层。该项目将 AI 代理视为一个完整的操作系统，通过注入技能（Skills）、强化本能（Instincts）、管理记忆（Memory）、强化安全策略（Security）以及推动研究优先的开发模式，显著提升代理在复杂软件开发任务中的表现。

ECC 解决了当前 AI 编程工具普遍存在的几个核心问题：代理缺乏长期记忆导致上下文断裂、技能库分散难以统一管理、安全策略薄弱容易产生误操作、以及对新型研究方法的支持不足。通过一套标准化的增强机制，ECC 让开发者和团队能够在多个 AI 编码工具之间保持一致的行为模式和策略配置，无需为每个工具单独定制。

项目面向的目标用户包括：依赖 AI 辅助编程的专业开发者、希望在团队中推广 AI 编码最佳实践的工程管理者、以及关注 AI 代理安全性和可靠性的技术研究者。无论你使用的是 Claude Code 还是 Cursor，ECC 都能提供一致的增强体验。

## 核心功能

- **统一技能库管理**：支持跨多种 AI 编码工具加载和共享技能包，包括代码审查、测试生成、重构建议等常用能力，避免重复配置。
- **本能行为优化**：通过可配置的规则集，调整代理在代码导航、文件修改、错误修复等场景中的默认行为模式，使其更符合个人或团队的工作习惯。
- **持久化记忆系统**：为代理提供跨会话的上下文记忆能力，包括项目结构记忆、代码风格偏好、常见问题解决方案等，减少重复性提问和错误。
- **安全策略框架**：内置多层安全机制，包括敏感操作确认、文件修改范围控制、命令执行白名单等，降低代理误操作导致的代码损坏或数据泄露风险。
- **研究优先模式**：支持快速接入最新的 AI 代理研究方法和提示词工程技巧，保持代理使用前沿技术，同时允许用户自定义实验性配置。
- **多工具兼容层**：提供统一的配置接口，一次配置即可在 Claude Code、Codex、Opencode、Cursor 等多个环境中生效，极大简化了工具切换的成本。

## 技术架构

ECC 采用模块化插件架构，核心是一个轻量级的运行时调度器，负责在不同 AI 编码工具之间转发和适配指令。项目基于 JavaScript 构建，利用 Node.js 的跨平台能力，确保在 macOS、Windows 和 Linux 上都能稳定运行。

架构设计中，ECC 将增强能力划分为四个主要层级：**技能层**（管理具体的编码能力）、**记忆层**（处理会话持久化和上下文检索）、**安全层**（实施策略检查和风险评估）以及**适配层**（对接不同的 AI 工具 API）。各层之间通过事件驱动机制通信，确保低延迟响应，同时保持插件间的松耦合。

值得注意的是，ECC 采用声明式配置格式（JSON/YAML）来描述技能和安全策略，用户无需编写代码即可定制代理行为。对于高级用户，项目也提供了 JavaScript API，允许编写自定义插件来扩展功能。这种双层设计既满足了普通用户的易用性需求，又为技术用户提供了深度定制空间。

## 安装与使用

**安装步骤**（以 npm 全局安装为例）：

```bash
# 全局安装 ECC 命令行工具
npm install -g @affaan-m/ecc

# 初始化项目配置
ecc init --project my-agent-project

# 将 ECC 集成到当前 AI 工具（以 Claude Code 为例）
ecc setup --tool claude-code
```

**最小可用示例**：创建 `ecc.config.yaml` 配置文件：

```yaml
tools:
  - claude-code
  - cursor

skills:
  - code-review
  - test-generation

security:
  confirm-before-edit: true
  block-commands:
    - "rm -rf"

memory:
  enabled: true
  persist-path: .ecc/memory.json
```

配置完成后，启动你的 AI 编码工具，ECC 会自动加载增强层。你可以通过 `ecc status` 查看当前启用的技能和安全策略，使用 `ecc skills add <skill-name>` 添加新技能，或通过 `ecc memory clear` 清除代理的会话记忆。

## 适用场景

- **大型代码库维护**：在拥有数十万行代码的复杂项目中，ECC 的持久化记忆系统帮助 AI 代理记住模块间依赖关系和设计决策，显著减少理解代码的反复试探。
- **团队协作开发**：通过统一的技能和安全策略配置，确保团队中的每个成员在使用 AI 代理时遵循相同的行为规范，提升代码风格一致性和安全性。
- **安全敏感环境**：对于金融、医疗等合规要求严格的行业，ECC 的安全框架提供了细粒度的操作审批机制，有效防止 AI 代理执行危险命令或访问敏感文件。
- **研究与实验**：研究人员和资深开发者可以利用 ECC 的研究优先模式，快速验证最新的提示词技术或代理行为调整，无需修改底层工具代码。

## 项目亮点

ECC 的差异化优势在于其**工具无关性**和**全生命周期覆盖**。与单一工具的插件系统不同，ECC 提供的是跨工具的统一增强层，这意味着你在 Cursor 中积累的技能和安全配置可以无缝迁移到 Codex 或 Opencode 上，避免了平台锁定。

另一个显著亮点是**记忆系统的设计**。ECC 不仅存储简单的键值对，还维护结构化的项目知识图谱，支持语义化检索，让代理能够主动调取与当前任务相关的历史上下文，而非每次从零开始。

此外，ECC 对**安全性的重视程度**远超一般同类工具。它将安全策略作为一等公民，提供可视化配置界面（通过 CLI 交互式命令）和实时风险日志，让用户对代理行为有完全的控制和可审计性。这种设计对于企业级采用尤为重要。
