## 项目概述

reverse-skill 是一个面向网络安全从业者的 AI 技能路由与工具链自举包，旨在解决安全研究过程中“工具分散、经验难以沉淀、AI 辅助效率低”的核心痛点。该项目由 zhaoxuya520 开发，以 PowerShell 为主要实现语言，通过 AI 驱动的自动路由机制，将逆向工程、渗透测试、安全研究等任务智能分发到对应的技能模块和工具链中。

项目主要服务三类用户：一是从事二进制逆向与漏洞分析的安全研究员，二是进行授权渗透测试的红队成员，三是希望将 AI 编程助手（如 Claude Code、Cursor、Cline）应用于安全场景的技术爱好者。它本质上是一套“安全技能操作系统”——让 AI 客户端能够理解安全任务的上下文，自动加载合适的工具链，并在执行过程中不断积累经验，形成可持续进化的知识体系。

## 核心功能

- **AI 自动路由**：基于任务描述和上下文，自动判断当前安全任务类型（逆向、渗透、漏洞研究等），并将其路由至最合适的技能模块，无需人工干预。
- **按需工具链自举**：当识别到特定任务时，自动检测并引导安装所需的逆向/渗透工具链，包括反汇编器、调试器、网络扫描器、漏洞利用框架等，实现“即用即装”。
- **自进化经验库**：每一次成功或失败的操作都会被记录、结构化并沉淀到本地知识库中，随着使用次数增加，AI 的决策质量和操作建议会持续优化。
- **多客户端兼容**：支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端，通过标准化的接口协议与各客户端无缝集成。
- **任务上下文感知**：能够读取当前工作目录、项目文件结构、历史操作日志等上下文信息，为 AI 提供更精准的安全分析决策支持。
- **安全边界约束**：内置合规检查机制，默认仅允许授权范围内的测试行为，避免误用或违规操作。

## 技术架构

reverse-skill 采用分层模块化架构设计。底层是 **技能路由引擎**，使用 PowerShell 实现了一套轻量级的规则引擎与环境探测机制，能够识别当前 AI 客户端类型、操作系统平台以及可用的安全工具链状态。中间层是**技能包仓库**，以 JSON/YAML 格式定义了各种安全任务的执行模板、工具调用序列和参数规范，便于扩展和定制。顶层则是**经验积累层**，通过日志分析、模式识别函数将操作历史和结果反馈转化为可查询的经验记录。

项目采用“配置即代码”的设计理念，所有路由规则、工具链定义和经验存储都是纯文本文件，方便用户通过 Git 进行版本管理和团队协作。同时，它利用 PowerShell 的脚本能力实现了跨平台支持（Windows/Linux/macOS），并通过符号链接或环境变量的方式集成到主流 AI 客户端的插件体系中。

## 安装与使用

安装 reverse-skill 非常简单，只需在终端中执行以下命令：

```powershell
git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill
.\install.ps1
```

安装脚本会自动检测当前环境中的 AI 客户端（Claude Code、Cursor 等）并将其注册为可用技能包。对于 Kiro 和 Cline 等客户端，需要在对应配置中启用外部技能目录。

最小使用示例（以 Claude Code 为例）：

1. 安装完成后，启动 Claude Code 并在项目根目录执行 `/skills list` 确认 reverse-skill 已加载。
2. 当遇到逆向分析任务时，输入自然语言描述，例如：“分析这个 ELF 文件的 main 函数流程”，AI 会自动触发路由引擎，加载对应的反汇编工具链并执行分析。
3. 如需手动指定技能，可输入 `/skill router --task binary-reverse --file target.elf` 强制路由。

## 适用场景

- **二进制逆向分析**：在 CTF 比赛、恶意软件分析或固件漏洞挖掘中，快速搭建 Ghidra、Radare2、x64dbg 等工具组合，并通过 AI 辅助生成反编译流程和分析思路。
- **授权渗透测试**：在获得授权的前提下，利用 AI 路由自动调用 nmap、Burp Suite、Metasploit 等工具，并基于经验库生成更精准的测试策略。
- **安全教学与研究**：作为教学辅助工具，帮助学生理解不同安全工具的使用场景和配合方式，同时积累个人的研究心得与笔记。
- **红蓝对抗演练**：在攻防演练中快速切换任务模式，AI 根据攻击面自动推荐后续路径，并记录每一步操作以便复盘。

## 项目亮点

与同类安全工具集或 AI 辅助方案相比，reverse-skill 最大的差异化优势在于其 **“路由 + 自举 + 进化”的三合一设计**。多数现有方案只是简单地将工具列表告诉 AI，而本项目通过路由引擎实现了任务意图与工具链的精准匹配，避免了“工具调用错乱”的常见问题。其次，按需自举机制降低了环境配置门槛，用户无需预先安装庞大的安全工具集合，AI 会在需要时智能引导安装，节省磁盘空间和安装时间。最后，自进化知识库使项目具备长期使用价值——随着个人或团队的安全经验不断注入，AI 输出质量会呈螺旋式上升，真正实现了“越用越聪明”的效果。此外，项目严格遵守授权操作边界，内置合规检查，保障使用的合法性。
