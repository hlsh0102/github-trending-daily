## 项目概述

Archify 是一个面向 AI 编程代理的 Node.js 渲染与验证系统，旨在将代码库或系统描述直接转化为精美、可验证的交互式系统图。它解决了开发者在架构设计、代码审查和文档编写中常见的痛点——手动绘制图表耗时费力、图表与实际代码脱节、多人在协作时难以维护一致性。通过让 Cursor、Claude Code、Codex CLI 和 OpenCode 等 AI 代理在对话中直接生成结构化的图表数据，Archify 将图表生成从手工劳动转变为自动化流程，目标用户是依赖 AI 辅助开发的软件工程师、架构师和技术团队。

## 核心功能

- **五种图表类型**：支持架构图、工作流图、时序图、数据流图和生命周期图，覆盖系统设计的绝大部分需求，每种类型均有针对性的布局与渲染逻辑。
- **四套预设与主题**：内置四套视觉预设，支持深色/浅色主题切换，并集成品牌标识，让图表可以直接用于对外演示或文档发布。
- **变更对比**：支持将两个验证过的图表快照进行 Before / Delta / After 三方对比，精确到节点和连线的增、删、改、移动与重路由，帮助团队在合并请求前清晰评估架构变更影响。
- **交互式探索**：图表中的每个节点均可搜索，可溯源至修订版本验证过的源代码，支持上/下游影响范围追踪、角色对比以及引导式讲解，所有交互都基于真实拓扑，不会凭空捏造。
- **多格式导出**：一张自包含的 HTML 文件即可承担所有展示需求，同时支持导出为 PNG、SVG、WebM 视频，以及 1200×630 像素的分享卡片，适用于会议、文档和社交媒体传播。
- **确定性校验**：基于类型化的 JSON 中间表示（IR）和确定性检查规则，保证同一输入必然产生相同输出，杜绝随机变动带来的不信任感。

## 技术架构

Archify 采用“解析—编译—渲染”的三层架构设计。代理端负责将代码库或用户描述解析为类型化的 JSON IR，这是整个系统的中间语言，定义了节点、连线、布局、样式等所有图元的结构化数据。随后，Archify 的编译层使用确定性算法将 JSON IR 编译为 HTML/SVG 结构，确保输出的可预测性和一致性。最后，渲染层在浏览器中呈现带有交互功能的最终图表。

这种设计带来了几个关键优势。首先，JSON IR 使得图表数据可以被任何支持 JSON 的工具链复用和验证，不依赖特定的前端框架。其次，确定性编译意味着相同的输入永远产生相同的外观，这在自动化审查和团队协作中至关重要。此外，单文件 HTML 输出将所有样式、脚本和数据打包在一起，无需外部资源即可离线打开和分享，兼顾了便携性和安全性。Archify 本身以 Node.js 实现，可以作为命令行工具或嵌入到代理的插件系统中使用。

## 安装与使用

安装 Archify 相对直接，可以通过 npm 全局安装或作为项目依赖引入：

```bash
npm install -g archify
# 或者
npm install --save-dev archify
```

最小使用示例如下。假设 `agent` 已生成一个符合 JSON IR 规范的文件 `architecture.json`，可以使用 CLI 编译输出 HTML：

```bash
archify build architecture.json -o output.html --theme dark --preset cloud
```

若希望在代理对话中直接生成，可以在 Cursor 或 Claude Code 的配置中启用 Archify 技能，代理将自动调用其渲染接口：

```
用户：请绘制微服务架构图
代理：{调用 archify，传入生成的结构化数据}
```

输出文件是自包含的 HTML，直接双击即可在浏览器中查看和交互。更多选项（如导出 PNG/WebM、生成对比图）可通过 `archify --help` 查看。

## 适用场景

- **架构评审与合并请求**：在代码合入前，通过 Before / Delta / After 对比快速识别架构变动，自动生成变更报告嵌入 PR 描述。
- **技术文档与知识库**：将系统设计、工作流说明生成可交互的图，嵌入 Markdown 文档或内部 Wiki，读者可以直接搜索节点并溯源代码。
- **系统演示与汇报**：利用深色主题、品牌标识和优雅的动效，为客户或管理层做架构展示，导出分享卡片用于公司通讯软件传播。
- **AI 辅助开发工作流**：在 AI 编程代理中实时生成模块关系图，帮助开发者理解大模型生成代码的上下文，减少“黑盒感”。

## 项目亮点

与 Mermaid、PlantUML 等传统图表工具相比，Archify 的差异化优势非常明显。首先，它专为 AI 代理协作而生，通过类型化 JSON IR 而非文本 DSL 描述图表，避免了自然语言转义和语法错误。其次，确定性校验让图表可审计，而传统工具往往输出随机布局，难以版本化管理。第三，交互和溯源能力是质变——读者不仅能看，还能搜索节点、打开原始代码，这大大提升了图表的可信度。最后，单文件自包含输出和丰富的导出格式，让分发与分享的摩擦几乎降为零。这些特性使其在 GitHub 上获得超过 4 万星标，成为 AI 驱动开发工具链中的热门选择。
