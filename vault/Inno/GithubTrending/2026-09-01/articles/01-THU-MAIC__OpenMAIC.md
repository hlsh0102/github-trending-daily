## 项目概述

OpenMAIC（Open Multi-Agent Interactive Classroom）是由清华大学 MAIC 团队开发的开源多智能体交互课堂平台。该项目旨在将传统课堂的沉浸式学习体验与多智能体 AI 技术相结合，用户只需一次点击，即可进入一个由多个 AI 智能体共同参与的互动学习环境。项目采用 TypeScript 编写，以 MIT 许可证开源，目前已在 GitHub 上获得超过 2.8 万 Star，热度持续攀升。

OpenMAIC 解决了传统在线学习平台互动性不足、学习体验单一的问题。在传统在线课堂中，学习者通常只能被动观看视频或阅读文本，缺乏实时互动和个性化反馈。而 OpenMAIC 通过构建一个由多个具备不同角色和能力的 AI 智能体组成的虚拟课堂，让学习者能够与智能体进行多轮对话、协作讨论和角色扮演，从而获得接近真实课堂的沉浸式学习体验。

项目的目标用户包括：希望利用 AI 进行个性化学习的学生、需要构建交互式教学内容的教育工作者、以及探索多智能体系统应用场景的研究人员和开发者。

## 核心功能

- **一键部署**：通过 Vercel 等平台可实现一键部署，无需复杂的服务器配置，快速搭建属于自己的多智能体课堂
- **多智能体协作**：支持配置多个 AI 智能体，每个智能体可拥有独立的角色设定、知识领域和对话风格，模拟真实课堂中的教师、助教和同学
- **多 LLM 提供商支持**：兼容 OpenAI、Anthropic 等多种主流大语言模型提供商，用户可根据需求自由选择或混合使用不同模型
- **交互式学习体验**：学习者可以同时与多个智能体进行对话，获得多样化的视角和反馈，支持多轮深入讨论
- **可定制化配置**：用户可通过环境变量和配置文件灵活调整智能体的数量、角色、系统提示词等核心参数
- **现代 Web 界面**：基于 TypeScript 构建的响应式前端界面，提供流畅的交互体验

## 技术架构

OpenMAIC 采用了现代前端技术栈，核心架构围绕多智能体协调机制展开。项目底层设计了一套智能体通信协议，使得不同智能体之间可以互相传递上下文信息，并根据对话历史动态调整各自的回应策略。

在技术选型方面，项目使用 TypeScript 作为主要开发语言，保证了类型安全性和代码可维护性。前后端通信通过标准化的 RESTful API 完成，同时针对流式输出场景实现了基于 Server-Sent Events（SSE）的实时响应机制，确保对话内容能够逐字呈现，提升交互体验。

项目的核心亮点在于其灵活的智能体编排引擎。该引擎支持将复杂的课堂对话流程分解为多个子任务，并分配给不同的智能体并行处理，最终由协调器汇总结果。同时，OpenMAIC 设计了统一的大模型提供商抽象层，通过适配器模式屏蔽了不同 LLM API 的差异，使得切换或新增模型提供商只需增加相应的适配器实现。

## 安装与使用

OpenMAIC 的安装部署过程非常简便，以下是基于 Docker 和 Vercel 的两种常见方式：

**方式一：本机 Docker 部署**

```bash
# 克隆仓库
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC

# 配置环境变量
cp .env.example .env.local
# 编辑 .env.local，填入至少一个 LLM 提供商的 API Key

# 使用 Docker 启动
docker-compose up -d
```

**方式二：Vercel 一键部署**

访问项目 README 中的 Vercel 部署链接，点击 "Deploy" 按钮，按照提示配置环境变量即可完成部署。部署过程中需配置至少一个 LLM 提供商的 API Key，所有提供商均为可选项，可根据实际需求填写。

**最小可用示例**：部署完成后，打开浏览器访问部署地址，进入课堂界面，选择一个预设的课堂场景（如"人工智能概论"），即可开始与多个智能体进行互动学习。

## 适用场景

- **个性化自学**：学习者可以根据自己的学习节奏，随时向课堂中的多个智能体提问，获得不同角度的解答和知识补充
- **交互式教学演示**：教师可以将 OpenMAIC 嵌入课程网站，为学生提供课外观摩和练习的互动环境
- **多视角讨论模拟**：在课程设计中模拟不同立场或学科背景的专家进行辩论，帮助学习者理解复杂议题的多面性
- **Agent 应用开发教学**：作为研究和学习多智能体系统协作机制的实验平台，开发者可以在此观察和调试多智能体的协同行为

## 项目亮点

与同类项目相比，OpenMAIC 具有以下差异化优势：

- **学术背景深厚**：项目源自清华大学 MAIC 团队，相关论文已发表于 JCST 期刊，具备扎实的理论基础
- **部署极简**：提供多种一键部署方案，无需深入理解底层实现即可快速启动，大幅降低了多智能体应用的上手门槛
- **社区热度极高**：在短时间内获得超过 2.8 万 Star，且日增 Star 数量持续保持在较高水平，表明社区认可度和活跃度非常高
- **文档完善**：提供中英双语的使用指南和体验教程，覆盖不同语言用户群体的需求
