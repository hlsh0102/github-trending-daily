## 项目概述

Scientific Agent Skills 是一个开源的科学智能体技能库，旨在将任何 AI 代理（Agent）转变为具备科学研发能力的“AI 科学家”。该项目由 K-Dense AI 团队开发，目前已被全球超过 190,000 名科研工作者使用，是当前规模最大的科学 Agent Skills 库。

该项目的核心价值在于将经过验证的科学方法论、专业数据库查询能力和实验设计流程，以标准化“技能”（Skills）的形式封装起来，让用户无需编写复杂提示词或学习特定领域 API，即可让通用 AI 代理执行专业的科学研究任务。项目采用 MIT 开源协议，兼容 Cursor、Claude Code、Codex、Pi、Antigravity 等主流 AI 编程与对话工具，并遵循开放的 Agent Skills 标准（agentskills.io）。

## 核心功能

- **165 个开箱即用的科学技能**：涵盖实验设计、数据统计分析、文献综述、假设生成、结果解读等科研全流程操作，每个技能均经过验证并附带使用说明。
- **100+ 科学数据库集成**：内置对生物学、化学、医学和药物发现领域主要公开数据库的查询接口，包括蛋白质结构、化合物性质、临床试验、基因表达等数据源。
- **多模型与工具兼容**：支持 Cursor、Claude Code、Codex、Pi、Antigravity 等主流代理，并遵循通用 Agent Skills 标准，方便迁移至支持该标准的其他工具。
- **K-Dense BYOK 桌面套件**：提供免费的本地 AI 协同学者程序，支持自带 API 密钥，可在离线环境下访问全部技能和数据库，可选云扩展用于重型计算。
- **持续验证与安全更新**：项目通过自动化工作流（skill-tests、security-scan）对技能进行持续测试和安全性审查，确保技能质量与数据安全。

## 技术架构

Scientific Agent Skills 基于开放且可移植的“技能”抽象层构建。每个技能本质上是一个结构化的指令包，包含明确的输入输出定义、执行步骤和调用的外部资源（如数据库 API）。这种设计使得技能可以与代理的主模型解耦，任何支持 Agent Skills 标准的工具都能加载并执行。

项目采用 Python 作为主要开发语言，利用 `pyproject.toml` 进行依赖管理与打包。技能库的组织方式按科学领域（生物、化学、医学、药物发现）分类，每个领域下包含独立的技能模块，便于用户按需引入。同时，项目采用模块化设计，允许社区贡献新技能，并通过内建的测试框架（skill-tests）对新增技能进行自动验证。

与 K-Dense BYOK 桌面应用的集成展示了其架构的可扩展性——BYOK 作为本地客户端，通过 API 与远程大模型通信，同时利用本地的技能库和数据库适配器，实现数据隐私与云计算的按需切换。

## 安装与使用

### 基本安装

1. 克隆仓库到本地：
```bash
git clone https://github.com/K-Dense-AI/scientific-agent-skills.git
cd scientific-agent-skills
```

2. 安装依赖（建议使用虚拟环境）：
```bash
pip install -e .
```

3. 在你的 AI 代理（如 Claude Code、Cursor）中，将技能目录路径配置到代理的技能加载路径中。

### 最小使用示例

以 Cursor 为例，在项目配置中指定技能目录后，即可在对话中直接调用技能。例如，在提示词中引用：

```
使用 `fetch_clinical_trials` 技能查找针对非小细胞肺癌的最新三期临床试验数据，并按入组人数排序。
```

代理会自动识别并执行相应技能，返回格式化的查询结果。若使用 K-Dense BYOK，可直接下载桌面应用，配置 API 密钥后即获得完整的科研工作台，所有技能和数据库均通过图形界面可视化调用。

## 适用场景

- **药物研发初期调研**：科研人员在项目启动阶段，可利用技能库快速检索化合物性质、靶点关联和已有临床试验数据，大幅缩短文献调研时间。
- **跨学科实验设计**：化学背景的研究者需要进行基因表达分析时，可直接使用库中生物信息学技能，无需掌握专业分析工具。
- **学术写作辅助**：研究人员在撰写论文时，利用数据统计和可视化技能完成结果分析，或借助文献综述技能快速生成相关研究的背景概述。
- **AI 代理能力扩展**：开发者为自建的 AI 应用集成科学计算与数据库查询能力时，可基于该技能库进行二次开发，快速添加垂直领域的专业功能。

## 项目亮点

- **规模与验证优势**：作为目前最大的科学技能库，提供 165 个技能，且均通过自动化测试验证，相比同类项目覆盖更广、可靠性更高。
- **标准驱动兼容性**：不是绑定单一模型的封闭插件，而是遵循开放标准，用户可自由换用不同 AI 代理，避免技术锁定。
- **本地优先与隐私保护**：通过 K-Dense BYOK 实现完全的本地运行，科研数据不出设备，同时保留云扩展选项，兼顾安全与性能。
- **活跃的社区与采纳度**：超过 19 万用户的使用量反映出项目的实际有效性，而持续的社交更新（Twitter、LinkedIn、Reddit）和演示视频降低了新手的学习门槛。
