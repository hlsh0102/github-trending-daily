## 项目概述

Hermes Agent 是由 Nous Research 打造的一款自我进化的 AI 智能体。与传统 AI 助手不同，Hermes Agent 内置了持续学习循环：它从每次交互中提炼技能、在使用过程中不断改进自身、主动将有价值的知识持久化、能够检索过去的对话记录，并在多次会话中逐渐建立起对你个人模型的深度理解。它的目标用户是那些不仅需要一个 AI 聊天工具，更需要一个能随时间推移不断适应和成长的智能伙伴的开发者、研究者以及技术爱好者。

## 核心功能

- **自学习循环**：Hermes Agent 的核心竞争力在于它拥有一个内置的学习机制。它能够从每一次对话和任务执行中自动创建和更新“技能”，这些技能可以被复用在未来更复杂的工作流中。
- **跨会话记忆与模型构建**：它不仅仅记住你说过的话，更会通过分析你的偏好、习惯和反复出现的需求，主动构建一个不断深化的用户模型。这意味着随着时间推移，它的回应会越来越贴合你的个人风格。
- **多平台访问**：Agent 不绑定于你的个人电脑。你可以在云端虚拟机（VPS 或 GPU 集群）上部署它，然后通过 Telegram 等即时通讯工具随时与之交互，体验持久在线的服务。
- **模型无关架构**：你拥有完全的模型选择自由。无论是开源模型还是商业 API，只要满足接口规范，Hermes Agent 即可接入。你可以轻松切换基础模型来测试不同的效果或平衡成本。
- **轻量级部署**：设计上极尽弹性。它可以在每月仅需 5 美元的虚拟专用服务器（VPS）上流畅运行，也可以利用 GPU 集群处理复杂推理任务，甚至在完全空闲时的 serverless 无服务器架构下，成本几乎为零。

## 技术架构

Hermes Agent 采用模块化、基于事件的架构设计。其核心引擎由一个轻量级的 Python 运行时驱动，内部实现了以下几个关键模块：

1.  **技能生成与存储引擎**：该模块负责在每次任务后分析成功或失败的经验，抽象出可复用的步骤和逻辑片段，并将其编译为结构化的“技能”。技能以可插拔的方式存储在本地或远程数据库中。
2.  **记忆与上下文管理系统**：通过向量化嵌入和高效的检索机制，Agent 能够从海量的历史对话中快速定位相关信息。系统维护一个“渐近用户模型”，随着交互次数的增加，模型精度呈指数级提升。
3.  **多 Agent 协调层**：虽然作为单个 Agent 运行，但其内部架构允许通过任务分解，将复杂问题分散给不同的子模块处理（例如，一个模块负责检索，另一个负责生成）。
4.  **通用模型适配器**：设计了一套统一的 API 抽象层，使得与 Hugging Face Transformers、OpenAI API、vLLM 等主流推理框架的集成变得无缝。切换后端模型只需一行配置。

架构的核心设计哲学是“自省”——Agent 会定期对自己的行为日志进行反思（自我提示），识别出可以优化的模式，并自动触发相应的技能更新或记忆整理。

## 安装与使用

安装 Hermes Agent 非常直接。推荐使用 Docker 以获得最佳环境一致性：

**1. 克隆仓库并进入目录**
```bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
```

**2. 使用 Docker Compose 启动（推荐）**
```bash
docker-compose up -d
```

**3. 或使用 pip 安装**
确保 Python 3.10+ 环境准备就绪：
```bash
pip install hermes-agent
# 启动服务
hermes-agent serve
```

**4. 最小交互示例**

启动后，可以通过 HTTP API 或集成的 Telegram Bot 进行对话。一个最简单的 Python 客户端调用示例：

```python
import requests

response = requests.post(
    "http://localhost:8000/v1/chat",
    json={
        "message": "你好，请帮我回忆一下我昨天提到的那个项目管理计划。",
        "user_id": "my-user-id"
    }
)
print(response.json()["response"])
```

运行时，Hermes Agent 会自动连接你配置的模型端点，并开始建立记忆库。

## 适用场景

- **个人知识库与持续助手**：作为日常研究或工作中永不遗忘的跨会话助手。它会记住你读过的论文、写过的代码片段、以及你的个人偏好，成为你的“第二大脑”。
- **自动化工作流引擎**：部署在云端，通过监听 Telegram 消息或 webhook，自动执行复杂的多步骤任务，如数据抓取、报告生成、代码审查等。
- **智能客服与用户支持**：由于内置用户模型，可以为企业提供高度个性化的支持服务。Agent 能根据用户的历史互动记录，迅速切入问题核心，减少重复沟通。
- **AI 代理研究与实验**：对于研究 AI 自我改进、持续学习和多 Agent 协调的开发者，这是一个理想的实验平台，其日志和反思机制提供了极佳的可视化。

## 项目亮点

- **真正的自我进化**：市面上大多数 AI Agent 在部署后能力是静态的，而 Hermes Agent 的核心设计就是动态成长。它“反省”并“学习”，这使其长期使用价值远超普通静态 Agent。
- **极低的拥有成本**：支持从 $5/月的 VPS 到服务器集群的无缝部署，彻底打破了高性能 AI 智能体的使用门槛。主动优化的 serverless 支持意味着闲置零成本。
- **高度灵活的模型自主权**：不锁定任何厂商或模型。你可以基于自己的偏好和隐私需求，自由切换本地运行的开源模型与云端商业模型。
- **无缝的多平台体验**：Agent 运行在服务器端，用户在 Telegram、Web 或 CLI 之间随意切换，对话和历史完全同步，体验流畅统一。
