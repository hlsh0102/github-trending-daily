今日GitHub热搜 Top10 来了，开源项目一手掌握 👇

1️⃣ Headroom 🔥
Python 项目，专治上下文太长、Token 太贵。能把发给 LLM 的工具输出、日志、RAG 结果压缩 60%-95%，本地运行，数据安全。AI Agent 开发者必看。

2️⃣ Hermes Agent
Nous Research 出品，能自我进化的 AI 代理。内置学习循环，从对话中创建技能，还能记忆你的偏好，越用越懂你。低至 5 美元 VPS 就能跑。

3️⃣ ECC
专为 AI 编程助手打造的性能优化系统，支持 Claude Code、Cursor 等。提供技能管理、本能响应、记忆优化、安全扫描，帮你提升编码效率。

4️⃣ PaddleOCR
百度飞桨的 OCR 神器，8万+ Star。PDF/图片转结构化 JSON 或 Markdown，内置视觉语言模型，识别文字、表格、公式准确率 96.3%+，支持 100+ 语言。

5️⃣ Spec Kit
GitHub 官方出品，帮团队实施“规范驱动开发”。用 Markdown/YAML 写规范，AI 代理按规范编码，还支持“规范即测试”，减少返工。

6️⃣ NVIDIA Cosmos
英伟达的物理 AI 平台。提供预训练的世界模型和数据集，能根据文本生成物理场景视频，或理解物理交互。机器人、自动驾驶开发者重点关注。

7️⃣ Open Notebook
开源的 Notebook LM 替代品，注重隐私。支持 PDF、网页等多格式文档，基于 LLM 做智能问答、自动生成摘要笔记，数据自己掌控。

8️⃣ Open-LLM-VTuber
开源跨平台，用语音跟任意 LLM 对话，还有 Live2D 虚拟形象实时动嘴眨眼。支持语音打断，全本地运行。二次元爱好者狂喜。

9️⃣ Coding Interview University
经典的 CS 自学计划，35万 Star。从算法到系统设计全覆盖，资源都是免费优质课程。求职大厂、巩固基础的开发者必修课。

🔟 Copilot SDK
GitHub 官方 SDK，帮你把 Copilot 的代理工作流（规划、调工具、编辑文件）直接集成到你自己的应用里。覆盖 Python/TS/Go/.NET/Java/Rust。
