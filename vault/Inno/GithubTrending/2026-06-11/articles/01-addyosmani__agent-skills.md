## 项目概述

Agent Skills 是一个为 AI 编码代理提供生产级工程技能的开源项目。它解决的核心问题是：AI 代理在辅助软件开发时，往往缺乏持续遵循成熟工程实践的能力，容易产出不规范、未测试或难以维护的代码。该项目将高级工程师在构建软件时使用的工作流程、质量门禁和最佳实践编码为可执行的“技能”，使 AI 代理能够在开发全周期内一致地应用这些实践。目标用户包括使用 AI 辅助编程的开发者、希望标准化团队开发流程的工程管理者，以及构建定制化 AI 编码工具的技术团队。

## 核心功能

- **生命周期命令映射**：提供 7 个斜杠命令（`/spec`, `/plan`, `/build`, `/test`, `/review`, `/code-simplify`, `/ship`），分别对应从需求定义到生产发布的完整开发阶段，每个命令自动激活对应阶段所需的技能集合。
- **自动规划与实现**：`/build auto` 命令能够在规约文件存在后，自动生成实现计划并依次执行构建，减少人工介入步骤。
- **质量门禁集成**：通过 `/review` 和 `/test` 命令内置代码审查和测试验证环节，确保每次提交都通过预设的质量标准。
- **自动化简化流程**：`/code-simplify` 命令专门用于降低代码复杂度，优先追求清晰度而非技巧性实现。
- **渐进式构建策略**：遵循“一次只构建一个切片”的原子化任务分解原则，降低单次变更风险。
- **技能可扩展性**：项目结构允许开发者自定义或扩展现有技能，以适应不同团队或项目的特定工程规范。

## 技术架构

该项目以 Shell 脚本为主要实现语言，采用轻量级、无依赖的设计思路。其架构核心是一组可调用的命令脚本，每个命令对应一个独立的技能文件夹（如 `/spec`、`/plan` 等）。这些脚本通过以下方式工作：

1. **命令触发**：用户在聊天界面或命令行中输入斜杠命令，触发对应的技能脚本。
2. **上下文感知**：脚本根据当前工作目录、已有文件（如 PRD 文档、测试文件）和 Git 仓库状态，动态调整执行逻辑。
3. **管道化流程**：命令之间通过共享文件（如规约文档、计划列表）串联，形成一个端到端的开发流水线。
4. **门禁检查点**：在 `/test`、`/review` 等环节设置检查点，如果质量不达标则阻断流程并反馈修改建议。
5. **可组合性**：用户可以通过组合多个命令（如先 `/spec` 后 `/build`）来适配不同开发场景。

该架构的显著特点是“定义即执行”——技能不再是抽象的文档，而是可直接运行的代码，确保 AI 代理能100%遵循既定的工程规范。

## 安装与使用

### 安装
1. 克隆仓库到本地：
```bash
git clone https://github.com/addyosmani/agent-skills.git
cd agent-skills
```
2. 根据需要将项目目录添加到 PATH 环境变量，或直接在 AI 编程工具的工作区中引用该目录。
3. （可选）根据团队规范自定义技能脚本。

### 最小可用示例
假设你正在开发一个新功能，按以下步骤操作：

1. **定义需求**：在 AI 代理输入 `/spec`，它会引导你描述功能需求，自动生成规范文档。
2. **规划实现**：输入 `/plan`，AI 代理会将规范拆解为原子任务，输出实施计划。
3. **构建代码**：输入 `/build`，AI 代理按计划逐一实现代码，并在每个任务完成后等待确认。
4. **测试验证**：输入 `/test`，AI 代理自动运行已有测试并提示补充缺失测试。
5. **审查与简化**：输入 `/review` 检查代码质量，输入 `/code-simplify` 优化复杂度。
6. **交付上线**：输入 `/ship`，完成最终检查后提交合并请求。

## 适用场景

- **个人开发者日常开发**：在编码过程中保持工程纪律，避免草率提交，尤其适合需要频繁切换上下文的独立开发者。
- **AI 辅助编程的团队标准化**：当团队使用多种 AI 工具（如 GitHub Copilot、Cursor）时，统一命令技能确保所有成员输出遵循相同规范。
- **新项目启动**：从零开始构建项目时，使用 `/spec` -> `/plan` -> `/build` 流程建立高质量的工程基础。
- **代码重构优化**：针对遗留代码库，使用 `/test` + `/review` + `/code-simplify` 组合渐进式改善代码健康度。

## 项目亮点

与同类项目相比，Agent Skills 的差异化优势在于：

1. **生命周期全覆盖**：不仅关注编码环节，而是覆盖从需求到交付的完整开发周期，形成闭环。
2. **可执行而非说教**：传统最佳实践指南往往只是文档，Agent Skills 将技能转化为可直接运行的命令，确保严格执行。
3. **轻量无侵入**：基于 Shell 脚本实现，几乎无运行时依赖，可轻松集成到任何 AI 编程环境。
4. **自我改进设计**：通过 `/review` 和 `/code-simplify` 形成代码质量的正向循环，项目本身也在实践中持续优化技能库。
5. **社区驱动标准**：项目以 MIT 许可开源，允许团队基于实际经验贡献和演进技能集，形成集体工程智慧。
