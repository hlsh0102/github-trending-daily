## 项目概述

MoneyPrinterTurbo 是一个基于人工智能大模型的开源工具，能够根据用户提供的视频主题或关键词，全自动完成从文案撰写、素材搜集、字幕生成到背景音乐配制的完整视频制作流程，最终输出高清短视频。该项目由 harry0703 开发并维护，目前在 GitHub 上已获得超过 8.5 万颗星标，受到内容创作者、自媒体运营者以及技术爱好者的广泛关注。

该项目主要解决了短视频制作中普遍存在的效率低下问题。传统短视频制作需要经历选题策划、文案编写、素材寻找、剪辑配音、字幕添加等多个环节，耗时且需要一定专业能力。MoneyPrinterTurbo 将这一流程压缩到“输入主题、一键生成”的极简操作中，大幅降低了视频制作的门槛。

## 核心功能

- **AI 文案自动生成**：基于用户输入的主题或关键词，调用大语言模型自动撰写匹配的短视频解说文案，支持多种内容风格和语言。
- **智能素材匹配**：根据生成的文案内容，自动搜索并选取合适的视频素材片段，无需手动逐个下载和整理。
- **自动语音合成**：支持将文案内容转换为自然的语音旁白，提供多种音色和语速选择。
- **动态字幕生成**：自动为视频添加同步字幕，支持字幕样式和位置的自定义。
- **背景音乐自动配乐**：根据视频情绪选择并自动嵌入合适的背景音乐，并支持音量自动化调节。
- **完整视频合成**：将上述所有元素（素材、语音、字幕、音乐）整合为一个高清完整视频文件，支持多种输出分辨率和格式。

## 技术架构

MoneyPrinterTurbo 采用前后端分离的架构设计。后端基于 Python 开发，主要利用大型语言模型（如 GPT 系列、Claude 等）进行文案生成与语义理解，通过图像搜索和视频素材 API 实现素材的自动匹配与下载，并集成语音合成（TTS）引擎实现旁白生成。视频合成部分依赖于 FFmpeg 等开源音视频处理工具，对素材进行剪辑、拼接与渲染。

前端提供直观的 Web 界面，用户可以通过浏览器轻松操作，无需接触任何命令行或代码。整个项目采用模块化设计，文案生成、素材拾取、语音合成、视频合成等模块可独立配置和替换，便于开发者根据自身需求进行定制或扩展。

此外，项目支持通过 API 接口调用，方便集成到其他系统或工作流中，同时提供 Docker 容器化部署方案，简化环境配置与依赖管理。

## 安装与使用

### 安装要求
- Python 3.9 及以上版本
- FFmpeg（视频处理依赖）
- 网络连接（用于调用 AI 服务和素材搜索）

### 基本安装步骤

1. **克隆仓库**
   ```bash
   git clone https://github.com/harry0703/MoneyPrinterTurbo.git
   cd MoneyPrinterTurbo
   ```

2. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

3. **配置环境变量**
   复制 `.env.example` 为 `.env` 文件，在其中填入对应的大模型 API 密钥和语音服务密钥。

4. **启动 Web 服务**
   ```bash
   python app.py
   ```

5. **使用**
   在浏览器中访问 `http://localhost:5000`，在页面的输入框中填写视频主题或关键词，点击生成按钮即可等待视频制作完成。

### 最小可用示例

在配置完成后，你可以尝试输入例如“夏季适合喝的三种清凉饮品”作为主题，系统将自动生成一段约 30-60 秒的短视频，包含文案解说、背景音乐和相关素材片段。

- **营销与广告宣传**：企业市场人员可批量生成产品介绍、活动宣传类短视频，用于社交媒体投放。
- **个人创意表达**：普通用户可将生活中的灵感或见闻快速转化为视频作品，分享至社交平台。
