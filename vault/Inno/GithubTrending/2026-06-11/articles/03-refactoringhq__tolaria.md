## 项目概述

Tolaria 是一款面向 macOS、Windows 和 Linux 的桌面应用，专注于管理 **Markdown 知识库**。它旨在帮助用户摆脱对特定知识管理平台的依赖，将笔记和知识以纯文本形式存储于本地，同时提供强大的组织与检索能力。项目的目标用户包括知识工作者、开发者、研究者以及任何希望构建“第二大脑”或团队文档库的人。Tolaria 的核心理念是“文件优先”和“Git 优先”，确保数据完全归属用户，且天然具备版本控制能力。

## 核心功能

- **Markdown 原生支持**：所有笔记均为纯 Markdown 文件，可直接用任意文本编辑器打开编辑，无需格式转换或导出步骤。
- **Git 版本控制**：每个知识库（Vault）都是一个 Git 仓库，支持分支、提交、历史回溯等标准 Git 操作，便于协作与变更追踪。
- **快速全文搜索**：基于文件系统的索引机制，支持即时搜索笔记标题和内容，即使管理上万条笔记也能保持流畅。
- **工作流集成**：提供收件箱式工作流，支持从网页、文档等来源快速捕获内容，并按自定义流程完成分类与归档。
- **跨平台支持**：统一在 macOS、Windows 和 Linux 上运行，保持一致的体验与数据格式。
- **可扩展架构**：基于 TypeScript 构建，便于开发插件或自定义功能，适配不同知识管理场景。

## 技术架构

Tolaria 采用 **Electron** 作为桌面应用框架，结合 **TypeScript** 实现前后端逻辑。其架构设计遵循模块化原则：

- **文件系统抽象层**：直接操作本地 Markdown 文件，不依赖外部数据库，确保数据持久化与可移植性。
- **Git 集成模块**：通过 Node.js 调用本地 Git 命令，实现仓库初始化、提交、拉取、推送等操作，用户可在界面内直接管理版本。
- **索引与搜索引擎**：利用文件监控（如 chokidar）实时追踪文件变动，并构建内存中的倒排索引，实现毫秒级搜索响应。
- **UI 组件体系**：基于 React 构建用户界面，支持暗色主题、分栏布局、快捷键系统，兼顾效率与美观。

这种架构的优势在于：数据完全本地化、无需云服务、且可无缝对接 DevOps 工具链。用户既可以在 Tolaria 内编辑，也可以随时切换到 VS Code 或 Obsidian 等工具进行批量操作。

## 安装与使用

### 安装步骤
1. 前往 [GitHub Releases 页面](https://github.com/refactoringhq/tolaria/releases) 下载对应系统的安装包（.dmg、.exe 或 .AppImage）。
2. 双击安装包，按提示完成安装。
3. 首次启动后，创建或选择一个本地文件夹作为知识库根目录。

### 最小可用示例
```bash
# 创建一个新知识库
mkdir my-knowledge && cd my-knowledge
git init
echo "# Hello World" > welcome.md

# 在 Tolaria 中打开该文件夹，即可开始管理笔记
```

应用启动后，你将看到文件树浏览视图和编辑面板。你可以：
- 通过快捷键 `Cmd/Ctrl + N` 创建新笔记
- 使用 `Cmd/Ctrl + P` 打开全局搜索
- 通过右键菜单或 Git 面板执行提交、推送等操作

## 适用场景

- **个人知识管理（第二大脑）**：将日常笔记、学习心得、项目复盘等以 Markdown 文件保存，利用 Git 追溯知识演化过程。
- **团队文档协作**：将公司技术文档、API 手册、流程说明文件纳入同一仓库，成员可通过 Git 分支协作编辑，避免版本冲突。
- **AI 上下文库**：存储大量结构化的纯文本语料，作为大型语言模型的本地知识库，或用于训练自定义助手的行为与记忆。
- **开发者笔记系统**：结合代码片段、调试日志、技术方案等，与代码仓库并列管理，形成统一的开发知识体系。

## 项目亮点

- **数据主权不妥协**：与多数知识管理应用不同，Tolaria 从不锁定数据。所有笔记都是标准 Markdown，你可以在任何环境下直接访问和迁移。
- **原生 Git 支持**：将版本控制无缝融入笔记管理，让知识库具备与代码库同等的可追溯性和协作能力，这是许多同类工具所缺失的。
- **轻量高效**：项目采用简洁的技术栈，不引入复杂数据库或云服务，因此占用的资源极少，即便在低配设备上也能流畅运行。
- **活跃社区与透明开发**：项目在 GitHub 上拥有超过 1.5 万颗星，作者公开分享使用工作流，社区提交的议题和 PR 响应迅速。
