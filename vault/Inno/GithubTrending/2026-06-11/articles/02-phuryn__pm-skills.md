## 项目概述

PM Skills Marketplace 是一个面向产品经理的 AI 操作技能集合，提供了超过 100 项智能技能、命令和插件，覆盖从产品发现、战略规划、执行、发布到增长的全流程。该项目旨在将经过验证的产品管理框架嵌入到 AI 工作流中，帮助产品经理在实际工作中直接应用 Teresa Torres、Marty Cagan 和 Alberto Savoia 等专家的方法论。目标用户是使用 AI 助手（如 Claude Code 和 Cowork）的产品经理、创业者以及希望提升决策质量的团队成员。

## 核心功能

- **结构化技能库**：提供 68 个 PM 技能，每个技能都编码了经过验证的产品管理框架，如发现、假设映射、优先级排序和战略制定。
- **链式工作流**：内置 42 个链式工作流，能够跨 9 个插件自动组合多个技能，实现从想法到发布的端到端流程。
- **智能命令系统**：支持 `/discover`、`/strategy`、`/write-prd`、`/plan-launch`、`/north-star` 等命令，用户可快速启动特定产品管理任务。
- **多平台兼容**：专为 Claude Code 和 Cowork 设计，同时兼容其他主流 AI 助手。
- **自动化执行**：技能可自动加载，在相关上下文中主动提供分析框架和指导，无需手动切换工具。
- **代码交付能力**：支持通过 AI 构建可运行代码，将产品决策直接转化为技术实现。

## 技术架构

该项目采用模块化技能架构，每个技能是一个独立的功能单元，封装了特定 PM 领域的知识、分析框架或工作流程。技能之间通过链式工作流进行组合，形成更复杂的业务流程。插件系统作为技能的容器，每个插件可包含多个技能和命令，并提供统一的接口。技能加载机制基于上下文感知，当 AI 检测到相关任务时自动激活匹配的技能。这种设计使得系统具备高扩展性，开发者可以通过贡献新的技能和插件来丰富功能。项目遵循 MIT 许可证开放源码，便于社区协作和二次开发。

## 安装与使用

1. **克隆仓库**：
   ```bash
   git clone https://github.com/phuryn/pm-skills.git
   cd pm-skills
   ```

2. **配置 AI 助手**：根据所选 AI 平台的说明，将技能目录导入到 AI 助手的配置中。例如在 Claude Code 中，可以通过环境变量或配置文件指定技能路径。

3. **启动技能**：在 AI 对话中直接使用命令：
   - `/discover` — 启动产品发现流程
   - `/strategy` — 获取战略清晰度
   - `/write-prd` — 编写产品需求文档
   - `/plan-launch` — 制定发布计划
   - `/north-star` — 定义核心指标

4. **定制工作流**：高级用户可参考 `docs/` 目录下的文档，自定义技能组合或创建新的链式工作流。

最小可用示例：安装后只需在 AI 中输入 `/discover` 命令，即可立即获得结构化的发现框架支持。

## 适用场景

- **产品发现阶段**：当面对一个新想法缺乏结构化分析方法时，使用 `/discover` 命令可以自动执行发现框架，帮助识别用户需求、验证假设。
- **战略规划会议**：团队需要确定产品方向时，通过 `/strategy` 技能快速应用战略框架，确保讨论基于成熟方法论。
- **PRD 编写**：需要撰写产品需求文档时，`/write-prd` 命令提供模板化指导，确保文档结构完整且符合最佳实践。
- **发布与增长分析**：产品上线前使用 `/plan-launch` 规划发布节奏，上线后通过 `/north-star` 技能定义和追踪核心指标。

## 项目亮点

与通用的 AI 提示词或自动化工具相比，PM Skills Marketplace 的差异化优势在于每个技能都编码了可验证的产品管理框架，而不是提供泛泛的建议。用户获得的不是零散的文字生成，而是结构化的决策支持流程。系统通过链式工作流自动组合多个技能，避免了手动切换上下文的碎片化体验。项目采用开放贡献模式，社区可以持续添加经过验证的新技能和插件，使得技能库随着行业最佳实践的发展而迭代。此外，该项目不仅支持文档生成，还能输出可运行代码，将产品决策直接转化为技术成果。
