## 项目概述

Maigret 是一款开源的情报收集工具，能够仅通过一个用户名，在超过 3000 个网站上自动搜索与该用户名关联的账户信息，并生成一份完整的用户档案（dossier）。该项目由 soxoj 开发维护，基于 Python 语言编写，采用 MIT 许可证发布。

该项目主要解决了公开来源情报（OSINT）领域中用户名关联分析的需求。对于安全研究人员、调查记者、数字取证专家以及普通用户而言，Maigret 提供了一种高效、自动化且无需 API 密钥的解决方案，能够快速了解某个用户名在互联网上的分布情况，挖掘潜在的关联信息。

## 核心功能

- **超大规模站点扫描**：支持在 3000 多个预定义的网站中搜索用户名，涵盖社交媒体、论坛、电商、开发平台、博客等各类互联网服务，是目前覆盖面最广的开源用户名搜索工具之一。
- **无需 API 密钥**：所有检测均通过模拟 HTTP 请求直接分析网页内容完成，用户无需注册或申请任何第三方服务的 API 权限，开箱即用。
- **智能结果排序与分类**：自动识别并排除虚假匹配（如 404 页面、重定向等），对真实匹配结果按照站点类型、可信度进行归类，并提供用户名所在页面的直接链接。
- **多格式报告导出**：支持将扫描结果导出为 HTML、JSON、CSV、XMind（思维导图）等格式，便于后续分析、归档或报告分享。
- **AI 辅助分析**：集成了 AI 模型接口（可选），能够对收集到的公开页面内容进行摘要和分析，自动提炼用户档案的关键信息（如地理位置、职业、兴趣等）。
- **灵活的自定义配置**：允许用户添加自定义站点规则、调整扫描超时、启用代理或 Tor 网络，并支持针对单个用户名或批量用户列表进行扫描。

## 技术架构

Maigret 采用模块化架构设计，主要由以下核心组件构成：

1. **站点引擎（Site Engine）**：包含一个基于 YAML 格式编写的站点规则库，每个规则定义了如何检测某网站上的用户名（例如 URL 模式、错误响应特征等）。该规则库是 Maigret 的核心资产，支持社区贡献和动态更新。
2. **请求调度器（Request Scheduler）**：使用 `aiohttp` 异步 HTTP 库实现高效的并发请求管理，能够同时向数百个站点发起检测，大幅缩短扫描时间。同时内置重试机制、错误处理和超时控制。
3. **结果处理器（Result Processor）**：对返回的响应进行解析，排除噪声数据（如通用错误页面、验证码等），并使用评分算法对匹配结果进行可信度评级。
4. **报告生成器（Report Generator）**：将处理后的结果转化为用户可读的多种报告格式，包括美观的 HTML 页面和结构化数据文件。
5. **AI 集成模块**：可选调用 OpenAI、Anthropic 等大语言模型 API，对已收集的页面文本进行深度分析，生成结构化人物画像。

整体设计遵循“轻量依赖、高并发、可扩展”的原则，Python 3.10+ 即可运行，安装过程简单，能够在普通个人电脑上稳定运行。

## 安装与使用

**安装方式（推荐使用 pip）：**

```bash
pip install maigret
```

**最小可用示例（命令行）：**

```bash
maigret username
```

将 `username` 替换为你想调查的用户名，Maigret 会自动开始扫描并在终端中实时输出进度。

**常用选项示例：**

- 保存详细报告到指定目录：
```bash
maigret username --output ./reports
```
- 限制只搜索前 500 个最常用的站点（节省时间）：
```bash
maigret username --top-sites 500
```
- 启用 AI 分析（需设置环境变量 `OPENAI_API_KEY`）：
```bash
maigret username --ai
```

**作为 Python 包使用：**

```python
from maigret import Maigret

engine = Maigret()
results = engine.search("username")
print(results)
```

## 适用场景

- **安全审计与渗透测试**：红队人员或安全研究员可以通过用户名搜索快速了解目标人员在公网的暴露面，为后续攻击面分析提供线索。
- **数字取证与社交工程**：执法部门或调查机构可利用 Maigret 收集嫌疑人的网络账号信息，辅助身份确认或证据链构建。
- **个人隐私风险评估**：普通用户可检查自己的用户名是否在未知网站上留下痕迹，评估个人信息的泄露风险。
- **品牌保护与假冒账号发现**：企业市场或安全团队使用 Maigret 扫描特定用户名（如品牌名称）在各大平台的注册情况，发现仿冒账号并采取行动。

## 项目亮点

相较于同类工具（如 Sherlock、WhatsMyName 等），Maigret 具有以下差异化优势：

1. **站点覆盖量遥遥领先**：支持超过 3000 个站点，且社区活跃，规则库持续更新，覆盖面在开源界无出其右。
2. **高可靠性检测**：采用启发式分析而非简单的状态码判断，能有效过滤大量误报，提高结果的可信度。
3. **丰富的导出和分析能力**：支持思维导图、AI 摘要等高级功能，不仅告诉用户“哪里搜到了”，还能帮助理解“这些信息意味着什么”。
4. **完善的文档与多语言支持**：项目维护了中英文等多语言文档，安装使用门槛较低，新手也能快速上手。
5. **活跃的社区与持续迭代**：GitHub 已获得超过 32000 个 Star，贡献者众多，Bug 修复和功能更新频繁。
