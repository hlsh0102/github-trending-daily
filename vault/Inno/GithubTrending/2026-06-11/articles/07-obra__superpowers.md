## 项目概述

Superpowers 是一套专为编码代理设计的完整软件开发方法论，构建在一组可组合的技能之上，并附带初始指令以确保代理正确使用这些技能。该项目解决的核心问题是：当前的编码代理（如 Claude、Codex、Cursor 等）往往在收到任务后立即跳入代码编写，缺乏系统性的需求分析、设计和规划过程，导致生成的结果质量不稳定、难以维护。Superpowers 的目标用户是所有使用编码代理进行软件开发的工程师，无论你使用的是 Claude Code、Codex CLI、Codex App、Factory Droid、Gemini CLI、OpenCode、Cursor 还是 GitHub Copilot CLI，都能从中受益。

## 核心功能

- **需求驱动的工作流**：编码代理不会立即编写代码，而是先退一步，询问用户的真实目标，通过对话引导出完整的需求规格。
- **分段式规格展示**：将需求规格拆分成足够短的段落呈现给用户，确保用户能够真正阅读并理解每一项内容，而非一次性输出长篇大论。
- **实现计划生成**：在用户确认设计后，代理生成一份清晰的实现计划，风格如同一位有热情但经验有限的初级工程师——强调纯粹的 red/green TDD、YAGNI（你不需要它）和 DRY（不要重复自己）原则。
- **子代理驱动开发**：用户批准计划后，系统启动子代理驱动开发流程，由多个代理逐个处理工程任务，同时进行审查验证。Claude 可以连续自主工作数小时而不偏离既定计划。
- **跨工具兼容**：支持包括 Claude Code、Codex CLI、Codex App、Factory Droid、Gemini CLI、OpenCode、Cursor 和 GitHub Copilot CLI 在内的主流编码代理工具。
- **可组合的技能体系**：所有技能模块均可独立使用，也可以按需组合，适配不同规模和类型的项目。

## 技术架构

Superpowers 的核心设计思路是通过一套标准化的“技能”模块和“初始指令”来改造编码代理的行为模式。项目采用 Shell 脚本作为主要实现语言，利用每个编码工具提供的“系统提示”或“自定义指令”机制注入方法论规则。

其架构特点包括：

1. **分层设计**：底层为基础技能模块（如需求分析、测试驱动、重构等），上层为工作流引擎（子代理协调、任务拆分、进度追踪）。
2. **基于事件驱动**：每次用户输入或代理输出都会触发状态机转换，确保工作流始终遵循“需求→设计→计划→实现→审查”的循环。
3. **可插拔集成**：通过配置文件适配不同编码工具，无需修改核心逻辑即可在 Claude Code、Cursor、Copilot CLI 等环境中使用。
4. **无侵入性**：Superpowers 不修改编码工具本身，而是通过外部指令影响其行为，因此对其他工作流和现有项目完全兼容。

## 安装与使用

以下以 Claude Code 为例说明基本安装步骤：

1. **创建配置文件**：在项目根目录下创建 `.claude/instructions` 文件，内容指向工具技能模块。
2. **复制脚本**：从仓库克隆 `superpowers` 目录到项目根路径。
3. **启动代理**：运行 `claude` 或 `codex` 等命令启动编码代理。

最小可用示例（在终端中执行）：

```bash
# 克隆仓库到任意位置
git clone https://github.com/obra/superpowers.git

# 将 superpowers 目录复制到你的项目根目录
cp -r superpowers/skills /path/to/your/project/.skills

# 配置 Claude Code 使用这些技能
echo ".skills/init" > /path/to/your/project/.claude/instructions

# 启动编程会话
cd /path/to/your/project && claude
```

首次运行时，代理会自动加载技能模块并进入需求收集阶段。只需在对话中描述你想构建的内容，Superpowers 将引导你完成整个开发流程。

## 适用场景

- **新项目快速启动**：当团队需要从零开始构建一个应用时，Superpowers 确保从一开始就遵循正确的方法论，避免早期随意编码导致的后期返工。
- **复杂功能开发**：对于需要多个步骤、涉及多种技术栈的功能，子代理驱动开发模式可以并行推进不同模块，同时保持代码的一致性。
- **团队协作标准化**：帮助团队建立统一的开发流程，新成员通过使用 Superpowers 可以快速适应团队的编码规范和测试标准。
- **远程/异步开发**：开发者可以提交需求后，让代理自主工作数小时，返回时审查已完成的成果，大幅提升异步工作效率。

## 项目亮点

与同类工具相比，Superpowers 的差异化优势在于：

1. **完整的方法论体系**：大部分编码扩展只提供零散的功能（如自动补全、代码审查），而 Superpowers 提供了从需求收集到部署验证的全流程方法论，让代理真正成为“软件开发伙伴”而非“代码生成器”。
2. **跨工具通用性**：不是某个编码工具的专属插件，而是可以在 Claude Code、Cursor、Codex、Copilot CLI 等多款主流工具上运行的一套方法论，降低了工具切换的成本。
3. **强调“先思考再编码”**：强制代理在做任何编码工作前先完成需求分析和设计规划，这恰好是 AI 编码工具最容易忽视的关键步骤。
4. **轻量级实现**：基于纯 Shell 脚本，不依赖任何运行时环境或框架，拷贝即用，降低了部署和使用门槛。
5. **开源且 MIT 许可**：允许任何团队自由修改和定制，适用于企业内部部署和二次开发。
