## 项目概述

`/last30days` 是一个由 AI 智能体驱动的搜索引擎技能（Skill），能够跨 Reddit、X（Twitter）、YouTube、Hacker News、Polymarket 以及整个网络进行主题研究，并生成有据可依的摘要报告。与传统搜索引擎依赖编辑或算法排序不同，它依据点赞数、投票数和真实市场交易数据来衡量内容权重，帮助用户快速了解某个话题在过去30天内最受关注的信息和讨论。

该项目最初作为 Claude Code 的插件开发，现已兼容 50 多种 AI 开发工具和聊天平台，目标用户包括开发者、研究人员、投资者、内容创作者以及任何需要从多源动态数据中快速获取综合概览的用户。

## 核心功能

- **多平台聚合搜索**：一次查询即可检索 Reddit、X、YouTube、Hacker News、Polymarket 预测市场和通用网页内容，无需分别访问各平台。
- **智能摘要生成**：AI 自动分析收集到的内容，按相关性、热度（点赞/投票/讨论度）排序，并合成结构化的摘要报告。
- **零配置即时使用**：安装后立即支持 Reddit、Hacker News、Polymarket 和 GitHub 的查询，无需任何 API 密钥或配置。
- **30秒快速扩展**：首次运行后的设置向导可一键解锁 X、YouTube、TikTok 等更多平台，整个过程约30秒。
- **基于实际数据的排序机制**：使用“赞、投票和真金白银”作为排名依据——例如 Polymarket 反映了真实市场押注，Reddit 投票反映社区共识，比传统搜索引擎更贴近真实舆论。
- **跨工具兼容**：支持 Claude Code、Codex、Cursor、Copilot、Gemini CLI 以及 50 多种 Agent Skills 平台，通过统一的 `npx skills` 命令安装。

## 技术架构

项目采用“技能（Skill）”架构，这是 AI 智能体生态中一种轻量级的插件模式。核心代码为 Python，运行时技能规范定义在 `skills/last30days/SKILL.md` 文件中，该文件是命令和设置行为的权威来源。

架构设计理念强调去中心化和低耦合：
- **管道化处理**：v3 版本采用管道（pipeline）架构，将数据采集、清洗、排序、摘要生成各阶段解耦，便于扩展和维护。
- **插件化注册**：通过 `npx skills` 工具进行全局或项目级安装，技能注册后即可在多种 AI 宿主中调用，无需深度集成。
- **逐步解锁式平台扩展**：核心平台（Reddit、HN、Polymarket、GitHub）内置在基础包中，可选平台通过交互式向导按需启用，减少不必要的依赖和权限请求。

这种方式使得项目既能保持核心代码的轻量，又具备高度的可扩展性，适应不同用户的隐私和使用偏好。

## 安装与使用

**推荐方式（Claude Code 用户）**：
```
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```
此方式会自动接收 Marketplace 的更新。

**通用方式（Codex、Cursor、Copilot、Gemini CLI 等）**：
```bash
npx skills add mvanhorn/last30days-skill -g
```
`-g` 参数表示全局安装，所有项目均可调用；去掉该参数则仅对当前项目生效。

更多安装选项（包括 claude.ai 网页版、OpenClaw 及手动方式）请参见项目 README 的 Install 部分。

**使用示例**：
安装完成后，在支持的 AI 聊天或开发工具中直接输入类似指令：
```
/last30days "AI 芯片产业最新动态"
```
AI 会调用技能，自动搜索各平台过去30天内的相关内容，整理后返回一份包含关键讨论、热门帖子、市场预测和视频的综合报告。

## 适用场景

- **市场研究与投资决策**：投资者可以快速了解某个股票、代币或行业在过去30天的 Reddit 讨论热度和 Polymarket 预测市场走向，结合 X 和新闻生成多维度分析。
- **内容创作与选题规划**：自媒体作者或视频创作者使用 `/last30days` 查询热门话题在各平台的传播情况，识别讨论趋势和高赞观点，为内容选题提供数据支撑。
- **技术趋势追踪**：开发者或产品经理搜索“Rust 2025 现状”或“AI Agent 最新进展”，获取 GitHub、HN 和 YouTube 上的高质量讨论和代码资源。
- **舆情监测与竞品分析**：企业或机构跟踪品牌口碑或竞品动态，汇总 Reddit 差评、X 热门吐槽和 YouTube 测评，快速产出舆情简报。

## 项目亮点

与传统的搜索引擎或网络监控工具相比，`/last30days` 的核心差异化优势在于：

1. **智能体原生设计**：不是普通的浏览器插件或独立应用，而是专为 AI 智能体打造的“技能”，深度融入工作流中，用户无需切换工具即可获取结构化信息。
2. **真实社交信号加权**：不依赖 SEO 或编辑推荐，而是根据点赞数、投票数和真金白银的市场押注来衡量内容质量，结果更贴近真实的社区共识。
3. **30天时间窗口聚焦**：默认限定在过去30天，天然避开过时内容，非常适合关注快速变化的技术、商业和时事领域。
4. **一键安装，零成本起步**：无需注册、无需 API 密钥，核心平台即装即用，30秒内即可让更多平台生效，降低了使用门槛。
5. **开源且 MIT 许可**：代码完全开放，社区可自由审计、修改和扩展，目前 GitHub 获得超过 39,000 颗星，增长率惊人，市场认可度极高。
