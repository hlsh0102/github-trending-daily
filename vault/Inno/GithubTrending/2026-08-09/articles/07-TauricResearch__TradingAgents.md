## 项目概述

TradingAgents 是一个基于多智能体（Multi-Agents）与大语言模型（LLM）的金融交易框架，由 TauricResearch 团队开发并开源。该项目将人工智能领域前沿的 Agent 协作范式引入量化投资与基本面分析场景，构建了一套完整的“研究-辩论-决策-风控”交易流水线。

该框架解决了传统量化策略开发中几个长期存在的痛点：单一模型无法全面覆盖复杂金融市场信息、人工研报分析耗时费力、以及投资决策缺乏可解释性。通过模拟真实投资团队中研究员、交易员、风控官等角色的协作模式，TradingAgents 让大语言模型在分工与辩论中生成更有依据、更具备多维视角的交易建议。

项目面向量化研究员、个人投资者、金融科技开发者以及大语言模型应用研究者。无论你是希望借助 AI 辅助日常投资决策，还是想研究多智能体协作在金融领域的落地路径，TradingAgents 都提供了开箱即用的工具和灵活的扩展接口。

## 核心功能

- **多角色 Agent 体系**：内置基本面研究员、情绪分析师、技术分析师、交易员、风控官等不同角色的 Agent，每个 Agent 拥有独立的提示词模板与知识侧重点，模拟真实投研团队分工。
- **多智能体辩论机制**：支持看多与看空两方 Agent 基于各自分析逻辑进行结构化辩论，通过观点碰撞产生更全面、更少偏见的投资结论。
- **完整决策流水线**：从数据获取、研究分析、辩论讨论到最终交易决策和风险评估，形成端到端的自动化流程，用户只需提供标的与日期参数。
- **多维信息分析**：整合新闻情绪、技术指标、基本面数据等多种信息源，每个维度由专门 Agent 负责深度挖掘。
- **可解释性报告**：每一步分析均由 LLM 生成自然语言推理过程，交易建议附带完整思路链条，方便用户回溯和验证。
- **简单易用的 CLI 接口**：通过命令行参数即可快速启动对任意股票的分析与交易信号生成，无需编写额外代码。

## 技术架构

TradingAgents 基于 Python 语言实现，核心设计围绕“角色分工”与“辩论协作”两条主线展开。框架抽象了 `AnalystAgent`、`TraderAgent`、`RiskAgent` 等基础类，每个 Agent 内部封装了独立的 LLM 调用配置（支持 OpenAI、Anthropic 等主流模型 API），并通过统一的上下文管理器在各阶段传递分析结果。

关键架构特点包括：

- **阶段化流水线**：整个交易决策过程被划分为 Research（研究）、 Debate（辩论）、 Trade（交易）、 Risk（风控）四个阶段，每一阶段输出结构化数据供下一阶段消费，逻辑清晰且便于替换或扩展单个环节。
- **辩论图谱**：在看多/看空论证过程中，框架会记录双方论点、论据和反驳关系，形成可追溯的辩论图谱，最终由裁判 Agent 根据辩论质量综合打分。
- **记忆与上下文管理**：由于单次决策涉及多轮 Agent 交互，框架实现了高效的上下文摘要与传递机制，避免长对话导致的 token 开销失控。
- **模块化设计**：数据加载器、Agent 类型、提示词模板均可独立定制，研究人员可以方便地替换新闻源、添加自定义 Agent 角色或修改辩论规则。

## 安装与使用

TradingAgents 要求 Python 3.10 以上环境，并通过 pip 进行安装：

```bash
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
pip install -r requirements.txt
```

首次使用前需要配置大语言模型 API 密钥。在项目根目录创建 `.env` 文件并填入你的密钥（以 OpenAI 为例）：

```bash
OPENAI_API_KEY=sk-your-key
```

最小可用示例如下，分析英伟达（NVDA）当前的交易信号：

```bash
python main.py --tickers NVDA --show_reasoning
```

运行后，框架会自动拉取最新的新闻与价格数据，依次执行研究、辩论、交易决策和风险评估，最终在终端输出一份包含目标价格、持仓建议（买入/持有/卖出）以及完整推理过程的报告。如果需要调整辩论轮数或启用更详细的分析输出，可参考项目文档中的 CLI 参数说明。

## 适用场景

- **个人投资研究辅助**：投资者在做出交易决策前，可使用 TradingAgents 快速生成一份融合基本面、技术面与市场情绪的综合分析报告，减少信息盲区。
- **量化策略信号生成**：量化团队可以将 TradingAgents 作为另类 alpha 信号源，将其输出的多空观点与持仓比例转化为因子，集成到现有策略组合中。
- **金融舆情监控**：通过定期运行框架，可以自动化追踪特定股票池的多空情绪强度变化，提前发现市场预期反转的早期信号。
- **多智能体系统教学与科研**：高校实验室和研究人员可以借鉴该框架的辩论建模、角色分工设计，用于大语言模型在金融决策领域的学术实验。

## 项目亮点

与传统的单一 Prompt 分析工具或简单 RAG 问答系统相比，TradingAgents 具有明显的差异化优势：

- **对抗式辩论机制**：将投资决策建模为多智能体辩论过程，而非简单的“问题-回答”。通过观点碰撞有效削弱单一大模型常见的确认偏误，提升决策稳健性。
- **领域知识深度嵌入**：Agent 提示词经过金融语境专门打磨，涵盖估值模型、财报解读、技术形态等专业术语与推理范式，而非通用对话模型。
- **完全开源与可复现**：代码、提示词模板与流程设计全部公开（Apache-2.0 协议），用户可完全掌控分析逻辑，也方便二次开发。
- **活跃社区与高关注度**：项目在 GitHub 上已获得近十万 Star，并成为当日热门仓库第一名。开发团队持续更新，社区讨论活跃，便于交流与贡献。
