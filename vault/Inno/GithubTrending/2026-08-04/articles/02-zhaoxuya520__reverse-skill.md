## 项目概述

reverse-skill 是一个面向网络安全领域的技能路由包（Skill Router Pack），专为逆向工程、授权渗透测试和安全研究场景设计。该项目通过 AI 驱动的智能路由机制，将开发者的安全任务请求自动分发至最合适的技能模块，并在需要时按需自举（bootstrap）对应工具链，同时维护一个自动进化的知识库以持续沉淀经验。

项目主要服务于三类用户：从事二进制逆向分析的安全研究员、进行授权渗透测试的红队/蓝队工程师，以及希望在 AI 编程客户端中集成安全能力的安全开发者。它支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端，能够将原本碎片化的安全工具调用与 AI 任务执行无缝衔接，显著提升安全分析工作的效率与自动化水平。

## 核心功能

- **AI 智能路由**：基于自然语言任务描述，自动匹配并路由至对应的逆向/渗透技能模块，无需手动切换工具或脚本
- **按需工具链自举**：当任务需要特定工具时，自动检测环境中缺失的工具链并完成安装与配置，确保开箱即用
- **自进化知识库**：每次任务执行后自动记录有效方法、参数组合与踩坑经验，知识库随使用持续迭代更新
- **多客户端兼容**：原生支持 Claude Code、Kiro、Cursor、Cline 等主流 AI 编程客户端，通过统一接口对接
- **安全合规约束**：内置授权检测与操作边界控制，确保所有操作符合授权渗透测试与合规要求
- **模块化技能体系**：按逆向工程、Web 渗透、二进制分析等细分领域组织技能模块，支持自定义扩展

## 技术架构

reverse-skill 采用轻量级架构，以 PowerShell 为核心实现语言，借助其良好的 Windows/Linux/macOS 跨平台能力，降低部署复杂度。项目整体设计遵循三层结构：

**路由层**：负责解析 AI 客户端传入的任务指令，通过关键词匹配与语义分析，结合内置的优先级规则，将任务准确分发至对应技能模块。该层采用可插拔设计，便于新增自定义路由规则。

**执行层**：由一系列独立的技能模块组成，每个模块封装了特定安全任务的完整执行逻辑，包括工具调用、参数构造、输出解析等。执行层具备工具链自举能力，在检测到必要工具缺失时，自动调用包管理器（如 apt、pip、scoop）完成环境准备。

**知识层**：采用结构化文件存储（如 JSON/YAML）记录历史任务的执行摘要、成功模式与失败教训。知识层通过定期总结机制，将碎片化经验转化为可查询的路由条件，形成正向反馈循环，持续提升路由准确率。

这种架构设计的显著特点是"薄路由、厚模块"：路由层保持轻量以便快速分发，而重逻辑全部内聚于技能模块中，既保证了系统的响应速度，又便于安全研究人员独立扩展新技能。

## 安装与使用

**环境要求**：PowerShell 7.0+（推荐使用 PowerShell Core，亦可兼容 Windows PowerShell 5.1），支持 Windows、macOS、Linux 操作系统。

**安装步骤**：

1. 克隆仓库到本地目录：

```bash
git clone https://github.com/zhaoxuya520/reverse-skill.git
cd reverse-skill
```

2. 执行初始化脚本，完成核心模块加载与环境检测：

```powershell
./init.ps1
```

3. 在支持的 AI 客户端（如 Claude Code、Cursor）中，将仓库路径添加为技能包来源，或通过其插件机制引入本项目的 skill 定义文件。

**最小使用示例**：

在支持的 AI 客户端中，直接以自然语言发起任务请求。例如：

```
请分析当前目录下 sample.bin 文件的 PE 结构，并提取其导入表信息。
```

reverse-skill 将自动路由至对应的二进制分析技能模块，若检测到 `objdump` 或 `pefile` 等工具缺失，会提示并自动安装所需依赖，随后执行分析并返回结果。整个过程中无需手动配置工具路径或编写脚本。

## 适用场景

- **CTF 与漏洞研究**：在 CTF 比赛中快速分析二进制文件、逆向算法，或对已知漏洞进行 PoC 验证，减少重复性环境搭建的时间开销
- **企业安全审计**：授权渗透测试中对目标系统进行信息收集、漏洞扫描与利用验证，由 AI 路由统一调度 nmap、sqlmap 等工具链
- **安全工具链集成**：将 reverse-skill 作为中间层，将已有的安全脚本与 AI 客户端整合，实现自然语言驱动的安全分析工作流
- **安全知识沉淀**：团队内部部署统一知识库，通过持续使用积累项目特有的安全分析经验，降低人员流动带来的知识流失风险

## 项目亮点

与同类安全工具包相比，reverse-skill 的核心差异在于其"AI 原生"的设计理念。多数安全工具仅提供命令行接口，而本项目直接面向 AI 客户端构建路由层，使 AI 能自主决策使用何种工具、如何组合调用，真正实现自然语言驱动安全分析。

此外，自进化知识库是另一项显著差异化优势。传统工具链的使用经验通常依赖人工整理文档，而 reverse-skill 在执行任务后自动沉淀可复用的方法论，且知识质量随使用量提升，形成数据飞轮效应。

最后，项目对合规性的内建重视也值得一提。路由层内置授权检测逻辑，确保未通过授权验证的任务不会触发任何实际攻击行为，这在开源安全工具中较为少见，符合企业安全合规审计的硬性要求。
