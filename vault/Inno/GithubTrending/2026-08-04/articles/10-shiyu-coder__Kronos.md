## 项目概述

Kronos 是一个面向金融市场的开源基础模型，旨在将自然语言处理的前沿技术引入量化分析与投资决策领域。该项目由 shiyu-coder 发起并维护，核心目标是为金融时间序列数据构建一个通用的表征学习框架，让研究者与开发者能够像处理文本一样“阅读”和“理解”市场行情。Kronos 名称源于希腊神话中的时间之神，暗合金融数据天然的时间序列属性。

该项目解决了传统金融建模中两大痛点：其一是特征工程高度依赖人工经验，且难以迁移到不同市场或资产类别；其二是大多数深度学习模型针对单一任务设计，缺乏跨任务、跨市场的泛化能力。Kronos 通过在大规模金融时序语料上进行自监督预训练，学习到通用的市场动态表征，从而为价格预测、波动率估计、投资组合构建等下游任务提供统一的模型底座。目标用户包括量化研究员、金融科技开发者、数据科学家以及对智能投研感兴趣的学术研究者。

## 核心功能

- **多市场预训练模型**：提供在大规模全球股票、指数、商品及加密货币数据上预训练的模型权重，支持主流市场覆盖。
- **基于 Patch 的时序编码**：借鉴 Vision Transformer 的分块思想，将连续的价格序列切分为局部 patch 进行嵌入，有效捕捉局部趋势与跨时间步的依赖关系。
- **灵活的微调接口**：支持在自定义数据集上进行有监督微调（Fine-tuning），可快速适配个股预测、行业轮动等专属任务。
- **概率预测头**：内置针对时序预测的专用输出头，可输出未来价格分布的参数化结果，支持区间预测与风险度量。
- **轻量级推理管线**：提供简洁的 Python API，支持从 Hugging Face 直接加载权重，在标准 CPU/GPU 环境下完成快速推理。
- **开源基线 benchmark**：附带多个公开数据集上的评估脚本与预训练结果，便于用户横向对比模型效果。

## 技术架构

Kronos 的模型设计受到大语言模型架构的深刻启发，但针对金融时序数据的特性进行了专门改造。整体架构采用编码器-解码器范式，其中编码器基于 Transformer 结构，但与传统 NLP 模型有几点关键差异。

**输入层**：原始分钟级或日级价格序列首先被归一化并转换为对数收益率，以消除绝对价格水平的影响。随后，序列被分割为固定长度的 patch（例如 16 或 32 个时间步），每个 patch 通过一个线性投影层映射为隐向量，并叠加可学习的位置编码。这种 patch 化设计显著减少了序列长度，使模型能够处理更长的历史窗口。

**核心编码器**：采用多层自注意力机制，但注意力计算中引入了因果掩码（Causal Mask），确保模型在预测时只能利用历史信息，避免未来数据的泄漏。同时，模型中加入了针对金融数据设计的标准化层（LayerNorm 的变体），以应对收益序列中常见的重尾分布与方差波动。

**预训练策略**：Kronos 采用自监督的掩码重建任务进行预训练。具体而言，随机遮蔽部分时间步的 patch，并训练模型根据上下文重建被遮蔽的数值。该任务迫使模型学习到价格序列内部的结构性规律，而非仅记忆表面数值。预训练语料覆盖了跨越 20 年以上的全球主要市场数据，总量达数百亿个时间步。

**输出头**：对于预测任务，模型使用独立的回归头输出未来 K 步的收益分布参数（均值与方差），这一设计使得模型天然支持量化投资中常用的置信区间分析。整体参数量控制在 1 亿以内（base 版本），在保持表达能力的同时兼顾了训练与推理效率。

## 安装与使用

Kronos 需要 Python 3.9+ 环境，推荐使用 PyTorch 2.0 及以上版本。可通过 pip 直接安装：

```bash
pip install kronos-finance
```

若希望使用最新开发版，可从源码安装：

```bash
git clone https://github.com/shiyu-coder/Kronos.git
cd Kronos
pip install -e .
```

**最小使用示例**：从 Hugging Face 加载预训练权重，并对一段历史价格序列进行未来 5 日收益预测。

```python
import kronos
import torch

# 加载预训练模型（自动从 Hugging Face 下载权重）
model = kronos.Kronos.from_pretrained("NeoQuasar/Kronos-base")

# 构造输入数据：形状为 [batch, seq_len]，此处为 512 个日频对数收益率
dummy_input = torch.randn(1, 512)

# 预测未来 5 步的收益分布
with torch.no_grad():
    mean, variance = model.predict(dummy_input, horizon=5)
print(f"预期收益: {mean.item():.4f}, 波动: {variance.item():.4f}")
```

更多高级用法，如自定义数据集微调与评估，请参考仓库中的 `examples/` 目录及项目文档。

## 适用场景

- **智能投研与选股**：利用预训练表征提取市场状态特征，结合基本面因子构建多因子选股模型，提升 alpha 因子的有效性。
- **风险管理与压力测试**：通过 Kronos 输出的概率预测，计算投资组合在极端市场环境下的潜在损失（VaR、CVaR），辅助风险限额设定。
- **高频交易信号生成**：在分钟级数据上微调模型，生成短期内价动量或反转信号，作为交易系统的辅助决策输入。
- **学术研究与新型金融指标构建**：将 Kronos 作为特征提取器，探索市场有效性假设、投资者情绪量化等金融经济学研究课题。

## 项目亮点

与现有的时间序列预测模型（如 LSTM、TFT、N-BEATS）相比，Kronos 的差异化优势非常明显。首先，它是极少数以“基础模型”范式的开源金融模型，其预训练权重能够通过微调适配多种下游任务，而不是为一个任务训练一个模型。其次，模型专门针对金融数据设计了 patch 化输入与概率输出，相比通用时序模型，在收益率分布拟合与长序列依赖捕捉上表现更佳。此外，项目提供了完整的数据预处理代码、评估基准与 Live Demo，降低了新用户的上手门槛。最后，MIT 许可证允许商业使用，这使得 Kronos 可以无缝集成至企业的量化生产环境中。
