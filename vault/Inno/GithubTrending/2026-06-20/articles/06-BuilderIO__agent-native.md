## 项目概述

Agent-Native 是一个开源的 TypeScript 框架，用于构建“智能体原生”的应用程序。该项目由 BuilderIO 开发，核心理念是：你不需要在丰富的用户界面和自主智能体之间做出选择——每一个 Agent-Native 应用既是完整的 UI 应用，又是强大的智能体应用。

对于正在构建 AI 应用、智能助手或自动化工作流的开发者来说，Agent-Native 解决了两个关键痛点：一是传统聊天界面（Chat UI）的功能限制（无法实现富文本编辑、拖拽、复杂交互），二是纯智能体系统缺乏用户可控的操作界面。该项目旨在让人类和 AI 智能体在同一个应用内平等协作，共享状态、数据库和操作入口。

## 核心功能

- **UI 与智能体完全同步**：智能体和用户界面共享同一个数据库和状态。无论是用户通过点击操作，还是智能体自主执行任务，任何一方的变更都会实时反映到另一方。
- **实时多人协作**：支持人类和多个智能体同时在同一个文档上编辑。基于 CRDT（无冲突复制数据类型）的合并机制保证了数据一致性，支持实时光标、选中范围、用户头像等多人协作特性。智能体作为“一等公民编辑器”直接参与协同编辑。兼容任何 SQL 数据库和任何主机环境（包括 Serverless）。
- **上下文感知**：智能体能够感知用户当前正在查看的内容。用户可以选中文本，按下 Cmd+I 快捷键，直接对智能体下达操作指令，智能体将基于当前上下文执行任务。
- **用户级工作空间**：每个用户拥有独立的工作空间，包含技能配置、记忆存储、指令模板、子智能体和 MCP（模型上下文协议）服务器。所有数据以 SQL 数据库为后端，支持按用户自定义。提供了与 Claude Code 同等级别的灵活性，同时保持 SaaS 级的运营成本。
- **智能体间互调（A2A）**：用户可以在任意应用中标记另一个智能体。智能体之间通过 A2A（Agent-to-Agent）协议互相发现、通信并执行跨应用的协作任务。
- **可复用集成**：通过一个集中式服务（Dispatch）统一管理外部服务提供商的连接。敏感密钥存储在安全保管库（Vault）中，应用（如 Brain、Analytics、Mail、Dispatch 等）可以共享同一套账号元数据和凭据引用。
- **三种应用形态**：同一套智能体可以以三种不同形式运行——无头 API（供其他服务调用）、富聊天界面、或完整的应用程序（智能体和 UI 深度集成）。

## 技术架构

Agent-Native 采用 TypeScript 编写，其核心架构理念是“智能体与 UI 对等”。框架以 SQL 数据库（理论上支持任何 SQL 引擎）作为统一的数据持久化层，结合 CRDT 算法实现实时协作和状态同步。在身份与权限方面，它提出了“用户级工作空间”概念，通过数据库行级安全策略（RLS）或类似机制实现多租户隔离。

框架内部划分了多个职责分明的模块：核心运行时负责智能体的执行与调度；MCP 服务器模块处理模型上下文协议，使智能体能够访问外部工具和数据；A2A 通信模块实现智能体间的发现与调用；UI 组件库提供开箱即用、可深度集成的界面元素。在集成方面，Agent-Native 采用“可复用集成”模式——通过集中式服务管理外部服务凭证，避免在每个应用中重复配置。

这种架构设计使得框架具有三个显著特点：一是 **低延迟**（共享状态避免了不必要的网络往返）；二是 **高可扩展性**（SQL 数据库 + CRDT 保证了横向扩展能力）；三是 **环境友好**（支持 Serverless 部署，适合现代云原生应用）。

## 安装与使用

假设项目已发布到 npm，安装命令如下：

```bash
npm install @builderio/agent-native
# 或
yarn add @builderio/agent-native
```

基础使用示例（伪代码，实际以项目文档为准）：

```typescript
import { AgentApp } from '@builderio/agent-native';

// 创建一个智能体应用
const app = new AgentApp({
  db: 'postgresql://...',      // 指定数据库连接
  ai: { model: 'gpt-4' },      // 配置 AI 模型
});

// 定义一个技能（可被智能体调用的能力）
app.skill('translate', async (input, { user }) => {
  // 调用外部翻译 API
  return translatedText;
});

// 启动应用（同时暴露 API 和 UI）
app.listen(4000);
```

实际使用时，建议先查看项目的 `examples` 目录，其中提供了从入门到高级的完整示例。

## 适用场景

- **内部工具与自动化平台**：允许使用者通过自然语言命令（如“生成上个月的销售报告并发送邮件”）来完成复杂工作流，同时提供传统 UI 以便人工复核和微调。
- **智能协作编辑器**：文档、幻灯片、电子表格的多人协作场景，智能体可以实时协助用户编辑、格式化、查询数据，并与其他智能体协作完成跨文档任务。
- **客户支持与运营系统**：构建智能客服或运营后台，智能体自动处理 Ticket、查询客户数据，同时人工客服可以随时介入并接管控制权。
- **AI 应用脚手架**：快速构建基于“智能体 + UI”范式的 MVP（最小可行产品），框架提供了开箱即用的协作、集成和部署能力。

## 项目亮点

Agent-Native 与市面上其他 AI 代理框架（如 LangChain、AutoGPT 等）的差异化优势在于：

1. **UI 与智能体的深度绑定**：大多数框架只关注智能体逻辑，忽视用户体验。Agent-Native 从一开始就将 UI 和智能体放在同等地位，提供“双向操作”——同一个动作既可通过 UI 点击，也可通过自然语言请求。
2. **原生实时协作**：CRDT 技术的集成意味着该系统天生支持多人实时编辑，智能体可以像人类协作者一样在文档中工作，这在同类框架中非常罕见。
3. **全方位的环境兼容**：支持 Serverless 部署，兼容任何 SQL 数据库（PostgreSQL、MySQL、SQLite 等），这意味着开发者可以选择任意云平台或自建环境。
4. **企业级的多租户设计**：通过用户级工作空间和集中式集成管理，提供了企业级的安全性和可管理性，同时保持较低的成本。
5. **开放与可定制**：作为开源项目，用户可以自由定制、审计、贡献代码，无需担心厂商锁定。
