## 项目概述

Superpowers 是一套为编码智能体设计的完整软件开发方法论，构建在一组可组合的技能和初始指令之上，确保你的智能体能够正确使用它们。该项目由 Obra 创建，旨在解决当前 AI 编码工具在软件开发过程中缺乏结构化方法论的问题。

许多开发者在使用编码智能体时，往往发现它们直接跳入代码编写，缺乏对项目需求的深入理解、缺乏合理的架构设计、缺乏测试驱动开发意识、缺乏持续重构的能力。Superpowers 通过提供一套系统化的技能框架，让编码智能体能够遵循成熟的软件工程实践，从而显著提升生成代码的质量和可维护性。

该项目的目标用户是所有使用编码智能体进行软件开发的开发者，特别是那些希望让 AI 协作更高效、更可控的团队和个人。无论你使用 Claude Code、Cursor、GitHub Copilot CLI 还是其他主流编码智能体，Superpowers 都能为它们赋能。

## 核心功能

- **需求澄清与规格定义**：智能体不会直接编写代码，而是首先与用户深入交流，理解真正目标，并生成易于阅读的设计规格文档
- **渐进式实现计划**：将设计转化为清晰、可执行的实现计划，强调红/绿/绿 TDD（测试驱动开发）、YAGNI（你不会需要它）和 DRY（不要重复自己）原则
- **可组合技能库**：提供一系列经过验证的技能，智能体可以根据需要组合使用，覆盖从设计、编码到测试、重构的完整开发流程
- **多平台兼容**：支持 Claude Code、Antigravity、Codex App、Codex CLI、Cursor、Factory Droid、Gemini CLI、GitHub Copilot CLI、Kimi Code、OpenCode、Pi 等多种主流编码智能体
- **社区驱动进化**：开源社区可以贡献新的技能、改进现有技能，使方法论不断演进
- **轻量级集成**：不需要复杂的配置或额外的服务器，通过简单的指令注入即可让现有编码智能体获得超能力

## 技术架构

Superpowers 采用分层架构设计：

- **核心方法论层**：定义了智能体应该遵循的开发流程和决策原则，包括需求分析、设计、实现、测试、重构等阶段的标准流程
- **技能库层**：包含一系列独立的技能模块，每个技能封装了特定的软件开发实践，如 TDD 技能、重构技能、代码审查技能等。技能之间通过标准接口相互调用
- **适配器层**：负责将核心方法论和技能库适配到不同的编码智能体平台，确保在不同环境下的一致性体验
- **指令注入层**：通过初始指令和配置文件将方法论注入到智能体的工作流程中，无需修改智能体本身的代码

项目使用 Shell 脚本作为主要实现语言，充分利用了 Shell 的轻量和跨平台特性。设计思路强调“先想后做”：让智能体在动手编码前先完成需求理解、架构设计和测试计划，从而避免常见的“AI 黑盒”问题。

## 安装与使用

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/obra/superpowers.git
   cd superpowers
   ```

2. 根据你使用的编码智能体，查看对应的快速开始指南。例如，如果使用 Claude Code，查看 `docs/claude-code.md`。

3. 按照指南将 Superpowers 指令注入到智能体的系统提示或配置中。

4. 启动你的编码智能体，开始使用 Superpowers 进行开发。

最小可用示例（以 Claude Code 为例）：
```bash
# 在项目根目录执行
claude code --prompt "使用 Superpowers 方法论来开发一个新的 Web 应用"
```

智能体将会自动应用需求澄清、设计规格、TDD 实现等流程。

## 适用场景

- **新项目启动**：当你需要从零开始构建一个项目时，Superpowers 帮助智能体先进行需求分析和架构设计，避免一开始就走上错误方向
- **遗留系统维护**：在维护旧代码时，Superpowers 会促使智能体先理解现有代码库的结构、测试覆盖情况和改造风险，然后制定安全的重构计划
- **团队协作开发**：多个开发者使用编码智能体时，统一的方法论确保每个智能体都遵循相同的开发规范和流程，减少协作冲突
- **复杂功能实现**：当实现复杂功能时，Superpowers 会要求智能体先编写测试，再进行实现，确保功能正确性的同时保持代码的可测试性

## 项目亮点

- **系统化方法论**：不同于大多数编码智能体工具仅提供命令或模板，Superpowers 提供了一整套经过验证的软件开发方法论
- **智能体不可知**：不绑定特定编码智能体，可以在大多数主流平台上使用，降低了迁移成本
- **社区驱动进化**：技能库由开源社区持续贡献和优化，能够快速适应新的开发实践和工具变化
- **轻量无侵入**：不需要修改智能体本身的代码或部署额外服务，通过指令注入即可生效
- **强调软件工程最佳实践**：内置 TDD、YAGNI、DRY 等原则，帮助智能体生成的代码更接近专业开发者的水平
- **高可见度**：GitHub 上获得超过 23 万星标，日增超过 1000 星，说明社区对它的高度认可
