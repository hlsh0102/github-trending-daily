## 项目概述

codebase-memory-mcp 是一个为 AI 编码代理设计的高性能代码智能 MCP 服务器。它能够将整个代码库索引为持久化的知识图谱——对于一个普通规模的仓库，索引时间仅为毫秒级；即使是拥有 2800 万行代码、7.5 万个文件的 Linux 内核，也只需 3 分钟即可完成全量索引。项目以单一静态二进制文件形式分发，无任何运行时依赖，开箱即用。

该项目解决了 AI 编码代理在面对大型代码库时常见的两个痛点：一是索引速度慢，导致开发流程中断；二是上下文窗口有限，无法有效利用代码库的结构信息。通过持久化的知识图谱和毫秒级查询能力，codebase-memory-mcp 让 AI 代理能够快速理解代码结构，显著减少不必要的 token 消耗（最多减少 99%）。

目标用户包括使用 AI 编码代理（如 GitHub Copilot、Cursor、Continue 等）的开发者、需要维护大型代码库的团队，以及希望将代码智能集成到自定义工作流中的研究人员和工程师。

## 核心功能

- **2700 万行代码级索引性能**：普通仓库毫秒级索引，Linux 内核级仓库 3 分钟内完成。
- **支持 158 种编程语言**：通过 tree-sitter AST 分析实现高质量语法解析，覆盖绝大多数主流语言。
- **混合 LSP 语义类型解析**：针对 Python、TypeScript、JavaScript、JSX、TSX、PHP、C#、Go、C、C++、Java、Kotlin、Rust 等语言，通过 Hybrid LSP 技术解析语义类型，提升知识图谱的精确度。
- **持久化知识图谱**：索引结果持久化存储，支持函数、类、调用链、HTTP 路由、跨服务链接等多种结构元素的查询。
- **14 个 MCP 工具**：提供丰富的代码查询和分析工具接口，满足不同场景下的调用需求。
- **零依赖单二进制分发**：支持 macOS、Linux、Windows，下载后运行 `install` 命令即可完成配置。
- **毫秒级子查询**：结构化查询响应时间低于 1 毫秒，确保 AI 代理实时获取代码信息。

## 技术架构

codebase-memory-mcp 使用 C 语言编写，充分发掘了底层性能潜力。其核心架构围绕两种解析引擎构建：

1. **tree-sitter AST 解析引擎**：为 158 种语言提供统一的语法分析支持。tree-sitter 能够增量解析，支持错误恢复，这使得知识图谱的构建可以逐步进行，而非一次性全量扫描。

2. **Hybrid LSP 语义层**：针对 11 种主流语言，通过集成语言服务器协议（LSP）获取更丰富的语义信息。不同于传统的全量 LSP 调用（通常耗时较长），codebase-memory-mcp 实现了混合模式，只在关键节点调用 LSP，从而在精度和速度之间取得平衡。

知识图谱采用高效的持久化存储方案，索引结果可直接用于后续工作会话，无需重复构建。这种设计使得 AI 编码代理在不同会话间共享代码理解，大幅提升开发效率。

架构的另一特点是模块化和轻量级。整个项目以单一静态链接的二进制文件交付，无需安装 Python、Node.js 等运行时环境，降低了部署复杂度和安全风险。

## 安装与使用

安装过程极为简洁：

1. **下载二进制文件**：从 GitHub Releases 页面获取适用于当前平台的最新版本。
2. **运行安装命令**：
   ```bash
   ./codebase-memory-mcp install
   ```
   该命令会完成所有必要的配置和注册工作。
3. **启动服务**（以 MCP 模式运行）：
   ```bash
   ./codebase-memory-mcp serve --path /path/to/your/codebase
   ```

最小可用示例（与 AI 代理集成）：

```json
{
  "mcpServers": {
    "codebase-memory": {
      "command": "/path/to/codebase-memory-mcp",
      "args": ["serve", "--path", "/path/to/your/project"]
    }
  }
}
```

配置完成后，AI 代理可通过 MCP 协议调用进程工具（如查询函数定义、查找调用者、获取类型信息等），无需任何额外代码。

## 适用场景

- **大型代码库的 AI 辅助开发**：当开发者使用 AI 编码代理处理拥有数十万甚至百万级文件的项目时，codebase-memory-mcp 确保代理能够快速定位和理解相关代码结构，避免因上下文窗口限制导致的理解偏差。

- **跨服务代码分析**：通过知识图谱中的跨服务链接，开发者可以轻松追踪微服务架构中的服务间调用关系，进行影响分析和重构评估。

- **持续集成中的代码质量检查**：将 codebase-memory-mcp 集成到 CI/CD 流水线中，自动生成 API 调用图、类型关系图，辅助代码审查和架构合规性检查。

- **研究型实验平台**：对于研究代码理解、知识图谱构建或 AI 编程的团队，该项目提供了一个高性能的实验基础，支持自定义查询和集成。

## 项目亮点

相比同类项目，codebase-memory-mcp 的差异化优势体现在：

1. **极致的性能**：普通仓库毫秒级索引、Linux 内核级仓库 3 分钟索引、毫秒级查询，远超基于 Python 或 TypeScript 的同类型项目。
2. **Token 效率革命**：通过知识图谱降低 AI 代理读取整个文件的必要，可减少 99% 的 token 消耗，直接降低 API 调用成本。
3. **零依赖的部署体验**：单一静态二进制文件，无运行时依赖，下载即用，完美适配 Docker、CI/CD 等轻量环境。
4. **广泛的语言覆盖**：158 种语言 + 11 种主流语言的语义解析，几乎没有覆盖不到的编程语法。
5. **研究驱动的持续优化**：项目基于学术研究（参考 arXiv:2603.27277），持续进行算法和性能的迭代改进。
