## 项目概述

Continue 是一款开源的编程智能体（coding agent），旨在为开发者提供一个可自由定制、本地可控的 AI 编码助手。该项目由 continuedev 团队维护，以 Apache-2.0 许可证开源，在 GitHub 上获得了超过 34000 颗星。Continue 以 CLI、VS Code 扩展和 JetBrains 插件三种形式提供服务，让开发者能够在日常开发环境中直接与 AI 交互，实现代码生成、重构、解释、测试编写等任务。它的目标用户是希望将 AI 能力无缝集成到本地开发工作流中的软件工程师，特别是那些重视隐私、可定制性和开源透明度的团队或个人。

需要注意的是，当前 `continuedev/continue` 仓库已进入只读状态，不再积极开发。团队发布了最终版 2.0.0，包含了去除匿名遥测、移除身份认证、修复大量 bug 等改进。对于希望继续使用或基于其开发的用户，这仍是一个功能完备的稳定基线。

## 核心功能

- **多形态支持**：同一套代码库同时提供 CLI、VS Code 扩展和 JetBrains 插件三种使用方式，适应不同开发者的偏好和环境。
- **上下文感知的代码对话**：在 IDE 内选中代码后，可直接向 AI 提出问题或指令，AI 能理解当前文件、选中片段乃至整个项目的上下文。
- **代码生成与修改**：支持根据自然语言描述生成新代码，或对现有代码进行重构、优化、添加注释等操作。
- **模型自由选择**：不绑定特定 AI 模型，可与多种本地或远程大语言模型（如 Ollama、OpenAI、Anthropic 等）集成。
- **任务自动化**：通过 CLI 或 IDE 命令执行批处理任务，如批量代码审查、文档生成、单元测试编写等。
- **隐私优先**：2.0.0 版本完全去除了匿名遥测，移除了外部身份认证依赖，确保所有操作可完全本地化进行。

## 技术架构

Continue 采用模块化设计，核心引擎与具体 IDE 集成层分离。其技术栈基于 TypeScript，保证了跨平台和跨编辑器的一致性。架构上包含以下几个关键部分：

- **协议层**：定义了一套标准化的请求/响应协议，用于 IDE 插件与后端 AI 模型之间的通信。这允许用户自由切换不同的模型后端。
- **上下文构建器**：自动收集当前工作区中的相关上下文（打开的文件、选中代码、最近修改、项目结构等）并打包成 AI 模型可理解的提示。
- **多形态适配层**：为 VS Code、JetBrains 和 CLI 分别实现了适配器，将协议层的统一指令转化为各平台的原生操作。
- **可扩展的插件系统**：支持通过配置文件和自定义脚本扩展行为，例如添加自定义的代码块处理器或新的 AI 模型提供者。

这种架构使 Continue 非常灵活：用户可以在不同的 IDE 之间获得相似的体验，同时能够深度定制 AI 的行为。由于不依赖任何远程服务，Continue 尤其适合在离线环境或对数据安全有严格要求的场景中使用。

## 安装与使用

**VS Code 扩展**：
1. 打开 VS Code，进入扩展市场。
2. 搜索 "Continue" 并安装（或直接访问 market.visualstudio.com 搜索 `Continue.continue`）。
3. 安装后在左侧活动栏出现 Continue 图标，点击即可打开聊天面板。

**JetBrains 插件**：
1. 在 JetBrains IDE 中打开 Settings/Preferences → Plugins。
2. 搜索 "Continue" 并安装。
3. 安装后通过 Tool Windows 菜单打开 Continue 面板。

**CLI**：
```bash
# 全局安装 CLI 工具
npm install -g @continuedev/cli

# 使用 CLI 交互式对话
continue "Explain this function: $(cat myfile.ts)"
```

**最小可用示例**：
安装完成后，在 IDE 中打开一个代码文件，选中一段代码，然后在 Continue 面板中输入：“用中文解释这段代码做了什么”。或者直接输入：“为这个函数添加详细的 JSDoc 注释”。Continue 将根据当前上下文生成响应。如果未配置模型，首次使用时会有引导界面提示设置模型提供者（如 Ollama 本地模型或 OpenAI API）。

## 适用场景

- **本地开发环境下的智能代码补全与解释**：在不离开编辑器的前提下，快速获取对陌生代码的解释、寻找 bug 或获取重构建议。
- **批量代码任务处理**：通过 CLI 对项目中的多个文件执行重复性任务，如添加版权注释、转换代码风格、生成单元测试框架。
- **离线或高安全性开发**：结合本地大语言模型（如 Ollama 运行的模型），在完全断网的环境中获得 AI 编码协助，避免代码泄露风险。
- **学习与新项目探索**：帮助开发者快速理解一个不熟悉的代码库，或者为新项目生成初始代码骨架。

## 项目亮点

- **真正开源的替代方案**：与许多依赖云端服务的编码助手不同，Continue 提供了完整的、可自主托管的本地替代方案，其代码完全开放且可审计。
- **多 IDE 统一体验**：在 VS Code 和 JetBrains 之间提供几乎一致的功能和界面，降低了团队切换工具时的学习成本。
- **隐私优先的设计哲学**：2.0.0 版本彻底移除遥测和身份验证，让用户完全掌控自己的数据流和使用的模型。
- **极高的可定制性**：支持任意模型后端，且架构允许深度自定义。用户可以编写自己的提示模板、代码处理规则，甚至扩展新的功能入口。
