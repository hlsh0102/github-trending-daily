## 项目概述

Penpot 是一款面向设计和开发协作的开源设计工具。它完全基于 Web 浏览器运行，无需安装任何本地软件，旨在打破设计师与开发者之间的壁垒，让两者在同一平台上无缝协作。Penpot 解决了传统设计工具闭源、高昂授权费、以及难以与开发流程整合的痛点，适用于从独立设计师到大型企业团队的所有用户。作为一款被认证的数字公共产品，Penpot 承诺永远免费、开放，并鼓励社区贡献。

## 核心功能

- **基于 Web 的矢量设计**：无需安装，打开浏览器即可使用完整的矢量图形编辑功能，支持路径绘制、布尔运算、图层管理等专业设计操作。
- **实时多人协作**：支持团队成员同时编辑同一个设计文件，实时看到其他人的光标和修改，极大提升远程协作效率。
- **组件与样式系统**：支持创建可复用的设计组件和全局样式（颜色、字体、效果），便于保持设计一致性并快速迭代。
- **原型制作与交互**：可将静态设计稿连接成可交互的原型，支持点击、悬停等触发动作，直观展示用户流程。
- **开发者友好**：直接生成 CSS、SVG、HTML 代码片段，支持在设计稿中查看元素尺寸、间距和属性，减少沟通成本。
- **自托管能力**：提供 Docker 镜像和详细文档，用户可自行部署在私有服务器上，完全掌控数据安全与资源使用。

## 技术架构

Penpot 采用了前后端分离的架构。前端主要使用 **ClojureScript** 和 **React** 构建，利用函数式编程的优势实现高效且可靠的交互逻辑。后端则基于 **Clojure** 语言开发，搭配 **PostgreSQL** 数据库存储数据，**Redis** 用于缓存和实时消息推送（如协作编辑）。这种技术选型强调了性能与可扩展性：Clojure 的不可变数据结构非常适合处理复杂的图形状态，而函数式编程范式让并发协作中的冲突处理变得更加简洁可靠。此外，Penpot 完整采用了 **SVG** 作为原生文件格式，这意味着设计文件本身就是标准的 Web 矢量图形，开发者可以直接用代码访问和操作设计元素，实现了设计与代码的“同源”。

## 安装与使用

**快速开始（使用 Docker）**：

1. 确保已安装 Docker 和 Docker Compose。
2. 克隆 Penpot 官方 Docker 部署仓库：
   ```bash
   git clone https://github.com/penpot/penpot-docker.git
   cd penpot-docker
   ```
3. 启动服务：
   ```bash
   docker compose -p penpot up -d
   ```
4. 打开浏览器访问 `http://localhost:9001`，注册账号即可开始使用。

**最小可用示例（网页直接使用）**：

1. 访问 Penpot 官方公开实例：`https://design.penpot.app`。
2. 使用邮箱注册或直接登录（支持 GitHub/GitLab 账号登录）。
3. 创建一个新项目，在画布上绘制矩形和圆形，尝试使用组合路径功能（路径 -> 合并/减去/相交）。
4. 创建一个文本框，输入文字，并在右侧面板调整字体、大小和颜色。
5. 点击“导出”按钮，选择导出为 SVG 或 PNG 格式。

## 适用场景

- **初创公司与中小企业**：无需昂贵的设计工具授权费，通过自托管或免费云实例即可获得专业设计能力，且开发团队能直接查看样式信息，加速产品迭代。
- **开源项目与社区协作**：开源项目的设计资源可以以 Penpot 文件形式在 GitHub 仓库中分享，任何人都可以 fork 并参与设计修改，与代码协作流程无缝对接。
- **教育与培训**：教师可创建课堂设计项目，学生无需安装软件，通过浏览器即可参与协作练习，降低了设计学习的门槛。
- **设计与开发混合团队**：设计师使用 Penpot 完成界面设计，开发者可以直接在设计稿中读取尺寸、颜色代码和 SVG 图形，大幅减少沟通歧义和资源交接时间。

## 项目亮点

Penpot 相较于 Figma、Sketch 等同类工具，最核心的差异化优势在于其 **完全开源与自由** 的特性。它不是商业产品的“简化版”，而是提供了完整功能，并承诺永远保持免费和开放（MPL-2.0 许可）。其次，Penpot 的 **“代码优先”设计理念** 贯穿始终：设计文件即 SVG，开发者无需借助第三方插件即可提取设计信息。此外，它支持 **双向社区驱动**——用户可以根据自身需求提交功能请求或直接贡献代码，这种灵活性是任何闭源工具都无法提供的。最后，其 **自托管能力** 为注重数据隐私的企业提供了合规选择，这在当前设计工具市场中极为罕见。
