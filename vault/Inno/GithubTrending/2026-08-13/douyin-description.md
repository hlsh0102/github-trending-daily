今日 GitHub 趋势榜来了，十大开源项目一文速览 👇

1️⃣ **cathymnlavery/diagram-design**：AI 编程工具的图表技能包，29 种编辑级图表风格，自动匹配品牌配色字体，输出原生 HTML/SVG，告别千篇一律的圆角矩形。

2️⃣ **macro-inc/macro**：团队协作“全家桶”，将邮件、聊天、文档、任务、CRM 整合到一个 Rust 写成的快速界面，共享 AI 记忆，@ 引用串联一切，减少工具切换。

3️⃣ **semantica-agi/semantica**：面向高风险金融医疗领域的图原生 AI 基础设施。构建知识图谱，运行因果推理，决策全程可溯源，让 AI 从“黑盒”变白盒。

4️⃣ **stablyai/orca**：桌面端 AI 代理“调度中心”。同时并行运行 Codex、ClaudeCode 等多个编码代理，各自独立目录，统一追踪，用自己的订阅即可，效率翻倍。

5️⃣ **msitarzewski/agency-agents**：专业化 AI 代理“招聘库”。每个代理有独特个性和交付标准，覆盖前端开发、社群运营等场景，可直接集成到主流编程工具。

6️⃣ **shiyu-coder/Kronos**：金融大模型。从海量时间序列中学习市场“语言”，支持股票、加密、外汇等，可微调用于预测与风险管理，麻省理工许可。

7️⃣ **NanmiCoder/MediaCrawler**：自媒体数据采集神器。支持小红书、抖音、B 站、微博等七大平台，封装反爬细节，统一接口采集公开数据，仅供学习研究。

8️⃣ **hugohe3/ppt-master**：文档一键转原生可编辑 PPT。生成真形状、真动画与语音旁白，遵循你的自定义模板，PowerPoint 和 WPS 里随意改。

9️⃣ **infiniflow/ragflow**：开源 RAG 引擎。深度文档理解 + 图识别解析，配合 Agent 能力，精准检索复杂表格与版面，为公司大模型打造高质量私有知识库上下文。

🔟 **paperclipai/paperclip**：团队 AI 代理管理面板。统一监控、编排、调度多个智能体，可视化工作流，轻量可自托管，7.7 万星增长强劲。
