## 项目概述

MediaCrawler 是一个功能强大的多平台自媒体数据采集工具，专注于抓取国内主流内容平台的公开信息。项目目前支持小红书笔记与评论、抖音视频与评论、快手视频与评论、B站视频与评论、微博帖子与评论、百度贴吧帖子与回复，以及知乎问答文章与评论的采集。该项目在 GitHub 上已获得超过 62000 颗星，是目前最活跃的开源爬虫项目之一。

MediaCrawler 解决的痛点是：研究者和开发者需要跨平台采集公开内容数据时，往往需要为每个平台单独编写爬虫代码，维护成本高且容易因平台改版而失效。该工具将这些平台的抓取逻辑统一封装，提供一致的调用接口，让用户无需关心底层反爬细节即可完成数据采集。项目主要面向数据分析师、学术研究者、市场调研人员以及爬虫技术学习者。

需要特别说明的是，项目作者明确要求使用者以学习为目的使用本仓库，禁止用于商业用途和非法行为。

## 核心功能

- **多平台覆盖**：同时支持小红书、抖音、快手、B站、微博、贴吧、知乎七大平台，覆盖图文、视频、问答等多种内容形态。
- **内容与评论采集**：每个平台均支持内容正文和评论区数据的抓取，满足从内容到互动反馈的完整数据链路。
- **关键词搜索爬取**：支持按关键词搜索内容并进行爬取，适合主题研究和舆情监测场景。
- **指定博主批量爬取**：可输入指定博主的主页链接，批量获取该博主发布的所有内容及其评论。
- **灵活的输出格式**：支持 CSV、JSON 和数据库（如 MySQL、MongoDB）等多种数据存储方式，方便后续分析与处理。
- **代理池支持**：内置代理配置选项，可配合代理池使用以降低 IP 被封禁的风险。

## 技术架构

MediaCrawler 基于 Python 语言构建，核心依赖 Playwright 浏览器自动化框架。Playwright 通过控制真实的 Chromium 浏览器实例来执行 JavaScript 并模拟用户操作，从而绕过基于浏览器指纹和 JavaScript 渲染的反爬机制。这一设计使得工具能够稳定地抓取采用前端渲染（SPA）架构的现代 Web 应用。

在代码组织上，项目采用**平台模块化**架构。每个平台（小红书、抖音、快手等）都有独立的爬虫模块，这些模块继承自一个统一的抽象基类，实现了类似的接口方法（如 `start()`、`login()`、`get_content()` 等）。这种设计让新平台的接入变得相对容易，开发人员只需根据平台特性实现对应方法即可。

此外，项目内置了登录态管理机制。对于需要登录才能查看完整内容的平台（如小红书、抖音），工具支持通过扫码方式登录一次，并将 Cookie 序列化保存到本地，后续运行时可自动复用登录状态，有效减少登录次数和封号风险。

调度层面，MediaCrawler 使用了异步编程模式（`asyncio`）配合 Playwright 的异步 API，在保证并发效率的同时控制请求频率，避免对目标平台造成过大压力。

## 安装与使用

**环境要求**：Python 3.8+，支持 Windows、macOS 和 Linux 系统。

**安装步骤**：

1. 克隆仓库：
   ```bash
   git clone https://github.com/NanmiCoder/MediaCrawler.git
   cd MediaCrawler
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```

3. 安装数据库驱动（如使用 MySQL 或 MongoDB 存储）：
   ```bash
   pip install pymysql pymongo
   ```

**最小使用示例**：

以爬取小红书关键词内容为例：

```bash
python main.py --platform xhs --lt qrcode --type keyword --keyword "美食"
```

参数说明：
- `--platform`：指定平台，如 `xhs`（小红书）、`dy`（抖音）、`ks`（快手）、`bili`（B站）、`wb`（微博）、`tieba`（贴吧）、`zhihu`（知乎）
- `--lt`：登录方式，`qrcode` 表示扫码登录，也可以使用 `cookie` 方式
- `--type`：爬取类型，`keyword` 表示按关键词搜索，`detail` 表示指定帖子/视频链接
- `--keyword`：搜索关键词

首次运行时，程序会弹出浏览器窗口要求扫码登录对应平台。登录完成后，程序将自动执行搜索并抓取内容，默认输出到 `data/` 目录下的 CSV 或 JSON 文件。如需存储到数据库，可在配置文件中设置 MySQL 或 MongoDB 的连接参数。

## 适用场景

- **学术研究与舆情分析**：采集指定话题在多个平台的传播情况，分析不同平台用户对同一事件的态度差异。
- **市场调研与竞品分析**：跟踪竞品品牌在社交平台上的用户反馈与评论，辅助产品决策和营销策略制定。
- **内容运营与自媒体管理**：定期抓取目标领域热门内容，辅助选题策划和内容创作参考。
- **爬虫技术学习与研究**：研究主流网站的反爬策略与浏览器自动化技术的实际应用。

## 项目亮点

MediaCrawler 与同类爬虫工具相比，具有几项显著的差异化优势。

首先是**平台覆盖面广**。个人开发者维护的爬虫项目往往只专注于一两个平台，而 MediaCrawler 一次性覆盖七个主流中文平台，且保持同步更新，这在开源社区中较为罕见。

其次是**活跃的社区维护**。项目拥有超过 62000 星标和持续的正向增长趋势，作者保持着高频的代码更新和 Issue 响应，对于平台接口变动能够快速适配——这对于爬虫类项目至关重要。

第三是**工程化程度高**。项目不是简单的脚本集合，而是提供了完整的命令行界面、数据库持久化、登录态管理、代理配置等工程化能力，方便用户直接集成到自己的数据流水线中。

最后是**完善的多语言文档**。项目同时提供中文、英文和西班牙文版本的 README，降低了非中文使用者的上手门槛。
