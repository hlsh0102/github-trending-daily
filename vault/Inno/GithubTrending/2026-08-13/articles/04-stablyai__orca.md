## 项目概述

Orca 是一款面向开发者的 AI 代理编排桌面应用（ADE，Agent Desktop Environment），旨在解决多编码代理并行运行时面临的上下文隔离、会话管理和资源调度难题。它允许用户在同一工作界面中同时运行 Codex、ClaudeCode、OpenCode 等主流 AI 编码代理，让它们各司其职、协同工作。

对于追求极致效率的开发者，Orca 提供了一种全新的工作模式：让多个代理分别处理不同的代码库、文件或任务，而无需手动切换终端窗口或担心上下文互相干扰。项目采用 MIT 许可证开源，目前由 stablyai 组织维护，在 GitHub 上已获得超过 4.4 万 Star，并持续保持高速增长。

## 核心功能

- **多代理并行编排**：在同一界面中运行任意数量的编码代理（Codex、ClaudeCode、OpenCode 等），支持分屏查看各代理的工作状态，实现真正意义上的并行开发。
- **自带订阅接入**：使用您自己的 AI 服务订阅即可启动代理，无需额外购买 Orca 专属的 API 套餐，完全掌控使用成本。
- **跨平台运行**：原生支持 macOS、Windows 和 Linux 三大桌面操作系统，同时提供手机端和 VPS（云服务器）部署方案，随时随地接入您的代理工作流。
- **上下文隔离与环境持久化**：每个代理拥有独立的工作目录和会话历史，项目配置、环境变量和任务上下文在重启后自动恢复，无需重复初始化。
- **会话归档与回溯**：完整记录各代理的执行日志、文件变更和决策过程，支持按时间线回溯任意代理的思维过程，便于审计和复盘。
- **轻量级资源占用**：基于 TypeScript 开发，采用高效的进程管理和资源调度策略，即使同时运行多个代理，对宿主机的 CPU 和内存占用仍保持在合理水平。

## 技术架构

Orca 采用 Electron + TypeScript 构建跨平台桌面客户端，底层通过进程隔离机制将每个编码代理运行在独立的子进程中，并通过自定义的 IPC（进程间通信）协议实现主界面与各代理之间的高效数据交换。这种设计确保了某个代理的崩溃不会影响其他代理的正常运行，极大提升了系统的稳定性。

在 VPS 或移动端场景下，Orca 支持以客户端-服务器模式运行：桌面端作为控制面板，通过 WebSocket 或基于 HTTP 的 REST API 与远程代理进程通信，实现异地的任务分发和状态监控。核心编排引擎抽象了不同代理的输入输出接口，使得接入新的编码代理只需实现一个轻量适配器即可。

与同类工具相比，Orca 的创新点在于其"以任务为中心"的设计理念：用户可以先定义任务队列，再由编排引擎根据各代理的专长和当前负载自动分配任务，而非简单地提供多窗口平铺功能。这种任务调度算法经过了多轮优化，能够在混合使用开源模型（如 OpenCode）和商业模型（如 ClaudeCode）时保持出色的吞吐效率。

## 安装与使用

**桌面端安装**：访问 [GitHub Releases](https://github.com/stablyai/orca/releases) 页面，下载对应操作系统的安装包（macOS 用户可选择 .dmg 或 .zip 格式，Windows 用户使用 .exe 安装程序，Linux 用户可选择 .AppImage 或 .deb 包）。安装完成后，首次启动需要完成以下三步：

1. 在"设置"中填入您的 AI 服务 API Key（支持 OpenAI、Anthropic、OpenCode 等提供商）。
2. 选择一个工作目录作为默认项目根路径。
3. 从"代理管理"面板添加您已安装的编码代理 CLI 工具（如 `codex`、`claude` 等），Orca 会自动检测并注册。

**最小使用示例**：

```bash
# 1. 启动 Orca
# 2. 在界面右上角点击"+"号，选择"Codex"作为代理类型
# 3. 指定一个任务描述，例如："重构 src/utils.ts 中的日期函数"
# 4. 点击"运行"，Orca 将在隔离环境中启动 Codex 代理并实时展示输出
# 5. 重复步骤 2-4 添加第二个代理，分配"编写 README 文档"任务
# 6. 观察两个代理并行工作，分屏查看各自进展
```

**VPS 部署**：Orca 提供无头（headless）模式，可通过 `npm install -g @stably/orca-server` 安装服务端，然后在桌面端使用远程连接功能进行管理。

## 适用场景

- **代码评审与并行重构**：将多个编码代理分别指派给不同模块的重构任务，再由审查代理统一检查代码质量和风格一致性，可将大型重构周期从数天压缩到数小时。
- **文档与代码同步生成**：让一个代理专职阅读源代码并生成 README、API 文档，另一个代理负责编写测试用例，两者并行互不干扰，显著提升项目交付效率。
- **复杂问题排查**：当遇到难以定位的 bug 时，可以让多个代理从不同角度（如日志分析、堆栈追踪、依赖冲突排查）同时入手，并在 Orca 中汇总各代理的排查结论，辅助快速定位根因。

## 项目亮点

Orca 与市面上的多代理管理工具（如 Claude Projects 或自定义脚本方案）相比，主要优势体现在三个方面：

**第一，真正的"自带订阅"模式。** 用户无需为 Orca 的代理计费，只需使用已有的 AI 服务订阅，极大地降低了尝试门槛和长期成本。

**第二，跨平台且形态完整。** 从桌面端到移动端再到 VPS 的无缝切换能力，在同类型开源项目中相当稀缺。无论是个人开发者在家用笔记本上的轻量使用，还是团队在云端 GPU 服务器上的重负载运行，Orca 都能提供一致的体验。

**第三，任务优先的编排哲学。** 不局限于"把多个终端塞进一个窗口"，而是通过任务队列和智能调度让代理协作更自然。其开源协议允许开发者按需深度定制，这是封闭商业产品难以比拟的灵活性。
