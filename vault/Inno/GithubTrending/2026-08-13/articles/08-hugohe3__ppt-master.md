## 项目概述

PPT Master 是一个基于人工智能的演示文稿生成工具，它能够将各类文档或主题描述直接转化为真正原生、可编辑的 PowerPoint 文件。与市面上大多数“生成 PPT”工具不同，PPT Master 生成的不是图片拼接的 PDF 或简易网页，而是包含原生形状、切换效果、动画、图表、表格以及音频旁白的 .pptx 文件，这意味着用户可以像对待手工制作的演示文稿一样，在 Microsoft PowerPoint 或 WPS 中自由编辑、二次修改。

该项目由 Hugo He 发起并维护，以 MIT 许可证开源，目前在 GitHub 上已获得超过 4.5 万颗星标，社区活跃度极高。无论你是需要快速准备课堂展示的学生、频繁产出方案汇报的职场人士，还是希望自动化生成报告的内容团队，都能借助 PPT Master 将构思到成品所需的时间从数小时压缩到数分钟甚至更短。

## 核心功能

- **原生 PowerPoint 输出**：生成的文件包含真正的原生形状、母版、切换效果与动画，绝非图片或 PDF 的伪装，所有元素都可以在 PowerPoint 中直接编辑。
- **文档/主题双模式生成**：既支持上传 Word、Markdown、PDF 等现有文档作为输入源，也支持仅输入一句话主题，由 AI 自动规划大纲并生成完整演示文稿。
- **数据驱动的图表与表格**：当内容涉及数据统计或对比时，AI 能主动生成带真实数据支撑的柱状图、饼图、折线图及规范化表格，而非文字性描述。
- **自定义模板支持**：允许用户上传自己的 .pptx 模板，AI 在生成内容时会自动适配模板的版式、配色与字体风格，保持品牌一致性。
- **智能音频旁白生成**：根据每页幻灯片的演讲者备注，自动合成高质量的语音旁白，并嵌入到对应页面中，非常适合远程教学或自动演示场景。
- **多语言内容支持**：内置多语言处理能力，可以根据输入文档的语言生成相应语言风格的演示文稿，并能准确理解中英文混排材料。

## 技术架构

PPT Master 的核心架构围绕“AI 内容生成层”与“原生 PPT 构建层”分离设计。在内容生成层，项目接入多种主流大语言模型 API（如 Kimi、OpenAI 兼容接口等），通过精心设计的提示词链（Prompt Chain）将输入文档拆解为大纲、每页要点、演讲者备注、图表数据等结构化中间表示。这种结构化提取使得后续构建层能够精准映射到 PPT 对象模型上。

在 PPT 构建层，项目基于 python-pptx 库进行了深度封装和扩展，开发了一套“语义化建模范式”。开发者可以像描述“这一页需要一个标题、三个要点和一个柱状图”这样声明式地定义幻灯片结构，底层引擎会自动计算布局坐标、缩放比例、字体大小等细节，确保生成的幻灯片既美观又不越界。此外，针对切换动画和音频嵌入等复杂特性，项目直接操作 OOXML 底层协议，绕过了标准库的功能限制，实现了对 PPT 动画和音频的完整控制。

架构上还设计了一个缓存与异步任务系统，长时间运行的生成任务会以队列形式处理，用户可以在等待过程中收到进度通知，同时避免重复生成相同内容造成资源浪费。

## 安装与使用

PPT Master 采用 Python 编写，支持 Python 3.9 及以上版本。安装过程十分简单，使用 pip 即可完成：

```bash
# 安装 PPT Master
pip install ppt-master
```

首次使用前，需要配置大语言模型的 API 密钥。你可以在环境变量中设置，比如使用 Kimi 作为默认模型：

```bash
export KIMI_API_KEY="your_api_key_here"
```

接下来，只需执行一条命令即可根据 Word 文档生成演示文稿：

```bash
# 从文档生成
ppt-master generate --source ./产品白皮书.docx --output ./产品介绍.pptx

# 从主题直接生成
ppt-master generate --topic "2024年新能源行业趋势分析" --slides 12
```

若需要使用自定义模板，只需追加 `--template` 参数：

```bash
ppt-master generate --topic "季度财务汇报" --template ./公司模板.pptx --output ./Q3汇报.pptx
```

你也可以通过 Python 代码以更灵活的方式调用：

```python
from ppt_master import PPTMaster

client = PPTMaster(api_key="your_key")
client.generate(
    source="2025年度市场策略规划.docx",
    output="策略规划.pptx",
    template="brand.pptx",
    with_audio=True  # 自动生成旁白
)
```

## 适用场景

- **企业汇报与投融资演示**：分析师或产品经理可将冗长的研究报告一键转化为精简的呈现材料，AI 自动提炼关键指标并生成图表，加速决策沟通。
- **教育培训课件制作**：教师只需提供讲义或教学大纲，即可生成包含动画演示和语音旁白的课程 PPT，可应用于在线教育平台或翻转课堂。
- **会议纪要与任务同步**：将会议记录的 Markdown 文本直接转换为分发用幻灯片，便于参会者回顾重点行动项，保持信息同步。
- **内容营销与自媒体创作**：博主和营销人员可快速将长文观点拆解为视觉化分享卡片，配合音频旁白生成适合视频号的自动播放内容。

## 项目亮点

- **真正的可编辑性**：在演示文稿自动生成领域，绝大多数工具生成的是“死图”，而 PPT Master 输出的是活生生的原生文档，彻底解决了后续修改痛点。
- **模板感知能力**：不同于简单套用固定版面，系统能解析模板中的母版结构、配色变量和占位符规则，生成内容自动适应品牌视觉规范。
- **端到端的自动化闭环**：从文本、图像、表格到音频，全链路由 AI 驱动，整体产出物即是一个完整的多媒体演示包，无需人工拼接素材。
- **高度开放的集成生态**：支持接入多种大模型平台 API，并提供 Python SDK 与命令行双接口，方便开发者嵌入自有工作流或构建上层应用。
