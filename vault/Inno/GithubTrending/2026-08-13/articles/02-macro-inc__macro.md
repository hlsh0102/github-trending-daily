## 项目概述

Macro 是一个面向团队的一体化工作空间，将电子邮件、即时消息、文档、任务管理、AI 代理、通话和 CRM 统一到一个快速流畅的界面中。所有工作对象通过 `@` 符号进行关联引用，并共享团队级别的 AI 记忆，从而让团队成员和 AI 代理无需在多个工具之间来回切换。

该项目由 Macro Inc. 开发，使用 Rust 语言编写，遵循 AGPL-3.0 开源协议。Macro 的诞生源于创始团队自身的痛点：在将上一家创业公司扩展到约 20 人规模时，团队分别使用了 Slack、Linear、Notion、HubSpot 和 Superhuman 等工具，但这些工具之间无法有机协作，公司被各种集成和自动化脚本“缝补”在一起，整体运转混乱且难以计算。Macro 是对企业办公软件的一次彻底重新设计，旨在为团队提供一个真正意义上的“操作系统”。

## 核心功能

- **统一消息与沟通**：将电子邮件和即时消息整合在同一界面中，支持团队内部及外部沟通的无缝切换，告别在邮件客户端和聊天软件之间反复横跳的碎片化体验。
- **文档与知识库**：内置团队文档协作功能，支持实时编辑与共享，文档中的任何内容都可以通过 `@` 引用其他工作对象，形成知识网络。
- **任务与项目管理**：提供任务分配、进度跟踪和项目管理能力，任务可以与相关的文档、消息和客户记录直接关联，确保上下文完整。
- **AI 代理与共享记忆**：内置可配置的 AI 代理，能够访问团队共享的记忆层。代理可以自动总结对话、提取待办事项、搜索历史记录，并基于团队上下文提供智能建议。
- **内置 CRM 与客户记录**：将客户关系管理直接嵌入工作空间，所有与客户相关的沟通、文档和任务自动汇聚在统一的客户视图中，无需单独维护 CRM 系统。
- **全局 `@` 关联与搜索**：任何对象（消息、文档、任务、客户、联系人）都可以通过 `@` 符号被引用到其他位置，并支持全局快速搜索，确保信息随时可查。

## 技术架构

Macro 的底层使用 Rust 语言开发。Rust 的高性能、内存安全和并发特性为该应用提供了坚实的性能基础，使其能够处理大量实时消息和文档编辑操作，同时保持界面流畅与响应迅速。

在架构设计上，Macro 采用了“共享团队记忆”作为核心数据层。所有工作对象（消息、文档、任务、客户记录等）并非孤立存储，而是通过统一的数据模型相互关联。这种设计使得 `@` 引用成为可能——当一个文档或消息中引用了一个任务或联系人时，系统能自动解析并建立起持久的关系链接。

AI 能力并非外挂组件，而是原生集成在数据层之上。AI 代理能够读取和写入团队记忆，理解实体之间的关系，从而在对话、任务管理和信息检索等场景中提供上下文相关的辅助。这一架构使得 AI 不只是简单的聊天机器人，而是真正能够操作和查询团队全部工作数据的智能助手。

前端方面，Macro 提供了高度集约化的单页界面，将多种工具视图融合为统一体验，减少了用户在模块间切换的认知负担。

## 安装与使用

Macro 目前提供托管云服务，用户可以直接访问 [macro.com/app](https://macro.com/app) 注册使用。对于希望自行部署或参与开发的用户，可以从 GitHub 仓库获取源码进行构建。

```bash
# 克隆仓库
git clone https://github.com/macro-inc/macro.git
cd macro

# 按照仓库中的 CONTRIBUTING.md 指南配置开发环境
# 编译并运行（具体命令见仓库文档）
cargo build
cargo run
```

在使用层面，Macro 采用低上手成本的设计。注册后即可创建团队工作空间，导入或创建文档、发起消息，并通过 `@` 符号引用团队成员、文档、任务或客户记录。AI 代理可通过自然语言指令调用来辅助完成各类工作，例如“@agent 总结今天与客户的邮件往来”或“@agent 将这份文档中的待办事项创建为任务”。

详细的使用指南和功能文档可参考 [docs.macro.com](https://docs.macro.com)。

## 适用场景

- **创业公司与小型团队**：需要以极低成本获得完整办公套件，并希望打破工具孤岛，让团队信息统一流动，尤其适合从初期就希望构建知识积累的团队。
- **以客户为中心的业务团队**：销售、客户成功和交付团队可以在同一界面中管理客户沟通、合同文档和任务，无需在 CRM 和协作工具间复制粘贴信息。
- **需要 AI 深度介入的团队**：希望 AI 代理不只是独立聊天工具，而是能够读取和检索团队全部工作上下文的团队，可以利用 Macro 的共享记忆能力显著提升信息整理和检索效率。
- **对工具整合度有极高要求的远程分布式团队**：通过统一的消息、文档与任务中心，减少远程协作中的信息丢失和“工具切换疲劳”。

## 项目亮点

与同类产品（如 Notion、Slack + 各类插件组合）相比，Macro 的核心差异化在于所有功能共享同一数据模型与记忆层。`@` 关联不是简单的超链接，而是系统层面的实体关系，这使得 AI 代理能够真正理解和操作这些关系，实现跨模块的自动化。此外，Rust 的高性能后端提供了极其流畅的交互体验，摆脱了传统 Electron 类应用可能存在的卡顿。

该项目在 GitHub 上迅速获得了大量关注（2000+ 星标），反映了市场对下一代一体化工作平台的强烈需求。
