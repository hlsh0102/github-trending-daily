## 项目概述

Diagram Design 是一个为 Claude Code、Codex 和 Pi 等 AI 编程助手设计的技能包（Skill），提供了 29 种编辑级质量的图表类型。该项目解决了开发者在使用 AI 生成图表时面临的普遍痛点：千篇一律的圆角矩形、花哨的阴影效果、以及需要花费大量时间在 Figma 中手动调整样式的问题。

项目的目标用户是那些希望在文档、博客文章或演示文稿中嵌入专业图表的开发者和技术写作者。通过该技能，用户可以直接用自然语言描述需求，获得与品牌风格一致的自包含 HTML + SVG 图表，无需任何外部设计工具。

## 核心功能

- **29 种编辑级图表类型**：涵盖架构图、流程图、金字塔图、队列图、策略追踪图、信任边界图等多种视觉表达形式，每种类型都经过精心设计，符合编辑出版标准。
- **品牌风格自动适配**：通过读取用户的网站或设计规范，在 60 秒内将图表样式与品牌形象对齐，包括配色、字体和间距。
- **语义化模式系统**：图表的行为逻辑（如队列、策略追踪、信任边界）与布局分离，允许不同类型的图表共享底层语义模式，无需增加新的图表类型即可扩展表达范围。
- **静态输出与可选动效**：默认生成静态 HTML，确保兼容性和可访问性；对于需要逐步讲解的场景，可启用可访问的动效模式。
- **多源格式转换**：支持将 draw.io 或 Mermaid 生成的图表源文件重新绘制为指定格式、尺寸和细节层级。
- **跨工具兼容**：作为通用的 Agent Skill，可同时用于 Claude Code、Codex 和 Pi，无需针对不同平台单独适配。

## 技术架构

Diagram Design 的核心设计理念是“语义与布局分离”。项目定义了一套抽象的行为语义模式，这些模式描述了图表元素之间的关系（例如依赖、循环、边界），而非具体的视觉呈现。每个图表类型在底层引用一种或多种语义模式，并通过 HTML + SVG 的渲染层将其转化为编辑级视觉输出。

自包含是另一个关键架构特点。所有图表都被渲染为单个 HTML 文件，内嵌 SVG 图形，不依赖外部 JavaScript 库或网络字体，确保在任何环境中都能正确显示。同时，项目默认不添加阴影等装饰性效果，强调内容本身的清晰性和信息传达效率。

新版本中引入的 Loop 类型展示了其创新性的“共享内存枢纽”设计：飞轮图中的虚线代表数据回写路径，这种表现手法在语义上精确地描述了状态更新的循环机制。此外，项目持续优化语义类型的数量控制，通过行为抽象而非类型堆砌来扩展表达能力，保持了系统的简洁性和可维护性。

## 安装与使用

安装 Diagram Design 十分简单。首先，确保你已安装 Claude Code、Codex 或 Pi 之一。然后将该技能包克隆或下载到本地，并按照对应工具的 Skill 配置指南将其接入。

最小使用示例如下：

1. 在 Claude Code 中，向模型发出指令：“使用 Diagram Design 技能，绘制一个描述用户认证流程的架构图。”
2. 模型将调用该技能，自动选择合适的图表类型（如队列图或流程图），并生成一个自包含的 HTML 文件。
3. 打开生成的 HTML 文件，即可在浏览器中查看和导出图表。
4. 如需品牌适配，指定网站 URL：`——参考 littlemight.com 的视觉风格`，技能会自动抓取并匹配样式。

对于已有的 Mermaid 或 draw.io 图表，可直接提供源文件：“将此 Mermaid 流程图重新绘制为 800 像素宽的编辑级 SVG”，技能将完成格式转换和样式优化。

## 适用场景

- **技术文档撰写**：在 API 文档、架构说明或设计提案中嵌入专业图表，提升文档的可读性和说服力。
- **博客与内容创作**：为技术博客、行业分析文章配备定制化的视觉元素，避免使用千篇一律的库存图或通用模板。
- **产品演示与汇报**：快速生成用于内部评审或客户演示的系统架构图、业务流程桶图，保证品牌视觉一致性。
- **设计系统补充**：在缺乏专业设计资源的情况下，为设计系统提供高质量的基础图表组件。

## 项目亮点

与同类项目相比，Diagram Design 最显著的差异化在于对“编辑级质量”的坚持。它没有追随当前 AI 生成内容的“Mermaid 风格”或“通用圆角框”潮流，而是基于出版和编辑设计的专业标准，提供了一种视觉上更接近专业杂志或书籍中图表质感的解决方案。

项目将图表行为语义与布局解耦的架构思想，使其具备了超越简单模板系统的扩展能力。语义模式可以复用，从而避免了图表类型无限膨胀的问题，这一设计体现了良好的工程思维。

此外，对静态输出默认策略和可选动效的权衡也值得关注——在保证内容可访问性和环境兼容性的同时，为用户提供了渐进增强的选项，而非强制所有场景使用动画效果。
