## 项目概述

OpenMontage 是全球首个开源、智能体驱动的视频制作系统。它将大型语言模型（LLM）的能力与完整的视频生产流程相结合，提供了一套从概念到成片的自动化解决方案。项目内置了 12 条生产流水线（Pipeline）、100 多个工具以及 700 多个智能体技能与制作知识文件，能够将你现有的 AI 编程助手直接转变为功能完整的视频制作工作室。

该项目主要面向视频创作者、内容团队、AI 开发者以及希望通过自然语言交互来简化视频制作流程的各类用户。无论你是需要快速生成宣传片、教学视频，还是希望将既有素材进行二次创作，OpenMontage 都能通过智能体编排的方式，大幅降低视频制作的技术门槛和时间成本。

## 核心功能

- **12 条生产流水线**：覆盖视频制作的全生命周期，包括策划、脚本撰写、素材收集、剪辑、配音、字幕、色彩校正、导出发布等环节，每条流水线都针对特定的视频类型进行了优化。
- **100+ 集成工具**：内置了丰富的工具链，支持调用外部 API（如语音合成、图像生成、视频编辑引擎），也包含本地处理的脚本工具，实现了制作环节的全面自动化。
- **700+ 技能与知识文件**：系统包含了大量由专业制作团队沉淀下来的技能模块（如分镜设计技巧、转场节奏建议）和领域知识文档，让智能体在处理任务时具备专业水准的判断力。
- **智能体编排与协同**：支持多智能体并行工作，每个智能体负责一个制作环节（如编剧、导演、剪辑师），通过统一的调度机制协同完成任务。
- **自然语言驱动**：你可以直接用中文或英文描述视频需求（例如“根据这篇博客做一个 2 分钟的科普视频”），系统会自动拆解任务并执行对应流水线。
- **可扩展与定制**：所有流水线和技能均以模块化方式组织，开发者可以基于项目提供的接口自定义新的工具或替换现有流程。

## 技术架构

OpenMontage 的核心架构遵循“智能体 + 流水线 + 工具库”的三层设计思路。

- **智能体层（Agent Layer）**：系统基于最新的 Agent 框架（如 ReAct 模式）构建了多个具备专业角色的智能体。每个智能体都被赋予了独立的提示词（Prompt）、工具集以及行为约束，可以在复杂任务中自主决策。
- **流水线层（Pipeline Layer）**：流水线被定义为一个有向无环图（DAG），每个节点代表一个具体的处理步骤或工具调用。这种设计使得流程可编排、可监控、可回放，并且可以轻松地插入或移除中间环节。
- **工具层（Tool Layer）**：工具层封装了所有外部依赖，包括但不限于 FFmpeg 命令封装、API 客户端（用于连接 TTS、LLM 视觉模型等）以及文件处理模块。工具的输出均被标准化为中间格式，确保不同流水线之间的数据兼容。

此外，项目支持多种模型提供商（见 `docs/PROVIDERS.md`），你可以通过配置文件切换底层所使用的 LLM（如 OpenAI、Anthropic、或本地部署的模型）。整个系统采用 Python 编写，利用异步 I/O 处理耗时任务，保证了高吞吐下的稳定性。

## 安装与使用

**安装步骤**（以 Python 3.10+ 为例）：

1. 克隆仓库：
   ```bash
   git clone https://github.com/calesthio/OpenMontage.git
   cd OpenMontage
   ```

2. 创建虚拟环境并安装依赖：
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. 配置 API 密钥（以下为最小化配置）：
   ```bash
   cp .env.example .env
   # 编辑 .env，填入你的 OpenAI 或 Anthropic API Key
   ```

4. 启动命令行交互或调用 Python API：

   **最小示例：使用自然语言生成视频脚本**
   ```python
   from openmontage import MontageStudio

   studio = MontageStudio()
   result = studio.run_prompt(
       "制作一个 60 秒的产品介绍短视频，风格为科技感"
   )
   print(result.script)  # 输出生成的脚本内容
   ```

   **使用预置流水线：**
   ```bash
   python -m openmontage.cli --pipeline news_video --topic "AI最新进展"
   ```

## 适用场景

- **内容工作室的自动化生产**：针对短视频平台（如抖音、YouTube Shorts）的高频内容需求，可搭建自动化生产链路，将图文素材或 RSS 新闻源自动转化为视频。
- **教育与培训材料生成**：将讲义、课件或论文摘要快速转换为配音讲解视频，适合在线教育平台和企业内部培训。
- **广告与营销素材的快速迭代**：营销团队可在几小时内生成多个版本的视频广告，并通过 A/B 测试筛选最佳创意。
- **个人创作者的 AI 辅助工作流**：作为你编程助手的“插件”，在编写代码的间隙直接生成视频说明文档或演示视频，提升个人产出效率。

## 项目亮点

- **全球首个开源方案**：在视频制作领域，大多数商用系统为闭源且昂贵，OpenMontage 提供了一套完整的开源替代品，且采用 AGPLv3 许可证，允许自由使用和修改（需开源衍生作品）。
- **知识深度与工具广度的结合**：700+ 技能文件不是简单的代码片段，而是经过梳理的专业制作知识（如构图法则、声音设计规范），这使得输出的视频不仅在流程上完整，在审美和逻辑上也更具专业性。
- **低门槛接入**：项目提供了清晰的 Agent Guide 和 Provider 配置文档，即便你不熟悉视频制作细节，仅凭自然语言也能启动复杂任务；对于开发者而言，模块化的设计也方便二次开发。
- **活跃的社区与趋势地位**：项目在 GitHub 上已获得超过 5.3 万星标，且近期增长迅猛，表明其解决了视频创作者的真实痛点，并获得了广泛认可。
