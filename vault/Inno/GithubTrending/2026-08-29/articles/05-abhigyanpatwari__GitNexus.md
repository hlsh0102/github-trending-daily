## 项目概述

GitNexus 是一款运行在浏览器中的零服务器代码智能引擎，致力于将任意 Git 仓库转化为交互式知识图谱。用户只需将 GitHub、GitLab、Azure Repos 或本地 Git 仓库，甚至 ZIP 压缩包拖入浏览器，GitNexus 便会在本地完成全部解析与建模工作，生成可视化的代码关系网络，并内置一个基于 Graph RAG（检索增强生成）的智能问答助手，帮助开发者快速理解陌生代码库的结构与逻辑。

该项目主要面向需要频繁探索新代码库的开发者、技术负责人、开源贡献者以及代码审计人员。它解决了传统代码阅读方式中“只见树木不见森林”的痛点——当面对一个包含数百个文件、数千个函数的大型仓库时，GitNexus 能够自动提取实体与依赖关系，并以图谱形式呈现，让代码的全貌与细节一目了然。

## 核心功能

- **多源仓库导入**：支持从 GitHub、GitLab、Azure Repos 直接克隆，也支持上传本地 ZIP 压缩包或选择本机目录，无需配置任何服务器或数据库。
- **自动知识图谱生成**：解析仓库中的 TypeScript、JavaScript、Python、Java 等主流语言代码，自动提取模块、类、函数、变量及其调用关系，构建有向知识图谱。
- **Graph RAG 智能问答**：内置基于知识图谱的检索增强生成引擎，用户可以用自然语言提问（如“登录流程是如何实现的？”），系统会结合图谱中的实体关系生成上下文相关的回答。
- **交互式图谱可视化**：基于力导向布局的交互式画布，支持缩放、拖拽、节点聚焦与关系过滤，帮助用户从任意切入点浏览代码结构。
- **零数据出境**：所有解析、建模与问答均在浏览器本地完成，代码内容不会上传到任何服务器，适合对代码保密性有高要求的场景。
- **轻量级部署**：作为一个纯前端单页应用，可通过 npm 一键启动，也支持构建后部署到任意静态托管平台（如 GitHub Pages）。

## 技术架构

GitNexus 采用纯前端架构，以 TypeScript 为开发语言，核心设计理念是“一切计算都在客户端完成”。在技术选型上，它依赖以下关键组件：

- **文件解析引擎**：利用 Web Worker 在后台线程中解析多种编程语言的语法树，避免阻塞主线程 UI。对于 Git 仓库，采用 wasm-git 类库实现浏览器端的 Git 协议支持，无需依赖后端代理。
- **图谱数据模型**：采用内存中的图数据库结构，以邻接表方式存储节点（文件、符号）与边（导入、调用、继承关系），并支持增量更新。
- **Graph RAG 管道**：将知识图谱作为外部知识源，结合向量化嵌入模型与向量索引，在问答时先检索相关子图，再交由大语言模型（可切换 OpenAI、本地模型等）生成回答，实现“先定位，后回答”的精准推理。
- **可视化层**：使用 Canvas 技术实现高性能图谱渲染，配合自定义的力导向算法，确保即使包含数万节点的图谱也能保持流畅交互。

架构上最大的特点是“零服务器”不做妥协：即使面对大规模仓库，也通过分片解析与 Web Worker 并行策略来保障性能，同时所有数据仅驻留在浏览器内存中，关闭标签页即完全清除，从物理层面断了数据泄露的可能。

## 安装与使用

GitNexus 提供了非常简单快捷的启动方式。首先确保本机已安装 Node.js（v18 及以上版本），然后通过 npm 全局安装：

```bash
npm install -g gitnexus
```

安装完成后，在任意目录启动：

```bash
gitnexus
```

浏览器会自动打开本地地址 `http://localhost:3000`，即进入 GitNexus 界面。如果是通过 Docker 或直接克隆源码使用，也可以：

```bash
git clone https://github.com/abhigyanpatwari/GitNexus.git
cd GitNexus
npm install
npm start
```

首次使用时，在左侧面板选择仓库来源（GitHub/GitLab/Azure/本地/ZIP），粘贴仓库地址或上传文件。GitNexus 会在几十秒内完成解析，随后生成完整的知识图谱。用户可以在右侧问答窗口输入问题，例如：

```text
“请解释 paymentService 模块中 validatePayment 方法的完整调用链”
```

系统会返回结构化的回答，并高亮图谱中相关的节点与路径，辅助开发者快速定位核心逻辑。

## 适用场景

- **新成员快速上手项目**：开发者加入新团队或接手遗留系统时，通过 GitNexus 快速生成图谱，从入口文件开始追踪依赖关系，大幅缩短“看代码”的时间成本。
- **代码审查与架构评估**：技术负责人在进行系统重构或技术选型前，使用图谱检查模块耦合度、识别循环依赖与上帝类，为架构决策提供可视化依据。
- **安全审计与漏洞溯源**：安全工程师在审查开源依赖或内部代码时，利用 Graph RAG 语义搜索快速定位敏感函数（如 `eval`、`exec`）的调用路径，提高审计覆盖度。
- **离线环境代码研究**：在无法访问外网的隔离开发环境中，通过本地 ZIP 导入代码，依然获得完整的图谱问答能力，不依赖任何云服务。

## 项目亮点

GitNexus 的差异化优势主要体现在以下方面：第一，真正意义上的“零服务器”——不同于大多数代码分析工具需要自建后端服务或依赖云端 API，GitNexus 完全在浏览器内完成，从根源上消除数据隐私顾虑与部署成本。第二，将知识图谱与 RAG 深度结合，不是简单的文本检索，而是基于结构化关系的语义推理，问答结果更为准确且可解释。第三，支持多语言与多仓库源，且解析速度快，对于大型 Monorepo 仓库也能流畅处理。第四，项目采用 PolyForm Noncommercial 许可证，免费开放给个人与内部使用，同时社区活跃（已获得 OpenSSF 安全评分高分），并在 Discord 上提供及时的支持与反馈渠道。
