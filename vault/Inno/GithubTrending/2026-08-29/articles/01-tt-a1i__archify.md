## 项目概述

Archify 是一个面向 AI 编程代理（如 Cursor、Claude Code、Codex CLI 和 OpenCode）的 Node.js 渲染与验证系统，旨在于聊天环境中直接将代码库或系统描述转化为精美、可交互的系统架构图。该项目解决了软件开发中架构文档难以维护、图表与代码脱节、以及传统绘图工具无法嵌入 AI 工作流等核心问题。通过让 AI 代理生成类型化的 JSON 中间表示（IR），Archify 能够确定性地将其编译为自包含的 HTML/SVG 文件，使得架构图不仅可以打开演示，还能在合并前进行差异对比，确保每一次架构变更都有据可查。目标用户包括使用 AI 辅助开发的软件工程师、架构师、技术文档撰写者以及需要向团队或客户展示系统设计的专业人士。

## 核心功能

- **五种图表类型与四套预设**：支持架构图、工作流图、序列图、数据流图和生命周期图，并提供四套视觉预设，配合深色/浅色主题与内置品牌标识，开箱即用。
- **架构变更对比**：可将两个验证过的架构快照进行“之前/差异/之后”三态对比，精确列出新增、删除、修改、移动和重路由的事实，便于在合并前审查架构变更。
- **可追溯的交互探索**：支持搜索节点、打开经修订验证的源码链接、追踪上游/下游的关联范围与精确路由，还能对比角色差异，播放引导式解说，全程不虚构拓扑结构。
- **单文件输出与多格式导出**：基于类型化 JSON IR 和确定性检查，生成自包含的 HTML 文件，同时可导出 PNG、SVG、WebM 视频以及 1200×630 分享卡片，便于分享和嵌入文档。
- **有限的动效与品牌集成**：内置微妙的动画效果提升演示质感，同时保持克制，避免喧宾夺主；支持自定义品牌标识，使图表与公司或产品视觉风格统一。
- **确定性验证机制**：所有图表的生成都经过确定性检查，保证同一输入必然产生同一输出，便于自动化测试和持续集成。

## 技术架构

Archify 的核心设计遵循“类型化 JSON IR + 确定性编译”的管线架构。AI 代理首先将系统描述或代码库分析结果转换为严格类型的 JSON 中间表示，该 IR 定义了节点、边、层级、角色和路由等语义元素，不涉及任何视觉细节。随后，Archify 的 Node.js 渲染引擎接收这一 IR，通过一套确定性算法将其映射到布局、样式和交互逻辑，最终生成自包含的 HTML 文件（内含内联 SVG）。这种架构的优势在于：一方面，AI 代理只需关注拓扑事实的提取，无需处理复杂的视觉布局；另一方面，渲染引擎的确定性保证了图表生成的可重复性和可测试性。此外，系统内置验证层，能够检查 IR 的完整性和一致性，拒绝生成含有悬空引用或非法拓扑的图表。整个系统设计为可在 Cursor、Claude Code、Codex CLI 和 OpenCode 多种代理环境中无缝运行，并以 MIT 许可证开源，便于社区扩展和定制。

## 安装与使用

### 安装

Archify 作为 Node.js 包分发，可通过 npm 或直接集成到 AI 代理的配置中。基础安装方式如下：

```bash
npm install archify
```

对于 Cursor 或 Claude Code 等代理，可将其作为 Agent Skill 引入，在代理配置中声明 Archify 的调用接口即可。

### 最小可用示例

以下是一个在 AI 代理会话中生成架构图的典型流程：

1. **描述系统**：在聊天中向代理描述你的系统，例如“一个包含前端、后端 API、数据库和缓存层的微服务架构”。
2. **代理生成 IR**：代理自动调用 Archify，生成对应的类型化 JSON IR（无需手动编写）。
3. **渲染图表**：Archify 将 IR 编译为自包含的 HTML 文件，保存在工作目录。
4. **打开与导出**：直接用浏览器打开 HTML 文件即可交互查看，或使用 CLI 命令导出 PNG/SVG：

```bash
archify render input.json --output diagram.html
archify export diagram.html --format png --output diagram.png
```

## 适用场景

- **AI 辅助架构评审**：在 Cursor 或 Claude Code 中分析代码库时，即时生成当前架构图，并在重构前后对比差异，确保变更符合预期。
- **技术文档与演示**：为团队会议或客户演示制作精美的系统架构图、时序图或数据流图，无需依赖收费的绘图软件。
- **持续集成中的架构验证**：将 Archify 集成到 CI 流程，每次代码合并前自动生成架构快照并对比，防止架构腐化。
- **知识库与新人培训**：为新员工生成系统生命周期图和工作流图，辅以可点击的源码链接，加速理解存量系统。

## 项目亮点

与传统的绘图工具（如 draw.io、PlantUML、Mermaid）或纯 AI 生成图片的方案相比，Archify 的核心差异在于其“确定性验证 + 事实可追溯”的设计哲学。传统工具往往只生成静态图片，无法验证拓扑的正确性，且与代码脱节；而 Archify 通过类型化 IR 和确定性检查确保了图表的准确性，并提供变更对比功能，使架构图成为可审计的工程资产。此外，自包含的单文件输出和多种导出格式极大地提升了分享便利性，而内嵌的交互能力（搜索、追溯、引导解说）则让图表从“展示品”升级为“探索工具”。对于深度使用 AI 代理的开发者而言，Archify 无缝嵌入了现有的代码生成工作流，实现了从代码到架构图再到评审的闭环。
