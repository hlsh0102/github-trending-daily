## 项目概述

God's Eye View（原名 WorldView）是一款运行在浏览器中的开源“间谍卫星模拟器”，但与模拟器不同的是，它展示的数据全部来自真实世界的公开信号源。项目将全球范围内可公开获取的空间情报数据——包括实时航班、船舶、卫星、地震、交通流量以及公共摄像头画面——整合到一个照片级逼真的 3D 地球模型上，让用户以沉浸式的方式观察和理解我们星球上正在发生的事情。

该项目由视频创作者 bilawalsidhu 发起，其 YouTube 系列视频累计播放量超过 500 万次。开发者将其定位为“开源空间情报”工具，旨在打破传统开源情报（OSINT）分析中信息碎片化的瓶颈，将分散在各种浏览器标签页中的数据信号转化为一个统一、直观的空间载体。项目在 GitHub 上已获得超过 11,000 颗星标，并在发布当天获得近 4,000 颗新星，显示出社区对这类工具的强烈需求。

## 核心功能

- **真实世界数据可视化**：实时接入全球航班应答机、船舶自动识别系统（AIS）、卫星轨道要素、地震仪和公共摄像头等公开数据源，以三维形式呈现在地球模型上。
- **照片级逼真 3D 地球**：基于 WebGL 技术构建的高保真地球渲染，支持无缝缩放、旋转和平移，提供接近卫星视角的视觉体验。
- **多图层叠加**：用户可自由切换和组合不同类型的数据图层，包括空中交通、海上交通、轨道卫星、地震活动、城市交通状况和公共摄像头位置。
- **AI 语音控制**：内置实时 AI 智能体，支持自然语言语音指令，用户可以通过说话直接操控地图、查询数据或切换视角。
- **标注视图模式**：对于无法提供实时视频流的位置，系统会显示清晰标注的模拟视图，帮助用户理解该位置的实际情况，避免误导。
- **完全开源可扩展**：项目代码完全公开，用户可以根据需要添加新的数据源、修改渲染逻辑或集成到自己的应用中。

## 技术架构

God's Eye View 采用纯 JavaScript 构建，核心依赖 WebGL 技术实现高性能的 3D 地球渲染。前端架构围绕“数据层-渲染层-交互层”的三层设计展开：

- **数据层**：通过 WebSocket 和 HTTP 长连接从多个公开 API 实时拉取数据，包括 OpenSky Network（航班）、MarineTraffic（船舶）、CelesTrak（卫星轨道）以及 USGS（地震）等。数据经过标准化处理后统一送入渲染管线。
- **渲染层**：基于自定义的 WebGL 引擎构建地球网格、大气散射效果和光照模型。所有实体（飞机、船舶、卫星等）使用实例化渲染技术，确保同时渲染数千个动态对象时依然保持流畅。
- **交互层**：采用响应式设计，支持鼠标、触摸和语音三种交互方式。语音控制模块通过浏览器原生 Web Speech API 获取语音输入，再经由后端 AI 服务进行意图识别和指令解析，最终转换为地图操作。
- **AI 集成**：项目集成了实时 AI 智能体，该智能体不仅能够理解语音指令，还能根据用户的问题主动选择相关的数据图层进行展示。例如，当用户询问“现在有多少架飞机在太平洋上空飞行”时，系统会自动聚焦到相关区域并显示统计信息。

## 安装与使用

安装 God's Eye View 运行本地实例需要 Node.js 环境（建议 v18 及以上）。基本步骤如下：

```bash
# 克隆仓库
git clone https://github.com/bilawalsidhu/gods-eye-view.git

# 进入项目目录
cd gods-eye-view

# 安装依赖
npm install

# 配置环境变量（部分数据源需要免费 API 密钥）
cp .env.example .env
# 编辑 .env 文件，填入你申请的 API 密钥

# 启动开发服务器
npm run dev
```

启动后，浏览器会自动打开 `http://localhost:3000`，你将看到一个可交互的 3D 地球。初次使用时，可以通过鼠标拖拽旋转地球、滚动缩放视角。若想体验语音控制功能，点击界面上的麦克风按钮并授权浏览器使用麦克风，然后直接说出指令，例如“显示全球航班”或“聚焦日本地区”。项目提供了详细的“首次使用五分钟”指南，帮助新用户快速上手。

## 适用场景

- **开源情报分析**：对于安全研究人员、记者或数据分析师，项目提供了一个直观的界面来同时观察多个维度的全球动态，大大降低了 OSINT 分析的门槛。
- **地理教学与科普**：教师和科普博主可以利用其实时数据和逼真渲染，向学生展示全球航运路线、航班密集区域、地震带分布等地理知识，使抽象概念变得具体可感。
- **个人兴趣探索**：对航空航天、地理或科技感兴趣的普通用户，可以在闲暇时探索全球各地的实时动态，体验“上帝视角”观察世界的乐趣。
- **事件监测与应急响应**：在自然灾害或重大事件发生时，用户可以通过地震图层和交通图层快速评估受影响区域的情况，辅助决策。

## 项目亮点

- **真实数据，透明来源**：与同类视觉效果工具不同，God's Eye View 的所有数据均来自公开可验证的信号源，并明确标注数据出处，用户可自行交叉核实。
- **开源精神和社区驱动**：项目完全开源，鼓励用户参与贡献。开发者在 README 中明确表示“你可以提问、破坏、扩展它”，这种开放态度吸引了大量开发者参与改进。
- **极低的入门门槛**：无需安装任何桌面软件，打开浏览器即可使用。语音控制功能更大幅降低了操作难度，让非技术用户也能轻松驾驭复杂的地理数据。
- **多源整合的视角创新**：首次将航班、船舶、卫星、地震、交通和摄像头等多元数据统一到单一三维空间坐标系中，提供了前所未有的全局关联分析能力。
- **清晰的标注系统**：项目对无法提供实时画面的位置使用经过明确标注的模拟视图，这种诚实的设计避免了用户产生误解，增加了数据的可信度。
