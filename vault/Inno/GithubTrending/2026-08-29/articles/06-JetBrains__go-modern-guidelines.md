## 项目概述
JetBrains 出品的 **go-modern-guidelines** 是一个专门为 AI 编码代理（如 GitHub Copilot、Codeium 等）设计的指南仓库。它解决了一个普遍存在的痛点：即使是最先进的 AI 模型，在生成 Go 代码时也常常依赖过时或低效的写法。项目通过提供一套结构化、版本感知的现代 Go 编码规范，帮助 AI 代理在生成代码时自动采用更简洁、更高效、更符合 Go 语言演进方向的新特性与标准库 API，从而显著提升代码质量与开发效率。目标用户是使用 AI 辅助编码的 Go 开发者，以及希望为团队内部 AI 工具注入最佳实践的工程管理者。

## 核心功能
- **版本感知的代码生成**：自动读取项目 `go.mod` 文件中的 Go 版本，仅使用该版本及之前可用的语言特性和标准库函数，避免生成与目标版本不兼容的代码。
- **现代惯用法替代**：引导 AI 代理使用 `max(a, b)` 取代 if-else 比较，用 `slices.Contains` 替代手写循环，用 `cmp.Or(a, b, c)` 简化链式 nil 检查等，直接提升代码可读性与简洁度。
- **覆盖至 Go 1.27 的新特性指南**：包含从 Go 1.0 到 Go 1.27 的所有实用更新，特别涵盖如 `new(42)`（直接获取值指针）、`errors.AsType[T](err)`（类型安全的错误匹配）等最新引入的语法糖。
- **与 `modernize` 分析器对齐**：指南内容与 Go 官方 `modernize` 代码分析器（用于检测并重构过时写法）的目标完全一致，确保 AI 代理推荐的模式与官方工具推荐的改进方向同步。
- **轻量级可插拔设计**：以单文件形式提供的指南（SKILL.md），可轻松集成到不同类型的 AI 编码代理工作流中，无需复杂配置。
- **开源授权**：采用 Apache-2.0 许可，允许自由使用、修改与再分发，便于团队在内部模型中定制。

## 技术架构
项目采用简洁的“单一事实来源”设计。核心是一份精心结构化的 Markdown 指南文件（`plugin/skills/use-modern-go/SKILL.md`），作为 AI 代理的上下文指令。指南内容按 Go 版本演进推理路径组织，并附带清晰的示例，以对抗模型训练数据中的“频率偏见”——即模型倾向选择训练数据中出现更多的旧模式。其关键设计思路在于：
1. **动态版本检测**：指导 AI 代理在执行代码生成任务前，先解析 `go.mod` 文件确定目标 Go 版本，确保生成的 API 调用不会超出该版本的兼容范围。
2. **对抗式示例对比**：为每个推荐模式提供“旧写法 vs 新写法”的对比，强化模型对新特性的记忆。
3. **与官方工具链协同**：指南覆盖范围与 `modernize` 分析器目标对齐，使得无论是人类代码审查还是机器自动重构，都遵循同一套现代标准，减少认知偏差。

## 安装与使用
由于该指南是纯文本规范，其“安装”即指将其内容注入到 AI 编码代理的配置中。常见步骤如下：
1. **获取指南文件**：克隆或直接下载 `plugin/skills/use-modern-go/SKILL.md` 文件。
2. **配置 AI 代理**：根据您使用的 AI 编码工具（如 Copilot、Cursor、Codeium 等）的文档，将该文件内容作为自定义指令或系统提示词的一部分导入。例如，在 Cursor 中可添加到 `.cursorrules` 文件，在 Copilot 中可通过 `github/copilot-instructions.md` 引用。
3. **验证效果**：在包含 `go.mod` 的 Go 项目中，输入一段常见的旧式循环或 nil 判断代码，并让 AI 代理进行重构，观察其是否引入 `for i := range n` 或 `slices.Contains` 等新写法。

**最小可用示例**：
假设您的项目 `go.mod` 指定 `go 1.22`，配置好指南后，向代理发出指令：“将一个整数切片中大于 10 的元素找出来”。传统 AI 可能会生成：
```go
var result []int
for _, v := range nums {
    if v > 10 {
        result = append(result, v)
    }
}
```
而启用本指南后，代理将优先输出：
```go
result := slices.Collect(slices.Values(nums), func(v int) bool { return v > 10 })
```
（注：实际 API 查找可在指南附录的版本特性表中验证兼容性。）

## 适用场景
- **团队 AI 编码规范统一**：为团队内部使用的 AI 代码助手提供定制规范，避免每个开发者各自为政地给模型“喂”不同的提示词，确保代码风格统一。
- **大型项目现代化重构**：在接手维护历史代码库时，借助 AI 代理快速将旧式代码段（如手动切片遍历、错误类型断言）升级为现代标准库实现。
- **新项目初始化开发**：在新项目中使用 `go.mod` 明确指定高版本 Go，并利用指南引导 AI 直接生成符合最新最佳实践的初始代码骨架。
- **学习与教学**：开发者可阅读指南文件，系统了解 Go 语言从 1.0 到 1.27 的语法演进，作为个人技能提升的参考手册。

## 项目亮点
与常见的“Go 代码风格指南”不同，本项目的差异化优势在于：
- **目标受众独特**：专门为 AI 编码代理优化，而非人类开发者，内容高度结构化、示例化，便于模型解析与执行。
- **版本动态感知**：其他指南通常是静态的“最新写法”，而本项目要求 AI 代理根据项目实际 Go 版本选择可用特性，解决了新特性在旧版本项目中不可用的问题。
- **生态协同效应**：作为 JetBrains 出品，与 IntelliJ IDEA 等 IDE 的 Go 插件及 `modernize` 工具协同，形成从“AI 生成→IDE 检查→人工确认”的完整闭环。
- **社区热度验证**：上线即获得近 3000 星标（单日新增 574 星），反映出开发者对 AI 生成代码质量改进的迫切需求。
