## 项目概述

screenshot-to-code 是一个利用 AI 将视觉设计转化为实际代码的开源工具。用户只需拖入一张截图、上传一个 Figma 设计稿，甚至提交一段屏幕录制视频，项目就能自动生成对应的前端代码，实现了从“看到”到“实现”的自动化流程。

该项目解决了开发流程中一个长期存在的痛点：从设计稿到代码的阶段往往耗时且机械。对于需要快速验证想法、制作原型或批量生成页面的开发者来说，screenshot-to-code 可以显著缩短这一过程，将精力集中在更复杂的业务逻辑上。项目由 Python 驱动，当前在 GitHub 上已获得超过 75,000 颗星，目标用户包括前端开发者、产品经理、独立开发者以及任何需要将静态设计转化为可运行代码的人。

## 核心功能

- **多格式代码生成**：支持将截图或设计稿转换为多种技术栈的代码，包括 HTML + Tailwind、HTML + CSS、React + Tailwind、Vue + Tailwind、Bootstrap 以及 Ionic + Tailwind，用户可根据项目需求选择输出格式。
- **屏幕录制转原型**：允许用户录制网站的动态交互过程，AI 将其转化为可运行的代码原型，适合快速捕捉动态效果并转化为初始开发版本。
- **多模型 AI 驱动**：内置对多种先进 AI 模型的支持，默认配置包括 Gemini 3 Flash，以及 GPT-5.5、Claude Opus 4.6 等作为备选，并支持通过 Replicate 调用图像生成模型，保证生成质量与灵活性。
- **设计稿导入**：除屏幕截图外，直接支持 Figma 设计文件的导入，方便设计师将作品直接交付给开发环节，减少手动切图与排版的时间。

## 技术架构

项目采用前后端分离的架构。后端基于 Python 构建，负责与 AI 模型的 API 交互，处理图像或视频输入，并将模型返回的代码进行整理和输出。前端则提供了一个清晰的交互界面，让用户可以上传文件、查看生成结果并实时预览。

设计思路的核心是“以视觉为输入，以代码为输出”。系统首先通过图像识别模型解析输入素材中的界面元素、布局结构和视觉样式，然后将其转换为结构化的语义描述，最后针对用户选择的技术栈生成对应的 JSX、Vue 模板或纯 HTML 代码。这种管线化的处理方式使得它不仅支持静态截图，也能处理视频流，只需对帧序列进行连续分析即可。

由于默认模型配置支持多样化的 AI 提供商，项目在设计上保持了较高的抽象度，方便后续接入新的模型或替换现有配置，而无需改动核心处理逻辑。本地运行需要配置相应的 API 密钥，后端服务会统一管理这些凭据。

## 安装与使用

要运行本地环境，需要先确保安装了 Python 和 Node.js。主要步骤包括：

1. 克隆仓库并进入目录：
   ```bash
   git clone https://github.com/abi/screenshot-to-code.git
   cd screenshot-to-code
   ```

2. 设置后端环境，安装 Python 依赖并配置环境变量（如 OpenAI、Anthropic 或 Google 的 API 密钥）：
   ```bash
   cd backend
   pip install -r requirements.txt
   cp .env.example .env
   # 编辑 .env 文件，填入对应的 API 密钥
   ```

3. 启动后端服务：
   ```bash
   python main.py
   ```

4. 安装并启动前端开发服务器：
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

5. 打开浏览器访问 `http://localhost:5173`，上传截图或视频，选择目标技术栈，点击生成即可获得代码。

对于不想本地配置的用户，官方提供了托管版本 [screenshottocode.com](https://screenshottocode.com)，可直接在线使用，无需任何环境搭建。

## 适用场景

- **快速原型验证**：产品经理或创业者可以在白板上画出草图或截图参考竞品界面，在数分钟内得到一个可点击的 HTML 原型，用于用户测试或向投资人演示。
- **设计交付提效**：设计团队完成 Figma 设计稿后，可直接导入生成基础代码，开发团队在此基础上进行业务逻辑对接，大幅减少重复性切图与布局工作。
- **前端学习与参考**：初学者可以将看到的高质量网页截图导入，观察 AI 生成的代码结构，学习不同 CSS 框架的写法和布局思路。
- **页面迁移与改版**：在需要对旧网站进行技术栈升级（例如从纯 CSS 迁移到 Tailwind）时，可以利用截图工具生成新框架的代码，作为迁移起点。

## 项目亮点

与同类工具相比，screenshot-to-code 的主要优势在于其**极高的灵活性与生态集成度**。它支持的技术栈覆盖了当前前端开发的主流选择，从经典的 Bootstrap 到现代的 React、Vue 组合，能够满足不同团队的技术偏好。

其次，项目对**多模型的支持**意味着用户不受限于单一 AI 提供商，可以根据生成质量、成本或速度需求在不同模型间切换，甚至在未来接入更优秀的模型。这种模型无关的设计使项目具备了较强的未来适应性。

此外，**屏幕录制转原型**的功能在同类开源项目中较为少见，它将动态交互也纳入了自动化生成的范畴，大大扩展了应用的边界。最后，作为 MIT 协议的开源项目，它可以自由用于商业项目，且社区活跃，Star 数量持续增长，保证了持续的迭代动力和社区支持。
