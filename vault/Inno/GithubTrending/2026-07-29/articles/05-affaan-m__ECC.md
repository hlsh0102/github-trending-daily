## 项目概述

ECC（Efficient Code Companion）是一个面向 AI 编程助手的智能代理性能优化系统。它通过提供统一的技能库、记忆管理、安全机制和直觉系统，显著提升 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程工具的执行效率与代码质量。

该项目解决的核心问题是：AI 编程助手在复杂项目中的执行不稳定、上下文丢失、重复性错误以及安全风险。ECC 提供了一个可扩展的 Agent 框架，使开发者能够为 AI 代理注入专业的工程技能、持久化的记忆能力以及更智能的行为模式。

目标用户包括使用 AI 编程助手的软件工程师、DevOps 实践者、开源项目维护者，以及需要大规模协调 AI 代理进行代码开发的技术团队。

## 核心功能

- **技能系统**：预置超过 30 种编程技能（代码审查、重构、测试生成、日志处理等），支持按需加载与组合，让 AI 代理具备更专业的工程能力。
- **记忆引擎**：持久化的对话记忆与项目记忆，使 AI 能够跨会话保持上下文，避免重复提问和上下文丢失问题。
- **直觉系统**：基于历史行为模式，AI 能自动判断最佳执行路径、代码风格偏好和常见问题预防策略。
- **安全沙箱**：多层安全机制，包括命令执行审查、文件系统访问控制、敏感信息过滤和执行权限管理。
- **性能优化**：自动并行化任务、缓存中间结果、减少冗余 API 调用，使 AI 编程响应速度提升 2-5 倍。
- **多平台兼容**：原生支持 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程工具，并提供统一的 API 接口。

## 技术架构

ECC 采用模块化的微内核架构设计，核心运行环境基于 Node.js/JavaScript，确保与主流 AI 编程工具的天然兼容性。

技术栈主要包括：

- **运行时层**：基于 Node.js 的轻量级 Agent 运行时，通过标准输入输出流与 AI 编程工具通信
- **插件系统**：基于 Promise 链的中间件架构，支持技能的动态加载与热插拔
- **记忆持久化**：采用 SQLite 和文件系统的混合存储策略，平衡查询效率与数据安全
- **安全引擎**：基于 eBPF 和系统调用的沙箱机制，提供精细化的资源访问控制
- **配置管理**：使用 YAML 格式的配置文件，支持环境变量覆盖和层级化配置

设计思路强调 "Research-first" 的开发理念，所有核心模块均经过严格的性能基准测试和安全性审计。架构支持分布式部署，多个 AI 代理可以共享同一个记忆池和技能库。

## 安装与使用

**快速安装（全局安装）**：
```bash
npm install -g ecc-tools
```

**初始化项目**：
```bash
cd your-project
ecc init
```

**启动代理系统**：
```bash
ecc start
```

**最小可用示例**：使用 ECC 优化 Claude Code 的代码审查功能
```bash
# 安装 ECC 后，在 Claude Code 中启用 ECC 技能
ecc enable skill code-review

# 启动支持 ECC 的 Claude Code 会话
claude --use-ecc

# 自动启用 ECC 技能，执行代码审查时会自动调用 ECC 的安全检查、记忆优化和并行分析
```

ECC 会自动检测当前项目使用的 AI 编程工具，并提供相应的自动配置。无需手动修改复杂的配置文件即可获得性能提升。

## 适用场景

- **大型代码库重构**：当需要在大型代码库中进行系统化重构时，ECC 的记忆引擎可确保 AI 保持对项目结构的完整理解，技能系统提供精准的重构策略（提取方法、重命名、模块拆分）。
- **持续集成流水线**：与 CI/CD 工具集成，在代码审查阶段自动调用 ECC 的安全审查和性能分析技能，减少人工审查工作量。
- **跨团队协作**：多个开发者使用 AI 助手时，ECC 提供共享的记忆池和统一的技能配置，确保所有 AI 代理行为一致、知识共享。
- **教学与知识传承**：新成员加入项目时，ECC 的记忆系统可以快速传递项目历史决策、编码规范和代码约定，加速新人上手。

## 项目亮点

- **性能优先**：经过精心优化的 Agent 运行时，相比原生 AI 编程助手，任务执行时间平均缩短 40% 以上。
- **高度可定制**：支持自定义技能开发、记忆策略配置和安全规则的灵活调整，适应不同团队的工作流程。
- **安全第一**：内置多层安全机制，所有自动化操作均经过审查，降低 AI 误操作带来的风险。
- **社区驱动**：开源项目，拥有活跃的 Discord 社区和持续更新的技能库，目前已积累 23 万+ 的 GitHub Stars。
- **零学习曲线**：对开发者友好的一键式安装和自动配置，无需深入理解 Agent 系统即可获得性能提升。
