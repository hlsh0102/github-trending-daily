## 项目概述

**Awesome Systematic Trading** 是一个精心策划的资源聚合仓库，专门面向系统化交易（量化交易）领域的研究者、开发者和交易员。该项目系统地收集了构建、回测、执行量化交易策略所需的核心资源，包括 97 个库与软件包、40 多项量化策略、55 本推荐书籍、23 个视频访谈，以及多个博客和课程资源。其目标用户涵盖从刚入门的量化爱好者到寻求专业工具与研究资料的高级从业者。项目由论文与回测社区（paperswithbacktest.com）维护，旨在降低量化交易研究门槛，为从业者提供一站式的学习与实践工具索引。

## 核心功能

- **资源聚合库**：按类别整理了 97 个用于研究、回测和实盘交易的库与软件包，覆盖事件驱动框架、向量化回测引擎、数据源、风险管理工具等。
- **策略参考库**：收录了 40 多项由学术界和金融机构公开的系统化交易策略，包括趋势跟踪、均值回归、统计套利、机器学习策略等经典类型。
- **学习路径指南**：提供了 55 本分级别书籍（从入门到专业）、23 个技术讲座视频，以及持续更新的博客和课程清单，帮助用户系统化学习。
- **可发现性设计**：仓库包含详细的目录索引，并在 README 中提供中文版链接，方便非英语用户快速定位所需资源。
- **社区生态入口**：通过关联 `paperswithbacktest.com` 网站，为用户提供了 Python 实现的策略示例和独家内容，形成资源-实践的闭环。

## 技术架构

作为一个资源索引仓库，其技术架构以 **GitHub README 文档结构**为核心，主要使用 Markdown 语法组织内容。仓库采用分层分类设计：顶级分类包括库与包、策略、书籍、视频、博客等；每个分类下再细分子类别（如“回测与实盘交易”下的“事件驱动框架”和“向量化框架”）。仓库依赖静态页面渲染（GitHub 原生支持），并利用 `awesome.re` 徽章标记其“Awesome List”属性。其维护方式依赖社区贡献和定期人工审核，仓库本身不包含可执行代码或计算依赖，但列表链接的外部资源（如 Python 库）需用户自行安装管理。这种设计思路使得仓库轻量化、易维护、可快速浏览。

## 安装与使用

该仓库无需传统安装，直接通过浏览器访问即可使用。以下是典型使用流程：

1.  **访问仓库**：打开 `https://github.com/paperswithbacktest/awesome-systematic-trading`
2.  **浏览目录**：直接阅读 `README.md` 文件，或点击顶部中文版链接切换到中文指南。
3.  **按需检索**：使用页面内搜索功能快速定位所需类型，例如搜索“backtesting”可过滤出所有回测框架相关资源。
4.  **访问外部资源**：点击列表中的链接即可跳转至相应库的 GitHub 仓库、书籍购买页面、学术论文或视频平台。

**最小可用示例**：若用户需要选择一个 Python 量化回测框架，可在“Libraries and packages” > “Backtesting and Live Trading” > “General - Vector Based Frameworks” 下找到 `backtesting.py`、`vectorbt` 等库，并直接点击其 GitHub 链接进入安装文档。

## 适用场景

- **量化交易入门学习**：新手可以通过书籍、课程和入门级框架（如 `backtesting.py`）快速建立知识体系，避免信息孤岛。
- **策略研究与回测**：研究人员可以从 40+ 策略清单中寻找灵感，并利用列表中的事件驱动或向量化回测库（如 `zipline`、`vectorbt`）实现验证。
- **实盘交易系统设计**：高级开发者可以筛选列表中的实时交易库（如 `ccxt`、`robin-stocks`）和风险管理工具，构建完整的自动化交易管线。
- **持续知识更新**：交易员可通过博客和视频部分跟踪行业最新趋势与技术讨论，保持对高频交易、机器学习策略等前沿动态的认知。

## 项目亮点

- **资源覆盖面广**：与同类单一主题清单不同，该项目一次性覆盖了从工具、策略到学术内容的完整生命周期，避免了多来源查找的麻烦。
- **质量筛选标准**：所有收录资源均经过人工审核，优先选择被广泛使用、更新活跃或具有学术严谨性的项目，保证了可信度。
- **多语言友好**：专门提供中文版 README（`README_zh.md`），大大降低了中文用户的阅读成本，这在全球性 Awesome List 中较为少见。
- **活跃社区生态**：项目关联 `paperswithbacktest.com` 网站，提供 Python 实现教程和独家研究内容，使资源清单超越静态罗列，具有实践驱动价值。
- **持续更新**：项目截至当前已有近万星标，且持续保持日常活跃更新（每日增长数百星），说明维护者持续投入且社区反馈良好。
