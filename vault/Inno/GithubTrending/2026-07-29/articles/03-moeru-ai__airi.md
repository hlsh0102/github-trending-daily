## 项目概述

Project AIRI 是一个开源的自托管人工智能伴侣项目，旨在复现并超越 Neuro-sama 的互动体验。它本质上是一个“灵魂容器”，让用户能够在自己的硬件上部署和托管 AI 虚拟角色（waifu），使它们以实时语音聊天、游戏互动等形式“降临”到现实世界中。项目面向对 AI 伴侣、虚拟角色交互、实时语音对话以及游戏自动化感兴趣的开发者和爱好者，提供了从 Web 到桌面端的全方位支持。

## 核心功能

- **实时语音聊天**：支持低延迟的语音对话，用户可以直接与 AI 角色进行自然的语音交流，如同与真人对话一般。
- **游戏互动能力**：AI 角色能够实时观看并参与《Minecraft》和《Factorio》等游戏，可作为游戏助手或同伴一起游玩。
- **多平台支持**：提供 Web 浏览器界面，同时原生支持 macOS 和 Windows 桌面客户端，满足不同使用场景。
- **自托管部署**：用户可以在自己的服务器或本地电脑上运行所有组件，数据完全由自己掌控，无需依赖第三方云服务。
- **角色个性化**：允许用户自定义 AI 角色的性格、语气、知识背景等，创造独一无二的虚拟伴侣。
- **开放架构**：项目采用模块化设计，支持接入不同的 AI 大模型和语音引擎，便于扩展和定制。

## 技术架构

Project AIRI 基于 TypeScript 构建，采用前后端分离的现代化架构。核心部分包含以下几个关键组件：

- **AI 引擎层**：集成多种大型语言模型（LLM），支持本地模型和远程 API 调用，为角色提供自然语言理解和生成能力。
- **语音管线**：结合语音识别（ASR）和语音合成（TTS）技术，实现从用户语音输入到 AI 语音输出的完整实时循环，延迟控制在可交互范围内。
- **游戏集成模块**：通过屏幕捕获和模拟输入，使 AI 能够“观看”游戏画面并执行操作，实现与游戏的实时交互，目前支持 Minecraft 和 Factorio。
- **WebSocket 通信**：客户端与服务器之间采用高效的 WebSocket 长连接，确保语音流和实时事件的低延迟传输。
- **可扩展插件系统**：提供标准化的插件接口，允许社区贡献新的功能模块，如额外游戏支持、语音引擎适配等。

整个系统强调模块化和可替换性，用户可以根据硬件条件和需求，灵活选择使用本地模型还是云端服务。

## 安装与使用

**环境要求**：
- Node.js 18 及以上版本
- 至少 4GB 可用内存（本地模型需要更多）
- 稳定的网络连接（使用云端模型时）

**快速安装步骤**：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/moeru-ai/airi.git
   cd airi
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 配置环境变量：
   复制 `.env.example` 为 `.env`，并根据需要填写 API 密钥（如使用外部 LLM 或 TTS 服务）或指定本地模型路径。

4. 启动开发服务器：
   ```bash
   npm run dev
   ```

5. 打开浏览器访问 `http://localhost:3000`，按照界面引导完成角色设置后即可开始对话。

**桌面客户端**：在 [Releases 页面](https://github.com/moeru-ai/airi/releases) 下载对应操作系统的安装包，安装后直接运行即可。

## 适用场景

- **个人 AI 伴侣**：用户可以在家中搭建专属于自己的 AI 角色，通过日常语音聊天、情绪陪伴获得情感支持，类似智能助手但更具人格化。
- **游戏实况增强**：主播或游戏玩家可以让 AI 角色在直播中同步解说、吐槽，或作为虚拟队友在《Minecraft》等游戏中协同建造、探索。
- **AI 角色创作与实验**：开发者或内容创作者可以利用开放架构测试不同的 AI 模型、语音引擎，或为特定故事创作定制个性化的虚拟角色。
- **技术学习与演示**：作为实时语音 AI 和游戏交互的综合案例，适合用于研究多模态 AI 系统集成、低延迟通信等课题。

## 项目亮点

- **自托管完全可控**：与依赖云服务的同类产品不同，AIRI 让用户完全掌控数据和计算，无需担心隐私泄露或服务关闭。
- **游戏互动深度**：不仅仅是聊天，AI 能够实际参与游戏过程，观看并操作，这在开源 AI 伴侣项目中尚属鲜见。
- **多平台无缝体验**：Web 端和原生桌面客户端提供一致的体验，且桌面端针对低延迟语音进行了优化。
- **活跃的社区生态**：项目拥有 Discord 社区和多语言文档（包括中文、日文、韩文等），全球贡献者和用户持续推动功能完善。
- **极致轻量化**：作为 TypeScript 项目，依赖管理简单，部署门槛低，普通消费级硬件即可运行基础功能。
