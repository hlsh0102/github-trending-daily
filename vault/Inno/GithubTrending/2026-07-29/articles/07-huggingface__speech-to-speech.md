## 项目概述

Speech To Speech 是由 Hugging Face 推出的开源语音智能体管道项目。它解决了构建具备实时语音交互能力的智能体时面临的多个痛点：低延迟、模块化可替换、以及摆脱对特定商业 API 的依赖。目标用户包括机器人开发者、语音交互应用构建者、AI 产品原型设计人员，以及希望在自己的硬件上运行完整开源语音管道的开发者。

该项目提供了一个**完全模块化、低延迟**的语音智能体管道，核心流程为：**VAD（语音活动检测） -> STT（语音转文字） -> LLM（大语言模型） -> TTS（文字转语音）**。整个系统通过一个**与 OpenAI Realtime API 兼容的 WebSocket 接口**暴露出来，这意味着任何支持 OpenAI Realtime 协议的客户端都可以直接连接并使用，包括 OpenAI 官方客户端或其他第三方客户端。所有组件均可按需替换，LLM 槽位支持符合 OpenAI 通信协议的各类服务，可以是托管提供商、Hugging Face 推理端点，或者本地运行的 vLLM / llama.cpp 服务器，从而实现完全本地、完全开源的部署。

该管道已在生产环境中运行，作为数千台 Reachy Mini 机器人的对话后端。

## 核心功能

- **OpenAI Realtime 兼容接口**：对外提供与 OpenAI Realtime API 一致的 WebSocket 接口，允许用户无缝切换后端，从托管 OpenAI 服务切换到自托管语音管道，而无需修改客户端代码。
- **模块化组件设计**：管道由 VAD、STT、LLM、TTS 四个独立模块组成，每个模块都可以独立替换或配置，支持使用不同模型、不同提供商的不同组合。
- **低延迟实时推理**：针对语音交互场景优化，确保端到端延迟控制在可接受的范围内，适合需要实时响应的应用，如机器人对话。
- **全开源栈支持**：支持完全使用开源模型运行整个管道，包括本地部署的 LLM 和 TTS 模型，真正实现私有化、本地化的语音智能体。
- **简单易用的快速启动**：通过 pip 安装后，只需设置 API 密钥并运行一行命令即可启动服务器，降低了使用门槛。

## 技术架构

项目采用经典的四阶段管道架构，按顺序处理语音输入并生成语音输出：

1. **VAD（语音活动检测）**：检测用户何时开始和停止说话。此阶段是管道入口，确保只将有效的语音片段送入后续处理。
2. **STT（语音转文字）**：将检测到的语音片段转换为文本。支持多种开源模型，如 Whisper、Wav2Vec2 等。
3. **LLM（大语言模型）**：接收文本输入，生成回复文本。此模块支持任何兼容 OpenAI API 的 LLM 服务，包括本地运行的 vLLM 或 llama.cpp 服务器，以及 Hugging Face 的推理端点。
4. **TTS（文字转语音）**：将 LLM 生成的文本转换为语音输出。同样支持多种开源 TTS 模型，如 Bark、Tortoise TTS、XTTS 等。

整个系统以 WebSocket 服务器形式运行，对外暴露 `/v1/realtime` 端点。客户端通过 WebSocket 连接发送语音输入流，服务器实时处理并将生成的语音输出流返回给客户端。这种架构允许低延迟的双向语音通信，同时保持了高度的灵活性——每个模块都可以独立升级或替换，而不会影响其他模块。

项目使用 Python 开发，依赖常用的深度学习框架和音频处理库。设计上强调可扩展性，用户可以通过配置文件或环境变量定制每个阶段使用的模型和参数。

## 安装与使用

安装非常简单，只需使用 pip：

```bash
pip install speech-to-speech
```

然后设置 OpenAI API 密钥（用于 LLM 部分，也可以配置其他提供商）：

```bash
export OPENAI_API_KEY=your_key_here
```

启动服务器：

```bash
speech-to-speech
```

默认情况下，服务器会在 `ws://localhost:8765/v1/realtime` 启动。此时任何兼容 OpenAI Realtime API 的客户端都可以连接并从 OpenAI 切换到本地服务器。

如需使用完全本地化的堆栈，可以将 LLM 部分配置为本地运行的 vLLM 或 llama.cpp 实例，并选择合适的开源 STT 和 TTS 模型。

## 适用场景

- **机器人语音交互**：已实际用于数千台 Reachy Mini 机器人的对话系统，适合需要自然语音交互的实体机器人产品。
- **智能语音助手**：可以构建具备对话理解能力的智能音箱、语音助手或虚拟客服，支持完全本地化部署以保护隐私。
- **原型开发与测试**：开发者可以利用此项目快速搭建语音交互原型，并在不同模型组合间快速切换对比效果。
- **教育与研究**：适合作为语音交互系统的参考实现，用于教学或研究模块化语音管道的设计与优化。

## 项目亮点

- **与 OpenAI Realtime API 兼容**：最大的差异化优势在于可以直接替换 OpenAI 的 Realtime API 服务，用户无需修改客户端代码即可切换后端，极大降低了迁移成本。
- **完全模块化且可替换**：与许多一体化的语音模型不同，本项目允许自由组合不同供应商、不同模型的 VAD、STT、LLM、TTS 组件，提供了前所未有的灵活性。
- **生产级可靠性**：已经在数千台实际部署的机器人上运行，证明了其稳定性和低延迟性能。
- **全开源可私有化**：支持完全使用开源模型，可以在本地硬件上运行，满足对数据安全和隐私有严格要求的场景。
- **低上手成本**：简洁的安装和启动流程，让开发者能快速开始实验或集成。
