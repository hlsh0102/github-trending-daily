## 项目概述

free-stockdb 是一个面向 A 股市场的本地量化数据引擎，专注于解决个人量化投资者在数据处理环节的痛点。它将数据同步、清洗、复权、组织为可直接用于批量查询和计算研究的数据底座。用户只需“双击更新、双击启动、直接调用”，即可在本地拥有一个完整、高效、随时可用的金融数据库。

该项目主要面向 A 股日K、分钟K以及 ETF 分钟和 tick 级数据的量化研究与回测场景。目标用户是个人量化投资者、金融数据分析爱好者、以及希望在本地构建自有数据基础设施的研究人员。通过将数据完全落地到用户磁盘，free-stockdb 彻底消除了对远程 API 接口的依赖，使得大规模回测和指标计算变得快速、稳定且免费。

## 核心功能

- **增量同步与本地存储**：支持日K、分钟K、ETF 分钟及 tick 级数据的增量同步。通过 `sync_url.txt` 配置文件指定数据源，使用 Zstd 压缩传输，支持断点续传，只同步变化数据，极大减少带宽和同步时间。
- **全自动数据清洗与复权**：同步过程自动处理停牌、退市、代码变更、缺失数据补充和时间排序等问题。内置完整的复权因子，支持写时计算，查询时自动应用复权结果，无需手动处理。
- **高性能时序存储引擎**：采用定制的 C++ 时序引擎作为数据存储层，针对金融时间序列数据进行了深度优化，提供高效的批量查询能力，比通用的数据库方案（如 SQLite + Pandas）快数倍。
- **内置 39 种指标与 5 种指数**：预置了 MA、MACD、KDJ 等 39 种常用技术指标，以及 5 种市场指数。使用 Rust 计算核心，在全市场分钟数据上计算指标仅需数秒，远快于 Pandas 逐行遍历。
- **内置板块映射**：内置申万一级、二级、三级行业分类以及 1200+ 个概念板块，通过 `bk.get()` 接口可毫秒级查询某只股票所属的所有板块，或某板块包含的全部股票。
- **五种调用方式**：统一支持 Python SDK、HTTP API、Excel / WPS 插件、HTML 网页、以及 AI MCP（Model Context Protocol）接口，满足不同场景下的调用需求，无需重复对接。

## 技术架构

free-stockdb 的核心架构分为三层：数据同步层、数据存储与计算层、以及接口层。

**数据同步层**：负责从配置的 URL 数据源拉取数据。流程顺序为：数据同步 -> 数据清洗 -> 复权处理 -> 增量写入本地存储。该层使用增量同步算法，仅处理发生变化的数据，配合 Zstd 压缩传输和断点续传机制，确保同步效率。

**数据存储与计算层**：这是项目的核心技术。存储引擎采用定制的 C++ 时序数据库，针对金融数据的按时间点、按时间段、按证券代码的高频查询模式进行了索引和缓存优化。计算层使用 Rust 实现，核心是为全市场多标的批量计算做向量化优化，提供 39 种预定义指标和 5 种指数的批量计算能力。

**接口层**：采用微服务架构设计，对外提供统一的查询和计算 API。通过 HTTP 服务桥接，同时支持 Python（通过 `pyfree` 库）、Excel（通过 HTTP 请求或插件）、HTML 网页（直接调用）、以及 AI MCP 协议接入。架构设计确保查询和计算都基于本地数据，完全不依赖远程网络链路，从而避免限频、封号等不稳定因素。

## 安装与使用

### 安装步骤（以 Windows 为例）

1. **下载**：从 [GitHub Releases 页面](https://github.com/hello245m/free-stockdb/releases) 下载最新 Windows 压缩包（如 `free-stockdb-windows-v0.2.1-more-power.zip`）。
2. **解压**：将压缩包解压到本地一个固定目录（建议不要放在中文路径下）。
3. **首次更新数据**：双击运行 `update.bat` 或 `free-stockdb-update.exe`，程序会连接配置的数据源，首次同步可能需要较长时间（视数据量而定）。
4. **启动服务**：双击 `start.bat` 或 `free-stockdb.exe`，程序会启动本地 HTTP 服务（默认端口 9070）。
5. **调用**：打开浏览器访问 `http://localhost:9070`，或通过 Python SDK、Excel 插件等方式连接。

### 最小可用示例（Python 调用）

```python
# 安装 Python SDK：pip install pyfree
from pyfree import FreeDB

# 连接本地引擎
db = FreeDB(host='127.0.0.1', port=9070)

# 查询股票日线数据
df = db.get_kline(
    stocks=['000001.SZ', '600000.SH'],
    start='2023-01-01',
    end='2023-12-31',
    freq='day',
    fq='backward'  # 后复权
)
print(df)

# 计算全市场 MACD 指标
result = db.calc_indicator(
    name='MACD',
    stocks='all',          # 全市场
    start='2024-01-01',
    end='2024-03-31',
    freq='30min',
    params={'fast': 12, 'slow': 26, 'signal': 9}
)
print(result)
```

## 适用场景

- **全市场分钟线回测**：对 A 股 7000+ 股票进行分钟级的全市场策略回测。使用免费本地引擎，可获得离线、快速、无限次数的回测体验，不再受限于 API 调用次数和网络耗时。
- **高效率指标研究**：在本地快速计算全市场股票的多种技术指标（MA, MACD, KDJ, RSI 等），用于因子挖掘、多因子模型构建或盘后数据分析。内置的 Rust 计算核心使得大规模批量计算秒级完成。
- **行业/概念板块因子分析**：利用内置的申万行业与概念板块映射，快速完成“板块-成分股”的双向查询，分析特定行业的走势，或构建基于板块轮动的量化策略。
- **日常盘后数据维护**：作为个人量化研究的数据基础设施，每天自动增量同步日K、分钟K数据，并自动完成清洗和复权，确保研究数据始终处于最新状态，无需人工干预。

## 项目亮点

- **一键部署，开箱即用**：无需配置数据库、无需编写复杂的同步脚本。下载解压后，双击启动即可获得完整的本地数据引擎，极大地降低了个人量化研究的数据工程门槛。
- **高性能批量计算**：使用 C++ 和 Rust 构建的计算核心，在批量处理全市场分钟数据时，速度比传统的 Pandas 方案快 3 倍以上，使得大规模回测和指标计算从“不可能”变为“实时”。
- **真正的本地优先**：所有数据存储于用户自己的磁盘，不依赖任何远程 API 服务。这消除了网络延迟、限频、封号、接口变更等不稳定因素，保证研究和回测的可重复性和稳定性。
- **多种调用方式统一**：提供 Python SDK、HTTP API、Excel 插件、HTML 网页和 AI MCP 五种调用方式，用户可根据不同场景灵活选择，无需为不同工具重复开发数据接口。
- **消除远程 API 方案的隐性成本**：根据项目方的实测，使用远程 API 进行全市场分钟线回测，仅数据工程环节就需要 10-15 个工作日。free-stockdb 将这个时间压缩到以小时为单位，让用户能快速聚焦于策略开发本身。
