## 项目概述

AI Berkshire 是一个基于 Claude Code / Codex 的价值投资研究框架，它将巴菲特、芒格、段永平、李录四位投资大师的方法论系统化、结构化，通过 AI Agent 实现专业级的投资研究。该项目解决了传统 AI 投资分析中“分析模糊、缺乏决策力”的核心痛点，目标用户是希望在 AI 辅助下进行深度、纪律性价值投资的个人投资者和研究者。

项目的核心理念是：一个人 + Claude Code / Codex = 一个投研团队。通过多 Agent 并行研究和强制输出决策结论，AI Berkshire 让投资者不再依赖“一方面 … 另一方面 …”的模糊分析，而是获得可执行的、基于大师方法论的投资建议。

截至本介绍文档撰写时，该项目已在 GitHub 上获得超过 7700 颗星标，且增长迅速，证明了其与社区需求的高度契合。

## 核心功能

- **多大师方法论系统化**：将巴菲特、芒格、段永平、李录四位大师的投资原则（如巴菲特的安全边际、芒格的格栅理论、段永平的“买股票就是买公司”、李录的长期主义）转化为可执行的 AI 指令和检查清单，确保分析不偏离核心价值框架。
- **强制结论输出，不打太极**：AI Berkshire 强制输出明确的“通过/不通过/灰色地带”结论，并附带具体的价格区间和分层投资建议（激进型、稳健型、保守型），彻底清除通用 AI 的模糊表述。
- **四大师视角对抗分析**：不是单一视角的分析，而是让四位大师的方法论在同一个问题下产生“真实的矛盾和张力”。系统会模拟不同大师之间的辩论，揭示投资决策中的权衡与风险，避免单一片面。
- **镜子测试与决策纪律**：内置“镜子测试”等决策纪律检查。例如，“5 句话说不完整 = 不买，没有例外”，确保投资者在无法清晰理解企业逻辑时，不会轻易做出决策。
- **实盘可验证的绩效记录**：项目公开了基于该框架的真实实盘收益记录。2024 年全年收益 +69.29%，2025 年至今收益 +66.38%，连续两年大幅跑赢主要指数（标普 500、恒生指数、沪深 300、纳斯达克），两年累计实盘收益超过 146 万元。
- **兼容多种 AI 平台**：同时兼容 Claude Code 与 Codex，降低了用户的使用门槛。

## 技术架构

AI Berkshire 是一个 Skill 合集，其核心并非复杂的后端服务，而是一套结构化的提示词、工作流和检查清单，运行在 Claude Code 或 Codex 等大型语言模型（LLM）之上。

- **基于 Skill 的设计**：项目以“Skill”为单位组织知识，每个 Skill 封装了一位大师的方法论、关键概念（如“护城河”、“能力圈”、“复利”）和决策规则。这种模块化设计便于扩展和维护。
- **多 Agent 并行研究**：通过精心设计的多轮对话框架，系统能够在单次交互中并行调用不同大师的视角，进行多层次、多维度的企业分析。这模拟了真实投研团队的“红蓝军对抗”，提升了分析的深度和全面性。
- **结果可编程化**：不满足于自然语言描述，项目强制要求输出结构化的 JSON 或表格格式结果（如带有分层建议的“买入/不买”决策表），便于用户直接将其引入自己的投资决策系统或交易模型中。
- **用户界面**：项目本身不提供前端 UI，其“使用界面”就是 Claude Code 或 Codex 的命令行或图形化对话窗。用户通过输入企业名称或股票代码，触发预定义的 Skill 工作流。

## 安装与使用

AI Berkshire 的使用方式非常直接，不需要复杂的安装流程。

1.  **克隆或下载仓库**：将 `xbtlin/ai-berkshire` 仓库克隆到本地或下载其内容。
2.  **配置 AI 助手**：将仓库中的 Skill 文件（通常是 Markdown 或 JSON 格式）导入到你的 Claude Code 或 Codex 项目中。具体操作方法取决于你使用的 AI 平台。
3.  **启动分析**：直接向 AI 助手发出指令，例如：`运行四位大师的对抗分析，研究腾讯控股（00700.HK）的当前投资价值。`

**最小可用示例：**

假设你已配置好项目，输入以下指令：

> 请根据巴菲特和段永平的方法论，分析拼多多的商业模式，并给出你的“通过/不通过/灰色地带”结论及建议价格区间。

AI Berkshire 将输出类似以下格式的分析结果（简化示例）：

| 大师视角 | 核心观点 | 结论 |
|---------|---------|------|
| 巴菲特 | 护城河（用户规模/网络效应）强，但管理层动机存疑，缺乏长期确定性。 | 不通过（稳健型） |
| 段永平 | “买股票就是买公司”，但当前价格未达到“好价格+好公司”的双重要求。 | 灰色地带（激进型可考虑） |

## 适用场景

- **个人投资者的深度研究辅助**：普通投资者难以像专业机构一样组建投研团队。AI Berkshire 让一个人就能完成多视角、高纪律性的公司研究，节省大量时间，并提升决策质量。
- **专业投资者的第二意见与交叉验证**：即使拥有自己的投资框架，也可以使用 AI Berkshire 作为“AI 同僚”，快速获得来自四位大师视角的对抗性分析，验证自己的假设，发现可能忽略的风险。
- **投资学习与认知提升**：通过观察四位大师方法论如何被应用于真实案例，投资者可以快速理解价值投资的核心理念，并学习如何在自己的决策中融入这些原则。这是一个高效的学习工具。
- **构建量化投资策略的辅助环节**：量化策略者可以将 AI Berkshire 的结论（如“通过/不通过”）作为因子，融入到自己的多因子选股模型中，筛选出符合价值投资理念的候选标的。

## 项目亮点

- **真实有效的投资绩效**：与众多停留在概念层面的 AI 投资项目不同，AI Berkshire 公开了基于该框架实现的显著超额收益实盘记录，使其方法论具有极高的可信度和实践价值。
- **系统化的“大师智慧”**：它不仅仅是将几位大师的名言罗列出来，而是将其思想转化为具有可操作性的分析步骤和强制结论的决策机制，真正将“智慧”工程化。
- **对抗性与决策纪律**：核心亮点在于“四大师视角对抗”和“强制结论”。它避免了 AI 常有的“和事佬”式分析，强迫系统（以及用户）直面决策，这对于投资至关重要。
- **极低的使用门槛**：作为一套 Skill 合集，它的部署和使用都非常简单，几乎不增加用户的技术负担，任何使用 Claude Code 或 Codex 的人都能快速上手。
