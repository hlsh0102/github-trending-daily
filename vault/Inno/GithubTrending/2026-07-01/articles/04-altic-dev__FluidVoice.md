## 项目概述

FluidVoice 是一款专为 macOS 设计的高性能语音转文字（STT）听写应用，采用完全离线的设备端处理架构。它解决了传统云端听写服务延迟高、依赖网络连接、数据隐私受威胁等核心痛点。项目目标用户包括码农、作家、学生、内容创作者以及任何需要高效、私密、快速语音输入的 macOS 用户。作为 Wispr Flow 的开源替代方案，FluidVoice 通过自定义训练的 AI 增强模型，在本地实现了接近实时的语音识别体验，同时完全掌控用户数据。项目以 GPLv3 开源许可发布，目前仅支持 macOS，但 Windows、iOS 和 Linux 版本正在开发中。

## 核心功能

- **离线设备端语音识别**：所有语音处理在本地 Mac 上完成，无需网络连接，保证数据隐私和低延迟。
- **自定义训练的 AI 增强模型**：基于先进的开源模型（如 NVIDIA Nemotron Speech 3.5、Parakeet Flash/v3/v2、Cohere、Apple Speech、Whisper 等）进行微调，优化了实时听写的准确率和响应速度。
- **多模型支持**：用户可灵活选择和切换不同的语音识别模型，以适应不同语言、口音或使用场景（如快速听写 vs. 高精度识别）。
- **实时听写与即时输出**：语音输入时几乎无延迟地转换为文字，支持实时显示和快速插入到任何应用程序中。
- **极低资源占用**：经过优化的本地推理引擎，即使在较旧的 Mac 设备上也能流畅运行，不拖慢系统整体性能。
- **开源与社区驱动**：完全开源，代码透明，接受社区贡献和自定义扩展，鼓励用户参与模型训练或功能开发。

## 技术架构

FluidVoice 采用纯本地化的端到端架构，核心组件包括：

- **语音捕获模块**：利用 macOS 原生 Core Audio API 低延迟捕获麦克风输入，并进行音频预处理（降噪、归一化等）。
- **本地推理引擎**：基于 Swift 编写的原生推理框架，集成了 Core ML 和 MLX 等 Apple 原生机器学习工具，实现对多种 STT 模型（如 Whisper、Parakeet 系列）的实时加载与推理。推理引擎针对 Apple Silicon（M1/M2/M3/M4）和 Intel Mac 进行了深度优化，利用 Neural Engine 和 GPU 加速。
- **AI 增强管道**：在基础 STT 模型之上，通过自定义训练的后处理模型对识别结果进行纠错、标点恢复、上下文理解等增强操作，显著提升听写准确率。训练语料包括公开语音数据集和社区贡献的录制数据。
- **文本输出接口**：通过模拟键盘输入或 Accessibility API 将识别文字实时插入到系统剪贴板或当前激活的应用程序中（如文本编辑器、聊天窗口、IDE 等）。
- **模型管理系统**：允许用户从内置模型库中选择和下载不同精度的模型文件，并根据本地硬件资源自动切换最优配置。

架构设计强调低耦合和模块化，便于未来扩展至其他平台（Windows/Linux）。所有处理流程均基于异步并发，确保 UI 始终保持流畅无卡顿。

## 安装与使用

### 安装方式

1. **Homebrew（推荐）**：
   打开终端，执行以下命令：
   ```bash
   brew install --cask fluidvoice
   ```

2. **手动安装**：
   前往 [GitHub 最新发布页](https://github.com/altic-dev/FluidVoice/releases/latest)，下载 `.dmg` 或 `.app` 文件，解压后拖入“应用程序”文件夹。

### 基本使用

1. 启动 FluidVoice（首次启动时可能需要授予麦克风和辅助功能权限）。
2. 从菜单栏图标点击“开始听写”或按下预设的全局快捷键（默认 Option+F）。
3. 对着麦克风说话，文字将实时出现在当前光标所在位置。
4. 可通过菜单栏设置：
   - **模型选择**：切换不同 STT 模型（轻量、标准、高精度）。
   - **语言**：指定识别语言（目前支持英语、中文、日语、法语、德语等）。
   - **快捷键**：自定义启动/停止语音输入的快捷键。
   - **输出方式**：选择直接插入到文档或先复制到剪贴板。

### 最小可用示例

安装完成后，打开任意可编辑文本区域（如备忘录、VS Code、浏览器输入框），按 `Option+F` 开始说话，FluidVoice 会立即将语音转为文字并自动输入。要停止，再次按 `Option+F` 或说“停止听写”。整个过程完全离线，无网络依赖。

## 适用场景

- **编程与开发**：在 IDE 中使用语音快速编写代码注释、写文档、记录开发思路，无需双手离开键盘。
- **学术写作与内容创作**：在 Pages、Word、Markdown 编辑器等中高效撰写论文、博客、脚本，语音输入速度远超打字。
- **无障碍辅助**：为有打字困难或肢体不便的用户提供可靠的语音输入方式，且数据无需上传至云端。
- **快速笔记与会议记录**：在会议、头脑风暴或学习时，用语音实时记录灵感、待办事项或要点，并在结束后轻松导出整理。

## 项目亮点

- **最快速的 macOS 听写应用**：得益于本地推理和自定义增强模型，FluidVoice 实现了行业中领先的端到端延迟（<300ms），显著快于大多数云端方案。
- **完全离线 + 隐私优先**：所有数据处理均在本地完成，无任何数据外泄风险。这是与主流云端听写服务（如 Google、Apple 云端、Wispr Flow）的关键差异化优势。
- **高度可定制**：用户可选择不同基础模型和增强模型，甚至训练自己的模型并导入使用。开源特性允许开发者深入定制和扩展功能。
- **跨平台愿景**：虽然目前仅支持 macOS，但明确规划的 Windows、Linux、iOS 版本将使其成为跨桌面和移动平台的统一听写方案。
- **社区驱动的优化**：项目积极吸纳社区贡献，包括模型改进、性能优化和语言支持，形成了良性生态系统。
