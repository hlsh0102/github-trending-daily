## 项目概述

video-use 是一个基于 Claude Code 等编码代理实现视频编辑的开源工具。它的核心理念非常简单：将原始素材放入一个文件夹，通过自然语言对话与 AI 代理交互，最终获得一个可直接使用的 `final.mp4` 文件。该项目旨在消除传统视频编辑软件中复杂的菜单操作和预设限制，让视频创作回归内容本身。

项目面向的受众广泛，包括内容创作者、视频编辑师、教育工作者、播客制作者，以及任何需要快速处理视频素材但不想深入学习专业编辑软件的用户。video-use 100% 开源，采用 MIT 许可协议，已在 GitHub 上获得超过 12,800 颗星标。

## 核心功能

- **自动去除填充词和空白片断**：智能识别并剪除 `umm`、`uh` 等填充词以及拍摄之间的死区，无需手动逐帧检查
- **自动色彩分级**：可以对每个片段应用暖色调电影感、中性鲜明或自定义 FFmpeg 色彩链，统一视频视觉风格
- **无痕音频淡入淡出**：在每个剪切点自动应用 30 毫秒的音频淡入淡出，彻底消除因剪切导致的爆音或咔哒声
- **自定义字幕烧录**：默认采用两词大写的样式，且支持完全自定义字幕的字体、颜色、位置和显示方式
- **动画叠加生成**：支持通过 HyperFrames、Remotion、Manim 或 PIL 生成动画叠加层，由并行运行的子代理独立创建每个动画
- **渲染自评估**：在每个剪切边界进行自动渲染评估，在展示最终结果前确认输出质量
- **会话记忆持久化**：将会话状态保存在 `project.md` 文件中，下次编辑时可以无缝衔接上次的工作进度

## 技术架构

video-use 的核心设计思路是将视频编辑任务分解为一系列可编程的子任务，并由不同的 AI 代理并行处理。项目基于 Python 实现，依赖 FFmpeg 作为底层视频处理引擎，确保对各种视频格式的兼容性和高效的硬件加速支持。

关键技术栈包括：使用 Claude Code 等编码代理作为自然语言接口，通过自定义提示词驱动编辑流程；FFmpeg 负责视频编码、解码、剪切和色彩处理；HyperFrames、Remotion、Manim 等框架用于生成动画覆盖层；PIL（Pillow）用于简单静态图像处理。

架构上的重要特点是其模块化和并行处理能力。每个动画生成任务都作为独立子代理并行运行，互不干扰，极大减少了处理大量动画叠加时的等待时间。同时，通过 `project.md` 文件维护会话状态，实现了长时间编辑项目的断点续传能力。

## 安装与使用

基本安装步骤如下：

1. 克隆仓库并进入项目目录：
```bash
git clone https://github.com/browser-use/video-use.git
cd video-use
```

2. 安装依赖并设置 FFmpeg：
```bash
pip install -r requirements.txt
# 确保系统中已安装 FFmpeg 并配置好路径
```

3. 设置编码代理（如 Claude Code）并运行：
```bash
# 运行 Claude Code 并粘贴设置提示词
claude
```

在编码代理的交互界面中，粘贴以下提示词：
```
Set up https://github.com/browser-use/video-use for me.
Read install.md first to install this repo, wire up ffmpeg, register the project.
```

之后只需将原始视频素材放入指定文件夹，通过自然语言描述编辑目标（如“去除所有停顿”、“应用暖色调”、“添加标题动画”），video-use 将自动执行编辑流程并输出 `final.mp4`。

## 适用场景

- **内容创作者快速发布**：YouTube、抖音、Bilibili 等平台的博主可以在录制完素材后，通过自然语言快速完成基础剪辑，如去除废话、添加字幕和简单过渡效果
- **播客视频后期**：播客制作中常包含大量长时间对话，video-use 可以自动识别并删减不必要的沉默和重复内容，大幅缩短剪辑时间
- **教育视频与教程制作**：教师和培训人员在录制教学视频后，需要去除演示过程中的错误或停顿，同时叠加动画演示和字幕，video-use 能够一站式完成
- **采访和纪录片粗剪**：在采访拍摄结束后，可以快速生成包含基础色彩校正和剪辑的粗剪版本，为专业后期提供起点

## 项目亮点

video-use 最大的差异化优势在于其完全由自然语言驱动，摒弃了传统视频编辑软件中复杂的菜单、预设和快捷操作。用户只需像和朋友聊天一样描述编辑需求，AI 代理就能理解并执行。

与同类 AI 视频编辑工具相比，video-use 保持 100% 开源，不存在供应商锁定问题。用户可以完全控制编辑流程，甚至自定义 FFmpeg 色彩链和动画框架，满足高度专业化的需求。

另外，其并行处理和会话记忆机制也显著提升了实用性。多个动画可以同时生成，无需串行等待；长时间项目可以分多次完成，实现“周复一周”的渐进式编辑。
