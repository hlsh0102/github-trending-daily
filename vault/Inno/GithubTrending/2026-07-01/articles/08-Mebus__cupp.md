## 项目概述

CUPP（Common User Passwords Profiler）是一个基于 Python 的开源工具，旨在根据用户个人信息生成可能的密码字典。在安全测试或取证调查中，密码强度评估是一个关键环节。许多用户倾向于使用与个人生活相关的简单密码，如生日、昵称、宠物名或常见词语，这使得他们容易被针对性攻击所破解。CUPP 正是为了应对这一挑战而诞生——它通过交互式问答收集目标用户的公开信息，然后基于这些信息生成高度定制化的密码候选列表。该工具主要面向安全研究人员、渗透测试人员以及数字取证分析师，帮助他们在授权测试或犯罪调查中评估密码强度或进行密码恢复。

## 核心功能

- **交互式信息采集**：通过一系列预设问题（如姓名、出生日期、配偶名、宠物名、喜好等）引导用户输入目标人物的公开信息，无需手动编辑配置文件。
- **智能密码生成**：根据收集到的信息自动组合、变形和扩展出大量可能的密码变体，包括数字替换、大小写变换、常见附加字符（如 `!`、`@`、`#`）、年份组合等。
- **字典文件支持**：允许用户导入现有的密码字典文件（如哈希泄露列表或 WyD.pl 输出结果），并将其与生成的自定义密码列表合并或进行交叉分析，提高覆盖范围。
- **灵活的命令行选项**：支持 `-i`（交互模式）、`-w`（使用现有字典进行混合分析）等参数，可轻松集成到渗透测试工作流中。
- **轻量级与跨平台**：纯 Python 实现，支持 Python 3，可在 Windows、Linux 和 macOS 上直接运行，无需复杂依赖。

## 技术架构

CUPP 采用简洁的单一脚本架构，核心逻辑集中在 `cupp.py` 文件中。其工作流程分为三个阶段：

1. **信息采集阶段**：通过交互式 CLI 提示用户逐项输入目标个人资料，如名字（包括昵称）、姓氏、出生日期、伴侣和子女姓名、宠物名、公司名、特殊关键词以及喜欢的数字等。所有输入数据以字典形式暂存。
2. **密码生成引擎**：该引擎利用组合数学和常见密码模式库，对输入信息进行一系列变换：
   - 直接拼接：如“John1980”、“Alice@123”
   - 数字替换：将字母替换为相似数字（如 `e`→`3`、`i`→`1`）
   - 大小写变体：全大写、全小写、首字母大写、大小写交替
   - 添加前后缀：常见后缀如 `123`、`!`、`2023`；前缀如 `@`、`#`
   - 词汇替换：用同义词或变体替代（如“dog”→“doggy”）
   - 倒序和镜像：反转字符串或使用 Leet 语言编码
3. **输出生成**：所有生成的候选密码写入结果文件（默认文件名包含时间戳），支持去重和排序，输出格式为每行一个密码的纯文本文件，易于被其他工具（如 Hashcat 或 John the Ripper）直接使用。

代码设计遵循“纯文本输入/纯文本输出”原则，没有任何图形界面或数据库依赖，使其在受限环境（如 Docker 容器或远程 SSH 会话）中也能稳定运行。

## 安装与使用

**环境要求**：Python 3.6 或更高版本。

**安装步骤**：

```bash
# 通过 Git 克隆仓库
git clone https://github.com/Mebus/cupp.git
cd cupp

# 直接运行（无需额外安装任何 Python 包）
```

**基本使用**：

交互式模式（最常用）：

```bash
python3 cupp.py -i
```

程序将依次询问以下信息（部分字段可选，直接按回车跳过）：
```
[+] Name: John
[+] Surname: Doe
[+] Birthday (YYYYMMDD): 19800315
[+] Partner's name: Jane
[+] Pet's name: Buddy
...
[+] Please wait...
[+] Generating dictionary...
[+] Results saved to 'john-doe.cupp.txt'
```

导入现有字典并进行模式分析：

```bash
python3 cupp.py -w /path/to/wordlist.txt
```

查看命令行帮助：

```bash
python3 cupp.py -h
```

**最小可用示例**：只需输入姓名和生日，即可生成一个中等规模的密码列表。例如，输入姓名“admin”和生日“19900101”，会生成包含“admin1990”、“Admin1990!”、“admin0101”等常见变体的几百个密码。

## 适用场景

- **授权渗透测试**：在对客户企业进行安全评估时，使用 CUPP 针对特定员工生成密码字典，可以测试企业密码策略的有效性，帮助发现使用弱密码的高风险账户。
- **数字取证调查**：在犯罪调查中，如果发现嫌疑人设备加密，取证人员可以利用 CUPP 快速生成基于嫌疑人个人信息（如姓名、配偶、宠物、爱好）的密码列表，用于尝试解锁设备或加密文件。
- **企业安全意识培训**：安全团队可以利用 CUPP 生成员工可能使用的弱密码示例，通过实际演示对比强密码与弱密码的差异，提升员工的安全防范意识。
- **个人账户安全自查**：用户可以使用 CUPP 模拟攻击者对自己进行密码提取测试，了解如果自己的个人信息被泄露，攻击者可能猜出哪些密码变体，从而主动更换更安全的密码。

## 项目亮点

- **高度定制化**：与通用字典工具不同，CUPP 专注于基于个人信息的针对性密码生成，使测试更贴近现实攻击场景。它能够生成“生日+配偶名”这类高度个人化的密码组合，通用字典往往无法覆盖。
- **零依赖部署**：项目只有一个 Python 文件，无需安装任何第三方库，下载即可运行。这种“直接使用”的设计大大降低了使用门槛，特别适合临时测试或受限环境。
- **社区成熟度高**：项目已积累超过 6000 个 GitHub 星标，拥有活跃的 Issue 和 Pull Request 社区，持续更新已有 10 年以上，稳定性和可靠性经过市场验证。
- **兼容渗透测试生态**：输出格式直接兼容 Hashcat / John the Ripper 等主流密码破解工具，可以无缝嵌入自动化的渗透测试流水线中。
