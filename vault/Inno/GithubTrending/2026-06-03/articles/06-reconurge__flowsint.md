## 项目概述

Flowsint 是一个面向网络安全分析师和调查人员的开源 OSINT 图探索工具。它提供了一个可视化、灵活且可扩展的基于图的调查平台，帮助用户对公开来源情报（OSINT）数据进行关联分析。该项目专注于道德调查、透明度和可验证性，强调负责任的使用准则。无论是追踪网络威胁、分析社交网络关系，还是调查数字足迹，Flowsint 都能将复杂的数据关系转化为直观的图结构，让调查人员快速发现隐藏的线索和模式。

## 核心功能

- **可视化图探索**：通过交互式图形界面呈现数据节点及它们之间的关系，支持拖拽、缩放和路径高亮，让调查过程一目了然。
- **灵活的数据集成**：支持导入多种来源的 OSINT 数据，包括 IP 地址、域名、电子邮件、哈希值等，并可自定义数据字段和标签。
- **可扩展的调查工作流**：允许用户创建和保存调查会话，支持多步骤、分支式调查路径，并能导出调查记录用于报告。
- **本地隐私优先**：所有调查数据默认存储在本地机器上，无需外部服务器，确保敏感调查信息的私密性。
- **开源与社区驱动**：基于 Apache-2.0 协议开放源代码，鼓励社区贡献功能、修复问题并参与伦理讨论。
- **内置伦理指导**：附带详细的 ETHICS.md 文件，明确规范项目使用边界，防止滥用。

## 技术架构

Flowsint 采用现代化的前后端分离架构，主要由 TypeScript 语言构建。前端基于响应式框架（可能使用 React 或 Vue）实现富交互的图可视化界面，后端则提供轻量级的数据存储和查询接口。关键技术亮点包括：

- **图数据库思维**：虽然没有强制使用专门的图数据库，但数据模型围绕节点和边设计，支持高效的关联查询和路径分析。
- **Docker 容器化部署**：利用 Docker 和 Makefile 实现一键式生产环境启动，降低环境配置成本，确保跨平台一致性。
- **模块化设计**：核心调查模块、数据导入模块和可视化模块相互解耦，便于后续扩展第三方插件或集成新的 OSINT 数据源。

## 安装与使用

Flowsint 的安装非常简洁，只需依赖 Docker 和 Make 工具。以下是快速启动步骤：

1. **安装预依赖**：确保系统已安装 Docker 和 Make。
2. **克隆仓库**：
   ```bash
   git clone https://github.com/reconurge/flowsint.git
   cd flowsint
   ```
3. **一键启动生产环境**：
   ```bash
   make prod
   ```
4. **创建账户**：打开浏览器访问 `http://localhost:5173/register`，注册一个新账户（默认无预设凭证）。
5. **开始调查**：登录后即可创建新的调查会话，导入 OSINT 数据或手动添加节点，通过图形界面探索关系。

**最小可用示例**：启动后，在调查画布中添加一个“域名”节点，然后关联其对应的“IP 地址”节点，Flowsint 会自动尝试通过内置的数据源（如 VirusTotal、Shodan API）丰富节点信息。用户可以手动拖动节点布局，并添加注释记录发现。

## 适用场景

- **网络威胁分析**：安全分析师使用 Flowsint 追踪恶意域名、IP 地址的关联关系，快速绘制攻击基础设施图谱。
- **数字身份调查**：调查人员通过关联电子邮件、用户名、社交账号等节点，还原一个人的数字足迹和社交网络。
- **事件响应取证**：在安全事件发生后，用 Flowsint 梳理攻击路径、受影响资产和关联线索，生成可视化报告。
- **开源情报训练**：用于教学场景，帮助初学者理解 OSINT 调查中的信息关联方法论和可视化技术。

## 项目亮点

- **隐私优先与零信任设计**：颠覆传统 OSINT 工具依赖云端服务的模式，Flowsint 将数据控制权完全交给用户，本地存储确保调查过程不外泄。
- **伦理驱动的开发理念**：不同于许多只关注功能的工具，Flowsint 明确将 ETHICS.md 作为核心文档，规范调查边界，防止被用于侵犯隐私等不当用途。
- **极简部署体验**：利用 Docker + Make 实现“克隆—运行”两步启动，对于非技术背景的调查人员极其友好。
- **活跃的社区生态**：项目在发布早期即获得超过 4600 颗 Star，社区通过 Discord 和 GitHub 积极贡献，快速迭代新特性。
