## 项目概述

ECC（全称 Enterprise Chain Control / 智能体链控系统）是一个专为智能体（Agent）工作流设计的原生编排系统。它解决了当前 AI 编码助手在复杂项目中普遍存在的碎片化难题：不同工具（Claude Code、Codex、OpenCode、Cursor 等）各自为政，缺乏统一的技能、记忆、安全与性能优化机制。

项目目标用户是深度使用 AI 编码助手的开发者和工程团队，尤其是需要跨工具、跨项目、跨语言维护一致智能体行为的企业级用户。ECC 提供了一套开箱即用的“智能体操作系统”——包含内置的技能库、本能反应模式、长期记忆优化、持续学习流水线、安全扫描以及研究优先的开发方法论。

## 核心功能

- **多智能体跨工具适配**：原生支持 Claude Code、Codex、OpenCode、Cursor 等多种主流 AI 编码助手，提供统一的编排接口和适配层，使同一套技能和配置可在不同环境中无缝运行。
- **技能与本能系统**：内置丰富的可复用技能（Skills）和本能行为（Instincts），让智能体能够自主完成代码审查、重构、测试生成、文档构建等典型开发任务。
- **记忆优化与持续学习**：提供智能记忆管理引擎，自动压缩、索引和复用历史上下文，支持跨会话的持续学习，减少重复询问，提升工作效率。
- **安全扫描与防护**：集成实时安全扫描能力，在智能体生成或修改代码时自动检测敏感信息泄露、依赖风险、权限滥用等安全隐患。
- **研究优先开发流水线**：内置“研究优先”的工作流引擎，支持先进行多维度的探索性分析（代码库分析、架构推导、风险预判），再生成可执行的开发方案。
- **性能监控与调优**：包含智能体工效（Harness Performance）监控系统，实时追踪各工具的响应速度、上下文利用率和错误率，并自动给出优化建议。

## 技术架构

ECC 采用模块化、可插拔的架构设计。核心是一个轻量级的**编排内核**，运行在 Node.js 运行时之上。该内核负责：

1. **适配器层**：通过独立的适配器模块与不同 AI 编码助手（Claude Code、Codex 等）的 API 或命令行接口通信，屏蔽各工具的差异性。
2. **技能引擎**：技能被抽象为独立的 JavaScript 模块，遵循统一的输入/输出规范，支持链式调用和并行执行。
3. **记忆存储层**：基于本地文件系统和可选的外部存储（支持 SQLite、Redis 等），实现持久化的长期记忆，并带有智能压缩算法。
4. **安全沙箱**：在技能执行和代码生成时，通过静态分析和正则匹配引擎进行威胁检测，并支持自定义安全策略。
5. **事件总线**：所有模块通过事件总线进行解耦通信，便于扩展和第三方集成。

ECC 的包设计同样遵循模块化原则，在 npm 上发布为 `ecc-universal`、`ecc-agentshield` 等独立包，用户可根据需要按需引入。

## 安装与使用

ECC 可以通过 npm 全局安装或局部安装到项目中：

```bash
# 全局安装
npm install -g ecc-universal

# 或安装精简版（仅核心功能）
npm install ecc-universal
```

安装后，可使用 `ecc` 命令行工具快速启动一个智能体工作流：

```bash
# 初始化当前项目为 ECC 工作区
ecc init

# 运行一次完整的代码审视技能（对当前目录）
ecc run skill:code-review

# 查看所有可用技能
ecc list skills

# 启动持续学习模式
ecc start learning-watch
```

在与 Claude Code 或 Cursor 集成时，只需在对应的工具配置文件中加载 ECC 适配器：

```json
{
  "extensions": ["ecc-universal"],
  "skills": ["code-review", "test-generation", "docs-assembly"]
}
```

## 适用场景

- **大型多模块项目开发**：团队使用多种 AI 编码助手（如前端用 Cursor，后端用 Claude Code），需要保证智能体的行为习惯、安全策略和技能知识保持一致。
- **代码安全审计流水线**：在 CI/CD 中集成 ECC 的安全扫描技能，自动检测每个 Pull Request 中的潜在风险，并生成安全报告。
- **长期维护的遗留项目**：利用 ECC 的记忆优化和持续学习能力，使 AI 智能体能够逐步理解项目的历史决策、代码习惯和业务逻辑，越用越精准。
- **智能体行为研究与实验**：需要系统性地测试和对比不同 AI 编码助手在特定任务上的表现，ECC 提供统一的工作流捕获和回溯分析工具。

## 项目亮点

- **全生态系统覆盖**：支持 12 种以上语言生态，拥有 170+ 贡献者和 28K+ Forks，社区活跃度高，生态成熟。
- **工具链无关**：与其他智能体框架不同，ECC 不绑定任何特定 AI 编码助手，而是在上层提供统一的编排系统，真正实现“一次配置，到处运行”。
- **开箱即用的实战能力**：项目从真实的多工具工程工作流中提炼而来，内置的技能和本能直接可用于生产环境，无需大量定制开发。
- **零信任安全设计**：安全扫描不是附加功能，而是核心组件，从内核层面保障智能体行为的可控性。
