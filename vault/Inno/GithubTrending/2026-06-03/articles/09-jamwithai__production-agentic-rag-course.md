## 项目概述

The Mother of AI Project 是一个面向学习者的生产级 RAG（检索增强生成）系统实战课程。该项目以构建 arXiv 论文策展助手为主线，引导开发者从零开始搭建一套完整的、可投入实际使用的 AI 研究辅助系统。它解决了两个核心问题：一是学术论文信息过载，研究人员难以高效获取和消化最新成果；二是 RAG 技术学习路径碎片化，缺乏从基础到生产环境的系统教程。项目目标用户包括希望掌握现代 AI 工程技能的开发者、从事学术研究的科研人员，以及任何对构建 RAG 系统感兴趣的学习者。该项目托管在 GitHub 上，已获得超过 6500 颗星标，社区活跃度极高。

## 核心功能

- **自动论文获取与解析**：从 arXiv 自动抓取学术论文元数据与全文，支持按领域、关键词等条件筛选，并将纸内容解析为结构化数据。
- **多阶段检索管道**：先通过关键词搜索进行第一轮粗筛，再结合向量检索进行语义匹配，最后使用重排序模型优化结果，确保检索精度与覆盖面。
- **问答生成与引用溯源**：基于检索到的上下文，利用大语言模型生成自然语言回答，并自动提供引用来源，方便用户验证信息。
- **系统监控与日志**：集成生产环境所需的监控工具，追踪检索延迟、准确率等关键指标，并提供详细操作日志供调试与优化。
- **Docker 一键部署**：通过编排文件定义所有依赖服务，开发者只需一条命令即可启动包括数据库、推理引擎、应用服务器在内的完整系统。
- **分阶段学习模块**：课程按周划分为多个阶段，从基础环境搭建、数据处理、检索逻辑实现，逐步进阶到优化、监控与高级特性，适合循序渐进学习。

## 技术架构

项目采用模块化、微服务化的设计思路，其技术栈与架构特点如下：

- **后端框架**：基于 FastAPI 构建 RESTful API 服务，利用其异步特性处理高并发请求，同时通过 Pydantic 实现数据验证与序列化。
- **数据存储与检索**：使用 OpenSearch (2.19) 作为全文搜索引擎与向量数据库，同时支持传统关键词搜索与嵌入向量检索，实现了混合搜索能力。
- **向量化引擎**：采用 Sentence-Transformers 将论文标题、摘要与全文转换为高维向量，支持多种预训练模型切换，以适应不同语言与领域。
- **编排与部署**：借助 Docker Compose 将所有服务（API、数据库、推理服务等）容器化，确保环境一致性并简化部署流程。项目根目录下的 `docker-compose.yml` 文件定义了各服务的依赖关系与网络配置。
- **数据处理管道**：使用 Apache Airflow 或等效工作流引擎协调数据抓取、清洗、向量化与入库流程，支持增量更新与定时任务。
- **监控与可观测性**：集成 Prometheus 与 Grafana 采集系统指标，提供检索延迟、吞吐量、错误率等可视化仪表盘，帮助开发者发现瓶颈。

## 安装与使用

**环境要求**：Python 3.12+、Docker 与 Docker Compose。

**基本安装步骤**：
```bash
# 1. 克隆仓库
git clone https://github.com/jamwithai/production-agentic-rag-course.git
cd production-agentic-rag-course

# 2. 创建并激活虚拟环境
python3.12 -m venv .venv
source .venv/bin/activate  # Windows 用户使用 .venv\Scripts\activate

# 3. 安装 Python 依赖
pip install -r requirements.txt

# 4. 启动基础设施服务
docker-compose up -d

# 5. 运行数据初始化脚本（抓取示例论文并构建索引）
python scripts/init_data.py

# 6. 启动 API 服务
uvicorn app.main:app --reload
```

**最小可用示例**：启动后访问 `http://localhost:8000/docs` 即可看到 Swagger API 文档。发送如下 POST 请求即可进行论文检索：
```json
POST /api/search
{
  "query": "attention mechanism in transformers",
  "top_k": 5
}
```
系统将返回最相关的论文标题、摘要、全文链接以及基于大模型生成的回答。

## 适用场景

- **学术文献综述**：研究人员输入某个研究领域的关键词，系统自动检索 arXiv 上相关论文并生成综述摘要，辅助快速了解前沿进展。
- **技术方案调研**：工程师在开发新产品时，可以使用本系统快速检索与特定技术方案（如向量数据库、模型压缩）相关的最新论文，获取技术细节与实现思路。
- **教育辅助**：高校教师或学生可以利用该工具追踪课程相关研究动态，生成个性化阅读列表，提升学术信息获取效率。
- **企业内部知识库**：企业可借鉴本项目的 RAG 架构，构建内部技术文档或专利库的智能问答系统，支持员工快速获取专业知识。
