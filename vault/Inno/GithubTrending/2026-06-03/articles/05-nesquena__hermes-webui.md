## 项目概述

Hermes WebUI 是一个轻量级、深色主题的 Web 界面，为 [Hermes Agent](https://hermes-agent.nousresearch.com/) 提供了浏览器端的操作入口。Hermes Agent 是一款运行在服务器上的自主智能体，它能够持续学习并随着运行时间的增长而变得更加强大。传统的访问方式依赖于终端或即时通讯应用，而 Hermes WebUI 则让用户能够通过任何现代浏览器（包括手机浏览器）来管理和交互这个智能体。

该项目由 Nous Research 维护，旨在解决传统 CLI 操作门槛较高、移动端访问不便的问题。目标用户包括希望在任何设备上便捷使用 Hermes Agent 的开发者、AI 研究人员以及自动化工作流爱好者。

## 核心功能

- **完整 CLI 功能对等**：从 Web UI 可以执行终端能做的所有操作，包括创建会话、发送指令、管理配置文件等，无需在终端和浏览器之间切换。
- **三面板布局**：左侧边栏管理会话和导航，中央区域用于对话，右侧面板浏览工作区文件。这种布局让多任务处理和信息查看更加高效。
- **作曲家底栏**：模型选择、配置文件切换和工作区控制始终显示在底栏，用户编写消息时所有设置触手可及。
- **上下文环指示器**：通过一个圆形的上下文环实时显示当前会话的 Token 使用情况，帮助用户直观掌握资源消耗。
- **Hermes 控制中心**：位于侧边栏底部的启动器，集中管理所有设置和会话工具，包括密码配置、模型参数调整等高级功能。
- **浅色/深色主题切换**：除了默认的深色主题，还提供完整的浅色主题支持，适应不同使用环境和个人偏好。

## 技术架构

Hermes WebUI 在设计上追求极简与高效。项目基于 Python 后端和纯原生 JavaScript 前端构建，**没有使用任何前端框架、构建工具或打包器**。这意味着部署时无需运行 npm install、webpack 或任何编译步骤。

核心技术栈包括：
- **Python**：后端服务，处理与 Hermes Agent 的 API 通信，提供会话管理和文件操作接口。
- **原生 JavaScript**：前端交互逻辑，利用现代浏览器 API（如 Fetch API、WebSocket）实现实时通信。
- **CSS**：响应式布局和主题样式，支持深色/浅色模式的无缝切换。

架构特点：
- **零构建步骤**：仓库即运行状态，克隆后直接启动，非常适合快速部署和定制。
- **前后端分离**：前端通过 RESTful API 与后端通信，服务端不负责渲染 HTML，便于后续扩展为移动端 App 的后端。
- **轻量级依赖**：仅依赖 Python 核心库和 Hermes Agent 的 API 协议，避免大型框架带来的性能开销和兼容性问题。

## 安装与使用

### 安装步骤

1. **克隆仓库**：
   ```bash
   git clone https://github.com/nesquena/hermes-webui.git
   cd hermes-webui
   ```

2. **安装依赖**：
   本项目依赖 Python 3.8+，建议创建虚拟环境后运行：
   ```bash
   pip install -r requirements.txt
   ```

3. **启动服务**：
   ```bash
   python app.py
   ```
   默认情况下，服务会在 `http://localhost:5000` 启动。

4. **访问界面**：
   打开浏览器访问上述地址，你会看到三面板布局的 Hermes WebUI。

### 最小可用示例

启动后，你可以立即开始使用：
- 左侧边栏创建新会话
- 在中央区域输入消息，与 Hermes Agent 对话
- 右侧面板浏览和选择工作区文件
- 使用底栏切换模型或查看 Token 使用情况

如果需要密码保护，可以在 Hermes 控制中心中配置管理员密码。

## 适用场景

- **移动办公**：在没有 SSH 客户端的手机上，通过浏览器随时随地管理 Hermes Agent，查看运行状态、发送指令。
- **团队协作**：将 WebUI 部署在共享服务器上，团队成员可以通过浏览器共同访问同一个 Agent 实例，便于协作调试和任务分配。
- **远程服务器管理**：对于运行在云端或内网服务器的 Hermes Agent，WebUI 提供了比终端更友好的远程管理界面，特别适合不熟悉 CLI 的用户。

## 项目亮点

- **零前端框架**：在几乎所有 Web 项目都依赖 React/Vue 等框架的背景下，Hermes WebUI 坚持使用原生 JS，这不仅带来了极快的加载速度，也让二次开发和定制变得简单直接。
- **完整功能对等**：许多 Web UI 只提供 CLI 功能的子集，而 Hermes WebUI 实现了与终端完全一致的功能，用户无需在两者之间取舍。
- **移动端优先设计**：三面板布局在手机上会自动适配，底栏和侧边栏的交互经过专门优化，确保在小屏幕上的操作体验依然流畅。
- **MIT 开源许可**：项目采用宽松的 MIT 许可，允许商业使用和自由修改，为开发者提供了最大的灵活性。
