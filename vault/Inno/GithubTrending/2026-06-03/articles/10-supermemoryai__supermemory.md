## 项目概述
Supermemory 是一个面向 AI 时代的记忆引擎与上下文管理层，旨在为各类 AI 应用提供极致快速、可扩展的记忆服务。该项目解决了 AI 在长期对话、跨会话知识保持以及个性化上下文理解方面的核心痛点——即传统大语言模型在交互中缺乏持久记忆能力，无法有效维护用户历史、偏好或知识库。目标用户包括 AI 应用开发者、企业知识管理团队、个人效率工具构建者以及研究机构，它既可以作为个人/企业的“大脑”使用，也能作为 LLM 的底层记忆基础设施。作为一项研究实验室产出的开源项目，Supermemory 在 LongMemEval、LoCoMo 和 ConvoMem 三大主流 AI 记忆基准测试中均排名第一，证明了其技术领先性。

## 核心功能
- **高性能记忆存储与检索**：基于弹性的存储架构实现毫秒级读写，支持规模化的记忆数据管理，在三大基准测试中验证了其速度和准确度。
- **跨会话上下文持久化**：自动维护用户与 AI 交互的完整历史，确保多轮对话、跨应用场景下上下文不丢失，提供连贯的个性化体验。
- **灵活的 API 接口**：提供 npm 包和 PyPI 包两种集成方式，开发者可通过简洁的 API 调用将记忆能力嵌入任意 AI pipeline，不需要关心底层基础设施。
- **面向企业的可扩展架构**：支持集群化部署，能够处理海量用户和知识条目，适合构建公司级知识库或助手型产品。
- **实时同步与事件驱动**：支持记忆的增量更新和事件触发机制，使得知识变化能立即反映到后续 AI 推理中，满足实时性要求。
- **多模态记忆支持**：虽然核心以文本为主，但架构预留了图片、链接等非结构化信息的存储和关联能力，可扩展至多模态场景。

## 技术架构
Supermemory 采用 TypeScript 和 Python 双栈实现，前端应用与核心库分离设计。其架构核心围绕“记忆即服务”理念：底层使用高性能键值存储和向量数据库结合的方式，既支持精确匹配也支持语义检索；中间层实现了基于图结构的上下文关联引擎，能够将孤立的记忆片段组织成可推理的知识网络；上层提供 RESTful 和 SDK 两种访问模式，并内置缓存层和异步批处理机制，以应对高并发场景。特别值得注意的设计是“记忆分片与合并”算法：在导入大量数据时自动执行去重、相关性聚类和重要性排序，从而在有限上下文窗口内最大化信息密度。此外，项目还包含了开箱即用的 Web 管理面板（dashboard），方便用户可视化查看和管理记忆内容。

## 安装与使用
Supermemory 支持通过 npm 或 pip 快速集成：

**npm 安装（Node.js 环境）：**
```bash
npm install supermemory
```

**pip 安装（Python 环境）：**
```bash
pip install supermemory
```

**最小可用示例（Node.js）：**
```javascript
import { Supermemory } from 'supermemory';

const memory = new Supermemory({ apiKey: 'your-api-key' });

// 写入记忆
await memory.save('用户偏好: 喜欢科幻电影，尤其《星际穿越》');

// 检索记忆
const result = await memory.query('用户的电影喜好？');
console.log(result); // 输出相关记忆片段
```

**环境配置：**
用户需要在 [console.supermemory.ai](https://console.supermemory.ai) 创建账户并获取 API Key，同时可以根据实际需求配置数据持久化方式（默认本地存储或连接外部数据库）。

## 适用场景
- **智能助手与聊天机器人**：让个人或企业级 AI 助手记住用户历史偏好、对话习惯，实现“见过的客户不会忘”的体验，适合客服、销售辅助和虚拟私人助理。
- **知识管理平台**：作为公司内部知识库的大脑层，自动整合文档、会议记录、项目笔记，支持自然语言语义搜索，帮助团队快速沉淀并复用隐性知识。
- **AI 研究实验**：研究人员可利用 Supermemory 快速构建需要长期记忆的 AI agent 模型，或在迁移学习、终身学习研究中作为记忆模块的基线系统，其基准测试成绩确保了可靠性。
- **个性化内容推荐**：结合用户交互历史动态更新兴趣画像，驱动更精准的推荐算法，适用于资讯阅读、教育平台和社交媒体场景。

## 项目亮点
- **基准测试表现卓越**：在 LongMemEval、LoCoMo 和 ConvoMem 三个业内公认的记忆能力排行榜上均位居榜首，技术实力经过严格验证，远超同类开源方案。
- **双语言 SDK 支持**：同时提供 TypeScript 和 Python 原生 SDK，覆盖最主流的两大 AI 开发生态，降低了不同背景团队的接入门槛。
- **极简集成体验**：只需几行代码即可将记忆能力注入现有 AI 流程，无需理解底层存储细节，对比自定义实现可节省数周开发时间。
- **企业级可扩展性**：从原型验证到生产部署无缝升级，架构天然支持横向扩展，不会因数据量增长出现性能瓶颈。
- **开源与商业化并存**：采用 MIT 许可证，完全开放源码并提供云端托管版（dashboard），开发者可自由选择自托管或使用官方服务。
