## 项目概述

OpenAI Skills 是一个面向 Codex 的“技能”（Skills）目录仓库，旨在为 AI 智能体提供可复用的指令、脚本和资源集合。所谓“技能”，本质上是将某一类任务的执行知识打包成标准化的文件夹结构，使得 AI 智能体能够发现并调用这些能力去完成特定工作。

该项目解决了 AI 智能体在应对复杂任务时缺乏结构化、可复用能力的问题。在没有技能系统之前，每次对话都需要重新描述任务细节和步骤，效率低下且结果不稳定。Skills 的引入让“写一次，处处使用”成为现实，团队和个人都能将最佳实践沉淀为可安装、可分享的单元。该项目的目标用户包括 Codex 的使用者、希望扩展 AI 智能体能力的开发者，以及寻求标准化任务执行流程的团队。

需要特别注意的是，该仓库目前已经标记为**弃用状态**。官方建议用户转向新的 OpenAI Plugins 仓库，并参考“Build plugins”指南创建技能插件。尽管如此，该仓库在技能目录组织和安装流程上的设计理念，仍然对新插件体系具有重要参考价值。

## 核心功能

- **技能发现与安装**：仓库提供了一套清晰的技能安装流程，用户可以直接在 Codex 环境中通过 `$skill-installer` 命令安装所需的技能，无需手动下载文件或修改配置。
- **分层技能目录**：技能被划分为三个层级：`.system`（系统级，随最新版 Codex 自动安装）、`.curated`（精选级，需手动安装）、`.experimental`（实验级，供探索使用）。这种分层设计允许技能在不同成熟度上进行管理和发布。
- **技能缓存与搜索**：Codex 会自动发现可用的技能，并提供命令提示功能，帮助用户快速找到并调用合适的技能完成当前任务。
- **响应文件支持**：技能可以包含响应文件（response files），当用户触发某个技能时，Codex 会将对应的响应文件内容自动附加到对话上下文中，从而使智能体能立即获得执行任务所需的详细指南。
- **插件化扩展生态**：虽然仓库已弃用，但其后续演进的插件体系支持开发者将多个技能打包进一个插件中，实现更细粒度的能力控制和组合。

## 技术架构

该项目的核心架构思想是将“技能”定义为一种标准化的文件夹结构。一个技能文件夹通常包含一个 `SKILL.md` 文件用于描述技能的功能和使用方式，以及可选的脚本和资源文件。这种设计遵循了 Agent Skills 开放标准（见 agentskills.io），保证了不同 AI 智能体平台之间的技能可移植性。

Codex 的任务流程与技能系统深度集成。用户在对话中描述任务后，Codex 会从可用技能列表中选择最匹配的技能；若用户明确要求使用某个技能，Codex 也会遵循指令。此外，Codex 还能自动发现并合理应用技能，甚至能将多个技能组合使用以完成复合型任务。这种“发现-选择-调用”的模式，使得技能系统能够与智能体的原生推理能力无缝配合。

在分发层面，仓库采用分类管理策略：系统技能随 Codex 版本发布自动集成到所有用户环境中；精选技能经过了更严格的验证，鼓励更广泛的安装；实验技能则作为预发布渠道，允许先行尝试但可能需要更多调整。这种分布策略平衡了稳定性和创新的需求。

## 安装与使用

**注意**：由于仓库已弃用，以下步骤基于历史版本，建议新项目直接参考 OpenAI Plugins 仓库的指南。

安装技能的基本步骤如下：

1. **使用系统技能**：`.system` 目录下的技能已随最新版 Codex 自动安装，用户无需任何操作即可使用。
2. **安装精选技能**：在 Codex 中打开对话框，输入以下命令安装指定精选技能：

```
$skill-installer gh-address-comments
```

该命令默认从 `skills/.curated` 目录查找并安装同名技能。

3. **安装实验技能**：对于实验性技能，需指定技能文件夹名称，例如：

```
$skill-installer install the create-plan skill from the .experimental folder
```

安装完成后，Codex 会缓存技能并在需要时自动调用。用户可以在对话中描述任务，Codex 会自动选择合适的技能，也可以明确要求在任务中使用某个技能名称。对于通过 GitHub 仓库直接安装技能的情况，可以将技能仓库 URL 告知 Codex 进行安装。

## 适用场景

- **代码审查与评论**：例如通过 `gh-address-comments` 技能，自动获取 GitHub 上的评审意见并生成带引用的回复草稿，大幅减少开发者处理反馈的时间。
- **任务规划与拆分**：使用 `create-plan` 类技能，帮助智能体将复杂目标分解为可执行的步骤序列，适用于项目管理或大型软件开发的前期筹备。
- **团队最佳实践固化**：团队可将自己沉淀的编码规范、安全检查流程或部署手册制作成技能，供所有成员在 Codex 环境中复用，确保执行的一致性。
- **自定义工作流自动化**：通过将日常重复的、依赖特定操作序列的任务封装为技能，将通用智能体转化为领域专家，提升个人的自动化水平。

## 项目亮点

- **开放标准拥抱**：遵循 Agent Skills 开放标准，而非锁定于封闭的私有格式。这意味着按标准编写的技能可以在多个支持该标准的智能体平台之间迁移，降低了生态转换的成本。
- **开箱即用的体验**：系统技能随 Codex 发布自动生效，用户无需配置即可体验完整能力；精选技能的安装流程也足够轻量，只需一句自然语言指令。
- **分层管理策略**：系统、精选、实验的三级目录划分，既保障了核心功能的稳定性（系统级），又为社区贡献和快速迭代提供了渠道（实验级），形成了健康的分发生态。
- **清晰的演进路径**：尽管项目本身已弃用，但团队明确指出了迁移方向和详细指南，并保留了插件化扩展的升级路径。这种负责任的项目管理方式，为后续开发者与使用者提供了清晰的衔接。
