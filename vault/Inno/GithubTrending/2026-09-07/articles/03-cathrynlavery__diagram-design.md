## 项目概述

diagram-design 是一个面向 AI 编程助手（如 Claude Code、Codex、Pi 等）的图表设计套件，提供 39 种编辑级（editorial-grade）图表类型。该项目解决了当前 AI 生成图表时普遍存在的"设计灾难"问题——千篇一律的圆角矩形、刺眼的阴影、以及令人审美疲劳的 Mermaid 默认样式。它面向的是那些需要在文档、博客、提案或架构说明中使用专业图表，但又不想花费大量时间在 Figma 或 PowerPoint 中手动调整的设计师和开发者。项目的核心理念是：**你不需要成为设计师，也能生成设计师认可的图表**。

## 核心功能

- **39 种图表类型**：覆盖架构图、循环图（Loop）、Sankey 图、鱼骨图、Wardley 图、看板、用户旅程、部署图、依赖图、UML 类图、故事地图和数据库 schema 等，满足绝大多数技术写作与系统设计需求。
- **自包含 HTML + SVG**：每个图表输出为独立的 HTML 文件，内含 SVG 矢量图形，无需外部依赖、无需网络请求、无需本地运行时即可分享或嵌入。
- **语义化模式系统**：将"行为语义"与"布局语法"解耦。队列、策略追踪、信任边界等概念可以复用现有图表类型，无需为每个新概念创造一种新类型。
- **零阴影、零 Mermaid 膨胀**：默认样式遵循编辑设计（editorial design）原则——扁平、克制、清晰，摒弃花哨装饰，专注信息层级与可读性。
- **静态为默认，动态可选**：输出默认是纯静态 HTML，适合文档和打印；对需要分步讲解的场景，可开启无障碍动效（accessible motion），并按需控制动画强度。
- **源文件转换能力**：能够识别并重绘 draw.io 或 Mermaid 格式的源文件，在指定格式、尺寸和细节级别下输出相同内容的专业图表。

## 技术架构

diagram-design 的技术核心在于两个层面：**图表类型注册表**和**样式与语义分离的渲染引擎**。

图表类型注册表维护了 39 种图表的配置，每种类型声明其所需的图层结构、节点类型、连接逻辑以及默认样式变量（如配色、线宽、间距）。渲染引擎根据用户输入的文本描述或结构化数据，通过模式匹配选择最合适的图表类型，然后生成标准化的 HTML + SVG 文档。

项目刻意避免使用重量级 JavaScript 框架，所有图表均以静态 HTML 呈现，这意味着输出文件可以在浏览器直接打开、打印或嵌入任何文档。SVG 的生成遵循严格的层级结构，确保代码可读且易于在 AI 编程环境中迭代修改。

作为一个为 AI 编码工具设计的"技能"（Skill），diagram-design 在使用时通过自然的指令交互（如"画一个三层架构图"）触发，它自身决定了图表类型、布局与样式，从而省略了传统图表工具中繁琐的手动调整步骤。此外，项目在 2.5.10 版本引入了 10 种新的布局语法，但类型总数保持稳定，这种"语法扩展而不类型爆炸"的设计理念，使得 skill 的指令面保持简洁，可维护性显著提升。

## 安装与使用

diagram-design 并非传统意义上的软件库，它需要嵌入 AI 编码工具中。对于支持 Agent Skills 的主机（如 Claude Code 或 Factory Droid），将本仓库路径加入技能配置即可，若使用 Claude Code 则通过 `install-skill` 指令操作。

**使用示例**：在支持的环境（如 Claude Code）中，你只需用自然语言和期望的输出格式编写指令即可。

```text
你是一名系统架构师。使用 diagram-design 绘制一个电子商务系统的部署架构图，包含 3 个前端服务、2 个后端 API、数据库集群和缓存层。输出为 HTML+SVG，宽度 1200px，横向布局，采用编辑风格（无阴影）。
```

或者在给定已有 Mermaid 源码时，指示重绘：

```text
请用最好的图表类型重绘以下 Mermaid 流程图，加入必要的排版调整，去除冗余元素，并输出为 4:3 的 SVG 文件：[Mermaid 源码]
```

生成后的 HTML 文件可直接保存，浏览器打开即为成品，亦支持进一步定制样式变量（如修改配色代码）后再次渲染。

## 适用场景

- **技术文档与设计师协作**：当你在编写系统设计文档、API 说明或开发日志，需要专业视觉的表达，且不想与 UI 设计师反复沟通颜色与阴影细节时，此工具可一键交付审阅级图表。
- **AI 辅助架构评审**：AI 编程代理在参与代码重构或技术方案评审时，快速生成多种备选架构图，用于直观讨论，避免混乱的白板手绘。
- **博客与内容创作**：技术博客写手、内容团队需要给复杂的流程或概念配上高质量图表，diagram-design 提供的编辑风格能提升文章的信息美感，而无需购买专业图表设计软件。
- **遗留图表重构**：团队拥有大量基于 draw.io 或 Mermaid 的历史图表，风格不统一，希望快速批量升级为一致的设计风格——该工具提供了从旧格式到新格式的无损迁移路径。

## 项目亮点

- **对抗审美疲劳**：多数 AI 图表工具生成的结果带有明显的模板痕迹，本项目的核心卖点是严格的编辑设计风格——可辨识、经得起出版级审查，而非"四不像"的技术插图。
- **语义与布局解耦**：大多数同类工具将每一种画法都视为独立功能，导致类型库膨胀。diagram-design 用语义模式替代类型堆砌，用最小的类型集合表达最丰富的业务行为，这是其扩展性与易用性兼备的关键。
- **面向 AI 范式而非图形界面**：项目不为终端用户提供图形编辑器，它是为 Agent 或 Skill 的指令式工作流设计的。输出的 HTML+SVG 文件完全由代码生成，具备完美的可脚本化能力，契合现代 AI 原生开发流程。
- **对无障碍（Accessibility）的认真态度**：虽然默认是静态图，但它在支持动效的可访问场景中引入了可选的运动方案，为有阅读障碍的用户保留了可控的叙事节奏。
- **开放与实用许可证**：采用 MIT 协议，任何人可自由使用、修改、分发，加上极高的仓库热度（超过 3.2 万 Stars），社区验证了其项目生态的活跃与可靠性。
