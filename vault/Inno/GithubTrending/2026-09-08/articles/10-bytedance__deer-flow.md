## 项目概述

DeerFlow（**D**eep **E**xploration and **E**fficient **R**esearch **Flow）是由字节跳动开源的一款面向长周期任务的超级智能体框架（SuperAgent Harness）。它的核心目标是让 AI 智能体能够自主完成从**研究、编码到创作**的完整工作流，任务时长从几分钟到数小时不等。

与市面上大量只能处理单轮对话或短链路任务的轻量级 Agent 框架不同，DeerFlow 构建了一套完整的智能体基础设施——包括**沙箱环境、持久化记忆、工具调用、技能扩展、子智能体编排以及消息网关**——使得 AI 可以像人类工程师一样，在一项复杂的长期任务中持续工作、分步推进并最终交付成果。

DeerFlow 2.0 是该项目的一次彻底重写，与 1.x 版本不共享任何代码。1.x 版本（原 Deep Research 框架）目前在 `1.x` 分支上继续维护。自 2.0 发布以来，项目迅速攀升至 GitHub Trending 榜首，目前拥有超过 8 万 Star，社区活跃度极高。

## 核心功能

- **子智能体编排（Sub-agents Orchestration）**：支持将复杂任务动态拆解为多个子任务，交由不同的子智能体并行或串行执行，实现层级化任务管理。
- **持久化记忆（Memory）**：内置记忆系统，让智能体能够在长时间任务中保存和检索上下文信息，避免"边做边忘"的尴尬，确保长周期任务的一致性。
- **安全沙箱（Sandboxes）**：为代码执行和文件操作提供隔离环境，保障任务执行的安全性，同时支持多种沙箱后端。
- **可扩展技能库（Extensible Skills）**：通过插件化机制，用户可以为智能体持续添加新技能，使其能力边界可以随需求不断扩展。
- **消息网关（Message Gateway）**：统一的消息通信层，让不同子系统、工具和智能体之间能够高效传递数据与控制信号。
- **全流程自动化**：支持从问题定义、资料收集、方案设计到代码编写/文档产出的完整闭环，真正完成"研究→编码→创作"的任务链。

## 技术架构

DeerFlow 2.0 采用 **Python** 作为主要开发语言，在架构设计上遵循了几项关键原则：

**解耦与模块化**。整体架构将「编排层」与「执行层」分离。编排层负责任务规划、分解与子智能体的调度策略；执行层则专注于具体动作的落地执行。这种设计使得任意一层都可以独立替换或扩展，例如更换不同的调度算法而不影响执行环境。

**事件驱动机制**。通过消息网关串联各模块之间的通信，配合事件驱动模型，智能体在执行任务过程中能够实时响应外部反馈或内部状态变化，从而适应动态调整的任务需求。

**多层记忆体系**。DeerFlow 结合短期工作记忆与长期存储记忆，在任务执行过程中既保持对当前局面的敏锐认知，又能调用历史经验辅助决策，这在调试代码、跨轮次研究等场景尤为关键。

**工具即插即用**。技能（Skills）的设计类似 VS Code 的插件体系，每个技能封装一个特定的工具能力（如网页搜索、数据库查询、绘图渲染等），子智能体按需加载，极大提升了框架的灵活性。

## 安装与使用

DeerFlow 通过标准的 Python 包管理方式发布。参考仓库结构，建议的最小安装步骤如下：

1. **克隆仓库**

```bash
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow
```

2. **安装后端依赖**

项目采用 `pyproject.toml` 管理依赖（位于 `backend/` 目录下），同时提供了 `Makefile` 辅助构建。你可以使用 `make install` 或手动执行：

```bash
cd backend
pip install -e .
```

3. **配置 API 密钥**

在环境变量中设置你所使用的 LLM 服务商（如 OpenAI、Anthropic 或兼容接口）的 API Key：

```bash
export LLM_API_KEY=your_api_key_here
```

4. **启动并运行一个任务**

```python
from deerflow import SuperAgent

agent = SuperAgent()
result = agent.run("调研 2025 年向量数据库的技术趋势，并撰写一份带图表的简要报告")
print(result)
```

如果你的使用场景仅是阅读官网展示的案例，也可以直接访问 [deerflow.tech](https://deerflow.tech) 观看只读演示，无需注册或登录。

## 适用场景

- **自动化研究报告撰写**：给定一个研究主题，DeerFlow 可自主搜索资料、交叉验证信息、整合输出带结构化数据的深度报告，适用于投研、咨询、战略分析等领域。
- **代码库探索与编码任务**：智能体能够基于记忆和子智能体分工，对一个中大型代码仓库进行理解、定位问题并完成跨文件的代码修改与验证，可作为资深开发者的高效助手。
- **创意内容生产**：融合研究与生成能力，从素材收集到文本撰写一气呵成，适合长文创作、科普内容制作和技术文档构建等场景。
- **多步骤自动化工作流**：任何需要分阶段执行且各阶段依赖上下文延续的业务自动化流程，例如数据清洗→分析→可视化→PPT 生成的流水线。

## 项目亮点

- **直面长周期任务痛点**：大多数 Agent 框架在任务超过几十步之后就容易出现上下文丢失、错误累积等问题。DeerFlow 通过组合记忆、子智能体与消息网关机制，专门优化了几分钟到数小时的「马拉松式」任务场景的稳定性和完成度。
- **基于真实工程实践打磨**：源自字节跳动内部工程团队的实际需求，而非实验室的玩具项目。对于工具调用、沙箱隔离、错误恢复等生产环境痛点，都有针对性的设计。
- **积极迭代与版本重构**：2.0 版本推翻重来而非渐进修补，体现团队对架构演进的果断投入。活跃的主线开发与对 1.x 分支的持续维护，兼顾了新老用户的诉求。
- **友好的二次开发接口**：独立的技能扩展机制和模块化解耦架构，让社区贡献者和企业用户可以低成本地将 DeerFlow 接入自有系统。
