## 项目概述

God's Eye View 是一个运行在浏览器中的开源“间谍卫星模拟器”，但它与同类项目最大的不同在于——**所有数据都是真实的**。项目将全球公开的空间情报信号，包括实时航班、船舶、卫星、地震、交通流量乃至公共摄像头画面，整合到一个照片级逼真的 3D 地球仪上，让用户得以从一个前所未有的宏观视角观察世界的实时动态。

该项目源自 YouTube 上超过 500 万播放量的病毒式系列视频（原名为 WorldView），由开发者 bilawalsidhu 发起并开源。其目标用户包括地理信息爱好者、开源情报（OSINT）研究者、数据可视化爱好者、教育工作者，以及任何对“实时观察地球”抱有好奇心的人。项目的核心理念是：“世界正在持续广播——飞行应答器、船舶信标、轨道要素、地震仪、公共摄像头——而 God's Eye View 就是接收这些信号的窗口。”它将分散在无数浏览器标签页中的公开数据，整合为一个可交互、可探索的“地方”，而非冷冰冰的数据表格。

## 核心功能

- **实时全球态势感知**：在单一 3D 地球仪上叠加显示全球范围内的实时飞机、船舶、卫星、地震活动、道路交通流量以及公共摄像头画面，所有数据均来自公开可用的实时数据源。
- **照片级逼真 3D 渲染**：基于 WebGL 技术构建高度拟真的三维地球，包括地形、海洋、光照等细节，提供沉浸式的空间探索体验。
- **AI 语音控制**：集成实时 AI 智能体，支持自然语言语音指令，用户可以直接“说出”想查看的目标或区域，实现真正的“免提”操作。
- **智能视角模型**：对于无法提供实时视频流的目标（如特定卫星或军事设施），系统会自动生成带有明确标识的模拟视角，帮助用户理解该目标的理论外观与位置，同时避免与真实画面混淆。
- **开源可扩展**：项目完全开源，用户可以自由修改、扩展数据源或界面，甚至将其作为基础框架构建自己的空间情报应用。

## 技术架构

God's Eye View 是一款纯前端 JavaScript 应用，核心依托于 WebGL 实现高性能的 3D 地球渲染。项目采用模块化的数据接入层设计，通过 WebSocket 或轮询机制，从多个公开 API 实时拉取数据流，包括航班 ADS-B 信号、船舶 AIS 信号、卫星轨道 TLE 数据、USGS 地震数据等。前端通过统一的数据模型将异构数据标准化，并在地球仪上进行空间映射与可视化呈现。

项目的 AI 语音控制模块基于实时语音识别与意图解析技术，将用户指令转化为具体的视角移动、图层开关或目标搜索动作。在“模拟视角”功能中，系统利用轨道力学与摄影测量学原理，结合卫星的实时位置与姿态数据，计算并渲染出理论上的观景画面，并明确叠加“模拟视图”水印，确保数据透明性。

整体架构设计强调“即时性”与“沉浸感”的平衡：所有数据采集、解析、渲染均在浏览器本地完成，无需后端服务器，既降低了部署门槛，也最大程度减少了数据延迟。

## 安装与使用

由于项目是纯前端应用，你可以通过以下两种方式快速运行：

**方式一：直接克隆仓库并本地运行**

```bash
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
# 安装依赖（假设已安装 Node.js）
npm install
# 启动开发服务器
npm run dev
```

启动后，浏览器将自动打开本地开发地址（通常为 `http://localhost:3000`），即可看到完整的地球仪界面。

**方式二：静态部署**

项目构建后产出为纯静态文件，可以部署到任意静态托管平台（如 GitHub Pages、Vercel、Netlify）。

**最小可用示例：**

```javascript
// 在浏览器控制台中，直接通过全局 API 控制视角
// 例如：飞往东京上空
window.gev.flyTo({ lat: 35.6762, lng: 139.6503, altitude: 5000 });

// 开启船舶图层
window.gev.toggleLayer('vessels', true);

// 使用语音控制（点击界面上的麦克风按钮后，直接说：“放大到上海”）
```

## 适用场景

- **教育与科普**：用于地理、航天、信息科学等课程的教学演示，直观展示全球交通网络、卫星运行规律或地震分布带，让抽象的空间概念变得生动可感。
- **开源情报（OSINT）研究**：为研究机构、新闻记者或独立研究者提供一个快速整合全球公开数据的可视化工作台，辅助进行事件追踪、态势分析或线索发现。
- **数据可视化作品与实验**：开发者可基于该项目的高质量 3D 地球底座与实时数据流，快速构建个性化的可视化作品，探索空间数据的更多呈现可能。
- **日常探索与娱乐**：纯粹出于好奇心的用户，可以像玩一款“地球沙盒”一样，随时查看地球任何一个角落正在发生的公开动态。

## 项目亮点

- **真实数据驱动的“间谍模拟”**：不同于市面上纯虚构或模拟数据的类似产品，God's Eye View 的所有图层都连接到真实公开数据源，确保每一次查看都是地球当下的真实状态。
- **全端本地化，零后端依赖**：无需注册账号、无需自建服务器，克隆即是完整应用。数据直接在浏览器中汇聚渲染，部署与分享成本极低。
- **AI 语音交互开创先河**：在同类 3D 地球项目中率先引入实时 AI 语音控制，极大地降低了操作门槛，“看着地球，问它问题”成为可能。
- **透明的数据边界**：对于无法获取真实视频流的目标，系统以明确的“模拟视图”进行呈现，在提供直观感受的同时，严防误导，体现数据伦理。
- **活跃的社区与影响力**：背靠 500 万+ 播放量的 YouTube 系列视频，项目拥有活跃的用户社群与持续的迭代动力，且完全开源，任何人都可参与共建。
