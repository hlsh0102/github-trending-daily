## 项目概述

OpenMAIC（Open Multi-Agent Interactive Classroom）是由清华大学 THU-MAIC 团队开发的开源多智能体互动课堂项目。该项目致力于让用户通过一次点击即可获得沉浸式的多智能体学习体验。简而言之，OpenMAIC 将大型语言模型（LLM）驱动的多个智能体组织成一个虚拟课堂环境，用户可以在其中与不同角色（如教师、同学、助教等）进行互动学习。项目采用 TypeScript 编写，基于 MIT 许可证开源，目前已在 GitHub 上获得超过 22000 颗星，显示出社区的高度关注。

该项目解决的核心问题是传统在线学习交互模式单一、缺乏沉浸感的问题。通过构建多智能体协同的交互环境，OpenMAIC 希望让学习过程变得更加生动、个性化和可参与。其目标用户包括教育工作者、学习者、AI 研究者以及任何对多智能体系统感兴趣的开发者。

## 核心功能

- **一键部署与启动**：项目支持通过 Vercel 等平台一键克隆并部署，用户只需配置至少一个 LLM 提供商的 API 密钥即可运行，极大降低了使用门槛。
- **多智能体角色模拟**：系统内置了多种智能体角色，能够模拟真实课堂中的教师、同学、助教等角色，提供多对一的互动体验。
- **多 LLM 提供商支持**：兼容 OpenAI、Anthropic 等多个主流大语言模型提供商，用户可以根据需要自由选择或混合使用不同的模型（所有提供商均为可选配置）。
- **沉浸式交互界面**：提供友好的网页端聊天界面，支持多轮对话和上下文管理，让用户感受到置身于一个真实的互动课堂中。
- **可扩展的智能体配置**：开发者可以通过修改配置来定制智能体的性格、知识领域和对话风格，以适应不同的教学场景或学科需求。
- **中英文双语支持**：项目提供英文用户指南和中文体验指南，方便不同语言背景的用户快速上手。

## 技术架构

OpenMAIC 的技术架构围绕“多智能体编排”和“流式交互”两个核心设计思路展开。

在客户端，项目使用现代前端框架与 TypeScript 构建，确保类型安全和开发体验。界面层负责展示多智能体的对话流、状态以及用户输入交互。在服务端，项目采用无服务器架构（Serverless），通过 API 路由处理来自前端的请求。核心引擎负责管理和调度多个 LLM 智能体：根据用户输入和对话状态，决定哪个智能体应该“发言”、如何组织回复，以及如何注入系统提示词来维持角色设定。

关键设计特点包括：
- **事件驱动与流式响应**：项目利用流式传输（Streaming）技术，让智能体的回复以打字机效果逐字显示，这与真实对话的节奏一致，显著提升了沉浸感。
- **可插拔的 Provider 抽象层**：通过统一的接口抽象，项目能够无缝接入不同的 LLM API。这种设计不仅避免了对单一云厂商的锁定，还允许用户在不同模型之间进行对比或组合使用。
- **配置驱动的角色系统**：智能体的身份、语气和知识库并非硬编码在业务逻辑中，而是通过配置文件进行管理。这使得非开发者也能通过修改配置来调整课堂氛围或创建特定领域的课堂（如法学课堂、医学课堂等）。

## 安装与使用

安装 OpenMAIC 非常简单，推荐使用 Vercel 进行一键部署。

1.  **环境准备**：确保你拥有一个 GitHub 账号和一个 LLM 提供商（如 OpenAI、Anthropic）的 API 密钥。
2.  **一键部署**：点击项目 README 中提供的 Vercel 部署链接（`https://vercel.com/new/clone?repository-url=...`），Vercel 会自动克隆仓库并引导你进行配置。
3.  **环境变量配置**：在部署配置页面，至少填写一个 LLM 提供商的密钥（例如 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`）。所有密钥均为可选，但至少需要一个才能让智能体回复。
4.  **启动访问**：完成部署后，Vercel 会生成一个可公网访问的 URL。打开该 URL 即可进入互动课堂。
5.  **本地开发（可选）**：如果你想在本地二次开发，可以克隆仓库后执行 `npm install` 安装依赖，创建 `.env.local` 文件并填入相应的 API 密钥，最后运行 `npm run dev` 启动开发服务器。

一个典型的交互示例是：用户进入课堂后，向“教师”智能体提问“什么是量子纠缠？”，此时“同学”智能体可能会插话表达自己的理解，“助教”智能体则可能补充相关公式或课外阅读链接，用户可以与这些不同的意见进行对话，从而多角度理解概念。

## 适用场景

- **个性化自主学习**：用户可以根据自己的节奏，在没有任何社会压力的环境中向多个 AI 角色提问，适合自学新领域知识或备考复习。
- **课堂教学辅助**：教师可以使用 OpenMAIC 作为教学工具，演示 AI 如何模拟课堂讨论，或者将其作为课后答疑的数字助教，减轻答疑负担。
- **多智能体系统研究**：对于 AI 研究者或学生，该项目提供了一个直观的、基于网页的多智能体交互示例，便于研究多角色对话、角色一致性以及模型协作策略。
- **创意写作与头脑风暴**：用户可以将不同智能体设定为不同的编辑或评论员，让它们对一篇文案进行点评和修改建议，获得多维度的反馈。

## 项目亮点

与同类开源项目相比，OpenMAIC 的差异化优势主要体现在三点：

1.  **极致的易用性**：相较于许多需要复杂本地环境配置的 AI 项目，OpenMAIC 通过 Vercel 实现了“一次点击”即可在线体验，对非技术用户极其友好。
2.  **以教学场景为核心**：项目并非通用的多智能体聊天框架，而是深度聚焦于“课堂”这一特定场景，细致打磨了角色互动逻辑和用户体验，使其更贴合学习者的心智模型。
3.  **模块化与可配置性**：尽管体验简单，但底层的 Provider 抽象和角色配置机制保证了其灵活性，使其能够适应从技术演示到实际教研的多种需求，兼顾了“开箱即用”与“深度定制”。
