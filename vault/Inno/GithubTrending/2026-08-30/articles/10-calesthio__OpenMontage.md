## 项目概述

OpenMontage 是全球首个开源、基于智能体（Agentic）的视频生产系统。它将传统视频制作流程中的策划、脚本、拍摄、剪辑、配音、字幕等环节，抽象为可编排的自动化流水线，让开发者能够通过自然语言或代码驱动 AI 助手，完成从创意到成片的完整视频制作。

该项目由 calesthio 发起，旨在打破专业视频制作的高门槛，将原本需要多人协作、昂贵软件和大量时间投入的流程，压缩到个人开发者或小型团队可以在几分钟内完成。无论你是希望快速生成社交媒体短视频、制作教学演示，还是构建自动化视频内容生产线，OpenMontage 都提供了一套开箱即用的基础设施。

## 核心功能

- **12 条专业生产流水线（Pipelines）**：覆盖纪录片、产品宣传、教程讲解、新闻播报、短视频口播等主流视频类型，每条流水线封装了该类型视频从创意到输出的完整工作流。
- **100+ 集成工具**：内置了文本生成、图像生成、视频剪辑、音频合成、字幕识别、素材检索等超过 100 个第三方工具接口，统一封装为智能体可调用的能力。
- **700+ 技能与生产知识文件**：项目附带大量行业知识库，包括镜头语言、剪辑节奏、色彩搭配、配音规范等专业制作知识，让 AI 智能体在生成视频时遵循专业标准。
- **自然语言驱动**：支持直接输入「制作一个 60 秒的产品介绍视频」这样的指令，系统会自动拆解任务、选择合适的流水线和工具，完成全流程制作。
- **支持从已有视频反向工程**：粘贴任意视频链接，系统可以分析其结构、风格和剪辑模式，并生成与之相似的视频。
- **可编程 API 与事件回调**：开发者可以通过 Python 代码精细控制流水线每一步的执行，也可以监听各个阶段的事件，集成到自己的业务系统中。

## 技术架构

OpenMontage 的核心是一个基于 **Python** 的事件驱动型智能体编排框架。项目设计遵循以下几个关键原则：

1. **流水线即代码**：每条生产流水线是一个可序列化的 Python 脚本，定义了状态机、工具调用顺序和决策逻辑。这种设计让流水线可以轻松版本化、测试和分享。
2. **分层智能体架构**：系统顶层是一个「导演智能体」，负责理解用户意图，拆解为子任务；下层则是多个「专业智能体」，如编剧智能体、剪辑智能体、音效智能体，它们各自调用专长的工具链。
3. **统一的工具抽象层**：所有外部服务（如 OpenAI、Stable Diffusion、FFmpeg 等）都通过统一的接口协议接入，使得替换或新增工具不影响上层流程逻辑。
4. **知识文件注入机制**：700 多个生产知识文件以结构化 Markdown 存储，在每次运行时按需检索并注入到智能体的上下文窗口中，确保生成内容符合专业规范。

这种架构的最大优势在于 **可扩展性**：开发者不需要理解全部 700 个知识文件，只需专注于某一环节（如音频处理）就能深度定制，而其他部分继续沿用默认策略。

## 安装与使用

OpenMontage 要求 Python 3.9 及以上版本。推荐使用虚拟环境安装：

```bash
# 1. 克隆仓库
git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage

# 2. 创建并激活虚拟环境（可选）
python -m venv venv
source venv/bin/activate  # Windows 用户使用 venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置 API 密钥
cp .env.example .env
# 编辑 .env 文件，填入你使用的 AI 提供商（如 OpenAI）的 API 密钥
```

最小可用示例——生成一个 30 秒的产品口播视频：

```python
from openmontage import Director

director = Director()  # 初始化导演智能体

# 直接使用高层 API
video = director.produce(
    prompt="制作一个 30 秒的咖啡机产品介绍视频，突出便携和快速加热特点",
    pipeline="product_teaser"  # 指定使用产品宣传流水线
)

video.save("output.mp4")
```

如果你希望从已有视频开始，可以粘贴视频 URL 作为输入：

```bash
python cli.py --from-video "https://example.com/example.mp4" \
              --style "仿照原视频风格"
```

## 适用场景

- **内容创作者与自媒体**：定期产出短视频的创作者可以利用流水线批量生成素材草稿，再人工精修，将制作时间从半天压缩到半小时。
- **在线教育与企业培训**：将讲义自动转化为带旁白和字幕的教学视频，支持多语言配音，极大降低课程制作成本。
- **产品与营销团队**：输入产品卖点，自动生成多个版本的推广视频（横屏、竖屏、不同时长），用于 A/B 测试投放效果。
- **视频平台与 MCN 机构**：基于可编程 API，将 OpenMontage 嵌入现有的内容管理系统，实现视频内容的自动化生产与分发。

## 项目亮点

- **全球首创的 Agentic 视频制作范式**：不同于现有的自动剪辑工具，OpenMontage 让智能体深度参与内容创作，理解「为什么这样剪」而不是「怎么剪」。
- **专业知识的深度积累**：700+ 知识文件并非简单的 API 文档，而是将电影工业的隐性经验显性化，这是大多数开源项目无法企及的深度。
- **极高的定制自由度**：从替换单个工具到编写全新的流水线，开发者的每个环节都能介入。系统还提供了 Agent Guide 和 Review Guide，帮助二次开发者理解设计意图。
- **开源与社区驱动**：采用 AGPL-3.0 协议，核心代码完全开放。项目在 GitHub 上已获得超过 5 万 Star，社区贡献活跃，提供了丰富的插件和案例。
