## 项目概述

Archify 是一个面向 AI 编程助手的绘图与验证系统，能够将代码库或系统描述直接转化为精美的交互式架构图、流程图、时序图、数据流图与生命周期图。它适用于 Cursor、Claude Code、Codex CLI 和 OpenCode 等主流 AI 编程环境，让开发者可以在对话中即时生成可演示、可验证的系统地图，无需离开聊天窗口。

该项目解决了两个核心问题：一是 AI 生成的图表往往缺乏结构验证，难以反映真实系统拓扑；二是传统绘图工具与 AI 工作流割裂，产出物难以沉淀和审查。Archify 通过类型化 JSON 中间表示和确定性编译，让每次生成都可靠、可比较、可共享。目标用户包括使用 AI 辅助开发的软件工程师、系统架构师和技术文档编写者。

## 核心功能

- **五种图表类型与四种视觉预设**：支持架构图、工作流、时序、数据流和生命周期图，搭配多种预设风格，一键适配不同汇报场景。
- **变更对比审查**：可对两个已验证的架构快照进行 Before / Delta / After 三态对比，精确列出新增、删除、修改、移动和重路由的节点与关系。
- **交互式探索**：支持节点搜索、逐级追踪上下游依赖、查看具体路由与角色对比，所有交互均基于已验证拓扑，不会产生臆造内容。
- **多格式导出**：生成自包含的 HTML 文件，同时支持导出 PNG、SVG、WebM 视频以及 1200×630 的分享卡片，便于嵌入文档或演示。
- **确定性验证机制**：通过类型化 JSON IR 和确定性检查，确保每次编译结果可预期、可校验，避免 AI 生成带来的随机误差。
- **深色 / 浅色主题与品牌标识**：内置多种主题和品牌标记，开箱即用，适合直接向客户或团队展示。

## 技术架构

Archify 采用 Node.js 构建，核心设计围绕“类型化中间表示 + 确定性编译”展开。AI 代理（如 Claude Code、Cursor）首先将系统描述转换为类型化 JSON IR（中间表示），该 IR 严格定义了节点、边、属性和布局信息。随后，Archify 的渲染引擎以确定性的方式将 JSON IR 编译为 HTML/SVG 图形，确保相同输入始终产生相同输出。

这种架构带来两个显著优势。其一，**验证前置**：JSON IR 在渲染前经过类型检查与语义验证，从源头杜绝了拓扑错误和非法连接。其二，**快照可比较**：由于编译确定性，任意两个时点的快照都能进行精确的差异计算，从而支持变更审查功能。此外，整个渲染过程不依赖外部服务或网络资源，输出为单一 HTML 文件，极大降低了分享和部署成本。

## 安装与使用

Archify 通过 npm 分发，可在任意 Node.js 环境中安装使用。安装命令如下：

```bash
npm install -g archify
```

安装完成后，在支持的 AI 编程助手（如 Cursor 或 Claude Code）中，直接通过技能调用即可使用。以下是一个最小使用示例：

```bash
# 从系统描述生成架构图
archify render --input system.json --output diagram.html

# 比较两个架构快照的差异
archify diff --before before.json --after after.json
```

其中 `system.json` 为类型化 JSON IR 文件，可由 AI 代理自动生成，也可手写。生成后的 HTML 可直接用浏览器打开，并支持导出 PNG 或 SVG 等格式。

## 适用场景

- **AI 辅助架构设计**：在编码过程中，让 AI 代理实时绘制当前系统的架构图，并在演进过程中持续更新，保持文档与代码同步。
- **代码评审与变更审查**：在合并请求前，生成系统的 Before / Delta / After 对比图，直观展示本次改动对整体拓扑的影响，提升评审效率。
- **技术汇报与方案演示**：生成带有交互和动效的架构图，直接用于客户演示、团队分享或技术方案评审，无需额外准备幻灯片。
- **数据流与生命周期可视化**：对于事件驱动系统或复杂数据处理管道，快速生成数据流图和生命周期图，辅助定位瓶颈与依赖关系。

## 项目亮点

与同类工具相比，Archify 的差异化优势集中在三点。第一，**验证驱动的生成理念**：绝大多数 AI 绘图工具只是将提示词转为图片，而 Archify 通过类型化 IR 和确定性编译，保证生成的图表在结构上是正确且可校验的。第二，**面向 AI 工作流的深度集成**：它并非独立绘图软件，而是作为 AI 助手的技能存在，支持在聊天环境中直接调用，并可与代码库进行联动追踪。第三，**完整的变更对比能力**：这不仅是一个绘图工具，更是一个架构演进的可视化审查系统，这种能力在同类产品中较为稀缺。此外，项目采用 MIT 许可证，社区活跃，目前已获得超过 3 万颗星标。
