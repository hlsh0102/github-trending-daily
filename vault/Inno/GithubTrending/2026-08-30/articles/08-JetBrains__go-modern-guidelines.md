## 项目概述

Modern Go Guidelines 是 JetBrains 发布的一个开源指南仓库，旨在帮助 AI 编码代理编写符合现代实践规范的 Go 代码。该仓库为代码代理提供了一套系统性的编码准则，使其能够自动使用 Go 标准库中的最新特性和惯用写法，而不是停留在旧式模式上。

随着 AI 编码工具日益普及，它们生成的 Go 代码质量参差不齐，普遍存在"训练数据滞后"和"频率偏差"两大问题：模型可能不了解训练截止日期后新增的语言特性，即使了解也更倾向于输出训练数据中出现频率更高的旧式模式。该项目通过提供显式的参考准则，有效解决了这些问题，使得 AI 代理能够编写与现代 Go 版本保持同步的高质量代码。

该项目的目标用户包括使用 AI 编码助手进行 Go 开发的软件工程师、维护大型 Go 代码库的团队，以及关注 Go 语言演进的开发者。

## 核心功能

- **全面的 Go 特性覆盖**：涵盖从 Go 1.0 到 Go 1.27 的所有重要语言特性，包括 `modernize` 分析器所涵盖的全部范围，并提供详细的说明与代码示例（见 FEATURES.md）。
- **版本感知编码**：代理自动从 `go.mod` 文件中检测项目使用的 Go 版本，并仅使用该版本及之前可用语言特性和标准库函数，避免兼容性问题。
- **现代惯用模式优先**：引导代理采用较新的写法替代老旧模式，例如使用 `max(a, b)` 替代 if-else 判断，使用 `slices.Contains` 替代手写循环，使用 `cmp.Or(a, b, c)` 替代一长串 nil 检查链。
- **最新 Go 1.26 特性支持**：明确标注新版本中才可用的特性，如 `new(42)` 直接获取指向值的指针，以及 `errors.AsType[T](err)` 进行类型安全的错误匹配。
- **与 Go 团队方向对齐**：项目遵循 Go 官方团队对语言演进的发展方向，确保推荐做法的权威性与正确性。

## 技术架构

Modern Go Guidelines 采用纯文档仓库的形式，以 Markdown 文件承载结构化的编码规范。其核心是一份精心维护的 FEATURES.md 文件，按 Go 版本组织记录各版本引入的语言特性和标准库新增函数，并附上简明示例说明。

项目的设计遵循"显式优于隐性"原则：将分散在 Go 各版本 release notes 和文档中的新特性集中到单一参考源，供 AI 代理在生成代码时快速检索。同时，这种设计也充分利用了 AI 模型的上下文学习能力，通过为代理提供高质量参考文本，引导其产生符合现代规范的输出。

仓库还配套说明了代理的推理规则：先读取 go.mod 来判断最小支持的 Go 版本，再根据该版本决定可使用哪些现代特性，最后在生成代码时优先采用最新且兼容的写法。这种"版本感知+现代优先"的双层策略既保证了代码的先进性，又避免了因使用过新特性而导致的编译失败。

## 安装与使用

该仓库本身无需安装，使用方式是将规则集成到 AI 编码代理的配置或提示词中。

1. **克隆或引用仓库**：将仓库克隆到本地或直接通过 URL 引用其内容。
   ```bash
   git clone https://github.com/JetBrains/go-modern-guidelines.git
   ```

2. **作为指导文档使用**：将 FEATURES.md 的内容作为上下文提供给 AI 编码代理，或将其放入项目的 `.cursorrules`、`.prettierrc` 等受支持的配置文件中。例如，使用 Claude Code、Cursor、GitHub Copilot 时，可在系统提示中指定 "请参考 Modern Go Guidelines 编写符合现代惯例的 Go 代码"。

3. **最小验证示例**：在 Go 1.26+ 项目中，AI 代理应在代码自动化中倾向以下写法：

   ```go
   // 旧写法
   var a *int = new(int)
   // 现代写法（Go 1.26+）
   a := new(42) // 返回指向值为 42 的指针

   // 旧写法
   var result = "default"
   if a != nil {
       result = a.Value
   }
   // 现代写法
   result := cmp.Or(a, b,  "default")
   ```

## 适用场景

- **AI 辅助开发流程**：团队使用 GitHub Copilot、Codeium 或其他 AI 编码工具进行 Go 项目日常开发时，可显著提升代码生成质量。
- **大型 Go 代码库现代化改造**：帮助团队参照最新最佳实践系统性地重构旧代码，与 `gopls modernize` 工具配合使用。
- **对代码审查与培训**：为开发小组提供统一的 Go 编码标准参考，作为 code review 检查清单或新员工培训材料。
- **Go 语言学习与借鉴**：个人开发者可通过 FEATURES.md 快速了解 Go 各版本的功能演进，掌握更地道的编码方式。

## 项目亮点

### 针对 AI 生成代码问题量身定制
与传统的编码规范不同，该项目直接针对 AI 编码代理的常见失误（训练数据滞后、频率偏差）设计解决方案，实用性强。

### 兼具时效性与全面性
覆盖面从 Go 1.0 至最新的 1.27 版本，并持续跟踪 Go 团队发版节奏更新内容，保持技术前沿性。

### 无侵入设计
无需引入依赖或修改构建流程，仅通过文档规范指导代理行为，接入成本极低，与现有 Go 工具链无缝兼容。

### 来源权威
由 JetBrains（GoLand IDE 开发商）维护，与 Go 官方团队发展方向保持一致，规范准确性有保障；在 GitHub 上已获超过 2900 星，获得了社区的广泛认可。
