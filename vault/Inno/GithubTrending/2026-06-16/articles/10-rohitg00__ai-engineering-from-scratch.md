## 项目概述

AI Engineering from Scratch 是一份面向 AI 工程师的完整学习指南，致力于帮助开发者从零基础开始，系统掌握 AI 工程化的核心技能，最终能够独立构建和部署 AI 应用。该项目由 GitHub 上广受欢迎的 Agent Memory 项目的创建者 rohitg00 发起，目前已包含 503 节课程、20 个阶段，覆盖从理论到实践的完整学习路径。

这个项目诞生的背景是：大量使用 AI 工具的学生和开发者并不了解其底层原理，更缺乏将 AI 技术落地为可用产品的能力。项目通过循序渐进的课程设计和大量实战练习，帮助学习者真正掌握“理解、构建、交付”的完整 AI 工程化流程。目标用户包括希望转型 AI 方向的软件工程师、已有代码基础的非 AI 领域技术人、以及想要系统提升 AI 开发能力的在校学生。

## 核心功能

- **503 节结构化课程**：从机器学习基础到高级推理引擎设计，课程按阶段组织，循序渐进，每节课都包含理论讲解和代码实现。
- **20 个专项学习阶段**：涵盖机器学习、深度学习、流行模型系统、大规模语言模型、智能体、RAG（检索增强生成）、推理引擎以及实践项目等完整知识体系。
- **完整代码示例与可运行项目**：每个阶段都提供配套代码，学习者可以边学边练，直接运行和修改示例代码。
- **综合实战项目**：项目后期提供多个端到端的 AI 应用开发实践，覆盖了从需求分析到部署上线的完整流程。
- **持续更新的内容体系**：项目维护者会参考行业最新进展，定期更新课程内容，确保学习者学到的是当前实用的技术和框架。
- **社区驱动与贡献机制**：项目支持社区贡献和讨论，学习者可以通过 PR 和 Issue 参与内容完善，形成良性学习生态。

## 技术架构

项目以 Python 作为主要编程语言，依托 Python 在 AI 和数据科学领域的成熟生态。课程设计中广泛使用主流深度学习框架（如 PyTorch、TensorFlow 等），以及 NLP 和计算机视觉领域的通用工具库。整个项目的技术思路遵循“从底层原理到工程实践”的学习逻辑，具体体现在以下几个方面：

- **分层渐进式结构**：先构建数学和算法基础，再学习模型训练和优化，最后深入到推理引擎、智能体系统等高级话题。
- **代码优先的教法**：每节课程的理论讲解后都紧跟代码实现，让学习者在实践中理解抽象概念。
- **模块化设计**：每个阶段和课程相对独立，学习者可以根据自身基础选择性学习，或跳过已经熟悉的环节。
- **端到端覆盖**：从数据处理、模型训练、评估优化到部署上线，项目完整覆盖 AI 工程化的所有关键环节。

## 安装与使用

项目的使用方式非常直接，不需要复杂的安装过程。基本步骤如下：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
   cd ai-engineering-from-scratch
   ```

2. 安装基础的 Python 环境（建议使用 Python 3.10 或更高版本）：
   ```bash
   pip install -r requirements.txt
   ```

3. 从你感兴趣的阶段开始学习，例如第一阶段的基础内容：
   ```bash
   cd phase-01-machine-learning-basics
   jupyter notebook
   ```
   或者直接使用 VS Code 打开对应的 Python 文件运行。

4. 每个课程文件夹下都有详细的 README 说明和代码注释，建议按照课程顺序逐步学习。

需要注意的是，部分高阶课程可能需要 GPU 环境或额外的依赖库，项目中会注明具体的安装要求，尤其是在大规模语言模型和推理引擎相关阶段。

## 适用场景

- **AI 工程新人入门**：如果你有一定编程基础但缺乏 AI 知识，这个项目提供了一条从零到一的完整学习路径，帮你快速建立 AI 工程化的知识框架。
- **软件工程师转型**：对于希望转向 AI 方向的软件工程师，项目中的实战项目部分提供了宝贵的工程实践案例，可以直接应用于实际工作。
- **高校课程辅助**：作为 AI 相关课程的补充教材，学生可以通过项目中的代码示例和练习巩固课堂所学，加深对机器学习原理的理解。
- **技术面试准备**：项目中的综合练习题和实战项目可以帮助面试者系统梳理 AI 核心知识点，并积累有说服力的项目经验。

## 项目亮点

- **零基础友好且体系完整**：与其他只提供零散笔记或教程的项目不同，这个项目构建了从基础数学到高级推理引擎的完整知识体系，没有知识断层。
- **聚焦工程实践**：不满足于理论讲解，项目强调“能构建、能交付”，每个阶段都有可以实际运行的代码和案例，学习者可以立刻看到应用效果。
- **真正快速的迭代**：项目在 GitHub 上活跃更新，目前已有超过 3.3 万 star 和持续的增长，其内容紧跟 AI 领域最新进展（如大规模语言模型、RAG、智能体等）。
- **社区共建生态**：项目鼓励学习者通过 Issue 和 PR 参与内容贡献，形成了开放、共建的学习社区氛围。
- **与知名项目联动**：项目创建者同时还维护着热门的 Agent Memory 项目，学习者可以在完成本课程后，将所学直接应用到更高级的开源项目中去。
