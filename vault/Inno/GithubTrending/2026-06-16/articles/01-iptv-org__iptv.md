## 项目概述

IPTV 是一个全球公开 IPTV 频道集合项目，托管在 GitHub 上。它从世界各地收集了大量可公开访问的 IPTV 频道，并将其整理成标准化的 M3U 播放列表文件。项目的主要目标是解决用户寻找可靠、免费且覆盖广泛的 IPTV 频道列表的难题。目标用户包括希望使用 IPTV 观看直播电视节目的普通观众、开发测试人员、以及研究电视广播技术的爱好者。项目采用 Unlicense 许可证，完全开源免费，目前已获得超过 12 万 GitHub 星标，是同类项目中规模最大、最活跃的之一。

## 核心功能

- **全球频道集合**：收录来自全球数百个国家和地区的公开 IPTV 频道，涵盖新闻、体育、娱乐、电影、儿童节目等多种类型。
- **标准化 M3U 播放列表**：所有频道以标准 M3U 格式提供，可直接在大多数支持直播流的视频播放器中使用。
- **电子节目指南（EPG）支持**：提供配套的 EPG 数据下载工具，用户可以获取频道的节目时间表，实现类似传统电视的节目预告功能。
- **分类筛选**：除了主播放列表，还提供按国家、语言、类别等维度筛选的子播放列表，方便用户快速定位所需内容。
- **结构化数据库**：频道元数据（名称、标志、国家、语言、类别等）存储在独立数据库中，支持社区贡献和错误修正。
- **API 接口**：提供 RESTful API，开发者可以编程方式查询频道数据、播放列表链接和 EPG 信息。

## 技术架构

项目采用多仓库协作架构，主要技术栈包括 TypeScript、Node.js 和 GitHub Actions。核心设计思路是将数据、播放列表生成和 API 服务分离：

- **数据层**：`iptv-org/database` 仓库管理所有频道元数据，采用 JSON 格式存储，社区通过 issue 和 pull request 贡献数据。
- **生成层**：主仓库 `iptv-org/iptv` 通过 GitHub Actions 定期从数据库仓库拉取最新数据，自动汇总生成 M3U 播放列表文件，并发布到 GitHub Pages。
- **服务层**：`iptv-org/api` 仓库提供基于 Node.js 的轻量级 API 服务，支持按国家、语言、类别等参数动态查询频道列表。
- **EPG 层**：`iptv-org/epg` 仓库包含抓取和生成 EPG 数据的工具，利用 GitHub Actions 定时更新 XMLTV 格式的节目指南。

这种架构保证了数据维护的灵活性、播放列表生成的自动化以及查询接口的可扩展性。所有自动化任务（数据更新、播放列表构建、EPG 生成）均由 GitHub Actions 触发器驱动，无需人工干预。

## 安装与使用

使用 IPTV 播放列表非常简单，无需安装任何软件。只需执行以下步骤：

1. **选择播放列表**：主播放列表链接为 `https://iptv-org.github.io/iptv/index.m3u`。如需特定国家或类别的列表，可参考 `PLAYLISTS.md` 文件中的索引。
2. **打开视频播放器**：在支持 M3U 播放列表的视频播放器中（如 VLC、IINA、Kodi、PotPlayer 等），选择“打开网络流”或类似选项。
3. **输入链接**：粘贴上一步复制的 M3U 链接，点击打开。播放器会自动加载频道列表并显示为节目菜单。
4. **选择频道**：从列表中选择想要观看的频道，等待缓冲即可播放。

最小可用示例（以 VLC 为例）：
- 打开 VLC Media Player。
- 点击“媒体” -> “打开网络串流”。
- 在网络 URL 输入框中粘贴 `https://iptv-org.github.io/iptv/index.m3u`。
- 点击“播放”，VLC 将载入频道列表，左侧显示所有频道名称，双击即可切换观看。

## 适用场景

- **个人娱乐**：全球范围内免费观看公开的直播电视节目，无需订阅付费 TV 服务。适合旅居海外者观看家乡频道，或探索不同国家的文化内容。
- **开发测试**：开发 IPTV 相关应用（播放器、EPG 工具、频道搜索工具）时，作为稳定、多样的测试数据集。项目提供的 API 可模拟真实业务场景。
- **教育与研究**：分析全球电视广播的分布规律、频道类型偏好、语言覆盖等，用于传媒研究或数据可视化项目。
- **嵌入式/物联网项目**：在树莓派、智能音箱等设备上集成 IPTV 播放功能，提供流媒体演示或信息展示屏。

## 项目亮点

- **规模巨大且持续更新**：收录数十万个频道，覆盖全球绝大多数国家和地区。每天自动同步数据，保持列表新鲜度。
- **社区驱动质量保障**：任何用户都可以通过 GitHub issue 报告失效频道或添加新频道，经过审核后合并到数据库，确保数据准确性。
- **零成本使用**：完全免费，无广告、无追踪、无黑盒限制。播放列表直接公开，不依赖任何中介平台。
- **生态完整**：核心仓库之外，还提供数据库、API、EPG、Awesome-IPTV（应用推荐）等多个配套项目，形成一站式 IPTV 解决方案。
- **标准化输出**：严格遵守 M3U 格式标准，兼容几乎所有主流播放器。频道元数据结构化，易于二次开发。
