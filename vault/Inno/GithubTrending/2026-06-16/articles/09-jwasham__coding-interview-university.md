## 项目概述

Coding Interview University 是一份由前亚马逊工程师 John Washam 创建的开源计算机科学学习计划，旨在帮助开发者系统性地准备技术面试。项目最初只是作者个人备考 Google 的待办清单，但经过不断完善，最终演变为涵盖数据结构、算法、系统设计等核心领域的完整知识体系。作者本人通过这份计划成功入职亚马逊，并将经验无偿分享给社区。项目的目标用户是所有希望进入大型科技公司（如 Google、Amazon、Facebook、Microsoft）的软件工程师，无论是应届生还是转行者，都能从中受益。与市面上零散的刷题指南不同，它提供了一条从基础到进阶的明确路径，强调“理解原理”而非“死记答案”。

## 核心功能

- **结构化学习路线图**：从编程语言基础（如 C、Python、Java）开始，逐步覆盖数据结构（数组、链表、树、图）、算法（排序、搜索、动态规划）、系统设计、计算机网络等主题，每部分都按优先级排序。
- **精选学习资源**：整合了 Yale、MIT、Stanford 等顶尖大学的公开课（如 MIT 6.006 算法导论）、经典教材（如《算法导论》）、视频教程及在线练习平台（如 LeetCode、HackerRank），并标注了必看和可选内容。
- **量化学习进度表**：提供每日/每周学习计划模板，包括复习提醒和自测题目，帮助用户跟踪完成度。作者建议每天投入 8-12 小时，但强调可根据个人基础灵活调整。
- **多语言翻译支持**：项目已翻译成包括中文、日语、西班牙语等 20 多种语言，降低了全球开发者的参与门槛。
- **面试技巧与经验分享**：包含作者亲身总结的时间管理、压力应对、白板编程技巧，以及多个大厂的真实面试流程解析。
- **社区协作与贡献指南**：任何人都可以通过 Issue 或 Pull Request 补充新资源、修正错误，项目维护者定期审核更新，保持内容时效性。

## 技术架构

Coding Interview University 本身是一个纯 Markdown 文档项目，不涉及代码运行或服务器部署。其核心设计体现在以下方面：

- **分层知识组织**：采用“概念 → 实现 → 应用”的递进结构。例如，讲解“二叉搜索树”时，先通过视频理解定义，再手写代码实现插入/删除操作，最后结合 LeetCode 题目（如验证二叉搜索树）进行实战。
- **资源筛选机制**：所有链接均经过人工筛选，优先选择 20 分钟以内的视频、包含代码示例的文章、以及权威性高的大学课程，避免信息过载。
- **可定制性设计**：使用 `<details>` 标签折叠非核心内容（如翻译列表、扩展话题），主文档保持简洁。用户可基于自身基础跳过已掌握的部分，或深入感兴趣的子主题（如分布式系统、数据库索引）。
- **版本控制友好**：每个 Commit 附有清晰说明，用户可通过 Git 切换不同版本，对比资源更新历史。例如，2023 年新增的“机器学习面试准备”章节可在特定 Tag 下查看。

## 安装与使用

### 基本使用步骤

1. **访问仓库**：打开 [coding-interview-university](https://github.com/jwasham/coding-interview-university)，直接阅读 `README.md`。
2. **选择语言**：在页面顶部点击 “Translations” 折叠面板，选择中文或其他语言版本（如 [中文版](translations/README-zh.md)）。
3. **制定计划**：根据自身时间安排，从 “Daily Plan” 章节复制模板到本地笔记中，按周划分学习任务。例如，第一周：学完“算法复杂度分析”和“数组与链表”的推荐视频，并完成 5 道基础 LeetCode 题。
4. **开始学习**：按顺序浏览每个主题，点击提供的视频链接（如 YouTube 播放列表）或 PDF 教材，手写代码实现关键算法。
5. **自测与复习**：每个大章节末尾有“复习问题”列表，使用间隔重复方法（如 Anki 卡片）巩固知识点。

### 最小示例

假设你已完成编程语言基础，以下是“栈与队列”章节的一个最小学习片段：

1. 观看 YouTube 视频：《数据结构基础：栈与队列》（链接见文档）。
2. 用 Python 实现栈的 push/pop 操作：
   ```python
   class Stack:
       def __init__(self):
           self.items = []
       def push(self, item):
           self.items.append(item)
       def pop(self):
           return self.items.pop()
   ```
3. 在 LeetCode 上搜索标签为 “Stack” 的简单题目，如 “Valid Parentheses”，尝试独立解决。
4. 对照文档中的答案示例，检查思路是否正确。

## 适用场景

- **大厂面试冲刺**：目标为 Amazon、Google、Meta 等公司的软件开发岗位，需要 3-6 个月系统性备考的开发者。项目覆盖了高频考点（如树遍历、动态规划、LRU 缓存）和常见陷阱（如循环不变式证明）。
- **转行入门补课**：非科班出身的程序员（如自学前端、数据分析师）希望通过系统学习补齐计算机科学知识短板，理解算法底层原理而非只会调用 API。
- **在职工程师提升**：已有 2-5 年经验的开发者希望挑战更高薪酬的岗位，或准备跳槽至技术栈不同的公司（如从 Web 开发转向嵌入式/后端）。项目中的系统设计章节（如设计 Twitter 或聊天系统）对此类用户尤为实用。
- **教育机构课程参考**：大学或编程训练营可将该计划作为“算法与数据结构”课程的外置补充 syllabus，帮助学生衔接理论与面试实操。

## 项目亮点

- **已验证的成功路径**：作者本人及数千名 Contributor 通过该计划获得了大型科技公司的 Offer，其有效性在 GitHub 上获得 35 万+ Star 的广泛认可。项目 README 首句即展示了可量化的成果。
- **拒绝“刷题主义”**：与多数面试题库不同，该项目强调**从根理解**，例如会要求读者亲手推导快速排序的时间复杂度，而非仅仅记忆代码模板。每个算法都提供了至少三种实现方式（递归/迭代/多线程）。
- **动态维护与社区驱动**：项目每月更新 10-20 次，及时跟进如 LeetCode 题库变化、新增教育平台（如 AlgoMonster）。用户可提交 Issue 建议淘汰过时资源（如老旧视频），投票决定是否保留。
- **零成本与无版权限制**：采用 CC-BY-SA-4.0 许可证，允许自由分发、改编（如制作本地化教程或出版书籍），只需注明原作者。没有任何隐藏付费内容或赞助链接。
- **心理支持与时间管理**：项目包含“如何避免 burnout”章节，提供冥想指导、番茄工作法建议，以及作者当年“每天写代码 8 小时失败时的复盘”。这对长期备考者的心理健康尤为重要。
