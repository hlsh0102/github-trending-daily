## 项目概述

Chatwoot 是一个开源的、全渠道的客户支持平台，旨在为企业提供自托管的实时聊天、邮件支持和客户服务解决方案。作为 Intercom、Zendesk、Salesforce Service Cloud 等商业客户支持工具的替代品，Chatwoot 让团队能够通过单一界面集中管理来自网站、应用、社交渠道和电子邮件的客户咨询。

该项目诞生于对商业客服软件高昂成本和封闭生态的不满，其目标用户包括需要灵活定制客户支持系统的中小型企业、注重数据隐私的团队、开源爱好者以及希望完全掌控客户沟通流程的技术团队。目前 Chatwoot 在 GitHub 上已获得超过 3.1 万颗星，社区活跃度极高。

## 核心功能

- **多渠道统一收件箱**：支持整合来自网站实时聊天、电子邮件、Facebook Messenger、Twitter、WhatsApp 等多个渠道的客户消息，所有对话在一个界面中统一管理。
- **智能自动化**：支持自动分配对话给特定客服人员，基于关键词、客户属性等规则触发自动回复，以及设置工作流自动处理常见问题。
- **实时协作功能**：客服团队内部可使用 @ 提及功能进行沟通，支持查看其他客服正在处理的会话以及添加内部备注，提升团队协作效率。
- **强大的客户数据管理**：自动追踪客户浏览行为、历史对话记录、自定义属性等，提供 360 度客户视图，帮助客服快速了解客户背景。
- **自定义与扩展**：支持自定义聊天组件的样式和颜色，通过开放 API 和 Webhook 与其他业务系统（如 CRM、ERP）集成，并可安装社区开发的插件。
- **报告与分析**：内置仪表盘提供对话量、响应时间、客户满意度等关键指标的统计报告，帮助团队优化客服质量。

## 技术架构

Chatwoot 基于 Ruby on Rails 框架构建，使用 PostgreSQL 作为主要数据库，Redis 用于缓存和实时消息队列。前端采用 Vue.js 框架开发，确保用户界面响应迅速且交互流畅。

项目采用了微服务导向的架构设计，核心服务包括消息路由引擎、实时推送服务（基于 WebSocket）以及异步任务处理模块。对于实时通信，Chatwoot 使用 Action Cable 实现 WebSocket 连接，确保客户和客服之间的消息能够即时同步。其 API 设计遵循 RESTful 规范，便于第三方系统集成。

值得一提的是，Chatwoot 的部署非常灵活，可以使用 Docker 容器化方案快速启动，也支持直接在 Ubuntu、macOS 等操作系统上手动安装。项目内置了多语言支持（通过 Crowdin 管理翻译），目前已经本地化到多种主要语言。

## 安装与使用

Chatwoot 提供多种部署方式，推荐使用 Docker 进行快速安装。以下是最简单的安装步骤：

1. **使用 Docker Compose（推荐）**：
   ```bash
   git clone https://github.com/chatwoot/chatwoot.git
   cd chatwoot
   cp .env.example .env
   # 编辑 .env 文件，设置 SECRET_KEY_BASE 和数据库密码等必要配置
   docker-compose up -d
   ```

2. **访问服务**：安装完成后，打开浏览器访问 `http://localhost:3000`，使用管理员账户登录，即可开始配置客服渠道。

3. **最小可用示例**：登录后，进入“设置”页面，添加“网站”渠道，复制嵌入代码粘贴到你的网站 HTML 中，即可在网站上激活实时聊天组件。客户发送的消息将自动出现在 Chatwoot 的收件箱中，客服可进行回复、转接或标记处理。

## 适用场景

- **初创企业与中小企业**：希望以零成本获得类似 Zendesk 的客户支持系统，无需支付高额年费即可管理多个客服渠道。
- **注重数据隐私的团队**：需要将客户沟通数据存储在自有服务器上，避免第三方商业平台的数据合规风险。
- **开发者与开源社区**：需要高度可定制的客户支持系统，能够通过 API 与内部工具深度集成，甚至修改核心代码来满足特定需求。
- **多语言客户服务团队**：处理来自全球不同语言地区的客户咨询，利用 Chatwoot 的多语言界面和自动翻译功能提升效率。

## 项目亮点

Chatwoot 与商业客服工具的主要差异化优势体现在三个方面：

- **完全开源与自托管**：代码完全公开，团队可以自由审查、修改和扩展，没有供应商锁定风险。数据完全掌握在自己手中，符合 GDPR 等隐私法规要求。
- **零成本启动**：相比 Intercom 每人每月数百美元的费用，Chatwoot 提供相同甚至更丰富的功能，且无需支付许可费用。
- **活跃的社区生态**：拥有超过 3.1 万 GitHub 星标、活跃的 Discord 讨论组和持续更新的 Docker 镜像，社区贡献者不断发布新功能和修复，项目迭代速度极快。
