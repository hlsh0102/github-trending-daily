## 项目概述

G0DM0D3 是一个完全开源、注重隐私透明的多模型聊天界面，旨在突破后训练层的极限，服务于红队测试、认知研究与自由 AI 交互。项目面向黑客、哲学家和系统调试者，提供了前所未有的模型操控能力和交互自由度。该项目托管在 GitHub 上，以 TypeScript 为主要开发语言，采用 AGPL-3.0 许可证，代表了 AI 交互领域的前沿探索方向。

## 核心功能

- **多模型支持** — 集成超过 60 个 OpenRouter 模型和最多 44 个 Venice 模型，同时支持本地模型接入，实现跨提供商的无缝切换
- **GODMODE CLASSIC** — 5 个经过实战验证的提示词与模型组合并行运行，快速从中筛选出最佳响应结果
- **ULTRAPLINIAN** — 多模型评估引擎，支持 5 个层级（12–60 个 OpenRouter 模型），通过复合评分机制进行智能评估
- **本地模型运行** — 支持在自有硬件上运行 ULTRAPLINIAN，兼容 Ollama、LM Studio、llama.cpp 和 vLLM 等多种本地推理引擎
- **Parseltongue 输入扰动引擎** — 专为红队测试设计的输入扰动工具，提供 33 种技术，分为 3 个强度等级
- **AutoTune 参数自适应** — 上下文感知的采样参数引擎，覆盖 20 种查询场景，自动调整模型生成参数
- **隐私控制** — 默认启用仅包含元数据的应用遥测，用户可根据需求自由调整隐私设置

## 技术架构

G0DM0D3 采用现代前端架构，基于 TypeScript 构建，确保了代码的类型安全性和可维护性。项目的核心设计理念是“认知无约束”——通过多层架构实现模型调用的完全透明和可控。

在模型接入层，项目采用插件式架构，支持多种推理提供商（OpenRouter、Venice）和本地引擎（Ollama、LM Studio、llama.cpp、vLLM）。中间层实现了统一的参数控制和响应处理管道，包括 AutoTune 的自适应参数调节和 Parseltongue 的输入扰动功能。最上层则是并行评估框架（GODMODE CLASSIC 和 ULTRAPLINIAN），通过多模型对比和复合评分算法，提供高质量的响应结果。

项目的架构特点在于其高度的可扩展性和隐私保护设计。所有核心功能都基于模块化设计，用户可以自由组合不同的模型、提示词和参数配置。

## 安装与使用

由于项目主要面向有一定技术背景的用户，安装过程要求具备基本的命令行操作能力。用户可以通过以下步骤快速开始使用：

1. 克隆仓库到本地环境：
```bash
git clone https://github.com/elder-plinius/G0DM0D3.git
cd G0DM0D3
```

2. 安装项目依赖：
```bash
npm install
```

3. 配置模型提供商和本地模型连接（可选）：
   - 在 OpenRouter 注册并获取 API 密钥
   - 或配置本地推理引擎（Ollama/LM Studio 等）

4. 启动开发服务器：
```bash
npm run dev
```

最小可用示例：启动后，用户可以直接在界面中选择任意已配置的模型，输入提示词即可获得响应。对于高级功能，可以切换至 GODMODE CLASSIC 模式，系统会自动调用 5 个预设模型组合并行生成响应，并展示对比结果。

## 适用场景

- **红队安全测试** — 利用 Parseltongue 输入扰动引擎和 ULTRAPLINIAN 多模型评估，对 AI 系统进行系统的红队测试，发现安全漏洞和边界行为
- **认知科学研究** — 研究者可通过多模型对比、参数微调和本地模型运行，进行 AI 认知机理的深入探索
- **提示词工程优化** — AutoTune 的上下文自适应参数调节功能，帮助提示词工程师精准控制模型生成行为，优化输出质量
- **模型性能基准测试** — 通过 GodMode Classic 和 ULTRAPLINIAN 的并行评估能力，对多个模型在同一任务上的表现进行量化对比

## 项目亮点

G0DM0D3 与同类项目相比，最显著的差异化优势在于其“解放 AI 认知”的核心理念。项目不仅提供模型调用的界面，更重要的是赋予用户完全的控制权——从模型选择、参数调节到隐私设置，所有环节都透明可控。

其次，项目的红队测试能力极为突出。Parseltongue 引擎提供的 33 种输入扰动技术覆盖了当前主流的攻击向量，且分为不同强度等级，适合从入门到专业的各类测试需求。

第三，多模型并行评估的架构设计独具匠心。无论是 GodMode Classic 的 5 组合并行，还是 ULTRAPLINIAN 的 12–60 模型复合评分，都显著提升了响应质量和对比效率。

最后，项目对本地模型和开源生态的深度支持，使其成为自由 AI 交互领域的重要基础设施，尤其适合隐私敏感和离线环境的使用场景。
