## 项目概述

UI Skills 是一个面向设计工程师（Design Engineers）的开源命令行工具，旨在帮助 AI 代理或开发者在执行 UI 相关任务时，精准选择并应用最合适的 UI 技能集（Skill Sets）。该项目通过定义一系列结构化的 UI 技能类别和子技能，解决了设计工程师在自动化 UI 开发流程中缺乏统一、可复用的技能参考标准这一痛点。目标用户包括从事界面设计、前端开发、设计系统构建的设计工程师，以及希望在 AI 辅助下高效完成 UI 任务的开发者。

## 核心功能

- 交互式技能引导：通过 `npx ui-skills start` 命令，AI 代理能够基于当前任务快速路由到正确的 UI 技能集，提升任务执行的准确性和效率。
- 技能类别浏览：使用 `npx ui-skills categories` 列出所有可用的 UI 技能类别，帮助用户宏观了解能力覆盖范围。
- 基于类别的技能筛选：通过 `npx ui-skills list --category motion` 等命令，按特定类别（如动效、布局、配色等）列出子技能，实现精细化查询。
- 具体技能查询：支持 `npx ui-skills get baseline-ui` 命令获取单个 UI 技能的详细定义、适用场景及相关资源。
- 零配置快速启动：无需本地安装或配置文件即可通过 npx 直接运行，降低使用门槛。

## 技术架构

项目采用 TypeScript 作为主要开发语言，充分利用类型系统确保技能分类的准确性和可维护性。核心架构基于 CLI 模式，通过 Node.js 运行时实现命令行交互。设计思路围绕“技能路由”展开，将 UI 设计能力抽象为可分类、可组合的技能对象，每个技能包含唯一标识、所属类别、描述以及可能的子步骤。架构特点包括模块化设计（各命令独立封装）、轻量化（运行时依赖少）以及可扩展性（支持社区贡献新技能类别）。

## 安装与使用

安装需确保已安装 Node.js（推荐 v18 及以上版本）。UI Skills 无需全局安装，可直接通过 npx 运行：

```bash
# 进入交互式 CLI
npx ui-skills

# 启动 AI 代理技能路由
npx ui-skills start

# 列出所有技能类别
npx ui-skills categories

# 按类别列出技能
npx ui-skills list --category motion

# 获取单个技能详情
npx ui-skills get baseline-ui
```

其中，`npx ui-skills start` 是核心功能，执行后 CLI 会进入交互模式，引导用户选择或输入当前 UI 任务描述，然后返回最匹配的技能集建议。

## 适用场景

- AI 辅助 UI 开发：当开发者使用 AI 编码助手进行界面开发时，通过 UI Skills 路由到对应技能集，确保 AI 生成代码符合特定设计模式或动画规范。
- 设计系统组件开发：设计工程师在构建组件库时，可查询特定类别的技能（如“布局”、“交互”），获取标准化实现参考。
- 新项目初始化：在启动新 UI 项目时，通过技能列表快速评估所需能力范围，辅助技术选型。
- 团队技能标准化：团队可将 UI Skills 作为共享技能清单，确保不同成员和 AI 工具遵循统一的设计语言。

## 项目亮点

- 与其他 AI 工具定位框架不同，UI Skills 专注于 UI 设计工程领域的技能编排，提供了更细粒度、更垂直的能力分类。
- 采用轻量级 npx 交互模式，无需安装即可使用，同时保证了 CLI 随时更新到最新版本。
- 技能集设计贴合实际 UI 开发工作流，从基础布局到高级动效均有覆盖，且开源社区可扩展。
- 独特的“技能路由”机制，为 AI 辅助开发提供了结构化的上下文指导，减少了 AI 生成代码的试错成本。
