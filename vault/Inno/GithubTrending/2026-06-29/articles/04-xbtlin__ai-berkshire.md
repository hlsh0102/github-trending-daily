## 项目概述

AI Berkshire 是一套基于 Claude Code / Codex 的价值投资研究框架，由开发者 xbtlin 创建。该项目将巴菲特、芒格、段永平、李录四位投资大师的方法论系统化、结构化，通过多 Agent 并行研究模式，实现专业级的投资分析。项目核心理念是“一个人 + Claude Code / Codex = 一个投研团队”，旨在用 AI 重新定义投资研究的深度与效率。

项目目标用户包括个人投资者、价值投资研究者、量化投资爱好者，以及任何希望借助 AI 提升投资分析质量与决策纪律的人。不同于简单的提问式 AI 分析，AI Berkshire 解决了传统 AI 投资分析“给不出结论、打不了太极、缺乏决策纪律”的核心痛点。

## 核心功能

- **强制输出结论**：AI Berkshire 强制输出“通过/不通过/灰色地带”三种结果，附带具体价格区间和分层建议（激进型/稳健型/保守型），而不是普通 AI 那种“一方面...另一方面...”的平衡分析。
- **四大师方法论对抗**：同时调用巴菲特（护城河/安全边际）、芒格（逆向思维/能力圈）、段永平（商业模式/企业文化）、李录（文明视角/长期主义）四种分析视角，产生真实的矛盾和张力，而非单一分析。
- **多 Agent 并行研究**：通过 Claude Code / Codex 的 Agent 能力，并行执行多维度分析任务，包括财务分析、竞争格局、管理层评估、估值测算等，大幅提升研究效率。
- **实盘验证与回测**：框架附带真实账户收益截图（2024 年 +69.29%，2025 年至今 +66.38%），连续两年大幅跑赢全球主要指数，提供可验证的实盘表现。
- **结构化输出与可追溯性**：分析结果以表格、清单、评分卡等形式输出，每一步分析逻辑可追溯，便于决策复盘。
- **个性化策略适配**：支持激进型、稳健型、保守型三种策略偏好，用户可根据自身风险承受能力选择对应的建仓建议。

## 技术架构

AI Berkshire 基于 Python 开发，深度集成 Claude Code 和 Codex 等大型语言模型的能力。其技术架构呈现以下特点：

1. **Agent 化研究流程**：将传统投研流程拆解为多个独立的分析 Agent，每个 Agent 负责一个特定维度（如财务分析 Agent、估值 Agent、管理层评估 Agent 等），通过并行执行提升效率。

2. **方法论模板引擎**：四位大师的方法论被编码为可执行的模板和规则，Agent 在分析时自动加载对应的评估框架，确保每次分析都遵循大师的投资纪律。

3. **对抗式分析机制**：不同 Agent 之间会就同一标的产生分歧，系统强制记录和呈现这些矛盾点，避免单一视角的盲区。

4. **可扩展的插件体系**：框架支持新增分析维度和定制化 Agent，用户可以根据自身研究习惯调整分析流程。

5. **真实回测与验证模块**：集成了历史回测和实盘验证功能，支持将分析结果与真实市场表现进行对比，持续优化分析模型。

## 安装与使用

### 安装步骤

1. 克隆项目仓库：
```bash
git clone https://github.com/xbtlin/ai-berkshire.git
cd ai-berkshire
```

2. 安装 Python 依赖（建议使用虚拟环境）：
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. 配置 AI API：在项目根目录创建 `.env` 文件，写入你的 Claude Code 或 Codex API 密钥：
```
CLAUDE_API_KEY=your_claude_api_key_here
CODEX_API_KEY=your_codex_api_key_here
```

### 最小可用示例

```python
# 快速分析一个标的
from ai_berkshire import Analyst

analyst = Analyst(strategy="aggressive")  # 激进型策略
result = analyst.analyze("PDD")  # 分析拼多多

print(result)
# 输出包含：通过/不通过/灰色地带判断，建仓价格区间，四大师视角分析摘要
```

## 适用场景

- **个股深度研究**：对单只股票进行全方位、多视角的深度分析，输出可量化的买卖建议和价格区间。
- **投资组合复核**：定期对现有持仓进行复盘，使用四大师方法论重新评估，判断是否应继续持有、加仓或减仓。
- **候选标的筛选**：快速筛选大量候选标的，通过 AI 并行分析生成候选池，大幅提升研究效率。
- **投资决策会议准备**：生成结构化的分析报告，包含矛盾点和争议点，供投资团队或个人决策参考。

## 项目亮点

与传统的 AI 投资分析工具相比，AI Berkshire 具备以下差异化优势：

1. **不是“问 AI”，而是“用 AI 执行方法论”**：普通 AI 投资分析就像问“我该不该买”，AI Berkshire 则是让 AI 成为严格执行大师投资纪律的分析师。

2. **真实的对抗式分析**：不是简单叠加四位大师的方法，而是让它们产生真实的矛盾和张力，暴露不同视角下结论的差异，帮助投资者看到“盲区”。

3. **实盘验证而非纸上谈兵**：项目公开了连续两年的真实账户收益数据，跑赢全球主要指数 40–50 个百分点，具备可追溯的实盘表现。

4. **强制决策纪律**：输出必须包含“通过/不通过/灰色地带”的明确判断，并附带价格区间，避免“看起来对、但没法用”的分析。

5. **开源可定制**：基于 MIT 许可，用户可以自由修改、扩展分析维度，适配个人投资风格。
