## 项目概述

FluidVoice 是一款专为 macOS 设计的开源语音转文字离线听写应用。它完全在本地运行，无需联网，无需向云端发送任何语音数据，即可实现快速、准确的语音转文字功能。项目旨在解决用户对隐私敏感、追求低延迟的听写需求，目标用户包括需要快速输入文字的开发者、作家、学生以及任何希望提升文字输入效率的 Mac 用户。FluidVoice 采用了先进的本地 AI 模型进行增强，确保了在离线环境下的卓越表现。

## 核心功能

- **零延迟本地听写**：采用重新构建的 Parakeet 引擎，实现从说话到文字出现在屏幕上的几乎无延迟体验。
- **本地 AI 增强（Fluid Intelligence）**：完全在设备上运行的 AI 模型，用于优化听写效果，无需云服务、API 密钥或数据离开 Mac。
- **自适应主题**：支持浅色/深色主题自动切换，并提供一个紧凑的工具栏切换器。
- **全面更新的设置向导**：提供一体化的首次设置流程，包括语言优先的语音引擎配置、实时听写试用以及 AI 增强设置。
- **开源免费**：遵循 GPLv3 许可证，所有代码开源，用户可以自由使用、检查和修改。

## 技术架构

FluidVoice 使用 Swift 语言开发，充分利用了 macOS 平台的底层能力。其核心技术栈围绕本地 AI 模型构建，特别是对 **Parakeet 实时边缘单元 (eou) 模型** 的深度集成，该模型来自 NVIDIA 的 Hugging Face 仓库，专门针对低延迟的语音活动检测和转写进行了优化。项目通过本地推理引擎在用户的 Mac 上运行模型，避免了对网络连接的依赖。设计思路上，FluidVoice 将语音处理、AI 增强、UI 渲染和系统集成等模块解耦，确保了响应速度和低资源占用。这种架构使得 FluidVoice 能够在不牺牲隐私和速度的前提下，提供接近云端服务的听写质量。

## 安装与使用

### 安装

FluidVoice 提供了两种便捷的安装方式：

1. **通过 Homebrew 安装（推荐）**：
   ```bash
   brew install --cask fluidvoice
   ```

2. **手动下载**：
   - 访问 [GitHub 发布页](https://github.com/altic-dev/FluidVoice/releases/latest) 下载最新版本的 `.dmg` 文件，然后按照常规 macOS 应用安装步骤操作。

### 最小可用示例

安装完成后：

1. 启动 FluidVoice 应用。
2. 按照首次启动时出现的设置向导进行操作：
   - 选择您的首选语音识别语言。
   - 进行实时听写试用，验证语音输入是否正常工作。
   - 根据需要开启或配置本地 AI 增强（Fluid Intelligence）。
3. 设置完成后，您可以直接在任何文本输入字段中使用 FluidVoice 进行听写。点击菜单栏中的 FluidVoice 图标或使用预设快捷键（通常为 `Option + D` 或可自定义），开始说话，文字将实时出现在当前光标位置。
4. 要停止听写，再次点击图标或按下同一快捷键。

您无需任何额外配置即可立即使用。所有 AI 增强功能完全在本地运行，无需网络连接。

## 适用场景

- **快速文字记录**：记者、作家、博客作者等在需要快速捕捉想法或采访内容时，无需手动打字。
- **代码注释与文档编写**：开发者可以使用语音快速输入代码注释、README 文档或提交消息，提升工作效率。
- **无障碍辅助工具**：对于有书写障碍或手部疲劳的用户，语音听写提供了一种高效的替代输入方式。
- **隐私敏感场景**：在需要处理敏感信息（如医疗记录、法律文件、金融数据）时，数据始终停留在本地，不会泄露给第三方云服务。

## 项目亮点

与大多数需要联网的听写工具相比，FluidVoice 的核心优势在于**完全的离线处理**和**极低的延迟**。它没有将语音数据上传到云端，因此保证了最高的隐私安全。同时，通过针对本地 AI 模型的深度优化，它在响应速度上达到了“几乎无延迟”的水平，这是许多同类产品难以企及的。此外，FluidVoice 作为开源项目，不仅免费使用，还允许社区参与者审查代码、提出改进并贡献功能，形成了健康的发展生态。项目同时提供 Homebrew 安装支持，进一步降低了 macOS 用户的使用门槛。
