## 项目概述

Vibe-Trading 是一款由香港大学数据科学实验室（HKUDS）开发的开源个人交易代理工具。该项目旨在通过一条简洁的命令，为普通用户赋予全面的自动化交易能力。用户无需具备专业的编程或量化交易知识，即可利用大型语言模型（LLM）技术，实现市场分析、策略制定与自动化执行。Vibe-Trading 的目标用户包括个人投资者、交易爱好者、量化研究初学者以及希望快速验证交易想法的开发人员。

## 核心功能

- **单命令启动**：用户只需执行一条命令，即可启动完整的交易代理系统，包含后端服务、前端界面和交易引擎，极大降低了使用门槛。
- **大语言模型驱动**：集成主流 LLM（如 GPT、Claude 等），用于解析市场数据、生成交易建议、撰写分析报告，实现自然语言交互。
- **多市场支持**：支持股票、加密货币、外汇等多种金融市场的行情获取与交易执行，满足不同用户的投资需求。
- **实时数据流处理**：利用 WebSocket 等技术实现实时行情推送，确保交易信号的及时性。
- **可视化策略编辑器**：提供图形化界面，允许用户通过拖拽方式构建和调整交易策略，无需编写代码。
- **风险控制模块**：内置止损、止盈、仓位管理等风险控制机制，帮助用户管理交易风险。

## 技术架构

Vibe-Trading 采用前后端分离的微服务架构，主要技术栈包括：

- **后端**：基于 FastAPI 构建，提供 RESTful API 和 WebSocket 接口，负责行情数据处理、策略执行、订单管理等核心业务逻辑。FastAPI 的高异步性能确保了系统的实时响应能力。
- **前端**：使用 React 19 框架开发，提供现代化的用户交互界面，包括行情图表、策略回测、交易记录等模块。React 的组件化设计便于功能扩展与维护。
- **代理引擎**：核心交易代理模块，集成 LLM 接口，实现从自然语言到交易决策的转换。该模块通过 LangChain 等框架与多个大模型交互，支持模型切换和参数调优。
- **数据层**：利用 Redis 作为缓存数据库处理高频行情数据，使用 PostgreSQL 存储历史交易记录和用户配置。数据持久化与缓存分离的设计保证了系统的高吞吐量。
- **部署方式**：提供 Docker 容器化部署方案，支持一键启动整个系统。用户也可通过 PyPI 包直接安装，灵活性高。

## 安装与使用

Vibe-Trading 提供两种主要安装方式：

**方式一：通过 PyPI 安装（推荐）**

```bash
pip install vibe-trading-ai
vibe-trading start
```

**方式二：Docker 容器部署**

```bash
docker pull hkuds/vibe-trading:latest
docker run -p 8000:8000 -v ./config:/app/config hkuds/vibe-trading
```

启动后，访问 `http://localhost:8000` 即可进入交易代理界面。首次使用时，需配置 LLM API Key（如 OpenAI、Anthropic 等）。完成配置后，用户可通过自然语言下达交易指令，例如：

```
“帮我分析 Apple 股票过去 30 天的走势，并给出买入或卖出的建议”
```

系统会自动获取数据、生成分析报告，并支持一键执行交易。

## 适用场景

- **个人量化投资**：普通投资者可利用 Vibe-Trading 快速搭建个人量化交易系统，无需编写复杂代码即可实现自动化策略。
- **策略研发与回测**：量化研究用户可基于可视化的策略编辑器进行快速原型设计，并在历史数据上验证策略有效性。
- **教学与学习**：金融科技或数据科学课程中，教师可将 Vibe-Trading 作为实践教学工具，帮助学生理解自动化交易原理。
- **多市场套利监控**：跨市场投资者可配置多个行情源，利用实时数据流监测套利机会。

## 项目亮点

- **零代码配置**：对比传统量化交易框架（如 Backtrader、Zipline），Vibe-Trading 无需用户编写 Python 代码即可完成策略部署。自然语言交互方式大幅降低了使用门槛。
- **LLM 原生集成**：当前市场中虽有部分项目尝试引入 AI，但 Vibe-Trading 将大语言模型作为核心决策引擎，而非简单的辅助功能。这种设计使其在策略灵活性、市场解读能力方面具备独特优势。
- **全栈开源**：前后端代码完全开源，用户可根据自身需求进行二次开发或功能扩展。MIT 许可证进一步降低了商业使用限制。
- **实时反馈**：结合 WebSocket 与 LLM 推理，系统能在毫秒级别提供市场动态的解读与响应，兼顾深度分析与实时性。
- **社区活跃**：GitHub 上已获得超过 14,500 个 Star，社区贡献活跃，持续迭代更新。
