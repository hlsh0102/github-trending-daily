## 项目概述

openpilot 是由 comma.ai 开发的一款面向机器人技术的操作系统。目前，它主要专注于升级超过 300 款支持车辆的驾驶辅助系统。该项目以 MIT 许可证开源，目标用户包括希望为爱车引入更先进自动驾驶能力的车主、汽车爱好者和自动驾驶技术研究人员。通过 openpilot，用户可以将普通车辆的部分驾驶功能提升至接近 L2 级别的自动驾驶水平，实现更智能、更安全的驾驶体验。

## 核心功能

- **自适应巡航控制（ACC）**：根据前车速度自动调整车速，保持安全距离，支持完全停走功能。
- **车道保持辅助（LKA）**：利用摄像头和神经网络实时检测车道线，使车辆始终保持在车道中央行驶。
- **车道变更辅助**：在驾驶员确认后，系统可自动完成安全变道操作。
- **驾驶员监控**：通过车内摄像头实时监测驾驶员注意力状态，确保驾驶员随时准备接管车辆。
- **基于视觉的导航**：仅依赖摄像头视觉输入，即可实现道路识别、交通信号灯检测和路口通行。
- **持续更新与扩展**：定期推出新功能、新车型支持和性能优化，用户可通过 OTA 方式获取更新。

## 技术架构

openpilot 采用模块化设计，核心基于 Python 和 C++ 混合开发。其技术架构具有以下特点：

- **神经元网络驱动**：使用深度学习模型处理摄像头输入的视觉数据，实现端到端的驾驶决策。模型经过大量真实驾驶数据训练，具有强大的环境感知能力。
- **多进程通信**：利用 comma.ai 自研的 **messaging** 中间件实现模块间高效通信，确保实时性和低延迟。
- **硬件抽象层**：支持多种计算平台（如 comma three、comma four 等专用设备），同时兼容普通 PC 进行仿真开发。
- **仿真测试环境**：内置基于 **CARLA** 或 **OpenStreetMap** 的仿真工具，方便开发者在不实际路测的情况下验证算法。
- **日志与可视化**：完整记录驾驶过程中的传感器数据、模型输出和决策日志，便于分析与调试。

## 安装与使用

### 硬件准备

使用 openpilot 需要在车内安装 comma.ai 提供的专用设备（如 comma four 或兼容的 Android 手机+行车记录仪），并通过 OBD-II 接口连接车辆总线。

### 快速安装

针对支持的设备，可使用以下命令一步完成安装：

```bash
bash <(curl -fsSL openpilot.comma.ai)
```

### 最小可用示例

安装完成后，连接设备到车辆，启动引擎并将设备固定在前挡风玻璃上。系统会自动校准摄像头和 GPS。校准完成后，可在中控屏上看到 openpilot 的界面。通过方向盘上的按钮激活自适应巡航和车道保持功能，系统开始工作。

### 开发者模式

对于希望参与开发的用户：

1. 克隆仓库：`git clone https://github.com/commaai/openpilot.git`
2. 进入目录：`cd openpilot`
3. 配置开发环境：`./tools/install_ubuntu.sh`
4. 运行仿真测试：`./tools/sim/run_bridge.py`

## 适用场景

- **日常通勤**：在高速公路或城市快速路上，openpilot 可大幅减轻驾驶负担，自动保持车道和跟车距离，让驾驶员更轻松。
- **长途旅行**：系统能连续工作数小时，始终保持稳定驾驶状态，减少疲劳驾驶风险。
- **研究与学习**：作为开源自动驾驶系统，适合高校、科研团队和爱好者研究端到端驾驶神经网络架构、传感器融合等课题。
- **车辆功能升级**：为旧款或入门级车型提供原本不具备的先进驾驶辅助功能，延长车辆使用价值。

## 项目亮点

- **开源且可移植**：相比特斯拉 Autopilot 等闭源系统，openpilot 完全开源，社区可自由修改、扩展和贡献代码。
- **端到端神经网络**：不同于传统模块化方案（分别处理感知、决策、控制），openpilot 采用统一的神经网络直接从摄像头像素输出驾驶指令，更接近人类驾驶方式。
- **广泛的车型兼容性**：支持超过 300 种车型，涵盖丰田、本田、现代、大众等主流品牌，且持续新增支持。
- **活跃的社区生态**：拥有 Discord 社区、官方文档和贡献指南，开发者可方便地获取帮助和参与开发。
- **商业化产品支撑**：comma.ai 提供硬件设备（comma four），用户无需复杂改装即可使用，降低了准入门槛。
