## 项目概述

SimpleX 是一个去中心化的即时通讯网络，也是首个完全消除用户标识符的通信平台。与传统的即时通讯软件（如 Telegram、Signal 或 Matrix）不同，SimpleX 不依赖电话号码、用户名、电子邮件地址或任何形式的用户 ID 来识别参与者。这一设计从根本上解决了元数据泄露问题——即使攻击者能够截获通信链路，也无法确定谁在跟谁聊天。项目适用于所有对隐私有极致要求的用户，包括记者、活动家、企业人士以及任何希望将数字身份与通信行为彻底解绑的个人。目前 SimpleX 已提供 iOS、Android 和桌面客户端，并获得了包括 Privacy Guides、Whonix 和 Kuketz Blog 在内的多家隐私权威机构的推荐。

## 核心功能

- **匿名标识与连接**：通过一次性生成的临时地址（SimpleX 地址）而非持久用户 ID 来建立联系，每次连接都可以是全新的匿名身份。
- **端到端加密**：所有消息均使用强加密协议保护，确保内容仅发送者与接收者可见。
- **无元数据模型**：由于不存储任何用户标识符，服务器无法获知消息发送者与接收者之间的关系，从根源上消除了元数据追踪的可能。
- **去中心化架构**：使用分布式服务器网络（而非单一提供商），用户可自建或选择不同的服务节点，避免单点依赖。
- **跨平台支持**：覆盖 iOS、Android 和桌面操作系统（Windows、macOS、Linux），并提供多语言界面（包括中文）。
- **开放源码与审计保障**：项目使用 AGPL-3.0 许可，代码完全透明，并已通过 Trail of Bits 等专业安全公司的安全审计。

## 技术架构

SimpleX 的核心创新在于其标识协议和路由机制。传统通讯协议中，每个用户都有一个唯一的持久标识符（如手机号或用户名），用于路由消息。SimpleX 完全摒弃了这一范式，转而采用**一次性临时标识符**和**队列（queue）** 的概念：每条对话中的消息通过一个专门的队列传递，队列仅关联临时令牌，而不绑定任何用户信息。服务器只需负责存储和转发这些队列中的加密消息，无法从队列数据中推断出对话参与者是谁。

技术栈方面，核心库使用 **Haskell** 编写，这赋予项目强大的类型安全和并发处理能力。Haskell 的函数式特性也有助于减少并发错误和状态混乱，对于这类需要高可靠性的通信系统尤为关键。客户端则通过 Swift（iOS）、Kotlin（Android）以及 Electron（桌面）实现，并调用 Haskell 编译的原生库来处理底层业务逻辑。

## 安装与使用

SimpleX 提供了非常简便的安装流程：

1. **移动端**：在 iOS 和 Android 应用商店搜索「SimpleX Chat」下载安装。
2. **桌面端**：访问 [GitHub Releases](https://github.com/simplex-chat/simplex-chat/releases) 页面，选择对应操作系统的安装包（Windows exe、macOS dmg 或 Linux AppImage）。

首次使用时无需注册或登录。应用会直接显示一个二维码头像作为你的唯一连接入口。用户可以将此二维码分享给好友来建立私密连接。具体步骤：

- 点击「连接」→ 扫描对方二维码或粘贴其 SimpleX 地址。
- 等待双方确认，即可开始加密对话。
- 如需加入公开群组，可在应用内搜索群组地址或通过链接加入。

命令行客户端（适用于高级用户）可以通过 Haskell 的构建工具 stack 或从源码编译获得，相关文档位于 README 的「Install the app」部分。

## 适用场景

- **敏感通信**：记者、律师或商界人士在进行涉及商业秘密或法律敏感内容的对话时，可使用 SimpleX 避免被追踪。
- **匿名社交**：用户希望与陌生人建立临时联系而不暴露自身数字身份时，零标识符设计极大降低了隐私泄露风险。
- **自建通讯网络**：企业和社区可部署自己的 SimpleX 服务器节点，控制通信链路，同时享受开源的灵活性和审查抵抗能力。
- **数字安全培训**：作为教学案例，展示无标识通讯的实际可行性，以及元数据保护在现代通讯中的重要性。

## 项目亮点

SimpleX 与 Signal、Matrix/Element 等主流隐私通信平台相比，最显著的区别在于**完全消除了用户标识符**。Signal 虽然具有强加密，但依赖手机号注册；Matrix 使用用户名和家庭服务器地址。这些设计都留下了可被追踪的持久身份。SimpleX 的「一次一连接」模式将匿名性提升到了新高度——没有人能通过分析网络流量来建立用户行为画像。此外，SimpleX 的代码被 Trail of Bits 审计通过，且社区活跃度高，近期 GitHub 星标数快速增长（单日新增超过 1000 星），表明其获得了广泛的技术认可。
