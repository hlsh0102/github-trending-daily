## 项目概述

herdr 是一个运行在终端中的智能体多路复用器。它允许用户在同一个终端窗口中同时运行多个编码智能体，并实时查看每个智能体的状态——是阻塞、工作中还是已完成。该项目解决了开发者在同时管理多个 AI 编码助手时缺乏统一视图和管理工具的问题。目标用户是使用各类编码智能体（如 Claude Code、GPT-Engineer、Codex 等）的开发者，尤其是那些需要并行执行多个任务或需要远程管理智能体会话的用户。

## 核心功能

- **真正的独立终端**：每个智能体拥有一个真实的终端环境，而非模拟终端。这使得即使是全屏 TUI 应用也能正确显示，不存在渲染兼容问题。
- **窗口管理与分屏**：支持点击、拖拽、分割窗格，并可以将智能体会话组织到工作区和标签页中。
- **状态实时监控**：一目了然地查看每个智能体是阻塞、工作中还是已完成状态。
- **会话持久化**：关闭笔记本电脑后会话不会丢失，可以从另一个终端或通过 SSH 从手机重新接入。
- **远程访问支持**：智能体运行在本地机器或服务器上，通过 SSH 可以从任何位置接入。
- **轻量级部署**：单个 Rust 二进制文件，无 GUI、无 Electron、无仅 Mac 可用限制、无账户注册、无遥测。

## 技术架构

herdr 使用 Rust 语言编写，保证了高性能和低资源占用。其核心设计理念是“为智能体重写 tmux”——为 AI 编码助手提供一个类似 tmux 的多会话管理体验。每个智能体分配一个真正的 PTY（伪终端），而非库模拟的终端环境，这确保了所有终端控制序列的准确传递。持久化机制基于会话存储，使得在终端断开后重新连接时可以恢复所有智能体状态。通信方面，项目提供了 Socket API，允许外部工具以编程方式与 herdr 交互。整体架构轻量，无外部依赖，单个二进制文件即可运行。

## 安装与使用

**安装步骤：**

1. 确保系统已安装 Rust 工具链（如果从源码编译）。
2. 从 GitHub Releases 页面下载对应平台的预编译二进制文件，或使用 Cargo 安装：
   ```bash
   cargo install herdr
   ```
3. 或者使用包管理器（如 Homebrew 或 Scoop）安装（如果已提供支持）。

**最小可用示例：**

```bash
# 启动 herdr
herdr

# 创建一个新会话
herdr new -n my-session

# 在会话中启动一个智能体（例如本地运行 echo 命令）
herdr run -s my-session "echo 'Hello from herdr!'"

# 列出所有会话状态
herdr ls

# 连接到指定会话
herdr attach -s my-session
```

实际使用时，可以启动如 Claude Code、Codex CLI 等智能体程序，并通过 herdr 管理它们的生命周期。

## 适用场景

- **并行任务执行**：同时运行多个独立的编码任务（如代码审查、单元测试、文档生成），每个任务由不同的智能体处理，并在一个窗口中统一监控进度。
- **远程开发工作流**：在远程服务器上部署 herdr，通过 SSH 从本地终端或手机接入，管理多个长期运行的智能体会话，即使网络连接不稳定也无所谓。
- **多模型对比测试**：并排启动使用不同大语言模型的编码智能体，在相同提示下对比它们的响应质量和执行效率。
- **团队开发协作**：共享一个 herdr 会话，让团队成员查看各自智能体的工作状态，协调并行开发任务。

## 项目亮点

herdr 的核心差异化优势在于其“真正终端”的设计理念。与许多使用模拟终端的工具不同，herdr 为每个智能体提供了完整的 PTY 支持，这确保了任何基于终端的应用（包括全屏 TUI）都能正确工作。此外，它保持了 tmux 级别的轻量和持久性，但专门为智能体场景优化了可视化管理。无需注册账户、无遥测数据、单一二进制文件部署，这些特点使 herdr 特别适合注重隐私和效率的开发者。同时，Rust 语言的选择带来了出色的性能和内存安全性。
