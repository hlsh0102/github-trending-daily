## 项目概述

Meetily 是一款以隐私为首要原则的 AI 会议助手，专为 macOS 和 Windows 平台设计。它实现了完全本地化的会议记录与总结流程，无需将任何音频或文字数据上传到云端。项目基于 Rust 构建，集成了比传统 Whisper 快 4 倍的 Parakeet/Whisper 实时转录引擎、说话人分离（Speaker Diarization）技术以及基于 Ollama 的本地摘要生成能力。无论是远程协作的团队、需要归档会议记录的职场人士，还是对数据合规性有严格要求的企业用户，都能从 Meetily 的自托管、开源特性中受益。

## 核心功能

- **超高速实时转录**：集成优化后的 Parakeet/Whisper 引擎，在本地即可实现比标准 Whisper 快 4 倍的实时语音转文字，延迟极低，适合会议场景的即时反馈。
- **说话人分离**：自动识别并区分会议中不同发言人的声音，在转录文本中清晰标注说话的来源，方便后续的对话回溯与责任归属。
- **AI 摘要与要点提取**：通过本地运行的 Ollama 大语言模型，自动将冗长的会议对话提炼为结构化摘要、待办事项和关键决定，无需联网即可获得高质量的总结。
- **100% 本地处理**：所有音频录制、转录、说话人识别和摘要生成均在用户自己的设备上完成，零数据外传，从根本上杜绝隐私泄露风险。
- **跨平台桌面应用**：提供针对 macOS 和 Windows 的原生桌面客户端，界面简洁易用，开箱即用，不需要复杂的命令行配置。
- **自托管与开源**：代码完全开源（MIT 许可证），用户可自行审查、修改或自托管服务，摆脱对第三方商业服务的依赖。

## 技术架构

Meetily 的技术栈围绕“本地优先”和“性能”两个核心原则设计：

- **底层引擎**：核心转录使用 CTranslate2 对 Whisper 模型进行优化，并结合 Parakeet（基于 CTC 的轻量级端到端模型）实现极速推理。说话人分离则采用基于 PyAnnote 的本地模型。所有模型文件在首次启动时下载到本地，后续完全离线运行。
- **大模型集成**：摘要生成模块对接本地运行的 Ollama，支持 Llama、Mistral 等开源模型。用户可自行选择并切换模型，灵活控制资源占用和总结质量。
- **桌面应用框架**：前端采用 Tauri（基于 Rust 的桌面应用框架），它比 Electron 更轻量，启动更快，内存占用更低，同时保证了原生应用的用户体验。
- **数据流设计**：音频流经麦克风捕获后，先由本地降噪模块处理，再送入实时转录管线；转录结果与说话人标签一并存入本地 SQLite 数据库；用户点击“生成摘要”时，将转录文本送入 Ollama 进行推理。整个过程中没有任何数据离开用户电脑。
- **模块化与可扩展**：项目的 Rust 核心负责高性能的音频管道和模型加载，逻辑清晰；前端负责 UI 展示与交互。这种设计便于社区为 Meetily 添加新的模型后端或功能插件。

## 安装与使用

**安装步骤**：

1. 访问 [Meetily 的 GitHub Releases 页面](https://github.com/Zackriya-Solutions/meeting-minutes/releases) 下载对应操作系统的安装包（macOS 或 Windows）。
2. 双击安装包，按照提示完成安装。首次启动时，应用会自动下载所需的模型文件（转录模型、说话人分离模型、Ollama 模型），请保持网络畅通。
3. 如使用 Ollama 摘要功能，请确保已在本地安装并启动了 Ollama 服务。Meetily 会自动检测并连接。

**最小可用示例**：

1. 打开 Meetily 应用，在主界面点击“开始录制”按钮。
2. 开始会议或讲话，应用会实时显示转录文本，并自动标记不同发言人。
3. 会议结束后，点击“结束录制”和“生成摘要”，稍等片刻即可看到结构化的会议总结。
4. 您也可以随时从历史记录中查看、导出或重新生成之前会议的摘要。

## 适用场景

- **远程团队协作**：在 Zoom、Teams 或腾讯会议等应用中，开一个 Meetily 窗口即可自动记录并总结讨论内容，无需手动整理会议纪要。
- **学术研讨与访谈**：研究者或记者可以利用 Meetily 的说话人分离功能，轻松记录多人研讨或访谈，快速定位关键观点。
- **个人知识管理**：日常讲座、播客或头脑风暴时，用 Meetily 转录并生成摘要，纳入个人的笔记系统，实现信息的高效归档。
- **数据合规敏感场景**：法律、金融、医疗等行业的内部会议，对数据外传有严格禁止。Meetily 提供的纯本地方案完全满足这类合规需求。

## 项目亮点

- **隐私零妥协**：与大多数依赖云 API 的会议助手不同，Meetily 从根源上杜绝了数据外传。所有处理都在用户自己的电脑上完成，适合对隐私有最高要求的用户。
- **性能领先**：通过 Parakeet/Whisper 优化和 Rust 实现的低延迟音频管道，Meetily 在实时转录速度上显著优于同类开源方案，同时保持了较高的准确率。
- **自托管与完全控制**：用户不仅拥有数据所有权，还拥有整个软件的修改权。项目采用 MIT 许可证，开发者可以自由 fork、定制或集成。
- **开箱即用的体验**：虽然是技术驱动的项目，但 Meetily 提供了美观的原生 GUI，安装后即可使用，无需理解背后的复杂模型或命令行操作。
