## 项目概述

Machine Learning Systems（机器学习系统）是由哈佛大学 edge 实验室开源的一本在线教科书，对应课程编号 CS249R。该项目系统性地讲解了如何从工程角度设计和构建人工智能系统，覆盖从算法原理到硬件实现的完整链路。项目目标用户包括计算机科学、电子工程领域的高年级本科生、研究生，以及希望系统化理解机器学习系统全栈的工业界工程师。通过结合理论阐述与可运行的代码实践，该项目旨在弥合传统机器学习课程（偏重模型算法）与硬件/系统课程（偏重底层实现）之间的鸿沟。

## 核心功能

- **交互式教科书**：以网页形式呈现完整的课程教材，包含丰富的图表、公式推导和代码片段，读者可直接在浏览器中阅读和运行示例。
- **微型深度学习框架 TinyTorch**：从零用 Python 实现的一个简化版自动微分框架，用于帮助理解现代深度学习框架（如 PyTorch）的底层运作机制，包括张量运算、计算图和自动梯度。
- **配套实验与练习**：提供多个 Jupyter Notebook 格式的实验，覆盖神经网络实现、模型训练、性能分析等内容，读者可以动手实践以巩固理论。
- **硬件开发套件支持**：项目整合了基于 Arduino 等嵌入式平台的实验套件，使学习者在资源受限的边缘设备上也能部署和运行机器学习模型，直观体会系统设计的权衡。
- **多语言与国际化**：提供了英文、中文、日文、韩文等多种语言的 README，降低了非英语母语学习者的入门门槛，并计划将全书内容进行多语言翻译。

## 技术架构

该项目整体采用文档优先、代码并行的架构。核心教材使用 Markdown 与 Jupyter Notebook 混合编写，通过 GitHub Actions 进行持续集成（CI）验证，确保每次提交都能通过语法检查、代码运行测试和格式规范。技术栈方面，TinyTorch 是一个纯 Python 实现的微型框架，不依赖第三方深度学习库（仅依赖 NumPy），其设计模仿了 PyTorch 的核心接口（例如 `Tensor`、`nn.Module`、`autograd`），但代码量精简，便于教学。硬件的实验套件部分则基于 Arduino 生态，使用 C++ 编写，并通过串口与 Python 前端通信，展现了从单片机到上层应用的完整系统层次。整套教材以独立章节组织，每章聚焦一个主题（如数据加载、模型设计、分布式训练、模型量化、边缘部署等），内容从基础概念逐步深入到前沿研究。

## 安装与使用

安装过程极为简便。首先克隆仓库：

```bash
git clone https://github.com/harvard-edge/cs249r_book.git
cd cs249r_book
```

若只想阅读教材，可在浏览器中直接打开 `docs` 目录下的 HTML 文件，或通过本地服务器预览（推荐使用 Python 内置服务器）：

```bash
python -m http.server 8000
```

如需运行 TinyTorch 相关实验，建议创建一个独立的 Python 环境，并安装必要的依赖：

```bash
python -m venv venv
source venv/bin/activate  # Windows下使用 venv\Scripts\activate
pip install -r requirements.txt
```

随后即可在 `labs/` 目录中找到 Notebook 文件，运行 Jupyter 启动：

```bash
jupyter notebook
```

对于硬件开发套件部分，需额外安装 Arduino IDE 以及对应板卡的支持包，具体步骤在各实验的 README 中有详细说明。

## 适用场景

- **高校教学**：可作为机器学习系统、嵌入式 AI 等课程的主教材或参考书，配合实验课使用，帮助学生从代码层面理解框架设计。
- **个人自学**：适合已经掌握基本机器学习算法、希望深入理解系统实现的工程师或研究者，通过阅读教材和动手实现 TinyTorch，可以系统化补全工程视角的知识。
- **硬件入门 AI**：对于嵌入式/IoT 开发者，项目中针对微型处理器（MCU）的实验可以快速建立将 AI 部署到实际硬件的能力认知。
- **框架开发者参考**：TinyTorch 的设计模式为想要自行扩展或改造深度学习框架的开发者提供了简洁的范例。

## 项目亮点

- **从零构建的 TinyTorch**：不同于市面上多数教科书仅讲解框架用法，该项目提供了一份可读性极强、可以逐行阅读的微型框架代码，让读者真正看到自动微分与张量运算的内部实现。
- **软硬件一体化视角**：绝大多数 ML 书籍只谈及服务器端模型训练与推理，本项目则覆盖了从云端 GPU 到边缘 MCU 的完整栈，使学习者理解不同场景下的系统设计权衡。
- **持续集成与质量保障**：仓库配置了多套 GitHub Actions 工作流，分别对教材内容、TinyTorch 库、实验文件和硬件套件进行自动验证，保证了代码的正确性与稳定性处于高水平。
- **活跃的开源社区**：项目在 GitHub 上获得大量关注（短期内迅速积累超过 26k 星标），来自全球的贡献者积极参与翻译、修改和实验开发，展现了很强的生态活力。
