## 项目概述

System Prompts Leaks 是一个专门收集、整理和持续更新主流 AI 聊天机器人系统提示（System Prompt）的开源仓库。这些系统提示是 AI 模型在对话开始时接收到的隐式指令，决定了模型的行为规范、输出风格和能力边界。项目覆盖了 Anthropic、OpenAI、Google、xAI 等公司的主要模型，包括 Claude Fable 5、Opus 4.8、ChatGPT 5.5、GPT 5.5 Codex、Gemini 3.5 Flash 等，并提供详细的差异化对比分析。目标用户包括 AI 研究人员、开发者、产品经理以及任何对 AI 模型行为机制感兴趣的用户。

## 核心功能

- **系统提示提取与归档**：从多个 AI 服务中提取并保存完整的系统提示文本，覆盖 Claude、ChatGPT、Gemini、Grok 等主要模型的最新版本
- **版本差异化对比**：提供同一产品线不同版本间的系统提示差异分析（如 Opus 4.8 到 Fable 5），通过 DiffCheck 工具展示精确的内容变更
- **多平台覆盖**：不仅包括网页端模型，还涵盖 GitHub Copilot macOS 应用、Codex 等功能性产品的系统提示
- **实时更新追踪**：项目保持频繁更新，记录每个模型系统提示的最新获取日期和对应版本号
- **结构化组织**：按公司（Anthropic、OpenAI、Google、Microsoft 等）和产品进行分类，便于快速检索和对照

## 技术架构

该项目本质上是一个文档化数据仓库，以 Markdown 文件为主要载体，采用以下设计：

- **层级目录结构**：根目录按公司名分组（如 `Anthropic/`、`OpenAI/`），公司目录下按产品线或版本进一步细分（如 `OpenAI/Codex/`）
- **辅助工具集成**：引用第三方差异对比工具（DiffCheck）来可视化系统提示的版本演变过程
- **更新日志机制**：通过表格记录每个文件的获取日期、版本号和对应链接，实现版本追踪
- **开源许可选择**：采用 CC0-1.0 许可协议，允许任何人自由使用、复制、修改和分发这些数据，无需署名或承担任何责任

## 安装与使用

由于该项目本质上是公开的文档库，使用方式极为简单：

1. **直接访问**：无需安装任何软件，直接打开 GitHub 仓库页面 `https://github.com/asgeirtj/system_prompts_leaks`
2. **浏览文件**：在仓库目录中找到目标公司文件夹，点击对应的 Markdown 文件即可查看完整的系统提示
3. **下载使用**：可通过 `git clone` 或直接下载 ZIP 文件将整个仓库同步到本地
4. **订阅更新**：关注仓库的 Star 动态或使用 GitHub 的 Watch 功能获取更新通知

**最小可用示例**：要查看 Claude Fable 5 的系统提示，直接访问 `Anthropic/claude-fable-5.md` 这个文件即可获得完整的文本内容。

## 适用场景

- **AI 模型研究**：研究人员可以通过对比不同版本的系统提示，分析模型行为变化的本质原因
- **提示工程实践**：提示工程师可以从官方系统提示中学习指令设计技巧，提升自身提示工程水平
- **产品竞争分析**：产品经理通过研究竞争对手模型的底层指令，理解其设计理念和边界限制
- **AI 安全教育**：安全研究人员可以审视系统提示中的安全约束和自我防护机制，发现潜在的漏洞点

## 项目亮点

- **独家数据来源**：该项目获得了《华盛顿邮报》的报道认可（2026 年 5 月），说明其数据采集的独特性和可信度
- **极高的时效性**：项目维护者声称定期更新，最新记录的时间跨度仅为数天至数周，确保内容与官方发布几乎同步
- **开源全透明**：采用 CC0-1.0 许可，没有任何使用限制，任何人都可以自由利用这些数据做进一步研究或二次创作
- **差异化分析能力**：提供同一产品不同版本间的精确差异对比，帮助用户理解模型迭代的演变轨迹
- **生态覆盖全面**：从通用对话模型（Claude、ChatGPT）到专用编码助手（Codex、Copilot）再到设计工具（Claude Design），覆盖 AI 应用的多个细分领域
