## 4. [[repos/Tencent__BrowserSkill|Tencent/BrowserSkill]]

BrowserSkill 是一个 TypeScript 项目，通过 CLI 和浏览器扩展让 AI Agent 复用用户已登录的真实浏览器会话，从而在需要登录态的网站上执行自动化操作。它通过独立的 Agent 窗口运行任务，避免打断用户正常工作，并在遇到验证码或确认弹窗时交由用户接管。该项目面向任何可调用 shell 的 AI Agent，如 Cursor、Claude Code、Codex 等，不绑定特定模型或框架。
