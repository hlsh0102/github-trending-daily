## 项目概述

Tinycast 是一款完全原生实现的 macOS 启动器，用 Swift 编写，定位为轻量级效率工具。它将应用启动、全局热键管理和剪贴板历史三项高频操作整合到同一个入口，通过一个快捷键唤出，让用户在一天中反复用到的功能集中在同一处完成。

项目要解决的问题很直接：许多同类启动器依赖 Electron 或 Web 技术栈，常驻内存动辄数百 MB，启动与响应也存在可感知的延迟。Tinycast 选择使用 SwiftUI 与 AppKit 构建，官方宣称常驻内存控制在 100 MB 以内，并且不包含遥测、不引入任何第三方依赖。

目标用户是追求系统原生体验、在意资源占用的 macOS 用户，尤其是长期使用启动器类工具、对启动速度与内存敏感的开发者和重度键盘操作者。项目采用 AGPL-3.0 许可，免费且开源。

## 核心功能

- **应用启动器**：通过单一快捷键唤出搜索面板，快速查找并打开应用、文件与系统命令，替代逐个翻找启动台的操作。
- **全局热键管理**：集中配置与管理热键，减少在系统设置与各应用之间来回切换的成本。
- **剪贴板历史**：自动记录复制过的文本与内容，支持回溯并重新粘贴此前复制过的条目。
- **Raycast 扩展兼容**：可以运行真实的 Raycast 扩展，并将其以原生 SwiftUI 组件渲染，从而复用现有扩展生态。
- **原生 SwiftUI / AppKit 实现**：界面与交互遵循 macOS 原生范式，不依赖 WebView 渲染层。

## 技术架构

项目完全使用 Swift 6.0 编写，界面层由 SwiftUI 与 AppKit 共同承担，最低支持 macOS 26 及以上系统。架构上一个关键特点是**零第三方依赖**：不引入外部包管理器依赖，也不包含 Electron 等跨平台运行时，从而减少体积、内存开销与供应链风险。

在扩展能力上，Tinycast 选择兼容 Raycast 扩展协议，但将扩展的输出以原生 SwiftUI 视图渲染，而非嵌入网页。这种设计在保留扩展生态可用性的同时，维持了原生渲染的性能与观感一致性。项目明确声明无遥测采集，运行过程中不上报用户数据。

## 安装与使用

推荐通过 GitHub Releases 页面下载最新版本：

1. 打开 [Releases](https://github.com/abue-ammar/tinycast/releases/latest) 页面，下载对应架构的安装包。
2. 将应用拖入「应用程序」文件夹，首次启动时按系统提示授予辅助功能等相关权限。
3. 启动后在设置中配置唤出快捷键（默认提供单一全局热键）。

若从源码构建，需要安装 Xcode 与 Swift 6.0 工具链，克隆仓库后使用 Xcode 打开工程构建运行：

```bash
git clone https://github.com/abue-ammar/tinycast.git
cd tinycast
open *.xcodeproj
```

基础使用流程为：按下快捷键唤出搜索面板 → 输入关键词查找应用或命令 → 回车执行；剪贴板历史与热键管理在同一面板内切换查看。

## 适用场景

- **日常应用启动**：用键盘搜索替代鼠标点击，快速打开常用应用与文件。
- **剪贴板复用**：在编写文档或代码时找回此前复制过的片段，避免重复复制。
- **热键集中管理**：统一维护跨应用的快捷键配置，降低记忆与查找成本。
- **Raycast 扩展迁移**：希望在原生、低占用环境下继续使用已有 Raycast 扩展的用户。

## 项目亮点

与同类启动器相比，Tinycast 的差异化主要体现在三点。其一是**资源占用**：以原生技术栈实现，官方强调内存控制在 100 MB 以内，明显区别于基于 Electron 的方案。其二是**零依赖与无遥测**：不引入第三方库、不上报数据，代码可审计，适合对隐私和供应链敏感的用户。其三是**扩展兼容策略**：在保持原生渲染的前提下兼容 Raycast 扩展，兼顾生态可用性与性能表现。项目采用 AGPL-3.0 开源许可，并保持了较高的社区关注度。
