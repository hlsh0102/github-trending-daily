## 项目概述

Agency Agents 是一个开源的 AI 智能体（Agent）集合项目，旨在为开发者提供一套立即可用的、高度专业化的 AI 助手阵容。项目源于 Reddit 上的一场讨论，经过数月迭代而成。它将“AI 智能体”从简单的提示词模板提升为具备完整人格、专业流程和可验证交付物的“虚拟员工”——从擅长前端开发的“魔法师”到精通 Reddit 社区运营的“忍者”，从负责创意注入的“灵感师”到把控质量的“现实检验员”，每一位智能体都拥有独特的性格、工作方法和产出标准。

项目主要面向三类用户：希望借助 AI 自动化重复性开发与运营任务的个人开发者；需要快速搭建内部 AI 工具链的创业团队；以及正在探索 AI 原生工作流的企业技术部门。对于刚接触 AI 编程助手的用户，该项目提供了零门槛的入门体验；对于资深用户，它则是一个可以深度定制的智能体资源库。

## 核心功能

- **专业分工的智能体阵容**：内置数百名覆盖前端、后端、社区运营、内容创作、项目管理等领域的 AI 智能体，每个智能体都经过“战斗测试”，具备明确的领域知识边界。
- **人格化交互体验**：每个智能体都有独特的对话风格和决策逻辑，避免千篇一律的 AI 回复，让协作过程更接近与真人团队配合。
- **可验证的交付物**：智能体不仅输出代码或建议，更会附带测试用例、部署脚本、性能指标等可衡量成果，确保产出质量。
- **多平台一键接入**：支持将任意智能体安装到 Claude Code、Cursor、Codex、Gemini、Osaurus 等主流 AI 开发工具，无需编写额外适配代码。
- **持续更新的智能体库**：项目以“数字人才市场”模式运营，社区可贡献新角色，核心团队定期精选合并，确保智能体能力与工具生态同步演进。
- **开箱即用的 Shell 脚本**：所有智能体配置逻辑封装在 Shell 脚本中，便于审计、修改或离线部署，无需复杂依赖。

## 技术架构

项目采用纯 Shell 脚本作为核心分发格式，这一选择体现了高度的可移植性：无论是 macOS、Linux 还是 Windows 的 Git Bash 环境，用户都可以直接运行安装脚本，将智能体配置注入到目标 AI 工具中。每个智能体本质上是一个结构化的“角色定义文件”，包含身份设定、领域知识库、任务处理流程、输出规范及测试断言，遵循 MIT 开源协议。

架构上，项目遵循“配置与逻辑分离”的原则：智能体的“人格”部分由自然语言定义文件承载，而“执行能力”则依赖宿主 AI 工具（如 Claude Code、Cursor）的底层模型。这避免了重复造轮子，让智能体的专业深度可以随着底层模型的迭代而自动增强。项目还提供官方配套的桌面应用（Agency Agents App），该应用基于 Electron 或 Tauri 构建，封装了智能体浏览、配置注入和自动更新流程，使非命令行用户也能轻松管理整个“虚拟团队”。此外，项目的版本演化路径通过 GitHub Actions 实现自动化测试，确保每个智能体定义在多种工具环境下都能稳定运行。

## 安装与使用

**方式一：命令行安装（适合开发者）**

```bash
# 克隆仓库
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents

# 查看可用智能体列表
./list-agents.sh

# 将指定智能体安装到 Claude Code（示例：安装一个前端专家）
./install-agent.sh frontend-wizard claude-code

# 将多个智能体一并注入到 Cursor
./install-agent.sh reddit-ninja reality-checker cursor
```

**方式二：桌面应用安装（适合所有用户）**

1. 访问 [Agency Agents 官方网站](https://agencyagents.app) 下载对应操作系统的最新版本（支持 macOS、Linux、Windows）。
2. 打开应用，浏览“智能体名册”，点击每个角色可查看其职责、性格和交付物示例。
3. 选择目标平台（如 Claude Code、Gemini CLI），点击“安装”按钮，应用会自动完成配置写入，全程无需修改配置文件。

**最小可用示例**：安装一个“现实检验员”智能体到 Claude Code 后，在对话中直接询问“请对我的新功能设计进行批判性分析”，该智能体会自动切换到严谨模式，输出风险清单和替代方案，而不会给出泛泛而谈的赞美。

## 适用场景

- **自动化代码审查与优化**：将“逻辑审查员”“性能优化师”等智能体接入 CI/CD 流程，对每次提交的代码自动进行多维度审查，发现潜在缺陷并给出修改建议。
- **社区内容运营**：在 Reddit、论坛等平台使用“社区忍者”智能体自动生成回复草稿、识别讨论热点、管理社区氛围，帮助团队规模化运营线上社群。
- **创意与产品孵化**：在头脑风暴阶段调用“灵感师”智能体生成多方向的产品方案，随后借助“现实检验员”智能体过滤掉低可行性想法，形成高效的“发散—收敛”工作流。
- **企业知识管理适配**：为团队内部 Wiki 或技术支持机器人定制专属智能体，使其具备企业特有的术语库和服务流程，提升客服响应质量与一致性。

## 项目亮点

- **开源且免费可商用**：采用 MIT 协议，透明开放，企业可放心基于其二次开发，也支持通过 GitHub Sponsors 支持作者持续维护。
- **社区驱动的高质量迭代**：区别于小型 prompt 合集，该项目拥有活跃的贡献机制，已经积累了超过 14 万 Star，每个智能体都有严谨的定义规范和验收标准。
- **极致的易用性**：无论是通过桌面应用还是命令行，从发现到安装一个智能体通常只需不到一分钟，无需编写任何配置代码。
- **生态兼容性强**：单套智能体定义即可覆盖当前主流的 AI 开发工具，避免了为不同工具重复定义提示词的繁琐工作。
- **面向交付而非聊天**：始终强调“可衡量的产出”，每个智能体都包含测试与验证步骤，促使 AI 从“聊天助手”转变为“可靠协作者”。
