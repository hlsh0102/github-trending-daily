## 项目概述

MediaCrawler 是一个功能强大的多平台自媒体数据采集工具，专注于抓取国内主流内容平台的公开帖子和评论数据。项目目前支持小红书笔记与评论、抖音视频与评论、快手视频与评论、B 站视频与评论、微博帖子与评论、百度贴吧帖子与评论回复，以及知乎问答文章与评论的采集。

该项目解决了自媒体运营者、市场研究人员、数据分析师等群体在收集跨平台公开数据时面临的重复开发、接口不稳定、反爬机制复杂等痛点，提供了一个开箱即用的统一解决方案。MediaCrawler 在 GitHub 上已获得超过 6 万 Star，是目前该领域最受关注的开源项目之一。

## 核心功能

- **多平台覆盖**：一站式支持小红书、抖音、快手、B 站、微博、贴吧、知乎七大主流平台，无需为每个平台单独开发采集脚本。
- **帖子与评论采集**：既可抓取帖子/视频/笔记的正文、标题、发布时间、点赞数、收藏数等基础信息，也可递归采集全部评论及回复内容。
- **关键词与指定链接采集**：支持通过关键词搜索采集目标内容，也支持直接传入指定帖子链接进行定向采集。
- **登录态管理与持久化**：支持通过 Cookie 登录，并提供登录状态缓存，避免频繁扫码登录。
- **灵活的存储后端**：数据可写入 CSV、JSON 文件，或通过配置接入 MySQL、SQLite、PostgreSQL、MongoDB 等数据库，方便后续分析处理。
- **异步并发采集**：基于异步框架实现并发请求，在保证稳定的前提下显著提升采集效率。

## 技术架构

MediaCrawler 基于 Python 3.8+ 开发，核心依赖包括 Playwright（浏览器自动化）、httpx（HTTP 客户端）、Pydantic（数据校验）等。项目整体设计遵循模块化原则，每个平台对应独立的爬虫模块，共享统一的数据模型和存储逻辑。

在反爬策略上，MediaCrawler 采用浏览器自动化模拟真实用户操作，配合随机延迟、代理切换、请求重试等机制降低被识别和封禁的风险。对于需要登录的平台，项目支持 Cookie 导入与自动缓存，减少人工干预频率。

项目还提供了 CLI 命令行模式和 Web 可视化界面（基于 Flask 构建），用户既可以在终端中灵活指定平台、关键词、采集数量等参数，也可以通过浏览器界面更直观地操作和查看数据。

在数据层，所有采集结果先经过 Pydantic 模型校验，确保数据完整性和类型正确，再通过统一的 Writer 接口输出到不同存储目标。这种设计降低了新增平台时的对接成本，也便于后续扩展更多存储方式。

## 安装与使用

**环境准备**：需要 Python 3.8 及以上版本，并安装 Playwright 浏览器内核。

**安装步骤**：

1. 克隆仓库并安装依赖：

```bash
git clone https://github.com/NanmiCoder/MediaCrawler.git
cd MediaCrawler
pip install -r requirements.txt
```

2. 安装 Playwright 浏览器：

```bash
playwright install
```

3. 根据需求修改配置文件 `config/base_config.py`，设置平台、关键词、采集数量、存储方式等参数。

**最小可用示例**——以采集小红书笔记为例：

```bash
python main.py --platform xhs --lt qrcode --type search --keywords "美食"
```

该命令会通过二维码登录小红书，搜索关键词“美食”，并将结果默认保存为 CSV 文件。

**指定链接采集示例**：

```bash
python main.py --platform dy --type detail --urls "https://v.douyin.com/xxxxx/"
```

如果需要使用数据库存储，在 `base_config.py` 中启用对应的 DB 类型并填写连接信息即可，首次运行会自动建表。

## 适用场景

- **竞品与热点监测**：企业市场部门可通过关键词追踪竞品在各平台的发布内容及用户反馈，及时掌握市场动态。
- **学术研究与舆情分析**：研究人员采集指定话题下的跨平台讨论数据，用于舆情演化分析、传播规律研究或社会调查。
- **自媒体运营与选题策划**：运营人员分析爆款内容的评论互动，洞察用户偏好，辅助内容选题与创作方向决策。
- **数据仓库建设**：为构建中文社交媒体语料库或训练数据集，批量采集指定领域的历史帖子和评论数据。

## 项目亮点

- **覆盖面广且统一**：单仓库解决七个主流平台的数据采集问题，数据模型和输出格式统一，显著降低学习和维护成本。
- **社区活跃度高**：6 万+ Star 和持续更新保证了项目的生命力，Issue 区响应及时，常见问题均有解决方案。
- **可视化管理**：相比同类纯命令行工具，提供 Web 界面操作方式，降低了非技术用户的使用门槛。
- **持续迭代**：项目定期适配各平台的反爬变化，修复失效接口，保持采集的可用性。
