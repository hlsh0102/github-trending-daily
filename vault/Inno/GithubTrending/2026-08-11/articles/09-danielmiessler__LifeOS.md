## 项目概述

LifeOS 是一个通用型人工智能辅助框架（General Purpose AI Harness），旨在帮助用户在生活和工作中从“当前状态”（Current State）高效地迈向“理想状态”（Ideal State）。它不仅仅是一个简单的 AI 聊天工具，而是一套完整的“生活操作系统”：它能够捕获你是谁、你关心什么、你想要去哪里，并利用这些完整的上下文信息，让 AI 真正地“了解你”，从而为你的每一个目标提供个性化的辅助。

无论你是想构建应用、创办公司，还是推进创意项目，LifeOS 都能通过其独特的“爬山算法”（Hill-climbing）理念，将宏大目标分解为可执行的小步骤，持续引导你向上攀登。该项目由知名安全与 AI 领域专家 Daniel Miessler 发起，目前已在 GitHub 上获得超过 18000 颗星，社区活跃度极高。

## 核心功能

- **个性化 AI 上下文引擎**：LifeOS 会构建一个持续更新的“用户画像”数据库，包含你的价值观、偏好、长期目标和当前项目状态，确保 AI 的每次输出都基于对你的深度理解。
- **目标分解与任务追踪**：自动将你的“理想状态”拆解为多层次的、可操作的任务列表，并与你的日常待办事项无缝集成。
- **通用型 AI 编排**：内置对多种主流大语言模型（如 OpenAI、Anthropic 等）的支持，提供统一的接口层，允许你自由切换或组合不同的 AI 模型以完成特定任务。
- **生命周期管理**：从目标的设定、执行、反馈到迭代，LifeOS 提供完整的闭环管理流程，支持日志记录、反思总结和进度可视化。
- **跨领域适配**：无论是职业发展、健康管理、学习新技能还是财务管理，LifeOS 提供灵活的模板和自定义字段，能够适配不同领域的目标管理需求。

## 技术架构

LifeOS 采用 **TypeScript** 编写，基于 **Bun** 运行时构建，兼顾了现代 JavaScript 生态的灵活性与高性能。其架构设计围绕“状态机”哲学展开：

1.  **核心数据层**：以结构化 JSON 或 Markdown 文件存储用户的状态、目标、偏好和上下文，保证数据的可移植性和透明度，用户可以随时查看和编辑自己的“人生数据”。
2.  **AI 适配层**：通过独立的 Provider 抽象层封装不同 AI 服务的 API，支持流式输出、工具调用（Function Calling）等功能，使得模型切换成本极低。
3.  **爬山算法引擎**：这是项目的灵魂——系统会基于当前状态与理想状态之间的差距，设定“梯度”，并调用 AI 计算出下一步最合理的行动（即“爬升动作”）。每一步执行后，系统会重新评估状态，形成动态循环。
4.  **可扩展的插件机制**：支持用户通过简单的配置或脚本扩展功能，例如集成日历、邮件、代码仓库等外部工具，让 AI 能够主动获取实时信息。

## 安装与使用

LifeOS 的安装极为简便，只需确保本地环境已安装 Bun 运行时即可。以下是基本步骤：

```bash
# 1. 克隆仓库
git clone https://github.com/danielmiessler/LifeOS.git

# 2. 进入目录
cd LifeOS

# 3. 安装依赖
bun install

# 4. 配置环境变量（例如设置你的 AI API 密钥）
cp .env.example .env
# 编辑 .env 文件，填入 OPENAI_API_KEY 或 ANTHROPIC_API_KEY

# 5. 启动交互式会话
bun run start
```

**最小可用示例**：
启动后，你可以直接输入以下指令体验核心流程：

```
init "我想要在三个月内发布我的第一款 SaaS 产品"
```

LifeOS 会调用 AI 进行分析，自动生成一组从市场调研、MVP 开发到上线推广的登山路径图，并开始引导你执行第一步。

## 适用场景

- **个人知识管理与项目推进**：构建一个能持续追踪你所有笔记、灵感并自动关联到当前目标的第二大脑。
- **创业公司运营**：将公司的 OKR（目标与关键结果）导入 LifeOS，让 AI 担任虚拟 COO，每周自动生成周报、识别风险并推荐下一步行动。
- **习惯养成与自我提升**：设定“成为一名晨间跑步者”的理想状态，LifeOS 会根据你的日程和体力数据，动态调整你的训练计划与激励反馈。
- **复杂研究或写作项目**：当需要撰写长篇报告或论文时，LifeOS 能帮你管理所有参考资料，并基于你的核心论点生成章节大纲和初稿。

## 项目亮点

与市场上其他的 AI 助理或笔记工具相比，LifeOS 的差异化优势非常明显：

1.  **“状态机”而非“对话机”**：传统工具聚焦于单次对话，LifeOS 则拥有跨会话的长期记忆和目标状态机，AI 不会遗忘你的最终目标。
2.  **透明化数据主权**：所有个人数据以明文文件存储，你可以随时导出或迁移，不锁定在私有云中。
3.  **通用性远超特定场景**：它不是一个只写代码或只写文章的专用工具，而是一个元框架，允许你定义任何领域的“理想状态”。
4.  **活跃的开源生态与哲学驱动**：创始人 Daniel Miessler 将“Bridging the gap between Current and Ideal”这一认知科学理念深度产品化，持续快速迭代。
