## 项目概述

Agent Skills 是由 Google Chrome 团队工程经理 Addy Osmani 开源的一个项目，旨在为 AI 编码代理提供一套生产级工程技能。所谓“技能”，指的是资深软件工程师在日常开发中所遵循的工作流程、质量门禁和最佳实践。该项目将这些隐性知识显式编码，使 AI 代理能够在软件开发的每个阶段保持一致的行为标准。

该项目解决了当前 AI 编程工具面临的一个核心问题：大多数 AI 代理能够生成代码，但缺乏对完整软件工程生命周期的理解。它们往往跳过了需求定义、规划、测试和代码审查等关键环节，导致生成的代码质量参差不齐。Agent Skills 通过将工程纪律注入 AI 代理的工作流程，使其能够像资深工程师一样思考和工作。

目标用户包括：使用 AI 辅助编程工具的开发者、希望将 AI 编码代理集成到正式开发流程中的工程团队，以及 AI 工具链的构建者。项目采用 MIT 许可证，对商业使用和二次开发均无限制。

## 核心功能

- **8 个斜杠命令映射完整开发生命周期**：提供 `/spec`、`/plan`、`/build`、`/test`、`/review`、`/ship` 等命令，分别对应需求定义、技术规划、增量构建、测试验证、代码审查和发布上线等阶段。
- **按需自动激活技能**：每个斜杠命令会自动加载与当前开发阶段相关的技能集合，开发者无需手动切换上下文或提示词。
- **规范先行原则**：`/spec` 命令强制在任何编码工作之前完成需求细化和 PRD（产品需求文档）编写，确保 AI 代理先理解“做什么”再思考“怎么做”。
- **原子化任务分解**：`/plan` 命令引导 AI 将大型功能拆解为小而独立的任务单元，降低每次代码变更的复杂度和风险。
- **测试作为验证标准**：`/test` 命令将测试视为代码正确性的证明，而非可选环节，确保 AI 代理生成的每一段代码都有对应的验证手段。
- **内置代码审查门禁**：`/review` 命令模拟资深工程师的审查流程，在合并代码前检查实现质量、安全性和一致性。

## 技术架构

Agent Skills 的设计核心是“技能”这一抽象概念。每个技能本质上是一组结构化的指令、约束条件和决策规则，打包成 AI 代理可读取的格式。项目采用分层架构：

- **命令层**：暴露给用户的 8 个斜杠命令，负责解析用户的开发意图，并映射到相应的技能集合。
- **技能编排层**：根据当前命令和项目状态，动态组合和排序多个技能。例如，`/build` 命令会激活编码规范技能、模块化设计技能和增量提交技能。
- **执行层**：与具体的 AI 代理框架（如 Claude Code、Codex 等）对接，将技能指令转化为代理可执行的动作序列。

项目采用 JavaScript 编写，巧妙利用 AI 代理的“系统提示词”机制。技能文件包含标准化的元数据（如适用范围、优先级、触发条件），使得代理可以在不增加上下文负担的情况下按需加载。这种模块化设计意味着技能可以独立更新和维护，团队可以根据自身工程文化定制或扩展技能库。

架构上的一大特点是**阶段门禁**机制。每个技能在执行前会检查前置条件，例如 `/build` 命令要求必须先有经过 `/plan` 确认的任务分解，这从机制上避免了 AI 代理跳过关键步骤。

## 安装与使用

安装 Agent Skills 的基本步骤如下（具体命令可能因 AI 代理框架而异）：

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/addyosmani/agent-skills.git
   ```

2. 根据所使用的 AI 代理框架，将技能目录配置到代理的可用技能路径中。例如，对于支持技能目录的代理，可以设置环境变量或配置文件指向克隆的目录。

3. 在 AI 代理会话中启用所需命令。

最小可用示例——使用 `/spec` 命令定义一个新功能：

```
> /spec 实现用户注册功能，支持邮箱和密码登录方式

AI Agent 将自动加载规范编写技能，输出包含以下内容的结构化 PRD：
- 功能背景与目标
- 用户故事与验收标准
- 技术约束与非功能需求
- 接口定义草案
```

使用 `/build` 命令进入增量构建阶段：

```
> /build 开始实现注册功能的第一部分

AI Agent 将按照先前的任务分解，一次只实现一个模块，并在每个任务完成后输出进展摘要和测试建议。
```

## 适用场景

- **AI 辅助的正式软件开发项目**：团队使用 AI 编程工具，但需要确保代码符合组织标准和工程规范，Agent Skills 提供了结构化的约束框架。
- **快速原型到生产级过渡**：从概念验证阶段进入产品化阶段时，使用 `/spec` 和 `/plan` 命令补全工程文档和架构规划，让 AI 代理生成从“能跑”到“能维护”的代码。
- **团队协作中的 AI 代理治理**：当多人共用 AI 编程助手时，标准化技能可以确保所有代理行为一致，减少因提示词差异导致的质量波动。
- **教学与知识沉淀**：将资深工程师的实践经验编码为可复用的技能，帮助新团队或初级开发者理解专业开发流程。

## 项目亮点

Agent Skills 的差异化优势在于其**系统性**。目前大多数 AI 编码工具都聚焦于“生成代码”这一单一环节，而该项目覆盖了从需求到上线的完整链路。它不追求让代理一次生成大段代码，而是强调“一次一个小切片”的增量构建哲学，这与现代敏捷开发实践高度一致。

该项目的另一亮点是**可组合性与透明性**。技能文件是纯文本的、人类可读的，团队可以逐行审查 AI 代理遵循的规则，甚至自行修改和扩展。相比之下，许多商业 AI 代码工具的处理过程是不透明的黑盒。

此外，项目将 AI 代理定位为“遵循工程纪律的团队成员”而非“代码生成器”，这一理念转型具有前瞻性。它明确要求 AI 在写代码前先理解需求，在提交前先完成测试，这些人类工程师早已视为理所当然的步骤，如今被系统地编码为机器可执行的规则。
