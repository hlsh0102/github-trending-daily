## 项目概述

NGINX（发音为"engine x"）是全球最流行的 Web 服务器，同时也是一款高性能的负载均衡器、反向代理服务器、API 网关和内容缓存系统。该项目是 NGINX 的官方开源版本仓库，采用简化的 2-clause BSD-like 许可证发布。NGINX 解决了高并发场景下传统 Web 服务器性能瓶颈的问题，尤其适用于需要同时处理大量连接、提供静态内容、作为后端服务代理或实现流量分发与负载均衡的场景。目标用户包括系统管理员、运维工程师、后端开发人员以及任何需要构建高性能网络基础设施的开发团队。

## 核心功能

- **高性能 Web 服务器**：基于事件驱动架构，能高效服务静态文件与动态内容，支持 HTTP/1.1、HTTP/2、HTTP/3 等协议。
- **反向代理与负载均衡**：将客户端请求转发至后端服务器集群，支持轮询、最少连接数、IP 哈希等负载均衡算法，并可配合健康检查实现高可用。
- **内容缓存与加速**：对后端响应进行缓存，减少重复请求对后端服务的压力，加速静态与动态内容的分发。
- **API 网关能力**：支持请求路由、速率限制、访问控制、SSL/TLS 终止等，可作为微服务架构的统一入口。
- **流媒体与 TCP/UDP 代理**：可传输 HTTP 以外的协议，如用于 WebSocket 代理、邮件代理或通用 TCP/UDP 流量转发。
- **模块化与可扩展性**：官方提供丰富模块集，同时支持第三方动态模块，便于按需定制功能。

## 技术架构

NGINX 采用异步、非阻塞的事件驱动模型，其核心是一个高效的事件循环，通过 epoll（Linux）、kqueue（BSD）等系统调用实现单进程或少量进程处理海量并发连接。其架构由以下关键组件构成：

- **Master 进程**：负责读取配置文件、管理工作进程、执行平滑重启与热升级。
- **Worker 进程**：处理实际网络请求，每个 worker 独立运行事件循环，无锁设计保证了高性能与可伸缩性。
- **事件模块**：抽象不同操作系统下的 I/O 多路复用机制，实现跨平台的高并发处理能力。
- **模块化设计**：核心功能与扩展功能通过模块层实现，模块可编译为静态或动态加载形式。NGINX 的配置语言采用声明式风格，通过指令块（如 `http`, `server`, `location`）组织层次化的规则，使得配置简洁且易于理解。

## 安装与使用

NGINX 提供了多种安装方式：

1. **预编译包**（推荐大多数生产环境使用）：
   - 对于 Debian/Ubuntu，添加官方仓库后执行 `sudo apt install nginx`。
   - 对于 RHEL/CentOS，添加官方 YUM 仓库后执行 `sudo yum install nginx`。
2. **源码编译**（用于自定义模块或特殊系统）：
   ```bash
   wget https://nginx.org/download/nginx-1.26.0.tar.gz
   tar -xzf nginx-1.26.0.tar.gz
   cd nginx-1.26.0
   ./configure --prefix=/usr/local/nginx
   make
   make install
   ```

**最小可用示例**：创建一个最简单的反向代理配置文件 `/etc/nginx/conf.d/proxy.conf`：

```nginx
server {
    listen 80;
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

启动 NGINX：`sudo nginx` 或 `sudo systemctl start nginx` 即可运行。此时访问服务器 80 端口，请求将被转发至本机的 3000 端口应用。

## 适用场景

- **高并发静态资源托管**：如大型网站的前端静态文件（HTML、CSS、JS、图片）分发，利用 NGINX 的高并发能力与 sendfile 系统调用实现高效传输。
- **微服务 API 网关**：统一对外暴露接口，实现路由分发、认证鉴权、流量控制、日志记录等功能，降低后端服务复杂度。
- **负载均衡与反向代理**：将流量分散至多台后端服务器，提升应用可用性与扩展性，常用于 Web 应用集群、数据库读负载均衡等。
- **缓存加速**：对后端动态内容或第三方 API 响应进行缓存，降低响应延时与后端负载，常见于内容管理系统或电商平台。

## 项目亮点

- **极高的并发处理能力**：事件驱动模型使其能在普通硬件上轻松处理数万个并发连接，远超传统线程/进程模型的性能。
- **极低的内存占用**：每个连接消耗极小的内存（通常小于 1KB），在相同硬件上能承载更多用户。
- **配置灵活且可读性强**：层次化的配置结构使得路由、限流、SSL 等复杂规则清晰易懂，支持热重载以不停机更新配置。
- **广泛的社区与生态**：作为全球最流行的 Web 服务器，拥有海量文档、第三方模块、监控工具（如 NGINX Plus 的状态页）及商业支持（F5 提供企业版本）。
- **长期稳定与安全**：开源项目维护超过 20 年，版本迭代注重稳定性与安全性，定期发布安全补丁。
