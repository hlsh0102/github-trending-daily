## 项目概述

OpenMAIC（Open Multi-Agent Interactive Classroom）是由清华大学 MAIC 团队开发的开源项目，旨在为用户提供一键式、沉浸式的多智能体课堂学习体验。该项目将大语言模型驱动的多智能体系统与传统课堂场景深度融合，模拟出包含学生、助教、教师等多种角色的互动学习环境。用户只需提供至少一个 LLM API Key，即可在真实浏览器环境中体验多智能体协作、自主提问与即时反馈的交互式学习流程。

该项目主要面向三类用户：一是希望探索多智能体系统在教育场景中应用的研究者与开发者；二是需要快速搭建互动教学原型、进行课程实验的教育工作者；三是对大语言模型能力感兴趣、希望以更直观方式理解多智能体协作机制的爱好者。OpenMAIC 的核心价值在于降低了构建多智能体教育应用的门槛，使普通用户无需深入了解底层架构即可获得完整的课堂互动体验。

## 核心功能

- **一键部署与启动**：通过 Vercel 平台或本地环境快速部署，仅需配置一个或多个 LLM 提供商的 API Key（如 OpenAI、Anthropic），所有提供商均为可选，降低使用门槛。
- **多角色智能体模拟**：支持学生、助教、教师等多角色智能体协同工作，每个角色具备独立的身份设定与回应策略，真实模拟课堂对话场景。
- **实时互动反馈**：课堂环境中的问题提出、讨论与解答均会得到即时响应，智能体间可以互相追问与讨论，形成动态的知识建构过程。
- **可配置的多 LLM 支持**：内置对多个主流大语言模型提供商的适配，用户可根据偏好或需求自由选择不同的模型驱动角色行为。
- **实时状态可视化**：界面清晰展示各智能体的活动状态与输出过程，用户可直观观察多智能体间的协作流程图景。
- **开源可扩展架构**：基于 TypeScript 构建，模块化设计便于研究者将 OpenMAIC 集成到自有实验流程或在其基础上扩展自定义场景。

## 技术架构

OpenMAIC 的核心技术栈以 TypeScript 为主要开发语言，利用现代前端框架构建交互界面，并在底层对接多个大语言模型 API 服务。

在架构设计上，OpenMAIC 采用了**事件驱动**的多智能体编排机制。系统将课堂定义为有状态的事件流会话，教师、助教、学生等不同角色作为独立的智能体单元，通过异步消息通道进行通信和协作。每一个智能体的行为逻辑由策略模板驱动，该模板可以通过自然语言 Prompt 定制，从而灵活改变角色的行为风格与知识领域。

系统设计充分考虑了**服务端与客户端的解耦**。由于运行时需要处理多个 LLM 的流式响应与并发请求，OpenMAIC 在部署上支持前后端分离：界面层负责将课堂状态实时渲染为可视化视图；逻辑层负责调度智能体，管理会话状态，并将 LLM 返回的增量内容实时推送至各订阅方。对于使用 Vercel 部署的轻量场景，系统通过无服务器函数（Serverless Functions）来承接 API 请求转发，避免 CORS 与密钥泄漏问题。

此外，项目具备良好的**环境变量管理机制**。OpenAI、Anthropic 等 API Key 均可独立配置并通过环境变量注入，所有服务均以可选方式加载，确保用户至少配置一个 Key 即可运行完整的交互流程，减少了初次上手的配置负担。

## 安装与使用

OpenMAIC 的部署支持两种模式，用户可根据自身技术背景与环境选择。

**方式一：Vercel 平台部署（推荐）**

1. 点击仓库 README 中的 Vercel 部署按钮，进入按需配置页面；
2. 在环境变量设置中填入至少一个 LLM 提供商的 Key（如 `OPENAI_API_KEY`）；
3. 点击部署，Vercel 将自动完成构建，部署成功后即可访问线上课堂体验。

**方式二：本地开发运行**

```bash
# 克隆仓库
git clone https://github.com/THU-MAIC/OpenMAIC.git
cd OpenMAIC

# 安装依赖
npm install

# 配置环境变量（至少一个）
cp .env.local.example .env.local
# 编辑 .env.local，填入 OPENAI_API_KEY 或 ANTHROPIC_API_KEY 等

# 启动开发模式
npm run dev
```

启动后，打开浏览器访问 `http://localhost:3000` 即可看到课堂主界面。进入后会默认创建一个模拟课堂会话，包含多位虚拟学生与助教，你可以在界面中直接以学生或教师身份发起讨论，观察各智能体如何给出回应与互动。

## 适用场景

- **教育科技研究**：用于人机交互、多智能体协同学习、智能辅导系统等方向的实验数据收集与原型验证，帮助研究者快速获得可复现的实验环境。
- **交互式课程设计**：教师可利用角色定制，打造不同学科背景的虚拟学伴与助教，为学生提供 24 小时可用的讨论空间，增强课后延伸学习的主动性。
- **大模型能力探索**：对于希望观察不同提示词策略、不同 LLM 模型在长对话中协同表现的技术爱好者，OpenMAIC 提供了一个贴近真实场景的测试沙箱。
- **开源社区生态共建**：针对多智能体框架的开发者和维护者，OpenMAIC 提供了一套完整的前端参考实现，展示了如何将复杂的 Agent 状态机优雅嵌入可视化交互应用。

## 项目亮点

OpenMAIC 的差异化优势主要体现在易用性与沉浸感的高度统一。与大多数需要自行编写复杂编排逻辑的多智能体框架不同，OpenMAIC 通过产品化的设计，让用户“开箱即用”地获得课堂体验。而其基于真实浏览器环境的交互模式，也区别于传统后端强化学习模拟器，带来了更直观的用户感知。

项目代码开源且采用 MIT 许可证，允许学术与非商业自由度极高的二次开发。同时，来自清华大学的学术背景与 JCST 论文支撑，为项目的算法设计提供了理论解释与权威背书。此外，项目配有中英文双语指南，分别面向全球用户与国内社区，很好地消弭了上手文档的语言隔阂。
