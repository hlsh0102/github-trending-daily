## 项目概述

Invidious 是一个开源的 YouTube 替代前端，旨在为用户提供一种更加注重隐私、轻量且无广告干扰的 YouTube 观看体验。它本质上是一个独立的 Web 应用，可以部署在自己的服务器上，作为用户与 YouTube 之间的中间层。该项目主要面向那些对隐私敏感、希望摆脱 Google 追踪和广告、或者希望拥有一个更简洁观看界面的用户，同时也适合希望自定义 YouTube 服务体验的开发者或自托管爱好者。

## 核心功能

- **隐私保护**：通过代理服务器访问 YouTube，隐藏用户真实 IP 地址，避免 Google 的定向追踪和指纹收集。
- **无广告与纯净界面**：默认界面不包含任何广告，提供了清晰、专注的视频观看体验。
- **订阅与内容管理**：支持在无 Google 账号的情况下，创建本地订阅列表、播放列表和观看历史，所有数据仅保存在服务器本地。
- **内置代理功能**：提供音频与视频的流媒体代理，可直接下载视频或音频文件（支持多种格式），而无需访问原始站点。
- **RSS 订阅支持**：可为订阅频道和播放列表生成 RSS 源，方便通过外部阅读器跟踪内容更新。
- **多实例与多语言**：提供公开实例供直接使用，同时支持丰富的社区翻译，界面支持多种语言。

## 技术架构

Invidious 使用 **Crystal** 语言编写，这是一种语法类似 Ruby 但编译为原生代码的编程语言。选择 Crystal 旨在结合开发效率与运行性能。项目采用典型的 **MVC**（模型-视图-控制器）架构，Web 框架选用 Kemal，用于构建轻量且高效的 HTTP 服务器。数据持久化方面，核心订阅、播放列表等元数据存储于 **PostgreSQL** 数据库中，对于需要高并发读取的数据（如热门视频等）则依赖 **Redis** 进行缓存。

在服务器端，Invidious 动态解析 YouTube 的网页数据，提取视频流、元数据等关键信息，然后将其重新封装并渲染为自己界面。这一过程使得客户端浏览器仅与 Invidious 服务器通信，从而实现了对 YouTube API 的间接访问和隐私隔离。项目支持通过配置文件或环境变量进行高度的自定义设置，方便不同规模的主机进行部署与调优。整体架构旨在以较低的资源开销运行，适合部署在树莓派或小型 VPS 上。

## 安装与使用

Invidious 提供了多种安装方式，最常用的是使用 Docker（使用项目仓库中的 `docker-compose.yml`）或直接从源码编译。以下是从源码编译的最小步骤概述：

**前提条件**：需要安装 Crystal 语言、PostgreSQL 和 Redis，并配置好数据库、密钥及域名（或使用默认本地设置）。

1.  克隆代码并安装依赖：
    ```bash
    git clone https://github.com/iv-org/invidious.git
    cd invidious
    shards install
    ```
2.  复制并配置环境变量（至少需要配置 `DATABASE_URL` 和 `HMAC_KEY`）：
    ```bash
    cp .env.example .env
    # 编辑 .env 文件，填写数据库连接及随机生成的 HMAC_KEY
    ```
3.  运行数据库迁移并启动服务：
    ```bash
    crystal run src/invidious.cr
    ```

启动后，在浏览器中导航至 `http://your-server-ip:3000` 即可看到 Invidious 首页。此时，你可以直接搜索视频或粘贴 YouTube 链接进行播放，并注册一个本地账号用于管理订阅。

## 适用场景

- **个人隐私浏览**：在未登录 Google 账号的设备上，希望安全、隐私地观看视频，避免观看历史和搜索记录被平台关联。
- **组织或社区内部服务**：企业或学校在内部网络中搭建 Invidious，为成员提供统一、无广告的视频访问渠道，同时可有效过滤视频推荐算法带来的干扰。
- **轻量化设备的媒体访问**：在性能有限的设备（如老旧电脑或嵌入式系统）上，运行 Invidious 前端比加载臃肿的官方网页更流畅，节省计算和网络资源。
- **内容订阅与自动化的中转站**：基于其 RSS 功能和内置 API，用户可以构建如频道更新提醒、视频归档等自动化工作流。

## 项目亮点

与直接使用 YouTube 或寻找其他浏览器过滤插件相比，Invidious 的差异化优势明显：

- **数据自主权**：你的订阅、播放历史完全存储在自己控制的服务器实例上，不依赖任何中央云服务。
- **API 友好性**：项目自带清晰的内部 API，允许开发者以一种非官方但稳定的方式获取 YouTube 数据，为第三方应用提供了方便的数据源。
- **社区与自托管生态成熟**：项目提供了官方文档、命令行管理工具及丰富的配置选项，且拥有庞大的社区提供公开实例和翻译支持，维护活跃，持续跟进 YouTube 的界面变动。
- **低资源占用**：相较于拥有重型 Web UI 的官方页面或使用浏览器自动化方案的第三方工具，采用 Crystal 编写的 Invidious 在内存和 CPU 占用上显著更低，使其成为可在极低成本硬件上运行的服务。
