## 项目概述

中国专利.skill 是一款面向研发工程师、专利工程师与知识产权从业者的开源智能体技能包。它针对国内专利申请流程中的核心痛点——专利点挖掘难、交底书撰写繁琐、公开专利解读门槛高——提供了从研发素材到可交付交底书的一站式辅助能力。项目按发明人/申请人维度检索公开专利清单，覆盖发明专利、实用新型与外观设计三类专利的交底书编写，同时提供专利通俗解读与政策动向嗅探功能。其目标用户是长期从事技术研发却鲜少署名发明人的一线工程师，以及需要高效处理专利文献与答复审查意见的 IP 专业人士。

## 核心功能

- **专利点挖掘与交底书生成**：从项目设计文档、代码或口头描述中梳理可申请的技术方案，自动生成结构完整的交底书初稿，包含技术领域、背景技术、发明内容、具体实施方式等必备章节。
- **多类型专利适配**：针对发明、实用新型、外观设计分别定制撰写模板，能识别并写入结构框图、外观设计图片（六面视图）等非文字要素。
- **通俗化解读与私有知识库沉淀**：将晦涩的公开专利文献转化为通俗笔记与概念图谱，并自动导入 Obsidian 形成个人专利情报库，支持双链、图谱可视化与渐进式积累。
- **审查意见答复辅助**：基于专利对比文件与审查意见通知书内容，辅助生成答复思路框架与意见陈述书草稿。
- **政策动向嗅探**：检索并归纳最新专利政策、资助办法与审查指南修订动态，帮助用户把握申请时机与策略。
- **多轮迭代与追溯管理**：交底书支持多版本迭代修改，每次改动另存为新时间戳文件，并保留对话修改记录，便于后续补充材料与团队协作追溯。

## 技术架构

项目以 Python 为核心语言，采用模块化技能包设计，深度集成 AgentSkills 框架标准。在自动化层，项目依托 Playwright 驱动无头浏览器完成公开专利数据库的检索与详情抓取，降低了反爬虫机制对数据获取的干扰。在文档处理层，系统内置了对 Mermaid 流程图的支持，并能将技术方案中的结构关系渲染为框图插入交底书；针对外观设计专利，已实现基图片的读取与排版。技能的设计遵循“场景驱动”原则：交底书编写、专利解读、政策嗅探各自作为独立的技能流程，统一通过可复用的内部 API 与外部工具交互。其突出特点是强调上下文记忆与追溯能力——每一轮迭代的对话记录和生成文件均按时间戳归档，形成完整的项目时间线。此外，项目预留了与 Obsidian CLI 及外部数据库（Bases）的接口，便于将解读结果进一步加工为结构化知识库。

## 安装与使用

因项目依赖中国专利审查系统的公开数据源与本地文档处理工具，安装步骤如下：

1. 克隆仓库并安装 Python 依赖：
   ```bash
   git clone https://github.com/handsomestWei/patent-disclosure-skill.git
   cd patent-disclosure-skill
   pip install -r requirements.txt
   playwright install chromium
   ```

2. 根据本地环境配置 Obsidian 知识库路径及检索关键词白名单（配置文件位于 `config.yaml`）。

3. 最小可用示例：
   ```python
   from skill import PatentSkill
   
   skill = PatentSkill()
   # 输入项目描述，自动挖掘专利点并生成交底书
   disclosure = skill.generate_disclosure(
       project_name="智能门锁低功耗唤醒模块",
       technical_material="docs/design_spec.md",
       patent_type="utility_model"  # 可选 invention / utility_model / design
   )
   print(f"交底书已生成：{disclosure.output_path}")
   ```

   运行后，输出目录下将生成带时间戳的交底书 Markdown 源文件、Mermaid 框图及可编辑的 Word 文档初稿。详细说明请参考仓库内 `INSTALL.md` 与 `SKILL.md`。

## 适用场景

- **企业研发部门的专利申请提速**：研发人员在完成项目阶段性交付后半小时内，即可从设计文档中梳理出基础交底材料，避免申请事项因“没时间写材料”而无期限搁置。
- **个人发明人与独立创新者的知识管理**：持续关注自身技术领域内公开专利，通过通俗解读快速掌握竞争对手布局，同时将自有方案快速转化为规范交底书。
- **代理机构与 IP 团队的批量化预审**：在进行新案预审或答复审查意见前，批量检索同类专利作为对比文件，利用通俗笔记快速定位技术差异点，提高答复质量与效率。

## 项目亮点

与通用的大模型写作工具或传统专利管理软件相比，该项目的差异化优势体现在：其一，深度适配中国专利制度与表格规范，而非针对美欧专利流程的简单汉化，能够直接输出符合国内初审要求的交底素材；其二，打通了“交底书撰写 — 审查答复 — 情报积累”的业务闭环，而非只停留在单次文本生成；其三，创新的“私有专利知识库”机制，让用户解读过的每一篇专利自动成为个人知识图谱的节点，实现知识资产的规模效应；其四，全流程保留多版本追溯记录，解决了企业在专利管理中的审计与协作合规问题。此外，项目完全开源（MIT 协议），允许企业在内网进行二次定制开发。
