## 项目概述

video-use 是一个将视频编辑能力赋予编码代理（Coding Agents）的开源项目，由 Browser Use 团队开发。它彻底改变了传统视频编辑的工作方式：你不再需要打开复杂的剪辑软件，只需将原始素材放入文件夹，通过自然语言与 Claude Code 等编码代理对话，即可获得经过完整编辑的 `final.mp4` 文件。无论你的内容是人像口播、混剪、教程、旅行记录还是访谈，video-use 都能自动完成繁琐的编辑工作，无需任何预设模板或菜单操作。

该项目面向内容创作者、视频编辑新手、开发者以及任何希望自动化视频处理流程的用户，核心理念是“让代码替你完成重复性的剪辑劳动”。

## 核心功能

- **智能填充词与空白段裁剪**：自动识别并去除“umm”、“uh”等语气填充词以及拍摄中的无用停顿和死空间，让最终视频节奏更加紧凑流畅。
- **全自动色彩分级**：为每一段视频片段自动应用色彩分级处理，内置暖色调电影感、中性高饱和等多种风格，也支持用户自定义完整的 ffmpeg 色彩处理链。
- **无缝音频过渡**：在每一次剪切点自动加入 30 毫秒的音频淡入淡出效果，彻底消除剪辑中常见的“爆音”问题，让听觉体验更加顺滑。
- **自定义字幕烧录**：支持将字幕直接烧录到视频中，默认采用双词大写分组以增强可读性，且完全支持自定义字幕样式与格式。
- **并行动画叠加生成**：通过 HyperFrames、Remotion、Manim 或 PIL 等多种引擎生成动画叠加层，并由多个并行运行的子代理分别负责单个动画任务，大幅提升复杂视觉效果的生产效率。
- **输出自我质量评估**：在交付最终视频之前，系统会在每一个剪切边界自动评估渲染结果，确保画面与音频质量达标后才向用户展示输出内容。
- **持久化会话记忆**：将项目状态与编辑历史记录在 `project.md` 文件中，即使一周后再次启动代理会话，也能无缝续接上一次的工作进度。

## 技术架构

video-use 的底层设计基于两个核心原则：**代理驱动**与**模块化工具链**。项目采用 Python 编写，其工作流并不固化为某个单一的视频编辑逻辑，而是将视频处理所需的各项能力拆解为可被语言模型调用的“工具包”。当用户下达编辑指令时，编码代理（如 Claude Code、Codex 或 Hermes）能够自主规划调用路径，组合使用这些工具完成复杂的编辑任务。

技术上，项目以 ffmpeg 作为核心的音视频处理引擎，负责实际的剪切、转码和特效合成。对于需要动画或图形渲染的场景，video-use 可调度 HyperFrames、Remotion、Manim 等外部渲染工具，并通过进程隔离的方式由子代理并行执行，最大化利用多核计算资源。项目的评估机制则巧妙地在 ffmpeg 的每个输出时间点插入校验节点，通过程序化方式检测视频帧与音频波形的一致性，从而实现无需人工介入的自动质检。

视觉层面，video-use 维持了与 Browser Use 家族一致的美学风格，采用 CLI 驱动的交互方式，但所有复杂参数均由代理自动生成，用户层面看就像一次纯粹的对话。项目在 Apache 2.0 与 MIT 许可下开源，核心依赖环境要求仅为 Python 3.10+ 与 ffmpeg。

## 安装与使用

要开始使用 video-use，请按照以下步骤操作：

1. **安装依赖**：确保你的系统已安装 Python 3.10 及以上版本以及 ffmpeg（需支持 libx264 与 aac 编码）。
2. **克隆仓库与配置**：执行 `git clone https://github.com/browser-use/video-use.git` 后，根据 `install.md` 中的引导完成仓库初始化配置，其中包含将 video-use 注册为代理可用的 MCP（Model Context Protocol）工具，并设置好 ffmpeg 的 PATH 环境变量。
3. **工具集成**：在 Claude Code、Codex 或 Hermes 等支持 MCP 的编码代理中，添加新工具并指向 video-use 的启动脚本。

**一个最小可用的使用示例如下**：

1. 创建一个项目文件夹，并将你的原始视频素材（如 `interview_raw.mp4`）放入其中。
2. 在代理的会话界面中，粘贴以下提示语：

```
请基于 /path/to/your/footage 文件夹中的素材，编辑一段最终成片。
请去除所有语气填充词，应用暖色调电影感分级，
并自动生成匹配字幕，最终输出 final.mp4。
```

3. 代理将调用 video-use 的工具链完成处理，并在工作区中生成最终的 `final.mp4` 文件。

## 适用场景

- **口播内容快速制作**：播客主或 YouTube 博主可将数小时的口播原始录音与视频交付 video-use，它可以自动去除所有口头语和冷场，同时生成高对比度的字幕风格，让内容更适宜短视频平台传播。
- **海量素材的智能混剪**：对于旅行 Vlog 或活动记录，用户无需手动挑选镜头，只需告诉代理“选出包含人物表情的特写镜头，按照时间顺序拼接”，video-use 即可配合代理完成素材分析与剪辑排序。
- **教学视频的自动化后期**：录制屏幕或 PPT 讲解时，可设定统一的色彩与压缩规格，大段录制内容可自动切分章节并为每个知识点生成配套的 Manim 动画示意图，极大节省教师社群的内容产出时间。

## 项目亮点

与 CapCut、Premiere Pro 等传统编辑器以及 SSIM 等自动剪辑库相比，video-use 的独特之处在于将大语言模型的“意图理解”能力置于编辑流程的中央。传统软件要求用户手动设置滤镜参数与时间轴，而 video-use 允许代理自主推理如何安排动画、决定哪一部分色彩需要调整，这意味着其具备近乎无限的可扩展性——任何能够被描述为“视频处理命令”的新需求，都可以在不更新软件本身的前提下被代理通过调用既有工具完成。

此外，项目的记忆机制带来了连贯的长期工作体验，且完全开源免费，与商业 SaaS 类剪辑工具形成了鲜明对比，赋予了开发者完全掌控自己数据与工作流的自由。
