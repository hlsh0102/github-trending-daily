## 项目概述

学术研究是一个复杂且漫长的过程，从选题、文献调研、实验设计、论文撰写到最终投稿发表，每一步都充满了繁琐的细节和重复性劳动。而对于使用 AI 辅助研究的学者来说，最大的痛点往往在于：AI 生成的初稿质量不稳定、引用格式错误频出、逻辑一致性难以保证，以及论文风格与个人学术履历脱节。

**Academic Research Skills for Claude Code** 正是为解决这一问题而生的开源项目。它是一个专为 Claude Code 设计的功能扩展包，覆盖了从“研究 → 写作 → 审阅 → 修订 → 定稿”的完整学术出版管道。该项目并非一个简单的写作提示词集合，而是一套深度集成到 Claude Code 工作流中的模块化技能库。

该项目面向的目标用户包括：使用 Claude Code 作为编程助手的研究生、博士后、教师以及独立研究者。无论你是在撰写期刊论文、会议论文、学位论文还是基金申请书，只要你的工作流涉及 Claude Code，这套工具就能显著提升从草稿到定稿的效率。

## 核心功能

该插件提供了一套完整、可组合的学术研究技能，其主要功能包括：

- **规划与结构化（`/ars-plan`）**：通过苏格拉底式对话引导你梳理论文结构，而不是替你直接生成大纲，确保研究叙事逻辑自洽。
- **风格校准（Style Calibration）**：会学习你过往的写作样本，提取你的句式偏好、标点习惯和词汇选择，使得 AI 生成的内容更接近你的“学术声音”，而非千篇一律的机器腔调。
- **撰写质量检查（Writing Quality Check）**：内置检测算法，专门识别让散文读起来像 AI 生成的特征（如过度使用某种连词、句式过于整齐划一等），并提供修改建议。
- **引用格式化与文献追查（Reference Hunting）**：自动根据提供的文献列表查找正确的 DOI、补齐缺失的卷期页码，并按照目标期刊要求格式化引用。
- **逻辑与数据一致性校验**：对论文中的论证链条进行交叉检查，标记潜在的逻辑跳跃、断言与证据不匹配，以及数据引用不一致的问题。
- **修订与最终化**：提供从内审（Self-Review）到外部同行预审（Pre-Submission Review）的完整修订技能，确保终稿符合出版标准。

## 技术架构

该项目以 Claude Code 的 Skills 机制为核心构建。Claude Code 支持通过**插件（Plugin）市场**分发能力，而该仓库正是利用了这一点。

- **插件化安装**：项目被设计为标准的 Claude Code 插件，可通过 `/plugin marketplace add` 命令直接添加。这种架构使得技能包可以独立于主项目进行版本迭代，并支持多环境（CLI、VS Code、JetBrains）同步。
- **SKILL 文件定义**：每个技能（如 `/ars-plan`、`/ars-write`）由独立的 Markdown 文件定义，其中包含了供 Claude 模型理解和执行的详细指令、启发式规则和工作流模板。这种做法借鉴了认知科学中的“最小化可行提示词”设计理念，将复杂的学术规范编码为模型易于遵循的步骤。
- **Python 运行时支持**：尽管提示词是核心，但项目使用 Python 编写辅助脚本，用于处理无法通过文本提示词完成的确定性任务，例如 BibTeX 解析、DOI 验证查询、以及文本统计特征计算等。
- **风格提取管线**：在首次使用时，工具通过调用 Claude 的 API 分析你提供的文本样本，提取特征并生成一份个性化的风格偏好文档（如 JSON 或 Markdown），在下游任务中作为上下文追加到提示词中。

## 安装与使用

安装过程极其简单，前提是你已经安装了 Claude Code（版本需在 v3.7.0 及以上）。

**快速安装（市场方式）**：

在你的 Claude Code 环境下输入以下命令：

```text
/plugin marketplace add Imbad0202/academic-research-skills
/plugin install academic-research-skills
```

**手动安装（传统符号链接方式）**：

将仓库克隆至本地，然后将 `skills` 目录内的文件夹符号链接到 Claude 的配置目录（如 `~/.claude/skills`）即可。

**最小可用示例**：

安装完成后，你可以输入 `/ars-plan` 开始一次结构化访谈。系统会询问你关于论文的核心论点、目标期刊受众、主要证据来源等问题。通过对话生成骨架后，使用 `/ars-draft`（或与写作相关的其他技能）生成第一版稿件。

后续即可调用 `/ars-write` 进行章节写作，并在完成后运行 `/ars-review` 进行多轮质量检查与修订。

## 适用场景

- **论文初稿生成与格式整理**：尤其适用于时间紧张且参考文献量巨大的情况，可在数小时内完成从大纲到完整初稿的过程，且引文格式准确无误。
- **多轮期刊投稿与拒稿重投**：在收到编辑或审稿人意见后，需要针对评论逐条修改。该工具的修订技能可以强制检查是否每一条审稿意见都在“Response Letter”和正文修改中得到了响应。
- **非英语母语者的学术写作辅助**：Style Calibration 结合文法检查，能够大幅消除语言中的“中式英语”或翻译腔，帮助研究者更自信地提交英文手稿。
- **系统性文献综述撰写**：对于那些动辄包含上百篇参考文献的大综述，引用查找和格式化功能可以自动化处理文献的查漏补缺，并快速生成符合特定投稿期刊要求的参考文献列表。

## 项目亮点

相较于市面上的通用写作助手或“人类化（Humanizer）”工具，这个项目最大的差异在于**它不帮你“伪装”**。

1.  **以学术逻辑为优先**：许多工具只关注润色句子，而该项目首先关注的是论证结构的合理性。它能识别你论证中的弱环，而不是替你用华丽的辞藻掩盖它们。
2.  **个性化而非模板化**：风格校准功能学习的是你本人的写作特征，因此生成的文本在统计学特征上更像本人，而不是像一个平均水平的作者或一个模板化的“论文生成机”。
3.  **全流程管理而非单点作业**：它覆盖了从研究方向规划到最终投稿的完整生命周期，使得整个过程的状态和进度在 Claude Code 的上下文中是连贯的，无需频繁切换工具或重新描述上下文。
4.  **确定性与生成性的结合**：项目深刻地认识到大语言模型的随机性缺陷。因此，引用查重、DOI 验证、一致性哈希对比等工作通过脚本以确定性的方式完成，绝不依赖模型的“幻觉”猜测。
