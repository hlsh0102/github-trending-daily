Agent Toolkit for AWS 是 AWS 官方提供的插件和技能集合，旨在帮助 AI 编码助手（如 Claude Code、Codex、Cursor）在 AWS 上构建、部署和管理应用。它通过预构建的 MCP 服务器和工具，简化了 AI Agent 与 AWS 服务（如 CDK、Bedrock、Glue）的集成，让开发者无需手动配置即可让 AI 直接操作云资源。
