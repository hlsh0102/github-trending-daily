## 项目概述

SkillSpector 是一款专门用于扫描 AI 智能体技能安全性的工具。随着 Claude Code、Codex CLI、Gemini CLI 等 AI 编程助手的普及，用户频繁安装各种第三方技能包。然而，这些技能往往以隐式信任为基础执行，缺乏充分的审查流程。研究表明，**26.1% 的 AI 技能包含安全漏洞**，**5.2% 显示存在恶意意图**。

SkillSpector 致力于解决这一安全隐患，帮助用户在安装 AI 智能体技能之前回答一个关键问题：**“这个技能安装安全吗？”** 该项目由 NVIDIA 发布，面向 AI 开发者、安全工程师以及所有使用 AI 编程助手并关心安全性的用户。

## 核心功能

- **多格式输入支持**：可以扫描 Git 仓库、URL 链接、zip 压缩包、本地目录或单个文件，灵活适应不同的部署场景
- **64 种漏洞模式检测**：覆盖 16 个安全类别，包括提示注入、数据窃取、权限提升、供应链攻击、过度代理、输出处理、系统提示泄露、内存投毒、工具滥用、恶意智能体、触发器滥用、危险代码（AST 分析）、污点追踪、YARA 签名、MCP 最小权限和 MCP 工具投毒
- **两阶段分析流水线**：第一阶段执行快速的静态分析，快速筛选出明显问题；第二阶段可选使用 LLM 进行语义评估，深度检测复杂的安全风险
- **实时漏洞查询**：通过 SC4 模块向 OSV.dev 查询实时 CVE 数据，同时内置自动离线回退机制，确保断网环境也能正常运行
- **多种输出格式**：支持终端输出、JSON 报告、Markdown 报告和 SARIF 标准报告格式，便于集成到 CI/CD 流水线中
- **风险评分体系**：提供 0-100 的量化风险分数，配合严重等级标签和明确的安全建议，让用户快速做出安全决策

## 技术架构

SkillSpector 基于 Python 开发，采用模块化的分析引擎架构。其核心设计思路是“分层检测、逐步深入”：

第一层是**快速静态分析层**，主要依靠预定义的 64 种漏洞模式进行模式匹配和 AST 语法分析。这一层不依赖外部网络，执行效率高，能够在秒级时间内完成大多数常见恶意模式的检测。针对代码层面的安全风险，它使用 AST 分析检测危险函数调用和可疑代码模式；针对行为层面的风险，则通过 YARA 签名规则识别已知恶意模式。

第二层是**可选的 LLM 语义分析层**，利用大语言模型对代码进行更深层次的语义理解。这一层能够检测静态分析难以发现的复杂漏洞，例如跨函数的污点传播、隐式的权限提升逻辑等。用户可以根据安全需求和分析时间成本自主决定是否启用这一阶段。

数据流经过分析引擎后，进入**报告生成模块**。该模块将分析结果统一格式化为风险评分和报告输出。风险评分算法综合了漏洞数量、严重等级、攻击难度等多个维度，输出一个 0-100 的量化分数，并附带对应的安全建议。

组件设计上，SkillSpector 强调**可扩展性**。用户和开发者可以通过官方开发指南自定义检测规则、添加新的分析器，或集成到现有的安全工作流中。项目的开发文档详细说明了包布局和如何扩展分析器流水线。

## 安装与使用

**安装要求**：需要 Python 3.8 或以上版本。

**安装方式**：

```bash
pip install skillspector
```

或者从 GitHub 仓库克隆后本地安装：

```bash
git clone https://github.com/NVIDIA/SkillSpector.git
cd SkillSpector
pip install -r requirements.txt
```

**基本使用示例**：

扫描一个远程 Git 仓库：

```bash
skillspector scan https://github.com/example/some-agent-skill
```

扫描本地目录：

```bash
skillspector scan ./downloaded-skills/
```

输出 JSON 格式报告：

```bash
skillspector scan --format json ./skill-file.py
```

启用 LLM 语义分析（需要配置 LLM API）：

```bash
skillspector scan --llm-analysis --api-key YOUR_API_KEY ./skill-file.py
```

## 适用场景

- **技能市场审核**：在部署到官方或社区技能市场之前，对提交的 AI 智能体技能进行自动化安全检查，确保上架技能不包含恶意代码或已知漏洞
- **开发阶段安全集成**：将 SkillSpector 集成到团队的 CI/CD 流水线中，每次技能代码变更自动触发扫描，防止不安全代码进入生产环境
- **个人使用前的安全检查**：安全工程师或普通开发者在从互联网下载 AI 智能体技能包时，先使用 SkillSpector 进行本地扫描，确认无风险后再安装使用
- **安全研究分析**：安全研究人员使用 SkillSpector 对大量 AI 技能进行批量扫描，发现新型漏洞模式或攻击手法，推动安全意识提升和防御机制改进

## 项目亮点

- **专注垂直安全领域**：与通用代码扫描工具不同，SkillSpector 专门针对 AI 智能体技能这一新兴攻击面设计，覆盖了提示注入、系统提示泄露、过度代理等 AI 特有的风险类别
- **实时漏洞情报集成**：通过 OSV.dev 实时查询 CVE 数据，确保检测能力与最新公开漏洞保持同步，避免依赖过时的静态规则库
- **分层分析策略**：快速静态分析满足日常快速检查需求，可选的 LLM 语义分析提供更深层次的检测能力，用户可以按需平衡速度与深度
- **工业级输出标准**：支持 SARIF 格式，能够无缝集成到 GitHub Security Code Scanning、Azure DevOps 等主流安全工具生态，降低企业导入成本
