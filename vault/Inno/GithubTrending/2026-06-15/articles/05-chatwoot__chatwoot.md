## 项目概述

Chatwoot 是一个开源的客户支持平台，旨在为企业提供一套完整的全渠道沟通工具，涵盖在线实时聊天、邮件支持以及社交媒体消息处理等功能。该项目是商业客户支持系统如 Intercom、Zendesk 和 Salesforce Service Cloud 的替代方案，使企业能够在不依赖昂贵订阅服务的情况下，自主掌控客户沟通流程。目标用户包括需要轻量级、可自托管客服系统的中小型企业、初创团队以及注重数据隐私的开发者组织。项目以 Ruby on Rails 为主要技术栈，并集成了现代前端框架，提供了简洁、高效的用户界面。

## 核心功能

- **全渠道消息聚合**：支持网站实时聊天、电子邮件、Facebook Messenger、Twitter DM、WhatsApp、Telegram 和 LINE 等多个渠道的消息集成，所有对话集中在一个统一收件箱中管理。
- **自动化工作流**：通过自定义规则自动分配对话、设置自动回复、触发标签或通知，减少人工处理重复性任务的工作量。
- **多代理协作**：支持团队成员协同处理对话，提供内部备注、转发、对话合并与拆分等功能，便于高效分工。
- **智能对话机器人**：内置机器人框架，允许通过可视化编辑器或 API 构建自动化应答流程，处理常见查询并筛选复杂问题。
- **数据分析与报表**：提供实时仪表盘，展示客服团队响应时间、对话量、客户满意度评分等关键性能指标，支持数据导出。
- **客户上下文管理**：自动记录用户历史对话、浏览器信息、地理位置和行为事件，帮助客服人员快速了解客户背景。

## 技术架构

Chatwoot 采用经典的 Ruby on Rails 后端架构，配合 PostgreSQL 数据库存储核心业务数据，Redis 用于缓存和后台作业队列。前端基于 Vue.js 构建，使用 Webpack 进行模块打包，确保了 SPA（单页面应用）的流畅交互体验。项目采用 RESTful API 设计，支持 Webhook 和双向 API 集成，便于与第三方系统（如 CRM、工单系统）对接。核心消息处理依赖 Sidekiq 进行异步任务调度，以实现实时消息推送和邮件轮询。部署方面支持 Docker 容器化，提供一键部署脚本来简化本地或云服务器环境搭建，同时通过环境变量配置支持 HTTPS、SMTP 邮件服务以及外部存储（如 S3、GCS）集成。架构设计强调可扩展性，插件系统允许开发者通过 CORS 和白名单机制添加自定义渠道。

## 安装与使用

Chatwoot 提供多种部署方式，包括 Docker Compose 快速部署和手动源码安装。以下是通过 Docker 的最小安装示例：

1. **克隆仓库**：
   ```bash
   git clone https://github.com/chatwoot/chatwoot.git
   cd chatwoot
   ```

2. **配置环境变量**：
   复制 `.env.example` 至 `.env`，并修改 `SECRET_KEY_BASE`、`POSTGRES_PASSWORD` 等必要参数。

3. **启动服务**：
   ```bash
   docker-compose up -d
   ```

4. **数据库迁移与示例数据创建**：
   ```bash
   docker-compose exec chatwoot rails db:create db:migrate db:seed
   ```

5. **访问后台**：
   浏览器打开 `http://localhost:3000`，使用默认管理员账号（邮箱：`admin@chatwoot.com`，密码：`password`）登录。

使用过程中，用户可通过左侧导航栏的“收件箱”配置新渠道，例如通过添加 JavaScript 代码段将实时聊天小部件嵌入网站，或通过邮箱设置对接 IMAP/SMTP 邮件支持。所有渠道对话均会在统一界面中实时呈现，客服人员可像操作聊天软件一样进行回复和标签分类。

## 适用场景

- **中小型电商客服**：通过实时聊天和邮件集成处理订单查询、退换货请求，利用机器人自动回答常见物流问题，减少客服人力成本。
- **SaaS 产品技术支持**：团队内部使用 Chatwoot 接收用户反馈和 bug 报告，通过多渠道（网站、社交媒体、邮件）收集问题并统一流转处理。
- **社区运营群组**：管理 Telegram 或 Discord 群组成员发起的咨询，利用自动标签和分配规则区分新用户与老用户的需求。
- **隐私敏感型组织**：如医疗或教育机构，需要将客户数据存储在自己服务器上，避免使用第三方托管服务带来的合规风险。

## 项目亮点

Chatwoot 的核心差异化优势在于其完全开源且透明。与商业竞品相比，用户可自行部署至本地或私有云，避免了数据外传和供应商锁定问题；得益于活跃的开源社区，项目持续快速迭代，支持多达 20 种语言界面。技术上采用现代化前后端分离架构，性能优于许多基于 PHP 的老牌开源客服系统。此外，该项目提供了丰富的 API 文档和可扩展性，允许开发者通过插件或自定义渠道轻松集成现有业务系统，而无需受制于平台功能限制。相较于自研客服系统，Chatwoot 开箱即用且功能成熟，极大地降低了开发投入。
