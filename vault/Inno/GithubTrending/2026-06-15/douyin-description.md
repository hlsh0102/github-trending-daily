今日 GitHub 热点速报：10 个你不能错过的开源项目 🚀

#1 iptv-org/iptv 📺
全球公共 IPTV 频道资源合集，提供 M3U 播放列表，粘贴到播放器就能看世界各地电视，适合想摆脱有线电视订阅的朋友。

#2 freeCodeCamp/freeCodeCamp 💻
知名免费编程学习平台开源版，覆盖全栈开发和机器学习课程，已帮超 10 万人找到首份开发者工作，自学党首选。

#3 pytest-dev/pytest 🧪
Python 生态最流行的测试框架，语法简洁、插件丰富，支持从单元测试到端到端测试，开发者必备工具。

#4 swc-project/swc ⚡
基于 Rust 的高性能 JS/TS 编译器，比 Babel 快 20 倍以上，能大幅缩短构建时间，大型项目团队必看。

#5 chatwoot/chatwoot 💬
开源客户支持平台，替代 Intercom/Zendesk，支持网站聊天、邮件和社交媒体消息聚合，可自托管，注重数据隐私。

#6 NVIDIA/SkillSpector 🔒
AI 代理技能安全扫描工具，检测 64 种漏洞模式，能预防提示注入和数据窃取，安装前先扫一下。

#7 meshery/meshery 🛠️
开源云原生管理器，统一管理 Kubernetes 和服务网格，提供性能测试和可视化拓扑，多云环境利器。

#8 cypress-io/cypress 🖥️
前端端到端测试框架，直接在浏览器中运行，支持实时重载和自动等待，调试体验一流。

#9 GorvGoyl/Clone-Wars 🎯
收录 100+ 热门网站（如 Netflix、TikTok）的克隆项目合集，附源码和教程，适合通过仿写练手。

#10 Introduction-to-Autonomous-Robots 📚
开源自主机器人教材，涵盖运动学、感知和规划等核心算法，理工科学生和研究者可自取。
